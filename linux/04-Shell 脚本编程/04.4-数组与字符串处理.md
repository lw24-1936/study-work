## 概述

数组和字符串处理是脚本处理「一批数据」和「文本变换」的核心。数组分一维数组（下标数字）和关联数组（下标字符串，类似字典）；字符串处理靠「参数扩展」——bash 内置的一整套 `${var...}` 语法，能做截取、去前后缀、替换、默认值。这些语法不用调用外部命令（sed/awk），脚本里就地完成、速度快。

```text
三类核心能力：
1. 一维数组 —— arr=(a b c)，${arr[0]} 取值、${arr[@]} 全部、${#arr[@]} 长度
2. 关联数组 —— declare -A map，map[key]=val，${map[key]} 取值
3. 参数扩展 —— ${s:pos:len} 截取、${s#prefix} 去前缀、${s%suffix} 去后缀、${s/old/new} 替换
```

## 核心概念

三类核心能力：一维/关联数组、字符串截取替换、参数扩展。下面三个小节逐一展开。

### 一维与关联数组

一维数组用 `arr=(元素...)` 定义，下标从 0 开始，`${arr[0]}` 取第一个、`${arr[@]}` 取全部、`${#arr[@]}` 取长度。关联数组要先 `declare -A` 声明，下标是字符串，`map[key]=value` 赋值、`${map[key]}` 取值——适合做「名字到值」的映射，比如配置项、计数器。关联数组是 bash 4+ 特性，老系统注意兼容。

```bash
arr=(apple banana cherry)
echo "一维数组全部: ${arr[@]}"
echo "第1个元素: ${arr[0]}   数组长度: ${#arr[@]}"

declare -A map
map[name]=alice
map[age]=30
echo "关联数组: name=${map[name]} age=${map[age]}"
```

```text
# 实测
一维数组全部: apple banana cherry
第1个元素: apple   数组长度: 3
关联数组: name=alice age=30
```

### 字符串截取与替换

字符串处理全靠参数扩展语法：`${s:pos:len}` 从 pos 起截 len 个字符、`${s:pos}` 从 pos 到末尾、`${#s}` 长度、`${s#prefix}` 去掉最短前缀、`${s##prefix}` 去掉最长前缀、`${s%suffix}` 去掉最短后缀、`${s%%suffix}` 去掉最长后缀、`${s/old/new}` 替换第一个、`${s//old/new}` 替换全部。这套语法是脚本里处理路径、文件名、字符串的主力。

```bash
s="hello world"
echo "截取前5个: ${s:0:5}   从第6个起: ${s:6}   总长度: ${#s}"
echo "去前缀: ${s#hello }   去后缀: ${s% world}   替换: ${s/world/linux}"
```

```text
# 实测
截取前5个: hello   从第6个起: world   总长度: 11
去前缀: world   去后缀: hello   替换: hello linux
```

### 参数扩展

参数扩展提供「变量默认值」类的能力：`${var:-默认}` 变量为空/未定义时用默认值（不改 var）、`${var:=默认}` 为空时赋默认值并返回（会改 var）、`${var:?错误信息}` 为空时报错退出、`${var:+替代}` 非空时返回替代值。这些语法让脚本在「变量可能没设置」的场景下健壮——尤其 `${1:?用法}` 强制参数非空，是写脚本的常用 guard。

```bash
unset x
echo "默认值: ${x:-default}"      # 返回 default，x 仍是空
echo "仍为空: ${x:-empty}"
```

```text
# 实测
默认值: default
仍为空: empty
# ${x:-default} 只返回默认值不赋值；${x:=default} 会真正给 x 赋值
```

## 工作原理

参数扩展 `${...}` 是 bash 内置的「字符串求值器」——不调外部命令，直接在当前 shell 里完成截取/替换/默认值，所以快。数组在 bash 里是「带数字/字符串下标的变量集合」，关联数组（declare -A）底层是哈希表，下标是字符串。这些操作都在 shell 内部完成，不 fork。

```text
参数扩展 = 内置字符串求值，不调外部命令（快）
${s:pos:len} 截取 / ${s#p} 去前缀 / ${s/old/new} 替换 / ${var:-d} 默认值
一维数组 arr=(...) 数字下标；关联数组 declare -A 字符串下标（哈希）
```

## 常用命令与配置

```shell
arr=(a b c)            # 定义一维数组
declare -A map         # 定义关联数组
echo "${arr[@]}"       # 全部元素
echo "${#arr[@]}"      # 数组长度
echo "${s:0:5}"        # 截取
echo "${s/old/new}"    # 替换
```

## 配置文件解析

数组/字符串处理不直接对应配置文件，但常用来解析配置——用 while read 逐行读配置文件，用参数扩展拆分 KEY=VALUE、去注释、去空白。

```text
解析 KEY=VALUE 配置：
while IFS='=' read -r k v; do
  k=${k%% *}            # 去尾部空白
  case $k in \#*) continue;; esac   # 跳过注释
  config["$k"]=$v       # 存进关联数组
done < config.ini
```

## 应用场景实战

### 场景一：批量处理文件时用数组收集结果

```bash
#!/usr/bin/env bash
# 找出大文件，用数组收集后统一处理
big_files=()
while IFS= read -r f; do
    big_files+=("$f")
done < <(find /var/log -type f -size +50M 2>/dev/null)

echo "找到 ${#big_files[@]} 个大文件："
for f in "${big_files[@]}"; do
    echo "  $f"
done
```

### 场景二：解析路径和文件名

```bash
#!/usr/bin/env bash
path="/var/log/nginx/access.log"
echo "目录: ${path%/*}"           # /var/log/nginx（去最短后缀，即文件名）
echo "文件名: ${path##*/}"        # access.log（去最长前缀，即目录）
echo "扩展名: ${path##*.}"        # log
echo "去扩展名: ${path%.*}"       # /var/log/nginx/access
```

## 性能与调优

```text
1. 字符串处理用参数扩展，比 sed/awk 少开子进程
2. 关联数组 O(1) 查找，适合做「键值查找/计数」，别用线性遍历
3. 大数组追加 arr+=(x) 比 arr=("${arr[@]}" x) 快
4. 循环里重复 ${#s} 长度不变时可先存变量
```

## 安全与权限

```text
1. 关联数组 key 来自外部输入时，注意 key 含特殊字符（空格/换行）
2. 用 ${var:?} 强制变量非空，避免空值拼进路径
3. 处理用户输入文件名时用参数扩展去路径（防路径穿越）
```

## 故障排查

```shell
declare -p arr         # 查看数组完整内容（调试）
# 常见：关联数组没 declare -A、数组下标越界返回空不报错
set -u                 # 让未定义变量报错
```

## 常见问题

```text
Q1: 关联数组 map[key]=v 报错？
A: 没 declare -A map，先声明关联数组。

Q2: ${arr[@]} 遍历元素被拆断？
A: 加引号 "${arr[@]}"，否则含空格元素被拆。

Q3: ${var:-默认} 不改变量？
A: - 只返回默认值，要「返回并赋值」用 ${var:=默认}。

Q4: ${s#p} 去前缀没去干净？
A: 单 # 去最短匹配，贪婪用双 ##（${s##p}）。
```

## 面试题

```text
1. 一维数组和关联数组的区别？
   答：一维数组数字下标，关联数组（declare -A）字符串下标，bash 4+ 支持。

2. ${var:-x} 和 ${var:=x} 的区别？
   答：- 只返回默认值不改 var，= 返回并赋值给 var。

3. 怎么去掉字符串的前后缀？
   答：${s#prefix} 去最短前缀、${s##prefix} 去最长前缀、${s%suffix} 去最短后缀。

4. 遍历数组为什么加引号？
   答："${arr[@]}" 每个元素独立保留，不加引号按空白拆分。
```

## 最佳实践与踩坑记录

### 最佳实践

1. 遍历数组用 for f in "${arr[@]}"，加引号防元素含空格被拆
2. 解析路径/文件名用参数扩展（${path##*/}），比 basename/dirname 快且不用子进程
3. 关联数组用 declare -A，适合「键值映射」，但注意 bash 4+ 才有
4. 变量可能为空时用 ${var:-默认} 给兜底，强制非空用 ${var:?错误}
5. 字符串处理优先参数扩展，sed/awk 留给复杂场景

### 踩坑记录

```text
坑 1：遍历数组用 ${arr[@]} 不加引号，元素含空格被拆
结论：arr=("a b" "c d") 遍历时被拆成 a、b、c、d 四个。
原因：${arr[@]} 不加引号会按空白重新分词。
解法：始终用 "${arr[@]}" 加引号遍历。

坑 2：关联数组没 declare -A 声明
结论：map[key]=val 当普通数组用，key 被当成下标 0。
原因：不 declare -A 就是普通数组，字符串下标不生效。
解法：关联数组必须先 declare -A map。

坑 3：${s#prefix} 和 ${s##prefix} 混淆
结论：想贪婪去前缀却用了单 #，结果没去干净。
原因：单 # 去掉「最短」匹配，双 ## 去掉「最长」匹配。
解法：路径去目录用 ${path##*/}（最长前缀），去文件名用 ${path%/*}（最短后缀）。

坑 4：数组下标越界不报错返回空
结论：${arr[100]} 越界不报错，静默返回空字符串。
原因：bash 数组越界访问不报错，返回空。
解法：先判断下标 < ${#arr[@]}，或用 set -u 让未设置变量报错。

坑 5：${var:-默认} 和 ${var:=默认} 混淆
结论：以为 ${var:-默认} 会给 var 赋值，结果后续用 $var 还是空。
原因：- 只返回默认值不改变量，= 才真正赋值。
解法：要「返回且赋值」用 :=，只「临时兜底」用 :-。
```
