## 概述

脚本光会顺序执行不够，还得会「算」和「判断」。运算符负责算术（`$(( ))`）和字符串/数值比较，流程控制负责分支（if/case）和循环（for/while/until/select）。这是脚本从「命令清单」升级为「真正程序」的关键一步——写巡检脚本、部署脚本、批量处理，全靠这几样。

```text
流程控制全景：
1. 算术 —— $((3 + 5 * 2)) 整数运算，支持 + - * / % 及位运算
2. 判断 —— test / [] 老式，[[]] 增强（支持 && || 正则 =~）
3. 分支 —— if / case，case 适合多值匹配
4. 循环 —— for 遍历列表、while 条件循环、until 直到为真、select 菜单
```

## 核心概念

运算符与流程控制的核心：算术求值、条件判断、分支、循环。下面四个小节逐一展开，每节按「是什么 → 为什么 → 怎么用 → 边界/易错点」讲。

### 算术与字符串运算

**是什么**：算术运算用 `$(( ))`，支持加减乘除取模和位运算，注意是整数运算。字符串运算主要是比较（`==` 相等、`!=` 不等、`-z` 判空、`-n` 判非空、`<` `>` 字典序）和长度/截取。

**为什么**：脚本要算数（循环计数器、百分比、端口号加减）、要比字符串（判断环境名、文件名、配置值），没有运算符这些都得调外部命令，又慢又绕。

**怎么用**：

```shell
echo "3+5*2 = $((3 + 5 * 2))"
a=10; b=3
echo "10/3 = $((a / b))   10%3 = $((a % b))"
s="hello world"
echo "字符串长度: ${#s}"
```

```text
# 实测
3+5*2 = 13
10/3 = 3   10%3 = 1
字符串长度: 11
```

**复合赋值与自增自减**：算术里可以用 C 风格写法，`(( ))` 双括号是算术求值环境，变量不用写 `$`。

```shell
n=0
((n++))                 # n=1
((n += 5))              # n=6
echo "n=$n"

a=5
((a--))                 # a=4
echo "a=$a"
```

**位运算**：`<<` `>>` 移位、`&` 与、`|` 或、`^` 异或、`~` 取反，处理标志位、权限位、子网掩码时用。

```shell
echo "$((1 << 3))"     # 8（1 左移 3 位）
echo "$((0b1010 & 0b1100))"  # 8（按位与）
echo "$((5 ^ 3))"      # 6（异或）
```

**小数运算**：`$(( ))` 只能整数，要小数用 `bc` 或 `awk`。

```shell
echo "scale=2; 10/3" | bc        # 3.33
awk 'BEGIN { printf "%.2f\n", 10/3 }'  # 3.33
```

**字符串拼接与截取**：

```shell
a="hello"; b="world"
echo "$a $b"             # hello world（空格拼接）
echo "${a}_${b}"         # hello_world（下划线拼接）
echo "${a:0:3}"          # hel（从 0 开始取 3 个字符）
echo "${a^^}"            # HELLO（转大写）
echo "${a^^}${b^^}"      # HELLOWORLD
```

**边界/易错点**：

- `10/3` 结果是 3 不是 3.33——bash 算术是整数运算，除法取整。
- `$(( ))` 里变量可以不写 `$`（`$((a+b))` 和 `$(($a+$b))` 都对），但混着写易错，建议统一不写 `$`。
- 字符串 `<` `>` 在 `[ ]` 里要转义（`\<` `\>`），在 `[[ ]]` 里不用；这是字典序比较，不是数值比较。

### 条件判断 test 与 [[]]

**是什么**：条件判断有两种写法——老式 `test`（或 `[ ]`，本质是外部 test 命令）和新式 `[[ ]]`（bash 关键字）。`[[ ]]` 是增强版，支持 `&&` `||` 逻辑、`=~` 正则匹配、字符串比较不用加引号防拆分，是现在的推荐写法。

**为什么**：所有分支和循环都靠「条件是否成立」驱动，而条件就是一条返回退出码的命令。`[ ]` 空变量会报错、逻辑组合要分写，`[[ ]]` 解决了这些坑。

**怎么用**：数值比较在 `[ ]` 和 `[[ ]]` 里都用 `-eq -ne -gt -lt -ge -le`，字符串用 `== != -z -n`。

```shell
s1="abc"; s2="abc"
[[ $s1 == $s2 ]] && echo "s1==s2"
[ -z "$s1" ] && echo "s1为空" || echo "s1非空"
num=10
[ $num -gt 5 ] && echo "num大于5"
```

```text
# 实测
s1==s2
s1非空
num大于5
# 记忆：数值比较 -gt/-lt/-eq，字符串比较 ==/!=，判空 -z/-n
```

**文件测试**：`-e` 存在、`-f` 是普通文件、`-d` 是目录、`-r/-w/-x` 可读/写/执行、`-s` 非空、`-L` 符号链接、`-nt/-ot` 新旧比较。

```shell
f="/etc/hostname"
[[ -e $f ]] && echo "$f 存在"
[[ -f $f ]] && echo "$f 是普通文件"
[[ -d $f ]] && echo "$f 是目录" || echo "$f 不是目录"
[[ -s $f ]] && echo "$f 非空"
```

**逻辑组合**：`[[ ]]` 里用 `&&` `||` `!` 组合多个条件，比 `[ ]` 的 `-a` `-o` 清晰。

```shell
age=25
[[ $age -ge 18 && $age -lt 60 ]] && echo "劳动年龄"
[[ ! -e /tmp/nofile ]] && echo "文件不存在"
```

**正则匹配 `=~`**：在双中括号测试里用 `=~` 运算符做正则匹配，匹配结果存 `BASH_REMATCH` 数组。

```shell
ip="192.168.1.100"
if [[ $ip =~ ^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
  echo "$ip 是合法 IP"
fi
```

**算术条件 `(( ))`**：纯算术比较用 `(( ))` 更简洁，返回退出码可直接当 if 条件。

```shell
x=10
(( x > 5 )) && echo "x>5"
(( x == 10 )) && echo "x==10"
```

**边界/易错点**：

- `[ ]` 里 `==` 不是 POSIX（有些环境只认 `=`），数值比较必须用 `-eq`，字符串比较放 `[[ ]]` 里用 `==`。
- `[ ]` 里变量为空会报 `unary operator expected`；`[[ ]]` 空变量安全。
- `=~` 右边正则别加引号（加引号会被当字面字符串匹配）；正则来源要可控，别用未验证输入拼（防 ReDoS）。

### if 与 case

**是什么**：if 做二选一或多条件分支，语法 `if 条件; then ... elif ...; else ...; fi`。case 做多值匹配，语法 `case 值 in 模式) ... ;; esac`，模式支持 `|` 或和 `*` `?` `[ ]` 通配。

**为什么**：脚本要根据不同情况走不同逻辑——成功/失败、不同环境、不同发行版。判断「变量是几个已知值中的哪个」用 case 比一堆 if/elif 清晰得多。

**怎么用**：

```shell
num=10
if [ $num -gt 5 ]; then
  echo "num>5"
else
  echo "num<=5"
fi

os="ubuntu"
case $os in
  ubuntu|debian) echo "Debian 系" ;;
  centos|rocky)  echo "Red Hat 系" ;;
  *) echo "其他" ;;
esac
```

```text
# 实测
num>5
Debian 系
```

**if/elif 多分支与嵌套**：

```shell
score=85
if [ $score -ge 90 ]; then
  echo "优秀"
elif [ $score -ge 60 ]; then
  echo "及格"
else
  echo "不及格"
fi
```

**case 模式匹配**：`*` 匹配任意串、`?` 匹配单个字符、`[abc]` 匹配字符集、`|` 匹配多个。

```shell
read -p "输入 y/n: " ans
case "$ans" in
  y|Y|yes|YES) echo "确认" ;;
  n|N|no|NO)   echo "取消" ;;
  *) echo "无效输入" ;;
esac
```

**判断命令是否成功（if 直接接命令）**：if 后面可以直接接命令，不一定要 `[ ]`。

```shell
if ping -c 1 -W 1 8.8.8.8 > /dev/null 2>&1; then
  echo "网络可达"
else
  echo "网络不可达"
fi
```

**边界/易错点**：

- if 忘写 `fi`、case 忘写 `esac`，语法直接报错，是最常见的漏写。
- case 分支末尾漏 `;;` 会 fall-through，继续执行下一个分支。
- case 的模式是通配符（glob）不是正则，`*` 匹配任意串但 `.` 不是「任意字符」。

### for 与 while 与 until 与 select

**是什么**：四种循环各有场景——for 遍历已知列表（文件、数字序列、命令结果）；while 条件为真就循环（读文件、等条件满足）；until 条件为假就循环（和 while 相反，等到满足才停）；select 生成交互式菜单。

**为什么**：批量处理靠循环——遍历一堆文件、轮询一个条件、反复重试，都离不开循环。日常 90% 用 for 和 while。

**怎么用**：

```shell
# for：遍历列表
for i in 1 2 3; do echo "第 $i 次循环"; done

# while：条件循环（倒计时）
n=3
while [ $n -gt 0 ]; do echo "倒计时 $n"; n=$((n-1)); done
```

```text
# 实测
第 1 次循环
第 2 次循环
第 3 次循环
倒计时 3
倒计时 2
倒计时 1
```

**for 的几种列表来源**：

```shell
for f in *.txt; do echo "文件: $f"; done          # glob 通配
for i in {1..5}; do echo "$i"; done                # 花括号展开 1 2 3 4 5
for i in $(seq 1 5); do echo "$i"; done            # seq 生成序列
for f in "$@"; do echo "参数: $f"; done            # 遍历位置参数
for ((i=0; i<5; i++)); do echo "i=$i"; done        # C 风格 for
```

**while 读文件逐行处理**：

```shell
while IFS= read -r line; do
  echo "读到: $line"
done < /etc/hostname
```

**until 反向条件**：条件为假就继续，为真才停。

```shell
n=1
until [ $n -gt 3 ]; do
  echo "n=$n"
  n=$((n+1))
done
```

**select 交互菜单**：`select` 自动生成带序号的菜单，用户输入序号选择，`$REPLY` 是序号、选中的项存变量里。

```shell
PS3="请选择: "
select opt in "启动" "停止" "重启" "退出"; do
  case $opt in
    启动) echo "执行启动" ;;
    停止) echo "执行停止" ;;
    重启) echo "执行重启" ;;
    退出) echo "再见"; break ;;
    *) echo "无效选项" ;;
  esac
done
```

**break 与 continue**：`break` 跳出整个循环，`continue` 跳过本次进入下一次，`break N` 跳出 N 层循环。

```shell
for i in {1..5}; do
  [ $i -eq 3 ] && continue    # 跳过 3
  [ $i -eq 5 ] && break       # 到 5 就停
  echo "$i"
done
```

**边界/易错点**：

- `for f in $(ls *.txt)` 遇空格文件名被拆断，改用 `for f in *.txt`（glob 不拆分）或 `while read`。
- 管道里的 while 循环跑在子 shell 里，循环内改的变量循环外读不到（经典陷阱）。
- `while read` 会吞掉每行末尾空格（IFS 分词），要原样读用 `while IFS= read -r line`。

## 工作原理

Shell 里「判断和循环」靠退出码驱动：test/`[[]]` 判断返回 0（真）或非 0（假），if/while 根据这个退出码决定走哪个分支。算术 `$(( ))` 是 shell 内置的整数求值器，字符串比较走 test 的字符串语义。

```text
判断原理：命令的退出码 0=真 / 非 0=假
if 条件; then —— 条件是一条返回退出码的命令（[[ ]] / [ ] / test / 任意命令）
$(( )) 整数求值器，[[ ]] 支持 =~ 正则
```

`(( ))` 的退出码规则和 `[ ]` 相反——`(( 表达式 ))` 里表达式结果为 0（假）时退出码是 1，结果非 0（真）时退出码是 0。所以 `(( x > 5 ))` 当 x=10 时退出码为 0，if 判断为真。

```text
(( )) 退出码细节：
(( 0 ))  → 退出码 1（算术值 0 = 假）
(( 1 ))  → 退出码 0（算术值非 0 = 真）
```

## 常用命令与配置

```shell
[ $a -eq $b ]          # 数值相等判断（test 命令）
[[ $a == $b ]]         # 字符串相等（bash 增强）
(( a > b ))            # 算术比较（C 风格）
test -f file           # 文件测试
case ... esac          # 多值匹配
for / while / until    # 循环
select ... do ... done # 交互菜单
break / continue       # 跳出/继续循环
seq 1 10               # 生成数字序列
```

## 配置文件解析

流程控制本身没有配置文件，但它常配合读取配置——如 `. /etc/os-release` 读发行版信息（ID/VERSION_ID 变量），配合 case 判断发行版。这是脚本里「读配置 + 分支」的典型组合。

```text
/etc/os-release：ID（发行版代号）、VERSION_ID（版本）
脚本里 . /etc/os-release 后，$ID 就是发行版名，case "$ID" 分支处理
```

自己写的脚本配置也走「读变量 → 分支」的模式：配置文件里放 `KEY=value`，脚本 source 引入后用 case/if 分支处理。

```shell
# config.sh —— 简单键值配置
APP_ENV=production
APP_PORT=8080
```

```shell
# 主脚本 source 后按配置分支
source ./config.sh
case "$APP_ENV" in
  production) echo "生产环境，端口 $APP_PORT" ;;
  *) echo "非生产环境" ;;
esac
```

## 应用场景实战

### 场景一：按磁盘使用率分级告警的巡检脚本

```bash
#!/usr/bin/env bash
# 检查根分区使用率，分级输出
usage=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$usage" -ge 90 ]; then
  echo "严重：磁盘使用率 $usage%（需立即清理）"
elif [ "$usage" -ge 80 ]; then
  echo "警告：磁盘使用率 $usage%（建议清理）"
else
  echo "正常：磁盘使用率 $usage%"
fi
```

### 场景二：根据发行版选对包管理器

```bash
#!/usr/bin/env bash
. /etc/os-release
case "$ID" in
  ubuntu|debian)   pkg="apt install -y" ;;
  rhel|rocky|almalinux|centos) pkg="dnf install -y" ;;
  arch|manjaro)    pkg="pacman -S --noconfirm" ;;
  *) echo "未知发行版: $ID"; exit 1 ;;
esac
echo "本机包管理命令：$pkg"
```

### 场景三：批量重命名文件 + 服务就绪轮询

两个高频组合：for 循环批量处理文件、while 循环等服务就绪。

```bash
#!/usr/bin/env bash
# 1) for 批量把 .tmp 后缀改成 .txt
for f in *.tmp; do
  [ -e "$f" ] || continue          # 没有匹配时 glob 原样返回，跳过
  mv "$f" "${f%.tmp}.txt"
  echo "重命名: $f -> ${f%.tmp}.txt"
done

# 2) while 轮询等服务端口起来（最多等 30 秒）
count=0
while ! curl -sf http://127.0.0.1:8080/health > /dev/null; do
  count=$((count + 1))
  [ $count -ge 30 ] && { echo "服务启动超时" >&2; exit 1; }
  sleep 1
done
echo "服务已就绪"
```

## 性能与调优

```text
1. 用 [[ ]] 替代 [ ] —— 内置测试更快，且支持 && || 短路
2. 大循环用 while read，别用 for $(ls)（一次性展开 + 按空白分词）
3. 算术用 $(( ))，别调外部 expr（省子进程）
4. 提前 break 循环，避免无效迭代
5. 循环体里避免反复开子进程（命令替换、管道），把结果先算好再进循环
```

## 安全与权限

```text
1. 变量比较加引号，防空变量导致语法错误
2. 正则匹配 =~ 时注意模式来源，别用未验证输入拼正则（ReDoS/注入）
3. 脚本里读外部输入（read）要校验，别直接 eval
4. 数值比较前先确认变量是数字，避免非法值导致判断逻辑被绕过
5. case 分支务必写兜底的 *) 分支，未匹配时明确处理而不是静默跳过
```

## 故障排查

```shell
bash -n script.sh    # 语法错误（if/case 忘 fi/esac）
bash -x script.sh    # 看循环/分支实际走了哪条
# 常见：if 忘 fi、case 忘 esac、[ ] 里缺空格
```

```text
常见故障速查：
[ $a == $b ] 报错 → [ ] 里 == 非 POSIX，数值用 -eq、字符串放 [[]]
unary operator expected → 变量为空，加引号或换 [[ ]]
循环只执行一次就退出 → 检查 while 条件写反了没、变量是否被子 shell 隔离
case 连续执行多个分支 → 漏了 ;; 结束符
```

## 常见问题

```text
Q1: [ $a == $b ] 报错？
A: [ ] 里 == 不是 POSIX，数值比较用 -eq，字符串比较在 [[]] 里用 ==。

Q2: if 里 [ $num -gt 5 ] 报 unary operator expected？
A: $num 为空，条件缺操作数；用 [[ ]] 或加引号 "$num"。

Q3: for i in $(ls) 处理文件名含空格出错？
A: $( ) 结果按空白分词，改用 for f in *.txt 或 while read。

Q4: case 匹配后连续执行了多个分支？
A: 漏了 ;; 结束符，每个分支末尾都要写 ;;。

Q5: 管道里的 while 循环改了变量，循环外读不到？
A: 管道让循环跑在子 shell，变量修改不传回；用进程替换 while read < <(cmd) 或把结果写文件。

Q6: $((10/3)) 结果是 3 不是 3.33？
A: bash 算术是整数运算，除法取整；要小数用 bc（echo "scale=2; 10/3" | bc）或 awk。

Q7: until 和 while 有什么区别？
A: while 条件为真才循环，until 条件为假才循环（为真就停）；until 等价于 while ! 条件。

Q8: for ((i=0; i<5; i++)) 和 for i in {1..5} 有什么区别？
A: 前者是 C 风格算术循环（bash 扩展，变量可参与），后者是花括号展开（静态列表，变量不能参与）。
```

## 面试题

```text
1. [ ] 和 [[ ]] 的区别？
   答：[ ] 是 test 命令（POSIX），[[ ]] 是 bash 关键字，支持 && || =~ 正则且空变量安全。

2. 数值比较和字符串比较用什么操作符？
   答：数值 -eq/-ne/-gt/-lt/-ge/-le，字符串 ==/!=/-z/-n。

3. break 和 continue 的区别？
   答：break 跳出整个循环，continue 跳过本次进入下一次。

4. 如何遍历一个目录下的所有文件？
   答：for f in *.txt 或 find ... | while read f，别用 for f in $(ls)。

5. until 和 while 的关系？
   答：until 条件为假才循环，等价于 while ! 条件；while 是条件为真才循环。

6. (( )) 和 $(( )) 有什么区别？
   答：$(( )) 求值并返回结果（用于取值），(( )) 求值并返回退出码（用于条件判断，可直接当 if 条件）。

7. =~ 正则匹配时右边为什么不能加引号？
   答：加引号后模式被当作字面字符串匹配，失去正则语义；匹配结果存 BASH_REMATCH 数组。

8. case 的模式和正则表达式一样吗？
   答：不一样，case 用通配符（glob）：* 任意串、? 单字符、[abc] 字符集、| 或；不是正则语法。
```

## 最佳实践与踩坑记录

### 最佳实践

1. 条件判断优先用 [[ ]]，支持 && || 和正则，比 [ ] 更安全
2. 数值比较用 -eq/-gt/-lt，字符串用 ==/!=，别混用
3. 多值匹配用 case，比一串 if/elif 清晰且好维护
4. 遍历列表用 for x in "$@"，读文件用 while read
5. 算术统一用 $(( ))，别用 expr（慢且老）
6. 纯算术条件用 (( )) 比 [ $a -gt $b ] 简洁，且不用担心空变量
7. case 每个分支都写 ;;，最后加 *) 兜底分支

### 踩坑记录

```text
坑 1：数值比较误用 == 当 -eq
结论：[ $num == 5 ] 在 bash 里是字符串比较，语义不对。
原因：== 是字符串比较，-eq 才是数值比较，混用导致判断错误。
解法：数值用 -eq -ne -gt -lt -ge -le，字符串才用 == !=。

坑 2：[ $x == $y ] 里 x 为空时报语法错误
结论：x 未定义时 [ $x == "abc" ] 报 unary operator expected。
原因：变量展开为空后，条件表达式缺操作数。
解法：用 [[ $x == "abc" ]]（双中括号里空变量安全），或加引号。

坑 3：算术 $(( )) 里变量没写 $ 也能用但混着写易错
结论：$((a + b)) 和 $(($a + $b)) 都对，但 $((10/3)) 结果是 3 不是 3.33。
原因：bash 算术是整数运算，除法取整。
解法：需要小数用 bc 或 awk（echo "10/3" | bc -l）。

坑 4：for 循环遍历命令输出被空格拆断
结论：for f in $(ls *.txt) 遇到含空格文件名被拆成多个。
原因：$(ls) 结果按空白分词，空格文件名被拆断。
解法：用 while read 或 for f in *.txt（glob 不拆分）。

坑 5：case 里忘了双分号导致 fall-through
结论：case 分支匹配后没写 ;;，继续执行下一个分支。
原因：;; 是 case 分支的结束标记，漏写会 fall-through。
解法：每个 case 分支末尾都写 ;;，esac 前最后一个可省略但建议统一写。

坑 6：管道里 while 循环内改的变量循环外读不到
结论：echo "$count" 在管道 while 循环外打印的是旧值。
原因：管道让右侧命令跑在子 shell，变量修改不传回父 shell。
解法：用进程替换 while read ... done < <(cmd)，避免子 shell 隔离。

坑 7：for f in *.txt 没匹配到文件时循环体仍执行一次
结论：目录下没有 .txt 文件时，循环体把 *.txt 当字面文件名处理了一次。
原因：glob 无匹配时默认原样返回模式串，不是空。
解法：循环体内加 [ -e "$f" ] || continue 跳过，或先 shopt -s nullglob。
```
