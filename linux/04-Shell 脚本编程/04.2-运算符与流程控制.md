## 概述

脚本光会顺序执行不够，还得会「算」和「判断」。运算符负责算术（`$(( ))`）和字符串/数值比较，流程控制负责分支（if/case）和循环（for/while/until）。这是脚本从「命令清单」升级为「真正程序」的关键一步——写巡检脚本、部署脚本、批量处理，全靠这几样。

```text
流程控制全景：
1. 算术 —— $((3 + 5 * 2)) 整数运算，支持 + - * / % 
2. 判断 —— test / [] 老式，[[]] 增强（支持 && || 正则 =~）
3. 分支 —— if / case，case 适合多值匹配
4. 循环 —— for 遍历列表、while 条件循环、until 直到为真、select 菜单
```

## 核心概念

运算符与流程控制的核心：算术求值、条件判断、分支、循环。下面四个小节逐一展开。

### 算术与字符串运算

算术运算用 `$(( ))`，支持加减乘除取模，注意是整数运算（10/3=3，不是 3.33）。字符串运算主要是比较：`==` 相等、`!=` 不等、`-z` 判空、`-n` 判非空、`<` `>` 字典序。字符串比较和数值比较用的是两套操作符，别混——数值用 `-eq -ne -gt -lt`，字符串用 `== !=`。

```shell
echo "3+5*2 = $((3 + 5 * 2))"
a=10; b=3
echo "10/3 = $((a / b))   10%3 = $((a % b))"
s="hello world"
echo "字符串长度: ${#s}"
```

```text
# 实测
3+5*2 = 13
10/3 = 3   10%3 = 1
字符串长度: 11
```

### 条件判断 test 与 [[]]

条件判断有两种写法：老式 `test`（或 `[ ]`）和新式 `[[ ]]`。`[[ ]]` 是 bash 的增强版，支持 `&&` `||` 逻辑、`=~` 正则匹配、字符串比较不用加引号防拆分，是现在的推荐写法。数值比较在 `[ ]` 和 `[[ ]]` 里都用 `-eq -ne -gt -lt -ge -le`，字符串用 `== != -z -n`。

```shell
s1="abc"; s2="abc"
[[ $s1 == $s2 ]] && echo "s1==s2"
[ -z "$s1" ] && echo "s1为空" || echo "s1非空"
num=10
[ $num -gt 5 ] && echo "num大于5"
```

```text
# 实测
s1==s2
s1非空
num大于5
# 记忆：数值比较 -gt/-lt/-eq，字符串比较 ==/!=，判空 -z/-n
```

### if 与 case

if 做二选一或多条件分支，语法 `if 条件; then ... elif ...; else ...; fi`。case 做多值匹配，语法 `case 值 in 模式) ... ;; esac`，模式支持 `|` 或和 `*` 通配。判断「某个变量是几个已知值中的哪个」用 case 比一堆 if/elif 清晰得多——发行版判断、命令选项解析都是 case 的主场。

```shell
num=10
if [ $num -gt 5 ]; then
  echo "num>5"
else
  echo "num<=5"
fi

os="ubuntu"
case $os in
  ubuntu|debian) echo "Debian 系" ;;
  centos|rocky)  echo "Red Hat 系" ;;
  *) echo "其他" ;;
esac
```

```text
# 实测
num>5
Debian 系
```

### for 与 while 与 until 与 select

四种循环各有场景：for 遍历已知列表（文件、数字序列、命令结果）；while 条件为真就循环（读文件、等条件满足）；until 条件为假就循环（和 while 相反，等到满足才停）；select 生成交互式菜单。日常 90% 用 for 和 while，select 只在写交互脚本时用。

```shell
# for：遍历列表
for i in 1 2 3; do echo "第 $i 次循环"; done

# while：条件循环（倒计时）
n=3
while [ $n -gt 0 ]; do echo "倒计时 $n"; n=$((n-1)); done
```

```text
# 实测
第 1 次循环
第 2 次循环
第 3 次循环
倒计时 3
倒计时 2
倒计时 1
```

## 工作原理

Shell 里「判断和循环」靠退出码驱动：test/`[[]]` 判断返回 0（真）或非 0（假），if/while 根据这个退出码决定走哪个分支。算术 `$(( ))` 是 shell 内置的整数求值器，字符串比较走 test 的字符串语义。

```text
判断原理：命令的退出码 0=真 / 非 0=假
if 条件; then —— 条件是一条返回退出码的命令（[[ ]] / [ ] / test）
$(( )) 整数求值器，[[ ]] 支持 =~ 正则
```

## 常用命令与配置

```shell
[ $a -eq $b ]          # 数值相等判断
[[ $a == $b ]]         # 字符串相等（bash 增强）
(( a > b ))            # 算术比较（C 风格）
case ... esac          # 多值匹配
for / while / until    # 循环
break / continue       # 跳出/继续循环
```

## 配置文件解析

流程控制本身没有配置文件，但它常配合读取配置——如 `. /etc/os-release` 读发行版信息（ID/VERSION_ID 变量），配合 case 判断发行版。这是脚本里「读配置 + 分支」的典型组合。

```text
/etc/os-release：ID（发行版代号）、VERSION_ID（版本）
脚本里 . /etc/os-release 后，$ID 就是发行版名，case "$ID" 分支处理
```

## 应用场景实战

### 场景一：按磁盘使用率分级告警的巡检脚本

```bash
#!/usr/bin/env bash
# 检查根分区使用率，分级输出
usage=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$usage" -ge 90 ]; then
  echo "严重：磁盘使用率 $usage%（需立即清理）"
elif [ "$usage" -ge 80 ]; then
  echo "警告：磁盘使用率 $usage%（建议清理）"
else
  echo "正常：磁盘使用率 $usage%"
fi
```

### 场景二：根据发行版选对包管理器

```bash
#!/usr/bin/env bash
. /etc/os-release
case "$ID" in
  ubuntu|debian)   pkg="apt install -y" ;;
  rhel|rocky|almalinux|centos) pkg="dnf install -y" ;;
  arch|manjaro)    pkg="pacman -S --noconfirm" ;;
  *) echo "未知发行版: $ID"; exit 1 ;;
esac
echo "本机包管理命令：$pkg"
```

## 性能与调优

```text
1. 用 [[ ]] 替代 [ ] —— 内置测试更快，且支持 && || 短路
2. 大循环用 while read，别用 for $(ls)（一次性展开 + 按空白分词）
3. 算术用 $(( ))，别调外部 expr（省子进程）
4. 提前 break 循环，避免无效迭代
```

## 安全与权限

```text
1. 变量比较加引号，防空变量导致语法错误
2. 正则匹配 =~ 时注意模式来源，别用未验证输入拼正则（ReDoS/注入）
3. 脚本里读外部输入（read）要校验，别直接 eval
```

## 故障排查

```shell
bash -n script.sh    # 语法错误（if/case 忘 fi/esac）
bash -x script.sh    # 看循环/分支实际走了哪条
# 常见：if 忘 fi、case 忘 esac、[ ] 里缺空格
```

## 常见问题

```text
Q1: [ $a == $b ] 报错？
A: [ ] 里 == 不是 POSIX，数值比较用 -eq，字符串比较在 [[]] 里用 ==。

Q2: if 里 [ $num -gt 5 ] 报 unary operator expected？
A: $num 为空，条件缺操作数；用 [[ ]] 或加引号 "$num"。

Q3: for i in $(ls) 处理文件名含空格出错？
A: $( ) 结果按空白分词，改用 for f in *.txt 或 while read。

Q4: case 匹配后连续执行了多个分支？
A: 漏了 ;; 结束符，每个分支末尾都要写 ;;。
```

## 面试题

```text
1. [ ] 和 [[ ]] 的区别？
   答：[ ] 是 test 命令（POSIX），[[ ]] 是 bash 关键字，支持 && || =~ 正则且空变量安全。

2. 数值比较和字符串比较用什么操作符？
   答：数值 -eq/-ne/-gt/-lt/-ge/-le，字符串 ==/!=/-z/-n。

3. break 和 continue 的区别？
   答：break 跳出整个循环，continue 跳过本次进入下一次。

4. 如何遍历一个目录下的所有文件？
   答：for f in *.txt 或 find ... | while read f，别用 for f in $(ls)。
```

## 最佳实践与踩坑记录

### 最佳实践

1. 条件判断优先用 [[ ]]，支持 && || 和正则，比 [ ] 更安全
2. 数值比较用 -eq/-gt/-lt，字符串用 ==/!=，别混用
3. 多值匹配用 case，比一串 if/elif 清晰且好维护
4. 遍历列表用 for x in "$@"，读文件用 while read
5. 算术统一用 $(( ))，别用 expr（慢且老）

### 踩坑记录

```text
坑 1：数值比较误用 == 当 -eq
结论：[ $num == 5 ] 在 bash 里是字符串比较，语义不对。
原因：== 是字符串比较，-eq 才是数值比较，混用导致判断错误。
解法：数值用 -eq -ne -gt -lt -ge -le，字符串才用 == !=。

坑 2：[[ $x == $y ]] 里 x 为空时报语法错误
结论：x 未定义时 [[ $x == "abc" ]] 报 unary operator expected。
原因：变量展开为空后，条件表达式缺操作数。
解法：用 [[ $x == "abc" ]]（双中括号里空变量安全），或加引号。

坑 3：算术 $(( )) 里变量没写 $ 也能用但混着写易错
结论：$((a + b)) 和 $(($a + $b)) 都对，但 $((10/3)) 结果是 3 不是 3.33。
原因：bash 算术是整数运算，除法取整。
解法：需要小数用 bc 或 awk（echo "10/3" | bc -l）。

坑 4：for 循环遍历命令输出被空格拆断
结论：for f in $(ls *.txt) 遇到含空格文件名被拆成多个。
原因：$(ls) 结果按空白分词，空格文件名被拆断。
解法：用 while read 或 for f in *.txt（glob 不拆分）。

坑 5：case 里忘了双分号导致 fall-through
结论：case 分支匹配后没写 ;;，继续执行下一个分支。
原因：;; 是 case 分支的结束标记，漏写会 fall-through。
解法：每个 case 分支末尾都写 ;;，esac 前最后一个可省略但建议统一写。
```
