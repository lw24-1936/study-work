## 概述

脚本光会顺序执行不够，还得会「算」和「判断」。运算符负责算术（`$(( ))`）和字符串/数值比较，流程控制负责分支（if/case）和循环（for/while/until）。这是脚本从「命令清单」升级为「真正程序」的关键一步——写巡检脚本、部署脚本、批量处理，全靠这几样。

```text
流程控制全景：
1. 算术 —— $((3 + 5 * 2)) 整数运算，支持 + - * / % 
2. 判断 —— test / [] 老式，[[]] 增强（支持 && || 正则 =~）
3. 分支 —— if / case，case 适合多值匹配
4. 循环 —— for 遍历列表、while 条件循环、until 直到为真、select 菜单
```

## 算术与字符串运算

算术运算用 `$(( ))`，支持加减乘除取模，注意是整数运算（10/3=3，不是 3.33）。字符串运算主要是比较：`==` 相等、`!=` 不等、`-z` 判空、`-n` 判非空、`<` `>` 字典序。字符串比较和数值比较用的是两套操作符，别混——数值用 `-eq -ne -gt -lt`，字符串用 `== !=`。

```shell
echo "3+5*2 = $((3 + 5 * 2))"
a=10; b=3
echo "10/3 = $((a / b))   10%3 = $((a % b))"
s="hello world"
echo "字符串长度: ${#s}"
```

```text
# 实测
3+5*2 = 13
10/3 = 3   10%3 = 1
字符串长度: 11
```

## 条件判断 test 与 [[]]

条件判断有两种写法：老式 `test`（或 `[ ]`）和新式 `[[ ]]`。`[[ ]]` 是 bash 的增强版，支持 `&&` `||` 逻辑、`=~` 正则匹配、字符串比较不用加引号防拆分，是现在的推荐写法。数值比较在 `[ ]` 和 `[[ ]]` 里都用 `-eq -ne -gt -lt -ge -le`，字符串用 `== != -z -n`。

```shell
s1="abc"; s2="abc"
[[ $s1 == $s2 ]] && echo "s1==s2"
[ -z "$s1" ] && echo "s1为空" || echo "s1非空"
num=10
[ $num -gt 5 ] && echo "num大于5"
```

```text
# 实测
s1==s2
s1非空
num大于5
# 记忆：数值比较 -gt/-lt/-eq，字符串比较 ==/!=，判空 -z/-n
```

## if 与 case

if 做二选一或多条件分支，语法 `if 条件; then ... elif ...; else ...; fi`。case 做多值匹配，语法 `case 值 in 模式) ... ;; esac`，模式支持 `|` 或和 `*` 通配。判断「某个变量是几个已知值中的哪个」用 case 比一堆 if/elif 清晰得多——发行版判断、命令选项解析都是 case 的主场。

```shell
num=10
if [ $num -gt 5 ]; then
  echo "num>5"
else
  echo "num<=5"
fi

os="ubuntu"
case $os in
  ubuntu|debian) echo "Debian 系" ;;
  centos|rocky)  echo "Red Hat 系" ;;
  *) echo "其他" ;;
esac
```

```text
# 实测
num>5
Debian 系
```

## for 与 while 与 until 与 select

四种循环各有场景：for 遍历已知列表（文件、数字序列、命令结果）；while 条件为真就循环（读文件、等条件满足）；until 条件为假就循环（和 while 相反，等到满足才停）；select 生成交互式菜单。日常 90% 用 for 和 while，select 只在写交互脚本时用。

```shell
# for：遍历列表
for i in 1 2 3; do echo "第 $i 次循环"; done

# while：条件循环（倒计时）
n=3
while [ $n -gt 0 ]; do echo "倒计时 $n"; n=$((n-1)); done
```

```text
# 实测
第 1 次循环
第 2 次循环
第 3 次循环
倒计时 3
倒计时 2
倒计时 1
```

## 应用场景实战

### 场景一：按磁盘使用率分级告警的巡检脚本

```bash
#!/usr/bin/env bash
# 检查根分区使用率，分级输出
usage=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$usage" -ge 90 ]; then
  echo "严重：磁盘使用率 $usage%（需立即清理）"
elif [ "$usage" -ge 80 ]; then
  echo "警告：磁盘使用率 $usage%（建议清理）"
else
  echo "正常：磁盘使用率 $usage%"
fi
```

### 场景二：根据发行版选对包管理器

```bash
#!/usr/bin/env bash
. /etc/os-release
case "$ID" in
  ubuntu|debian)   pkg="apt install -y" ;;
  rhel|rocky|almalinux|centos) pkg="dnf install -y" ;;
  arch|manjaro)    pkg="pacman -S --noconfirm" ;;
  *) echo "未知发行版: $ID"; exit 1 ;;
esac
echo "本机包管理命令：$pkg"
```

## 最佳实践与踩坑记录

### 最佳实践

1. 条件判断优先用 [[ ]]，支持 && || 和正则，比 [ ] 更安全
2. 数值比较用 -eq/-gt/-lt，字符串用 ==/!=，别混用
3. 多值匹配用 case，比一串 if/elif 清晰且好维护
4. 遍历列表用 for x in "$@"，读文件用 while read
5. 算术统一用 $(( ))，别用 expr（慢且老）

### 踩坑记录

```text
坑 1：数值比较误用 == 当 -eq
结论：[ $num == 5 ] 在 bash 里是字符串比较，语义不对。
原因：== 是字符串比较，-eq 才是数值比较，混用导致判断错误。
解法：数值用 -eq -ne -gt -lt -ge -le，字符串才用 == !=。

坑 2：[[ $x == $y ]] 里 x 为空时报语法错误
结论：x 未定义时 [[ $x == "abc" ]] 报 unary operator expected。
原因：变量展开为空后，条件表达式缺操作数。
解法：用 [[ $x == "abc" ]]（双中括号里空变量安全），或加引号。

坑 3：算术 $(( )) 里变量没写 $ 也能用但混着写易错
结论：$((a + b)) 和 $(($a + $b)) 都对，但 $((10/3)) 结果是 3 不是 3.33。
原因：bash 算术是整数运算，除法取整。
解法：需要小数用 bc 或 awk（echo "10/3" | bc -l）。

坑 4：for 循环遍历命令输出被空格拆断
结论：for f in $(ls *.txt) 遇到含空格文件名被拆成多个。
原因：$(ls) 结果按空白分词，空格文件名被拆断。
解法：用 while read 或 for f in *.txt（glob 不拆分）。

坑 5：case 里忘了双分号导致 fall-through
结论：case 分支匹配后没写 ;;，继续执行下一个分支。
原因：;; 是 case 分支的结束标记，漏写会 fall-through。
解法：每个 case 分支末尾都写 ;;，esac 前最后一个可省略但建议统一写。
```
