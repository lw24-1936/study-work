## 概述

交换空间（swap）是「内存不够时把不常用的内存页临时写到磁盘」的兜底空间。物理内存用满时，内核把冷数据换出到 swap，腾出内存给活跃进程。swap 分两种：swap 分区（独立分区）和 swap 文件（普通文件当 swap，更灵活）。swappiness 参数控制「内核多积极地用 swap」。swap 是「兜底」不是「替代内存」——swap 太多会拖慢系统。

```text
swap 核心概念：
1. 作用 —— 内存不足时把冷内存页换出到磁盘，腾出物理内存
2. 形式 —— swap 分区（独立分区）或 swap 文件（普通文件，灵活）
3. swappiness —— 0-100，控制换出积极度（默认 60，越高越爱用 swap）
4. 定位 —— 兜底，不是内存替代品，大量用 swap 说明内存不足
```

## swap 分区与 swap 文件

swap 分区是专门类型（分区类型 82）的分区，swap 文件是普通文件（`dd` 创建 + `mkswap` 格式化 + `swapon` 启用）。现代发行版（Ubuntu）默认用 swap 文件（如 /swap.img），因为文件大小可随时调整、不用重新分区。查看 swap 用 `swapon --show` 或 `cat /proc/swaps`，启用/停用用 swapon/swapoff。

```text
# 实测（本机 swap 是文件不是分区）
$ swapon --show
NAME      TYPE SIZE  USED PRIO
/swap.img file   8G 76.7M   -1
# swap 是 /swap.img 文件，8G，当前用了 76.7M（内存够时基本不用）
```

```shell
# 创建并启用一个 swap 文件
dd if=/dev/zero of=/swapfile bs=1M count=2048   # 建 2G 文件
chmod 600 /swapfile
mkswap /swapfile                                # 格式化为 swap
swapon /swapfile                                # 启用
swapon --show                                   # 确认
# 持久化：写进 fstab，/swapfile none swap sw 0 0
```

## swappiness

swappiness（0-100）控制内核「多积极地换出内存页到 swap」。值越高，内核越早、越积极地把内存换出；值越低，越倾向用满物理内存再说。默认 60（适中）。数据库服务器常调低到 10-20（尽量用物理内存，避免数据库缓存被换出），桌面/内存紧张时保持默认或调高。`cat /proc/sys/vm/swappiness` 查看，`sysctl vm.swappiness=10` 临时改。

```text
# 实测（本机默认 swappiness）
$ cat /proc/sys/vm/swappiness
60
# 默认 60：均衡策略，内存用到一定程度就开始换出
```

```shell
sysctl vm.swappiness=10              # 临时调低（数据库服务器常用）
sysctl -w vm.swappiness=10           # 等价写法
# 持久化：/etc/sysctl.conf 加 vm.swappiness=10
```

## 应用场景实战

### 场景一：内存不够了，快速加一个 swap 文件应急

```shell
# 1. 建 4G swap 文件并启用
dd if=/dev/zero of=/swapfile2 bs=1M count=4096
chmod 600 /swapfile2
mkswap /swapfile2
swapon /swapfile2
# 2. 确认生效
swapon --show
free -h
# 3. 持久化（避免重启丢失）
echo '/swapfile2 none swap sw 0 0' >> /etc/fstab
```

### 场景二：给数据库服务器调低 swappiness

```shell
# 1. 查看当前值
cat /proc/sys/vm/swappiness
# 2. 调低到 10（优先用物理内存，避免数据库缓存被换出拖慢查询）
sysctl vm.swappiness=10
# 3. 持久化
echo 'vm.swappiness=10' >> /etc/sysctl.conf
sysctl -p
```

## 最佳实践与踩坑记录

### 最佳实践

1. swap 大小：内存 ≤2G 用 2 倍，2-8G 用 1 倍，>8G 用 4-8G 兜底即可
2. 数据库服务器调低 swappiness（10-20），优先用物理内存
3. swap 文件权限设 600，防止被普通用户读取
4. 观察 swap 使用：free -h 或 vmstat，swap 持续高说明内存不足该加内存
5. 需要临时加 swap 用 swap 文件，比重启加分区快得多

### 踩坑记录

```text
坑 1：swap 文件权限太宽
结论：chmod 644 swap 文件，普通用户能读到换出的内存数据。
原因：swap 里可能有敏感数据（密码等内存页），权限 644 会泄露。
解法：swap 文件必须 chmod 600，只 root 可读写。

坑 2：swap 文件 swapon 报 insecure permissions
结论：swapon 提示 insecure permissions 0644，拒绝启用。
原因：swap 文件权限不是 600，系统认为不安全。
解法：chmod 600 /swapfile 后再 swapon。

坑 3：swap 分区没写进 fstab，重启后失效
结论：swapon 启用的 swap 重启后没了。
原因：swapon 是临时的，不写 fstab 不持久化。
解法：写 /etc/fstab（/swapfile none swap sw 0 0），或 systemd swap 单元。

坑 4：swappiness 调成 0 以为禁用 swap
结论：swappiness=0 后系统还是用了 swap。
原因：swappiness=0 只是「尽量避免」，内存极度紧张时仍会换出。
解法：要真正禁用就 swapoff -a，或接受「0 = 尽量不用」。

坑 5：swap 空间过大导致磁盘被占满
结论：配了 64G swap，磁盘被 swap 文件占满。
原因：swap 文件按预设大小直接占磁盘空间。
解法：按内存比例合理设 swap 大小，别盲目设超大值。
```
