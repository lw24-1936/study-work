## 概述

awk 是三剑客里唯一带「编程语言」属性的工具——它能按字段处理、做条件判断、循环、数组统计、数值计算。核心模型是「模式 + 动作」：对每一行，匹配到模式就执行动作。默认按空白切字段（$1 $2 ...），所以分析「按列」的数据（日志、CSV、命令输出）特别顺手。日志统计分析、报表计算、字段提取，awk 是主力。

```text
awk 核心模型：
1. 结构 —— awk '模式 {动作}' 文件，逐行读入、匹配模式、执行动作
2. 字段 —— 默认按空白切分，$1 $2 ... 是字段，$0 是整行，NF 是字段数
3. 能力 —— 内置变量 + 条件 + 循环 + 数组 + 函数，本质是个小型解释器
```

## 核心概念

awk 的核心概念是「字段模型 + 编程语言要素」两大部分。

### 字段与记录

awk 把每行叫一条「记录」（record），按分隔符切成「字段」（field）。默认分隔符是空白（空格/制表符），`-F` 指定其它分隔符（CSV 用 `-F,`）。`$1 $2 ...` 引用字段，`$0` 是整行，`$NF` 是最后一个字段。分析日志时「IP 是 $1、状态码是 $9」这种对应关系一旦摸清，后面全是顺手的事。

```shell
# nginx 日志：$1 IP、$7 路径、$9 状态码、$10 字节数
awk '{print $1, $9, $10, $7}' /var/log/nginx/access.log | head -3
```

```text
# 实测（本机真实 nginx 日志）
100.115.7.80 200 2849 /
100.115.7.80 200 29709 /assets/vendor-CjyC-hUb.css
100.115.7.80 200 279 /manifest.webmanifest
# nginx 默认日志格式按空白切分后，$1=客户端IP、$7=请求路径、$9=状态码、$10=响应字节
```

`$NF` 是最后一个字段、`$(NF-1)` 是倒数第二个，这两个在「列数不固定」时最实用——不用数一共有几列，直接取尾部字段。`-F` 接的是正则，所以能写多字符分隔符：

```shell
# 取最后两个字段（$NF 最后一个、$(NF-1) 倒数第二个）
awk '{print $1, $(NF-1), $NF}' /tmp/demo.txt | head -2

# -F 多字符分隔符（正则）：逗号或分号都算分隔
echo "a,b;c" | awk -F'[,;]' '{print $2}'

# 输出用 OFS 控制字段间分隔符（默认空格）
awk 'BEGIN{OFS=" | "} {print $1, $2, $3}' /tmp/demo.txt | head -2
```

```text
要点：
1. 记录 = 一行，字段 = 按 FS 切出来的一段；默认 FS 是「连续空白」，多个空格/制表符当一个分隔
2. $0 是整行、$NF 是最后一个字段、$(NF-1) 是倒数第二个——列数不固定时优先用它们
3. -F 接正则：-F'[,;]' 表示逗号或分号都算分隔，-F'[ ,]' 表示空格或逗号
4. 边界：awk 不解析引号转义，CSV 字段里含逗号会被拆错，复杂 CSV 用 csvkit 或 Python csv
5. 易错点：FS 为单个空格（-F' ' 或默认）是「连续空白」特例；要按「字面单个空格」切须写 -F'[ ]'
```

### 内置变量

awk 内置变量省去大量手工计数。`NR` 是当前记录号（跨文件累计）、`FNR` 是当前文件内的记录号、`NF` 是当前行字段数、`FS` 是输入分隔符、`OFS` 是输出分隔符、`RS` 是记录分隔符。最常用的是 NR（行号）和 NF（字段数）——`awk 'NR>1'` 跳过表头、`awk '{print NF}'` 看每行几列。

```shell
# NR 行号 + NF 字段数 + 部分字段
awk '{print NR, NF, $1, $4}' /tmp/demo.txt
```

```text
# 实测
1 6 2026-08-18 user=alice
2 6 2026-08-18 user=bob
3 6 2026-08-18 user=carol
4 6 2026-08-18 user=alice
5 6 2026-08-18 user=dave
6 6 2026-08-18 user=eve
# 每行 6 个字段：$1=日期 $2=时间 $3=级别 $4=user $5=action $6=ip
```

FS/OFS/RS 三个变量控制「怎么切」和「怎么拼」；FNR 在处理多文件时区分「当前文件里的行号」：

```shell
# FS 输入按冒号切、OFS 输出用逗号拼回
awk 'BEGIN{FS=":"; OFS=","} {print $1, $3}' /etc/passwd | head -3

# RS 改成空串：按「段落」处理（空行分隔的块算一条记录）
awk 'BEGIN{RS=""} {print NR, NF}' /tmp/para.txt

# FNR vs NR：处理多个文件时 FNR 每个文件重新从 1 数
awk '{print FILENAME, FNR, NR}' /tmp/a.txt /tmp/b.txt
```

```text
要点：
1. NR 跨文件累计、FNR 每个文件重新计数；配合 FILENAME 能定位「第几个文件的第几行」
2. NF 是字段数，$NF 因此天然是最后一个字段；NR 常用于 NR>1 跳过表头
3. FS/OFS 成对：FS 管输入切分、OFS 管输出拼接；RS 改记录分隔符可跨行/按段落处理
4. 易错点：OFS 只在「逗号分隔多个输出项」时生效，print $1 $2 之间没有逗号则不分隔
5. 易错点：$0 整行不受 OFS 影响；对 $0 重新赋值后要 $1=$1 强制重算才会按 OFS 重排
```

### 模式与动作

awk 的「模式」可以是正则、条件表达式、或行号范围；「动作」是花括号里的语句。`awk '/ERROR/ {print}'` 匹配含 ERROR 的行、`awk '$3=="ERROR"'` 是条件、`awk 'NR==1,NR==3'` 是行号范围。模式省略时默认对所有行执行动作，动作省略时默认打印整行（等价 grep）。

```shell
# 正则模式：匹配含 ERROR 的行（等价 grep ERROR）
awk '/ERROR/' /tmp/demo.txt | head -2
```

```text
# 实测
2026-08-18 10:00:05 ERROR user=bob   action=query  ip=10.0.0.2
2026-08-18 10:01:10 ERROR user=alice action=upload ip=10.0.0.1
```

模式还可以是「正则匹配某个字段」（用 `~` / `!~`），或「行号范围」，甚至可以写多个「模式 {动作}」串成一个脚本：

```shell
# 字段级正则：第 5 个字段以 action=query 结尾的行
awk '$5 ~ /action=query$/' /tmp/demo.txt | head -2

# 取反：第 3 个字段不是 INFO 的行
awk '$3 !~ /INFO/' /tmp/demo.txt | head -2

# 行号范围：只打印第 2 到第 3 行
awk 'NR==2, NR==3' /tmp/demo.txt

# 多个模式串成脚本：先筛 ERROR，再筛含 alice 的
awk '/ERROR/ && /alice/' /tmp/demo.txt
```

```text
要点：
1. 模式类型：正则（/re/）、字段正则（$n ~ /re/）、条件（$3=="ERROR"）、行号范围（NR==a,NR==b）
2. 模式省略 = 所有行都执行动作；动作省略 = 默认 print $0（等价 grep）
3. 多个「模式 {动作}」按书写顺序对同一行依次求值，命中哪个执行哪个
4. 易错点：/ERROR/ 是「整行包含」，$3 ~ /ERROR/ 才是「第 3 字段包含」；要精确匹配用 $3=="ERROR"
5. 易错点：范围模式 NR==a,NR==b 是「开关式」——从 a 开始到 b 结束，会跨越连续区间
```

### 条件

awk 的条件判断用 `if`，或直接写「条件 {动作}」这种模式形式。支持 `== != < > <= >= && || !` 全套逻辑运算。条件让 awk 能做「过滤 + 计算」二合一——比如「统计状态码大于等于 500 的行数」「找出工资超 15000 的人」。字段是数字就按数值比较，是字符串就按字典序比较。

```shell
# 只处理 ERROR 级别的行，打印时间+动作
awk '$3=="ERROR" {print $1, $2, $5}' /tmp/demo.txt
```

```text
# 实测
2026-08-18 10:00:05 action=query
2026-08-18 10:01:10 action=upload
2026-08-18 10:02:30 action=login
```

`if/else` 语句和三目运算符写分支逻辑；`&&`/`||` 组合多个条件：

```shell
# if/else 分支：ERROR 标红心、其它标横线
awk '{if ($3=="ERROR") print "E", $0; else print "-", $0}' /tmp/demo.txt | head -3

# 三目运算符：一行内完成条件赋值
awk '{print ($3=="ERROR" ? "严重" : "正常"), $2}' /tmp/demo.txt | head -3

# 组合条件：INFO 级别且含 alice 的行
awk '$3=="INFO" && /alice/' /tmp/demo.txt
```

```text
要点：
1. 条件判断 = 关系运算（== != < > <= >=）+ 逻辑运算（&& || !）
2. 两种写法等价：awk '条件 {动作}' 和 awk '{if (条件) 动作}'
3. 三目 x ? y : z 适合一行内给变量赋值或输出分支结果
4. 易错点：字段默认是字符串，"10" > "9" 按字典序为假；数值比较要 $n+0 或 -v 传数字
5. 易错点：字符串比较用 ==，正则匹配用 ~；把 == 写成 = 是赋值、恒为真
```

### 循环

awk 支持 for / while 循环，常用来遍历一行内的所有字段。典型场景：「一行里不确定哪个字段含目标，遍历找出来」——比如日志里 ip= 字段位置不固定时，用 `for (i=1; i<=NF; i++)` 逐个字段判断。这是 awk 比 grep/sed 强的地方：它能在字段级别做逻辑。

```shell
# 遍历所有字段，提取 ip= 开头的那个
awk '{for (i=1; i<=NF; i++) if ($i ~ /^ip=/) print $i}' /tmp/demo.txt
```

```text
# 实测
ip=10.0.0.1
ip=10.0.0.2
ip=10.0.0.3
ip=10.0.0.1
ip=10.0.0.4
ip=10.0.0.5
```

`while` 适合「不知道次数、满足条件就继续」的场景，`break` 提前退出、`continue` 跳过本次、`next` 直接跳到下一条记录：

```shell
# while 循环：从第 2 个字段开始找第一个含 = 的字段
awk '{i=2; while (i<=NF && $i !~ /=/) i++; print $i}' /tmp/demo.txt | head -2

# next：跳过第一行（表头），后续行照常处理
awk 'NR==1 {next} {print NR, $1}' /tmp/demo.txt | head -2

# break：遍历字段，找到目标就停止（避免继续无谓比较）
awk '{for (i=1; i<=NF; i++) if ($i ~ /^ip=/) {print $i; break}}' /tmp/demo.txt | head -2
```

```text
要点：
1. for 用于「已知边界」的遍历（i=1; i<=NF; i++），while 用于「条件驱动」的循环
2. break 跳出当前循环、continue 跳过本次迭代、next 跳到下一条记录（不执行后续动作）
3. 遍历字段是 awk 区别于 grep/sed 的核心能力——字段位置不固定时逐个找
4. 易错点：for 循环里改 $i 不影响 $0，要写回整行需显式 $0=$0 重算
5. 易错点：next 会跳过当前行后续所有「模式 {动作}」，别放在统计逻辑之前误跳行
```

### 数组

awk 的数组是关联数组（下标可以是任意字符串），天然适合做「分组计数」。最经典的统计范式：`awk '{cnt[$k]++} END {for (x in cnt) print x, cnt[x]}'`——按某个字段分组、累加、最后输出。日志里统计「各状态码数量」「各 IP 访问次数」「各接口调用量」，全是这个套路。数组在 END 块里统一输出（因为要等所有行读完）。

```shell
# 按级别分组计数
awk '{cnt[$3]++} END {for (k in cnt) print k, cnt[k]}' /tmp/demo.txt
```

```text
# 实测
INFO 2
ERROR 3
WARN 1
```

数组还支持「成员判断」「删除元素」「求长度」，多维场景用下标拼接模拟：

```shell
# 统计每个 IP 每个级别的次数（二维分组，下标用逗号拼成键）
awk '{cnt[$6" "$3]++} END {for (k in cnt) print k, cnt[k]}' /tmp/demo.txt

# 判断键是否存在 + 数组长度
awk '{seen[$3]=1} END {print "级别数:", length(seen); if ("ERROR" in seen) print "有 ERROR"}' /tmp/demo.txt

# 删除元素：统计时排除掉某个键
awk '{cnt[$3]++} END {delete cnt["INFO"]; for (k in cnt) print k, cnt[k]}' /tmp/demo.txt
```

```text
要点：
1. 关联数组下标是字符串，cnt[$3]++ 天然做分组计数，无需预声明
2. 输出放 END：所有行读完后数组才完整，遍历用 for (k in arr)
3. `k in arr` 判断键是否存在、delete arr[k] 删元素、length(arr) 求元素个数
4. 多维：用下标拼接模拟（cnt[$a SUBSEP $b] 或 cnt[$a","$b]），awk 本身无真正二维数组
5. 易错点：for (k in arr) 遍历顺序不确定，要排序输出 pipe 给 sort 或用 PROCINFO["sorted_in"]
```

### 字符串与数值函数

awk 内置函数分字符串和数值两类。字符串：`length()` 长度、`substr(s,m,n)` 截取、`index(s,t)` 查找、`split(s,arr,sep)` 拆分、`tolower()/toupper()` 大小写。数值：`int()` 取整、`sqrt()` 平方根、`rand()` 随机。正则相关 `match()`、`sub()/gsub()` 做替换。数值运算 awk 直接支持 `+ - * / %`，做 CSV 汇总、求平均、求和都很直接。

```shell
# 数值运算：过滤工资>=15000 的，求全体平均工资
awk -F, '$4>=15000 {print $2, $4}' /tmp/users.csv
awk -F, 'NR>1 {sum+=$4} END {print "平均工资:", sum/(NR-1)}' /tmp/users.csv
```

```text
# 实测
name salary
alice 15000
carol 18000
eve 16000
平均工资: 14200
# NR>1 跳过表头（第一行是 name,salary）；sum/(NR-1) 除以有效数据行数
```

常用函数的典型用法：

```shell
# 字符串：截取、长度、查找、拆分
echo "2026-08-18" | awk '{print substr($1,1,4), substr($1,6,2), length($1)}'
awk '{print index($4, "=")}' /tmp/demo.txt | head -1
awk '{n=split($0, a, " "); print "字段数:", n, "首字段:", a[1]}' /tmp/demo.txt | head -1

# 替换：sub 替换第一个、gsub 替换全部
awk '{gsub(/user=/, "", $4); print $4}' /tmp/demo.txt | head -2

# 大小写 + 格式化 + 取整
echo "Hello" | awk '{print tolower($1), toupper($1)}'
awk 'BEGIN{printf "%.2f\n", 10/3}'
awk 'BEGIN{print int(3.9), sqrt(16)}'
```

```text
要点：
1. 字符串：length/substr/index/split/tolower/toupper；正则替换 sub（首个）/gsub（全部）/match（定位）
2. 数值：int 截断取整（非四舍五入）、sqrt 开方、rand 随机（配 srand(种子) 才可复现）
3. split(s, arr, sep) 把字符串拆进数组，返回拆出的段数——和字段切分互补
4. sprintf/printf 格式化输出，做报表对齐列宽时用它
5. 易错点：int() 是截断不是四舍五入（int(3.9)=3）；rand() 默认每次种子相同，要 srand() 才随机
```

### BEGIN 与 END

BEGIN 块在读取任何输入之前执行（初始化、打印表头），END 块在所有输入处理完后执行（汇总、打印结果）。「BEGIN 设分隔符 + 主体逐行处理 + END 汇总」是 awk 脚本的标准三段式。做报表时 BEGIN 打印列名、END 打印合计行，结构清晰。

```shell
# 三段式：BEGIN 表头 → 主体统计 → END 输出
awk 'BEGIN {print "级别统计:"} {cnt[$3]++} END {for (k in cnt) print k, cnt[k]}' /tmp/demo.txt
```

```text
# 实测
级别统计:
INFO 2
ERROR 3
WARN 1
```

BEGIN 里设 FS/OFS、END 里打印合计行；两个块都能写多个，按顺序执行：

```shell
# BEGIN 设分隔符 + 打印表头；END 打印数据行数
awk 'BEGIN{FS=","; print "姓名,工资"} NR>1{sum+=$4} END{print "平均:", sum/(NR-1)}' /tmp/users.csv

# 多文件时 END 只在全部处理完后执行一次
awk 'BEGIN{n=0} {n+=NF} END{print "总字段数:", n}' /tmp/demo.txt
```

```text
要点：
1. BEGIN 读数据前执行一次（初始化变量/设 FS/OFS/打表头），END 处理完执行一次（汇总/合计）
2. 主体对每条记录执行一次；三段式是 awk 报表脚本的标准骨架
3. BEGIN/END 可写多个，按出现顺序执行；无输入文件时也能只靠 BEGIN 输出（如纯计算）
4. 易错点：字段 $1 只在主体有效，BEGIN 里还没有字段、END 里是最后一条记录的字段残留
5. 易错点：END 里 NR 是总行数，适合算平均（sum/NR），但注意跳过表头后要除以 (NR-1)
```

## 工作原理

awk 的执行模型是「三段式 + 逐记录循环」：

1. **BEGIN 阶段**：读入任何数据之前执行一次，用于初始化变量、设 FS/OFS、打印表头。
2. **主体循环**：按记录分隔符 RS（默认换行）逐条读入，每读一条先按 FS 切成字段、更新 NR/NF，然后**按顺序**对每个「模式 {动作}」求值——模式命中就执行对应动作。
3. **END 阶段**：所有记录处理完后执行一次，用于输出汇总结果。

关键点：字段切分发生在「每条记录读入时」，所以 `$1` 等字段只在主体循环里有效；关联数组要等到 END 里遍历输出，因为那时所有记录才处理完。理解这个「读一条 → 过一遍所有模式 → 下一条」的循环，就理解了 awk 为什么是日志统计的标准工具。

```text
awk 执行流程：
BEGIN（一次）→ 逐记录循环 { 切字段 → 更新 NR/NF → 按序匹配模式执行动作 } → END（一次）
```

```text
逐记录循环的细节：
1. 每条记录先按 RS 读入、再按 FS 切字段、更新 NR/NF/FNR
2. 然后按脚本书写顺序依次对每个「模式 {动作}」求值，命中即执行
3. 一个动作里 next 会立即跳到下一条记录，跳过当前行剩余的其它模式
4. 内存模型：变量和关联数组跨记录存活，这是分组统计能累积的原因
```

## 常用命令与配置

awk 的常用参数与高频单行命令：

```shell
awk -F, '{print $1}' file            # 指定分隔符为逗号
awk -v threshold=100 '$2 > threshold' file   # 外部传变量
awk -f script.awk file               # 从脚本文件加载程序
awk 'NR>1 {print}' file              # 跳过第一行（表头）
awk '{cnt[$1]++} END {for (k in cnt) print k, cnt[k]}' file   # 分组计数
awk '{sum+=$2} END {print sum/NR}' file                        # 求平均
```

```text
参数分工：
-F 输入分隔符 / -v 传变量 / -f 脚本文件 / -F'[ ,]' 多字符分隔符
```

更多高频单行命令（按用途分组）：

```shell
# 字段提取
awk '{print $1, $NF}' file                                   # 首字段 + 末字段
awk -F: '{print $1, $3, $7}' /etc/passwd                     # 切 passwd

# 过滤
awk '$3=="ERROR"' file                                       # 精确匹配字段
awk '$2 > 100' file                                          # 数值过滤
awk 'NR>=10 && NR<=20' file                                  # 行号区间

# 统计
awk '{cnt[$1]++} END {for (k in cnt) print k, cnt[k]}' file  # 分组计数
awk '{sum+=$2; if ($2>max) max=$2} END {print "和:", sum, "最大:", max}' file  # 求和+最大值
awk 'NR>1 {s+=$2} END {printf "平均: %.2f\n", s/(NR-1)}' file              # 求平均

# 改写字段顺序 / 格式化输出
awk '{print $3, $1, $2}' file                               # 重排字段
awk '{printf "%-10s %5d\n", $1, $2}' file                   # 对齐输出
```

```text
实用技巧：
1. -v 传变量避免在单引号里拼 shell 变量（引号地狱），还能传数值做比较
2. 复杂脚本写 .awk 文件用 -f 加载，可复用、可加注释、可版本管理
3. 单行命令优先「提取/过滤/统计」三类，覆盖 90% 日志分析需求
```

## 配置文件解析

awk 没有独立配置文件，但它的程序可以通过脚本文件和变量「配置化」：

```text
1. 把复杂 awk 程序写进 .awk 文件，用 awk -f script.awk 加载——可复用、可版本管理
2. -v 传变量相当于「运行时配置」，把阈值/分隔符等参数化
3. ENVIRON 数组 —— awk 程序内可直接读环境变量（ENVIRON["HOME"]），
   把外部环境当配置来源
4. 脚本文件结构：
   BEGIN { FS=","; OFS="," }     # 配置段
   { ... }                        # 主逻辑
   END { ... }                    # 汇总
```

脚本文件示例（`report.awk`，与 nginx 日志配套）：

```awk
# report.awk —— 统计 nginx 日志状态码分布
BEGIN {
    FS = " "                 # 配置段：输入分隔符
    OFS = "\t"               # 输出用 tab 对齐
    print "状态码", "数量"    # 表头
}
{
    cnt[$9]++                # 主逻辑：$9 是状态码
}
END {
    for (k in cnt)           # 汇总段：输出结果
        print k, cnt[k]
}
```

```text
用法：awk -f report.awk /var/log/nginx/access.log | sort -k2 -rn
要点：
1. 脚本文件让 awk 程序脱离 shell 引号转义，写复杂逻辑更清晰
2. ENVIRON["NAME"] 读环境变量，可把阈值/目录等做成配置
3. -v 传变量优先级高于脚本内的赋值，适合做「运行时参数」
```

### 场景三：生成带合计行的报表（BEGIN 表头 + 分组统计 + END 合计）

完整报表：BEGIN 打印表头、主体按部门统计人数和工资总和、END 打印合计行。这是 awk 做「日报/周报」的标准三段式。

```shell
# 数据文件 /tmp/sales.csv：name,region,amount
cat /tmp/sales.csv
```

```text
name,region,amount
alice,华东,1200
bob,华南,800
carol,华东,1500
dave,华北,600
eve,华南,900
```

```shell
# 三段式报表：表头 → 分组求和 → 合计
awk -F, 'BEGIN {
    printf "%-8s %8s\n", "区域", "销售额"
    printf "%-8s %8s\n", "------", "------"
}
NR>1 {
    total[$2] += $3          # 按区域累加销售额
    grand += $3              # 总计
}
END {
    for (r in total)
        printf "%-8s %8d\n", r, total[r]
    printf "%-8s %8d\n", "------", "------"
    printf "%-8s %8d\n", "合计", grand
}' /tmp/sales.csv
```

```text
区域       销售额
------    ------
华东       2700
华南       1700
华北        600
------    ------
合计       5000
```

```text
说明：
1. BEGIN 里 printf 打印表头（%-8s 左对齐、%8d 右对齐）
2. 主体 NR>1 跳过表头，total[$2]+=$3 按区域累加，grand 累计总计
3. END 里 for 遍历输出各区域、最后打印合计行
4. 这是 awk 做报表的完整范式：任何「分组 + 合计」的数据都能套
```

## 性能与调优

```text
1. awk 单遍扫描就能完成过滤+统计，比 grep|sort|uniq 多进程管道更快
2. 关联数组在大文件下内存累积，几十 GB 日志别把所有键憋在内存里，改用 sort|uniq -c 流式统计
3. 字段切分是主要开销，字段越多越慢，必要时用单字符分隔符
4. 复杂逻辑写成 .awk 文件用 -f 加载，比命令行堆一长串更易维护
5. 数值比较注意字段类型，避免字符串比较导致的重复扫描和错误结果
```

```text
进阶调优：
1. 用 gawk（GNU awk）时，需要稳定输出顺序可设 PROCINFO["sorted_in"]="@val_num_desc"，
   省掉尾部 sort 进程
2. 大文件优先 awk 过滤再交给其它工具，先缩小数据量是管道优化的第一原则
3. 字符串连接（s = s $0）在 gawk 里是 O(1) 摊还，但 mawk 等实现可能是 O(n^2)，
   大量拼接用数组 + join 思路更稳
4. 避免在每行里重复调用 system()（每调用 fork 一次进程，极慢），能用内置函数就别起子进程
```

## 安全与权限

```text
1. awk 的 system() 会执行 shell 命令，脚本里拼接未校验输入时存在命令注入风险，尽量别用
2. 用 awk 处理日志提取的敏感字段（token/密码）别原样写入输出或日志
3. awk 脚本文件若有可执行权限且带 shebang，注意其被意外调用的权限边界
4. 处理 /etc/shadow、私钥等敏感文件时，awk 结果别重定向到可被他人读的位置
5. 从外部输入（文件名、-v 变量）拼进 system() 前先校验，或改用 awk 内置能力替代
6. 处理用户可控的输入文件时，警惕 getline 从文件读入导致的路径/内容注入，尽量别用 getline
```

## 故障排查

```text
「统计结果不对」排查顺序：
1. 字段错位 —— 先 awk '{print NR, NF, $1, $2, $3}' 看清每列是什么
2. 分隔符 —— 默认按空白切，CSV 要 -F,，多空格/特殊分隔符要核对
3. 数值 vs 字符串 —— 字段默认字符串，比较排序要 $n+0 数值化
4. 表头混入 —— 忘了 NR>1 跳过表头，统计多出奇怪键
5. 数组遍历顺序 —— for(k in arr) 无序，要排序 pipe 给 sort
```

```text
「命令报语法错误」排查：
1. 单引号内再放单引号 —— awk '{print "it'"'"'s"}' 这类转义写错，改用 -v 或脚本文件
2. 括号/花括号不匹配 —— 复杂脚本先存文件再 awk -f，编辑器里能看清配对
3. -F 分隔符里的特殊正则字符 —— -F'.' 会把点当「任意字符」，要 -F'\\.'
4. gawk 与 mawk 差异 —— 某些扩展（如 PROCINFO）只在 gawk 可用，发行版默认 awk 可能是 mawk
```

## 常见问题

```text
Q1: awk 和 sed 怎么选？
A: 单行内的替换/删除用 sed，字段级提取、分组统计、数值计算用 awk。awk 是完整语言，sed 是流编辑器。

Q2: 为什么统计结果里字段编号总是对不上？
A: 多空格、分隔符、日志格式和默认 nginx 格式不同都会错位。先 awk '{print NR, NF, $1...}' 摸清字段。

Q3: CSV 字段里含逗号怎么办？
A: awk 不解析引号转义，只按字符切。复杂 CSV 用 csvkit 或 Python 的 csv 模块。

Q4: awk 能跨行处理吗？
A: 默认按记录（行）处理，跨行要靠 RS 改记录分隔符或状态变量，复杂场景不如 Python。

Q5: NR 和 FNR 到底差在哪？
A: NR 是「已经读过的总记录数」，跨文件累计；FNR 是「当前文件内的记录号」，每换一个文件重新从 1 数。处理多个文件要区分行号时用 FNR，要全局行号用 NR。

Q6: 怎么把 shell 变量传进 awk？
A: 用 -v 传：awk -v key="$var" '$1==key' file。别在单引号里直接拼 $var（shell 不会展开单引号内的变量），也避免引号转义地狱。

Q7: for (k in arr) 输出顺序乱怎么办？
A: 关联数组不保证遍历顺序。要排序就 pipe 给 sort，或 gawk 里设 PROCINFO["sorted_in"]="@val_num_desc"（按值倒序）/@ind_str_asc（按键升序）。
```

## 面试题

```text
1. awk 的 BEGIN、主体、END 分别什么时候执行？
   答：BEGIN 读数据前执行一次（初始化/表头），主体每条记录执行一次（逐行处理），END 数据处理完后执行一次（汇总）。

2. 用 awk 统计日志里每个状态码的数量？
   答：awk '{cnt[$9]++} END {for (k in cnt) print k, cnt[k]}' access.log，用关联数组做分组计数。

3. NR 和 FNR 的区别？
   答：NR 是跨文件累计的记录号，FNR 是当前文件内的记录号。处理多文件时 FNR 每个文件重新计数。

4. awk 的字段默认怎么切分？怎么指定分隔符？
   答：默认按空白（空格/制表符）切分，-F 指定其它分隔符（-F, 或 -F'[ ,]' 多字符）。

5. awk 里 $0、$1、$NF、NF 分别是什么？
   答：$0 是整行、$1 是第一个字段、$NF 是最后一个字段、NF 是字段总数。$(NF-1) 是倒数第二个字段。

6. 用 awk 求一个 CSV 文件某列的平均值怎么写？
   答：awk -F, 'NR>1 {sum+=$4; n++} END {print sum/n}' file.csv，NR>1 跳过表头，累加后除以有效行数。

7. awk 和 grep/sed 比强在哪？
   答：awk 是完整的小型语言——能做字段级提取、条件判断、循环、关联数组分组统计、数值计算，这是 grep（行级匹配）和 sed（流式替换）做不到的。字段级分组统计是它的杀手锏。
```

## 最佳实践与踩坑记录

### 最佳实践

1. 分析日志先摸清字段位置（$1 是什么、$9 是什么），再写统计
2. 分组计数用关联数组 + END 输出，这是 awk 最高频的范式
3. CSV 处理记得 -F, 和 NR>1 跳过表头
4. 复杂统计写成 .awk 脚本文件，别堆在命令行里
5. awk 做不了的（跨行、复杂逻辑）才考虑 Python，能 awk 就 awk
6. 需要稳定排序输出时 pipe 给 sort，或 gawk 用 PROCINFO["sorted_in"]
7. 提取尾部字段用 $NF / $(NF-1)，别去数一共几列

### 踩坑记录

```text
坑 1：字段编号搞错，统计结果全错
结论：本以为是 $4 是级别，结果统计出来牛头不对马嘴。
原因：多空格/分隔符没摸清，字段错位。
解法：先 awk '{print NR, NF, $1, $2, $3...}' 看清每列是什么，再写统计。

坑 2：CSV 里字段本身含分隔符导致错位
结论：-F, 切分含逗号的字段（如 "a,b"）被拆成两列。
原因：awk 不解析 CSV 的引号转义，只按字符切。
解法：简单 CSV 用 awk，复杂 CSV 用 csvkit 或 Python 的 csv 模块。

坑 3：数值字段当字符串比较，排序/判断出错
结论：awk 'NR>1 && $4>15000' 对 10000 和 20000 比较结果反了。
原因：字段默认是字符串，字符串比较按字典序 "10000" > "15000" 为假但 "20000" > "15000" 为真，边界值会错。
解法：显式数值化 $4+0 > 15000，或确保字段无前导字符。

坑 4：END 块里数组遍历顺序不确定
结论：for (k in arr) 输出的顺序每次可能不同。
原因：awk 关联数组不保证遍历顺序，和插入顺序无关。
解法：需要排序输出时，把结果 pipe 给 sort，或 gawk 用 PROCINFO["sorted_in"]。

坑 5：awk 里单引号转义地狱
结论：awk '{print "'"'"'"}' 这类嵌套引号写错。
原因：shell 单引号内不能直接放单引号。
解法：awk 脚本存成文件 awk -f script.awk，或改用双引号包裹并用反斜杠转义。

坑 6：FS 设成单个空格却想按「字面空格」切分
结论：以为 -F' ' 是按单个空格切，结果连续多个空格被当成一个分隔符。
原因：awk 里 FS 为单个空格（含默认值）是「连续空白」特例，等价于按空白切分。
解法：要按字面单个空格切须写 -F'[ ]'；要按「一个或多个空格」切写 -F'[ ]+'。

坑 7：忘了 int() 是截断取整，四舍五入结果不符预期
结论：awk 'BEGIN{print int(2.6)}' 输出 2，以为会得到 3。
原因：awk 的 int() 是向下截断，不是四舍五入。
解法：四舍五入用 int(x+0.5)，或 printf "%.0f\n" x（printf 才按四舍五入格式化）。
```
