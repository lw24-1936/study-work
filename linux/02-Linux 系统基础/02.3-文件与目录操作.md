## 概述

文件与目录操作是 Linux 日常使用最频繁的基本功，分三块：增删改查（ls/cd/mkdir/touch/cp/mv/rm）、查看内容（cat/less/head/tail/od/hexdump）、查找定位（find/locate/which/whereis/type）。它们组合起来能覆盖绝大多数「文件在哪、内容是什么、怎么搬怎么删」的场景。熟练这些命令是后面学文本三剑客、Shell 脚本、故障排查的前提。

```text
命令三分类：
1. 增删改查 —— ls/cd/pwd/mkdir/touch/cp/mv/rm/rmdir，管文件本身的创建移动删除
2. 查看内容 —— cat/less/more/head/tail/nl/od/hexdump，管文件内容的显示
3. 查找定位 —— find/locate/which/whereis/type，管文件在哪、命令是哪个
```

## 常用命令

这组命令管文件的创建、移动、复制、删除。要点：cp 加 -a 保留属性（权限/时间戳/软链），mv 改名和移动同一条命令，rm 是删除且没有回收站、删了基本找不回，rmdir 只能删空目录。ls 是最常用的「看」命令，-l 看详细属性、-h 人类可读大小、-t 按时间排序。

```text
常用命令要点：
1. ls —— -l 详细列表、-a 含隐藏文件、-h 可读大小、-t 按时间、-S 按大小
2. cd —— cd ~ 回家、cd - 回上一个目录、cd .. 上一级
3. mkdir —— -p 递归创建多级目录，touch —— 建空文件或刷新时间戳
4. cp —— -r 递归复制目录、-p 保留属性、-a 归档复制（= -dpR）
5. mv —— 改名和移动通用，同分区移动不复制数据只改目录项
6. rm —— -r 递归、-f 强制不提示；rmdir —— 只能删空目录
```

```shell
# 创建与移动
mkdir -p /tmp/demo/sub
touch /tmp/demo/a.txt /tmp/demo/b.txt
cp -a /tmp/demo /tmp/demo.bak       # 归档复制，保留所有属性
mv /tmp/demo/a.txt /tmp/demo/c.txt  # 改名
rm -rf /tmp/demo.bak                # 递归删除

# 看目录
ls -lah /tmp/demo                   # 详细 + 隐藏 + 可读大小
ls -lt                              # 按修改时间倒序
```

## 文件查看

查看文件内容分「整篇读」和「按需读」两类。cat 一次性输出全文（小文件用），less 是交互式分页器（大文件用，能搜索、翻页、前后滚动），more 是 less 的前身（只能向前翻）。head/tail 看头看尾，tail -f 实时跟踪追加内容（盯日志神器）。nl 加行号，od 和 hexdump 用八进制/十六进制看二进制文件或不可见字符。

```text
查看命令分工：
1. cat —— 一次输出全文，-n 加行号，适合小文件或拼接（cat a b > c）
2. less —— 交互分页，/搜索、g 开头、G 结尾、q 退出，大文件首选
3. more —— 简化版分页器，只能向前，功能弱于 less
4. head/tail —— -n 取行数、-c 取字节数，tail -f 实时跟踪追加
5. nl —— 输出带行号，od/hexdump —— 八进制/十六进制看二进制
```

```shell
# 看小文件与拼接
cat -n /etc/hosts
cat part1.txt part2.txt > all.txt

# 看大文件（日志）
less /var/log/syslog        # / 搜索关键词，G 跳结尾
tail -n 50 /var/log/syslog  # 最后 50 行
tail -f /var/log/syslog     # 实时跟踪，Ctrl+C 退出

# 看二进制 / 不可见字符
hexdump -C a.bin | head     # 十六进制 + ASCII
od -c a.bin | head          # 八进制看字符
```

## 文件查找

查找分「实时全盘搜」和「数据库秒查」两种思路。find 实时遍历文件系统，条件最灵活（按名字/类型/大小/时间），但慢；locate 查 updatedb 预建的索引数据库，秒出结果但可能过期（刚建的文件查不到）。which/whereis/type 是查「命令」不是查「文件」——which 找 PATH 里的可执行文件，whereis 连 man 和源码一起找，type 判断是 shell 内置还是外部命令。

```text
查找命令分工：
1. find —— 实时遍历，按 -name/-type/-size/-mtime 过滤，-exec 对结果执行操作
2. locate —— 查索引数据库，秒出但需 updatedb 更新，新建文件可能搜不到
3. which —— 找 PATH 里的可执行文件，whereis —— 连 man/源码一起定位
4. type —— 判断命令类型（shell 内置 / 别名 / 外部程序）
```

```shell
# find 按条件查找
find / -name "*.log" -type f 2>/dev/null          # 按名字
find /var/log -type f -mtime -7                    # 7 天内修改的
find /tmp -type f -size +100M                      # 大于 100MB 的
find /var/log -name "*.gz" -exec rm {} \;          # 找到并删除

# 数据库查找与命令定位
updatedb && locate nginx.conf                     # 更新索引后秒查
which python3                                       # PATH 里的位置
whereis ls                                          # 命令 + man + 源码
type cd                                             # cd 是 shell 内置
```

## 应用场景实战

### 场景一：找出 /var/log 下最近 3 天修改过的大日志文件并归档

```shell
# 1. 找最近 3 天修改、大于 50MB 的日志
find /var/log -type f -name "*.log" -mtime -3 -size +50M

# 2. 逐个看行数，确认要处理
find /var/log -type f -name "*.log" -size +50M -exec wc -l {} \;

# 3. 归档（压缩）后删除原文件释放空间
find /var/log -type f -name "*.log" -size +50M -exec gzip {} \;
ls -lh /var/log/*.log.gz
```

### 场景二：快速查看一个接口服务的运行状态和日志尾部

```shell
# 1. 定位进程（find 找配置文件 / pgrep 找进程）
find /etc -name "*.conf" | grep -i nginx

# 2. 看日志尾部定位报错
tail -n 100 /var/log/nginx/error.log

# 3. 实时跟踪，边请求边看日志
tail -f /var/log/nginx/access.log
```

```text
# 实测输出（本机真实 nginx 访问日志）
$ tail -n 2 /var/log/nginx/access.log

```

### 场景三：批量重命名文件并查找大文件

```shell
# 1. 批量把 .txt 改成 .md（shell 循环，去掉原扩展名）
for f in *.txt; do mv "$f" "${f%.txt}.md"; done
# 或用 rename 命令（Debian 系）
rename 's/\.txt$/.md/' *.txt

# 2. 找出当前目录下最大的 10 个文件
find . -type f -exec ls -lh {} \; | sort -k5 -rh | head -10

# 3. 统计某目录下各类型文件数量
find /var/log -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn
```

## 最佳实践与踩坑记录

### 最佳实践

1. 大文件用 less 分页看，别用 cat 把几 GB 日志刷屏
2. 删文件前先 ls 确认目标，rm -rf 加绝对路径、别手滑带空格的变量
3. 复制目录要保留属性用 cp -a，别用 cp -r（会丢权限和时间戳）
4. 找文件能用 locate 先秒查，查不到再 find 实时遍历
5. 看日志跟踪用 tail -f，配 grep 过滤更高效（tail -f log | grep ERROR）

### 踩坑记录

```text
坑 1：rm -rf $DIR/ 当 DIR 为空变量，误删根目录
结论：变量没赋值，rm -rf / 把系统删光。
原因：脚本里 DIR 变量为空，路径变成 /，-f 又不提示。
解法：删之前 echo "$DIR" 校验非空，或用 rm -rf "/opt/$DIR" 限定父目录。

坑 2：find -exec 结果里带空格文件名导致命令断错
结论：文件名含空格，-exec {} 执行时参数被拆分。
原因：{} 未加引号，shell 按空格分词。
解法：用 find ... -print0 | xargs -0，或 -exec 里给 {} 加引号。

坑 3：cp -r 复制后文件权限和时间戳变了
结论：复制的目录权限丢失，时间戳全变成复制时间。
原因：cp -r 不保留属性，要用 -p 或 -a。
解法：目录备份用 cp -a（归档模式），或 tar -p。

坑 4：locate 搜不到刚创建的文件
结论：刚 touch 的文件 locate 查不到。
原因：locate 查的是 updatedb 的索引快照，新文件还没入索引。
解法：先 updatedb 刷新索引，或改用 find 实时查找。

坑 5：用 cat 查看大日志导致终端卡死
结论：几 GB 的日志 cat 一刷，终端直接卡住。
原因：cat 无分页，一次性输出全部内容。
解法：大文件用 less，或 tail/head 只看需要的部分。

坑 6：mv 跨文件系统移动大目录极慢
结论：把大目录 mv 到另一块盘，卡了十几分钟。
原因：跨文件系统 mv 是「复制 + 删除」，要完整读写数据，不是改目录项。
解法：同分区 mv 秒完成；跨分区用 rsync --remove-source-files 或接受复制耗时。
```
