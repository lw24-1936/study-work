## 概述

AI（人工智能）是让机器模拟人类智能的技术，从机器学习到深度学习再到 LLM，层层递进。

```text
概念层次（从大到小）：
人工智能（AI）
  └── 机器学习（ML）
        └── 深度学习（DL）
              └── 大语言模型（LLM）
                    └── 生成式 AI / AIGC
```

## 人工智能（AI）

人工智能是让机器具备智能（学习、推理、理解）的统称。

```text
AI 的分类：
1. 弱 AI（Narrow AI）—— 专注特定任务（人脸识别、语音助手）
2. 强 AI（General AI）—— 通用智能（尚未实现）
```

```text
AI 的应用：
1. 计算机视觉 —— 人脸识别、图像识别
2. 自然语言处理 —— 翻译、对话、摘要
3. 语音识别 —— 语音助手
4. 推荐系统 —— 个性化推荐
```

## 机器学习（ML）

机器学习是 AI 的核心方法，让机器从数据中学习规律。

### 三种学习类型

```text
1. 监督学习（Supervised）—— 有标签数据（分类、回归）
2. 无监督学习（Unsupervised）—— 无标签（聚类、降维）
3. 强化学习（Reinforcement）—— 试错学习（游戏、机器人）
```

### 监督学习示例

```text
分类：判断邮件是垃圾邮件还是正常邮件（标签：是/否）
回归：预测房价（标签：具体价格）
```

### 典型算法

```text
1. 线性回归 —— 预测连续值
2. 逻辑回归 —— 二分类
3. 决策树 —— 分类/回归
4. 随机森林 —— 集成学习
5. SVM —— 支持向量机
```

## 深度学习（DL）

深度学习是机器学习的子集，用多层神经网络学习复杂特征。

### 神经网络

```text
神经网络模拟人脑神经元：
输入层 → 隐藏层（多层）→ 输出层
```

```text
深度学习的"深"：多层隐藏层（几十到几百层）
每层提取不同层次的特征
```

### 典型架构

```text
1. CNN（卷积神经网络）—— 图像处理
2. RNN（循环神经网络）—— 序列数据
3. Transformer —— 注意力机制（LLM 的基础）
```

### 深度学习的应用

```text
1. 图像识别 —— CNN
2. 语音识别 —— RNN/Transformer
3. 自然语言处理 —— Transformer
```

## 大语言模型（LLM）

LLM 是基于 Transformer 的大规模语言模型，理解并生成自然语言。

### LLM 的特点

```text
1. 规模大 —— 数十亿到数万亿参数
2. 预训练 —— 海量文本训练
3. 通用 —— 对话、翻译、写作、代码
4. 涌现能力 —— 规模大到一定程度出现新能力
```

### 主流 LLM

```text
国外：GPT（OpenAI）、Claude（Anthropic）、Gemini（Google）
国内：DeepSeek、Qwen（通义千问）、文心一言、Kimi
开源：Llama、DeepSeek、Qwen
```

### LLM 的能力

```text
1. 文本生成 —— 写作、代码
2. 对话 —— 聊天、问答
3. 翻译 —— 多语言翻译
4. 摘要 —— 长文本摘要
5. 推理 —— 逻辑推理
```

## 生成式 AI 与 AIGC

### 生成式 AI（Generative AI）

```text
生成式 AI：能生成新内容（文本、图片、音频、视频）的 AI
区别于判别式 AI（只判断分类）
```

### AIGC（AI Generated Content）

```text
AIGC = AI 生成内容
1. 文本生成 —— ChatGPT、写作
2. 图片生成 —— Midjourney、Stable Diffusion
3. 视频生成 —— Sora
4. 音频生成 —— 语音合成、音乐
```
