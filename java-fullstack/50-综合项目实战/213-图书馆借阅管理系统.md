## 项目背景

图书馆借阅管理系统（Library Management System）是图书行业最经典的业务系统，从高校图书馆到公共图书馆、从社区书屋到企业图书角都依赖它完成「采书 → 编目 → 借还 → 逾期 → 统计」的闭环。选择它作为综合实战项目，是因为它把业务系统的三类典型难题都包含在内：状态机（图书副本的在馆/已借/预约三态流转）、复杂的业务计算（逾期罚款、借阅期限）、副本与预约的联动（一馆多副本、多人排队预约）。逻辑密度高但规模适中，非常适合做完整的实战演练。

业务痛点：

```text
1. 借还靠手工登记：借书还书写在纸质登记本上，条码扫描后还要人工翻本子，速度慢易出错
2. 逾期靠人眼发现：借出去的书超期没人知道，罚款算不清楚，读者有意见
3. 图书去向不明：一本书被谁借走、何时还、是否丢书，一问三不知，馆藏对不上账
4. 预约靠到馆排队：热门书被借走就借不到，读者反复到馆询问，体验差
5. 副本管理混乱：同一本书多个副本，有的在馆有的外借，管理员无法快速定位可借副本
6. 统计靠人工数：热门图书、读者借阅排行、馆藏流通率，月底手工统计费时费力
```

目标用户与核心诉求：

```text
1. 读者：检索图书、在线预约、查看自己的借阅与逾期情况、自助续借，希望少跑一趟是一趟
2. 图书管理员：扫码借还、处理预约与罚款、管理馆藏副本，希望操作快、账目清
3. 馆长/采编：查看馆藏统计、借阅排行、图书流通分析，指导采购与剔旧
```

项目要解决的核心问题一句话概括：让每本图书的每个副本「状态可查、流转可控、逾期可算、预约可等」，借阅全流程数字化。

## 功能介绍

功能按角色拆成三个端：读者端（OPAC 检索台）、馆员工作台（借还前台）、管理后台（馆长/采编）。

```text
一、读者端（读者视角）
1. 图书检索 —— 按书名/作者/ISBN/分类检索图书，查看在馆状态与副本分布
2. 图书详情 —— 封面、简介、馆藏副本列表（每本副本的在馆/外借/预约状态）
3. 借阅与预约 —— 在馆图书直接到馆借阅，外借图书可在线预约排队
4. 我的借阅 —— 当前借阅列表、应还日期、逾期提醒与罚款金额
5. 续借 —— 到期前在线续借一次（延长借期，有次数限制）
6. 借阅历史 —— 历史借还记录、罚款缴纳记录

二、馆员工作台（借还前台视角）
1. 图书管理 —— 图书（ISBN 维度）与馆藏副本（条码维度）的录入、编辑、下架
2. 读者管理 —— 读者办证、挂失、注销，读者状态管理
3. 借书 —— 扫描读者证 + 扫描图书条码，自动校验可借状态并出借
4. 还书 —— 扫描条码归还，自动计算逾期天数与罚款
5. 罚款管理 —— 逾期罚款登记、缴纳、减免
6. 预约处理 —— 预约队列查看，归还图书自动流转给下一个预约者

三、管理后台（馆长/采编视角）
1. 分类管理 —— 中图法分类维护，图书归类
2. 统计报表 —— 热门图书榜、读者借阅排行、馆藏流通率、逾期率分析
3. 规则配置 —— 借阅期限、可借数量、续借次数、罚款单价、预约保留天数等参数
```

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 开发框架 | Spring Boot 2.7/3.x | 生态成熟，起步快，社区资料多 |
| 持久层 | MyBatis-Plus | 单表 CRUD 零 SQL，复杂统计与报表走 XML |
| 数据库 | MySQL 8.0 | 图书、读者、借阅、预约等核心业务数据落库 |
| 缓存 | Redis | 副本状态缓存、预约队列、逾期任务锁、热门榜 |
| 定时任务 | Spring Task | 逾期扫描、罚款计算、预约到期提醒 |
| 条码扫描 | 扫码枪模拟键盘输入 / 微信小程序扫码 | 馆员端条码枪即扫即输，读者端小程序扫码 |
| 鉴权 | Spring Security + JWT | 无状态认证，前后端分离标配 |
| 前端 | Vue 3 + Element Plus | 后台管理类系统的成熟组合 |
| 构建 | Maven | 依赖管理标准工具 |

选型说明：

```text
1. 图书与副本分表建模：book 表存书目（ISBN 维度），book_copy 表存馆藏副本（条码维度），一本书 5 个副本就是 5 行 copy
2. Redis 承担四件事：副本状态缓存（高频读）、预约排队队列、逾期扫描分布式锁、热门榜 ZSet
3. 罚款计算不落库存储过程：用 Service 方法按规则动态计算（借期、单价、宽限期可配），改规则不动数据库
4. 借阅状态机用「副本状态 + 借阅记录状态」双字段：副本状态服务查询，记录状态服务审计
```

请求链路示例（馆员扫描借书）：

```text
1. 馆员扫码枪输入读者证号，前端 POST /api/borrow/check-reader
2. 馆员再扫图书条码，前端 POST /api/borrow，body 为 readerId + copyBarcode
3. Service 校验读者状态（正常/挂失/逾期未还超限）与借阅数量上限
4. 校验副本状态必须为「在馆」（状态机非法流转直接拒绝）
5. 加分布式锁 copy:lock:{copyId}，防止并发借同一本副本
6. 事务内：副本状态置为「已借」，插入借阅记录（应还日期 = 今天 + 借期）
7. 若该副本有预约队列且队首是当前读者，弹出队首预约并标记完成
8. 删除副本状态缓存，返回借阅成功；读者端「我的借阅」刷新
```

还书链路（扫描归还 + 逾期计算）：

```text
1. 馆员扫描条码，前端 POST /api/borrow/return {copyBarcode}
2. 查找该副本「借出未还」的最新借阅记录，无则报「未借出」
3. 计算逾期天数：实际还书日 - 应还日期，逾期则按单价生成罚款记录
4. 事务内：副本状态置为「在馆」，借阅记录置为「已还」，写还书时间
5. 检查该副本预约队列：有预约者则副本状态置为「已预约」，通知队首读者来取
6. 删除副本状态缓存；逾期读者端看到罚款金额，可在线缴纳或到馆缴纳
```

Redis Key 设计：

```text
copy:status:{copyId}            String  副本状态缓存（0在馆 1已借 2已预约），TTL 30 分钟，借还时删除
copy:lock:{copyId}              String  副本操作分布式锁，SETNX 防止并发借/还同一副本
reservation:queue:{bookId}      ZSet    图书预约队列（score=queue_no），借还时维护
fine:unpaid:{readerId}          String  读者未缴罚款总额缓存，读者端展示加速
borrow:task:lock                String  逾期扫描定时任务分布式锁
book:hot:rank                   ZSet    热门图书榜（借出次数加权分）
```

## 核心实现

### 1. 借阅状态机与借书

```java
@Service
public class BorrowService {

    private static final String COPY_LOCK_PREFIX = "copy:lock:";
    private static final String COPY_STATUS_PREFIX = "copy:status:";

    @Autowired
    private BookCopyMapper bookCopyMapper;
    @Autowired
    private BorrowRecordMapper borrowRecordMapper;
    @Autowired
    private ReaderMapper readerMapper;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 借书：扫码借出
     * 副本状态机：0在馆 -> 1已借（借出）/ 2已预约（预约者取书）
     * 非法流转（已借/丢失的副本再借）直接拒绝
     */
    @Transactional
    public Long borrow(String cardNo, String barcode, Long operatorId) {
        // 1. 校验读者
        Reader reader = readerMapper.selectOne(new LambdaQueryWrapper<Reader>()
                .eq(Reader::getCardNo, cardNo));
        if (reader == null || reader.getStatus() != 1) {
            throw new BusinessException("读者不存在或状态异常");
        }
        // 2. 校验可借数量
        int maxBorrow = reader.getReaderType() == 2 ? 10 : 5;
        if (reader.getBorrowCount() >= maxBorrow) {
            throw new BusinessException("借阅数量已达上限");
        }
        // 3. 加副本锁，防止并发借同一副本
        BookCopy copy = bookCopyMapper.selectOne(new LambdaQueryWrapper<BookCopy>()
                .eq(BookCopy::getBarcode, barcode));
        if (copy == null) {
            throw new BusinessException("副本不存在");
        }
        String lockKey = COPY_LOCK_PREFIX + copy.getId();
        Boolean locked = redis.opsForValue().setIfAbsent(lockKey, "1", 10, TimeUnit.SECONDS);
        if (!Boolean.TRUE.equals(locked)) {
            throw new BusinessException("操作繁忙，请重试");
        }
        try {
            // 4. 状态机校验：只有「在馆」和「已预约」可借出
            if (copy.getStatus() != 0 && copy.getStatus() != 2) {
                throw new BusinessException("该副本当前不可借出");
            }
            // 5. 预约校验：副本是「已预约」状态时，只有队首预约者能借
            if (copy.getStatus() == 2) {
                Reservation top = reservationMapper.selectOne(new LambdaQueryWrapper<Reservation>()
                        .eq(Reservation::getCopyId, copy.getId())
                        .eq(Reservation::getStatus, 1)
                        .orderByAsc(Reservation::getQueueNo).last("LIMIT 1"));
                if (top == null || !top.getReaderId().equals(reader.getId())) {
                    throw new BusinessException("该副本已被预约，请预约者本人来借");
                }
            }
            // 6. 借期规则：教师 60 天，其他 30 天
            int days = reader.getReaderType() == 3 ? 60 : 30;
            // 7. 更新副本状态为已借，累计借出次数 +1
            BookCopy copyUpdate = new BookCopy();
            copyUpdate.setId(copy.getId());
            copyUpdate.setStatus(1);
            copyUpdate.setBorrowCount(copy.getBorrowCount() + 1);
            bookCopyMapper.updateById(copyUpdate);
            // 8. 插入借阅记录
            BorrowRecord record = new BorrowRecord();
            record.setCopyId(copy.getId());
            record.setBookId(copy.getBookId());
            record.setReaderId(reader.getId());
            record.setBorrowTime(LocalDateTime.now());
            record.setDueTime(LocalDateTime.now().plusDays(days));
            record.setStatus(0);
            record.setOperatorId(operatorId);
            borrowRecordMapper.insert(record);
            // 9. 读者在借数量 +1
            Reader readerUpdate = new Reader();
            readerUpdate.setId(reader.getId());
            readerUpdate.setBorrowCount(reader.getBorrowCount() + 1);
            readerMapper.updateById(readerUpdate);
            // 10. 若该副本有预约队列，弹出队首并标记完成
            completeReservation(copy.getId(), reader.getId());
            return record.getId();
        } finally {
            redis.delete(lockKey);
            redis.delete(COPY_STATUS_PREFIX + copy.getId());
        }
    }
}
```

### 2. 还书与逾期罚款计算

```java
@Service
public class ReturnService {

    @Autowired
    private BookCopyMapper bookCopyMapper;
    @Autowired
    private BorrowRecordMapper borrowRecordMapper;
    @Autowired
    private FineRecordMapper fineRecordMapper;
    @Autowired
    private ReaderMapper readerMapper;
    @Autowired
    private BorrowRuleService ruleService;

    /**
     * 还书：扫描条码
     * 归还时计算逾期天数与罚款；有预约的副本自动进入「已预约」等待队首读者
     */
    @Transactional
    public ReturnResult doReturn(String barcode) {
        BookCopy copy = bookCopyMapper.selectOne(new LambdaQueryWrapper<BookCopy>()
                .eq(BookCopy::getBarcode, barcode));
        if (copy == null) {
            throw new BusinessException("副本不存在");
        }
        // 1. 找该副本「借出中」的最新记录
        BorrowRecord record = borrowRecordMapper.selectOne(new LambdaQueryWrapper<BorrowRecord>()
                .eq(BorrowRecord::getCopyId, copy.getId())
                .eq(BorrowRecord::getStatus, 0)
                .orderByDesc(BorrowRecord::getBorrowTime).last("LIMIT 1"));
        if (record == null) {
            throw new BusinessException("该副本未借出，无法归还");
        }
        LocalDateTime now = LocalDateTime.now();
        // 2. 更新借阅记录为已还
        BorrowRecord update = new BorrowRecord();
        update.setId(record.getId());
        update.setStatus(1);
        update.setReturnTime(now);
        borrowRecordMapper.updateById(update);
        // 3. 读者在借数量 -1
        Reader reader = readerMapper.selectById(record.getReaderId());
        Reader readerUpdate = new Reader();
        readerUpdate.setId(reader.getId());
        readerUpdate.setBorrowCount(reader.getBorrowCount() - 1);
        readerMapper.updateById(readerUpdate);
        // 4. 计算逾期罚款（规则：逾期单价 x 天数，教师宽限 0 天，普通读者宽限 3 天）
        ReturnResult result = new ReturnResult();
        long overdueDays = Duration.between(record.getDueTime(), now).toDays();
        if (overdueDays > 0) {
            int grace = reader.getReaderType() == 3 ? 0 : 3;
            long billable = Math.max(0, overdueDays - grace);
            if (billable > 0) {
                BigDecimal amount = ruleService.overdueFineUnit()
                        .multiply(BigDecimal.valueOf(billable));
                FineRecord fine = new FineRecord();
                fine.setReaderId(reader.getId());
                fine.setBorrowId(record.getId());
                fine.setType(1);
                fine.setAmount(amount);
                fine.setOverdueDays((int) billable);
                fine.setStatus(0);
                fineRecordMapper.insert(fine);
                result.setFineAmount(amount);
            }
        }
        // 5. 副本状态流转：有预约 -> 已预约（通知队首），无预约 -> 在馆
        Reservation next = reservationMapper.selectOne(new LambdaQueryWrapper<Reservation>()
                .eq(Reservation::getBookId, copy.getBookId())
                .eq(Reservation::getStatus, 0)
                .orderByAsc(Reservation::getQueueNo).last("LIMIT 1"));
        BookCopy copyUpdate = new BookCopy();
        copyUpdate.setId(copy.getId());
        if (next != null) {
            copyUpdate.setStatus(2); // 已预约，等队首读者来取
            bookCopyMapper.updateById(copyUpdate);
            // 分配副本并通知：保留 2 天，过期释放
            Reservation resUpdate = new Reservation();
            resUpdate.setId(next.getId());
            resUpdate.setCopyId(copy.getId());
            resUpdate.setStatus(1);
            resUpdate.setExpireTime(now.plusDays(2));
            reservationMapper.updateById(resUpdate);
            result.setReservedReaderId(next.getReaderId());
            // 生产环境：站内信/短信通知「您预约的书已到馆，请 2 天内来取」
        } else {
            copyUpdate.setStatus(0);
            bookCopyMapper.updateById(copyUpdate);
        }
        return result;
    }

    /**
     * 续借：到期前可续借一次（续借从原应还日顺延借期）
     */
    @Transactional
    public void renew(Long borrowId, Long readerId) {
        BorrowRecord record = borrowRecordMapper.selectById(borrowId);
        if (record == null || !record.getReaderId().equals(readerId)) {
            throw new BusinessException("借阅记录不存在");
        }
        if (record.getStatus() != 0) {
            throw new BusinessException("该记录已归还，不能续借");
        }
        if (record.getRenewCount() >= ruleService.maxRenew()) {
            throw new BusinessException("已达最大续借次数");
        }
        if (record.getDueTime().isBefore(LocalDateTime.now())) {
            throw new BusinessException("已逾期，请先归还并缴纳罚款");
        }
        // 有预约的图书不可续借（预约者优先）
        Long reservationCount = reservationMapper.selectCount(new LambdaQueryWrapper<Reservation>()
                .eq(Reservation::getBookId, record.getBookId())
                .eq(Reservation::getStatus, 0));
        if (reservationCount > 0) {
            throw new BusinessException("该书已有读者预约，不能续借");
        }
        BorrowRecord update = new BorrowRecord();
        update.setId(borrowId);
        update.setDueTime(record.getDueTime().plusDays(ruleService.loanDays()));
        update.setRenewCount(record.getRenewCount() + 1);
        update.setStatus(2); // 已续借
        borrowRecordMapper.updateById(update);
    }
}
```

### 3. 图书预约与队列管理

```java
@Service
public class ReservationService {

    @Autowired
    private ReservationMapper reservationMapper;
    @Autowired
    private BookCopyMapper bookCopyMapper;
    @Autowired
    private StringRedisTemplate redis;

    private static final String QUEUE_KEY_PREFIX = "reservation:queue:";

    /**
     * 预约图书：全部副本都在借时排队
     * 队列用 MySQL 的 queue_no 排序（事实源），Redis ZSet 加速展示
     */
    @Transactional
    public Long reserve(Long bookId, Long readerId) {
        // 1. 防重复预约
        Long exist = reservationMapper.selectCount(new LambdaQueryWrapper<Reservation>()
                .eq(Reservation::getBookId, bookId)
                .eq(Reservation::getReaderId, readerId)
                .in(Reservation::getStatus, 0, 1));
        if (exist > 0) {
            throw new BusinessException("您已预约过该书");
        }
        // 2. 计算队尾序号：当前最大 queue_no + 1
        Reservation last = reservationMapper.selectOne(new LambdaQueryWrapper<Reservation>()
                .eq(Reservation::getBookId, bookId)
                .orderByDesc(Reservation::getQueueNo).last("LIMIT 1"));
        int queueNo = (last == null ? 0 : last.getQueueNo()) + 1;
        // 3. 插入预约记录
        Reservation reservation = new Reservation();
        reservation.setBookId(bookId);
        reservation.setReaderId(readerId);
        reservation.setQueueNo(queueNo);
        reservation.setStatus(0);
        reservationMapper.insert(reservation);
        // 4. 同步 Redis 队列（score = queue_no）
        redis.opsForZSet().add(QUEUE_KEY_PREFIX + bookId,
                String.valueOf(reservation.getId()), queueNo);
        return reservation.getId();
    }

    /**
     * 取消预约：读者主动取消，或通知后超时未取自动释放
     * 释放后重新分配副本给下一位预约者
     */
    @Transactional
    public void cancel(Long reservationId, Long readerId) {
        Reservation reservation = reservationMapper.selectById(reservationId);
        if (reservation == null || !reservation.getReaderId().equals(readerId)) {
            throw new BusinessException("预约记录不存在");
        }
        if (reservation.getStatus() != 0 && reservation.getStatus() != 1) {
            throw new BusinessException("当前状态不可取消");
        }
        // 已被通知待取（status=1）：释放副本，归还到在馆或转给下一预约者
        if (reservation.getStatus() == 1 && reservation.getCopyId() != null) {
            Reservation next = reservationMapper.selectOne(new LambdaQueryWrapper<Reservation>()
                    .eq(Reservation::getBookId, reservation.getBookId())
                    .eq(Reservation::getStatus, 0)
                    .orderByAsc(Reservation::getQueueNo).last("LIMIT 1"));
            BookCopy copy = bookCopyMapper.selectById(reservation.getCopyId());
            BookCopy copyUpdate = new BookCopy();
            copyUpdate.setId(copy.getId());
            if (next != null) {
                // 顺延给下一位预约者，保留期重新计算
                copyUpdate.setStatus(2);
                bookCopyMapper.updateById(copyUpdate);
                Reservation nextUpdate = new Reservation();
                nextUpdate.setId(next.getId());
                nextUpdate.setCopyId(copy.getId());
                nextUpdate.setStatus(1);
                nextUpdate.setExpireTime(LocalDateTime.now().plusDays(2));
                reservationMapper.updateById(nextUpdate);
            } else {
                copyUpdate.setStatus(0);
                bookCopyMapper.updateById(copyUpdate);
            }
        }
        Reservation update = new Reservation();
        update.setId(reservationId);
        update.setStatus(3);
        reservationMapper.updateById(update);
        redis.opsForZSet().remove(QUEUE_KEY_PREFIX + reservation.getBookId(),
                String.valueOf(reservationId));
    }
}
```

### 4. 逾期扫描定时任务

```java
@Component
public class OverdueScanTask {

    private static final String TASK_LOCK = "borrow:task:lock";

    @Autowired
    private BorrowRecordMapper borrowRecordMapper;
    @Autowired
    private ReservationMapper reservationMapper;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 每天凌晨扫描逾期借阅：
     * 1. 给读者发逾期提醒（站内信/短信）
     * 2. 扫描「已通知待取」的预约，超保留期未取则释放
     */
    @Scheduled(cron = "0 0 1 * * ?")
    public void scanOverdue() {
        // 分布式锁：多实例部署时只有一个实例执行
        Boolean locked = redis.opsForValue().setIfAbsent(TASK_LOCK, "1", 30, TimeUnit.MINUTES);
        if (!Boolean.TRUE.equals(locked)) {
            log.info("逾期扫描任务已被其他实例执行");
            return;
        }
        try {
            LocalDateTime now = LocalDateTime.now();
            // 1. 扫描借出中且已逾期的记录
            List<BorrowRecord> overdue = borrowRecordMapper.selectList(
                    new LambdaQueryWrapper<BorrowRecord>()
                            .eq(BorrowRecord::getStatus, 0)
                            .lt(BorrowRecord::getDueTime, now));
            for (BorrowRecord record : overdue) {
                // 逾期提醒（这里简化打日志，生产接短信/邮件网关）
                long days = Duration.between(record.getDueTime(), now).toDays();
                log.info("逾期提醒: readerId={}, copyId={}, 逾期{}天",
                        record.getReaderId(), record.getCopyId(), days);
            }
            // 2. 扫描「已通知待取」超期的预约，释放给下一位
            List<Reservation> expired = reservationMapper.selectList(
                    new LambdaQueryWrapper<Reservation>()
                            .eq(Reservation::getStatus, 1)
                            .lt(Reservation::getExpireTime, now));
            for (Reservation res : expired) {
                reservationService.cancelBySystem(res.getId()); // 系统代取消，走释放逻辑
            }
        } finally {
            redis.delete(TASK_LOCK);
        }
    }
}
```

```java
@Service
public class StatisticsService {

    private static final String HOT_RANK = "book:hot:rank";

    @Autowired
    private BorrowRecordMapper borrowRecordMapper;
    @Autowired
    private BookMapper bookMapper;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 热门图书榜：按借出次数统计近 30 天排行
     * 定时任务每天刷新 ZSet，读者端秒查
     */
    @Scheduled(cron = "0 30 1 * * ?")
    public void refreshHotRank() {
        // 近 30 天按 book_id 分组统计借出次数
        List<Map<String, Object>> stats = borrowRecordMapper.selectMaps(
                new QueryWrapper<>()
                        .select("book_id, COUNT(*) AS cnt")
                        .ge("borrow_time", LocalDateTime.now().minusDays(30))
                        .groupBy("book_id")
                        .orderByDesc("cnt")
                        .last("LIMIT 50"));
        ZSetOperations<String, Object> zset = redis.opsForZSet();
        for (Map<String, Object> row : stats) {
            Long bookId = (Long) row.get("book_id");
            Long cnt = ((Number) row.get("cnt")).longValue();
            zset.add(HOT_RANK, String.valueOf(bookId), cnt);
        }
        // 只保留前 50，防止 ZSet 无限膨胀
        zset.removeRange(HOT_RANK, 50, -1);
    }

    /**
     * 读者借阅排行：全量或按部门/类型统计
     * 借阅次数 = borrow_record 按 reader_id 分组计数
     */
    public List<ReaderRankVO> readerRank(int topN) {
        List<Map<String, Object>> stats = borrowRecordMapper.selectMaps(
                new QueryWrapper<>()
                        .select("reader_id, COUNT(*) AS cnt")
                        .groupBy("reader_id")
                        .orderByDesc("cnt")
                        .last("LIMIT " + topN));
        List<ReaderRankVO> result = new ArrayList<>();
        for (Map<String, Object> row : stats) {
            ReaderRankVO vo = new ReaderRankVO();
            vo.setReaderId((Long) row.get("reader_id"));
            vo.setBorrowCount(((Number) row.get("cnt")).longValue());
            result.add(vo);
        }
        return result;
    }

    /**
     * 馆藏流通率：指定时间段的借出次数 / 馆藏副本总数
     * 反映馆藏利用率，指导采编采购方向
     */
    public BigDecimal circulationRate(LocalDateTime start, LocalDateTime end) {
        Long borrowCount = borrowRecordMapper.selectCount(new LambdaQueryWrapper<BorrowRecord>()
                .ge(BorrowRecord::getBorrowTime, start)
                .lt(BorrowRecord::getBorrowTime, end));
        Long copyCount = bookCopyMapper.selectCount(null);
        if (copyCount == 0) {
            return BigDecimal.ZERO;
        }
        return BigDecimal.valueOf(borrowCount)
                .divide(BigDecimal.valueOf(copyCount), 2, RoundingMode.HALF_UP);
    }
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 图书与副本分表是借阅系统的根基：书目（ISBN）与实体副本（条码）必须分开建模，否则「5 个副本 3 个被借」根本无法表达
2. 借还操作必须加副本级分布式锁：并发借同一本副本会出现「一册两借」，Redis SETNX + 数据库乐观校验双保险
3. 状态机显式定义：副本状态（在馆/已借/预约/丢失）与借阅记录状态分开维护，流转前校验，杜绝「借了还能再借」
4. 罚款是计算出来的不是存出来的：逾期罚款按「应还日期 + 规则」动态计算，规则参数（单价/宽限/封顶）配置化，改规则不动历史数据
5. 预约队列的队首分配放在还书事务里：还书与「分配副本给队首」同事务提交，避免「书还了但预约者不知道」的中间态
6. 定时任务必须加分布式锁：逾期扫描、预约过期释放等任务用 SETNX 抢锁，多实例部署只允许一个执行
7. 副本状态高频读走 Redis：读者端查「在馆状态」是最高频请求，缓存副本状态 + 借还时删缓存，命中率极高

### 踩坑记录

```text
坑 1：同一副本被并发借出两次
结论：一本书的两个读者都显示借阅成功，馆藏对不上账。
原因：借书逻辑先查状态再更新，两步之间无锁，并发请求都查到「在馆」。
解法：副本操作加 Redis 分布式锁 copy:lock:{copyId}；UPDATE 时带 status=0 条件，影响行数为 0 说明已被借走。

坑 2：还书时逾期罚款重复生成
结论：同一笔借阅记录生成两条罚款。
原因：还书接口被重复调用（前端双击/扫码枪重复触发），没做幂等。
解法：还书记录 UPDATE 带 status=0 条件（乐观锁），影响行数 0 直接返回「已归还」；罚款以借阅记录唯一关联。

坑 3：预约者取书时副本被非预约者借走
结论：预约排队的读者到馆发现书被别人借走了。
原因：副本「已预约」状态下，借书逻辑只校验了 status=2，没校验借书人是不是队首预约者。
解法：status=2 时必须校验「当前借书人 == 队首预约者」，否则拒绝；管理员强制借出需单独权限。

坑 4：预约通知后无人取书，副本长期占用
结论：预约者不来取，副本一直停在「已预约」状态，别人也借不了。
原因：只做了「通知」，没做「保留期到期释放」。
解法：通知时写 expire_time（如 2 天），定时任务扫描 status=1 且超期的预约，自动取消并顺延给下一位或转在馆。

坑 5：续借后应还日期计算错误
结论：续借 30 天，但应还日期只加了 10 天。
原因：续借用「当前时间 + 借期」而不是「原应还日 + 借期」，读者拖延到快到期才续借就吃亏。
解法：续借必须从原应还日期顺延：newDue = oldDue + loanDays；有预约的图书禁止续借。

坑 6：逾期天数计算含当天导致多罚一天
结论：读者第 31 天还书被罚 2 天（30 天借期）。
原因：Duration.between 算出的秒数换算天数时向上取整，边界日多算。
解法：用「应还日次日 0 点」为起算点：overdue = now.toLocalDate().toEpochDay() - dueDate.toLocalDate().toEpochDay()，未跨天为 0。

坑 7：统计报表 SQL 越来越慢
结论：借阅排行按月查询要 3 秒以上。
原因：borrow_record 表数据量几十万行，GROUP BY 全表扫描，无覆盖索引。
解法：建联合索引 idx_reader_borrow (reader_id, borrow_time)；月度报表提前用定时任务预聚合到统计表，报表只查统计表。
```
