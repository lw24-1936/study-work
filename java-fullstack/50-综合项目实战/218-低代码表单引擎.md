## 项目背景

低代码表单引擎（Low-Code Form Engine）是低代码平台的核心组件：运营、HR、财务等非研发人员通过拖拽组件就能设计出「报名表、审批单、信息采集表」，系统根据设计配置自动生成可填写的表单页面，提交的数据自动入库，无需为每个新表单写一遍前后端代码。传统模式下每张新表单都是一次完整开发（建表 + 接口 + 页面 + 校验），周期以天计；表单引擎把「表单 = 配置」的 JSON 化，让新表单上线从几天缩短到几分钟。这个项目是低代码方向的最佳实战载体，覆盖了 JSON Schema 驱动、动态渲染、数据收集、报表统计等一整套机制。

业务痛点：

```text
1. 重复开发浪费：每张报名表/审批单都要写建表 SQL、CRUD 接口、前端表单页，大量重复劳动
2. 上线周期长：业务提需求到表单上线动辄 3-5 天，错过活动窗口
3. 字段变更麻烦：加一个字段要改表结构、改接口、改页面、改校验，牵一发动全身
4. 校验规则散落：必填、长度、正则、联动显隐散落在前后端各处，难以统一维护
5. 数据无法沉淀：各表单数据格式各异，无法统一查询、导出、统计
6. 非研发依赖重：运营做个小问卷都要排期等开发，自主性为零
```

目标用户与核心诉求：

```text
1. 业务人员（运营/HR/行政）：拖拽设计表单，配置校验与联动，发布后收集数据，导出 Excel
2. 研发人员：通过引擎的 API 嵌入自定义表单，减少重复 CRUD 开发
3. 平台管理员：管理表单模板、数据权限、发布状态
```

项目要解决的核心问题一句话概括：把「表单开发」抽象成「表单配置」，让业务人员用拖拽设计器几分钟生成一张可收集数据的表单，数据统一入 JSON 存储、可查询可导出可统计。

## 功能介绍

功能按角色与模块拆分：表单设计器（配置端）、表单渲染（填写端）、数据管理（收集端）、平台管理（治理端）。

```text
一、表单设计器（配置端，业务人员使用）
1. 组件拖拽 —— 从组件库拖入画布：单行文本/多行文本/数字/单选/多选/下拉/日期/时间/上传/评分/子表单
2. 属性配置 —— 选中组件配置：标题、占位符、必填、默认值、校验规则（长度/正则/范围）
3. 逻辑联动 —— 配置条件显隐（选「是」才显示补充字段）、选项联动、动态下拉（依赖接口）
4. 布局调整 —— 拖拽排序、栅格分列（一行两列/三列）、分组标题
5. 发布管理 —— 保存草稿/发布/下线，发布后生成填写链接与二维码

二、表单渲染（填写端，终端用户使用）
1. 动态渲染 —— 根据表单 JSON Schema 自动渲染可填写页面
2. 前端校验 —— 必填/格式/长度即时校验，提交前拦截
3. 条件联动 —— 按配置实时显隐字段、禁用字段
4. 草稿保存 —— 填写中途保存草稿，下次继续
5. 提交反馈 —— 提交成功页/重复提交拦截

三、数据管理（收集端）
1. 数据列表 —— 按表单查看收集的数据，分页/搜索/筛选
2. 数据详情 —— 单条数据完整查看（含子表单、上传文件）
3. 数据导出 —— 一键导出 Excel（字段名表头）
4. 数据统计 —— 单选/多选/下拉字段的选项分布统计（饼图/柱状图）
5. 数据编辑 —— 管理员可修正错误数据（留痕）

四、平台管理（治理端）
1. 表单模板 —— 常用表单（报名/审批/问卷）存为模板，一键套用
2. 权限控制 —— 表单级查看/编辑/导出权限（按角色/部门）
3. 发布审核 —— 可选开启发布前审核流程
4. 存储治理 —— 表单与数据量统计、归档、清理
```

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 开发框架 | Spring Boot 2.7/3.x | 生态成熟，快速搭建 |
| 持久层 | MyBatis-Plus | 单表 CRUD 零 SQL，复杂查询走 XML |
| 数据库 | MySQL 8.0 | 表单定义、提交数据、模板等业务数据 |
| 缓存 | Redis | 表单定义缓存、提交防重（SETNX） |
| 文件存储 | MinIO / 本地磁盘 | 表单附件、图片上传 |
| 前端 | Vue 3 + Element Plus + Form Designer | 拖拽设计器与动态渲染 |
| 表单 Schema | JSON Schema 风格（自定义扩展） | 组件定义与校验规则标准化 |
| Excel 导出 | EasyExcel | 大数据量流式导出 |
| 构建 | Maven | 依赖管理标准工具 |

选型说明：

```text
1. 表单定义用 JSON Schema 风格：组件类型、属性、校验规则、联动逻辑全部 JSON 化，一份配置驱动设计器、渲染器、校验器三端
2. 数据存储用「表单主表 + JSON 数据列」而非动态建表：提交数据整体存 JSON 列，避免每张表单动态建表的 DDL 风暴
3. 动态渲染靠前端 Schema 驱动：设计器保存 JSON，填写页读取 JSON 渲染，后端只负责存取与校验元数据
4. 校验双层：前端即时校验（体验）+ 后端权威校验（防绕过），后端用同一份 Schema 生成校验规则
5. 联动逻辑存 JSON 表达式：条件显隐用简单 DSL（fieldA == 'yes' && fieldB > 3），后端不解释执行，前端执行 + 后端存储
```

表单设计到数据收集的完整链路：

```text
1. 运营在画布拖入「姓名（单行文本）+ 手机号（单行文本，正则校验）+ 意向城市（下拉）」
2. 配置联动：意向城市选「其他」时显示「自定义城市」输入框
3. 点击发布：表单定义（JSON Schema）写入 MySQL，状态置为已发布，生成填写链接
4. 终端用户打开链接：前端拉取表单 Schema，动态渲染表单页
5. 用户填写提交：前端校验通过 → POST 提交数据（JSON 数据 + 防重 token）
6. 后端权威校验：按 Schema 校验规则逐字段校验，通过则写入提交数据表
7. 运营在管理端看到数据列表，点导出得到 Excel
8. 统计页展示意向城市分布饼图（后端聚合 JSON 数据列）
```

## 核心实现

### 1. 表单定义：保存与发布（Schema 校验 + 版本管理）

```java
@Service
public class FormDefService {

    @Autowired
    private FormDefMapper formDefMapper;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    @Autowired
    private ObjectMapper objectMapper;

    /**
     * 保存表单（草稿或发布）
     * 保存前校验 Schema 合法性：字段 key 唯一、类型合法、联动引用存在
     */
    @Transactional(rollbackFor = Exception.class)
    public Long saveForm(FormDef form) {
        // 1. 校验 Schema 合法性
        validateSchema(form.getSchemaJson());

        if (form.getId() == null) {
            // 新建：version 从 1 开始
            form.setVersion(1);
            form.setStatus(0);
            formDefMapper.insert(form);
        } else {
            // 更新：version +1，若已发布则置回草稿（改后需重新发布）
            FormDef old = formDefMapper.selectById(form.getId());
            form.setVersion(old.getVersion() + 1);
            form.setStatus(0);
            formDefMapper.updateById(form);
        }
        return form.getId();
    }

    /** 发布表单：校验通过后置为已发布，写缓存 */
    public void publish(Long formId) {
        FormDef form = formDefMapper.selectById(formId);
        if (form == null) {
            throw new BizException("表单不存在");
        }
        form.setStatus(1);
        formDefMapper.updateById(form);
        // 写 Schema 缓存（发布后立即生效）
        redisTemplate.opsForValue().set(
                "form:schema:" + formId, form.getSchemaJson(), 24, TimeUnit.HOURS);
    }

    /** 校验 Schema：字段 key 唯一、类型在白名单、联动引用存在 */
    private void validateSchema(String schemaJson) {
        try {
            JsonNode root = objectMapper.readTree(schemaJson);
            Set<String> fieldKeys = new HashSet<>();
            Set<String> types = Set.of("input", "textarea", "number",
                    "radio", "checkbox", "select", "date", "time", "upload", "score");
            for (JsonNode field : root.path("fields")) {
                String key = field.path("key").asText();
                String type = field.path("type").asText();
                if (!fieldKeys.add(key)) {
                    throw new BizException("字段 key 重复: " + key);
                }
                if (!types.contains(type)) {
                    throw new BizException("非法组件类型: " + type);
                }
                // 联动引用校验：visibleWhen.field 必须存在
                JsonNode visibleWhen = field.path("visibleWhen");
                if (visibleWhen.isObject() && !visibleWhen.path("field").asText().isEmpty()) {
                    String ref = visibleWhen.path("field").asText();
                    if (!fieldKeys.contains(ref)) {
                        throw new BizException("联动引用的字段不存在: " + ref);
                    }
                }
            }
        } catch (Exception e) {
            throw new BizException("Schema 格式错误: " + e.getMessage());
        }
    }
}
```

### 2. 表单渲染：按 Schema 组装填写页数据

```java
@RestController
@RequestMapping("/api/form")
public class FormRenderController {

    @Autowired
    private FormRenderService renderService;

    /** 填写页获取表单 Schema（匿名可访问，只返回已发布表单） */
    @GetMapping("/{formCode}/schema")
    public Result<FormSchemaVO> getSchema(@PathVariable String formCode) {
        return Result.success(renderService.getSchemaByCode(formCode));
    }
}

@Service
public class FormRenderService {

    @Autowired
    private FormDefMapper formDefMapper;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /** 缓存优先取 Schema；未命中查库并回填缓存 */
    public FormSchemaVO getSchemaByCode(String formCode) {
        // 1. 先按 code 查表单 id（code -> id 也走缓存）
        FormDef form = formDefMapper.selectByCode(formCode);
        if (form == null || form.getStatus() != 1) {
            throw new BizException("表单不存在或未发布");
        }
        // 2. Schema 缓存命中直接返回
        String cacheKey = "form:schema:" + form.getId();
        Object cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return FormSchemaVO.of(form, String.valueOf(cached));
        }
        // 3. 未命中：查库 + 回填缓存
        redisTemplate.opsForValue().set(cacheKey, form.getSchemaJson(), 24, TimeUnit.HOURS);
        return FormSchemaVO.of(form, form.getSchemaJson());
    }
}
```

### 3. 数据提交：后端权威校验 + 防重 + 落库

```java
@Service
public class FormSubmitService {

    @Autowired
    private FormDataMapper formDataMapper;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private ObjectMapper objectMapper;

    /**
     * 提交表单数据
     * 1. 校验表单已发布
     * 2. 按 Schema 校验规则逐字段校验（后端权威校验，防绕过前端）
     * 3. 防重：前端带防重 token（表单id+时间戳哈希），SETNX 幂等
     * 4. 落库：data_json 整体存储
     */
    @Transactional(rollbackFor = Exception.class)
    public Long submit(SubmitRequest req) {
        // 1. 表单存在且已发布
        FormDef form = formDefMapper.selectById(req.getFormId());
        if (form == null || form.getStatus() != 1) {
            throw new BizException("表单未发布");
        }

        // 2. 后端权威校验
        validateBySchema(form.getSchemaJson(), req.getData());

        // 3. 防重：token 幂等（同一 token 只能提交一次）
        String dedupKey = "form:submit:" + req.getFormId() + ":" + req.getDedupToken();
        Boolean first = redisTemplate.opsForValue()
                .setIfAbsent(dedupKey, "1", 24, TimeUnit.HOURS);
        if (!Boolean.TRUE.equals(first)) {
            throw new BizException("请勿重复提交");
        }

        // 4. 落库
        FormData data = new FormData();
        data.setFormId(req.getFormId());
        data.setDataJson(objectMapper.writeValueAsString(req.getData()));
        data.setSubmitIp(req.getSubmitIp());
        formDataMapper.insert(data);

        // 5. 计数
        redisTemplate.opsForValue().increment("form:counter:" + req.getFormId());
        return data.getId();
    }

    /** 按 Schema 规则校验数据 */
    private void validateBySchema(String schemaJson, Map<String, Object> data) {
        try {
            JsonNode root = objectMapper.readTree(schemaJson);
            for (JsonNode field : root.path("fields")) {
                String key = field.path("key").asText();
                String type = field.path("type").asText();
                boolean required = field.path("required").asBoolean(false);
                Object value = data.get(key);

                // 必填校验
                if (required && (value == null || String.valueOf(value).isEmpty())) {
                    throw new BizException("字段必填: " + field.path("label").asText());
                }
                if (value == null) continue;

                // 类型与规则校验
                JsonNode rules = field.path("rules");
                if (rules.isObject()) {
                    String val = String.valueOf(value);
                    if (rules.has("maxLength")
                            && val.length() > rules.path("maxLength").asInt()) {
                        throw new BizException(field.path("label").asText() + " 超长");
                    }
                    if (rules.has("pattern")
                            && !val.matches(rules.path("pattern").asText())) {
                        throw new BizException(field.path("label").asText() + " 格式不正确");
                    }
                    if (rules.has("min") && Double.parseDouble(val) < rules.path("min").asDouble()) {
                        throw new BizException(field.path("label").asText() + " 小于最小值");
                    }
                }
            }
        } catch (Exception e) {
            if (e instanceof BizException) throw (BizException) e;
            throw new BizException("数据校验失败: " + e.getMessage());
        }
    }
}
```

### 4. 数据导出 Excel（EasyExcel 流式）

```java
@Service
public class FormExportService {

    @Autowired
    private FormDataMapper formDataMapper;
    @Autowired
    private FormDefMapper formDefMapper;
    @Autowired
    private ObjectMapper objectMapper;

    /**
     * 导出表单数据为 Excel
     * 表头 = Schema 字段 label，行 = 提交数据
     * 大数据量用 EasyExcel 流式写（SXSSF 风格，内存友好）
     */
    public void export(Long formId, HttpServletResponse response) throws IOException {
        FormDef form = formDefMapper.selectById(formId);
        List<String> headers = extractHeaders(form.getSchemaJson());

        response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
        response.setCharacterEncoding("utf-8");
        String fileName = URLEncoder.encode(form.getFormName(), "UTF-8");
        response.setHeader("Content-Disposition", "attachment;filename=" + fileName + ".xlsx");

        // 流式写：每 1000 行刷一次，避免大表单 OOM
        ExcelWriter writer = EasyExcel.write(response.getOutputStream()).build();
        WriteSheet sheet = EasyExcel.writerSheet("数据").head(headers.stream()
                .map(h -> Collections.singletonList(h)).collect(Collectors.toList())).build();

        int page = 1, size = 1000;
        while (true) {
            List<FormData> rows = formDataMapper.selectPageByForm(formId, page, size);
            if (rows.isEmpty()) break;
            List<List<Object>> excelRows = rows.stream().map(d -> {
                try {
                    Map<String, Object> map = objectMapper.readValue(
                            d.getDataJson(), new TypeReference<Map<String, Object>>() {});
                    return headers.stream().map(map::get).collect(Collectors.toList());
                } catch (Exception e) {
                    return Collections.<Object>emptyList();
                }
            }).collect(Collectors.toList());
            writer.write(excelRows, sheet);
            page++;
        }
        writer.finish();
    }

    /** 从 Schema 提取表头（字段 label 列表） */
    private List<String> extractHeaders(String schemaJson) {
        try {
            JsonNode root = objectMapper.readTree(schemaJson);
            List<String> headers = new ArrayList<>();
            root.path("fields").forEach(f -> headers.add(f.path("label").asText()));
            return headers;
        } catch (Exception e) {
            return Collections.emptyList();
        }
    }
}
```

### 5. 数据统计：选项分布聚合

```java
@Service
public class FormStatService {

    @Autowired
    private FormDataMapper formDataMapper;
    @Autowired
    private ObjectMapper objectMapper;

    /**
     * 统计指定字段的选项分布（单选/多选/下拉）
     * 从所有提交数据的 JSON 中提取该字段值，按选项分组计数
     */
    public List<StatItem> statField(Long formId, String fieldKey) {
        List<FormData> all = formDataMapper.selectByForm(formId);
        Map<String, Integer> counter = new HashMap<>();
        for (FormData data : all) {
            try {
                Map<String, Object> map = objectMapper.readValue(
                        data.getDataJson(), new TypeReference<Map<String, Object>>() {});
                Object value = map.get(fieldKey);
                if (value == null) continue;
                // 多选（数组）逐个计数，单选（字符串）直接计数
                if (value instanceof List) {
                    ((List<?>) value).forEach(v ->
                            counter.merge(String.valueOf(v), 1, Integer::sum));
                } else {
                    counter.merge(String.valueOf(value), 1, Integer::sum);
                }
            } catch (Exception ignored) {
                // 单条脏数据跳过，不影响统计
            }
        }
        return counter.entrySet().stream()
                .map(e -> new StatItem(e.getKey(), e.getValue()))
                .sorted((a, b) -> b.getCount() - a.getCount())
                .collect(Collectors.toList());
    }
}
```

### 6. 模板套用：一键生成新表单

```java
@Service
public class FormTemplateService {

    @Autowired
    private FormTemplateMapper templateMapper;
    @Autowired
    private FormDefService formDefService;

    /**
     * 从模板创建表单：复制模板 Schema，生成新表单定义
     * 模板使用次数 +1
     */
    public Long createFromTemplate(Long templateId, String formName) {
        FormTemplate template = templateMapper.selectById(templateId);
        if (template == null) {
            throw new BizException("模板不存在");
        }
        FormDef form = new FormDef();
        form.setFormName(formName);
        form.setFormCode("f_" + System.currentTimeMillis());  // 唯一编码
        form.setSchemaJson(template.getSchemaJson());
        form.setTemplateFlag(0);
        Long formId = formDefService.saveForm(form);

        // 模板使用计数
        templateMapper.incrUseCount(templateId);
        return formId;
    }
}
```

## 实际应用场景

```text
1. 运营在表单引擎设计器拖入 5 个组件：姓名（必填）、手机号（正则校验）、公司（文本）、职位（下拉）、意向话题（多选）

3. 点击发布，自动生成填写链接，运营贴到公众号文章
4. 用户填写提交，前端即时校验手机号格式
5. 后端权威校验兜底，防绕过前端直接 POST
6. 活动结束后运营导出 Excel 名单，按意向话题统计饼图
7. 全程 10 分钟完成，无需研发介入
```

```text
1. HR 从「审批单」模板一键套用，微调字段
```


## 最佳实践与踩坑记录

### 最佳实践

1. 表单定义与数据分离存储：定义存 schema_json，数据存 data_json，永远不动态建表——这是低代码表单能「几分钟上线」的根本
2. Schema 校验前置：保存表单时校验字段 key 唯一、类型合法、联动引用存在，坏 Schema 进不了库
3. 校验双层：前端即时校验（体验）+ 后端按 Schema 权威校验（安全），后端校验规则从同一份 Schema 生成，杜绝两端不一致
4. 版本管理：每次编辑 version +1，发布状态置回草稿，避免「改了一半的 Schema 被线上使用」
5. 缓存一致性：发布时写缓存、编辑时删缓存，用 cache-aside 模式保证表单 Schema 即时生效
6. 防重提交：前端带 dedupToken + 后端 SETNX，防止连点/重试产生脏数据
7. 导出用流式：EasyExcel 分页拉取 + 流式写，几千条数据不 OOM
8. 联动逻辑只存不执行：后端存 JSON 表达式，前端执行，避免后端引入表达式引擎的安全风险

### 踩坑记录

```text
坑 1：动态建表导致 DDL 风暴
结论：每张新表单都动态建表，上线几百张表单后数据库表爆炸。
原因：最初设计是「表单 = 一张表」，忽略了表单数量增长。
解法：改为「表单定义表 + 提交数据表（data_json 列）」统一存储，查询走 JSON 提取或辅助索引列。

坑 2：坏 Schema 进了库
结论：前端拖了个非法组件，发布后填写页白屏。
原因：保存时没校验 Schema 合法性。
解法：保存接口做 Schema 校验（key 唯一/类型白名单/联动引用存在），非法直接拒绝。

坑 3：校验只做了前端
结论：绕过前端直接 POST 接口，提交了空数据。
原因：后端没做权威校验，信任了前端。
解法：后端按同一份 Schema 逐字段校验（必填/长度/正则/范围），前端校验只是体验层。

坑 4：改表单影响线上
结论：运营改了字段后线上表单渲染出错。
原因：编辑中的 Schema 直接覆盖已发布的 Schema。
解法：版本管理——编辑置草稿，重新发布才生效；线上渲染永远读已发布版本。

坑 5：重复提交
结论：用户连点提交按钮生成多条重复数据。
原因：没有防重机制。
解法：前端生成 dedupToken + 后端 SETNX 幂等；同一 token 只允许提交一次。

坑 6：导出大表单 OOM
结论：导出 5 万条数据内存溢出。
原因：一次性查出全部数据再写 Excel。
解法：EasyExcel 分页拉取 + 流式写，每 1000 条刷一次。

坑 7：JSON 数据列无法高效统计
结论：按选项分布统计要遍历全表，慢。
原因：data_json 无法走索引。
解法：高频统计字段提取为辅助索引列（提交时同步写入），低频统计接受全表扫描（数据量可控）。
```
