## 项目背景

招聘管理系统（Recruitment Management System）是人力资源数字化里最高频的一类业务系统，几乎每家中大型公司都要维护一条「职位发布 → 简历收集 → 简历筛选 → 面试评估 → Offer 发放 → 入职转化」的完整招聘流水线。选择它作为综合实战项目，是因为它把普通 CRUD 之外的三类硬核问题都覆盖了：文件解析（简历 PDF/Word 抽取）、状态机（面试流程和 Offer 生命周期）、匹配算法（候选人-职位匹配打分），非常适合用来检验「Spring Boot + 持久层 + 缓存 + 文件处理」这条技术线的综合能力。

业务痛点：

```text
1. 简历靠邮箱收：HR 每天在邮箱里翻几百封附件，命名混乱、格式不一，整理成本极高
2. 简历信息靠肉眼录入：姓名、电话、工作年限、技能要点全靠 HR 手工复制进 Excel，易错且耗时
3. 筛选靠人工翻简历：一个职位收 500 份简历，HR 逐份打开看，无关键词命中、无匹配度排序
4. 面试进度靠口头同步：面试官约完时间不通知 HR，候选人面完没人记录结果，流程断层
5. Offer 状态混乱：发了 Offer 不知道候选人是否接受，超期未确认无人跟进，口头 Offer 反悔频发
6. 人才池浪费：落选但不错的候选人简历直接丢弃，下次有合适职位又要重新找
```

目标用户与核心诉求：

```text
1. HR（招聘专员）：发布职位、收简历、筛选简历、安排面试、发 Offer，需要一套全流程可视化的操作台
2. 面试官：查看候选人简历与面试安排、填写面试评价，需要轻量、不被打断的评估入口
3. 候选人：投递简历、查看投递进度（筛选/面试/Offer 各阶段）、确认面试与 Offer，需要进度透明
4. 招聘负责人：看各职位漏斗数据（投递量/初筛率/面试通过率/Offer 接受率），指导招聘策略
```

项目要解决的核心问题一句话概括：把简历从「邮箱附件 + Excel 表格」变成「结构化数据 + 流程状态机」，让招聘全流程线上化、可追踪、可分析。

## 功能介绍

功能按角色拆成四个端：候选人门户（投递端）、HR 工作台（招聘端）、面试官工作台（评估端）、管理看板（数据端）。

```text
一、候选人门户（候选人视角）
1. 职位浏览 —— 按职位名称/城市/类型搜索职位，查看职位详情与要求
2. 在线投递 —— 上传简历文件（PDF/Word）或在线填写简历，投递指定职位
3. 投递进度 —— 查看投递状态流转：已投递/初筛中/面试中/已发 Offer/已淘汰
4. 面试确认 —— 收到面试邀约后确认或改期，查看面试官与面试形式
5. Offer 确认 —— 收到 Offer 后可接受或拒绝，附薪资福利详情

二、HR 工作台（招聘端）
1. 职位管理 —— 职位的增删改查、上下架、复制历史职位快速新建
2. 简历管理 —— 简历上传、自动解析、人工补充修正解析结果
3. 简历筛选 —— 按关键词/标签/期望薪资/工作年限过滤，匹配度打分排序
4. 面试安排 —— 邀约候选人、创建多轮面试（技术面/HR 面）、记录每轮结果
5. Offer 管理 —— 发起 Offer（含薪资结构）、跟踪接受/拒绝、超期提醒
6. 人才库 —— 淘汰候选人归档进人才库，按标签检索复用

三、面试官工作台（评估端）
1. 面试日历 —— 查看被分配的面试安排与候选人简历摘要
2. 面试评价 —— 打分（技术能力/沟通/潜力）+ 文字评价 + 通过/淘汰结论
3. 面评记录 —— 历史面评回看，供后续 Offer 决策参考

四、管理看板（招聘负责人视角）
1. 漏斗统计 —— 各职位投递量→初筛通过→面试→Offer→入职的转化率
2. 渠道分析 —— 各投递渠道（官网/招聘平台/内推）的简历量与转化
3. 面试通过率 —— 各面试官/各职位维度的通过率与平均耗时
```

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 开发框架 | Spring Boot 2.7/3.x | 生态成熟，起步快，社区资料多 |
| 持久层 | MyBatis-Plus | 单表 CRUD 零 SQL，复杂统计走 XML，兼顾效率与灵活 |
| 数据库 | MySQL 8.0 | 简历、职位、面试、Offer 等核心业务数据落库 |
| 缓存 | Redis | 投递去重锁、职位浏览计数、匹配结果缓存、流程状态缓存 |
| 文件存储 | 本地磁盘 / MinIO | 简历文件上传，小项目本地，生产用 MinIO 对象存储 |
| 简历解析 | Apache POI + PDFBox | POI 解析 Word/Excel，PDFBox 解析 PDF，提取简历文本 |
| 鉴权 | Spring Security + JWT | 无状态认证，前后端分离标配 |
| 定时任务 | Spring Task | Offer 超期提醒、简历解析重试、看板统计预计算 |
| 前端 | Vue 3 + Element Plus | 后台管理类系统的成熟组合 |
| 构建 | Maven | 依赖管理标准工具 |

选型说明：

```text
1. 简历解析选 POI + PDFBox 而非付费解析服务：基础版自建解析（抽文本+正则抽字段）够用，进阶再接 OCR/大模型
2. Redis 承担四件事：投递幂等锁（同一人同一职位只投一次）、职位浏览计数、匹配打分缓存、面试状态机临时态
3. 状态机用数据库字段 + Redis 缓存双写：数据库是事实源，Redis 加速状态查询与流转校验
4. 文件存储抽象成 StorageService 接口：本地磁盘实现上线即可用，后续换 MinIO/OSS 只改实现类
```

```text
│  └──────────┘ └──────────┘ └────────┘ └────────────────┘   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 简历解析模块（POI/PDFBox→文本→字段抽取→标签提取）        │  │
│  │ 匹配引擎（职位要求 vs 简历标签 → 打分）                 │  │
│  │ 流程状态机（投递→面试→Offer 状态流转校验）              │  │
│  └──────────────────────────────────────────────────────┘  │
└──────┬───────────────────┬───────────────────┬─────────────┘
       │                   │                   │

└─────────────┘   └─────────────────┘   └─────────────────┘
```

请求链路示例（候选人投递简历）：

```text
1. 前端 POST /api/delivery，multipart 上传简历文件 + 职位 id
2. Controller 调 DeliveryService.deliver(candidateId, positionId, file)
3. 先取 Redis 锁：SETNX delivery:lock:{candidateId}:{positionId}，防止重复投递
4. 文件落盘：StorageService 保存文件，返回文件 URL，记录文件类型与大小
5. 简历解析：异步线程用 PDFBox/POI 提取文本 → 正则抽姓名/电话/邮箱/年限 → 技能标签匹配
6. 解析结果写 resume 表，同时写入 Redis 缓存匹配打分结果
7. 投递记录 delivery 表插入 status=已投递，通知渠道/HR（站内信或消息）
8. 返回投递成功，候选人门户刷新进度
```

面试邀约链路（HR 安排面试）：

```text
1. HR 在投递详情页点「邀约面试」，填面试官、时间、形式（视频/现场）
2. Service 校验候选人与投递状态（必须处于「初筛通过」），不合法则拒绝
3. 创建 interview 记录，状态机流转：初筛通过 → 面试中
4. 通知面试官（站内信）与候选人（短信/邮件模板）
5. 候选人确认后，面试官工作台出现面试卡片；到点面试，面试官提交评价
6. 评价提交触发状态机：全部通过 → HR 面 / 任一淘汰 → 已淘汰并归档人才库
```

Redis Key 设计：

```text
delivery:lock:{candidateId}:{positionId}  String  投递幂等锁，SETNX + TTL 30s，防止重复投递
position:view:{positionId}                String  职位浏览计数器，INCR，定时批量刷库
delivery:match:{deliveryId}               String  匹配打分缓存，TTL 1 小时
delivery:status:{deliveryId}              String  投递状态缓存（读多写少），TTL 30 分钟
offer:expire:check                         String  定时任务分布式锁（SETNX），防止多实例重复扫描过期 Offer
talent:tag:{tagName}                       Set    人才库按标签索引的候选人 id 集合
candidate:recent:{candidateId}            List    候选人最近投递记录（最多 20 条）
```

## 核心实现

### 1. 简历文件上传与解析（POI + PDFBox）

```java
@Service
public class ResumeParserService {

    @Autowired
    private StorageService storageService;
    @Autowired
    private ResumeMapper resumeMapper;

    /**
     * 保存简历文件并异步解析
     * 解析流程：文件落盘 -> 提取纯文本 -> 正则抽字段 -> 技能标签匹配
     */
    public Long uploadAndParse(MultipartFile file, Long candidateId) {
        // 1. 校验文件类型，只允许 pdf/doc/docx
        String ext = StringUtils.substringAfterLast(file.getOriginalFilename(), ".");
        if (!Set.of("pdf", "doc", "docx").contains(ext.toLowerCase())) {
            throw new BusinessException("仅支持 pdf/doc/docx 格式简历");
        }
        // 2. 文件落盘（本地/MinIO），返回访问 URL
        String fileUrl = storageService.store(file);
        // 3. 建简历记录，状态置为待解析
        Resume resume = new Resume();
        resume.setCandidateId(candidateId);
        resume.setFileUrl(fileUrl);
        resume.setFileName(file.getOriginalFilename());
        resume.setFileType(ext);
        resume.setStatus(0);
        resumeMapper.insert(resume);
        // 4. 异步解析（生产环境可丢 MQ，这里用线程池）
        CompletableFuture.runAsync(() -> parse(resume.getId(), file));
        return resume.getId();
    }

    /**
     * 解析：提取文本 -> 抽取字段 -> 更新简历表
     */
    public void parse(Long resumeId, MultipartFile file) {
        try {
            String text = extractText(file);
            Resume r = new Resume();
            r.setId(resumeId);
            r.setContentText(text);
            r.setName(RegexUtil.matchFirst(text, "(姓名|Name)[:：]\\s*(\\S+)", 2));
            r.setPhone(RegexUtil.matchFirst(text, "1[3-9]\\d{9}", 0));
            r.setEmail(RegexUtil.matchFirst(text, "[\\w.+-]+@[\\w-]+\\.[\\w.]+", 0));
            r.setWorkYears(RegexUtil.matchInt(text, "(\\d+)\\s*年(以上)?(工作)?经验", 1));
            r.setEduLevel(detectEdu(text));
            r.setTags(detectTags(text)); // 技能词表匹配
            r.setStatus(1);
            resumeMapper.updateById(r);
        } catch (Exception e) {
            // 解析失败置为待人工，HR 在后台手工补录
            Resume r = new Resume();
            r.setId(resumeId);
            r.setStatus(2);
            resumeMapper.updateById(r);
            log.error("简历解析失败, resumeId={}", resumeId, e);
        }
    }

    /** 按扩展名选择解析器：PDF 用 PDFBox，Word 用 POI */
    private String extractText(MultipartFile file) throws Exception {
        String ext = StringUtils.substringAfterLast(file.getOriginalFilename(), ".");
        if ("pdf".equalsIgnoreCase(ext)) {
            try (PDDocument doc = PDDocument.load(file.getInputStream())) {
                PDFTextStripper stripper = new PDFTextStripper();
                return stripper.getText(doc);
            }
        }
        // doc/docx 用 POI 解析（docx 用 XWPFWordExtractor，doc 用 HWPFDocument）
        try (InputStream in = file.getInputStream()) {
            if ("docx".equalsIgnoreCase(ext)) {
                try (XWPFDocument doc = new XWPFDocument(in)) {
                    return new XWPFWordExtractor(doc).getText();
                }
            }
            try (HWPFDocument doc = new HWPFDocument(in)) {
                return new WordExtractor(doc).getText();
            }
        }
    }
}
```

### 2. 简历投递：幂等锁 + 匹配打分

```java
@Service
public class DeliveryService {

    private static final String LOCK_PREFIX = "delivery:lock:";

    @Autowired
    private DeliveryMapper deliveryMapper;
    @Autowired
    private ResumeMapper resumeMapper;
    @Autowired
    private PositionMapper positionMapper;
    @Autowired
    private MatchEngine matchEngine;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 投递：SETNX 幂等锁防重复投递（同一候选人同一职位只投一次）
     * 数据库唯一索引 uk_candidate_position 兜底
     */
    public Long deliver(Long candidateId, Long positionId, Long resumeId, Integer channel) {
        // 1. 加投递锁，防止并发双击重复提交
        String lockKey = LOCK_PREFIX + candidateId + ":" + positionId;
        Boolean locked = redis.opsForValue().setIfAbsent(lockKey, "1", 30, TimeUnit.SECONDS);
        if (!Boolean.TRUE.equals(locked)) {
            throw new BusinessException("请勿重复投递");
        }
        try {
            // 2. 校验职位在招聘中
            Position position = positionMapper.selectById(positionId);
            if (position == null || position.getStatus() != 1) {
                throw new BusinessException("职位不存在或已关闭");
            }
            // 3. 校验是否已投递过（数据库唯一索引也会兜底）
            Long count = deliveryMapper.selectCount(new LambdaQueryWrapper<Delivery>()
                    .eq(Delivery::getCandidateId, candidateId)
                    .eq(Delivery::getPositionId, positionId));
            if (count > 0) {
                throw new BusinessException("已投递过该职位");
            }
            // 4. 计算候选人-职位匹配度（简历标签 vs 职位要求）
            Resume resume = resumeMapper.selectById(resumeId);
            int score = matchEngine.score(resume, position);
            // 5. 插入投递记录，状态=已投递
            Delivery delivery = new Delivery();
            delivery.setCandidateId(candidateId);
            delivery.setPositionId(positionId);
            delivery.setResumeId(resumeId);
            delivery.setChannel(channel == null ? 1 : channel);
            delivery.setStatus(0);
            delivery.setMatchScore(score);
            deliveryMapper.insert(delivery);
            // 6. 匹配结果写缓存，供筛选页秒开
            redis.opsForValue().set("delivery:match:" + delivery.getId(),
                    String.valueOf(score), 1, TimeUnit.HOURS);
            return delivery.getId();
        } finally {
            redis.delete(lockKey);
        }
    }

    /**
     * 简历筛选：关键词 + 标签 + 匹配度排序
     * content_text LIKE 命中关键词，tags 命中标签，match_score 排序
     */
    public PageResult<DeliveryVO> screen(Long positionId, String keyword,
                                         String tag, int page, int size) {
        LambdaQueryWrapper<Delivery> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Delivery::getPositionId, positionId);
        if (StringUtils.hasText(keyword)) {
            wrapper.apply("EXISTS (SELECT 1 FROM resume r WHERE r.id = delivery.resume_id "
                    + "AND (r.content_text LIKE {0} OR r.name LIKE {0}))", "%" + keyword + "%");
        }
        if (StringUtils.hasText(tag)) {
            wrapper.apply("EXISTS (SELECT 1 FROM resume r WHERE r.id = delivery.resume_id "
                    + "AND FIND_IN_SET({0}, r.tags))", tag);
        }
        wrapper.orderByDesc(Delivery::getMatchScore).orderByAsc(Delivery::getCreateTime);
        Page<Delivery> pageInfo = deliveryMapper.selectPage(
                new Page<>(page, size), wrapper);
        // 组装 VO：补充候选人姓名、简历摘要、职位信息
        return buildPageResult(pageInfo);
    }
}
```

### 3. 候选人-职位匹配引擎

```java
@Component
public class MatchEngine {

    /**
     * 匹配打分：职位要求关键词 vs 简历标签/文本
     * 规则：命中 1 个核心技能 +15 分，命中 1 个普通技能 +8 分，
     * 工作年限满足 +20 分，学历达标 +10 分，满分 100 封顶
     */
    public int score(Resume resume, Position position) {
        int score = 0;
        // 1. 技能匹配：职位 requirements 里的关键词逐个比对简历 tags
        String[] reqs = position.getRequirements().split("[,，]");
        List<String> resumeTags = Arrays.asList(
                StringUtils.defaultString(resume.getTags()).split("[,，]"));
        for (String req : reqs) {
            String key = req.trim();
            if (key.isEmpty()) {
                continue;
            }
            boolean hit = resumeTags.contains(key)
                    || StringUtils.containsIgnoreCase(resume.getContentText(), key);
            score += isCoreSkill(key) ? 15 : 8;
            if (score >= 100) {
                return 100;
            }
        }
        // 2. 年限匹配：职位要求如「3-5年」，简历年限落在此区间 +20
        if (resume.getWorkYears() != null && resume.getWorkYears() >= 3) {
            score += 20;
        }
        // 3. 学历匹配：本科及以上 +10
        if (isBachelorOrAbove(resume.getEduLevel())) {
            score += 10;
        }
        return Math.min(score, 100);
    }

    /** 核心技能词表：命中这些词权重更高 */
    private boolean isCoreSkill(String keyword) {
        return Set.of("Java", "Spring", "MySQL", "Redis", "分布式",
                "微服务", "高并发", "架构", "Kafka", "ES").contains(keyword);
    }
}
```

### 4. 面试流程状态机

```java
@Service
public class InterviewService {

    @Autowired
    private InterviewMapper interviewMapper;
    @Autowired
    private DeliveryMapper deliveryMapper;

    /**
     * 面试流程状态机：投递状态与面试轮次联动
     * 状态流转（非法流转直接抛异常）：
     * 已投递(0) -> 初筛中(1) -> 初筛通过(2) -> 面试中(3) -> 已发Offer(4) -> 已入职(5)
     * 任意节点可到已淘汰(6)，候选人可主动放弃(7)
     */
    private static final Map<Integer, Set<Integer>> ALLOWED_TRANSITIONS = Map.of(
            0, Set.of(1, 6),
            1, Set.of(2, 6),
            2, Set.of(3, 6),
            3, Set.of(4, 6),
            4, Set.of(5, 6)
    );

    /** 创建面试邀约：投递状态必须是「初筛通过」 */
    public Long createInterview(Interview interview) {
        Delivery delivery = deliveryMapper.selectById(interview.getDeliveryId());
        if (delivery == null || delivery.getStatus() != 2) {
            throw new BusinessException("候选人当前状态不可安排面试");
        }
        interview.setStatus(0); // 待候选人确认
        interviewMapper.insert(interview);
        // 投递状态推进到「面试中」
        transition(delivery, 3);
        // 生产环境：发站内信/短信通知面试官与候选人
        return interview.getId();
    }

    /** 面试官提交评价，触发后续流转 */
    public void submitEvaluation(Long interviewId, Integer result, String comment,
                                 Integer scoreTech, Integer scoreComm, Integer scorePotential) {
        Interview interview = interviewMapper.selectById(interviewId);
        if (interview == null || interview.getStatus() != 1) {
            throw new BusinessException("面试尚未确认，不能提交评价");
        }
        // 更新面试结果
        Interview update = new Interview();
        update.setId(interviewId);
        update.setResult(result);
        update.setComment(comment);
        update.setScoreTech(scoreTech);
        update.setScoreComm(scoreComm);
        update.setScorePotential(scorePotential);
        update.setStatus(2);
        interviewMapper.updateById(update);

        Delivery delivery = deliveryMapper.selectById(interview.getDeliveryId());
        if (result == 2) {
            // 淘汰：投递状态 -> 已淘汰，简历归档人才库
            transition(delivery, 6);
            talentPoolService.archive(delivery.getCandidateId());
        } else if (result == 1) {
            // 通过：判断是否还有下一轮（技术面 -> 二面 -> HR面）
            if (interview.getRound() >= 3) {
                transition(delivery, 4); // 最后一轮通过，进入发 Offer 阶段
            }
            // 中间轮次通过：保持「面试中」，HR 安排下一轮
        }
    }

    /** 状态机核心：校验流转合法性并更新 */
    private void transition(Delivery delivery, int targetStatus) {
        Set<Integer> allowed = ALLOWED_TRANSITIONS.get(delivery.getStatus());
        if (allowed == null || !allowed.contains(targetStatus)) {
            throw new BusinessException("非法的状态流转: "
                    + delivery.getStatus() + " -> " + targetStatus);
        }
        Delivery update = new Delivery();
        update.setId(delivery.getId());
        update.setStatus(targetStatus);
        deliveryMapper.updateById(update);
    }
}
```

```java
@Service
public class OfferService {

    @Autowired
    private OfferMapper offerMapper;
    @Autowired
    private DeliveryMapper deliveryMapper;

    /**
     * 发放 Offer：投递状态必须是「面试中」且最后一轮已通过
     * Offer 有确认截止时间，超期自动置为已过期（定时任务扫描）
     */
    public Long issueOffer(Offer offer) {
        Delivery delivery = deliveryMapper.selectById(offer.getDeliveryId());
        if (delivery == null || delivery.getStatus() != 3) {
            throw new BusinessException("候选人未完成全部面试，不能发 Offer");
        }
        Long exist = offerMapper.selectCount(new LambdaQueryWrapper<Offer>()
                .eq(Offer::getDeliveryId, offer.getDeliveryId()));
        if (exist > 0) {
            throw new BusinessException("该投递已发放过 Offer");
        }
        offer.setStatus(0);
        offer.setExpireTime(LocalDateTime.now().plusDays(3)); // 默认 3 天确认期
        offerMapper.insert(offer);
        // 投递状态推进到「已发Offer」
        Delivery update = new Delivery();
        update.setId(delivery.getId());
        update.setStatus(4);
        deliveryMapper.updateById(update);
        return offer.getId();
    }

    /** 候选人接受 Offer */
    public void accept(Long offerId, Long candidateId) {
        Offer offer = getValidOffer(offerId, candidateId);
        if (offer.getStatus() != 0) {
            throw new BusinessException("Offer 当前状态不可接受");
        }
        if (offer.getExpireTime().isBefore(LocalDateTime.now())) {
            throw new BusinessException("Offer 已过期，请联系 HR");
        }
        offer.setStatus(1);
        offerMapper.updateById(offer);
        // 投递状态 -> 已入职（入职日期以 Offer 为准）
        Delivery update = new Delivery();
        update.setId(offer.getDeliveryId());
        update.setStatus(5);
        deliveryMapper.updateById(update);
    }

    /** 候选人拒绝 Offer：可选原因，简历回人才库 */
    public void reject(Long offerId, Long candidateId, String reason) {
        Offer offer = getValidOffer(offerId, candidateId);
        offer.setStatus(2);
        offer.setRemark(reason);
        offerMapper.updateById(offer);
        Delivery update = new Delivery();
        update.setId(offer.getDeliveryId());
        update.setStatus(7); // 候选人放弃
        deliveryMapper.updateById(update);
    }

    /** 定时任务：扫描超期未确认的 Offer，置为已过期并提醒 HR */
    @Scheduled(cron = "0 0/30 * * * ?")
    public void expireCheck() {
        List<Offer> expired = offerMapper.selectList(new LambdaQueryWrapper<Offer>()
                .eq(Offer::getStatus, 0)
                .lt(Offer::getExpireTime, LocalDateTime.now()));
        for (Offer offer : expired) {
            offer.setStatus(3);
            offerMapper.updateById(offer);
            log.info("Offer 超期自动过期, offerId={}", offer.getId());
        }
    }
}
```

### 6. 人才库：标签索引与复用

```java
@Service
public class TalentPoolService {

    private static final String TAG_SET_PREFIX = "talent:tag:";

    @Autowired
    private CandidateTagMapper candidateTagMapper;
    @Autowired
    private TagMapper tagMapper;
    @Autowired
    private ResumeMapper resumeMapper;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 淘汰候选人归档人才库：把简历标签写入人才库索引
     * 双重存储：MySQL 关联表（事实源）+ Redis Set（检索加速）
     */
    public void archive(Long candidateId) {
        Resume resume = resumeMapper.selectOne(new LambdaQueryWrapper<Resume>()
                .eq(Resume::getCandidateId, candidateId)
                .orderByDesc(Resume::getId).last("LIMIT 1"));
        if (resume == null || StringUtils.isBlank(resume.getTags())) {
            return;
        }
        for (String tagName : resume.getTags().split("[,，]")) {
            String name = tagName.trim();
            if (name.isEmpty()) {
                continue;
            }
            // 1. 标签入库（存在则复用）
            Tag tag = tagMapper.selectOne(new LambdaQueryWrapper<Tag>()
                    .eq(Tag::getName, name));
            if (tag == null) {
                tag = new Tag();
                tag.setName(name);
                tagMapper.insert(tag);
            }
            // 2. 建立候选人-标签关联（先删后插，保证幂等）
            candidateTagMapper.delete(new LambdaQueryWrapper<CandidateTag>()
                    .eq(CandidateTag::getCandidateId, candidateId)
                    .eq(CandidateTag::getTagId, tag.getId()));
            CandidateTag ct = new CandidateTag();
            ct.setCandidateId(candidateId);
            ct.setTagId(tag.getId());
            candidateTagMapper.insert(ct);
            // 3. 同步 Redis Set，供人才库标签筛选秒查
            redis.opsForSet().add(TAG_SET_PREFIX + name, String.valueOf(candidateId));
        }
    }

    /**
     * 人才库检索：按标签交集/并集查候选人
     * 先查 Redis Set 交集得到候选 id，再回 MySQL 查详情
     */
    public List<CandidateVO> searchByTags(List<String> tags) {
        if (tags.isEmpty()) {
            return Collections.emptyList();
        }
        // Redis Set 交集：要求候选人同时具备多个标签
        String[] keys = tags.stream().map(t -> TAG_SET_PREFIX + t).toArray(String[]::new);
        Set<String> candidateIds = redis.opsForSet().intersect(Arrays.asList(keys));
        if (candidateIds == null || candidateIds.isEmpty()) {
            return Collections.emptyList();
        }
        return candidateIds.stream()
                .map(Long::valueOf)
                .map(id -> resumeMapper.selectOne(new LambdaQueryWrapper<Resume>()
                        .eq(Resume::getCandidateId, id).orderByDesc(Resume::getId)
                        .last("LIMIT 1")))
                .filter(Objects::nonNull)
                .map(this::toCandidateVO)
                .toList();
    }
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 投递幂等双保险：Redis SETNX 锁挡住并发双击，数据库唯一索引（candidate_id + position_id）兜底，两者缺一不可
2. 简历解析必须异步：PDFBox/POI 解析一个 2MB PDF 要几百毫秒，放同步链路会拖垮上传接口，用线程池或 MQ 解耦，失败进「待人工」队列
3. 状态机只允许显式流转：把「允许的状态转移表」写成常量 Map，流转前校验，杜绝跳过环节（如没面试就发 Offer）
4. 简历文本只存解析结果不存原文件内容进 MySQL：content_text 用 MEDIUMTEXT，列表查询绝不 SELECT 该字段，详情页才取
5. 匹配打分规则收敛在 MatchEngine 一个类里：打分权重可配置（技能命中/年限/学历），调整规则不散落各处
6. 淘汰不等于流失：所有淘汰候选人都走 archive() 归档人才库，标签入 MySQL 关联表 + Redis Set 双写
7. 定时任务加分布式锁：Offer 超期扫描等任务用 SETNX 抢锁，多实例部署时保证只有一个实例执行

### 踩坑记录

```text
坑 1：候选人重复投递同一个职位
结论：同一候选人同职位出现多条投递记录。
原因：前端双击 + 网络重试，后端没做幂等，唯一索引缺失。
解法：加 Redis SETNX 锁 + 数据库唯一索引 uk_candidate_position 双保险；锁的 TTL 要大于业务执行时间。

坑 2：简历解析后电话号码乱码/丢失
结论：PDF 里明明是 13 位手机号，解析出来是乱码。
原因：PDF 嵌入字体无 ToUnicode 映射，PDFBox 提取的文本是乱码；部分简历是扫描件（图片 PDF）。
解法：无字库的 PDF 用 OCR 兜底（Tesseract）；扫描件提示 HR 人工补录；解析失败状态置 2 而不是静默成功。

坑 3：面试评价提交后投递状态错乱
结论：一轮面试通过后候选人状态直接跳到「已发Offer」。
原因：评价提交逻辑里没判断轮次，所有通过都推进到发 Offer 阶段。
解法：轮次与下一环节映射表（技术面->二面、HR面->发Offer），按 round 判断推进目标。

坑 4：Offer 确认超期后仍能接受
结论：超过截止时间的 Offer 还能被候选人点接受。
原因：接受接口只校验了 status=0，没校验 expire_time。
解法：accept() 里双重校验 status + expire_time；定时任务把超期 Offer 置为已过期，双保险。

坑 5：简历文件重名互相覆盖
结论：两个候选人上传同名的「简历.pdf」，后上传的覆盖了先上传的。
原因：文件直接以原始文件名落盘。
解法：存储路径用 UUID/时间戳重命名，原始文件名只存数据库 file_name 字段；目录按日期分桶（uploads/2026/08/）。

坑 6：关键词筛选 LIKE 命中率过低
结论：搜「Java」筛不出写「java/Java8/JAVA」的简历。
原因：LIKE 大小写与分词问题，中文简历文本没做统一规范化。
解法：解析时对文本统一 lowerCase 并去空白；关键词匹配用 tags 字段（结构化）优先，content_text 全文兜底。

坑 7：人才库标签越积越多
结论：人才库有几百个近义标签（Java、JAVA、java 各一个）。
原因：标签写入前没做归一化，也没复用已有标签。
解法：写入前统一 trim + toLowerCase；先查重再插入（存在即复用）；定时任务合并近义标签。
```
