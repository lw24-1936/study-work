## 概述

综合项目实战是从入门到进阶的 9 个项目，覆盖 Java 全栈开发的所有技术栈，是检验学习成果的最佳方式。

```text
项目进阶路线：
项目一（基础）→ 项目二（Web）→ 项目三（Spring Boot）
→ 项目四（前后端分离）→ 项目五（消息队列）
→ 项目六（微服务）→ 项目七（高并发）
→ 项目八（数据平台）→ 项目九（AI 应用）
```

```text
学习建议：
1. 按顺序完成（难度递进）
2. 每个项目独立可运行
3. 完成后整理技术总结
4. 项目可作为简历亮点
```

### 核心实现

@Service
public class EmployeeService {

    @Autowired
    private EmployeeMapper employeeMapper;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 带缓存查询
    public Employee getById(Long id) {
        String key = "employee:" + id;
        Employee emp = (Employee) redisTemplate.opsForValue().get(key);
        if (emp != null) return emp;

        emp = employeeMapper.selectById(id);
        if (emp != null) {
            redisTemplate.opsForValue().set(key, emp, 1, TimeUnit.HOURS);
        }
        return emp;
    }
}
```

// 订单服务调用用户服务（Feign）

    @GetMapping("/api/users/{id}")
    User getUser(@PathVariable Long id);

    @Autowired
    private UserClient userClient;

### 技术要点

```

### 核心实现（详见 170-秒杀系统）

```java
public Result seckill(Long userId, Long goodsId) {
    // 1. 限流
    if (!limiter.tryAcquire()) return Result.error("系统繁忙");

    // 2. 限购（幂等）
    Boolean first = redisTemplate.opsForValue()
        .setIfAbsent("seckill:user:" + userId, "1", 24, TimeUnit.HOURS);
    if (!Boolean.TRUE.equals(first)) return Result.error("每人限购一件");

    // 3. Redis 原子扣库存（防超卖）
    Long stock = redisTemplate.opsForValue().decrement("stock:" + goodsId);
    if (stock < 0) {
        redisTemplate.opsForValue().increment("stock:" + goodsId);
        return Result.error("已售罄");
    }

    // 4. MQ 异步下单
    mqProducer.send(new SecKillMessage(userId, goodsId));
    return Result.success("秒杀成功");
}
```

// RAG 问答
public String ragAnswer(String question) {
    // 1. 向量检索
    List<Document> docs = vectorStore.similaritySearch(
        SearchRequest.query(question).withTopK(3));

    // 2. 拼接上下文
    String context = docs.stream()
        .map(Document::getContent)
        .collect(Collectors.joining("\n"));

    // 3. LLM 生成
    return chatClient.prompt()
        .system("根据资料回答：\n" + context)
        .user(question)
        .call()
        .content();
}
