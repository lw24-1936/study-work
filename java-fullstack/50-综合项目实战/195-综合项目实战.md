## 概述

综合项目实战是从入门到进阶的 29 个项目，覆盖 Java 全栈开发的所有技术栈，是检验学习成果的最佳方式。前 9 个是进阶路线核心项目（从 Java SE 到 AI 应用），后 20 个是独立可落地的企业级项目（每个项目单独成文，含完整项目背景、功能设计、数据库设计、核心代码与真实应用场景），可直接作为简历项目。

```text
项目进阶路线（前 9 个，难度递进）：
项目一（基础）→ 项目二（Web）→ 项目三（Spring Boot）
→ 项目四（前后端分离）→ 项目五（消息队列）
→ 项目六（微服务）→ 项目七（高并发）
→ 项目八（数据平台）→ 项目九（AI 应用）
```


### 核心实现

```java
@Service
public class EmployeeService {

    @Autowired
    private EmployeeMapper employeeMapper;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    // 带缓存查询
    public Employee getById(Long id) {
        String key = "employee:" + id;
        Employee emp = (Employee) redisTemplate.opsForValue().get(key);
        if (emp != null) return emp;

        emp = employeeMapper.selectById(id);
        if (emp != null) {
            redisTemplate.opsForValue().set(key, emp, 1, TimeUnit.HOURS);
        }
        return emp;
    }
}
```

### 核心实现

```java
// 订单服务调用用户服务（Feign）
@FeignClient(name = "user-service")
public interface UserClient {
    @GetMapping("/api/users/{id}")
    User getUser(@PathVariable Long id);
}

// 订单服务调用
@Service
public class OrderService {
    @Autowired
    private UserClient userClient;

    public Order getOrderDetail(Long orderId) {
        Order order = orderMapper.selectById(orderId);
        order.setUser(userClient.getUser(order.getUserId()));   // Feign 调用
        return order;
    }
}
```

```java
// RAG 问答
public String ragAnswer(String question) {
    // 1. 向量检索
    List<Document> docs = vectorStore.similaritySearch(
        SearchRequest.query(question).withTopK(3));

    // 2. 拼接上下文
    String context = docs.stream()
        .map(Document::getContent)
        .collect(Collectors.joining("\n"));

    // 3. LLM 生成
    return chatClient.prompt()
        .system("根据资料回答：\n" + context)
        .user(question)
        .call()
        .content();
}
```
