## 项目背景

停车场管理系统（Parking Management System）是城市静态交通数字化里最贴近日常的基础设施系统，从商业综合体停车场、医院停车场到小区地下车库，都依赖它完成「入场识别 → 场内管理 → 出场计费 → 道闸放行」的闭环。选择它作为综合实战项目，是因为它把两类真实业务的硬核问题都覆盖了：计费规则引擎（免费时长、阶梯费率、封顶金额的组合计算）和并发一致性（同一辆车在出口闸机反复触发识别，必须保证只结算一次）。规模小但并发真实，非常适合实战演练。

业务痛点：

```text
1. 人工收费效率低：出口岗亭一车一停一算，高峰期排队十分钟起步，车主体验差
2. 计费规则混乱：免费时长、夜间半价、阶梯费率、单日封顶，规则复杂算错账，纠纷不断
3. 重复计费风险：出口摄像头多次触发识别，同一辆车被扣两次费，客诉与退款压力大
4. 场内车辆不明：停车场有多少车、哪个车位空着、有车长期滞留，运营者一无所知
5. 月卡管理粗放：包月车辆手工登记，续费靠提醒，过期车照样放行，收入流失
6. 收入对不上账：现金、扫码、月卡混合收费，收费记录与道闸放行记录对不上
```

目标用户与核心诉求：

```text
1. 车主：快速进出场、按实际时长准确计费、支持多种支付方式（扫码/月卡/现金）
2. 停车场管理员：实时查看场内车辆与空余车位、处理异常车辆、核对收费记录
3. 停车场经营者：制定与调整计费规则、查看收入统计与车流分析、管理月卡客户
```

项目要解决的核心问题一句话概括：让每一辆车「进场有记录、场内可查询、出场算得准、放行不重复」，收费账目清晰可追溯。

## 功能介绍

功能按角色拆成三个端：车主端（小程序/扫码）、岗亭端（现场收费）、管理后台（运营管理）。

```text
一、车主端（车主视角）
1. 车牌绑定 —— 小程序绑定车牌，与微信/支付宝支付账户关联
2. 在线缴费 —— 出场前扫码预付，无感支付免排队
3. 月卡购买 —— 在线购买/续费月卡，支持多种套餐（月卡/季卡/年卡）
4. 停车记录 —— 查看自己的进出场记录与缴费明细
5. 车位查询 —— 查看场内剩余车位数（大屏/小程序）

二、岗亭端（现场收费视角）
1. 车辆入场 —— 摄像头拍照自动识别车牌，识别失败转手动录入
2. 车辆出场 —— 识别车牌计算费用，收费后手动开闸放行
3. 手动开闸 —— 应急开闸（设备故障/免费车辆），记录操作日志
4. 异常处理 —— 无入场记录车辆、识别错误车牌修正、超时未出场核对
5. 月卡核验 —— 月卡车辆自动放行，过期月卡现场提示续费

三、管理后台（经营者视角）
1. 车位管理 —— 车位编号/类型（普通/新能源/无障碍）/状态维护
2. 计费规则 —— 免费时长、时段费率、阶梯费率、封顶金额的可视化配置
3. 月卡管理 —— 月卡开通、续费、退费，到期提醒与批量处理
4. 场内车辆 —— 实时场内车辆列表、长停车辆（超 24 小时）预警
5. 道闸联动 —— 入场/出场道闸状态监控，手动放行记录
6. 收入统计 —— 按日/月/规则维度统计收入，支付方式占比、免费放行统计
```

## 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 开发框架 | Spring Boot 2.7/3.x | 生态成熟，起步快，社区资料多 |
| 持久层 | MyBatis-Plus | 单表 CRUD 零 SQL，复杂统计走 XML |
| 数据库 | MySQL 8.0 | 车辆、车位、进出场记录、月卡等业务数据落库 |
| 缓存 | Redis | 入场快照、出场防重复结算锁、场内计数、月卡缓存 |
| 定时任务 | Spring Task | 超时未出场扫描、月卡到期提醒、收入日汇总 |
| 车牌识别 | 第三方 OCR（如百度/腾讯车牌识别 API） | 摄像头抓拍图片识别车牌，识别失败降级手动录入 |
| 道闸联动 | HTTP 接口对接道闸控制器 | 道闸厂商提供开闸/关闸/状态查询接口 |
| 支付 | 微信/支付宝支付 API（沙箱） | 出场缴费与月卡购买 |
| 鉴权 | Spring Security + JWT | 管理端与岗亭端认证 |
| 前端 | Vue 3 + Element Plus | 后台管理类系统的成熟组合 |
| 构建 | Maven | 依赖管理标准工具 |

选型说明：

```text
1. 车牌识别不自己训练模型：接入成熟 OCR API，识别置信度低时降级为人工录入，业务可用性优先
2. Redis 承担四件事：入场记录快照（秒级查询）、出场防重复结算锁、场内车辆计数、月卡缓存
3. 计费引擎做成独立组件：规则参数化（免费时长/费率阶梯/封顶），改规则只改配置不改代码
4. 道闸联动走接口抽象：闸机厂商千差万别，统一 GateService 接口，对接不同厂商只换实现类
5. 出场结算幂等是核心：用 Redis 分布式锁 + MySQL 状态机双重保障「一次出场只计一次费」
```

请求链路示例（车辆入场）：

```text
1. 入口摄像头抓拍，调车牌识别 API 得到车牌号「京A12345」，置信度 0.98
2. 前端 POST /api/entry {plateNo, cameraId, imageUrl}
3. Service 校验车牌格式（正则：省份简称+字母+数字），格式非法拒绝
4. 校验该车是否已在场内（Redis 查 plate:entry:{plateNo}），在场则拒绝重复入场
5. 记录入场：MySQL 插入 entry_record（车牌/时间/入口/识别方式），Redis 写入入场快照
6. 场内车辆计数 INCR parking:count:total，道闸接口 GateService.openGate(entryGate)
7. 开闸成功返回放行，抓拍图存档；若道闸异常则告警并人工干预
```

出场结算链路（车辆出场计费）：

```text
1. 出口摄像头识别车牌「京A12345」，POST /api/exit/calculate {plateNo}
2. 查 Redis 入场快照 plate:entry:{plateNo}，无快照则查 MySQL 兜底，都无则报「无入场记录」
3. 加分布式锁 exit:lock:{plateNo}（SETNX），抢锁失败说明正在结算，直接返回「处理中」
4. 查月卡缓存/数据库：有有效月卡则免单，否则按计费引擎算费（免费时长->阶梯费率->封顶）
5. 生成应收金额返回岗亭/车主小程序；车主缴费成功后 POST /api/exit/confirm
6. 确认接口再次校验锁与状态机（结算中->已结算），事务内写 exit_record、更新车位状态
7. 道闸开闸放行，删除入场快照，场内计数 DECR；支付失败/超时释放锁，车辆可重新发起结算
```

Redis Key 设计：

```text
plate:entry:{plateNo}      String  入场快照（JSON：entryId/entryTime/entryGate），出场计算与防重复用
exit:lock:{plateNo}        String  出场结算分布式锁，SETNX + TTL 2 分钟，防并发重复计费
exit:status:{entryId}      String  结算状态缓存（0待支付 1已支付 2已放行），TTL 10 分钟
parking:count:total        String  场内车辆总数计数器（INCR/DECR），实时余位展示
parking:count:{type}       String  各类型车位占用计数（新能源/普通）
month:card:{plateNo}       String  月卡有效期缓存（endTime 时间戳），出场时免查库
month:card:lock:{plateNo}  String  月卡办理/续费锁，防并发重复开卡
task:lock:income           String  收入汇总定时任务分布式锁
```

## 核心实现

### 1. 车辆入场：OCR 识别 + 防重复入场

```java
@Service
public class EntryService {

    private static final String PLATE_ENTRY_PREFIX = "plate:entry:";
    private static final String PARKING_COUNT = "parking:count:total";

    @Autowired
    private EntryRecordMapper entryRecordMapper;
    @Autowired
    private PlateRecognizer plateRecognizer;
    @Autowired
    private GateService gateService;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 车辆入场：拍照识别 -> 校验 -> 落库 -> 开闸
     * 防重复入场：Redis 查该车牌是否已在场，在场拒绝
     */
    @Transactional
    public EntryVO entry(MultipartFile image, String plateNo, String gate, String camera) {
        // 1. 识别车牌：有图片走 OCR，无图片（手动录入）直接用传入车牌
        String recognized = plateNo;
        boolean auto = true;
        if (image != null && !image.isEmpty()) {
            recognized = plateRecognizer.recognize(image);
            if (recognized == null) {
                throw new BusinessException("车牌识别失败，请手动录入");
            }
        } else {
            auto = false;
        }
        // 2. 车牌格式校验（简化版正则：省份简称 + 字母数字）
        if (!recognized.matches("^[京津沪渝冀豫云辽黑湘皖鲁新苏浙赣鄂桂甘晋蒙陕吉闽贵粤青藏川宁琼使领][A-Z][A-Z0-9]{5,6}$")) {
            throw new BusinessException("车牌格式非法: " + recognized);
        }
        // 3. 防重复入场：查 Redis 快照，在场则拒绝
        String exist = redis.opsForValue().get(PLATE_ENTRY_PREFIX + recognized);
        if (exist != null) {
            throw new BusinessException("该车辆已在场内，请勿重复入场");
        }
        // 4. 落库入场记录
        EntryRecord record = new EntryRecord();
        record.setPlateNo(recognized);
        record.setEntryTime(LocalDateTime.now());
        record.setEntryGate(gate);
        record.setEntryCamera(camera);
        record.setRecognizeType(auto ? 1 : 2);
        record.setStatus(0); // 在场
        entryRecordMapper.insert(record);
        // 5. 写 Redis 入场快照（出场计费与防重复依赖）
        EntrySnapshot snapshot = new EntrySnapshot();
        snapshot.setEntryId(record.getId());
        snapshot.setPlateNo(recognized);
        snapshot.setEntryTime(record.getEntryTime());
        redis.opsForValue().set(PLATE_ENTRY_PREFIX + recognized,
                JSON.toJSONString(snapshot), 30, TimeUnit.DAYS);
        // 6. 场内计数 +1，并尝试分配车位（有车牌的车分配空闲车位）
        redis.opsForValue().increment(PARKING_COUNT);
        allocateSpace(recognized);
        // 7. 道闸放行（失败不影响入场记录，人工干预）
        boolean opened = gateService.openGate(gate);
        if (!opened) {
            log.warn("入场道闸开闸失败, gate={}, plate={}", gate, recognized);
        }
        EntryVO vo = new EntryVO();
        vo.setPlateNo(recognized);
        vo.setEntryTime(record.getEntryTime());
        vo.setGateOpened(opened);
        return vo;
    }
}
```

### 2. 计费规则引擎

```java
@Component
public class FeeRuleEngine {

    /**
     * 计费核心：免费时长 -> 阶梯费率 -> 单日封顶 -> 夜间优惠
     * 规则来自 fee_rule 表，引擎只依赖规则对象，规则可配置
     */
    public FeeResult calculate(FeeRule rule, LocalDateTime entryTime, LocalDateTime exitTime) {
        long minutes = Duration.between(entryTime, exitTime).toMinutes();
        if (minutes <= 0) {
            minutes = 1; // 最小计费 1 分钟
        }
        FeeResult result = new FeeResult();
        result.setDurationMin(minutes);

        // 1. 免费时长内免费（如 15 分钟内免费）
        if (minutes <= rule.getFreeMinutes()) {
            result.setAmount(BigDecimal.ZERO);
            result.setFeeType("免费时长内");
            return result;
        }
        // 2. 扣除免费时长后重新计算计费时长（按整小时向上取整）
        long billableMinutes = minutes - rule.getFreeMinutes();
        long hours = (billableMinutes + 59) / 60; // 向上取整到小时

        // 3. 阶梯费率：首小时费用 + 后续每小时费用
        BigDecimal amount;
        if (hours <= 1) {
            amount = rule.getFirstHourFee();
        } else {
            amount = rule.getFirstHourFee()
                    .add(rule.getPerHourFee()
                            .multiply(BigDecimal.valueOf(hours - 1)));
        }
        // 4. 夜间优惠：跨夜间时段的停车按整段夜间价计费（简化：22:00-06:00 按 nightFee）
        if (rule.getNightFee() != null && crossesNight(entryTime, exitTime, rule)) {
            amount = rule.getNightFee();
        }
        // 5. 单日封顶：超过 24 小时的，按「天数 x 日封顶 + 尾段费」算
        if (rule.getDayCap() != null && minutes > 24 * 60) {
            long days = minutes / (24 * 60);
            long tailMinutes = minutes % (24 * 60);
            BigDecimal tailFee = tailMinutes == 0 ? BigDecimal.ZERO
                    : calculateTail(rule, tailMinutes);
            amount = rule.getDayCap().multiply(BigDecimal.valueOf(days)).add(tailFee);
        }
        result.setAmount(amount);
        result.setFeeType("阶梯计费");
        return result;
    }

    /** 尾段（不足一天）费用：走同一套阶梯规则但不叠加日封顶 */
    private BigDecimal calculateTail(FeeRule rule, long minutes) {
        long hours = (minutes + 59) / 60;
        if (hours <= 1) {
            return rule.getFirstHourFee();
        }
        return rule.getFirstHourFee()
                .add(rule.getPerHourFee().multiply(BigDecimal.valueOf(hours - 1)));
    }

    /** 判断是否跨夜间时段（22:00-06:00） */
    private boolean crossesNight(LocalDateTime entry, LocalDateTime exit, FeeRule rule) {
        LocalTime nightStart = LocalTime.parse(rule.getNightStart());
        LocalTime nightEnd = LocalTime.parse(rule.getNightEnd());
        // 简化：入场在夜间时段内 或 出场在夜间时段内 即视为享受夜间优惠
        return (!entry.toLocalTime().isBefore(nightStart) || entry.toLocalTime().isBefore(nightEnd))
                && (exit.toLocalTime().isAfter(nightStart) || !exit.toLocalTime().isAfter(nightEnd));
    }
}
```

### 3. 出场结算：防重复计费（分布式锁 + 状态机）

```java
@Service
public class ExitService {

    private static final String EXIT_LOCK_PREFIX = "exit:lock:";
    private static final String PLATE_ENTRY_PREFIX = "plate:entry:";

    @Autowired
    private EntryRecordMapper entryRecordMapper;
    @Autowired
    private ExitRecordMapper exitRecordMapper;
    @Autowired
    private FeeRuleEngine feeRuleEngine;
    @Autowired
    private MonthlyCardService monthlyCardService;
    @Autowired
    private GateService gateService;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 出场结算：计算应收金额（幂等）
     * 防重复计费三道防线：
     * 1. Redis SETNX 分布式锁（2 分钟 TTL 自动释放）
     * 2. 入场记录状态机：只在「在场」时允许结算
     * 3. exit_record 唯一索引 uk_entry（同一入场记录只能有一条结算）
     */
    public ExitResult calculate(String plateNo) {
        // 1. 抢出场结算锁，抢不到说明正在结算中
        String lockKey = EXIT_LOCK_PREFIX + plateNo;
        Boolean locked = redis.opsForValue().setIfAbsent(lockKey, "1", 2, TimeUnit.MINUTES);
        if (!Boolean.TRUE.equals(locked)) {
            throw new BusinessException("该车辆正在结算中，请稍候");
        }
        try {
            // 2. 查入场记录（Redis 快照优先，MySQL 兜底）
            EntryRecord entry = findEntry(plateNo);
            if (entry == null) {
                throw new BusinessException("无入场记录，请核对车牌");
            }
            // 3. 状态机校验：只有「在场」才能结算
            if (entry.getStatus() != 0) {
                throw new BusinessException("该车辆已出场，请勿重复结算");
            }
            // 4. 已存在结算记录则直接返回（幂等）
            ExitRecord exist = exitRecordMapper.selectOne(new LambdaQueryWrapper<ExitRecord>()
                    .eq(ExitRecord::getEntryId, entry.getId()));
            if (exist != null) {
                return toResult(exist);
            }
            LocalDateTime exitTime = LocalDateTime.now();
            // 5. 月卡抵扣：有效月卡免单
            MonthlyCard card = monthlyCardService.getValidCard(plateNo);
            BigDecimal amount = BigDecimal.ZERO;
            int feeType = 2; // 月卡抵扣
            FeeRule rule = null;
            if (card == null) {
                // 6. 临停计费：取启用的规则（生产可支持按车场/时段选规则）
                rule = feeRuleMapper.selectOne(new LambdaQueryWrapper<FeeRule>()
                        .eq(FeeRule::getStatus, 1).last("LIMIT 1"));
                FeeResult fee = feeRuleEngine.calculate(rule, entry.getEntryTime(), exitTime);
                amount = fee.getAmount();
                feeType = 1;
            }
            // 7. 插入结算记录（状态=待支付），唯一索引 uk_entry 兜底并发
            ExitRecord record = new ExitRecord();
            record.setEntryId(entry.getId());
            record.setPlateNo(plateNo);
            record.setEntryTime(entry.getEntryTime());
            record.setExitTime(exitTime);
            record.setDurationMin((int) Duration.between(entry.getEntryTime(), exitTime).toMinutes());
            record.setFeeType(feeType);
            record.setRuleId(rule == null ? null : rule.getId());
            record.setTotalAmount(amount);
            record.setStatus(0);
            try {
                exitRecordMapper.insert(record);
            } catch (DuplicateKeyException e) {
                // 并发兜底：另一请求已插入，直接查回返回
                return toResult(exitRecordMapper.selectOne(new LambdaQueryWrapper<ExitRecord>()
                        .eq(ExitRecord::getEntryId, entry.getId())));
            }
            return toResult(record);
        } finally {
            // 支付完成后由 confirm 接口删除锁；这里保留锁防并发（TTL 兜底）
        }
    }

    /**
     * 支付完成确认出场：校验金额 -> 更新状态 -> 开闸放行
     * 状态机：0待支付 -> 1已支付 -> 2已放行
     */
    @Transactional
    public void confirmExit(Long exitId, BigDecimal paidAmount, Integer payType, String payNo) {
        ExitRecord record = exitRecordMapper.selectById(exitId);
        if (record == null || record.getStatus() != 0) {
            throw new BusinessException("结算记录不存在或已处理");
        }
        // 金额校验：实付必须等于应收（月卡/免费单为 0 也要走支付确认）
        if (paidAmount.compareTo(record.getTotalAmount()) != 0) {
            throw new BusinessException("支付金额与应收不符");
        }
        // 乐观锁更新：UPDATE ... WHERE status=0
        int rows = exitRecordMapper.casUpdatePaid(exitId, paidAmount, payType, payNo);
        if (rows == 0) {
            throw new BusinessException("结算已被处理，请勿重复支付");
        }
        // 状态机推进：已支付 -> 已放行
        ExitRecord update = new ExitRecord();
        update.setId(exitId);
        update.setStatus(2);
        exitRecordMapper.updateById(update);
        // 更新入场记录为已出场
        EntryRecord entryUpdate = new EntryRecord();
        entryUpdate.setId(record.getEntryId());
        entryUpdate.setStatus(1);
        entryUpdate.setExitTime(record.getExitTime());
        entryRecordMapper.updateById(entryUpdate);
        // 释放车位与场内计数
        releaseSpace(record.getPlateNo());
        redis.opsForValue().decrement(PARKING_COUNT);
        // 开闸放行
        gateService.openGate("exit-1");
        // 清理入场快照与结算锁
        redis.delete(PLATE_ENTRY_PREFIX + record.getPlateNo());
        redis.delete(EXIT_LOCK_PREFIX + record.getPlateNo());
    }
}
```

```java
@Service
public class MonthlyCardService {

    private static final String CARD_LOCK_PREFIX = "month:card:lock:";
    private static final String CARD_CACHE_PREFIX = "month:card:";

    @Autowired
    private MonthlyCardMapper monthlyCardMapper;
    @Autowired
    private StringRedisTemplate redis;

    /**
     * 办理/续费月卡：同一车牌同一时间只有一张有效卡
     * 续费 = 在原到期时间上顺延，而非从今天重新起算
     */
    @Transactional
    public Long createOrRenew(MonthlyCard card) {
        // 1. 加车牌锁，防并发重复开卡
        String lockKey = CARD_LOCK_PREFIX + card.getPlateNo();
        Boolean locked = redis.opsForValue().setIfAbsent(lockKey, "1", 10, TimeUnit.SECONDS);
        if (!Boolean.TRUE.equals(locked)) {
            throw new BusinessException("操作繁忙，请重试");
        }
        try {
            // 2. 查有效旧卡
            MonthlyCard exist = monthlyCardMapper.selectOne(new LambdaQueryWrapper<MonthlyCard>()
                    .eq(MonthlyCard::getPlateNo, card.getPlateNo())
                    .eq(MonthlyCard::getStatus, 1)
                    .orderByDesc(MonthlyCard::getEndTime).last("LIMIT 1"));
            LocalDateTime start = LocalDateTime.now();
            if (exist != null && exist.getEndTime().isAfter(start)) {
                // 续费：从旧卡到期时间顺延，避免「提前续费亏天数」
                start = exist.getEndTime();
            }
            // 3. 按卡类型计算到期时间
            LocalDateTime end = switch (card.getCardType()) {
                case 1 -> start.plusMonths(1);  // 月卡
                case 2 -> start.plusMonths(3);  // 季卡
                case 3 -> start.plusYears(1);   // 年卡
                default -> throw new BusinessException("卡类型非法");
            };
            card.setStartTime(start);
            card.setEndTime(end);
            card.setStatus(1);
            monthlyCardMapper.insert(card);
            // 4. 写 Redis 缓存，出场时免查库
            redis.opsForValue().set(CARD_CACHE_PREFIX + card.getPlateNo(),
                    String.valueOf(end.atZone(ZoneId.systemDefault()).toInstant().toEpochMilli()),
                    2, TimeUnit.DAYS);
            return card.getId();
        } finally {
            redis.delete(lockKey);
        }
    }

    /**
     * 查询有效月卡：Redis 缓存优先，缓存失效查库
     * 出场结算时调用：有效则免单
     */
    public MonthlyCard getValidCard(String plateNo) {
        // 1. 查缓存（只存到期时间戳，命中且未过期即可免查库）
        String cached = redis.opsForValue().get(CARD_CACHE_PREFIX + plateNo);
        if (cached != null) {
            long endTs = Long.parseLong(cached);
            if (endTs > System.currentTimeMillis()) {
                return new MonthlyCard(plateNo); // 占位对象，仅表示有效
            }
        }
        // 2. 缓存未命中或已过期，查库
        return monthlyCardMapper.selectOne(new LambdaQueryWrapper<MonthlyCard>()
                .eq(MonthlyCard::getPlateNo, plateNo)
                .eq(MonthlyCard::getStatus, 1)
                .gt(MonthlyCard::getEndTime, LocalDateTime.now())
                .orderByDesc(MonthlyCard::getEndTime).last("LIMIT 1"));
    }

    /**
     * 定时任务：每天扫描到期月卡，置为过期并提醒续费
     */
    @Scheduled(cron = "0 30 0 * * ?")
    public void expireScan() {
        List<MonthlyCard> expired = monthlyCardMapper.selectList(
                new LambdaQueryWrapper<MonthlyCard>()
                        .eq(MonthlyCard::getStatus, 1)
                        .lt(MonthlyCard::getEndTime, LocalDateTime.now()));
        for (MonthlyCard card : expired) {
            MonthlyCard update = new MonthlyCard();
            update.setId(card.getId());
            update.setStatus(0); // 已过期
            monthlyCardMapper.updateById(update);
            redis.delete(CARD_CACHE_PREFIX + card.getPlateNo());
            log.info("月卡到期: plate={}, endTime={}", card.getPlateNo(), card.getEndTime());
        }
    }
}
```

```java
@Service
public class IncomeService {

     * 每日收入汇总：定时任务在凌晨执行

                    case 2 -> alipay = alipay.add(r.getPaidAmount());

                monthCardCount++;
            }
            if (r.getFeeType() == 3 || r.getTotalAmount().compareTo(BigDecimal.ZERO) == 0) {
                freeCount++;
            }
        }
        // 汇总表 upsert（唯一索引 uk_date）
        IncomeDaily daily = incomeDailyMapper.selectOne(new LambdaQueryWrapper<IncomeDaily>()

        daily.setPayWechat(wechat);

        daily.setMonthCardCount(monthCardCount);
        daily.setFreeCount(freeCount);

            incomeDailyMapper.insert(daily);
        } else {
            incomeDailyMapper.updateById(daily);
```

```text
7. 月度经营分析：收入日汇总表显示日均收入 4.2 万，免费时长内离场车辆占比 12%，据此优化免费时长
```

### 场景二：医院停车场（免费时长 + 长停治理）

三甲医院停车场 600 个车位，就医车辆停留时间长、周转率低：

```text
1. 免费时长调至 30 分钟（就医接送友好），首小时 5 元，之后每小时 2 元，24 小时封顶 30 元
2. 凌晨定时任务扫描场内车辆，超 24 小时的长停车辆进入预警列表，管理员电话联系挪车
3. 出院患者家属把车停一周的情况：按「天数 x 日封顶 + 尾段费」计费，规则引擎自动算清
4. 患者家属缴费高峰期：出口结算接口扛住并发，锁 + 状态机保证每车只算一次
5. 医务人员办理年卡，出场免单自动放行，减少出口排队
6. 无入场记录的车（识别失败漏录）出场时走人工通道，岗亭补录后放行并记录
7. 运营调整：把部分普通车位改为「就医专用」类型，统计各类型车位周转率辅助决策
```

### 场景三：小区地下车库（月卡为主）

住宅小区地下车库 800 个固定车位 + 200 个临停车位：

```text
1. 业主办理年卡：一次性缴费 3600 元，系统按年卡类型自动计算到期时间（次年同日）
2. 月卡车辆进场自动识别放行，出场自动抬杆，全程无感通行
3. 月卡到期前 7 天，定时任务给车主发续费提醒；过期后出场按临停计费并提示续费
4. 访客临停：30 分钟免费，之后每小时 5 元，扫码缴费出场
5. 提前续费不亏天数：业主月中续费年卡，新卡从旧卡到期日顺延计算
6. 违规占用：月卡专用车位被临停车占用，系统标记异常，保安现场处理
7. 收入对账：月卡收入与临停收入分渠道统计，财务核对月卡台账与收款流水
```

## 最佳实践与踩坑记录

### 最佳实践

1. 出场结算幂等是系统的生命线：Redis 分布式锁 + 入场记录状态机 + exit_record 唯一索引三层防护，保证「一次出场只结算一次」
2. 计费规则全部参数化：免费时长、阶梯费率、封顶、夜间优惠都来自 fee_rule 表，改规则改数据不改代码，上线后运营可自助调整
3. 入场快照写 Redis：出场计算、防重复入场、场内查询都依赖入场信息，Redis 快照让这些高频操作毫秒级完成，MySQL 只做最终落账
4. 车牌识别必须留降级通道：OCR 置信度不足时转手动录入，永远不要让「识别失败」阻塞入场，业务可用性优先
5. 月卡续费从旧卡到期日顺延：避免「提前续费亏天数」的客诉，同时用 Redis 缓存到期时间戳让出场校验免查库
6. 道闸联动统一抽象：GateService 接口 + 厂商实现 + 操作审计日志，换设备厂商只加实现类，所有放行动作可追溯
7. 收入报表用定时任务预聚合：明细表数据量大，日汇总表先算好，报表查询永远秒开

### 踩坑记录

```text
坑 1：出口摄像头多次触发，同一辆车被重复计费
结论：车主被扣两次费，客诉退款。
原因：出场结算接口没有幂等，每次识别都重新插入一条结算记录。
解法：三道防线——Redis SETNX 锁（结算中拒绝新请求）+ 入场记录状态机（在场才可结算）+ exit_record 唯一索引 uk_entry（数据库兜底）。

坑 2：锁的 TTL 设置太短，长事务把锁提前释放
结论：结算事务还没提交，锁已过期，另一请求进入并发处理。
原因：SETNX 锁 TTL 2 秒，但支付回调 + 开闸全链路耗时超过 2 秒。
解法：TTL 放宽到 2 分钟并加业务校验兜底（已存在结算记录直接返回）；锁只保护「计算+插单」的短临界区，支付确认用状态机乐观锁。

坑 3：免费时长边界多收钱
结论：停车 14 分 59 秒被收了首小时费用。
原因：时长换算向上取整时把免费时长也算进去了。
解法：先扣免费时长再向上取整计费小时：billableMinutes = minutes - freeMinutes，hours = ceil(billableMinutes / 60)。

坑 4：跨天停车计费算错
结论：停 25 小时的车只收了 2 倍首小时费，没有按日封顶。
原因：计费引擎只处理了单段阶梯，没处理「超过 24 小时按天叠加」。
解法：minutes > 1440 时拆成「天数 x 日封顶 + 尾段阶梯费」，尾段复用同一套阶梯计算。

坑 5：月卡到期后仍被自动放行
结论：月卡过期的车出场免单，收入流失。
原因：出场时只查了「存在月卡记录」，没校验 end_time 是否在现在之后。
解法：getValidCard 查询条件必须带 endTime > now()；Redis 缓存到期时间戳，缓存命中也要比较当前时间。

坑 6：场内计数与真实车数不一致
结论：大屏显示剩余 500 位，实际只剩 200 位。
原因：入场成功但 Redis INCR 失败，或出场时 Redis DECR 与删除快照不同步。
解法：定时任务每小时用 MySQL「在场记录数」校准 Redis 计数；入场快照写入与 INCR 放在同一事务后串行执行，失败重试。

坑 7：手动录入车牌格式不统一
结论：同一辆车被录成「京A12345」和「京A 12345」，出场时查不到入场记录。
原因：手动录入没做规范化，空格/大小写/全半角混入。
解法：录入与识别结果统一走 normalizePlate()：去除空格、统一大写、校验正则，入库前强制规范化。
```
