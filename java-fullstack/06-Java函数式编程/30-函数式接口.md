## 概述

函数式接口（Functional Interface）是**只有一个抽象方法**的接口——它的唯一使命就是作为 Lambda 表达式的目标类型。

Java 在 `java.util.function` 包中预定义了 43 个函数式接口，但日常只用其中的十几个。它们分为四大家族：

| 家族 | 核心方法 | 语义 | 标准接口 |
|------|----------|------|----------|
| Function | `R apply(T t)` | 输入 T，输出 R（转换） | `Function<T,R>` |
| Consumer | `void accept(T t)` | 输入 T，无返回值（消费） | `Consumer<T>` |
| Supplier | `T get()` | 无输入，返回 T（供给） | `Supplier<T>` |
| Predicate | `boolean test(T t)` | 输入 T，返回 boolean（断言） | `Predicate<T>` |

理解这四大家族的语义后，其他所有变体（`BiFunction`、`IntConsumer` 等）都不需要死记。

## @FunctionalInterface

`@FunctionalInterface` 是可选注解，但从语义上强烈建议使用：

```java
@FunctionalInterface
public interface MyHandler {
    void handle(String input);

    // 可以有多个 default 方法和 static 方法
    default void before() {
        System.out.println("before");
    }

    static MyHandler empty() {
        return input -> { };
    }
}

// 如果加了第二个抽象方法，编译报错：
// @FunctionalInterface
// interface Bad {
//     void method1();
//     void method2();  // 编译错误！
// }
```

加 `@FunctionalInterface` 的好处：
- 编译器会检查只有**一个**抽象方法
- 告诉阅读代码的人"这个接口是为 Lambda 设计的"
- 防止维护时不小心添加第二个抽象方法破坏 Lambda 兼容性

## 四大核心接口

```java
// 记忆框架：输入 → 输出
// 1. Function<T, R>     T → R     有去有回（转换）
// 2. Consumer<T>        T → void  有去无回（消费）
// 3. Supplier<T>        () → T    无中生有（供给）
// 4. Predicate<T>       T → bool  判断真伪（断言）
```

## Function —— 转换

接收一个参数，返回另一个值——做类型转换或数据加工的核心：

```java
// 接口定义
@FunctionalInterface
public interface Function<T, R> {
    R apply(T t);

    // 组合方法（default）
    default <V> Function<V, R> compose(Function<? super V, ? extends T> before);
    default <V> Function<T, V> andThen(Function<? super R, ? extends V> after);

    static <T> Function<T, T> identity();
}

// 基本用法
Function<String, Integer> strLen = String::length;
Function<Integer, String> intToStr = String::valueOf;
Function<String, User> toUser = name -> new User(name);

System.out.println(strLen.apply("hello"));    // 5
System.out.println(intToStr.apply(42));       // "42"
System.out.println(toUser.apply("张三"));      // User{name='张三'}
```

### 原始类型特化

为了减少装箱拆箱，提供原始类型变体：

```java
IntFunction<R>          // int → R
LongFunction<R>          // long → R
DoubleFunction<R>        // double → R

ToIntFunction<T>         // T → int
ToLongFunction<T>        // T → long
ToDoubleFunction<T>      // T → double

IntToLongFunction        // int → long
IntToDoubleFunction      // int → double
LongToIntFunction        // long → int
LongToDoubleFunction     // long → double
DoubleToIntFunction      // double → int
DoubleToLongFunction     // double → long

// 用法
ToIntFunction<String> strToInt = Integer::parseInt;
int result = strToInt.applyAsInt("42");   // 返回 int，不是 Integer
```

## Consumer —— 消费

接收一个参数，没有返回值——做副作用操作：打印、存储、修改外部状态：

```java
// 接口定义
@FunctionalInterface
public interface Consumer<T> {
    void accept(T t);
    default Consumer<T> andThen(Consumer<? super T> after);
}

// 基本用法
Consumer<String> printer = System.out::println;
Consumer<User> saveUser = user -> userRepository.save(user);
Consumer<List<String>> clearList = List::clear;

printer.accept("Hello");     // 打印
saveUser.accept(newUser);    // 保存

// 链式消费
Consumer<String> process = 
    ((Consumer<String>) s -> System.out.println("第一步: " + s))
    .andThen(s -> System.out.println("第二步: " + s));
process.accept("hello");
// 输出：
// 第一步: hello
// 第二步: hello
```

### 原始类型特化

```java
IntConsumer      // int → void
LongConsumer     // long → void
DoubleConsumer   // double → void
```

## Supplier —— 供给

无参数，返回一个值——延迟计算、工厂方法、默认值提供：

```java
// 接口定义
@FunctionalInterface
public interface Supplier<T> {
    T get();
}

// 基本用法
Supplier<Double> random = Math::random;
Supplier<User> newUser = User::new;
Supplier<Long> currentTime = System::currentTimeMillis;

Double d = random.get();           // 0.123...
User user = newUser.get();         // 新 User 实例

// 延迟计算 —— 值只在需要时才计算
public class Lazy<T> {
    private final Supplier<T> supplier;
    private T value;
    private boolean computed;

    public Lazy(Supplier<T> supplier) {
        this.supplier = supplier;
    }

    public T get() {
        if (!computed) {
            value = supplier.get();
            computed = true;
        }
        return value;
    }
}
```

### 原始类型特化

```java
BooleanSupplier   // () → boolean
IntSupplier       // () → int
LongSupplier      // () → long
DoubleSupplier    // () → double
```

## Predicate —— 断言

接收一个参数，返回 boolean——用于过滤、条件判断：

```java
// 接口定义
@FunctionalInterface
public interface Predicate<T> {
    boolean test(T t);

    default Predicate<T> and(Predicate<? super T> other);
    default Predicate<T> or(Predicate<? super T> other);
    default Predicate<T> negate();

    static <T> Predicate<T> isEqual(Object targetRef);
    static <T> Predicate<T> not(Predicate<? super T> target);  // JDK 11+
}

// 基本用法
Predicate<String> isEmpty = String::isEmpty;
Predicate<String> isLong = s -> s.length() > 10;
Predicate<User> isAdult = u -> u.getAge() >= 18;

isEmpty.test("");      // true
isAdult.test(user);    // false

// 组合 —— Predicate 的杀手锏
Predicate<String> nonEmpty = isEmpty.negate();
Predicate<String> longAndNonEmpty = nonEmpty.and(isLong);
Predicate<String> emptyOrLong = isEmpty.or(isLong);

// 复杂过滤条件
Predicate<User> activeAdult = ((Predicate<User>) u -> u.isActive())
    .and(u -> u.getAge() >= 18)
    .and(u -> u.getLevel() != null);
```

### 原始类型特化

```java
IntPredicate     // int → boolean
LongPredicate    // long → boolean
DoublePredicate  // double → boolean
```

## Operator 系列

Operator 是特殊的 Function——输入和输出类型相同：

```java
// UnaryOperator<T> extends Function<T, T>     —— T → T
UnaryOperator<String> upper = String::toUpperCase;
String result = upper.apply("hello");  // "HELLO"

// JDK 原始类型变体
IntUnaryOperator    // int → int
LongUnaryOperator   // long → long
DoubleUnaryOperator // double → double
```

```java
// BinaryOperator<T> extends BiFunction<T, T, T>  —— (T, T) → T
BinaryOperator<Integer> add = Integer::sum;
BinaryOperator<String> concat = String::concat;

int sum = add.apply(1, 2);         // 3
String s = concat.apply("a", "b"); // "ab"

// 静态方法——获取 min/max 比较器
BinaryOperator<Integer> min = BinaryOperator.minBy(Integer::compareTo);
BinaryOperator<Integer> max = BinaryOperator.maxBy(Integer::compareTo);

// 原始类型变体
IntBinaryOperator
LongBinaryOperator
DoubleBinaryOperator
```

## Bi 系列（二元）

函数式接口的基本形式是单参数——需要两个参数时用 Bi 前缀：

```java
// BiFunction<T, U, R> —— (T, U) → R
BiFunction<Integer, Integer, String> toPair = (a, b) -> a + "-" + b;
BiFunction<String, Integer, User> userCreator = User::new;

String pair = toPair.apply(1, 2);            // "1-2"
User user = userCreator.apply("张三", 25);     // User{name='张三', age=25}

// BiConsumer<T, U> —— (T, U) → void
BiConsumer<String, Integer> printEntry = (k, v) -> System.out.println(k + "=" + v);
map.forEach(printEntry);

// BiPredicate<T, U> —— (T, U) → boolean
BiPredicate<String, String> equals = String::equals;
BiPredicate<Integer, Integer> gt = (a, b) -> a > b;
```

注意：没有 `BiSupplier`——Supplier 不需要参数，自然也没有"二元 Supplier"这一说。

## 复合与组合

函数式接口提供了默认方法用于组合——这是函数式编程的基石：

```java
// Function 组合
Function<Integer, Integer> times2 = x -> x * 2;
Function<Integer, Integer> plus3 = x -> x + 3;

// compose: 先执行参数中的 Function，结果传给调用者
Function<Integer, Integer> f1 = times2.compose(plus3);   // f(x) = (x+3)*2
System.out.println(f1.apply(5));  // 16

// andThen: 先执行调用者，结果传给参数中的 Function
Function<Integer, Integer> f2 = times2.andThen(plus3);   // f(x) = x*2+3
System.out.println(f2.apply(5));  // 13

// identity: 返回输入本身
Function<String, String> id = Function.identity();
System.out.println(id.apply("hi"));  // "hi"
```

```java
// Predicate 组合
Predicate<String> notEmpty = s -> !s.isEmpty();
Predicate<String> startsWithA = s -> s.startsWith("A");

Predicate<String> filter = notEmpty.and(startsWithA);   // 同时满足
Predicate<String> either = notEmpty.or(startsWithA);    // 满足任一
Predicate<String> reversed = notEmpty.negate();          // 取反

// JDK 11+ 静态引用
Predicate<String> isNotEmpty = Predicate.not(String::isEmpty);
```

```java
// Consumer 链
Consumer<String> step1 = s -> System.out.println("第一步: " + s);
Consumer<String> step2 = s -> System.out.println("第二步: " + s);
Consumer<String> step3 = s -> System.out.println("第三步: " + s);

Consumer<String> pipeline = step1.andThen(step2).andThen(step3);
pipeline.accept("data");
```

## 应用场景实战

### 场景一：通用对象转换器注册表

```java
public class ConverterRegistry {
    private final Map<Class<?>, Map<Class<?>, Function<?, ?>>> converters = new HashMap<>();

    public <S, T> void register(Class<S> source, Class<T> target, Function<S, T> converter) {
        converters.computeIfAbsent(source, k -> new HashMap<>())
                  .put(target, converter);
    }

    @SuppressWarnings("unchecked")
    public <S, T> T convert(S source, Class<T> target) {
        Function<S, T> converter = (Function<S, T>) converters
            .getOrDefault(source.getClass(), Map.of())
            .get(target);
        if (converter == null) {
            throw new IllegalArgumentException("无转换器: " 
                + source.getClass() + " → " + target);
        }
        return converter.apply(source);
    }
}

// 用法
ConverterRegistry registry = new ConverterRegistry();
registry.register(User.class, UserDTO.class, u -> new UserDTO(u.getName()));
UserDTO dto = registry.convert(user, UserDTO.class);
```

### 场景二：条件链执行器

```java
public class ConditionalRunner<T> {
    private final List<Pair<Predicate<T>, Consumer<T>>> rules = new ArrayList<>();

    public ConditionalRunner<T> when(Predicate<T> condition, Consumer<T> action) {
        rules.add(new Pair<>(condition, action));
        return this;
    }

    public void execute(T input) {
        for (var rule : rules) {
            if (rule.getKey().test(input)) {
                rule.getValue().accept(input);
            }
        }
    }
}

// 用法
new ConditionalRunner<Order>()
    .when(o -> o.getAmount() > 1000, o -> sendVipNotification(o))
    .when(o -> o.isInternational(),   o -> calculateCustoms(o))
    .when(o -> o.isPreOrder(),        o -> reserveInventory(o))
    .execute(order);
```

### 场景三：Supplier 实现工厂与缓存

```java
public class ObjectPool<T> {
    private final Queue<T> pool = new ConcurrentLinkedQueue<>();
    private final Supplier<T> factory;

    public ObjectPool(Supplier<T> factory, int initialSize) {
        this.factory = factory;
        for (int i = 0; i < initialSize; i++) {
            pool.offer(factory.get());
        }
    }

    public T borrow() {
        T obj = pool.poll();
        return obj != null ? obj : factory.get();
    }

    public void release(T obj) {
        pool.offer(obj);
    }
}

// 用法
ObjectPool<Connection> connPool = new ObjectPool<>(
    () -> dataSource.getConnection(),
    10
);
```

### 场景四：Builder 模式 + Consumer

```java
public class UserBuilder {
    private String name;
    private int age;
    private String email;

    public UserBuilder with(Consumer<UserBuilder> config) {
        config.accept(this);
        return this;
    }

    public User build() {
        return new User(name, age, email);
    }

    // getter/setter 省略...
}

// 用法
User user = new UserBuilder()
    .with(b -> { b.setName("张三"); b.setAge(25); })
    .with(b -> b.setEmail("zhangsan@example.com"))
    .build();
```

## 最佳实践与选型指南

### 选型表

| 你需要... | 用 |
|-----------|-----|
| 转换 A 到 B | `Function<A, B>` |
| 做副作用（打印、保存、修改状态） | `Consumer<T>` |
| 生成/提供值 | `Supplier<T>` |
| 条件判断/过滤 | `Predicate<T>` |
| 转换自身类型 | `UnaryOperator<T>` |
| 两个参数做一件事（副作用） | `BiConsumer<T,U>` |
| 两个参数返回一个值 | `BiFunction<T,U,R>` |
| 避免原始类型装箱 | `IntFunction`、`ToIntFunction` 等 |

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| Lambda 赋值给 Object | 没有目标类型 | 强转 `(Runnable) () -> ...` 或赋给函数式接口变量 |
| `addThen` vs `compose` 搞混 | 执行顺序相反 | `f.andThen(g)` = 先 f 后 g；`f.compose(g)` = 先 g 后 f |
| BiConsumer 和 Consumer<Map.Entry> 混用 | 语义不同 | `map.forEach((k,v) -> ...)` 更直观 |
| Predicate.and 短路不执行 | 从左到右，左侧 false 则不执行右侧 | 检查逻辑顺序 |

### 接口汇总

```
单参数：
  Function<T,R>    T→R
  Consumer<T>      T→void
  Supplier<T>      ()→T
  Predicate<T>     T→bool
  UnaryOperator<T> T→T

双参数：
  BiFunction<T,U,R>   (T,U)→R
  BiConsumer<T,U>     (T,U)→void
  BiPredicate<T,U>    (T,U)→bool
  BinaryOperator<T>   (T,T)→T

原始类型：
  Int/Long/Double + Function/Consumer/Supplier/Predicate
  例如：IntFunction<R>, ToIntFunction<T>, IntConsumer, IntSupplier, IntPredicate
  Int/Long/Double + UnaryOperator / BinaryOperator
  例如：IntUnaryOperator, IntBinaryOperator
```

## 总结

- 函数式接口 = 只有一个抽象方法的接口，Lambda 的目标类型
- 四大核心：`Function`(转换)、`Consumer`(消费)、`Supplier`(供给)、`Predicate`(断言)
- `@FunctionalInterface` 不是必须但强烈推荐——编译器帮你把关
- Operator 是输入输出同类型的 Function：`UnaryOperator<T>` = `Function<T,T>`
- Bi 系列处理双参数场景：`BiFunction`、`BiConsumer`、`BiPredicate`、`BinaryOperator`
- 原始类型特化避免装箱：`IntFunction`、`ToIntFunction`、`IntConsumer` 等
- 组合方法：`Function.andThen/compose`、`Predicate.and/or/negate`、`Consumer.andThen`
