## 概述

Java 图片处理是办公自动化的常见需求，包括压缩、裁剪、缩放、水印、格式转换、OCR。

```text
常见图片库：
1. ImageIO —— JDK 内置，基础读写
2. Thumbnailator —— 简单易用（压缩、缩放、裁剪、水印）
3. OpenCV —— 计算机视觉（复杂处理）
4. Tesseract —— OCR 文字识别
```

```text
选型建议：
1. 基础读写 —— ImageIO
2. 常用处理（压缩/缩放/裁剪/水印）—— Thumbnailator
3. OCR —— Tesseract（tess4j）
4. 复杂视觉 —— OpenCV
```

## ImageIO 基础

ImageIO 是 JDK 内置的图片读写 API。

### 读取图片

```java
BufferedImage image = ImageIO.read(new File("input.jpg"));
int width = image.getWidth();
int height = image.getHeight();
```

### 写入图片

```java
ImageIO.write(image, "jpg", new File("output.jpg"));
ImageIO.write(image, "png", new File("output.png"));
```

### 支持的格式

```text
ImageIO 内置支持：
- JPEG/JPG
- PNG
- BMP
- GIF
- WBMP

WebP 需要额外插件（如 webp-imageio）
```

## Thumbnailator 图片处理

Thumbnailator 是简洁的图片处理库，链式调用完成压缩、缩放、裁剪、水印。

### 依赖

```xml
<dependency>
    <groupId>net.coobird</groupId>
    <artifactId>thumbnailator</artifactId>
    <version>0.4.20</version>
</dependency>
```

### 基本操作

```java
// 缩放
Thumbnails.of("input.jpg")
    .size(200, 200)          // 缩放到 200x200
    .toFile("output.jpg");

// 按比例缩放
Thumbnails.of("input.jpg")
    .scale(0.5)              // 缩放到 50%
    .toFile("output.jpg");

// 保持比例（指定宽，高自适应）
Thumbnails.of("input.jpg")
    .width(200)
    .keepAspectRatio(true)
    .toFile("output.jpg");

// 旋转
Thumbnails.of("input.jpg")
    .rotate(90)              // 旋转 90 度
    .toFile("output.jpg");

// 水印
Thumbnails.of("input.jpg")
    .size(400, 400)
    .watermark(Positions.BOTTOM_RIGHT,
        ImageIO.read(new File("watermark.png")), 0.5f)  // 透明度 50%
    .toFile("output.jpg");
```

## 图片压缩

图片压缩减小文件体积，是图片处理最常见的需求。

### 质量压缩（JPEG）

```java
// 降低 JPEG 质量（体积减小，画质略降）
Thumbnails.of("input.jpg")
    .scale(1.0)              // 尺寸不变
    .outputQuality(0.5)      // 质量 50%
    .toFile("output.jpg");
```

```java
// 用 ImageIO 手动压缩
BufferedImage image = ImageIO.read(new File("input.jpg"));
ImageWriter writer = ImageIO.getImageWritersByFormatName("jpg").next();
ImageWriteParam param = writer.getDefaultWriteParam();
param.setCompressionMode(ImageWriteParam.MODE_EXPLICIT);
param.setCompressionQuality(0.5f);   // 质量 50%

try (ImageOutputStream ios = ImageIO.createImageOutputStream(new File("output.jpg"))) {
    writer.setOutput(ios);
    writer.write(null, new IIOImage(image, null, null), param);
}
```

### 缩放压缩

```java
// 缩小尺寸（大幅减小体积）
Thumbnails.of("input.jpg")
    .size(800, 800)          // 限制最大 800x800
    .outputQuality(0.7)
    .toFile("output.jpg");
```

### 压缩策略

```text
1. 尺寸压缩 —— 缩小分辨率（影响最大）
2. 质量压缩 —— 降低 JPEG 质量（0.7-0.8 通常够用）
3. 格式转换 —— PNG → JPEG（去掉透明通道）
```

## 图片裁剪

图片裁剪截取图片的一部分。

### Thumbnailator 裁剪

```java
// 中心裁剪（裁剪到指定尺寸，保持中心）
Thumbnails.of("input.jpg")
    .size(200, 200)
    .crop(Positions.CENTER)   // 中心裁剪
    .toFile("output.jpg");
```

```java
// 指定区域裁剪
Thumbnails.of("input.jpg")
    .sourceRegion(Positions.CENTER, 400, 400)  // 中心 400x400
    .size(200, 200)
    .toFile("output.jpg");
```

### ImageIO 手动裁剪

```java
BufferedImage image = ImageIO.read(new File("input.jpg"));
// 裁剪 (x, y, width, height)
BufferedImage cropped = image.getSubimage(100, 100, 400, 400);
ImageIO.write(cropped, "jpg", new File("output.jpg"));
```

## 水印

水印在图片上叠加文字或图片，保护版权。

### 图片水印

```java
Thumbnails.of("input.jpg")
    .size(800, 800)
    .watermark(Positions.BOTTOM_RIGHT,
        ImageIO.read(new File("logo.png")), 0.5f)
    .toFile("output.jpg");
```

### 文字水印

```java
public void addTextWatermark(String input, String output, String text) {
    BufferedImage image = ImageIO.read(new File(input));
    Graphics2D g = (Graphics2D) image.getGraphics();

    // 设置字体和颜色
    g.setFont(new Font("宋体", Font.BOLD, 30));
    g.setColor(new Color(0, 0, 0, 80));   // 半透明

    // 在右下角画文字
    int x = image.getWidth() - 200;
    int y = image.getHeight() - 30;
    g.drawString(text, x, y);
    g.dispose();

    ImageIO.write(image, "jpg", new File(output));
}
```

## OCR 文字识别

OCR（Optical Character Recognition）识别图片中的文字。

### Tesseract（tess4j）

```xml
<dependency>
    <groupId>net.sourceforge.tess4j</groupId>
    <artifactId>tess4j</artifactId>
    <version>5.9.0</version>
</dependency>
```

```java
ITesseract tesseract = new Tesseract();
tesseract.setDatapath("tessdata");      // 语言包路径
tesseract.setLanguage("chi_sim");       // 简体中文

String text = tesseract.doOCR(new File("image.png"));
System.out.println(text);
```

### OCR 的注意事项

```text
1. 图片质量 —— 清晰度影响识别率
2. 语言包 —— 中文需要 chi_sim 语言包
3. 预处理 —— 灰度化、二值化、去噪提升识别率
4. 识别率 —— 手写识别率低，印刷体高
```

### OCR 预处理

```java
// 预处理提升识别率
public BufferedImage preprocess(BufferedImage image) {
    // 灰度化
    BufferedImage gray = new BufferedImage(
        image.getWidth(), image.getHeight(), BufferedImage.TYPE_BYTE_GRAY);
    Graphics2D g = gray.createGraphics();
    g.drawImage(image, 0, 0, null);
    g.dispose();
    return gray;
}
```

## 应用场景实战

### 场景 1：上传图片自动压缩（头像）

```java
@PostMapping("/upload")
public Result upload(MultipartFile file) throws IOException {
    // 1. 压缩到 200x200
    ByteArrayOutputStream out = new ByteArrayOutputStream();
    Thumbnails.of(file.getInputStream())
        .size(200, 200)
        .outputQuality(0.8)
        .toOutputStream(out);

    // 2. 上传到 OSS
    String url = ossService.upload(out.toByteArray(), "avatar.jpg");
    return Result.success(url);
}
```

### 场景 2：生成缩略图

```java
// 原图生成多个尺寸的缩略图
public void generateThumbnails(String input) throws IOException {

    Thumbnails.of(input).size(800, 800).toFile("thumb-800.jpg");
    // 中图
    Thumbnails.of(input).size(400, 400).toFile("thumb-400.jpg");
    // 小图
    Thumbnails.of(input).size(100, 100).toFile("thumb-100.jpg");
}
```


## 最佳实践与踩坑记录

### 最佳实践

1. **常用处理用 Thumbnailator**。链式 API 简洁，比 ImageIO 手动处理简单。

2. **压缩先缩尺寸再降质量**。尺寸影响最大。

3. **WebP 格式用插件**。ImageIO 不支持 WebP，需要额外插件。

4. **OCR 先预处理**。灰度化、二值化提升识别率。

5. **处理后的图片及时释放**。BufferedImage 占内存，处理完释放。

### 踩坑记录

**坑 1：JPEG 转 PNG 体积反而大**

```text
JPEG 是有损压缩，PNG 是无损，JPEG 转 PNG 体积可能更大
```

格式转换要考虑：照片用 JPEG，图标/透明用 PNG。

**坑 2：ImageIO 不支持 WebP**

```java
ImageIO.read(new File("image.webp"));   // 返回 null，不支持
```

WebP 用 webp-imageio 插件。

**坑 3：缩放失真**

```java
Thumbnails.of("input.jpg").size(200, 200)   // 强制 200x200，比例失真
```

用 keepAspectRatio(true) 保持比例，或 scale(比例)。

**坑 4：OCR 识别率低**

```text
图片模糊、倾斜、手写，OCR 识别率低
```

预处理（灰度、二值化、去噪），或提升图片质量。

**坑 5：图片处理内存溢出**

```text
处理超大图片（几万像素），内存不足 OOM
```

限制上传图片尺寸，或分块处理。

**坑 6：透明背景丢失**

```text
PNG 透明背景转 JPEG，透明变黑色
```

需要透明用 PNG，JPEG 不支持透明。
