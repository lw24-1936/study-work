## 概述

Java 处理 PDF 是办公自动化的常见需求，包括生成（导出）、解析（读取）、合并、拆分。

```text
常见 PDF 库：
1. iText —— 功能最全（生成、编辑、表单），部分功能收费
2. OpenPDF —— iText 的开源分支
3. Apache PDFBox —— 开源，解析、合并拆分
4. JasperReports —— 报表模板生成
```

```text
选型建议：
1. 生成 PDF —— iText/OpenPDF 或模板方案
2. 解析 PDF —— PDFBox（提取文本）
3. 合并拆分 —— PDFBox
4. 复杂报表 —— JasperReports
```

## PDF 生成

### iText 生成

```xml
<dependency>
    <groupId>com.itextpdf</groupId>
    <artifactId>itext7-core</artifactId>
    <version>7.2.5</version>
</dependency>
```

```java
try (PdfWriter writer = new PdfWriter("out.pdf");
     PdfDocument pdf = new PdfDocument(writer);
     Document document = new Document(pdf)) {

    // 添加文本
    document.add(new Paragraph("你好，PDF！"));

    // 添加表格
    Table table = new Table(2);   // 2 列
    table.addCell("姓名");
    table.addCell("年龄");
    table.addCell("张三");
    table.addCell("20");
    document.add(table);
}
```

### OpenPDF 生成（免费）

```xml
<dependency>
    <groupId>com.github.librepdf</groupId>
    <artifactId>openpdf</artifactId>
    <version>1.3.30</version>
</dependency>
```

```java
try (Document document = new Document()) {
    PdfWriter.getInstance(document, new FileOutputStream("out.pdf"));
    document.open();
    document.add(new Paragraph("你好，PDF！"));
    document.close();
}
```

### 中文字体处理

```java
// iText 生成中文需要指定字体（默认字体不支持中文）
PdfFont font = PdfFontFactory.createFont(
    "C:/Windows/Fonts/simsun.ttc", PdfEncodings.IDENTITY_H);
document.add(new Paragraph("中文内容").setFont(font));
```

```text
关键：PDF 生成中文必须指定支持中文的字体，
否则中文显示乱码或空白。
```

## PDF 模板

PDF 模板是预设计好样式的 PDF，填充数据生成最终 PDF。

### 模板方案

```text
方案 1：AcroForm 表单（iText 填充表单字段）
方案 2：模板 + 定位填充（在固定坐标写文字）
方案 3：HTML 转 PDF（flyingsaucer）
方案 4：Word 模板 → PDF（poi-tl + 转换）
```

### HTML 转 PDF（flyingsaucer）

```xml
<dependency>
    <groupId>org.xhtmlrenderer</groupId>
    <artifactId>flying-saucer-pdf-openpdf</artifactId>
    <version>9.1.22</version>
</dependency>
```

```java
// 用 HTML 模板生成 PDF（灵活，支持 CSS）
String html = "<html><body><h1>订单详情</h1>"
    + "<p>订单号：ORD001</p></body></html>";

try (OutputStream os = new FileOutputStream("out.pdf")) {
    ITextRenderer renderer = new ITextRenderer();
    renderer.setDocumentFromString(html);
    renderer.layout();
    renderer.createPDF(os);
}
```

```text
HTML 转 PDF 的优势：
1. 模板灵活 —— 用 HTML/CSS 设计，易调整
2. 中文支持好 —— 指定中文字体即可
3. 复用前端技术 —— 前端工程师也能做模板
```

### 模板方案对比

| 方案 | 灵活性 | 复杂度 | 适用 |
|------|--------|--------|------|
| HTML 转 PDF | 高 | 低 | 通用推荐 |
| AcroForm | 中 | 中 | 固定表单 |
| 坐标填充 | 低 | 高 | 精确控制 |
| Word 模板 | 高 | 中 | Word 模板已有 |

## PDF 解析

PDF 解析是提取 PDF 中的文本内容。

### PDFBox 提取文本

```xml
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox</artifactId>
    <version>2.0.30</version>
</dependency>
```

```java
try (PDDocument document = PDDocument.load(new File("input.pdf"))) {
    PDFTextStripper stripper = new PDFTextStripper();
    String text = stripper.getText(document);
    System.out.println(text);   // 提取全文
}
```

### 逐页提取

```java
try (PDDocument document = PDDocument.load(new File("input.pdf"))) {
    PDFTextStripper stripper = new PDFTextStripper();
    for (int i = 1; i <= document.getNumberOfPages(); i++) {
        stripper.setStartPage(i);
        stripper.setEndPage(i);
        String pageText = stripper.getText(document);
        System.out.println("第 " + i + " 页：" + pageText);
    }
}
```

### PDF 解析的局限

```text
1. 扫描件无法提取 —— 图片型 PDF 需要 OCR
2. 表格提取困难 —— 表格结构可能丢失
3. 格式丢失 —— 只提取文本，样式丢失
```

```text
提取文本 → PDFBox
扫描件 OCR → Tesseract 等 OCR 工具
```

## PDF 合并与拆分

### PDFBox 合并

```java
try (PDDocument merged = new PDDocument()) {
    for (String file : files) {
        PDDocument doc = PDDocument.load(new File(file));
        for (PDPage page : doc.getPages()) {
            merged.addPage(page);
        }
        doc.close();
    }
    merged.save("merged.pdf");
}
```

### PDFBox 拆分

```java
try (PDDocument document = PDDocument.load(new File("input.pdf"))) {
    Splitter splitter = new Splitter();
    splitter.setSplitAtPage(10);   // 每 10 页拆一个文件
    List<PDDocument> parts = splitter.split(document);

    for (int i = 0; i < parts.size(); i++) {
        parts.get(i).save("part-" + i + ".pdf");
        parts.get(i).close();
    }
}
```

### PDFBox 按页拆分

```java
// 拆成单页
try (PDDocument document = PDDocument.load(new File("input.pdf"))) {
    for (int i = 0; i < document.getNumberOfPages(); i++) {
        PDDocument single = new PDDocument();
        single.addPage(document.getPage(i));
        single.save("page-" + (i + 1) + ".pdf");
        single.close();
    }
}
```

## 应用场景实战

### 场景 1：订单 PDF 生成（HTML 模板）

```java
@Service
public class PdfService {

    public void generateOrderPdf(Order order, OutputStream os) {
        // 1. 用模板引擎生成 HTML
        String html = templateEngine.process("order-template", Map.of(
            "orderNo", order.getOrderNo(),
            "userName", order.getUserName(),
            "amount", order.getAmount()
        ));

        // 2. HTML 转 PDF
        ITextRenderer renderer = new ITextRenderer();
        renderer.setDocumentFromString(html);
        renderer.layout();
        renderer.createPDF(os);
    }
}
```

### 场景 2：合同解析（提取文本）

```java
public String extractContractText(String pdfPath) {
    try (PDDocument document = PDDocument.load(new File(pdfPath))) {
        PDFTextStripper stripper = new PDFTextStripper();
        return stripper.getText(document);
    }
}
```

### 场景 3：报表合并

```java
// 多份月报合并成年度报告
public void mergeReports(List<String> monthlyReports, String output) {
    try (PDDocument merged = new PDDocument()) {
        for (String report : monthlyReports) {
            PDDocument doc = PDDocument.load(new File(report));
            for (PDPage page : doc.getPages()) {
                merged.addPage(page);
            }
            doc.close();
        }
        merged.save(output);
    }
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. **生成 PDF 用 HTML 模板**。灵活、中文支持好、易维护。

2. **中文字体必须指定**。否则中文乱码。

3. **大 PDF 解析用流式**。避免一次性加载全部。

4. **扫描件用 OCR**。PDFBox 只能提取文本型 PDF。

5. **iText 注意版权**。iText 部分功能 AGPL 协议，商用注意。

### 踩坑记录

**坑 1：中文乱码**

```java
document.add(new Paragraph("中文"));   // 没指定字体，乱码
```

生成 PDF 必须指定中文字体（simsun、simhei 等）。

**坑 2：扫描件提取为空**

```text
PDFBox 提取扫描件 PDF，文本为空（图片没有文本层）
```

扫描件用 OCR（Tesseract 等）识别。

**坑 3：iText 版权问题**

```text
iText 7 部分功能是 AGPL 协议，商用闭源项目需付费
```

商用用 OpenPDF 或 PDFBox（Apache 协议）。

**坑 4：表格提取结构丢失**

```text
PDFBox 提取表格，单元格内容混在一起，结构丢失
```

表格提取用专门的库（pdfplumber 是 Python 的），或坐标定位。

**坑 5：HTML 转 PDF 的 CSS 支持有限**

```text
flyingsaucer 不支持复杂 CSS（flex、grid）
```

用简单的 CSS（表格、段落），复杂布局用其他方案。

**坑 6：大 PDF 合并内存溢出**

```text
合并超大 PDF（几百页），全加载内存 OOM
```

用流式合并（PDFMergerUtility），或分批处理。
