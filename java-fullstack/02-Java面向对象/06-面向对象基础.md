## 面向对象思想

面向对象编程（OOP）把现实世界的事物抽象为**对象**，对象有**状态**（属性）和**行为**（方法）。和面向过程最大的区别：面向过程关注"做什么的步骤"（动词优先），面向对象关注"谁来做"（名词优先）。

Java 不是纯面向对象语言——8 种基本类型不是对象，`static` 方法属于类不属于实例。但和 C++ 比，Java 不允许多继承、不允许运算符重载、不能脱离类写函数——面向对象的纯度更高。

## 类与对象

**类**是模板/蓝图，**对象**是按模板创建的具体实例。一个类可以有多个对象。

```java
// 定义一个类
public class User {
    String name;        // 属性（状态）
    int age;

    void sayHello() {   // 方法（行为）
        System.out.println("Hello, I'm " + name);
    }
}

// 创建并使用对象
User user = new User();
user.name = "Tom";
user.age = 20;
user.sayHello();        // "Hello, I'm Tom"
```

类定义构成 `.java` 文件，编译后变成 `.class` 文件。运行时 JVM 加载 class，按模板在堆上创建对象。

## 属性与方法

```java
public class User {
    // 属性（字段/成员变量）
    private String name;
    private int age;

    // 方法
    public void setName(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }
}
```

方法签名由**方法名 + 参数类型列表**组成，不包括返回值类型。

## 构造方法

构造方法是与类同名的特殊方法，`new` 对象时自动调用。没有返回值类型声明。

```java
public class User {
    private String name;
    private int age;

    // 无参构造
    public User() {
        this.name = "Unknown";
        this.age = 0;
    }

    // 带参构造
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

// 使用
User u1 = new User();               // 调用无参构造 → Unknown, 0
User u2 = new User("Tom", 20);      // 调用带参构造 → Tom, 20
```

规则：
- 如果没有显式定义任何构造方法，编译器自动生成一个无参构造（什么都不做）
- 一旦定义了任何构造方法，自动生成的无参构造就消失了
- 一个类可以有多个构造方法（重载）

```java
public class User {
    private String name;

    public User(String name) {      // 有参构造
        this.name = name;
    }
}

User u = new User();              // 编译错误：没有无参构造
```

> 框架经常需要无参构造（MyBatis、Jackson 反序列化时），所以写了有参构造后记得同时写一个无参构造。Lombok 的 `@NoArgsConstructor` 和 `@AllArgsConstructor` 可以自动生成。

## this 关键字

`this` 是当前对象的引用，出现在实例方法和构造方法中。

```java
public class User {
    private String name;

    public User(String name) {
        this.name = name;       // this.name 是属性，name 是参数
    }

    public User() {
        this("Default");        // 调用另一个构造方法（必须放在第一行）
    }

    public void print() {
        System.out.println(this); // 当前对象的引用
    }

    public User getThis() {
        return this;              // 返回当前对象
    }
}
```

`this` 的三个主要用途：
1. 区分属性和局部变量同名的情况
2. 构造方法中调用另一个构造方法（`this(...)`）
3. 把当前对象传给其他方法或作为返回值

## 对象创建与销毁

### 创建过程

`new User("Tom", 20)` 背后发生了什么：

1. JVM 检查 User 类是否已加载，没有则先加载
2. 在堆上分配内存（大小由类结构决定）
3. 将内存空间清零（属性获得默认值：name=null, age=0）
4. 执行构造方法中的初始化代码（name="Tom", age=20）
5. 返回对象引用

### 销毁

Java 没有析构函数，程序员不能手动"销毁"对象。JVM 的垃圾回收器（GC）自动回收不再被引用的对象。

对象失去引用的几种情况：

```java
// 1. 引用指向 null
User u = new User();
u = null;                 // 原来的 User 对象成了垃圾

// 2. 引用指向其他对象
User u1 = new User();
User u2 = new User();
u1 = u2;                  // 第一个 User 对象没有引用了

// 3. 局部变量离开作用域
{
    User temp = new User();
}                         // 离开代码块，temp 被销毁，对象待 GC
```

GC 不一定立即执行——只能说对象"可回收"，具体什么时候回收由 JVM 决定。

## 方法重载

同一个类中，多个方法可以同名，但参数列表必须不同（数量、类型或顺序不同）。

```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public int add(int a, int b, int c) {       // 参数数量不同
        return a + b + c;
    }

    public double add(double a, double b) {      // 参数类型不同
        return a + b;
    }

    public String add(String a, String b) {      // 参数类型不同
        return a + b;
    }
}
```

注意：
- 方法重载只看参数列表，和返回值类型无关
- 不能定义只有返回值不同的两个方法——编译错误
- 调用时编译器根据参数类型决定匹配哪个方法（编译时多态）
