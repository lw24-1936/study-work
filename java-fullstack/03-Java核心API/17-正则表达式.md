## 概述

正则表达式（Regular Expression）是一种描述字符串模式的微型语言。Java 通过 `java.util.regex` 包提供支持，核心是两个类：

- **Pattern**：编译后的正则表达式（不可变，线程安全）
- **Matcher**：对特定输入执行匹配操作的引擎（可变，线程不安全）

工作流程：`正则字符串` → `Pattern.compile()` 编译 → `Pattern.matcher(input)` 获得 Matcher → 执行匹配/查找/替换。

## Pattern 与 Matcher

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

// 编译正则 —— Pattern 对象可以复用（线程安全）
Pattern pattern = Pattern.compile("\\d{3}-\\d{4}");

// 创建 Matcher
Matcher matcher = pattern.matcher("电话: 010-8822, 021-5555");

// matches() —— 整个字符串完全匹配
System.out.println(matcher.matches());    // false

// find() —— 查找下一个匹配的子串（迭代器模式）
while (matcher.find()) {
    System.out.println(matcher.group());  // 010-8822, 021-5555
    System.out.println(matcher.start());  // 匹配起始位置
    System.out.println(matcher.end());    // 匹配结束位置
}

// 重置 Matcher 复用
matcher.reset("新输入: 0755-9999");
while (matcher.find()) {
    System.out.println(matcher.group());  // 0755-9999
}
```

### 快捷方法

```java
// Pattern 上的静态方法（一次性使用）
boolean matches = Pattern.matches("\\d+", "12345");     // true

// String 上自带的方法（内部都会编译 Pattern）
String text = "hello world";
String[] parts = text.split("\\s+");                     // ["hello", "world"]
String replaced = text.replaceAll("\\w+", "xxx");        // "xxx xxx"
String first = text.replaceFirst("\\w+", "xxx");         // "xxx world"
```

## 正则表达式语法速查

| 语法 | 含义 | 示例匹配 |
|------|------|----------|
| `.` | 任意单个字符 | `a.c` 匹配 "abc"、"a c" |
| `\d` | 数字 [0-9] | `\d+` 匹配 "123" |
| `\D` | 非数字 | `\D+` 匹配 "abc" |
| `\w` | 单词字符 [a-zA-Z0-9_] | `\w+` 匹配 "hello_123" |
| `\W` | 非单词字符 | `\W+` 匹配 "!@#" |
| `\s` | 空白字符（空格、制表、换行） | `\s+` 匹配空格们 |
| `\S` | 非空白字符 | |
| `[abc]` | a、b 或 c 中任意一个 | `[aeiou]` 匹配元音 |
| `[^abc]` | 除了 a/b/c 之外的字符 | |
| `[a-z]` | a 到 z 的任意字符 | `[0-9]` 匹配一位数字 |
| `\` | 转义 | `\\.` 匹配字面点号 |

Java 字符串中的反斜杠需要双重转义——`\d` 在 Java 字符串里写成 `"\\d"`。

## 字符类

```java
// 预定义字符类
Pattern.compile("\\d");     // 一位数字
Pattern.compile("\\d+");    // 一位或多位数字

// 自定义字符类
Pattern.compile("[abc]");       // a、b、c 之一
Pattern.compile("[a-zA-Z]");    // 任意大小写字母
Pattern.compile("[0-9a-fA-F]"); // 十六进制字符

// 排除型字符类
Pattern.compile("[^0-9]");      // 非数字字符

// 并集/交集（很少用，但存在）
Pattern.compile("[a-z&&[^aeiou]]");  // 小写辅音字母
Pattern.compile("[a-z&&[def]]");     // d、e、f

// 注意：字符类里的 . 和 * 就是字面字符
Pattern.compile("[.*]");    // 匹配字面 . 或 *
```

## 量词

量词控制前面元素出现的次数：

| 量词 | 含义 | 贪婪性 |
|------|------|--------|
| `?` | 0 或 1 次 | 贪婪 |
| `*` | 0 或多次 | 贪婪 |
| `+` | 1 或多次 | 贪婪 |
| `{n}` | 恰好 n 次 | - |
| `{n,}` | 至少 n 次 | 贪婪 |
| `{n,m}` | n 到 m 次 | 贪婪 |

**贪婪 vs 非贪婪**：默认是贪婪匹配（尽可能多地吃字符），在量词后加 `?` 变成非贪婪（尽可能少地吃字符）：

```java
String html = "<div>hello</div><div>world</div>";

// 贪婪：.* 尽可能多吃，匹配到最后一个 </div>
Pattern greedy = Pattern.compile("<div>.*</div>");
Matcher m1 = greedy.matcher(html);
if (m1.find()) {
    System.out.println(m1.group());
    // <div>hello</div><div>world</div> —— 一口吃掉两个 div
}

// 非贪婪：.*? 尽可能少吃，匹配到第一个 </div> 就停
Pattern lazy = Pattern.compile("<div>.*?</div>");
Matcher m2 = lazy.matcher(html);
while (m2.find()) {
    System.out.println(m2.group());
    // <div>hello</div>
    // <div>world</div>
}
```

**占有量词**（`*+`、`++`、`?+`、`{n,m}+`）：匹配后不回溯，失败了就直接宣告失败，常用于避免灾难性回溯：

```java
// 灾难性回溯示例
Pattern evil = Pattern.compile("(a+)+b");
// 输入 "aaaaaaaaaaaaaaaaaaaaaaaaac" 会让引擎陷入指数级回溯

// 占有量词 —— 匹配后不放手
Pattern safe = Pattern.compile("(a++)+b");
// 输入同上，失败更快
```

## 分组与捕获

```java
// 捕获组：用括号分组，自动从 1 开始编号
Pattern p = Pattern.compile("(\\d{3})-(\\d{4})");
Matcher m = p.matcher("010-8822");
if (m.find()) {
    System.out.println(m.group());      // 010-8822（整个匹配）
    System.out.println(m.group(0));     // 010-8822（等同于 group()）
    System.out.println(m.group(1));     // 010（第一个括号）
    System.out.println(m.group(2));     // 8822（第二个括号）
}

// 具名捕获组（JDK 7+）
Pattern p2 = Pattern.compile("(?<area>\\d{3})-(?<number>\\d{4})");
Matcher m2 = p2.matcher("010-8822");
if (m2.find()) {
    System.out.println(m2.group("area"));     // 010
    System.out.println(m2.group("number"));   // 8822
}

// 非捕获组 (?:...) —— 分组但不捕获（不占编号，性能更好）
Pattern p3 = Pattern.compile("(?:\\d{3})-(\\d{4})");
Matcher m3 = p3.matcher("010-8822");
if (m3.find()) {
    System.out.println(m3.group(1));    // 8822（编号没有被 ?: 占用）
}

// 反向引用 —— 在正则内引用前面捕获组的内容
Pattern p4 = Pattern.compile("(\\w+)\\s+\\1");
// 匹配 "hello hello"、"go go" 等重复单词
```

## 边界匹配

| 锚点 | 含义 |
|------|------|
| `^` | 行开头（多行模式下） |
| `$` | 行结尾（多行模式下） |
| `\b` | 单词边界 |
| `\B` | 非单词边界 |
| `\A` | 整个输入开头 |
| `\Z` | 整个输入结尾（不含最后行终止符） |
| `\z` | 整个输入结尾 |

```java
// 单词边界
Pattern p = Pattern.compile("\\bcat\\b");
System.out.println(p.matcher("cat").find());         // true
System.out.println(p.matcher("catalog").find());     // false
System.out.println(p.matcher("scat").find());        // false

// 行模式 —— 让 ^ 和 $ 匹配每一行的开头结尾
String multiLine = "line1\nline2\nline3";
Pattern linePattern = Pattern.compile("^line\\d", Pattern.MULTILINE);
Matcher lm = linePattern.matcher(multiLine);
while (lm.find()) {
    System.out.println(lm.group());   // line1, line2, line3
}
```

## 前瞻与后瞻

前瞻（Lookahead）和后瞻（Lookbehind）是"零宽度断言"——只检查前后内容而不消耗字符：

| 语法 | 名称 | 含义 |
|------|------|------|
| `(?=X)` | 正向前瞻 | 后面必须是 X |
| `(?!X)` | 负向前瞻 | 后面不能是 X |
| `(?<=X)` | 正向后瞻 | 前面必须是 X |
| `(?<!X)` | 负向后瞻 | 前面不能是 X |

```java
// 前瞻：找到后面跟着 "元" 的数字
Pattern p1 = Pattern.compile("\\d+(?=元)");
Matcher m1 = p1.matcher("价格 100元，折扣 50元");
while (m1.find()) {
    System.out.println(m1.group());   // 100, 50 —— 匹配到数字但不吃"元"
}

// 负向前瞻：找到后面不是 "元" 的数字
Pattern p2 = Pattern.compile("\\d+(?!元)");
Matcher m2 = p2.matcher("编号 100元 和 200");
while (m2.find()) {
    System.out.println(m2.group());   // 00（100 里的）, 200
}

// 后瞻（JDK 7+，且必须是固定长度！）
Pattern p3 = Pattern.compile("(?<=¥)\\d+");
Matcher m3 = p3.matcher("¥100 和 ¥200");
while (m3.find()) {
    System.out.println(m3.group());   // 100, 200
}

// 负向后瞻：前面不是 ¥
Pattern p4 = Pattern.compile("(?<!¥)\\d+");
```

注意：后瞻在 Java 中要求固定长度（不能是 `.*` 这种变长），但 JDK 13+ 放宽了部分限制。

## 替换与分割

```java
String text = "apple, banana, cherry";

// replaceAll —— 替换所有匹配
String result = text.replaceAll("\\w+", "fruit");
System.out.println(result);     // fruit, fruit, fruit

// replaceFirst —— 只替换第一个
String first = text.replaceFirst("\\w+", "FRUIT");
System.out.println(first);      // FRUIT, banana, cherry

// 替换中引用捕获组 —— $1, $2
String phone = "010-8822";
String masked = phone.replaceAll("(\\d{3})-(\\d{4})", "$1-****");
System.out.println(masked);     // 010-****

// 在 Matcher 中使用 appendReplacement 做复杂替换
Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("user_123 score_456");
StringBuffer sb = new StringBuffer();
while (m.find()) {
    String replacement = "[" + m.group() + "]";
    m.appendReplacement(sb, replacement);
}
m.appendTail(sb);
System.out.println(sb);   // user_[123] score_[456]

// split —— 按正则分割
String csv = "a, b ,c , d";
String[] items = csv.split("\\s*,\\s*");   // [a, b, c, d]

// 限制分割次数
String data = "a:b:c:d";
String[] limited = data.split(":", 2);      // [a, b:c:d]
```

## 应用场景实战

### 场景一：表单校验

```java
public class ValidationUtil {
    // 手机号
    private static final Pattern MOBILE = 
        Pattern.compile("^1[3-9]\\d{9}$");
    
    // 邮箱
    private static final Pattern EMAIL = 
        Pattern.compile("^[\\w.-]+@[\\w-]+(\\.[\\w-]+)+$");
    
    // 身份证（18 位，简单校验）
    private static final Pattern ID_CARD = 
        Pattern.compile("^\\d{17}[\\dXx]$");
    
    // 强密码：8-20 位，至少含大小写字母和数字
    private static final Pattern STRONG_PWD = 
        Pattern.compile("^(?=.*[a-z])(?=.*[A-Z])(?=.*\\d)[\\w!@#$%^&*]{8,20}$");

    public static boolean isMobile(String s) {
        return s != null && MOBILE.matcher(s).matches();
    }

    public static boolean isEmail(String s) {
        return s != null && EMAIL.matcher(s).matches();
    }
}
```

### 场景二：日志解析

```java
public class LogParser {
    // 解析 Nginx 日志：[02/Aug/2026:14:30:00 +0800] "GET /api/users HTTP/1.1" 200 1234
    private static final Pattern LOG_PATTERN = Pattern.compile(
        "\\[(?<time>[^\\]]+)\\]\\s+\"(?<method>\\w+)\\s+(?<path>[^\\s]+)[^\"]*\"\\s+(?<status>\\d+)\\s+(?<size>\\d+)"
    );

    public static LogEntry parse(String line) {
        Matcher m = LOG_PATTERN.matcher(line);
        if (m.find()) {
            return new LogEntry(
                m.group("time"),
                m.group("method"),
                m.group("path"),
                Integer.parseInt(m.group("status")),
                Integer.parseInt(m.group("size"))
            );
        }
        return null;
    }
}
```

### 场景三：文本提取

```java
public class TextExtractor {
    // 提取文本中所有 URL
    private static final Pattern URL_PATTERN = 
        Pattern.compile("https?://[\\w./-]+");

    public static List<String> extractUrls(String text) {
        List<String> urls = new ArrayList<>();
        Matcher m = URL_PATTERN.matcher(text);
        while (m.find()) {
            urls.add(m.group());
        }
        return urls;
    }

    // 提取中文
    private static final Pattern CHINESE = 
        Pattern.compile("[\\u4e00-\\u9fa5]+");
    
    public static String extractChinese(String text) {
        StringBuilder sb = new StringBuilder();
        Matcher m = CHINESE.matcher(text);
        while (m.find()) {
            sb.append(m.group());
        }
        return sb.toString();
    }
}
```

### 场景四：驼峰与下划线互转

```java
public class NameConverter {
    // userName -> user_name
    public static String camelToSnake(String camel) {
        return camel.replaceAll("([A-Z])", "_$1").toLowerCase();
    }

    // user_name -> userName
    private static final Pattern SNAKE = Pattern.compile("_(\\w)");
    public static String snakeToCamel(String snake) {
        Matcher m = SNAKE.matcher(snake.toLowerCase());
        StringBuffer sb = new StringBuffer();
        while (m.find()) {
            m.appendReplacement(sb, m.group(1).toUpperCase());
        }
        m.appendTail(sb);
        return sb.toString();
    }
}
```

## 最佳实践与踩坑记录

### 性能

```java
// 正确：预编译 Pattern，复用
public class Patterns {
    public static final Pattern EMAIL = Pattern.compile("...");
}

// 错误：每次调用都编译一次 Pattern
boolean result = "test@example.com".matches("^[\\w.-]+@[\\w-]+...");
// String.matches 内部每次都会 Pattern.compile!
```

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| `\d` 在代码中不生效 | Java 字符串中 `\` 需要写成 `\\` | `Pattern.compile("\\d+")` |
| matches() 返回 false | matches() 要求完全匹配（隐含 `^...$`） | 用 `find()` 或加 `.*` |
| `find()` 只匹配一次就不动了 | Matcher 有内部状态，find() 是迭代器 | 用 while (m.find()) 循环 |
| 正则导致 CPU 100% | 灾难性回溯 | 用占有量词、减少嵌套量词、限制输入长度 |
| 匹配中文无效 | 字节/字符编码不一致 | 用 `[\\u4e00-\\u9fa5]` |

### 关键建议

1. **预编译 Pattern**：Pattern 的编译开销不低，静态常量是最佳实践
2. **matches vs find**：`matches()` = 整个字符串匹配（自带 `^...$`），`find()` = 子串匹配
3. **字符串不需要正则**：`indexOf`、`startsWith`、`endsWith` 比正则快 10 倍以上
4. **不信任用户输入构造的正则**：`Pattern.compile(userInput)` 可能被注入（ReDoS 攻击），对用户输入做好长度和内容限制
5. **考虑用 Guava / Apache Commons 的工具类**：`CharMatcher`、`Strings` 等对常见场景封装得更好

## 总结

- `Pattern` 预编译后复用，`Matcher` 是迭代器模式（`find()` 循环）
- Java 字符串中正则的 `\` 必须写成 `\\`（转义两次）
- `matches()` 要求全文匹配，`find()` 查找子串——多数场景用 `find()`
- 捕获组 `(...)` 用 `group(n)` 提取，具名组 `(?<name>...)` 用 `group("name")` 可读性更好
- 前瞻后瞻是零宽度断言，不消耗字符；注意后瞻在 Java 中的固定长度限制
- 避免灾难性回溯：限制输入长度、用占有量词、减少嵌套量词
