## 概述

Java 的日期时间 API 经历了两个时代：

| 时代 | API | 特点 |
|------|-----|------|
| JDK 1.0 ~ 1.7 | `Date`、`Calendar`、`SimpleDateFormat` | 可变对象、线程不安全、设计混乱、月份从 0 开始 |
| JDK 8+ | `java.time`（JSR-310） | 不可变对象、线程安全、清晰分离日期/时间/时区、流畅 API |

现在写新代码应该只使用 `java.time` 包。旧版 API 的类只在与遗留系统交互时才需要了解。

## 旧版 API：Date 与 Calendar

```java
import java.util.Date;
import java.util.Calendar;
import java.text.SimpleDateFormat;

// Date —— 实际上存储的是时间戳（毫秒），toString() 才显示成日期
Date now = new Date();
System.out.println(now);   // Tue Aug 12 15:30:00 CST 2026

// Calendar —— 可变对象，月份从 0 开始（0 代表一月）
Calendar cal = Calendar.getInstance();
cal.set(2026, Calendar.AUGUST, 12);    // 注意：月份用常量
int year = cal.get(Calendar.YEAR);
int month = cal.get(Calendar.MONTH);   // 0-11
int day = cal.get(Calendar.DAY_OF_MONTH);

// SimpleDateFormat —— 线程不安全！
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
String str = sdf.format(now);          // "2026-08-12 15:30:00"
Date parsed = sdf.parse("2026-08-12"); // 解析字符串
```

旧 API 的致命问题：`SimpleDateFormat` 内部有可变状态——多线程共用一个实例会出乱码或错位。`Date` 本身是可变的，setter 会修改已有对象。

## Java 8 时间 API 核心类

`java.time` 包的设计遵循精确定义：

| 类 | 包含内容 | 示例 |
|----|----------|------|
| `LocalDate` | 日期（年/月/日） | 2026-08-12 |
| `LocalTime` | 时间（时/分/秒/纳秒） | 15:30:00.123456789 |
| `LocalDateTime` | 日期 + 时间 | 2026-08-12T15:30:00 |
| `Instant` | UTC 时间线上的一个点（时间戳） | 2026-08-12T07:30:00Z |
| `ZonedDateTime` | 日期时间 + 时区 | 2026-08-12T15:30:00+08:00[Asia/Shanghai] |
| `OffsetDateTime` | 日期时间 + UTC 偏移 | 2026-08-12T15:30:00+08:00 |
| `Duration` | 时间量（纳秒精度） | PT1H30M（1 小时 30 分） |
| `Period` | 日期量（年/月/日） | P1Y2M3D（1 年 2 月 3 天） |
| `ZoneId` | 时区标识 | Asia/Shanghai |

所有类都是**不可变的（immutable）**——运算返回新对象，线程安全。

## LocalDate / LocalTime / LocalDateTime

```java
import java.time.*;

// 获取当前日期/时间
LocalDate today     = LocalDate.now();           // 2026-08-12
LocalTime now       = LocalTime.now();           // 15:30:00.123
LocalDateTime nowDT = LocalDateTime.now();       // 2026-08-12T15:30:00.123

// 指定值创建
LocalDate date    = LocalDate.of(2026, 8, 12);
LocalTime time    = LocalTime.of(15, 30, 0);
LocalDateTime dt  = LocalDateTime.of(2026, 8, 12, 15, 30, 0);
// 或组合
LocalDateTime dt2 = LocalDateTime.of(date, time);

// 解析字符串
LocalDate parsedDate = LocalDate.parse("2026-08-12");
LocalTime parsedTime = LocalTime.parse("15:30:00");
LocalDateTime parsedDT = LocalDateTime.parse("2026-08-12T15:30:00");

// 运算 —— 返回新对象，原对象不变
LocalDate tomorrow  = today.plusDays(1);
LocalDate lastWeek  = today.minusWeeks(1);
LocalDate nextMonth = today.plusMonths(1);
LocalDate sameDayNextYear = today.plusYears(1);

// withXXX 方法 —— 修改某个字段
LocalDate firstOfMonth = today.withDayOfMonth(1);
LocalDate endOfYear    = today.withDayOfYear(today.lengthOfYear());

// 获取字段值
int year  = today.getYear();          // 2026
Month month = today.getMonth();       // AUGUST
int day   = today.getDayOfMonth();    // 12
DayOfWeek dow = today.getDayOfWeek(); // TUESDAY
boolean leap = today.isLeapYear();    // false

// 比较
boolean after  = tomorrow.isAfter(today);
boolean before = lastWeek.isBefore(today);
boolean equal  = date1.isEqual(date2);
```

### LocalTime 专项操作

```java
LocalTime t = LocalTime.of(15, 30, 45);

t.getHour();        // 15
t.getMinute();      // 30
t.getSecond();      // 45
t.getNano();        // 0

LocalTime plusHour = t.plusHours(2);      // 17:30:45
LocalTime truncated = t.truncatedTo(ChronoUnit.MINUTES);  // 15:30

// 计算时间差（转换成秒数比较）
long seconds = t.toSecondOfDay();          // 55845（15*3600 + 30*60 + 45）
```

## Instant 与时间戳

`Instant` 代表 UTC 时间线上的一个精确时刻，内部存储为"从 1970-01-01T00:00:00Z（Unix 纪元）开始的秒数 + 纳秒调整"。

```java
import java.time.Instant;

Instant now = Instant.now();                   // UTC 时间
System.out.println(now);                       // 2026-08-12T07:30:00.123Z

// 从时间戳创建
Instant fromEpochSecond = Instant.ofEpochSecond(1_700_000_000L);
Instant fromEpochMilli  = Instant.ofEpochMilli(System.currentTimeMillis());

// 时间戳值
long epochSecond = now.getEpochSecond();       // 秒
long epochMilli  = now.toEpochMilli();         // 毫秒

// Instant 的运算
Instant later   = now.plusSeconds(3600);
Instant earlier = now.minusMillis(5000);
```

Instant 适合存储"绝对时间点"——数据库的 TIMESTAMP 列、事件发生时间、分布式系统的排序依据。

## ZonedDateTime 与时区

```java
import java.time.ZoneId;
import java.time.ZonedDateTime;
import java.util.Set;

// 所有可用时区
Set<String> zones = ZoneId.getAvailableZoneIds();
// ZoneId.of("Asia/Shanghai"), ZoneId.of("America/New_York"), etc.

// 从 LocalDateTime + 时区创建
LocalDateTime local = LocalDateTime.of(2026, 8, 12, 15, 30);
ZoneId shanghai = ZoneId.of("Asia/Shanghai");
ZonedDateTime zdt = ZonedDateTime.of(local, shanghai);
System.out.println(zdt);
// 2026-08-12T15:30+08:00[Asia/Shanghai]

// 当前时间的 ZonedDateTime
ZonedDateTime now = ZonedDateTime.now();             // 系统默认时区
ZonedDateTime nyc  = ZonedDateTime.now(ZoneId.of("America/New_York"));

// 时区转换
ZonedDateTime shanghaiTime = ZonedDateTime.now(ZoneId.of("Asia/Shanghai"));
ZonedDateTime tokyoTime   = shanghaiTime.withZoneSameInstant(ZoneId.of("Asia/Tokyo"));
// 瞬间不变，表示方式变了

// OffsetDateTime —— 比 ZonedDateTime 简单，只保留偏移量
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
OffsetDateTime odt = OffsetDateTime.of(local, ZoneOffset.ofHours(8));
```

`ZonedDateTime` vs `OffsetDateTime`：ZonedDateTime 记录了完整的时区规则（含夏令时），OffsetDateTime 只记录偏移量。数据库通常用 OffsetDateTime 或 Instant。

## Duration 与 Period

```java
// Duration —— 基于时间的量（小时/分钟/秒/纳秒）
Duration duration = Duration.ofHours(2).plusMinutes(30);
System.out.println(duration);          // PT2H30M

Duration between = Duration.between(
    LocalTime.of(9, 0),
    LocalTime.of(17, 30)
);
System.out.println(between);           // PT8H30M
System.out.println(between.toHours()); // 8
System.out.println(between.toMinutes()); // 510

// Period —— 基于日期的量（年/月/日）
Period period = Period.of(1, 2, 15);   // 1 年 2 月 15 天
System.out.println(period);            // P1Y2M15D

Period dateBetween = Period.between(
    LocalDate.of(2025, 1, 1),
    LocalDate.of(2026, 8, 12)
);
System.out.println(dateBetween.getYears());   // 1
System.out.println(dateBetween.getMonths());  // 7
System.out.println(dateBetween.getDays());    // 11
```

使用原则：**时间差用 Duration，日期差用 Period**。不要用 Period 算小时，也不要用 Duration 算月份——Period 不关心夏令时和闰秒，只按日历算。

## DateTimeFormatter

```java
import java.time.format.DateTimeFormatter;
import java.time.format.FormatStyle;
import java.util.Locale;

// 预定义
DateTimeFormatter iso       = DateTimeFormatter.ISO_LOCAL_DATE;
DateTimeFormatter isoDt     = DateTimeFormatter.ISO_LOCAL_DATE_TIME;

// 自定义
DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String str = LocalDateTime.now().format(fmt);

// 解析
LocalDateTime parsed = LocalDateTime.parse("2026-08-12 15:30:00", fmt);

// 本地化
DateTimeFormatter cnFormatter = DateTimeFormatter
    .ofLocalizedDateTime(FormatStyle.MEDIUM)
    .withLocale(Locale.CHINA);
System.out.println(LocalDateTime.now().format(cnFormatter));
// 2026年8月12日 15:30:00

// 常用 pattern
DateTimeFormatter f1 = DateTimeFormatter.ofPattern("yyyy-MM-dd");          // 2026-08-12
DateTimeFormatter f2 = DateTimeFormatter.ofPattern("yyyy/MM/dd HH:mm");    // 2026/08/12 15:30
DateTimeFormatter f3 = DateTimeFormatter.ofPattern("MMM dd, yyyy", Locale.US); // Aug 12, 2026
```

与 `SimpleDateFormat` 不同，`DateTimeFormatter` 是线程安全的——可以作为常量共享。

## 时间转换与互操作

```java
// LocalDateTime <-> Instant（需要时区）
ZoneId zone = ZoneId.systemDefault();
Instant instant = LocalDateTime.now().atZone(zone).toInstant();
LocalDateTime local = LocalDateTime.ofInstant(instant, zone);

// LocalDate -> LocalDateTime
LocalDateTime startOfDay = LocalDate.now().atStartOfDay();   // 00:00
LocalDateTime endOfDay   = LocalDate.now().atTime(23, 59, 59);

// ZonedDateTime <-> Instant
ZonedDateTime zdt = instant.atZone(zone);
Instant back = zdt.toInstant();

// Date <-> Instant（新旧 API 互转）
import java.util.Date;
Date legacy = new Date();
Instant fromLegacy = legacy.toInstant();    // Date -> Instant
Date backToLegacy = Date.from(instant);     // Instant -> Date

// Calendar <-> ZonedDateTime
Calendar legacyCal = Calendar.getInstance();
ZonedDateTime fromCalendar = legacyCal.toInstant().atZone(zone);
Calendar backToCalendar = GregorianCalendar.from(zdt);

// 时间戳（毫秒）
long timestamp = System.currentTimeMillis();
Instant fromTs = Instant.ofEpochMilli(timestamp);
LocalDateTime fromTsLocal = LocalDateTime.ofInstant(fromTs, zone);
```

## 应用场景实战

### 场景一：年龄计算

```java
public static int calculateAge(LocalDate birthDate) {
    LocalDate today = LocalDate.now();
    int age = today.getYear() - birthDate.getYear();
    // 如果今年生日还没到，减一岁
    if (today.getDayOfYear() < birthDate.getDayOfYear()) {
        age--;
    }
    return age;
}

int age = calculateAge(LocalDate.of(1990, 6, 15));
```

### 场景二：工作日判断

```java
import java.time.DayOfWeek;
import java.util.EnumSet;

public class WorkDayUtil {
    private static final EnumSet<DayOfWeek> WEEKEND = 
        EnumSet.of(DayOfWeek.SATURDAY, DayOfWeek.SUNDAY);

    public static boolean isWorkDay(LocalDate date) {
        return !WEEKEND.contains(date.getDayOfWeek());
    }

    // 计算两日期之间的工作日数
    public static long workDaysBetween(LocalDate start, LocalDate end) {
        return start.datesUntil(end.plusDays(1))
            .filter(d -> isWorkDay(d))
            .count();
    }
}
```

### 场景三：过期判断

```java
public class ExpiryCheck {
    public static boolean isExpired(LocalDateTime targetTime, Duration ttl) {
        return Duration.between(targetTime, LocalDateTime.now())
                       .compareTo(ttl) > 0;
    }

    // 用法：验证码 5 分钟有效
    LocalDateTime sentTime = LocalDateTime.now().minusMinutes(6);
    boolean expired = isExpired(sentTime, Duration.ofMinutes(5));  // true
}
```

### 场景四：生成报表时间范围

```java
public class TimeRange {
    // 本月第一天 00:00:00
    public static LocalDateTime monthStart() {
        return LocalDate.now()
            .withDayOfMonth(1)
            .atStartOfDay();
    }

    // 本月最后一天 23:59:59
    public static LocalDateTime monthEnd() {
        return LocalDate.now()
            .withDayOfMonth(LocalDate.now().lengthOfMonth())
            .atTime(23, 59, 59);
    }

    // 最近 7 天
    public static LocalDateTime last7Days() {
        return LocalDateTime.now().minusDays(7);
    }
}
```

### 场景五：跨时区订单创建

```java
public class OrderTimestamp {
    // 订单创建时间统一存为 UTC 时间戳
    public static long orderTimestamp() {
        return Instant.now().toEpochMilli();
    }

    // 展示时转用户时区
    public static String formatForUser(long epochMilli, String zoneId) {
        Instant instant = Instant.ofEpochMilli(epochMilli);
        ZonedDateTime userTime = instant.atZone(ZoneId.of(zoneId));
        DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
        return userTime.format(fmt);
    }
}
```

## 最佳实践与踩坑记录

### 选择原则

| 场景 | 推荐类 |
|------|--------|
| 生日、纪念日（纯日期） | `LocalDate` |
| 闹钟、课程表（纯时间） | `LocalTime` |
| 会议时间（无时区） | `LocalDateTime` |
| 数据库时间戳、事件时间 | `Instant` |
| 跨时区展示、日历应用 | `ZonedDateTime` |
| API 传输（ISO 8601） | `Instant` 或带偏移的字符串 |

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| `SimpleDateFormat` 多线程乱码 | 内部状态可变 | 用 `DateTimeFormatter`（不可变）或在每次使用时新建 |
| 月份差 1 个月 | `Calendar.MONTH` 从 0 开始 | 用 `LocalDate`，月份用 1-12 |
| 时区转换后时间不对 | 用 `LocalDateTime` 做了时区运算 | 用 `ZonedDateTime` 或 `Instant` 做时区间转换 |
| 两日期差的天数不对 | `Period.between` 的天数域只算差额（非总天数） | 用 `ChronoUnit.DAYS.between(start, end)` |
| `parse` 失败 | pattern 和输入不匹配 | 检查 pattern 字符大小写（MM=月, mm=分） |

### 关键建议

```java
// 存储：一律用 Instant 或 UTC 时间戳
// 展示：在展示层转用户时区
// 计算：用 Duration / Period / ChronoUnit，不要手动算毫秒

// 正确算日期差（总天数）
long totalDays = ChronoUnit.DAYS.between(startDate, endDate);
long totalHours = ChronoUnit.HOURS.between(startTime, endTime);

// 不要这样算
int days = period.getDays();   // 只是差额的"天"部分，不含年和月
```

## 总结

- 新版 `java.time` 包不可变且线程安全，应完全替代旧的 `Date`/`Calendar`/`SimpleDateFormat`
- `LocalDate` / `LocalTime` / `LocalDateTime` 处理无时区场景，`Instant` 存储绝对时间点
- 时区操作用 `ZonedDateTime`，时间计算用 `Duration`（时间）和 `Period`（日期）
- `DateTimeFormatter` 线程安全，可作为常量共享；pattern 区分大小写（MM vs mm）
- 存储用 UTC/时间戳，展示层转用户时区——这是时间处理的第一原则
