## 概述

反射是 Java 的"镜子"——让程序在运行时检查自身结构并操作对象。通过反射，你可以在不知道具体类型的情况下创建对象、调用方法、访问字段。它是 Spring IOC、JUnit 测试、ORM 框架、序列化库的基石。

核心 API 位于 `java.lang.reflect` 包：

```
Class<T>        —— 类的元数据入口
Constructor<T>  —— 构造方法
Method          —— 普通方法
Field           —— 字段（成员变量）
Modifier        —— 修饰符解析（public/static/final 等）
Parameter       —— 方法参数信息（JDK 8+）
```

## Class 对象

`Class` 是反射的入口——每个加载的类在 JVM 中有一个唯一的 `Class` 对象：

```java
// 四种获取 Class 的方式
// 1. 类名.class（最常用，编译期安全）
Class<String> c1 = String.class;

// 2. 对象.getClass()
String s = "hello";
Class<?> c2 = s.getClass();       // 运行时类型

// 3. Class.forName() —— 动态加载（类名来自配置/数据库）
Class<?> c3 = Class.forName("java.lang.String");

// 4. 类加载器
Class<?> c4 = ClassLoader.getSystemClassLoader().loadClass("java.lang.String");
```

### Class 的核心方法

```java
Class<?> clazz = User.class;

// 基本信息
String name = clazz.getName();           // "com.example.User"
String simple  = clazz.getSimpleName();  // "User"
Package pkg    = clazz.getPackage();     // com.example
int modifiers  = clazz.getModifiers();   // 修饰符位掩码

// 继承关系
Class<?> superClass  = clazz.getSuperclass();        // 父类
Class<?>[] interfaces = clazz.getInterfaces();        // 实现的接口

// 判断
boolean isInterface   = clazz.isInterface();
boolean isEnum        = clazz.isEnum();
boolean isAnnotation  = clazz.isAnnotation();
boolean isArray       = clazz.isArray();
boolean isAssignable  = clazz.isAssignableFrom(AdminUser.class);  // 是否是其父类

// 创建实例（无参构造）
User user = (User) clazz.getDeclaredConstructor().newInstance();
```

## Constructor —— 反射创建对象

```java
Class<User> clazz = User.class;

// 获取所有 public 构造器
Constructor<?>[] publicCtors = clazz.getConstructors();

// 获取所有构造器（含 private）
Constructor<?>[] allCtors = clazz.getDeclaredConstructors();

// 获取指定参数类型的构造器
Constructor<User> ctor = clazz.getDeclaredConstructor(String.class, int.class);

// 创建实例
User u1 = clazz.getDeclaredConstructor().newInstance();           // 无参
User u2 = clazz.getDeclaredConstructor(String.class, int.class)
                .newInstance("张三", 25);                          // 有参

// 访问 private 构造器（需要 setAccessible）
Constructor<User> privateCtor = clazz.getDeclaredConstructor(String.class);
privateCtor.setAccessible(true);  // 突破访问控制
User u3 = privateCtor.newInstance("secret");

// 构造器信息
String ctorName = ctor.getName();                    // 类名
int paramCount = ctor.getParameterCount();           // 参数数量
Class<?>[] paramTypes = ctor.getParameterTypes();    // 参数类型数组
```

## Method —— 反射调用方法

```java
Class<User> clazz = User.class;
User user = new User("张三", 25);

// 获取所有 public 方法（含继承的）
Method[] publicMethods = clazz.getMethods();

// 获取本类声明的所有方法（含 private，不含继承的）
Method[] declaredMethods = clazz.getDeclaredMethods();

// 获取指定方法（方法名 + 参数类型）
Method getName = clazz.getMethod("getName");          // 无参
Method setName = clazz.getMethod("setName", String.class);  // 有参

// 调用方法
String name = (String) getName.invoke(user);           // user.getName()
setName.invoke(user, "李四");                           // user.setName("李四")

// 调用 private 方法
Method privateMethod = clazz.getDeclaredMethod("encrypt", String.class);
privateMethod.setAccessible(true);
String result = (String) privateMethod.invoke(user, "data");

// 调用静态方法
Method staticMethod = clazz.getMethod("parse", String.class);
User parsed = (User) staticMethod.invoke(null, "张三");  // obj 传 null

// 方法信息
String mName = getName.getName();                     // "getName"
Class<?> returnType = getName.getReturnType();        // String.class
Class<?>[] paramTypes = getName.getParameterTypes();  // 参数类型
int modifiers = getName.getModifiers();               // 修饰符
```

## Field —— 反射访问字段

```java
Class<User> clazz = User.class;
User user = new User("张三", 25);

// 获取所有 public 字段（含继承的）
Field[] publicFields = clazz.getFields();

// 获取本类声明的所有字段（含 private）
Field[] declaredFields = clazz.getDeclaredFields();

// 获取指定字段
Field nameField = clazz.getDeclaredField("name");
nameField.setAccessible(true);  // private 字段必须

// 读取字段值
String name = (String) nameField.get(user);

// 设置字段值
nameField.set(user, "李四");

// 读取/设置静态字段（obj 传 null）
Field constField = clazz.getDeclaredField("MAX_AGE");
constField.setAccessible(true);
int maxAge = (int) constField.get(null);   // 静态字段 obj=null

// 字段信息
String fName = nameField.getName();                    // "name"
Class<?> fType = nameField.getType();                  // String.class
int modifiers = nameField.getModifiers();              // private
```

## Modifier —— 检查修饰符

```java
import java.lang.reflect.Modifier;

Method method = clazz.getMethod("doSomething");
int mod = method.getModifiers();

// 检查修饰符
boolean isPublic    = Modifier.isPublic(mod);
boolean isPrivate   = Modifier.isPrivate(mod);
boolean isStatic    = Modifier.isStatic(mod);
boolean isFinal     = Modifier.isFinal(mod);
boolean isAbstract  = Modifier.isAbstract(mod);
boolean isSynchronized = Modifier.isSynchronized(mod);
boolean isNative    = Modifier.isNative(mod);

// 转为字符串
String modStr = Modifier.toString(mod);  // "public static final"

// 修饰符位掩码解码
// PUBLIC(0x01) | STATIC(0x08) | FINAL(0x10) → 0x19 → "public static final"
```

## 泛型反射

由于类型擦除，泛型信息在运行时大部分丢失——但声明在类/方法签名上的可以通过反射获取：

```java
// 1. 获取类声明的泛型参数
public class Repository<T, ID> { }

// 直接获取：Repository.class.getTypeParameters() → [T, ID]
// 但获取不到具体类型（运行时 T 被擦除为 Object）

// 2. 获取具体子类的泛型参数（关键技巧！）
public class UserRepository extends Repository<User, Long> { }

Type superType = UserRepository.class.getGenericSuperclass();
if (superType instanceof ParameterizedType) {
    ParameterizedType pt = (ParameterizedType) superType;
    Type[] args = pt.getActualTypeArguments();
    System.out.println(args[0]);  // class com.example.User
    System.out.println(args[1]);  // class java.lang.Long
}

// 3. 获取泛型字段
class Container {
    List<String> items;
}
Field field = Container.class.getDeclaredField("items");
Type genericType = field.getGenericType();
if (genericType instanceof ParameterizedType) {
    Type[] args = ((ParameterizedType) genericType).getActualTypeArguments();
    System.out.println(args[0]);  // class java.lang.String
}

// 4. 获取泛型方法参数/返回值
public <T extends Comparable<T>> T max(List<T> list) { ... }
Method method = ...;
Type[] paramTypes = method.getGenericParameterTypes();  // [List<T>]
Type returnType = method.getGenericReturnType();        // T
TypeVariable<?>[] typeParams = method.getTypeParameters(); // [T extends Comparable<T>]
```

## 注解反射

```java
// 检查类上的注解
if (clazz.isAnnotationPresent(Table.class)) {
    Table table = clazz.getAnnotation(Table.class);
    System.out.println(table.name());
}

// 检查方法上的注解
Method method = clazz.getMethod("findById");
if (method.isAnnotationPresent(Cacheable.class)) {
    Cacheable cache = method.getAnnotation(Cacheable.class);
    System.out.println(cache.ttl());
}

// 检查字段上的注解
Field field = clazz.getDeclaredField("name");
Column col = field.getAnnotation(Column.class);
System.out.println(col.name() + " " + col.nullable());

// 获取所有注解
Annotation[] annotations = clazz.getAnnotations();             // 含 @Inherited
Annotation[] declared = clazz.getDeclaredAnnotations();        // 仅本类声明的

// 重复注解（JDK 8+）
Role[] roles = clazz.getAnnotationsByType(Role.class);

// 检查注解参数上的注解
Method method = clazz.getMethod("create", User.class);
Parameter[] params = method.getParameters();
for (Parameter param : params) {
    if (param.isAnnotationPresent(NotNull.class)) {
        // 参数有 @NotNull
    }
}
```

## 反射性能与优化

反射比直接调用慢（原因：类型检查、装箱拆箱、安全检查、数组遍历）：

```java
// 性能对比（近似）
// 直接调用:    ~1ns
// 反射(getMethod+invoke): ~50ns (JIT 优化后)
// setAccessible 前: ~100ns

// 优化策略：
// 1. 缓存 Method/Field/Constructor 对象 —— 最大收益
public class ReflectionCache {
    private static final Map<String, Method> cache = new ConcurrentHashMap<>();

    public static Method getCachedMethod(Class<?> clazz, String name, Class<?>... params) {
        String key = clazz.getName() + "." + name;
        return cache.computeIfAbsent(key, k -> {
            try { return clazz.getMethod(name, params); }
            catch (NoSuchMethodException e) { throw new RuntimeException(e); }
        });
    }
}

// 2. setAccessible(true) —— 跳过访问检查
// 3. 用 MethodHandle (JDK 7+) 替代反射（更接近直接调用）
// 4. 用 LambdaMetafactory (JDK 8+) —— 生成接近原生性能的调用
```

## setAccessible 与模块化限制

JDK 9+ 模块化系统对反射做了限制——访问内部 API 需要显式开放：

```bash
# 允许代码通过反射访问 java.base 的 private 成员
--add-opens java.base/java.lang=ALL-UNNAMED

# 允许通过反射访问指定包
--add-opens com.example.module/com.example.internal=ALL-UNNAMED
```

```java
// Spring 等框架在启动时会大量调用 setAccessible(true)
// JDK 17+ 默认会发出警告（可通过 --add-opens 消除）
// JDK 24+ 默认禁止非法反射访问（强封装）
```

## 应用场景实战

### 场景一：Bean 属性拷贝

```java
public class BeanUtils {
    public static <T> T copyProperties(Object source, Class<T> targetClass) {
        try {
            T target = targetClass.getDeclaredConstructor().newInstance();
            for (Field sourceField : source.getClass().getDeclaredFields()) {
                sourceField.setAccessible(true);
                try {
                    Field targetField = targetClass.getDeclaredField(sourceField.getName());
                    targetField.setAccessible(true);
                    targetField.set(target, sourceField.get(source));
                } catch (NoSuchFieldException e) {
                    // 目标没有这个字段，跳过
                }
            }
            return target;
        } catch (Exception e) {
            throw new RuntimeException("拷贝失败", e);
        }
    }
}
```

### 场景二：通用 ORM 结果映射

```java
public class RowMapper {
    public static <T> T mapRow(ResultSet rs, Class<T> clazz) throws Exception {
        T instance = clazz.getDeclaredConstructor().newInstance();
        ResultSetMetaData meta = rs.getMetaData();

        for (int i = 1; i <= meta.getColumnCount(); i++) {
            String columnName = meta.getColumnLabel(i);  // 数据库列名
            try {
                Field field = clazz.getDeclaredField(camelCase(columnName));
                field.setAccessible(true);
                field.set(instance, rs.getObject(i));
            } catch (NoSuchFieldException e) {
                // 数据库有多余列，忽略
            }
        }
        return instance;
    }

    private static String camelCase(String snake) {
        // user_name → userName
        return Pattern.compile("_(\\w)")
            .matcher(snake.toLowerCase())
            .replaceAll(m -> m.group(1).toUpperCase());
    }
}
```

### 场景三：配置文件注入

```java
public class ConfigInjector {
    public static void inject(Object target, Properties props) {
        String prefix = target.getClass().getSimpleName().toLowerCase() + ".";
        for (Field field : target.getClass().getDeclaredFields()) {
            if (field.isAnnotationPresent(ConfigValue.class)) {
                ConfigValue cv = field.getAnnotation(ConfigValue.class);
                String key = prefix + cv.value();
                String value = props.getProperty(key);
                if (value != null) {
                    field.setAccessible(true);
                    try {
                        // 类型转换
                        Object converted = convert(field.getType(), value);
                        field.set(target, converted);
                    } catch (Exception e) {
                        throw new RuntimeException("注入失败: " + field.getName(), e);
                    }
                }
            }
        }
    }

    private static Object convert(Class<?> type, String value) {
        if (type == String.class) return value;
        if (type == int.class || type == Integer.class) return Integer.parseInt(value);
        if (type == long.class || type == Long.class) return Long.parseLong(value);
        if (type == boolean.class || type == Boolean.class) return Boolean.parseBoolean(value);
        throw new IllegalArgumentException("不支持的类型: " + type);
    }
}
```

### 场景四：获取具体泛型参数

```java
// TypeToken 模式——Gson/Jackson 都用这个技巧
public abstract class TypeReference<T> {
    private final Type type;

    protected TypeReference() {
        Type superClass = getClass().getGenericSuperclass();
        this.type = ((ParameterizedType) superClass).getActualTypeArguments()[0];
    }

    public Type getType() { return type; }
}

// 用法
TypeReference<List<User>> ref = new TypeReference<List<User>>() {};
System.out.println(ref.getType());  // java.util.List<com.example.User>
```

## 最佳实践与踩坑记录

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| `ClassNotFoundException` | 类名拼写错误或不在 classpath | 检查全限定名和 classpath |
| `NoSuchMethodException` | 方法名或参数类型不匹配 | 用 `getDeclaredMethods()` 遍历确认 |
| `IllegalAccessException` | 访问了 private 成员没 setAccessible | 调用 `setAccessible(true)` |
| 反射调用比直接调用慢很多 | 安全检查 + 装箱 + 数组包装 | 缓存 Method/Field；考虑 MethodHandle |
| JDK 17+ 反射警告 | 模块化限制增强 | `--add-opens` 开放访问 |
| 泛型反射获取不到实际类型 | 类型擦除 | 通过匿名子类保留泛型信息（TypeToken 模式） |

### 获取字段/方法的规则

```
getMethods()         → 所有 public 方法（含继承的）
getDeclaredMethods() → 本类声明的所有方法（含 private，不含继承的）
getFields()          → 所有 public 字段（含继承的）
getDeclaredFields()  → 本类声明的所有字段（含 private，不含继承的）

getMethod(name, types)       → public 方法
getDeclaredMethod(name, types) → 本类声明的方法（含 private）
getField(name)               → public 字段
getDeclaredField(name)       → 本类声明的字段（含 private）
```

### 性能建议

```
1. Class.forName() 开销大 → 缓存 Class 对象
2. getMethod/getField 每次都有查找开销 → 缓存 Method/Field
3. setAccessible(true) 每次调用都有检查 → 一次设置，复用
4. Method.invoke() 开销大 → 考虑 MethodHandle (JDK 7+) 或 LambdaMetafactory (JDK 8+)
5. 热点路径避免反射 → 反射生成字节码缓存（如 ReflectASM）
```

## 总结

- `Class` 是反射入口，四种获取方式：`.class`、`getClass()`、`Class.forName()`、`ClassLoader.loadClass()`
- `Constructor.newInstance()` 创建对象，`Method.invoke()` 调用方法，`Field.get/set()` 读写字段
- `setAccessible(true)` 突破 private 限制，JDK 9+ 需 `--add-opens`
- 泛型反射通过匿名子类保留类型信息（TypeToken 模式），声明在签名上的可通过 `ParameterizedType` 获取
- 注解反射：`isAnnotationPresent()` → `getAnnotation()` → 读取属性值
- 性能关键：缓存 Method/Field 对象 + setAccessible + 避免重复 getMethod/getField
