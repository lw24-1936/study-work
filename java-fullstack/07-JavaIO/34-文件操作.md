## 概述

Java 有两套文件操作 API：

| API | 包 | 引入 | 特点 |
|-----|-----|------|------|
| `File` | `java.io` | JDK 1.0 | 路径操作 + 元数据，无读写方法 |
| `Path` + `Files` | `java.nio.file` | JDK 7 (NIO.2) | 现代化、完整的文件 API |

原则：新代码一律用 `Path` / `Files`，`File` 只在与旧 API 互操作时才用。

## File 类（旧 API）

`File` 代表文件或目录的路径，不保证文件实际存在：

```java
File file = new File("/home/user/data.txt");
File dir = new File("/home/user");
File relative = new File("config/app.properties");

// 基本信息
String name = file.getName();            // "data.txt"
String path = file.getPath();            // 构造时传入的路径
String absPath = file.getAbsolutePath(); // 完整绝对路径
String parent = file.getParent();        // "/home/user"

// 是否存在、类型
boolean exists = file.exists();
boolean isFile = file.isFile();
boolean isDir = file.isDirectory();
boolean hidden = file.isHidden();

// 读写权限
boolean canRead = file.canRead();
boolean canWrite = file.canWrite();
boolean canExec = file.canExecute();

// 文件信息
long length = file.length();             // 字节数
long modified = file.lastModified();     // 最后修改时间戳

// 创建操作
boolean created = file.createNewFile();  // 创建文件
boolean mkdirOk = file.mkdir();          // 创建单层目录
boolean mkdirsOk = file.mkdirs();        // 创建多层目录

// 删除
boolean deleted = file.delete();         // 立即删除
file.deleteOnExit();                     // JVM 退出时删除

// 目录列表
String[] names = dir.list();             // 文件名数组
File[] files = dir.listFiles();          // File 对象数组
File[] filtered = dir.listFiles((d, name) -> name.endsWith(".txt"));

// 转 Path（与新 API 互操作）
Path path = file.toPath();
```

### File 的缺陷

```java
// 1. 错误信息缺失——返回 false 不知道原因
boolean ok = file.delete();
if (!ok) {
    // 是权限不够？文件不存在？被占用？不知道！
}

// 2. 没有读写方法——File 不能直接读文件内容
// 必须配合 FileInputStream / FileReader 使用

// 3. 路径处理弱——无法轻松 resolve、normalize

// 4. 符号链接处理不透明
```

## Path 与 Paths（新 API）

`Path` 是 NIO.2 的路径抽象——比 `File` 更强大、更安全、语义更清晰：

```java
import java.nio.file.Path;
import java.nio.file.Paths;

// 创建 Path —— 不要求文件实际存在
Path p1 = Paths.get("/home/user/data.txt");
Path p2 = Paths.get("/home", "user", "data.txt");   // 拼接
Path p3 = Path.of("/home/user/data.txt");            // JDK 11+ 更简洁

// 路径信息
Path fileName = p1.getFileName();       // data.txt
Path parent = p1.getParent();           // /home/user
Path root = p1.getRoot();               // /
int nameCount = p1.getNameCount();      // 路径组件数
Path name = p1.getName(1);              // user（索引从 0 开始）

// 路径操作
Path resolved = p1.resolve("subdir");   // 拼接子路径
Path sibling = p1.resolveSibling("other.txt"); // 兄弟路径
Path relative = p1.relativize(Paths.get("/home/user/other.txt")); // 相对路径
Path normalized = p1.normalize();       // 消除 . 和 ..
Path absolute = p1.toAbsolutePath();    // 转绝对路径
Path real = p1.toRealPath();            // 解析符号链接（文件必须存在）

// 与 File 互操作
File file = p1.toFile();
Path back = file.toPath();

// 比较
boolean equals = p1.equals(p2);
boolean starts = p1.startsWith("/home");
boolean ends = p1.endsWith("data.txt");
```

## Files 工具类

`Files` 是文件操作的"一站式工具类"——创建、复制、移动、删除、读写、属性全包：

```java
import java.nio.file.Files;
import java.nio.file.StandardCopyOption;

Path source = Path.of("source.txt");
Path target = Path.of("target.txt");

// 存在性检查
boolean exists = Files.exists(source);
boolean notExists = Files.notExists(source);
boolean isDir = Files.isDirectory(source);
boolean isRegular = Files.isRegularFile(source);
boolean isHidden = Files.isHidden(source);
boolean readable = Files.isReadable(source);
boolean writable = Files.isWritable(source);
boolean executable = Files.isExecutable(source);
long size = Files.size(source);
```

### 创建

```java
// 创建文件
Files.createFile(Path.of("new.txt"));

// 创建目录
Files.createDirectory(Path.of("mydir"));          // 单层
Files.createDirectories(Path.of("a/b/c"));        // 多层，已存在不报错

// 创建临时文件/目录
Path tmpFile = Files.createTempFile("prefix", ".tmp");
Path tmpDir = Files.createTempDirectory("mydir");
```

### 复制、移动、删除

```java
// 复制
Files.copy(source, target);                                       // 默认：存在则失败
Files.copy(source, target, StandardCopyOption.REPLACE_EXISTING);  // 覆盖
Files.copy(source, target, StandardCopyOption.COPY_ATTRIBUTES);   // 复制属性

// 移动（重命名）
Files.move(source, target, StandardCopyOption.REPLACE_EXISTING);
Files.move(source, target, StandardCopyOption.ATOMIC_MOVE);      // 原子移动

// 删除
Files.delete(Path.of("file.txt"));          // 不存在则抛异常
Files.deleteIfExists(Path.of("file.txt"));  // 不存在则返回 false
```

### 文件读写快捷方法

```java
Path file = Path.of("data.txt");

// 读取全部字节
byte[] bytes = Files.readAllBytes(file);

// 读取全部行（小文件）
List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);

// 按行流式读取（大文件）
try (Stream<String> stream = Files.lines(file, StandardCharsets.UTF_8)) {
    stream.filter(line -> line.contains("ERROR"))
          .forEach(System.out::println);
}

// 写入字节
Files.write(file, "Hello".getBytes(StandardCharsets.UTF_8));

// 写入行
List<String> data = List.of("line1", "line2");
Files.write(file, data, StandardCharsets.UTF_8);

// 追加模式
Files.writeString(file, "追加内容\n", StandardCharsets.UTF_8,
                  StandardOpenOption.APPEND);

// JDK 11+ 读写字符串
String content = Files.readString(file, StandardCharsets.UTF_8);
Files.writeString(file, "hello world", StandardCharsets.UTF_8);
```

## 文件遍历

### 单层目录

```java
// 列出目录下的所有条目（Path 对象）
try (Stream<Path> entries = Files.list(Path.of("/home/user"))) {
    entries.filter(Files::isRegularFile)
           .filter(p -> p.toString().endsWith(".txt"))
           .forEach(System.out::println);
}
```

### 递归遍历

```java
// 递归遍历（默认深度不限）
try (Stream<Path> tree = Files.walk(Path.of("/home/user"))) {
    tree.filter(Files::isRegularFile)
        .forEach(System.out::println);
}

// 限制深度
try (Stream<Path> tree = Files.walk(Path.of("/home/user"), 2)) {  // 最深 2 层
    tree.forEach(System.out::println);
}

// 查找——按条件过滤的递归遍历
PathMatcher matcher = FileSystems.getDefault().getPathMatcher("glob:**/*.java");
try (Stream<Path> found = Files.find(
         Path.of("."), 10,
         (path, attrs) -> matcher.matches(path) && attrs.size() < 1024 * 1024)) {
    found.forEach(System.out::println);
}
```

## 文件属性

```java
Path file = Path.of("data.txt");

// 基本属性（跨平台）
long size = Files.size(file);
FileTime lastModified = Files.getLastModifiedTime(file);
UserPrincipal owner = Files.getOwner(file);

// 批量读取属性
BasicFileAttributes attrs = Files.readAttributes(file, BasicFileAttributes.class);
System.out.println(attrs.creationTime());
System.out.println(attrs.lastAccessTime());
System.out.println(attrs.isDirectory());
System.out.println(attrs.isRegularFile());
System.out.println(attrs.isSymbolicLink());

// 修改时间
Files.setLastModifiedTime(file, FileTime.fromMillis(System.currentTimeMillis()));

// POSIX 权限（Linux/Mac）
Set<PosixFilePermission> perms = Files.getPosixFilePermissions(file);
Files.setPosixFilePermissions(file, PosixFilePermissions.fromString("rw-r--r--"));

// 设置所有者
UserPrincipalLookupService lookup = FileSystems.getDefault().getUserPrincipalLookupService();
UserPrincipal user = lookup.lookupPrincipalByName("root");
Files.setOwner(file, user);
```

## 临时文件

```java
// 创建临时文件
Path tmpFile = Files.createTempFile("myapp", ".tmp");
// → /tmp/myapp123456789.tmp

// 指定目录
Path tmpInDir = Files.createTempFile(Path.of("/custom/tmp"), "myapp", ".log");

// 创建临时目录
Path tmpDir = Files.createTempDirectory("myapp");
// → /tmp/myapp987654321

// 程序退出时清理
tmpFile.toFile().deleteOnExit();
// 或手动删除
Files.deleteIfExists(tmpFile);
```

## 文件系统（FileSystem）

```java
import java.nio.file.FileSystem;
import java.nio.file.FileSystems;
import java.nio.file.FileStore;

// 默认文件系统
FileSystem fs = FileSystems.getDefault();
System.out.println(fs.getSeparator());     // /
System.out.println(fs.getRootDirectories());  // [/]

// 磁盘空间
FileStore store = Files.getFileStore(Path.of("/"));
long total = store.getTotalSpace();
long usable = store.getUsableSpace();
long free = store.getUnallocatedSpace();

// 遍历所有磁盘
for (FileStore s : FileSystems.getDefault().getFileStores()) {
    System.out.printf("%s: %d GB 可用\n", s.name(), s.getUsableSpace() / 1024 / 1024 / 1024);
}
```

## 应用场景实战

### 场景一：查找目录下最大的 N 个文件

```java
public static List<Path> largestFiles(Path dir, int n) throws IOException {
    try (Stream<Path> walk = Files.walk(dir)) {
        return walk.filter(Files::isRegularFile)
            .sorted((a, b) -> {
                try {
                    return Long.compare(Files.size(b), Files.size(a));
                } catch (IOException e) {
                    throw new UncheckedIOException(e);
                }
            })
            .limit(n)
            .collect(Collectors.toList());
    }
}
```

### 场景二：监控目录变化

```java
// WatchService 在 NIO.2 章节会详细展开，这里给一个快速预览
WatchService watcher = FileSystems.getDefault().newWatchService();
Path dir = Path.of("/path/to/watch");
dir.register(watcher, StandardWatchEventKinds.ENTRY_CREATE,
                       StandardWatchEventKinds.ENTRY_MODIFY,
                       StandardWatchEventKinds.ENTRY_DELETE);

while (true) {
    WatchKey key = watcher.take();
    for (WatchEvent<?> event : key.pollEvents()) {
        System.out.println(event.kind() + ": " + event.context());
    }
    key.reset();
}
```

### 场景三：递归删除目录

```java
public static void deleteDirectory(Path dir) throws IOException {
    if (!Files.exists(dir)) return;
    
    try (Stream<Path> walk = Files.walk(dir)) {
        walk.sorted(Comparator.reverseOrder())  // 先删内层
            .forEach(path -> {
                try {
                    Files.delete(path);
                } catch (IOException e) {
                    throw new UncheckedIOException(e);
                }
            });
    }
}
```

### 场景四：按扩展名分类文件

```java
public static Map<String, List<Path>> groupByExtension(Path dir) throws IOException {
    try (Stream<Path> stream = Files.list(dir)) {
        return stream.filter(Files::isRegularFile)
            .collect(Collectors.groupingBy(p -> {
                String name = p.getFileName().toString();
                int dot = name.lastIndexOf('.');
                return dot >= 0 ? name.substring(dot).toLowerCase() : "(无扩展名)";
            }));
    }
}
```

## 最佳实践与踩坑记录

### API 选型

| 需求 | 推荐 API |
|------|----------|
| 路径拼接、解析、规范化 | `Path.of()` / `Paths.get()` |
| 创建/删除/复制/移动文件 | `Files.createFile()` / `Files.delete()` / `Files.copy()` / `Files.move()` |
| 小文件读写 (< 10MB) | `Files.readString()` / `Files.writeString()` (JDK 11+) |
| 大文件按行读 | `Files.lines()` (Stream) |
| 二进制大文件读写 | `FileInputStream` + `BufferedInputStream` |
| 目录遍历 | `Files.list()` / `Files.walk()` / `Files.find()` |

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| `Files.list()` 忘 close | 返回的 Stream 持有目录句柄 | 用 try-with-resources |
| `Files.walk()` 跑进循环链接 | 符号链接成环 | `Files.walk(dir, FileVisitOption.FOLLOW_LINKS)` 时加深度限制 |
| `File.delete()` 返回 false | 目录非空或权限不够 | 用 `Files.walk` 递归删除；用 `Files.delete` 抛具体异常 |
| `File.renameTo()` 不可靠 | 平台相关，跨文件系统可能失败 | 用 `Files.move()`，支持 `ATOMIC_MOVE` |
| `readAllLines` 大文件 OOM | 全量加载到内存 | 用 `Files.lines()` 流式读取 |

### 关键规则

```
1. 新代码不用 File 类 —— 用 Path + Files
2. walk/list 返回的 Stream 必须 try-with-resources
3. 不要用 File.renameTo() —— 用 Files.move()
4. 读写文本始终指定 StandardCharsets.UTF_8
5. 临时文件用完删除 —— createTempFile + deleteIfExists
```

## 总结

- `File` 是 JDK 1.0 遗留类，新代码用 `Path` + `Files`
- `Path.of()` (JDK 11+) 创建路径，支持 resolve/relativize/normalize
- `Files` 是文件操作一站式工具：创建/复制/移动/删除/读写/属性/遍历
- `Files.readString/writeString` 适合小文件快捷读写，`Files.lines()` 流式处理大文件
- `Files.walk()` 递归遍历 + `Files.list()` 单层遍历，返回的 Stream 必须 try-with-resources
- 临时文件用 `Files.createTempFile`，记得清理
