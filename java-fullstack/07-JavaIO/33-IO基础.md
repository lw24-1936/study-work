## 概述

Java IO 是 JDK 1.0 就存在的 API，基于**流（Stream）**的抽象——数据像水一样在"管道"中流动，一端是数据源，另一端是目标。理解 Java IO 的关键是抓住两条线：

```
字节流（二进制）        字符流（文本）
─────────────          ─────────────
InputStream            Reader
OutputStream           Writer
    ↓                     ↓
FileInputStream        FileReader
BufferedInputStream    BufferedReader
DataInputStream        InputStreamReader（转换桥）
ObjectInputStream
```

核心设计模式：**装饰器模式**。基础流提供数据来源（FileInputStream），装饰器流增加功能（BufferedInputStream 加缓冲、DataInputStream 加类型读取）——你可以像搭积木一样叠加：

```java
// 从一个文件读取，带缓冲，按 UTF-8 解码，按行读取
BufferedReader reader = new BufferedReader(
    new InputStreamReader(
        new FileInputStream("data.txt"),
        StandardCharsets.UTF_8
    )
);
```

## 字节流：InputStream / OutputStream

字节流按**字节**（8 位）处理数据，用于所有二进制数据：图片、视频、PDF、以及所有文本（文本本质上也是字节）。

### InputStream

```java
public abstract class InputStream implements Closeable {
    abstract int read();                           // 读一个字节，返回 0-255，结尾返回 -1
    int read(byte[] b);                            // 读多个字节，返回实际读取数
    int read(byte[] b, int off, int len);          // 指定位置和长度
    void close();                                  // 关闭流
    long skip(long n);                             // 跳过 n 个字节
    int available();                               // 可读字节数（不一定准确）
    byte[] readAllBytes();                         // JDK 9+ 一次性读取全部
    long transferTo(OutputStream out);             // JDK 9+ 直接传输到输出流
}
```

```java
// 基础读取
try (InputStream is = new FileInputStream("data.bin")) {
    int b;
    while ((b = is.read()) != -1) {
        System.out.printf("%02X ", b);  // 打印十六进制
    }
}

// 批量读取（性能好得多）
try (InputStream is = new FileInputStream("data.bin")) {
    byte[] buffer = new byte[8192];
    int bytesRead;
    while ((bytesRead = is.read(buffer)) != -1) {
        // 处理 buffer[0..bytesRead-1]
    }
}

// JDK 9+ 一次性读取
byte[] allBytes = new FileInputStream("data.bin").readAllBytes();
String content = new String(allBytes, StandardCharsets.UTF_8);
```

### OutputStream

```java
public abstract class OutputStream implements Closeable, Flushable {
    abstract void write(int b);                    // 写一个字节（低 8 位）
    void write(byte[] b);                          // 写整个数组
    void write(byte[] b, int off, int len);        // 指定位置和长度
    void flush();                                  // 刷新缓冲区
    void close();                                  // 关闭流
}
```

```java
// 基础写入
try (OutputStream os = new FileOutputStream("output.bin")) {
    os.write(0x48);          // 'H'
    os.write(new byte[]{0x65, 0x6C, 0x6C, 0x6F});  // 'ello'
    os.flush();              // 确保写入磁盘
}

// 文件追加模式
try (OutputStream os = new FileOutputStream("log.txt", true)) {
    os.write("追加一行\n".getBytes(StandardCharsets.UTF_8));
}
```

## 字符流：Reader / Writer

字符流按**字符**（16 位 Unicode）处理，内置编解码，用于纯文本：

```java
// Reader
try (Reader reader = new FileReader("text.txt", StandardCharsets.UTF_8)) {
    int ch;
    while ((ch = reader.read()) != -1) {
        System.out.print((char) ch);
    }
}

// Writer
try (Writer writer = new FileWriter("output.txt", StandardCharsets.UTF_8)) {
    writer.write("Hello 世界");
    writer.write("第二行\n");
}
```

注意：`FileReader` / `FileWriter` 使用系统默认编码（不可控！）。绝对不要用——总是用 `InputStreamReader`/`OutputStreamWriter` 显式指定编码。

## 字节流 vs 字符流

| 维度 | 字节流 | 字符流 |
|------|--------|--------|
| 基类 | InputStream / OutputStream | Reader / Writer |
| 单位 | 1 字节 (8 位) | 1 字符 (16 位 Unicode) |
| 数据处理 | 原始字节，无编码 | 自动编解码 |
| 适用场景 | 所有文件（图片、音频、PDF、文本） | 纯文本文件 |
| 缓冲 | 无（需 BufferedInputStream） | 无（需 BufferedReader） |
| 编码控制 | 手动（转 InputStreamReader） | FileReader 不可控，用 InputStreamReader |

## 缓冲流

不带缓冲的流——每次 `read()` 都触发系统调用（涉及内核态切换），性能灾难。缓冲流包装一个 8KB 内部缓冲区，一次系统调用填满缓冲区，后续 `read()` 直接从内存取：

```java
// 无缓冲（慢）
InputStream raw = new FileInputStream("large.bin");

// 有缓冲（快百倍）
InputStream buffered = new BufferedInputStream(new FileInputStream("large.bin"));

// 字符缓冲——多了 readLine()
BufferedReader reader = new BufferedReader(new FileReader("text.txt"));
String line;
while ((line = reader.readLine()) != null) {
    System.out.println(line);
}

// 缓冲写入
BufferedWriter writer = new BufferedWriter(new FileWriter("out.txt"));
writer.write("hello");
writer.newLine();             // 跨平台换行
writer.flush();
```

BufferedReader 的核心价值是 `readLine()` —— 按行读取文本，比逐字符读取方便得多。

## 转换流：字节到字符的桥梁

`InputStreamReader` / `OutputStreamWriter` 是字节流和字符流之间的适配器——将字节按指定编码转换为字符（或反之）：

```java
// 从字节流 → 字符流（解码）
try (BufferedReader reader = new BufferedReader(
         new InputStreamReader(
             new FileInputStream("data.txt"),
             StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// 从字符流 → 字节流（编码）
try (BufferedWriter writer = new BufferedWriter(
         new OutputStreamWriter(
             new FileOutputStream("output.txt"),
             StandardCharsets.UTF_8))) {
    writer.write("中文内容");
}
```

这条链是 Java IO 设计的精髓：`FileInputStream` (字节源) → `InputStreamReader` (字节→字符) → `BufferedReader` (缓冲+按行读)。每一种只做一件事，自由组合。

## 数据流与对象流

### DataInputStream / DataOutputStream

按 Java 基本类型读写二进制数据——不是文本，是原始字节表示：

```java
// 写入二进制格式
try (DataOutputStream dos = new DataOutputStream(
         new BufferedOutputStream(new FileOutputStream("data.bin")))) {
    dos.writeInt(42);
    dos.writeDouble(3.14);
    dos.writeUTF("hello");       // 用 modified UTF-8 写字符串
    dos.writeBoolean(true);
}

// 读取
try (DataInputStream dis = new DataInputStream(
         new BufferedInputStream(new FileInputStream("data.bin")))) {
    int i = dis.readInt();       // 42
    double d = dis.readDouble(); // 3.14
    String s = dis.readUTF();    // "hello"
    boolean b = dis.readBoolean(); // true
}
```

适用于简单的二进制格式（自定义文件头、游戏存档等）。

### ObjectInputStream / ObjectOutputStream

将实现了 `Serializable` 的对象整体写入/读取（序列化）：

```java
class User implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;
    // ...
}

// 写入
try (ObjectOutputStream oos = new ObjectOutputStream(
         new FileOutputStream("user.obj"))) {
    oos.writeObject(new User("张三", 25));
}

// 读取
try (ObjectInputStream ois = new ObjectInputStream(
         new FileInputStream("user.obj"))) {
    User user = (User) ois.readObject();
    System.out.println(user.getName());  // 张三
}
```

## 标准输入输出

```java
System.in   // InputStream  —— 标准输入（键盘）
System.out  // PrintStream — 标准输出（屏幕）
System.err  // PrintStream — 标准错误（屏幕）

// 从控制台读取
Scanner scanner = new Scanner(System.in);
System.out.print("请输入: ");
String input = scanner.nextLine();

// 或 BufferedReader
BufferedReader consoleReader = new BufferedReader(new InputStreamReader(System.in));
String line = consoleReader.readLine();
```

## PrintStream / PrintWriter

`PrintStream` 和 `PrintWriter` 是最高频使用的输出类——它们提供了 `print()` / `println()` / `printf()` 系列方法，把各种类型自动转成字符串并输出。`System.out` 就是 `PrintStream`，日志框架的 appender 常用 `PrintWriter`。

### PrintStream（字节输出）

```java
// PrintStream 包装 OutputStream，永不抛 IOException（异常被吞掉，需 checkError()）
PrintStream ps = new PrintStream(new FileOutputStream("log.txt"), true, StandardCharsets.UTF_8);

ps.println("Hello World");          // 输出字符串 + 换行
ps.print("值: ");                   // 输出字符串（不换行）
ps.println(42);                     // 输出 int
ps.printf("%s 的年龄是 %d%n", "张三", 25);  // 格式化输出

// 检查是否发生过 IO 错误
if (ps.checkError()) {
    System.err.println("写入失败");
}
```

### PrintWriter（字符输出，推荐）

```java
// PrintWriter 比 PrintStream 更通用——包装 Writer 而不是 OutputStream
// 也是自动 flush 可选、异常不抛
try (PrintWriter pw = new PrintWriter(
         new BufferedWriter(new FileWriter("output.txt", StandardCharsets.UTF_8)), true)) {

    pw.println("第一行");
    pw.println("第二行");
    pw.printf("格式化: %s, %d%n", "test", 100);
}
```

### 选择建议

| 场景 | 用 |
|------|-----|
| 写文本文件 | `PrintWriter` + `BufferedWriter` |
| 写 System.out（标准输出） | 已经是 `PrintStream`，直接用 |
| 写二进制 | `BufferedOutputStream`（Print 系列不适合） |
| 需要抛异常 | 不用 Print 系列，用原始 `OutputStream`/`Writer` |

注意：`PrintStream`/`PrintWriter` 的方法不会抛 `IOException`——异常被内部吞掉，需要通过 `checkError()` 检查。对于不能容忍静默丢失错误的关键写入，用 `BufferedWriter` + 手动处理 `IOException`。

## Piped Streams（线程间通信）

管道流用于在线程之间传递字节/字符数据——一个线程写，另一个线程读：

```java
// 字节管道
PipedOutputStream out = new PipedOutputStream();
PipedInputStream in = new PipedInputStream(out);  // 连接两者

// 写线程
new Thread(() -> {
    try (out) {
        out.write("Hello from thread".getBytes(StandardCharsets.UTF_8));
    } catch (IOException e) { /* handle */ }
}).start();

// 读线程
new Thread(() -> {
    try (in) {
        byte[] buf = new byte[1024];
        int n = in.read(buf);
        System.out.println(new String(buf, 0, n, StandardCharsets.UTF_8));
    } catch (IOException e) { /* handle */ }
}).start();
```

实际开发中很少直接用 Piped Stream——`BlockingQueue` 或 `Exchanger` 更简单可靠。了解即可。

## 应用场景实战

### 场景一：文件复制

```java
public static void copyFile(Path source, Path target) throws IOException {
    try (InputStream in = new BufferedInputStream(Files.newInputStream(source));
         OutputStream out = new BufferedOutputStream(Files.newOutputStream(target))) {
        byte[] buffer = new byte[8192];
        int bytesRead;
        while ((bytesRead = in.read(buffer)) != -1) {
            out.write(buffer, 0, bytesRead);
        }
    }
}

// JDK 9+ 一行
// in.transferTo(out);
```

### 场景二：按行读取大文件

```java
public static List<String> grep(Path file, String keyword) throws IOException {
    List<String> matches = new ArrayList<>();
    try (BufferedReader reader = new BufferedReader(
             new InputStreamReader(Files.newInputStream(file), StandardCharsets.UTF_8))) {
        String line;
        while ((line = reader.readLine()) != null) {
            if (line.contains(keyword)) {
                matches.add(line);
            }
        }
    }
    return matches;
}
```

### 场景三：CSV 解析

```java
public static List<String[]> parseCSV(Path csvFile) throws IOException {
    List<String[]> rows = new ArrayList<>();
    try (BufferedReader reader = new BufferedReader(
             new InputStreamReader(Files.newInputStream(csvFile), StandardCharsets.UTF_8))) {
        String line;
        while ((line = reader.readLine()) != null) {
            if (line.isBlank()) continue;
            rows.add(line.split(","));
        }
    }
    return rows;
}
```

### 场景四：内存中读写字节（ByteArray Stream）

```java
// ByteArrayInputStream / ByteArrayOutputStream 在内存中操作字节
ByteArrayOutputStream baos = new ByteArrayOutputStream();
baos.write("Hello".getBytes(StandardCharsets.UTF_8));
byte[] data = baos.toByteArray();  // 获取内部字节数组

ByteArrayInputStream bais = new ByteArrayInputStream(data);
String result = new String(bais.readAllBytes(), StandardCharsets.UTF_8);
```

## 最佳实践与踩坑记录

### 流层次架构

```
FileInputStream          ← 数据源
  └─ BufferedInputStream ← 加缓冲
       └─ DataInputStream ← 按类型读
            └─ readInt()

写也同理：
FileOutputStream ← 数据目标
  └─ BufferedOutputStream
       └─ DataOutputStream
            └─ writeInt()
```

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| 中文乱码 | FileReader 用了系统默认编码 | 用 `InputStreamReader(stream, UTF_8)` |
| 文件读了一半报 EOF | 没检查 `read` 的返回值 | `while((bytesRead = in.read(buf)) != -1)` |
| 文件没写入磁盘 | 没 flush 或 close | 用 try-with-resources 自动 close，close 前会 flush |
| 逐字节读取大文件极慢 | 每次 read() 触发系统调用 | 用 BufferedInputStream + 8KB 缓冲区 |
| 内存溢出 | `readAllBytes()` 读大文件 | 流式处理，不一次全加载 |

### 关键规则

```
1. 永远用 try-with-resources —— 自动关闭，不用手动 finally
2. 永远包缓冲 —— BufferedInputStream / BufferedReader
3. 文本 IO 永远指定编码 —— StandardCharsets.UTF_8
4. 读操作始终检查返回值 —— read() 返回 -1 表示结束
5. 写完 flush —— 或靠 close 自动 flush
6. 设计时优先考虑 NIO.2 的 Files 工具类 —— 更简洁
```

## 总结

- Java IO 四大基类：`InputStream` / `OutputStream`（字节）和 `Reader` / `Writer`（字符）
- 装饰器模式：基础流 + 缓冲流 + 转换流 + 数据流自由叠加
- `BufferedReader.readLine()` 是按行处理文本的核心方法
- `InputStreamReader` 是字节到字符的桥梁——并指定编码（永远不要用无参 FileReader）
- 缓冲流带来 10-100 倍性能提升——每流必包
- try-with-resources 保证流关闭，属于必须遵守的规范
