## 概述

Java 的网络 API 在 `java.net` 包中，从 JDK 1.0 就存在。它提供从底层 Socket 编程到高层 HTTP 连接的全套支持。

网络编程的两大传输层协议：

| 协议 | Java 核心类 | 特点 |
|------|------------|------|
| **TCP** | `Socket` / `ServerSocket` | 面向连接、可靠、有序、有流量控制 |
| **UDP** | `DatagramSocket` / `DatagramPacket` | 无连接、不可靠、低延迟、适合实时场景 |

高层封装：
- `URL` / `URLConnection` — 直接操作 HTTP/FTP 等协议
- `HttpURLConnection` — 发送 HTTP 请求（Java 9+ 推荐用 `HttpClient`）

## InetAddress

`InetAddress` 表示 IP 地址（IPv4 或 IPv6），同时可解析主机名：

```java
import java.net.InetAddress;

// 通过主机名获取
InetAddress addr = InetAddress.getByName("www.google.com");
System.out.println(addr.getHostName());      // www.google.com
System.out.println(addr.getHostAddress());   // 142.250.xxx.xxx

// 本机地址
InetAddress local = InetAddress.getLocalHost();
System.out.println(local.getHostName());
System.out.println(local.getHostAddress());

// 回环地址
InetAddress loopback = InetAddress.getLoopbackAddress();  // 127.0.0.1
InetAddress ipv6loop = InetAddress.getByName("::1");

// 通过 IP 获取
InetAddress byIp = InetAddress.getByName("8.8.8.8");

// 获取所有 IP（负载均衡域名可能返回多个）
InetAddress[] all = InetAddress.getAllByName("www.google.com");
for (InetAddress a : all) {
    System.out.println(a.getHostAddress());
}

// 可达性测试（类似 ping）
boolean reachable = addr.isReachable(3000);  // 3 秒超时
```

## Socket 与 ServerSocket（TCP）

TCP 编程是经典的客户端-服务端模型：

```
客户端                       服务端
  │                            │
  │  new Socket(host, port)     │  new ServerSocket(port)
  │  ──── connect ───────────→  │  serverSocket.accept()
  │  ←── 三次握手 ────────────→  │
  │                            │
  │  getOutputStream().write()  │
  │  ──── 数据 ──────────────→  │
  │                            │  socket.getInputStream().read()
  │  ←── 响应 ───────────────  │  socket.getOutputStream().write()
  │  getInputStream().read()    │
  │                            │
  │  socket.close()             │  socket.close()
```

### TCP 服务端

```java
public class SimpleServer {
    public static void main(String[] args) throws IOException {
        try (ServerSocket server = new ServerSocket(8080)) {
            System.out.println("服务端启动，监听 8080...");
            
            while (true) {
                // accept() 阻塞直到有客户端连接
                Socket client = server.accept();
                System.out.println("客户端连接: " + client.getInetAddress());
                
                // 每个连接开一个线程处理（简单但低效的模型）
                new Thread(() -> handleClient(client)).start();
            }
        }
    }

    private static void handleClient(Socket client) {
        try (client;  // JDK 9+ Socket 也实现了 AutoCloseable
             BufferedReader in = new BufferedReader(
                 new InputStreamReader(client.getInputStream(), StandardCharsets.UTF_8));
             PrintWriter out = new PrintWriter(
                 new OutputStreamWriter(client.getOutputStream(), StandardCharsets.UTF_8), true)) {
            
            String line;
            while ((line = in.readLine()) != null) {
                System.out.println("收到: " + line);
                out.println("Echo: " + line);  // 原样返回
                if ("bye".equals(line)) break;
            }
        } catch (IOException e) {
            System.err.println("客户端异常: " + e.getMessage());
        }
    }
}
```

### TCP 客户端

```java
public class SimpleClient {
    public static void main(String[] args) throws IOException {
        try (Socket socket = new Socket("localhost", 8080);
             PrintWriter out = new PrintWriter(
                 new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true);
             BufferedReader in = new BufferedReader(
                 new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
             BufferedReader console = new BufferedReader(new InputStreamReader(System.in))) {
            
            System.out.println("已连接服务器，输入消息（bye 退出）:");
            
            String userInput;
            while ((userInput = console.readLine()) != null) {
                out.println(userInput);          // 发送
                String response = in.readLine(); // 接收
                System.out.println("服务器: " + response);
                if ("bye".equals(userInput)) break;
            }
        }
    }
}
```

### Socket 选项

```java
Socket socket = new Socket();
socket.setSoTimeout(5000);               // 读超时 5 秒
socket.setTcpNoDelay(true);              // 禁用 Nagle 算法（降低延迟）
socket.setKeepAlive(true);               // 开启 TCP KeepAlive
socket.setReuseAddress(true);            // 允许重用地址
socket.setSoLinger(true, 10);            // close 时停留 10 秒

ServerSocket server = new ServerSocket();
server.setReuseAddress(true);
server.setSoTimeout(10000);              // accept 超时
server.bind(new InetSocketAddress(8080), 50); // 绑定 + 50 个积压连接
```

## DatagramSocket（UDP）

UDP 是无连接协议——不需要建立连接，直接发数据包。速度快但不可靠（丢包、乱序、重复都不管）：

### UDP 服务端

```java
public class UdpServer {
    public static void main(String[] args) throws IOException {
        try (DatagramSocket socket = new DatagramSocket(9090)) {
            byte[] buf = new byte[1024];
            
            while (true) {
                DatagramPacket packet = new DatagramPacket(buf, buf.length);
                socket.receive(packet);  // 阻塞等待数据包
                
                String msg = new String(packet.getData(), 0, packet.getLength(),
                                        StandardCharsets.UTF_8);
                System.out.printf("来自 %s:%d 的消息: %s%n",
                    packet.getAddress(), packet.getPort(), msg);
                
                // 回复
                String response = "收到: " + msg;
                byte[] respBytes = response.getBytes(StandardCharsets.UTF_8);
                DatagramPacket respPacket = new DatagramPacket(
                    respBytes, respBytes.length,
                    packet.getAddress(), packet.getPort()
                );
                socket.send(respPacket);
            }
        }
    }
}
```

### UDP 客户端

```java
public class UdpClient {
    public static void main(String[] args) throws IOException {
        try (DatagramSocket socket = new DatagramSocket()) {
            InetAddress server = InetAddress.getByName("localhost");
            
            // 发送
            String msg = "Hello UDP";
            byte[] data = msg.getBytes(StandardCharsets.UTF_8);
            DatagramPacket sendPacket = new DatagramPacket(
                data, data.length, server, 9090);
            socket.send(sendPacket);
            System.out.println("已发送: " + msg);
            
            // 接收回复
            byte[] buf = new byte[1024];
            DatagramPacket recvPacket = new DatagramPacket(buf, buf.length);
            socket.receive(recvPacket);
            String response = new String(recvPacket.getData(), 0,
                                         recvPacket.getLength(), StandardCharsets.UTF_8);
            System.out.println("回复: " + response);
        }
    }
}
```

### UDP 广播与多播

```java
// 广播（发送到同网段所有设备）
DatagramSocket broadcastSocket = new DatagramSocket();
broadcastSocket.setBroadcast(true);
InetAddress broadcastAddr = InetAddress.getByName("255.255.255.255");
DatagramPacket packet = new DatagramPacket(data, data.length, broadcastAddr, 9090);
broadcastSocket.send(packet);

// 多播（加入组播组）
MulticastSocket multicastSocket = new MulticastSocket(9090);
InetAddress group = InetAddress.getByName("224.0.0.1");
multicastSocket.joinGroup(group);
// ... 收发
multicastSocket.leaveGroup(group);
```

## URL 与 URLConnection

`URL` 类提供高层的协议访问——你不用关心底层 Socket：

```java
import java.net.URL;
import java.net.URLConnection;
import java.net.HttpURLConnection;

URL url = new URL("https://api.example.com/data?id=1");

// 基本信息
System.out.println(url.getProtocol());   // https
System.out.println(url.getHost());       // api.example.com
System.out.println(url.getPort());       // -1（默认端口）
System.out.println(url.getPath());       // /data
System.out.println(url.getQuery());      // id=1

// 打开连接并读取
URLConnection conn = url.openConnection();
conn.setConnectTimeout(5000);
conn.setReadTimeout(5000);

try (BufferedReader reader = new BufferedReader(
         new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}
```

### HttpURLConnection

```java
URL url = new URL("https://api.example.com/users");

HttpURLConnection conn = (HttpURLConnection) url.openConnection();
conn.setRequestMethod("POST");
conn.setRequestProperty("Content-Type", "application/json");
conn.setRequestProperty("Authorization", "Bearer token123");
conn.setDoOutput(true);
conn.setConnectTimeout(5000);
conn.setReadTimeout(5000);

// 发送请求体
String jsonBody = "{\"name\": \"张三\", \"age\": 25}";
try (OutputStream os = conn.getOutputStream()) {
    os.write(jsonBody.getBytes(StandardCharsets.UTF_8));
}

// 读取响应
int status = conn.getResponseCode();
String responseBody;
try (BufferedReader reader = new BufferedReader(
         new InputStreamReader(
             status >= 400 ? conn.getErrorStream() : conn.getInputStream(),
             StandardCharsets.UTF_8))) {
    responseBody = reader.lines().collect(Collectors.joining("\n"));
}

System.out.println("状态码: " + status);
System.out.println("响应: " + responseBody);
conn.disconnect();
```

## URI 解析

`URI` 用于标识资源但不一定可访问（`URL` 是 `URI` 的子集——URL 同时定位资源）：

```java
import java.net.URI;

URI uri = new URI("https://user:pass@www.example.com:8080/path?query=1#fragment");

System.out.println(uri.getScheme());      // https
System.out.println(uri.getUserInfo());    // user:pass
System.out.println(uri.getHost());        // www.example.com
System.out.println(uri.getPort());        // 8080
System.out.println(uri.getPath());        // /path
System.out.println(uri.getQuery());       // query=1
System.out.println(uri.getFragment());    // fragment

// URL = URI的子集，多了网络访问能力
URL url = uri.toURL();
```

## 应用场景实战

### 场景一：简单的 HTTP 文件下载

```java
public static void download(String urlStr, Path dest) throws IOException {
    URL url = new URL(urlStr);
    try (InputStream in = url.openStream();
         OutputStream out = Files.newOutputStream(dest)) {
        byte[] buf = new byte[8192];
        int bytesRead;
        while ((bytesRead = in.read(buf)) != -1) {
            out.write(buf, 0, bytesRead);
        }
    }
}
```

### 场景二：端口扫描

```java
public static List<Integer> scanPorts(String host, int start, int end, int timeout) {
    List<Integer> openPorts = new ArrayList<>();
    for (int port = start; port <= end; port++) {
        try (Socket socket = new Socket()) {
            socket.connect(new InetSocketAddress(host, port), timeout);
            openPorts.add(port);
        } catch (IOException e) {
            // 端口关闭或不可达
        }
    }
    return openPorts;
}
```

### 场景三：UDP 局域网发现

```java
public class LanDiscovery {
    public static void broadcast(String message, int port) throws IOException {
        try (DatagramSocket socket = new DatagramSocket()) {
            socket.setBroadcast(true);
            byte[] data = message.getBytes(StandardCharsets.UTF_8);
            DatagramPacket packet = new DatagramPacket(data, data.length,
                InetAddress.getByName("255.255.255.255"), port);
            socket.send(packet);
        }
    }

    public static String listen(int port) throws IOException {
        try (DatagramSocket socket = new DatagramSocket(port)) {
            byte[] buf = new byte[256];
            DatagramPacket packet = new DatagramPacket(buf, buf.length);
            socket.receive(packet);
            return new String(packet.getData(), 0, packet.getLength(), StandardCharsets.UTF_8);
        }
    }
}
```

## 最佳实践与踩坑记录

### 选型指南

| 场景 | 推荐 |
|------|------|
| 简单的 HTTP GET 请求 | `URL.openStream()` |
| HTTP POST 等复杂请求 | `HttpURLConnection` 或 JDK 11+ `HttpClient` |
| 需要可靠传输 | TCP Socket |
| 实时音视频/游戏 | UDP DatagramSocket |
| 局域网发现 | UDP 广播/多播 |
| 大量并发连接 | NIO Channel + Selector（或 Netty） |
| 生产环境 HTTP 客户端 | OkHttp / Apache HttpClient（比原生 API 更完善） |

### 常见问题表

| 问题 | 原因 | 修复 |
|------|------|------|
| `accept()` 无限阻塞 | 没有连接到来 | 设置 `ServerSocket.setSoTimeout()` |
| `read()` 无限阻塞 | 对方没发送数据或没发送结束标志 | 设置 `socket.setSoTimeout()` |
| 连接被拒绝 (Connection refused) | 服务端未启动或端口错误 | 检查服务端是否运行 |
| 端口被占用 (Address already in use) | 上次程序没释放端口 | `setReuseAddress(true)` 或等一下再启动 |
| UDP 丢包 | UDP 不保证送达 | 加序列号、ACK 确认、超时重传 |
| DNS 解析慢 | 网络或 DNS 服务器问题 | 设置 InetAddress 缓存；使用 IP 直连 |

### 关键规则

```
1. 所有网络操作都可能抛 IOException —— 必须处理
2. Socket 用完必须关闭（用 try-with-resources）
3. 设置合理的超时时间（connect、read 都要设）
4. 指定编码 —— 网络传输用 StandardCharsets.UTF_8
5. 大数据传输时分块读写 —— 8KB 缓冲区
6. 生产环境的 HTTP 客户端用 OkHttp/Apache——它们处理了连接池、重试、超时
```

## 总结

- `InetAddress` 处理 IP 地址和主机名解析；`Socket`/`ServerSocket` 实现 TCP 通信
- TCP 三次握手 + 双向字节流；UDP 无连接数据包，快但不可靠
- `DatagramSocket`/`DatagramPacket` 处理 UDP——广播和多播是局域网发现的利器
- `URL`/`HttpURLConnection` 提供高层 HTTP 访问——但 JDK 11+ 的 `HttpClient` 才是现代选择
- 网络编程两大原则：设置超时 + 关闭资源（try-with-resources）
- 实际项目用 Netty 封装 SocketChannel + Selector，原生 API 更多是理解底层原理
