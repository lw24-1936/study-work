## 概述

创建型模式关注对象的创建，把对象的创建和使用解耦。

```text
5 种创建型模式：
1. 单例 —— 一个类只有一个实例
2. 工厂方法 —— 子类决定创建哪个对象
3. 抽象工厂 —— 创建相关对象家族
4. 建造者 —— 分步骤构建复杂对象
5. 原型 —— 克隆已有对象
```

## 单例模式 Singleton

单例模式保证一个类只有一个实例，并提供全局访问点。

### 意图

```text
保证一个类只有一个实例，常用于：
1. 配置管理 —— 全局唯一配置
2. 连接池 —— 共享连接
3. 日志 —— 统一日志
```

### 饿汉式（简单）

```java
public class Singleton {
    private static final Singleton INSTANCE = new Singleton();  // 类加载时创建

    private Singleton() {}   // 私有构造，禁止外部创建

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

### 懒汉式（双重检查锁）

```java
public class Singleton {
    private static volatile Singleton instance;   // volatile 防止指令重排

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {              // 第一次检查
            synchronized (Singleton.class) {  // 加锁
                if (instance == null) {       // 第二次检查
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

### 枚举单例（推荐）

```java
public enum Singleton {
    INSTANCE;

    public void doSomething() { ... }
}

// 使用
Singleton.INSTANCE.doSomething();
```

```text
枚举单例的优势：
1. 线程安全（JVM 保证）
2. 防反射攻击
3. 防反序列化破坏
```

## 工厂方法 Factory Method

工厂方法定义一个创建对象的接口，让子类决定实例化哪个类。

### 意图

```text
把对象的创建延迟到子类，客户端不关心具体类型
```

### 结构

```java
// 产品接口
interface Product {
    void use();
}

// 具体产品
class ProductA implements Product {
    public void use() { System.out.println("A"); }
}
class ProductB implements Product {
    public void use() { System.out.println("B"); }
}

// 工厂接口
interface Factory {
    Product createProduct();
}

// 具体工厂
class FactoryA implements Factory {
    public Product createProduct() { return new ProductA(); }
}
class FactoryB implements Factory {
    public Product createProduct() { return new ProductB(); }
}
```

### 简单工厂（工厂方法的简化）

```java
// 简单工厂：一个工厂类创建所有产品
public class SimpleFactory {
    public static Product create(String type) {
        return switch (type) {
            case "A" -> new ProductA();
            case "B" -> new ProductB();
            default -> throw new IllegalArgumentException();
        };
    }
}
```

## 抽象工厂 Abstract Factory

抽象工厂创建相关对象的家族，保证产品间的兼容性。

### 意图

```text
创建一组相关的对象（如 UI 的按钮 + 输入框），保证同一家族的产品配套
```

### 结构

```java
// 抽象产品
interface Button { void render(); }
interface TextField { void render(); }

// 抽象工厂
interface UIFactory {
    Button createButton();
    TextField createTextField();
}

// 具体工厂（Windows 风格）
class WindowsFactory implements UIFactory {
    public Button createButton() { return new WindowsButton(); }
    public TextField createTextField() { return new WindowsTextField(); }
}

// 具体工厂（Mac 风格）
class MacFactory implements UIFactory {
    public Button createButton() { return new MacButton(); }
    public TextField createTextField() { return new MacTextField(); }
}
```

```text
抽象工厂 vs 工厂方法：
工厂方法 —— 创建一种产品
抽象工厂 —— 创建一组相关产品（产品家族）
```

## 建造者模式 Builder

建造者模式分步骤构建复杂对象。

### 意图

```text
解决构造器参数过多的问题，链式构建复杂对象
```

### 结构

```java
public class User {
    private String name;       // 必填
    private int age;           // 必填
    private String email;      // 可选
    private String phone;      // 可选
    private String address;    // 可选

    private User(Builder builder) {
        this.name = builder.name;
        this.age = builder.age;
        this.email = builder.email;
        this.phone = builder.phone;
        this.address = builder.address;
    }

    public static class Builder {
        private String name;
        private int age;
        private String email;
        private String phone;
        private String address;

        public Builder(String name, int age) {   // 必填参数在构造器
            this.name = name;
            this.age = age;
        }

        public Builder email(String email) { this.email = email; return this; }
        public Builder phone(String phone) { this.phone = phone; return this; }
        public Builder address(String address) { this.address = address; return this; }

        public User build() { return new User(this); }
    }
}

// 使用
User user = new User.Builder("张三", 20)
    .email("a@b.com")
    .phone("123456")
    .build();
```

### 场景：Lombok @Builder

```java
@Builder
public class User {
    private String name;
    private int age;
    private String email;
}

// 使用
User user = User.builder()
    .name("张三")
    .age(20)
    .build();
```

## 原型模式 Prototype

原型模式通过克隆已有对象来创建新对象。

### 意图

```text
对象创建成本高（如复杂初始化），通过克隆快速创建
```

### 结构

```java
// 实现 Cloneable 接口
public class Prototype implements Cloneable {
    private String name;
    private List<String> list;

    @Override
    public Prototype clone() {
        try {
            Prototype copy = (Prototype) super.clone();
            copy.list = new ArrayList<>(this.list);   // 深拷贝 list
            return copy;
        } catch (CloneNotSupportedException e) {
            throw new RuntimeException(e);
        }
    }
}
```

```text
浅拷贝 vs 深拷贝：
浅拷贝 —— 基本类型复制，引用类型共享（super.clone 默认）
深拷贝 —— 引用类型也复制（手动复制引用字段）
```

### 场景：Spring 的 @Scope("prototype")

```java
@Component
@Scope("prototype")   // 每次获取都创建新实例（原型模式）
public class PrototypeBean { ... }
```

## 创建型模式总结

| 模式 | 意图 | 适用 |
|------|------|------|
| 单例 | 一个类一个实例 | 配置、连接池 |
| 工厂方法 | 子类决定创建类型 | 解耦创建 |
| 抽象工厂 | 创建产品家族 | 配套产品 |
| 建造者 | 分步构建复杂对象 | 参数多的对象 |
| 原型 | 克隆对象 | 创建成本高 |

```text
使用建议：
1. 单例 —— 最常用（配置、工具类）
2. 建造者 —— 参数多的对象（Lombok @Builder）
3. 工厂 —— 解耦创建，策略选择
4. 原型 —— 少用（Java 有 Cloneable，但深拷贝麻烦）
```
