## 概述

行为型模式关注对象之间的通信和职责分配。

```text
11 种行为型模式：
观察者、策略、模板方法、命令、状态、责任链、
迭代器、中介者、备忘录、访问者、解释器
```

## 观察者模式 Observer

观察者模式定义一对多的依赖，一个对象变化，通知所有依赖者。

### 意图

```text
对象状态变化时，自动通知所有观察者（发布-订阅）
```

### 结构

```java
// 观察者接口
interface Observer {
    void update(String message);
}

// 主题（被观察者）
class Subject {
    private List<Observer> observers = new ArrayList<>();

    public void attach(Observer observer) { observers.add(observer); }
    public void detach(Observer observer) { observers.remove(observer); }

    public void notifyObservers(String message) {
        for (Observer observer : observers) {
            observer.update(message);   // 通知所有观察者
        }
    }
}
```

### 场景：事件监听、消息订阅

```java
// Spring 事件就是观察者模式
@EventListener
public void onOrderCreated(OrderCreatedEvent event) {
    // 观察者处理事件
}
```

## 策略模式 Strategy

策略模式定义算法家族，让算法可以互换。

### 意图

```text
消除大量 if-else，算法独立封装，可互换
```

### 结构

```java
// 策略接口
interface PaymentStrategy {
    void pay(double amount);
}

// 具体策略
class AlipayStrategy implements PaymentStrategy {
    public void pay(double amount) { System.out.println("支付宝支付 " + amount); }
}
class WechatStrategy implements PaymentStrategy {
    public void pay(double amount) { System.out.println("微信支付 " + amount); }
}

// 上下文
class PaymentContext {
    private PaymentStrategy strategy;

    public PaymentContext(PaymentStrategy strategy) { this.strategy = strategy; }

    public void execute(double amount) {
        strategy.pay(amount);
    }
}

// 使用（消除 if-else）
PaymentContext context = new PaymentContext(new AlipayStrategy());
context.execute(100);
```

```text
策略模式 vs 工厂模式：
策略 —— 关注算法互换（行为）
工厂 —— 关注对象创建
两者常配合使用（工厂创建策略）
```

## 模板方法 Template Method

模板方法定义算法骨架，子类实现具体步骤。

### 意图

```text
定义算法流程，延迟具体步骤到子类
```

### 结构

```java
// 抽象类（定义模板）
abstract class DataProcessor {

    // 模板方法（final，定义流程）
    public final void process() {
        readData();     // 步骤 1
        processData();  // 步骤 2
        writeData();    // 步骤 3
    }

    abstract void readData();     // 子类实现
    abstract void processData();  // 子类实现
    abstract void writeData();    // 子类实现
}

// 具体类
class CSVProcessor extends DataProcessor {
    void readData() { System.out.println("读 CSV"); }
    void processData() { System.out.println("处理 CSV"); }
    void writeData() { System.out.println("写 CSV"); }
}
```

### 场景：Spring 的 JdbcTemplate、RestTemplate

```text
JdbcTemplate：定义数据库操作模板，子类提供 SQL 和参数
```

## 命令模式 Command

命令模式把请求封装成对象，支持撤销、队列、日志。

### 意图

```text
把操作封装成对象，解耦请求发送者和执行者
```

### 结构

```java
// 命令接口
interface Command {
    void execute();
}

// 具体命令
class LightOnCommand implements Command {
    private Light light;
    public LightOnCommand(Light light) { this.light = light; }
    public void execute() { light.on(); }
}

// 调用者
class RemoteControl {
    private Command command;
    public void setCommand(Command command) { this.command = command; }
    public void pressButton() { command.execute(); }
}
```

### 场景：撤销操作、任务队列

```text
支持撤销：命令记录操作，撤销时反向执行
```

## 状态模式 State

状态模式让对象的行为随状态变化而变化。

### 意图

```text
消除大量状态判断的 if-else，状态独立封装
```

### 结构

```java
// 状态接口
interface State {
    void handle();
}

// 具体状态
class PendingState implements State {
    public void handle() { System.out.println("待支付"); }
}
class PaidState implements State {
    public void handle() { System.out.println("已支付"); }
}

// 上下文
class Order {
    private State state;

    public void setState(State state) { this.state = state; }
    public void handle() { state.handle(); }
}
```

```text
状态模式 vs 策略模式：
状态 —— 对象内部状态变化（自动切换）
策略 —— 客户端选择策略（手动切换）
```

## 责任链模式 Chain of Responsibility

责任链模式让多个对象依次处理请求。

### 意图

```text
请求沿链传递，每个处理器决定处理还是传递
```

### 结构

```java
// 处理器接口
abstract class Handler {
    protected Handler next;

    public void setNext(Handler next) { this.next = next; }

    public abstract void handle(String request);
}

// 具体处理器
class AuthHandler extends Handler {
    public void handle(String request) {
        if (request.contains("auth")) {
            System.out.println("鉴权处理");
        } else if (next != null) {
            next.handle(request);   // 传递给下一个
        }
    }
}
```

### 场景：过滤器链、拦截器链

```java
// Servlet Filter 链、Spring Interceptor 链都是责任链
public interface Filter {
    void doFilter(request, response, FilterChain chain);   // chain 传递
}
```

## 迭代器模式 Iterator

迭代器模式提供统一的遍历方式，不暴露内部结构。

### 结构

```java
// Java 内置迭代器
List<String> list = new ArrayList<>();
Iterator<String> iterator = list.iterator();
while (iterator.hasNext()) {
    String item = iterator.next();
}
```

```text
迭代器模式在 Java 中已内置（Iterator 接口），
开发者直接用，无需自己实现
```

## 其他行为型模式

### 中介者模式 Mediator

```text
中介者：对象间通过中介者通信，避免网状依赖
场景：聊天室（用户通过聊天室通信）
```

### 备忘录模式 Memento

```text
备忘录：保存对象状态，支持恢复
场景：撤销、游戏存档
```

### 访问者模式 Visitor

```text
访问者：给一组对象添加新操作，不改对象本身
场景：语法树遍历、报表生成
```

### 解释器模式 Interpreter

```text
解释器：定义语法，解析执行
场景：正则表达式、SQL 解析、表达式计算
```

## 行为型模式总结

| 模式 | 意图 | 场景 |
|------|------|------|
| 观察者 | 状态变化通知 | 事件、消息 |
| 策略 | 算法互换 | 支付、排序 |
| 模板方法 | 定义流程骨架 | JdbcTemplate |
| 命令 | 封装请求 | 撤销、队列 |
| 状态 | 状态行为 | 订单状态 |
| 责任链 | 链式处理 | 过滤器链 |
| 迭代器 | 统一遍历 | 集合遍历 |
| 中介者 | 中心通信 | 聊天室 |
| 备忘录 | 状态保存 | 撤销 |
| 访问者 | 加新操作 | 语法树 |
| 解释器 | 解析执行 | 表达式 |

```text
使用建议：
1. 策略 —— 最常用（消除 if-else）
2. 观察者 —— 事件、消息（Spring 事件）
3. 模板方法 —— 框架（JdbcTemplate）
4. 责任链 —— 过滤器、拦截器
5. 状态 —— 状态机（订单、审批）
```
