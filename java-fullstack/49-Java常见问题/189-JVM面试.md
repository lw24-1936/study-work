## JVM 内存结构

**问题 1：JVM 内存结构？**

```text
JVM 运行时内存区域：
1. 堆（Heap）—— 对象实例（GC 管理，线程共享）
2. 栈（Stack）—— 方法调用、局部变量（线程私有）
3. 方法区（Method Area）—— 类信息、常量（线程共享）
4. 程序计数器（PC）—— 指令位置（线程私有）
5. 本地方法栈 —— native 方法（线程私有）
```

**问题 2：堆的结构？**

```text
堆分新生代和老年代：
1. 新生代（Young）—— Eden + Survivor0 + Survivor1（8:1:1）
2. 老年代（Old）—— 长期存活对象

对象分配：Eden → Survivor → 老年代
```

**问题 3：JDK 8 的内存变化？**

```text
JDK 7 之前：方法区 = 永久代（PermGen，堆内）
JDK 8 之后：方法区 = 元空间（Metaspace，本地内存）

好处：元空间动态扩展，不再有 PermGen OOM
```

## GC 垃圾回收

**问题 1：如何判断对象可回收？**

```text
1. 引用计数法 —— 有引用计数（有循环引用问题）
2. 可达性分析 —— 从 GC Roots 出发（主流）

GC Roots：栈引用、静态变量、常量、JNI 引用
```

**问题 2：GC 算法有哪些？**

```text
1. 标记-清除（Mark-Sweep）—— 有碎片
2. 标记-复制（Mark-Copy）—— 新生代（快，浪费空间）
3. 标记-整理（Mark-Compact）—— 老年代（无碎片，慢）
```

**问题 3：Minor GC 和 Full GC？**

```text
Minor GC —— 新生代 GC（频繁，快）
Major GC —— 老年代 GC
Full GC —— 整个堆 GC（慢，STW 长）
```

**问题 4：GC 收集器有哪些？**

```text
1. Serial —— 单线程（小应用）
2. Parallel —— 多线程，高吞吐（默认，JDK 8）
3. CMS —— 低延迟（已废弃）
4. G1 —— 区域化，可预测停顿（JDK 9+ 默认）
5. ZGC —— 极低延迟（大堆）
```

## 类加载与双亲委派

**问题 1：类加载过程？**

```text
类加载的 5 个阶段：
加载 → 验证 → 准备 → 解析 → 初始化

加载 —— 读取字节码
验证 —— 校验合法性
准备 —— 分配内存，赋默认值
解析 —— 符号引用转直接引用
初始化 —— 执行静态代码块
```

**问题 2：双亲委派模型？**

```text
双亲委派：类加载请求先委派给父加载器

加载顺序：
1. 先询问父加载器是否加载过
2. 父加载器能加载 → 父加载
3. 父加载器不能 → 子加载器加载
```

```text
类加载器层次：
Bootstrap ClassLoader（启动类加载器）
→ Extension ClassLoader（扩展类加载器）
→ Application ClassLoader（应用类加载器）
→ 自定义 ClassLoader
```

**问题 3：为什么用双亲委派？**

```text
1. 避免重复加载 —— 父加载器加载过，子不重复加载
2. 安全 —— 防止篡改核心类（如自定义 java.lang.String）
```

## G1 与 ZGC

**问题 1：G1 的特点？**

```text
G1（Garbage First）：
1. 区域化 —— 堆分成多个 Region
2. 可预测停顿 —— 设置停顿目标（-XX:MaxGCPauseMillis）
3. 优先回收垃圾最多的 Region（Garbage First）
4. 适合大堆（4G+）
```

**问题 2：ZGC 的特点？**

```text
ZGC（JDK 11+，JDK 15 正式）：
1. 极低停顿 —— 亚毫秒级（< 10ms）
2. 染色指针 —— 并发标记
3. 适合大堆（TB 级）+ 低延迟
```

## OOM 排查

**问题：OOM 如何排查？**

```text
1. 开启 HeapDump（-XX:+HeapDumpOnOutOfMemoryError）
2. 导出堆转储文件（heapdump.hprof）
3. 用 MAT 分析（大对象、泄漏对象）
4. 定位泄漏源（集合未清理、缓存无限增长）
5. 修复泄漏，验证
```

```text
常见 OOM 类型：
1. OutOfMemoryError: Java heap space —— 堆内存不足
2. OutOfMemoryError: Metaspace —— 元空间不足（类加载过多）
3. StackOverflowError —— 栈溢出（递归过深）
```
