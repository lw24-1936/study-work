## 集合框架总览

**问题：Java 集合框架有哪些？**

```text
Collection
├── List（有序，可重复）
│   ├── ArrayList（数组）
│   ├── LinkedList（链表）
│   └── Vector（线程安全，弃用）
├── Set（无序，不可重复）
│   ├── HashSet（哈希）
│   ├── LinkedHashSet（有序哈希）
│   └── TreeSet（排序）
└── Queue（队列）
    └── LinkedList / PriorityQueue

Map（键值对）
├── HashMap（哈希，线程不安全）
├── LinkedHashMap（有序）
├── TreeMap（排序）
├── ConcurrentHashMap（线程安全）
└── Hashtable（线程安全，弃用）
```

## HashMap 高频问题

**问题 1：HashMap 的底层结构？**

```text
JDK 7：数组 + 链表
JDK 8：数组 + 链表 + 红黑树（链表长度 >= 8 转红黑树）

数组（哈希桶）→ 哈希冲突用链表 → 长链表转红黑树
```

**问题 2：HashMap 的 put 流程？**

```text
1. 计算 key 的 hash（hashCode ^ (hashCode >>> 16)）
2. 计算索引：hash & (n - 1)
3. 该位置为空 → 直接放入
4. 有值（冲突）→ 链表追加 / 红黑树插入
5. 找到相同 key → 覆盖 value
6. size > 阈值（容量 × 0.75）→ 扩容（2 倍）
```

**问题 3：HashMap 为什么容量是 2 的幂？**

```text
1. 索引计算用 &（位运算快）：hash & (n - 1)
2. n 是 2 的幂，n-1 二进制全 1，哈希分布均匀
3. 扩容 2 倍，rehash 时部分元素位置不变
```

**问题 4：HashMap 为什么线程不安全？**

```text
1. JDK 7 并发扩容可能死循环（头插法）
2. 并发 put 可能丢数据
3. 并发场景用 ConcurrentHashMap
```

**问题 5：HashMap 和 Hashtable 的区别？**

```text
1. 线程安全 —— Hashtable 安全（synchronized），HashMap 不安全
2. 性能 —— HashMap 快，Hashtable 慢（全表锁）
3. null —— HashMap 允许 null key/value，Hashtable 不允许
4. 弃用 —— Hashtable 已被 ConcurrentHashMap 替代
```

## ConcurrentHashMap

**问题 1：ConcurrentHashMap 如何保证线程安全？**

```text
JDK 7 —— 分段锁（Segment），每段一把锁
JDK 8 —— CAS + synchronized

JDK 8 的机制：
1. 空位置 → CAS 无锁放入
2. 有值 → synchronized 锁单个节点（细粒度）
3. 读操作无锁（volatile 保证可见性）
```

**问题 2：ConcurrentHashMap 为什么高效？**

```text
1. 锁粒度细 —— 锁单个节点，不是整个表
2. CAS 无锁 —— 空位置直接 CAS
3. 读无锁 —— volatile 可见性
4. 并发度高 —— 多个线程操作不同节点互不阻塞
```

## ArrayList 与 LinkedList

**问题 1：ArrayList 和 LinkedList 的区别？**

| 维度 | ArrayList | LinkedList |
|------|-----------|------------|
| 底层 | 数组 | 双向链表 |
| 随机访问 | O(1) | O(n) |
| 头插/删除 | O(n) | O(1) |
| 尾插 | O(1)（均摊） | O(1) |
| 内存 | 连续（友好） | 分散（节点+指针） |

```text
使用建议：
1. 默认用 ArrayList（随机访问快）
2. 频繁头插/删除才用 LinkedList（少见）
```

**问题 2：ArrayList 的扩容机制？**

```text
1. 默认容量 10
2. 扩容 1.5 倍（oldCapacity + oldCapacity >> 1）
3. 扩容涉及数组复制（代价高，建议预分配容量）
```

## HashSet 与 TreeMap

**问题 1：HashSet 的底层实现？**

```text
HashSet 底层是 HashMap：
1. 元素作为 HashMap 的 key
2. value 是一个固定的 Object（PRESENT）
3. 利用 HashMap 的 key 唯一性实现去重
```

**问题 2：TreeMap 和 HashMap 的区别？**

| 维度 | TreeMap | HashMap |
|------|---------|---------|
| 底层 | 红黑树 | 哈希表 |
| 有序 | 有序（按 key 排序） | 无序 |
| 复杂度 | O(log n) | O(1) |
| null key | 不允许 | 允许 |

```text
使用建议：
1. 需要排序 → TreeMap
2. 快速查找 → HashMap（默认）
```
