## 一维数组

数组是固定长度的、存储同类型元素的有序容器。在 Java 中数组是对象，存在堆上。

```java
// 声明 + 初始化分开写
int[] arr;
arr = new int[5];        // 元素默认值 0

// 声明 + 初始化一起
int[] arr2 = new int[5];

// 声明 + 静态初始化
int[] arr3 = {1, 2, 3, 4, 5};
int[] arr4 = new int[]{1, 2, 3, 4, 5};  // 等价写法
```

两种声明风格 `int[] arr` 和 `int arr[]` 都合法，但 Googler 和绝大多数项目用 `int[] arr`——类型和变量名分开，更清晰。

数组长度通过 `.length` 属性获取（不是方法）：

```java
int[] arr = {10, 20, 30};
System.out.println(arr.length);  // 3
```

数组一旦创建，长度不可变。需要变长容器用 `ArrayList`。

## 二维与多维数组

```java
// 二维数组：数组的数组
int[][] matrix = new int[3][4];   // 3 行 4 列
matrix[0][0] = 1;
matrix[2][3] = 42;

// 静态初始化
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// Java 的二维数组是"锯齿形"的——每行可以不同长度
int[][] jagged = new int[3][];
jagged[0] = new int[2];   // 第 1 行 2 列
jagged[1] = new int[5];   // 第 2 行 5 列
jagged[2] = new int[3];   // 第 3 行 3 列
```

Java 没有真正的多维数组——所谓的"二维数组"就是一个数组，其中每个元素是另一个数组。这解释了为什么可以"锯齿"（每行长度不同）。

## 数组初始化

数组创建时，元素自动获得默认值：

| 元素类型 | 默认值 |
|---------|--------|
| `byte/short/int/long` | `0` |
| `float/double` | `0.0` |
| `char` | `'\u0000'`（空字符） |
| `boolean` | `false` |
| 引用类型（String 等） | `null` |

```java
int[] nums = new int[3];       // [0, 0, 0]
String[] names = new String[3]; // [null, null, null]
```

## 数组遍历

```java
int[] arr = {1, 2, 3, 4, 5};

// 方式 1：for 索引
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

// 方式 2：增强 for（最常用）
for (int num : arr) {
    System.out.println(num);
}
```

增强 for 无法获取索引。需要索引时（比如同时遍历两个数组、或者操作相邻元素），用传统的 `for (int i = 0; ...)`。

## 数组复制

```java
int[] src = {1, 2, 3, 4, 5};

// 方式 1：clone()
int[] copy1 = src.clone();

// 方式 2：Arrays.copyOf（推荐）
int[] copy2 = Arrays.copyOf(src, src.length);
int[] shorter = Arrays.copyOf(src, 3);     // [1, 2, 3]

// 方式 3：Arrays.copyOfRange
int[] partial = Arrays.copyOfRange(src, 1, 4); // [2, 3, 4]（含头不含尾）

// 方式 4：System.arraycopy（最底层，最快）
int[] dest = new int[5];
System.arraycopy(src, 0, dest, 0, src.length);
// 参数：源数组, 源起始, 目标数组, 目标起始, 复制长度
```

`System.arraycopy` 是 native 方法，性能最好。`Arrays.copyOf` 底层也调用 `System.arraycopy`。

> 直接 `=` 赋值不是复制，而是让两个引用指向同一个数组对象：
> ```java
> int[] a = {1, 2, 3};
> int[] b = a;
> b[0] = 999;
> System.out.println(a[0]);  // 999 — a 也被改了
> ```

## 数组排序

```java
int[] arr = {5, 2, 8, 1, 9};

// 升序排序（原地修改）
Arrays.sort(arr);            // [1, 2, 5, 8, 9]

// 部分排序：索引 1 到 4（含头不含尾）
Arrays.sort(arr, 1, 4);

// 对象数组排序：元素必须实现 Comparable 接口
String[] names = {"Charlie", "Alice", "Bob"};
Arrays.sort(names);          // ["Alice", "Bob", "Charlie"]

// 自定义比较器
String[] words = {"hello", "a", "world"};
Arrays.sort(words, (a, b) -> Integer.compare(a.length(), b.length()));
// ["a", "hello", "world"]
```

降序排序基本类型没有直接方法，需要转成包装类型或手动反转：

```java
// 基本类型降序：升序排序后手动反转
Arrays.sort(arr);
for (int i = 0; i < arr.length / 2; i++) {
    int temp = arr[i];
    arr[i] = arr[arr.length - 1 - i];
    arr[arr.length - 1 - i] = temp;
}

// Integer 降序
Integer[] boxed = {5, 2, 8, 1, 9};
Arrays.sort(boxed, Collections.reverseOrder());
```

## Arrays 工具类

`java.util.Arrays` 是数组的瑞士军刀：

```java
int[] arr = {3, 1, 4, 1, 5, 9};

// 转为字符串（调试用）
Arrays.toString(arr);                  // "[3, 1, 4, 1, 5, 9]"
Arrays.deepToString(matrix);           // 多维数组

// 二分查找（数组必须先排序）
Arrays.binarySearch(arr, 4);           // 返回索引，找不到返回负值

// 填充
Arrays.fill(arr, 0);                   // 全部填 0
Arrays.fill(arr, 1, 4, 100);           // 索引 1-3 填 100

// 判断相等
Arrays.equals(arr1, arr2);             // 一维数组
Arrays.deepEquals(arr2d1, arr2d2);     // 多维数组

// 生成 Stream（Java 8+）
Arrays.stream(arr).filter(n -> n > 3).sum();

// 并行排序（大数据量时有优势）
Arrays.parallelSort(arr);
```

## 可变参数

可变参数允许方法接受零个或多个同类型参数，本质是语法糖——编译后变成数组：

```java
// 声明：类型... 参数名
public static int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    return total;
}

// 调用
sum();              // 0
sum(1, 2);          // 3
sum(1, 2, 3, 4, 5); // 15
```

规则：
- 一个方法最多一个可变参数
- 可变参数必须在参数列表最后
- 和数组参数重载会导致歧义——尽量避免

```java
// main 方法的等价写法
public static void main(String... args) { }
```

## 数组与集合转换

```java
// 数组 → List
String[] arr = {"a", "b", "c"};

// 方式 1：Arrays.asList（固定大小，不能增删）
List<String> list1 = Arrays.asList(arr);
list1.set(0, "x");    // 可以修改元素
// list1.add("d");    // UnsupportedOperationException

// 方式 2：new ArrayList（可变大小，推荐）
List<String> list2 = new ArrayList<>(Arrays.asList(arr));
list2.add("d");       // 正常

// List → 数组
List<String> list = List.of("x", "y", "z");
String[] back = list.toArray(new String[0]);
// 传 new String[0] 是性能最优做法（JVM 会优化）
```

`Arrays.asList(arr)` 返回的是 Arrays 内部类 `ArrayList`（不是 `java.util.ArrayList`），大小固定。需要增删元素时手动包一层 `new ArrayList<>(...)`。
