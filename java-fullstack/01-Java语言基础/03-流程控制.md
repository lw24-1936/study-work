## if / if-else

```java
// 单分支
if (score >= 60) {
    System.out.println("及格");
}

// 双分支
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// 多分支
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else if (score >= 70) {
    System.out.println("C");
} else {
    System.out.println("D");
}
```

条件表达式必须是 `boolean` 类型——Java 没有"非零即真"的概念。

```java
int x = 1;
// if (x) { }    // 编译错误，int 不能当 boolean 用
if (x != 0) { }  // 正确
```

单行语句可以省略大括号，但实践中始终写大括号——避免后面加代码时忘记补、缩进骗过眼睛。Google Java Style Guide 强制要求大括号。

## switch / switch 表达式

### 传统 switch

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("周一");
        break;              // 没有 break 会穿透到下一个 case
    case 2:
        System.out.println("周二");
        break;
    case 3:
    case 4:                 // 多个 case 共用同一段逻辑
        System.out.println("周三或周四");
        break;
    default:
        System.out.println("其他");
}
```

switch 的匹配条件类型：`byte`, `short`, `int`, `char`, `String`（Java 7+），`enum`（Java 5+）。

没有 `break` 会**穿透（fall-through）**到下一个 case——这是设计上的"特性"，实际开发中 90% 是 bug。如果需要刻意穿透，用注释标注 `// fall through`。

### switch 表达式（Java 14+）

有返回值、不用 break 的 switch：

```java
// 箭头语法
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "无效";
};

// 带代码块的箭头语法
String desc = switch (status) {
    case 0 -> {
        System.out.println("处理中...");
        yield "待处理";         // yield 返回值
    }
    case 1 -> "已完成";
    default -> "未知";
};
```

switch 表达式是 Java 12 预览、Java 14 正式引入。`yield` 关键字只在 switch 表达式的代码块中使用。

## for 循环

### 传统 for

```java
for (初始化; 条件; 更新) {
    // 循环体
}

for (int i = 0; i < 10; i++) {
    System.out.println(i);     // 0 到 9
}
```

三个表达式都可以省略（但分号不能省）：

```java
// 相当于 while(true)
for (;;) {
    // 无限循环
}
```

初始化部分声明的变量作用域仅限于 for 循环体：

```java
for (int i = 0; i < 10; i++) { }
System.out.println(i);        // 编译错误：i 在作用域外
```

### 增强 for（for-each）

```java
int[] arr = {1, 2, 3, 4, 5};
for (int num : arr) {
    System.out.println(num);
}

List<String> list = List.of("a", "b", "c");
for (String s : list) {
    System.out.println(s);
}
```

增强 for 遍历时不能修改集合结构（增删元素），否则抛 `ConcurrentModificationException`。如果需要边遍历边删除，用 Iterator 的 `remove()` 或 `removeIf()`。

## while / do-while

```java
// while：先判断，再执行
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

// do-while：先执行一次，再判断
int j = 0;
do {
    System.out.println(j);
    j++;
} while (j < 5);
```

do-while 保证循环体至少执行一次。典型场景：用户输入校验——不管用户输入什么，至少问一次。

## break / continue / return

### break

跳出当前循环（只跳出一层）：

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;            // 整个循环终止
    }
    System.out.println(i); // 输出 0-4
}
```

### continue

跳过当前迭代，进入下一轮：

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;          // 偶数跳过
    }
    System.out.println(i); // 输出 1, 3, 5, 7, 9
}
```

### return

return 直接结束方法执行。在循环中使用 return 会同时结束循环和所在方法：

```java
public int find(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;        // 找到就返回，方法结束
        }
    }
    return -1;               // 没找到
}
```

## 嵌套循环与标签语句

### 嵌套循环

任意循环可以嵌套：

```java
// 九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println();
}
```

### 标签语句

`break` 和 `continue` 默认只作用于最内层循环。标签可以指定跳出到哪一层：

```java
// 带标签的 break
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            break outer;          // 跳出 outer 标记的外层循环
        }
        System.out.println(i + "," + j);
    }
}
// 输出: 0,0  0,1  0,2  1,0

// 带标签的 continue
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) {
            continue outer;       // 跳到 outer 循环的下一轮
        }
        System.out.println(i + "," + j);
    }
}
// 输出: 0,0  1,0  2,0 — 每轮内层的 j 到 1 就跳过整个外层迭代
```

标签语法在实际项目中极少使用——如果需要标签来跳出循环，通常意味着这段逻辑应该重构为单独的方法，用 `return` 退出。但面试可能会考，JDK 源码中也有少量用法。
