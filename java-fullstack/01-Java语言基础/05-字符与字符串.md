## char 类型

`char` 是 2 字节无符号整数，存储 UTF-16 编码的一个代码单元（code unit）。

```java
char c1 = 'A';           // 字面量
char c2 = 65;            // ASCII 码
char c3 = '\u0041';      // Unicode 转义
char c4 = '\n';          // 转义字符（换行）
char c5 = '\t';          // 制表符
char c6 = '\\';          // 反斜杠本身
```

常用转义字符：

| 转义序列 | 含义 |
|---------|------|
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\uXXXX` | Unicode 字符（4 位十六进制） |

`char` 参与算术运算时自动提升为 `int`：

```java
char c = 'A';
int i = c + 1;       // 66
char c2 = (char) i;  // 'B'
```

> Java 的 `char` 只用 2 字节（U+0000 ~ U+FFFF），超出 BMP（基本多语言平面）的字符（如部分 emoji、罕见汉字）需要两个 char 表示（代理对，surrogate pair）。处理 Unicode 文本时用 `String.codePointAt()` 而不是 `charAt()`。

## String 基础

String 不是基本类型，是 `java.lang.String` 类的实例。但因为用得太频繁，Java 给了它特殊待遇——可以直接用字面量创建。

```java
String s1 = "hello";                    // 字面量
String s2 = new String("hello");        // 构造器（几乎不用）
char[] chars = {'h', 'e', 'l', 'l', 'o'};
String s3 = new String(chars);          // 从 char 数组创建
```

## String 常量池与不可变性

### 不可变性

String 对象一旦创建，内容就不可修改。所有看似"修改"字符串的操作（concat、replace、substring 等）实际上都返回一个新的 String 对象，原对象毫发无损。

```java
String s = "hello";
s.toUpperCase();          // 返回 "HELLO"，但 s 还是 "hello"
s = s.toUpperCase();      // 把新对象的引用赋给 s
```

不可变性的好处：
- **线程安全**：多线程随便读，不需要同步
- **可以池化**：相同内容的字符串复用同一个对象
- **hash 缓存**：String 对象缓存 `hashCode()`，HashMap 的 key 查找更快

### 常量池

字符串常量池是 JVM 方法区（Java 8 后是 Metaspace）中的一块特殊区域。直接用字面量创建的字符串会放在池里，相同内容复用同一个对象。

```java
String a = "hello";
String b = "hello";
System.out.println(a == b);          // true — 同一个对象

String c = new String("hello");
System.out.println(a == c);          // false — new 强制在堆上创建新对象
System.out.println(a.equals(c));     // true — 内容相同
```

`intern()` 方法可以手动将字符串放入常量池：

```java
String s1 = new String("hello");
String s2 = s1.intern();              // 返回常量池中的 "hello"
System.out.println(s1 == s2);         // false，s1 在堆上，s2 在池中

String s3 = "hello";
System.out.println(s2 == s3);         // true
```

日常开发不需要手动调用 `intern()`，JVM 自动管理常量池。知道它的存在有助于理解 `==` 和 `equals` 在不同场景下的行为差异。

## StringBuilder 与 StringBuffer

字符串拼接在循环中会产生大量中间对象，应该用可变字符串类：

```java
// 低效写法：每次 + 都创建新 String 对象
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i;               // 每次创建新对象，大量 GC
}

// 正确写法
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString(); // 只产生一个最终对象
```

| 类 | 线程安全 | 性能 | 适用场景 |
|----|---------|------|----------|
| `String` | 不可变，天然安全 | — | 少量拼接、字符串常量 |
| `StringBuilder` | 否 | 快 | **单线程拼接（首选）** |
| `StringBuffer` | 是（方法都加 synchronized） | 慢 | 多线程拼接（极少见） |

常用方法：

```java
StringBuilder sb = new StringBuilder();
sb.append("Hello");              // 追加
sb.append(" ").append("World");  // 链式调用
sb.insert(5, ",");               // 指定位置插入
sb.delete(5, 6);                 // 删除
sb.replace(0, 5, "Hi");          // 替换
sb.reverse();                    // 反转
sb.charAt(0);                    // 取字符
sb.length();                     // 长度
sb.setLength(0);                 // 清空（比 new 高效）
String result = sb.toString();   // 转 String
```

## 字符编码

字符和字节之间的映射关系。常见编码：

| 编码 | 说明 |
|------|------|
| ASCII | 7 位，128 个字符，英语够用 |
| ISO-8859-1 | 8 位，覆盖西欧语言 |
| GBK / GB2312 | 中文编码，GBK 兼容 GB2312 |
| UTF-8 | **现代标准**，变长 1-4 字节，完全兼容 ASCII |
| UTF-16 | Java 内部使用，基本字符 2 字节，辅助平面 4 字节 |

```java
// String → 字节
byte[] utf8 = "你好".getBytes(StandardCharsets.UTF_8);
byte[] gbk = "你好".getBytes(Charset.forName("GBK"));

// 字节 → String
String s1 = new String(utf8, StandardCharsets.UTF_8);
String s2 = new String(gbk, Charset.forName("GBK"));

// 乱码场景：UTF-8 编码的字节用 GBK 解码
byte[] data = "你好".getBytes(StandardCharsets.UTF_8);
String garbled = new String(data, Charset.forName("GBK"));
// 输出乱码："浣犲ソ"
```

> 始终显式指定编码，不要依赖 `getBytes()` 的无参版本（使用平台默认编码，Windows 上是 GBK，Linux 上是 UTF-8）。

## 字符串常用操作

```java
String s = "hello world";

// 比较
s.equals("hello world");                      // 内容相等（敏感大小写）
s.equalsIgnoreCase("HELLO WORLD");            // 忽略大小写
s.compareTo("abc");                           // 字典序比较

// 查找
s.contains("world");                          // true
s.startsWith("hel");                          // true
s.endsWith("rld");                            // true
s.indexOf('o');                               // 4（首次出现位置）
s.lastIndexOf('o');                           // 7（末次出现位置）
s.indexOf("wor");                             // 6

// 截取（含头不含尾）
s.substring(6);                               // "world"
s.substring(0, 5);                            // "hello"
s.charAt(0);                                  // 'h'

// 替换
s.replace('l', 'L');                          // "heLLo worLd"
s.replace("hello", "hi");                     // "hi world"
s.replaceAll("\\s+", "_");                    // 正则替换："hello_world"
s.replaceFirst("l", "L");                     // "heLlo world"

// 分割
String[] parts = "a,b,c".split(",");           // ["a", "b", "c"]
// 注意：split 的参数是正则表达式
"a.b.c".split(".");                           // [] — . 在正则中匹配任意字符
"a.b.c".split("\\.");                         // ["a", "b", "c"]

// 去空格
"  hello  ".trim();                           // "hello"（只去首尾 ASCII 空格）
"  hello  ".strip();                          // "hello"（Java 11+，去了 Unicode 空格）

// 格式化
String.format("Hello, %s! You have %d messages.", "Tom", 3);
// "Hello, Tom! You have 3 messages."
// %s=字符串, %d=整数, %f=浮点, %.2f=保留两位

// 其他
s.length();                                    // 11
s.isEmpty();                                   // false
s.isBlank();                                   // false（Java 11+，空白字符串返回 true）
"".isEmpty();                                  // true
"   ".isBlank();                               // true
```

## Text Blocks

Java 13 预览、Java 15 正式引入。用三个双引号包裹多行字符串：

```java
// 老写法
String json = "{\n" +
              "  \"name\": \"Tom\",\n" +
              "  \"age\": 25\n" +
              "}";

// Text Blocks（Java 15+）
String json = """
    {
      "name": "Tom",
      "age": 25
    }
    """;

// SQL
String sql = """
    SELECT id, name, email
    FROM users
    WHERE status = 'active'
    ORDER BY created_at DESC
    """;
```

Text Blocks 的缩进规则：以**内容行中最左边非空格的列**为基准，删除每行前面等量的空格。尾部的三个引号控制缩进基准——如果放在一行末尾，闭合引号位置不计入基准。

```java
// 这三个写法不等价
String s1 = """
    hello
    """;              // "hello\n" — 闭合引号在单独行

String s2 = """
    hello
""";                  // "    hello\n" — 闭合引号和内容同缩进
```

`\`（续行符）可以阻止换行，`\s` 保留行尾空格：

```java
String s = """
    SELECT id, name \
    FROM users \
    WHERE id > 100
    """;
// "SELECT id, name FROM users WHERE id > 100\n"
```
