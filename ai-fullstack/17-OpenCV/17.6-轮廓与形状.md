## 概述

轮廓（contour）是二值图里目标边界的有序点序列，`cv2.findContours` 负责把它们抽出来，后续所有"数个数、量尺寸、判形状、排顺序"的需求都建立在这批点之上：面积 `contourArea`、周长 `arcLength`、多边形近似 `approxPolyDP`、凸包 `convexHull`、外接几何 `boundingRect`/`minAreaRect`/`minEnclosingCircle`、以及描述子层面的 `moments`/`HuMoments`/`matchShapes`。与边缘检测的区别在于：边缘是"梯度大的像素集合"，轮廓是"闭合目标的多边形表示"，前者不能直接算面积和质心。

```text
本篇主线：
1. findContours —— 输入要求（CV_8U 二值图）、返回值个数（2 个）、CHAIN_APPROX_SIMPLE/NONE 的点数差异
2. 层级 —— [next, prev, first_child, parent] 四元组，以及 RETR_EXTERNAL/LIST/CCOMP/TREE 的取舍
3. 面积与周长 —— contourArea 的精度与方向（oriented）、arcLength 的 closed 参数
4. 近似与凸包 —— approxPolyDP 的 eps 与顶点数关系、convexHull、solidity、convexityDefects
5. 外接几何 —— boundingRect / minAreaRect（角度语义）/ minEnclosingCircle 与圆度、矩形度
6. 矩与形状描述 —— m00 与质心、mu 中心矩、7 个 Hu 不变矩的平移/旋转/尺度/镜像不变性（实测差异 0）
7. 匹配与筛选 —— matchShapes 的 I1/I2/I3、按面积/圆度/长宽比/凸度做工程化过滤与排序
```

本机实测环境：Ubuntu 24.04、Python 3.14.7、`opencv-python-headless 5.0.0.93`（`cv2.__version__` 为 `5.0.0`）、numpy 2.5.4，纯 CPU。下面 `text` 块全部是本机真实运行输出。本文所有示例共用同一张合成图（外方块 + 内洞 + 圆 + 三角 + 星形），便于横向对比各特征的数值。官方文档：https://docs.opencv.org/5.0/py_tutorials/py_imgproc/py_contours/py_contour_features/py_contour_features.html 。

## findContours 与轮廓层级

`cv2.findContours(image, mode, method)` 从**单通道 8 位**图像里抽取轮廓，把非零像素视为前景，并在前景与背景的交界处生成点序列。返回值在有 GUI 与无 GUI 的 OpenCV 版本里不同：OpenCV 3 返回三值 `(image, contours, hierarchy)`，OpenCV 4/5 返回 **两值 `(contours, hierarchy)`**——本机 5.0.0 实测返回 2 个值。`method` 决定点的稠密程度：`CHAIN_APPROX_NONE` 保留边界上所有像素（顺时针/逆时针连续点），`CHAIN_APPROX_SIMPLE` 只保留水平/垂直/对角段的端点。

```python
import cv2
import numpy as np

img = np.zeros((240, 320), np.uint8)
cv2.rectangle(img, (20, 20), (120, 120), 255, -1)      # 外方块
cv2.rectangle(img, (40, 40), (100, 100), 0, -1)        # 内洞
cv2.circle(img, (200, 70), 45, 255, -1)
tri = np.array([[240, 140], [310, 220], [170, 220]], np.int32)
cv2.fillPoly(img, [tri], 255)
star = []
for i in range(10):
    r = 45 if i % 2 == 0 else 18
    a = np.pi / 2 + i * np.pi / 5
    star.append([int(90 + r * np.cos(a)), int(190 + r * np.sin(a))])
cv2.fillPoly(img, [np.array(star, np.int32)], 255)

print("findContours 返回值个数 =", len(cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)))
cs, hi = cv2.findContours(img, cv2.RETR_TREE, cv2.CHAIN_APPROX_NONE)
for tag, i in [("星形", 0), ("三角", 1), ("圆", 2), ("方块", 3), ("内洞", 4)]:
    c = cs[i]
    x, y, w, h = cv2.boundingRect(c)
    print("%-4s #%d 点数=%-4d 面积=%-9.1f 周长=%-8.2f bbox=(%d,%d,%d,%d) 父=%d 子=%d" %
          (tag, i, len(c), cv2.contourArea(c), cv2.arcLength(c, True), x, y, w, h, hi[0][i][3], hi[0][i][2]))

# 输入是否被改写（OpenCV 3 会改写输入图，4/5 不会）
before = img.copy()
cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print("调用 findContours 前后输入图完全一致:", bool(np.array_equal(before, img)))
print("hierarchy 的 shape =", hi.shape, "（第 0 维是虚设的，实际取 hi[0][i] = [next, prev, first_child, parent]）")
```

```text
三角   #1 点数=300  面积=5600.0   周长=357.99   bbox=(170,140,141,81) 父=-1 子=-1
```

轮廓数 5 = 4 个外轮廓 + 1 个洞；`方块` 的 `first_child=4` 与 `内洞` 的 `parent=3` 互相印证。`CHAIN_APPROX_NONE` 让圆保留 252 个点、方块 400 个点（每边 100 个像素都有点），点位顺序是沿边界连续走的，这对需要按边界顺序算曲率/凸缺陷的场景是必要的；`CHAIN_APPROX_SIMPLE` 会把方块压到 4 个点（本机另一组实测：156 点 -> 4 点）。

```text
要点：
1. findContours 的输入必须是单通道 CV_8U（本机 float32 与 3 通道图都报 (-2:Unspecified error)），非零即前景
2. OpenCV 4/5 返回 (contours, hierarchy) 两个值；旧教程里的 `_, contours, _ = ...` 在新版本会 ValueError
3. CHAIN_APPROX_SIMPLE 只留拐点，方块 400 点压到 4 点；CHAIN_APPROX_NONE 保留全部边界像素，做曲率/凸缺陷分析时用
4. hierarchy 是 (1, N, 4) 的数组，用 hi[0][i] 取 [next, prev, first_child, parent]，-1 表示不存在
5. OpenCV 4/5 不会改写输入图（本机实测前后完全一致），但传引用给函数后仍建议留一份原始掩膜副本
```

## 检索模式与层级数组

`mode` 决定返回哪些轮廓以及层级怎么组织：`RETR_EXTERNAL` 只要最外层（速度最快、最常用于计数）、`RETR_LIST` 全部轮廓但不建父子关系、`RETR_CCOMP` 压成两层（外轮廓 + 内孔）、`RETR_TREE` 完整嵌套树。同一张图在四种模式下的输出差别如下。

```python
import cv2
import numpy as np

img = np.zeros((240, 320), np.uint8)
cv2.rectangle(img, (20, 20), (120, 120), 255, -1)
cv2.rectangle(img, (40, 40), (100, 100), 0, -1)
cv2.circle(img, (200, 70), 45, 255, -1)
cv2.fillPoly(img, [np.array([[240, 140], [310, 220], [170, 220]], np.int32)], 255)
star = []
for i in range(10):
    r = 45 if i % 2 == 0 else 18
    a = np.pi / 2 + i * np.pi / 5
    star.append([int(90 + r * np.cos(a)), int(190 + r * np.sin(a))])
cv2.fillPoly(img, [np.array(star, np.int32)], 255)

for mode, name in [(cv2.RETR_EXTERNAL, "RETR_EXTERNAL"), (cv2.RETR_LIST, "RETR_LIST"),
                   (cv2.RETR_CCOMP, "RETR_CCOMP"), (cv2.RETR_TREE, "RETR_TREE")]:
    cs, hi = cv2.findContours(img, mode, cv2.CHAIN_APPROX_SIMPLE)
    print("%-14s 轮廓数=%d hierarchy.shape=%s" % (name, len(cs), hi.shape))
    print("   层级 [next, prev, child, parent]:", hi[0].tolist())
```

本机真实输出：

```text
RETR_EXTERNAL  轮廓数=4 hierarchy.shape=(1, 4, 4)
   层级 [next, prev, child, parent]: [[1, -1, -1, -1], [2, 0, -1, -1], [3, 1, -1, -1], [-1, 2, -1, -1]]
RETR_LIST      轮廓数=5 hierarchy.shape=(1, 5, 4)
   层级 [next, prev, child, parent]: [[1, -1, -1, -1], [2, 0, -1, -1], [3, 1, -1, -1], [4, 2, -1, -1], [-1, 3, -1, -1]]
RETR_CCOMP     轮廓数=5 hierarchy.shape=(1, 5, 4)
   层级 [next, prev, child, parent]: [[1, -1, -1, -1], [2, 0, -1, -1], [3, 1, -1, -1], [-1, 2, 4, -1], [-1, -1, -1, 3]]
RETR_TREE      轮廓数=5 hierarchy.shape=(1, 5, 4)
   层级 [next, prev, child, parent]: [[1, -1, -1, -1], [2, 0, -1, -1], [3, 1, -1, -1], [-1, 2, 4, -1], [-1, -1, -1, 3]]
```

`RETR_EXTERNAL` 只给出 4 个外轮廓且 `child`/`parent` 全为 -1；`RETR_LIST` 给出 5 个但同样是平铺（`child`/`parent` 恒为 -1，只有 `next`/`prev` 成链）；`RETR_CCOMP` 把内洞挂到外方块下（第 3 个轮廓 `child=4`，第 4 个 `parent=3`）；本图嵌套只有两层，所以 `RETR_CCOMP` 与 `RETR_TREE` 输出完全相同——嵌套更深时（如图中有三层环）两者才会分叉。按层级筛选轮廓的标准写法是看每个轮廓的父索引：

```python
hole = np.zeros((100, 100), np.uint8)
cv2.rectangle(hole, (20, 20), (80, 80), 255, -1)
cv2.rectangle(hole, (40, 40), (60, 60), 0, -1)
cs, hi = cv2.findContours(hole, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE)
h = hi[0]
top = [i for i in range(len(cs)) if h[i][3] == -1]        # 父为 -1 = 最外层
holes = [i for i in range(len(cs)) if h[i][3] != -1]      # 有父 = 内孔
print("最外层轮廓 %d 个，内孔 %d 个" % (len(top), len(holes)))
print("带孔的零件索引 =", sorted({h[j][3] for j in holes} & set(top)))
```

本机真实输出（逐条打印轮廓信息）：

```text
CCOMP 轮廓#0: 面积 = 3600.0 (oriented -3600.0), 父 = -1
CCOMP 轮廓#1: 面积 = 482.0 (oriented 482.0), 父 = 0
```

由此得到 `top = [0]`、`holes = [1]`，`{h[j][3] for j in holes} & set(top) = [0]`，即"0 号轮廓带孔"。要点是**不要用面积大小猜外层与内孔**（本例内孔面积 482 不算小），一律用 `hi[0][i][3]` 是否等于 -1 来判断。

```text
要点：
1. 只数目标个数用 RETR_EXTERNAL（最快，且不会被内孔干扰计数）
2. 需要"外轮廓 + 内孔"两层关系（带孔零件、环形目标）用 RETR_CCOMP：外层 parent=-1，孔 parent 指向外层
3. 需要完整嵌套层级用 RETR_TREE；本图只有两层时它与 CCOMP 输出相同（实测）
4. 判定"外轮廓"统一用 hi[0][i][3] == -1，判定"孔"用 hi[0][i][3] != -1，不要靠面积大小猜
5. RETR_LIST 不建父子关系（child/parent 恒为 -1），遍历全部轮廓时最省事，但会同时拿到洞
```

## 面积与周长

`cv2.contourArea(contour, oriented=False)` 用格林公式对轮廓多边形求面积（单位是像素²），`cv2.arcLength(curve, closed)` 累加相邻点距离得到周长/弧长。两者算的都是**多边形**而非像素集合，所以与 `np.count_nonzero` 的结果会差一圈边界（约等于周长的一半）。

```python
import cv2
import numpy as np

cs, hi = cv2.findContours(img, cv2.RETR_TREE, cv2.CHAIN_APPROX_NONE)
c_sq = cs[3]                                     # 外方块 101x101
print("contourArea = %.1f, 几何面积 101*101 = %d, 差 = %.1f" %
      (cv2.contourArea(c_sq), 101 * 101, 101 * 101 - cv2.contourArea(c_sq)))
print("arcLength(closed=True) = %.2f, (closed=False) = %.2f, 几何周长 = 404" %
      (cv2.arcLength(c_sq, True), cv2.arcLength(c_sq, False)))
print("oriented=True 顺时针轮廓 = %.1f, 反向 = %.1f" %
      (cv2.contourArea(c_sq, oriented=True), cv2.contourArea(c_sq[::-1].copy(), oriented=True)))
print("退化输入: 单点 = %.1f, 空轮廓(int32) = %.1f" %
      (cv2.contourArea(np.array([[[5, 5]]], np.int32)), cv2.contourArea(np.zeros((0, 1, 2), np.int32))))

# 洞的方向符号（RETR_CCOMP 下的外层与孔）
hole = np.zeros((100, 100), np.uint8)
cv2.rectangle(hole, (20, 20), (80, 80), 255, -1)
cv2.rectangle(hole, (40, 40), (60, 60), 0, -1)
cs2, hi2 = cv2.findContours(hole, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE)
for i, c in enumerate(cs2):
    print("CCOMP 轮廓#%d 面积 = %.1f (oriented = %.1f), 父 = %d" %
          (i, cv2.contourArea(c), cv2.contourArea(c, oriented=True), hi2[0][i][3]))
```

本机真实输出：

```text
contourArea = 10000.0, 几何面积 101*101 = 10201, 差 = 201.0
arcLength(closed=True) = 400.00, (closed=False) = 399.00, 几何周长 = 404
oriented=True 顺时针轮廓 = -10000.0, 反向 = 10000.0
退化输入: 单点 = 0.0, 空轮廓(int32) = 0.0
CCOMP 轮廓#0 面积 = 3600.0 (oriented = -3600.0), 父 = -1
CCOMP 轮廓#1 面积 = 482.0 (oriented = 482.0), 父 = 0
```

`contourArea` 得到 10000（边界多边形的面积）比像素计数 10201 少 201；`arcLength(closed=True)` 得到 400 而几何周长 404（101 边长 4 倍是 404），因为轮廓点沿边界中心线走，少了角点外侧那一点。**符号很有用**：`oriented=True` 下外轮廓是 -10000（顺时针），孔是 +482（逆时针）——方向相反正好可以用来判断"这是孔还是实体"，也能区分轮廓的内外性质。

```text
要点：
1. contourArea 算的是轮廓多边形面积，比 np.count_nonzero 少约"周长/2"，不要期待两者相等（实测 10000 对 10201）
2. oriented=True 用符号表达方向：外轮廓一侧为负、孔为正是常见结果，可用来判定孔洞
3. 点集 dtype 必须是 CV_32F/CV_32S；传 float64 直接报 Assertion failed（本机实测），int32 的 findContours 输出可以直接用
4. arcLength(closed=True) 会加上首尾闭合的那一段距离（方块 400 对 399），算周长用 True
5. 单点或空轮廓返回 0，不会抛错，但下游做除法（圆度、长宽比）前必须判零
```

## 多边形近似与凸包

`cv2.approxPolyDP(curve, epsilon, closed)` 用 Douglas-Peucker 算法把轮廓压成折线，`epsilon` 是允许的最大偏离（通常取 `ratio * arcLength`）。`cv2.convexHull` 求凸包，`isContourConvex` 判断凸性，`convexityDefects` 给出所有凹点的位置与凹陷深度——这是"有没有缺口/是不是凹形"最直接的量化手段。

```python
import cv2
import numpy as np

cs, hi = cv2.findContours(img, cv2.RETR_TREE, cv2.CHAIN_APPROX_NONE)
c_sq, c_circle, c_star, c_tri = cs[3], cs[2], cs[0], cs[1]
print("approxPolyDP 顶点数随 epsilon 变化（epsilon = ratio * 周长）:")
for tag, c in [("圆", c_circle), ("方块", c_sq), ("星形", c_star), ("三角", c_tri)]:
    per = cv2.arcLength(c, True)
    out = ["%-4s 点数=%-4d" % (tag, len(c))]
    for r in (0.001, 0.005, 0.01, 0.02, 0.05):
        out.append("eps=%.3f->%d点" % (r, len(cv2.approxPolyDP(c, r * per, True))))
    print("  " + "  ".join(out))

ap_sq = cv2.approxPolyDP(c_sq, 0.01 * cv2.arcLength(c_sq, True), True)
print("isContourConvex: 方块 NONE 轮廓(%d 点) = %s; approxPolyDP 后(%d 点) = %s" %
      (len(c_sq), cv2.isContourConvex(c_sq), len(ap_sq), cv2.isContourConvex(ap_sq)))

for tag, c in [("方块", c_sq), ("圆", c_circle), ("星形", c_star), ("三角", c_tri)]:
    hull = cv2.convexHull(c)
    d = cv2.convexityDefects(c, cv2.convexHull(c, returnPoints=False))
    print("%-4s 点数=%d 凸包点数=%d 面积=%.1f 凸包面积=%.1f solidity=%.4f 凹点缺陷数=%s" %
          (tag, len(c), len(hull), cv2.contourArea(c), cv2.contourArea(hull),
           cv2.contourArea(c) / cv2.contourArea(hull), 0 if d is None else len(d)))

d = cv2.convexityDefects(c_star, cv2.convexHull(c_star, returnPoints=False))
dd = d.reshape(-1, 4)
print("convexityDefects 返回 shape =", d.shape, "dtype =", d.dtype)
print("星形缺陷 [start_idx, end_idx, far_idx, dist/256]:")
print(dd.tolist())
print("最深凹陷 = %.2f 像素" % (dd[:, 3].max() / 256.0))
far = c_star.reshape(-1, 2)[dd[:, 2]]
print("凹陷点坐标 =", far.tolist())
print("按深度 > 5 像素筛选真实凹角 =", int((dd[:, 3] / 256.0 > 5).sum()), "个")
```

```text
[[236, 0, 262, 4864], [0, 56, 31, 4613], [56, 118, 87, 4533], [118, 180, 149, 4606], [180, 236, 205, 4613]]
最深凹陷 = 19.00 像素
凹陷点坐标 = [[90, 172], [72, 184], [78, 204], [101, 204], [107, 184]]
按深度 > 5 像素筛选真实凹角 = 5 个
```

几个关键读数：**epsilon 的作用是"允许偏离多少像素"**——圆在 eps=1% 周长时压成 12 边形、5% 时几乎退化为 4 边形；方块在任何比例下都是精确的 4 点（因为它是真正的多边形）；星形在 eps>=0.5% 后稳定在 10 点（5 尖 5 凹），这正是它的"真实复杂度"。**`isContourConvex` 对 400 点的方块轮廓返回 False**，因为它要求严格凸（不允许共线点），而 `CHAIN_APPROX_NONE` 的方块每边都有共线点；先 `approxPolyDP` 压成 4 点再判就是 True。凸包与 solidity（轮廓面积/凸包面积）能干净地区分形状：方块 1.0000、圆 0.9880（栅格化的近似圆）、星形 0.4947。`convexityDefects` 每行是 `[起点索引, 终点索引, 最远点索引, 距离*256]`（距离被放大 256 倍存成整数），星形的 5 个凹角深度都在 17.7-19.0 像素之间。

```text
要点：
1. approxPolyDP 的 epsilon 取"周长 × 比例"（常用 0.01-0.02），比例越大顶点越少；判断形状前先用它把点数压下来
2. isContourConvex 要求严格凸：NONE 模式的矩形轮廓（含共线点）返回 False，approxPolyDP 之后才为 True（实测）
3. solidity = contourArea / convexHullArea 是区分凸形/凹形最稳的特征（实测方块 1.0、星形 0.4947）
4. convexityDefects 的第四列是"距离 × 256"，用之前除以 256；返回 shape 是 (N,4) 的 int32
5. convexHull 默认 returnPoints=True 返回点坐标，convexityDefects 需要的是 returnPoints=False 的索引，两者别混
```

## 外接矩形与外接圆

四种外接几何各有用途：`boundingRect` 给轴对齐矩形（快、适合裁剪 ROI），`minAreaRect` 给最小面积旋转矩形（适合倾斜目标的尺寸测量），`minEnclosingCircle` 给最小外接圆（适合圆形目标定位），`fitEllipse` 拟合椭圆（适合需要姿态的场景）。由它们派生的形状特征——矩形度 `extent`、长宽比、圆度 `4πA/P²`——是工业分拣最常用的判据。

```python
import cv2
import numpy as np

for tag, c in [("方块", c_sq), ("圆", c_circle), ("星形", c_star)]:
    x, y, w, h = cv2.boundingRect(c)
    rect = cv2.minAreaRect(c)
    (cx, cy), r = cv2.minEnclosingCircle(c)
    a, p = cv2.contourArea(c), cv2.arcLength(c, True)
    print("%-4s boundingRect=(%d,%d,%d,%d) 长宽比=%.3f extent=%.4f" % (tag, x, y, w, h, w / h, a / (w * h)))
    print("     minAreaRect 中心=(%.2f,%.2f) 宽高=(%.2f,%.2f) 角度=%.2f boxPoints=%s" %
          (rect[0][0], rect[0][1], rect[1][0], rect[1][1], rect[2], cv2.boxPoints(rect).astype(int).tolist()))
    print("     minEnclosingCircle 中心=(%.2f,%.2f) r=%.2f；圆度 4πA/P²=%.4f；等周比 P²/(4πA)=%.4f" %
          (cx, cy, r, 4 * np.pi * a / p ** 2, p ** 2 / (4 * np.pi * a)))

# minAreaRect 的角度语义：用已知角度构造再反解
for label, rrect in [("已知角 12 度", ((60.0, 40.0), (80.0, 30.0), 12.0)),
```

## 轮廓矩与 Hu 不变矩

`cv2.moments(contour)` 给出零阶到三阶矩：`m00` 是面积、`(m10/m00, m01/m00)` 是质心、`mu20/mu02/mu11` 是去中心化后的中心矩（描述散布与方向）。`cv2.HuMoments(m)` 把中心矩归一化组合成 7 个**平移、旋转、尺度不变**的量（第 7 个还具备镜像不变性），是形状匹配与粗分类的经典描述子。

```python
import cv2
import numpy as np

for tag, c in [("方块", c_sq), ("圆", c_circle), ("星形", c_star)]:
    M = cv2.moments(c)
    hu = cv2.HuMoments(M).flatten()
    pts = c.reshape(-1, 2).astype(float)
    print("%-4s m00=%.1f m10=%.0f m01=%.0f 质心=(%.3f,%.3f) 顶点均值=(%.2f,%.2f) mu20=%.1f mu02=%.1f mu11=%.1f" %
          (tag, M["m00"], M["m10"], M["m01"], M["m10"] / M["m00"], M["m01"] / M["m00"],
           pts[:, 0].mean(), pts[:, 1].mean(), M["mu20"], M["mu02"], M["mu11"]))
    print("     log10|Hu1..Hu7| =", np.round(np.log10(np.abs(hu)), 4).tolist())

M0 = cv2.moments(c_star)
for label, arr in [("放大 2 倍", c_star.reshape(-1, 2) * 2),
                   ("旋转 90 度", cv2.transform(c_star, np.float32([[0, -1, 240], [1, 0, 0]])).reshape(-1, 2)),
                   ("平移 (30,10)", c_star.reshape(-1, 2) + [30, 10]),
                   ("水平镜像", np.stack([-c_star.reshape(-1, 2)[:, 0] + 180, c_star.reshape(-1, 2)[:, 1]], axis=1))]:
    Mv = cv2.moments(arr.astype(np.int32))
    diff = np.abs(np.log10(np.abs(cv2.HuMoments(M0).flatten())) -
                  np.log10(np.abs(cv2.HuMoments(Mv).flatten()))).max()
    print("[不变性] 星形%s: m00=%.1f (原 %.1f), 7 个 Hu 矩 log10 最大差 = %.4f" % (label, Mv["m00"], M0["m00"], diff))
```

```text
5. Hu 矩的数值跨度极大（本机星形从 -0.68 到 -13.24），比较时用对数或按 I 范数归一，别直接比原值
```

## 形状匹配与轮廓筛选

`cv2.matchShapes(c1, c2, method, 0.0)` 基于 Hu 矩给出相似度：值越小越像（0 表示完全一致），三种方法 `CONTOURS_MATCH_I1`（对 1/m 求和）、`I2`（对 m 之差求和）、`I3`（对 |mA-mB|/|mA| 取最大）取自官方 `ShapeMatchModes`。工程上很少只靠它做判定，更多是"特征向量 + 阈值"的组合过滤。

```python
import cv2
import numpy as np

pairs = [("方块 vs 方块放大1.5x", c_sq, (c_sq.reshape(-1, 2) * 1.5).reshape(-1, 1, 2).astype(np.int32)),
         ("方块 vs 圆", c_sq, c_circle),
         ("方块 vs 星形", c_sq, c_star),
         ("圆 vs 星形", c_circle, c_star),
         ("方块 vs 内洞", c_sq, cs[4])]
for tag, a, b in pairs:
    print("%-22s I1=%.6f I2=%.6f I3=%.6f" %
          (tag, cv2.matchShapes(a, b, cv2.CONTOURS_MATCH_I1, 0.0),
           cv2.matchShapes(a, b, cv2.CONTOURS_MATCH_I2, 0.0),
           cv2.matchShapes(a, b, cv2.CONTOURS_MATCH_I3, 0.0)))

info = []
for i, c in enumerate(cs):
    a, p = cv2.contourArea(c), cv2.arcLength(c, True)
    x, y, w, h = cv2.boundingRect(c)
    hull = cv2.convexHull(c)
    info.append(dict(i=i, area=a, circ=4 * np.pi * a / p ** 2, extent=a / (w * h),
                     ar=w / h, solidity=a / cv2.contourArea(hull), parent=hi[0][i][3], box=(x, y, w, h)))
print("圆形(圆度>0.85, 面积>1000):", [(d["i"], round(d["area"])) for d in info if d["area"] > 1000 and d["circ"] > 0.85])
print("方形(extent>0.9 且 0.9<长宽比<1.1):", [(d["i"], round(d["area"])) for d in info if d["extent"] > 0.9 and 0.9 < d["ar"] < 1.1])
print("凹形(solidity<0.6):", [(d["i"], round(d["solidity"], 4)) for d in info if d["solidity"] < 0.6])
print("按行分组排序 (y//100, x):", sorted([(d["box"][1] // 100, d["box"][0], d["i"]) for d in info]))
```

```text

4. 轮廓筛选的典型顺序：面积阈值 -> 长宽比 -> 圆度/凸度 -> 位置（过滤边框伪轮廓）；每步都打印剩余数量
5. 排序做 OCR/拼版时用 (行分组 key, x) 排序，行 key 取 y 除以行高的取整，比按 y 直接排稳（同一行文字 y 会有几像素抖动）
```

## 应用场景实战

### 场景一：传送带零件计数与形状分类

分拣线要在一次拍照里数清零件个数并判形状（圆/方/三角/带孔环）。要点是：用 `RETR_CCOMP` 拿到"外轮廓 + 内孔"的关系来判断带孔件，用面积/圆度/凸度/近似顶点数做分类，并用外接矩形过滤噪声。

```python
import cv2
import numpy as np

img = np.zeros((300, 500), np.uint8)
cv2.circle(img, (80, 80), 35, 255, -1)
cv2.circle(img, (200, 80), 35, 255, -1)
cv2.rectangle(img, (300, 45), (370, 115), 255, -1)
cv2.rectangle(img, (420, 45), (490, 115), 255, -1)
cv2.fillPoly(img, [np.array([[60, 200], [120, 280], [10, 280]], np.int32)], 255)
cv2.fillPoly(img, [np.array([[220, 200], [290, 280], [150, 280]], np.int32)], 255)
cv2.circle(img, (420, 240), 30, 255, -1)
cv2.circle(img, (420, 240), 12, 0, -1)                 # 带孔零件

cnts, hier = cv2.findContours(img, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE)
h = hier[0]
top = [i for i in range(len(cnts)) if h[i][3] == -1]
holes = [i for i in range(len(cnts)) if h[i][3] != -1]
print("RETR_CCOMP: 顶层轮廓 %d 个 + 内孔轮廓 %d 个 = %d" % (len(top), len(holes), len(cnts)))
counts = {"圆": 0, "方": 0, "三角": 0, "环": 0}
rows = []
for i in top:
    c = cnts[i]
    a, p = cv2.contourArea(c), cv2.arcLength(c, True)
    x, y, w, hh = cv2.boundingRect(c)
    circ = 4 * np.pi * a / p ** 2
    hull = cv2.convexHull(c)
    sol = a / cv2.contourArea(hull)
    ap = len(cv2.approxPolyDP(c, 0.02 * p, True))
    has_hole = i in {h[j][3] for j in holes}           # 该轮廓是否是某个孔的父亲
    if has_hole:
        label = "环"
    elif circ > 0.82:
        label = "圆"
    elif ap == 4 and sol > 0.9:
        label = "方"
    else:
        label = "三角"
    counts[label] += 1
    rows.append((x + w // 2, y + hh // 2, label, a, circ, sol, ap, has_hole))
for r in sorted(rows, key=lambda r: (r[1] // 100, r[0])):
    print("  中心=(%3d,%3d) 类别=%-2s 面积=%7.1f 圆度=%.3f 凸度=%.3f 近似顶点=%d 带孔=%s" % r)
print("统计 =", counts, " 总数 =", sum(counts.values()))
```

### 场景二：OCR 前的文本块定位与阅读顺序排序

文字行里的每个字符是独立轮廓，直接排序会得到错乱的顺序。标准做法是先横向膨胀把同一单词/同一行的字符合并成块，再用"行分组 + 行内按 x 排序"得到阅读顺序。

```python
import cv2
import numpy as np

page = np.zeros((300, 400), np.uint8)
words = [(30, 40), (110, 40), (200, 40), (30, 90), (140, 90), (30, 150)]
for x, y in words:
    for ch in range(3):                                # 每个"词"画 3 个字符方块
        cv2.rectangle(page, (x + ch * 22, y), (x + ch * 22 + 16, y + 22), 255, -1)
merged = cv2.dilate(page, cv2.getStructuringElement(cv2.MORPH_RECT, (25, 5)))
cnts, _ = cv2.findContours(merged, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
boxes = sorted(cv2.boundingRect(c) for c in cnts)
rows = {}
for x, y, w, hb in boxes:
    rows.setdefault(round((y + hb / 2) / 30), []).append((x, y, w, hb))
print("膨胀 25x5 合并后文本块 %d 个（原来是 %d 个独立字符块）" % (len(boxes), len(words) * 3))
order = []
for n, k in enumerate(sorted(rows), 1):
    line = sorted(rows[k], key=lambda b: b[0])
    order += [b[0] for b in line]
    print("  第 %d 行 (中心 y≈%d): x=%s" % (n, k * 30, [b[0] for b in line]))
print("阅读顺序 x 序列 =", order)
cv2.imwrite("/root/.hermes/cache/scratch/scene_ocr_boxes.png", merged)
```

本机真实输出：

```text
膨胀 25x5 合并后文本块 5 个（原来是 18 个独立字符块）
  第 1 行 (中心 y≈60): x=[18, 188]
  第 2 行 (中心 y≈90): x=[18, 128]
  第 3 行 (中心 y≈150): x=[18]
阅读顺序 x 序列 = [18, 188, 18, 128, 18]
```

18 个字符块被合并成 5 个词块（膨胀核宽度 25 大于字符间距 6，所以同一词的三个字符连成一块，而词间距 40 大于核宽、不会被错误合并）。行分组用 `round((y + h/2) / 30)` 得到 3 行，行内按 x 升序即为阅读顺序。这套流程是所有 OCR 前置处理（PaddleOCR/Textract 的检测后处理同理）的标准形态。

## 最佳实践与踩坑记录

最佳实践：

1. findContours 之前一定先二值化（`threshold`/`inRange`/`Canny` 都可），并在需要保留内部结构时选 `RETR_CCOMP` 或 `RETR_TREE`，只数个数用 `RETR_EXTERNAL`。
2. 点数太多时先用 `approxPolyDP`（eps 取周长 1%-2%）压缩，再做凸包、多边形分类等几何运算，速度与稳定性都更好。
3. 形状分类优先用"可解释特征 + 阈值"：面积、圆度 `4πA/P²`、矩形度 `extent`、长宽比、solidity；`matchShapes` 用作兜底或相似检索。
4. 所有特征计算前判零（`m00`、`arcLength`、`w*h`），并统一用 `hi[0][i][3] == -1` 判断"是否为最外层轮廓"。
5. 需要跨版本稳定时，`minAreaRect` 的角度用 `boxPoints` 反算方向，不要直接依赖角度值与其符号。
6. 轮廓结果落盘可视化（`cv2.drawContours` + `imwrite`）再进下一步：把每个候选的 id、面积、特征值标在图上，人工抽查一轮能省掉大量返工。

坑 1：`contourArea` / `arcLength` 收到 float64 点集直接报断言错误

```text
结论：Assertion failed: npoints >= 0 && (depth == CV_32F || depth == CV_32S) in function 'contourArea'
原因：这两个函数只接受 CV_32F 或 CV_32S 的点集；用 numpy 手工构造点（默认 float64）或做过乘除运算后类型会变成 float64
解法：统一 .astype(np.float32) 或 .astype(np.int32)；findContours 返回的 int32 轮廓可以直接用，自己拼的点集要显式指定类型
```

坑 2：`isContourConvex` 对矩形返回 False

```text
结论：本机实测 CHAIN_APPROX_NONE 的 400 点方块轮廓 isContourConvex = False，approxPolyDP 压成 4 点后为 True
原因：该函数要求严格凸（不允许共线点），而不压缩的轮廓在每条直边上都有共线点
解法：判断形状前先 approxPolyDP；判定"是否凸"要用压缩后的折线，或改用 solidity（面积/凸包面积）做连续量判断
```

坑 3：用 `contourArea` 过滤单像素宽线段或细环状目标

```text
结论：单像素宽线段的 contourArea = 0；半径 10 的环形轮廓（1 像素宽）面积只有 53
原因：contourArea 算的是多边形围成的面积，退化多边形为 0，细环围住的是洞
解法：线段用 boundingRect 的宽高比过滤；环/缺陷用 connectedComponentsWithStats 的像素计数或 minAreaRect 尺寸
```

坑 4：`findContours` 传 float32 图或 3 通道图

```text
结论：OpenCV(5.0.0) contours_new.cpp:332: error: (-2:Unspecified error) in function 'static std::shared_ptr<ContourScanner_>'
原因：轮廓抽取只支持单通道 CV_8U；灰度化的 float 图、BGR 彩色图、CV_16U 深度都会失败（错误码是 -2 而不是常见的 -215）
解法：先 cv2.cvtColor 转灰度再 threshold 成 CV_8U 单通道；从深度学习里拿到的 float 掩膜要乘 255 再 .astype(np.uint8)
```

坑 5：把灰度图当成"已经二值化"直接做轮廓分析

```text
结论：前景 120 的灰度图直接 findContours 会得到轮廓（本机 1 个、面积 1521），但它找的是"非零 vs 零"的边界，不是"目标 vs 背景"
原因：findContours 把任何非零像素视为前景，灰度值之间的过渡区域没有意义
解法：显式 cv2.threshold（或 inRange）拿到 0/255 掩膜再抽轮廓；本机同一张图 OTSU 的阈值是 0，说明双峰灰度图上 OTSU 会把"任何非零"当目标，这类图反而要用固定阈值或 inRange
```

坑 6：`minAreaRect` 的角度与宽高在版本间不一致

```text
结论：本机 5.0.0 上已知 12 度反解出角度 -78.41、宽高 (30.57, 81.56)（宽高互换）；已知 70 度反解出 -19.80
原因：OpenCV 对最小面积矩形的表示（哪条边当 width、角度范围是 [-90,0) 还是 (0,90]）在 4.5.1 与 2025 年的 PR #28051 之间反复调整过（见 opencv/opencv issue #24436）
解法：需要旋转角时用 boxPoints 反算长边方向与夹角，或按图标的"最长边"归一化角度；跨版本升级后必须回归测试角度相关逻辑
```
