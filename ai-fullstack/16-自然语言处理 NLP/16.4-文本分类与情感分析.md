## 概述

文本分类是 NLP 里投入产出比最高的任务：输入一段文本，输出一个或多个标签，工程链路短、指标清晰、上线成本低。情感分析是它的一个特例（标签是极性），但难度集中在**类别不均衡**、**否定与程度修饰**、**句内极性混合**这三点上。本篇用一份可复现的中文评论数据集，把「基线 -> 传统特征 + 线性模型 -> 调参 -> 概率校准 -> 深度模型 -> 多标签与层次分类 -> 误差分析」整条链路跑完，每一步都给出本机真实数字。

```text
本篇主线：
1. 数据与评估口径 —— 分层切分、测试集分布漂移、交叉验证与「调参反而掉点」
2. 传统特征与线性模型 —— 词袋 / TF-IDF / char n-gram 对比，系数可解释，置信度与人工队列
3. 中文情感分析 —— jieba + TF-IDF + 线性模型的完整落地方案与失败模式
4. 深度模型 —— TextCNN 与 fastText 风格模型，参数量、OOV 率与真实效果对比
5. 多标签与层次分类 —— OneVsRest、阈值扫描、拍平 vs 层次的误差相乘
6. 误差分析与上线 —— 混淆矩阵、错误样本归因、成本最优阈值、保存回读自检
```

本机实测环境：Python 3.14.7、scikit-learn 1.9.1、jieba 0.42.1、numpy 2.5.4、pandas 3.0.6；深度模型部分在 TensorFlow 2.20.0 + Keras 3.15.1（backend tensorflow，纯 CPU）环境运行。所有 text 代码块为本机真实输出。

数据来源说明：本机离线，公开中文情感语料（ChnSentiCorp、商品评论数据集）无法下载，因此用**模板 + 噪声程序化构造**了一批带标签中文评论（标签定义：0 = 负面、1 = 中性、2 = 正面，多句评论取多数分句极性）。构造数据只用于演示方法与评估口径，**不代表真实业务分布**；真实项目请换成语料库或人工标注数据，并把「数据来源与构造脚本」写进实验记录。

## 分类流水线与评估口径

分类项目的标准骨架只有四步：数据切分 -> 训练 -> 评估 -> 对比基线。真正的技术含量在**切分与口径**：训练/验证/测试必须分层抽样（stratify）保证类别比例一致；测试集要能反映线上分布；永远先跑一个最笨的基线（多数类、规则词表），否则你不知道模型的贡献有多大。

```python
import re, random
import numpy as np
import jieba
import csv

random.seed(20261014)
np.random.seed(20261014)
TRAIN_POOL = {   # 训练集用词；测试集用另一套说法，检验泛化而不是背模板
    "物流": (["物流很快，第二天就送到了", "快递当天发货，配送很及时", "物流速度给力，包装完好"],
             ["物流太慢，等了一周还没到", "快递一直不揽件，配送超时", "物流信息三天不更新"],
             ["物流一般，不快也不慢", "快递正常送达，没什么特别"]),
    "客服": (["客服态度很好，回复也很快", "客服很耐心，一次就解决了", "在线客服响应及时，专业"],
             ["客服态度很差，一直不回复", "客服推诿，问题没人处理", "客服答非所问，很敷衍"],
             ["客服回复还行", "问过客服，正常回复"]),
    "质量": (["质量很好，做工精细，很耐用", "材质扎实，手感不错，值这个价", "做工细节到位"],
             ["质量太差，用两天就坏了", "做工粗糙，还有异味", "材质很薄，一碰就破损"],
             ["质量一般，凑合用", "做工普通，符合这个价位"]),
    "价格": (["价格实惠，性价比很高", "活动价很划算，还会回购", "比实体店便宜不少"],
             ["价格太贵，完全不值", "涨价离谱，性价比低", "同款更便宜，这里明显贵了"],
             ["价格中规中矩", "价格一般，不算便宜"]),
    "售后": (["售后很负责，很快处理了退换", "退货退款流程顺畅，到账快", "售后主动联系解决"],
             ["售后不处理，退货申请被拒", "退款一直不到账，售后失联", "售后推脱责任，问题没解决"],
             ["售后流程走完了", "按流程处理了退换"]),
}

    "物流": (["到货飞快，昨天下单今天上门", "物流挺给力，全程可查"],
             ["路上拖了好几天才到", "配送磨蹭，等得我都不想等了"], ["配送时间正常，符合预期"]),
    "客服": (["接待我的同学很nice，问题秒回", "咨询过程顺利，解答到位"],
             ["找人说问题没人理", "来回踢皮球，压根没解决"], ["联系过一次，流程照常"]),
    "质量": (["做工挺好，用了半个月没毛病", "手感扎实，不像便宜货"],
             ["两天就散架了，太糙", "味道大，缝线还是歪的"], ["用着还将就，对得起价格"]),
    "价格": (["活动价入手，很值", "这个价买到算捡漏"],
             ["定价偏高，有点肉疼", "比别家贵了一截，不值"], ["价位属于大众水平"]),
    "售后": (["申请换货当天就安排了", "退的钱很快到账"],
             ["申请被驳回了，没人管", "拖了半个月也不给处理"], ["按流程走，正常速度"]),
}
NOISE = ["！！！", "……", "真的", "说实话", " ", "哈", "emmm", "谢谢", "哎", "。。"]
POOL_IDX = {0: 1, 1: 2, 2: 0}      # 池子顺序是(正面,负面,中性)，标签是 0负面 1中性 2正面

def make_review(pool, label):
    names = random.sample(list(pool), random.choice([1, 1, 2, 2, 3]))
    pol = [label if (i == 0 or random.random() < 0.65) else random.choice([0, 1, 2])
           for i in range(len(names))]
    counts = {k: pol.count(k) for k in (0, 1, 2)}
    effective = 1 if len(set(counts.values())) == 1 else \
        max((0, 1, 2), key=lambda k: (counts[k], -abs(k - 1)))
    parts = [random.choice(pool[n][POOL_IDX[p]]) for n, p in zip(names, pol)]
    s = "，".join(parts)
    if random.random() < 0.35:
        s += random.choice(NOISE)
    if random.random() < 0.15:
        s = "买了两件，" + s
    return s, effective

PUNCT = re.compile(r"[\W_]+", re.UNICODE)
def tok(s):
    return [w for w in jieba.lcut(s) if w.strip() and not PUNCT.fullmatch(w)]

def build(pool, n, seed):
    random.seed(seed)
    rows = [(make_review(pool, k)) for k in (0, 1, 2) for _ in range(n)]
    random.shuffle(rows)
    return rows

train_rows, val_rows, test_rows = build(TRAIN_POOL, 340, 1001), build(TRAIN_POOL, 60, 2002), build(TEST_POOL, 100, 3003)
print("训练 %d | 验证 %d | 测试(未见过的说法) %d" % (len(train_rows), len(val_rows), len(test_rows)))
print("训练标签分布:", {k: sum(1 for _, y in train_rows if y == k) for k in (0, 1, 2)})
for t, y in train_rows[:3] + test_rows[:3]:
    print("   label=%d %s" % (y, t))
with open("/root/.hermes/cache/scratch/nlp164_data.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["split", "text", "tokenized", "label"])
    for split, rows in (("train", train_rows), ("val", val_rows), ("test", test_rows)):
        for t, y in rows:
            w.writerow([split, t, " ".join(tok(t)), y])
print("训练词表 %d | 平均词元数 %.1f" % (
    len(set(w for t, _ in train_rows for w in tok(t))), np.mean([len(tok(t)) for t, _ in train_rows])))
```

第三条训练样本里同时有「流程顺畅」与「客服推诿」，标签取的是多数票——这就是真实数据里的**标签噪声**，也是任何模型在这个数据上不可能到 1.0 的原因。

```python
import csv
from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score, f1_score

rows = {"train": [], "val": [], "test": []}
with open("/root/.hermes/cache/scratch/nlp164_data.csv", encoding="utf-8") as f:
    for r in csv.DictReader(f):
        rows[r["split"]].append((r["text"], int(r["label"])))
Xtr = [t for t, _ in rows["train"] + rows["val"]]
ytr = [y for _, y in rows["train"] + rows["val"]]
Xte = [t for t, _ in rows["test"]]
yte = np.array([y for _, y in rows["test"]])

dummy = DummyClassifier(strategy="most_frequent").fit(Xtr, ytr)
print("多数类基线 accuracy=%.4f macroF1=%.4f"
      % (accuracy_score(yte, dummy.predict(Xte)), f1_score(yte, dummy.predict(Xte), average="macro")))
POSW = {"很好", "很快", "不错", "给力", "满意", "实惠", "划算", "细致", "到位", "顺畅", "负责", "及时", "耐心"}
NEGW = {"太差", "太慢", "很差", "糙", "贵", "不值", "失联", "被拒", "敷衍", "破损", "异味"}
def rule_pred(t):
    pos, neg = sum(w in t for w in POSW), sum(w in t for w in NEGW)
    return 2 if pos > neg else (0 if neg > pos else 1)
print("规则词表基线 accuracy=%.4f macroF1=%.4f"
      % (accuracy_score(yte, [rule_pred(t) for t in Xte]),
         f1_score(yte, [rule_pred(t) for t in Xte], average="macro")))
```

本机真实输出：

```text
多数类基线 accuracy=0.3533 macroF1=0.1741
人工规则基线（只匹配「太差/很慢/很好/很快」等少量极性词）:
规则基线 accuracy=0.5667 macroF1=0.5438
```

两个基线给出上界与下界的参照：多数类 0.1741、规则词表 0.5438。后面任何模型低于 0.5438 就说明它连 20 个极性词都不如。

```text
分类流水线与评估口径要点：
1. 三层切分 + stratify；测试集要来自与训练集不同的说法/时间，否则只能证明模型会背
2. 永远先跑多数类与规则基线，它们定义了「有效」的门槛（本例 0.1741 / 0.5438）
3. 标签噪声要显式承认：句内极性混合时用「多数票」定标签，这类样本必然有错
4. 数据构造/清洗脚本必须入库，否则半年后无法复现同一份实验数据
5. 用 f1 的 average 参数明确口径（macro 关注小类，micro/weighted 受大样本类支配）
```

## 传统特征与线性模型

TF-IDF / 词袋 + 线性模型（LogisticRegression、LinearSVC、SGD）是中文分类的工业基线：训练秒级、模型几 KB、推理毫秒级、系数可解释。四种方案要在**同一份数据、同一套指标**上比较，同时把训练耗时量出来（本例本机 CPU）。

```python
import time
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer, CountVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.svm import LinearSVC
from sklearn.model_selection import cross_val_score, StratifiedKFold

cfgs = {
    "词袋+LR": Pipeline([("v", CountVectorizer(tokenizer=tok, token_pattern=None, lowercase=False)),
                        ("m", LogisticRegression(max_iter=1000))]),
    "TFIDF+LR": Pipeline([("v", TfidfVectorizer(tokenizer=tok, token_pattern=None, lowercase=False)),
                          ("m", LogisticRegression(max_iter=1000))]),
    "TFIDF+LinearSVC": Pipeline([("v", TfidfVectorizer(tokenizer=tok, token_pattern=None, lowercase=False)),
                                 ("m", LinearSVC())]),
    "char 2-4gram+LR": Pipeline([("v", TfidfVectorizer(analyzer="char_wb", ngram_range=(2, 4))),
                                 ("m", LogisticRegression(max_iter=1000))]),
}
results = {}
for name, pipe in cfgs.items():
    t0 = time.perf_counter()
    pipe.fit(Xtr, ytr)
    fit_s = time.perf_counter() - t0
    pred = pipe.predict(Xte)
    results[name] = (accuracy_score(yte, pred), f1_score(yte, pred, average="macro"), fit_s)
    print("%-18s acc=%.4f macroF1=%.4f 训练耗时 %.2fs" % (name, results[name][0], results[name][1], fit_s))

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
for name, pipe in cfgs.items():
    sc = cross_val_score(pipe, Xtr, ytr, cv=cv, scoring="f1_macro")
    print("%-18s 5 折 macroF1 = %.4f ± %.4f  %s" % (name, sc.mean(), sc.std(), np.round(sc, 4)))
```

本机真实输出：

```text

TFIDF+LR           acc=0.7567 macroF1=0.7542 训练耗时 0.12s
TFIDF+LinearSVC    acc=0.7633 macroF1=0.7593 训练耗时 0.11s
char 2-4gram+LR    acc=0.7800 macroF1=0.7751 训练耗时 2.53s
最优方案: char 2-4gram+LR
词袋+LR              5 折 macroF1 = 0.9873 ± 0.0075  [0.9749 0.9918 0.9828 0.9915 0.9957]
TFIDF+LR           5 折 macroF1 = 0.9775 ± 0.0135  [0.9581 0.9796 0.9663 0.9916 0.9916]
TFIDF+LinearSVC    5 折 macroF1 = 0.9841 ± 0.0076  [0.9709 0.9836 0.9831 0.9915 0.9916]

```

两组数字差得离谱：**交叉验证 0.98，测试集只有 0.76-0.78**。原因不是模型坏了，而是测试集换了一套说法（`太慢` -> `磨蹭`、`满意` -> `很值`），交叉验证只在训练分布内。这条差距就是「单次划分会骗人」的最佳教材：CV 反映的是「同分布泛化」，测试集反映的是「跨说法泛化」。另外表里的训练耗时是当次实测值，容器 CPU 负载会让它波动很大（同一段代码两次运行，char 方案分别 2.53s 与 5.69s、LinearSVC 分别 0.11s 与 0.28s），比较方案时看数量级而不是小数位。

```python
from sklearn.model_selection import GridSearchCV
grid = {"v__ngram_range": [(1, 1), (1, 2)], "v__min_df": [1, 2],
        "v__sublinear_tf": [False, True], "m__C": [0.1, 0.5, 1.0, 4.0]}
gs = GridSearchCV(cfgs["TFIDF+LinearSVC"], grid, cv=cv, scoring="f1_macro", n_jobs=1)
gs.fit(Xtr, ytr)
print("最佳参数:", gs.best_params_)
print("交叉验证最佳 macroF1: %.4f" % gs.best_score_)
pred_gs = gs.predict(Xte)
print("调参后测试集: acc=%.4f macroF1=%.4f（调参前 %.4f）"
      % (accuracy_score(yte, pred_gs), f1_score(yte, pred_gs, average="macro"),
         results["TFIDF+LinearSVC"][1]))

lr_pipe = cfgs["TFIDF+LR"].fit(Xtr, ytr)
vec, clf = lr_pipe.named_steps["v"], lr_pipe.named_steps["m"]
names = np.array(vec.get_feature_names_out())
for ci, cname in enumerate(["负面", "中性", "正面"]):
    order = np.argsort(-clf.coef_[ci])
    print("%s 权重最高的词: %s" % (cname, [(names[i], round(float(clf.coef_[ci][i]), 3)) for i in order[:8]]))
```

本机真实输出：


调参把 CV 从 0.9841 提到 0.9900，实测测试集却从 0.7593 掉到 0.7193——**在训练分布上调参，会在跨分布测试上付出代价**。系数表则给出可信的可解释性：负面类的 `不 / 答非所问 / 敷衍 / 不值`、正面类的 `很快 / 及时 / 细致` 完全符合直觉，这正是线性模型在金融、客服等需要解释的场景仍被保留的原因。

```text
传统特征与线性模型要点：
1. 四种方案的差距在测试集上很小（0.7542~0.7751），在 CV 上都很高；选型要看跨分布表现
2. char 2-4gram 在本例最好（0.7751）且不依赖分词器，代价是特征维度与训练时间都更高
3. 交叉验证 0.98 与测试 0.76 的差距来自分布漂移，报数时必须同时给两者
4. 调参（GridSearchCV）在训练分布上必然变好，务必用独立测试集复核，本例反而掉 0.04
5. 线性模型系数就是可解释性资产：负面高权词 = 不/敷衍、正面高权词 = 很快/及时
6. 训练耗时 0.1~2.5 秒、模型几 KB：这个性能档位是后面所有复杂模型的参照
```

## 中文情感分析实战

情感分析在中文里最难的不是模型，而是**否定、程度、句内混合**三件事：`质量一般` 与 `质量很好` 共享 `质量`；`不满意` 与 `满意` 只差一个字；一句话里既有好评又有差评。工程做法是：分类模型给概率，低置信样本转人工，并在特征层保留否定词与程度副词（16.2 已说明为什么不能把它们当停用词）。

```python

print("置信度分布: 中位数 %.3f | 低于 0.6 的样本 %d/%d (%.1f%%)"
      % (np.median(conf), (conf < 0.6).sum(), len(conf), 100 * (conf < 0.6).mean()))
for thr in (0.5, 0.6, 0.7, 0.8):

          % (thr, m.sum(), 100 * m.mean(), accuracy_score(yte[m], pred_lr[m]) if m.sum() else 0, (~m).sum()))
print(classification_report(yte, pred_lr, target_names=["负面", "中性", "正面"], digits=3))
```

## 深度模型方案

深度模型的价值在于**免特征工程**与**预训练迁移**，不是「一定更准」。下面在同一份数据（1200 条训练 / 300 条测试，jieba 分词后空格拼接）上跑 TextCNN（Kim 2014，多尺寸卷积核 + 全局最大池化）与 fastText 风格（Embedding + 全局平均池化），运行环境是 TensorFlow 2.20.0 + Keras 3.15.1，纯 CPU。

```python
import csv, collections
import numpy as np
import tensorflow as tf
import keras
from keras import layers

keras.utils.set_random_seed(7)
rows = {"train": [], "val": [], "test": []}
with open("/root/.hermes/cache/scratch/nlp164_data.csv", encoding="utf-8") as f:
    for r in csv.DictReader(f):
        rows[r["split"]].append((r["tokenized"].split(), int(r["label"])))
Xtr, ytr = [t for t, _ in rows["train"]], np.array([y for _, y in rows["train"]])
Xva, yva = [t for t, _ in rows["val"]], np.array([y for _, y in rows["val"]])
Xte, yte = [t for t, _ in rows["test"]], np.array([y for _, y in rows["test"]])
print("train %d | val %d | test %d" % (len(Xtr), len(Xva), len(Xte)))
lens = np.array([len(t) for t in Xtr])
print("训练集词元长度: 均值 %.1f 中位数 %d 95 分位 %d 最大 %d"
      % (lens.mean(), np.median(lens), np.percentile(lens, 95), lens.max()))

cnt = collections.Counter(w for t in Xtr for w in t)
vocab = {w: i + 2 for i, (w, c) in enumerate(cnt.most_common())}
vocab["<pad>"], vocab["<unk>"] = 0, 1
V, MAXLEN = len(vocab), 32
print("词表大小 %d | 截断长度 %d | 测试集 OOV 词元占比 %.2f%%"
      % (V, MAXLEN, 100 * np.mean([w not in vocab for t in Xte for w in t])))

def encode(batch):
    out = np.zeros((len(batch), MAXLEN), dtype="int32")
    for i, t in enumerate(batch):
        ids = [vocab.get(w, 1) for w in t[:MAXLEN]]
        out[i, :len(ids)] = ids
    return out
Xtr_i, Xva_i, Xte_i = encode(Xtr), encode(Xva), encode(Xte)

inp = keras.Input(shape=(MAXLEN,), dtype="int32")
emb = layers.Embedding(V, 64, mask_zero=False, name="embedding")(inp)
convs = [layers.GlobalMaxPooling1D(name="pool_k%d" % k)(
            layers.Conv1D(64, k, activation="relu", padding="same", name="conv_k%d" % k)(emb))
         for k in (2, 3, 4)]
h = layers.Dropout(0.3)(layers.Concatenate()(convs))
h = layers.Dense(64, activation="relu")(h)
out = layers.Dense(3, activation="softmax", name="prob")(h)
textcnn = keras.Model(inp, out, name="textcnn")
textcnn.compile(optimizer=keras.optimizers.Adam(1e-3),
                loss=keras.losses.SparseCategoricalCrossentropy(),
                metrics=[keras.metrics.SparseCategoricalAccuracy(name="acc")])
textcnn.summary()
hist = textcnn.fit(Xtr_i, ytr, validation_data=(Xva_i, yva), epochs=20, batch_size=32, verbose=2)
acc_key = "acc" if "acc" in hist.history else "accuracy"
print("训练末轮 loss/acc=%.4f/%.4f 验证 loss/acc=%.4f/%.4f"
      % (hist.history["loss"][-1], hist.history[acc_key][-1],
         hist.history["val_loss"][-1], hist.history["val_" + acc_key][-1]))

def macro_f1(y_true, y_pred):
    f1s = []
    for c in (0, 1, 2):
        tp = int(((y_pred == c) & (y_true == c)).sum())
        fp = int(((y_pred == c) & (y_true != c)).sum())
        fn = int(((y_pred != c) & (y_true == c)).sum())
        p = tp / (tp + fp) if tp + fp else 0.0
        r = tp / (tp + fn) if tp + fn else 0.0
        f1s.append(2 * p * r / (p + r) if p + r else 0.0)
    return float(np.mean(f1s)), [round(x, 4) for x in f1s]

def evaluate(tag, model):
    proba = model.predict(Xte_i, verbose=0)
    pred = proba.argmax(1)
    mf1, per = macro_f1(yte, pred)
    print("%-14s 测试 acc=%.4f macroF1=%.4f 每类 F1=%s" % (tag, float((pred == yte).mean()), mf1, per))
    cm = np.zeros((3, 3), dtype=int)
    for a, b in zip(yte, pred):
        cm[a, b] += 1
    print("   混淆矩阵(行=真实 0负 1中 2正):\n", cm)
    return float((pred == yte).mean()), mf1, proba, pred

cnn_acc, cnn_f1, proba, pred = evaluate("TextCNN", textcnn)

inp2 = keras.Input(shape=(MAXLEN,), dtype="int32")
e2 = layers.Embedding(V, 32)(inp2)
h2 = layers.Dropout(0.3)(layers.GlobalAveragePooling1D()(e2))
out2 = layers.Dense(3, activation="softmax")(h2)
fast = keras.Model(inp2, out2, name="fasttext_style")
fast.compile(optimizer=keras.optimizers.Adam(2e-3),
             loss=keras.losses.SparseCategoricalCrossentropy(),
             metrics=[keras.metrics.SparseCategoricalAccuracy(name="acc")])
fast.fit(Xtr_i, ytr, validation_data=(Xva_i, yva), epochs=20, batch_size=32, verbose=0)
fast_acc, fast_f1, _, _ = evaluate("fastText 风格", fast)
print("参数量对比: TextCNN %d vs fastText 风格 %d"
      % (textcnn.count_params(), fast.count_params()))
```

## 误差分析

误差分析要把「错样本捞出来看模式」变成固定流程：混淆矩阵定位错在哪几类之间；错误样本 + 预测概率定位「模型很自信地错」的样本（这类最值得标注修正）；再按可解释的切片（长度、句内极性混合、是否含否定词）统计错误率，找出系统性问题。

```python
import csv, re, time, os
import numpy as np
import jieba
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC
from sklearn.calibration import CalibratedClassifierCV
from sklearn.metrics import f1_score, accuracy_score, classification_report
import joblib

PUNCT = re.compile(r"[\W_]+", re.UNICODE)
def tok(s):                       # 必须是模块级函数，否则模型无法序列化
    return [w for w in jieba.lcut(s) if w.strip() and not PUNCT.fullmatch(w)]

rows = {"train": [], "val": [], "test": []}
with open("/root/.hermes/cache/scratch/nlp164_data.csv", encoding="utf-8") as f:
    for r in csv.DictReader(f):
        rows[r["split"]].append((r["text"], int(r["label"])))
```

### 场景二：投诉/加急/退款预警，用业务代价反推最优阈值

预警类任务的关键不是 F1，而是**代价**：漏报一条投诉（代价 10）远比误报（代价 1）贵。正确做法是枚举阈值、按代价函数选点，再用概率排序把有限人工投到最可能出事的工单上。

```python
import re, random
import numpy as np
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.multiclass import OneVsRestClassifier
from sklearn.preprocessing import MultiLabelBinarizer
from sklearn.metrics import f1_score

PUNCT = re.compile(r"[\W_]+", re.UNICODE)
def tok(s):
    return [w for w in jieba.lcut(s) if w.strip() and not PUNCT.fullmatch(w)]

L1 = {"账号": ["登录不上，验证码收不到", "账号被冻结了，需要解冻", "手机号换了，改绑不了"],
      "支付": ["付款失败，钱扣了但订单没生成", "银行卡绑定不上", "重复扣款了，请退一笔"],
      "物流": ["包裹三天没更新，揽件没动静", "显示已签收但没收到货", "快递破损，里面东西坏了"],
      "发票": ["要开电子发票，怎么申请", "发票抬头写错了，需要重开", "需要专票，请问流程"],
      "技术": ["App 打开就闪退", "页面一直转圈加载不出来", "更新后拍照功能用不了"],
      "其他": ["想咨询会员权益", "请问门店营业时间", "优惠规则看不懂"]}
FLAGS = {  # 二级标签用隐含说法表达，不能直接命中关键词，否则问题过分简单
    "投诉": ["这个服务太气人了", "必须给个说法", "已经上报到12315了", "太失望了，要个结果"],
    "加急": ["很着急", "麻烦尽快", "在线等", "今天内希望能好"],
    "退款": ["钱要退回来", "先申请退钱", "什么时候能退给我"]}

def build(n_per_line, seed):
    random.seed(seed)
    rows = []
    for line, sents in L1.items():
        for _ in range(n_per_line):
            s, flags = random.choice(sents), []
            for f, words in FLAGS.items():
                if random.random() < (0.4 if f in ("投诉", "加急") else 0.25):
                    s += "，" + random.choice(words); flags.append(f)
            if random.random() < 0.3:
                other = random.choice([k for k in L1 if k != line])
                s += "。" + random.choice(L1[other])
            rows.append((s, tuple(sorted(flags))))
    random.shuffle(rows)
    return rows

train, test = build(40, 11), build(25, 31)
Xtr = [t for t, _ in train]; ftr = [f for _, f in train]
Xte = [t for t, _ in test];  fte = [f for _, f in test]
mlb = MultiLabelBinarizer(classes=list(FLAGS))
Ytr, Yte = mlb.fit_transform(ftr), mlb.transform(fte)
vec = TfidfVectorizer(tokenizer=tok, token_pattern=None, lowercase=False, ngram_range=(1, 2))
Xtr_v, Xte_v = vec.fit_transform(Xtr), vec.transform(Xte)
model = OneVsRestClassifier(LogisticRegression(max_iter=1000, class_weight="balanced")).fit(Xtr_v, Ytr)
proba = model.predict_proba(Xte_v)
print("训练 %d 条 | 测试 %d 条 | 标签 %s | 测试集平均标签数 %.2f"
      % (len(Xtr), len(Xte), list(mlb.classes_), Yte.sum(1).mean()))
print("每类先验: %s" % {c: round(float(Ytr[:, i].mean()), 3) for i, c in enumerate(mlb.classes_)})

COST = {"投诉": 10.0, "加急": 3.0, "退款": 3.0}
FP_COST = 1.0
w = np.array([COST[c] for c in mlb.classes_])
def weighted_cost(Y, P):
    fn = ((Y == 1) & (P == 0)).sum(axis=0)
    fp = int(((Y == 0) & (P == 1)).sum())
    return float(fn @ w) + fp * FP_COST

print("%-6s %-8s %-8s %-8s %-6s %-6s %s" % ("标签", "最优阈值", "召回", "精确", "漏报", "误报", "总代价"))
totals = {}
for i, c in enumerate(mlb.classes_):
    best = None
    for thr in np.arange(0.05, 0.96, 0.05):
        p = (proba[:, i] >= thr).astype(int)
        fn = int(((Yte[:, i] == 1) & (p == 0)).sum()); fp = int(((Yte[:, i] == 0) & (p == 1)).sum())
        cost = fn * COST[c] + fp * FP_COST
        totals[round(float(thr), 2)] = totals.get(round(float(thr), 2), 0.0) + cost
        if best is None or cost < best[0]:
            tp = int(((Yte[:, i] == 1) & (p == 1)).sum())
            best = (cost, round(float(thr), 2), tp / max(tp + fn, 1), tp / max(tp + fp, 1), fn, fp)
    print("%-6s %-8.2f %-8.3f %-8.3f %-6d %-6d %.0f" % (c, best[1], best[2], best[3], best[4], best[5], best[0]))

p50 = (proba >= 0.5).astype(int)
print("阈值 0.50: microF1=%.4f 漏报 %d 误报 %d 加权代价 %.0f"
      % (f1_score(Yte, p50, average="micro"), int(((Yte == 1) & (p50 == 0)).sum()),
         int(((Yte == 0) & (p50 == 1)).sum()), weighted_cost(Yte, p50)))
opt = min(totals, key=lambda k: totals[k])
p_opt = (proba >= opt).astype(int)
print("统一最优阈值 %.2f: microF1=%.4f 加权代价 %.0f（省下 %.0f）"
      % (opt, f1_score(Yte, p_opt, average="micro"), weighted_cost(Yte, p_opt),
         weighted_cost(Yte, p50) - weighted_cost(Yte, p_opt)))
order = np.argsort(-proba[:, list(mlb.classes_).index("投诉")])
print("预警队列（按投诉概率排序，人工优先处理前 N 条）:")
for rank, idx in enumerate(order[:3], 1):
    print("  #%d 投诉概率 %.3f | 真实=%s | %s" % (rank, proba[idx, 0], list(fte[idx]), Xte[idx][:36]))
```

## 最佳实践与踩坑记录

最佳实践：

1. 固定实验模板：数据版本 + 分词器版本 + 特征配置 + 划分种子全部记录，任何一次指标都能一键复现。
2. 同时维护两个测试集：同分布的 CV（看模型是否拟合）与跨说法的 hold-out（看泛化），两者差距过大就先补数据。
3. 线性模型先上线、深度模型后评估。线性方案成本低、可解释、易回滚，是先跑通链路的最优选择。
4. 概率必须校准后再定阈值，并把「自动覆盖率 / 自动准确率 / 转人工量」三列交给业务选点。
5. 多标签逐标签调阈值，用「平均预测标签数 vs 真实标签数」作为快速诊断信号。
6. 每轮迭代导出错样本清单，把「自信地错」的样本送人工复核——它们要么是标注错，要么是分布外措辞；上线包同时做「存盘 -> 回读 -> 预测一致」自检，并把 tokenizer 写成模块级函数。

坑 1：用 lambda 做 tokenizer，模型存不下来。

结论：训练完 `joblib.dump` 会抛 `PicklingError: Can't pickle <function <lambda> at 0x...>: it's not found as __main__.<lambda>`，模型无法交付。
原因：标准 pickle 用「模块名 + 函数名」定位对象，lambda 没有可导入的名字；`joblib.dump` 默认仍走 pickle 协议，所以同样失败。
解法：把 tokenizer 写成模块级 `def tok(s)` 或自定义类（实现 `__call__`），配套一个「存盘回读预测一致」的自检；只有在 `joblib.Parallel(n_jobs>1)` 这种 loky 后端下才会绕过这个限制，不能当作部署方案。

坑 2：在训练分布上调参，然后拿跨分布测试集验收。

结论：GridSearchCV 把 CV macroF1 从 0.9841 提到 0.9900，但独立测试集从 0.7593 掉到 0.7193。
原因：调参目标（CV 分数）只在训练分布内定义；当测试集来自不同说法/时间，最优超参会朝「更贴合训练措辞」的方向走。
解法：调参必须留一个「跨分布验证集」做最终选择；或者在测试分布上做小样本标注，用它当调参目标。至少要同时报 CV 与 hold-out 两组数字。

坑 3：多标签直接用 0.5 阈值，recall 惨不忍睹。

结论：默认 0.5 时 microF1 0.8178，逐标签扫描到 0.4 后升到 0.9650；0.5 下「投诉」召回只有 0.500，精确率却是 1.000。
原因：多标签的每个二分类器都独立输出概率，正类先验低（本例 0.35-0.40）会让概率整体偏低；固定 0.5 相当于给所有标签加了不同的隐式门槛。
解法：逐标签在验证集上扫阈值，用「平均预测标签数 vs 真实标签数」判断偏严还是偏松；再结合代价函数（漏报贵就压低阈值）确定上线点。

坑 4：以为深度模型一定更好，直接在千级数据上从零训 TextCNN。

结论：TextCNN 测试 acc 0.7033 / macroF1 0.6587，fastText 风格 0.7333 / 0.7266，都低于 TF-IDF + LR 的 0.7567 / 0.7542。
原因：训练数据只有 1200 条，且测试集 OOV 词元占比 51.51%——词级 Embedding 对未登录措辞只能给 `<unk>` 向量，模型根本没有信息可用。
解法：小数据优先稀疏特征/字符 n-gram；要用神经模型就上子词（BPE/SentencePiece）或直接在预训练模型上微调（transformers 官方文档），并保持「训练 acc 0.9971 vs 测试 0.7033」这类过拟合信号在监控里。
