## 概述

机器学习要解决的问题可以归成一句话：给定一批数据，找到一个函数，让它在没见过的数据上也能给出对的输出。这句话拆开就是本主题的六块内容——数据有没有标签决定学习范式，要优化什么决定损失函数，怎么优化决定梯度下降与优化器，怎么防止「背下训练集」决定正则化，怎么判断好坏决定评估指标，而模型为什么会错决定偏差方差分析。本主题全部示例均可直接运行，实测环境为 Python 3.14 + numpy 2.5.4 + scikit-learn 1.9.1。

```text
六个问题的固定顺序：
1. 范式 —— 监督（有标签）/ 无监督（无标签）/ 半监督（部分标签）/ 强化学习（奖励信号）
2. 目标 —— 损失函数把「好」量化成一个可求导的标量
3. 优化 —— 梯度下降及其变体迭代降低损失
4. 泛化 —— 正则化、早停、数据划分控制过拟合
5. 度量 —— 选对指标，否则优化的方向和业务目标相反
6. 诊断 —— 偏差高就是欠拟合，方差高就是过拟合，解法完全不同
```

## 监督无监督半监督与强化学习

按「数据里有没有标签」和「反馈长什么样」划分，机器学习有四种基本范式。监督学习用带标签样本学输入到输出的映射（分类、回归）；无监督学习只有输入，目标是发现结构（聚类、降维、异常检测）；半监督学习用少量标签加大量无标签数据，常见手段是伪标签自训练或一致性正则；强化学习没有正确答案，只有一个会随动作变化的奖励信号，智能体通过试错最大化长期回报。前三种处理静态数据，第四种处理与环境的交互序列。

```python
# pip install scikit-learn
import numpy as np
from sklearn.datasets import make_classification, load_iris
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.cluster import KMeans

# 无监督：只用特征，不看标签
Xi = load_iris(return_X_y=True)[0]
Xs = StandardScaler().fit_transform(Xi)
print("无监督 KMeans（不看标签）聚类中心形状:", KMeans(n_clusters=3, n_init=10, random_state=42).fit(Xs).cluster_centers_.shape)

Xb, yb = make_classification(n_samples=1500, n_features=20, n_informative=8, random_state=42)
Xtr, Xte, ytr, yte = train_test_split(Xb, yb, test_size=0.3, random_state=42, stratify=yb)
full = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)).fit(Xtr, ytr)
print("监督（全部 %d 条带标签）  测试准确率 %.4f" % (len(ytr), full.score(Xte, yte)))

# 半监督：只有 10% 的样本有标签
rng = np.random.default_rng(0)
picked = rng.choice(len(Xtr), size=int(0.10 * len(Xtr)), replace=False)
mask = np.zeros(len(Xtr), dtype=bool)
mask[picked] = True
few = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)).fit(Xtr[mask], ytr[mask])
print("半监督 step1 只用 %d 条带标签      测试准确率 %.4f" % (mask.sum(), few.score(Xte, yte)))

# 半监督：用带标签模型给高置信度无标签样本打伪标签，再合并训练
conf = few.predict_proba(Xtr[~mask]).max(axis=1) >= 0.9
Xaug = np.vstack([Xtr[mask], Xtr[~mask][conf]])
yaug = np.concatenate([ytr[mask], few.predict(Xtr[~mask][conf])])
semi = make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)).fit(Xaug, yaug)
print("半监督 step2 伪标签自训练          测试准确率 %.4f" % semi.score(Xte, yte))
```

真实输出（本机执行）：

```text
无监督 KMeans（不看标签）聚类中心形状: (3, 4)
监督（全部 1050 条带标签）  测试准确率 0.7356
半监督 step1 只用 105 条带标签      测试准确率 0.7156
半监督 step2 伪标签自训练          测试准确率 0.7044
```

这个实验的结论要说清楚：只用 10% 标签训出的模型（0.7156）已经接近全量标签（0.7356），但**伪标签自训练这一步反而掉到了 0.7044**。原因是基础模型不够强，错误预测被打上伪标签后又被学回去，形成确认偏差（confirmation bias）。所以半监督的前提是基础模型本身要足够可靠，且要给伪标签设置信度阈值、多轮迭代并监控验证集。

四种范式对照：

| 范式 | 数据要求 | 反馈信号 | 典型任务 | 代表算法 |
|---|---|---|---|---|
| 监督学习 | 输入 + 标签 | 与真实标签的误差 | 分类、回归、排序 | 逻辑回归、XGBoost、神经网络 |
| 无监督学习 | 只有输入 | 无 | 聚类、降维、异常检测 | KMeans、DBSCAN、PCA、自编码器 |
| 半监督学习 | 少量标签 + 大量无标签 | 少量标签 + 伪标签 | 标注昂贵的分类任务 | 自训练、一致性正则、FixMatch |
| 强化学习 | 环境交互轨迹 | 延迟的奖励 | 决策、控制、推荐、博弈 | Q-Learning、DQN、PPO、离线 RL |

```text
范式选择要点：
1. 有标签且标签可靠 -> 监督学习；标签获取成本高才考虑半监督
2. 无标签且目标是「分群/找异常」-> 无监督；想预测具体数值只能靠监督
3. 决策会影响后续状态（跨时间）-> 强化学习；否则就是普通的监督预测问题
4. 半监督的伪标签必须设置信度阈值并监控验证集，否则会放大错误
5. 线上推荐与广告系统常把「监督排序 + 强化学习探索」组合使用
```

## 损失函数与目标函数

损失函数（loss function）度量单个样本的预测与真值的差距，所有样本损失的平均（或求和）就是训练要最小化的目标函数，加上正则项后称成本函数。选损失函数等于选「模型关心什么」：均方误差（MSE）对大误差惩罚重，适合回归且对异常值敏感；平均绝对误差（MAE）对异常值稳健；交叉熵（cross-entropy）度量两个概率分布的差异，是分类任务的标准损失，与 softmax/sigmoid 的输出天然配套，梯度形式也最简洁（预测概率减真实标签）。

```python
import numpy as np

# 回归损失：MSE 与 MAE 对异常值的敏感度不同
y_true = np.array([1.0, 0.0, 1.0])
y_pred = np.array([0.9, 0.2, 0.6])
print("MSE =", float(np.mean((y_true - y_pred) ** 2)))

outlier_true = np.array([1.0, 0.0, 1.0, 1.0])
outlier_pred = np.array([0.9, 0.2, 0.6, 0.0])   # 最后一个错得离谱
print("含异常样本 MSE = %.4f  MAE = %.4f" % (
    np.mean((outlier_true - outlier_pred) ** 2), np.mean(np.abs(outlier_true - outlier_pred))))

# 分类损失：二元交叉熵
eps = 1e-12
p = np.clip(y_pred, eps, 1 - eps)
bce = -np.mean(y_true * np.log(p) + (1 - y_true) * np.log(1 - p))
print("二元交叉熵 BCE = %.4f" % bce)

# 多分类交叉熵：logits -> softmax -> 取真实类别的负对数
logits = np.array([[2.0, 1.0, 0.1], [0.5, 2.5, 0.3]])
labels = np.array([0, 1])
e = np.exp(logits - logits.max(axis=1, keepdims=True))
probs = e / e.sum(axis=1, keepdims=True)
print("softmax 概率 =\n", np.round(probs, 4))
print("多分类交叉熵 CE = %.4f" % -np.mean(np.log(probs[np.arange(len(labels)), labels])))
print("交叉熵与梯度：dCE/dlogit = p - onehot(y)，预测越错梯度越大")
```

真实输出（本机执行）：

```text
MSE = 0.07
含异常样本 MSE = 0.3025  MAE = 0.4250
二元交叉熵 BCE = 0.2798
softmax 概率 =
 [[0.659  0.2424 0.0986]
 [0.1086 0.8025 0.0889]]
多分类交叉熵 CE = 0.3185
交叉熵与梯度：dCE/dlogit = p - onehot(y)，预测越错梯度越大
```

第四个样本预测 0.0、真值 1.0，是一个极端错误。MSE 对它的梯度是 2(pred − true) = -2.0，MAE 的梯度恒为 ±1，也就是说同一个异常样本对 MSE 的参数更新推动力是 MAE 的两倍——因为 MSE 隐含假设噪声服从高斯分布，遇到重尾分布或脏数据时会被少数极端样本主导。注意交叉熵的实现不能先算概率再取对数，`softmax` 输出的 0.8025 取 log 没问题，但极小概率直接 `log` 会下溢成 `-inf`，所以框架里都用 log-softmax 合并计算。

常见损失函数对照：

| 损失 | 表达式要点 | 适用任务 | 特点 |
|---|---|---|---|
| MSE / L2 | 误差平方的均值 | 回归 | 可导、对大误差敏感、假设噪声近似高斯 |
| MAE / L1 | 绝对误差的均值 | 回归（含异常值） | 对异常值稳健，原点不可导、梯度恒定 |
| Huber | 小误差用 L2、大误差用 L1 | 回归（折中） | 兼顾稳健与可导，需设 delta 阈值 |
| 二元交叉熵 | `-[y·log p + (1-y)·log(1-p)]` | 二分类、多标签 | 与 sigmoid 配套，梯度 = p - y |
| 多分类交叉熵 | `-log softmax(logits)[真实类]` | 多分类 | 与 softmax 配套，需注意数值稳定性 |
| 对比损失 / InfoNCE | 拉近正样本、推远负样本 | 表征学习、检索 | 依赖负样本构造，是 RAG 与 CLIP 的基础 |

```text
损失函数选择要点：
1. 回归默认 MSE，数据有异常值或重尾分布换 MAE 或 Huber
2. 分类默认交叉熵，别用 MSE 训分类（梯度会在预测饱和时消失）
3. 交叉熵的实现要用 log-softmax 组合（如 PyTorch 的 CrossEntropyLoss 已内含 softmax），避免先算概率再取对数导致下溢
4. 不平衡数据用加权交叉熵或 focal loss，而不是靠调阈值解决全部问题
5. 多任务学习要给每个任务的损失设权重，权重本身就是超参数，需要调
```

## 梯度下降与优化算法

梯度下降是机器学习训练的统一引擎：损失函数对参数的梯度指向上升最快的方向，沿反方向走一小步就能降低损失，步长由学习率控制。按每次用多少样本算梯度分三种：批量梯度下降（BGD，用全部样本，稳定但慢）、随机梯度下降（SGD，用一个样本，快但抖）、小批量梯度下降（Mini-batch，用一批，工程上默认选择）。在基础梯度下降上加动量（Momentum）能抑制震荡、加速收敛；Adam 进一步做逐参数自适应学习率，是目前最常用的默认优化器。

```python
import numpy as np

# 造一个已知答案的线性回归问题：y = 2*x1 - 1*x2 + 0.5*x3 + 噪声
rng = np.random.default_rng(0)
n, d = 500, 3
X = rng.normal(size=(n, d))
w_true = np.array([2.0, -1.0, 0.5])
y = X @ w_true + 0.1 * rng.normal(size=n)
print("真值 w =", w_true, " 理论最优 MSE = %.4f（噪声方差 0.1^2）" % 0.01)

def mse(w, b):
    r = X @ w + b - y
    return float(r @ r / n)

def train(kind, lr, epochs=200, batch=None):
    w, b = np.zeros(d), 0.0
    m, v, mom = np.zeros(d), np.zeros(d), np.zeros(d)
    hist = {}
    for t in range(1, epochs + 1):
        if batch is None:                      # 批量梯度下降：全量算梯度
            idx = np.arange(n)
        else:                                  # 小批量：每轮抽一个 batch
            idx = rng.choice(n, size=batch, replace=False)
        Xb, yb = X[idx], y[idx]
        grad_w = 2 * Xb.T @ (Xb @ w + b - yb) / len(idx)
        grad_b = 2 * np.mean(Xb @ w + b - yb)
        if kind == "adam":
            m = 0.9 * m + 0.1 * grad_w
            v = 0.999 * v + 0.001 * grad_w ** 2
            w -= lr * (m / (1 - 0.9 ** t)) / (np.sqrt(v / (1 - 0.999 ** t)) + 1e-8)
        elif kind == "momentum":
            mom = 0.9 * mom + grad_w
            w -= lr * mom
        else:
            w -= lr * grad_w
        b -= lr * grad_b
        if t in (5, 20, 200):
            hist[t] = mse(w, b)
    return w, hist

for kind, lr in (("sgd", 0.05), ("momentum", 0.02), ("adam", 0.2)):
    w, hist = train(kind, lr)
    print("%-9s w = %s  loss@5=%.4f loss@20=%.5f loss@200=%.6f"
          % (kind, np.round(w, 3), hist[5], hist[20], hist[200]))

w_mb, hist_mb = train("sgd", 0.05, batch=32)
print("mini-batch(32) w = %s  loss@200=%.6f（同样 200 轮，算的梯度次数多得多）" % (np.round(w_mb, 3), hist_mb[200]))
```

真实输出（本机执行）：

```text
真值 w = [ 2.  -1.   0.5]  理论最优 MSE = 0.0100（噪声方差 0.1^2）
sgd       w = [ 2.004 -0.999  0.506]  loss@5=1.8317 loss@20=0.11160 loss@200=0.010587
momentum  w = [ 2.004 -0.999  0.506]  loss@5=1.4766 loss@20=0.44729 loss@200=0.010587
adam      w = [ 2.004 -0.999  0.506]  loss@5=1.0771 loss@20=0.30910 loss@200=0.010587
mini-batch(32) w = [ 2.004 -0.996  0.507]  loss@200=0.010632（同样 200 轮，算的梯度次数多得多）
```

三种优化器最终都收敛到近似真值（0.010587，已经贴住理论最优 0.01），但收敛速度差别明显：第 5 轮 Adam 的损失是 1.0771，普通梯度下降是 1.8317，动量法 1.4766——Adam 的自适应步长让它在病态方向上走得更快。小批量版本用 32 个样本估梯度，200 轮后损失 0.010632，与全量几乎一致，但每轮只用了 32 个样本的代价。

优化器演进：

| 优化器 | 核心机制 | 优点 | 缺点与注意 |
|---|---|---|---|
| BGD | 全量样本算梯度 | 梯度精确、收敛平稳 | 大数据集一轮太慢，内存压力大 |
| SGD | 单样本算梯度 | 更新快、能跳出局部极小 | 抖动大，需要学习率衰减 |
| Mini-batch SGD | 一批算梯度 | 兼顾速度与稳定性、利于 GPU 并行 | batch size 需调，太小噪声大太大显存爆 |
| Momentum | 累积历史梯度方向 | 抑制震荡、加速穿越平缓区 | 多一个动量系数要调 |
| RMSProp / AdaGrad | 按参数的历史梯度平方缩放学习率 | 适合稀疏特征 | 需维护状态，早期学习率易衰减过快 |
| Adam / AdamW | 动量 + 自适应学习率 + 偏差修正 | 开箱即用，收敛快 | 泛化偶尔不如调好的 SGD；权重衰减要用解耦版 AdamW |

```text
梯度下降实践要点：
1. 学习率是第一超参数，先做 lr 扫描（如 1e-1 / 1e-2 / 1e-3）再调别的
2. 工程默认用 mini-batch（32-512）+ Adam 做基线，追求极限泛化时换 SGD + 动量 + 余弦退火
3. 梯度要做归一化：特征不标准化会让同一学习率在不同维度上表现差异巨大
4. 监控训练损失曲线：不下降是学习率太小或梯度断了；震荡发散是学习率太大
5. 大模型训练用梯度裁剪（grad clip）防止个别 batch 的异常梯度毁掉训练
```

## 过拟合与正则化

过拟合指模型把训练数据里的噪声也学了进去，表现为训练集指标远好于验证集。判断过拟合的标准是「训练与验证的差距」，不是训练指标本身。对抗过拟合有两条路：降低模型有效容量（更浅的网络、更少特征、限制树深度），或加约束（L1/L2 正则、Dropout、早停、数据增强）。L2 正则把权重往 0 压但不为 0，L1 会把部分权重直接压成 0 从而做特征选择。

```python
import numpy as np
from sklearn.datasets import make_classification, make_regression
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.metrics import accuracy_score, root_mean_squared_error

# 1) 容量控制：同样的数据，限制决策树深度
Xb, yb = make_classification(n_samples=120, n_features=30, n_informative=5, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(Xb, yb, test_size=0.3, random_state=0)
t1 = DecisionTreeClassifier(random_state=0).fit(Xtr, ytr)
t2 = DecisionTreeClassifier(max_depth=3, min_samples_leaf=5, random_state=0).fit(Xtr, ytr)
print("完全不剪枝     训练 %.4f 测试 %.4f（严重过拟合）" % (t1.score(Xtr, ytr), t1.score(Xte, yte)))
print("max_depth=3    训练 %.4f 测试 %.4f" % (t2.score(Xtr, ytr), t2.score(Xte, yte)))

# 2) L1/L2 正则：120 个特征里只有 10 个真正有用
Xr, yr = make_regression(n_samples=200, n_features=120, n_informative=10, noise=25.0, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(Xr, yr, test_size=0.3, random_state=0)
for name, model in (("OLS", LinearRegression()),
                    ("Ridge(alpha=1)", Ridge(alpha=1.0)),
                    ("Ridge(alpha=1000)", Ridge(alpha=1000.0)),
                    ("Lasso(alpha=2)", Lasso(alpha=2.0, max_iter=20000))):
    m = make_pipeline(StandardScaler(), model).fit(Xtr, ytr)
    coef = m[-1].coef_
    print("%-18s 测试 RMSE %8.2f  非零系数 %3d / 120  ||w||=%.1f"
          % (name, root_mean_squared_error(yte, m.predict(Xte)),
             int(np.sum(np.abs(coef) > 1e-6)), np.linalg.norm(coef)))
```

真实输出（本机执行）：

```text

max_depth=3    训练 0.9524 测试 0.8056
OLS                测试 RMSE    58.77  非零系数 120 / 120  ||w||=205.8
```

三个结论一目了然：不剪枝的树训练准确率 1.0、测试只有 0.8056，差距 0.19 就是过拟合；L2 正则缩小了权重范数（205.8 → 194.6），测试 RMSE 从 58.77 降到 51.07；但 alpha 调到 1000 时权重被压得太狠（范数 29.4），测试 RMSE 反弹到 165.27，变成欠拟合。正则强度是需要调的，不是越大越好。L1 则直接把 120 个特征压到 31 个非零，测试 RMSE 最低（23.80）：稀疏解在这个「特征多、有效特征少」的场景里最有效。

```text

1. 判断过拟合看「训练 - 验证」的差距，不是训练指标绝对值
2. L2（Ridge / weight_decay）缩小权重、平滑模型，是最通用的默认选择
3. L1（Lasso）产生稀疏解、可做特征选择，但特征高度相关时结果不稳定
4. Dropout 是神经网络的专属正则，训练时随机置零激活，推理时关闭
5. 早停（early stopping）用验证集指标连续若干轮不提升就停，是性价比最高的正则手段
6. 正则强度（alpha / weight_decay / dropout 概率）必须通过验证集调，调过头就是欠拟合
```

## 评估指标与选择

评估指标决定「什么算好」，选错指标会得到与业务目标相反的结果。分类任务看混淆矩阵派生的指标：准确率在不平衡数据上会骗人，精确率（precision）关心「报出来的有多少是真的」，召回率（recall）关心「真的抓到了多少」，F1 是两者的调和平均，ROC-AUC 衡量整体排序能力且不受阈值影响。回归任务用 RMSE（与目标同量纲、放大大误差）、MAE（稳健）、R2（解释了多大比例的方差）。

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import (accuracy_score, precision_score, recall_score, f1_score,
                             roc_auc_score, average_precision_score, confusion_matrix)

# 类别不平衡：正例约 10%
Xb, yb = make_classification(n_samples=2000, n_features=10, weights=[0.9, 0.1], random_state=42)
Xtr, Xte, ytr, yte = train_test_split(Xb, yb, test_size=0.3, random_state=42, stratify=yb)
clf = make_pipeline(StandardScaler(), GradientBoostingClassifier(random_state=0)).fit(Xtr, ytr)
prob = clf.predict_proba(Xte)[:, 1]
pred = clf.predict(Xte)
print("混淆矩阵 [[TN FP],[FN TP]]:\n", confusion_matrix(yte, pred))
print("全猜负类的准确率（基线）= %.4f" % (1 - yte.mean()))
print("accuracy  %.4f" % accuracy_score(yte, pred))
print("precision %.4f  recall %.4f  f1 %.4f" % (precision_score(yte, pred), recall_score(yte, pred), f1_score(yte, pred)))
print("roc_auc   %.4f   pr_auc %.4f" % (roc_auc_score(yte, prob), average_precision_score(yte, prob)))
for thr in (0.5, 0.3):
    p = (prob >= thr).astype(int)
    print("阈值 %.1f -> recall %.4f precision %.4f" % (thr, recall_score(yte, p), precision_score(yte, p)))
```

真实输出（本机执行）：


注意「全猜负类的准确率」基线是 0.8983，模型 0.9367 看起来只高了约 4 个百分点；但精确率 0.6949 说明报出来的风险样本里约七成是真的，召回率 0.6721 说明真风险里抓到了三分之二——这才是业务关心的数字。指标必须和基线一起看。

指标选择表：

| 场景 | 推荐指标 | 理由 |
|---|---|---|
| 类别平衡的分类 | accuracy / F1 | 类别均衡时准确率不失真 |
| 类别不平衡的分类 | PR-AUC / F1 / recall@precision | 负类占多数时 accuracy 与 ROC-AUC 都偏高估 |
| 排序与推荐 | NDCG / MAP / Recall@K | 关心的是排序位置而非单个标签 |
| 回归（同量纲） | RMSE / MAE | 与业务单位一致，便于沟通 |
| 回归（相对解释力） | R2 | 表示解释了目标方差的比例，可跨任务比较 |
| 概率校准质量 | LogLoss / Brier / 校准曲线 | 关心「模型说 0.8 就真的约八成」 |

```text
评估指标要点：
1. 先算基线（全猜多数类、规则系统、上一版模型），没有基线的指标没有意义
2. 不平衡分类别只看 accuracy，看 PR-AUC 并在业务约束下选阈值
3. 指标必须与业务成本对齐：漏判成本 vs 误判成本决定你优化 precision 还是 recall
4. 训练时用的损失函数和上线用的评估指标可以不同，但要确认优化方向不冲突
5. 报告结果要带交叉验证均值与标准差，单次划分的结果不足以支撑决策
```

## 偏差与方差

偏差（bias）是模型假设与真实规律的系统性差距，高偏差表现为训练和验证都差，即欠拟合；方差（variance）是模型对训练集扰动的敏感度，高方差表现为训练好、验证差，即过拟合。二者的权衡是机器学习最基本的取舍：模型容量越大，偏差越小、方差越大。诊断方法是对比不同复杂度模型的训练/验证误差曲线——两条曲线都高是偏差问题（加特征、加容量、换模型），只有验证曲线高是方差问题（加数据、加正则、减容量）。

```python
import numpy as np

# 用多项式拟合 sin 曲线：次数 = 模型容量
rng = np.random.default_rng(1)
Xs = np.linspace(-3, 3, 25)
ys = np.sin(Xs) + 0.3 * rng.normal(size=Xs.size)     # 真实规律 + 噪声
Xt = np.linspace(-3, 3, 200)
yt = np.sin(Xt)
rows = []
for deg in (1, 3, 9, 15):
    coef, *_ = np.linalg.lstsq(np.vander(Xs, deg + 1), ys, rcond=None)
    train_err = float(np.mean((np.vander(Xs, deg + 1) @ coef - ys) ** 2))
    test_err = float(np.mean((np.vander(Xt, deg + 1) @ coef - yt) ** 2))
    rows.append((deg, train_err, test_err))
best_test = min(r[2] for r in rows)                  # 复杂度扫描里最好的泛化误差
print("degree  训练MSE   测试MSE   结论")
for deg, tr_e, te_e in rows:
    verdict = "高偏差（欠拟合）" if tr_e > 0.15 else ("高方差（过拟合）" if te_e > 1.5 * best_test else "合适")
    print("%5d   %8.4f  %8.4f   %s" % (deg, tr_e, te_e, verdict))
```

真实输出（本机执行）：

```text
degree  训练MSE   测试MSE   结论
    1     0.2645    0.1805   高偏差（欠拟合）
    3     0.0464    0.0054   合适
    9     0.0193    0.0211   高方差（过拟合）
   15     0.0126    0.0338   高方差（过拟合）
```

1 次多项式在训练集上是 0.2645，测试 0.1805，两条曲线都高——典型的高偏差；9 次和 15 次多项式训练误差降到 0.0193 和 0.0126，但测试误差反弹到 0.0211 和 0.0338——典型的高方差。3 次多项式两边都低，是容量最匹配的点。

```text
偏差方差诊断要点：
1. 训练高、验证高 -> 偏差问题：加特征、加容量、减小正则、延长训练
2. 训练低、验证高 -> 方差问题：加数据、加正则、减容量、集成（bagging）
3. 学习曲线是标准诊断工具：曲线是否还在上升决定加数据有没有用
4. 加数据只解决方差，不解决偏差；偏差高时花钱标数据是浪费
5. 集成方法天然降方差：bagging（随机森林）降方差，boosting 主要降偏差
```

## 应用场景实战

### 场景一：低正例率场景下的风险模型交付（PR-AUC 驱动选型）

金融风控、欺诈检测、设备故障预警的共同特点是正例极少（本例 3.6%），这时 ROC-AUC 会显得很高但业务效果可能很差。正确做法是用 PR-AUC（平均精度）做模型选择，再用 precision-recall 曲线按业务约束（例如「召回率不低于 0.6」）反选阈值。

```python
# pip install scikit-learn
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, StratifiedKFold, GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (average_precision_score, roc_auc_score,
                             precision_recall_curve, classification_report)

X, y = make_classification(n_samples=8000, n_features=25, n_informative=8,
                           weights=[0.97, 0.03], flip_y=0.01, random_state=7)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, random_state=7, stratify=y)
print("训练集 %d 条，正例率 %.4f" % (len(ytr), ytr.mean()))

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=7)
candidates = {
    "logreg": (make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000, class_weight="balanced")),
               {"logisticregression__C": [0.1, 1.0]}),
    "rf": (RandomForestClassifier(n_estimators=200, class_weight="balanced", random_state=7),
           {"n_estimators": [200], "max_depth": [6, None]}),
}
best = {}
for name, (est, grid) in candidates.items():
    gs = GridSearchCV(est, grid, scoring="average_precision", cv=cv, n_jobs=-1).fit(Xtr, ytr)
    best[name] = gs.best_estimator_
    print("%-7s 最佳参数 %-38s CV PR-AUC %.4f" % (name, str(gs.best_params_), gs.best_score_))

for name, model in best.items():
    prob = model.predict_proba(Xte)[:, 1]
    prec, rec, thr = precision_recall_curve(yte, prob)
    ok = rec[:-1] >= 0.60                      # 业务约束：召回率不低于 0.6
    picked = float(thr[ok].max()) if ok.any() else 0.5
    print("%s: ROC-AUC %.4f  PR-AUC %.4f  满足召回的阈值 %.3f"
          % (name, roc_auc_score(yte, prob), average_precision_score(yte, prob), picked))
    print(classification_report(yte, (prob >= picked).astype(int), digits=3,
                                target_names=["正常", "风险"], zero_division=0))
```

### 场景二：用学习曲线判断「该加数据还是该换模型」

模型效果不达标时，团队的第一反应往往是「再标点数据」。学习曲线能直接回答这个问题：把训练集从 10% 逐步加到 100%，画训练与验证分数。如果验证曲线已经走平，加数据的收益接近零，该做的是换更强的模型或加特征；如果两条曲线差距大且验证曲线仍在上升，加数据才有用。

```python
# pip install scikit-learn
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import learning_curve, train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier

def diagnose(est, X, y, name):
    sizes, train_scores, test_scores = learning_curve(
        est, X, y, cv=5, scoring="accuracy",
        train_sizes=np.linspace(0.1, 1.0, 6), n_jobs=-1)
    tr, te = train_scores.mean(axis=1), test_scores.mean(axis=1)
    print("== %s ==" % name)
    for s, a, b in zip(sizes, tr, te):
        print("  样本 %5d  训练 %.4f  验证 %.4f  差距(训练-验证) %+.4f" % (s, a, b, a - b))
    gap, final_te = tr[-1] - te[-1], te[-1]
    if gap > 0.15:
        print("  诊断：严重过拟合 -> 加正则/减容量/加数据")
    elif final_te < 0.75 and (te[-1] - te[-2]) > 0.01:
        print("  诊断：欠拟合且曲线仍在上行 -> 加数据或提升模型容量")
    elif final_te < 0.75:
        print("  诊断：欠拟合（训练与验证都低）-> 换更强模型或加特征")
    else:
        print("  诊断：已接近该模型上限，继续加数据的收益有限")
    print()

Xb, yb = make_classification(n_samples=3000, n_features=20, n_informative=3,
                             n_redundant=0, class_sep=0.9, flip_y=0.06, random_state=3)
Xtr, Xte, ytr, yte = train_test_split(Xb, yb, test_size=0.2, random_state=3)
diagnose(make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)), Xtr, ytr, "线性模型（容量小）")
diagnose(RandomForestClassifier(n_estimators=300, random_state=3), Xtr, ytr, "随机森林 max_depth=None（容量大）")
diagnose(RandomForestClassifier(n_estimators=300, max_depth=3, random_state=3), Xtr, ytr, "随机森林 max_depth=3（限制容量）")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 任何实验先建立基线（多数类预测、规则系统、上一版模型），没有基线的指标无法解释
2. 数据划分优先用分层抽样（`stratify`）；时序数据必须按时间切分，绝不能随机打乱
3. 特征标准化、缺失值填补等预处理必须放进 Pipeline，避免用测试集信息污染训练
4. 报告结果时给交叉验证的均值与标准差，单次划分的差异可能完全来自随机种子
5. 不平衡分类用 PR-AUC 选模型、按业务成本选阈值，不要迷信默认 0.5 和 accuracy
6. 正则强度、学习率、树深度这类超参数一律用验证集调，禁止在测试集上调参
7. 每次实验记录数据版本、随机种子、超参数与指标，保证可复现

### 踩坑记录

```text
坑 1：在划分训练/测试集之前就做了标准化或缺失值填补
结论：测试集指标虚高，上线后效果明显下滑。
原因：全局统计量（均值、方差、中位数）把测试集信息泄漏进了训练过程，即数据泄漏。
解法：把所有依赖统计量的预处理放进 Pipeline，只对训练折 fit，再 transform 验证折与测试集。

坑 2：特征量纲差异大却直接跑梯度下降
结论：损失震荡不收敛，或某个维度的参数几乎不动。
原因：未标准化时不同维度的梯度尺度相差几个数量级，同一个学习率无法同时适配。
解法：树模型可以不管量纲，线性模型/神经网络必须先做标准化，再扫学习率。

坑 3：半监督的伪标签用错了置信度阈值，效果反而比只用少量标签更差
结论：本主题实测中伪标签自训练让准确率从 0.7156 掉到 0.7044。
原因：基础模型不够强时，错误预测被赋予高置信度并回灌进训练集，形成确认偏差。
解法：提高阈值（如 0.9 以上）、只在一轮里加少量高置信样本、每轮都在独立验证集上验证，不提升就停。

坑 4：不平衡数据只看准确率并直接使用 0.5 阈值
结论：模型准确率 0.93 看似不错，实际召回率只有 0.67，漏掉三分之一的风险客户。
原因：负类占比高会抬高 accuracy，而默认阈值与业务成本无关。
解法：用 PR-AUC 评估、按业务成本反选阈值、必要时用 class_weight 或采样调整。

坑 5：时序数据随机划分训练集与测试集
结论：离线指标漂亮，线上完全失效。
原因：随机划分会让「未来」的样本进入训练集，模型学到的信息在预测时不可得。
解法：按时间切分（如前 80% 训练、后 20% 测试），或使用滚动窗口式的时间序列交叉验证。
```
