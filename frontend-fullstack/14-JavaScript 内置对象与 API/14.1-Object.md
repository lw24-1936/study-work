## 概述

Object 是 JavaScript 的内置对象，提供大量静态方法用于遍历、转换、控制对象的属性。这些方法是日常开发处理对象的核心工具。

```text
Object 静态方法分类：
遍历 —— keys、values、entries、fromEntries
属性控制 —— defineProperty、freeze、seal、preventExtensions
原型 —— create、getPrototypeOf、setPrototypeOf
其他 —— assign、hasOwn、is
```

## Object.keys / values / entries

三个方法用于遍历对象的键、值、键值对，都只返回**自有可枚举**属性。

```js
const obj = { a: 1, b: 2, c: 3 };

Object.keys(obj);       // ['a', 'b', 'c']（键数组）
Object.values(obj);     // [1, 2, 3]（值数组）
Object.entries(obj);    // [['a',1], ['b',2], ['c',3]]（键值对数组）
```

```js
// 配合 for...of 遍历
for (const [key, value] of Object.entries(obj)) {
  console.log(key, value);
}
```

```js
// 注意：只返回自有可枚举属性，不含原型链、不含 Symbol
const o = { a: 1 };
Object.defineProperty(o, 'hidden', { value: 2, enumerable: false });
Object.keys(o);         // ['a']（hidden 不可枚举，不返回）
```

```text
keys/values/entries 的边界：
1. 只返回「自有」属性（不遍历原型链）
2. 只返回「可枚举」属性
3. 不包含 Symbol 键（Symbol 用 getOwnPropertySymbols）
```

## Object.fromEntries

fromEntries 是 entries 的逆操作，把键值对数组转回对象。

```js
// entries → fromEntries 往返
const obj = { a: 1, b: 2 };
const entries = Object.entries(obj);   // [['a',1],['b',2]]
const back = Object.fromEntries(entries);  // { a: 1, b: 2 }
```

```js
// Map → 对象
const map = new Map([['x', 1], ['y', 2]]);
const objFromMap = Object.fromEntries(map);   // { x: 1, y: 2 }
```

```js
// 实用：数组转对象（配合 map）
const users = [['id1', 'Alice'], ['id2', 'Bob']];
const userMap = Object.fromEntries(users);   // { id1: 'Alice', id2: 'Bob' }

// 键转换
const transformed = Object.fromEntries(
  Object.entries(obj).map(([k, v]) => [k.toUpperCase(), v]),
);
```

## Object.freeze 冻结

freeze 让对象**完全不可变**：不能增删改属性，且浅冻结（嵌套对象不受影响）。

```js
const obj = Object.freeze({ name: 'Alice' });

obj.name = 'Bob';      // 静默失败（严格模式抛错）
obj.age = 30;          // 不生效
delete obj.name;       // 不生效

obj.name;              // 'Alice'（未变）
```

```js
// 判断是否冻结
Object.isFrozen(obj);   // true
```

```js
// 浅冻结：嵌套对象仍可变
const o = Object.freeze({ nested: { x: 1 } });
o.nested.x = 999;       // 生效！nested 未被冻结
```

```text
freeze 的特性：
1. 不可增删改 —— 属性完全只读
2. 浅冻结 —— 只冻结顶层，嵌套对象需递归冻结
3. 配合 const 使用 —— const 防重赋值，freeze 防改内容
```

```js
// 深冻结
function deepFreeze(obj) {
  Object.values(obj).forEach(v => {
    if (v && typeof v === 'object') deepFreeze(v);
  });
  return Object.freeze(obj);
}
```

## Object.seal 密封

seal 禁止**增删**属性，但允许**修改**已有属性的值。

```js
const obj = Object.seal({ name: 'Alice' });

obj.name = 'Bob';      // 允许（可改值）
obj.age = 30;          // 不允许（不能新增）
delete obj.name;       // 不允许（不能删除）

Object.isSealed(obj);  // true
```

```text
freeze vs seal vs preventExtensions：
freeze —— 不可增、删、改（完全冻结）
seal —— 不可增、删，可改值（密封）
preventExtensions —— 不可增，可删、可改（禁扩展）

冻结程度：freeze > seal > preventExtensions
```

## Object.defineProperty 定义属性

defineProperty 精确控制属性的描述符（值、可写、可枚举、可配置）。

```js
const obj = {};

Object.defineProperty(obj, 'name', {
  value: 'Alice',
  writable: false,       // 不可写
  enumerable: true,      // 可枚举
  configurable: false,   // 不可配置
});

obj.name;                // 'Alice'
obj.name = 'Bob';        // 静默失败（writable false）
```

```js
// 定义访问器属性（getter/setter）
Object.defineProperty(obj, 'fullName', {
  get() { return `${this.first} ${this.last}`; },
  set(v) { [this.first, this.last] = v.split(' '); },
});
```

```text
defineProperty 的默认值（与字面量相反）：
用 defineProperty 定义时，writable/enumerable/configurable 默认都是 false！
用字面量定义时，三者默认 true。

这是常见坑：defineProperty 定义的属性默认不可枚举、不可写。
```

```js
// 批量定义
Object.defineProperties(obj, {
  a: { value: 1, writable: true, enumerable: true },
  b: { value: 2, writable: true, enumerable: true },
});
```

## 应用场景实战

### 场景一：配置对象的不可变保护

```js
const CONFIG = Object.freeze({
  apiBase: 'https://api.example.com',
  timeout: 3000,
});
// 全局配置不可被意外修改
```

### 场景二：对象与 Map 互转

```js
// 对象 → Map
const map = new Map(Object.entries(obj));

// Map → 对象
const objBack = Object.fromEntries(map);
```

## 最佳实践与踩坑记录

### 最佳实践

1. 遍历对象用 Object.keys/values/entries + for...of
2. 键值对数组转对象用 fromEntries（替代手写 reduce）
3. 需要不可变的配置用 freeze（注意深冻结）
4. 精确控制属性用 defineProperty，记得显式写描述符
5. 判断自有属性用 Object.hasOwn

### 踩坑记录

```text
坑 1：defineProperty 默认不可枚举
结论：defineProperty 定义的属性 Object.keys 看不到。
原因：默认 enumerable 为 false。
解法：显式写 enumerable: true。

坑 2：freeze 是浅冻结
结论：冻结后嵌套对象仍可改。
原因：freeze 只冻结顶层。
解法：需要深冻结用递归 deepFreeze。

坑 3：keys 不含 Symbol 和原型属性
结论：遍历「漏掉」了某些属性。
原因：keys 只返回自有可枚举字符串键。
解法：Symbol 用 getOwnPropertySymbols，原型属性需显式处理。

坑 4：freeze 后静默失败
结论：非严格模式改冻结对象不报错，难以发现。
原因：静默失败，无异常。
解法：严格模式开发，或用 try/catch 明确。

坑 5：fromEntries 覆盖重复键
结论：重复键时后者覆盖前者。
原因：对象键唯一，fromEntries 后写覆盖先写。
解法：注意键唯一性，或用 Map（可重复遍历）。
```
