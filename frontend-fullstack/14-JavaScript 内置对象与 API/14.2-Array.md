## 概述

Array 是前端最常用的数据结构，其方法分为**返回新数组**（不可变）和**原地修改**（可变）两类。掌握这些方法的语义与边界，能写出简洁、正确的数据处理代码。

```text
数组方法分类：
遍历转换 —— map、filter、reduce、forEach、flatMap
查找 —— find、findIndex、findLast、some、every、includes
排序 —— sort、toSorted、reverse、toReversed
增删改 —— push、pop、shift、unshift、splice、slice、concat
扁平化 —— flat、flatMap

关键：区分「返回新数组」vs「原地修改」，避免副作用。
```

## map / filter / reduce

map 映射每个元素，filter 过滤元素，reduce 归约为单个值。三者是函数式数据处理的核心。

```js
// map：逐个转换
[1, 2, 3].map(n => n * 2);           // [2, 4, 6]

// filter：过滤符合条件的
[1, 2, 3, 4].filter(n => n % 2 === 0);  // [2, 4]

// reduce：归约为单个值
[1, 2, 3, 4].reduce((acc, n) => acc + n, 0);  // 10
```

```js
// 链式组合
const users = [
  { name: 'Alice', age: 25 },
  { name: 'Bob', age: 17 },
  { name: 'Cara', age: 30 },
];

const adultNames = users
  .filter(u => u.age >= 18)   // 过滤成年
  .map(u => u.name)           // 提取名字
  .sort();                    // 排序
```

```js
// reduce 的进阶用法
// 分组
const grouped = users.reduce((acc, u) => {
  (acc[u.age >= 18 ? 'adult' : 'minor'] ||= []).push(u);
  return acc;
}, {});

// 计数
const count = [1, 2, 2, 3, 3, 3].reduce((acc, n) => {
  acc[n] = (acc[n] || 0) + 1;
  return acc;
}, {});
```

## forEach 与 reduceRight

forEach 逐个执行副作用（不返回新数组）；reduceRight 从右向左归约。

```js
// forEach：执行副作用（打印、推送）
[1, 2, 3].forEach(n => console.log(n));

// 注意：forEach 不返回数组，且无法 break
```

```js
// reduceRight：从右向左归约
[1, 2, 3].reduceRight((acc, n) => acc - n, 0);   // -6（0-3-2-1）
[1, 2, 3].reduce((acc, n) => acc - n, 0);        // -6（0-1-2-3）
```

```text
forEach vs map：
forEach —— 副作用（打印、修改外部），不返回
map —— 转换并返回新数组

需要「返回值」用 map，纯「副作用」用 forEach。
```

## find / findIndex / findLast

find 返回第一个匹配的元素，findIndex 返回下标，findLast 从后往前找。

```js
const arr = [1, 2, 3, 4, 5];

arr.find(n => n > 3);          // 4（第一个匹配元素）
arr.findIndex(n => n > 3);     // 3（下标）
arr.findLast(n => n < 5);      // 4（从后往前第一个）
arr.findLastIndex(n => n < 5); // 3

arr.find(n => n > 10);         // undefined（无匹配）
arr.findIndex(n => n > 10);    // -1
```

```text
find 系列的特点：
1. 返回「第一个」匹配（find 元素、findIndex 下标）
2. 无匹配返回 undefined / -1
3. findLast/findLastIndex 是 ES2023 新增（从后往前）
```

## some / every / includes

some 判断是否有元素满足，every 判断是否全部满足，includes 判断是否包含某值。

```js
const arr = [1, 2, 3, 4];

arr.some(n => n > 3);     // true（至少一个满足）
arr.every(n => n > 0);    // true（全部满足）
arr.every(n => n > 3);    // false

arr.includes(2);          // true（包含 2）
arr.includes(10);         // false

// includes 用严格相等（===），NaN 例外（能正确判断 NaN）
[NaN].includes(NaN);      // true
```

```text
some/every 的短路：
some —— 找到第一个满足即停止（true）
every —— 找到第一个不满足即停止（false）

空数组：every 返回 true，some 返回 false。
```

## flat / flatMap

flat 扁平化嵌套数组，flatMap 是先 map 再 flat(1)。

```js
// flat：指定深度扁平化
[1, [2, [3, [4]]]].flat();        // [1, 2, [3, [4]]]（默认深度 1）
[1, [2, [3, [4]]]].flat(2);       // [1, 2, 3, [4]]
[1, [2, [3, [4]]]].flat(Infinity);// [1, 2, 3, 4]（完全扁平）
```

```js
// flatMap：map + flat(1)
const arr = ['hello world', 'foo bar'];
arr.flatMap(s => s.split(' '));   // ['hello', 'world', 'foo', 'bar']

// 等价于
arr.map(s => s.split(' ')).flat();// 同上
```

```js
// flatMap 的典型：过滤 + 映射（返回空数组过滤）
[1, 2, 3, 4].flatMap(n => n % 2 === 0 ? [n * 2] : []);
// [4, 8]（奇数的返回空数组被 flat 掉）
```

## sort / toSorted

sort 原地排序（默认按字符串字典序），toSorted 返回新数组（ES2023）。

```js
// 默认排序：转字符串字典序（数字会出错）
[10, 2, 1].sort();          // [1, 10, 2]（字典序！）

// 数字排序：传比较函数
[10, 2, 1].sort((a, b) => a - b);   // [1, 2, 10]（升序）
[10, 2, 1].sort((a, b) => b - a);   // [10, 2, 1]（降序）
```

```js
// toSorted：返回新数组，不改原数组（ES2023）
const arr = [3, 1, 2];
const sorted = arr.toSorted();   // [1, 2, 3]
arr;                             // [3, 1, 2]（原数组不变）
```

```text
sort 的坑：
1. 默认按字符串字典序，数字排序必须传比较函数
2. sort 原地修改，toSorted 返回新数组
3. 比较函数返回负数 a 在前，正数 b 在前，0 不变
```

## splice / slice / concat

splice 原地增删改，slice 返回子数组副本，concat 合并数组。

```js
// splice：原地增删（会修改原数组）
const arr = [1, 2, 3, 4, 5];
arr.splice(2, 2);           // 从下标 2 删除 2 个，返回 [3, 4]
arr;                        // [1, 2, 5]（原数组被改）

arr.splice(1, 0, 9, 9);     // 在下标 1 插入，返回 []
arr;                        // [1, 9, 9, 2, 5]
```

```js
// slice：返回副本（不修改原数组）
const arr2 = [1, 2, 3, 4, 5];
arr2.slice(1, 3);           // [2, 3]（左闭右开）
arr2.slice(-2);             // [4, 5]（负索引）

// concat：合并
[1, 2].concat([3, 4]);      // [1, 2, 3, 4]
```

```text
splice vs slice（易混淆）：
splice —— 原地修改（增删改），返回被删除的元素
slice —— 返回副本（不改原数组），用于截取

现代替代：ES2023 的 toSpliced 返回新数组。
```

## 应用场景实战

### 场景一：数据管道式处理

```js
const orders = [...];

const totalRevenue = orders
  .filter(o => o.status === 'paid')
  .map(o => o.amount)
  .reduce((sum, a) => sum + a, 0);
```

### 场景二：去重与扁平化

```js
// 去重（Set）
const unique = [...new Set([1, 2, 2, 3])];   // [1, 2, 3]

// 扁平化嵌套
const flat = [[1, 2], [3, 4]].flat();        // [1, 2, 3, 4]
```

## 最佳实践与踩坑记录

### 最佳实践

1. 数据转换优先 map/filter/reduce，避免手写 for 循环
2. 需要新数组用 toSorted/toReversed/toSpliced，避免原地修改
3. 数字排序必须传比较函数
4. 去重用 Set，扁平化用 flat，过滤+映射用 flatMap
5. 判断存在用 some/includes，判断全部用 every

### 踩坑记录

```text
坑 1：默认 sort 按字典序
结论：[10, 2, 1].sort() 得到 [1, 10, 2]。
原因：默认转字符串按字典序比较。
解法：数字排序传 (a, b) => a - b。

坑 2：sort 原地修改
结论：排序后原数组变了，以为返回新数组。
原因：sort 原地排序。
解法：需要保留原数组用 [...arr].sort() 或 toSorted。

坑 3：forEach 不能 break
结论：forEach 里 break 报语法错误。
原因：forEach 是函数回调，不是循环语句。
解法：用 for...of（可 break），或 some/every 短路。

坑 4：splice 误用成 slice
结论：想截取却原地删除了原数组。
原因：splice 和 slice 混淆。
解法：截取用 slice，增删改用 splice。

坑 5：map 里用 forEach 或反之
结论：map 返回 undefined 数组，或 forEach 期望返回数组。
原因：方法语义混淆。
解法：转换用 map（返回新数组），副作用用 forEach。
```
