## 概述

JSON（JavaScript Object Notation）是数据交换的标准文本格式，跨语言、跨平台。它是前后端通信、配置存储、数据持久化的基石。

```text
JSON 的特性：
1. 纯文本 —— 可读、可传输、可存储
2. 语言无关 —— 几乎所有语言都支持
3. 结构简单 —— 对象（{}）和数组（[]）两种结构
4. 类型有限 —— 字符串、数字、布尔、null、对象、数组

两个核心方法：
JSON.parse —— 字符串 → 对象（反序列化）
JSON.stringify —— 对象 → 字符串（序列化）
```

```text
JSON 与 JavaScript 对象的区别：
JSON —— 纯文本，键必须双引号，无函数/undefined/注释
对象 —— JS 数据结构，键可无引号，可含函数等

JSON 合法的值：字符串、数字、布尔、null、对象、数组。
```

## JSON.parse 解析

JSON.parse 把 JSON 字符串解析为 JavaScript 对象。

```js
const json = '{"name":"Alice","age":30,"hobbies":["reading","code"]}';
const obj = JSON.parse(json);

obj.name;        // 'Alice'
obj.age;         // 30
obj.hobbies;     // ['reading', 'code']
```

```js
// 解析失败会抛异常
try {
  JSON.parse('{ invalid }');
} catch (error) {
  console.error('JSON 解析失败:', error.message);
}
```

```js
// 第二个参数 reviver：转换解析结果
const json2 = '{"date":"2026-01-15","count":"10"}';
const obj2 = JSON.parse(json2, (key, value) => {
  if (key === 'count') return Number(value);   // 转数字
  if (key === 'date') return new Date(value);  // 转日期
  return value;
});
```

## JSON.stringify 序列化

JSON.stringify 把 JavaScript 对象序列化为 JSON 字符串。

```js
const obj = { name: 'Alice', age: 30, active: true };
JSON.stringify(obj);     // '{"name":"Alice","age":30,"active":true}'
```

```js
// 第二个参数 replacer：过滤/转换
// 数组形式：只保留指定键
JSON.stringify(obj, ['name']);      // '{"name":"Alice"}'

// 函数形式：转换每个值
JSON.stringify(obj, (key, value) => {
  return typeof value === 'string' ? value.toUpperCase() : value;
});
```

```js
// 第三个参数 space：缩进美化
JSON.stringify(obj, null, 2);
// {
//   "name": "Alice",
//   "age": 30,
//   "active": true
// }
```

```text
stringify 会忽略的值：
1. undefined
2. 函数
3. Symbol（键和值都会被忽略）
4. 值为这些的键，序列化时被省略
```

```js
const o = {
  a: undefined,       // 被忽略
  b: function() {},   // 被忽略
  c: Symbol('x'),     // 被忽略
  d: null,            // 保留
};
JSON.stringify(o);    // '{"d":null}'
```

## Serialization 序列化

序列化是「对象 → 字符串」的过程，用于传输和存储。JSON.stringify 是最常用方式。

```js
// 序列化到存储
const state = { user: 'Alice', theme: 'dark' };
localStorage.setItem('app-state', JSON.stringify(state));

// 序列化到网络
fetch('/api/save', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(state),
});
```

```js
// toJSON 自定义序列化
const obj = {
  name: 'Alice',
  password: 'secret',
  toJSON() {
    return { name: this.name };   // 序列化时排除 password
  },
};
JSON.stringify(obj);   // '{"name":"Alice"}'
```

```text
自定义序列化（toJSON）：
对象定义 toJSON 方法，stringify 时会调用它，返回的值替代原对象。
常用于：隐藏敏感字段、定制输出结构。
```

## Deserialization 反序列化

反序列化是「字符串 → 对象」的过程，JSON.parse 是标准方式。

```js
// 从存储读取
const json = localStorage.getItem('app-state');
const state = JSON.parse(json);

// 从网络读取
const response = await fetch('/api/data');
const data = await response.json();   // fetch 内置 JSON 反序列化
```

```js
// 安全反序列化：捕获解析错误
function safeParse(json, fallback = null) {
  try {
    return JSON.parse(json);
  } catch {
    return fallback;
  }
}
```

```text
反序列化的注意：
1. 不信任的 JSON 要 try/catch
2. JSON 不含函数、日期等（日期是字符串，需手动转）
3. 原型污染 —— 解析后对象可能含 __proto__ 键（需注意）
```

## 应用场景实战

### 场景一：深拷贝（简单场景）

```js
// JSON 深拷贝（局限：丢失函数、undefined、日期、循环引用）
const copy = JSON.parse(JSON.stringify(original));
```

### 场景二：本地存储持久化

```js
// 保存
const prefs = { theme: 'dark', fontSize: 16 };
localStorage.setItem('prefs', JSON.stringify(prefs));

// 读取
const loaded = JSON.parse(localStorage.getItem('prefs'));
```

## 最佳实践与踩坑记录

### 最佳实践

1. JSON.parse 加 try/catch，避免解析失败崩溃
2. 序列化敏感对象用 toJSON 排除敏感字段
3. 深拷贝优先 structuredClone，JSON 方式仅用于纯数据
4. 大数据序列化注意性能，避免循环 stringify
5. 日期等特殊类型序列化前转字符串，解析后手动还原

### 踩坑记录

```text
坑 1：JSON.parse 解析失败抛异常
结论：非法 JSON 直接抛错，程序崩溃。
原因：parse 对非法输入抛 SyntaxError。
解法：try/catch 包裹，或 safeParse 兜底。

坑 2：JSON 不支持 undefined/函数
结论：序列化后这些字段消失。
原因：JSON 格式不支持 undefined、函数、Symbol。
解法：序列化前转换，或用 replacer 处理。

坑 3：JSON 深拷贝丢失特殊值
结论：用 JSON 深拷贝，日期变字符串、函数丢失、循环引用报错。
原因：JSON 只支持纯数据。
解法：用 structuredClone（支持更多类型）。

坑 4：字符串里的换行未转义
结论：多行文本序列化后 parse 报错。
原因：JSON 字符串中换行需转义。
解法：用 JSON.stringify 自动转义，别手写 JSON。

坑 5：原型污染
结论：解析含 __proto__ 的 JSON，对象原型被污染。
原因：JSON.parse 不会阻止 __proto__ 键。
解法：用 Object.create(null) 或过滤 __proto__ 键。
```
