## 概述

Intl 是 ECMAScript 的国际化 API，提供数字、日期、字符串比较、相对时间、复数规则、列表等本地化能力，替代手写格式化。

```text
Intl 的核心对象：
NumberFormat —— 数字、货币、百分比格式化
DateTimeFormat —— 日期时间格式化
Collator —— 语言感知的字符串排序/比较
RelativeTimeFormat —— 相对时间（3 天前、in 2 hours）
PluralRules —— 复数形式选择
ListFormat —— 列表连接（a、b 和 c）
```

## Locale 地区

Locale 是地区标识符（语言 + 地区 + 其他），决定格式化的规则。

```js
// 语言标签
'en'          // 英语
'zh-CN'       // 中文（简体，中国大陆）
'zh-TW'       // 中文（繁体，台湾）
'en-US'       // 英语（美国）
'ja-JP'       // 日语（日本）

// 获取用户默认地区
Intl.NumberFormat().resolvedOptions().locale;
```

```text
Locale 的组成：
语言（language）—— 如 zh、en
地区（region）—— 如 CN、US
脚本（script）—— 如 Hans、Hant
扩展（extension）—— 如 u-nu-hanidec

地区决定了：数字分隔符、日期格式、货币符号、排序规则等。
```

## NumberFormat 数字格式化

NumberFormat 格式化数字、货币、百分比，支持千分位、小数位等。

```js
// 千分位
new Intl.NumberFormat('en-US').format(1234567.89);   // '1,234,567.89'
new Intl.NumberFormat('zh-CN').format(1234567.89);   // '1,234,567.89'

// 小数位
new Intl.NumberFormat('en-US', {
  minimumFractionDigits: 2,
  maximumFractionDigits: 2,
}).format(123.4);                                    // '123.40'
```

```js
// 货币
new Intl.NumberFormat('zh-CN', {
  style: 'currency',
  currency: 'CNY',
}).format(12345);                                    // '¥12,345.00'

new Intl.NumberFormat('en-US', {
  style: 'currency',
  currency: 'USD',
}).format(12345);                                    // '$12,345.00'
```

```js
// 百分比
new Intl.NumberFormat('en-US', {
  style: 'percent',
}).format(0.123);                                    // '12%'
```

## DateTimeFormat 日期格式化

DateTimeFormat 按地区格式化日期时间（详见 [[14.4-Date-Temporal]]）。

```js
const d = new Date('2026-01-15T10:30:00');

new Intl.DateTimeFormat('zh-CN').format(d);          // '2026/1/15'
new Intl.DateTimeFormat('en-US').format(d);          // '1/15/2026'

new Intl.DateTimeFormat('zh-CN', {
  dateStyle: 'full',
  timeStyle: 'short',
}).format(d);                                        // '2026年1月15日星期四 10:30'
```

## Collator 字符串比较

Collator 提供语言感知的字符串排序和比较，正确处理本地排序规则（如中文拼音、重音）。

```js
// 默认 sort 按 Unicode 码点排序
['c', 'a', 'b'].sort();                    // ['a','b','c']（ASCII 没问题）

// 语言感知排序（处理重音、中文等）
const collator = new Intl.Collator('zh');
['啊', '波', '吧'].sort(collator.compare);  // 按拼音排序
```

```js
// 中文拼音排序
const names = ['张三', '李四', '王五'];
const zhCollator = new Intl.Collator('zh', { sensitivity: 'base' });
names.sort(zhCollator.compare);

// 比较大小
zhCollator.compare('a', 'b');   // -1（a < b）
```

```text
Collator 的价值：
1. 本地排序 —— 中文按拼音、法语按重音规则
2. 大小写/重音不敏感 —— sensitivity 选项
3. 数字感知 —— numeric: true 让 '2' < '10'
```

## RelativeTimeFormat 相对时间

RelativeTimeFormat 格式化「相对时间」，如「3 天前」「in 2 hours」。

```js
const rtf = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });

rtf.format(-1, 'day');        // '昨天'
rtf.format(-3, 'day');        // '3天前'
rtf.format(2, 'hour');        // '2小时后'
rtf.format(1, 'week');        // '下周'
```

```js
// 计算相对时间
function timeAgo(date) {
  const diff = date - Date.now();
  const minutes = Math.round(diff / 60000);
  const rtf = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });
  if (Math.abs(minutes) < 60) return rtf.format(minutes, 'minute');
  const hours = Math.round(minutes / 60);
  return rtf.format(hours, 'hour');
}
```

## PluralRules 与 ListFormat

PluralRules 选择复数形式，ListFormat 连接列表项。

```js
// PluralRules：根据数量选择复数类别
const pr = new Intl.PluralRules('en-US');
pr.select(0);      // 'other'
pr.select(1);      // 'one'
pr.select(2);      // 'other'
```

```js
// ListFormat：连接列表
const lf = new Intl.ListFormat('zh-CN', { type: 'conjunction' });
lf.format(['苹果', '香蕉', '橙子']);   // '苹果、香蕉和橙子'

const lfEn = new Intl.ListFormat('en-US', { type: 'disjunction' });
lfEn.format(['a', 'b', 'c']);          // 'a, b, or c'
```

```text
PluralRules 的用途：正确选择「1 个 / 多个」的词形。
ListFormat 的用途：本地化的「A、B 和 C」连接。
```

## 应用场景实战

### 场景一：金额展示

```js
function formatPrice(amount, currency = 'CNY') {
  return new Intl.NumberFormat('zh-CN', {
    style: 'currency',
    currency,
  }).format(amount);
}
formatPrice(12345.5);   // '¥12,345.50'
```

### 场景二：人性化时间

```js
function formatTimeAgo(date) {
  const seconds = Math.round((Date.now() - date) / 1000);
  const rtf = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });
  if (seconds < 60) return rtf.format(-seconds, 'second');
  if (seconds < 3600) return rtf.format(-Math.round(seconds / 60), 'minute');
  return rtf.format(-Math.round(seconds / 3600), 'hour');
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 数字、日期、货币展示用 Intl，别手写格式化
2. 本地排序用 Collator，别用默认 sort
3. 相对时间用 RelativeTimeFormat
4. 列表连接用 ListFormat
5. 货币金额注意区分「展示」与「计算」（计算用整数分）

### 踩坑记录

```text
坑 1：手写千分位
结论：自己拼正则或循环加逗号，易错且不支持本地化。
原因：忽略 Intl.NumberFormat。
解法：直接用 Intl.NumberFormat。

坑 2：默认 sort 排序中文/重音错误
结论：中文按码点排序，结果不符合预期。
原因：默认 sort 按 Unicode 码点，非语言规则。
解法：用 Intl.Collator 的 compare。

坑 3：货币金额用浮点计算
结论：金额出现精度误差。
原因：Intl 只负责格式化，计算仍需注意浮点。
解法：计算用整数分，格式化用 Intl 展示。

坑 4：忽略 locale 差异
结论：硬编码英文格式，多语言环境显示错误。
原因：未根据用户 locale 动态格式化。
解法：从用户/浏览器获取 locale，传入 Intl。

坑 5：RelativeTimeFormat 单位换算错误
结论：时间差换算单位时误差大。
原因：手动换算分钟/小时/天，边界处理不当。
解法：统一换算基准，或用库（如 dayjs）辅助。
```
