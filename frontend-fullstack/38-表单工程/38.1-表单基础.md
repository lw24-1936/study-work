## 概述

表单是用户输入数据的核心交互。一个完整表单由多种输入控件（Input、Select、Checkbox、Radio、Upload、Date Picker、Rich Text）组成，并配合校验（Validation）保证数据合法。掌握各类控件的受控写法与校验是表单工程的基础。

```text
表单基础组成：
1. Input —— 文本输入框
2. Select —— 下拉选择框
3. Checkbox —— 多选框
4. Radio —— 单选框
5. Upload —— 文件上传
6. Date Picker —— 日期选择
7. Rich Text —— 富文本编辑器
8. Validation —— 校验规则
```

```html
<!-- 原生表单基础结构 -->
<form>
  <label>用户名 <input name="username" required /></label>
  <button type="submit">提交</button>
</form>
```

## Input

Input 是最基础的文本输入控件，类型有 text、password、number、email 等。React 中用受控组件（value + onChange）管理输入值。

```jsx
// React 受控 Input
import { useState } from 'react';

function InputDemo() {
  const [value, setValue] = useState('');
  return (
    <input
      type="text"
      value={value}
      onChange={(e) => setValue(e.target.value)}
      placeholder="请输入"
    />
  );
}
```

```html
<!-- Vue 用 v-model 双向绑定 -->
<input v-model="value" type="text" placeholder="请输入" />
```

```text
Input 常见类型：
text / password / number / email / tel / url / search
textarea —— 多行文本
受控组件 —— value + onChange 统一管理（推荐）
```

## Select

Select 是下拉选择框，用于从多个选项中选择一个或多个。

```jsx
function SelectDemo() {
  const [value, setValue] = useState('apple');
  return (
    <select value={value} onChange={(e) => setValue(e.target.value)}>
      <option value="apple">苹果</option>
      <option value="banana">香蕉</option>
      <option value="orange">橙子</option>
    </select>
  );
}
```

```html
<!-- Vue 多选 select -->
<select v-model="selected" multiple>
  <option value="a">A</option>
  <option value="b">B</option>
</select>
```

```text
Select 要点：
1. 单选 value 为字符串，多选为数组
2. 受控时需保证 value 匹配某个 option
3. 大量选项用搜索式下拉（组件库 Select）
```

## Checkbox

Checkbox 是多选框，可选中多个值，常用数组管理选中项。

```jsx
function CheckboxDemo() {
  const [checked, setChecked] = useState([]);
  const options = ['A', 'B', 'C'];

  const toggle = (opt) => {
    setChecked((prev) =>
      prev.includes(opt) ? prev.filter((x) => x !== opt) : [...prev, opt],
    );
  };

  return options.map((opt) => (
    <label key={opt}>
      <input
        type="checkbox"
        checked={checked.includes(opt)}
        onChange={() => toggle(opt)}
      />
      {opt}
    </label>
  ));
}
```

```text
Checkbox 要点：
1. 多选用数组保存选中值
2. 单个开关用布尔值 checked
3. 受控时 checked + onChange 配合
```

## Radio

Radio 是单选框，一组 Radio 中只能选一个，用 name 分组。

```jsx
function RadioDemo() {
  const [gender, setGender] = useState('male');
  return (
    <div>
      <label>
        <input
          type="radio"
          name="gender"
          value="male"
          checked={gender === 'male'}
          onChange={() => setGender('male')}
        />
        男
      </label>
      <label>
        <input
          type="radio"
          name="gender"
          value="female"
          checked={gender === 'female'}
          onChange={() => setGender('female')}
        />
        女
      </label>
    </div>
  );
}
```

```text
Radio 要点：
1. 同组 name 相同，保证互斥
2. value + checked 受控管理
3. 适合二选一或少量固定选项
```

## Upload

Upload 是文件上传控件，通过 input[type=file] 或组件库 Upload 实现，支持单文件、多文件、拖拽上传。

```jsx
function UploadDemo() {
  const [files, setFiles] = useState([]);

  const onChange = (e) => {
    setFiles(Array.from(e.target.files));
  };

  const submit = async () => {
    const formData = new FormData();
    files.forEach((f) => formData.append('files', f));
    await fetch('/api/upload', { method: 'POST', body: formData });
  };

  return (
    <div>
      <input type="file" multiple onChange={onChange} />
      <button onClick={submit}>上传</button>
    </div>
  );
}
```

```text
Upload 要点：
1. 用 FormData 上传文件
2. 限制文件类型、大小、数量
3. 大文件考虑分片上传、断点续传
4. 组件库 Upload 支持拖拽、进度条、预览
```

## Date Picker

Date Picker 是日期选择控件，原生 input[type=date] 功能有限，复杂场景用组件库 DatePicker（支持范围、时间、禁用日期）。

```jsx
// 原生日期选择
function DateDemo() {
  const [date, setDate] = useState('');
  return <input type="date" value={date} onChange={(e) => setDate(e.target.value)} />;
}
```

```jsx
// Ant Design DatePicker（支持范围选择）
import { DatePicker } from 'antd';

const { RangePicker } = DatePicker;
<RangePicker onChange={(dates) => console.log(dates)} />;
```

```text
Date Picker 要点：
1. 原生 date 返回 'YYYY-MM-DD' 字符串
2. 时区处理要小心（Date 对象序列化）
3. 组件库支持范围、时间、禁用、格式化
```

## Rich Text

富文本编辑器用于图文混排内容编辑，如文章、评论。常见方案：Quill、TipTap、wangEditor、Slate。

```jsx
// Quill 集成示例
import { useEffect, useRef } from 'react';
import Quill from 'quill';
import 'quill/dist/quill.snow.css';

function RichTextEditor({ value, onChange }) {
  const ref = useRef(null);
  const editorRef = useRef(null);

  useEffect(() => {
    editorRef.current = new Quill(ref.current, { theme: 'snow' });
    editorRef.current.on('text-change', () => {
      onChange(editorRef.current.root.innerHTML);
    });
    return () => editorRef.current = null;
  }, []);

  return <div ref={ref} />;
}
```

```text
Rich Text 要点：
1. 输出 HTML 字符串，注意 XSS 需过滤
2. 受控/非受控模式切换
3. 图片上传需对接上传接口
4. 关注编辑器性能与内存
```

## Validation

Validation 是表单校验，确保数据合法。分原生校验（required、pattern）和自定义校验（正则、函数），校验时机有提交时、失焦时、实时。

```jsx
// 手动校验
function validate(values) {
  const errors = {};
  if (!values.username) errors.username = '用户名必填';
  if (values.email && !/^\S+@\S+\.\S+$/.test(values.email)) {
    errors.email = '邮箱格式错误';
  }
  return errors;
}

// 原生 HTML 校验
<input required minLength={3} pattern="[A-Za-z]+" />
```

```text
校验方式：
1. HTML 原生 —— required/min/max/pattern
2. 手写函数 —— 灵活但样板多
3. 校验库 —— Zod、Yup 声明式 schema
4. 组件库 Form —— rules 配置
```

## 应用场景实战

### 场景一：注册表单（多种控件 + 校验）

```jsx
function RegisterForm() {
  const [form, setForm] = useState({ username: '', gender: '', hobbies: [] });
  const [errors, setErrors] = useState({});

  const handleChange = (key) => (e) => {
    const value = e.target.type === 'checkbox'
      ? (e.target.checked ? [...form.hobbies, e.target.value] : form.hobbies.filter((x) => x !== e.target.value))
      : e.target.value;
    setForm({ ...form, [key]: value });
  };

  const submit = () => {
    const errs = validate(form);
    setErrors(errs);
    if (Object.keys(errs).length === 0) submitToServer(form);
  };

  return (
    <form onSubmit={(e) => { e.preventDefault(); submit(); }}>
      <input value={form.username} onChange={handleChange('username')} />
      {errors.username && <span>{errors.username}</span>}
      {/* 单选、复选、提交按钮... */}
      <button type="submit">注册</button>
    </form>
  );
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 表单统一用受控组件，状态集中管理
2. 校验用声明式 schema（Zod/Yup），少手写 if
3. 输入框配 label 和 name，提升可访问性
4. 提交按钮处理 loading 与防重复提交
5. 文件上传限制类型与大小，后端再校验

### 踩坑记录

```text
坑 1：受控 input 只传 value 不传 onChange
结论：输入框只读，无法输入（React 警告）。
原因：受控组件必须同时提供 value 和 onChange。
解法：补上 onChange 更新 state，或改用 defaultValue。

坑 2：checkbox 用 value 而非 checked
结论：勾选状态不生效。
原因：checkbox 的受控属性是 checked，不是 value。
解法：用 checked + onChange 管理选中状态。

坑 3：富文本内容直接渲染导致 XSS
结论：恶意脚本注入执行。
原因：富文本输出 HTML 未过滤。
解法：用 sanitize（如 DOMPurify）过滤后再渲染。

坑 4：日期时区错乱
结论：选择的日期保存后相差一天。
原因：Date 对象与字符串序列化时区不一致。
解法：统一用 'YYYY-MM-DD' 字符串，或明确时区。

坑 5：上传文件未校验大小/类型
结论：超大文件上传失败或服务器报错。
原因：前端未限制文件大小和类型。
解法：前端限制 + 后端二次校验。
```
