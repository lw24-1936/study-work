## 概述

高级表单处理复杂场景：动态增删字段（Dynamic Form）、嵌套对象（Nested Form）、字段数组（Array Field）、异步校验（Async Validation）、多步骤表单（Multi-Step Form）、草稿（Draft）与自动保存（Auto Save）。这些能力常见于配置表单、问卷、复杂业务录入。

```text
高级表单核心概念：
1. Dynamic Form —— 根据条件动态增减字段
2. Nested Form —— 嵌套对象结构（a.b.c）
3. Array Field —— 动态数组字段（useFieldArray）
4. Async Validation —— 异步校验（查重、接口校验）
5. Multi-Step Form —— 多步骤表单（分步填写）
6. Draft —— 草稿保存与恢复
7. Auto Save —— 自动保存（防抖/定时）
```

```js
// 高级表单常见形态：字段数组 + 动态增删
const { fields, append, remove } = useFieldArray({ control, name: 'items' });
```

## Dynamic Form

动态表单根据用户输入或条件动态渲染、增删字段。常见于「根据类型显示不同字段」「添加多个联系人」等场景。

```jsx
import { useState } from 'react';

function DynamicForm() {
  const [type, setType] = useState('person');
  const [fields, setFields] = useState([{ id: 1 }]);

  const addField = () => setFields([...fields, { id: Date.now() }]);
  const removeField = (id) => setFields(fields.filter((f) => f.id !== id));

  return (
    <div>
      <select value={type} onChange={(e) => setType(e.target.value)}>
        <option value="person">个人</option>
        <option value="company">公司</option>
      </select>

      {/* 根据类型显示不同字段 */}
      {type === 'person' ? (
        <input placeholder="姓名" />
      ) : (
        <input placeholder="公司名" />
      )}

      {/* 动态增删字段 */}
      {fields.map((f) => (
        <div key={f.id}>
          <input placeholder="联系人" />
          <button type="button" onClick={() => removeField(f.id)}>删除</button>
        </div>
      ))}
      <button type="button" onClick={addField}>添加</button>
    </div>
  );
}
```

```text
动态表单要点：
1. 字段列表存 state，增删改 state
2. 每个动态字段要有唯一 key
3. 删除时同步清理对应数据
```

## Nested Form

嵌套表单处理对象嵌套结构（如 `address.city`），用点号路径绑定字段，提交时还原为嵌套对象。

```jsx
import { useForm } from 'react-hook-form';

function NestedForm() {
  const { register, handleSubmit } = useForm({
    defaultValues: {
      user: { name: '', address: { city: '', street: '' } },
    },
  });

  const onSubmit = (data) => console.log(data.user.address.city);

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {/* 用点号路径绑定嵌套字段 */}
      <input {...register('user.name')} placeholder="姓名" />
      <input {...register('user.address.city')} placeholder="城市" />
      <input {...register('user.address.street')} placeholder="街道" />
      <button type="submit">提交</button>
    </form>
  );
}
```

```text
嵌套表单要点：
1. 用点号路径（a.b.c）注册字段
2. 提交数据自动还原嵌套结构
3. 深层嵌套时注意默认值结构一致
```

## Array Field

字段数组用于「一组同构字段」的动态管理，如订单明细、教育经历、配置列表。React Hook Form 用 useFieldArray。

```jsx
import { useForm, useFieldArray } from 'react-hook-form';

function ArrayFieldForm() {
  const { register, control, handleSubmit } = useForm({
    defaultValues: { items: [{ name: '', qty: 1 }] },
  });
  const { fields, append, remove } = useFieldArray({
    control,
    name: 'items',
  });

  const onSubmit = (data) => console.log(data.items);

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {fields.map((field, index) => (
        <div key={field.id}>
          <input {...register(`items.${index}.name`)} placeholder="名称" />
          <input type="number" {...register(`items.${index}.qty`)} placeholder="数量" />
          <button type="button" onClick={() => remove(index)}>删除</button>
        </div>
      ))}
      <button type="button" onClick={() => append({ name: '', qty: 1 })}>添加一项</button>
      <button type="submit">提交</button>
    </form>
  );
}
```

```text
useFieldArray 要点：
1. fields 数组渲染，key 用 field.id（不是 index）
2. append 添加、remove 删除、insert 插入、move 移动
3. 注册路径用 items.${index}.field 形式
```

## Async Validation

异步校验在字段级联查重、调接口验证等场景使用，返回 Promise，表单库支持 async validate。

```jsx
import { useForm } from 'react-hook-form';

async function checkUsername(username) {
  const res = await fetch(`/api/check-username?name=${username}`);
  const data = await res.json();
  if (data.exists) return '用户名已存在'; // 返回错误信息
  return true; // 校验通过
}

function Form() {
  const { register, handleSubmit, formState: { errors } } = useForm();

  return (
    <form onSubmit={handleSubmit(() => {})}>
      <input
        {...register('username', {
          required: '必填',
          validate: async (value) => await checkUsername(value),
        })}
      />
      {errors.username && <span>{errors.username.message}</span>}
    </form>
  );
}
```

```text
异步校验要点：
1. validate 返回 Promise，返回 true 通过、字符串为错误
2. 需防抖，避免每次键入都请求
3. 处理并发（旧请求结果覆盖新请求）
```

## Multi-Step Form

多步骤表单把长表单拆成多个步骤，分步填写、分步校验，最后统一提交。用步骤状态管理当前步骤。

```jsx
function MultiStepForm() {
  const [step, setStep] = useState(0);
  const [data, setData] = useState({});

  const steps = [
    { title: '基本信息', fields: ['name', 'email'] },
    { title: '详细信息', fields: ['address', 'phone'] },
    { title: '确认', fields: [] },
  ];

  const next = (stepData) => {
    setData({ ...data, ...stepData });
    setStep(step + 1);
  };
  const prev = () => setStep(step - 1);

  const submit = () => {
    api.submit(data); // 最后统一提交
  };

  return (
    <div>
      <h3>{steps[step].title}</h3>
      {/* 渲染当前步骤的字段，每步独立校验 */}
      {step === 0 && <BasicStep onNext={next} initial={data} />}
      {step === 1 && <DetailStep onNext={next} onPrev={prev} initial={data} />}
      {step === 2 && <ConfirmStep data={data} onPrev={prev} onSubmit={submit} />}
    </div>
  );
}
```

```text
多步骤表单要点：
1. 每步独立校验，通过才能进入下一步
2. 步骤间共享数据（提升到父级 state）
3. 支持返回修改（保留已填数据）
4. 最后一步统一提交
```

## Draft

草稿功能保存用户未完成的内容，便于意外关闭后恢复。草稿可存 localStorage 或服务端，定时或手动保存。

```jsx
import { useEffect, useState } from 'react';

const DRAFT_KEY = 'form-draft';

function DraftForm() {
  const [values, setValues] = useState(() => {
    // 初始化时恢复草稿
    const saved = localStorage.getItem(DRAFT_KEY);
    return saved ? JSON.parse(saved) : { title: '', content: '' };
  });

  // 定时保存草稿
  useEffect(() => {
    const timer = setInterval(() => {
      localStorage.setItem(DRAFT_KEY, JSON.stringify(values));
    }, 30_000);
    return () => clearInterval(timer);
  }, [values]);

  const clearDraft = () => localStorage.removeItem(DRAFT_KEY);

  return (
    <div>
      <input value={values.title} onChange={(e) => setValues({ ...values, title: e.target.value })} />
      <button onClick={clearDraft}>清除草稿</button>
    </div>
  );
}
```

```text
草稿要点：
1. 初始化时恢复草稿
2. 定时/失焦/手动保存
3. 提交成功后清除草稿
4. 注意草稿数据版本与序列化
```

## Auto Save

自动保存无需用户手动点保存，内容变化后自动持久化。核心是「防抖」：停止输入一段时间后再保存，避免频繁请求。

```jsx
import { useEffect, useRef, useState } from 'react';

function AutoSaveEditor() {
  const [content, setContent] = useState('');
  const timerRef = useRef(null);

  useEffect(() => {
    // 防抖：停止输入 1 秒后保存
    clearTimeout(timerRef.current);
    timerRef.current = setTimeout(async () => {
      await api.save(content);
      setSaved(true);
    }, 1000);

    return () => clearTimeout(timerRef.current);
  }, [content]);

  return <textarea value={content} onChange={(e) => setContent(e.target.value)} />;
}
```

```text
自动保存要点：
1. 防抖 —— 停止输入后再保存
2. 显示保存状态（保存中/已保存）
3. 失败重试与提示
4. 离开页面前确保已保存（配合 beforeunload）
```

## 最佳实践与踩坑记录

### 最佳实践

1. 字段数组用 useFieldArray，key 用 field.id 而非 index
2. 异步校验加防抖，并处理并发覆盖
3. 多步骤表单每步独立校验，数据提升到父级
4. 草稿与自动保存用防抖 + 定时，提交后清理
5. 动态删除字段时同步清理数据，避免脏数据

### 踩坑记录

```text
坑 1：字段数组用 index 当 key
结论：删除中间项时输入内容错乱。
原因：index 不稳定，React 复用错误节点。
解法：用 useFieldArray 的 field.id 作为 key。

坑 2：异步校验未防抖
结论：每次键入都发请求，接口被打爆。
原因：validate 直接发请求无防抖。
解法：防抖后再请求，或用 onChange 手动触发。

坑 3：多步骤表单数据丢失
结论：返回上一步时已填内容清空。
原因：步骤组件局部 state 卸载后丢失。
解法：数据提升到父级，步骤间共享。

坑 4：自动保存未做离开保护
结论：离开页面时最新内容未保存。
原因：只依赖防抖定时，未处理突然离开。
解法：beforeunload 或路由守卫兜底保存。

坑 5：草稿数据版本不兼容
结论：恢复草稿报错或字段错乱。
原因：数据结构变更，旧草稿未迁移。
解法：草稿加版本号，恢复时做迁移。
```
