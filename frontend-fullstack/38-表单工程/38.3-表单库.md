## 概述

表单库把「值管理、校验、错误提示、提交状态」等样板逻辑封装起来，让开发者专注业务。React 生态有 React Hook Form（非受控、高性能）和 Formik（受控、直观）；Vue 有 VeeValidate 等；Zod 提供声明式 schema 校验，可与各表单库集成。

```text
主流表单库：
1. React Hook Form —— 非受控、高性能、hooks 风格
2. Formik —— 受控、直观、成熟稳定
3. Ant Design Form —— 组件库内置，rules 配置
4. Vue Form —— Vue 生态（VeeValidate 等）
5. Zod Validation —— 声明式 schema 校验库
```

```js
// 三者共同目标：少写样板，统一管理表单状态与校验
const { register, handleSubmit, formState } = useForm();
```

## React Hook Form

React Hook Form（RHF）基于非受控组件 + ref 实现，性能好（减少重渲染），API 简洁，通过 register 注册字段、handleSubmit 处理提交。

```jsx
import { useForm } from 'react-hook-form';

function LoginForm() {
  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm();

  const onSubmit = (data) => {
    console.log(data); // 校验通过后的数据
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input
        {...register('email', {
          required: '邮箱必填',
          pattern: { value: /^\S+@\S+$/, message: '格式错误' },
        })}
      />
      {errors.email && <span>{errors.email.message}</span>}

      <input {...register('password', { required: '密码必填', minLength: { value: 6, message: '至少6位' } })} />
      {errors.password && <span>{errors.password.message}</span>}

      <button disabled={isSubmitting}>登录</button>
    </form>
  );
}
```

```text
RHF 特点：
1. 非受控，减少重渲染，性能好
2. register 注册字段，返回 ref/onChange/onBlur
3. 内置 rules 校验，支持 watch、reset、setValue
4. 与 Zod/Yup 集成：resolver
```

## Formik

Formik 基于受控组件，用 Formik 组件或 useFormik hook 管理状态，提供 values、errors、touched、handleChange 等。

```jsx
import { useFormik } from 'formik';

function LoginForm() {
  const formik = useFormik({
    initialValues: { email: '', password: '' },
    validate: (values) => {
      const errors = {};
      if (!values.email) errors.email = '邮箱必填';
      return errors;
    },
    onSubmit: (values) => {
      console.log(values);
    },
  });

  return (
    <form onSubmit={formik.handleSubmit}>
      <input
        name="email"
        value={formik.values.email}
        onChange={formik.handleChange}
        onBlur={formik.handleBlur}
      />
      {formik.touched.email && formik.errors.email && <span>{formik.errors.email}</span>}
      <button type="submit">登录</button>
    </form>
  );
}
```

```text
Formik 特点：
1. 受控组件，状态集中管理
2. 提供 values/errors/touched/handleChange 等
3. 支持 validationSchema（Yup/Zod）
4. 集成度高，但重渲染较多
```

```text
RHF vs Formik：
RHF —— 非受控、性能更好、代码更少
Formik —— 受控、直观、状态可预测
性能敏感选 RHF，简单直观选 Formik。
```

## Ant Design Form

Ant Design 的 Form 组件内置表单管理，通过 rules 声明校验规则，Form.Item 包裹字段，支持布局、校验、联动。

```jsx
import { Form, Input, Button } from 'antd';

function LoginForm() {
  const [form] = Form.useForm();

  const onFinish = (values) => {
    console.log(values);
  };

  return (
    <Form form={form} onFinish={onFinish} layout="vertical">
      <Form.Item
        name="email"
        label="邮箱"
        rules={[
          { required: true, message: '邮箱必填' },
          { type: 'email', message: '格式错误' },
        ]}
      >
        <Input />
      </Form.Item>
      <Form.Item name="password" label="密码" rules={[{ required: true, message: '密码必填' }]}>
        <Input.Password />
      </Form.Item>
      <Form.Item>
        <Button type="primary" htmlType="submit">登录</Button>
      </Form.Item>
    </Form>
  );
}
```

```text
Ant Design Form 特点：
1. rules 声明式校验（required/type/validator）
2. Form.Item name 绑定字段
3. 支持联动（shouldUpdate、dependencies）
4. 与组件库深度集成
```

## Vue Form

Vue 表单常用 VeeValidate（配合 Zod/Yup）或组件库自带 Form（Element Plus、Naive UI 的 Form）。

```vue
<!-- VeeValidate + Zod -->
<script setup>
import { useForm } from 'vee-validate';
import { toTypedSchema } from '@vee-validate/zod';
import { z } from 'zod';

const schema = toTypedSchema(
  z.object({
    email: z.string().email('格式错误'),
    password: z.string().min(6, '至少6位'),
  }),
);

const { defineField, errors, handleSubmit } = useForm({ validationSchema: schema });
const [email, emailAttrs] = defineField('email');
const [password, passwordAttrs] = defineField('password');

const onSubmit = handleSubmit((values) => console.log(values));
</script>

<template>
  <form @submit="onSubmit">
    <input v-model="email" v-bind="emailAttrs" />
    <span>{{ errors.email }}</span>
    <input v-model="password" v-bind="passwordAttrs" type="password" />
    <span>{{ errors.password }}</span>
    <button type="submit">登录</button>
  </form>
</template>
```

```vue
<!-- Element Plus Form -->
<template>
  <el-form :model="form" :rules="rules" ref="formRef">
    <el-form-item label="邮箱" prop="email">
      <el-input v-model="form.email" />
    </el-form-item>
    <el-button type="primary" @click="submit">登录</el-button>
  </el-form>
</template>
```

```text
Vue 表单方案：
1. VeeValidate —— 独立校验库，配合 Zod/Yup
2. Element Plus / Naive UI Form —— 组件库内置 rules
3. v-model 天然双向绑定，表单管理更直接
```

## Zod Validation

Zod 是 TypeScript 优先的 schema 校验库，用声明式方式定义数据结构和校验规则，可与 RHF、Formik、VeeValidate 集成。

```js
import { z } from 'zod';

// 定义 schema
const userSchema = z.object({
  username: z.string().min(3, '至少3个字符'),
  email: z.string().email('邮箱格式错误'),
  age: z.number().int().min(0).max(150),
  role: z.enum(['admin', 'user']),
});

// 校验
const result = userSchema.safeParse({
  username: 'alice',
  email: 'a@b.com',
  age: 20,
  role: 'admin',
});

if (result.success) {
  console.log(result.data); // 校验通过，类型安全
} else {
  console.log(result.error.issues); // 错误详情
}
```

```js
// 与 React Hook Form 集成
import { zodResolver } from '@hookform/resolvers/zod';
import { useForm } from 'react-hook-form';

const schema = z.object({
  email: z.string().email('格式错误'),
  password: z.string().min(6, '至少6位'),
});

function Form() {
  const { register, handleSubmit, formState: { errors } } = useForm({
    resolver: zodResolver(schema),
  });
  // register + handleSubmit 同前
}
```

```text
Zod 特点：
1. 声明式 schema，可读性强
2. TypeScript 类型自动推导（z.infer）
3. safeParse 返回结果对象，不抛异常
4. 支持组合、可选、默认值、自定义 refine
```

## 最佳实践与踩坑记录

### 最佳实践

1. 校验规则用 Zod/Yup 声明式定义，少手写 if
2. 性能敏感选 React Hook Form，简单直观选 Formik
3. 组件库项目直接用其内置 Form（AntD/Element Plus）
4. 统一校验错误信息文案，提升用户体验
5. 复杂校验（跨字段）用 refine 或自定义 validator

### 踩坑记录

```text
坑 1：RHF register 后手动加 value 导致冲突
结论：输入框行为异常。
原因：register 返回受控属性与手动 value 冲突。
解法：只用 register 展开的属性，不重复设置 value/onChange。

坑 2：Formik 忘记 onBlur 导致 touched 不更新
结论：错误提示不出现。
原因：touched 靠 handleBlur 更新，未绑定 onBlur。
解法：input 上绑 formik.handleBlur。

坑 3：Zod 校验类型与表单值类型不符
结论：数字字段校验失败或类型报错。
原因：表单值默认是字符串，schema 声明 number。
解法：用 z.coerce.number() 转换，或 input type=number。

坑 4：AntD Form 未设 name 拿不到值
结论：onFinish 里该字段为 undefined。
原因：Form.Item 没写 name 属性。
解法：每个 Form.Item 配 name 绑定字段。

坑 5：跨字段校验写在单字段 rules 里
结论：两次密码不一致无法校验。
原因：单字段 rules 拿不到其它字段值。
解法：用 schema.refine 或 Form validator 访问整表单。
```
