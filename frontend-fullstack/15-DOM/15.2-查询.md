## 概述

DOM 查询是获取页面元素的入口。现代开发主要用 querySelector 系列（CSS 选择器），老式 getElementById 等仍有特定用途。

```text
查询方法分类：
getElementById —— 按 id（返回单个，最快）
querySelector —— CSS 选择器（返回第一个匹配）
querySelectorAll —— CSS 选择器（返回所有，静态 NodeList）
getElementsByXxx —— 按类名/标签（返回动态 HTMLCollection）

现代推荐：querySelector / querySelectorAll（统一 CSS 选择器语法）。
```

## getElementById

getElementById 按 id 查找元素，返回单个元素（或 null），性能最好。

```js
const el = document.getElementById('app');
el;               // <div id="app">... 或 null
```

```js
// 未找到返回 null
const missing = document.getElementById('not-exist');
missing;          // null
```

```text
getElementById 特点：
1. 按 id 精确查找（id 应唯一）
2. 返回单个元素或 null
3. 性能最好（浏览器内部索引）
4. 只能用 id，不能用其他选择器
```

## querySelector

querySelector 用 CSS 选择器查找，返回**第一个**匹配的元素。

```js
// 各种 CSS 选择器
document.querySelector('.class');        // 类
document.querySelector('#id');           // id
document.querySelector('div');           // 标签
document.querySelector('div > p');       // 子代
document.querySelector('.a.b');          // 多类
document.querySelector('[data-id="1"]'); // 属性
```

```js
// 在指定元素内查询（限定范围）
const container = document.querySelector('.container');
const btn = container.querySelector('.btn');
```

```js
// 未找到返回 null
document.querySelector('.not-exist');    // null
```

```text
querySelector 特点：
1. 完整 CSS 选择器语法
2. 返回第一个匹配或 null
3. 可在任意元素上调用（限定范围）
4. 选择器非法会抛 SyntaxError
```

## querySelectorAll

querySelectorAll 返回**所有**匹配的元素，结果是**静态** NodeList（不受后续 DOM 变化影响）。

```js
const items = document.querySelectorAll('.item');
items;                     // NodeList（类数组）
items.length;              // 数量
items[0];                  // 第一个
```

```js
// NodeList 可遍历（forEach、for...of）
items.forEach(item => console.log(item));
for (const item of items) console.log(item);

// 转数组
const arr = [...items];
const arr2 = Array.from(items);
```

```js
// 静态性：快照，不受后续 DOM 修改影响
const list = document.querySelectorAll('.item');   // 3 个
document.body.append(document.createElement('div')); // 加新元素（非 .item）
list.length;                                        // 仍是 3
```

```text
querySelectorAll 的静态性 vs getElementsByClassName 的动态性：
querySelectorAll —— 静态 NodeList（快照）
getElementsByClassName —— 动态 HTMLCollection（实时反映变化）
```

```js
// 对比：动态集合实时更新
const live = document.getElementsByClassName('item');
const div = document.createElement('div');
div.className = 'item';
document.body.append(div);
live.length;              // 自动 +1（动态）
```

## closest 向上查找

closest 从当前元素**向上**（含自身）查找最近的匹配祖先。

```js
// HTML：<div class="card"><button class="btn">点击</button></div>
const btn = document.querySelector('.btn');

btn.closest('.card');     // 找到最近的 .card 祖先
btn.closest('div');       // 最近的 div（含自身向上）
btn.closest('body');      // body
btn.closest('.not-exist'); // null（无匹配）
```

```js
// 典型：事件委托中找目标所属的容器
document.addEventListener('click', e => {
  const card = e.target.closest('.card');
  if (card) {
    // 点击在 card 内部
  }
});
```

```text
closest 的特点：
1. 从自身开始向上查找（含自身）
2. 返回最近的匹配祖先或 null
3. 事件委托的黄金搭档
```

## matches 匹配判断

matches 判断元素是否匹配某个 CSS 选择器，返回布尔。

```js
const el = document.querySelector('.btn');

el.matches('.btn');        // true
el.matches('.card');       // false
el.matches('button');      // true
```

```js
// 典型：事件委托中判断目标类型
document.addEventListener('click', e => {
  if (e.target.matches('button.primary')) {
    // 点击了 primary 按钮
  }
});
```

```text
matches 的用途：
1. 判断元素是否符合选择器
2. 事件委托中过滤目标
3. 条件样式/逻辑判断
```

## 应用场景实战

### 场景一：事件委托（closest + matches 配合）

```js
document.querySelector('.list').addEventListener('click', e => {
  const item = e.target.closest('.list-item');   // 找到列表项
  if (!item) return;                              // 不在列表项内

  if (e.target.matches('.delete-btn')) {
    item.remove();                                // 点删除按钮
  }
});
```

### 场景二：批量操作选中元素

```js
document.querySelectorAll('.todo:not(.done)').forEach(todo => {
  todo.classList.add('pending');
});
```

## 最佳实践与踩坑记录

### 最佳实践

1. 现代查询统一用 querySelector / querySelectorAll
2. 唯一元素用 querySelector，多个用 querySelectorAll
3. 事件委托用 closest 找容器，matches 判断目标
4. 限定范围：在容器元素上查询，避免全局扫描
5. 缓存查询结果，避免重复查询

### 踩坑记录

```text
坑 1：querySelectorAll 是静态的
结论：拿到的 NodeList 不会自动更新。
原因：返回快照，后续 DOM 变化不反映。
解法：需要动态用 getElementsByXxx，或重新查询。

坑 2：选择器非法抛异常
结论：querySelector(':bad') 抛 SyntaxError。
原因：非法 CSS 选择器。
解法：确保选择器合法，或 try/catch 包裹动态选择器。

坑 3：id 以数字开头时 getElementById 正常但选择器需转义
结论：querySelector('#123') 报错（CSS 标识符不能数字开头）。
原因：CSS 选择器语法限制。
解法：用 getElementById，或用属性选择器 [id="123"]。

坑 4：closest 包含自身
结论：closest 从自身开始，可能返回自己。
原因：closest 语义是「含自身向上」。
解法：需要排除自身时，从 parentElement 开始 closest。

坑 5：NodeList 不是真数组
结论：NodeList 没有 map/filter 等方法。
原因：NodeList 是类数组，非 Array。
解法：用 [...list] 或 Array.from 转数组。
```
