## 概述

DOM 修改是动态更新页面内容的核心能力：创建、插入、删除、替换、克隆节点，或直接操作 HTML/文本内容。

```text
修改方式分类：
节点操作 —— createElement、append、remove、replaceWith、cloneNode
内容操作 —— innerHTML、textContent、insertAdjacentHTML

节点操作更安全可控，innerHTML 更简洁但有 XSS 风险。
```

## createElement 创建节点

createElement 创建元素节点，createTextNode 创建文本节点。

```js
const div = document.createElement('div');
div.textContent = '新元素';
div.className = 'box';

const text = document.createTextNode('纯文本');
```

```js
// 创建后需插入 DOM 才可见
document.body.appendChild(div);
```

```text
创建节点的常用方式：
document.createElement(tagName) —— 元素
document.createTextNode(text) —— 文本
document.createDocumentFragment() —— 片段
```

## append / prepend / before / after

现代方法在指定位置插入节点，支持多个参数、字符串（自动转文本）。

```js
const parent = document.querySelector('.list');

// append：末尾插入
parent.append(el);                       // 追加元素
parent.append('文本', el2, el3);          // 多参数
parent.append('<b>会被当文本</b>');        // 字符串按纯文本插入

// prepend：开头插入
parent.prepend(el);

// before / after：元素前后插入（兄弟位置）
el.before(newEl);     // el 前面
el.after(newEl);      // el 后面
```

```js
// 对比：appendChild 只能插元素，不能插字符串
parent.appendChild(el);   // 老式，单参数
```

```text
现代方法 vs 老式方法：
append/prepend —— 支持多参数、字符串，功能更强（现代）
appendChild/insertBefore —— 单参数，仅节点（老式）

before/after —— 插入到元素的前后兄弟位置
```

## remove / replaceWith

remove 删除元素自身，replaceWith 用新内容替换自身。

```js
// remove：移除元素
const el = document.querySelector('.old');
el.remove();               // 从 DOM 中移除

// 老式：removeChild（需通过父节点）
el.parentNode.removeChild(el);
```

```js
// replaceWith：替换
const old = document.querySelector('.old');
old.replaceWith(newElement);            // 替换为元素
old.replaceWith('新文本');               // 替换为文本
old.replaceWith(el1, el2);              // 替换为多个
```

## cloneNode 克隆

cloneNode 克隆节点，参数 true 表示深克隆（含子节点）。

```js
const source = document.querySelector('.template');

// 浅克隆：只克隆自身，不含子节点
const shallow = source.cloneNode(false);

// 深克隆：克隆自身及所有子节点
const deep = source.cloneNode(true);
```

```js
// 典型：克隆模板
const template = document.querySelector('#item-template');
const clone = template.content.cloneNode(true);   // 克隆模板内容
document.querySelector('.list').append(clone);
```

```text
cloneNode 的注意：
1. false 浅克隆（只自身），true 深克隆（含子节点）
2. 克隆不复制事件监听器（需重新绑定）
3. 克隆会复制属性、内联样式等
```

## innerHTML / textContent

innerHTML 读写 HTML 字符串（解析标签），textContent 读写纯文本（转义）。

```js
const el = document.querySelector('.box');

// innerHTML：解析 HTML
el.innerHTML = '<b>加粗</b>';      // 渲染为粗体
el.innerHTML;                       // '<b>加粗</b>'

// textContent：纯文本
el.textContent = '<b>加粗</b>';     // 显示字面量 '<b>加粗</b>'
el.textContent;                     // '<b>加粗</b>'
```

```text
innerHTML vs textContent：
innerHTML —— 解析 HTML 标签，有 XSS 风险，性能较重（重解析）
textContent —— 纯文本，安全，性能好

用户输入一律用 textContent，避免 XSS。
```

## insertAdjacentHTML

insertAdjacentHTML 在指定位置插入 HTML 字符串，比 innerHTML 更精细（不覆盖现有内容）。

```js
const el = document.querySelector('.box');

// 四个位置
el.insertAdjacentHTML('beforebegin', '<p>前</p>');  // 元素之前
el.insertAdjacentHTML('afterbegin', '<p>内首</p>'); // 内部开头
el.insertAdjacentHTML('beforeend', '<p>内尾</p>');  // 内部末尾
el.insertAdjacentHTML('afterend', '<p>后</p>');     // 元素之后
```

```text
四个位置：
beforebegin —— 元素前（兄弟）
afterbegin —— 内部第一个子节点前
beforeend —— 内部最后一个子节点后
afterend —— 元素后（兄弟）

优势：局部插入，不覆盖已有内容（innerHTML 会覆盖全部）。
```

## 应用场景实战

### 场景一：动态渲染列表

```js
function renderList(items) {
  const ul = document.querySelector('ul');
  ul.textContent = '';          // 清空
  const fragment = document.createDocumentFragment();
  items.forEach(item => {
    const li = document.createElement('li');
    li.textContent = item;      // 用户数据用 textContent（防 XSS）
    fragment.append(li);
  });
  ul.append(fragment);
}
```

### 场景二：克隆模板行

```js
const template = document.querySelector('#row-template');
function addRow(data) {
  const row = template.content.cloneNode(true);
  row.querySelector('.name').textContent = data.name;
  document.querySelector('tbody').append(row);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用户输入用 textContent，别用 innerHTML（防 XSS）
2. 批量插入用 DocumentFragment
3. 局部插入用 insertAdjacentHTML，替代整体 innerHTML 覆盖
4. 克隆模板注意重新绑定事件
5. 优先用现代方法（append/remove），老式方法仅兼容

### 踩坑记录

```text
坑 1：innerHTML 覆盖已有内容
结论：el.innerHTML += '...' 会清空重建，丢失事件、输入状态。
原因：+= 会重新解析整个 innerHTML。
解法：用 insertAdjacentHTML 局部插入，或节点操作。

坑 2：append 字符串按文本处理
结论：append('<b>x</b>') 显示字面量标签。
原因：append 的字符串参数是纯文本。
解法：要解析 HTML 用 insertAdjacentHTML 或 innerHTML。

坑 3：cloneNode 不复制事件
结论：克隆的元素没有原事件监听器。
原因：事件监听器不在节点属性中，clone 不复制。
解法：克隆后重新绑定事件，或用事件委托。

坑 4：textContent 与 innerHTML 安全混淆
结论：用 innerHTML 插用户输入导致 XSS。
原因：innerHTML 解析脚本/事件属性。
解法：用户数据用 textContent，白名单场景才用 innerHTML。

坑 5：remove 后元素仍被引用
结论：移除后内存未释放。
原因：移除只脱离 DOM，若 JS 还持有引用则不 GC。
解法：移除后置空引用。
```
