## 概述

DOM 属性分为「HTML 属性」（attribute，写在标签里）和「DOM 属性」（property，对象上的属性）。两者大多数同步，但部分属性（如 value、checked）存在差异。

```text
attribute vs property：
attribute —— HTML 标签上的属性（getAttribute/setAttribute 操作）
property —— DOM 对象上的属性（el.xxx 直接访问）

大多数情况同步（el.id、el.className），但：
value/checked 等表单属性不同步（property 是当前状态，attribute 是初始值）。
```

## getAttribute / setAttribute / removeAttribute

attribute 系列方法读写 HTML 标签上的属性。

```js
const el = document.querySelector('a');

// 读取
el.getAttribute('href');          // 'https://example.com'

// 设置
el.setAttribute('href', '/new-url');
el.setAttribute('data-id', '123');

// 删除
el.removeAttribute('data-id');

// 判断
el.hasAttribute('href');          // true
```

```js
// 自定义属性（data-* 或任意属性）
el.setAttribute('data-role', 'button');
el.setAttribute('aria-label', '关闭');
```

```text
attribute 方法的特点：
1. 操作「字符串」值（HTML 标签上的原始值）
2. 属性名不区分大小写（HTML）
3. 适合读写任意属性（含自定义）
```

## dataset 数据属性

dataset 是 data-* 属性的便捷访问方式，自动转换命名。

```html
<div id="user" data-id="123" data-user-name="Alice" data-active="true"></div>
```

```js
const el = document.querySelector('#user');

el.dataset.id;            // '123'
el.dataset.userName;      // 'Alice'（data-user-name → userName）
el.dataset.active;        // 'true'（字符串，不是布尔）

// 设置
el.dataset.id = '456';
el.dataset.userAge = '30';   // 自动生成 data-user-age
```

```text
dataset 的命名转换：
data-user-name → dataset.userName（连字符转驼峰）
dataset.userAge → data-user-age（驼峰转连字符）

注意：dataset 值都是字符串，需要数字/布尔要手动转换。
```

## classList 类名操作

classList 是类名操作的标准 API，支持增删改查、切换。

```js
const el = document.querySelector('div');

// 添加
el.classList.add('active', 'visible');   // 多类

// 删除
el.classList.remove('active');

// 切换（有则删，无则加）
el.classList.toggle('dark');              // 加
el.classList.toggle('dark', isDark);      // 第二个参数控制

// 判断
el.classList.contains('active');          // true/false

// 替换
el.classList.replace('old', 'new');
```

```js
// 对比 className（整体覆盖）
el.className = 'box active';     // 覆盖全部类名
el.className;                    // 'box active'
```

```text
classList vs className：
classList —— 精细操作（增删切换），推荐
className —— 整体读写字符串，易覆盖
```

## style 内联样式

style 读写元素的内联样式，属性名转驼峰，值需带单位。

```js
const el = document.querySelector('div');

// 设置（驼峰命名）
el.style.color = 'red';
el.style.backgroundColor = '#0066cc';
el.style.fontSize = '16px';        // 数值+单位
el.style.width = '100px';

// 读取（只读内联样式）
el.style.color;                     // 'red'
```

```js
// 批量设置（cssText 或 Object.assign）
el.style.cssText = 'color: red; font-size: 16px;';
Object.assign(el.style, { color: 'red', fontSize: '16px' });
```

```js
// 读取计算后的样式（含 CSS 样式表）
getComputedStyle(el).color;          // 最终生效的颜色
getComputedStyle(el).fontSize;       // '16px'
```

```js
// CSS 自定义属性
el.style.setProperty('--theme', 'dark');
el.style.getPropertyValue('--theme');   // 'dark'
```

```text
style 的注意：
1. style 只读写「内联样式」，不含 CSS 样式表
2. 读取计算后样式用 getComputedStyle
3. 属性名转驼峰（background-color → backgroundColor）
4. 数值通常要加单位（除 zIndex、opacity 等）
```

## 应用场景实战

### 场景一：表单状态管理

```js
const input = document.querySelector('input');
const btn = document.querySelector('button');

// 判断输入是否有内容，切换按钮状态
input.addEventListener('input', e => {
  btn.disabled = !e.target.value;   // property 反映当前状态
});
```

### 场景二：主题切换

```js
function toggleTheme() {
  const root = document.documentElement;
  const isDark = root.dataset.theme === 'dark';
  root.dataset.theme = isDark ? 'light' : 'dark';
  root.classList.toggle('dark', !isDark);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 类名操作用 classList，别用 className 拼接
2. data-* 用 dataset 访问，值注意类型转换
3. 表单状态（value/checked/disabled）用 property
4. 计算后样式用 getComputedStyle
5. 读 HTML 原始属性用 getAttribute

### 踩坑记录

```text
坑 1：attribute 与 property 不同步
结论：input.value 变了，getAttribute('value') 还是初始值。
原因：value 等表单属性，property 是当前状态，attribute 是初始值。
解法：读当前值用 property，读初始值用 attribute。

坑 2：dataset 值都是字符串
结论：data-active="false" 是字符串 'false'，判断时出错。
原因：dataset 不自动转类型。
解法：手动 Number()/Boolean 判断，或用 === 'true'。

坑 3：style 读不到 CSS 样式表的值
结论：el.style.color 为空，但页面有颜色。
原因：style 只读内联样式。
解法：用 getComputedStyle(el).color。

坑 4：className 覆盖其他类
结论：el.className = 'x' 丢掉了原有类。
原因：className 是整体字符串赋值。
解法：用 classList.add/remove 精细操作。

坑 5：样式属性名用连字符
结论：el.style.background-color 报错。
原因：JS 里连字符被当作减号。
解法：转驼峰 backgroundColor。
```
