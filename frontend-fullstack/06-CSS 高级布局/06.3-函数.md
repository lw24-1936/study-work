## 概述

CSS 函数让属性值能「动态计算」，是 CSS 从「静态值」走向「响应式」的关键能力。calc 算尺寸、clamp 做流式范围、var 引用变量、env 适配安全区域——这些函数让样式更灵活、更少硬编码。

```text
CSS 函数的分类：
1. 数学 —— calc、min、max、clamp（计算尺寸）
2. 变量 —— var（引用自定义属性）
3. 环境 —— env（读取环境值，如安全区域）
4. 颜色 —— color-mix（颜色混合）
5. 属性 —— attr（读取元素属性）
```

## calc 计算

calc 在 CSS 里做数学计算，可混合不同单位：

```css
.box {
  width: calc(100% - 80px);    /* 宽度 = 100% 减去 80px */
  height: calc(100vh - 60px);  /* 高度 = 视口高减去固定头部 */
}
```

```text
calc 的语法要点：
1. 运算符两侧必须有空格：calc(100% - 80px)
   错：calc(100%-80px)（减号没空格，被当成负号）
2. 支持 + - * / 运算
3. 可以混合单位（% + px 是 calc 的独特能力）
```

```text
calc 的典型用途：
1. 减去固定尺寸（如 calc(100% - 侧边栏宽)）
2. 居中偏移（calc(50% - 自身一半)）
3. 动态间距
```

## min、max、clamp 数学函数

这三个函数做「数值比较」，是响应式设计的利器。

### min 取小

```css
.box {
  width: min(100%, 600px);  /* 取较小值：不超过 600px */
}
```

### max 取大

```css
.box {
  width: max(50%, 200px);  /* 取较大值：至少 200px */
}
```

### clamp 夹取

clamp(min, 理想值, max) 把值限制在 min 和 max 之间：

```css
h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
  /* 最小 1.5rem，随视口 4vw，最大 3rem */
}
```

```text
clamp 的机制：
clamp(最小值, 理想值, 最大值)
结果 = max(最小值, min(理想值, 最大值))

即：理想值被「夹」在最小和最大之间。
```

```text
三个函数的应用：
min() —— 限制上限（宽度不超过 X）
max() —— 限制下限（宽度至少 X）
clamp() —— 同时限制上下限（流式尺寸）

clamp 是响应式字号的标配。
```

```text
min/max/clamp 的对比：
min(100%, 600px)    —— 取小（等效 max-width）
max(50%, 200px)     —— 取大（等效 min-width）
clamp(200px, 50%, 600px) —— 夹取（等效 min-width + max-width）
```

## var 引用变量

var() 引用 CSS 自定义属性（变量）：

```css
:root {
  --primary: #0066cc;
  --spacing: 16px;
}
.button {
  background: var(--primary);
  padding: var(--spacing);
}
```

```text
var() 的语法：
var(--变量名, 默认值)

第二个参数是「兜底值」，变量未定义时使用：
color: var(--primary, blue);
```

```text
var 的完整内容见 06.4-CSS 变量。
```

## env 安全区域

env() 读取环境变量，最常用的是「安全区域」（刘海屏、底部 Home 条）：

```css
.header {
  /* 适配刘海屏，避开顶部安全区域 */
  padding-top: env(safe-area-inset-top);
}

.footer {
  /* 适配底部 Home 条 */
  padding-bottom: env(safe-area-inset-bottom);
}
```

```text
env 的常见值：
safe-area-inset-top —— 顶部安全区域
safe-area-inset-bottom —— 底部安全区域
safe-area-inset-left / right —— 左右安全区域

使用时需配合 viewport-fit=cover：
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```

```text
env 的用途：
移动端全屏应用（尤其 iOS 刘海屏）适配，避免内容被刘海/Home 条遮挡。
```

## color-mix 颜色混合

color-mix 混合两种颜色，是现代 CSS 的颜色能力：

```css
.box {
  /* 混合 50% 的红色和蓝色 */
  background: color-mix(in srgb, red 50%, blue);
}
```

```text
color-mix 的语法：
color-mix(in 色彩空间, 颜色1 比例, 颜色2 比例)

用途：
1. 动态生成颜色（如 hover 态加深、透明度变体）
2. 基于主色派生辅助色（主题系统）
```

```css
:root {
  --primary: #0066cc;
}
.button:hover {
  /* hover 时颜色加深（混合黑色） */
  background: color-mix(in srgb, var(--primary), black 20%);
}
```

## attr 读取属性

attr 读取元素的 HTML 属性作为 CSS 值：

```css
/* 读取 data-label 属性的值作为内容 */
.tooltip::after {
  content: attr(data-tooltip);
}
```

```html
<span data-tooltip="这是提示文字">悬停看提示</span>
```

```text
attr 的用途：
1. content: attr(data-xxx) —— 把属性值显示成内容（提示文字）
2. 读取属性作为样式值

限制：早期 attr 只能用于 content，现代 CSS 已扩展到其他属性（兼容性渐进）。
```

## 应用场景实战

### 场景一：流式字号 + 响应式容器

```css
:root {
  --max-width: 1200px;
}

.container {
  width: min(100% - 32px, var(--max-width));
  margin-inline: auto;
}

h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}
```

### 场景二：刘海屏适配

```css
/* 全屏顶部栏，避开刘海 */
.top-bar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  padding-top: env(safe-area-inset-top);
}
```

### 场景三：主题色派生

```css
:root {
  --primary: #0066cc;
}
.button {
  background: var(--primary);
}
.button:hover {
  background: color-mix(in srgb, var(--primary), white 15%);
}
.button:active {
  background: color-mix(in srgb, var(--primary), black 15%);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 流式尺寸用 clamp，限制范围用 min/max
2. calc 运算符两侧加空格（否则解析成负号）
3. 安全区域适配用 env()，配 viewport-fit=cover
4. 颜色变体用 color-mix，避免硬编码多个颜色值
5. 变量用 var(--name, 兜底值)，防止未定义时报错

### 踩坑记录

```text
坑 1：calc 运算符没空格
结论：calc(100%-80px) 不生效，值被忽略。
原因：- 两侧没空格，被解析成「负号」而非「减号」。
解法：calc(100% - 80px)，+ 和 - 两侧必须有空格。

坑 2：clamp 最小值大于最大值
结论：clamp 结果始终是错误的值。
原因：clamp(min, val, max) 要求 min <= max。
解法：检查 min 和 max 的大小关系。

坑 3：env 没配 viewport-fit=cover 不生效
结论：safe-area-inset 值为 0，刘海屏没适配。
原因：没设 viewport-fit=cover，浏览器不启用安全区域。
解法：viewport meta 加 viewport-fit=cover。

坑 4：var 变量未定义导致属性失效
结论：用了未定义的变量，整条声明失效。
原因：var() 引用不存在的变量，属性值无效。
解法：用 var(--name, 默认值) 提供兜底，或确保变量已定义。

坑 5：attr 用于 content 之外的属性（兼容性）
结论：attr() 在非 content 属性上不生效。
原因：老浏览器只支持 attr 用于 content。
解法：查兼容性，非 content 场景做降级。
```
