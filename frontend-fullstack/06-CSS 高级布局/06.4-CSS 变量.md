## 概述

CSS 变量（自定义属性）让样式值可以「定义一次、处处引用」，是主题系统、设计令牌、深色模式的基础设施。相比 Sass 变量的编译期替换，CSS 变量是「运行时」的——可以动态改变、可以继承、可以配合 JS 操作。

```text
CSS 变量的核心价值：
1. 统一管理 —— 颜色、间距、字号定义一次，全局引用
2. 运行时可变 —— 可动态切换（主题、深色模式）
3. 可继承 —— 作用域内的子元素都能用
4. 配合 JS —— 通过 JS 读取和修改变量
```

## Custom Properties 自定义属性

CSS 变量通过 `--` 前缀定义，用 var() 引用：

```css
:root {
  --primary: #0066cc;
  --spacing: 16px;
  --radius: 8px;
}

.button {
  background: var(--primary);
  padding: var(--spacing);
  border-radius: var(--radius);
}
```

```text
定义与引用：
定义 —— --变量名: 值;（通常放 :root 全局定义）
引用 —— var(--变量名)

命名规范：--kebab-case（如 --primary-color）
```

```text
var() 的兜底值：
var(--name, 默认值) —— 变量未定义时用默认值

color: var(--primary, #0066cc);
```

```text
CSS 变量 vs Sass 变量：
CSS 变量 —— 运行时存在，可动态改、可继承、可被 JS 操作
Sass 变量 —— 编译时替换，构建后不存在，不能运行时改

现代项目以 CSS 变量为主，Sass 变量退居构建期辅助。
```

## CSS Variable Scope 作用域

CSS 变量的作用域遵循「继承」规则：

```css
:root {
  --color: blue;   /* 全局作用域 */
}

.card {
  --color: red;    /* 局部作用域（只影响 .card 内） */
}

.card .title {
  color: var(--color);  /* 红色（继承最近的 .card 定义） */
}

.other {
  color: var(--color);  /* 蓝色（用 :root 的全局值） */
}
```

```text
作用域规则：
1. 变量定义在哪个选择器，就在哪个选择器（及其子元素）生效
2. :root 定义 = 全局变量
3. 局部定义会「覆盖」全局定义（就近原则）
4. 子元素继承最近的祖先定义
```

```text
作用域的应用：
组件级变量 —— 组件内定义，覆盖全局值，实现「组件定制」
如：.theme-dark 里重定义 --color，其子元素自动用深色值
```

## Theme 与 Design Token

### Design Token

Design Token（设计令牌）是把设计系统的「原始值」抽象成命名变量：

```css
:root {
  /* 颜色 */
  --color-primary: #0066cc;
  --color-bg: #ffffff;
  --color-text: #333333;
  --color-border: #e0e0e0;

  /* 间距 */
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;

  /* 字号 */
  --font-sm: 12px;
  --font-md: 14px;
  --font-lg: 16px;

  /* 圆角 */
  --radius-sm: 4px;
  --radius-md: 8px;
}
```

```text
Design Token 的分层：
原始值（Primitive）—— 具体色值/尺寸（--color-blue-500: #0066cc）
语义值（Semantic）—— 有语义的引用（--color-primary: var(--color-blue-500)）
组件值（Component）—— 组件专用（--button-bg: var(--color-primary)）

分层让「改一处」能精准影响「该影响的地方」。
```

### Theme 主题

主题是「一套 Design Token 的集合」，通过切换作用域实现：

```css
:root {
  --bg: #ffffff;
  --text: #333333;
}

/* 深色主题：在同一作用域重定义 */
[data-theme="dark"] {
  --bg: #1a1a1a;
  --text: #eeeeee;
}
```

## Dynamic Theme 动态主题

动态主题是「运行时切换主题」，靠 CSS 变量 + 作用域实现：

```js
// 切换主题：改 html 的 data-theme 属性
document.documentElement.dataset.theme = 'dark';
```

```html
<!-- data-theme 属性控制主题 -->
<html data-theme="light">
```

```css
:root { /* light 主题默认 */ }
[data-theme="dark"] {
  --bg: #1a1a1a;
}
```

```js
// 或直接改 CSS 变量（更灵活）
document.documentElement.style.setProperty('--bg', '#1a1a1a');
```

```text
动态主题的实现方式：
1. data-theme 属性 + 作用域重定义（推荐，语义清晰）
2. class 切换（.theme-dark）
3. JS 直接 setProperty 改变量（适合少量动态值）

核心：变量是运行时可变的，改变量值 = 换主题。
```

## Dark Mode 深色模式

深色模式是「主题」的典型应用，通常配合系统偏好：

```css
:root {
  --bg: #ffffff;
  --text: #333333;
}

/* 跟随系统深色偏好 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
    --text: #eeeeee;
  }
}
```

```text
深色模式的三种方案：
1. 纯 CSS（prefers-color-scheme）—— 跟随系统，无需 JS
2. 手动切换（data-theme）—— 用户主动选，存 localStorage
3. 系统 + 手动结合 —— 默认跟随系统，用户可手动覆盖
```

```js
// 手动切换深色模式（结合 localStorage）
function toggleDark() {
  const dark = document.documentElement.dataset.theme === 'dark';
  document.documentElement.dataset.theme = dark ? 'light' : 'dark';
  localStorage.setItem('theme', dark ? 'light' : 'dark');
}

// 初始化：读 localStorage 或系统偏好
const saved = localStorage.getItem('theme');
if (saved) {
  document.documentElement.dataset.theme = saved;
} else if (matchMedia('(prefers-color-scheme: dark)').matches) {
  document.documentElement.dataset.theme = 'dark';
}
```

```text
深色模式的注意点：
1. 所有颜色都用变量，否则切主题时漏改
2. 图片/阴影也要适配（深色下阴影更微妙）
3. 对比度在深色下要重新检查
4. 避免「纯黑 + 纯白」（刺眼），用灰阶（#1a1a1a + #eeeeee）
```

## 应用场景实战

### 场景一：完整的设计令牌 + 主题系统

```css
:root {
  /* 原始色 */
  --blue-500: #0066cc;
  --gray-100: #f5f5f5;
  --gray-900: #1a1a1a;

  /* 语义色（light） */
  --color-primary: var(--blue-500);
  --color-bg: #ffffff;
  --color-text: var(--gray-900);
  --color-border: #e0e0e0;
}

[data-theme="dark"] {
  --color-primary: #3399ff;  /* 深色下主色更亮 */
  --color-bg: var(--gray-900);
  --color-text: #eeeeee;
  --color-border: #333333;
}

.card {
  background: var(--color-bg);
  color: var(--color-text);
  border: 1px solid var(--color-border);
}
```

### 场景二：组件级变量覆盖

```css
:root { --button-bg: #0066cc; }

/* 危险按钮：组件内覆盖变量 */
.button-danger {
  --button-bg: #cc3300;
}
.button {
  background: var(--button-bg);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 全局变量定义在 :root，组件变量定义在组件选择器
2. 用 Design Token 分层（原始值 → 语义值 → 组件值）
3. 所有颜色/间距/字号都走变量，杜绝硬编码
4. 主题切换用 data-theme 属性 + 作用域，深色模式配 prefers-color-scheme
5. 深色模式避免纯黑纯白，用灰阶

### 踩坑记录

```text
坑 1：变量名拼写不一致
结论：var(--primary) 和 var(--Primary) 是不同变量，后者未定义失效。
原因：CSS 变量区分大小写。
解法：统一命名规范（kebab-case），不混用大小写。

坑 2：硬编码颜色导致主题切换漏改
结论：切深色模式后，部分元素颜色没变。
原因：部分样式硬编码了色值，没走变量。
解法：所有主题相关颜色走变量，用 lint 或审查杜绝硬编码。

坑 3：变量在 :root 之外的作用域理解错误
结论：改了局部变量，没生效到预期范围。
原因：CSS 变量作用域是「定义选择器及其子元素」，继承规则理解错。
解法：理解就近继承，局部覆盖只在对应子树生效。

坑 4：JS 读变量时机过早
结论：JS 读 getComputedStyle 拿到空值。
原因：元素还没渲染或变量定义在 JS 之后。
解法：在 DOMContentLoaded 后读取，或用 setProperty 显式设置。

坑 5：深色模式对比度不足
结论：深色下文字看不清。
原因：深色主题颜色没单独调对比度，直接反色。
解法：深色主题单独设计颜色，检查 WCAG 对比度。
```
