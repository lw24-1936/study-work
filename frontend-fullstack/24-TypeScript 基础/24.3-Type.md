## 概述

Type（类型别名）用 type 关键字给类型起名字，可以表示任意类型——包括联合、交叉、元组、字面量等复杂结构，比 interface 更灵活。

```text
type 的能力：
1. 类型别名 —— 给类型起名复用
2. 联合类型 —— union
3. 交叉类型 —— intersection
4. 字面量类型 —— literal
5. 元组类型 —— tuple
6. 函数类型 —— function type
7. 映射类型 —— mapped type
8. 条件类型 —— conditional type
```

```ts
// 基本类型别名
type ID = string | number;
type Point = { x: number; y: number };
```

## type alias

Type alias（类型别名）用 type 给任意类型起一个名字，方便复用和表达语义。

```ts
type UserID = number;
type Name = string;

let id: UserID = 1001;
let name: Name = 'Alice';
```

```ts
// 别名可以表达复杂类型
type Handler = (event: Event) => void;
type Config = {
  url: string;
  retries: number;
};
```

```text
type 与 interface 对比：
1. type 可表示任何类型（原始值、联合、元组等）
2. interface 只描述对象/函数结构
3. type 不能声明合并，interface 可以
4. 组合优先用 type，扩展优先用 interface
```

## union

Union（联合类型）用 | 连接多个类型，表示值可以是其中任意一种。

```ts
type Status = 'pending' | 'success' | 'error';
type ID = string | number;

let status: Status = 'success';
let id: ID = 123;
id = 'abc';   // 合法，ID 可以是 string 或 number
```

```ts
// 联合类型访问共有属性，或用类型收窄
function formatId(id: string | number): string {
  if (typeof id === 'number') {
    return id.toFixed(0);   // 收窄为 number
  }
  return id.toUpperCase();  // 收窄为 string
}
```

```text
联合类型要点：
1. 只能访问所有成员共有的属性/方法
2. 用 typeof、instanceof、in 等收窄后操作
3. 常用于状态、枚举值、多态参数
```

## intersection

Intersection（交叉类型）用 & 合并多个类型，要求值同时满足所有类型。

```ts
type Named = { name: string };
type Aged = { age: number };

type Person = Named & Aged;   // 同时有 name 和 age

const p: Person = { name: 'Alice', age: 18 };
```

```ts
// 交叉类型组合多个能力
type ErrorHandling = { onError?: (e: Error) => void };
type RequestConfig = { url: string; method?: string };
type FullRequest = RequestConfig & ErrorHandling;

const req: FullRequest = {
  url: '/api',
  method: 'GET',
  onError: (e) => console.log(e),
};
```

```text
交叉类型要点：
1. 对象交叉 = 属性合并
2. 同名属性类型需兼容，冲突会导致 never
3. 常用于组合多个接口的能力
```

## literal

Literal（字面量类型）用具体的值作为类型，限制变量只能是该值。

```ts
type Direction = 'left' | 'right' | 'up' | 'down';
type DiceRoll = 1 | 2 | 3 | 4 | 5 | 6;
type Truthy = true;

let dir: Direction = 'left';
// dir = 'diagonal';  // 报错：不是允许的字面量
```

```ts
// 字面量类型实现「枚举」效果
type HttpMethod = 'GET' | 'POST' | 'PUT' | 'DELETE';

function request(method: HttpMethod, url: string) {
  return { method, url };
}
request('POST', '/api');
```

```text
字面量类型要点：
1. 字符串字面量、数字字面量、布尔字面量
2. 常与联合类型搭配做枚举
3. 配合 const 声明变量会自动推断为字面量类型
```

## tuple

Tuple（元组类型）表示固定长度、固定元素类型的数组。

```ts
type Point3D = [number, number, number];
type Pair = [string, number];

let p: Point3D = [1, 2, 3];
let pair: Pair = ['age', 18];
```

```ts
// 可选元素与剩余元素
type Config = [string, number?, boolean?];
type List = [number, ...string[]];   // 首个是 number，后面是 string

const c1: Config = ['a'];
const c2: Config = ['a', 1, true];
const l: List = [1, 'x', 'y'];
```

```ts
// 解构元组
const [x, y, z] = p;
console.log(x, y, z);
```

```text
元组要点：
1. 长度固定，元素类型对应位置
2. 用 ? 标记可选元素，用 ... 标记剩余
3. 常用于函数多返回值、坐标等固定结构
```

## function type

Function type（函数类型）描述函数的参数和返回值类型，可用箭头语法定义。

```ts
type Add = (a: number, b: number) => number;
type Callback = (result: string) => void;

const add: Add = (a, b) => a + b;
const log: Callback = (result) => console.log(result);
```

```ts
// 含可选参数和重载
type RequestFn = {
  (url: string): Promise<Response>;
  (url: string, options: object): Promise<Response>;
};
```

```ts
// 函数类型作为参数
function withCallback(fn: (n: number) => string) {
  return fn(42);
}
withCallback((n) => n.toString());
```

## mapped type

Mapped type（映射类型）基于已有类型的键生成新类型，用 in keyof 遍历键。

```ts
type Flags = {
  darkMode: boolean;
  animation: boolean;
};

// 把所有属性变成可选
type OptionalFlags = { [K in keyof Flags]?: Flags[K] };
// 等价于 { darkMode?: boolean; animation?: boolean; }

// 把所有属性变成只读
type ReadonlyFlags = { readonly [K in keyof Flags]: Flags[K] };
```

```ts
// 映射类型配合泛型实现通用工具
type MyPartial<T> = { [K in keyof T]?: T[K] };
type MyReadonly<T> = { readonly [K in keyof T]: T[K] };

type PartialFlags = MyPartial<Flags>;
```

```text
映射类型要点：
1. 语法：[K in keyof T]: 新类型
2. 可加 ? 和 readonly 修饰
3. 是 Partial、Readonly 等工具类型的实现基础
```

## conditional type

Conditional type（条件类型）根据条件表达式选择类型，语法类似三元运算符。

```ts
type IsString<T> = T extends string ? true : false;

type A = IsString<string>;   // true
type B = IsString<number>;   // false
```

```ts
// 常见应用：提取函数返回类型
type Unwrap<T> = T extends Promise<infer U> ? U : T;

type R1 = Unwrap<Promise<string>>;   // string
type R2 = Unwrap<number>;            // number
```

```ts
// 分布式条件类型（联合类型会逐个判断）
type ToArray<T> = T extends any ? T[] : never;
type Arr = ToArray<string | number>;   // string[] | number[]
```

```text
条件类型要点：
1. 语法：T extends U ? X : Y
2. 联合类型会分布式展开（裸类型参数时）
3. 配合 infer 提取类型，是高级类型的基础
```

## 应用场景实战

### 场景一：API 状态与响应建模

```ts
type ApiState = 'idle' | 'loading' | 'success' | 'error';

type ApiResult<T> = {
  state: ApiState;
  data?: T;
  error?: string;
};

// 元组：坐标
type LatLng = [number, number];

// 函数类型：请求函数
type Fetcher<T> = (url: string) => Promise<ApiResult<T>>;
```

### 场景二：用映射类型批量生成表单状态

```ts
type FormValues = {
  name: string;
  email: string;
  age: number;
};

// 生成「每个字段 + 校验错误」的表单状态
type FormErrors<T> = { [K in keyof T]?: string };
type FormTouched<T> = { [K in keyof T]: boolean };

type SignupErrors = FormErrors<FormValues>;
// { name?: string; email?: string; age?: string }
```

## 最佳实践与踩坑记录

### 最佳实践

1. 复杂组合类型用 type，对象结构扩展用 interface
2. 用联合 + 字面量类型替代魔法字符串枚举
3. 固定结构数组用 tuple 而非普通数组
4. 批量属性变换用映射类型，别手写重复
5. 条件类型配合 infer 提取类型，避免重复定义

### 踩坑记录

```text
坑 1：交叉类型属性冲突得到 never
结论：A & B 后某属性类型变成 never。
原因：同名属性类型不兼容，交叉结果为 never。
解法：调整类型设计，避免同名属性类型冲突。

坑 2：元组越界访问
结论：访问元组不存在的索引报错。
原因：元组长度固定，越界索引没有对应类型。
解法：用可选元素或剩余元素扩展，或改用普通数组。

坑 3：联合类型直接访问专属属性
结论：string | number 上调用 toFixed 报错。
原因：联合类型只能访问共有成员。
解法：先用 typeof/in 等收窄，再访问专属成员。

坑 4：条件类型未分布式展开
结论：期望联合类型逐个判断却没生效。
原因：类型参数被包裹（如 T[]）时不会分布式。
解法：保持裸类型参数 T extends ... 形式。

坑 5：字面量类型变量被拓宽
结论：let 声明后类型变成 string 而非字面量。
原因：let 变量会拓宽，const 才保留字面量类型。
解法：用 const，或显式标注字面量类型。
```
