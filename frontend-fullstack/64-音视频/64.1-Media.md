## 概述

浏览器媒体能力覆盖「播放」「录制」「处理」「实时」四大方向。Audio/Video 负责播放，MediaSource 支持流式播放（MSE），MediaRecorder 负责录制，Web Audio API 提供音频处理与合成。它们共同构成 Web 音视频的基础设施。

```text
媒体相关 API 全景：
1. Audio / Video —— 媒体播放元素
2. MediaSource —— 媒体源扩展（MSE），流式/自适应播放
3. MediaRecorder —— 录制音视频流为文件
4. Web Audio API —— 音频处理、合成、可视化
5. getUserMedia —— 采集摄像头/麦克风（见 WebRTC 篇）

共同基础：Blob、MediaStream、可播放的编码格式
```

```js
// 检测浏览器媒体能力
const audio = document.createElement('audio');
console.log('MP3 支持：', audio.canPlayType('audio/mpeg'));
console.log('AAC 支持：', audio.canPlayType('audio/mp4; codecs="mp4a.40.2"'));
```

## Audio

Audio 元素用于播放音频，支持 src 或 <source> 多源回退，以及大量控制方法与事件。

```html
<audio controls preload="metadata">
  <source src="audio.mp3" type="audio/mpeg" />
  <source src="audio.ogg" type="audio/ogg" />
  你的浏览器不支持 audio 标签。
</audio>
```

```js
const audio = new Audio('audio.mp3');

audio.play();                 // 播放（返回 Promise）
audio.pause();                // 暂停
audio.currentTime = 30;       // 跳到 30 秒
audio.volume = 0.5;           // 音量 0~1
audio.muted = true;           // 静音
audio.playbackRate = 1.5;     // 1.5 倍速

// 事件
audio.addEventListener('ended', () => console.log('播放结束'));
audio.addEventListener('timeupdate', () => console.log(audio.currentTime));
```

```text
Audio 关键点：
1. play() 返回 Promise，可能因自动播放策略被拒绝
2. preload：none / metadata / auto
3. 多 source 按顺序尝试，直到找到可播格式
4. 移动端需用户手势后才能 play()
```

## Video

Video 元素用于播放视频，支持字幕、海报、自适应分辨率等，是 Web 视频播放的核心。

```html
<video controls width="640" poster="poster.jpg">
  <source src="movie.mp4" type="video/mp4" />
  <source src="movie.webm" type="video/webm" />
</video>
```

```js
const video = document.querySelector('video');

video.addEventListener('loadedmetadata', () => {
  console.log(video.videoWidth, video.videoHeight);  // 原始分辨率
  console.log(video.duration);
});

video.play()
  .then(() => console.log('开始播放'))
  .catch((err) => console.log('自动播放被阻止：', err));
```

```text
Video 常用属性：
1. currentTime / duration —— 当前时间 / 总时长
2. paused / ended —— 状态
3. playbackRate —— 倍速
4. buffered —— 已缓冲区间（TimeRanges）
5. readyState —— 就绪状态（HAVE_ENOUGH_DATA=4）
```

## MediaSource

MediaSource（媒体源扩展，MSE）允许 JS 动态构造媒体流并喂给 video/audio，是 HLS/DASH 播放、流媒体、视频拼接的技术基础。

```js
const video = document.querySelector('video');
const mediaSource = new MediaSource();
video.src = URL.createObjectURL(mediaSource);

mediaSource.addEventListener('sourceopen', () => {
  const mime = 'video/mp4; codecs="avc1.42E01E, mp4a.40.2"';
  const sourceBuffer = mediaSource.addSourceBuffer(mime);

  fetch('segment1.mp4')
    .then((res) => res.arrayBuffer())
    .then((buf) => sourceBuffer.appendBuffer(buf));
});
```

```text
MediaSource 核心概念：
1. SourceBuffer —— 接收媒体数据分片
2. appendBuffer —— 追加分片（异步，需等 updateend）
3. 支持多 SourceBuffer —— 音频/视频分离
4. 配合流式分片实现直播/点播
```

```js
// 监听 SourceBuffer 更新完成，串行追加分片
sourceBuffer.addEventListener('updateend', () => {
  if (segments.length) {
    sourceBuffer.appendBuffer(segments.shift());
  } else {
    mediaSource.endOfStream();
  }
});
```

## MediaRecorder

MediaRecorder 将 MediaStream（摄像头、屏幕、音频）录制为 Blob 文件，是 Web 端录屏、录音、录制会议的基础。

```js
const stream = await navigator.mediaDevices.getUserMedia({ audio: true, video: true });
const recorder = new MediaRecorder(stream, { mimeType: 'video/webm' });
const chunks = [];

recorder.ondataavailable = (e) => chunks.push(e.data);
recorder.onstop = () => {
  const blob = new Blob(chunks, { type: 'video/webm' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'recording.webm';
  a.click();
};

recorder.start();                     // 开始录制
setTimeout(() => recorder.stop(), 5000);  // 5 秒后停止
```

```text
MediaRecorder 关键点：
1. mimeType 受浏览器支持限制（WebM 最通用）
2. timeslice —— start(1000) 每秒触发 dataavailable，便于分段上传
3. ondataavailable 在 stop 或 timeslice 时触发
4. 需要 HTTPS 或 localhost 才能访问媒体设备
```

## Web Audio API

Web Audio API 提供完整的音频处理能力：合成、滤波、空间音效、可视化。核心是 AudioContext 与节点图（Node Graph）。

```text
Web Audio 核心模型：
1. AudioContext —— 音频上下文，一切节点的容器
2. 源节点 —— 振荡器、音频缓冲、媒体流
3. 处理节点 —— 增益、滤波、压缩等
4. 目标节点 —— 扬声器（destination）
```

```js
// 振荡器发声
const ctx = new AudioContext();
const osc = ctx.createOscillator();   // 源：振荡器
const gain = ctx.createGain();        // 处理：增益

osc.type = 'sine';                    // sine/square/sawtooth/triangle
osc.frequency.value = 440;            // 440Hz

osc.connect(gain).connect(ctx.destination);  // 连接节点图
gain.gain.value = 0.3;

osc.start();
setTimeout(() => osc.stop(), 1000);
```

```js
// 可视化：AnalyserNode 获取频域数据
const analyser = ctx.createAnalyser();
analyser.fftSize = 256;
source.connect(analyser);
analyser.connect(ctx.destination);

const data = new Uint8Array(analyser.frequencyBinCount);
function draw() {
  analyser.getByteFrequencyData(data);   // 频域数据
  // 用 data 绘制频谱柱状图
  requestAnimationFrame(draw);
}
draw();
```

```text
Web Audio 常见节点：
1. OscillatorNode —— 振荡器（合成音）
2. GainNode —— 增益（音量控制）
3. BiquadFilterNode —— 滤波器（高低通）
4. AnalyserNode —— 分析（可视化）
5. AudioBufferSourceNode —— 播放解码后的音频缓冲
```

## 应用场景实战

### 场景一：录音并即时回放

```js
async function recordAndPlayback() {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  const recorder = new MediaRecorder(stream);
  const chunks = [];

  recorder.ondataavailable = (e) => chunks.push(e.data);
  recorder.onstop = () => {
    const blob = new Blob(chunks, { type: 'audio/webm' });
    const audio = new Audio(URL.createObjectURL(blob));
    audio.play();
    stream.getTracks().forEach((t) => t.stop());
  };

  recorder.start();
  setTimeout(() => recorder.stop(), 3000);
}
```

### 场景二：音乐可视化

```js
async function visualize() {
  const ctx = new AudioContext();
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  const source = ctx.createMediaStreamSource(stream);
  const analyser = ctx.createAnalyser();
  analyser.fftSize = 512;
  source.connect(analyser);

  const data = new Uint8Array(analyser.frequencyBinCount);
  function loop() {
    analyser.getByteFrequencyData(data);
    const avg = data.reduce((s, v) => s + v, 0) / data.length;
    document.querySelector('.bar').style.width = `${avg * 2}px`;
    requestAnimationFrame(loop);
  }
  loop();
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 播放前先 canPlayType 检测格式支持，多 source 回退
2. 自动播放需用户手势，做好 play() 被拒的降级
3. MediaRecorder 优先用 WebM，跨浏览器最稳
4. 媒体设备访问必须 HTTPS（或 localhost）
5. AudioContext 在用户手势后创建，否则处于 suspended 状态
6. 视频预加载用 preload="metadata"，避免浪费带宽

### 踩坑记录

```text
坑 1：自动播放被浏览器阻止
结论：页面加载后直接 video.play() 抛 NotAllowedError。
原因：浏览器自动播放策略要求用户手势。
解法：在 click/touch 等手势中调用 play()，或设 muted 自动播放。

坑 2：MediaSource 连续 appendBuffer 出错
结论：快速追加分片报 InvalidStateError。
原因：SourceBuffer 未更新完就再次 append。
解法：监听 updateend 后串行追加下一分片。

坑 3：AudioContext 无声音
结论：创建 AudioContext 后播放没声音。
原因：浏览器要求用户手势才能恢复音频上下文。
解法：在用户手势回调里创建或调用 ctx.resume()。

坑 4：录音文件无法播放
结论：录制的 Blob 打开失败。
原因：mimeType 拼写错误或不被支持。
解法：用 MediaRecorder.isTypeSupported() 检测后选择 mimeType。

坑 5：内存泄漏——getUserMedia 流未释放
结论：长时间使用后设备指示灯常亮、内存上涨。
原因：MediaStream 的 track 未 stop。
解法：用完调用 stream.getTracks().forEach(t => t.stop())。
```
