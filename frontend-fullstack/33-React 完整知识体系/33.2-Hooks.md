## 概述

Hooks 是 React 16.8 引入的函数式能力，让函数组件也能拥有状态和副作用。它们必须以 `use` 开头，并且只能在组件顶层或自定义 Hook 中调用。

```text
Hooks 的两条铁律：
1. 只在组件顶层调用 —— 不能在条件、循环、嵌套函数中调用
2. 只在 React 函数中调用 —— 组件或自定义 Hook
原因：React 依赖 Hook 的调用顺序来关联内部状态。
```

```jsx
import { useState, useEffect } from 'react';

function Clock() {
  const [now, setNow] = useState(new Date());
  useEffect(() => {
    const timer = setInterval(() => setNow(new Date()), 1000);
    return () => clearInterval(timer);  // 清理函数
  }, []);
  return <div>{now.toLocaleTimeString()}</div>;
}
```

## useState

`useState` 管理组件局部状态，返回 `[状态, 更新函数]`。更新函数会触发重新渲染。

```jsx
const [count, setCount] = useState(0);          // 基本类型
const [user, setUser] = useState({ name: '' }); // 对象
const [list, setList] = useState([]);           // 数组

// 惰性初始化：初始值只计算一次（昂贵计算适用）
const [data, setData] = useState(() => expensiveInit());
```

```jsx
// 更新对象/数组时返回新引用
setUser(prev => ({ ...prev, name: 'Alice' }));
setList(prev => [...prev, newItem]);
```

## useEffect

`useEffect` 处理副作用（请求、订阅、定时器、DOM 操作），在渲染提交后异步执行。

```jsx
useEffect(() => {
  // 副作用：挂载后执行
  const controller = new AbortController();
  fetch('/api/user', { signal: controller.signal })
    .then(r => r.json())
    .then(setUser);

  // 清理函数：卸载或依赖变化时执行
  return () => controller.abort();
}, []);  // 空依赖：只在挂载/卸载执行
```

```jsx
// 依赖变化时重新执行
useEffect(() => {
  document.title = `${count} 条消息`;
}, [count]);  // count 变化才执行

// 不传依赖数组：每次渲染都执行（一般不推荐）
useEffect(() => {
  console.log('每次渲染执行');
});
```

## useContext

`useContext` 读取 Context 提供的值，跨层级传递数据而无需逐层传 props。

```jsx
import { createContext, useContext } from 'react';

const ThemeContext = createContext('light');

function ThemedButton() {
  const theme = useContext(ThemeContext);  // 读取最近 Provider 的值
  return <button className={theme}>按钮</button>;
}

// 上层通过 Provider 提供值
<ThemeContext.Provider value="dark">
  <ThemedButton />
</ThemeContext.Provider>;
```

## useReducer

`useReducer` 是 `useState` 的替代，用 reducer 函数集中管理复杂的状态转换逻辑。

```jsx
import { useReducer } from 'react';

const initialState = { count: 0 };

function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    case 'reset':
      return { count: action.payload };
    default:
      return state;
  }
}

function Counter() {
  const [state, dispatch] = useReducer(reducer, initialState);
  return (
    <div>
      <span>{state.count}</span>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
      <button onClick={() => dispatch({ type: 'reset', payload: 0 })}>重置</button>
    </div>
  );
}
```

## useMemo

`useMemo` 缓存计算结果，依赖不变时返回上次的缓存值，避免昂贵计算重复执行。

```jsx
import { useMemo } from 'react';

function List({ items }) {
  // 只在 items 变化时重新排序
  const sorted = useMemo(
    () => [...items].sort((a, b) => a.score - b.score),
    [items]
  );
  return <ul>{sorted.map(i => <li key={i.id}>{i.name}</li>)}</ul>;
}
```

## useCallback

`useCallback` 缓存函数引用，避免子组件因「每次渲染都拿到新函数」而无效重渲染。

```jsx
import { useCallback, memo } from 'react';

const Child = memo(function Child({ onClick }) {
  return <button onClick={onClick}>点我</button>;
});

function Parent() {
  // 函数引用稳定，配合 memo 时 Child 不会因父组件重渲染而更新
  const handleClick = useCallback(() => {
    console.log('clicked');
  }, []);

  return <Child onClick={handleClick} />;
}
```

## useRef

`useRef` 返回可变引用对象，修改 `.current` 不触发渲染，常用于访问 DOM 或保存跨渲染的变量。

```jsx
import { useRef, useEffect } from 'react';

function AutoFocusInput() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus();  // 访问真实 DOM 节点
  }, []);

  return <input ref={inputRef} />;
}
```

```jsx
// 保存上一次的值（不触发渲染的「快照」）
function usePrevious(value) {
  const ref = useRef();
  useEffect(() => {
    ref.current = value;
  });
  return ref.current;
}
```

## useImperativeHandle

`useImperativeHandle` 配合 `forwardRef`，向父组件暴露自定义的实例方法（而非整个 DOM）。

```jsx
import { forwardRef, useImperativeHandle, useRef } from 'react';

const FancyInput = forwardRef(function FancyInput(props, ref) {
  const inputRef = useRef(null);

  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current.focus(),
    clear: () => { inputRef.current.value = ''; },
  }));

  return <input ref={inputRef} />;
});

function App() {
  const ref = useRef(null);
  return (
    <div>
      <FancyInput ref={ref} />
      <button onClick={() => ref.current.focus()}>聚焦</button>
    </div>
  );
}
```

## useLayoutEffect

`useLayoutEffect` 与 `useEffect` 签名相同，但它在 DOM 更新后、浏览器绘制前**同步**执行，适合需要在绘制前测量/修改 DOM 的场景。

```jsx
import { useLayoutEffect, useRef, useState } from 'react';

function Tooltip({ target }) {
  const ref = useRef(null);
  const [pos, setPos] = useState({ x: 0, y: 0 });

  useLayoutEffect(() => {
    // 在绘制前测量尺寸，避免闪烁
    const rect = target.getBoundingClientRect();
    setPos({ x: rect.left, y: rect.bottom });
  }, [target]);

  return <div ref={ref} style={{ left: pos.x, top: pos.y }}>提示</div>;
}
```

```text
useEffect vs useLayoutEffect：
1. useEffect —— 异步、绘制后执行，不阻塞渲染
2. useLayoutEffect —— 同步、绘制前执行，会阻塞渲染
3. 默认用 useEffect，仅测量布局/避免闪烁时用 useLayoutEffect
```

## useInsertionEffect

`useInsertionEffect` 在 DOM 变更后、`useLayoutEffect` 之前执行，专为 CSS-in-JS 库设计，用于在布局读取前插入样式。

```jsx
import { useInsertionEffect } from 'react';

function useCSS(rule) {
  useInsertionEffect(() => {
    const style = document.createElement('style');
    style.textContent = rule;
    document.head.appendChild(style);
    return () => style.remove();
  }, [rule]);
}
```

```text
三种 Effect 的执行顺序（提交阶段）：
useInsertionEffect → useLayoutEffect → useEffect
前两者同步执行，useEffect 异步执行。
```

## useId

`useId` 生成跨服务端/客户端一致的唯一 ID，用于表单控件与 label 的关联、无障碍属性等。

```jsx
import { useId } from 'react';

function EmailField() {
  const id = useId();
  return (
    <div>
      <label htmlFor={id}>邮箱</label>
      <input id={id} type="email" />
    </div>
  );
}
```

## useTransition

`useTransition` 标记「非紧急」状态更新，让紧急更新（如输入）优先处理，避免界面卡顿。

```jsx
import { useState, useTransition } from 'react';

function SearchList() {
  const [query, setQuery] = useState('');
  const [items, setItems] = useState([]);
  const [isPending, startTransition] = useTransition();

  const handleChange = (e) => {
    setQuery(e.target.value);            // 紧急：立即更新输入框
    startTransition(() => {              // 非紧急：列表更新可被打断
      setItems(searchData(e.target.value));
    });
  };

  return (
    <div>
      <input value={query} onChange={handleChange} />
      {isPending ? <Spinner /> : <List items={items} />}
    </div>
  );
}
```

## useDeferredValue

`useDeferredValue` 延迟一个值的更新，让它在紧急更新完成后、空闲时再生效，常用于「跟随输入」的派生渲染。

```jsx
import { useState, useDeferredValue } from 'react';

function Search() {
  const [text, setText] = useState('');
  const deferredText = useDeferredValue(text);  // 滞后于 text

  // text 立即更新输入框，deferredText 延迟驱动昂贵列表
  return (
    <div>
      <input value={text} onChange={e => setText(e.target.value)} />
      <SlowList query={deferredText} />
    </div>
  );
}
```

## useSyncExternalStore

`useSyncExternalStore` 订阅外部数据源（如全局 store、浏览器 API），保证并发渲染下数据一致性。

```jsx
import { useSyncExternalStore } from 'react';

// 订阅一个外部 store
const store = {
  listeners: new Set(),
  state: { count: 0 },
  subscribe(listener) {
    store.listeners.add(listener);
    return () => store.listeners.delete(listener);
  },
  getSnapshot() { return store.state; },
  increment() {
    store.state = { count: store.state.count + 1 };
    store.listeners.forEach(l => l());
  },
};

function Counter() {
  const { count } = useSyncExternalStore(store.subscribe, store.getSnapshot);
  return <button onClick={store.increment}>{count}</button>;
}
```

```jsx
// 订阅浏览器 API：在线状态
function useOnline() {
  return useSyncExternalStore(
    (cb) => {
      window.addEventListener('online', cb);
      window.addEventListener('offline', cb);
      return () => {
        window.removeEventListener('online', cb);
        window.removeEventListener('offline', cb);
      };
    },
    () => navigator.onLine
  );
}
```

## 应用场景实战

### 场景一：数据请求 + 防抖搜索

```jsx
import { useState, useEffect, useRef } from 'react';

function useDebouncedSearch() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (!query) { setResults([]); return; }
    setLoading(true);
    const timer = setTimeout(async () => {
      const res = await fetch(`/api/search?q=${query}`);
      const data = await res.json();
      setResults(data);
      setLoading(false);
    }, 300);
    return () => { clearTimeout(timer); setLoading(false); };
  }, [query]);

  return { query, setQuery, results, loading };
}
```

### 场景二：全局购物车（useReducer + Context）

```jsx
import { createContext, useContext, useReducer } from 'react';

const CartContext = createContext(null);

function cartReducer(state, action) {
  switch (action.type) {
    case 'add':
      return [...state, action.item];
    case 'remove':
      return state.filter(i => i.id !== action.id);
    default:
      return state;
  }
}

export function CartProvider({ children }) {
  const [cart, dispatch] = useReducer(cartReducer, []);
  return (
    <CartContext.Provider value={{ cart, dispatch }}>
      {children}
    </CartContext.Provider>
  );
}

export function useCart() {
  return useContext(CartContext);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 把副作用和状态逻辑抽成自定义 Hook，复用并隔离关注点
2. useEffect 依赖数组写全，或用 eslint-plugin-react-hooks 自动检查
3. 昂贵计算用 useMemo，稳定回调用 useCallback，别过度使用
4. 需要「上一次的值」或访问 DOM 用 useRef，而不是 state
5. 大数据列表搜索用 useTransition/useDeferredValue 保持输入流畅

### 踩坑记录

```text
坑 1：在条件中调用 Hook
结论：运行时报错或状态错乱。
原因：Hook 调用顺序被打乱，React 无法正确关联状态。
解法：把条件判断移到 Hook 内部，或提前 return 后不再调用 Hook。

坑 2：useEffect 依赖漏写导致读到旧值
结论：闭包捕获了旧 state，逻辑用错数据。
原因：依赖数组不全，effect 没在数据变化时重跑。
解法：依赖写全，配合 ESLint 的 exhaustive-deps 规则。

坑 3：忘记清理副作用导致内存泄漏
结论：定时器/订阅/请求在卸载后仍执行。
原因：没有返回清理函数。
解法：定时器 clear、订阅 unsubscribe、请求 abort。

坑 4：用 state 存 ref 才该存的东西
结论：高频更新导致不必要的重渲染。
原因：把「不参与渲染」的值存进了 state。
解法：不渲染的值放 useRef，需要渲染才用 state。

坑 5：useMemo/useCallback 滥用
结论：代码变复杂却没有性能收益，甚至更慢。
原因：缓存本身也有开销，简单计算无需缓存。
解法：先测量性能瓶颈，再针对性加 memo。
```
