## 概述

Web Storage 是浏览器提供的键值存储 API，包括 localStorage 和 sessionStorage。两者 API 相同、只能存字符串，区别在生命周期和作用域。

```text
Web Storage 的特点：
1. 简单键值对 —— setItem/getItem/removeItem
2. 只能存字符串 —— 对象需 JSON 序列化
3. 同步操作 —— 阻塞主线程
4. 容量约 5MB —— 比 Cookie 大得多

localStorage —— 持久化，同源所有标签页共享
sessionStorage —— 会话级，每个标签页独立
```

## localStorage 持久存储

localStorage 数据持久化，关闭浏览器也不丢失，同源所有标签页共享。

```js
// 基本操作
localStorage.setItem('key', 'value');
localStorage.getItem('key');          // 'value'
localStorage.removeItem('key');
localStorage.clear();                 // 清空所有
```

```js
// 存对象需 JSON 序列化
const user = { name: 'Alice', age: 30 };
localStorage.setItem('user', JSON.stringify(user));
const loaded = JSON.parse(localStorage.getItem('user'));
```

```js
// 遍历
for (let i = 0; i < localStorage.length; i++) {
  const key = localStorage.key(i);
  console.log(key, localStorage.getItem(key));
}
```

```text
localStorage 的特性：
1. 持久化 —— 关闭浏览器不丢失
2. 同源共享 —— 同域名所有标签页共享
3. 容量约 5MB
4. 不随请求发送（区别于 Cookie）
```

## sessionStorage 会话存储

sessionStorage 数据在**当前标签页会话**内有效，关闭标签页即清除，每个标签页独立。

```js
// API 与 localStorage 完全相同
sessionStorage.setItem('temp', 'value');
sessionStorage.getItem('temp');
sessionStorage.removeItem('temp');
```

```text
sessionStorage 的特性：
1. 会话级 —— 关闭标签页即清除
2. 标签页独立 —— 每个标签页有独立的 sessionStorage
3. 刷新页面保留（同标签页会话内）
4. 适用：表单临时数据、临时状态
```

```js
// 典型：表单草稿（刷新不丢，关闭标签页清除）
form.addEventListener('input', () => {
  sessionStorage.setItem('draft', JSON.stringify(formData));
});
```

## localStorage vs sessionStorage vs Cookie

```text
对比维度      localStorage    sessionStorage    Cookie
生命周期      持久化          会话级            可设过期
作用域        同源所有标签页  单个标签页        同源（可配 Domain）
容量          ~5MB            ~5MB              ~4KB
随请求发送    否              否                是
服务端可读    否              否                是
API           同步            同步              document.cookie
```

```text
选择建议：
1. 持久化偏好/配置 → localStorage
2. 临时会话数据 → sessionStorage
3. 服务端需要读的（会话、鉴权）→ Cookie
4. 大数据 → IndexedDB
```

## 应用场景实战

### 场景一：主题持久化

```js
function saveTheme(theme) {
  localStorage.setItem('theme', theme);
}
function loadTheme() {
  return localStorage.getItem('theme') || 'light';
}
```

### 场景二：跨标签页通信

```js
// 页面 A：写入
localStorage.setItem('message', 'hello');

// 页面 B：监听（storage 事件在其他标签页修改时触发）
window.addEventListener('storage', (e) => {
  if (e.key === 'message') console.log(e.newValue);
});
```

## 最佳实践与踩坑记录

### 最佳实践

1. 对象存 localStorage 先 JSON.stringify
2. 敏感数据（token）别存 localStorage（易被 XSS 窃取）
3. 临时数据用 sessionStorage
4. 跨标签页通信用 storage 事件
5. 大数据用 IndexedDB，别塞 localStorage

### 踩坑记录

```text
坑 1：存对象忘序列化
结论：存对象得到 '[object Object]'。
原因：storage 只能存字符串。
解法：JSON.stringify 存，JSON.parse 取。

坑 2：JSON.parse 失败
结论：取回数据 parse 抛错。
原因：数据损坏或格式不对。
解法：try/catch 包裹解析。

坑 3：敏感信息存 localStorage
结论：token 被 XSS 窃取。
原因：localStorage 可被任意 JS 读取。
解法：敏感数据用 HttpOnly Cookie，localStorage 只存非敏感。

坑 4：容量超限
结论：大量数据写入失败（QuotaExceededError）。
原因：localStorage 约 5MB 上限。
解法：大数据用 IndexedDB。

坑 5：隐私模式下行为异常
结论：隐私模式 localStorage 抛异常或容量极小。
原因：部分浏览器隐私模式限制存储。
解法：try/catch 包裹，降级到内存。
```
