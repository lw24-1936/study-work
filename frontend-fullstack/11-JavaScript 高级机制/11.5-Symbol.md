## 概述

Symbol 是 ES6 引入的原始类型，用于创建**唯一**的值。它既是对象的属性键（避免冲突），也是一组**内置符号**（Well-known Symbols）用于定制语言行为。

```text
Symbol 的两大用途：
1. 唯一值 —— 每次 Symbol() 都不同，作属性键避免冲突
2. 内置符号 —— Symbol.iterator 等，定制对象的内建行为

特性：
1. 唯一性 —— 相同描述也互不相等
2. 不可枚举 —— 普通 Symbol 属性不出现在 for...in
3. 不能 new —— Symbol 是原始值，非构造函数
```

## Symbol 基础

```js
const s1 = Symbol('desc');
const s2 = Symbol('desc');

s1 === s2;             // false（即使描述相同，也唯一）
typeof s1;             // 'symbol'

// 作为对象属性键
const obj = {
  [s1]: 'value',
};
obj[s1];               // 'value'
```

```js
// 全局 Symbol 注册表（跨模块共享）
const g1 = Symbol.for('app.key');
const g2 = Symbol.for('app.key');
g1 === g2;             // true（Symbol.for 返回同一 Symbol）

Symbol.keyFor(g1);     // 'app.key'（查注册表的 key）
```

```text
Symbol() vs Symbol.for()：
Symbol('x') —— 每次创建新的唯一 Symbol
Symbol.for('x') —— 查全局注册表，有则复用，无则创建

普通 Symbol 属性不可枚举：
for...in、Object.keys 看不到 Symbol 键，
Object.getOwnPropertySymbols 才能取到。
```

## Symbol.iterator

Symbol.iterator 定义对象的默认迭代器，使对象可被 for...of、展开运算符使用。

```js
const obj = {
  data: [1, 2, 3],
  [Symbol.iterator]() {
    let i = 0;
    const data = this.data;
    return {
      next() {
        return i < data.length
          ? { value: data[i++], done: false }
          : { done: true };
      },
    };
  },
};

for (const v of obj) {
  console.log(v);      // 1 2 3
}
[...obj];              // [1, 2, 3]
```

```text
Symbol.iterator 的作用：
1. 让对象可迭代（for...of、展开、解构）
2. 返回迭代器对象（有 next 方法，返回 {value, done}）
3. 数组、字符串、Map、Set 都内置了 Symbol.iterator
```

## Symbol.asyncIterator

Symbol.asyncIterator 定义异步迭代器，用于 for await...of 遍历异步数据流。

```js
const asyncIterable = {
  data: [1, 2, 3],
  async *[Symbol.asyncIterator]() {
    for (const item of this.data) {
      await new Promise(r => setTimeout(r, 100));   // 模拟异步
      yield item;
    }
  },
};

(async () => {
  for await (const v of asyncIterable) {
    console.log(v);      // 1 2 3（逐个异步产出）
  }
})();
```

```text
Symbol.asyncIterator 的特点：
1. 返回异步迭代器，next() 返回 Promise<{value, done}>
2. 用于 for await...of 循环
3. 适合流式数据、分页加载、异步序列
```

## Symbol.toPrimitive

Symbol.toPrimitive 定制对象转原始值的行为，在隐式类型转换（运算、比较）时被调用。

```js
const obj = {
  value: 42,
  [Symbol.toPrimitive](hint) {
    if (hint === 'string') return `value: ${this.value}`;
    if (hint === 'number') return this.value;
    return this.value;      // default
  },
};

+obj;                  // 42（number 提示）
String(obj);           // 'value: 42'（string 提示）
obj + 1;               // 43（default 提示）
```

```text
Symbol.toPrimitive 的 hint 参数：
'string' —— 需要字符串时（String()、模板字符串）
'number' —— 需要数字时（算术运算、+obj）
'default' —— 不确定时（== 比较、obj + x）

优先级：Symbol.toPrimitive > valueOf > toString
```

## Symbol.toStringTag

Symbol.toStringTag 定制 Object.prototype.toString.call() 返回的类型标签。

```js
class MyClass {
  get [Symbol.toStringTag]() {
    return 'MyClass';
  }
}

Object.prototype.toString.call(new MyClass());   // '[object MyClass]'
Object.prototype.toString.call([]);              // '[object Array]'
```

```text
Symbol.toStringTag 的用途：
1. 精确类型判断 —— 区分数组/对象/自定义类
2. 替代不精确的 typeof
3. 内置类型也有对应的 toStringTag
```

```js
// 精确判断类型的通用方法
function getType(x) {
  return Object.prototype.toString.call(x).slice(8, -1);
}
getType([]);         // 'Array'
getType(new Date()); // 'Date'
getType(null);       // 'Null'
```

## 应用场景实战

### 场景一：防属性名冲突

```js
// 库给对象加元数据，用 Symbol 避免与用户键冲突
const META = Symbol('meta');
function attachMeta(obj, data) {
  obj[META] = data;      // 不污染、不冲突
  return obj;
}
```

### 场景二：自定义可迭代集合

```js
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  *[Symbol.iterator]() {
    for (let i = this.start; i <= this.end; i++) yield i;
  }
}

[...new Range(1, 5)];    // [1, 2, 3, 4, 5]
```

## 最佳实践与踩坑记录

### 最佳实践

1. 需要唯一键或隐藏元数据用 Symbol
2. 自定义可迭代对象实现 Symbol.iterator
3. 精确类型判断用 Symbol.toStringTag + toString.call
4. 跨模块共享 Symbol 用 Symbol.for 注册表
5. 控制类型转换用 Symbol.toPrimitive

### 踩坑记录

```text
坑 1：Symbol 属性被 for...in 忽略
结论：Symbol 键的属性遍历不到。
原因：普通 Symbol 属性不可枚举。
解法：用 Object.getOwnPropertySymbols 获取。

坑 2：Symbol 不能 new
结论：new Symbol() 报 TypeError。
原因：Symbol 是原始值，非构造函数。
解法：直接 Symbol() 调用。

坑 3：JSON.stringify 忽略 Symbol 键
结论：Symbol 键的属性不进 JSON。
原因：JSON 序列化只处理字符串键。
解法：需要序列化时用字符串键或自定义 toJSON。

坑 4：Symbol.for 与 Symbol 混用
结论：Symbol.for('x') === Symbol('x') 为 false。
原因：Symbol.for 查注册表，Symbol 总是新建。
解法：统一用 Symbol.for 做跨模块共享，Symbol 做局部唯一。

坑 5：忘了 Symbol.iterator 导致不可迭代
结论：for...of 自定义对象报错。
原因：对象没有 Symbol.iterator 方法。
解法：实现 Symbol.iterator（或继承可迭代对象）。
```
