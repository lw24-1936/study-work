## 概述

class 是 ES6 引入的面向对象语法，本质是**原型继承的语法糖**——底层仍是函数 + 原型链，但提供了更清晰的写法。

```text
class 的本质：
class Person {} 等价于 function Person() {} + 原型方法
class 只是更友好的封装，没有引入新的继承模型。

特性：
1. 更直观的构造、继承、静态成员语法
2. 支持私有字段、getter/setter、static
3. 底层仍是原型链（extends 也走原型）
```

## class 声明

class 声明类，用 new 创建实例。类声明**不会提升**（与函数声明不同）。

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}

const p = new Person('Alice');
p.sayHi();                    // 'Hi, Alice'
```

```text
class 与 function 的区别：
1. 类声明不提升（函数声明会提升）
2. 类体默认严格模式
3. 类方法不可枚举
4. 类不能用 call 等方式调用（必须 new）
5. 类表达式、类字段等新特性
```

```js
// 类表达式
const Point = class {
  constructor(x, y) { this.x = x; this.y = y; }
};
```

## constructor 构造函数

constructor 是类实例化时执行的特殊方法，用于初始化实例属性。

```js
class User {
  constructor(name, age) {
    this.name = name;    // 实例属性
    this.age = age;
  }
}

const u = new User('Alice', 30);
u.name;                  // 'Alice'
```

```text
constructor 要点：
1. 每个类只能有一个 constructor
2. 不写 constructor 时，默认是 constructor() {}
3. 实例属性建议在 constructor 中初始化
4. 类字段（class fields）可在类体内直接声明
```

```js
// 类字段（ES2022）：直接声明，无需 constructor
class User {
  name = 'default';      // 实例字段
  #secret = 42;          // 私有字段
}
```

## extends 与 super

extends 实现继承，super 用于调用父类的构造函数或方法。

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);          // 调用父类构造函数（必须，且在 this 之前）
    this.breed = breed;
  }
  speak() {
    return `${super.speak()} — woof`;   // 调用父类方法
  }
}

const d = new Dog('wang', 'husky');
d.speak();                // 'wang makes a sound — woof'
```

```text
super 的两个用途：
1. super(args) —— 调用父类构造函数（子类构造函数内，必须在 this 前）
2. super.method() —— 调用父类的方法

关键规则：
子类写了 constructor，就必须先调用 super()，否则访问 this 报错。
```

## static 静态成员

static 定义类级别的属性和方法，通过**类本身**访问，而非实例。

```js
class MathUtil {
  static PI = 3.14159;              // 静态字段

  static square(n) {
    return n * n;
  }
}

MathUtil.square(4);     // 16（通过类访问）
MathUtil.PI;            // 3.14159

const m = new MathUtil();
// m.square(4);         // TypeError（静态方法不在实例上）
```

```text
static 的用途：
1. 工具方法 —— 与实例无关的纯函数（如 Math 的静态方法）
2. 工厂方法 —— 返回实例的静态方法
3. 常量 —— 类级别的共享常量
```

```js
class User {
  static fromJSON(json) {
    return new User(json.name);
  }
}
const u = User.fromJSON({ name: 'Alice' });
```

## Private Field 私有字段

ES2022 引入 `#` 前缀的私有字段/方法，实现真正的封装（外部无法访问）。

```js
class BankAccount {
  #balance = 0;              // 私有字段

  deposit(amount) {
    this.#balance += amount;
  }

  #validate(amount) {        // 私有方法
    return amount > 0;
  }

  getBalance() {
    return this.#balance;
  }
}

const acc = new BankAccount();
acc.deposit(100);
acc.getBalance();            // 100
// acc.#balance;             // SyntaxError（外部无法访问）
```

```text
私有字段特性：
1. # 前缀 —— 声明与访问都必须带 #
2. 真正私有 —— 外部、子类都无法访问
3. 与 TS 的 private 不同 —— TS 是编译期检查，JS 私有字段是运行时真隔离
```

```js
// 私有字段 vs 命名约定（_balance 只是约定，仍可访问）
class A {
  _balance = 0;      // 约定私有，但 a._balance 仍能访问
  #secret = 1;       // 真私有，外部无法访问
}
```

## getter 与 setter

getter/setter 定义访问器属性，在读写属性时执行逻辑，实现受控访问。

```js
class Temperature {
  constructor(celsius) {
    this._celsius = celsius;
  }

  get celsius() {
    return this._celsius;
  }

  set celsius(value) {
    if (value < -273.15) throw new Error('低于绝对零度');
    this._celsius = value;
  }

  get fahrenheit() {
    return this._celsius * 9 / 5 + 32;   // 派生属性
  }
}

const t = new Temperature(20);
t.celsius;              // 20（getter）
t.fahrenheit;           // 68（派生）
t.celsius = 30;         // setter（校验通过）
```

```text
getter/setter 的用途：
1. 校验 —— setter 中校验值的合法性
2. 派生值 —— getter 计算派生属性（如 fahrenheit）
3. 受控访问 —— 隐藏内部存储（_celsius）
```

## Mixin 混入

Mixin 是一种「组合式」复用方式，把多个对象的功能「混入」类，弥补单继承的不足。

```js
// 定义 mixin（接收类，返回增强后的类）
const SerializableMixin = Base => class extends Base {
  toJSON() {
    return JSON.stringify(this);
  }
};

const TimestampMixin = Base => class extends Base {
  timestamp() {
    return Date.now();
  }
};

class Model {
  constructor(name) { this.name = name; }
}

// 组合多个 mixin
class EnhancedModel extends SerializableMixin(TimestampMixin(Model)) {}

const m = new EnhancedModel('user');
m.toJSON();        // '{"name":"user"}'
m.timestamp();     // 时间戳
```

```text
Mixin 的意义：
1. 多继承替代 —— 组合多个功能，绕过单继承限制
2. 代码复用 —— 通用能力（序列化、日志、时间戳）抽成 mixin
3. 与继承互补 —— 继承表达「是什么」，mixin 表达「有什么能力」
```

## 应用场景实战

### 场景一：带校验的数据模型

```js
class User {
  #name;
  constructor(name) {
    this.name = name;      // 走 setter 校验
  }
  get name() { return this.#name; }
  set name(v) {
    if (!v || v.length < 2) throw new Error('名字太短');
    this.#name = v;
  }
}
```

### 场景二：继承 + 静态工厂

```js
class Shape {
  static create(type, ...args) {
    const map = { circle: Circle, rect: Rect };
    return new map[type](...args);
  }
  area() { return 0; }
}

class Circle extends Shape {
  constructor(r) { super(); this.r = r; }
  area() { return Math.PI * this.r ** 2; }
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 需要封装用 # 私有字段，别依赖 _ 命名约定
2. 子类构造函数先 super()，再访问 this
3. 工具方法用 static，与实例状态解耦
4. 校验逻辑放 setter，派生值放 getter
5. 多能力组合用 mixin，继承表达 is-a 关系

### 踩坑记录

```text
坑 1：子类构造函数忘调 super
结论：访问 this 报 ReferenceError。
原因：子类有 constructor 就必须先 super()。
解法：constructor 第一行 super(...)。

坑 2：类声明不提升
结论：在类声明前 new 报 ReferenceError。
原因：类声明与 let 类似，存在 TDZ。
解法：类定义在使用之前。

坑 3：误以为 class 是全新模型
结论：期望 class 有传统 OOP 的全部特性（如方法重载）。
原因：class 是原型继承语法糖，无重载等特性。
解法：理解原型底层，用 JS 方式（默认参数等）实现。

坑 4：私有字段用 # 位置写错
结论：this.#x 和 #x 混淆，访问报错。
原因：声明 #x，访问必须 this.#x。
解法：私有字段声明与访问都带 #。

坑 5：静态方法里用 this 指向实例
结论：静态方法内 this 指向类而非实例。
原因：static 方法 this 是类本身。
解法：静态方法不访问实例属性，或用实例方法。
```
