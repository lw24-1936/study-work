## 概述

原型（Prototype）是 JavaScript 实现继承与属性共享的机制。每个对象都有一个内部原型，属性查找会沿原型链向上，直到找到或到达 null。

```text
原型相关的关键概念：
prototype —— 函数对象特有的属性（new 时作为实例的原型）
__proto__ —— 对象的内部原型（建议用 Object.getPrototypeOf 访问）
constructor —— 原型对象上的属性，指回构造函数
原型链 —— 通过原型连接的对象链条，用于属性查找
```

## prototype 属性

只有**函数对象**才有 prototype 属性。当函数用 new 调用时，新实例的原型指向该函数的 prototype。

```js
function Person(name) {
  this.name = name;
}

// 在 prototype 上定义共享方法
Person.prototype.sayHi = function() {
  return `Hi, ${this.name}`;
};

const p1 = new Person('Alice');
const p2 = new Person('Bob');

p1.sayHi();          // 'Hi, Alice'
p2.sayHi();          // 'Hi, Bob'
p1.sayHi === p2.sayHi;   // true（方法共享，不重复创建）
```

```text
prototype 的价值：
1. 方法共享 —— 所有实例共用 prototype 上的方法，节省内存
2. 实现继承 —— 子类通过原型链继承父类
3. 动态扩展 —— 运行时可给 prototype 加方法，所有实例立即可用
```

## __proto__ 与 constructor

__proto__ 是对象的内部原型访问器，constructor 是 prototype 上指向构造函数的属性。

```js
function Person(name) { this.name = name; }
const p = new Person('Alice');

p.__proto__ === Person.prototype;            // true（实例原型指向构造函数的 prototype）
Object.getPrototypeOf(p) === Person.prototype;  // true（推荐写法）

Person.prototype.constructor === Person;     // true（constructor 指回构造函数）
```

```text
三者关系（以 new Person() 为例）：
p.__proto__ → Person.prototype
Person.prototype.constructor → Person
Person.prototype.__proto__ → Object.prototype
```

```text
为什么建议 Object.getPrototypeOf：
1. __proto__ 是历史遗留的访问器，可被篡改
2. Object.getPrototypeOf 是标准方法，语义清晰
3. Object.create(null) 的对象没有 __proto__
```

## Prototype Chain 原型链

原型链是对象之间通过原型连接形成的链条。访问属性时，从对象自身开始沿链向上查找。

```js
function Animal(name) { this.name = name; }
Animal.prototype.eat = function() { return `${this.name} is eating`; };

const dog = new Animal('dog');

// 查找链：dog → Animal.prototype → Object.prototype → null
dog.eat();                 // 从 Animal.prototype 找到
dog.toString();            // 从 Object.prototype 找到
```

```text
原型链查找规则：
1. 先查对象自身属性
2. 没有则查 __proto__（原型）
3. 一路向上到 Object.prototype
4. 到 null 还没找到 → undefined

hasOwnProperty 可判断属性是否在自身（非原型链）。
```

```js
dog.hasOwnProperty('name');      // true（自身属性）
dog.hasOwnProperty('eat');       // false（原型链上的方法）
```

```text
原型链的终点：
所有普通对象的原型链最终都指向 Object.prototype，其原型是 null。
```

```js
Object.getPrototypeOf(Object.prototype);   // null（链的终点）
```

## Inheritance 继承

JavaScript 通过原型链实现继承。组合式继承（call + 原型链）是经典方案，ES6 的 class extends 是其语法糖。

```js
// 组合式继承：借用构造函数 + 原型链
function Animal(name) {
  this.name = name;
}
Animal.prototype.eat = function() { return `${this.name} eats`; };

function Dog(name, breed) {
  Animal.call(this, name);     // 1. 借用构造函数继承属性
  this.breed = breed;
}

Dog.prototype = Object.create(Animal.prototype);  // 2. 原型链继承方法
Dog.prototype.constructor = Dog;                   // 3. 修正 constructor

Dog.prototype.bark = function() { return 'woof'; };

const d = new Dog('wang', 'husky');
d.eat();      // 'wang eats'（继承自 Animal）
d.bark();     // 'woof'
d instanceof Dog;     // true
d instanceof Animal;  // true
```

```text
组合式继承的两步：
1. 继承属性 —— 子类构造函数内 call 父类（复制父类实例属性）
2. 继承方法 —— 子类 prototype 指向 Object.create(父类 prototype)
```

```js
// ES6 class extends（语法糖，底层仍是原型链）
class Animal {
  constructor(name) { this.name = name; }
  eat() { return `${this.name} eats`; }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);              // 调用父类构造函数
    this.breed = breed;
  }
  bark() { return 'woof'; }
}

const d = new Dog('wang', 'husky');
d.eat();                      // 'wang eats'
```

## Object.create 原型式继承

Object.create 以指定对象为原型创建新对象，是「原型式继承」的原生实现。

```js
const animal = {
  eat() { return `${this.name} eats`; },
};

// 以 animal 为原型创建新对象
const dog = Object.create(animal);
dog.name = 'wang';

dog.eat();              // 'wang eats'（从原型 animal 找到）
Object.getPrototypeOf(dog) === animal;   // true
```

```js
// 原型式继承的封装（Object.create 的常见用法）
function inheritFrom(proto) {
  return Object.create(proto);
}

const cat = Object.create(animal);
cat.name = 'mimi';
cat.eat();              // 'mimi eats'
```

```text
Object.create 的用途：
1. 原型式继承 —— 以任意对象为原型创建对象
2. Object.create(null) —— 创建无原型对象（纯字典，防污染）
3. 设定原型 —— 替代直接操作 __proto__
```

## 应用场景实战

### 场景一：给内置类型扩展方法（慎用）

```js
// 给数组原型加方法（实际项目慎用，可能冲突）
Array.prototype.last = function() {
  return this[this.length - 1];
};

[1, 2, 3].last();    // 3
```

### 场景二：实现简单的继承关系

```js
function Shape(name) {
  this.name = name;
}
Shape.prototype.area = function() { return 0; };

function Circle(name, r) {
  Shape.call(this, name);
  this.r = r;
}
Circle.prototype = Object.create(Shape.prototype);
Circle.prototype.constructor = Circle;
Circle.prototype.area = function() { return Math.PI * this.r * this.r; };

const c = new Circle('circle', 2);
c.area();            // 12.566...
```

## 最佳实践与踩坑记录

### 最佳实践

1. 新代码用 class extends，底层仍是原型链
2. 访问原型用 Object.getPrototypeOf，不用 __proto__
3. 判断自有属性用 Object.hasOwn，别依赖 hasOwnProperty
4. 原型链继承时记得修正 constructor
5. 数据字典用 Map 或 Object.create(null) 防污染

### 踩坑记录

```text
坑 1：直接赋值 prototype 破坏原型链
结论：Dog.prototype = Animal.prototype 后，改 Dog 方法影响 Animal。
原因：二者指向同一对象，共享原型。
解法：用 Object.create(Animal.prototype) 创建新对象。

坑 2：忘修正 constructor
结论：d.constructor 指向 Animal 而非 Dog。
原因：替换 prototype 后 constructor 丢失。
解法：Dog.prototype.constructor = Dog。

坑 3：遍历含原型属性的 for...in
结论：for...in 遍历出原型链上的属性。
原因：for...in 遍历可枚举属性（含原型链）。
解法：Object.keys + for...of，或 hasOwn 过滤。

坑 4：给内置原型加方法引发冲突
结论：Array.prototype.foo 与未来标准或库冲突。
原因：全局污染，可能被覆盖或覆盖他人。
解法：避免修改内置原型，用工具函数或 Symbol 键。

坑 5：Object.create(null) 无 hasOwnProperty
结论：无原型对象调用 hasOwnProperty 报错。
原因：原型为 null，没有继承 Object.prototype。
解法：用 Object.hasOwn(obj, key) 静态方法。
```
