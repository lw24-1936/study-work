## 概述

Window 是浏览器环境（BOM）的全局对象，代表浏览器窗口，是访问所有 Web API 的入口。它是 BOM（Browser Object Model）的核心。

```text
Window 的核心属性（BOM 五大对象）：
window —— 窗口自身（全局对象）
location —— 当前 URL
history —— 浏览历史
navigator —— 浏览器/设备信息
screen —— 屏幕信息
document —— 文档（DOM 入口）
```

## window 全局对象

window 是全局对象，全局变量、函数都是它的属性。窗口相关的 API 也挂在这里。

```js
// window 是全局对象
window.alert === alert;        // true
var x = 1;                     // var 声明的全局变量挂到 window
window.x;                      // 1（let/const 不挂）

// 窗口尺寸
window.innerWidth;             // 视口宽度
window.innerHeight;            // 视口高度
```

```js
// 窗口操作
window.open('https://example.com');   // 打开新窗口
window.close();                       // 关闭窗口（脚本打开的才能关）
window.scrollTo(0, 100);              // 滚动到指定位置
```

```js
// 对话框（会阻塞，少用）
alert('提示');
confirm('确定吗？');            // 返回 true/false
prompt('输入：');               // 返回输入值
```

```text
window 的职责：
1. 全局作用域 —— 全局变量、函数挂在这里
2. 窗口操作 —— 尺寸、滚动、打开关闭
3. 定时器 —— setTimeout、setInterval
4. 对话框 —— alert、confirm、prompt（阻塞，少用）
```

## location 地址对象

location 表示当前 URL，可读写，控制页面跳转（详见 [[17.2-Location]]）。

```js
window.location.href;         // 当前完整 URL
location.href = '/new-page';  // 跳转
location.reload();            // 刷新
```

## history 历史对象

history 管理浏览历史，支持 SPA 的路由切换（详见 [[17.3-History]]）。

```js
history.back();               // 后退
history.forward();            // 前进
history.pushState(null, '', '/page');   // SPA 添加历史记录
```

## navigator 浏览器信息

navigator 提供浏览器、设备、网络等信息。

```js
// 浏览器信息
navigator.userAgent;          // UA 字符串
navigator.language;           // 语言（'zh-CN'）
navigator.platform;           // 平台

// 网络状态
navigator.onLine;             // 是否在线

// 剪贴板/权限等 API 入口
navigator.clipboard;          // 剪贴板 API
navigator.geolocation;        // 地理位置
```

```js
// 现代特性检测（替代 UA 嗅探）
navigator.userAgentData?.mobile;   // 是否移动端
```

```text
navigator 的用途：
1. 环境信息 —— 语言、平台、UA
2. API 入口 —— clipboard、geolocation、mediaDevices
3. 网络状态 —— onLine、connection

注意：UA 嗅探不可靠，优先特性检测。
```

## screen 屏幕信息

screen 提供屏幕的物理信息。

```js
screen.width;          // 屏幕宽度（像素）
screen.height;         // 屏幕高度
screen.availWidth;     // 可用宽度（减去系统栏）
screen.colorDepth;     // 色深
```

```text
screen 的用途：
1. 获取屏幕尺寸（响应式布局参考）
2. 窗口定位（多显示器场景）
```

## document 文档对象

document 是 DOM 的入口，代表整个文档（详见 [[15.1-DOM 树]]）。

```js
document.title;           // 页面标题
document.body;            // body 元素
document.head;            // head 元素
document.readyState;      // 加载状态
document.URL;             // 文档 URL
```

## 应用场景实战

### 场景一：检测用户语言

```js
function getUserLanguage() {
  return navigator.language || navigator.userLanguage || 'en';
}
// 'zh-CN'
```

### 场景二：页面跳转与刷新

```js
// 跳转到新页面（可后退）
location.href = '/dashboard';

// 替换当前页面（不可后退）
location.replace('/login');

// 刷新
location.reload();
```

## 最佳实践与踩坑记录

### 最佳实践

1. 全局变量用 let/const（不挂 window），避免污染全局
2. 跳转用 location，SPA 路由用 history.pushState
3. 环境判断用特性检测，别用 UA 嗅探
4. 对话框（alert/confirm）阻塞主线程，生产环境少用
5. 语言获取用 navigator.language，配合 Intl 格式化

### 踩坑记录

```text
坑 1：var 全局变量污染 window
结论：var 声明的全局变量挂在 window，与 window 属性冲突。
原因：var 在全局作用域声明会变成 window 属性。
解法：用 let/const（不挂 window）。

坑 2：依赖 UA 判断浏览器
结论：UA 嗅探误判、易伪造。
原因：UA 字符串不可靠。
解法：用特性检测（如 'fetch' in window）。

坑 3：alert 阻塞主线程
结论：alert 弹出后脚本暂停，体验差。
原因：alert 是同步阻塞对话框。
解法：用自定义弹窗组件替代。

坑 4：innerWidth 与 clientWidth 混淆
结论：取页面宽度拿错值。
原因：innerWidth 是视口（含滚动条），clientWidth 是元素内容区。
解法：视口用 window.innerWidth，元素用 el.clientWidth。

坑 5：window.open 被浏览器拦截
结论：非用户手势触发的 open 被弹窗拦截。
原因：浏览器拦截非用户操作的弹窗。
解法：在用户点击事件里同步调用 open。
```
