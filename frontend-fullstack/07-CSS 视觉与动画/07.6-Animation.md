## 概述

Animation（关键帧动画）是 CSS 最强大的动画能力，用 @keyframes 定义动画的多个阶段，实现复杂、循环、自动播放的动画。相比 Transition 的「A 到 B」，Animation 能「A 到 B 到 C 再回 A」，是加载动画、循环动效的实现方式。

```text
Animation vs Transition：
Transition —— 状态切换（A → B），需触发，简单
Animation —— 关键帧（多阶段），可自动播放、循环，复杂

选择：简单 hover 用 transition，复杂/循环/自动播放用 animation。
```

## @keyframes 关键帧

@keyframes 定义动画的各个阶段：

```css
@keyframes slide-in {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}
```

```text
@keyframes 的语法：
@keyframes 动画名 {
  from { ... }      /* 0% 的别名 */
  to { ... }        /* 100% 的别名 */
  或
  0% { ... }
  50% { ... }
  100% { ... }
}
```

```css
/* 多阶段关键帧 */
@keyframes pulse {
  0% { transform: scale(1); }
  50% { transform: scale(1.2); }
  100% { transform: scale(1); }
}
```

```text
关键帧的要点：
1. 每个阶段定义一组 CSS 属性
2. 阶段之间的属性自动插值（过渡）
3. 0% 和 100% 可省略（用元素本身的状态）
```

## animation-name 与 animation-duration

### animation-name 动画名

指定应用哪个 @keyframes：

```css
.box {
  animation-name: slide-in;
}
```

### animation-duration 动画时长

指定动画一次循环的时长：

```css
.box {
  animation-duration: 0.5s;
  animation-duration: 2s;
}
```

## animation-delay 与 animation-iteration-count

### animation-delay 延迟

动画开始前的延迟：

```css
.box {
  animation-delay: 1s;   /* 延迟 1 秒开始 */
  animation-delay: -0.5s; /* 负值：从动画中途开始 */
}
```

### animation-iteration-count 循环次数

动画的循环次数：

```css
.box {
  animation-iteration-count: 1;        /* 1 次（默认） */
  animation-iteration-count: 3;        /* 3 次 */
  animation-iteration-count: infinite; /* 无限循环 */
}
```

## animation-direction 与 animation-fill-mode

### animation-direction 播放方向

动画循环时的播放方向：

```css
.box {
  animation-direction: normal;            /* 正向（默认） */
  animation-direction: reverse;           /* 反向 */
  animation-direction: alternate;         /* 正反交替（往返） */
  animation-direction: alternate-reverse; /* 反正交替 */
}
```

```text
animation-direction 的用途：
alternate —— 往返动画（如呼吸、摇摆），配合 infinite 使用。
```

### animation-fill-mode 填充模式

控制动画「开始前」和「结束后」的状态：

```css
.box {
  animation-fill-mode: none;       /* 默认，不填充 */
  animation-fill-mode: forwards;   /* 结束后保持最终状态 */
  animation-fill-mode: backwards;  /* 延迟期间应用起始状态 */
  animation-fill-mode: both;       /* 前后都填充（最常用） */
}
```

```text
fill-mode 的关键：
forwards —— 动画结束后停在「最后一帧」（to 的状态）
backwards —— 动画延迟期间就应用「第一帧」（from 的状态）
both —— 两者都（最常用）

没设 fill-mode，动画结束后元素「跳回」原始状态。
```

## animation-play-state 播放状态

控制动画的播放/暂停：

```css
.box {
  animation-play-state: running;  /* 播放（默认） */
  animation-play-state: paused;   /* 暂停 */
}
```

```text
play-state 的用途：
1. 悬停暂停动画
2. JS 控制动画暂停/恢复
```

```css
/* 悬停暂停动画 */
.loading {
  animation: spin 1s linear infinite;
}
.loading:hover {
  animation-play-state: paused;
}
```

## animation 简写

animation 简写一次性设置所有参数：

```css
.box {
  animation: slide-in 0.5s ease 0.1s 3 alternate both;
  /*         name      duration timing delay count direction fill-mode */
  animation: spin 1s linear infinite;  /* 最简写法 */
}
```

```text
animation 简写顺序：
animation: name duration timing-function delay iteration-count direction fill-mode play-state;

第一个「时间」是 duration，第二个是 delay。
```

## 应用场景实战

### 场景一：加载转圈（spinner）

```css
@keyframes spin {
  to { transform: rotate(360deg); }
}
.loading {
  width: 40px;
  height: 40px;
  border: 4px solid #eee;
  border-top-color: #0066cc;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
```

### 场景二：淡入上移动画（入场）

```css
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
.element {
  animation: fade-in-up 0.5s ease-out both;
}
```

### 场景三：呼吸/脉冲动画

```css
@keyframes breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.1); }
}
.dot {
  animation: breathe 2s ease-in-out infinite;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 动画只动 transform 和 opacity（GPU 加速，性能好）
2. 入场动画用 both（前后填充，避免闪跳）
3. 循环动画注意 respects prefers-reduced-motion
4. 无限循环动画提供暂停方式（play-state）
5. 动画时长合理（交互 0.3s，展示 0.5~2s）

### 踩坑记录

```text
坑 1：动画结束后跳回原状态
结论：动画播完元素「闪」回原始样式。
原因：没设 animation-fill-mode: forwards/both。
解法：需要停在结束态加 fill-mode: forwards 或 both。

坑 2：忘记配 reduced-motion
结论：对动画敏感的用户不适。
原因：动画没响应系统的「减少动态效果」设置。
解法：加 @media (prefers-reduced-motion: reduce) 关闭/减弱动画。

坑 3：动画 name 和 @keyframes 名不一致
结论：动画不播放。
原因：animation-name 引用的 keyframes 名拼写不一致。
解法：核对动画名（区分大小写）。

坑 4：简写里 duration 和 delay 位置搞反
结论：动画延迟时间异常。
原因：简写里第一个时间是 duration，第二个是 delay。
解法：animation: name 1s 2s（1s 时长，2s 延迟），顺序记牢。

坑 5：动画属性用 width/height 导致卡顿
结论：动画掉帧、卡顿。
原因：width/height 触发重排，不 GPU 加速。
解法：用 transform: scale 替代尺寸动画。
```
