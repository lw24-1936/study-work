## 概述

文本样式是排版的基础，从字体、字号、行高，到对齐、换行、溢出处理。前端常见的问题——文字溢出、长英文撑破布局、行高继承——都源于文本属性的细节。这篇笔记覆盖文本样式的完整知识。

```text
文本样式的三类：
1. 字体 —— font-family、font-size、font-weight（长什么样）
2. 排版 —— line-height、letter-spacing、text-align（怎么排）
3. 换行溢出 —— white-space、text-overflow、word-break（怎么断行）
```

## 字体：font-family、font-size、font-weight

### font-family

字体族，按优先级列出，浏览器用第一个可用的：

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
    "Microsoft YaHei", sans-serif;
}
```

```text
font-family 的规则：
1. 多个字体逗号分隔，从左到右按优先级
2. 字体名含空格要加引号（"Segoe UI"）
3. 最后加「通用族」（serif/sans-serif/monospace）兜底
```

```text
字体栈的设计（中英文混排）：
英文优先（系统 UI 字体），中文兜底（PingFang SC/微软雅黑），
最后通用族 sans-serif。
```

### font-size

字号，用 rem（相对根字号）或 px：

```css
body { font-size: 16px; }
h1 { font-size: 2rem; }  /* 32px */
```

### font-weight

字重（粗细）：

```css
.text { font-weight: 400; }   /* 正常 */
.title { font-weight: 600; }  /* 半粗 */
.bold { font-weight: 700; }   /* 粗体 */
```

```text
font-weight 的取值：
100~900（数字），常见：
400 —— 正常（normal）
500 —— 中等
600 —— 半粗
700 —— 粗体（bold）

或关键字：normal（400）、bold（700）
```

## 行高与字距：line-height、letter-spacing、word-spacing

### line-height

行高，控制文字行间距：

```css
.text {
  line-height: 1.6;   /* 无单位，相对自身字号（推荐） */
  line-height: 24px;  /* 固定像素 */
}
```

```text
line-height 的取值：
无单位数字（1.6）—— 推荐，相对自身字号，继承时正确缩放
px —— 固定，字号变化时行高不跟着变

正文建议 1.5~1.7，标题 1.2~1.4。
```

```text
无单位 vs 有单位的坑：
line-height: 1.6 —— 继承的是「1.6 这个比例」，子元素按自身字号计算
line-height: 1.6em/24px —— 继承的是「计算后的固定值」，子元素字号变了行高不变
```

### letter-spacing 与 word-spacing

```css
.text {
  letter-spacing: 0.5px;  /* 字间距（字母/汉字间） */
  word-spacing: 2px;      /* 词间距（单词间，英文） */
}
```

```text
letter-spacing —— 字符之间的间距（中英文都适用）
word-spacing —— 单词之间的间距（主要英文）

用途：标题加字距更精致，正文默认即可。
```

## 对齐：text-align

text-align 控制文本水平对齐：

```css
.text {
  text-align: left;     /* 左对齐（默认） */
  text-align: center;   /* 居中 */
  text-align: right;    /* 右对齐 */
  text-align: justify;  /* 两端对齐 */
}
```

```text
text-align 的注意点：
1. 只对「块级容器内的行内内容」生效
2. 对 flex/grid 布局无效（要用 justify-content）
3. 居中图片用 text-align: center（图片是行内元素）
```

## 换行与溢出：white-space、text-overflow、word-break、overflow-wrap

### white-space

控制空白和换行的处理：

```css
.text {
  white-space: normal;    /* 默认，空白折叠，自动换行 */
  white-space: nowrap;    /* 不换行（配合省略号） */
  white-space: pre;       /* 保留空白和换行（像 pre 标签） */
  white-space: pre-wrap;  /* 保留空白，自动换行 */
}
```

```text
white-space 常用值：
normal —— 空白折叠 + 自动换行（默认）
nowrap —— 不换行（单行省略的基础）
pre —— 保留所有空白和换行
pre-wrap —— 保留空白 + 自动换行
```

### text-overflow

控制溢出文本的显示（配合 overflow + nowrap）：

```css
.ellipsis {
  white-space: nowrap;      /* 不换行 */
  overflow: hidden;         /* 裁剪 */
  text-overflow: ellipsis;  /* 省略号 */
}
```

```text
单行省略的三件套（缺一不可）：
white-space: nowrap + overflow: hidden + text-overflow: ellipsis
```

### word-break

控制单词内断行（对长英文/URL 重要）：

```css
.text {
  word-break: break-all;   /* 任意位置断行（可能拆单词） */
  word-break: break-word;  /* 优先完整单词，必要时拆 */
}
```

```text
word-break 的用途：
长英文单词、长 URL 不换行会撑破布局，
word-break: break-all 强制在任意位置断行。
```

### overflow-wrap

溢出时是否断行（原名 word-wrap）：

```css
.text {
  overflow-wrap: break-word;  /* 长单词溢出时断行 */
}
```

```text
word-break vs overflow-wrap（区别）：
word-break: break-all —— 无条件在任意位置断（可能拆短词）
overflow-wrap: break-word —— 只在「一个单词太长溢出」时才断（更保守）

推荐：优先 overflow-wrap: break-word（少破坏单词），
      URL/长串才用 word-break: break-all。
```

## 应用场景实战

### 场景一：单行 + 多行省略

```css
/* 单行省略 */
.ellipsis-1 {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* 多行省略（2 行） */
.ellipsis-2 {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

### 场景二：长 URL/英文不撑破布局

```css
.content {
  overflow-wrap: break-word;  /* 长单词断行 */
  word-break: break-all;      /* URL 等长串也断 */
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. line-height 用无单位值（1.6），避免继承问题
2. 正文 line-height 1.5~1.7，标题 1.2~1.4
3. 字体栈英文优先 + 中文兜底 + 通用族
4. 长英文/URL 用 overflow-wrap: break-word 防撑破
5. 单行省略用「nowrap + hidden + ellipsis」三件套

### 踩坑记录

```text
坑 1：line-height 用 em/px 导致继承失真
结论：子元素字号变化，行高却不跟着变，间距失调。
原因：line-height: 1.6em 继承的是计算后的固定值。
解法：用无单位 line-height: 1.6。

坑 2：单行省略缺一不可
结论：设了 text-overflow: ellipsis 没省略号。
原因：缺少 white-space: nowrap 或 overflow: hidden。
解法：三件套齐全（nowrap + hidden + ellipsis）。

坑 3：长英文单词撑破布局
结论：长 URL/单词溢出容器，横向滚动。
原因：默认不拆单词，长单词不换行。
解法：overflow-wrap: break-word 或 word-break: break-all。

坑 4：text-align 对 flex 子元素无效
结论：flex 容器里 text-align: center 没居中。
原因：text-align 只对行内内容，flex 布局用 justify-content。
解法：flex 布局居中用 justify-content/align-items。

坑 5：中文字体栈顺序错误
结论：中文页面显示成奇怪的字体。
原因：中文兜底字体（PingFang/雅黑）没放在合适位置。
解法：英文 UI 字体在前，中文兜底在中，通用族在后。
```
