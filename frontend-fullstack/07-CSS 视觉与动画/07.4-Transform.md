## 概述

transform 对元素做「变换」——位移、旋转、缩放、倾斜，是 CSS 动画的基础。transform 的独特之处在于它只改变「视觉呈现」，不改变「布局」——元素变换后仍占原来的空间，且由 GPU 合成，性能极佳。

```text
transform 的四种变换：
translate —— 位移
rotate —— 旋转
scale —— 缩放
skew —— 倾斜

关键特性：不影响布局（视觉变换），GPU 加速（性能好）。
```

```text
transform 不触发重排（关键）：
transform 只改变「合成层」，不触发 Layout/Paint，
是高性能动画的首选属性（详见 07.7-CSS 性能）。
```

## translate 位移

translate 移动元素位置：

```css
.box {
  transform: translate(50px, 20px);   /* 水平 50，垂直 20 */
  transform: translateX(50px);         /* 只水平 */
  transform: translateY(20px);         /* 只垂直 */
  transform: translate(-50%, -50%);    /* 百分比相对自身 */
}
```

```text
translate 的特点：
1. 不影响布局（元素仍占原位）
2. 百分比相对「自身尺寸」（不是父元素）
3. translate(-50%, -50%) 是居中的经典用法
```

```css
/* 水平垂直居中（translate 相对自身） */
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## rotate 旋转

rotate 旋转元素：

```css
.box {
  transform: rotate(45deg);   /* 顺时针旋转 45 度 */
  transform: rotate(-45deg);  /* 逆时针 */
}
```

```text
rotate 的用法：
正角度顺时针，负角度逆时针。
配合 transform-origin 控制旋转中心。
```

```css
/* 悬停旋转 180 度（配合 transition） */
.icon {
  transition: transform 0.3s;
}
.icon:hover {
  transform: rotate(180deg);
}
```

## scale 缩放

scale 缩放元素：

```css
.box {
  transform: scale(1.5);      /* 放大 1.5 倍 */
  transform: scale(0.5);      /* 缩小到 0.5 倍 */
  transform: scale(1.5, 2);   /* 水平 1.5，垂直 2 */
  transform: scaleX(1.5);     /* 只水平 */
}
```

```text
scale 的用法：
1 为原大小，>1 放大，<1 缩小。
悬停放大（hover 效果）、图片缩放常用。
```

## skew 倾斜

skew 倾斜元素（平行四边形效果）：

```css
.box {
  transform: skew(10deg);      /* 水平倾斜 */
  transform: skew(10deg, 20deg); /* 水平 10，垂直 20 */
  transform: skewX(10deg);
  transform: skewY(10deg);
}
```

```text
skew 的用途：
1. 平行四边形标签/按钮
2. 斜切视觉设计
（现代设计里 skew 用得较少，rotate/scale 更常用）
```

## transform-origin 变换原点

transform-origin 设置变换的基准点（旋转中心、缩放中心）：

```css
.box {
  transform-origin: center;       /* 中心（默认） */
  transform-origin: top left;     /* 左上角 */
  transform-origin: 50% 50%;      /* 百分比定位 */
  transform: rotate(45deg);
}
```

```text
transform-origin 的影响：
rotate —— 绕哪个点旋转
scale —— 从哪个点缩放

例：transform-origin: left 时旋转，元素绕左边转。
```

## perspective 与 3D transform

### perspective 透视

perspective 给 3D 变换添加「透视深度」（近大远小）：

```css
.container {
  perspective: 500px;  /* 透视距离 */
}
.box {
  transform: rotateY(45deg);  /* 3D 旋转 */
}
```

```text
perspective 的作用：
让 3D 变换有「纵深」效果（近大远小）。
值越小，透视效果越强（越夸张）。
```

### 3D transform

3D 变换在 X/Y 轴基础上加 Z 轴：

```css
.box {
  transform: rotateX(45deg);   /* 绕 X 轴旋转（翻转） */
  transform: rotateY(45deg);   /* 绕 Y 轴旋转（翻书） */
  transform: rotateZ(45deg);   /* 绕 Z 轴（等同 2D rotate） */
  transform: translateZ(50px); /* Z 轴位移（靠近/远离） */
}
```

```text
3D transform 的典型用途：
1. 翻牌效果（rotateY）
2. 卡片翻转（rotateY 180deg）
3. 立体翻转菜单
```

```css
/* 翻牌效果 */
.card {
  transform-style: preserve-3d;  /* 保留 3D 空间 */
  transition: transform 0.6s;
}
.card.flipped {
  transform: rotateY(180deg);
}
.card .back {
  transform: rotateY(180deg);  /* 背面先翻转 */
  backface-visibility: hidden; /* 隐藏背面 */
}
```

## 应用场景实战

### 场景一：悬停缩放 + 居中

```css
/* 悬停放大 */
.card img {
  transition: transform 0.3s;
}
.card:hover img {
  transform: scale(1.1);
}

/* 绝对定位居中 */
.modal-center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 场景二：翻牌效果

```css
.flip-card {
  perspective: 1000px;
}
.flip-inner {
  transform-style: preserve-3d;
  transition: transform 0.6s;
}
.flip-card:hover .flip-inner {
  transform: rotateY(180deg);
}
.flip-front, .flip-back {
  backface-visibility: hidden;
}
.flip-back {
  transform: rotateY(180deg);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 动画用 transform（GPU 加速，不触发重排）
2. 居中用 translate(-50%, -50%)（相对自身，无需知道尺寸）
3. 百分比 translate 相对自身，不是父元素
4. 变换顺序影响结果（rotate 后再 translate 方向不同）
5. 3D 效果配 perspective 和 transform-style: preserve-3d

### 踩坑记录

```text
坑 1：transform 顺序不同结果不同
结论：translate 和 rotate 调换顺序，结果完全不一样。
原因：transform 按「从右到左」应用（矩阵乘法），顺序敏感。
解法：明确变换顺序，理解 rotate 会改变坐标轴方向。

坑 2：translate 百分比基准搞错
结论：translate(50%) 以为是父元素的一半。
原因：translate 百分比相对「自身尺寸」，不是父元素。
解法：记住 translate 百分比是相对自身，居中用 -50%。

坑 3：transform 不影响布局但影响定位
结论：transform 的元素视觉移动了，但绝对定位的「位置」没变。
原因：transform 是视觉变换，不改变布局位置。
解法：需要「真实移动」用 top/left，需要「视觉移动」用 transform。

坑 4：3D 变换没设 perspective 看不出效果
结论：rotateY(45deg) 看起来只是「压扁」，没有立体感。
原因：没设 perspective，3D 变换退化成平面。
解法：父元素设 perspective 给透视深度。

坑 5：transform 创建层叠上下文和 fixed 基准
结论：加了 transform 后，fixed 子元素相对它定位，z-index 行为变化。
原因：transform 创建层叠上下文，并改变 fixed 的包含块。
解法：注意 transform 的副作用（见 05.8-定位与层叠）。
```
