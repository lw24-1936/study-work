## 概述

背景是 CSS 视觉的基础能力，从纯色到图片到渐变，是现代 UI 设计的重要元素。渐变（尤其线性渐变）替代了大量「切图」工作，是高性能 UI 的关键。这篇笔记覆盖背景属性、三种渐变和背景的定位/尺寸/重复。

```text
背景的三类：
1. 纯色 —— background-color
2. 图片 —— background-image
3. 渐变 —— linear/radial/conic-gradient（本质也是 image）
```

## background 简写与 background-image

### background 简写

background 是多个背景属性的简写：

```css
.box {
  background: #f0f0f0 url(bg.jpg) center/cover no-repeat;
  /*        颜色    图片          位置/尺寸  重复 */
}
```

```text
background 简写的顺序（可省略任意项）：
background: color image position/size repeat attachment origin clip;
```

### background-image

background-image 设置背景图片（或渐变）：

```css
.box {
  background-image: url(bg.jpg);
  /* 或渐变 */
  background-image: linear-gradient(to right, red, blue);
}
```

```text
background-image 的要点：
1. 可设多张背景（逗号分隔），先写的在上层
2. 渐变也是 image（linear-gradient 等函数生成）
3. 图片路径相对 CSS 文件
```

## linear-gradient 线性渐变

linear-gradient 沿直线方向的渐变：

```css
.box {
  background: linear-gradient(to right, red, blue);
  /* 从左到右，红变蓝 */
}
```

```text
linear-gradient 的语法：
linear-gradient(方向, 颜色1, 颜色2, ...)

方向：
to right / to left / to top / to bottom（到某方向）
to top right（到右上角）
45deg（角度）
```

```css
/* 多色渐变 + 位置 */
.gradient {
  background: linear-gradient(
    to right,
    red 0%,
    yellow 50%,
    blue 100%
  );
}

/* 条纹（颜色位置相同形成硬边） */
.stripes {
  background: linear-gradient(
    to right,
    #000 0%, #000 50%,
    #fff 50%, #fff 100%
  );
  background-size: 40px 100%;  /* 重复条纹 */
}
```

```text
linear-gradient 的进阶用法：
1. 颜色位置（百分比）控制渐变节奏
2. 相邻色同位置 → 硬边（条纹）
3. 配合 background-size → 斑马纹、条纹图案
```

## radial-gradient 径向渐变

radial-gradient 从中心向外辐射的渐变：

```css
.box {
  background: radial-gradient(circle, red, blue);
  /* 圆形，中心红到边缘蓝 */
}
```

```text
radial-gradient 的语法：
radial-gradient(形状 尺寸 at 位置, 颜色1, 颜色2)

形状：circle（圆）、ellipse（椭圆，默认）
位置：at center、at top left
尺寸：closest-side、farthest-corner 等
```

```css
/* 从左上角发散的径向渐变 */
.spotlight {
  background: radial-gradient(circle at top left, #fff, #ccc);
}
```

## conic-gradient 锥形渐变

conic-gradient 绕中心点旋转的渐变（圆锥形）：

```css
.box {
  background: conic-gradient(red, yellow, green, blue, red);
  /* 绕中心旋转的色环 */
}
```

```text
conic-gradient 的语法：
conic-gradient(from 角度 at 位置, 颜色1, 颜色2)

典型用途：
1. 饼图/环形图
2. 色环
3. 雷达扫描效果
```

```css
/* 饼图（用 conic-gradient + 硬边） */
.pie {
  background: conic-gradient(
    red 0deg 90deg,
    blue 90deg 180deg,
    green 180deg 360deg
  );
  border-radius: 50%;
}
```

```text
三种渐变的对比：
linear-gradient —— 直线方向（背景过渡、条纹）
radial-gradient —— 中心向外（聚光灯、光晕）
conic-gradient —— 绕中心旋转（饼图、色环）
```

## background-size、background-position、background-repeat

### background-size

控制背景图片/渐变的尺寸：

```css
.box {
  background-size: cover;      /* 覆盖容器（可能裁剪） */
  background-size: contain;    /* 完整显示（可能留白） */
  background-size: 100% 100%;  /* 拉伸填满 */
  background-size: 200px 100px; /* 固定尺寸 */
}
```

```text
cover vs contain：
cover —— 铺满容器，超出部分裁剪（保证无空白）
contain —— 完整显示，可能留白（保证完整可见）

全屏背景图用 cover，展示完整图片用 contain。
```

### background-position

控制背景的位置：

```css
.box {
  background-position: center;      /* 居中 */
  background-position: top right;   /* 右上角 */
  background-position: 50% 50%;     /* 百分比定位 */
}
```

```text
background-position 的取值：
关键字 —— center/top/bottom/left/right
百分比/像素 —— 精确定位

配合 background-size: cover 使用（定位裁剪中心）。
```

### background-repeat

控制背景是否重复：

```css
.box {
  background-repeat: no-repeat;  /* 不重复 */
  background-repeat: repeat;     /* 重复（默认） */
  background-repeat: repeat-x;   /* 只水平重复 */
  background-repeat: repeat-y;   /* 只垂直重复 */
}
```

## 应用场景实战

### 场景一：全屏背景图（cover + 居中）

```css
.hero {
  background: url(hero.jpg) center/cover no-repeat;
  /* 居中 + 覆盖 + 不重复 */
}
```

### 场景二：按钮渐变背景

```css
.button {
  background: linear-gradient(to right, #0066cc, #3399ff);
  border: none;
  color: #fff;
}
```

### 场景三：斑马纹表格（渐变 + repeat）

```css
.table-zebra {
  background: repeating-linear-gradient(
    to bottom,
    #f9f9f9 0 40px,
    #ffffff 40px 80px
  );
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 全屏背景图用 cover，展示完整图用 contain
2. 渐变替代切图（性能好、可缩放）
3. 条纹/斑马纹用渐变 + background-size 实现，不用图片
4. background 简写注意顺序（position 在 size 前，用 / 分隔）
5. 多背景用逗号分隔，先写的在上层

### 踩坑记录

```text
坑 1：background 简写里 position/size 顺序写反
结论：background: center/cover 写反成 cover/center 报错。
原因：简写里 position 在前、size 在后，用 / 分隔。
解法：background: url(x.jpg) center/cover no-repeat（position/size）。

坑 2：background-size 百分比相对背景区而非元素
结论：background-size: 50% 不是元素宽度的一半。
原因：百分比相对「背景定位区」，不是元素。
解法：理解百分比基准，或用 px/cover/contain。

坑 3：渐变多颜色没设位置导致不均匀
结论：渐变颜色过渡和预期不符。
原因：没给颜色设位置，默认均匀分布。
解法：需要控制节奏时给颜色加百分比位置。

坑 4：background 简写覆盖了单独设置的属性
结论：先设 background-color，后写 background 简写，颜色被重置。
原因：简写会重置所有未写明的背景属性。
解法：简写放前面，单独属性放后面；或统一用简写。

坑 5：全屏背景图用 contain 导致留白
结论：背景图没铺满，四周留白。
原因：contain 保证完整显示但可能留白。
解法：全屏背景用 cover（铺满裁剪），展示图才用 contain。
```
