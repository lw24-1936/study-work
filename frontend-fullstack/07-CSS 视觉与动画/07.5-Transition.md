## 概述

Transition（过渡）让属性变化「平滑过渡」，而不是瞬间跳变。它是 CSS 动画最简单的形式——状态改变时（hover、class 切换），属性值从旧值渐变到新值。适合 hover 效果、状态切换等「一次性的平滑变化」。

```text
Transition 的机制：
元素属性从「状态 A」变到「状态 B」时，不是瞬间跳，
而是按指定时长和缓动曲线平滑过渡。

触发场景：hover、class 切换、focus 等状态变化。
```

```text
Transition vs Animation：
Transition —— 简单，状态切换的平滑过渡（A → B）
Animation —— 复杂，关键帧动画（可多阶段、循环、自动播放）
```

## transition-property 与 transition-duration

### transition-property 过渡属性

指定「哪些属性」参与过渡：

```css
.button {
  transition-property: background-color, transform;
  /* 只过渡这两个属性 */
}
```

```text
transition-property 的取值：
具体属性 —— background-color、transform、opacity 等
all —— 所有可过渡属性（默认）

推荐：明确列出过渡的属性，用 all 会过渡不该过渡的属性（性能）。
```

### transition-duration 过渡时长

指定过渡的持续时间：

```css
.button {
  transition-duration: 0.3s;   /* 0.3 秒 */
  transition-duration: 300ms;   /* 等价写法 */
}
```

```text
时长建议：
UI 交互（hover、按钮）—— 0.15s~0.3s（快，不拖沓）
视觉展示（卡片、弹窗）—— 0.3s~0.5s
过慢（>1s）会让用户觉得卡顿。
```

## transition-delay 延迟

transition-delay 指定过渡「延迟多久开始」：

```css
.box {
  transition-delay: 0.2s;  /* 延迟 0.2 秒才开始过渡 */
}
```

```text
delay 的用途：
1. 悬停后延迟响应（避免误触）
2. 多个属性错开过渡（先后过渡，层次感）
```

```css
/* 多个属性错开过渡 */
.box {
  transition-property: opacity, transform;
  transition-duration: 0.3s, 0.3s;
  transition-delay: 0s, 0.1s;  /* transform 延迟 0.1s */
}
```

## transition-timing-function 与 cubic-bezier

### transition-timing-function 缓动函数

控制过渡的「速度曲线」（先快后慢、匀速等）：

```css
.box {
  transition-timing-function: ease;      /* 默认，先快后慢 */
  transition-timing-function: linear;    /* 匀速 */
  transition-timing-function: ease-in;   /* 先慢后快 */
  transition-timing-function: ease-out;  /* 先快后慢 */
  transition-timing-function: ease-in-out; /* 两端慢中间快 */
}
```

```text
常见缓动：
ease —— 默认，轻微加速后减速（最常用）
linear —— 匀速（机械感，少用）
ease-in —— 加速（进入）
ease-out —— 减速（退出）
ease-in-out —— 加速再减速（往返动画）
```

### cubic-bezier 自定义贝塞尔曲线

cubic-bezier 自定义缓动曲线：

```css
.box {
  transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1);
  /* 四个参数定义曲线形状 */
}
```

```text
cubic-bezier(x1, y1, x2, y2)：
两个控制点定义贝塞尔曲线，x 轴是时间，y 轴是进度。

常用曲线：
ease = cubic-bezier(0.25, 0.1, 0.25, 1)
ease-in = cubic-bezier(0.42, 0, 1, 1)
ease-out = cubic-bezier(0, 0, 0.58, 1)
```

```text
cubic-bezier 的可视化：
用工具（cubic-bezier.com）拖拽曲线，直观调整缓动效果。
参数可以超过 0~1 范围（产生「回弹」效果，如 cubic-bezier(0.68, -0.55, 0.27, 1.55)）。
```

## transition 简写

transition 简写一次性设置所有过渡参数：

```css
.box {
  transition: background-color 0.3s ease 0.1s;
  /*         property        duration timing delay */
  transition: all 0.3s ease;  /* 最简写法 */
}
```

```text
transition 简写顺序：
transition: property duration timing-function delay;

多个属性用逗号分隔：
transition: opacity 0.3s, transform 0.3s ease-out;
```

## 应用场景实战

### 场景一：按钮 hover 过渡

```css
.button {
  background: #0066cc;
  transition: background-color 0.2s ease, transform 0.2s ease;
}
.button:hover {
  background: #0055aa;
  transform: translateY(-2px);
}
```

### 场景二：卡片悬停浮起 + 阴影

```css
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15);
}
```

### 场景三：展开收起（下拉菜单）

```css
.menu {
  opacity: 0;
  transform: translateY(-8px);
  visibility: hidden;
  transition: opacity 0.2s ease, transform 0.2s ease, visibility 0.2s;
}
.menu.open {
  opacity: 1;
  transform: translateY(0);
  visibility: visible;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 交互过渡用 0.15s~0.3s，不拖沓
2. 过渡 transform 和 opacity（GPU 加速，性能好）
3. 明确列出过渡属性，避免 transition: all
4. 缓动用 ease/ease-out（自然），避免 linear 的机械感
5. 多属性用逗号分隔，可设不同时长/延迟

### 踩坑记录

```text
坑 1：transition: all 过渡所有属性
结论：过渡了不该过渡的属性，性能差、效果乱。
原因：all 会监听所有可过渡属性，包括 width/height（触发重排）。
解法：明确列出要过渡的属性（transform/opacity 优先）。

坑 2：过渡 width/height 导致卡顿
结论：过渡尺寸属性，动画掉帧。
原因：width/height 触发 Layout/Paint，不 GPU 加速。
解法：用 transform: scale 替代尺寸过渡，或用 max-height 技巧。

坑 3：display: none 无法过渡
结论：display 在 none 和 block 间切换，过渡不生效。
原因：display 不是可过渡属性（瞬间切换）。
解法：用 opacity + visibility 组合，或用 transform 模拟。

坑 4：transition 写在 hover 里导致「进入有过渡退出没有」
结论：悬停有过渡，移开瞬间跳回。
原因：transition 写在 :hover 里，只在进入时生效。
解法：transition 写在基础状态（非 hover），进入退出都过渡。

坑 5：visibility 过渡的延迟技巧用错
结论：展开时正常，收起时立即消失（没过渡）。
原因：visibility 是不可渐变属性，瞬间切换，需配合 delay。
解法：visibility 的 transition 加 delay，让 opacity 先过渡完再隐藏。
```
