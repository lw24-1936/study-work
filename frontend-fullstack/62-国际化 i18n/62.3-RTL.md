## 概述

RTL（Right-to-Left，从右到左）是阿拉伯语、希伯来语等语言的书写方向，与中文、英文的 LTR（Left-to-Right）相反。支持 RTL 意味着整个布局要镜像翻转——不仅是文字方向，还包括左右间距、对齐、图标方向、布局顺序。

```text
RTL 语言：
阿拉伯语（ar）、希伯来语（he）、波斯语（fa）、乌尔都语（ur）

RTL 布局要翻转的不仅仅是文字：
1. 文字方向 —— 从右到左书写
2. 布局顺序 —— 侧边栏、导航从右侧开始
3. 间距 —— padding-left/right 互换
4. 图标方向 —— 返回箭头、前进箭头镜像
5. 文本对齐 —— 右对齐而非左对齐
```

```text
支持 RTL 的两条路径：
1. 逻辑属性 —— 用 margin-inline-start 等替代 left/right（推荐）
2. dir 属性 + 翻转 —— 根元素设 dir="rtl"，浏览器自动镜像
```

## RTL 与 LTR

LTR（Left-to-Right）是从左到右，RTL（Right-to-Left）是从右到左。HTML 通过 `dir` 属性声明方向，CSS 和布局都应基于方向而非「左右」来编写。

```html
<!-- 声明页面方向 -->
<html dir="rtl" lang="ar">
  <!-- 阿拉伯语页面，整个布局从右到左 -->
</html>

<!-- 局部切换方向（嵌入一段 LTR 文本） -->
<p dir="ltr">This is English text</p>
```

```css
/* dir 选择器 —— 按方向写差异样式 */
[dir='rtl'] .nav {
  text-align: right;
}

[dir='ltr'] .nav {
  text-align: left;
}
```

```text
dir 属性的作用：
1. 浏览器据此决定文字排列方向
2. 影响 text-align 的默认值
3. 影响 flexbox 的 main axis 方向
4. 影响 CSS 逻辑属性（inline-start）的解析
```

```text
RTL 与 LTR 的核心差异：
            LTR                      RTL
文字方向     左 → 右                  右 → 左
默认对齐     左对齐                   右对齐
flex 主轴   左 → 右                  右 → 左
侧边栏       左侧                     右侧
前进箭头     指向右                   指向左
```

```html
<!-- flex 布局在 RTL 下自动反转 -->
<div style="display: flex; gap: 8px;">
  <span>第一个</span>
  <span>第二个</span>
</div>
<!-- LTR：第一个在左；RTL：第一个在右 -->
```

## Logical Properties

Logical Properties（逻辑属性）用「方向无关」的词汇描述位置：`inline-start`/`inline-end` 代替 `left`/`right`，`block-start`/`block-end` 代替 `top`/`bottom`。同一套 CSS 在 LTR 和 RTL 下自动正确，无需写两份。

```text
物理属性 vs 逻辑属性：
物理（方向相关）          逻辑（方向无关）
left / right         →   inline-start / inline-end
top / bottom         →   block-start / block-end
margin-left          →   margin-inline-start
padding-right        →   padding-inline-end
border-left          →   border-inline-start
```

```css
/* 物理属性（需为 RTL 另写一份） */
.box {
  margin-left: 16px;
  padding-right: 8px;
  border-left: 1px solid #ccc;
  text-align: left;
}

/* 逻辑属性（LTR/RTL 自动适配） */
.box {
  margin-inline-start: 16px;
  padding-inline-end: 8px;
  border-inline-start: 1px solid #ccc;
  text-align: start;
}
```

```text
逻辑属性的映射关系（LTR 下）：
inline-start = left，inline-end = right
block-start = top，block-end = bottom

RTL 下自动反转：
inline-start = right，inline-end = left
```

```css
/* 常见的逻辑属性速查 */
.logical {
  margin-inline: 8px;         /* 水平方向（left+right） */
  margin-block: 16px;         /* 垂直方向（top+bottom） */
  padding-inline-start: 12px; /* 行首内边距 */
  inset-inline-start: 0;      /* 定位：行首贴边 */
  border-inline-end: 1px;     /* 行尾边框 */
  text-align: start;          /* 行首对齐 */
}
```

```text
text-align 的方向无关值：
start / end / left / right
其中 start = LTR 下的 left = RTL 下的 right

同理 float：inline-start / inline-end 取代 left / right。
```

```text
什么时候必须用物理属性（不翻转）：
1. 镜像无关的东西 —— 时钟方向、音视频进度条（时间从左到右）
2. 某些图标 —— 如播放按钮的三角形（永远指右）
3. 电话号码、URL —— 这些内容本身是 LTR 的，用 dir="ltr" 包裹
```

## 应用场景实战

### 场景一：用逻辑属性重构一个卡片组件，天然支持 RTL

```css
/* card.css —— 全部用逻辑属性 */
.card {
  padding-inline: 16px;
  padding-block: 12px;
  margin-inline-start: 8px;
  border-inline-start: 3px solid #1677ff;
  text-align: start;
}

.card__title {
  margin-block-end: 4px;
}
```

```html
<!-- LTR 页面：左边框、左对齐、左间距 -->
<html dir="ltr">
  <div class="card">...</div>
</html>

<!-- RTL 页面：同一套 CSS，自动右边框、右对齐、右间距 -->
<html dir="rtl">
  <div class="card">...</div>
</html>
```

### 场景二：处理嵌入 LTR 内容与图标方向

```html
<!-- 电话号码、URL 这类 LTR 内容，在 RTL 页面里单独声明方向 -->
<p dir="ltr">+1 (555) 123-4567</p>
<p dir="ltr">https://example.com</p>
```

```css
/* 图标方向 —— 返回箭头在 RTL 下镜像 */
.icon-back {
  /* 用 transform 镜像，或换成对应的 RTL 图标 */
}
[dir='rtl'] .icon-back {
  transform: scaleX(-1);   /* 水平翻转箭头 */
}
```

```text
哪些图标需要镜像：
返回/前进箭头、列表项前的箭头、面包屑分隔符、展开收起箭头

哪些不需要镜像：
播放/暂停（时间方向固定）、时钟、音量、勾选标记
```

## 最佳实践与踩坑记录

### 最佳实践

1. 一律用逻辑属性（inline/block），不写 left/right 物理属性
2. 根元素设 `dir` 属性，浏览器和 CSS 据此自动镜像
3. text-align 用 start/end，别用 left/right
4. 电话号码、URL 等 LTR 内容用 `dir="ltr"` 单独包裹
5. 返回箭头等方向性图标按 dir 镜像，时间类图标不镜像
6. 用 RTL 语言做视觉回归，别只测 LTR

### 踩坑记录

```text
坑 1：只设 dir="rtl" 但 CSS 全用物理属性
结论：文字方向对了，但间距、边框、对齐全错位。
原因：margin-left、text-align:left 等物理属性不随 dir 翻转。
解法：改用逻辑属性（margin-inline-start、text-align:start）。

坑 2：返回箭头在 RTL 下指错方向
结论：阿拉伯语页面「返回」箭头仍指向左（应该指向右）。
原因：图标是固定的 LTR 方向，没做镜像。
解法：按 dir 镜像方向性图标（transform: scaleX(-1)）。

坑 3：电话号码、URL 被 RTL 方向弄乱
结论：RTL 页面里的电话号码显示成「4567-123 (555)」。
原因：数字和符号被当成了 RTL 文本重新排列。
解法：LTR 内容用 dir="ltr" 包裹，强制从左到右。

坑 4：flex 布局方向在 RTL 下反转导致交互错乱
结论：Tab 键顺序和视觉顺序不一致。
原因：视觉反转了但 DOM 顺序没变，焦点顺序与视觉不符。
解法：理解 flex 在 RTL 下是视觉反转，DOM 顺序不变，
     焦点/读屏顺序要单独测试确认。

坑 5：混用物理属性和逻辑属性
结论：部分样式翻转、部分不翻，布局错乱难排查。
原因：同一组件既有 margin-left 又有 margin-inline-start。
解法：全库统一用逻辑属性，Lint 规则禁止 left/right 物理属性。
```
