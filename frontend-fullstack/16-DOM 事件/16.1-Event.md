## 概述

事件对象（Event）是事件发生时的信息载体，通过事件回调传入。不同类型的事件继承自 Event 基类，携带各自专属的信息。

```text
事件对象的核心信息：
type —— 事件类型（click、keydown 等）
target —— 触发事件的目标元素
currentTarget —— 监听器绑定的元素
timeStamp —— 事件发生时间

事件类型继承体系：
Event（基类）
├── MouseEvent（鼠标）
├── KeyboardEvent（键盘）
├── PointerEvent（指针，统一鼠标/触摸）
├── InputEvent（输入）
├── FocusEvent（焦点）
├── TouchEvent / WheelEvent / DragEvent / ClipboardEvent
```

## Event 基类

Event 是所有事件对象的基类，提供通用属性。

```js
element.addEventListener('click', (e) => {
  console.log(e.type);           // 'click'
  console.log(e.target);         // 实际触发元素
  console.log(e.currentTarget);  // 监听器所在元素
  console.log(e.timeStamp);      // 时间戳
});
```

```js
// 创建与派发自定义事件
const event = new Event('myEvent', { bubbles: true });
element.dispatchEvent(event);
```

```text
Event 关键属性：
type —— 事件类型
target —— 触发目标（事件实际发生的元素）
currentTarget —— 当前监听器绑定的元素（this）
bubbles —— 是否冒泡
cancelable —— 是否可取消
```

## MouseEvent 鼠标事件

MouseEvent 携带鼠标位置、按键、修饰键等信息。

```js
element.addEventListener('click', (e) => {
  console.log(e.clientX, e.clientY);   // 视口坐标
  console.log(e.pageX, e.pageY);       // 页面坐标（含滚动）
  console.log(e.button);               // 0左 1中 2右
  console.log(e.altKey, e.ctrlKey, e.shiftKey);   // 修饰键
});
```

```text
MouseEvent 关键属性：
clientX/Y —— 相对视口坐标
pageX/Y —— 相对页面坐标（含滚动）
button —— 按下的鼠标键（0 左、1 中、2 右）
altKey/ctrlKey/shiftKey/metaKey —— 修饰键状态
```

## KeyboardEvent 键盘事件

KeyboardEvent 携带按键信息：key、code、修饰键。

```js
document.addEventListener('keydown', (e) => {
  console.log(e.key);       // 按下的键（'a'、'Enter'、'ArrowUp'）
  console.log(e.code);      // 物理键位（'KeyA'、'Enter'、'ArrowUp'）
  console.log(e.ctrlKey);   // 是否按住 Ctrl
});
```

```js
// 组合键（如 Ctrl+S）
document.addEventListener('keydown', (e) => {
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();
    save();
  }
});
```

```text
KeyboardEvent 关键属性：
key —— 按键的值（区分大小写、考虑键盘布局）
code —— 物理键位（不随布局变化）
altKey/ctrlKey/shiftKey/metaKey —— 修饰键

key vs code：key 是「输入结果」，code 是「物理位置」。
```

## PointerEvent 指针事件

PointerEvent 统一鼠标、触摸、笔的输入，是推荐的现代指针事件。

```js
element.addEventListener('pointerdown', (e) => {
  console.log(e.pointerType);   // 'mouse' | 'touch' | 'pen'
  console.log(e.pointerId);     // 指针唯一 ID（多点触控）
  console.log(e.clientX, e.clientY);
});
```

```text
PointerEvent 的价值：
1. 统一鼠标/触摸/笔 —— 一套事件处理多种输入
2. pointerId —— 区分多点触控的不同手指
3. 替代 mousedown/touchstart 的分支判断

现代项目优先 PointerEvent，兼容旧浏览器需 polyfill。
```

## InputEvent 与 FocusEvent

InputEvent 用于输入框输入，FocusEvent 用于焦点变化。

```js
// InputEvent：输入时触发（含 value 变化）
input.addEventListener('input', (e) => {
  console.log(e.data);         // 插入的字符
  console.log(e.inputType);    // 输入类型（insertText、deleteContent 等）
});
```

```js
// FocusEvent：焦点进入/离开
input.addEventListener('focus', (e) => {
  console.log(e.relatedTarget);   // 焦点来源元素
});
input.addEventListener('blur', (e) => {
  console.log(e.relatedTarget);   // 焦点去向元素
});
```

```text
InputEvent 要点：
input 事件在 value 变化时触发（输入、粘贴、删除都触发）
e.data —— 本次插入的内容（删除时为 null）

FocusEvent 要点：
focus/blur —— 不冒泡（用 focusin/focusout 冒泡）
relatedTarget —— 焦点转移的另一方元素
```

## TouchEvent / WheelEvent / DragEvent / ClipboardEvent

这些事件各有专属属性，用于特定交互。

```js
// TouchEvent：触摸
element.addEventListener('touchstart', (e) => {
  e.touches;               // 所有触摸点
  e.touches[0].clientX;    // 第一个触点坐标
});

// WheelEvent：滚轮
element.addEventListener('wheel', (e) => {
  e.deltaY;                // 纵向滚动量
  e.deltaX;                // 横向滚动量
});

// DragEvent：拖拽
element.addEventListener('drop', (e) => {
  e.dataTransfer.getData('text/plain');
});

// ClipboardEvent：剪贴板
element.addEventListener('paste', (e) => {
  e.clipboardData.getData('text/plain');
});
```

```text
各事件的核心属性：
TouchEvent —— touches、changedTouches（触点）
WheelEvent —— deltaX、deltaY（滚动量）
DragEvent —— dataTransfer（拖拽数据）
ClipboardEvent —— clipboardData（剪贴板数据）
```

## 应用场景实战

### 场景一：键盘快捷键

```js
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') {
    closeModal();
  }
  if (e.ctrlKey && e.key === 'z') {
    undo();
  }
});
```

### 场景二：拖拽文件

```js
const dropZone = document.querySelector('.drop-zone');
dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  const files = e.dataTransfer.files;
  console.log(files);   // 拖入的文件列表
});
```

## 最佳实践与踩坑记录

### 最佳实践

1. 现代输入用 PointerEvent，统一鼠标/触摸/笔
2. 快捷键用 e.key + 修饰键判断，别用 keyCode（已废弃）
3. 拖拽记得 preventDefault 允许 drop
4. 触摸滚动冲突用 passive 优化
5. 需要冒泡的焦点事件用 focusin/focusout

### 踩坑记录

```text
坑 1：用废弃的 keyCode
结论：e.keyCode 在新标准已废弃。
原因：keyCode 被 key/code 取代。
解法：用 e.key（输入值）或 e.code（物理键位）。

坑 2：touch 与 mouse 事件重复触发
结论：移动端同时触发 touch 和 mouse 事件。
原因：浏览器为兼容触发模拟鼠标事件。
解法：用 PointerEvent 统一，或 preventDefault 阻止。

坑 3：drop 不触发
结论：拖拽到目标上 drop 无效。
原因：默认不允许 drop，需 preventDefault（dragover 和 drop 都要）。
解法：dragover/drop 都 preventDefault。

坑 4：focus/blur 不冒泡
结论：想用事件委托监听焦点，focus 不冒泡。
原因：focus/blur 不冒泡（focusin/focusout 冒泡）。
解法：用 focusin/focusout，或 capture 阶段监听。

坑 5：clientX 与 pageX 混淆
结论：页面滚动后坐标不对。
原因：clientX 是视口坐标，pageX 是页面坐标。
解法：需要绝对页面位置用 pageX/Y。
```
