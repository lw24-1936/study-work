## 概述

Zustand 是一个轻量、无样板的 React 状态管理库，基于「单一 store + hook」模型。它不需要 Provider 包裹，通过 selector 精确订阅，支持在 React 外部读写状态，API 极简。

```text
Zustand 核心概念：
1. Store —— create() 创建的 hook，含 state 与 action
2. Selector —— 从 store 中精确选择数据，避免过度渲染
3. Middleware —— 组合增强 store（immer、devtools 等）
4. Persistence —— persist 中间件持久化到 localStorage
```

```js
import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));

// 组件中使用
function Counter() {
  const { count, increment } = useStore();
  return <button onClick={increment}>{count}</button>;
}
```

## Store

Store 是 `create` 创建的 hook，内部是一个闭包状态。`set` 用于更新状态（支持对象或函数），`get` 读取当前状态。

```js
import { create } from 'zustand';

const useCounter = create((set, get) => ({
  count: 0,
  // 函数式更新（依赖旧状态）
  increment: () => set((state) => ({ count: state.count + 1 })),
  // 对象更新
  setCount: (count) => set({ count }),
  // 用 get 读取当前状态
  double: () => set({ count: get().count * 2 }),
}));
```

```js
// 在 React 外读写（不触发渲染）
useCounter.getState().count; // 读取
useCounter.setState({ count: 10 }); // 更新
useCounter.subscribe((state) => console.log(state.count)); // 订阅
```

```text
Store 特点：
1. 无 Provider，create 即用
2. 状态与 action 共存一个对象
3. 可在组件外、事件处理、异步回调中访问
4. 支持多个独立 store
```

## Selector

Selector 是从 store 中精确选取数据的函数。组件只订阅 selector 选中的部分，只有该部分变化时才重渲染。

```js
const useUserStore = create((set) => ({
  user: { name: 'Alice', age: 20 },
  age: 20,
  updateAge: (age) => set({ age }),
}));

// 只订阅 name（user.age 变化不会触发渲染）
const name = useUserStore((state) => state.user.name);

// 订阅多个值（默认浅比较，需 shallow 避免对象每次新建）
import { shallow } from 'zustand/shallow';
const { name, age } = useUserStore(
  (state) => ({ name: state.user.name, age: state.age }),
  shallow,
);
```

```text
Selector 要点：
1. 默认严格相等（Object.is）比较返回值
2. 返回新对象需传 shallow，否则每次都重渲染
3. 不传 selector 则订阅整个 store（不推荐）
```

## Middleware

Middleware 是包在 store 配置外的高阶函数，用于扩展能力。常用：immer、devtools、subscribeWithSelector、自定义日志。

```js
import { create } from 'zustand';
import { immer } from 'zustand/middleware/immer';
import { devtools } from 'zustand/middleware/devtools';

const useStore = create(
  devtools(
    immer((set) => ({
      user: { name: 'Alice', tags: [] },
      addTag: (tag) =>
        set((state) => {
          state.user.tags.push(tag); // Immer 可变写法
        }),
    })),
  ),
);
```

```js
// 自定义中间件（日志）
const log = (config) => (set, get, api) =>
  config(
    (...args) => {
      console.log('set', args);
      set(...args);
    },
    get,
    api,
  );

const useStore = create(log((set) => ({ count: 0, inc: () => set((s) => ({ count: s.count + 1 })) })));
```

```text
常用中间件：
immer —— 支持可变写法更新嵌套对象
devtools —— 接入 Redux DevTools 调试
persist —— 持久化
subscribeWithSelector —— 精确订阅监听
```

## Persistence

`persist` 中间件把状态持久化到 localStorage/sessionStorage，支持部分持久化、版本迁移。

```js
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

const useStore = create(
  persist(
    (set) => ({
      theme: 'light',
      setTheme: (theme) => set({ theme }),
    }),
    {
      name: 'app-storage', // localStorage key
      partialize: (state) => ({ theme: state.theme }), // 只持久化 theme
      version: 1,
      migrate: (persistedState, version) => {
        if (version === 0) return { theme: 'dark' };
        return persistedState;
      },
    },
  ),
);
```

```text
persist 配置：
name —— 存储 key
partialize —— 选择持久化哪些字段
version + migrate —— 数据结构升级迁移
storage —— 自定义存储（默认 localStorage）
```

## 应用场景实战

### 场景一：购物车（含持久化）

```js
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

const useCartStore = create(
  persist(
    (set, get) => ({
      items: [],
      add: (item) => set((s) => ({ items: [...s.items, item] })),
      remove: (id) => set((s) => ({ items: s.items.filter((i) => i.id !== id) })),
      clear: () => set({ items: [] }),
      total: () => get().items.reduce((sum, i) => sum + i.price, 0),
    }),
    { name: 'cart-storage' },
  ),
);
```

### 场景二：UI 状态（弹窗、加载态）

```js
const useUIStore = create((set) => ({
  loading: false,
  modalOpen: false,
  showModal: () => set({ modalOpen: true }),
  hideModal: () => set({ modalOpen: false }),
  setLoading: (loading) => set({ loading }),
}));
```

## 最佳实践与踩坑记录

### 最佳实践

1. 按领域拆分多个小 store，而非一个大 store
2. 用 selector 精确订阅，避免整 store 订阅
3. 返回对象的选择器加 shallow 比较
4. 需要持久化的状态用 persist 中间件
5. 复杂嵌套更新用 immer 中间件

### 踩坑记录

```text
坑 1：selector 返回新对象导致频繁重渲染
结论：每次 render 都新建对象，组件无限重渲染。
原因：默认 Object.is 比较，新对象总不相等。
解法：传 shallow 比较，或订阅原始值。

坑 2：在组件外误用 hook 形式
结论：报错或拿不到状态。
原因：useStore 是 hook，只能在组件内调用。
解法：组件外用 useStore.getState()/setState()。

坑 3：persist 未做版本迁移
结论：数据结构变更后，旧缓存数据导致崩溃。
原因：持久化数据与新版结构不匹配。
解法：配置 version + migrate。

坑 4：过度持久化
结论：localStorage 塞入大量数据，启动变慢。
原因：所有状态都持久化。
解法：用 partialize 只持久化必要字段。

坑 5：直接在 render 里调用 get()
结论：状态变化不会触发组件更新。
原因：get() 只读取不订阅。
解法：组件内用 hook + selector 订阅。
```
