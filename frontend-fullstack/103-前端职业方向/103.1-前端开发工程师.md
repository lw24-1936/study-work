## 概述

前端开发工程师是负责把设计稿转化为浏览器可运行页面的工程师，核心职责是「结构（HTML）+ 表现（CSS）+ 行为（JavaScript）」三件套，并逐步叠加类型系统（TypeScript）、框架（React/Vue）与工程化能力。这是一个从「能写页面」到「能高质量交付」持续进阶的角色。

```text
前端开发工程师的能力金字塔：
1. HTML —— 语义化结构，内容与可访问性的地基
2. CSS —— 布局与视觉，从盒模型到响应式
3. JavaScript —— 交互逻辑，语法、DOM、异步三大块
4. TypeScript —— 类型约束，工程规模化的保障
5. React / Vue —— 组件化开发，现代前端的主流范式
6. Engineering —— 工程化，构建、规范、协作与质量
```

## HTML

HTML（HyperText Markup Language）是网页的结构层，负责定义内容的语义而非外观。前端工程师首先要能写出语义正确、可访问的结构，为 CSS 与 JavaScript 提供稳定的锚点。

```text
HTML 核心能力：
1. 语义化标签 —— header/nav/main/article/section/footer 表达文档结构
2. 表单 —— input/select/textarea + label 关联，掌握校验与无障碍
3. 链接与多媒体 —— a/img/video/audio 及属性（alt、loading）
4. 可访问性 —— ARIA 角色、焦点管理、语义与键盘可操作
```

### 技能清单

```text
1. 能区分块级/行内/行内块元素，理解文档流
2. 熟练使用语义化标签替代 div 堆叠
3. 掌握表单元素与原生校验，理解 label 与控件关联
4. 知道 meta viewport、lang、charset 等页面级配置
5. 理解 DOM 树结构与 HTML 解析顺序（脚本阻塞）
```

### 能力要求

- 能独立还原一张设计稿的结构层，标签选择合理
- 能写出一份可被屏幕阅读器正确朗读的页面结构
- 能解释「为什么用 button 而不是 div + click」

## CSS

CSS（Cascading Style Sheets）是表现层，控制布局、视觉与响应式。核心是掌握盒模型、选择器优先级、布局体系（Flex/Grid）与响应式设计。

```text
CSS 核心能力：
1. 盒模型 —— content/padding/border/margin 与 box-sizing
2. 选择器与优先级 —— 特异性计算，避免 !important 滥用
3. 布局 —— Flex 一维、Grid 二维、Position 定位、浮动
4. 响应式 —— 媒体查询、相对单位、移动优先
```

### 技能清单

```text
1. 掌握盒模型与 box-sizing: border-box 的使用场景
2. 熟练 Flex 与 Grid，能徒手写出常见布局
3. 理解定位（relative/absolute/fixed/sticky）与层叠上下文
4. 会用媒体查询与相对单位（rem/vw）做响应式
5. 了解 CSS 变量、动画（transition/animation）基础
```

### 成长路径

- 初级：能照着设计稿写样式，实现基本布局
- 进阶：理解 BFC、层叠上下文、选择器性能
- 高级：掌握 CSS 工程化（预处理、原子化、CSS-in-JS）

## JavaScript

JavaScript 是行为层，负责交互、数据与异步。核心掌握语言基础（变量/类型/函数/闭包）、DOM 操作、事件机制与异步编程（Promise/async-await）。

```text
JavaScript 核心能力：
1. 语言基础 —— 类型、作用域、闭包、原型、this
2. DOM 操作 —— 查询、增删改、事件监听与委托
3. 异步 —— Promise、async/await、Event Loop
4. 模块化 —— ES Modules 与现代打包
```

### 技能清单

```text
1. 掌握 let/const/var 差异、类型判断与隐式转换
2. 理解闭包、原型链与 this 绑定规则
3. 熟练操作 DOM，掌握事件捕获/冒泡与委托
4. 会用 Promise 与 async/await 组织异步流程
5. 了解 Event Loop 与宏任务/微任务执行顺序
```

### 成长路径

- 初级：能写交互逻辑，会查 DOM 改样式
- 进阶：理解闭包/原型/this，能写健壮的异步代码
- 高级：深入 Event Loop、内存模型，能定位性能问题

## TypeScript

TypeScript 是 JavaScript 的超集，通过静态类型在编译期发现错误，是大型前端工程的标配。核心是类型系统：接口、类型别名、泛型与类型推断。

```text
TypeScript 核心能力：
1. 基础类型 —— string/number/boolean/object/array/tuple
2. 接口与类型别名 —— interface vs type，可选与只读
3. 泛型 —— 函数/类/接口的泛型复用
4. 类型推断与收窄 —— 联合类型、类型守卫、as 断言
```

### 技能清单

```text
1. 能给函数、对象、接口写准确的类型标注
2. 掌握 interface 与 type 的异同与选择
3. 会用泛型封装可复用的类型工具
4. 理解类型推断、联合类型与类型收窄
5. 会用 Utility Types（Partial/Pick/Omit/Record）
```

### 成长路径

- 初级：从 any 起步，逐步补全标注
- 进阶：熟练泛型与类型收窄，能读懂复杂类型
- 高级：掌握类型体操与声明文件，能设计类型工程

## React / Vue

React 与 Vue 是现代前端两大主流框架，核心是「组件化 + 响应式」。掌握其中一个并能理解其设计思想，是前端工程师的核心竞争力。

```text
React / Vue 核心能力：
1. 组件化 —— 组件拆分、props 传参、组合复用
2. 响应式 —— React 的 state/hooks，Vue 的 ref/reactive
3. 状态管理 —— 局部 state 与全局 store（Redux/Pinia）
4. 生命周期 —— 挂载、更新、卸载与副作用清理
```

### 技能清单

```text
1. 掌握组件拆分与 props/事件通信
2. 熟练 React Hooks（useState/useEffect/useMemo）或 Vue 组合式 API
3. 理解响应式原理（React 的 diff，Vue 的 Proxy）
4. 会用路由与全局状态管理
5. 理解副作用管理与组件卸载清理
```

### 成长路径

- 初级：能用框架完成页面，理解 props/state
- 进阶：理解响应式与渲染机制，能优化重渲染
- 高级：读懂框架源码，能设计复杂状态方案

## Engineering

工程化是把「写代码」升级为「可持续交付」的体系，涵盖构建工具、代码规范、版本管理与协作流程，是前端工程师从个人到团队的关键能力。

```text
Engineering 核心能力：
1. 构建工具 —— Vite/Webpack 的打包、HMR 与优化
2. 代码规范 —— ESLint/Prettier/Commit 规范
3. 版本管理 —— Git 分支、合并与协作流程
4. 测试与 CI —— 单元测试、自动化流水线
```

### 技能清单

```text
1. 会用 Vite/Webpack 搭建与配置项目
2. 掌握 ESLint/Prettier 规范代码
3. 熟练 Git 分支模型（feature/develop/main）
4. 了解 CI 流水线与自动化测试
5. 理解 npm 包管理与依赖治理
```

### 成长路径

- 初级：能跑通构建，会基础 Git 操作
- 进阶：能定制构建配置，建立团队规范
- 高级：能搭建工程体系，主导质量与效率建设

## 最佳实践与踩坑记录

### 最佳实践

1. 结构语义化，样式行为分离，避免内联样式与内联脚本
2. CSS 优先用 Flex/Grid，少用绝对定位硬编码
3. 异步统一用 async/await，避免回调地狱
4. 类型从第一天就写，杜绝 any 泛滥
5. 组件保持单一职责，props 下沉、状态上提
6. 提交信息规范化，配合 ESLint 在 CI 卡质量

### 踩坑记录

```text
坑 1：用 var 声明导致变量提升与作用域混乱
结论：循环里用 var 声明 i，异步回调拿到错误的值。
原因：var 是函数作用域且有提升，闭包捕获的是同一个变量。
解法：改用 let/const，或用闭包包裹传参。

坑 2：float 布局与父元素塌陷
结论：子元素全部 float 后，父容器高度为 0。
原因：float 元素脱离文档流，父容器无法撑开。
解法：父容器加 overflow: hidden 或使用 clearfix，现代布局改用 Flex。

坑 3：直接修改 state 导致视图不更新
结论：Vue 里给对象新增属性或 React 里直接改 state，页面无反应。
原因：响应式依赖劫持/引用比较，直接改不触发更新。
解法：Vue 用响应式 API 或整体替换，React 用 setState 返回新引用。

坑 4：any 泛滥让 TypeScript 形同虚设
结论：类型报错时用 any 绕过，运行时照样崩溃。
原因：any 关闭了类型检查，错误被推迟到运行时。
解法：用 unknown 收窄或补全真实类型，开启 strict 模式。

坑 5：useEffect 不清理副作用导致内存泄漏
结论：定时器、事件监听在组件卸载后仍在执行。
原因：副作用没有在 cleanup 中清除。
解法：在 useEffect 返回值里清理定时器与监听器。
```
