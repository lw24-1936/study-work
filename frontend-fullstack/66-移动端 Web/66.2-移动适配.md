## 概述

移动适配让页面在不同尺寸、不同 DPR 的设备上都能正确、舒适地显示。核心手段包括响应式布局（Responsive）、基于根字号缩放的 rem、动态视口单位（vw/vh/dvh）、安全区适配、触控目标尺寸与手势支持。

```text
移动适配的六个维度：
1. Responsive —— 断点 + 弹性布局，一套代码适配多屏
2. Rem —— 根字号缩放，整体等比适配
3. Viewport Units —— 相对视口的尺寸单位
4. Safe Area —— 刘海屏安全区留白
5. Touch Target —— 触控目标的合适尺寸
6. Gesture —— 手势（缩放、滑动）交互
```

```css
/* 移动优先的响应式基础 */
html { font-size: 16px; }
.container { width: 100%; padding: 0 16px; }
@media (min-width: 768px) {
  .container { max-width: 750px; margin: 0 auto; }
}
```

## Responsive

响应式设计（Responsive Web Design）通过媒体查询、弹性布局、相对单位，让页面自动适配不同屏幕尺寸，核心是「移动优先」。

```text
响应式三大要素：
1. 流式布局 —— 用 % / flex / grid 而非固定像素
2. 媒体查询 —— 按断点切换样式
3. 弹性图片 —— 图片不超出容器（max-width: 100%）
```

```css
/* 流式栅格：flex 布局 */
.row { display: flex; flex-wrap: wrap; }
.col { flex: 1 1 100%; }              /* 手机：单列 */
@media (min-width: 768px) {
  .col { flex: 1 1 50%; }             /* 平板：两列 */
}
@media (min-width: 1024px) {
  .col { flex: 1 1 25%; }             /* 桌面：四列 */
}
```

```css
/* 移动优先：先写小屏样式，再向上扩展 */
.card { padding: 12px; font-size: 14px; }
@media (min-width: 768px) {
  .card { padding: 20px; font-size: 16px; }
}
```

```css
/* 弹性图片与媒体 */
img, video {
  max-width: 100%;
  height: auto;
}
/* 响应式图片：按 DPR/宽度加载 */
img {
  srcset: url(small.jpg) 640w, url(medium.jpg) 1024w, url(large.jpg) 1600w;
  sizes: (max-width: 640px) 100vw, 50vw;
}
```

## Rem

Rem 是相对根元素（html）字体大小的单位。通过动态设置根字号，可实现整页等比缩放，是移动端经典适配方案。

```text
Rem 适配原理：
1. html 的 font-size 作为基准（如 1rem = 16px）
2. 所有尺寸用 rem 表达
3. 按设备宽度动态设置根字号 → 整体缩放
```

```js
// 动态设置根字号（以 375 设计稿为基准）
function setRem() {
  const designWidth = 375;                    // 设计稿宽度
  const baseSize = 100;                       // 1rem = 100px（设计稿）
  const scale = document.documentElement.clientWidth / designWidth;
  document.documentElement.style.fontSize = `${baseSize * scale}px`;
}
window.addEventListener('resize', setRem);
setRem();
```

```css
/* 使用：设计稿 24px → 0.24rem */
.title { font-size: 0.24rem; }   /* 基准 100px 时 = 24px */
.box { width: 3.75rem; }         /* 基准 100px 时 = 375px（满宽） */
```

## Viewport Units

Viewport Units（视口单位）相对视口尺寸计算，包括 vw、vh、vmin、vmax，以及动态的 dvh、svh、lvh。

```text
视口单位：
1. vw —— 视口宽度的 1%
2. vh —— 视口高度的 1%
3. vmin / vmax —— 视口较小/较大边的 1%
4. dvh / svh / lvh —— 动态/小/大视口高度（解决地址栏问题）
```

```css
/* 全屏容器 */
.hero { height: 100vh; }         /* 传统：地址栏问题 */
.hero { height: 100dvh; }        /* 动态：跟随地址栏收缩 */

/* 流式字体 */
.title { font-size: clamp(16px, 4vw, 32px); }  /* 随视口缩放但有上下限 */

/* 等比例元素（宽高比） */
.video-wrap { width: 100%; padding-top: 56.25%; }  /* 16:9 */
```

```text
dvh vs vh：
1. vh —— 布局视口高度，移动端包含地址栏（不准确）
2. svh —— 最小视口高度（地址栏展开）
3. lvh —— 最大视口高度（地址栏收起）
4. dvh —— 动态视口高度，实时跟随（推荐）
```

## Safe Area

Safe Area（安全区）适配让内容避开刘海、圆角、底部横条，通过 viewport-fit=cover 与 env() 实现。

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />
```

```css
/* 顶部/底部安全区 */
.header {
  padding-top: env(safe-area-inset-top);
}
.bottom-bar {
  padding-bottom: env(safe-area-inset-bottom);
}
/* 兼容 constant() 旧写法 */
.bottom-bar {
  padding-bottom: constant(safe-area-inset-bottom);
  padding-bottom: env(safe-area-inset-bottom);
}
```

```css
/* 全屏沉浸式背景 + 内容留白 */
.banner {
  background: #333;
  /* 背景延伸到安全区 */
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
}
```

## Touch Target

Touch Target（触控目标）指可点击元素的尺寸。移动端手指点击精度低，目标太小易误触，需要保证足够的可点击区域。

```text
触控目标尺寸建议：
1. Apple HIG —— 最小 44x44pt
2. Material Design —— 最小 48x48dp
3. WCAG —— 至少 24x24 CSS px（AA）
```

```css
/* 按钮保证最小触控尺寸 */
.btn {
  min-width: 44px;
  min-height: 44px;
  padding: 0 16px;
}

/* 图标按钮：用 padding 扩大点击区（视觉不变） */
.icon-btn {
  width: 24px;
  height: 24px;
  padding: 10px;          /* 视觉 24px，点击区 44px */
  box-sizing: content-box;
}
```

```css
/* 列表项间距：避免相邻误触 */
.list-item {
  padding: 12px 16px;
  min-height: 48px;
}
.list-item + .list-item {
  margin-top: 4px;
}
```

## Gesture

手势（Gesture）是移动端的核心交互，包括滑动、捏合缩放、长按、双击等，通过 Touch/Pointer 事件实现或借助手势库。

```text
常见手势：
1. 滑动（swipe）—— 单指快速移动，用于翻页/删除
2. 捏合（pinch）—— 双指缩放
3. 长按（long press）—— 按住不放，触发菜单
4. 双击（double tap）—— 快速点两下，缩放/点赞
5. 拖拽（drag）—— 按住移动
```

```js
// 滑动方向检测
let startX = 0, startY = 0;
document.addEventListener('touchstart', (e) => {
  startX = e.touches[0].clientX;
  startY = e.touches[0].clientY;
});
document.addEventListener('touchend', (e) => {
  const dx = e.changedTouches[0].clientX - startX;
  const dy = e.changedTouches[0].clientY - startY;
  if (Math.abs(dx) > Math.abs(dy) && Math.abs(dx) > 50) {
    console.log(dx > 0 ? '右滑' : '左滑');
  } else if (Math.abs(dy) > 50) {
    console.log(dy > 0 ? '下滑' : '上滑');
  }
});
```

```js
// 长按检测
let timer = null;
el.addEventListener('touchstart', () => {
  timer = setTimeout(() => console.log('长按触发'), 500);
});
el.addEventListener('touchend', () => clearTimeout(timer));
```

## 应用场景实战

### 场景一：rem + vw 结合的移动端布局

```css
/* 根字号用 vw 实现等比（无需 JS） */
html {
  font-size: 13.333vw;      /* 375 设计稿下 1rem = 50px */
}
@media (min-width: 768px) {
  html { font-size: 100px; } /* 桌面固定，避免过大 */
}
.title { font-size: 0.4rem; }  /* 375 下 = 20px */
```

### 场景二：抽屉菜单 + 手势关闭

```js
const drawer = document.querySelector('.drawer');
let startX = 0;

drawer.addEventListener('touchstart', (e) => {
  startX = e.touches[0].clientX;
});
drawer.addEventListener('touchend', (e) => {
  const dx = e.changedTouches[0].clientX - startX;
  if (dx < -80) {
    drawer.classList.remove('open');   // 左滑关闭
  }
});
```

## 最佳实践与踩坑记录

### 最佳实践

1. 移动优先：先写小屏，再媒体查询向上扩展
2. 布局用 flex/grid + 百分比，避免固定像素
3. 触控目标最小 44x44px，图标用 padding 扩大点击区
4. 高度相关用 dvh 而非 vh，适配地址栏
5. 字体用 clamp() 限制缩放范围，避免过大过小
6. 图片用 max-width:100% + srcset 响应式加载

### 踩坑记录

```text
坑 1：rem 根字号设置后布局错乱
结论：设置 html font-size 后部分元素尺寸异常。
原因：第三方库/浏览器默认样式用 px，不受 rem 控制。
解法：只对业务尺寸用 rem，第三方组件保持 px 或统一转换。

坑 2：vw 字号在小屏过小、大屏过大
结论：纯 vw 字体在超小屏难读、超宽屏夸张。
原因：vw 线性缩放无边界。
解法：用 clamp(min, vw, max) 限制范围。

坑 3：100vh 高度遮挡
结论：底部导航被地址栏或横条遮挡。
原因：vh 不随地址栏动态收缩。
解法：用 100dvh 或 JS 读 visualViewport。

坑 4：图片未做响应式导致横向溢出
结论：大图撑破容器出现横向滚动条。
原因：img 默认按原始尺寸显示。
解法：img { max-width: 100%; height: auto; }。

坑 5：触控目标过小导致误触
结论：相邻按钮频繁点错。
原因：目标 < 44px 且间距不足。
解法：扩大点击区 + 增加间距 + min-height。
```
