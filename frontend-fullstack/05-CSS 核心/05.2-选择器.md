## 概述

选择器是 CSS 选中元素的手段，是 CSS 最基础也最常用的能力。掌握选择器不仅要知道「怎么写」，还要理解「优先级」和「匹配效率」，才能写出可维护、不误伤的样式。这篇笔记覆盖从基础到现代的完整选择器体系。

```text
选择器的分类：
1. 基础选择器 —— 通配、类型、类、ID
2. 属性选择器 —— 按属性匹配
3. 组合选择器 —— 按关系匹配（后代/兄弟）
4. 伪类 —— 按状态/结构匹配
```

## 基础选择器：Universal、Type、Class、ID

```css
*          /* Universal 通配符：所有元素 */
div        /* Type 类型：所有 div */
.title     /* Class 类：class="title" 的元素 */
#main      /* ID：id="main" 的元素 */
```

```text
四种基础选择器：
Universal（*）—— 选中所有元素（优先级最低，慎用，性能差）
Type（元素）—— 按标签名（div、p、span）
Class（类）—— 按 class（最常用，可复用）
ID —— 按 id（唯一，优先级高，少用）
```

```text
优先级对比：
*  = 0,0,0,0
div = 0,0,0,1
.title = 0,0,1,0
#main = 0,1,0,0
```

```text
类 vs ID 的选择：
Class —— 可复用、优先级适中、样式首选
ID    —— 页面唯一、优先级高、适合 JS 定位而非样式

样式层优先用 Class，避免 ID 的高优先级带来的覆盖困难。
```

## 属性选择器 Attribute

按元素的属性（及属性值）匹配：

```css
[disabled]          /* 有 disabled 属性的元素 */
[type="text"]       /* type 属性等于 text */
[class~="btn"]      /* class 包含 btn（空格分隔的完整词） */
[href^="https"]     /* href 以 https 开头 */
[href$=".pdf"]      /* href 以 .pdf 结尾 */
[href*="example"]   /* href 包含 example */
[lang|="zh"]        /* lang 等于 zh 或以 zh- 开头 */
```

```text
属性选择器的运算符：
[attr]       —— 有该属性
[attr=val]   —— 属性值等于 val
[attr~=val]  —— 属性值包含完整词 val（空格分隔）
[attr|=val]  —— 属性值等于 val 或以 val- 开头
[attr^=val]  —— 以 val 开头
[attr$=val]  —— 以 val 结尾
[attr*=val]  —— 包含 val
```

```text
属性选择器的典型用途：
1. [disabled] 给禁用态加样式
2. [href^="https"] 区分外链
3. [type="checkbox"] 定制复选框样式
```

## 组合选择器：后代、子、相邻兄弟、通用兄弟

```css
div p        /* Descendant 后代：div 里的所有 p（任意层级） */
div > p      /* Child 子：div 的直接子 p */
h1 + p       /* Adjacent Sibling 相邻兄弟：紧跟 h1 的 p */
h1 ~ p       /* General Sibling 通用兄弟：h1 后的所有兄弟 p */
```

```text
四种组合器：
空格（后代）—— 祖先内的所有后代（任意深度）
>（子）—— 直接子元素
+（相邻兄弟）—— 紧跟其后的一个兄弟
~（通用兄弟）—— 之后的所有兄弟
```

```html
<div>
  <p>直接子元素</p>        <!-- div > p 命中，div p 也命中 -->
  <section>
    <p>后代（非直接子）</p> <!-- 只 div p 命中 -->
  </section>
  <h1>标题</h1>
  <p>相邻兄弟</p>           <!-- h1 + p 命中，h1 ~ p 也命中 -->
  <p>通用兄弟</p>           <!-- 只 h1 ~ p 命中 -->
</div>
```

```text
后代 vs 子的选择：
后代（空格）—— 宽松，命中所有层级
子（>）—— 严格，只命中直接子元素

子选择器更精确，避免误伤深层元素，可维护性更好。
```

## 状态伪类：hover、focus、active 等

状态伪类按「交互状态」匹配：

```css
a:hover          /* 鼠标悬停 */
button:focus     /* 获得焦点 */
button:focus-visible /* 键盘焦点（区别于鼠标点击） */
button:active    /* 按下（激活）时 */
input:checked    /* 选中的复选框/单选 */
input:disabled   /* 禁用的控件 */
input:enabled    /* 可用的控件 */
```

```text
focus vs focus-visible（重要区别）：
:focus —— 任何获得焦点的元素（鼠标点击和键盘 Tab 都触发）
:focus-visible —— 只在「键盘导航」时触发（鼠标点击不触发）

实践：用 :focus-visible 做焦点样式，避免鼠标点击也显示焦点框。
```

```css
button:focus-visible {
  outline: 2px solid blue;  /* 键盘导航时显示焦点 */
}
```

```text
hover/focus/active 的顺序（LVHA）：
link -> visited -> hover -> active（爱恨原则 Love Hate）
:active 要写在 :hover 之后，否则被覆盖。
```

## 结构伪类：first-child、last-child、nth-child

结构伪类按「元素在兄弟中的位置」匹配：

```css
li:first-child   /* 第一个子元素 */
li:last-child    /* 最后一个子元素 */
li:nth-child(2)  /* 第 2 个子元素 */
li:nth-child(odd)   /* 奇数位置（1,3,5...） */
li:nth-child(even)  /* 偶数位置（2,4,6...） */
li:nth-child(3n)    /* 每 3 个（3,6,9...） */
li:nth-child(2n+1)  /* 奇数（等价 odd） */
```

```text
nth-child 的公式：
nth-child(an+b) —— a 是步长，b 是偏移
nth-child(2n)   —— 偶数
nth-child(3n+1) —— 1, 4, 7...
nth-child(-n+3) —— 前 3 个
```

```text
nth-child vs nth-of-type（易混淆）：
nth-child(n)  —— 在所有兄弟元素中的位置（不管类型）
nth-of-type(n) —— 在同类型元素中的位置

li:nth-child(2)  —— 父元素的第 2 个子元素，且是 li
li:nth-of-type(2) —— 所有 li 里的第 2 个
```

```text
nth-child 的坑：
li:nth-child(2) 要求「第 2 个子元素」恰好是 li，
如果第 2 个子元素是别的标签，则不匹配。
```

## 函数伪类：not、is、where、has

现代函数式伪类：

```css
:not(.active)        /* 排除（不是 .active 的） */
:is(h1, h2, h3)      /* 匹配任一（h1 或 h2 或 h3） */
:where(h1, h2, h3)   /* 同 :is，但优先级为 0 */
article:has(> img)   /* 包含直接子 img 的 article */
```

```text
:is() vs :where()（关键区别）：
:is(h1, h2)  —— 优先级取参数里最高的（h1/h2 都是元素级 0,0,0,1）
:where(h1, h2) —— 优先级恒为 0

用途：:where 写「基础样式」（低优先级，易覆盖），
     :is 写「分组样式」（保持优先级）。
```

```css
/* :is 简化分组选择器 */
/* 老写法 */
section h1, section h2, section h3 { color: red; }
/* :is 写法 */
section :is(h1, h2, h3) { color: red; }
```

```text
:has() 父选择器（现代 CSS 的重要能力）：
CSS 一直缺「父选择器」（按子元素选中父元素），:has() 补上了。

article:has(> img) —— 包含直接 img 的 article
form:has(input:invalid) —— 包含非法输入的表单
```

```text
:not() 的要点：
1. 参数可以是选择器列表（:not(.a, .b)）
2. 不能嵌套 :not（:not(:not()) 无效）
3. 优先级取参数里最高的
```

## 应用场景实战

### 场景一：斑马纹表格 + 悬停高亮

```css
tbody tr:nth-child(odd) {
  background: #f9f9f9;   /* 奇数行浅灰 */
}
tbody tr:hover {
  background: #eef;      /* 悬停高亮 */
}
```

### 场景二：带图片的卡片加特殊样式（:has）

```css
/* 包含图片的卡片，图片区域特殊处理 */
.card:has(> img) {
  padding: 0;
}
.card:has(> img) .card-title {
  margin-top: 16px;
}
```

### 场景三：低优先级的基础样式（:where）

```css
/* 基础链接样式，低优先级，容易被具体样式覆盖 */
:where(a) {
  color: #0066cc;
  text-decoration: none;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 样式层优先用类选择器，避免 ID 和深层嵌套
2. 焦点样式用 :focus-visible，避免鼠标点击也显示焦点框
3. 分组选择器用 :is()，基础样式用 :where() 压低优先级
4. 子选择器（>）比后代选择器更精确，减少误伤
5. 结构伪类（nth-child）配 nth-of-type，理解两者区别

### 踩坑记录

```text
坑 1：nth-child 和 nth-of-type 混淆
结论：li:nth-child(2) 没选中预期的元素。
原因：nth-child 按所有兄弟的位置，nth-of-type 按同类型位置。
解法：明确要「所有兄弟里的第 n 个」还是「同类型里的第 n 个」。

坑 2：:focus 导致鼠标点击也出现焦点框
结论：点击按钮后残留蓝色焦点框，视觉突兀。
原因：:focus 对鼠标和键盘都触发。
解法：用 :focus-visible 替代 :focus 做焦点样式。

坑 3：后代选择器过宽导致误伤
结论：.nav a 误伤导航里深层嵌套的链接。
原因：空格（后代）匹配任意深度。
解法：用子选择器 .nav > a 限定直接子元素。

坑 4：:active 写在 :hover 前面被覆盖
结论：按下状态不生效。
原因：同优先级下后写的覆盖，:active 应写在 :hover 后。
解法：遵循 LVHA 顺序（link, visited, hover, active）。

坑 5：:has() 兼容性没考虑
结论：老浏览器（尤其老 Safari）:has() 不生效。
原因：:has() 是较新的特性，老浏览器不支持。
解法：查 caniuse，提供降级方案或用 JS 补充。
```
