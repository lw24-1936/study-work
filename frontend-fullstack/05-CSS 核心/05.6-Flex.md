## 概述

Flex（Flexible Box，弹性盒）是 CSS 的一维布局方案——让元素在「一行或一列」上灵活排列、对齐、分配空间。它是现代 CSS 布局的主力，替代了浮动和 inline-block 做水平排列的旧方案。

```text
Flex 的核心概念：
1. 容器（flex-container）—— 设 display: flex 的父元素
2. 项目（flex-item）—— 容器的直接子元素
3. 主轴（main axis）—— 项目排列的方向（flex-direction 决定）
4. 交叉轴（cross axis）—— 垂直于主轴的方向
```

```css
.container {
  display: flex;
}
```

```text
Flex 的两类属性：
容器属性 —— 作用在 flex-container 上，控制整体排列
子项属性 —— 作用在 flex-item 上，控制单个项目
```

## 容器属性：flex-direction、flex-wrap、justify-content、align-items、align-content、gap

### flex-direction 主轴方向

```css
.container {
  flex-direction: row;            /* 默认，水平从左到右 */
  flex-direction: row-reverse;    /* 水平从右到左 */
  flex-direction: column;         /* 垂直从上到下 */
  flex-direction: column-reverse; /* 垂直从下到上 */
}
```

### flex-wrap 换行

```css
.container {
  flex-wrap: nowrap;       /* 默认，不换行（超出收缩） */
  flex-wrap: wrap;         /* 换行 */
  flex-wrap: wrap-reverse; /* 反向换行 */
}
```

### justify-content 主轴对齐

```css
.container {
  justify-content: flex-start;   /* 默认，起点对齐 */
  justify-content: flex-end;     /* 终点对齐 */
  justify-content: center;       /* 居中 */
  justify-content: space-between; /* 两端对齐，中间均分 */
  justify-content: space-around;  /* 每个项目两侧均分 */
  justify-content: space-evenly;  /* 所有间距相等 */
}
```

### align-items 交叉轴对齐

```css
.container {
  align-items: stretch;     /* 默认，拉伸填满 */
  align-items: flex-start;  /* 起点对齐 */
  align-items: flex-end;    /* 终点对齐 */
  align-items: center;      /* 居中 */
  align-items: baseline;    /* 基线对齐 */
}
```

### align-content 多行对齐

```css
.container {
  align-content: flex-start; /* 多行时整体起点对齐 */
  align-content: center;
  align-content: space-between;
}
```

```text
align-content 只在「多行」（flex-wrap: wrap）时生效，
控制多行之间的对齐。单行无效。
```

### gap 间距

```css
.container {
  gap: 16px;          /* 行列间距都是 16px */
  gap: 16px 24px;     /* 行间距 16，列间距 24 */
}
```

```text
gap 是现代 CSS 的间距方案，替代「margin 加间距」的老做法，
避免最后一个元素也有多余 margin 的问题。
```

```text
主轴 vs 交叉轴的记忆：
flex-direction: row 时，主轴是水平，交叉轴是垂直。
justify-* 管主轴，align-* 管交叉轴。
```

## 子项属性：flex-grow、flex-shrink、flex-basis

这三个属性控制项目「如何分配剩余空间」和「如何收缩」。

### flex-basis 基准尺寸

```css
.item { flex-basis: 200px; }  /* 项目的基准尺寸（分配空间前的初始尺寸） */
.item { flex-basis: auto; }   /* 默认，按内容/width */
```

### flex-grow 放大比例

```css
.item { flex-grow: 1; }  /* 有剩余空间时按比例放大 */
```

```text
flex-grow 的机制：
容器有剩余空间时，按 flex-grow 比例分配。
flex-grow: 1 的项目都分到相等的剩余空间。
flex-grow: 0（默认）不放大。
```

### flex-shrink 缩小比例

```css
.item { flex-shrink: 1; }  /* 默认，空间不足时按比例缩小 */
.item { flex-shrink: 0; }  /* 不缩小（保持尺寸） */
```

```text
flex-shrink 的机制：
容器空间不足时，按 flex-shrink 比例收缩。
flex-shrink: 0 的项目不收缩（可能溢出）。
```

### flex 简写

```css
.item {
  flex: 1;            /* flex-grow:1, flex-shrink:1, flex-basis:0% */
  flex: 1 1 200px;    /* grow shrink basis */
  flex: none;         /* 0 0 auto（不放大不缩小） */
  flex: auto;         /* 1 1 auto */
}
```

```text
flex 简写的三种常见值：
flex: 1    —— 1 1 0%（等分剩余空间，最常用）
flex: none —— 0 0 auto（固定尺寸，不伸缩）
flex: auto —— 1 1 auto（按内容伸缩）
```

```text
flex: 1 的经典用法：
三个等宽列：每个 item 都 flex: 1，平均分配容器宽度。
```

## order 与 align-self

### order 排序

```css
.item { order: 2; }  /* 排序值，小的在前（默认 0） */
```

```text
order 的机制：
order 值小的排在前面，默认都是 0。
可改变视觉顺序（但不改变 DOM 顺序，注意可访问性）。
```

### align-self 单个项目对齐

```css
.item { align-self: center; }  /* 覆盖容器的 align-items，单独对齐 */
```

```text
align-self 的取值同 align-items，只作用于单个项目。
```

## 应用场景实战

### 场景一：水平垂直居中

```css
.center {
  display: flex;
  justify-content: center;  /* 主轴（水平）居中 */
  align-items: center;      /* 交叉轴（垂直）居中 */
  height: 300px;
}
```

### 场景二：三栏等宽布局

```css
.row {
  display: flex;
}
.col {
  flex: 1;  /* 三等分 */
}
```

### 场景三：导航栏（两端对齐）

```css
.navbar {
  display: flex;
  justify-content: space-between;  /* logo 在左，菜单在右 */
  align-items: center;
  padding: 0 16px;
}
```

### 场景四：卡片列表（flex-wrap + gap）

```css
.card-list {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card {
  flex: 1 1 300px;  /* 最小 300px，空间不足换行 */
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 间距用 gap，不用 margin（避免首尾多余间距）
2. 等分用 flex: 1，固定尺寸用 flex: none
3. 水平垂直居中用 flex（justify-content + align-items）
4. 列表换行用 flex-wrap: wrap + gap
5. 记住主轴/交叉轴：justify 管主轴，align 管交叉轴

### 踩坑记录

```text
坑 1：子元素默认被压缩变形
结论：flex 子元素被压缩，宽度比设的 width 小。
原因：flex-shrink 默认 1，空间不足时自动收缩。
解法：不想收缩的加 flex-shrink: 0，或 flex: none。

坑 2：align-content 单行不生效
结论：设了 align-content 没反应。
原因：align-content 只对多行（flex-wrap: wrap）生效。
解法：单行用 align-items，多行才用 align-content。

坑 3：flex: 1 和 flex-grow: 1 混淆
结论：以为 flex-grow: 1 就是等分，实际效果不同。
原因：flex: 1 是 1 1 0%（basis 为 0），flex-grow: 1 是 1 1 auto（basis 为 auto）。
解法：等分用 flex: 1（basis 0%），按内容伸缩用 flex: auto。

坑 4：margin: auto 在 flex 里的特殊行为
结论：flex 子元素设 margin: auto 产生意外的居中效果。
原因：flex 里 margin: auto 会吸收剩余空间（不同于普通文档流）。
解法：理解 flex 里 auto margin 是「吃剩余空间」，可用于精确定位。

坑 5：order 改变视觉顺序但影响可访问性
结论：order 改变视觉顺序，但 Tab 焦点顺序和屏幕阅读器还按 DOM 顺序。
原因：order 只改视觉，不改 DOM 和可访问性树。
解法：关键内容不要依赖 order 重排，必要时调整 DOM 顺序。
```
