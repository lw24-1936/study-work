## 概述

Grid 是 CSS 的二维布局方案——同时控制「行和列」，是页面级布局的最强工具。相比 Flex 的一维（要么行要么列），Grid 能直接定义行列网格，让元素精确摆放。

```text
Grid 的核心概念：
1. 容器（grid-container）—— display: grid 的元素
2. 网格线（grid line）—— 行和列的分隔线
3. 网格轨道（grid track）—— 两线之间的空间（行或列）
4. 网格区域（grid area）—— 行列交叉的矩形区域
```

```css
.container {
  display: grid;
}
```

```text
Grid vs Flex 的选择：
Grid —— 二维布局（行列同时控制），页面骨架、卡片网格
Flex —— 一维布局（行或列），导航栏、按钮组、组件内部排列
```

## 定义网格：grid-template-columns、grid-template-rows

grid-template-columns 定义列，grid-template-rows 定义行：

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;  /* 三列：200px + 两份均分 */
  grid-template-rows: 100px auto;        /* 两行：100px + 自适应 */
}
```

```text
grid-template-columns/rows 的取值：
固定值 —— 200px（固定像素）
比例   —— 1fr 2fr（按比例分配剩余空间）
自适应 —— auto（按内容）
函数   —— minmax()、repeat()
```

```css
/* repeat 简化重复定义 */
grid-template-columns: repeat(3, 1fr);       /* 三等分 */
grid-template-columns: repeat(2, 1fr 2fr);   /* 1fr 2fr 重复两次 */
```

```text
grid-template 简写：
grid-template: rows / columns;
grid-template: 100px auto / 1fr 1fr 1fr;
```

## fr 单位与 minmax

### fr 单位

fr（fraction，份）表示「剩余空间的比例单位」：

```css
.container {
  grid-template-columns: 1fr 2fr 1fr;  /* 1:2:1 的比例 */
}
```

```text
fr 的机制：
1fr 表示「一份剩余空间」。
先分配固定值（px/auto），剩余空间按 fr 比例分配。

1fr 2fr 1fr —— 中间列是两侧的两倍宽。
```

### minmax 函数

minmax(min, max) 定义轨道的最小/最大范围：

```css
.container {
  grid-template-columns: minmax(200px, 1fr) 1fr;
  /* 第一列最小 200px，最大 1fr */
}
```

```text
minmax 的用途：
1. 保证轨道不会太窄（min）或太宽（max）
2. 响应式：minmax(200px, 1fr) 内容不足时保底 200px
```

## 网格定位：grid-column、grid-row、grid-area

子项可以用 grid-column/grid-row 指定占据的网格位置：

```css
.item {
  grid-column: 1 / 3;   /* 从第 1 列线到第 3 列线（占 2 列） */
  grid-row: 1 / 2;      /* 第 1 行 */
}
```

```text
grid-column/grid-row 的取值：
1 / 3     —— 从网格线 1 到网格线 3
span 2    —— 跨 2 列/行
-1        —— 倒数第一根线（负数是倒序）
```

```css
/* 用 grid-area 命名区域（更直观） */
.container {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
```

```text
grid-template-areas 的用法：
用「字符串」画布局图，每个名字对应一个区域。
同名区域合并（header 占两列）。
grid-area 引用区域名。
```

```text
grid-area 简写：
grid-area: row-start / column-start / row-end / column-end;
```

## explicit grid 与 implicit grid

Grid 分「显式网格」和「隐式网格」：

```text
explicit grid（显式网格）：
通过 grid-template-columns/rows 明确定义的网格。

implicit grid（隐式网格）：
内容超出了显式定义的轨道，浏览器自动创建的额外轨道。
```

```css
.container {
  grid-template-columns: 1fr 1fr;  /* 显式定义 2 列 */
  /* 放 6 个 item，超出 2 列，自动换行创建隐式行 */
  grid-auto-rows: 100px;  /* 隐式行的尺寸 */
}
```

```text
隐式网格的控制：
grid-auto-rows —— 隐式行的高度
grid-auto-columns —— 隐式列的宽度
grid-auto-flow —— 自动放置方向（row/column/dense）
```

## auto-fit 与 auto-fill

auto-fit 和 auto-fill 是 repeat() 里的特殊关键字，用于「自动适应数量的轨道」：

```css
.container {
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  /* auto-fill：尽可能多地创建轨道（空轨道保留） */
}

.container2 {
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  /* auto-fit：创建轨道并拉伸，空的轨道折叠 */
}
```

```text
auto-fill vs auto-fit（关键区别）：
auto-fill —— 尽量多建轨道，即使没内容，空轨道也占位
auto-fit  —— 建轨道后，空的轨道折叠，剩余空间被有内容的轨道瓜分

实际效果：
auto-fill —— 内容不满时，右侧留空白
auto-fit  —— 内容不满时，内容拉伸填满
```

```text
典型用法（响应式卡片网格）：
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
每列最小 200px，空间够就多放几列，不够自动换行。
```

## gap 间距

gap 设置行列间距（同 Flex 的 gap）：

```css
.container {
  gap: 16px;        /* 行列都是 16px */
  gap: 16px 24px;   /* 行 16，列 24 */
  row-gap: 16px;    /* 只设行间距 */
  column-gap: 24px; /* 只设列间距 */
}
```

## 应用场景实战

### 场景一：经典页面布局（header + sidebar + main + footer）

```css
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}
```

### 场景二：响应式卡片网格

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 20px;
}
/* 每个卡片最小 250px，自动适应列数，空间够就多放 */
```

### 场景三：全屏居中单个元素

```css
.center {
  display: grid;
  place-items: center;  /* 水平和垂直都居中（align + justify 简写） */
  min-height: 100vh;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 页面骨架用 grid-template-areas（直观表达布局）
2. 响应式卡片用 repeat(auto-fill, minmax(200px, 1fr))
3. 等分用 repeat(n, 1fr)，比例用 fr
4. 间距用 gap，不用 margin
5. 单元素居中用 place-items: center

### 踩坑记录

```text
坑 1：grid 子元素默认拉伸填满
结论：子元素被拉伸到网格轨道大小。
原因：默认 align-items/justify-items 是 stretch。
解法：不想拉伸设 align-self/justify-self，或容器设 place-items。

坑 2：auto-fill 和 auto-fit 混淆
结论：卡片不满一行时，布局和预期不符。
原因：auto-fill 保留空轨道留白，auto-fit 折叠空轨道拉伸内容。
解法：要内容拉伸填满用 auto-fit，要固定列宽留白用 auto-fill。

坑 3：grid-template-areas 区域名拼错
结论：布局错乱，区域不显示。
原因：areas 字符串里的名字和 grid-area 对不上。
解法：areas 和 grid-area 的名字严格一致（用引号小心空格）。

坑 4：minmax 里 min 大于 max 报错
结论：轨道定义无效。
原因：minmax(min, max) 要求 min <= max。
解法：检查 minmax 参数，min 不能大于 max。

坑 5：隐式轨道尺寸意外
结论：内容超出显式网格，隐式行的尺寸和预期不符。
原因：没设 grid-auto-rows，隐式行按内容自适应。
解法：显式设置 grid-auto-rows 控制隐式轨道尺寸。
```
