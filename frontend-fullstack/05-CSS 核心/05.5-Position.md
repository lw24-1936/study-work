## 概述

position 属性控制元素的定位方式，是 CSS 布局的重要补充（flex/grid 管「排列」，position 管「脱离」）。五种定位方式各有用途：static 默认、relative 微调、absolute 绝对定位、fixed 固定视口、sticky 滚动粘性。

```text
五种定位方式：
static   —— 默认，正常文档流
relative —— 相对自身位置偏移
absolute —— 相对最近的定位祖先
fixed    —— 相对视口固定
sticky   —— 滚动时粘性固定
```

## static 静态定位

static 是默认值，元素按正常文档流排列：

```css
div { position: static; }  /* 默认，可省略 */
```

```text
static 的特点：
1. 正常文档流（不脱离）
2. top/left/right/bottom/z-index 不生效
3. 所有元素的默认状态
```

## relative 相对定位

relative 相对「自身原来的位置」偏移，但仍占位：

```css
.box {
  position: relative;
  top: 10px;    /* 向下移 10px（相对原位置） */
  left: 20px;   /* 向右移 20px */
}
```

```text
relative 的关键特性：
1. 相对自身原位置偏移（不是相对父元素）
2. 仍占原来的空间（文档流位置不变）
3. 常用于：给 absolute 子元素当「定位基准」
```

```text
relative 的典型用途：
作为 absolute 子元素的「定位上下文」（父 relative + 子 absolute）。
```

## absolute 绝对定位

absolute 相对「最近的定位祖先」定位，脱离文档流：

```css
.parent { position: relative; }  /* 定位基准 */
.child {
  position: absolute;
  top: 0;
  right: 0;  /* 定位到父元素右上角 */
}
```

```text
absolute 的定位基准：
相对最近的「非 static 定位的祖先」（relative/absolute/fixed）。
如果找不到，就相对「初始包含块」（通常是视口）。

关键：absolute 不是相对「父元素」，而是相对「定位祖先」。
父元素没设定位，absolute 会一直往上找。
```

```text
absolute 的特性：
1. 脱离文档流（不占位）
2. 尺寸收缩到内容（宽度不再自动填满）
3. 可用 top/left/right/bottom 精确控制位置
```

```text
absolute 的典型用途：
1. 角标/徽标（定位到卡片右上角）
2. 下拉菜单（定位到按钮下方）
3. 居中（left: 50% + transform: translateX(-50%)）
```

## fixed 固定定位

fixed 相对「视口」定位，页面滚动也不动：

```css
.back-to-top {
  position: fixed;
  bottom: 20px;
  right: 20px;  /* 固定在视口右下角 */
}
```

```text
fixed 的特性：
1. 相对视口定位，滚动不移动
2. 脱离文档流
3. 常用于：固定导航栏、返回顶部按钮、悬浮客服

注意：祖先有 transform/filter 时，fixed 会相对该祖先而非视口（特殊情况）。
```

## sticky 粘性定位

sticky 是 relative 和 fixed 的结合：正常滚动，到阈值后「粘住」：

```css
.header {
  position: sticky;
  top: 0;  /* 滚动到顶部时粘住 */
}
```

```text
sticky 的机制：
1. 正常在文档流里滚动（像 relative）
2. 滚动到阈值（如 top: 0）时「粘住」（像 fixed）
3. 粘住范围受父元素限制（父元素滚出视口，sticky 也滚出）
```

```text
sticky 的典型用途：
1. 吸顶导航栏
2. 表格吸顶表头
3. 长列表的分组标题吸顶
```

```text
sticky 生效的条件：
1. 设置 top/bottom/left/right 至少一个阈值
2. 父元素高度足够（父元素太矮没空间粘住）
3. 父元素没有 overflow: hidden（会破坏 sticky）
```

## z-index 与 stacking context 层叠上下文

### z-index

z-index 控制「重叠元素」的上下顺序，值大的在上层：

```css
.element {
  position: absolute;
  z-index: 10;  /* 数值越大越靠上 */
}
```

```text
z-index 生效的前提：
元素必须是「定位元素」（position 非 static）或 flex/grid 子元素。
static 元素的 z-index 无效。
```

### stacking context 层叠上下文

层叠上下文是「z-index 比较的边界」，决定了 z-index 的比较范围。

```text
层叠上下文（Stacking Context）：
一组元素形成的独立层叠空间，内部 z-index 只在内部比较，
不会跨出边界和外部元素比较。
```

```text
创建层叠上下文的条件（常见）：
1. position 非 static + z-index 非 auto
2. transform / filter / opacity < 1
3. position: fixed / sticky
4. flex/grid 子元素 + z-index 非 auto
```

```text
z-index 的「失效」现象（层叠上下文的坑）：
父元素 z-index 低，子元素 z-index 再高也盖不过父元素之上的其他元素，
因为子元素被「锁」在父元素的层叠上下文里。
```

```html
<style>
  .parent { position: relative; z-index: 1; }
  .child { position: absolute; z-index: 9999; }  /* 无效：被锁在 parent 里 */
  .sibling { position: relative; z-index: 2; }    /* 2 > 1，sibling 盖过 parent */
</style>
```

## 应用场景实战

### 场景一：卡片角标（absolute）

```css
.card { position: relative; }
.badge {
  position: absolute;
  top: -8px;
  right: -8px;
}
```

### 场景二：吸顶导航（sticky）

```css
.navbar {
  position: sticky;
  top: 0;
  z-index: 100;
  background: #fff;
}
```

### 场景三：绝对定位水平垂直居中

```css
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. absolute 配 relative 父元素（明确定位基准）
2. 吸顶用 sticky（替代 JS 监听滚动实现 fixed）
3. z-index 用「层」管理（10/100/1000 分层，避免随意设值）
4. 理解层叠上下文，避免 z-index 失效的困惑
5. 固定悬浮元素用 fixed，页面内定位用 absolute

### 踩坑记录

```text
坑 1：absolute 定位基准不是父元素
结论：absolute 元素相对「视口」定位，而不是父元素。
原因：父元素没设 position，absolute 一直往上找到定位祖先。
解法：给父元素设 position: relative。

坑 2：z-index 设了不生效
结论：元素设了高 z-index 还是被盖住。
原因：z-index 只对定位元素生效，或被父元素的层叠上下文限制。
解法：确认元素是定位元素，检查是否被层叠上下文「锁住」。

坑 3：sticky 不生效
结论：写了 position: sticky 没反应。
原因：没设 top 阈值，或父元素 overflow: hidden，或父元素高度不够。
解法：设 top 值，检查父元素是否 overflow 限制、高度是否足够。

坑 4：fixed 定位相对父元素而非视口
结论：fixed 元素随父元素滚动。
原因：祖先元素有 transform/filter 等属性，fixed 改相对该祖先定位。
解法：把 fixed 元素移出有 transform 的祖先，或改用其他方案。

坑 5：用 fixed 实现吸顶导致内容跳动
结论：fixed 吸顶时，元素脱离文档流，下方内容上移跳动。
原因：fixed 不占位，原位置空出来。
解法：吸顶用 sticky（保留占位），或 fixed 时补一个占位元素。
```
