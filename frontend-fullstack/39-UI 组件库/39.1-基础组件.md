## 概述

基础组件是构成界面的最小交互单元，涵盖输入（Input、Select）、选择（Checkbox、Radio、Switch）、展示（Avatar、Badge、Tag）、浮层（Tooltip、Popover、Modal、Drawer）等。成熟的组件库（Ant Design、Element Plus 等）都提供一致的设计与交互规范。

```text
基础组件的分类：
1. 输入类 —— Input、Select、DatePicker、TimePicker、Upload
2. 选择类 —— Checkbox、Radio、Switch、Slider
3. 操作类 —— Button、Dropdown
4. 展示类 —— Avatar、Badge、Tag
5. 浮层类 —— Tooltip、Popover、Modal、Drawer
```

```jsx
// 以 Ant Design 为例的组件导入方式
import { Button, Input, Select, Checkbox, Radio, Switch, Slider,
         DatePicker, TimePicker, Upload, Avatar, Badge, Tag, Tooltip,
         Popover, Modal, Drawer, Dropdown } from 'antd';
```

## Button

Button 是最常用的操作入口，有类型（主/次/文字/链接）、尺寸、加载态、禁用态等属性。

```jsx
import { Button } from 'antd';

function Actions() {
  return (
    <div>
      <Button type="primary">主要按钮</Button>
      <Button>默认按钮</Button>
      <Button type="dashed">虚线按钮</Button>
      <Button type="text">文字按钮</Button>
      <Button type="link">链接按钮</Button>
      <Button danger>危险按钮</Button>
      <Button loading>加载中</Button>
      <Button disabled>禁用</Button>
      <Button size="small">小按钮</Button>
    </div>
  );
}
```

```jsx
// 按钮 + 异步加载态（提交场景）
function SubmitButton() {
  const [loading, setLoading] = useState(false);
  const handleClick = async () => {
    setLoading(true);
    await apiSubmit();
    setLoading(false);
  };
  return <Button type="primary" loading={loading} onClick={handleClick}>提交</Button>;
}
```

## Input

Input 用于单行文本输入，常用属性有 value（受控）、onChange、placeholder、prefix/suffix、maxLength 等。

```jsx
import { Input } from 'antd';

function NameInput() {
  const [value, setValue] = useState('');

  return (
    <div>
      <Input
        value={value}
        onChange={e => setValue(e.target.value)}
        placeholder="请输入姓名"
        maxLength={20}
        prefix={<SearchOutlined />}
        allowClear
      />
      <p>已输入：{value}</p>
    </div>
  );
}
```

```jsx
// TextArea（多行）与 Password
import { Input } from 'antd';
const { TextArea, Password } = Input;

<TextArea rows={4} placeholder="多行文本" showCount maxLength={200} />;
<Password placeholder="密码" />;
```

## Select

Select 是下拉选择，支持单选、多选、搜索、分组等。

```jsx
import { Select } from 'antd';

const options = [
  { value: 'js', label: 'JavaScript' },
  { value: 'ts', label: 'TypeScript' },
  { value: 'py', label: 'Python' },
];

function LangSelect() {
  const [value, setValue] = useState('js');

  return (
    <Select
      value={value}
      onChange={setValue}
      options={options}
      placeholder="选择语言"
      style={{ width: 200 }}
    />
  );
}
```

```jsx
// 多选 + 搜索
<Select
  mode="multiple"
  options={options}
  showSearch
  filterOption={(input, option) => option.label.includes(input)}
  placeholder="可多选、可搜索"
/>;
```

## Checkbox 与 Radio

Checkbox 用于多选（可独立勾选，也可全选），Radio 用于单选（互斥）。

```jsx
import { Checkbox, Radio } from 'antd';

// Checkbox：多选
function Hobbies() {
  const [checked, setChecked] = useState(['reading']);
  const hobbies = ['reading', 'sports', 'music'];

  return (
    <Checkbox.Group
      options={hobbies}
      value={checked}
      onChange={setChecked}
    />
  );
}

// Radio：单选
function Gender() {
  const [gender, setGender] = useState('male');
  return (
    <Radio.Group value={gender} onChange={e => setGender(e.target.value)}>
      <Radio value="male">男</Radio>
      <Radio value="female">女</Radio>
    </Radio.Group>
  );
}
```

```jsx
// 全选/反选（受控 Checkbox.Group）
const all = ['a', 'b', 'c'];
const [selected, setSelected] = useState(['a']);
const isAll = selected.length === all.length;

<Checkbox
  checked={isAll}
  indeterminate={selected.length > 0 && !isAll}
  onChange={e => setSelected(e.target.checked ? all : [])}
/>;
```

## Switch

Switch 是开关，用于「开/关」两态切换，常用于功能启用、设置项。

```jsx
import { Switch } from 'antd';

function NotifySetting() {
  const [enabled, setEnabled] = useState(true);

  return (
    <div>
      <Switch checked={enabled} onChange={setEnabled} />
      <span>邮件通知{enabled ? '已开启' : '已关闭'}</span>
    </div>
  );
}
```

```jsx
// 带加载态：切换后异步保存
function SaveSwitch() {
  const [checked, setChecked] = useState(true);
  const [loading, setLoading] = useState(false);

  const handleChange = async (val) => {
    setLoading(true);
    await apiSave(val);       // 保存成功后再更新
    setChecked(val);
    setLoading(false);
  };

  return <Switch checked={checked} loading={loading} onChange={handleChange} />;
}
```

## Slider

Slider 是滑块，用于在区间内选择数值，可单值、区间、带刻度。

```jsx
import { Slider } from 'antd';

function PriceFilter() {
  const [range, setRange] = useState([0, 1000]);

  return (
    <div>
      <Slider
        range
        min={0}
        max={1000}
        value={range}
        onChange={setRange}
        marks={{ 0: '0', 500: '500', 1000: '1000' }}
      />
      <p>价格区间：{range[0]} - {range[1]}</p>
    </div>
  );
}
```

```jsx
// 单值滑块 + 步长
<Slider min={0} max={100} step={5} defaultValue={30} />;
```

## DatePicker 与 TimePicker

DatePicker 选择日期，TimePicker 选择时间，可组合成日期时间选择。

```jsx
import { DatePicker, TimePicker } from 'antd';

function DateForm() {
  const [date, setDate] = useState(null);
  const [time, setTime] = useState(null);

  return (
    <div>
      <DatePicker value={date} onChange={setDate} />
      <TimePicker value={time} onChange={setTime} />
      <DatePicker.RangePicker />          {/* 日期区间 */}
      <DatePicker showTime />             {/* 日期 + 时间 */}
    </div>
  );
}
```

```jsx
// 受控 + 格式化（dayjs）
import dayjs from 'dayjs';
<DatePicker
  value={date}
  onChange={setDate}
  format="YYYY-MM-DD"
  disabledDate={d => d.isBefore(dayjs(), 'day')}  // 禁选过去日期
/>;
```

## Upload

Upload 用于文件上传，支持点击/拖拽、多文件、进度、图片预览等。

```jsx
import { Upload, Button } from 'antd';

function FileUpload() {
  return (
    <Upload
      action="/api/upload"
      multiple
      onChange={info => console.log(info.file.status)}
    >
      <Button>点击上传</Button>
    </Upload>
  );
}
```

```jsx
// 图片上传 + 预览（受控 fileList）
function ImageUpload() {
  const [fileList, setFileList] = useState([]);

  return (
    <Upload
      listType="picture-card"
      fileList={fileList}
      onChange={({ fileList }) => setFileList(fileList)}
      beforeUpload={(file) => {
        if (file.size > 2 * 1024 * 1024) {
          message.error('图片不能超过 2MB');
          return false;
        }
        return true;
      }}
    >
      {fileList.length >= 5 ? null : <div>上传</div>}
    </Upload>
  );
}
```

## Avatar、Badge、Tag

这三个是「标识类」展示组件：Avatar 显示头像/图标，Badge 显示数字角标，Tag 显示标签。

```jsx
import { Avatar, Badge, Tag } from 'antd';

function UserMeta() {
  return (
    <div>
      <Avatar src="/avatar.png" />
      <Avatar>张</Avatar>                          {/* 文字头像 */}

      <Badge count={5}>
        <Avatar shape="square" icon={<MessageOutlined />} />
      </Badge>

      <Tag color="blue">前端</Tag>
      <Tag color="green">已完成</Tag>
      <Tag closable onClose={() => {}}>可关闭</Tag>
    </div>
  );
}
```

```jsx
// Badge 状态点、Tag 用于状态标记
<Badge status="success" text="在线" />;
<Badge status="processing" text="处理中" />;
```

## Tooltip 与 Popover

Tooltip 是轻量提示（悬停显示文字），Popover 是承载更多内容的气泡卡片。

```jsx
import { Tooltip, Popover, Button } from 'antd';

function Hover() {
  return (
    <div>
      <Tooltip title="这是提示文字">
        <Button>悬停看提示</Button>
      </Tooltip>

      <Popover
        title="标题"
        content={<div>气泡里可以有复杂内容</div>}
      >
        <Button>点击看气泡</Button>
      </Popover>
    </div>
  );
}
```

```jsx
// Popover 内放表单、操作
<Popover
  trigger="click"
  content={
    <div>
      <p>确认删除该条目？</p>
      <Button size="small" type="primary">确认</Button>
    </div>
  }
>
  <Button>删除</Button>
</Popover>;
```

## Modal 与 Drawer

Modal 是居中模态对话框（阻断式），Drawer 是从侧边滑出的抽屉面板，适合放表单、详情。

```jsx
import { Modal, Button } from 'antd';

function ConfirmDialog() {
  const [open, setOpen] = useState(false);

  return (
    <div>
      <Button onClick={() => setOpen(true)}>打开对话框</Button>
      <Modal
        title="确认操作"
        open={open}
        onOk={() => { doDelete(); setOpen(false); }}
        onCancel={() => setOpen(false)}
        okText="确认"
        cancelText="取消"
      >
        <p>确定要删除这条记录吗？</p>
      </Modal>
    </div>
  );
}
```

```jsx
import { Drawer, Button } from 'antd';

function DetailDrawer() {
  const [open, setOpen] = useState(false);
  return (
    <div>
      <Button onClick={() => setOpen(true)}>查看详情</Button>
      <Drawer title="订单详情" open={open} onClose={() => setOpen(false)}>
        <p>这里放表单或详情内容</p>
      </Drawer>
    </div>
  );
}
```

## Dropdown

Dropdown 是下拉菜单，点击后弹出菜单项列表，常用于「更多操作」入口。

```jsx
import { Dropdown, Button } from 'antd';

function MoreActions({ onEdit, onDelete, onCopy }) {
  const items = [
    { key: 'edit', label: '编辑' },
    { key: 'copy', label: '复制' },
    { type: 'divider' },
    { key: 'delete', label: '删除', danger: true },
  ];

  const onClick = ({ key }) => {
    if (key === 'edit') onEdit();
    if (key === 'delete') onDelete();
    if (key === 'copy') onCopy();
  };

  return (
    <Dropdown menu={{ items, onClick }} trigger={['click']}>
      <Button>更多</Button>
    </Dropdown>
  );
}
```

## 应用场景实战

### 场景一：用户信息编辑表单（抽屉 + 表单组件）

```jsx
import { useState } from 'react';
import { Drawer, Button, Input, Select, Radio, DatePicker } from 'antd';

function UserEditDrawer({ open, onClose, user }) {
  const [form, setForm] = useState(user);

  const set = (key) => (value) => setForm(prev => ({ ...prev, [key]: value }));

  return (
    <Drawer title="编辑用户" open={open} onClose={onClose} width={400}>
      <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
        <Input value={form.name} onChange={e => set('name')(e.target.value)} />
        <Select
          value={form.role}
          onChange={set('role')}
          options={[{ value: 'admin', label: '管理员' }, { value: 'user', label: '普通用户' }]}
        />
        <Radio.Group value={form.gender} onChange={e => set('gender')(e.target.value)}>
          <Radio value="male">男</Radio>
          <Radio value="female">女</Radio>
        </Radio.Group>
        <DatePicker value={form.birthday} onChange={set('birthday')} />
        <Button type="primary" onClick={() => onSave(form)}>保存</Button>
      </div>
    </Drawer>
  );
}
```

### 场景二：筛选栏（Select + Slider + Switch 组合）

```jsx
import { Select, Slider, Switch } from 'antd';

function FilterBar({ filters, onChange }) {
  return (
    <div className="filter-bar">
      <Select
        value={filters.category}

        options={[
          { value: 'all', label: '全部分类' },

        onChange={v => onChange('inStock', v)}
        checkedChildren="有货"
        unCheckedChildren="全部"
      />
    </div>
  );
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 输入类组件优先用「受控」模式，状态单一来源
2. 表单多字段时用表单库统一管理，避免散落的 useState
3. 上传做客户端校验（大小、类型），再走服务端二次校验
4. 弹层类（Modal/Drawer/Dropdown）控制 open 状态，统一关闭逻辑
5. 危险操作（删除）加二次确认，且按钮用 danger 视觉

### 踩坑记录

```text
坑 1：Input 受控但 value 写成 undefined
结论：控制台警告，输入框从受控切到非受控。
原因：value 初始为 undefined/null，React 视为非受控。
解法：value 初始给空字符串 ''，或用 defaultValue 做非受控。

坑 2：Select 的 value 与 options 类型不一致
结论：选中项不显示或 onChange 拿到异常值。
原因：value 是数字、option 的 value 是字符串。
解法：统一 value 类型（都字符串或都数字）。

坑 3：Modal 关闭后表单数据未重置
结论：再次打开还残留上次内容。
原因：组件未销毁，内部 state 保留。
解法：用 destroyOnClose 销毁，或在 onClose 时手动重置。

坑 4：Upload 上传失败未处理
结论：文件列表卡在 uploading 状态。
原因：onChange 只关注 done，忽略 error。
解法：处理 error 状态，移除失败项并提示重试。

坑 5：日期选择器时区/格式问题
结论：提交的日期与实际相差一天或格式不符。
原因：DatePicker 内部用 dayjs，与后端时区/格式不一致。
解法：统一用 dayjs 格式化，提交前转字符串，前后端对齐时区。
```
