## 概述

数据展示组件用于把结构化数据清晰呈现给用户，包括表格（Table）、树（Tree）、列表（List）、卡片（Card）、选项卡（Tabs）、折叠面板（Collapse）等。它们是后台管理系统与信息型页面的主力。

```text
数据展示组件的定位：
1. Table —— 结构化二维数据的核心载体
2. Tree —— 层级/父子关系数据
3. List —— 一维条目的滚动展示
4. Card —— 内容的分组容器
5. Tabs/Collapse —— 空间有限时的内容组织
6. Pagination —— 大数据集的分页
7. Timeline/Statistic/Descriptions —— 信息型展示
```

```jsx
// 以 Ant Design 为例的导入
import { Table, Tree, List, Card, Tabs, Collapse,
         Pagination, Timeline, Statistic, Descriptions } from 'antd';
```

## Table

Table 是最复杂的展示组件，由列定义（columns）与数据源（dataSource）驱动，支持排序、筛选、分页、行选择、固定列等。

```jsx
import { Table } from 'antd';

const columns = [
  { title: '姓名', dataIndex: 'name', key: 'name' },
  { title: '年龄', dataIndex: 'age', key: 'age', sorter: (a, b) => a.age - b.age },
  { title: '城市', dataIndex: 'city', key: 'city' },
];

const data = [
  { key: '1', name: 'Alice', age: 28, city: '上海' },
  { key: '2', name: 'Bob', age: 34, city: '北京' },
];

function UserTable() {
  return <Table columns={columns} dataSource={data} />;
}
```

```jsx
// 带分页、行选择、自定义渲染
<Table
  columns={[
    { title: '状态', dataIndex: 'status', render: s => <Tag color={s === 'ok' ? 'green' : 'red'}>{s}</Tag> },
    { title: '操作', key: 'action', render: (_, row) => <Button onClick={() => edit(row)}>编辑</Button> },
  ]}
  dataSource={rows}
  pagination={{ pageSize: 10, total: 100 }}
  rowSelection={{ selectedRowKeys, onChange: setSelectedRowKeys }}
/>;
```

## Tree

Tree 展示层级数据，支持展开/收起、勾选（级联）、拖拽排序等。

```jsx
import { Tree } from 'antd';

const treeData = [
  {
    title: '前端',
    key: 'fe',
    children: [
      { title: 'React', key: 'react' },
      { title: 'Vue', key: 'vue' },
    ],
  },
  { title: '后端', key: 'be' },
];

function CategoryTree() {
  return (
    <Tree
      treeData={treeData}
      defaultExpandAll
      checkable
      onCheck={(checkedKeys) => console.log(checkedKeys)}
    />
  );
}
```

```jsx
// 受控展开 + 选中
<Tree
  treeData={treeData}
  expandedKeys={expanded}
  onExpand={setExpanded}
  selectedKeys={selected}
  onSelect={(keys) => setSelected(keys)}
/>;
```

## List

List 是一维条目列表，支持滚动加载、分页、自定义渲染，适合消息流、评论等场景。

```jsx
import { List } from 'antd';

const messages = [
  { id: 1, user: 'Alice', text: '早上好' },
  { id: 2, user: 'Bob', text: '项目进展如何？' },
];

function MessageList() {
  return (
    <List
      dataSource={messages}
      renderItem={(item) => (
        <List.Item key={item.id}>
          <strong>{item.user}：</strong>{item.text}
        </List.Item>
      )}
    />
  );
}
```

```jsx
// 滚动加载更多
<List
  dataSource={items}
  renderItem={render}
  loadMore={<Button onClick={loadMore}>加载更多</Button>}
/>;
```

## Card

Card 是内容分组容器，提供标题、边框、封面、操作区等插槽。

```jsx
import { Card } from 'antd';

function PostCard({ post }) {
  return (
    <Card
      title={post.title}
      extra={<a href={`/post/${post.id}`}>查看</a>}
      style={{ width: 300 }}
    >
      <p>{post.summary}</p>
    </Card>
  );
}
```

```jsx
// 网格布局的卡片
<Card title="仪表盘">
  <Card.Grid style={{ width: '50%' }}>内容 A</Card.Grid>
  <Card.Grid style={{ width: '50%' }}>内容 B</Card.Grid>
</Card>;
```

## Tabs

Tabs 用于在同一区域内切换不同视图，避免页面跳转。

```jsx
import { Tabs } from 'antd';

function DetailTabs() {
  const items = [
    { key: '1', label: '基本信息', children: <BasicInfo /> },
    { key: '2', label: '订单记录', children: <OrderList /> },
    { key: '3', label: '操作日志', children: <OperationLog /> },
  ];

  return <Tabs defaultActiveKey="1" items={items} />;
}
```

```jsx
// 受控切换，配合路由/状态
function ControlledTabs() {
  const [active, setActive] = useState('1');
  return <Tabs activeKey={active} onChange={setActive} items={items} />;
}
```

## Collapse

Collapse 是折叠面板，用于收纳大量信息，按需展开，减少页面长度。

```jsx
import { Collapse } from 'antd';

function Faq() {
  const items = [
    { key: '1', label: '如何注册？', children: <p>填写手机号即可注册。</p> },
    { key: '2', label: '如何退款？', children: <p>在订单页申请退款。</p> },
  ];

  return <Collapse items={items} defaultActiveKey={['1']} />;
}
```

```jsx
// 手风琴模式（一次只展开一个）
<Collapse accordion items={items} />;
```

## Pagination

Pagination 分页控件，控制大数据集的分页展示，通常配合 Table 或列表使用。

```jsx
import { Pagination } from 'antd';

function PagedList() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);

  const load = async () => {
    const res = await fetchList({ page, pageSize });
    setData(res);
  };

  return (
    <div>
      <List dataSource={data} renderItem={render} />
      <Pagination
        current={page}
        pageSize={pageSize}
        total={100}
        onChange={(p, ps) => { setPage(p); setPageSize(ps); }}
        showSizeChanger
        showTotal={t => `共 ${t} 条`}
      />
    </div>
  );
}
```

## Timeline

Timeline 按时间顺序展示事件流，适合操作日志、物流轨迹、版本记录。

```jsx
import { Timeline } from 'antd';

function LogTimeline({ logs }) {
  const items = logs.map(log => ({
    color: log.type === 'error' ? 'red' : 'green',
    children: `${log.time} — ${log.content}`,
  }));

  return <Timeline items={items} />;
}
```

```jsx
// 静态示例
<Timeline
  items={[
    { children: '创建订单 2026-08-13 10:00' },
    { children: '已发货 2026-08-13 14:00' },
    { children: '已签收 2026-08-14 09:30' },
  ]}
/>;
```

function KpiCards() {

## Descriptions

Descriptions 以「标签-值」成对方式展示对象属性，适合详情页的信息罗列。

```jsx
import { Descriptions } from 'antd';

function UserDescriptions({ user }) {
  return (
    <Descriptions title="用户信息" bordered column={2}>
      <Descriptions.Item label="姓名">{user.name}</Descriptions.Item>

      <Descriptions.Item label="城市">{user.city}</Descriptions.Item>
      <Descriptions.Item label="邮箱">{user.email}</Descriptions.Item>
    </Descriptions>
  );
}
```

## 应用场景实战

### 场景一：订单列表页（Table + Pagination）

```jsx
import { useState, useEffect } from 'react';
import { Table, Tag } from 'antd';

function OrderPage() {
  const [data, setData] = useState([]);
  const [total, setTotal] = useState(0);
  const [query, setQuery] = useState({ page: 1, pageSize: 10 });

  useEffect(() => {
    fetchOrders(query).then(res => {
      setData(res.list);
      setTotal(res.total);
    });
  }, [query]);

  const columns = [
    { title: '订单号', dataIndex: 'orderNo', key: 'orderNo' },
    { title: '金额', dataIndex: 'amount', key: 'amount' },
    {
      title: '状态',
      dataIndex: 'status',
      key: 'status',
      render: s => {
        const map = { paid: ['green', '已支付'], pending: ['orange', '待支付'] };
        return <Tag color={map[s][0]}>{map[s][1]}</Tag>;
      },
    },
  ];

  return (
    <Table
      columns={columns}
      dataSource={data}
      rowKey="orderNo"
      pagination={{
        current: query.page,
        pageSize: query.pageSize,
        total,
        onChange: (page, pageSize) => setQuery({ page, pageSize }),
      }}
    />
  );
}
```

### 场景二：详情页（Descriptions + Timeline + Tabs）

```jsx
import { Descriptions, Timeline, Tabs } from 'antd';

function OrderDetail({ order }) {
  const tabs = [
    {
      key: 'info',
      label: '基本信息',
      children: (
        <Descriptions bordered column={1}>
          <Descriptions.Item label="订单号">{order.orderNo}</Descriptions.Item>
          <Descriptions.Item label="金额">￥{order.amount}</Descriptions.Item>
          <Descriptions.Item label="收货地址">{order.address}</Descriptions.Item>
        </Descriptions>
      ),
    },
    {
      key: 'log',
      label: '物流轨迹',
      children: (
        <Timeline
          items={order.logs.map(l => ({ children: `${l.time} ${l.content}` }))}
        />
      ),
    },
  ];

  return <Tabs items={tabs} />;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. Table 的 dataSource 必须提供唯一 rowKey，避免渲染错乱
2. 大量数据后端分页，前端只渲染当前页，别一次拉全量
3. 树形数据的 key 全局唯一，避免勾选/展开状态错乱
4. 详情信息优先用 Descriptions，语义清晰可维护
5. KPI 数值用 Statistic，统一格式（前缀/精度/后缀）

### 踩坑记录

```text
坑 1：Table 忘记设置 rowKey
结论：控制台警告，勾选/编辑状态错乱。
原因：默认用 index 作 key，数据变化时错位。
解法：显式设置 dataSource 中唯一的 rowKey。

坑 2：前端一次性渲染全量数据
结论：几千行数据导致页面卡顿。
原因：Table 渲染所有行，DOM 数量爆炸。
解法：后端分页 + 前端 pagination，或虚拟滚动。

坑 3：Tree 的 key 不唯一
结论：展开/勾选状态串位。
原因：不同层级用了相同 key。
解法：使用全局唯一 key（如 `${type}-${id}`）。

坑 4：Pagination 切换页后状态没同步
结论：页码变了但列表没刷新。
原因：只改了页码 state，没触发数据重新请求。
解法：把 page/pageSize 放进请求依赖，变化即重新拉取。

坑 5：Tabs 内容全部同时渲染导致慢
结论：切到某 Tab 时很卡。
原因：所有 Tab 的 children 都被渲染（非懒加载）。
解法：用 destroyOnClose 或懒加载，只在激活时渲染对应内容。
```
