## 概述

Component API 是设计系统组件的对外接口规范：同一个 Button 通过 variant、size、state 等参数组合出多种形态，通过 slot 和 composition 支持扩展。好的 Component API 让使用者无需翻源码即可正确使用，并天然保证一致性。

```text
Component API 的五个维度：
1. Variant —— 视觉变体（primary/secondary/danger）
2. Size —— 尺寸档位（sm/md/lg）
3. State —— 交互状态（hover/disabled/loading/selected）
4. Slot —— 内容插槽（icon、label、suffix）
5. Composition —— 组合能力（as-child、继承原生属性）
```

```jsx
// 一个 API 覆盖多种形态，而非造十几个组件
<Button variant="primary" size="md" disabled>提交</Button>
<Button variant="secondary" size="sm" loading>保存</Button>
```

## Variant

Variant 是同一组件的视觉变体，通过预设值收敛样式，避免使用者随意写样式破坏一致性。

```jsx
function Button({ variant = 'primary', children, ...rest }) {
  return <button className={`btn btn-${variant}`} {...rest}>{children}</button>;
}
```

```css
.btn { padding: 8px 16px; border-radius: 8px; }
.btn-primary { background: #2563eb; color: #fff; }
.btn-secondary { background: transparent; color: #2563eb; border: 1px solid #2563eb; }
.btn-danger { background: #dc2626; color: #fff; }
```

```jsx
// TypeScript 限定 variant 取值，杜绝拼写错误
type ButtonVariant = 'primary' | 'secondary' | 'danger';
interface ButtonProps {
  variant?: ButtonVariant;
}
```

## Size

Size 是尺寸档位，用 Token 阶梯定义，通常 2~4 档。

```jsx
function Button({ size = 'md', children }) {
  return <button className={`btn btn-${size}`}>{children}</button>;
}
```

```css
.btn-sm { padding: 4px 10px; font-size: 12px; }
.btn-md { padding: 8px 16px; font-size: 14px; }
.btn-lg { padding: 12px 24px; font-size: 16px; }
```

## State

State 覆盖交互与业务状态，包括 hover、active、focus、disabled、loading、selected 等。disabled 与 loading 要阻止交互，focus 要提供可见焦点环。

```jsx
function Button({ disabled = false, loading = false, onClick, children }) {
  return (
    <button
      className="btn"
      disabled={disabled || loading}
      onClick={onClick}
      aria-busy={loading}
    >
      {loading ? <span className="spinner" /> : null}
      {children}
    </button>
  );
}
```

```css
.btn:hover { filter: brightness(1.05); }
.btn:active { transform: scale(0.98); }
.btn:focus-visible { outline: 2px solid #60a5fa; outline-offset: 2px; }
.btn:disabled { opacity: 0.5; cursor: not-allowed; }
```

## Slot

Slot 是内容占位能力，让使用者向组件内注入自定义内容（图标、后缀、子标题等），保持结构不变、内容可换。

```jsx
function Card({ header, footer, children }) {
  return (
    <div className="card">
      {header && <div className="card-header">{header}</div>}
      <div className="card-body">{children}</div>
      {footer && <div className="card-footer">{footer}</div>}
    </div>
  );
}

// 用法：header/footer 即 slot
<Card header={<h3>标题</h3>} footer={<button>操作</button>}>
  卡片正文
</Card>
```

```jsx
// 命名 Slot（Vue 风格）
<template>
  <div class="card">
    <slot name="header" />
    <slot />
    <slot name="footer" />
  </div>
</template>
```

## Composition

Composition 让组件具备组合能力：转发 ref、透传原生属性、as-child 支持替换渲染元素，避免组件 API 与原生元素割裂。

```jsx
import { forwardRef } from 'react';

// 透传所有原生 button 属性 + 转发 ref
const Button = forwardRef(function Button({ variant = 'primary', className, ...rest }, ref) {
  return <button ref={ref} className={`btn btn-${variant} ${className ?? ''}`} {...rest} />;
});

// asChild：渲染成使用者指定的子元素（Radix UI 的 Slot 模式）
function Slot({ children, ...props }) {
  return React.cloneElement(children, { ...props, ...children.props });
}
```

```jsx
// 组合使用：Button 包 Link，渲染成链接但保持按钮样式
<Button asChild>
  <a href="/docs">查看文档</a>
</Button>
```

## Accessibility

组件的无障碍是硬性要求：语义标签、ARIA 属性、键盘可达、焦点管理都要内建到组件里，而不是靠使用者自觉。

```jsx
function Tabs({ items, active, onChange }) {
  return (
    <div role="tablist">
      {items.map(item => (
        <button
          key={item.id}
          role="tab"
          id={`tab-${item.id}`}
          aria-selected={active === item.id}
          aria-controls={`panel-${item.id}`}
          onClick={() => onChange(item.id)}
        >
          {item.label}
        </button>
      ))}
    </div>
  );
}
```

```jsx
// Dialog 的无障碍要点：焦点圈定 + Esc 关闭 + 背景锁定
function Dialog({ open, onClose, children }) {
  if (!open) return null;
  return (
    <div role="dialog" aria-modal="true" onKeyDown={e => e.key === 'Escape' && onClose()}>
      {children}
    </div>
  );
}
```

## 应用场景实战

### 场景一：完整的 Button 组件（Variant + Size + State + 原生属性透传）

```jsx
import { forwardRef } from 'react';

const Button = forwardRef(function Button({
  variant = 'primary',
  size = 'md',
  disabled = false,
  loading = false,
  className,
  children,
  ...rest
}, ref) {
  return (
    <button
      ref={ref}
      className={['btn', `btn-${variant}`, `btn-${size}`, className].filter(Boolean).join(' ')}
      disabled={disabled || loading}
      aria-busy={loading}
      {...rest}
    >
      {loading && <span className="spinner" aria-hidden="true" />}
      {children}
    </button>
  );
});

export default Button;
```

### 场景二：可组合的 Input 组件（前缀/后缀 Slot）

```jsx
function Input({ prefix, suffix, ...rest }) {
  return (
    <div className="input-group">
      {prefix && <span className="input-prefix">{prefix}</span>}
      <input className="input" {...rest} />
      {suffix && <span className="input-suffix">{suffix}</span>}
    </div>
  );
}

// 用法
<Input
  prefix={<SearchIcon />}
  suffix={<button>清除</button>}
  placeholder="搜索"
  aria-label="搜索"
/>
```

## 最佳实践与踩坑记录

### 最佳实践

1. variant/size/state 用联合类型收敛取值，不用任意字符串
2. 组件透传原生属性并转发 ref，不吞掉使用者的合法属性
3. disabled 和 loading 都要阻止交互，并设置对应 ARIA 状态
4. 插槽内容遵循命名约定，图标用 aria-hidden 避免被读屏重复朗读
5. 键盘操作与焦点管理内建在组件里，不依赖使用者

### 踩坑记录

```text
坑 1：className 被组件内部覆盖
结论：使用者传的 className 不生效。
原因：组件内部写了 className="btn" 且没有拼接外部 className。
解法：合并 className，把外部传入的放最后以支持覆盖。

坑 2：rest 展开把 disabled 覆盖
结论：loading 状态下按钮仍可点击。
原因：{...rest} 写在 disabled 之后，外部传的 disabled=false 覆盖了内部 disabled=loading。
解法：disabled 等受控状态写在 {...rest} 之后，保证内部状态优先。

坑 3：icon 按钮无 label 导致读屏空白
结论：只有图标的按钮，读屏软件读不出任何内容。
原因：SVG 图标没有可访问名称。
解法：加 aria-label 或 visually-hidden 文本，图标加 aria-hidden。

坑 4：variant 传入拼写错误不报错
结论：传 variant="primay" 静默失效，按钮无样式。
原因：variant 是普通字符串，没有类型约束。
解法：用 TS 联合类型定义，编译期即报错。

坑 5：焦点环被 outline: none 抹掉
结论：键盘用户看不到焦点在哪。
原因：为了美观写了 outline: none，又没补替代方案。
解法：用 :focus-visible 提供焦点环，或自定义 outline 样式。
```
