## 概述

Design Token 是把设计决策（颜色、字号、间距、圆角等）抽象成**平台无关的命名变量**，是设计系统里设计端与工程端共享的唯一事实来源。设计师在 Figma 里改一个 Token，工程侧通过工具同步，全站视觉一致更新。

```text
Design Token 的核心价值：
1. 单一事实来源 —— 设计与代码共享同一套命名变量
2. 平台无关 —— 同一 Token 可编译成 CSS 变量、JS 对象、iOS/Android 资源
3. 语义化 —— 用 color.bg.primary 而非 #ffffff 表达意图
4. 可维护 —— 改一处 Token，全站引用处自动更新
5. 约束收敛 —— 限定取值范围，避免设计师/开发者各造轮子
```

```css
/* 原始值（不直接用）→ 语义 Token（使用方只依赖这一层） */
:root {
  /* 语义 Token */
  --color-bg: #ffffff;
  --color-text: #1a1a1a;
  --space-md: 16px;
}
```

## Color

颜色 Token 通常分两层：**原始色板（palette）** 和 **语义色（semantic）**。语义色指向用途（背景/文字/主色/危险），原始色板按色阶编号。

```css
:root {
  /* 原始色板 */
  --blue-500: #3b82f6;
  --blue-600: #2563eb;

  /* 语义色：引用原始色板 */
  --color-primary: var(--blue-500);
  --color-primary-hover: var(--blue-600);
  --color-text: #1f2937;
  --color-text-secondary: #6b7280;
  --color-bg: #ffffff;
  --color-border: #e5e7eb;
  --color-danger: #ef4444;
}
```

```js
// Token 同时编译成 JS 对象，供 canvas/图表等非 CSS 场景使用
export const colors = {
  primary: '#3b82f6',
  text: '#1f2937',
  danger: '#ef4444',
};
```

## Typography

Typography Token 定义字体族、字号阶梯、字重、行高、字间距，避免字号随心所欲导致层级混乱。

```css
:root {
  --font-sans: -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif;
  --font-mono: 'SF Mono', 'Fira Code', monospace;

  /* 字号阶梯 */
  --font-size-xs: 12px;
  --font-size-sm: 14px;
  --font-size-md: 16px;
  --font-size-lg: 20px;
  --font-size-xl: 28px;

  /* 字重 */
  --font-weight-normal: 400;
  --font-weight-medium: 500;
  --font-weight-bold: 700;

  /* 行高 */
  --line-height-tight: 1.25;
  --line-height-normal: 1.6;
}
```

## Spacing

Spacing Token 基于固定步进（常见 4px 或 8px 基准）生成间距阶梯，保证布局对齐一致。

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;
  --space-8: 64px;
}

/* 用法 */
.card {
  padding: var(--space-4);
  margin-bottom: var(--space-5);
}
```

## Radius

Radius Token 统一圆角规格，通常分小/中/大/圆几档，禁止随意使用任意像素值。

```css
:root {
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;
  --radius-full: 9999px;
}

/* 按钮用 md，卡片用 lg，头像用 full */
.button { border-radius: var(--radius-md); }
.avatar { border-radius: var(--radius-full); }
```

## Shadow

Shadow Token 用层级命名（1~5 级），对应不同海拔的投影，表达元素在 Z 轴上的层级关系。

```css
:root {
  --shadow-1: 0 1px 2px rgba(0, 0, 0, 0.06);
  --shadow-2: 0 2px 8px rgba(0, 0, 0, 0.10);
  --shadow-3: 0 8px 24px rgba(0, 0, 0, 0.14);

  /* 语义阴影 */
  --shadow-focus: 0 0 0 3px rgba(59, 130, 246, 0.35);
}

.dropdown { box-shadow: var(--shadow-3); }
```

## Border

Border Token 定义边框宽度、颜色、样式，配合 Radius 使用。

```css
:root {
  --border-width: 1px;
  --border-width-bold: 2px;
  --border-color: #e5e7eb;
  --border-color-strong: #d1d5db;
  --border-style: solid;
}

.input {
  border: var(--border-width) var(--border-style) var(--border-color);
}
```

## Motion

Motion Token 定义动效时长、缓动函数，保证全站动画节奏一致、可访问（可被 prefers-reduced-motion 关闭）。

```css
:root {
  --duration-fast: 120ms;
  --duration-base: 200ms;
  --duration-slow: 320ms;

  --ease-in: cubic-bezier(0.4, 0, 1, 1);
  --ease-out: cubic-bezier(0, 0, 0.2, 1);
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
}

.button {
  transition: background-color var(--duration-base) var(--ease-out);
}

/* 无障碍：用户偏好减少动效时关闭 */
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; }
}
```

## Z-index

Z-index Token 用命名层级约束层叠顺序，避免出现 z-index: 99999 这种失控写法。

```css
:root {
  --z-dropdown: 100;
  --z-sticky: 200;
  --z-fixed: 300;
  --z-modal: 400;
  --z-tooltip: 500;
}

.modal { z-index: var(--z-modal); }
.tooltip { z-index: var(--z-tooltip); }
```

## 应用场景实战

### 场景一：用 Token 搭建一套浅色主题变量

```css
:root {
  /* 色板 */
  --gray-50: #f9fafb;
  --gray-900: #111827;
  --blue-500: #3b82f6;

  /* 语义 */
  --color-bg: var(--gray-50);
  --color-text: var(--gray-900);
  --color-primary: var(--blue-500);

  /* 间距 / 圆角 */
  --space-4: 16px;
  --radius-md: 8px;
}

.card {
  background: var(--color-bg);
  color: var(--color-text);
  padding: var(--space-4);
  border-radius: var(--radius-md);
}
```

### 场景二：Token 编译为 JS，供 Canvas 绘制使用

```js
// tokens.js —— 与 CSS 变量同源，供非 CSS 环境使用
export const tokens = {
  color: { primary: '#3b82f6', text: '#111827' },
  space: { md: 16, lg: 24 },
  radius: { md: 8 },
};

const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');
ctx.fillStyle = tokens.color.primary;
ctx.roundRect(20, 20, 200, 100, tokens.radius.md);
ctx.fill();
```

## 最佳实践与踩坑记录

### 最佳实践

1. 分两层：原始色板 + 语义 Token，使用方只依赖语义层
2. Token 命名表达用途（bg/text/primary），不表达具体值（blue-500 只在原始层出现）
3. 间距用固定步进阶梯，禁止任意值
4. 动效 Token 必须配合 prefers-reduced-motion
5. Token 同时产出 CSS 变量与 JS 对象，覆盖 DOM 与 Canvas/WebGL 场景

### 踩坑记录

```text
坑 1：直接用原始色值而非语义 Token
结论：改主题时到处漏改，视觉不一致。
原因：使用方写死了 #3b82f6，主题切换只改了语义层。
解法：所有组件只引用语义 Token，原始值只出现在 Token 定义处。

坑 2：Token 命名带具体颜色
结论：主色从蓝改成绿，--color-blue 语义失效。
原因：命名耦合了具体颜色而非用途。
解法：用 --color-primary 这类用途命名，颜色值可自由替换。

坑 3：z-index 值失控
结论：弹窗被别的元素盖住，改 z-index: 99999 仍然出问题。
原因：z-index 没有统一层级约定，各组件随意赋值。
解法：用命名 Token（--z-modal 等）定义层级，只在规定档位取值。

坑 4：间距不统一导致对不齐
结论：列表项间距 13px、15px、17px 混杂，视觉不齐。
原因：开发者随手写间距，没有 Token 约束。
解法：统一走 --space-N 阶梯，review 时禁止裸像素间距。

坑 5：动效时长不统一
结论：不同组件的 hover 反馈快慢不一，体验割裂。
原因：transition 时长散落在各组件。
解法：统一用 --duration-* 与 --ease-* Token。
```
