## 概述

Web Animations API（WAAPI）把 CSS 动画的能力搬进 JavaScript，通过 element.animate() 创建动画对象，可动态控制播放、暂停、反向、调速，且底层走与 CSS 动画相同的合成器管线，性能一致。

```text
WAAPI 三大核心对象：
1. Animation —— 动画实例，提供 play/pause/finish/cancel 等控制
2. KeyframeEffect —— 关键帧效果，定义目标元素与关键帧序列
3. AnimationTimeline —— 时间轴，驱动动画的进度来源

相比 CSS 动画的优势：
1. 运行时动态创建关键帧，无需预写 CSS
2. 可精细控制播放状态与时间
3. 通过 Promise 感知动画结束
4. 与 JS 状态联动更自然
```

```js
// 最小示例：与 CSS animation 等价的 JS 写法
const box = document.querySelector('.box');
const anim = box.animate(
  [
    { transform: 'translateX(0)', opacity: 1 },
    { transform: 'translateX(200px)', opacity: 0.5 },
  ],
  {
    duration: 1000,
    easing: 'ease-in-out',
    fill: 'both',
  }
);
```

## Animation

Animation 对象是 element.animate() 的返回值，代表一个正在运行（或暂停）的动画，提供完整的播放控制接口。

```text
Animation 常用方法：
1. play() —— 播放
2. pause() —— 暂停
3. reverse() —— 反向播放
4. finish() —— 跳到结束状态
5. cancel() —— 取消并回到初始状态
6. updatePlaybackRate() —— 调整播放速率

常用属性：
1. playbackRate —— 播放速率（1 正常，负值反向）
2. currentTime —— 当前时间（毫秒），可读写
3. effect —— 关联的 KeyframeEffect
4. finished —— 动画结束的 Promise
5. onfinish —— 结束回调
```

```js
const anim = element.animate(
  [{ transform: 'scale(1)' }, { transform: 'scale(1.5)' }],
  { duration: 800 }
);

anim.pause();                 // 暂停
anim.play();                  // 继续
anim.reverse();               // 反向
anim.playbackRate = 2;        // 2 倍速
anim.currentTime = 400;       // 跳到 400ms 处
anim.cancel();                // 取消
```

```js
// 通过 Promise 感知动画结束
anim.finished.then(() => {
  console.log('动画播放完成');
});

// 事件回调
anim.onfinish = () => console.log('finished');
anim.oncancel = () => console.log('cancelled');
```

```js
// 组合多个动画：Animation 也是可迭代的
const fadeIn = element.animate(
  [{ opacity: 0 }, { opacity: 1 }],
  { duration: 500, fill: 'forwards' }
);
const slideUp = element.animate(
  [{ transform: 'translateY(20px)' }, { transform: 'translateY(0)' }],
  { duration: 500, fill: 'forwards' }
);
// 并行播放，互不影响
```

## KeyframeEffect

KeyframeEffect 描述「在哪个元素上，按什么关键帧，用什么参数」执行动画。它把元素、关键帧、时间选项三部分解耦，是 WAAPI 的底层构建块。

```text
KeyframeEffect 构造三参数：
1. target —— 目标元素
2. keyframes —— 关键帧数组（或对象）
3. options —— 时间选项（duration、easing、delay、iterations 等）
```

```js
const effect = new KeyframeEffect(
  element,                       // 目标元素
  [                              // 关键帧数组
    { transform: 'rotate(0deg)', offset: 0 },
    { transform: 'rotate(180deg)', offset: 0.5 },
    { transform: 'rotate(360deg)', offset: 1 },
  ],
  {                              // 时间选项
    duration: 2000,
    iterations: Infinity,
    easing: 'linear',
  }
);

const anim = new Animation(effect, document.timeline);
anim.play();
```

```text
关键帧两种写法：
1. 数组写法 —— [{...}, {...}]，可带 offset 精确控制时间点
2. 对象写法 —— { opacity: [0, 1], transform: [...] }，按属性分组

offset：关键帧的时间位置（0~1），默认均分。
```

```js
// 对象写法（属性分组，等价于数组写法）
const effect2 = new KeyframeEffect(
  element,
  {
    opacity: [0, 1, 1, 0],
    transform: ['translateX(0)', 'translateX(100px)', 'translateX(100px)', 'translateX(0)'],
  },
  { duration: 3000, iterations: Infinity }
);
new Animation(effect2, document.timeline).play();
```

```js
// 复用 effect：换目标元素
const targets = document.querySelectorAll('.item');
targets.forEach((el) => {
  const cloned = new KeyframeEffect(el, effect.getKeyframes(), effect.getTiming());
  new Animation(cloned, document.timeline).play();
});
```

## AnimationTimeline

AnimationTimeline 是动画的时间轴，决定动画的进度基准。默认 document.timeline 以页面加载后的时间流逝驱动，也支持基于滚动位置的时间轴。

```text
时间轴类型：
1. document.timeline —— 默认文档时间轴（按真实时间推进）
2. ScrollTimeline —— 滚动驱动的进度时间轴
3. 自定义时间轴 —— 手动控制 currentTime

关键点：动画进度 = 时间轴的当前时间映射到 effect 的 duration。
```

```js
// 默认文档时间轴
const anim = new Animation(effect, document.timeline);
console.log(document.timeline.currentTime);  // 当前时间（毫秒）

// 手动控制时间轴进度
const tl = document.timeline;
const anim2 = new Animation(
  new KeyframeEffect(el, [{ opacity: 0 }, { opacity: 1 }], { duration: 1000 }),
  tl
);
anim2.play();
```

```js
// 滚动驱动动画（ScrollTimeline）
const scrollTimeline = new ScrollTimeline({
  source: document.querySelector('.scroll-container'),
  axis: 'block',               // 滚动方向
  scrollOffsets: [
    { target: document.querySelector('.start'), edge: 'start' },
    { target: document.querySelector('.end'), edge: 'end' },
  ],
});

const anim3 = new Animation(
  new KeyframeEffect(
    document.querySelector('.progress'),
    { width: ['0%', '100%'] },
    { duration: 1 }
  ),
  scrollTimeline
);
anim3.play();
```

```text
时间轴意义：
1. 把「动画进度」与「时间」解耦
2. 让动画可被滚动、手势等任意信号驱动
3. 是未来声明式滚动动画的基础
```

## 应用场景实战

### 场景一：Toast 消息弹入弹出

```js
function showToast(message) {
  const toast = document.createElement('div');
  toast.className = 'toast';
  toast.textContent = message;
  document.body.appendChild(toast);

  const enter = toast.animate(
    [
      { transform: 'translateY(20px)', opacity: 0 },
      { transform: 'translateY(0)', opacity: 1 },
    ],
    { duration: 300, easing: 'ease-out', fill: 'forwards' }
  );

  enter.finished.then(() => setTimeout(() => {
    toast.animate(
      [{ opacity: 1 }, { opacity: 0 }],
      { duration: 300, fill: 'forwards' }
    ).finished.then(() => toast.remove());
  }, 2000));
}
```

### 场景二：进度条随滚动填充

```js
const bar = document.querySelector('.progress-bar');
const container = document.querySelector('.article');
const timeline = new ScrollTimeline({
  source: container,
  scrollOffsets: [
    { target: container, edge: 'start' },
    { target: container, edge: 'end' },
  ],
});
bar.animate(
  { transform: ['scaleX(0)', 'scaleX(1)'] },
  { duration: 1, fill: 'both', timeline }
);
```

## 最佳实践与踩坑记录

### 最佳实践

1. 一次性动画用完记得 cancel，避免内存泄漏
2. 用 finished Promise 串联多段动画，比 setTimeout 更可靠
3. 复杂编排优先考虑 Web Animations 而非 setTimeout 链
4. 复用关键帧数组时用 effect.getKeyframes() 提取
5. 滚动驱动动画优先用 ScrollTimeline 而非 scroll 事件 + 手动计算
6. 需要暂停/反向/调速时才用 WAAPI，纯展示动画用 CSS 更简洁

### 踩坑记录

```text
坑 1：取消后无法重新 play
结论：cancel() 后直接 play() 无反应。
原因：cancel 会把动画标记为已取消，需要重建。
解法：用 pause() 代替 cancel()，或重新创建 Animation。

坑 2：fill 未设置导致动画闪回
结论：动画结束后元素回到初始样式。
原因：默认 fill 为 none。
解法：设置 fill: 'forwards' 或 'both'。

坑 3：ScrollTimeline 浏览器兼容性
结论：部分浏览器不支持 ScrollTimeline。
原因：该 API 仍在演进，Safari 支持较晚。
解法：特性检测 + 降级为 scroll 事件手动计算进度。

坑 4：iterations: Infinity 的动画忘记取消
结论：页面切走后动画仍在运行，消耗资源。
原因：无限循环动画不会自动结束。
解法：在组件卸载/页面隐藏时调用 anim.cancel()。

坑 5：getTiming() 返回只读对象
结论：修改 getTiming() 的返回对象不生效。
原因：它返回的是副本而非引用。
解法：用 effect.updateTiming(newTiming) 更新。
```
