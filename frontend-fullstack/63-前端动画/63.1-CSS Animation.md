## 概述

CSS Animation 是浏览器内置的动画能力，包含 Transition（过渡）、Keyframes（关键帧动画）和 Transform（变换）三大支柱。三者分工不同：Transform 负责「变形」，Transition 负责「两个状态之间的平滑过渡」，Keyframes 负责「多阶段编排动画」。它们由合成器线程驱动，性能远优于 JS 逐帧改样式。

```text
CSS 动画三大支柱：
1. Transform —— 位移、旋转、缩放、倾斜等几何变换，不触发回流
2. Transition —— 状态 A 到状态 B 的一次性平滑过渡
3. Keyframes —— 多阶段、可循环的复杂动画编排

优势：
1. 合成器线程执行，不阻塞主线程
2. 只触发 Composite（GPU 加速），性能好
3. 声明式，易于维护
```

```css
/* 三者组合的最小示例 */
.box {
  width: 100px;
  height: 100px;
  background: #4f8cff;
  transition: transform 0.3s ease;
}
.box:hover {
  transform: scale(1.2) rotate(10deg);
}
```

## Transition

Transition 让元素从「旧状态」平滑过渡到「新状态」。它监听属性值的变化，自动在两者之间插值。

```text
Transition 四要素：
1. transition-property —— 要过渡的属性（all 或指定属性）
2. transition-duration —— 持续时间（s / ms）
3. transition-timing-function —— 时序函数（ease、linear、cubic-bezier）
4. transition-delay —— 延迟开始时间
```

```css
/* 完整写法 */
.box {
  transition-property: opacity, transform;
  transition-duration: 0.3s, 0.5s;
  transition-timing-function: ease-in-out, linear;
  transition-delay: 0s, 0.1s;
}

/* 简写：property duration timing-function delay */
.box {
  transition: opacity 0.3s ease-in-out, transform 0.5s linear 0.1s;
}
```

```css
/* 时序函数对比 */
.ease     { transition-timing-function: ease; }        /* 慢-快-慢 */
.linear   { transition-timing-function: linear; }      /* 匀速 */
.ease-in  { transition-timing-function: ease-in; }     /* 慢-快 */
.ease-out { transition-timing-function: ease-out; }    /* 快-慢 */
.custom   { transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55); } /* 回弹 */
```

```text
Transition 注意点：
1. 只对「可插值的属性」有效（颜色、长度、透明度、transform 等）
2. display: none ↔ block 无法过渡，需用 visibility + opacity 替代
3. 需要状态变化触发（hover、class 切换、focus 等）
4. 无法自动循环，只能单向一次
```

```css
/* display 无法过渡的替代方案 */
.menu {
  opacity: 0;
  visibility: hidden;
  transform: translateY(-10px);
  transition: opacity 0.3s, transform 0.3s, visibility 0.3s;
}
.menu.open {
  opacity: 1;
  visibility: visible;
  transform: translateY(0);
}
```

## Keyframes

Keyframes（关键帧动画）通过 @keyframes 定义多个时间节点的状态，再由 animation 属性驱动，可循环播放、反向、暂停。

```text
@keyframes 结构：
1. 名称 —— 自定义动画名
2. from / to —— 0% 与 100% 的别名
3. 百分比 —— 0% 到 100% 之间的任意节点
```

```css
@keyframes slide-in {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  60% {
    transform: translateX(20px);
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}
```

```css
/* animation 简写 */
.box {
  animation: slide-in 1s ease-out 0s 1 normal both;
}
/* 对应完整属性 */
.box {
  animation-name: slide-in;
  animation-duration: 1s;
  animation-timing-function: ease-out;
  animation-delay: 0s;
  animation-iteration-count: 1;        /* 或 infinite */
  animation-direction: normal;         /* normal/reverse/alternate */
  animation-fill-mode: both;           /* none/forwards/backwards/both */
  animation-play-state: running;       /* running/paused */
}
```

```css
/* 常见组合：循环脉冲 */
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.1); }
}
.dot {
  animation: pulse 2s ease-in-out infinite;
}

/* 交替往返 + 暂停控制 */
.spinner:hover {
  animation-play-state: paused;
}
```

```text
fill-mode 的含义：
1. none —— 动画结束后回到初始样式（默认）
2. forwards —— 保留最后一帧（to 状态）
3. backwards —— 延迟期间应用第一帧（from 状态）
4. both —— forwards + backwards 组合

重点：希望动画结束后停在终点，用 forwards。
```

## Transform

Transform 对元素做几何变换，是最适合动画的属性之一，因为它不触发布局（Layout），只走合成阶段。

```text
Transform 常用函数：
1. translate(x, y) —— 位移（translateX/Y/3d）
2. scale(s) —— 缩放（scaleX/Y）
3. rotate(deg) —— 旋转（rotateX/Y/Z）
4. skew(deg) —— 倾斜
5. matrix() —— 矩阵（以上函数的底层表达）
```

```css
/* 2D 变换 */
.card {
  transform: translate(20px, 10px) rotate(15deg) scale(1.1);
}

/* 3D 变换 */
.card-3d {
  transform: perspective(500px) rotateY(45deg) translateZ(100px);
}
```

```css
/* transform-origin：变换的参考原点（默认中心 50% 50%） */
.clock-hand {
  transform-origin: bottom center;   /* 指针从底部旋转 */
  animation: rotate-hand 60s linear infinite;
}
@keyframes rotate-hand {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
```

```text
Transform 性能原理：
1. transform / opacity 只触发 Composite（合成）
2. 不触发 Layout（回流）与 Paint（重绘）
3. 配合 will-change 或独立图层，走 GPU 合成

对比：修改 width/height/top/left 会触发回流，动画卡顿。
```

```css
/* 性能优化：提前声明 will-change */
.list-item {
  will-change: transform;
}
.list-item:hover {
  transform: translateY(-4px);
}
```

```text
多个 transform 注意点：
transform 是单一属性，写两次会「覆盖」而非「叠加」。
要叠加多个变换，必须写在同一行，用空格分隔。
```

## 应用场景实战

### 场景一：按钮悬停反馈

```css
.btn {
  padding: 12px 24px;
  background: #4f8cff;
  color: #fff;
  border-radius: 8px;
  transition: transform 0.2s, box-shadow 0.2s, background 0.2s;
}
.btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 20px rgba(79, 140, 255, 0.4);
  background: #3a7bf0;
}
.btn:active {
  transform: translateY(0) scale(0.97);
}
```

### 场景二：骨架屏加载动画

```css
@keyframes shimmer {
  0%   { background-position: -200px 0; }
  100% { background-position: 200px 0; }
}
.skeleton {
  width: 100%;
  height: 20px;
  border-radius: 4px;
  background: linear-gradient(90deg, #eee 25%, #f6f6f6 50%, #eee 75%);
  background-size: 200px 100%;
  animation: shimmer 1.2s linear infinite;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 动画优先用 transform + opacity，避免 width/height/top/left
2. 长列表动画提前加 will-change，动画结束移除
3. 尊重 prefers-reduced-motion，为「减少动态效果」用户关闭动画
4. 过渡时间一般 0.2s~0.5s，交互反馈宜短、转场可稍长
5. 多个 transform 叠加写在同一个 transform 属性里
6. 用 animation-fill-mode: forwards 保留动画终点状态

### 踩坑记录

```text
坑 1：display:none 无法过渡
结论：元素从 display:none 切换到 block 时 transition 不生效。
原因：display 不是可插值属性，且 none 时元素不渲染。
解法：用 opacity + visibility 组合实现淡入淡出。

坑 2：多个 transform 相互覆盖
结论：.a { transform: translateX(10px); } 后又写 .b { transform: rotate(45deg); }，
最终只有 rotate 生效。
原因：transform 是单一属性，后者覆盖前者。
解法：合并写 transform: translateX(10px) rotate(45deg)。

坑 3：animation 结束后闪回
结论：动画播完元素突然跳回初始样式。
原因：默认 fill-mode 为 none，动画结束移除动画样式。
解法：设置 animation-fill-mode: forwards 或 both。

坑 4：移动端 100vh 与动画抖动
结论：动画元素在地址栏收缩时抖动。
原因：移动端视口高度变化触发回流。
解法：动画避免依赖 vh 布局，用 transform 位移代替。

坑 5：忽略 reduced-motion
结论：对眩晕敏感用户造成不适。
原因：未适配系统「减少动态效果」设置。
解法：@media (prefers-reduced-motion: reduce) 关闭或简化动画。
```
