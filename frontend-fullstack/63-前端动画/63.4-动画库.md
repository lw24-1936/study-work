## 概述

动画库封装了底层动画能力（rAF、CSS、WAAPI），提供时间轴、编排、缓动、手势联动等高级特性。主流方案包括：GSAP（通用高性能动画引擎）、Framer Motion（React 生态）、Motion（Framer Motion 的独立版本）、Lottie（AE 导出动画）。

```text
四大动画库定位：
1. GSAP —— 通用 JS 动画引擎，时间轴 + 缓动，兼容性最好
2. Framer Motion —— React 组件式动画，声明式 + 手势
3. Motion —— Framer Motion 的独立通用版本（支持 Vue/React/原生）
4. Lottie —— 播放 After Effects 导出的矢量动画（JSON）
```

```text
选型参考：
1. 复杂时间轴编排、跨框架 → GSAP
2. React 项目 + 组件动画 + 手势 → Framer Motion / Motion
3. 设计师交付的 AE 动画 → Lottie
4. 简单过渡 → 原生 CSS 足够，不必引库
```

## GSAP

GSAP（GreenSock Animation Platform）是最成熟的高性能动画库，核心是 Tween（补间）与 Timeline（时间轴），可对任意属性做精细动画。

```js
// 基础补间
import gsap from 'gsap';

gsap.to('.box', {
  x: 200,               // transform: translateX(200px)
  rotation: 360,
  duration: 1.5,
  ease: 'power2.out',   // 缓动函数
  repeat: -1,           // 无限循环
  yoyo: true,           // 往返
});
```

```js
// 时间轴：顺序编排多个动画
const tl = gsap.timeline();
tl.to('.box', { x: 100, duration: 0.5 })
  .to('.box', { y: 100, duration: 0.5 })
  .from('.title', { opacity: 0, y: -20, duration: 0.4 }, '-=0.2'); // 提前 0.2s 开始
```

```js
// ScrollTrigger：滚动驱动动画
import { ScrollTrigger } from 'gsap/ScrollTrigger';
gsap.registerPlugin(ScrollTrigger);

gsap.to('.hero', {
  opacity: 0,
  scrollTrigger: {
    trigger: '.hero',
    start: 'top top',
    end: 'bottom top',
    scrub: true,       // 进度跟随滚动
  },
});
```

```text
GSAP 特点：
1. 缓动系统强大，内置几十种 ease
2. Timeline 支持位置参数（绝对/相对/标签）
3. 插件生态：ScrollTrigger、Draggable、MorphSVG
4. 可直接补间任意 JS 对象属性（不限于 DOM）
```

## Framer Motion

Framer Motion 是 React 生态最流行的动画库，以声明式组件（motion.*）表达动画，天然支持布局动画、手势与进出场。

```jsx
import { motion, AnimatePresence } from 'framer-motion';

// 基础动画：初始 + 动画
function FadeIn() {
  return (
    <motion.div
      initial={{ opacity: 0, y: 20 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.5, ease: 'easeOut' }}
    >
      内容
    </motion.div>
  );
}
```

```jsx
// 布局动画：位置变化自动过渡
function List({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <motion.li key={item.id} layout>
          {item.text}
        </motion.li>
      ))}
    </ul>
  );
}
```

```jsx
// 进出场动画（配合 AnimatePresence）
function Toggle() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button onClick={() => setOpen(!open)}>切换</button>
      <AnimatePresence>
        {open && (
          <motion.div
            initial={{ height: 0, opacity: 0 }}
            animate={{ height: 'auto', opacity: 1 }}
            exit={{ height: 0, opacity: 0 }}
          >
            面板内容
          </motion.div>
        )}
      </AnimatePresence>
    </>
  );
}
```

```jsx
// 手势：拖拽
<motion.div
  drag
  dragConstraints={{ left: 0, right: 100, top: 0, bottom: 100 }}
/>
```

```text
Framer Motion 特点：
1. 声明式组件 API，符合 React 心智
2. layout 属性实现自动布局动画
3. AnimatePresence 管理卸载动画
4. 内置手势（drag、whileHover、whileTap）
```

## Motion

Motion 是 Framer Motion 团队的独立通用动画库，脱离 React 绑定，可在 React、Vue、Svelte 及原生 JS 中使用，API 与 Framer Motion 一脉相承。

```js
// 原生 JS 用法
import { animate } from 'motion';

const controls = animate(
  '.box',
  { x: 100, rotate: 45 },
  { duration: 0.8, ease: 'easeInOut' }
);
controls.stop();          // 停止
controls.finish();        // 跳到终点
```

```jsx
// Vue 用法（配合 @motionone/vue 或 motion 的 Vue 绑定）
import { motion } from 'motion/react';

function ReactComponent() {
  return <motion.div animate={{ scale: 1.2 }} />;
}
```

```text
Motion 特点：
1. 框架无关核心，同一 API 跨 React/Vue/Svelte
2. 与 Framer Motion 共享设计理念
3. 体积更小，适合非 React 或轻量场景
4. 支持 WAAPI 底层加速
```

## Lottie

Lottie 播放由 After Effects 通过 Bodymovin 插件导出的 JSON 动画。设计师在 AE 里制作动画，前端用 lottie 库直接渲染，实现「设计即交付」。

```js
// 基础播放
import lottie from 'lottie-web';

const anim = lottie.loadAnimation({
  container: document.getElementById('lottie'),
  renderer: 'svg',          // svg / canvas / html
  loop: true,
  autoplay: true,
  path: '/animation/data.json',   // AE 导出的 JSON
});
```

```js
// 事件与控制
anim.addEventListener('complete', () => console.log('播放完成'));
anim.play();
anim.pause();
anim.setSpeed(1.5);
anim.goToAndStop(30, true);   // 跳到第 30 帧
```

```text
Lottie 特点：
1. 矢量动画，任意缩放不失真
2. 体积小（JSON + 代码，远小于视频/GIF）
3. 支持交互（分段播放、事件回调）
4. 常见场景：加载动画、空状态、徽章动效
```

## 应用场景实战

### 场景一：GSAP 编排多段入场动画

```js
import gsap from 'gsap';

const tl = gsap.timeline({ defaults: { ease: 'power2.out' } });
tl.from('.hero-title', { y: 40, opacity: 0, duration: 0.6 })
  .from('.hero-sub', { y: 20, opacity: 0, duration: 0.4 }, '-=0.3')
  .from('.hero-btn', { scale: 0.8, opacity: 0, duration: 0.3 }, '-=0.2');
```

### 场景二：React 列表增删的布局动画

```jsx
import { motion, AnimatePresence } from 'framer-motion';

function TodoList({ todos, onRemove }) {
  return (
    <ul>
      <AnimatePresence>
        {todos.map((todo) => (
          <motion.li
            key={todo.id}
            layout
            initial={{ opacity: 0, x: -20 }}
            animate={{ opacity: 1, x: 0 }}
            exit={{ opacity: 0, x: 20 }}
            onClick={() => onRemove(todo.id)}
          >
            {todo.text}
          </motion.li>
        ))}
      </AnimatePresence>
    </ul>
  );
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 简单动画用 CSS，复杂编排才引库，控制包体积
2. 动画属性优先 transform/opacity，避免布局属性
3. 组件卸载时清理动画（GSAP 用 gsap.killTweensOf，React 用 cleanup）
4. Lottie 大文件按需加载，首屏别全量引入
5. 尊重 prefers-reduced-motion，为敏感用户降级动画
6. 进离场动画务必成对定义 initial/exit，避免视觉残留

### 踩坑记录

```text
坑 1：GSAP 动画在组件卸载后仍运行
结论：React 组件卸载后动画回调继续执行，可能报错。
原因：tween/timeline 未被清理。
解法：useEffect 返回清理函数调用 gsap.killTweensOf(target)。

坑 2：Framer Motion 的 height: 'auto' 动画闪烁
结论：height 0 到 auto 动画不流畅。
原因：auto 无法插值，motion 需测量后转换。
解法：尽量用 scale/opacity 代替 height 动画。

坑 3：AnimatePresence 缺 key 导致退出动画失效
结论：列表项删除时没有退出动画，直接消失。
原因：AnimatePresence 靠 key 识别子元素的进出。
解法：每个子元素设置唯一 key。

坑 4：Lottie renderer 选错导致性能差
结论：复杂动画用 svg 渲染导致掉帧。
原因：svg 渲染逐节点更新，大动画开销高。
解法：复杂/大量动画用 canvas renderer。

坑 5：多个库混用导致动画冲突
结论：GSAP 与 CSS transition 同时控制同一属性互相干扰。
原因：两条动画管线竞争同一属性。
解法：同一元素同一属性只用一种方案驱动。
```
