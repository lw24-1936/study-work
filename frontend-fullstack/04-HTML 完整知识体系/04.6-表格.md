## 概述

表格（table）用于展示「二维数据」——行列结构的数据。注意一个关键误区：表格只用于数据展示，不用于页面布局（那是老时代 div 出现前的做法）。现代表格的正确用法是「数据表」，配合 thead/tbody、caption、scope 保证语义和可访问性。

```text
表格的两个用途界限：
数据表 —— 用 table（正确的用法）
布局   —— 用 CSS Grid/Flex（table 布局已废弃）
```

## 表格基本结构：table、tr、th、td

table 是表格容器，tr（table row）是行，th（table header）是表头单元格，td（table data）是数据单元格。

```html
<table>
  <tr>
    <th>姓名</th>
    <th>年龄</th>
    <th>城市</th>
  </tr>
  <tr>
    <td>张三</td>
    <td>25</td>
    <td>北京</td>
  </tr>
  <tr>
    <td>李四</td>
    <td>30</td>
    <td>上海</td>
  </tr>
</table>
```

```text
核心标签：
table —— 表格容器
tr    —— 表格行（table row）
th    —— 表头单元格（默认加粗居中，有语义「这是列/行标题」）
td    —— 数据单元格（table data）
```

```text
th vs td：
th —— 表头，描述这一列/行的含义（默认加粗居中）
td —— 数据，具体内容

用 th 标记表头，屏幕阅读器才能把「表头」和「数据」关联起来读。
```

## 分区：thead、tbody、tfoot

表格可以按逻辑分成表头、主体、表尾三个区：

```html
<table>
  <thead>
    <tr><th>姓名</th><th>年龄</th></tr>
  </thead>
  <tbody>
    <tr><td>张三</td><td>25</td></tr>
    <tr><td>李四</td><td>30</td></tr>
  </tbody>
  <tfoot>
    <tr><td>平均年龄</td><td>27.5</td></tr>
  </tfoot>
</table>
```

```text
三个分区的意义：
thead —— 表头（列标题）
tbody —— 数据主体（可多个）
tfoot —— 表尾（合计、汇总）

实际作用：
1. 语义清晰 —— 浏览器/阅读器能区分表头和数据
2. 滚动表头 —— 数据多时表头固定、tbody 滚动
3. 打印 —— 跨页时表头/表尾重复
```

## caption 表格标题

caption 是表格的标题，放在 table 的第一个子元素。

```html
<table>
  <caption>2026 年员工年龄统计</caption>
  <thead>...</thead>
  <tbody>...</tbody>
</table>
```

```text
caption 的要点：
1. 必须是 table 的第一个子元素
2. 一个表格一个 caption
3. 屏幕阅读器用 caption 播报表格主题
```

## 单元格合并：colspan、rowspan

colspan 合并列（横向），rowspan 合并行（纵向）。

```html
<table>
  <tr>
    <th colspan="2">合并两列的表头</th>
  </tr>
  <tr>
    <td>单元格 1</td>
    <td>单元格 2</td>
  </tr>
</table>
```

```html
<table>
  <tr>
    <td rowspan="2">合并两行</td>
    <td>第 1 行</td>
  </tr>
  <tr>
    <td>第 2 行</td>
  </tr>
</table>
```

```text
colspan 与 rowspan：
colspan="n" —— 这个单元格横跨 n 列
rowspan="n" —— 这个单元格纵跨 n 行

合并后，被「占用」的位置不再写 td。
```

## scope 与可访问性

scope 属性声明 th 是「行表头」还是「列表头」，帮助屏幕阅读器关联表头和数据。

```html
<table>
  <tr>
    <th scope="col">姓名</th>   <!-- 列的表头 -->
    <th scope="col">年龄</th>
  </tr>
  <tr>
    <th scope="row">张三</th>   <!-- 行的表头 -->
    <td>25</td>
  </tr>
</table>
```

```text
scope 的取值：
scope="col" —— 这个 th 是「列」的表头（表头描述它下面的列）
scope="row" —— 这个 th 是「行」的表头（表头描述它右边的行）

复杂表格（合并单元格）还可以用 headers + id 精确关联：
<th id="col-age">年龄</th>
<td headers="col-age">25</td>
```

```text
可访问性的意义：
屏幕阅读器读数据单元格时，会先读关联的表头：
「姓名，张三」「年龄，25」。
没有 scope/th，读出来就是一堆孤立的数字，无法理解。
```

## 应用场景实战

### 场景一：语义完整的数据表

```html
<table>
  <caption>团队成员信息</caption>
  <thead>
    <tr>
      <th scope="col">姓名</th>
      <th scope="col">角色</th>
      <th scope="col">经验（年）</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">张三</th>
      <td>前端开发</td>
      <td>5</td>
    </tr>
    <tr>
      <th scope="row">李四</th>
      <td>后端开发</td>
      <td>8</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">平均经验</td>
      <td>6.5</td>
    </tr>
  </tfoot>
</table>
```

### 场景二：移动端表格的响应式处理

```text
表格在窄屏（手机）上会溢出。常见处理：
1. 外层包 overflow-x: auto 的容器，允许横向滚动
2. 数据表转成卡片布局（用 CSS 改变 display）
3. 只保留关键列，次要列折叠
```

```css
/* 方案 1：横向滚动 */
.table-wrapper {
  overflow-x: auto;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 表格只用于数据展示，布局用 CSS Grid/Flex
2. 表头用 th（配 scope），数据用 td
3. 用 thead/tbody/tfoot 分区，加 caption 说明主题
4. 复杂表格用 headers+id 精确关联表头和数据
5. 移动端表格加横向滚动容器（overflow-x: auto）

### 踩坑记录

```text
坑 1：用表格做页面布局
结论：布局僵硬、难响应式、语义错误、可访问性差。
原因：老时代的 table 布局习惯，用 table 排版。
解法：布局用 CSS Grid/Flex，table 只放真正的数据。

坑 2：表头用 td 而非 th
结论：屏幕阅读器读不出「表头-数据」的关联。
原因：td 无语义，表头应该用 th。
解法：表头用 th（配 scope="col/row"）。

坑 3：合并单元格后多写或漏写 td
结论：表格结构错乱，单元格错位。
原因：colspan/rowspan 合并后，被占用位置还写了 td，或该写的位置漏了。
解法：合并 n 列/行，就少写 n-1 个 td，仔细核对每行单元格数。

坑 4：caption 位置错误
结论：caption 不在第一个子元素，渲染位置异常。
原因：caption 必须是 table 的第一个子元素。
解法：caption 放 table 开头，且只有一个。

坑 5：跨页打印表头丢失
结论：打印多页表格，后续页没有表头。
原因：没用 thead，浏览器无法识别表头重复。
解法：表头放 thead，浏览器打印时自动跨页重复表头。
```
