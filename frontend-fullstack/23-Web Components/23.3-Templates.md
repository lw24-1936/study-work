## 概述

template 和 slot 是 Web Components 的模板机制：template 定义惰性的 HTML 片段，slot 实现内容投影（把外部内容插入组件指定位置）。两者配合让组件既封装结构，又允许外部填充内容。

```text
核心概念：
1. template —— 不渲染的 HTML 模板，可重复克隆使用
2. slot —— 内容投影占位符，接收外部传入的内容
3. named slot —— 具名插槽，按名称匹配投影内容
4. slotchange —— 插槽内容变化时触发的事件
```

```html
<template id="card-template">
  <style>
    .card { border: 1px solid #ccc; }
  </style>
  <div class="card">
    <slot name="title">默认标题</slot>
    <slot>默认内容</slot>
  </div>
</template>
```

## template

template 元素声明一个惰性的 HTML 片段，浏览器不会渲染它，只有通过 JS 克隆并插入文档才会生效。

```html
<template id="row-template">
  <tr>
    <td></td>
    <td></td>
  </tr>
</template>
```

```js
// 克隆模板内容
const template = document.getElementById('row-template');
const clone = template.content.cloneNode(true);   // 深克隆
document.querySelector('tbody').appendChild(clone);
```

```text
template 特点：
1. 惰性 —— 内容不渲染、不加载资源、不执行脚本
2. 复用 —— 可多次 cloneNode 生成实例
3. 隔离 —— 内容在 DocumentFragment 中，不直接属于文档
4. 访问 —— 通过 template.content 获取片段
```

```js
// 用 template 批量渲染列表
const tpl = document.getElementById('item-template');
const data = ['苹果', '香蕉', '橙子'];
data.forEach((name) => {
  const node = tpl.content.cloneNode(true);
  node.querySelector('.name').textContent = name;
  document.getElementById('list').appendChild(node);
});
```

```text
注意：
1. cloneNode(true) 深克隆，false 只克隆外壳
2. template.content 是 DocumentFragment，插入后即清空引用
3. 模板内的 img 等资源在插入文档前不会加载
```

## slot

slot 是内容投影的占位符。组件内部的 slot 会接收宿主元素中传入的子内容，实现「外部提供内容，组件决定位置」。

```html
<!-- 组件内部定义 slot -->
<template id="my-panel">
  <div class="panel">
    <slot>默认内容（未传内容时显示）</slot>
  </div>
</template>
```

```html
<!-- 使用组件，传入内容 -->
<my-panel>
  <p>这段内容会被投影到 slot 里</p>
</my-panel>
```

```text
slot 工作机制：
1. 宿主元素的子节点是「可投影内容」
2. 未命名 slot 接收所有未命名（无 slot 属性）的内容
3. 若没有传入内容，显示 slot 内的默认内容（fallback）
4. 投影的是节点引用，不复制，样式仍受原作用域影响
```

```js
class MyPanel extends HTMLElement {
  connectedCallback() {
    const tpl = document.getElementById('my-panel');
    this.attachShadow({ mode: 'open' })
        .appendChild(tpl.content.cloneNode(true));
  }
}
customElements.define('my-panel', MyPanel);
```

## named slot

Named slot（具名插槽）通过 name 属性区分多个插槽位置，外部内容用 slot 属性指定要投影到哪个具名插槽。

```html
<template id="layout">
  <header><slot name="header">默认头部</slot></header>
  <main><slot>默认主体</slot></main>
  <footer><slot name="footer">默认底部</slot></footer>
</template>
```

```html
<!-- 使用：通过 slot 属性指定投影位置 -->
<my-layout>
  <h1 slot="header">我的标题</h1>
  <p>主体内容（进未命名 slot）</p>
  <span slot="footer">版权信息</span>
</my-layout>
```

```text
命名规则：
1. slot 元素用 name 属性命名
2. 内容元素用 slot 属性指向具名插槽
3. 未指定 slot 属性的内容进默认（未命名）slot
4. 一个具名插槽可接收多个投影内容
```

```js
// 访问被投影的内容
const host = document.querySelector('my-layout');
const headerSlot = host.shadowRoot.querySelector('slot[name="header"]');
headerSlot.assignedElements();   // 投影到该插槽的元素数组
```

## slotchange

slotchange 事件在插槽的投影内容发生变化时触发（节点增删），用于响应式处理插槽内容。

```js
class MySlot extends HTMLElement {
  connectedCallback() {
    const slot = this.shadowRoot.querySelector('slot');
    slot.addEventListener('slotchange', (e) => {
      console.log('插槽内容变化', slot.assignedNodes());
    });
  }
}
```

```text
slotchange 触发时机：
1. 初始投影内容建立时
2. 后续新增/移除投影节点时
3. 注意：只在「直接子节点」变化时触发，属性变化不触发
```

```js
// 典型用法：根据插槽内容决定是否显示占位
class EmptyDetect extends HTMLElement {
  connectedCallback() {
    const slot = this.shadowRoot.querySelector('slot');
    const placeholder = this.shadowRoot.querySelector('.placeholder');
    slot.addEventListener('slotchange', () => {
      placeholder.hidden = slot.assignedNodes().length > 0;
    });
  }
}
```

```text
assignedNodes 与 assignedElements：
assignedNodes()   —— 返回所有投影节点（含文本节点）
assignedElements() —— 只返回投影的元素节点（忽略文本）
```

## 应用场景实战

### 场景一：带默认内容的自定义弹窗

```html
<template id="modal-tpl">
  <style>
    .overlay { position: fixed; inset: 0; background: rgba(0,0,0,.4); }
    .dialog { background: white; padding: 16px; }
  </style>
  <div class="overlay">
    <div class="dialog">
      <slot name="title"><h2>默认标题</h2></slot>
      <slot><p>默认正文</p></slot>
    </div>
  </div>
</template>
```

```html
<my-modal>
  <h2 slot="title">确认删除？</h2>
  <p>此操作不可撤销。</p>
</my-modal>
```

### 场景二：表格行模板批量渲染

```html
<template id="row-tpl">
  <tr>
    <td class="name"></td>
    <td class="price"></td>
  </tr>
</template>
<script>
  const products = [{ name: '键盘', price: 299 }, { name: '鼠标', price: 99 }];
  const tpl = document.getElementById('row-tpl');
  products.forEach((p) => {
    const row = tpl.content.cloneNode(true);
    row.querySelector('.name').textContent = p.name;
    row.querySelector('.price').textContent = p.price;
    document.querySelector('#tbody').appendChild(row);
  });
</script>
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 template 定义组件结构，用 cloneNode(true) 生成实例
2. 插槽提供默认内容（fallback），未传内容也友好
3. 用 named slot 组织多区域布局，语义清晰
4. 需要响应插槽变化时监听 slotchange
5. 投影内容样式在外部作用域，注意继承与命名冲突

### 踩坑记录

```text
坑 1：cloneNode(false) 克隆出空模板
结论：克隆的节点没有内容。
原因：浅克隆只复制 template 外壳，不含 content。
解法：使用 cloneNode(true) 深克隆。

坑 2：具名插槽内容投影错位
结论：内容没进预期的插槽位置。
原因：内容元素的 slot 属性与插槽 name 不匹配，落到默认插槽。
解法：核对 slot 属性名与 name 一致性。

坑 3：slotchange 不触发
结论：改了插槽内容但没收到事件。
原因：只改了投影元素的属性，节点本身未增删。
解法：slotchange 只监听节点增删，属性变化需用 MutationObserver。

坑 4：投影内容样式不生效
结论：外部内容进组件后样式丢失。
原因：投影节点仍属于外部文档，组件内部样式（shadow 内）管不到它。
解法：在外部定义投影内容样式，或用 ::slotted 从内部定制。

坑 5：template 内脚本不执行
结论：模板里的 <script> 没运行。
原因：template 是惰性片段，脚本不会在模板阶段执行。
解法：脚本逻辑放到组件类的 connectedCallback 中执行。
```
