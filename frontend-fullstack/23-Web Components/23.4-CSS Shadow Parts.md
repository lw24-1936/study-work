## 概述

Shadow DOM 的样式隔离虽然强大，但也带来了「外部无法定制内部样式」的问题。CSS Shadow Parts 提供两个伪元素 ::part 和 ::slotted，作为跨边界定制样式的官方通道。

```text
两种定制机制：
1. ::part —— 组件主动暴露内部部件，外部通过 part 定制
2. ::slotted —— 组件内部定制「投影进来的内容」的样式
```

```text
三者关系（样式定制方向）：
CSS 变量     → 组件定义变量，外部赋值（最常用）
::part       → 组件暴露部件名，外部直接改部件样式
::slotted    → 组件内部给投影内容加样式
```

## ::part

::part 让组件通过 part 属性暴露内部元素，外部样式用 ::part(name) 选择器定制这些暴露的部件。

```html
<!-- 组件内部：用 part 属性暴露元素 -->
<template id="button-tpl">
  <style>
    .btn { padding: 8px 16px; }
  </style>
  <button class="btn" part="button">点击</button>
</template>
```

```css
/* 外部样式：通过 ::part 定制暴露的部件 */
my-button::part(button) {
  background: #3f51b5;
  color: white;
  border-radius: 6px;
}
```

```text
::part 规则：
1. 组件内部元素需显式加 part 属性才算暴露
2. 外部只能定制暴露的部件，未暴露的元素无法触碰
3. 一个元素可声明多个 part（空格分隔）：part="button primary"
4. 只能命中「直接暴露」的元素，不能深入其后代
```

```html
<!-- 多个 part -->
<button part="button primary">...</button>
```

```css
my-button::part(button) { ... }
my-button::part(primary) { ... }
```

```text
限制：
1. ::part 不能组合（不能 ::part(a) ::part(b) 穿透嵌套）
2. 只能定制暴露部件本身，无法选择部件内部后代
3. 这是刻意设计，保证组件仍掌握封装边界
```

## ::slotted

::slotted 让组件内部为「投影进来的内容」（slot 内容）添加样式。它只能在 shadow 内部使用，针对被投影的节点。

```html
<!-- 组件内部：给投影内容加样式 -->
<template id="list-tpl">
  <style>
    ::slotted(li) { color: #333; margin: 4px 0; }
    ::slotted(.highlight) { color: red; font-weight: bold; }
  </style>
  <ul><slot></slot></ul>
</template>
```

```html
<!-- 使用：投影 li 内容 -->
<my-list>
  <li>普通项</li>
  <li class="highlight">高亮项</li>
</my-list>
```

```text
::slotted 规则：
1. 只能在 shadow 内部样式表中使用
2. 只能选中「顶层投影节点」，不能选其后代
3. 可配合类名/属性选择器筛选投影节点
```

```css
/* 合法：选择顶层投影节点 */
::slotted(li) { ... }
::slotted(.active) { ... }

/* 非法：不能选择投影节点的后代 */
::slotted(li span) { ... }   /* 无效 */
```

```text
样式优先级：
1. 投影节点自身的外部样式优先级高于 ::slotted
2. 外部定义在 light DOM 的样式会覆盖 ::slotted
3. ::slotted 只作为组件提供的默认样式
```

```html
<!-- 完整示例：组件给插槽内容提供基础样式 -->
<template id="badge-tpl">
  <style>
    ::slotted(span) {
      padding: 2px 8px;
      border-radius: 10px;
      background: #eee;
    }
  </style>
  <div class="badge"><slot></slot></div>
</template>
```

## 应用场景实战

### 场景一：可定制的按钮组件

```html
<template id="fancy-button">
  <style>
    :host { display: inline-block; }
    button { border: none; cursor: pointer; }
  </style>
  <button part="button"><slot></slot></button>
</template>
```

```css
/* 消费者定制按钮外观 */
fancy-button::part(button) {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: #fff;
  padding: 10px 24px;
  border-radius: 8px;
}
fancy-button::part(button):hover {
  opacity: 0.9;
}
```

### 场景二：列表组件定制投影项样式

```html
<template id="todo-list">
  <style>
    ::slotted(li) { list-style: none; padding: 8px; border-bottom: 1px solid #eee; }
    ::slotted(li.done) { text-decoration: line-through; color: #999; }
  </style>
  <ul><slot></slot></ul>
</template>
```

```html
<todo-list>
  <li>写代码</li>
  <li class="done">写文档</li>
</todo-list>
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 part 属性显式声明可定制的部件，边界清晰
2. 优先用 CSS 变量定制，::part 用于结构性样式
3. ::slotted 提供投影内容的默认样式，允许外部覆盖
4. part 命名保持语义化（如 part="button" 而非 part="b"）
5. 避免暴露过多 part，控制定制面与维护成本

### 踩坑记录

```text
坑 1：::part 选择器不生效
结论：外部样式没作用到组件内部。
原因：内部元素没加 part 属性，未暴露。
解法：给目标元素加 part 属性，确认 part 名与选择器一致。

坑 2：想穿透嵌套 part 失败
结论：::part(a) ::part(b) 组合无效。
原因：::part 不支持组合选择，不能跨组件层级穿透。
解法：每层组件各自暴露 part，或改用 CSS 变量传递。

坑 3：::slotted 选不到后代元素
结论：写了 ::slotted(li span) 不生效。
原因：::slotted 只能匹配顶层投影节点，不能选后代。
解法：只对顶层节点用 ::slotted，后代样式在 light DOM 处理。

坑 4：::slotted 在外部样式表无效
结论：在页面全局 CSS 写 ::slotted 不生效。
原因：::slotted 只能写在 shadow 内部样式表。
解法：投影内容样式在外部用普通选择器，组件内部才用 ::slotted。

坑 5：外部样式覆盖不了 ::slotted
结论：外部想覆盖组件默认投影样式失败。
原因：选择器优先级不够，或投影节点作用域理解错误。
解法：投影节点样式在 light DOM 用更高优先级选择器覆盖。
```
