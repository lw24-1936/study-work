## 概述

工具类型（Utility Types）是 TypeScript 内置的一组基于泛型实现的类型操作符，用于对已有类型做「变换」——改属性修饰、挑字段、取函数签名等。它们都是纯类型层面的操作，不产生任何运行时开销。

```text
工具类型的分类：
1. 属性修饰 —— Partial / Required / Readonly
2. 结构挑选 —— Pick / Omit
3. 构造对象 —— Record
4. 联合运算 —— Exclude / Extract / NonNullable
5. 函数提取 —— ReturnType / Parameters / ConstructorParameters
6. 实例与异步 —— InstanceType / Awaited
```

```ts
interface User {
  id: number;
  name: string;
  email?: string;
}
```

## 属性修饰：Partial、Required、Readonly

这三个类型用来「批量修改属性的修饰符」，底层是映射类型加 `+`/`-` 修饰符。

```ts
// Partial：所有属性变可选
type PartialUser = Partial<User>;
// { id?: number; name?: string; email?: string }

const patch: PartialUser = { name: 'Bob' };  // 只需传部分字段
```

```ts
// Required：所有属性变必选
type RequiredUser = Required<User>;
// { id: number; name: string; email: string }

// const u: RequiredUser = { id: 1, name: 'A' };  // 错误：缺 email
```

```ts
// Readonly：所有属性变只读
type ReadonlyUser = Readonly<User>;

const u: ReadonlyUser = { id: 1, name: 'A' };
// u.name = 'B';  // 错误：只读属性不可赋值
```

```ts
// 组合使用：深层只读通常要自己写递归映射
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object ? DeepReadonly<T[K]> : T[K];
};
```

## 结构挑选：Pick、Omit

Pick 从类型中「挑出」若干键构造新类型，Omit 则是「剔除」若干键。

```ts
// Pick：保留指定键
type UserBrief = Pick<User, 'id' | 'name'>;
// { id: number; name: string }
```

```ts
// Omit：去掉指定键
type UserWithoutId = Omit<User, 'id'>;
// { name: string; email?: string }
```

```ts
// Omit 的实现原理：Pick + Exclude
type MyOmit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>;
```

```ts
// 实战：DTO 转换，去掉内部字段
type PublicUser = Omit<User, 'id'> & { displayName: string };
```

## 构造对象：Record

Record 用一个键联合类型和一个值类型，构造「键值对」对象类型。

```ts
// Record<K, V>：键为 K 联合，值为 V
type Role = 'admin' | 'user' | 'guest';

const permissions: Record<Role, string[]> = {
  admin: ['read', 'write', 'delete'],
  user: ['read', 'write'],
  guest: ['read'],
};
```

```ts
// 用 Record 构造映射表
const statusText: Record<number, string> = {
  200: 'OK',
  404: 'Not Found',
  500: 'Internal Server Error',
};

statusText[404];  // 'Not Found'
```

```ts
// Record 的键来自 keyof 时，就是「全部键映射为同一类型」
type Flags = Record<keyof User, boolean>;
// { id: boolean; name: boolean; email: boolean }
```

## 联合运算：Exclude、Extract、NonNullable

这三个工具类型操作「联合类型」本身，做差集、交集、剔除 null/undefined。

```ts
type T = 'a' | 'b' | 'c';

// Exclude：从第一个联合中剔除第二个联合的成员
type WithoutA = Exclude<T, 'a'>;  // 'b' | 'c'

// Extract：取两个联合的交集
type OnlyAB = Extract<T, 'a' | 'b'>;  // 'a' | 'b'
```

```ts
// NonNullable：剔除 null 和 undefined
type MaybeString = string | null | undefined;
type StringOnly = NonNullable<MaybeString>;  // string
```

```ts
// Exclude 的实现（分配条件类型）
type MyExclude<T, U> = T extends U ? never : T;
```

## 函数提取：ReturnType、Parameters、ConstructorParameters

这三个类型从「函数/构造函数签名」中提取返回类型、参数元组、构造参数元组。

```ts
// ReturnType：取函数返回类型
function getUser(): { id: number } {
  return { id: 1 };
}
type UserResult = ReturnType<typeof getUser>;  // { id: number }
```

```ts
// Parameters：取函数参数元组
function save(name: string, age: number): void {}
type SaveArgs = Parameters<typeof save>;  // [name: string, age: number]

const args: SaveArgs = ['Alice', 30];
save(...args);
```

```ts
// ConstructorParameters：取构造函数参数元组
class Point {
  constructor(public x: number, public y: number) {}
}
type PointArgs = ConstructorParameters<typeof Point>;  // [x: number, y: number]
```

```ts
// 从已有函数「复用」参数类型
type OnChange = (value: string, event: Event) => void;
type ChangeValue = Parameters<OnChange>[0];  // string
```

## 实例与异步：InstanceType、Awaited

InstanceType 取构造函数返回的实例类型，Awaited 解包 Promise（递归）。

```ts
// InstanceType：取类实例类型
class Service {
  fetch() { return Promise.resolve(1); }
}
type ServiceInstance = InstanceType<typeof Service>;  // Service

const svc: ServiceInstance = new Service();
```

```ts
// Awaited：递归解包 Promise
type A = Awaited<Promise<string>>;           // string
type B = Awaited<Promise<Promise<number>>>;  // number（递归）

async function load(): Promise<string[]> {
  return ['a', 'b'];
}
type Loaded = Awaited<ReturnType<typeof load>>;  // string[]
```

```ts
// 实战：提取 async 函数返回的实际数据类型
async function fetchList() {
  const res = await fetch('/api/list');
  return res.json();  // 推断为 any，需要显式标注
}
type ListType = Awaited<ReturnType<typeof fetchList>>;
```

## 应用场景实战

### 场景一：表单更新（Partial + Pick）

```ts
interface FormState {
  username: string;
  email: string;
  age: number;
  subscribed: boolean;
}

// 更新部分字段
function updateForm(patch: Partial<FormState>): void {
  console.log(patch);
}

updateForm({ username: 'Alice' });
updateForm({ age: 25, subscribed: true });
```

### 场景二：API 响应类型变换（Omit + Record）

```ts
interface DbUser {
  id: number;
  password: string;
  name: string;
  email: string;
}

// 响应给前端的类型：去掉密码
type SafeUser = Omit<DbUser, 'password'>;

// 用户列表的 id -> 用户 映射
type UserMap = Record<number, SafeUser>;

const map: UserMap = {
  1: { id: 1, name: 'A', email: 'a@x.com' },
  2: { id: 2, name: 'B', email: 'b@x.com' },
};
```

## 最佳实践与踩坑记录

### 最佳实践

1. 修单个属性用「映射类型 + 交叉」或直接标注，整批修饰才用 Partial/Required
2. DTO 转换优先 Omit 而不是手写重复结构，减少字段漂移
3. 键值映射表用 Record，避免索引签名的 `[key: string]` 丢失键约束
4. 复用函数签名类型用 ReturnType/Parameters，避免重复声明
5. 处理异步返回用 Awaited，它递归解包嵌套 Promise

### 踩坑记录

```text
坑 1：Partial 只浅层可选
结论：Partial 不会把嵌套对象内部的属性也变成可选。
原因：映射类型只作用于顶层键，不递归。
解法：深层可选需要自己写递归映射类型 DeepPartial<T>。

坑 2：Omit 对联合类型失效
结论：Omit<A | B, 'x'> 的结果可能不是预期的「两个都去掉 x」。
原因：Omit 内部用 keyof T，keyof (A | B) 只保留公共键。
解法：对联合类型用 distributive Omit，写成 T extends any ? Omit<T, K> : never。

坑 3：ReturnType 需要传「类型」而不是「值」
结论：ReturnType<getUser> 直接报错。
原因：ReturnType 的参数是类型，需要 typeof 把函数值转成类型。
解法：写成 ReturnType<typeof getUser>。

坑 4：Record 的键不能用对象字面量做键
结论：Record<object, string> 不报错但几乎没法用。
原因：object 作为键类型被简化为 string，失去约束意义。
解法：键用联合字面量或 string | number | symbol。

坑 5：Awaited 对非 Promise 类型原样返回
结论：Awaited<string> 结果是 string，不是 never。
原因：Awaited 对非 Promise 直接返回原类型，符合预期。
解法：需要「必须异步」时额外加 Promise 约束。
```
