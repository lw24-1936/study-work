## 概述

图表是把数据映射为视觉元素（位置、长度、角度、颜色）的表达方式。选对图表类型是数据可视化的第一步：**比较用柱状，趋势用折线，占比用饼图，分布用散点**。前端实现主要靠 ECharts、D3、AntV 等库。

```text
图表类型的选择逻辑：
1. 比较大小/排名 → Bar（柱状图）
2. 趋势变化/时间序列 → Line（折线图）、Area（面积图）
3. 占比/构成 → Pie（饼图）、Funnel（漏斗图）
4. 相关性/分布 → Scatter（散点图）
5. 多维对比 → Radar（雷达图）
6. 密度/强度分布 → Heatmap（热力图）
7. 转化路径 → Sankey（桑基图）
8. 层级/关系 → Tree（树图）、Graph（关系图）
```

## Bar 与 Line 与 Area

柱状图用柱长比较类别数值，折线图用点连线表达趋势，面积图是折线下方填充颜色、强调量的累积。

```js
// ECharts：柱状图
const bar = {
  xAxis: { type: 'category', data: ['一月', '二月', '三月'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [120, 200, 150] }],
};
```

```js
// 折线图 + 面积图（areaStyle 填充）
const line = {
  xAxis: { type: 'category', data: ['周一', '周二', '周三', '周四', '周五'] },
  yAxis: { type: 'value' },
  series: [
    { type: 'line', data: [10, 22, 18, 30, 26] },
    { type: 'line', data: [5, 12, 15, 20, 22], areaStyle: {} },
  ],
};
```

## Pie

饼图用扇区角度表达占比，适合展示「部分占整体的比例」。类别过多或占比接近时改用柱状图。

```js
const pie = {
  series: [{
    type: 'pie',
    radius: ['40%', '70%'],        // 环形图
    data: [
      { name: 'Chrome', value: 5800 },
      { name: 'Safari', value: 2400 },
      { name: 'Firefox', value: 900 },
    ],
  }],
};
```

## Scatter

散点图用点的位置表达两个变量间的关系，可加第三个维度映射到颜色或大小（气泡图）。

```js
const scatter = {
  xAxis: { type: 'value' },
  yAxis: { type: 'value' },
  series: [{
    type: 'scatter',
    symbolSize: (val) => val[2] * 10,   // 第三维映射大小
    data: [[10, 8, 1], [20, 15, 2], [30, 12, 3], [40, 25, 4]],
  }],
};
```

## Radar

雷达图把多个维度的指标放在同一坐标系里对比，适合能力评估、多维评分。

```js
const radar = {
  radar: {
    indicator: [
      { name: '性能', max: 100 },
      { name: '体验', max: 100 },
      { name: '安全', max: 100 },
    ],
  },
  series: [{
    type: 'radar',
    data: [{ value: [80, 90, 70], name: '产品 A' }],
  }],
};
```

## Heatmap

热力图用颜色深浅表达数值密度或强度，常见于地图热力、相关性矩阵、日历活跃度。

```js
const heatmap = {
  xAxis: { type: 'category', data: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'] },
  yAxis: { type: 'category', data: ['9:00', '10:00', '11:00', '12:00'] },
  visualMap: { min: 0, max: 10, calculable: true },
  series: [{
    type: 'heatmap',
    data: [[0, 0, 5], [0, 1, 8], [1, 0, 3], [2, 2, 9]],
  }],
};
```

## Funnel

漏斗图展示层层转化的递减过程，适合销售漏斗、转化率分析。

```js
const funnel = {
  series: [{
    type: 'funnel',
    sort: 'descending',
    data: [
      { name: '访问', value: 10000 },
      { name: '注册', value: 4000 },
      { name: '下单', value: 1000 },
      { name: '支付', value: 600 },
    ],
  }],
};
```

## Sankey

桑基图用带宽表达流量在不同节点间的流动与转移，适合能源流向、用户迁移、资金流转。

```js
const sankey = {
  series: [{
    type: 'sankey',
    data: [
      { name: '来源 A' }, { name: '来源 B' },
      { name: '中间' }, { name: '目标' },
    ],
    links: [
      { source: '来源 A', target: '中间', value: 60 },
      { source: '来源 B', target: '中间', value: 40 },
      { source: '中间', target: '目标', value: 100 },
    ],
  }],
};
```

## Tree 与 Graph

树图表达层级结构（组织架构、目录树），关系图表达节点间的网状关系（社交网络、依赖图）。

```js
// 树图
const tree = {
  series: [{
    type: 'tree',
    data: [{
      name: '根节点',
      children: [
        { name: '子节点 1', children: [{ name: '叶子 1' }] },
        { name: '子节点 2' },
      ],
    }],
  }],
};
```

```js
// 关系图（力导向布局）
const graph = {
  series: [{
    type: 'graph',
    layout: 'force',
    data: [{ name: 'A' }, { name: 'B' }, { name: 'C' }],
    links: [
      { source: 'A', target: 'B' },
      { source: 'B', target: 'C' },
    ],
  }],
};
```

## 应用场景实战

### 场景一：仪表盘组合图表（柱状 + 折线双轴）

```js
// 销量柱状图 + 增长率折线，双 y 轴
const option = {
  tooltip: { trigger: 'axis' },
  legend: { data: ['销量', '增长率'] },
  xAxis: { type: 'category', data: ['Q1', 'Q2', 'Q3', 'Q4'] },
  yAxis: [
    { type: 'value', name: '销量' },
    { type: 'value', name: '增长率', axisLabel: { formatter: '{value}%' } },
  ],
  series: [
    { name: '销量', type: 'bar', data: [320, 430, 380, 500] },
    { name: '增长率', type: 'line', yAxisIndex: 1, data: [12, 20, 15, 25] },
  ],
};
```

### 场景二：用户转化漏斗

```js
// 从访问到付费的转化漏斗
const funnelOption = {

    type: 'funnel',
    left: '10%',
    width: '80%',
    label: { formatter: '{b}: {c}' },

      { value: 30000, name: '访问详情' },
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先想清楚「回答什么问题」再选图表类型，不为了图而图
2. 类别过多（饼图 > 6 类）时改用柱状图或 TopN 汇总
3. 数值坐标轴从 0 开始，避免柱状图截断造成视觉误导
4. 用 tooltip 和 dataZoom 处理大数据量，而不是一次性渲染所有点
5. 颜色使用语义化（对比、强调、分类），避免无意义的多彩

### 踩坑记录

```text
坑 1：饼图类别太多
结论：饼图挤成一团，小扇区根本看不清。
原因：类别超过 6 个仍用饼图。
解法：取 Top5，其余归入"其他"；或改柱状图。

坑 2：柱状图 y 轴不从 0 开始
结论：1.5 和 1.8 的差异被放大成天壤之别。
原因：y 轴起点设成了非 0 值，柱长差异被视觉夸大。
解法：数值型柱状图 y 轴从 0 开始，除非是强调差异的特定场景。

坑 3：大数据量直接渲染卡顿
结论：10 万数据点的折线图卡死页面。
原因：一次渲染所有点，DOM/Canvas 重绘开销巨大。
解法：用 dataZoom 分段加载、采样降频、或 LTTB 抽稀算法。

坑 4：折线图数据点密集时 tooltip 不准
结论：鼠标悬停时 tooltip 显示的不是最近的数据点。
原因：折线默认按 x 轴索引对齐，密集时偏移。
解法：tooltip 用 trigger: 'axis' 加 snap，或降采样后再展示。

坑 5：图例与数据不同步
结论：图例显示的名字和数据系列对不上。
原因：series 里的 name 和 legend.data 手写不一致。
解法：legend.data 省略，让 ECharts 从 series.name 自动生成。
```
