## 概述

ECharts 是 Apache 开源的配置式图表库，用一个 option 对象声明整个图表，内置丰富的图表类型、交互和动画。相比 D3 的底层原语，ECharts 用**声明式配置**快速出图，是业务图表的主力选择。

```text
ECharts 的核心概念：
1. option —— 描述图表的配置对象，setOption 一次声明
2. series —— 数据系列，一个图表可含多个系列
3. 坐标系 —— cartesian（直角）、polar（极坐标）、geo（地理）等
4. 组件 —— tooltip、legend、dataZoom、visualMap 等辅助组件
```

```js
import * as echarts from 'echarts';

const chart = echarts.init(document.getElementById('chart'));
chart.setOption(option);
```

## Series

Series 是数据系列，声明图表类型和对应的数据。一个 option 可包含多个 series 叠加（如柱状 + 折线）。

```js
const option = {
  xAxis: { type: 'category', data: ['A', 'B', 'C'] },
  yAxis: { type: 'value' },
  series: [
    { name: '销量', type: 'bar', data: [100, 200, 150] },
    { name: '目标', type: 'line', data: [120, 180, 160] },
  ],
};
```

```js
// 每个 series 可独立配置坐标系、样式、数据
const multi = {
  series: [
    { name: '销售', type: 'bar', barWidth: 20, itemStyle: { color: '#3b82f6' }, data: [10, 20] },
    { name: '增长', type: 'line', smooth: true, data: [5, 15] },
  ],
};
```

## Dataset

Dataset 是数据与样式分离的组件：数据集中管理，series 通过 encode 声明用哪些字段，避免数据重复、便于多系列共享同一份数据。

```js
const option = {
  legend: {},
  dataset: {
    source: [
      ['product', '2023', '2024'],
      ['A', 120, 150],
      ['B', 200, 180],
      ['C', 150, 190],
    ],
  },
  xAxis: { type: 'category' },
  yAxis: { type: 'value' },
  series: [
    { type: 'bar', encode: { x: 'product', y: '2023' } },
    { type: 'bar', encode: { x: 'product', y: '2024' } },
  ],
};
```

```js
// 按行对象形式的数据源（dataset 支持二维数组或对象数组）
dataset: {
  source: [
    { product: 'A', sales: 120, profit: 30 },
    { product: 'B', sales: 200, profit: 50 },
  ],
},
series: [{ type: 'bar', encode: { x: 'product', y: 'sales' } }],
```

## Axis

Axis 定义坐标轴：xAxis/yAxis 支持 category（类目）、value（数值）、time（时间）、log（对数）四种类型。

```js
const option = {
  xAxis: {
    type: 'time',                       // 时间轴
    axisLabel: { formatter: '{yyyy}-{MM}' },
  },
  yAxis: {
    type: 'value',
    min: 0,                             // 从 0 开始
    axisLabel: { formatter: '{value} 元' },
  },
};
```

```js
// 双 y 轴：series 用 yAxisIndex 指定挂载到哪个轴
yAxis: [
  { type: 'value', name: '销量' },
  { type: 'value', name: '增长率' },
],
series: [{ type: 'bar', data: [320, 430], yAxisIndex: 0 }],
```

## Tooltip

Tooltip 是悬浮提示框，展示数据明细。trigger 支持 item（单数据项）和 axis（整轴数据，多系列对齐时更常用）。

```js
tooltip: {
  trigger: 'axis',                       // 按轴触发，显示同轴所有系列
  axisPointer: { type: 'shadow' },       // 阴影指示器
  formatter: (params) => {
    const [{ axisValue }] = params;
    const detail = params.map(p => `${p.marker}${p.seriesName}: ${p.value}`).join('<br/>');
    return `${axisValue}<br/>${detail}`;
  },
},
```

```js
// 自定义 HTML tooltip
tooltip: {
  trigger: 'item',
  formatter: (p) => `<div style="padding:4px">${p.name}: <b>${p.value}</b></div>`,
},
```

## Legend

Legend 是图例，标注系列名称并可点击切换系列的显示/隐藏。可省略 data，自动从 series.name 生成。

```js
legend: {
  data: ['销量', '目标'],              // 可省略，自动取 series.name
  top: 10,
  selectedMode: 'multiple',            // 点击切换显隐
},
```

```js
// legend 选择状态可编程控制
chart.on('legendselectchanged', (params) => {
  console.log('当前选中', params.selected);
});
```

## DataZoom

DataZoom 是数据区域缩放组件，用于大数据量的分段浏览，支持滑块（slider）和内置（inside）两种交互。

```js
dataZoom: [
  { type: 'inside', start: 0, end: 100 },       // 滚轮/拖拽缩放
  { type: 'slider', start: 30, end: 70 },        // 底部滑块
],
```

```js
// 两个数据轴联动缩放（x 和 y 都缩放）
dataZoom: [
  { type: 'slider', xAxisIndex: 0, start: 20, end: 80 },
  { type: 'slider', yAxisIndex: 0, start: 20, end: 80 },
],
```

## VisualMap

VisualMap 把数值映射到视觉通道（颜色、大小、透明度），常见于热力图、地图的连续或分段着色。

```js
visualMap: {
  min: 0,
  max: 100,
  calculable: true,                     // 显示拖动手柄筛选
  inRange: { color: ['#e0f3ff', '#3b82f6'] },
},
```

```js
// 分段（piecewise）型 visualMap：按区间离散着色
visualMap: {
  type: 'piecewise',
  pieces: [
    { min: 0, max: 30, label: '低' },
    { min: 30, max: 70, label: '中' },
    { min: 70, max: 100, label: '高' },
  ],
},
```

## 应用场景实战

### 场景一：带缩放和 tooltip 的时间序列折线图

```js
const option = {
  title: { text: '服务器请求量' },
  tooltip: { trigger: 'axis' },
  legend: {},
  xAxis: { type: 'time' },
  yAxis: { type: 'value', min: 0 },
  dataZoom: [
    { type: 'inside' },
    { type: 'slider', bottom: 0 },
  ],
  series: [{
    name: '请求量',
    type: 'line',
    smooth: true,
    areaStyle: { opacity: 0.2 },
    data: [
      ['2026-08-01', 120], ['2026-08-02', 200], ['2026-08-03', 150],
      ['2026-08-04', 300], ['2026-08-05', 260],
    ],
  }],
};
```

### 场景二：dataset + 双系列对比柱状图

```js
const option = {
  legend: {},
  dataset: {
    source: [
      ['季度', '线上', '线下'],
      ['Q1', 320, 200],
      ['Q2', 430, 260],
      ['Q3', 380, 300],
      ['Q4', 500, 350],
    ],
  },
  xAxis: { type: 'category' },
  yAxis: { type: 'value', min: 0 },
  series: [
    { name: '线上', type: 'bar', encode: { x: '季度', y: '线上' } },
    { name: '线下', type: 'bar', encode: { x: '季度', y: '线下' } },
  ],
};
```

## 最佳实践与踩坑记录

### 最佳实践

1. 数据统一走 dataset + encode，避免每个 series 各自塞 data
2. 数值 y 轴设 min: 0，避免柱状图截断误导
3. 大数据量配 dataZoom 分段展示，别一次渲染几十万点
4. 响应式用 chart.resize() 配合容器尺寸监听
5. 组件销毁时调用 chart.dispose() 释放事件和资源

### 踩坑记录

```text
坑 1：容器宽度为 0 时报错或空白
结论：init 后图表不显示或提示宽度非法。
原因：在元素还没布局完成（display:none 或未挂载）时就 init。
解法：元素可见后再 init，或监听 resize 后 chart.resize()。

坑 2：setOption 时 series 数据没更新
结论：重新 setOption 后图还是旧数据。
原因：只传了 series 部分，未设置 merge 模式导致覆盖不完整。
解法：用 setOption(option, { notMerge: false }) 默认合并，或完整传入。

坑 3：重复 init 导致内存泄漏
结论：切换路由后图表仍占内存，事件还挂着。
原因：组件卸载时没调 chart.dispose()。
解法：卸载时 dispose，或把 init 放 effect 里用清理函数。

坑 4：tooltip 在数据密集时对不准
结论：tooltip 显示的值与鼠标位置不对应。
原因：默认按轴对齐，密集数据点需要吸附。
解法：tooltip 配 axisPointer.snap 或 trigger: 'axis' 加抽样。

坑 5：图例 name 与 series.name 不一致
结论：图例点了没反应，或显示错名字。
原因：legend.data 手写和 series.name 不一致。
解法：省略 legend.data，让 ECharts 自动从 series.name 生成。
```
