## 概述

WebGL 是浏览器里的 GPU 编程接口，通过 JavaScript 把顶点数据和着色器程序上传到显卡，由 GPU 并行渲染。它是 Three.js、ECharts GL 等库的底层，直接用它意味着自己写着色器、自己管理缓冲区。

```text
WebGL 的核心特点：
1. GPU 并行 —— 顶点和像素在显卡上大规模并行处理
2. 着色器编程 —— 用 GLSL 写 Vertex/Fragment Shader 控制渲染
3. 缓冲区驱动 —— 顶点数据存在 GPU Buffer 里，按绘制调用取用
4. 状态机 —— 通过 bind 设置当前状态，再 draw 执行绘制
```

```js
// 获取 WebGL 上下文
const canvas = document.getElementById('canvas');
const gl = canvas.getContext('webgl');
```

## Shader

Shader（着色器）是跑在 GPU 上的小程序，用 GLSL 编写。着色器分两类：顶点着色器处理每个顶点，片元着色器处理每个像素。两者编译、链接成一个 program 后使用。

```js
// 编译着色器的通用函数
function createShader(gl, type, source) {
  const shader = gl.createShader(type);
  gl.shaderSource(shader, source);
  gl.compileShader(shader);
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    throw new Error(gl.getShaderInfoLog(shader));
  }
  return shader;
}

// 编译并链接 program
const program = gl.createProgram();
gl.attachShader(program, vertexShader);
gl.attachShader(program, fragmentShader);
gl.linkProgram(program);
gl.useProgram(program);
```

```c
// GLSL 着色器源码（JavaScript 字符串里）
const vertexShaderSource = `
  attribute vec2 a_position;
  void main() {
    gl_Position = vec4(a_position, 0.0, 1.0);
  }
`;
```

## Vertex Shader

Vertex Shader 对每个顶点执行一次，负责把顶点坐标从模型空间变换到裁剪空间（通过 gl_Position 输出），并把需要传给片元的属性插值输出。

```c
// 顶点着色器：接收位置，可做矩阵变换
attribute vec3 a_position;
uniform mat4 u_matrix;

void main() {
  // 用矩阵把顶点变换到裁剪空间
  gl_Position = u_matrix * vec4(a_position, 1.0);
}
```

```c
// 传递 varying 给片元着色器做插值
attribute vec3 a_position;
varying vec3 v_position;

void main() {
  v_position = a_position;
  gl_Position = vec4(a_position, 1.0);
}
```

## Fragment Shader

Fragment Shader 对每个像素（片元）执行一次，决定该像素的最终颜色（通过 gl_FragColor 输出）。它是渐变、纹理采样、光照计算发生的地方。

```c
precision mediump float;
varying vec3 v_position;

void main() {
  // 用插值后的位置生成渐变
  gl_FragColor = vec4(v_position, 1.0);
}
```

```c
// 使用 uniform 控制颜色
precision mediump float;
uniform vec4 u_color;

void main() {
  gl_FragColor = u_color;
}
```

## Buffer

Buffer 是存顶点数据的 GPU 内存区域。流程：创建 buffer → 绑定 → 上传数据 → 关联 attribute 指针。

```js
// 创建缓冲区并上传顶点数据
const positionBuffer = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, positionBuffer);

const positions = new Float32Array([
  -0.5, -0.5,
   0.5, -0.5,
   0.0,  0.5,
]);
gl.bufferData(gl.ARRAY_BUFFER, positions, gl.STATIC_DRAW);
```

```js
// 关联 attribute 与 buffer，告诉 GPU 如何读取
const location = gl.getAttribLocation(program, 'a_position');
gl.enableVertexAttribArray(location);
gl.vertexAttribPointer(location, 2, gl.FLOAT, false, 0, 0);
```

## Texture

Texture 是 GPU 里的图像数据，在片元着色器里采样（texture2D），给表面贴颜色。通过纹理单元（texture unit）绑定。

```js
// 创建并上传纹理
const texture = gl.createTexture();
gl.bindTexture(gl.TEXTURE_2D, texture);
gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, image);
gl.generateMipmap(gl.TEXTURE_2D);
```

```c
// 片元着色器采样纹理
precision mediump float;
uniform sampler2D u_texture;
varying vec2 v_uv;

void main() {
  gl_FragColor = texture2D(u_texture, v_uv);
}
```

```js
// 绑定到纹理单元 0，并把 uniform 指向它
gl.activeTexture(gl.TEXTURE0);
gl.bindTexture(gl.TEXTURE_2D, texture);
gl.uniform1i(gl.getUniformLocation(program, 'u_texture'), 0);
```

## Uniform

Uniform 是每次绘制调用都保持不变的全局变量，供顶点和片元着色器共享，用来传变换矩阵、颜色、时间等。

```js
// 传 4x4 矩阵
const matrixLocation = gl.getUniformLocation(program, 'u_matrix');
gl.uniformMatrix4fv(matrixLocation, false, matrix);

// 传单值
gl.uniform1f(gl.getUniformLocation(program, 'u_time'), performance.now() / 1000);
```

```c
// 着色器侧声明 uniform
uniform mat4 u_matrix;
uniform float u_time;
```

## WebGL Pipeline

渲染管线是数据从顶点到像素的固定流程，理解它就能理解 WebGL 的每个环节。

```text
WebGL 渲染管线：
1. 顶点数据（Buffer）→ 输入到顶点着色器
2. 顶点着色器（Vertex Shader）→ 逐顶点变换，输出 gl_Position
3. 图元装配（Primitive Assembly）→ 顶点组装成三角形/线段
4. 光栅化（Rasterization）→ 三角形转成片元（候选像素）
5. 片元着色器（Fragment Shader）→ 逐片元计算颜色
6. 深度/混合测试（Depth/Blend Test）→ 决定最终写入的颜色
```

```js
// 完整的绘制调用：从绑定到 drawArrays
function draw() {
  gl.clearColor(0, 0, 0, 1);
  gl.clear(gl.COLOR_BUFFER_BIT);

  gl.useProgram(program);
  gl.bindBuffer(gl.ARRAY_BUFFER, positionBuffer);
  gl.vertexAttribPointer(positionLocation, 2, gl.FLOAT, false, 0, 0);

  gl.drawArrays(gl.TRIANGLES, 0, 3);   // 画 3 个顶点组成的三角形
}
```

## 应用场景实战

### 场景一：原生 WebGL 画一个彩色三角形

```js
const canvas = document.getElementById('c');
const gl = canvas.getContext('webgl');

const vs = `
  attribute vec2 a_position;
  varying vec2 v_position;
  void main() {
    v_position = a_position;
    gl_Position = vec4(a_position, 0.0, 1.0);
  }
`;
const fs = `
  precision mediump float;
  varying vec2 v_position;
  void main() {
    gl_FragColor = vec4(v_position + 0.5, 0.0, 1.0);
  }
`;

function shader(type, src) {
  const s = gl.createShader(type);
  gl.shaderSource(s, src);
  gl.compileShader(s);
  return s;
}

const program = gl.createProgram();
gl.attachShader(program, shader(gl.VERTEX_SHADER, vs));
gl.attachShader(program, shader(gl.FRAGMENT_SHADER, fs));
gl.linkProgram(program);
gl.useProgram(program);

const buf = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, buf);
gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-0.5, -0.5, 0.5, -0.5, 0, 0.5]), gl.STATIC_DRAW);

const loc = gl.getAttribLocation(program, 'a_position');
gl.enableVertexAttribArray(loc);
gl.vertexAttribPointer(loc, 2, gl.FLOAT, false, 0, 0);

gl.drawArrays(gl.TRIANGLES, 0, 3);
```

### 场景二：用 uniform 时间做动画

```js
const fs = `
  precision mediump float;
  uniform float u_time;
  void main() {
    float r = sin(u_time) * 0.5 + 0.5;
    gl_FragColor = vec4(r, 0.2, 1.0 - r, 1.0);
  }
`;
// ...编译链接同场景一...

const timeLoc = gl.getUniformLocation(program, 'u_time');
function animate(t) {
  gl.uniform1f(timeLoc, t / 1000);
  gl.drawArrays(gl.TRIANGLES, 0, 3);
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先编译再链接，并检查 COMPILE_STATUS/LINK_STATUS 日志
2. 顶点数据一次性上传（STATIC_DRAW），减少运行时 bufferData 调用
3. 纹理尺寸用 2 的幂，避免 mipmap 和 wrap 受限
4. 用 drawArrays/drawElements 的批次合并，减少绘制调用次数
5. 业务开发优先用 Three.js，直接写 WebGL 只用于极致性能或特殊效果

### 踩坑记录

```text
坑 1：着色器编译错误静默失败
结论：画面空白，没有任何报错。
原因：GLSL 编译失败但没有检查 COMPILE_STATUS。
解法：编译后检查状态，失败时输出 gl.getShaderInfoLog。

坑 2：忘了 enableVertexAttribArray
结论：顶点数据没生效，三角形画不出来。
原因：attribute 默认禁用，没 enable 就 draw。
解法：getAttribLocation 后调用 gl.enableVertexAttribArray。

坑 3：uniform 位置为 -1 时赋值无效
结论：uniform1f 调用不报错但没效果。
原因：uniform 名被优化掉（未使用）或拼写错误，getUniformLocation 返回 null/-1。
解法：检查 uniform 名拼写，确认着色器里真的用到了。

坑 4：纹理黑屏或报错
结论：贴图显示不出来。
原因：纹理尺寸非 2 的幂导致 wrap 方式受限，或没 generateMipmap。
解法：用 2 的幂纹理，正确设置 wrapS/wrapT，必要时 generateMipmap。

坑 5：上下文丢失导致白屏
结论：页面运行一段时间后 canvas 变白。
原因：GPU 上下文丢失（设备切换、驱动问题），没监听 webglcontextlost。
解法：监听 webglcontextlost 阻止默认并 webglcontextrestored 后重建资源。
```
