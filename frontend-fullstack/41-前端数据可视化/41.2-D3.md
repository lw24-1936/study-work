## 概述

D3（Data-Driven Documents）是底层可视化库，不提供现成图表，而是提供**数据绑定 DOM/SVG 的原语**（selection、scale、shape、transition）。它把控制权交给开发者，适合定制化强、库无法覆盖的图表场景。

```text
D3 的定位：
1. 不是图表库 —— 没有现成的 Bar/Pie，只有构建图表的原语
2. 数据驱动 —— 核心是 data join：数据与 DOM 元素一一绑定
3. 灵活 —— 从简单柱状图到复杂力导向图都能做
4. 与 ECharts 互补 —— ECharts 配置式出图快，D3 定制自由度高
```

```html
<!-- 引入 D3 -->
<script src="https://d3js.org/d3.v7.min.js"></script>
```

## Selection

Selection 是 D3 操作 DOM 的入口，链式选择元素并批量设置属性/样式。

```js
// 选择 + 批量操作
d3.selectAll('p')
  .style('color', 'steelblue')
  .attr('class', 'text');

// 添加元素
const svg = d3.select('body').append('svg').attr('width', 400).attr('height', 300);

svg.append('circle')
  .attr('cx', 50).attr('cy', 50).attr('r', 20)
  .style('fill', 'orange');
```

```js
// 读取绑定数据（datum / data）
d3.select('circle').datum({ value: 42 });
```

## Data Join

Data Join 是 D3 的灵魂：把数据数组与 DOM 元素集合绑定，用 enter/update/exit 三个选择集处理「新增 / 更新 / 移除」的元素。

```js
const data = [10, 20, 30, 40];

// 经典 enter-update-exit 三件套
const bars = svg.selectAll('rect')
  .data(data)                       // 绑定数据
  .join('rect')                     // 等价 enter+update+exit
  .attr('x', (d, i) => i * 40)
  .attr('y', d => 100 - d)
  .attr('width', 30)
  .attr('height', d => d);
```

```js
// 显式写出三个集合，理解数据流
const sel = svg.selectAll('rect').data(data);

sel.enter().append('rect')          // enter：数据多出的部分，新建元素
  .attr('width', 30);

sel.attr('height', d => d);         // update：已有元素，更新属性

sel.exit().remove();                // exit：元素多出的部分，移除
```

## Scale

Scale 把数据域（domain）映射到像素域（range），处理「数据值 → 坐标/颜色」的换算。

```js
// 线性比例尺：数据 0~100 → 像素 0~300
const linear = d3.scaleLinear().domain([0, 100]).range([0, 300]);
linear(50);        // 150

// 序数比例尺：类别 → 离散位置（柱状图的 x 位置）
const ordinal = d3.scaleBand()
  .domain(['A', 'B', 'C'])
  .range([0, 300])
  .padding(0.2);
ordinal('B');      // 120
ordinal.bandwidth(); // 80
```

```js
// 其他常用比例尺
d3.scaleLog();          // 对数
d3.scaleTime();         // 时间 → 像素
d3.scaleOrdinal();      // 离散 → 离散（颜色映射）
d3.scaleThreshold();    // 分段阈值
```

## Axis

Axis 基于 Scale 生成坐标轴刻度，d3-axis 负责渲染，把数据域刻度标到轴上。

```js
const x = d3.scaleLinear().domain([0, 100]).range([0, 400]);
const xAxis = d3.axisBottom(x);      // 底部 x 轴

svg.append('g')
  .attr('transform', 'translate(0, 200)')
  .call(xAxis);                       // call 把 selection 交给 axis 渲染
```

```js
// 自定义刻度格式
const yAxis = d3.axisLeft(y).ticks(5).tickFormat(d => `${d}%`);
```

## Shape

Shape 是路径生成器，把数据转成 SVG path 的 d 字符串，包括 line、area、arc（饼图）、symbol（符号）等。

```js
// 折线生成器
const line = d3.line()
  .x((d, i) => i * 50)
  .y(d => 100 - d);

svg.append('path')
  .datum([10, 40, 30, 60, 20])
  .attr('d', line)
  .attr('fill', 'none')
  .attr('stroke', 'steelblue');
```

```js
// 弧生成器：画饼图扇区
const arc = d3.arc().innerRadius(0).outerRadius(100);

svg.append('path')
  .attr('d', arc({ startAngle: 0, endAngle: Math.PI / 2 }))
  .attr('transform', 'translate(200, 150)')
  .attr('fill', 'orange');
```

## SVG 与 Canvas

SVG 适合元素数量少、需要交互命中的场景（每个元素是独立 DOM 节点，可绑事件）；Canvas 适合元素极多、追求性能的场景（统一绘制，无独立节点）。

```js
// SVG：元素是 DOM 节点，可直接绑事件
svg.selectAll('circle')
  .data(data)
  .join('circle')
  .on('click', (event, d) => console.log('点击了', d));
```

```js
// Canvas：高性能统一绘制，需自己维护命中检测
const ctx = canvas.getContext('2d');
data.forEach((d, i) => {
  ctx.fillStyle = 'steelblue';
  ctx.fillRect(i * 40, 100 - d, 30, d);
});
```

```text
SVG vs Canvas：
SVG —— 数量 < 1000、需交互/动画/缩放，每个元素可独立操作
Canvas —— 数量 > 10000、静态或高频重绘，性能优先
```

## Transition

Transition 让数据更新带平滑动画：selection 链式调用 transition() 后，属性变化自动插值过渡。

```js
// 更新数据时带过渡动画
function update(newData) {
  svg.selectAll('rect')
    .data(newData)
    .join('rect')
    .transition()                 // 进入过渡
    .duration(500)                // 时长
    .ease(d3.easeCubicInOut)      // 缓动
    .attr('height', d => d)
    .attr('y', d => 100 - d);
}
```

```js
// 延迟逐个出现（交错动画）
.transition()
  .delay((d, i) => i * 50)
  .duration(300);
```

## 应用场景实战

### 场景一：完整柱状图（Scale + Axis + Data Join 全链路）

```js
const data = [120, 220, 150, 300, 260];

const margin = { top: 20, right: 20, bottom: 40, left: 40 };
const width = 500 - margin.left - margin.right;
const height = 300 - margin.top - margin.bottom;

const svg = d3.select('#chart')
  .append('svg')
  .attr('width', width + margin.left + margin.right)
  .attr('height', height + margin.top + margin.bottom)
  .append('g')
  .attr('transform', `translate(${margin.left},${margin.top})`);

const x = d3.scaleBand().domain(d3.range(data.length)).range([0, width]).padding(0.2);
const y = d3.scaleLinear().domain([0, d3.max(data)]).range([height, 0]);

svg.append('g').attr('transform', `translate(0,${height})`).call(d3.axisBottom(x));
svg.append('g').call(d3.axisLeft(y));

svg.selectAll('rect')
  .data(data)
  .join('rect')
  .attr('x', (d, i) => x(i))
  .attr('y', d => y(d))
  .attr('width', x.bandwidth())
  .attr('height', d => height - y(d))
  .attr('fill', 'steelblue');
```

### 场景二：带过渡的数据更新

```js
// 定时更新数据，柱状图平滑过渡
const newData = () => Array.from({ length: 5 }, () => Math.random() * 300);

setInterval(() => {
  const d = newData();
  y.domain([0, d3.max(d)]);
  svg.selectAll('rect')
    .data(d)
    .transition()
    .duration(600)
    .attr('y', v => y(v))
    .attr('height', v => height - y(v));
}, 2000);
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 join() 统一 enter/update/exit，避免三件套重复代码
2. Scale 的 domain/range 集中管理，避免魔法数字散落
3. 大数据量用 Canvas 而非 SVG，SVG 节点数控制在千级以内
4. 过渡动画加 duration/ease 控制节奏，别让动画喧宾夺主
5. 复用 margin 约定（Convention），坐标轴和绘图区分离

### 踩坑记录

```text
坑 1：忘了 .attr('fill', 'none') 导致 path 被填充成实心
结论：折线图变成一块实心黑块。
原因：line 生成的 path 默认 fill 是黑色。
解法：折线 path 显式设 fill: none，只保留 stroke。

坑 2：exit().remove() 忘写导致数据减少时残留元素
结论：数据从 5 条变 3 条，图上还有 5 个柱子。
原因：只写了 enter/update，没处理 exit。
解法：用 join() 或显式 sel.exit().remove()。

坑 3：scaleBand 用错了取坐标方式
结论：柱状图柱子位置偏移、宽度不对。
原因：把 scaleBand 当线性 scale 用，直接 x(d) 而非 x(i) 或 x(d.name)。
解法：band scale 用 x(类别) 或 x(索引) 取位置，宽度用 x.bandwidth()。

坑 4：Canvas 场景误用 DOM 事件
结论：Canvas 绘制的元素绑 click 不触发。
原因：Canvas 是统一画布，没有独立 DOM 节点。
解法：在 canvas 上监听事件 + 手动命中检测（遍历数据算坐标范围）。

坑 5：过渡动画重复触发叠加
结论：快速更新时动画抖动、状态错乱。
原因：每次更新都新开 transition，旧动画未完成。
解法：transition 前用 .interrupt() 打断旧过渡，或加节流。
```
