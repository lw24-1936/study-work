## 概述

Three.js 是 WebGL 的封装库，用**场景图（Scene Graph）** 的思维组织 3D 对象：场景里放网格、相机、灯光，渲染器负责把相机看到的场景画到画布上。它屏蔽了 WebGL 的底层着色器细节，让 3D 开发聚焦在对象与逻辑上。

```text
Three.js 的渲染三要素：
1. Scene（场景）—— 容纳所有对象的容器
2. Camera（相机）—— 决定观察视角（透视/正交）
3. Renderer（渲染器）—— 把场景按相机视角渲染成像素
```

```js
import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);
```

## Scene 与 Camera 与 Renderer

场景图是树状结构：scene 是根节点，对象通过 add 挂载，父对象的位置/旋转/缩放会传递到子对象。

```js
// 对象挂载与层级
const group = new THREE.Group();
scene.add(group);

const child = new THREE.Mesh(geometry, material);
group.add(child);             // child 相对 group 定位

group.position.x = 10;        // 移动 group，child 跟随
```

```js
// 透视相机：近大远小，参数 = 视角、宽高比、近平面、远平面
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.z = 5;

// 正交相机：无透视，常用于 2.5D、工程图
const ortho = new THREE.OrthographicCamera(-1, 1, 1, -1, 0.1, 100);
```

```js
// 渲染循环
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, camera);
}
animate();
```

## Mesh 与 Geometry

Mesh 是「几何体 + 材质」的组合，是场景里可见对象的基本单位。Geometry 定义形状（顶点数据），Material 定义表面外观。

```js
// 立方体 = BoxGeometry（几何体）+ MeshBasicMaterial（材质）
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0x3b82f6 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
```

```js
// 常用内置几何体
new THREE.SphereGeometry(1, 32, 32);   // 球体
new THREE.CylinderGeometry(1, 1, 2);   // 圆柱
new THREE.PlaneGeometry(5, 5);         // 平面
new THREE.TorusGeometry(1, 0.3);       // 圆环
```

```js
// 自定义几何体：直接声明顶点
const geo = new THREE.BufferGeometry();
const vertices = new Float32Array([0, 0, 0, 1, 0, 0, 0, 1, 0]);
geo.setAttribute('position', new THREE.BufferAttribute(vertices, 3));
```

## Material

Material 定义物体对光的反应。基础材质不响应光照（MeshBasicMaterial 始终全亮），标准材质遵循物理光照（MeshStandardMaterial 需配光源）。

```js
// 基础材质：不受光影响，颜色恒定
const basic = new THREE.MeshBasicMaterial({ color: 0xff0000 });

// 标准材质：PBR 物理渲染，需灯光
const standard = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  roughness: 0.4,     // 粗糙度
  metalness: 0.8,     // 金属度
});

// 线框 / 透明 / 双面渲染
const wireframe = new THREE.MeshBasicMaterial({ wireframe: true });
const transparent = new THREE.MeshBasicMaterial({ transparent: true, opacity: 0.5 });
const doubleSide = new THREE.MeshBasicMaterial({ side: THREE.DoubleSide });
```

## Light

灯光是标准材质可见的前提。常见光源有环境光（均匀照亮）、方向光（平行光）、点光源、聚光灯。

```js
// 环境光：提供基础照明，无方向
const ambient = new THREE.AmbientLight(0xffffff, 0.5);
scene.add(ambient);

// 方向光：模拟太阳，平行照射
const dirLight = new THREE.DirectionalLight(0xffffff, 1);
dirLight.position.set(5, 10, 5);
scene.add(dirLight);
```

```js
// 点光源：从一点向四周发光
const pointLight = new THREE.PointLight(0xff8800, 1, 20);
pointLight.position.set(2, 3, 2);
scene.add(pointLight);
```

## Texture

Texture 是把图片贴到物体表面，用 TextureLoader 加载，配合 map 参数设置到材质。

```js
const loader = new THREE.TextureLoader();

// 基础颜色贴图
const texture = loader.load('/textures/wood.jpg');
const material = new THREE.MeshStandardMaterial({ map: texture });

// 法线贴图：增加表面凹凸细节（不改变几何体）
material.normalMap = loader.load('/textures/wood-normal.jpg');
```

```js
// 重复平铺与旋转
texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;
texture.repeat.set(2, 2);
```

## Animation

动画通过 requestAnimationFrame 循环更新对象属性实现。更复杂的骨骼/关键帧动画可用 AnimationMixer 播放 GLTF 模型内嵌动画。

```js
// 简单旋转动画
function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
```

```js
// 用时钟保证不同帧率下动画速度一致
const clock = new THREE.Clock();
function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta();      // 距上一帧的秒数
  cube.rotation.y += delta * 0.5;      // 每秒转 0.5 弧度
  renderer.render(scene, camera);
}
```

```js
// GLTF 模型动画：AnimationMixer 播放
const mixer = new THREE.AnimationMixer(gltf.scene);
const action = mixer.clipAction(gltf.animations[0]);
action.play();
// 循环里 mixer.update(delta)
```

## Raycaster

Raycaster 做射线拾取：从相机经鼠标位置发射射线，检测与物体的相交，实现点击选中 3D 对象。

```js
const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

window.addEventListener('click', (event) => {
  // 归一化设备坐标（-1 ~ 1）
  pointer.x = (event.clientX / innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / innerHeight) * 2 + 1;

  raycaster.setFromCamera(pointer, camera);
  const intersects = raycaster.intersectObjects(scene.children);
  if (intersects.length > 0) {
    console.log('点击到', intersects[0].object);
  }
});
```

## 应用场景实战

### 场景一：旋转立方体最小可运行示例

```js
import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const cube = new THREE.Mesh(
  new THREE.BoxGeometry(2, 2, 2),
  new THREE.MeshStandardMaterial({ color: 0x3b82f6, roughness: 0.3, metalness: 0.1 }),
);
scene.add(cube);

scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const dir = new THREE.DirectionalLight(0xffffff, 1);
dir.position.set(3, 5, 3);
scene.add(dir);

function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
animate();
```

### 场景二：点击选中变色（Raycaster）

```js
const spheres = [];
for (let i = 0; i < 5; i++) {
  const s = new THREE.Mesh(
    new THREE.SphereGeometry(0.5, 32, 32),
    new THREE.MeshStandardMaterial({ color: 0x888888 }),
  );
  s.position.x = i * 1.5 - 3;
  scene.add(s);
  spheres.push(s);
}

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

window.addEventListener('click', (e) => {
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const hits = raycaster.intersectObjects(spheres);
  if (hits.length) hits[0].object.material.color.set(0xff6600);
});
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 clock.getDelta() 驱动动画，保证不同帧率速度一致
2. 几何体和材质可复用就复用，别为每个物体 new 一份
3. 用 MeshStandardMaterial 时记得加灯光，否则物体全黑
4. 离屏对象用 visible = false 或移除，避免无谓渲染
5. 用 antialias + 合适的像素比（setPixelRatio）平衡画质与性能

### 踩坑记录

```text
坑 1：用了标准材质但没加灯光，物体全黑
结论：MeshStandardMaterial 的物体渲染出来是黑的。
原因：标准材质遵循物理光照，场景里没有光源。
解法：加 AmbientLight + DirectionalLight，或用 MeshBasicMaterial。

坑 2：贴图不显示或变形
结论：图片贴上去模糊、拉伸。
原因：贴图尺寸非 2 的幂，或 wrap/repeat 没设置对。
解法：用 2 的幂尺寸纹理，设置 wrapS/wrapT 和 repeat。

坑 3：动画在不同帧率下速度不一致
结论：高刷新率屏幕动画飞快，低端设备卡顿。
原因：每帧固定角度增量，没有按时间差补偿。
解法：用 clock.getDelta() 乘 delta 时间，动画按真实时间推进。

坑 4：内存泄漏导致页面越来越卡
结论：反复加载模型/纹理后帧率持续下降。
原因：几何体、材质、纹理没有 dispose，GPU 内存不释放。
解法：卸载时调用 geometry.dispose()、material.dispose()、texture.dispose()。

坑 5：窗口缩放后画面拉伸
结论：resize 后模型被拉变形。
原因：改了画布尺寸但没更新相机宽高比和投影矩阵。
解法：resize 时更新 camera.aspect 和 camera.updateProjectionMatrix()，再 renderer.setSize()。
```
