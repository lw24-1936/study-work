## 概述

Web 字体是页面加载的重要资源，加载慢会导致文字闪动（FOIT/FOUT）甚至不可见。优化核心是「减小字体体积、加快字体加载、优化加载体验」。

```text
字体优化手段：
1. WOFF —— 通用 Web 字体格式
2. WOFF2 —— 更高压缩率的现代格式
3. Font Subset —— 字体子集化，减小体积
4. font-display —— 控制加载期间的文字显示
5. Preload —— 预加载字体，加快就绪
6. Variable Font —— 可变字体，一个文件多字重
```

```text
字体加载的两种现象：
FOIT —— 字体未加载时文字不可见
FOUT —— 字体未加载时显示回退字体（后切换）
```

## WOFF

WOFF（Web Open Font Format）是专为 Web 设计的字体格式，内置压缩，比 TTF/OTF 更小，是 Web 字体的事实标准。

```css
@font-face {
  font-family: 'MyFont';
  src: url('myfont.woff') format('woff');
  font-weight: 400;
  font-style: normal;
}
```

```text
WOFF 特点：
1. 基于 TTF/OTF，内置 zlib 压缩
2. 体积比 TTF 小约 40%
3. 兼容所有现代浏览器
```

## WOFF2

WOFF2 是 WOFF 的升级版，采用 Brotli 压缩算法，体积比 WOFF 再小约 30%，是当前推荐的首选格式。

```css
@font-face {
  font-family: 'MyFont';
  src: url('myfont.woff2') format('woff2'),   /* 优先 WOFF2 */
       url('myfont.woff') format('woff');      /* WOFF 兜底 */
  font-weight: 400;
}
```

```text
WOFF2 vs WOFF：
WOFF2 —— Brotli 压缩，体积最小（首选）
WOFF —— zlib 压缩，兼容性兜底
声明顺序 —— WOFF2 在前，浏览器自动选可用的
```

```text
格式演进：
TTF/OTF → WOFF → WOFF2（体积递减，兼容递增）
```

## Font Subset

Font Subset（字体子集化）只保留实际用到的字符，大幅减小字体文件体积，尤其适合中文字体（几 MB 减到几十 KB）。

```text
子集化的原理：
完整中文字体约 3~10MB（含上万字符）
子集化只保留页面用到的字符，可减到几十 KB
```

```js
// 用 subset-font 工具子集化
// 只保留 "你好世界前端学习" 这几个字
const subsetFont = require('subset-font');

const subsetBuffer = await subsetFont(originalBuffer, '你好世界前端学习', {
  targetFormat: 'woff2',
});
```

```text
子集化策略：
1. 静态文案 —— 提取页面用到的全部字符
2. 动态文案 —— 提取高频字符 + 兜底
3. 工具 —— subset-font、fonttools、glyphhanger
```

## font-display

font-display 控制字体加载期间文字如何显示，解决 FOIT/FOUT 问题，是体验优化的关键属性。

```css
@font-face {
  font-family: 'MyFont';
  src: url('myfont.woff2') format('woff2');
  font-display: swap;   /* 立即显示回退字体，加载后切换 */
}
```

```text
font-display 取值：
auto —— 浏览器默认（通常是 block）
block —— 隐藏文字直到字体就绪（FOIT，最多 3s）
swap —— 立即显示回退字体，加载后切换（推荐）
fallback —— 短暂隐藏后回退，短时间不切换
optional —— 极短隐藏后回退，之后不再切换
```

```text
推荐策略：
正文文本 —— swap（保证可读性优先）
品牌 Logo —— block/optional（保证一致性）
```

## Preload

Preload 预加载关键字体，让字体尽早开始下载，缩短字体就绪时间，减少文字闪动。

```html
<!-- 预加载关键字体 -->
<link rel="preload" href="/fonts/myfont.woff2" as="font" type="font/woff2" crossorigin>
```

```text
Preload 要点：
1. 只预加载首屏关键字体
2. 必须加 crossorigin（字体请求需 CORS）
3. as="font" + type 指定字体类型
```

```css
/* 配合 @font-face 使用 */
@font-face {
  font-family: 'MyFont';
  src: url('/fonts/myfont.woff2') format('woff2');
  font-display: swap;
}
```

## Variable Font

Variable Font（可变字体）用一个字体文件包含多个轴（字重、字宽、斜体等）的连续变化，替代多个独立字重文件，大幅减少请求与体积。

```css
@font-face {
  font-family: 'MyVariableFont';
  src: url('myvariable.woff2') format('woff2-variations');
  font-weight: 100 900;   /* 字重范围 */
}
```

```css
/* 使用任意字重 */
h1 { font-family: 'MyVariableFont'; font-weight: 650; }
p  { font-family: 'MyVariableFont'; font-weight: 400; }
```

```text
Variable Font 优势：
1. 一个文件覆盖多个字重/字宽
2. 减少请求数与总体积
3. 支持精细的字重调节
```

```text
可变轴（axes）：
wght —— 字重（100~900）
wdth —— 字宽
ital —— 斜体
opsz —— 光学尺寸
```

## 应用场景实战

### 场景一：中文字体优化（子集化 + 预加载）

```html
<head>
  <!-- 预加载子集化后的字体 -->
  <link rel="preload" href="/fonts/subset.woff2" as="font" type="font/woff2" crossorigin>
  <style>
    @font-face {
      font-family: 'SubsetFont';
      src: url('/fonts/subset.woff2') format('woff2');
      font-display: swap;
    }
    body { font-family: 'SubsetFont', system-ui, sans-serif; }
  </style>
</head>
```

### 场景二：可变字体替代多字重

```css
@font-face {
  font-family: 'InterVariable';
  src: url('/fonts/inter-var.woff2') format('woff2-variations');
  font-weight: 100 900;
}

.title { font-family: 'InterVariable'; font-weight: 800; }
.body  { font-family: 'InterVariable'; font-weight: 400; }
```

## 最佳实践与踩坑记录

### 最佳实践

1. 字体优先用 WOFF2，WOFF 兜底
2. 中文字体必须子集化，否则体积失控
3. 正文用 font-display: swap 保证可读
4. 首屏关键字体用 preload 加速
5. 多字重场景用可变字体替代

### 踩坑记录

```text
坑 1：中文字体未子集化
结论：字体文件几 MB，首屏加载极慢。
原因：完整中文字体包含上万个字符。
解法：用 subset-font 等工具按需子集化。

坑 2：preload 字体缺 crossorigin
结论：字体被请求两次（预加载失效）。
原因：字体请求需 CORS，preload 未加 crossorigin 导致不匹配。
解法：preload 标签加 crossorigin。

坑 3：font-display 默认 block 导致文字消失
结论：字体加载慢时文字长时间不可见。
原因：默认 block 会隐藏文字直到加载完成。
解法：正文用 font-display: swap。

坑 4：WOFF2 无 WOFF 兜底
结论：旧浏览器字体加载失败。
原因：只声明了 WOFF2，未提供降级。
解法：@font-face 里 WOFF2 在前，WOFF 在后。

坑 5：可变字体未声明字重范围
结论：无法使用 100~900 的中间字重。
原因：font-weight 未声明范围，浏览器按默认处理。
解法：font-weight: 100 900 声明可变范围。
```
