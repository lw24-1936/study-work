## 概述

ECMAScript 是 JavaScript 的语言规范（标准），由 ECMA 国际组织的 TC39 委员会制定。JavaScript 是它的实现（V8、SpiderMonkey、JavaScriptCore 等引擎）。理解 ECMAScript 的版本演进，是掌握 JavaScript 能力边界的钥匙。

```text
几个易混淆概念：
ECMAScript（ES）—— 语言标准本身（语法、类型、内置对象规范）
JavaScript（JS） —— 语言的通称，浏览器/Node 中的实现
引擎 —— V8（Chrome/Node）、SpiderMonkey（Firefox）、JavaScriptCore（Safari）

版本命名：
ES5 → ES6（= ES2015）→ ES2016 → ES2017 → ... → 每年 6 月发布一版
```

## ECMAScript 与 JavaScript 的关系

ECMAScript 定义「语言核心」，JavaScript 在此基础上加上运行环境提供的 API。

```text
ECMAScript 规范内容：
1. 语法 —— 变量、表达式、语句、函数、类
2. 类型 —— 原始类型、对象、类型转换
3. 内置对象 —— Object、Array、Map、Promise、Proxy 等
4. 执行机制 —— 作用域、执行上下文、原型链、this

超出 ECMAScript 的环境 API（不属于语言标准）：
浏览器 —— DOM、BOM、Fetch、Web API
Node.js —— fs、http、process、Buffer
```

```js
// ECMAScript 定义的（语言核心）
const arr = [1, 2, 3];
arr.map(x => x * 2);
new Promise(r => setTimeout(r, 100));

// 环境提供的（非语言标准）
document.querySelector('#app');   // 浏览器 DOM
process.env.NODE_ENV;             // Node 环境
```

## TC39 提案流程

TC39 是负责制定 ECMAScript 标准的技术委员会，新特性必须经过严格的提案阶段才能进入规范。

```text
TC39 提案五阶段：
Stage 0 —— 草稿（想法，非正式）
Stage 1 —— 提案（论证价值，有 champion 负责）
Stage 2 —— 草案（有初步规范文本，语法/语义基本确定）
Stage 3 —— 候选（规范完成，等待实现与反馈）
Stage 4 —— 完成（至少两个引擎实现，纳入下一版规范）

关键点：Stage 3 特性可用 Babel/TypeScript 提前体验，Stage 4 才会正式发布。
```

```text
如何跟进新特性：
1. 查阅 tc39/proposals 仓库查看各提案阶段
2. Stage 4 提案汇总进每年 6 月的版本
3. 生产项目建议只用 Stage 4 或已广泛支持的 Stage 3 特性
```

## ES5 时代

ES5（2009 年）是「现代 JavaScript」的起点，带来了严格模式、数组方法和对象增强，奠定了稳定性基础。

```text
ES5 核心特性：
1. 严格模式 —— 'use strict' 消除静默错误
2. 数组方法 —— forEach、map、filter、reduce、some、every
3. 对象方法 —— Object.keys、Object.create、Object.defineProperty
4. JSON —— JSON.parse / JSON.stringify
5. 访问器属性 —— getter / setter
6. bind 方法 —— Function.prototype.bind
```

```js
'use strict';

const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);   // map 是 ES5 方法
const evens = nums.filter(n => n % 2 === 0);

const obj = Object.create(null);
Object.defineProperty(obj, 'name', {
  value: 'foo',
  writable: false,
});
```

## ES6 划时代变革

ES6（ES2015，2015 年）是最大的一次变革，几乎重塑了 JavaScript 的写法，是现代语法的分水岭。

```text
ES6 核心特性（按类别）：
声明 —— let、const（块级作用域）
函数 —— 箭头函数、默认参数、rest 参数
类 —— class、extends、super
模块 —— import / export（ES Modules）
数据结构 —— Map、Set、WeakMap、WeakSet
异步 —— Promise、Generator
字符串 —— 模板字符串、Symbol
解构 —— 数组/对象解构、扩展运算符
内置增强 —— Object.assign、Array.from、find、includes
```

```js
// 解构 + 箭头函数 + 模板字符串
const user = { name: 'Alice', age: 30 };
const { name, age } = user;
const greet = (n) => `Hello, ${n}!`;
console.log(greet(name));   // Hello, Alice!

// class + Promise
class Api {
  static fetch(url) {
    return fetch(url).then(r => r.json());
  }
}
```

## ES2016+ 年度迭代

ES6 之后改为每年发布小版本（ES2016、ES2017...），单次变更少但持续演进。

```text
ES2016（ES7）：
1. Array.prototype.includes
2. 指数运算符 **
```

```js
[1, 2, 3].includes(2);   // true
2 ** 10;                  // 1024
```

```text
ES2017（ES8）：
1. async / await
2. Object.values / Object.entries
3. 字符串填充 padStart / padEnd
4. 尾逗号（函数参数）
```

```js
async function load() {
  const data = await fetchData();
  return data;
}

Object.entries({ a: 1, b: 2 });   // [['a',1],['b',2]]
'7'.padStart(2, '0');             // '07'
```

## ES2020+ 现代特性

ES2020 开始，一批解决工程痛点的特性落地。

```text
ES2020：
1. 可选链 —— obj?.prop?.method?.()
2. 空值合并 —— a ?? b
3. BigInt —— 大整数
4. Promise.allSettled —— 等待全部 settle
5. 动态 import —— import()
6. globalThis —— 统一全局对象
```

```js
const city = user?.address?.city ?? '未知';

const big = 9007199254740993n;

Promise.allSettled([p1, p2]).then(results => {
  results.forEach(r => console.log(r.status));
});

const mod = await import('./module.js');
```

```text
ES2021：
1. 逻辑赋值运算符 —— ??=、&&=、||=
2. 数字分隔符 —— 1_000_000
3. String.prototype.replaceAll
4. Promise.any
```

```js
let count = 0;
count ??= 10;              // 仅在 null/undefined 时赋值
const million = 1_000_000;
'hello hello'.replaceAll('hello', 'hi');
```

## ES2022+ 与 ES2023+ / ES2024+ / ES2025+

```text
ES2022：
1. 类字段（class fields）—— 实例字段、静态字段
2. 私有字段/方法 —— #private
3. 顶层 await —— 模块顶层直接 await
4. at() 方法 —— 数组/字符串负索引
5. Object.hasOwn
```

```js
class Counter {
  #count = 0;              // 私有字段
  static version = '1.0';
  inc() { this.#count++; return this.#count; }
}

const arr = [1, 2, 3];
arr.at(-1);                // 3（最后一个）

Object.hasOwn(obj, 'key'); // 替代 hasOwnProperty
```

```text
ES2023：
1. 数组查找方法 —— findLast、findLastIndex
2. 不可变数组方法 —— toSorted、toReversed、toSpliced、with
3. 哈希集合语法 —— 尚未落地（提案中，勿混淆）
```

```js
const arr = [3, 1, 2];
const sorted = arr.toSorted();   // 返回新数组，不改原数组
arr;                              // [3,1,2] 原数组不变
```

```text
ES2024：
1. Object.groupBy / Map.groupBy —— 分组
2. 正则 v 标志 —— 集合运算与字符串属性
3. Promise.withResolvers —— 简化 deferred
4. ArrayBuffer 增强
```

```js
const grouped = Object.groupBy([1, 2, 3, 4], n => n % 2 === 0 ? 'even' : 'odd');
// { even: [2, 4], odd: [1, 3] }
```

```text
ES2025（最新）：
1. Iterator 辅助方法 —— map/filter/take/drop 等
2. 正则命名空间与更多 API 增强
3. 提案持续落地中，以 TC39 Stage 4 为准
```

## 应用场景实战

### 场景一：安全访问深层属性

```js
// 旧写法：层层判断
const city = user && user.address && user.address.city;

// 现代写法：可选链 + 空值合并
const city2 = user?.address?.city ?? '未知';
```

### 场景二：不可变数据操作

```js
// 用 ES2023 不可变方法，避免修改原数组
const list = [3, 1, 2];
const sorted = list.toSorted();       // 新数组
const reversed = list.toReversed();   // 新数组
const withNew = list.with(0, 99);     // 替换下标 0
```

## 最佳实践与踩坑记录

### 最佳实践

1. 新代码全面使用 ES6+ 语法，避免 ES5 陈旧写法
2. 生产环境用 Stage 4 特性，或转译 Stage 3（Babel/TS）
3. 用可选链与空值合并替代冗长的 null 检查
4. 关注 TC39 提案，但只采用广泛支持的特性
5. 用 browserslist + Babel 决定「能写多新」的语法

### 踩坑记录

```text
坑 1：把环境 API 当成 ES 标准
结论：用了 fetch 以为所有环境都支持。
原因：混淆 ECMAScript 标准与宿主环境 API。
解法：查 MDN 确认特性归属，评估目标环境支持度。

坑 2：Stage 3 特性直接上生产
结论：部分浏览器不支持，报错。
原因：过早使用未达 Stage 4 的提案特性。
解法：生产用 Stage 4 或转译，实验项目可尝鲜 Stage 3。

坑 3：混淆 ES 版本与 Node/浏览器版本
结论：Node 版本高不代表所有 ES 特性都支持。
原因：引擎实现进度不同，版本不等于特性全集。
解法：用 caniuse / node.green 查询具体特性支持。

坑 4：误用 toSorted 以为是原地排序
结论：arr.toSorted() 后原数组没变，以为 bug。
原因：ES2023 不可变方法返回新数组。
解法：区分 sort（原地）与 toSorted（新数组）语义。

坑 5：私有字段语法写错（# 位置）
结论：this.count 访问不到 #count。
原因：私有字段必须带 # 前缀访问。
解法：牢记 #field 声明、this.#field 访问，二者缺一不可。
```
