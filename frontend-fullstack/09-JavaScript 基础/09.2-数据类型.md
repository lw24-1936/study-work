## 概述

JavaScript 的数据类型分为**原始类型（Primitive）**与**引用类型（Object）**两大类。原始类型不可变、按值存储，对象类型可变、按引用存储。理解类型系统是避免大量 bug 的基础。

```text
JavaScript 类型全景（8 种）：
原始类型（7 种）：
1. Undefined —— 未定义
2. Null      —— 空值
3. Boolean   —— 布尔
4. Number    —— 数值（IEEE 754 双精度）
5. BigInt    —— 大整数（ES2020）
6. String    —— 字符串
7. Symbol    —— 唯一符号（ES6）

引用类型（1 种）：
8. Object    —— 对象（含 Array、Function、Date、RegExp 等）
```

```text
typeof 运算符返回结果（历史遗留的坑）：
typeof undefined    // 'undefined'
typeof null         // 'object'（历史 bug，null 是原始类型）
typeof true         // 'boolean'
typeof 42           // 'number'
typeof 42n          // 'bigint'
typeof 'str'        // 'string'
typeof Symbol()     // 'symbol'
typeof {}           // 'object'
typeof function(){} // 'function'（函数是对象，但 typeof 特判）
```

## 七种原始类型

```text
原始类型的共同特性：
1. 不可变 —— 值一旦创建不能修改（改变只是重新赋值）
2. 按值存储 —— 变量直接持有值本身
3. 按值比较 —— 比较的是值，不是引用
4. 无属性 —— 原始值本身没有属性（访问时会临时装箱）
```

```js
// 不可变与按值比较
let a = 'hello';
let b = a;
b = 'world';       // 改 b 不影响 a（值拷贝）
console.log(a);    // 'hello'

'abc' === 'abc';   // true（按值比较）
```

## Undefined 与 Null

Undefined 表示「未定义」（变量已声明未赋值、函数无返回值、对象无此属性），Null 表示「空值」（人为赋值的空）。

```js
let x;                    // undefined（声明未赋值）
const obj = {};
obj.missing;              // undefined（访问不存在的属性）

const empty = null;       // null（人为表示空）
```

```text
Undefined vs Null 语义：
Undefined —— 系统默认的空（引擎给的空）
Null —— 开发者显式的空（人为表示「无对象」）

判断技巧：
undefined 用 === undefined 或 typeof x === 'undefined'
null 用 === null（不能用 typeof，它是 'object'）
```

## Boolean 布尔值

Boolean 只有 true / false 两个值，配合**真值/假值**（Truthy/Falsy）在条件判断中发挥作用。

```text
假值（Falsy，共 8 个）：
false、0、-0、0n、''（空串）、null、undefined、NaN

其余全部为真值（Truthy），包括 '0'、[]、{}、'false'。
```

```js
if ('0') console.log('真');     // 打印（非空字符串是真值）
if ([]) console.log('真');      // 打印（空数组是真值）

Boolean('');      // false
Boolean('0');     // true
Boolean(0);       // false
```

## Number 数值

Number 是唯一的数值类型，采用 IEEE 754 双精度浮点数，覆盖整数与浮点数。

```js
42;            // 整数
3.14;          // 浮点
0xff;          // 十六进制 255
1e6;           // 科学计数法 1000000
Number.MAX_SAFE_INTEGER;  // 9007199254740991
```

```text
Number 的关键问题：
1. 精度 —— 超出 2^53 - 1 的整数会丢精度
2. 浮点误差 —— 0.1 + 0.2 !== 0.3
3. 特殊值 —— NaN、Infinity、-0

详见 [[09.4-Number]]。
```

## BigInt 大整数

BigInt 用于表示超过 Number 安全范围的大整数，通过 `n` 后缀或 BigInt() 创建。

```js
const big = 9007199254740993n;   // 超出 Number 安全范围
const fromNum = BigInt(42);

big + 1n;          // 9007199254740994n
```

```text
BigInt 注意：
1. 不能与 Number 混用运算 —— 1n + 1 会报错，需显式转换
2. 不能用于 Math 对象方法
3. 与 Number 比较可以，严格相等不行 —— 1n == 1 true，1n === 1 false
```

## String 字符串

String 表示文本，支持单引号、双引号、模板字符串三种写法。

```js
'a';                    // 单引号
"b";                    // 双引号
`${1 + 1}`;             // 模板字符串（可插值、多行）
```

```text
String 特性：
1. 不可变 —— 所有字符串方法返回新字符串
2. UTF-16 编码 —— 大部分字符一个码元，表情符号占两个
3. 类数组 —— 有 length、可索引访问、可迭代

详见 [[09.5-String]]。
```

## Symbol 符号

Symbol 用于创建**唯一**的值，常作为对象属性键，避免命名冲突。

```js
const s1 = Symbol('desc');
const s2 = Symbol('desc');
s1 === s2;      // false（即使描述相同，每个 Symbol 都唯一）

const obj = {
  [s1]: 'value',
};
obj[s1];        // 'value'
```

```text
Symbol 特性：
1. 唯一性 —— 每次 Symbol() 都不同
2. 不可枚举 —— 普通 Symbol 属性不出现在 for...in / Object.keys
3. 内置 Symbol —— Symbol.iterator、Symbol.toPrimitive 等定义语言行为
```

## Object 对象

Object 是所有引用类型的基类，是键值对的集合，Array、Function、Date 等都是它的特化形式。

```js
const obj = { name: 'Alice', age: 30 };
obj.name;                // 'Alice'
obj['age'];              // 30

const arr = [1, 2, 3];   // 数组也是对象
typeof arr;              // 'object'
```

```text
Object 特性：
1. 可变 —— 属性可增删改
2. 按引用存储 —— 变量持有的是引用（指针）
3. 按引用比较 —— 两个对象比较的是引用地址
4. 属性键 —— 字符串或 Symbol

详见 [[09.6-Object]] 与 [[11.3-原型]]。
```

```js
// 按引用比较的坑
const a = {};
const b = {};
a === b;         // false（不同引用）

const c = a;
c === a;         // true（同一引用）
```

## 应用场景实战

### 场景一：参数默认值与空值判断

```js
function greet(name) {
  const n = name ?? '匿名用户';   // null/undefined 走默认，空串保留
  return `Hello, ${n}`;
}
```

### 场景二：唯一标识

```js
// Symbol 做私有/唯一键，避免与用户数据键冲突
const ID = Symbol('id');
const user = { [ID]: 1, name: 'Alice' };
```

## 最佳实践与踩坑记录

### 最佳实践

1. 判断 null/undefined 用 ??，判断「空」用显式判断而非依赖真值
2. 大整数用 BigInt，避免 Number 精度丢失
3. 需要唯一键或定义语言行为时用 Symbol
4. 牢记 typeof null === 'object' 的坑，判断 null 用 === null
5. 理解按值 vs 按引用，避免对象比较的误解

### 踩坑记录

```text
坑 1：typeof null 是 'object'
结论：用 typeof 判断 null 失效。
原因：历史遗留 bug，null 被误报为 object。
解法：判断 null 用 x === null。

坑 2：0.1 + 0.2 不等于 0.3
结论：浮点运算精度误差。
原因：IEEE 754 二进制无法精确表示某些小数。
解法：用整数运算或 Number.EPSILON 容差比较。

坑 3：大整数精度丢失
结论：9007199254740993 被存成 9007199254740992。
原因：超过 Number.MAX_SAFE_INTEGER。
解法：用 BigInt（后缀 n）。

坑 4：真值判断误判
结论：if (count) 当 count=0 时走了 false 分支。
原因：0 是假值，业务上 0 可能是有意义的值。
解法：显式判断 count !== 0 或 count != null。

坑 5：BigInt 与 Number 混算
结论：1n + 1 直接报错。
原因：BigInt 与 Number 不能隐式混合运算。
解法：显式转换 Number(1n) + 1 或 1n + 1n。
```
