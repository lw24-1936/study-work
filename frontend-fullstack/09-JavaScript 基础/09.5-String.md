## 概述

String 是表示文本的原始类型，不可变、可迭代，采用 UTF-16 编码存储。它是前端最频繁操作的类型之一，掌握其编码细节与方法能避免大量字符串处理 bug。

```text
String 的核心特性：
1. 不可变 —— 所有方法返回新字符串，原值不变
2. UTF-16 —— 每个字符占 1-2 个码元
3. 类数组 —— 有 length、可下标访问、可 for...of 迭代
4. 三种写法 —— 单引号、双引号、模板字符串
```

## UTF-16 编码

JavaScript 字符串内部使用 UTF-16 编码，每个「码元」（code unit）是 16 位。length 属性返回的是**码元数量**，而非实际字符数。

```js
'a'.length;       // 1（一个码元）
'汉'.length;      // 1（BMP 内汉字一个码元）
'😀'.length;      // 2（表情符号占两个码元！）
```

```text
UTF-16 关键概念：
码元（code unit）   —— 16 位存储单元，length 统计的单位
码点（code point）  —— 实际字符的 Unicode 编号
BMP（基本多文种平面）—— U+0000 ~ U+FFFF，一个码元表示
补充平面 —— U+10000 以上，需要两个码元（代理对）
```

## Unicode 与代理对

超出 BMP 的字符（大多数 emoji、生僻字）需要用**代理对**（两个码元）表示，这带来了一系列处理陷阱。

```js
const emoji = '😀';

emoji.length;             // 2（两个码元，不是 1）
emoji[0];                 // 返回半个代理对（乱码字符）
emoji[1];                 // 另一半

// 正确获取码点数
[...emoji].length;        // 1（用展开符按码点拆分）
Array.from(emoji).length; // 1
```

```text
处理 Unicode 字符的正确姿势：
1. 按码点遍历用 for...of 或 [...str]
2. 码点转义 \u{1F600}
3. 正则用 u 标志正确处理代理对
4. 需要按「字符」计数时，用 [...str].length 而非 str.length
```

```js
// for...of 按码点迭代
for (const ch of 'a😀b') {
  console.log(ch);   // 'a'、'😀'、'b'
}

// 码点表示
'\u{1F600}';          // '😀'
```

## Template Literal 模板字符串

模板字符串（反引号）支持**插值**、**多行**和**标签模板**，是字符串拼接的现代替代。

```js
const name = 'Alice';
const age = 30;

// 插值
const msg = `Hello, ${name}, you are ${age} years old.`;

// 多行（保留换行）
const html = `
  <div>
    <span>${name}</span>
  </div>
`;

// 表达式插值
const sum = `${1 + 2}`;   // '3'
```

```text
模板字符串特性：
1. 插值 —— ${} 内可写任意表达式
2. 多行 —— 保留换行与缩进（注意会包含空格）
3. 标签模板 —— fn`...` 形式，用于 DSL（如 styled-components）
```

```js
// 标签模板
function highlight(strings, ...values) {
  return strings.reduce((acc, s, i) =>
    acc + s + (values[i] ? `<b>${values[i]}</b>` : ''), '');
}
highlight`Hello ${'Alice'}`;   // 'Hello <b>Alice</b>'
```

## String Methods 常用方法

```text
字符串方法分类：
查找 —— indexOf、includes、startsWith、endsWith、search
提取 —— slice、substring、substr（废弃）、charAt、at
转换 —— toUpperCase、toLowerCase、trim、padStart、padEnd
替换 —— replace、replaceAll
拆分拼接 —— split、concat、join
```

```js
const str = 'Hello World';

// 查找
str.includes('World');        // true
str.startsWith('Hello');      // true
str.endsWith('World');        // true
str.indexOf('o');             // 4

// 提取
str.slice(0, 5);              // 'Hello'
str.slice(-5);                // 'World'（负索引）
str.at(-1);                   // 'd'（ES2022）

// 转换
'  hi  '.trim();              // 'hi'
'7'.padStart(2, '0');         // '07'

// 替换
'aaa'.replaceAll('a', 'b');   // 'bbb'

// 拆分
'1,2,3'.split(',');           // ['1','2','3']
```

```text
slice vs substring vs substr：
slice —— 支持负索引，推荐
substring —— 负索引当 0，参数自动排序
substr —— 已废弃（第二参数是长度），勿用
```

## String Iterator 迭代器

字符串内置 Symbol.iterator，可用 for...of、展开运算符、Array.from 按码点迭代。

```js
const str = 'a😀b';

// for...of 按码点迭代
for (const ch of str) {
  console.log(ch);   // a、😀、b（正确，3 个字符）
}

// 展开运算符
[...str];            // ['a', '😀', 'b']

// 对比：按码元（下标）访问会拆散代理对
str[1];              // 半个 emoji（乱码）
```

```text
迭代器 vs 下标访问：
下标访问 str[i] —— 按码元，会拆散代理对
迭代器 for...of —— 按码点，正确处理 emoji 等

处理多语言/emoji 文本时，务必用迭代器方式。
```

## RegExp 正则表达式

正则用于字符串的模式匹配、查找、替换，是字符串处理的重要补充。

```js
// 字面量与构造函数
const re1 = /hello/i;                // 字面量
const re2 = new RegExp('hello', 'i'); // 构造函数

// 常用方法
/hello/.test('hello world');          // true（是否存在）
'hello world'.match(/o/g);            // ['o', 'o']（全局匹配）
'hello'.replace(/l/g, 'L');           // 'heLLo'（替换）
'hello world'.search(/world/);        // 6（匹配位置）
```

```text
正则标志：
g —— 全局匹配
i —— 忽略大小写
m —— 多行模式
s —— 点号匹配换行
u —— Unicode 模式（正确处理代理对）
y —— 粘性匹配

处理 emoji 的正则务必加 u 标志。
```

```js
// u 标志正确处理 emoji
'😀'.match(/./u);     // ['😀']（u 标志，匹配整个 emoji）
'😀'.match(/./);      // 匹配半个（无 u 标志）

// ES2024 v 标志：集合运算
// /[\p{Letter}&&\p{ASCII}]/v
```

## 应用场景实战

### 场景一：按字符（而非码元）截断文本

```js
function truncate(str, maxChars) {
  const chars = [...str];              // 按码点拆分
  return chars.length > maxChars
    ? chars.slice(0, maxChars).join('') + '...'
    : str;
}

truncate('a😀b😀c', 3);   // 'a😀b...'（正确，不拆散 emoji）
```

### 场景二：模板字符串生成 HTML

```js
function card(title, desc) {
  return `
    <div class="card">
      <h2>${title}</h2>
      <p>${desc}</p>
    </div>
  `;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 拼接字符串优先用模板字符串，避免 + 号拼接
2. 处理 emoji/多语言文本，按码点操作（for...of、[...str]）
3. 提取子串用 slice（支持负索引），别用 substr
4. 正则处理 Unicode 字符加 u 标志
5. 大量字符串拼接（循环内）用数组 join 或考虑性能

### 踩坑记录

```text
坑 1：emoji 的 length 是 2
结论：'😀'.length 返回 2，以为是 1。
原因：UTF-16 代理对，length 统计码元。
解法：按码点计数用 [...str].length。

坑 2：下标访问拆散 emoji
结论：'😀'[0] 得到乱码。
原因：下标按码元访问，拿到半个代理对。
解法：用 for...of 或 Array.from 按码点处理。

坑 3：slice 与 substring 参数理解错
结论：负索引处理结果出乎意料。
原因：substring 把负索引当 0，slice 支持负索引。
解法：统一用 slice，语义直观。

坑 4：replace 只替换第一个
结论：'aaa'.replace('a','b') 只替换一个。
原因：replace 字符串参数默认只替换首个匹配。
解法：用 replaceAll 或正则 /a/g。

坑 5：正则不加 u 标志误处理 Unicode
结论：匹配 emoji 结果错误。
原因：无 u 标志时按码元匹配。
解法：涉及 Unicode 的正则加 u 标志。
```
