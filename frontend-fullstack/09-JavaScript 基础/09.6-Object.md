## 概述

Object 是 JavaScript 所有引用类型的基类，是「键值对」的集合。理解对象的属性、描述符、原型链，是深入 JavaScript 的核心。

```text
Object 的核心概念：
1. 属性 —— 键（字符串/Symbol）+ 值 + 描述符
2. 属性描述符 —— 控制属性可枚举、可写、可配置
3. 原型链 —— 属性查找沿 [[Prototype]] 链向上
4. 创建方式 —— 字面量、Object.create、new、class
```

## Property 属性

对象的每个属性由**键、值、属性描述符**组成。键可以是字符串或 Symbol。

```js
const obj = {
  name: 'Alice',          // 字符串键
  [Symbol('id')]: 1,      // Symbol 键
  'full-name': 'Alice S', // 特殊字符串键（需引号）
};

obj.name;          // 点访问
obj['full-name'];  // 方括号访问（含特殊字符的键）
```

```text
访问属性的两种方式：
点访问 obj.name —— 简洁，键必须是合法标识符
方括号 obj[key] —— 支持任意字符串、变量、Symbol
```

## Descriptor 属性描述符

每个属性都带描述符，通过 Object.getOwnPropertyDescriptor / defineProperty 查看与设置。

```js
const obj = { name: 'Alice' };

Object.getOwnPropertyDescriptor(obj, 'name');
// {
//   value: 'Alice',
//   writable: true,       // 可写
//   enumerable: true,     // 可枚举
//   configurable: true,   // 可配置
// }
```

```text
两类描述符（互斥，不能同时设置 value 与 get/set）：
数据描述符 —— value、writable
访问描述符 —— get、set

共享描述符 —— enumerable、configurable
```

```js
// 访问器属性（getter/setter）
const user = {
  _name: 'Alice',
  get name() { return this._name; },
  set name(v) { this._name = v.toUpperCase(); },
};

user.name = 'bob';
user.name;         // 'BOB'
```

## Enumerable / Configurable / Writable

三个描述符标志控制属性的行为。

```text
writable（可写）：
false 时属性值不可改（非严格模式静默失败，严格模式报错）

enumerable（可枚举）：
false 时不出现在 for...in、Object.keys、展开运算符中

configurable（可配置）：
false 时不可删除、不可再改描述符（value/writable 例外）
```

```js
const obj = {};
Object.defineProperty(obj, 'secret', {
  value: 42,
  writable: false,
  enumerable: false,
  configurable: false,
});

obj.secret = 99;            // 静默失败（非严格模式）
Object.keys(obj);           // []（不可枚举）
delete obj.secret;          // false（不可配置）
```

```text
defineProperty 的默认值：
用 defineProperty 定义时，writable/enumerable/configurable 默认都是 false！
用字面量定义时，三者默认都是 true。

这是常见的坑：defineProperty 定义的属性默认不可枚举、不可写。
```

## Prototype 与 Prototype Chain 原型链

每个对象都有一个内部 [[Prototype]]（通过 __proto__ 或 Object.getPrototypeOf 访问），属性查找沿原型链向上。

```js
const parent = { greet() { return 'hello'; } };
const child = Object.create(parent);   // child 的原型是 parent

child.greet();             // 'hello'（从原型链找到）
child.hasOwnProperty('greet');  // false（greet 在原型上）
```

```text
原型链机制：
1. 访问属性时，先找自身，找不到沿 [[Prototype]] 向上
2. 链的顶端是 Object.prototype，再上是 null
3. 普通对象的原型是 Object.prototype
4. 函数对象还有 prototype 属性（用于 new 构造）
```

```js
// 原型链顶端
const obj = {};
Object.getPrototypeOf(obj) === Object.prototype;   // true
Object.getPrototypeOf(Object.prototype);           // null
```

```text
prototype vs __proto__ 区分：
prototype —— 函数对象特有的属性，new 时作为实例的原型
__proto__ —— 任意对象的内部原型访问器（建议用 Object.getPrototypeOf）
```

## Object.create 创建对象

Object.create 以指定对象为原型创建新对象，是「原型式继承」的基础。

```js
const proto = { type: 'animal', speak() { return this.name; } };

const dog = Object.create(proto);
dog.name = 'dog';
dog.speak();          // 'dog'

Object.getPrototypeOf(dog) === proto;   // true
```

```js
// 第二个参数：定义属性（默认描述符为 false）
const obj = Object.create(null, {
  name: { value: 'x', enumerable: true },
});
Object.keys(obj);     // ['name']
```

```text
Object.create(null) 的特殊用法：
创建「无原型」对象，用于纯数据字典，避免原型链污染。
常用于 Map 出现前的 key-value 存储，或防原型污染。
```

## Object.assign 浅拷贝

Object.assign 把源对象的**可枚举自有属性**复制到目标对象，返回目标对象，是浅拷贝。

```js
const target = { a: 1 };
const source = { b: 2, c: 3 };

Object.assign(target, source);
target;              // { a: 1, b: 2, c: 3 }
```

```js
// 浅拷贝：嵌套对象仍是引用
const original = { nested: { x: 1 } };
const copy = Object.assign({}, original);

copy.nested.x = 999;
original.nested.x;    // 999（被影响，浅拷贝只复制顶层）
```

```text
浅拷贝的边界：
Object.assign 只复制一层，嵌套对象/数组仍共享引用。
深拷贝需要 structuredClone（现代）、JSON 或递归实现。

现代推荐：const copy = { ...obj }（展开符，语义相同）；
深拷贝：structuredClone(obj)（支持循环引用、Date、Map 等）。
```

## Reflect 反射

Reflect 是一组与 Object 方法对应的**函数式** API，配合 Proxy 使用，提供更一致的元编程能力。

```text
Reflect 的价值：
1. 函数式 —— Reflect.get(obj, key) 替代 obj[key]
2. 返回布尔 —— Reflect.defineProperty 返回 true/false 而非报错
3. 与 Proxy 对应 —— Proxy 的 trap 与 Reflect 方法一一对应
4. 统一操作 —— 把 Object 的 try/catch 式操作变成返回值判断
```

```js
const obj = { name: 'Alice' };

Reflect.get(obj, 'name');        // 'Alice'（读）
Reflect.set(obj, 'name', 'bob'); // true（写）
Reflect.has(obj, 'name');        // true（in 运算符）

// 对比：Object.defineProperty 失败会抛错，Reflect 返回 false
Reflect.defineProperty(obj, 'x', { value: 1 });  // true
```

```text
Reflect 与 Object 的对应：
Object.defineProperty → Reflect.defineProperty（返回布尔）
delete obj.x → Reflect.deleteProperty（返回布尔）
key in obj → Reflect.has
Object.keys 等 → Reflect.ownKeys
```

## 应用场景实战

### 场景一：深拷贝

```js
const obj = { a: 1, nested: { b: 2 }, list: [1, 2] };

// 现代：structuredClone
const deep = structuredClone(obj);
deep.nested.b = 999;
obj.nested.b;          // 2（原对象不受影响）
```

### 场景二：防原型污染的对象

```js
// 用无原型对象做数据字典
const dict = Object.create(null);
dict['__proto__'] = 'safe';
dict.__proto__;        // undefined（不受原型污染）
```

## 最佳实践与踩坑记录

### 最佳实践

1. 浅拷贝用展开符 {...obj}，深拷贝用 structuredClone
2. 数据字典用 Map 或 Object.create(null)，防原型污染
3. 判断自有属性用 Object.hasOwn，避免 hasOwnProperty 被覆盖
4. 遍历用 Object.keys/values/entries，配合 for...of
5. 元编程操作（Proxy 场景）用 Reflect 统一处理

### 踩坑记录

```text
坑 1：defineProperty 默认不可枚举不可写
结论：用 defineProperty 定义的属性，Object.keys 看不到、改不了。
原因：默认 descriptor 为 false，与字面量默认 true 相反。
解法：显式写 writable/enumerable/configurable: true。

坑 2：Object.assign 是浅拷贝
结论：改了嵌套对象，原对象也被改。
原因：只复制顶层引用。
解法：深拷贝用 structuredClone 或递归实现。

坑 3：用 hasOwnProperty 被覆盖
结论：obj.hasOwnProperty 不是函数，报错。
原因：对象里定义了名为 hasOwnProperty 的属性覆盖了原型方法。
解法：用 Object.hasOwn(obj, key) 静态方法。

坑 4：for...in 遍历到原型属性
结论：遍历出继承来的属性。
原因：for...in 会遍历原型链上的可枚举属性。
解法：用 Object.keys + for...of，或 hasOwn 过滤。

坑 5：__proto__ 直接赋值污染原型
结论：obj.__proto__ = xxx 意外改变了原型。
原因：__proto__ 是特殊访问器，赋值会改原型。
解法：用 Object.setPrototypeOf（明确意图），或 Object.create。
```
