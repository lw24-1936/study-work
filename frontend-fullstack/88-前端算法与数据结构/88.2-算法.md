## 概述

算法是解决问题的套路，前端面试和日常优化都离不开这些核心范式。二分、双指针、滑动窗口解决「查找和子区间」问题；前缀和、差分数组把区间查询和区间修改降到 O(1)；贪心、动态规划、回溯是三大「最优化与搜索」框架；分治则是归并、快排的思想根基。掌握每种算法的适用信号，比背模板更重要。

```text
算法的适用信号：
1. Binary Search —— 有序数组里找目标/找边界
2. Two Pointer —— 有序数组求两数、去重、快慢指针
3. Sliding Window —— 求满足条件的连续子数组/子串
4. Prefix Sum —— 多次区间求和 O(1) 查询
5. Difference Array —— 多次区间增减 O(1) 修改
6. Greedy —— 局部最优即全局最优的问题
7. Dynamic Programming —— 有重叠子问题的最优化/计数
8. Backtracking —— 求所有组合/排列/子集的搜索
9. Divide and Conquer —— 归并排序、快速排序、大问题拆小
```

## Binary Search

Binary Search（二分查找）在有序序列中每次排除一半候选，把查找复杂度从 O(n) 降到 O(log n)。它的难点不在「找某个值」，而在「找第一个满足条件的边界」，边界处理是二分最容易出错的地方。

```js
// 基础二分：在有序数组中查找目标值
function binarySearch(nums, target) {
  let left = 0, right = nums.length - 1;
  while (left <= right) {
    const mid = left + ((right - left) >> 1);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}

// 变体：找第一个 >= target 的位置（lower bound）
function lowerBound(nums, target) {
  let left = 0, right = nums.length;
  while (left < right) {
    const mid = left + ((right - left) >> 1);
    if (nums[mid] >= target) right = mid;
    else left = mid + 1;
  }
  return left;
}
console.log(lowerBound([1, 3, 3, 5, 7], 3)); // 1
```

```text
Binary Search 的要点：
1. 前提 —— 序列必须有序（或满足单调性）
2. 防溢出 —— 用 left + ((right-left)>>1) 而非 (left+right)/2
3. 区间开闭 —— 明确 [left,right] 还是 [left,right)，边界才不乱
4. 应用 —— 查找、求平方根、旋转数组、寻找峰值
```

## Two Pointer

Two Pointer（双指针）用两个指针在数组上协同移动，把双重循环 O(n²) 优化到 O(n)。常见形式：左右指针（相向/同向）、快慢指针（判环、去重）、对撞指针（有序数组求两数之和）。

```js
// 左右对撞：有序数组两数之和
function twoSumSorted(nums, target) {
  let left = 0, right = nums.length - 1;
  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) return [left, right];
    if (sum < target) left++;
    else right--;
  }
  return [];
}

// 快慢指针：移除有序数组重复项
function removeDuplicates(nums) {
  let slow = 0;
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }
  return slow + 1;
}
console.log(removeDuplicates([1, 1, 2])); // 2
```

```text
Two Pointer 的要点：
1. 对撞指针 —— 有序数组求两数/三数之和、接雨水
2. 快慢指针 —— 判环、找中点、原地去重
3. 同向滑动 —— 配合滑动窗口思想
4. 优势 —— 把双重循环降到单次遍历 O(n)
```

## Sliding Window

Sliding Window（滑动窗口）维护一个左右边界的窗口，在数组/字符串上滑动，解决「连续子数组/子串」问题。核心是右边界扩展、左边界收缩，配合窗口内状态（如 Map 计数）做到 O(n)。

```js
// 无重复字符的最长子串
function lengthOfLongestSubstring(s) {
  const window = new Map();
  let left = 0, max = 0;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (window.has(ch)) {
      left = Math.max(left, window.get(ch) + 1);
    }
    window.set(ch, right);
    max = Math.max(max, right - left + 1);
  }
  return max;
}
console.log(lengthOfLongestSubstring('abcabcbb')); // 3

// 长度最小的子数组，和 >= target
function minSubArrayLen(target, nums) {
  let left = 0, sum = 0, min = Infinity;
  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
      min = Math.min(min, right - left + 1);
      sum -= nums[left++];
    }
  }
  return min === Infinity ? 0 : min;
}
```

```text
Sliding Window 的要点：
1. 右扩左缩 —— 右指针扩张满足条件，左指针收缩求最优
2. 窗口状态 —— 用 Map/计数维护窗口内的信息
3. 时机 —— 连续子数组/子串、恰好包含、最长最短
4. 复杂度 —— 每个元素进窗出窗各一次，O(n)
```

## Prefix Sum

Prefix Sum（前缀和）预先计算前 i 项之和，把任意区间 [l,r] 的和查询从 O(n) 降到 O(1)。它是「多次区间求和」问题的标配，也是差分、二维前缀和的起点。

```js
// 一维前缀和
function buildPrefixSum(nums) {
  const pre = [0];
  for (const n of nums) pre.push(pre[pre.length - 1] + n);
  return pre;
}
// 查询区间 [l, r] 的和（l、r 从 0 开始）
function rangeSum(pre, l, r) {
  return pre[r + 1] - pre[l];
}

const pre = buildPrefixSum([1, 2, 3, 4, 5]);
console.log(rangeSum(pre, 1, 3)); // 2+3+4 = 9

// 应用：和为 k 的子数组个数（前缀和 + 哈希）
function subarraySum(nums, k) {
  const map = new Map([[0, 1]]);
  let sum = 0, count = 0;
  for (const n of nums) {
    sum += n;
    count += map.get(sum - k) || 0;
    map.set(sum, (map.get(sum) || 0) + 1);
  }
  return count;
}
```

```text
Prefix Sum 的要点：
1. 定义 —— pre[i] = nums[0..i-1] 之和，pre[0]=0
2. 区间和 —— [l,r] 的和 = pre[r+1] - pre[l]
3. 配合哈希 —— 解决「和为 k 的子数组」类问题
4. 二维扩展 —— 矩阵区域和用二维前缀和
```

## Difference Array

Difference Array（差分数组）记录相邻元素的差值，把「区间 [l,r] 都加 x」这种批量修改从 O(n) 降到 O(1)。它和前缀和互为逆运算，适合「多次区间修改、最后统一查询」的场景。

```js
// 差分数组：区间 [l,r] 加 val
function rangeAdd(diff, n, l, r, val) {
  diff[l] += val;
  diff[r + 1] -= val; // r+1 越界时需扩数组
}

// 还原原数组
function restore(diff) {
  const res = [diff[0]];
  for (let i = 1; i < diff.length - 1; i++) {
    res.push(res[i - 1] + diff[i]);
  }
  return res;
}

// 应用：航班预订统计（每个区间 +seats）
function corpFlightBookings(bookings, n) {
  const diff = new Array(n + 2).fill(0);
  for (const [l, r, seats] of bookings) {
    diff[l] += seats;
    diff[r + 1] -= seats;
  }
  const res = [];
  let sum = 0;
  for (let i = 1; i <= n; i++) {
    sum += diff[i];
    res.push(sum);
  }
  return res;
}
console.log(corpFlightBookings([[1, 2, 10], [2, 3, 20]], 3)); // [10,30,20]
```

```text
Difference Array 的要点：
1. 定义 —— diff[i] = nums[i] - nums[i-1]
2. 区间修改 —— [l,r] 加 x 只需 diff[l]+=x, diff[r+1]-=x
3. 还原 —— 对 diff 做前缀和即得原数组
4. 适用 —— 多次修改后一次查询，如航班/会议室预订
```

## Greedy

Greedy（贪心）在每一步都取当前最优，希望最终得到全局最优。它实现简单、效率高，但只在问题具备「贪心选择性质」时正确。典型应用：区间调度、跳跃游戏、分配问题、找零钱（特定面额）。

```js
// 无重叠区间：最多能选多少个不重叠区间
function eraseOverlapIntervals(intervals) {
  intervals.sort((a, b) => a[1] - b[1]); // 按结束时间排序
  let count = 0;
  let end = -Infinity;
  for (const [s, e] of intervals) {
    if (s >= end) {
      count++;
      end = e;
    }
  }
  return intervals.length - count;
}

// 跳跃游戏：能否到达终点
function canJump(nums) {
  let farthest = 0;
  for (let i = 0; i < nums.length; i++) {
    if (i > farthest) return false;
    farthest = Math.max(farthest, i + nums[i]);
    if (farthest >= nums.length - 1) return true;
  }
  return false;
}
console.log(canJump([2, 3, 1, 1, 4])); // true
```

```text
Greedy 的要点：
1. 局部最优 —— 每步选当前最优
2. 前提 —— 问题需具备贪心选择性质（局部最优=全局最优）
3. 常见套路 —— 区间按结束时间排序、性价比排序
4. 需证明 —— 贪心不是万能的，拿不准时用 DP 兜底
```

## Dynamic Programming

Dynamic Programming（动态规划）把大问题拆成有重叠的子问题，用数组/表缓存子问题答案，避免重复计算。核心是「状态定义 + 状态转移方程」。它解决最优化、计数、可行性三类问题。

```js
// 爬楼梯：每次 1 或 2 阶，到 n 阶有几种走法
function climbStairs(n) {
  const dp = [1, 1];
  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
  }
  return dp[n];
}

// 0-1 背包：容量 W，物品有重量和价值，求最大价值
function knapsack(weights, values, W) {
  const dp = new Array(W + 1).fill(0);
  for (let i = 0; i < weights.length; i++) {
    for (let w = W; w >= weights[i]; w--) {
      dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
    }
  }
  return dp[W];
}
console.log(knapsack([2, 3, 4], [3, 4, 5], 5)); // 7
```

```text
Dynamic Programming 的要点：
1. 三要素 —— 状态定义、状态转移方程、边界条件
2. 重叠子问题 —— 用缓存消除重复计算
3. 递推方向 —— 一维从左到右，背包倒序遍历防重复选
4. 空间优化 —— 用滚动数组把 O(n²) 降到 O(n)
5. 应用 —— 背包、LIS、LCS、编辑距离、打家劫舍
```

## Backtracking

Backtracking（回溯）是穷举搜索的框架，通过「选择 → 递归 → 撤销」遍历解空间树，适合求所有组合、排列、子集。它配合剪枝能大幅减少搜索量。

```js
// 全排列
function permute(nums) {
  const res = [];
  const used = new Array(nums.length).fill(false);
  function backtrack(path) {
    if (path.length === nums.length) {
      res.push([...path]);
      return;
    }
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      used[i] = true;
      path.push(nums[i]);
      backtrack(path);        // 递归深入
      path.pop();             // 撤销选择
      used[i] = false;
    }
  }
  backtrack([]);
  return res;
}
console.log(permute([1, 2, 3]).length); // 6
```

```text
Backtracking 的要点：
1. 三步骤 —— 做选择、递归、撤销选择
2. 解空间树 —— 组合/排列/子集问题的统一框架
3. 剪枝 —— 提前排除不可能的分支，大幅提速
4. 去重 —— 排序 + 同层去重，避免重复结果
5. 应用 —— N 皇后、数独、组合总和、括号生成
```

## Divide and Conquer

Divide and Conquer（分治）把大问题递归拆成规模更小的同类子问题，分别解决后合并结果。归并排序、快速排序、二分都是分治思想的体现，复杂度常是 O(n log n)。

```js
// 归并排序
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = arr.length >> 1;
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  return merge(left, right);
}
function merge(a, b) {
  const res = [];
  let i = 0, j = 0;
  while (i < a.length && j < b.length) {
    res.push(a[i] <= b[j] ? a[i++] : b[j++]);
  }
  return res.concat(a.slice(i)).concat(b.slice(j));
}
console.log(mergeSort([5, 2, 4, 1, 3])); // [1,2,3,4,5]
```

```text
Divide and Conquer 的要点：
1. 三步 —— 分解、解决子问题、合并结果
2. 递归 —— 子问题与原问题同构
3. 复杂度 —— 常见 O(n log n)，由合并步骤决定
4. 应用 —— 归并排序、快速排序、求逆序对、最近点对
```

## 应用场景实战

### 场景一：滑动窗口 + 前缀和解决高频考题

```js
// 求数组中连续子数组的最大和（结合前缀和与贪心思想）
function maxSubArray(nums) {
  let preSum = 0, minPre = 0, max = -Infinity;
  for (const n of nums) {
    preSum += n;
    max = Math.max(max, preSum - minPre);
    minPre = Math.min(minPre, preSum);
  }
  return max;
}
console.log(maxSubArray([-2, 1, -3, 4, -1, 2, 1])); // 6
```

### 场景二：二分 + 双指针解决「有序」类问题

```js
// 在有序数组中找两个数，使它们的和等于目标（双指针）
// 再二分判断是否存在（二分查找）
function hasPair(nums, target) {
  const set = new Set(nums);
  for (const n of nums) {
    if (set.has(target - n)) return true;
  }
  return false;
}
console.log(hasPair([1, 2, 3, 4, 5], 9)); // true
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先识别问题信号再选算法，别拿着模板硬套
2. 二分务必统一区间开闭约定，避免边界 off-by-one
3. 动态规划先想清楚状态定义，转移方程自然就出来了
4. 回溯写清楚「选择/撤销」，剪枝放在递归前
5. 能 O(n) 双指针/滑动窗口的，别写 O(n²) 暴力
6. 涉及区间多次查询/修改，第一时间想前缀和/差分

### 踩坑记录

```text
坑 1：二分边界 off-by-one 死循环
结论：二分查找要么死循环，要么漏掉边界元素。
原因：left/right 开闭区间约定混乱，mid 更新写错。
解法：统一用 [left, right] 且 while(left<=right)，或 [left,right) 且 while(left<right)，不要混用。

坑 2：动态规划状态定义含糊导致转移写不出
结论：dp 数组含义不清，转移方程写一个错一个。
原因：没先明确 dp[i] 到底代表什么就动手写循环。
解法：先写一句话定义 dp[i] 的含义，再推导 dp[i] 与 dp[i-1] 的关系。

坑 3：回溯忘记撤销选择
结论：结果集里出现重复或错误的状态。
原因：递归返回后没有 path.pop() 和恢复 used 标记。
解法：每次递归后立即撤销本次选择，保持状态干净。

坑 4：贪心不验证正确性直接上
结论：遇到不满足贪心性质的问题，贪心得出错误答案。
原因：只看到「局部最优」的直觉，没验证全局是否最优。
解法：贪心前先举反例验证，拿不准时用 DP 兜底。

坑 5：滑动窗口 left 更新错导致结果偏大/偏小
结论：窗口收缩条件写错，答案始终不对。
原因：没搞清楚什么时候该收缩左边界、收缩到什么程度。
解法：明确「窗口不满足条件时收缩 left」，并用一个变量维护窗口状态。
```
