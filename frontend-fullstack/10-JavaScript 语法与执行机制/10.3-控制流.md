## 概述

控制流决定代码的执行顺序：条件分支选择路径，循环重复执行，异常处理兜底错误。选择正确的循环与分支结构能显著提升代码可读性。

```text
控制流结构：
分支 —— if、else if、switch、三元运算符
循环 —— for、for...in、for...of、while、do...while
跳转 —— break、continue、return
异常 —— try、catch、finally、throw
```

## if / switch 条件分支

if 是最基础的分支，switch 适合多值匹配，三元运算符适合简单二选一。

```js
// if / else if / else
const score = 85;
if (score >= 90) {
  console.log('优秀');
} else if (score >= 60) {
  console.log('及格');
} else {
  console.log('不及格');
}
```

```js
// switch：多值匹配（严格相等比较）
const color = 'red';
switch (color) {
  case 'red':
    console.log('红色');
    break;            // 不加 break 会穿透到下一个 case
  case 'blue':
    console.log('蓝色');
    break;
  default:
    console.log('其他');
}
```

```js
// 三元运算符：简单二选一
const age = 20;
const canDrink = age >= 18 ? '可以' : '不可以';
```

```text
switch 的陷阱：
1. 用严格相等（===）比较
2. 忘写 break 会「穿透」执行后续 case
3. 多条件用多个 case 堆叠（case 'a': case 'b':）
```

## for 循环

for 是经典的三段式循环，适合需要下标控制的场景。

```js
for (let i = 0; i < 5; i++) {
  console.log(i);   // 0 1 2 3 4
}
```

```text
for 三段式：
初始化（执行一次）→ 条件判断（每次迭代前）→ 迭代更新（每次迭代后）

省略任意段都合法，但要小心死循环。
```

```js
// 遍历数组（可用下标）
const arr = ['a', 'b', 'c'];
for (let i = 0; i < arr.length; i++) {
  console.log(i, arr[i]);
}
```

## for...in 遍历属性

for...in 遍历对象的**可枚举属性键（含原型链）**，注意它遍历的是键名，不是值。

```js
const obj = { a: 1, b: 2, c: 3 };

for (const key in obj) {
  console.log(key, obj[key]);   // a 1、b 2、c 3
}
```

```text
for...in 的坑：
1. 会遍历原型链上的可枚举属性
2. 遍历顺序不保证（数字键先排升序）
3. 不要用于遍历数组（应用 for...of）

安全做法：配合 Object.hasOwn 过滤自有属性。
```

```js
for (const key in obj) {
  if (Object.hasOwn(obj, key)) {
    console.log(key);   // 只遍历自有属性
  }
}
```

## for...of 遍历可迭代对象

for...of 遍历**可迭代对象**（数组、字符串、Map、Set、生成器等）的**值**，是最常用的遍历方式。

```js
// 数组
for (const item of [1, 2, 3]) {
  console.log(item);    // 1 2 3
}

// 字符串（按码点）
for (const ch of 'a😀') {
  console.log(ch);      // a 😀
}

// Map / Set
for (const [k, v] of new Map([['a', 1]])) {
  console.log(k, v);    // a 1
}
```

```text
for...of vs for...in：
for...of —— 遍历「值」（可迭代对象：数组、字符串、Map、Set）
for...in —— 遍历「键」（对象属性名，含原型链）

遍历数组用 for...of，遍历对象属性用 for...in 或 Object.entries。
```

```js
// 需要下标时用 entries
for (const [i, v] of [10, 20, 30].entries()) {
  console.log(i, v);    // 0 10、1 20、2 30
}
```

## while 与 do...while

while 在条件为真时循环，do...while 至少执行一次。

```js
// while：先判断后执行
let i = 0;
while (i < 3) {
  console.log(i);   // 0 1 2
  i++;
}
```

```js
// do...while：先执行后判断（至少一次）
let n = 0;
do {
  console.log(n);   // 0（至少执行一次）
  n++;
} while (n < 0);
```

```text
while vs for：
已知迭代次数 → for
未知次数、依赖条件 → while（如读取流直到结束）
```

## break 与 continue

break 跳出整个循环，continue 跳过本次迭代进入下一次。

```js
// break：跳出循环
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i);      // 0 1 2 3 4
}

// continue：跳过本次
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i);      // 0 1 3 4
}
```

```js
// 带标签的 break/continue（跳出嵌套循环）
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (j === 1) break outer;   // 跳出外层循环
  }
}
```

## try / catch / finally 异常处理

try/catch/finally 用于捕获和处理异常，throw 主动抛出异常。

```js
try {
  // 可能出错的代码
  const data = JSON.parse('{ invalid json }');
} catch (error) {
  // 出错时处理
  console.error('解析失败', error.message);
} finally {
  // 无论成败都执行（清理资源）
  console.log('结束');
}
```

```js
// throw 主动抛出
function divide(a, b) {
  if (b === 0) throw new Error('除数不能为 0');
  return a / b;
}
```

```text
异常处理要点：
1. catch 捕获 try 中抛出的错误
2. finally 无论是否异常都执行（清理、释放）
3. 可选 catch 绑定（ES2019）—— catch 不写参数
4. 异步错误 try/catch 抓不到（需 await 或 Promise.catch）
```

```js
// 异步错误：await 后才能被 try/catch 捕获
async function load() {
  try {
    const data = await fetchData();   // await 抛错可捕获
  } catch (e) {
    console.error(e);
  }
}

// 未 await 的 Promise 错误，try/catch 抓不到
try {
  fetchData();   // 返回的 Promise 未被 await，错误逃逸
} catch (e) {
  // 抓不到！
}
```

## 应用场景实战

### 场景一：遍历对象推荐写法

```js
const obj = { name: 'Alice', age: 30 };

// 推荐：Object.entries + for...of
for (const [key, value] of Object.entries(obj)) {
  console.log(key, value);
}
```

### 场景二：数组查找跳出

```js
function findFirstEven(arr) {
  for (const n of arr) {
    if (n % 2 === 0) return n;   // 找到即返回，等效 break
  }
  return null;
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 遍历数组用 for...of 或数组方法（map/filter/reduce）
2. 遍历对象用 Object.entries + for...of，慎用 for...in
3. switch 每个 case 记得 break，或改用对象映射
4. 异常处理捕获具体错误，finally 做资源清理
5. 简单二选一用三元运算符，复杂分支用 if/switch

### 踩坑记录

```text
坑 1：switch 忘写 break 穿透
结论：多个 case 都被执行。
原因：switch 默认穿透，break 才跳出。
解法：每个 case 加 break，或用对象映射替代。

坑 2：for...in 遍历数组拿到下标字符串
结论：for...in 数组得到 '0','1','2' 字符串。
原因：for...in 遍历键名（字符串），且会含原型属性。
解法：遍历数组用 for...of 或数组方法。

坑 3：for...of 遍历对象报错
结论：for (const x of {}) 抛 TypeError。
原因：普通对象不是可迭代对象。
解法：用 Object.entries/keys/values 或 for...in。

坑 4：try/catch 抓不到异步错误
结论：try 里调用 async 函数，错误没被 catch。
原因：未 await 的 Promise 错误不会同步抛出。
解法：await 后捕获，或用 .catch() 处理。

坑 5：while 条件永不满足导致死循环
结论：程序卡死。
原因：循环变量未更新或条件写错。
解法：确保循环内有状态推进，或用 for 替代。
```
