## 概述

运算符是表达式的组成部分。JavaScript 的运算符体系庞大，其中**比较与类型转换**、**逻辑运算符短路**、**空值合并与可选链**是最容易踩坑的部分。

```text
运算符分类：
算术 —— + - * / % ** ++ --
比较 —— == === != !== < > <= >=
逻辑 —— && || ! ??
位运算 —— & | ^ ~ << >> >>>
赋值 —— = += -= ??= &&= ||= 等
其他 —— typeof instanceof in delete void spread/rest
```

## Arithmetic 算术运算符

算术运算符用于数值计算，注意 `+` 的字符串拼接行为与浮点精度。

```js
10 + 5;      // 15
10 - 5;      // 5
10 * 5;      // 50
10 / 4;      // 2.5
10 % 3;      // 1（取余）
2 ** 10;     // 1024（指数）

// 自增自减
let i = 1;
i++;         // 后置：返回旧值后加一
++i;         // 前置：先加一再返回
```

```text
+ 的双重身份：
1. 数值相加 —— 两侧都是数字时
2. 字符串拼接 —— 任一侧是字符串时

陷阱：'1' + 2 → '12'（字符串拼接），不是 3。
```

```js
'1' + 2;         // '12'（拼接）
1 + '2';         // '12'
1 + 2 + '3';     // '33'（先算 1+2=3，再拼 '3'）
'1' + 2 + 3;     // '123'（先拼 '12'，再拼 '3'）
```

## Comparison 比较与 Strict Equality

比较运算符分严格（=== !==）与宽松（== !=）。严格比较不做类型转换，宽松比较会先转换。

```text
严格相等 ===：
类型不同 → false
类型相同 → 比较值（对象比引用，NaN 例外）

宽松相等 ==：
类型不同 → 先做隐式类型转换再比较（规则复杂，易出错）
```

```js
// 严格相等
1 === 1;           // true
1 === '1';         // false（类型不同）
{} === {};         // false（不同引用）
NaN === NaN;       // false（特殊）

// 宽松相等（有隐式转换）
1 == '1';          // true（字符串转数字）
0 == false;        // true（布尔转数字）
null == undefined; // true（二者宽松相等）
'0' == 0;          // true
```

```text
宽松相等 == 的转换规则（简化）：
1. 一方 null，另一方 undefined → true
2. 一方数字，另一方字符串 → 字符串转数字
3. 一方布尔 → 布尔转数字
4. 一方对象，另一方原始值 → 对象转原始值
```

```js
// 比较运算
3 > 2;             // true
'a' < 'b';         // true（按字典序）
'10' < '9';        // true（字符串按字典序，'1' < '9'）
```

## Logical 逻辑运算符

逻辑运算符 `&&`（与）、`||`（或）、`!`（非）具有**短路**特性，且返回值不是布尔而是操作数本身。

```text
&& 逻辑与：第一个假值就短路，否则返回最后一个
|| 逻辑或：第一个真值就短路，否则返回最后一个
! 逻辑非：取反，返回布尔
```

```js
// 短路与返回操作数
'a' && 'b';        // 'b'（都真，返回最后一个）
'' && 'b';         // ''（第一个假值，短路）
0 && 'b';          // 0

// || 返回第一个真值
'' || 'default';   // 'default'
0 || 1;            // 1
'a' || 'b';        // 'a'（第一个真值短路）
```

```text
常用模式：
1. 默认值 —— value || 'default'（但 0、'' 会被当假值）
2. 条件执行 —— condition && doSomething()
3. 取反 —— !value 转布尔
```

## Nullish Coalescing 空值合并

`??`（ES2020）只在左侧为 null 或 undefined 时返回右侧，与 `||` 的区别是不把 0、''、false 当空值。

```js
// || 的坑：0 和 '' 被当假值
0 || 10;           // 10（可能不是预期）
'' || 'default';   // 'default'

// ?? 只认 null/undefined
0 ?? 10;           // 0（保留 0）
'' ?? 'default';   // ''（保留空串）
null ?? 10;        // 10
undefined ?? 10;   // 10
```

```text
?? vs || 选择：
需要「假值兜底」（0、空串也要兜底）→ 用 ||
只需要「null/undefined 兜底」→ 用 ??

现代默认值处理推荐 ??。
```

## Optional Chaining 可选链

`?.`（ES2020）安全访问可能为 null/undefined 的属性或方法，避免层层判空。

```js
const user = { address: null };

// 传统写法
const city1 = user && user.address && user.address.city;

// 可选链
const city2 = user?.address?.city;   // undefined（不报错）
```

```js
// 方法调用
user?.getName?.();        // 方法存在才调用

// 数组索引
arr?.[0];

// 与 ?? 配合
const city = user?.address?.city ?? '未知';
```

## Bitwise 位运算符

位运算按 32 位整数逐位操作，速度快但可读性差，常用于位标志、权限、算法优化。

```text
位运算符：
&  与      |  或      ^  异或     ~  取反
<< 左移    >> 有符号右移  >>> 无符号右移
```

```js
5 & 3;       // 1（0101 & 0011 = 0001）
5 | 3;       // 7（0101 | 0011 = 0111）
5 ^ 3;       // 6（0101 ^ 0011 = 0110）
~5;          // -6（取反）

1 << 3;      // 8（左移 3 位 = 乘以 8）
8 >> 2;      // 2（右移 2 位 = 除以 4）
```

```text
位标志模式：
用单个整数的每一位表示一个开关，常用于权限系统。
```

```js
const READ = 1;     // 001
const WRITE = 2;    // 010
const EXEC = 4;     // 100

let perm = READ | WRITE;          // 011 = 3
perm & READ;                       // 1（有读权限）
perm & EXEC;                       // 0（无执行权限）
```

## Assignment 赋值与 Spread / Rest

赋值运算符包括基础 `=` 与复合赋值，ES2021 新增了逻辑赋值运算符。

```js
let a = 1;
a += 2;         // 3（等价 a = a + 2）
a *= 3;         // 9

// 逻辑赋值（ES2021）
let b = null;
b ??= 10;       // b = 10（null 时赋值）
b ||= 20;       // b 不变（已有真值）
b &&= 30;       // b = 30（有真值时赋右侧）
```

```text
Spread 展开（...）：
把可迭代对象展开为元素列表，用于数组/对象合并、函数调用。

Rest 剩余（...）：
把剩余元素收集为数组，用于函数参数、解构。
```

```js
// Spread
const arr = [1, 2, 3];
const arr2 = [...arr, 4];       // [1,2,3,4]
const obj2 = { ...{ a: 1 }, b: 2 };  // {a:1, b:2}
Math.max(...arr);               // 3（展开传参）

// Rest
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
sum(1, 2, 3);                    // 6

const [first, ...rest] = [1, 2, 3];   // first=1, rest=[2,3]
```

## typeof / instanceof / in / delete / void

这几个一元/二元运算符各有特殊用途。

```text
typeof x      —— 返回类型字符串（null 是 'object' 坑）
x instanceof C —— 判断原型链上是否有 C.prototype
key in obj    —— 判断属性（含原型链）是否存在
delete obj.k  —— 删除对象属性
void expr     —— 求值后返回 undefined
```

```js
typeof 'x';           // 'string'
typeof null;          // 'object'（历史 bug）
typeof function(){};  // 'function'

[] instanceof Array;  // true
{} instanceof Object; // true

'name' in { name: 1 };// true
'toString' in {};     // true（原型链上的属性）

const obj = { a: 1 };
delete obj.a;         // true
obj.a;                // undefined

void 0;               // undefined（早期取 undefined 的写法）
```

```text
typeof 的局限：
1. null → 'object'（历史 bug）
2. 无法区分数组/对象/日期（都返回 'object'）
3. 精确判断用 Object.prototype.toString.call(x)
```

## 应用场景实战

### 场景一：安全默认值

```js
// 配置项：0、空串是有意义的值
function init(options) {
  const retries = options.retries ?? 3;   // 0 也会保留
  const label = options.label ?? '默认';
  return { retries, label };
}
```

### 场景二：深层数据安全读取

```js
const data = { user: { profile: null } };
const nickname = data?.user?.profile?.nickname ?? '匿名';
```

## 最佳实践与踩坑记录

### 最佳实践

1. 比较一律用 === 和 !==，避免 == 的隐式转换
2. 默认值优先 ??，明确需要假值兜底才用 ||
3. 深层访问用 ?. 可选链，避免层层判空
4. 循环拼接字符串避免 + 号，用数组 join 或模板字符串
5. 需要类型精确判断用 Object.prototype.toString.call

### 踩坑记录

```text
坑 1：== 隐式转换
结论：'0' == 0、false == 0 都是 true，逻辑混乱。
原因：== 会做类型转换。
解法：统一用 ===。

坑 2：+ 号字符串拼接
结论：'1' + 2 得到 '12' 不是 3。
原因：任一侧是字符串就拼接。
解法：数值运算先 Number() 转换，或留意类型。

坑 3：|| 默认值吞掉 0
结论：count || 10 当 count=0 时返回 10。
原因：0 是假值。
解法：需要保留 0/'' 用 ??。

坑 4：typeof 判断数组是 object
结论：typeof [] === 'object'，无法区分数组。
原因：typeof 对引用类型都返回 object。
解法：Array.isArray([]) 判断数组。

坑 5：位运算误用于大数
结论：位运算结果超出 32 位范围出错。
原因：位运算按 32 位整数处理。
解法：大数不要用位运算，用普通算术。
```
