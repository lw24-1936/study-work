## 概述

函数是 JavaScript 的一等公民：可以赋值给变量、作为参数传递、作为返回值。理解函数声明方式与箭头函数的差异，是写出正确代码的关键。

```text
函数的三种定义方式：
1. 函数声明 —— function name() {}（可提升）
2. 函数表达式 —— const fn = function() {}（不提升）
3. 箭头函数 —— const fn = () => {}（无自己的 this）

函数的一等公民特性：
可赋值、可传参、可返回、可作为对象属性（方法）。
```

## Function Declaration 函数声明

函数声明使用 function 关键字，会被整体提升，可在声明前调用。

```js
// 函数声明（可提前调用）
sayHello();               // 'hello'（提升生效）
function sayHello() {
  console.log('hello');
}
```

```text
函数声明的特性：
1. 整体提升 —— 声明前可调用
2. 有 name 属性
3. 有自己的 this 和 arguments
```

## Function Expression 函数表达式

函数表达式把函数赋值给变量，不整体提升，只有变量声明被提升。

```js
// 函数表达式（不可提前调用）
// fn();                  // TypeError（fn 是 undefined）
const fn = function() {
  console.log('hi');
};
fn();                      // 'hi'
```

```js
// 具名函数表达式（便于递归与调试）
const factorial = function fact(n) {
  return n <= 1 ? 1 : n * fact(n - 1);   // 用内部名 fact 递归
};
```

```text
函数表达式 vs 函数声明：
声明 —— 整体提升，可提前调用，适合定义顶层函数
表达式 —— 不提升，适合赋值、传参、按需创建
```

## Arrow Function 箭头函数

箭头函数是 ES6 的简洁语法，最大的特点是**没有自己的 this**（继承外层作用域的 this）。

```js
// 基本语法
const add = (a, b) => a + b;        // 单表达式隐式返回
const square = x => x * x;          // 单参数可省略括号
const noop = () => {};              // 无参数

// 多语句需要花括号 + return
const calc = (a, b) => {
  const sum = a + b;
  return sum * 2;
};
```

```text
箭头函数与普通函数的核心区别：
1. 没有自己的 this —— this 继承定义处的外层作用域（词法绑定）
2. 没有 arguments —— 需用 rest 参数
3. 不能作构造函数 —— 不能用 new
4. 没有 prototype 属性
5. 不能用作 Generator
```

```js
// 箭头函数解决 this 丢失问题
const obj = {
  name: 'Alice',
  greet() {
    // 普通函数里 this 指向调用者，setTimeout 里会丢失
    setTimeout(() => {
      console.log(this.name);   // 'Alice'（箭头函数继承外层 this）
    }, 100);
  },
};
obj.greet();
```

```text
箭头函数的使用原则：
1. 需要继承 this（回调、事件处理）→ 箭头函数
2. 需要动态 this（对象方法、构造函数）→ 普通函数
3. 不要用箭头函数定义对象方法（this 会指向外层而非对象）
```

## Default Parameter 默认参数

默认参数在参数未传或为 undefined 时使用默认值。

```js
function greet(name = '匿名') {
  return `Hello, ${name}`;
}

greet();          // 'Hello, 匿名'
greet('Alice');   // 'Hello, Alice'
greet(undefined); // 'Hello, 匿名'（undefined 触发默认值）
greet(null);      // 'Hello, null'（null 不触发默认值）
```

```js
// 默认值可以是表达式，且能用前面的参数
function add(a, b = a * 2) {
  return a + b;
}
add(3);           // 9（b = 6）
```

```text
默认参数的坑：
1. 只有 undefined 触发默认值，null 不会
2. 默认参数在调用时求值，每次调用都可能不同
3. 默认参数与解构可组合
```

## Rest Parameter 与 Arguments

Rest 参数（...）把剩余参数收集成数组，是 arguments 类数组的现代替代。

```js
// rest 参数：真正的数组
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4);   // 10
```

```js
// arguments：类数组对象（普通函数内可用）
function oldStyle() {
  console.log(arguments);        // 类数组 [1,2,3]
  console.log(Array.from(arguments));  // 转数组
}
oldStyle(1, 2, 3);
```

```text
Rest vs Arguments：
Rest —— 真正的数组、箭头函数可用、只收集剩余参数
arguments —— 类数组、箭头函数不可用、包含所有参数

现代代码优先 Rest 参数。
```

## Return 返回值

return 结束函数执行并返回结果；无 return 或裸 return 返回 undefined。

```js
function add(a, b) {
  return a + b;      // 返回并结束
  // 之后的代码不执行
}

function noReturn() {}
noReturn();           // undefined
```

```text
return 注意：
1. return 后换行会插入分号，导致返回 undefined（ASI 坑）
2. 箭头函数单表达式隐式返回，花括号需显式 return
```

```js
// ASI 坑：return 后换行
function bad() {
  return          // 等价 return;（返回 undefined）
    1 + 2;
}
bad();            // undefined

// 正例
function good() {
  return 1 + 2;
}
good();           // 3
```

## Higher Order Function 与 Callback

高阶函数接收函数作参数或返回函数。回调函数是作为参数传入、稍后被调用的函数。

```js
// 高阶函数：接收函数作参数
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);        // map 是高阶函数
const evens = nums.filter(n => n % 2 === 0); // filter 是高阶函数
const sum = nums.reduce((a, b) => a + b, 0); // reduce 是高阶函数
```

```js
// 回调函数：传入后由对方在合适时机调用
setTimeout(() => console.log('延迟执行'), 1000);

button.addEventListener('click', () => {
  console.log('点击时回调');
});
```

```js
// 返回函数的函数（柯里化、工厂）
function multiply(factor) {
  return (n) => n * factor;   // 返回函数（闭包捕获 factor）
}
const double = multiply(2);
double(5);          // 10
```

```text
高阶函数的典型场景：
1. 数组方法 —— map/filter/reduce/sort 等
2. 事件回调 —— addEventListener
3. 异步回调 —— setTimeout、Promise.then
4. 函数工厂 —— 返回定制函数（柯里化）
```

## 应用场景实战

### 场景一：数组管道式处理

```js
const users = [
  { name: 'Alice', age: 25 },
  { name: 'Bob', age: 17 },
  { name: 'Cara', age: 30 },
];

const adultNames = users
  .filter(u => u.age >= 18)      // 过滤
  .map(u => u.name)              // 映射
  .sort();                       // 排序
```

### 场景二：柯里化复用

```js
const addTax = rate => price => price * (1 + rate);
const addVat = addTax(0.13);     // 固定税率 13%
addVat(100);                     // 113
addVat(200);                     // 226
```

## 最佳实践与踩坑记录

### 最佳实践

1. 需要继承 this 的回调用箭头函数
2. 对象方法、构造函数用普通函数（或方法简写）
3. 剩余参数用 rest，不用 arguments
4. 参数默认值给足，减少函数内判空
5. 单一职责：函数尽量短小，只做一件事

### 踩坑记录

```text
坑 1：箭头函数当对象方法
结论：this 指向错误（指向外层而非对象）。
原因：箭头函数没有自己的 this。
解法：对象方法用方法简写或普通函数。

坑 2：return 后换行返回 undefined
结论：return 后换行，函数返回 undefined。
原因：ASI 自动插入分号。
解法：返回值与 return 同行，或加括号。

坑 3：箭头函数不能 new
结论：new ArrowFn() 抛 TypeError。
原因：箭头函数没有 [[Construct]]。
解法：构造函数用 function 或 class。

坑 4：arguments 在箭头函数中不可用
结论：箭头函数内 arguments 是外层的或报错。
原因：箭头函数没有自己的 arguments。
解法：用 rest 参数（...args）。

坑 5：默认参数用 null 不触发
结论：传 null 走了 null，没走默认值。
原因：只有 undefined 触发默认参数。
解法：明确语义，需要兜底 null 用 ?? 处理。
```
