## 概述

Fetch API 是现代浏览器发起网络请求的标准方式，基于 Promise，取代了老旧的 XMLHttpRequest。它提供统一的请求/响应模型，支持多种数据格式。

```text
Fetch 的特点：
1. 基于 Promise —— 链式调用，配合 async/await
2. 统一模型 —— Request / Response 对象
3. 多种格式 —— JSON、FormData、Blob、ArrayBuffer、Stream
4. 不自动处理 —— 不自动 reject（需手动判断 ok）、无超时、无拦截器
```

## fetch 基础用法

```js
// GET 请求
fetch('/api/users')
  .then(res => res.json())     // 解析 JSON
  .then(data => console.log(data))
  .catch(err => console.error('网络错误', err));
```

```js
// async/await 写法
async function getUsers() {
  const res = await fetch('/api/users');
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  const data = await res.json();
  return data;
}
```

```js
// POST 请求
fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Alice' }),
});
```

```text
fetch 的重要特性：
1. fetch 返回的 Promise 只在「网络错误」时 reject
2. HTTP 错误状态（404、500）不会 reject，需手动判断 res.ok
3. 默认不发送 Cookie，需 credentials 配置
4. 无超时机制，需配合 AbortController
```

## Request 与 Response

Request 和 Response 是 fetch 的核心对象，封装请求与响应。

```js
// 构造 Request
const request = new Request('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Alice' }),
});

fetch(request).then(res => res.json());
```

```js
// Response 对象
const res = await fetch('/api/users');
res.status;              // 状态码（200、404...）
res.statusText;          // 状态文本
res.ok;                  // 状态码 200-299 为 true
res.headers;             // 响应头
res.url;                 // 最终 URL（重定向后）
```

```js
// 判断成功
if (res.ok) {
  const data = await res.json();
} else {
  console.error(`请求失败: ${res.status}`);
}
```

## Headers 请求头

Headers 对象管理请求/响应头。

```js
const headers = new Headers({
  'Content-Type': 'application/json',
  'Authorization': 'Bearer token123',
});

headers.append('X-Custom', 'value');
headers.get('Content-Type');     // 'application/json'
headers.has('Authorization');    // true
headers.set('X-Custom', 'new');
headers.delete('X-Custom');
```

```js
// 请求中设置头
fetch('/api/data', {
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`,
  },
});
```

## Body 请求体（JSON / FormData / Blob）

fetch 支持多种请求体格式，通过 body 和 Content-Type 指定。

```js
// JSON
fetch('/api', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Alice' }),
});

// FormData（表单/文件上传，自动设 multipart 边界）
const formData = new FormData();
formData.append('name', 'Alice');
formData.append('file', fileInput.files[0]);
fetch('/api/upload', { method: 'POST', body: formData });

// Blob（二进制）
const blob = new Blob(['data'], { type: 'text/plain' });
fetch('/api/upload', { method: 'POST', body: blob });
```

```js
// 响应体解析（多种格式）
const text = await res.text();            // 文本
const json = await res.json();            // JSON
const blob = await res.blob();            // Blob
const formData = await res.formData();    // FormData
const arrayBuffer = await res.arrayBuffer(); // ArrayBuffer
```

```text
响应体解析方法（一次只能用一个）：
text() —— 文本
json() —— JSON 对象
blob() —— Blob
formData() —— 表单数据
arrayBuffer() —— 二进制
```

## ArrayBuffer 与 Stream 流式处理

fetch 支持读取二进制数据和流式响应。

```js
// 读取 ArrayBuffer（处理二进制）
const buffer = await res.arrayBuffer();
const bytes = new Uint8Array(buffer);
```

```js
// 流式读取（大文件、进度显示）
const res = await fetch('/large-file');
const reader = res.body.getReader();
const contentLength = +res.headers.get('Content-Length');

let received = 0;
const chunks = [];
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  chunks.push(value);
  received += value.length;
  console.log(`进度: ${(received / contentLength * 100).toFixed(1)}%`);
}
```

```text
流式处理的场景：
1. 大文件下载 —— 边下载边处理，不用等全部完成
2. 进度显示 —— 逐步接收数据
3. 流式响应 —— SSE 类似的流式数据（如 AI 生成）
```

## 应用场景实战

### 场景一：带错误处理的请求封装

```js
async function request(url, options = {}) {
  const res = await fetch(url, options);
  if (!res.ok) {
    throw new Error(`请求失败: ${res.status} ${res.statusText}`);
  }
  return res.json();
}
```

### 场景二：上传文件（带进度）

```js
async function uploadWithProgress(file) {
  const formData = new FormData();
  formData.append('file', file);
  return fetch('/api/upload', { method: 'POST', body: formData });
}
```

## 最佳实践与踩坑记录

### 最佳实践

1. 始终检查 res.ok，处理 HTTP 错误
2. 超时用 AbortController，fetch 本身无超时
3. 需要 Cookie 时设 credentials: 'include'
4. 上传文件用 FormData，别手动拼 multipart
5. 大文件用流式处理，避免一次性读入内存

### 踩坑记录

```text
坑 1：404/500 不会 reject
结论：fetch 404 也走 then，误以为成功。
原因：fetch 只在网络错误时 reject。
解法：检查 res.ok，或封装统一处理。

坑 2：忘设 Content-Type
结论：POST JSON 后端解析失败。
原因：默认 Content-Type 不是 application/json。
解法：JSON 请求显式设 Content-Type。

坑 3：默认不携带 Cookie
结论：跨域/同源请求 cookie 没带上。
原因：fetch 默认 credentials 是 same-origin。
解法：跨域带 cookie 设 credentials: 'include'。

坑 4：响应体只能读一次
结论：res.json() 后再 res.text() 报错。
原因：响应体是流，只能消费一次。
解法：读一次后缓存，或克隆 res.clone()。

坑 5：fetch 无超时
结论：请求无限挂起。
原因：fetch 原生无 timeout。
解法：用 AbortController + setTimeout 实现超时。
```
