## 概述

媒体 API 是 wx 命名空间下与图片、录音、视频、音频相关的 API 集合，覆盖「采集 → 上传 → 展示 → 播放」全链路：图片选择（wx.chooseMedia / wx.chooseImage）、上传下载（wx.uploadFile / wx.downloadFile）、预览与保存（wx.previewImage / wx.saveImageToPhotosAlbum）、录音（wx.getRecorderManager）、视频选择与播放（wx.chooseVideo / wx.createVideoContext）、音频播放（wx.createInnerAudioContext）等。媒体能力是电商、社区、工具类小程序的核心基础设施，头像上传、商品图发布、语音留言、视频播放都依赖这一组 API。本章重点讲清「临时文件与持久文件的区别」「uploadFile 的完整参数」「音频视频上下文的使用时机」三个关键概念。

```text
媒体 API 全景：
1. 图片选择 —— wx.chooseMedia（新） / wx.chooseImage（旧），返回临时文件路径
2. 传输 —— wx.uploadFile 上传到后台 / wx.downloadFile 下载文件
3. 展示 —— wx.previewImage 图片预览 / wx.getImageInfo 读取图片信息
4. 保存 —— wx.saveImageToPhotosAlbum 保存到系统相册（需授权）
5. 录音 —— wx.getRecorderManager 录音管理器，mp3/aac/wav 格式
6. 播放 —— wx.createInnerAudioContext 音频 / wx.createVideoContext 视频控制
```

## 图片选择与临时文件

wx.chooseImage 是历史最久的选图 API，wx.chooseMedia 是基础库 2.10.0 起推荐的新 API，两者都支持从相册选择或调起相机拍照，success 回调返回的是**临时文件路径**（tempFilePath）。临时文件存放在微信的临时目录，小程序本次启动期间有效，退出后会被清理，因此需要持久化的图片必须立即 wx.uploadFile 上传到后台，或通过 wx.saveFile 转存为本地缓存文件。chooseMedia 相比 chooseImage 的增强：支持同时选择图片和视频（mediaType 数组）、返回 width/height/duration 等元信息、视频支持封面图（thumbTempFilePath）。

```js
// pages/media/choose.js
Page({
  data: {
    images: []
  },

  // 新 API：选择图片（基础库 2.10.0+，推荐）
  chooseImages() {
    wx.chooseMedia({
      count: 9,                        // 最多 9 张
      mediaType: ['image'],            // image / video / ['image','video']
      sourceType: ['album', 'camera'], // 相册 + 相机
      sizeType: ['original', 'compressed'], // 原图 / 压缩图
      camera: 'back',
      success: (res) => {
        // res.type: image / video
        // res.tempFiles: [{ tempFilePath, size, width, height, duration, thumbTempFilePath }]
        const paths = res.tempFiles.map((f) => f.tempFilePath)
        this.setData({ images: this.data.images.concat(paths) })
        console.log('临时文件：', paths)
      },
      fail: (err) => {
        // 用户取消时 errMsg 含 cancel
        if (!err.errMsg.includes('cancel')) {
          console.error('选择图片失败：', err.errMsg)
        }
      }
    })
  },

  // 旧 API：chooseImage（老项目兼容）
  chooseImagesLegacy() {
    wx.chooseImage({
      count: 9,
      sizeType: ['compressed'],
      sourceType: ['album', 'camera'],
      success: (res) => {
        // res.tempFilePaths: 临时路径数组
        // res.tempFiles: [{ path, size }]
        console.log(res.tempFilePaths)
      }
    })
  }
})
```

```xml
<!-- pages/media/choose.wxml（节选） -->
<view class="grid">
  <image
    wx:for="{{images}}"
    wx:key="*this"
    src="{{item}}"
    mode="aspectFill"
    class="thumb"
    bindtap="preview"
    data-url="{{item}}"
  />
</view>
<button bindtap="chooseImages">选择图片</button>
```

```text
图片选择与临时文件要点：
1. chooseMedia 是新 API（2.10.0+），chooseImage 老 API 仍可用但建议迁移
2. 返回的是临时文件路径，本次启动有效，退出即失效，需立即上传或 saveFile
3. count 最多 9 张；sourceType 可限定相册/相机
4. sizeType 选 compressed 可显著减小上传体积，头像/缩略图场景必选
5. 用户取消走 fail 回调，用 errMsg.includes('cancel') 判断
6. 视频的封面图在 thumbTempFilePath 字段
```

## 图片上传与下载

wx.uploadFile 把本地文件以 multipart/form-data 方式上传到后台，参数：url（上传接口地址）、filePath（本地临时文件路径）、name（后台接收的文件字段名，对应 SpringBoot 的 MultipartFile 参数名）、formData（额外表单字段）、timeout（超时时间，默认 60 秒）。返回值中的 data 是后台返回的**字符串**，需要 JSON.parse 解析。uploadFile 返回 UploadTask 对象，可以通过 task.onProgressUpdate 监听上传进度实现进度条。上传接口域名必须在后台配置为「uploadFile 合法域名」（不是 request 合法域名），并且必须是 HTTPS。

```js
// pages/media/upload.js
Page({
  data: {
    progress: 0
  },

  uploadAvatar(tempFilePath) {
    const task = wx.uploadFile({
      url: 'https://api.example.com/user/avatar',
      filePath: tempFilePath,          // 本地临时文件路径
      name: 'file',                    // 后台字段名（SpringBoot: @RequestParam("file") MultipartFile）
      formData: {
        userId: '10001',
        type: 'avatar'
      },
      timeout: 30000,                  // 30 秒超时
      success: (res) => {
        // res.statusCode: HTTP 状态码
        // res.data: 后台返回的字符串，必须 JSON.parse
        if (res.statusCode === 200) {
          const data = JSON.parse(res.data)
          if (data.code === 0) {
            wx.showToast({ title: '上传成功', icon: 'success' })
          } else {
            wx.showToast({ title: data.msg, icon: 'none' })
          }
        }
      },
      fail: (err) => {
        console.error('上传失败：', err.errMsg)
        wx.showToast({ title: '上传失败，请重试', icon: 'none' })
      }
    })

    // 上传进度监听
    task.onProgressUpdate((res) => {
      this.setData({ progress: res.progress })
      console.log('上传进度：', res.progress + '%')
    })
  }
})
```

wx.downloadFile 从网络下载文件到本地，success 回调返回 tempFilePath（临时路径）与 filePath（基础库 2.0.0+，下载到本地缓存目录的持久路径）。下载同样有合法域名限制（downloadFile 合法域名），返回 DownloadTask 同样支持 onProgressUpdate 与 abort。下载后的临时文件如需长期保存，用 wx.saveFile 转存（注意 saveFile 有 10MB 大小限制与总容量限制），或者直接打开（PDF 用 wx.openDocument，图片用 image 组件）。

```js
// pages/media/download.js
Page({
  downloadReport() {
    const task = wx.downloadFile({
      url: 'https://cdn.example.com/reports/202608.pdf',
      timeout: 60000,
      success: (res) => {
        if (res.statusCode === 200) {
          // 打开 PDF 文档预览
          wx.openDocument({
            filePath: res.tempFilePath,
            fileType: 'pdf',
            showMenu: true,   // 允许右上角菜单转发/保存
            success: () => console.log('打开成功'),
            fail: (err) => console.error('打开失败：', err.errMsg)
          })
        } else {
          wx.showToast({ title: '下载失败（' + res.statusCode + '）', icon: 'none' })
        }
      },
      fail: (err) => console.error('下载失败：', err.errMsg)
    })

    task.onProgressUpdate((res) => {
      console.log('下载进度：', res.progress + '%')
    })
  }
})
```

```text
图片上传与下载要点：
1. uploadFile 的 name 是后台字段名，必须与后台 MultipartFile 参数名一致
2. res.data 是字符串，先 JSON.parse 再取值；判断业务码前先看 statusCode
3. 上传/下载域名分别要求 uploadFile / downloadFile 合法域名，与 request 域名分开配置
4. timeout 默认 60 秒，大文件按需调大并配进度条提示
5. UploadTask / DownloadTask 支持 onProgressUpdate 与 abort
6. 下载的文件是临时路径，持久化用 wx.saveFile（有 10MB 单文件限制），文档类直接用 openDocument
```

## 图片预览与保存

wx.previewImage 打开全屏图片预览器，支持左右滑动切换、双指缩放、长按识别二维码/保存图片。参数 urls 是全部图片地址数组，current 是当前显示的那张（必须是 urls 中的一项）。注意预览的网络图片需要配置 downloadFile 合法域名。wx.getImageInfo 获取图片的宽高、类型、方向等信息，常用于「上传前压缩」「图片比例裁剪」「判断是否为动图」。

```js
// pages/media/preview.js
Page({
  data: {
    imageUrls: [
      'https://cdn.example.com/goods/1.jpg',
      'https://cdn.example.com/goods/2.jpg',
      'https://cdn.example.com/goods/3.jpg'
    ]
  },

  // 点击缩略图进入全屏预览
  preview(e) {
    const current = e.currentTarget.dataset.url
    wx.previewImage({
      current,                          // 当前显示图片，必须属于 urls
      urls: this.data.imageUrls,        // 全部图片
      success: () => console.log('预览成功')
    })
  },

  // 读取图片信息
  getImageInfo() {
    wx.getImageInfo({
      src: 'https://cdn.example.com/goods/1.jpg',
      success: (res) => {
        // res: { width, height, path, orientation, type }
        console.log('尺寸：', res.width + 'x' + res.height, '类型：', res.type)
        const isGif = res.type === 'gif'
        if (isGif) {
          wx.showToast({ title: '动图不支持裁剪', icon: 'none' })
        }
      },
      fail: (err) => console.error('读取图片信息失败：', err.errMsg)
    })
  }
})
```

wx.saveImageToPhotosAlbum 把图片保存到系统相册，**filePath 必须是本地路径**（临时路径或本地缓存路径），网络图片要先 downloadFile 再保存。该接口需要 scope.writePhotosAlbum 授权，用户拒绝后要通过 wx.openSetting 引导开启。保存成功或失败都要给用户明确反馈，失败时区分「拒绝授权」与「其他错误」。

```js
// pages/media/save.js
Page({
  // 保存海报到相册（先下载网络图，再保存）
  savePoster(url) {
    wx.showLoading({ title: '保存中', mask: true })

    wx.downloadFile({
      url,
      success: (res) => {
        if (res.statusCode !== 200) {
          wx.hideLoading()
          wx.showToast({ title: '下载失败', icon: 'none' })
          return
        }
        wx.saveImageToPhotosAlbum({
          filePath: res.tempFilePath,   // 必须是本地路径
          success: () => {
            wx.hideLoading()
            wx.showToast({ title: '已保存到相册', icon: 'success' })
          },
          fail: (err) => {
            wx.hideLoading()
            if (err.errMsg.includes('auth deny') || err.errMsg.includes('authorize')) {
              this.guideOpenSetting()   // 授权被拒，引导去设置
            } else {
              wx.showToast({ title: '保存失败', icon: 'none' })
            }
          }
        })
      },
      fail: () => {
        wx.hideLoading()
        wx.showToast({ title: '下载失败', icon: 'none' })
      }
    })
  },

  guideOpenSetting() {
    wx.showModal({
      title: '需要相册权限',
      content: '请在设置中开启「添加到相册」权限，以便保存图片',
      confirmText: '去设置',
      success: (res) => {
        if (res.confirm) {
          wx.openSetting({
            success: (settingRes) => {
              if (settingRes.authSetting['scope.writePhotosAlbum']) {
                wx.showToast({ title: '权限已开启，请重试', icon: 'none' })
              }
            }
          })
        }
      }
    })
  }
})
```

```text
图片预览与保存要点：
1. previewImage 的 current 必须是 urls 中的一项，否则预览定位错误
2. previewImage 的网络图片需要 downloadFile 合法域名
3. getImageInfo 返回宽高/类型，上传前可用它判断 gif、做压缩决策
4. saveImageToPhotosAlbum 只接受本地路径，网络图必须先 downloadFile
5. 保存相册需要 scope.writePhotosAlbum 授权，拒绝后 openSetting 引导
6. 保存失败时区分授权拒绝与其他异常，分别给出提示
```

## 录音与视频选择

录音使用 wx.getRecorderManager() 获取全局唯一的录音管理器，通过 onStart / onStop / onError 监听状态，start 传入录音参数（duration 最长时长、sampleRate 采样率、numberOfChannels 声道数、encodeBitRate 码率、format 格式），stop 结束后 onStop 回调返回 tempFilePath、duration、fileSize。录音需要 scope.record 授权。格式兼容性：mp3 / aac 在 iOS 与安卓都稳定，wav / PCM 在 iOS 上支持有限，跨端产品优先 mp3 或 aac。

```js
// pages/media/record.js
Page({
  data: {
    recording: false,
    duration: 0
  },

  onLoad() {
    this.recorderManager = wx.getRecorderManager()

    this.recorderManager.onStart(() => {
      this.setData({ recording: true })
    })

    this.recorderManager.onStop((res) => {
      // res: { tempFilePath, duration(ms), fileSize }
      this.setData({ recording: false })
      console.log('录音文件：', res.tempFilePath, '时长：', res.duration + 'ms')
      // 录音完成立即上传
      this.uploadAudio(res.tempFilePath)
    })

    this.recorderManager.onError((err) => {
      this.setData({ recording: false })
      console.error('录音失败：', err.errMsg)
      wx.showToast({ title: '录音失败', icon: 'none' })
    })
  },

  // 开始/停止录音
  toggleRecord() {
    if (this.data.recording) {
      this.recorderManager.stop()
      return
    }
    // 检查录音授权
    wx.getSetting({
      success: (res) => {
        if (res.authSetting['scope.record']) {
          this.startRecord()
        } else {
          wx.authorize({
            scope: 'scope.record',
            success: () => this.startRecord(),
            fail: () => {
              wx.showModal({
                title: '需要麦克风权限',
                content: '录音功能需要麦克风权限，请在设置中开启',
                confirmText: '去设置',
                success: (r) => { if (r.confirm) wx.openSetting() }
              })
            }
          })
        }
      }
    })
  },

  startRecord() {
    this.recorderManager.start({
      duration: 60000,            // 最长 60 秒（毫秒）
      sampleRate: 16000,          // 采样率，语音留言 16k 足够
      numberOfChannels: 1,        // 单声道，文件更小
      encodeBitRate: 48000,       // 码率
      format: 'mp3'               // mp3 / aac / wav / PCM
    })
  },

  uploadAudio(tempFilePath) {
    wx.uploadFile({
      url: 'https://api.example.com/voice/upload',
      filePath: tempFilePath,
      name: 'file',
      formData: { scene: 'comment' },
      success: (res) => {
        const data = JSON.parse(res.data)
        if (data.code === 0) {
          wx.showToast({ title: '语音上传成功', icon: 'success' })
        }
      }
    })
  }
})
```

wx.chooseVideo 从相册选择视频或调起相机拍摄，参数 sourceType（album / camera）、maxDuration（最长拍摄时长，秒）、camera（back / front）、compressed（是否压缩）。success 回调返回 tempFilePath、duration、size、height、width。新项目推荐用 wx.chooseMedia({ mediaType: ['video'] }) 替代，两者返回结构略有差异（chooseMedia 的 tempFiles 数组带 thumbTempFilePath 封面）。

```js
// pages/media/video.js
Page({
  data: {
    videoSrc: ''
  },

  chooseVideo() {
    wx.chooseVideo({
      sourceType: ['album', 'camera'],
      maxDuration: 60,        // 最长拍摄 60 秒
      camera: 'back',
      compressed: true,       // 压缩体积
      success: (res) => {
        // res: { tempFilePath, duration(秒), size, height, width }
        this.setData({ videoSrc: res.tempFilePath })
        console.log('视频时长：', res.duration + 's', '大小：', (res.size / 1024 / 1024).toFixed(2) + 'MB')
      }
    })
  }
})
```

```xml
<!-- pages/media/video.wxml（节选） -->
<video
  wx:if="{{videoSrc}}"
  src="{{videoSrc}}"
  controls
  enable-play-gesture
  style="width: 100%; height: 300px;"
/>
<button bindtap="chooseVideo">选择视频</button>
```

```text
录音与视频选择要点：
1. RecorderManager 是全局单例，先注册 onStart/onStop/onError 再 start
2. 录音需 scope.record 授权；录音时长受 duration 限制（毫秒）
3. 格式优先 mp3/aac，wav/PCM 在 iOS 上兼容性差
4. chooseVideo 用 maxDuration 限制时长，compressed 压缩体积
5. 新项目用 chooseMedia({ mediaType: ['video'] }) 替代 chooseVideo
6. 录音/视频文件都是临时路径，按需立即上传
```

## 音频播放与视频控制

wx.createInnerAudioContext 创建音频播放实例，src 支持网络地址与本地路径，常用方法 play / pause / stop / seek / destroy，常用事件 onPlay / onPause / onEnded / onError。两个高频坑：一是 iOS 上 InnerAudioContext 默认受静音键控制（obeyMuteSwitch 默认 true），拨到静音就没声音，语音类应用要设置 obeyMuteSwitch: false；二是 iOS 上 autoplay 自动播放不生效，必须在用户点击等手势回调里调用 play。播放结束（onEnded）后要手动 destroy 释放实例，避免内存泄漏与多实例声音重叠。

```js
// pages/media/audio.js
Page({
  onLoad() {
    this.audio = wx.createInnerAudioContext()
    this.audio.src = 'https://cdn.example.com/voice/10086.mp3'
    this.audio.obeyMuteSwitch = false   // iOS 上不受静音键控制（语音类必设）

    this.audio.onPlay(() => console.log('开始播放'))
    this.audio.onEnded(() => {
      console.log('播放结束')
      this.audio.destroy()              // 播放完释放实例
      this.audio = null
    })
    this.audio.onError((err) => {
      console.error('播放错误：', err.errMsg)
      wx.showToast({ title: '播放失败', icon: 'none' })
    })
  },

  // 必须在用户手势中调用 play（iOS autoplay 限制）
  play() {
    if (!this.audio) {
      this.audio = wx.createInnerAudioContext()
      this.audio.src = 'https://cdn.example.com/voice/10086.mp3'
      this.audio.obeyMuteSwitch = false
    }
    this.audio.play()
  },

  pause() {
    if (this.audio) this.audio.pause()
  },

  onUnload() {
    // 页面销毁必须释放音频实例
    if (this.audio) {
      this.audio.destroy()
      this.audio = null
    }
  }
})
```

wx.createVideoContext 与 video 组件配合使用：先在 wxml 中放置带 id 的 video 组件，再通过 wx.createVideoContext('videoId', this) 获取控制实例，可以调用 play / pause / stop / seek / requestFullScreen / exitFullScreen / playbackRate / sendDanmu 等方法。关键时机：必须在 video 组件渲染完成后调用（onReady 生命周期之后），否则拿不到实例报错；弹幕功能需要组件开启 enableDanmu 属性。视频进度与状态通过组件的 bindtimeupdate / bindended / binderror 事件监听。

```xml
<!-- pages/media/player.wxml -->
<video
  id="mainVideo"
  src="{{videoUrl}}"
  enable-danmu
  danmu-btn
  controls
  bindtimeupdate="onTimeUpdate"
  bindended="onVideoEnded"
  style="width: 100%; height: 240px;"
/>
<button bindtap="play">播放</button>
<button bindtap="pause">暂停</button>
<button bindtap="fullscreen">全屏</button>
```

```js
// pages/media/player.js
Page({
  data: {
    videoUrl: 'https://cdn.example.com/video/course-01.mp4',
    currentTime: 0
  },

  onReady() {
    // 必须在 onReady 之后创建 VideoContext
    this.videoContext = wx.createVideoContext('mainVideo', this)
  },

  play() {
    this.videoContext.play()
  },

  pause() {
    this.videoContext.pause()
  },

  seekTo(second) {
    this.videoContext.seek(second)   // 单位：秒
  },

  fullscreen() {
    this.videoContext.requestFullScreen({ direction: 90 })  // 横屏全屏
  },

  exitFullscreen() {
    this.videoContext.exitFullScreen()
  },

  // 倍速播放
  speedUp() {
    this.videoContext.playbackRate(2)
  },

  // 发弹幕（组件需 enable-danmu）
  sendDanmu() {
    this.videoContext.sendDanmu({
      text: '老师讲得真好',
      color: '#ff6600'
    })
  },

  onTimeUpdate(e) {
    this.setData({ currentTime: e.detail.currentTime })
  },

  onVideoEnded() {
    wx.showToast({ title: '播放结束', icon: 'none' })
  }
})
```

音频播放与视频控制要点：
1. InnerAudioContext 用完必须 destroy，页面 onUnload 释放，防内存泄漏
2. iOS 上 obeyMuteSwitch 默认 true（受静音键控制），语音类应用设 false
3. iOS 上 autoplay 不生效，play 必须在用户手势回调中调用

## 应用场景实战

### 场景一：发布动态（多图选择 + 压缩 + 上传 + 预览）

社区类小程序的核心发布流程：选多张图 → 逐张上传后台 → 成功后跳详情页，带进度反馈与失败重试。

```js
// pages/publish/publish.js
Page({
  data: {
    images: [],
    uploading: false
  },

  // 选择图片（最多 9 张）
  chooseImages() {
    const remain = 9 - this.data.images.length
    if (remain <= 0) {
      wx.showToast({ title: '最多上传 9 张', icon: 'none' })
      return
    }
    wx.chooseMedia({
      count: remain,
      mediaType: ['image'],
      sizeType: ['compressed'],       // 压缩图上传，节省流量
      sourceType: ['album', 'camera'],
      success: (res) => {
        const paths = res.tempFiles.map((f) => f.tempFilePath)
        this.setData({ images: this.data.images.concat(paths) })
      }
    })
  },

  // 点击图片预览
  previewImage(e) {
    const current = e.currentTarget.dataset.url
    wx.previewImage({ current, urls: this.data.images })
  },

  // 删除图片
  removeImage(e) {
    const index = e.currentTarget.dataset.index
    const images = this.data.images.slice()
    images.splice(index, 1)
    this.setData({ images })
  },

  // 发布：逐张上传
  publish() {
    const { images } = this.data
    if (images.length === 0) {
      wx.showToast({ title: '请至少选择一张图片', icon: 'none' })
      return
    }
    if (this.data.uploading) return
    this.setData({ uploading: true })
    wx.showLoading({ title: '发布中 0/' + images.length, mask: true })

    const uploadedUrls = []
    let index = 0

    const uploadNext = () => {
      if (index >= images.length) {
        // 全部上传完成，提交动态
        this.submitPost(uploadedUrls)
        return
      }
      wx.uploadFile({
        url: 'https://api.example.com/upload/image',
        filePath: images[index],
        name: 'file',
        timeout: 30000,
        success: (res) => {
          const data = JSON.parse(res.data)
          if (data.code === 0) {
            uploadedUrls.push(data.data.url)
            index++
            wx.showLoading({ title: '发布中 ' + index + '/' + images.length, mask: true })
            uploadNext()
          } else {
            this.failUpload('图片 ' + (index + 1) + ' 上传失败')
          }
        },
        fail: () => this.failUpload('网络异常，上传中断')
      })
    }

    uploadNext()
  },

  failUpload(msg) {
    wx.hideLoading()
    this.setData({ uploading: false })
    wx.showModal({ title: '发布失败', content: msg + '，请重试', showCancel: false })
  },

  submitPost(urls) {
    wx.request({
      url: 'https://api.example.com/post/create',
      method: 'POST',
      data: { images: urls, content: this.data.content },
      success: (res) => {
        wx.hideLoading()
        this.setData({ uploading: false })
        if (res.data.code === 0) {
          wx.showToast({ title: '发布成功', icon: 'success' })
          setTimeout(() => wx.navigateBack(), 1500)
        } else {
          wx.showModal({ title: '发布失败', content: res.data.msg, showCancel: false })
        }
      }
    })
  }
})
```

### 场景二：语音留言 + 音频播放（录音上传闭环）

客服/社区场景的语音留言：录音 → 上传 → 列表播放，处理 iOS 静音键与实例管理。

```js
// pages/voice/voice.js
Page({
  data: {
    messages: [],      // [{ id, url, duration }]
    playingId: -1
  },

  onLoad() {
    this.recorderManager = wx.getRecorderManager()
    this.setupRecorder()
    this.fetchMessages()
  },

  setupRecorder() {
    this.recorderManager.onStop((res) => {
      this.uploadVoice(res.tempFilePath, res.duration)
    })
    this.recorderManager.onError((err) => {
      console.error('录音错误：', err.errMsg)
      wx.showToast({ title: '录音失败', icon: 'none' })
    })
  },

  // 按住说话
  startRecord() {
    wx.getSetting({
      success: (res) => {
        if (res.authSetting['scope.record']) {
          this.recorderManager.start({
            duration: 60000,
            sampleRate: 16000,
            numberOfChannels: 1,
            encodeBitRate: 48000,
            format: 'mp3'
          })
        } else {
          wx.authorize({
            scope: 'scope.record',
            fail: () => {
              wx.showModal({
                title: '需要麦克风权限',
                content: '语音留言需要麦克风权限',
                confirmText: '去设置',
                success: (r) => { if (r.confirm) wx.openSetting() }
              })
            }
          })
        }
      }
    })
  },

  stopRecord() {
    this.recorderManager.stop()
  },

  uploadVoice(filePath, duration) {
    wx.showLoading({ title: '上传中', mask: true })
    wx.uploadFile({
      url: 'https://api.example.com/voice/upload',
      filePath,
      name: 'file',
      formData: { duration: String(duration) },
      success: (res) => {
        wx.hideLoading()
        const data = JSON.parse(res.data)
        if (data.code === 0) {
          wx.showToast({ title: '发送成功', icon: 'success' })
          this.fetchMessages()
        } else {
          wx.showToast({ title: '上传失败', icon: 'none' })
        }
      },
      fail: () => {
        wx.hideLoading()
        wx.showToast({ title: '上传失败', icon: 'none' })
      }
    })
  },

  // 播放语音（同一时间只播放一条）
  playVoice(e) {
    const item = e.currentTarget.dataset.item
    // 先停掉正在播放的
    if (this.audio) {
      this.audio.destroy()
      this.audio = null
    }
    if (this.data.playingId === item.id) {
      this.setData({ playingId: -1 })
      return
    }

    this.audio = wx.createInnerAudioContext()
    this.audio.src = item.url
    this.audio.obeyMuteSwitch = false          // iOS 静音键不影响
    this.audio.onEnded(() => {
      this.setData({ playingId: -1 })
      this.audio.destroy()
      this.audio = null
    })
    this.audio.play()
    this.setData({ playingId: item.id })
  },

  fetchMessages() {
    wx.request({
      url: 'https://api.example.com/voice/list',
      success: (res) => {
        this.setData({ messages: res.data.data })
      }
    })
  },

  onUnload() {
    if (this.audio) {
      this.audio.destroy()
      this.audio = null
    }
  }
})
```

## 最佳实践与踩坑记录

### 最佳实践

1. 统一封装 upload 工具（uploadFile 包装 Promise + 进度回调 + 超时 + 错误分类），全项目复用，避免每个页面重复写 JSON.parse 与状态码判断
2. 图片统一选 compressed 压缩图上传，原图只在「高清素材」类场景提供入口，可显著降低带宽与后台存储成本
3. 上传前用 getImageInfo 做合法性校验（类型、大小），gif 大图直接拒绝或提示
4. 上传/下载都展示进度，进度条是长耗时操作的基本体验要求；失败给出「重试」入口而不是干等
5. 音频播放做单例管理：同一时间只允许一个 InnerAudioContext 播放，播放新音频前 destroy 旧实例
6. 录音授权、相册授权统一走「getSetting → authorize → openSetting 引导」三段式流程，文案写清楚用途
7. 媒体 URL 统一走 CDN 并配置 downloadFile 合法域名，图片/音频/视频资源不要混用 request 域名
8. 真机测试矩阵覆盖 iOS + 安卓：录音格式、静音键、autoplay、相册授权行为在两端差异明显

### 踩坑记录

坑 1：chooseMedia 的临时文件路径下次启动就失效
结论：用户发布图片后过几天再打开，图片全部打不开（本地路径失效）。
原因：chooseMedia/chooseImage 返回的是临时文件，小程序退出后临时目录被清理。
解法：拿到临时路径后立即 uploadFile 上传到后台，页面展示用后台返回的 CDN URL；确需本地保存的用 wx.saveFile 转存。

坑 2：uploadFile 报 "url not in domain list"
结论：开发者工具勾选「不校验合法域名」时正常，真机上传直接失败。
原因：上传接口域名未配置到「uploadFile 合法域名」列表中（request 域名与 uploadFile 域名是分开配置的）。
解法：小程序后台「开发管理 - 服务器域名」中把上传接口域名加入 uploadFile 合法域名；本地调试用「不校验合法域名」开关，上线前必须配齐。

坑 3：uploadFile 的 res.data 直接当 JSON 用导致解析崩溃
结论：部分机型/后台返回非 JSON（如 HTML 错误页、纯文本），JSON.parse 抛异常页面白屏。
原因：res.data 是字符串，后台可能返回错误页，且没有做防御性解析。
解法：先判断 res.statusCode === 200，再 try/catch 包裹 JSON.parse，解析失败统一提示「上传失败」。

坑 4：saveImageToPhotosAlbum 报 "saveImageToPhotosAlbum:fail auth deny"
结论：保存海报功能在测试机正常，部分用户一直保存失败。
原因：该接口需要 scope.writePhotosAlbum 授权，用户之前拒绝过或系统相册权限被关闭。
解法：fail 回调中判断 errMsg 含 auth deny/authorize 时引导 openSetting；网络图片必须先 downloadFile 再保存，不能直接传网络 URL。

坑 5：iOS 上音频没有声音
结论：安卓播放正常，iOS 播放静音。
原因：InnerAudioContext 默认 obeyMuteSwitch 为 true，受手机静音键控制，用户拨到静音就没声。
解法：语音/音乐类场景创建实例后立即设置 audio.obeyMuteSwitch = false（仅 iOS 生效）。

坑 6：iOS 上 autoplay 自动播放不生效
结论：设置了 autoplay: true，安卓自动播放，iOS 毫无反应。
原因：iOS 系统限制媒体自动播放，必须由用户手势触发。
解法：不在 onLoad 中自动播放，改为在用户点击按钮等手势回调里调用 play()；或先展示播放按钮引导用户点击。

坑 7：createVideoContext 报 "Cannot read property 'play' of undefined"
结论：onLoad 里调用 wx.createVideoContext 后执行 play() 直接报错。
原因：video 组件还没渲染完成，context 未就绪。
解法：把 createVideoContext 放到 onReady 生命周期中执行，且组件必须带 id，上下文创建后先判空再调用方法。

坑 8：录音在 iOS 上录出来是空文件或格式错误
结论：录音功能安卓正常，iOS 上播放无声或文件无法解码。
原因：iOS 对录音格式支持与安卓不同，wav/PCM 等格式在 iOS 上支持差，或声道/采样率配置不被支持。
解法：跨端统一用 mp3 或 aac 格式，单声道、采样率 16k-44.1k；上线前 iOS + 安卓各真机录一段回放验证。
