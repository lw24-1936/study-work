## 概述

Flex（Flexible Box，弹性盒）是移动端页面布局的事实标准，也是小程序 WXSS 中最常用的布局方案。相比传统浮动与定位布局，Flex 通过「容器声明方向、项目声明伸缩」的方式，天然解决水平垂直居中、两端对齐、等高列、剩余空间分配等高频需求，且代码量少、语义清晰。

Flex 布局的核心是两套属性：容器属性（display、flex-direction、justify-content、align-items、flex-wrap、align-content）决定项目如何排列与对齐；项目属性（flex-grow、flex-shrink、flex-basis、order、align-self）决定单个项目如何伸缩与排序。理解主轴与交叉轴是掌握全部属性的前提：所有对齐属性都是围绕这两条轴定义的。

```text
Flex 布局要点：
1. 声明 —— display: flex 开启弹性布局，作用于容器
2. 两轴 —— 主轴（排列方向）与交叉轴（垂直方向）决定对齐语义
3. 容器 —— flex-direction、flex-wrap、justify-content、align-items
4. 项目 —— flex-grow/shrink/basis（简写 flex）、order、align-self
5. 分配 —— flex: 1 占据剩余空间，是自适应布局的核心武器
6. 组合 —— Flex + rpx 实现移动端全场景布局：居中、两端、等高、吸底
```

## Flex 容器与主轴交叉轴

任何一个节点声明 display: flex 后即成为 flex 容器，其直接子节点自动变为 flex 项目（flex item），进入弹性布局体系。容器有两条轴线：主轴（main axis）是项目排列的方向，交叉轴（cross axis）与主轴垂直。justify-content 控制项目在主轴上的对齐，align-items 控制项目在交叉轴上的对齐——只要确定了主轴方向，这两个属性的作用方向就确定了，这是理解 Flex 的第一性原理。

```wxml
<!-- pages/flex/flex.wxml -->
<view class="container">
  <view class="box">1</view>
  <view class="box">2</view>
  <view class="box">3</view>
</view>
```

```wxss
/* pages/flex/flex.wxss */
.container {
  display: flex;              /* 声明弹性容器 */
  height: 400rpx;
  background: #f0f0f0;
}

.box {
  width: 120rpx;
  height: 120rpx;
  background: #07c160;
  color: #ffffff;
  display: flex;              /* 盒子内部再开 flex，让数字居中 */
  align-items: center;
  justify-content: center;
}
```

Flex 容器的直接子节点是项目，但项目内部可以再嵌套 flex 容器（如上面每个 .box 内部用 flex 让数字居中），形成任意层级的弹性布局树。需要注意：flex 只影响「直接子节点」的排列，孙节点不受影响，必须逐层声明 display: flex。

```text
容器与两轴：
1. display: flex —— 声明弹性容器，直接子节点自动成为项目
2. 主轴 —— 项目排列方向，justify-content 沿主轴对齐
3. 交叉轴 —— 与主轴垂直，align-items 沿交叉轴对齐
4. 嵌套 —— 项目内部可再开 flex 容器，任意层级嵌套
5. 作用域 —— flex 只影响直接子节点，孙节点需逐层声明
6. 默认值 —— 主轴水平向右（row），交叉轴垂直向下
```

## flex-direction 与 flex-wrap

flex-direction 决定主轴方向，即项目的排列方向：row（默认）水平从左到右、row-reverse 水平从右到左、column 垂直从上到下、column-reverse 垂直从下到上。主轴方向一变，justify-content 与 align-items 的语义随之翻转——这是新手最容易绕晕的点：row 下 justify-content 控制水平方向、column 下它控制垂直方向。

```wxss
/* 四种主轴方向 */
.row-dir {
  display: flex;
  flex-direction: row;          /* 默认：水平，从左到右 */
}

.row-reverse-dir {
  display: flex;
  flex-direction: row-reverse;  /* 水平，从右到左 */
}

.column-dir {
  display: flex;
  flex-direction: column;       /* 垂直，从上到下：页面纵向布局标配 */
}

.column-reverse-dir {
  display: flex;
  flex-direction: column-reverse; /* 垂直，从下到上 */
}
```

flex-wrap 控制项目放不下时是否换行：nowrap（默认）不换行，项目会被压缩（flex-shrink 生效）；wrap 允许换行，超出的项目排到下一行；wrap-reverse 换行且新行排在上方。单行模式下 align-content 无效，只有 wrap 产生多行后 align-content 才参与交叉轴分配。

```wxml
<!-- pages/flex/flex.wxml —— 换行演示 -->
<view class="wrap-box">
  <view class="mini" wx:for="{{[1,2,3,4,5,6]}}" wx:key="*this">{{item}}</view>
</view>
```

```wxss
.wrap-box {
  display: flex;
  flex-wrap: wrap;              /* 允许换行，6 个 200rpx 宽的小块排成多行 */
}

.mini {
  width: 200rpx;
  height: 150rpx;
  margin: 16rpx;
  background: #07c160;
  color: #ffffff;
}
```

```text
flex-direction 与 flex-wrap：
1. row —— 默认，主轴水平，justify-content 管水平对齐
2. column —— 主轴垂直，页面纵向结构（header 内容 footer）的根基
3. 翻转 —— row-reverse/column-reverse 改变起排方向
4. nowrap —— 默认不换行，空间不足时项目被压缩
5. wrap —— 允许换行，多行布局（商品宫格、标签云）必备
6. 联动 —— wrap 后 align-content 才生效，单行时它无效
```

## justify-content 与 align-items

justify-content 沿主轴分配项目，取值：flex-start（默认，主轴起点对齐）、flex-end（终点对齐）、center（主轴居中）、space-between（首尾贴边、中间均分）、space-around（每个项目两侧等距，首尾间距为中间的一半）、space-evenly（所有间距完全相等）。两端对齐 space-between 是列表布局最高频的用法，配合 flex-wrap 直接生成规整的网格。

```wxss
/* justify-content 六种取值 */
.jc-start     { display: flex; justify-content: flex-start; }    /* 起点对齐 */
.jc-end       { display: flex; justify-content: flex-end; }      /* 终点对齐 */
.jc-center    { display: flex; justify-content: center; }        /* 主轴居中 */
.jc-between   { display: flex; justify-content: space-between; } /* 两端对齐 */
.jc-around    { display: flex; justify-content: space-around; }  /* 两侧等距 */
.jc-evenly    { display: flex; justify-content: space-evenly; }  /* 间距全等 */
```

align-items 沿交叉轴对齐单个项目（单行时作用于所有项目），取值：stretch（默认，交叉轴方向拉伸填满容器——等高列的来源）、flex-start、flex-end、center、baseline（按文本基线对齐）。垂直居中 = align-items: center（默认主轴 row 时）；「水平 + 垂直同时居中」= justify-content: center + align-items: center，是移动端弹窗、空态、加载占位的最常用组合。

```wxss
/* align-items 五种取值 */
.ai-stretch  { display: flex; align-items: stretch; }   /* 默认：拉伸等高 */
.ai-start    { display: flex; align-items: flex-start; }
.ai-end      { display: flex; align-items: flex-end; }
.ai-center   { display: flex; align-items: center; }    /* 交叉轴居中 */
.ai-baseline { display: flex; align-items: baseline; }  /* 文本基线对齐 */
```

```wxml
<!-- 完美居中：主轴 + 交叉轴双 center -->
<view class="empty-state">
  <view class="empty-icon">空</view>
  <text class="empty-text">暂无数据</text>
</view>
```

```wxss
.empty-state {
  display: flex;
  flex-direction: column;      /* 主轴变垂直，图标在上文字在下 */
  justify-content: center;     /* 垂直方向居中 */
  align-items: center;         /* 水平方向居中 */
  height: 600rpx;
}
```

多行场景（flex-wrap: wrap 后）还有一个 align-content：它沿交叉轴分配「整行」的空间（flex-start、center、space-between、space-around、stretch 等），与 align-items 的区别是 align-items 管行内项目对齐，align-content 管行与行之间的分布。单行容器中 align-content 不生效。

```text
justify-content 与 align-items：
1. justify-content —— 主轴对齐：start/end/center/between/around/evenly
2. align-items —— 交叉轴对齐：stretch/start/end/center/baseline
3. 居中组合 —— 双 center 实现水平垂直完全居中
4. 两端对齐 —— space-between 是列表/网格布局高频主力
5. 等高列 —— align-items 默认 stretch，子项自动等高
6. align-content —— 仅多行时管行间分布，单行无效
```

## flex 属性与 order

项目属性中最核心的是 flex 简写，它由三个子属性组成：flex-grow（放大比例，默认 0，空间有富余时按比例瓜分）、flex-shrink（缩小比例，默认 1，空间不足时按比例压缩）、flex-basis（项目在主轴上的初始大小，默认 auto 即按 width/height 或内容大小）。三个值共同决定项目在主轴上的尺寸如何伸缩。

```wxss
/* flex 简写与子属性 */
.flex-item-grow {
  flex-grow: 1;    /* 有剩余空间时占 1 份，常见于内容区自适应 */
}

.flex-item-no-shrink {
  flex-shrink: 0;  /* 空间不足也不压缩：图标、固定宽度元素必备 */
}

.flex-item-basis {
  flex-basis: 200rpx;  /* 主轴初始大小，优先于 width（row 下） */
}

/* 常用简写 */
.flex-1    { flex: 1; }        /* 等价 1 1 0%：等分剩余空间，自适应主力 */
.flex-none { flex: none; }     /* 等价 0 0 auto：不伸缩，按内容大小 */
.flex-auto { flex: auto; }     /* 等价 1 1 auto：可伸缩，基准为内容大小 */
```

flex: 1（1 1 0%）是使用频率最高的简写：flex-basis 为 0、grow 为 1，意味着项目不按自身内容占位，纯粹瓜分剩余空间。多个 flex: 1 的兄弟项目会均分容器宽度（等宽列）；flex: 2 与 flex: 1 组合则是 2:1 分栏。注意 flex-basis 设为 0% 后，子项自身的 width 属性不再参与主轴尺寸计算，只影响交叉轴（column 方向时相反）。

```wxml
<!-- 经典三栏：中间自适应，两侧固定 -->
<view class="three-col">
  <view class="side">左</view>
  <view class="main">内容自适应区</view>
  <view class="side">右</view>
</view>
```

```wxss
.three-col {
  display: flex;
  align-items: center;
}

.side {
  width: 120rpx;
  flex-shrink: 0;   /* 固定宽度，禁止被压缩 */
}

.main {
  flex: 1;          /* 占据两侧之外的剩余全部空间 */
  margin: 0 16rpx;
  text-align: center;
}
```

order 属性控制项目的排列顺序，默认 0，数值越小排越前，允许负数。它只改变视觉顺序，不改变 WXML 节点顺序（不影响事件冒泡、焦点顺序等逻辑行为），适合「视觉上把某元素提前/置后」的场景。align-self 则是项目级的交叉轴对齐，覆盖容器的 align-items 设置，实现「大家都居中、就它靠底」的局部定制。

```wxss
/* order 排序：视觉顺序与 WXML 顺序解耦 */
.order-box { display: flex; }

.order-box .first  { order: -1; }   /* 排最前 */
.order-box .last   { order: 2; }    /* 排最后 */
.order-box .normal { order: 0; }    /* 默认中间 */
```

```text
flex 属性与 order：
1. flex-grow —— 剩余空间分配比例，默认 0 不放大
2. flex-shrink —— 空间不足压缩比例，默认 1，想固定就设 0
3. flex-basis —— 主轴初始大小，默认 auto
4. flex: 1 —— 等价 1 1 0%，自适应布局主力，等分剩余空间
5. flex: none —— 不伸缩，固定宽度元素（图标、按钮）标配
6. order —— 视觉排序与节点顺序解耦；align-self 局部覆盖交叉轴对齐
```

## 常见布局实战

把上面的属性组合起来，移动端绝大多数布局都有固定套路。水平居中：容器 justify-content: center（或项目 margin: 0 auto）；垂直居中：容器 align-items: center；完全居中：双 center 组合；两端对齐：justify-content: space-between（导航栏标题居中、左右各一个操作按钮的经典结构）；等高列：align-items 默认 stretch，子项不设高度自动等高；吸底布局：容器 flex-direction: column + 内容区 flex: 1，footer 自然贴底。

```wxss
/* 导航栏：标题绝对居中，左右按钮两端分布 */
.nav {
  display: flex;
  align-items: center;
  justify-content: space-between;
  height: 88rpx;
  padding: 0 24rpx;
}

/* 页面骨架：头部固定、内容区自适应滚动、底部吸底 */
.page-flex {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}

.page-content {
  flex: 1;              /* 内容区吃掉中间所有空间，footer 被推到最底 */
  overflow-y: auto;
}

.page-footer {
  height: 100rpx;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

```wxml
<!-- 等高列：三张卡片高度一致，内容多少不影响 -->
<view class="cols">
  <view class="col-item">短内容</view>
  <view class="col-item">较长内容，撑开也不影响兄弟卡片高度</view>
  <view class="col-item">中</view>
</view>
```

```wxss
.cols {
  display: flex;
  align-items: stretch;      /* 默认值：三列等高 */
  margin: 0 -16rpx;          /* 负外边距抵消列间距，实现视觉均分 */
}

.col-item {
  flex: 1;
  margin: 0 16rpx;
  background: #ffffff;
  border-radius: 16rpx;
  padding: 24rpx;
}
```

rpx 与 Flex 是天然搭档：Flex 负责「空间怎么分」（比例、对齐、换行），rpx 负责「固定尺寸是多少」（边距、间距、固定宽高），二者分工明确。凡是「随容器变化的尺寸」交给 flex（flex: 1、flex-basis、百分比），「固定视觉尺寸」用 rpx，避免硬编码 rpx 宽度导致小屏放不下、大屏留白多。

```text
常见布局套路：
1. 水平居中 —— 容器 justify-content: center
2. 垂直居中 —— 容器 align-items: center（配合 column 方向时互换）
3. 完全居中 —— 双 center 组合，弹窗/空态/占位通用
4. 两端对齐 —— space-between，导航栏、操作条标配
5. 等高列 —— align-items: stretch 默认生效，无需额外代码
6. 吸底布局 —— column + 内容区 flex: 1，footer 自然贴底
```

## 应用场景实战

### 场景一：商品列表两列网格 + 底部吸底购买栏

电商商品列表：两列卡片网格（flex-wrap + space-between 保证每行两张、间距均匀），商品卡片内部用 column 结构（图片 + 信息 + 价格底部对齐），底部固定购买栏（吸底 + 按钮两端分布）。完整演示 Flex 在真实页面中的组合拳。

```wxml
<!-- pages/shop/shop.wxml -->
<view class="shop-page">
  <view class="goods-grid">
    <view class="goods-card" wx:for="{{goodsList}}" wx:key="id">
      <image class="goods-img" src="{{item.image}}" mode="aspectFill" />
      <view class="goods-info">
        <text class="goods-name">{{item.name}}</text>
        <view class="goods-bottom">
          <text class="goods-price">¥{{item.price}}</text>
```

### 场景二：个人中心页 —— 纵向骨架 + 横向功能宫格

个人中心页是 Flex 纵向骨架的典型：头部用户区（头像左、信息右，space-between 或 space-around）、功能宫格（wrap 四列）、底部版本信息（flex: 1 撑开贴底）。

```wxml
<!-- pages/profile/profile.wxml -->
<view class="profile-page">
  <!-- 头部用户区：水平布局，左头像右信息 -->
  <view class="user-header">
    <image class="avatar" src="{{userInfo.avatar}}" mode="aspectFill" />
    <view class="user-meta">
      <text class="user-name">{{userInfo.nickname}}</text>
      <text class="user-desc">{{userInfo.sign}}</text>
    </view>
    <text class="user-level">Lv.{{userInfo.level}}</text>
  </view>
```

## 最佳实践与踩坑记录

### 最佳实践

1. 页面纵向骨架一律 flex-direction: column（头部、内容 flex: 1、底部），横向内部结构再开 row 容器，层级清晰
2. 剩余空间分配用 flex: 1，固定尺寸用 rpx，两者分工明确，不要用 rpx 硬编码自适应区域
3. 固定宽高的元素（图标、头像、按钮）加 flex-shrink: 0，防止被压缩变形
4. 网格类布局用 flex-wrap + space-between 或百分比宽度，避免手工计算间距出现 1px 换行误差
5. 需要吸底的元素用「容器 column + 前置元素 flex: 1」或 margin-top: auto，比 fixed 定位更省心
6. 垂直水平居中优先双 center 组合，不要用 margin 负值或绝对定位硬凑
7. order 只用于视觉排序调整，业务逻辑顺序仍以 WXML 节点为准
8. 复杂布局拆分为「容器 + 项目」两层思考：先定主轴方向，再选对齐与伸缩属性

### 踩坑记录

```text
坑 1：flex 子项文字被压缩换行，布局错乱
结论：flex 容器里放了长文本，空间不足时文字被压成多行甚至溢出。
原因：flex 项目默认 flex-shrink: 1，且 min-width 默认 auto，内容不换行时宁死不缩。
解法：文字容器加 min-width: 0 允许收缩；或给固定元素 flex-shrink: 0；文本配 word-break: break-all。

坑 2：flex: 1 和 width 同时设置，宽度不符合预期
结论：子项写了 width: 300rpx 又写 flex: 1，实际宽度完全被 flex 接管。
原因：flex: 1 等价 1 1 0%，flex-basis 为 0 后主轴尺寸不再参考 width。
解法：固定宽度就不要用 flex: 1；想「基准 + 伸缩」用 flex: 1 1 auto 或显式 flex-basis。

坑 3：align-items 默认 stretch 导致子项被拉高
结论：横向排列的按钮高度莫名撑满容器，左右图标被拉伸。
原因：align-items 默认值是 stretch，子项不设高度时沿交叉轴填满。
解法：显式 align-items: center 或 flex-start；需要等高的场景才保留 stretch。

坑 4：垂直居中只写了 justify-content: center，没效果
结论：想垂直居中，容器写了 justify-content: center，元素还是贴顶。
原因：默认主轴是 row（水平），justify-content 管的是水平方向。
解法：垂直居中用 align-items: center；或先 flex-direction: column 再 justify-content: center。

坑 5：两列各 50% 加间距后第二列换行
结论：两个 50% 宽的子项加 margin 后，第二列被挤到下一行。
原因：50% + 50% + 间距超过 100%，nowrap 容器里百分比加间距直接溢出换行。
解法：用 space-between + 固定计算宽度；或用 flex: 1 + 内部 padding 代替百分比。

坑 6：flex 的 gap 属性在旧基础库/部分安卓不生效
结论：容器写了 gap: 20rpx，部分安卓真机间距全部消失，元素挤在一起。
原因：flex gap 依赖较新渲染内核，低版本基础库与旧安卓 WebView 不支持。
解法：用 margin 方案（子项 margin + 容器负 margin）保证全端兼容。

坑 7：吸底按钮被内容区遮挡或键盘顶起
结论：position: fixed 的底部栏被长列表内容盖住，输入框弹键盘时被顶乱。
原因：fixed 脱离文档流，未给内容留 padding；键盘弹起时 fixed 元素随视口变化。
解法：内容区加 padding-bottom 预留高度；键盘场景改用 safe-area 适配与输入框监听。

坑 8：flex 容器内 image 变形
结论：flex 布局里 image 设了宽高，真机上被拉伸或比例失真。
原因：image 组件默认 mode 会按固定宽高拉伸，flex-shrink 参与后又二次压缩。
解法：image 加 flex-shrink: 0；mode 用 aspectFill/widthFix 保持比例；宽高用 rpx 固定。
```
