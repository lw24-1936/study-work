## 概述

视图容器组件是小程序布局体系的地基，负责页面的块级布局、滚动、轮播、拖拽与原生组件覆盖。微信官方将 view、scroll-view、swiper、movable-view、cover-view 归入「视图容器」类别：view 对应 HTML 的 div，scroll-view 提供可定制滚动，swiper 实现轮播图，movable-view 支持自由拖拽，cover-view 解决原生组件层级覆盖问题。

```text
视图容器组件一览：
1. view —— 基础块级容器，类似 div，支持 hover 点击态
2. scroll-view —— 可滚动容器，支持横向/纵向滚动、锚点定位、下拉刷新
3. swiper/swiper-item —— 轮播容器，支持自动播放、循环、指示点
4. movable-view/movable-area —— 可移动容器，支持拖拽、缩放、惯性
5. cover-view/cover-image —— 覆盖在原生组件（map/video/canvas）之上的容器
6. 通用注意 —— 组件属性区分「静态属性」与「事件绑定」，数据通过绑定驱动
```

## view 基础容器

view 是最常用的容器组件，对应 HTML 的 div，默认块级、宽度撑满父容器。它最特别的能力是 hover 系列属性：给 view 添加 hover-class 后，手指按下时自动套用该 class，模拟出「按下变灰」的按钮反馈，这一效果在按钮、列表项、卡片上非常常用。

```wxml
<!-- pages/index/index.wxml -->
<view class="page">
  <!-- 基础容器：块级布局 -->
  <view class="card">
    <view class="card-title">基础容器</view>
    <view class="card-body">view 默认宽度 100%，高度由内容撑开</view>
  </view>

  <!-- hover 点击态：按下时套用 hover-class，松开后 400ms 内渐变消失 -->
  <view class="list-item" hover-class="list-item-hover" hover-start-time="50" hover-stay-time="200" bindtap="onItemTap">
    列表项（按下变灰）
  </view>

  <!-- hover-stop-propagation：阻止点击态冒泡到父级 -->
  <view class="list-item" hover-class="list-item-hover" hover-stop-propagation="true" bindtap="onItemTap">
    子项点击态不传递给父容器
  </view>
</view>
```

```wxss
/* pages/index/index.wxss */
.list-item {
  padding: 24rpx;
  background: #ffffff;
  border-radius: 12rpx;
}

/* 按下时的样式：深色背景 + 缩放反馈 */
.list-item-hover {
  background: #f2f3f5;
  transform: scale(0.98);
}
```

```text
view 属性要点：
1. hover-class —— 按下时切换的样式类，最核心的交互属性
2. hover-stop-propagation —— 是否阻止本节点的点击态冒泡到父节点（默认 false）
3. hover-start-time —— 按住多久后进入 hover 态（单位 ms，默认 50）
4. hover-stay-time —— 松开手指后保持 hover 态的时间（单位 ms，默认 400）
5. 注意 —— hover-class 只有 view 等少数组件支持，text 等组件没有该属性
6. 定位 —— view 配合 flex 布局是页面结构的主体，禁止用 view 嵌套过深导致渲染性能下降
```

## scroll-view 滚动容器

scroll-view 是「局部滚动」容器：页面本身滚动用页面滚动（onPageScroll/onReachBottom），容器内滚动用 scroll-view。它支持横向与纵向滚动，竖向滚动必须设置固定高度（否则高度自适应内容就不会产生滚动）；同时支持 scroll-into-view 锚点定位、上下边界事件、以及下拉刷新（refresher 系列，基础库 2.10.1+）。

```wxml
<!-- pages/scroll/scroll.wxml -->
<view class="page">
  <!-- 纵向滚动：必须给 scroll-view 设置高度 -->
  <scroll-view
    class="scroll-y"
    scroll-y="true"
    scroll-top="{{scrollTop}}"
    scroll-into-view="{{intoViewId}}"
    scroll-with-animation="true"
    lower-threshold="80"
    refresher-enabled="true"
    refresher-triggered="{{refreshing}}"
    bindscrolltolower="onLoadMore"
    bindrefresherrefresh="onRefresh"
    bindscroll="onScroll"
  >
    <view id="anchor-0" class="item">锚点 0</view>
    <view id="anchor-1" class="item">锚点 1</view>
    <view id="anchor-2" class="item">锚点 2</view>
    <view class="item" wx:for="{{items}}" wx:key="*this">条目 {{item}}</view>
    <view wx:if="{{loadingMore}}" class="loading">加载中...</view>
  </scroll-view>

  <!-- 横向滚动 -->
  <scroll-view class="scroll-x" scroll-x="true" enable-flex="true">
    <view class="tab" wx:for="{{tabs}}" wx:key="*this">{{item}}</view>
  </scroll-view>
</view>
```

```js
// pages/scroll/scroll.js
Page({
  data: {
    scrollTop: 0,
    intoViewId: '',
    refreshing: false,
    loadingMore: false,
    items: [1, 2, 3, 4, 5, 6, 7, 8],
    tabs: ['推荐', '热销', '新品', '折扣'],
  },

  // 滚动到底部（距底部小于 lower-threshold 80px）触发
  onLoadMore() {
    if (this.data.loadingMore) return
    this.setData({ loadingMore: true })
    setTimeout(() => {
      const next = this.data.items.concat(
        this.data.items.map((n) => n + 100)
      )
      this.setData({ items: next, loadingMore: false })
    }, 500)
  },

  // 下拉刷新触发（refresher-enabled 开启后）
  onRefresh() {
    this.setData({ refreshing: true })
    setTimeout(() => {
      this.setData({ items: [1, 2, 3], refreshing: false })
    }, 800)
  },

  // 滚动过程持续触发，可用于回到顶部按钮显隐
  onScroll(e) {
    this.setData({ showBackTop: e.detail.scrollTop > 200 })
  },

  // 回到顶部
  onBackTop() {
    this.setData({ scrollTop: 0 })
  },

  // 锚点跳转：把某个子元素的 id 赋给 scroll-into-view
  onGoAnchor() {
    this.setData({ intoViewId: 'anchor-2' })
  },
})
```

```text
scroll-view 要点：
1. 固定高度 —— 竖向滚动必须给 scroll-view 设置确定高度，内容超出才会滚动
2. scroll-x/scroll-y —— 横向/纵向滚动开关，可同时开启
3. scroll-top/scroll-left —— 受控滚动位置，赋值即滚动（回到顶部等）
4. scroll-into-view —— 子元素 id 锚点滚动，配合 scroll-with-animation 平滑
5. 触底加载 —— bindscrolltolower + lower-threshold 实现分页加载更多
6. 下拉刷新 —— refresher-enabled + bindrefresherrefresh + refresher-triggered 受控关闭
7. 边界事件 —— bindscrolltoupper/bindscrolltolower 在滚到两端时触发
8. 性能 —— 大量节点在 scroll-view 内仍会全部渲染，超长列表配合虚拟列表方案
```

页面级滚动与 scroll-view 的区别是高频考点：页面本身的滚动触发 Page.onReachBottom 做触底加载；scroll-view 内的滚动触发的是组件事件 bindscrolltolower。两者不要混淆，页面滚动时 onReachBottom 需要页面配置 onReachBottomDistance（默认 50px）。

## swiper 与 swiper-item 轮播容器

swiper 是轮播容器，swiper-item 是其中的每一屏，二者必须嵌套使用。swiper 默认宽度 100%、高度 150px，每个 swiper-item 默认宽高 100%。常用配置：autoplay 自动播放、interval 播放间隔、circular 循环播放、indicator-dots 指示点、current 当前索引（受控）。bindchange 在索引变化时触发，e.detail.current 为当前索引，e.detail.source 为变化来源（autoplay/touch/空）。

```wxml
<!-- pages/swiper/swiper.wxml -->
<view class="page">
  <!-- 基础轮播：自动播放 + 指示点 + 循环 -->
  <swiper
    class="banner"
    autoplay="true"
    interval="3000"
    duration="500"
    circular="true"
    indicator-dots="true"
    indicator-color="rgba(255, 255, 255, 0.4)"
    indicator-active-color="#ffffff"
    bindchange="onSwiperChange"
  >
    <swiper-item wx:for="{{banners}}" wx:key="id">
      <image class="banner-img" src="{{item.image}}" mode="aspectFill" data-id="{{item.id}}" bindtap="onBannerTap" />
    </swiper-item>
  </swiper>

  <!-- 受控轮播：通过 current 控制当前项，可加左右切换按钮 -->
  <swiper class="banner" current="{{current}}" circular="true" bindchange="onSwiperChange">
    <swiper-item wx:for="{{banners}}" wx:key="id">
      <view class="slide">{{item.title}}</view>
    </swiper-item>
  </swiper>
  <view class="controls">
    <button size="mini" bindtap="onPrev">上一页</button>
    <text>{{current + 1}} / {{banners.length}}</text>
    <button size="mini" bindtap="onNext">下一页</button>
  </view>

  <!-- 竖向轮播 + 多屏展示（display-multiple-items） -->
  <swiper class="vertical" vertical="true" circular="true" display-multiple-items="2">
    <swiper-item wx:for="{{banners}}" wx:key="id">
      <view class="v-slide">{{item.title}}</view>
    </swiper-item>
  </swiper>
</view>
```

```js
// pages/swiper/swiper.js
Page({
  data: {
    current: 0,
    banners: [
      { id: 1, title: '轮播 1', image: 'https://example.com/banner1.png' },
      { id: 2, title: '轮播 2', image: 'https://example.com/banner2.png' },
      { id: 3, title: '轮播 3', image: 'https://example.com/banner3.png' },
    ],
  },

  // current 变化时触发（用户滑动、autoplay 切换、代码设置都会触发）
  onSwiperChange(e) {
    this.setData({ current: e.detail.current })
  },

  onPrev() {
    const len = this.data.banners.length
    this.setData({ current: (this.data.current - 1 + len) % len })
  },

  onNext() {
    const len = this.data.banners.length
    this.setData({ current: (this.data.current + 1) % len })
  },

  onBannerTap(e) {
    const id = e.currentTarget.dataset.id
    wx.navigateTo({ url: '/pages/activity/activity?id=' + id })
  },
})
```

```text
swiper 要点：
1. 默认尺寸 —— swiper 宽 100% 高 150px，swiper-item 宽高 100%
2. autoplay/interval/duration —— 自动播放、间隔时间（默认 5000ms）、切换动画时长（默认 500ms）
3. circular —— 循环播放，首尾无缝衔接；不开启时首尾会回弹
4. indicator-dots —— 指示点开关与颜色（indicator-color/indicator-active-color）
5. current —— 当前索引，受控属性，赋值即可切换；bindchange 同步变化
6. vertical —— 竖向轮播；display-multiple-items —— 一屏展示多项
7. previous-margin/next-margin —— 露出前后屏边距，实现「中间大两边小」效果
8. 图片高度 —— swiper 高度固定，图片需用 mode="aspectFill" 或按比例计算高度，避免拉伸变形
```

bindchange 的一个细节：autoplay 切换、用户滑动、代码修改 current 都会触发 bindchange，因此不要在 bindchange 里做「current 变化就请求接口」之类的重操作，需要区分来源时读 e.detail.source（autoplay/touch/''）。

## movable-view 与 movable-area 可移动容器

movable-area 是移动区域（必须指定宽高），movable-view 是区域内可移动的视图，二者也是嵌套使用。movable-view 通过 direction 限定移动方向（all/horizontal/vertical/none），通过 x/y 设置初始位置，支持 inertia 惯性滑动、out-of-bounds 越界回弹、damping 阻尼系数；开启 scale 后支持双指缩放。典型应用：悬浮球、可拖动排序、图片裁剪缩放、地图浮层拖拽。

```wxml
<!-- pages/movable/movable.wxml -->
<view class="page">
  <!-- 基础拖拽：区域内自由移动 -->
  <movable-area class="area" style="width: 600rpx; height: 600rpx; background: #f2f3f5;">
    <movable-view
      class="ball"
      direction="all"
      inertia="true"
      out-of-bounds="true"
      damping="20"
      friction="2"
      bindchange="onMoveChange"
    >
      拖我
    </movable-view>
  </movable-area>

  <!-- 水平拖拽 + 受控位置（x/y 可赋值复位） -->
  <movable-area class="area-h" style="width: 600rpx; height: 120rpx; background: #f2f3f5;">
    <movable-view class="bar" direction="horizontal" x="{{x}}" y="0" bindchange="onBarChange">
      {{x}}
    </movable-view>
  </movable-area>
  <button size="mini" bindtap="onReset">复位</button>

  <!-- 缩放模式：双指缩放图片，范围 0.5 ~ 3 -->
  <movable-area class="area-zoom" style="width: 600rpx; height: 600rpx;">
    <movable-view
      class="zoom-box"
      direction="all"
      scale="true"
      scale-min="0.5"
      scale-max="3"
      scale-value="1"
      bindscale="onScale"
    >
      <image src="https://example.com/pic.png" mode="aspectFit" />
    </movable-view>
  </movable-area>
</view>
```

```js
// pages/movable/movable.js
Page({
  data: {
    x: 0,
    scale: 1,
  },

  // 拖动过程中持续触发，e.detail = { x, y, source }
  onMoveChange(e) {
    console.log('move', e.detail)
  },

  onBarChange(e) {
    this.setData({ x: Math.round(e.detail.x) })
  },

  onReset() {
    this.setData({ x: 0 })
  },

  // 缩放时触发，e.detail = { x, y, scale }
  onScale(e) {
    this.setData({ scale: e.detail.scale })
  },
})
```

```text
movable 系列要点：
1. movable-area —— 移动区域容器，必须显式设置宽高，movable-view 在其中移动
2. direction —— 移动方向：all/horizontal/vertical/none
3. x/y —— 受控初始位置与移动值，绑定 data 后可在 JS 中复位
4. inertia —— 惯性滑动（松手后按初速继续滑动一段）；out-of-bounds —— 越界后回弹
5. damping/friction —— 阻尼与摩擦系数，调节拖拽手感
6. scale —— 开启双指缩放，配合 scale-min/scale-max/scale-value 控制范围
7. bindchange —— 移动过程中触发；bindscale —— 缩放过程中触发
8. 注意 —— movable-view 不能超出 movable-area 边界，越界需配合 out-of-bounds 回弹体验
```

## cover-view 原生组件覆盖层

小程序中 map、video、canvas、camera、live-player 等是原生组件，原生组件的层级天然高于普通组件（WebView 内普通 view 无法覆盖）。cover-view 是唯一能稳定覆盖在原生组件之上的容器，cover-image 是其图片版本。基础库 2.4.4 之后 video、map 支持同层渲染，普通 view 也可以覆盖，但 cover-view 仍是兼容旧基础库与 canvas 等组件的标准方案。

```wxml
<!-- pages/map/map.wxml -->
<view class="page">
  <map
    id="map"
    class="map"
    latitude="{{latitude}}"
    longitude="{{longitude}}"
    markers="{{markers}}"
    show-location="true"
  >
    <!-- cover-view 覆盖在地图上：顶部标题条 -->
    <cover-view class="map-header">
      <cover-view class="map-title">当前门店：中心店</cover-view>
      <cover-view class="map-sub">营业时间 09:00-22:00</cover-view>
    </cover-view>

    <!-- 地图底部操作条：cover-image 用图片图标 -->
    <cover-view class="map-footer">
      <cover-image class="icon" src="/assets/nav.png" bindtap="onNavigate" />
      <cover-view class="btn" bindtap="onCall">拨打电话</cover-view>
    </cover-view>
  </map>

  <!-- 视频上的封面覆盖：视频播放前显示封面与播放按钮 -->
  <video class="video" src="{{videoSrc}}">
    <cover-view class="video-cover" wx:if="{{!playing}}" bindtap="onPlay">
      <cover-image class="play-btn" src="/assets/play.png" />
      <cover-view class="cover-text">点击播放</cover-view>
    </cover-view>
  </video>
</view>
```

```js
// pages/map/map.js
Page({
  data: {
    latitude: 39.9042,
    longitude: 116.4074,
    markers: [
      { id: 1, latitude: 39.9042, longitude: 116.4074, title: '中心店' },
    ],
    videoSrc: 'https://example.com/video.mp4',
    playing: false,
  },
  onNavigate() {
    wx.openLocation({
      latitude: this.data.latitude,
      longitude: this.data.longitude,
      name: '中心店',
    })
  },
  onCall() {
    wx.makePhoneCall({ phoneNumber: '400-800-0000' })
  },
  onPlay() {
    this.setData({ playing: true })
  },
})
```

```text
cover-view 要点：
1. 覆盖对象 —— 原生组件（map/video/canvas/camera/live-player 等）之上的文本容器
2. cover-image —— 覆盖在原生组件之上的图片，与 cover-view 配套使用
3. 子元素 —— cover-view 内可放 cover-view/cover-image/button 等少量组件，嵌套从基础库 2.1.0 起支持
4. 样式受限 —— cover-view 支持的 CSS 能力有限（如部分动画、flex 细节），复杂布局建议保持简单
5. 同层渲染 —— 基础库 2.4.4+ 的 video/map 支持同层渲染，普通 view 也能覆盖，但 cover-view 兼容性最稳
6. 事件 —— 支持 bindtap 等常规事件，点击覆盖层不会穿透到原生组件
```

```text
组件属性与事件速查：
1. 通用模式 —— 展示类属性直接写在标签上（autoplay/circular），变化类属性绑定 data（current/scroll-top）
2. 事件 —— 以 bind 开头（bindchange/bindscroll/bindtap），事件对象 e.detail 携带组件数据
3. 受控组件 —— swiper 的 current、scroll-view 的 scroll-top、movable-view 的 x/y 都是受控属性
4. data-* 传参 —— 事件中通过 e.currentTarget.dataset 读取自定义属性
5. 默认值 —— 每个组件都有默认值，先查文档再自定义，避免重复配置
6. 版本 —— 部分属性（refresher 系列等）有基础库版本要求，用 wx.canIUse 检测
```

## 应用场景实战

### 场景一：电商首页（轮播图 + 商品列表触底加载 + 下拉刷新）

综合使用 swiper、scroll-view 与 view 的完整首页：

```wxml
<!-- pages/home/home.wxml -->
<wxs src="../../utils/goods.wxs" module="g" />

<scroll-view
  class="home-scroll"
  scroll-y="true"
  refresher-enabled="true"
  refresher-triggered="{{refreshing}}"
  bindrefresherrefresh="onRefresh"
  bindscrolltolower="onLoadMore"
>
  <!-- 顶部轮播 -->
  <swiper
    class="banner"
    autoplay="true"
    interval="3000"
    circular="true"
    indicator-dots="true"
    indicator-active-color="#ff5000"
    bindchange="onBannerChange"
  >
    <swiper-item wx:for="{{banners}}" wx:key="id">
      <image class="banner-img" src="{{item.imageUrl}}" mode="aspectFill" data-link="{{item.link}}" bindtap="onBannerTap" />
    </swiper-item>
  </swiper>

  <!-- 金刚区导航 -->
  <view class="nav-grid">
    <view class="nav-item" hover-class="nav-item-hover" wx:for="{{navs}}" wx:key="name" data-url="{{item.url}}" bindtap="onNavTap">
      <image class="nav-icon" src="{{item.icon}}" />
      <text class="nav-name">{{item.name}}</text>
    </view>
  </view>

  <!-- 商品列表：数据一次 setData，价格由 wxs 格式化 -->
  <view class="goods-list">
    <view class="goods-item" hover-class="goods-item-hover" wx:for="{{goods}}" wx:key="id" data-id="{{item.id}}" bindtap="onGoodsTap">
      <image class="goods-img" src="{{item.image}}" mode="aspectFill" />
      <view class="goods-info">
        <view class="goods-name">{{item.name}}</view>
```

## 最佳实践与踩坑记录

### 最佳实践

1. 页面滚动优先用页面滚动：整页滚动时用页面自身能力（onPageScroll/onReachBottom），scroll-view 只用于局部区域滚动，避免双滚动嵌套
2. scroll-view 竖向滚动必须设高度：用固定值或 100vh/calc 计算高度，内容超出才产生滚动，这是最常见的「滚动不了」原因
3. 轮播图高度自适应：swiper 高度固定，图片用 mode="aspectFill" 或提前获取图片宽高比计算 swiper 高度，防止图片拉伸变形
4. 受控属性要闭环：swiper 的 current、scroll-view 的 scroll-top 是受控属性，赋值后要在对应 bindchange/bindscroll 中同步回 data，否则会「跳回原位置」
5. 触底加载做好防重：bindscrolltolower 可能连续触发，用 loadingMore/hasMore 标志位拦截，避免重复请求
6. 下拉刷新要手动收尾：refresher 触发后必须把 refresher-triggered 置回 false，否则刷新动画一直转
7. cover-view 保持简单结构：cover-view 样式能力受限，覆盖层只放文字、简单按钮、图片，复杂布局放普通层
8. 列表性能关注渲染量：swiper-item、scroll-view 内的长列表全部渲染，数据量大时分页或使用虚拟列表方案

### 踩坑记录

```text
坑 1：scroll-view 设置 scroll-y 后仍然不能滚动
结论：内容超出容器高度，但页面无法滚动。
原因：scroll-view 没有固定高度，高度被内容撑开，永远没有溢出。
解法：给 scroll-view 显式设置高度（如 height: 100vh 或 calc(100vh - 导航栏高度)），再开启 scroll-y。

坑 2：swiper 轮播图被拉伸变形
结论：图片在 swiper 中显示被拉长或压扁。
原因：swiper 高度固定 150px，图片 mode 默认为 scaleToFill 强制拉伸铺满。
解法：图片设置 mode="aspectFill"（裁剪填充）或 mode="widthFix"（等比缩放），并按图片宽高比设置 swiper 高度。

坑 3：swiper 的 current 设置后自动跳回
结论：代码设置 current 切换到第 3 屏，很快又跳回第 1 屏。
原因：current 是受控属性，bindchange 中没有把 e.detail.current 同步回 data，渲染又把 current 重置。
解法：bindchange 中执行 this.setData({ current: e.detail.current })，保持受控值一致。

坑 4：下拉刷新动画一直转不停
结论：refresher 下拉刷新后 loading 动画持续显示。
原因：触发 bindrefresherrefresh 后没有把 refresher-triggered 置回 false。
解法：数据加载完成后 this.setData({ refreshing: false })；失败分支也要复位，否则需要手动下拉才能恢复。

坑 5：bindscrolltolower 疯狂触发重复请求
结论：列表底部连续请求多个分页数据。
原因：触底事件在滚动停止前可能连续触发多次，且没有防重。
解法：加 loadingMore 与 hasMore 双重判断，请求中与无更多数据时直接 return。

坑 6：movable-view 拖不动或超出区域
结论：movable-view 无法拖动，或拖出可视区域。
原因：movable-area 未设置宽高（默认 0 或内容尺寸）；或 movable-view 尺寸超出 area 导致边界异常。
解法：movable-area 显式设置宽高；movable-view 尺寸不要大于 area；direction 按需设置 all/horizontal/vertical。

坑 7：普通 view 无法覆盖在地图/视频上
结论：map 上的按钮、标题条被原生组件盖住，点击不到。
原因：map/video 是原生组件，层级天然高于 WebView 内的普通 view。
解法：覆盖层改用 cover-view/cover-image；基础库 2.4.4+ 的 video/map 支持同层渲染，可逐步迁移到普通 view。

坑 8：hover-class 点击态不生效
结论：给 view 写了 hover-class，点击没有任何反馈。
原因：hover-class 写的类名在 wxss 中不存在，或写在了不支持 hover 属性的组件上。
解法：确认 hover-class 对应样式已定义；hover 只支持 view、button 等组件；检查 hover-start-time 是否过大。

坑 9：scroll-into-view 锚点跳转无效
结论：scroll-into-view 指定子元素 id，滚动没有发生。
原因：目标 id 的元素不在 scroll-view 内部，或 id 拼写不一致；scroll-view 未开启 scroll-y。
解法：确保目标元素是 scroll-view 的直接子节点且 id 唯一；滚动前把 scroll-into-view 置空再赋值，触发重新滚动。

坑 10：bindchange 中请求接口导致死循环
结论：swiper bindchange 里请求接口并 setData，页面不断切换、请求不断。
原因：setData 引起重渲染，重渲染又触发 bindchange，形成循环。
解法：bindchange 只同步 current 与做轻量操作；接口请求用节流或仅在 source 为 touch 时触发。
```
