## 概述

导航与媒体组件解决两类问题：页面之间的跳转（navigator）和多媒体内容的展示（image、video、audio、camera、live-player）。navigator 与 wx 路由 API 一一对应，是声明式的跳转方案；image 是页面里出现频率最高的媒体组件；video 与 audio 承载音视频播放；camera 提供扫码与拍摄；live-player 用于直播拉流。这类组件的共性是部分组件为原生组件（video、camera、live-player），存在层级与渲染特性，需要理解同层渲染与 cover-view 的配合。

```text
导航与媒体组件一览：
1. navigator —— 声明式页面跳转，open-type 对应 navigate/redirect/switchTab/reLaunch/navigateBack
2. image —— 图片展示，mode 控制缩放模式，支持懒加载与 webp
3. video/audio —— 视频与音频播放，video 为原生组件，audio 组件已废弃改用 API
4. camera —— 相机组件，支持拍照、录像与扫码模式
5. live-player —— 直播拉流组件，配合 cover-view 做界面覆盖
6. 通用注意 —— 媒体资源需 HTTPS 且域名加入合法域名白名单
```

## navigator 导航组件

navigator 是声明式的路由跳转组件，点击后执行跳转，等价于对应 wx API。open-type 决定跳转方式：navigate（默认，保留当前页入栈，页面栈最多 10 层）、redirect（关闭当前页再跳转）、switchTab（跳 tabBar 页面）、reLaunch（关闭所有页面重新打开）、navigateBack（返回上一页，delta 控制步数）。跳转时的点击态用 hover-class 控制。需要注意 switchTab 不能携带 query 参数，页面栈超过 10 层时 navigateTo 会失败。

```wxml
<!-- pages/navigator-demo/navigator-demo.wxml -->
<view class="nav-list">
  <!-- 普通跳转：压栈，目标页可返回 -->
  <navigator
    url="/pages/detail/detail?id=1001&from=list"
    hover-class="nav-hover"
    class="nav-item"
  >
    商品详情（navigate 压栈）
  </navigator>

  <!-- 重定向：关闭当前页，不能返回本页 -->
  <navigator url="/pages/login/login" open-type="redirect" hover-class="nav-hover" class="nav-item">
    登录页（redirect 关闭当前页）
  </navigator>

  <!-- 跳 tabBar 页面：不能带参数 -->
  <navigator url="/pages/home/home" open-type="switchTab" hover-class="nav-hover" class="nav-item">
    首页（switchTab）
  </navigator>

  <!-- 重新启动：关闭所有页面 -->
  <navigator url="/pages/index/index" open-type="reLaunch" hover-class="nav-hover" class="nav-item">
    重新进入首页（reLaunch）
  </navigator>

  <!-- 返回上一页 -->
  <navigator open-type="navigateBack" delta="1" hover-class="nav-hover" class="nav-item">
    返回上一页（navigateBack）
  </navigator>

  <!-- 退出小程序：基础库 2.17.3+ -->
  <navigator open-type="exit" hover-class="nav-hover" class="nav-item">
    退出小程序（exit）
  </navigator>
</view>
```

```js
// pages/navigator-demo/navigator-demo.js
Page({
  onLoad(query) {
    // navigator 跳转带过来的参数在这里接收
    console.log('query:', query) // { id: '1001', from: 'list' }
  },

  // 跳转前需要做判断的（比如未登录去登录）用 wx API 更灵活
  onGoOrder() {
    if (!wx.getStorageSync('token')) {
      wx.navigateTo({ url: '/pages/login/login' })
      return
    }
    wx.navigateTo({ url: '/pages/order/order' })
  }
})
```

```text
navigator 组件要点：
1. open-type —— navigate/redirect/switchTab/reLaunch/navigateBack/exit，与 wx 路由 API 对应
2. url —— 跳转路径，可带 query；页面 onLoad(query) 接收
3. 页面栈 —— navigate 最多 10 层，超出需 navigateBack 或 redirect
4. switchTab —— 跳 tabBar 页，url 不能带参数；tabBar 页面在 app.json 中声明
5. navigateBack —— delta 为返回层数，默认 1；不能返回则直接退出当前页栈
6. hover-class —— 跳转点击态样式，navigator 也支持 hover-start-time/hover-stay-time
```

## image 图片组件

image 是媒体组件的核心，它的关键属性是 mode——缩放模式决定了图片在容器内的呈现方式：scaleToFill（默认，拉伸填满，会变形）、aspectFit（完整显示，可能留白）、aspectFill（裁剪填满，不变形，封面首选）、widthFix（宽度固定，高度自适应，长图首选）。lazy-load 开启懒加载提升列表性能，webp 属性开启 webp 解码支持，binderror/bindload 处理加载失败与成功回调。image 有默认尺寸（320px × 240px），不设置宽高时按默认尺寸渲染。

```wxml
<!-- pages/image-demo/image-demo.wxml -->
<view class="img-section">
  <view class="section-title">封面图（aspectFill 裁剪填满，商品/新闻封面标准姿势）</view>
  <image
    class="cover-img"
    src="{{coverUrl}}"
    mode="aspectFill"
    lazy-load="true"
    binderror="onImgError"
    bindload="onImgLoad"
  />

  <view class="section-title">详情长图（widthFix 宽度固定高度自适应）</view>
  <image class="long-img" src="{{detailImg}}" mode="widthFix" />

  <view class="section-title">原图完整展示（aspectFit 等比缩放，留白）</view>
  <image class="fit-img" src="{{coverUrl}}" mode="aspectFit" />
</view>
```

```js
// pages/image-demo/image-demo.js
Page({
  data: {
    coverUrl: 'https://cdn.example.com/images/cover.png',
    detailImg: 'https://cdn.example.com/images/detail.png',
    fallbackUrl: '/assets/images/img-error.png'
  },

  onImgError(e) {
    // 加载失败：替换为本地占位图，避免裂图
    const dataset = e.currentTarget.dataset
    this.setData({ [dataset.key]: this.data.fallbackUrl })
  },

  onImgLoad(e) {
    // e.detail.width / e.detail.height 为图片实际尺寸，可用于自适应布局
    console.log('图片加载完成', e.detail.width, e.detail.height)
  }
})
```

```text
image 组件要点：
1. mode —— scaleToFill（默认拉伸）/ aspectFit（完整留白）/ aspectFill（裁剪填满）/ widthFix（宽定高自适应）
2. 默认尺寸 —— 320px × 240px，业务中务必显式设置宽高，否则布局漂移
3. lazy-load —— 页面滚动到可视区域附近才加载，列表场景必开
4. webp —— 基础库 2.9.0+，开启后支持 webp 格式解码
5. 事件 —— bindload 加载成功（可拿真实宽高）、binderror 加载失败（换占位图）
6. 域名 —— 图片地址需 HTTPS 且域名加入 downloadFile 合法域名
```

## video 与 audio 音视频组件

video 是视频播放组件，支持 controls 原生控件、autoplay 自动播放、poster 封面、object-fit 填充模式，并暴露 bindplay/bindpause/bindended/bindtimeupdate/binderror 等完整生命周期事件。video 是原生组件，基础库 2.4.4+ 支持同层渲染后可以覆盖普通 view；低版本需要 cover-view 覆盖。关于缓存：video 组件不提供本地缓存 API，重复播放同一地址依赖微信内置缓存策略，需要离线播放时应先用 wx.downloadFile 下载到本地临时路径再播放。audio 是旧版音频组件，自基础库 1.6.0 起不再维护，官方推荐使用 wx.createInnerAudioContext API 播放音频。

```wxml
<!-- pages/video-demo/video-demo.wxml -->
<view class="video-page">
  <!-- 视频播放器：同层渲染后普通 view 可以覆盖在上面 -->
  <view class="video-wrap">
    <video
      id="courseVideo"
      class="video-player"
      src="{{videoUrl}}"
      poster="{{posterUrl}}"
      controls="true"
      autoplay="false"
      loop="false"
      muted="false"
      object-fit="contain"
      show-center-play-btn="true"
      bindplay="onPlay"
      bindpause="onPause"
      bindended="onEnded"
      bindtimeupdate="onTimeUpdate"
      binderror="onVideoError"
    />
    <!-- 同层渲染后，普通 view 可覆盖在视频上做角标 -->
    <view class="video-badge" wx:if="{{isVip}}">VIP 专享</view>
  </view>

  <!-- 音频播放：audio 组件已废弃，用 wx.createInnerAudioContext -->
  <view class="audio-box" bindtap="onToggleAudio">
    <text>{{audioPlaying ? '暂停' : '播放'}} 课程音频</text>
    <text class="audio-time">{{audioTime}}</text>
  </view>
</view>
```

```js
// pages/video-demo/video-demo.js
Page({
  data: {
    videoUrl: 'https://cdn.example.com/videos/course01.mp4',
    posterUrl: 'https://cdn.example.com/images/poster.png',
    isVip: true,
    audioPlaying: false,
    audioTime: '00:00'
  },

  onLoad() {
    // 创建音频上下文：替代废弃的 audio 组件
    this.audioCtx = wx.createInnerAudioContext()
    this.audioCtx.src = 'https://cdn.example.com/audios/course01.mp3'
    this.audioCtx.onPlay(() => this.setData({ audioPlaying: true }))
    this.audioCtx.onPause(() => this.setData({ audioPlaying: false }))
    this.audioCtx.onEnded(() => this.setData({ audioPlaying: false, audioTime: '00:00' }))
    this.audioCtx.onTimeUpdate(() => {
      const t = Math.floor(this.audioCtx.currentTime)
      this.setData({ audioTime: this.formatTime(t) })
    })
    this.audioCtx.onError((err) => {
      wx.showToast({ title: '音频播放失败', icon: 'none' })
      console.error('audio error:', err)
    })
  },

  formatTime(seconds) {
    const m = String(Math.floor(seconds / 60)).padStart(2, '0')
    const s = String(seconds % 60).padStart(2, '0')
    return m + ':' + s
  },

  onToggleAudio() {
    if (this.audioCtx.paused) {
      this.audioCtx.play()
    } else {
      this.audioCtx.pause()
    }
  },

  // 通过 wx.createVideoContext 控制视频
  onReplay() {
    const ctx = wx.createVideoContext('courseVideo')
    ctx.seek(0)
    ctx.play()
  },

  onPlay() { console.log('video play') },
  onPause() { console.log('video pause') },
  onEnded() {
    // 播放结束：记录学习进度，提示用户
    wx.showToast({ title: '本节学习完成', icon: 'success' })
  },
  onTimeUpdate(e) {
    // e.detail.currentTime / e.detail.duration，节流后再上报进度
  },
  onVideoError(e) {
    wx.showToast({ title: '视频加载失败', icon: 'none' })
  },

  onUnload() {
    // 必须销毁音频上下文，释放资源
    if (this.audioCtx) this.audioCtx.destroy()
  }
})
```

```text
video/audio 要点：
1. video 属性 —— src/controls/autoplay/loop/muted/poster/object-fit/show-center-play-btn
2. video 事件 —— bindplay/bindpause/bindended/bindtimeupdate/binderror，控制用 createVideoContext
3. 同层渲染 —— 基础库 2.4.4+ 后 video 支持同层渲染，普通 view 可覆盖；低版本用 cover-view
4. 视频缓存 —— 组件不提供本地缓存 API，离线播放需 wx.downloadFile 下载到临时路径再播
5. audio 组件 —— 1.6.0 起废弃，一律使用 wx.createInnerAudioContext
6. 资源释放 —— innerAudioContext 用完必须 destroy()，onUnload 中清理，防止后台继续播放
```

## camera 与 live-player 相机与直播组件

camera 是相机组件，mode 支持 normal（普通拍照/录像）与 scanCode（扫码）两种模式，flash 控制闪光灯（auto/on/off/torch），拍照用 wx.createCameraContext().takePhoto，录像用 startRecord/stopRecord。mode="scanCode" 时摄像头自动识别二维码与小程序码，识别结果通过 bindscancode 回调。live-player 是直播拉流组件，src 接收 rtmp/https-flv 等拉流地址，mode 为 live 或 RTC，直播需要在小程序后台申请直播类目资质。两者都是原生组件，界面覆盖一律使用 cover-view/cover-image。

```wxml
<!-- pages/camera-demo/camera-demo.wxml -->
<view class="camera-page">
  <!-- 扫码模式：自动识别二维码/小程序码 -->
  <camera
    wx:if="{{scanMode}}"
    class="camera-box"
    mode="scanCode"
    flash="{{flash}}"
    bindscancode="onScanCode"
    binderror="onCameraError"
  >
    <cover-view class="scan-tip">将二维码放入框内</cover-view>
  </camera>

  <!-- 拍照模式 -->
  <camera
    wx:else
    class="camera-box"
    mode="normal"
    flash="{{flash}}"
    device-position="back"
    frame-size="medium"
  >
    <cover-view class="flash-btn" bindtap="onToggleFlash">{{flash === 'on' ? '关灯' : '开灯'}}</cover-view>
    <cover-view class="shoot-btn" bindtap="onTakePhoto">拍照</cover-view>
  </camera>

  <!-- 直播拉流（需直播类目资质） -->
  <!--
  <view class="live-wrap">
    <live-player
      class="live-player"
      src="{{liveUrl}}"
      mode="live"
      autoplay="true"
      min-cache="1"
      max-cache="3"
      bindstatechange="onLiveState"
      binderror="onLiveError"
    >
      <cover-view class="live-label">LIVE</cover-view>
    </live-player>
  </view>
  -->
</view>
```

```js
// pages/camera-demo/camera-demo.js
Page({
  data: {
    scanMode: false,
    flash: 'off'
  },

  // 创建相机上下文：拍照/录像
  onTakePhoto() {
    const ctx = wx.createCameraContext()
    ctx.takePhoto({
      quality: 'high',
      success: (res) => {
        // res.tempImagePath 为临时图片路径，可预览或上传
        wx.previewImage({ urls: [res.tempImagePath] })
      },
      fail: (err) => {
        wx.showToast({ title: '拍照失败，请检查相机权限', icon: 'none' })
        console.error(err)
      }
    })
  },

  onToggleFlash() {
    this.setData({ flash: this.data.flash === 'on' ? 'off' : 'on' })
  },

  // 扫码模式回调
  onScanCode(e) {
    // e.detail.result 为二维码内容，可用于扫码跳转、核销等业务
    const result = e.detail.result
    wx.showModal({
      title: '识别结果',
      content: result,
      showCancel: false
    })
  },

  onCameraError(e) {
    // 常见原因：未授权相机权限、模拟器不支持
    wx.showModal({
      title: '相机不可用',
      content: '请检查相机权限或使用真机调试',
      showCancel: false
    })
  },

  onLiveState(e) {
    // e.detail.code: 2001 连接中 / 2002 已连接 / 2003 重连 / 2004 播放结束
    console.log('live state:', e.detail.code)
  },

  onLiveError(e) {
    wx.showToast({ title: '直播加载失败', icon: 'none' })
    console.error('live error:', e.detail.errMsg)
  }
})
```

```text
camera/live-player 要点：
1. camera mode —— normal 拍照录像 / scanCode 自动扫码，bindscancode 返回识别结果
2. 拍摄 API —— wx.createCameraContext().takePhoto / startRecord / stopRecord
3. 权限 —— 相机需用户授权（scope.camera），且要在隐私协议中声明用途
4. live-player —— 直播拉流组件，src 为 rtmp/https-flv 地址，mode 为 live/RTC
5. 资质 —— 直播需申请直播类目资质，拉流地址一般由后台动态生成（防盗链）
6. 覆盖 —— camera/live-player 均为原生组件，界面元素用 cover-view/cover-image
```

## 应用场景实战

### 场景一：视频课程列表与详情（图片列表 + 导航跳转 + 视频播放）

列表页用 image + lazy-load 展示课程封面，navigator 跳转详情页，详情页用 video 播放课程视频并记录学习进度。

```wxml
<!-- pages/course-list/course-list.wxml -->
<view class="course-list">
  <navigator
    class="course-item"
    hover-class="item-hover"
    wx:for="{{courses}}"
    wx:key="id"
    url="/pages/course-detail/course-detail?id={{item.id}}"
  >
    <image class="course-cover" src="{{item.cover}}" mode="aspectFill" lazy-load="true" />
    <view class="course-info">
      <text class="course-name">{{item.name}}</text>
      <view class="course-meta">
        <text class="course-lessons">{{item.lessonCount}} 课时</text>
        <text class="course-price">¥{{item.price}}</text>
      </view>
    </view>
  </navigator>
  <view class="list-bottom">{{hasMore ? '上拉加载更多' : '没有更多了'}}</view>
</view>
```

```js
// pages/course-list/course-list.js
Page({
  data: {
    courses: [
      {
        id: 1,
        name: '小程序基础语法精讲',
        cover: 'https://cdn.example.com/images/course1.png',
        lessonCount: 20,
        price: '0.00'
      },
      {
        id: 2,
        name: '全栈项目实战',
        cover: 'https://cdn.example.com/images/course2.png',
        lessonCount: 45,
        price: '199.00'
      }
    ],
    hasMore: false
  }
})
```

```wxml
<!-- pages/course-detail/course-detail.wxml -->
<view class="detail-page">
  <video
    id="lessonVideo"
    class="detail-video"
    src="{{videoUrl}}"
    poster="{{coverUrl}}"
    controls="true"
    bindended="onLessonEnded"
    bindtimeupdate="onTimeUpdate"
  />
  <view class="lesson-info">
    <text class="lesson-title">{{lessonName}}</text>
    <text class="lesson-progress">已学 {{progressPercent}}%</text>
    <progress percent="{{progressPercent}}" stroke-width="4" activeColor="#ff5000" />
  </view>
  <button class="replay-btn" type="primary" plain="true" bindtap="onReplay">重新播放</button>
</view>
```

```js
// pages/course-detail/course-detail.js
Page({
  data: {
    videoUrl: 'https://cdn.example.com/videos/lesson01.mp4',
    coverUrl: 'https://cdn.example.com/images/lesson1.png',
    lessonName: '第 1 课：认识小程序',
    progressPercent: 0
  },

  onLoad(query) {
    // 真实项目：根据 query.id 请求课程详情，拿到 videoUrl
    console.log('course id:', query.id)
  },

  onTimeUpdate(e) {
    // 播放进度上报：节流后提交后台（如每 10 秒一次）
    const { currentTime, duration } = e.detail
    if (duration > 0) {
      const percent = Math.min(100, Math.floor((currentTime / duration) * 100))
      this.setData({ progressPercent: percent })
    }
  },

  onLessonEnded() {
    // 学习完成：上报后台，解锁下一课
    wx.showToast({ title: '本节学完，太棒了', icon: 'success' })
  },

  onReplay() {
    const ctx = wx.createVideoContext('lessonVideo')
    ctx.seek(0)
    ctx.play()
  }
})
```

### 场景二：门店扫码核销页（camera 扫码 + 结果反馈）

门店场景用 camera 扫码模式核销订单：扫到码后校验、提示结果，失败时提示错误原因。

```wxml
<!-- pages/scan-verify/scan-verify.wxml -->
<view class="scan-page">
  <camera
    class="scan-camera"
    mode="scanCode"
    flash="{{flash}}"
    bindscancode="onScanCode"
    binderror="onCameraError"
  >
    <cover-view class="scan-frame">对准订单二维码</cover-view>
    <cover-view class="flash-toggle" bindtap="onToggleFlash">
      {{flash === 'on' ? '关闭闪光灯' : '开启闪光灯'}}
    </cover-view>
  </camera>
  <view class="scan-result" wx:if="{{resultText}}">
    <text>{{resultText}}</text>
  </view>
</view>
```

```js
// pages/scan-verify/scan-verify.js
Page({
  data: {
    flash: 'off',
    resultText: '',
    scanning: false
  },

  onToggleFlash() {
    this.setData({ flash: this.data.flash === 'on' ? 'off' : 'on' })
  },

  onScanCode(e) {
    if (this.data.scanning) return
    this.setData({ scanning: true })
    const code = e.detail.result
    // 真实项目：把 code 发给后台核销接口
    wx.request({
      url: 'https://api.example.com/order/verify',
      method: 'POST',
      data: { code },
      success: (res) => {
        if (res.data.code === 0) {
          this.setData({ resultText: '核销成功：' + res.data.data.orderNo })
          wx.vibrateShort({ type: 'medium' })
        } else {
          this.setData({ resultText: res.data.msg || '核销失败' })
        }
      },
      complete: () => {
        // 间隔 2 秒后可继续扫下一单
        setTimeout(() => this.setData({ scanning: false }), 2000)
      }
    })
  },

  onCameraError() {
    wx.showModal({
      title: '无法使用相机',
      content: '请在设置中允许使用相机权限',
      confirmText: '去设置',
      success: (res) => {
        if (res.confirm) wx.openSetting()
      }
    })
  }
})
```

## 最佳实践与踩坑记录

### 最佳实践

1. 页面跳转统一用 navigator 声明式写法，需要条件判断（登录态、权限）时改用 wx.navigateTo，避免模板里写死逻辑
2. image 必须显式设置宽高，封面统一 aspectFill，详情长图用 widthFix，列表开启 lazy-load
3. 图片加载失败统一走 binderror 替换本地占位图，避免大量裂图影响观感
4. 音视频地址统一使用 CDN + HTTPS，域名提前加入 downloadFile 合法域名白名单，避免上线后临时改域名
5. video 控制用 wx.createVideoContext，播放结束（bindended）后 seek(0) 重置再播，避免状态错乱
6. 音频一律用 wx.createInnerAudioContext，onUnload 中 destroy 释放，防止页面退出后仍播放
7. 相机扫码场景加 scanning 防重，避免同一二维码连续触发多次核销
8. camera/live-player 等原生组件上的交互元素使用 cover-view，不依赖同层渲染特性写普通 view

### 踩坑记录

```text
坑 1：switchTab 跳转带参数丢失
结论：navigator 的 url 带了 query 跳 tabBar 页面，目标页 onLoad 收不到参数。
原因：switchTab 跳转规则不支持携带参数，微信会忽略 query。
解法：tabBar 页面间传参用全局变量、Storage 或事件总线；或先跳普通页再 switchTab。

坑 2：navigateTo 页面栈超过 10 层跳转失败
结论：连续跳转十几层后，再点击跳转无反应或报「navigateTo:fail webview count limit exceed」。
原因：页面栈最多 10 层，navigateTo 是压栈操作，超出上限失败。
解法：深层流程改用 redirect（关当前页）或 reLaunch；返回用 navigateBack，避免无限压栈。

坑 3：image 显示变形或被拉伸
结论：图片被拉成奇怪比例，或封面显示不全。
原因：mode 默认 scaleToFill 会拉伸填满容器；不同场景选错 mode。
解法：封面/列表图用 aspectFill（裁剪填满不变形），完整展示用 aspectFit，长图用 widthFix。

坑 4：image 加载报 downloadFile 域名不合法
结论：图片区域空白，控制台报「url not in domain list」。
原因：image 网络图属于 downloadFile 范畴，域名未加入合法域名白名单，且要求 HTTPS。
解法：mp 后台「开发管理-开发设置-服务器域名」添加 downloadFile 合法域名；本地开发可在工具中勾选「不校验合法域名」。

坑 5：video 遮挡普通 view，按钮点不到
结论：视频上方的按钮、角标显示不出来或点击无效。
原因：低版本基础库 video 是原生组件，层级高于 WebView 内容。
解法：基础库升级到 2.4.4+ 使用同层渲染；或覆盖元素改用 cover-view/cover-image。

坑 6：bindended 后再 play 视频黑屏
结论：视频播放结束后点击「重播」，画面黑屏只有声音或直接无反应。
原因：播放结束后内部状态未重置，直接 play 不会从头播放。
解法：重播前先 ctx.seek(0) 再 ctx.play()；或在 ended 回调里统一 seek(0)。

坑 7：还在用 audio 组件播放，真机无声音
结论：audio 组件在部分真机或新基础库上无法播放、无声。
原因：audio 组件自基础库 1.6.0 起已废弃，不再维护，新版本行为不保证。
解法：改用 wx.createInnerAudioContext，并在 onUnload 中 destroy；后台播放需配置 requiredBackgroundModes。

坑 8：camera 在模拟器黑屏或报错
结论：开发者工具中 camera 一片黑，或直接报错不可用。
原因：camera 依赖真机摄像头，模拟器不支持；权限未授权时同样不可用。
解法：用真机调试；首次使用引导用户授权相机权限；隐私协议中声明相机用途。

坑 9：live-player 拉流失败或黑屏
结论：直播画面一直加载/黑屏，bindstatechange 报错误码。
原因：拉流地址过期（rtmp 防盗链有时效）、网络不支持、类目资质未通过、https-flv 与 rtmp 兼容问题。
解法：拉流地址由后台实时生成并加签名；切换 rtmp/https-flv 协议测试；确认直播类目已开通。

坑 10：视频/音频在 iOS 上无法自动播放
结论：autoplay 设置 true，iOS 上仍不自动播放。
原因：iOS 对媒体自动播放有限制，尤其是无声音媒体与 WebView 内媒体。
解法：引导用户点击播放；muted 视频可自动播；首帧渲染后由用户手势触发播放。
```
