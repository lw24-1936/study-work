## 概述

开放能力组件是微信生态能力的载体：open-data 展示微信开放数据，web-view 内嵌 H5 网页，map 提供腾讯地图渲染，canvas 提供 2D 绘制能力，ad 承载广告流量，official-account 引导关注公众号。它们共同的特点是「部分能力受资质与场景约束」——web-view 需要配置业务域名，ad 需要开通流量主，official-account 仅在特定进入场景下展示。掌握这些约束，才能在业务接入时少走弯路。

```text
开放能力组件一览：
1. open-data —— 展示群名称、用户昵称头像等微信开放数据（仅展示）
2. web-view —— 承载 H5 网页的容器，需配置业务域名，页面全屏
3. map —— 腾讯地图组件，markers/polyline/regionchange 等能力
4. canvas —— 画布组件，type="2d" 新接口绘制海报、图表
5. ad —— 广告组件（banner/激励视频），需开通流量主
6. official-account —— 公众号关注组件，仅「扫码普通链接进入」场景展示
```

## open-data 开放数据组件

open-data 用于展示微信侧的开放数据，type 决定展示内容：userNickName（昵称）、userAvatarUrl（头像）、userGender（性别）、userCity/userProvince/userCountry（城市/省份/国家）、groupName（群名称）。它只能「展示」不能「读取」——数据无法通过 JS 拿到，样式也无法自定义（组件内数据由微信渲染）。需要特别注意两点：groupName 只有用户从群聊中打开小程序时才有值；2021 年隐私政策调整后，用户昵称头像的获取官方推荐改用头像昵称填写能力（chooseAvatar + nickname 输入框），open-data 的展示能力也在逐步收紧。

```wxml
<!-- pages/open-data-demo/open-data-demo.wxml -->
<view class="user-card">
  <!-- 展示用户头像昵称：样式由微信渲染，无法自定义 -->
  <open-data type="userAvatarUrl" class="user-avatar" />
  <open-data type="userNickName" class="user-name" />
  <open-data type="userGender" class="user-meta" />
</view>

<view class="group-card" wx:if="{{fromGroup}}">
  <!-- 仅当用户从群聊中打开小程序时，groupName 才有内容 -->
  <open-data type="groupName" class="group-name" />
</view>
```

```js
// pages/open-data-demo/open-data-demo.js
Page({
  data: { fromGroup: false },
  onLoad(query) {
    // 场景值 1044 等表示从微信群聊中打开
    const scene = Number(query.scene || 0)
    this.setData({ fromGroup: scene === 1044 || scene === 1047 })
  }
})
```

```text
open-data 组件要点：
1. type —— userNickName/userAvatarUrl/userGender/userCity/userProvince/userCountry/groupName
2. 只展示 —— 组件内数据由微信渲染，JS 拿不到，无法用于提交表单
3. groupName —— 仅用户从群聊打开小程序时才有值，其他场景为空
4. 样式限制 —— 组件内部渲染结构不可控，外部样式只影响容器
5. 政策变化 —— 2021 年后官方推荐头像昵称填写能力获取昵称头像
6. 个人主体 —— 部分开放数据能力（如 groupName）在个人主体下不可用
```

## web-view 网页容器组件

web-view 是承载 H5 网页的原生容器，铺满整个页面，一个页面只能放一个 web-view。它的核心约束在域名：只能加载配置过的「业务域名」下的页面，业务域名要求 HTTPS、ICP 备案，并在 mp 后台添加验证。web-view 与小程序页面是互斥关系，页面中放 web-view 后不能再放其他组件。网页内部可以通过微信 JS-SDK（wx.miniProgram）调用小程序的 navigateTo、switchTab、reLaunch、navigateBack 与 postMessage，实现 H5 与小程序的双向通信。

```wxml
<!-- pages/webview-page/webview-page.wxml -->
<!-- 承载 H5 页面：全屏铺满，页面内不能有其他组件 -->
<web-view
  src="{{webUrl}}"
  bindmessage="onWebMessage"
  bindload="onWebLoad"
  binderror="onWebError"
/>
```

```js
// pages/webview-page/webview-page.js
Page({
  data: {
    // 业务域名：必须在 mp 后台「业务域名」中配置并放置校验文件
    webUrl: 'https://h5.example.com/activity/detail?id=1001&token=' + wx.getStorageSync('token')
  },

  // H5 通过 wx.miniProgram.postMessage 发消息，小程序在特定时机收到
  onWebMessage(e) {
    // e.detail.data 为 H5 postMessage 的数据数组
    const data = e.detail.data || []
    if (data[0] && data[0].type === 'share') {
      // 网页请求小程序侧执行分享等动作
      wx.showShareMenu()
    }
  },

  onWebLoad() {
    console.log('web-view 加载完成')
  },

  onWebError(e) {
    // 常见：域名未配置、页面非 HTTPS、域名未备案
    wx.showToast({ title: '页面加载失败', icon: 'none' })
    console.error('web-view error:', e.detail)
  }
})
```

```html
<!-- H5 页面中引入微信 JS-SDK（示例） -->
<script src="https://res.wx.qq.com/open/js/jweixin-1.3.2.js"></script>
<script>
  // 网页内跳转到小程序页面
  wx.miniProgram.navigateTo({ url: '/pages/detail/detail?id=200' })

  // 网页向小程序发送消息（小程序侧在 bindmessage 中接收）
  wx.miniProgram.postMessage({ data: { type: 'share', title: '活动页' } })
</script>
```

```text
web-view 组件要点：
1. 全屏容器 —— 铺满页面，一个页面只能有一个 web-view，且不能与其他组件共存
2. 业务域名 —— 只能加载 mp 后台配置的业务域名，要求 HTTPS + ICP 备案 + 校验文件
3. JS-SDK —— 网页内通过 wx.miniProgram.navigateTo/postMessage 与小程通信
4. bindmessage —— 网页 postMessage 后，小程序在后退、分享、销毁时收到消息
5. 认证要求 —— 个人主体小程序使用 web-view 受限，建议企业主体
6. 使用策略 —— 活动页、复杂表单、既有 H5 迁移用 web-view；核心流程尽量原生实现
```

## map 地图组件

map 是基于腾讯地图的原生组件，longitude/latitude 定义中心点，scale 控制缩放级别（3-20），markers 渲染标记点（可配 title、iconPath、callout 气泡、label 标签），polyline 绘制路线，show-location 显示用户位置，bindmarkertap/bindregionchange 监听交互。标记点图标 iconPath 支持本地路径与网络路径（网络路径需在 downloadFile 域名白名单内）。map 组件本身不需要申请 key，但 wx.getLocation 等定位 API 需要在后台声明用途并配置隐私协议。

```wxml
<!-- pages/map-demo/map-demo.wxml -->
<view class="map-page">
  <map
    class="map-box"
    longitude="{{centerLng}}"
    latitude="{{centerLat}}"
    scale="{{scale}}"
    markers="{{markers}}"
    polyline="{{polyline}}"
    show-location="true"
    enable-3D="false"
    bindmarkertap="onMarkerTap"
    bindregionchange="onRegionChange"
  >
    <!-- 原生组件覆盖层：标题栏、按钮用 cover-view -->
    <cover-view class="map-header">门店位置</cover-view>
  </map>

  <view class="store-panel" wx:if="{{currentStore}}">
    <text class="store-name">{{currentStore.name}}</text>
    <text class="store-address">{{currentStore.address}}</text>
    <button class="nav-btn" bindtap="onOpenNavi">导航前往</button>
  </view>
</view>
```

```js
// pages/map-demo/map-demo.js
Page({
  data: {
    centerLng: 120.153576,
    centerLat: 30.287459,
    scale: 13,
    currentStore: null,
    markers: [
      {
        id: 1,
        latitude: 30.287459,
        longitude: 120.153576,
        title: '旗舰店',
        iconPath: '/assets/images/marker.png',
        width: 32,
        height: 32,
        callout: {
          content: '旗舰店（营业中）',
          color: '#333333',
          fontSize: 12,
          borderRadius: 4,
          bgColor: '#ffffff',
          padding: 6,
          display: 'BYCLICK'
        }
      },
      {
        id: 2,
        latitude: 30.274,
        longitude: 120.155,
        title: '体验店',
        iconPath: '/assets/images/marker.png',
        width: 32,
        height: 32
      }
    ],
    polyline: [
      {
        points: [
          { longitude: 120.153576, latitude: 30.287459 },
          { longitude: 120.155, latitude: 30.274 }
        ],
        color: '#10aeff',
        width: 4,
        dottedLine: false
      }
    ]
  },

  onMarkerTap(e) {
    // e.detail.markerId 为点击的标记点 id
    const marker = this.data.markers.find((m) => m.id === e.detail.markerId)
    if (marker) this.setData({ currentStore: marker })
  },

  onRegionChange(e) {
    // 拖拽地图时触发：e.type 为 begin/end
    if (e.type === 'end') {
      console.log('地图视野变化结束', e.detail)
    }
  },

  onOpenNavi() {
    const store = this.data.currentStore
    // 打开微信内置导航：跳转腾讯地图/微信位置
    wx.openLocation({
      latitude: store.latitude,
      longitude: store.longitude,
      name: store.title,
      scale: 18
    })
  }
})
```

```text
map 组件要点：
1. 定位 —— longitude/latitude 中心点、scale 缩放级别（3-20）
2. markers —— 标记点数组：id/latitude/longitude/title/iconPath/callout/label
3. 交互 —— bindmarkertap（点标记）、bindregionchange（视野变化）、bindpoitap（点地图 POI）
4. 覆盖层 —— map 是原生组件，标题栏/按钮用 cover-view/cover-image
5. 定位 API —— wx.getLocation 需后台声明用途 + 隐私协议，个人主体受限
6. 图标 —— marker 的 iconPath 网络图需 downloadFile 域名白名单，建议本地图标
```

## canvas 画布组件

canvas 提供绘图能力，用于生成分享海报、绘制图表、电子签名、图片合成等。旧版 canvas（canvas-id + wx.createCanvasContext）已不推荐，官方推荐 type="2d" 的新接口：通过 wx.createSelectorQuery 获取 canvas 节点（node），再 getContext('2d') 使用标准 Canvas 2D API 绘制。绘制完成后用 wx.canvasToTempFilePath 导出图片，配合 wx.saveImageToPhotosAlbum 保存到相册。网络图片不能直接 drawImage，必须先用 wx.getImageInfo 或 wx.downloadFile 转成本地路径。

```wxml
<!-- pages/canvas-demo/canvas-demo.wxml -->
<view class="canvas-page">
  <!-- type="2d" 新版画布：尺寸通过 style 控制 -->
  <canvas type="2d" id="posterCanvas" class="poster-canvas" />
  <button type="primary" bindtap="onGenerate">生成海报</button>
  <button plain="true" bindtap="onSave">保存到相册</button>
  <image wx:if="{{posterPath}}" class="poster-preview" src="{{posterPath}}" mode="widthFix" />
</view>
```

```js
// pages/canvas-demo/canvas-demo.js
Page({
  data: { posterPath: '', canvasWidth: 0, canvasHeight: 0 },

  onReady() {
    // 获取画布节点与尺寸（rpx 转 px）
    const query = wx.createSelectorQuery()
    query.select('#posterCanvas').fields({ node: true, size: true }).exec((res) => {
      const canvas = res[0].node
      const ctx = canvas.getContext('2d')
      this.canvas = canvas
      this.ctx = ctx
      // 设置画布实际像素尺寸（与显示尺寸一致，保证清晰度）
      canvas.width = res[0].width
      canvas.height = res[0].height
      this.setData({ canvasWidth: res[0].width, canvasHeight: res[0].height })
    })
  },

  async onGenerate() {
    const { ctx, canvas } = this
    const { canvasWidth: w, canvasHeight: h } = this.data

    // 绘制背景
    ctx.fillStyle = '#ffffff'
    ctx.fillRect(0, 0, w, h)

    // 绘制标题
    ctx.fillStyle = '#333333'
    ctx.font = 'bold 28px sans-serif'
    ctx.textAlign = 'center'
    ctx.fillText('我的分享海报', w / 2, 60)

    // 绘制二维码：网络图片必须先下载到本地
    const qrPath = await this.loadLocalImage('https://cdn.example.com/images/qr.png')
    const img = canvas.createImage()
    img.onload = () => {
      ctx.drawImage(img, w / 2 - 75, 120, 150, 150)
      // 导出图片
      wx.canvasToTempFilePath({
        canvas,
        success: (res) => this.setData({ posterPath: res.tempFilePath })
      })
    }
    img.src = qrPath
  },

  // 把网络图片转成本地路径（wx.getImageInfo 亦可）
  loadLocalImage(url) {
    return new Promise((resolve, reject) => {
      wx.downloadFile({
        url,
        success: (res) => resolve(res.tempFilePath),
        fail: reject
      })
    })
  },

  onSave() {
    if (!this.data.posterPath) return wx.showToast({ title: '请先生成海报', icon: 'none' })
    // 保存相册需要 scope.writePhotosAlbum 授权
    wx.saveImageToPhotosAlbum({
      filePath: this.data.posterPath,
      success: () => wx.showToast({ title: '已保存到相册', icon: 'success' }),
      fail: (err) => {
        if (err.errMsg.indexOf('auth') > -1) {
          wx.showModal({
            title: '需要相册权限',
            content: '请在设置中允许保存到相册',
            confirmText: '去设置',
            success: (res) => { if (res.confirm) wx.openSetting() }
          })
        }
      }
    })
  }
})
```

```text
canvas 组件要点：
1. 新接口 —— canvas type="2d" + createSelectorQuery 获取 node，getContext('2d') 绘制
2. 旧接口 —— canvas-id + wx.createCanvasContext 已不推荐，新项目一律用 2d 类型
3. 尺寸 —— canvas 的宽高通过 style 设置，绘制前手动把 node.width/height 对齐显示尺寸
4. 网络图片 —— drawImage 前必须下载到本地（downloadFile/getImageInfo）
5. 导出 —— wx.canvasToTempFilePath 导出临时图片，保存相册需 writePhotosAlbum 授权
6. 性能 —— 海报生成放在 onReady 后执行，避免页面未就绪拿不到节点
```

## ad 广告组件与 official-account 公众号关注组件

ad 组件承载微信广告，最常用两种形态：banner 广告（ad unit-id）与激励式视频广告（ad unit-id + ad-type="video"），插屏广告用 wx.createInterstitialAd API 创建。使用 ad 的前提是开通流量主：小程序累计独立访客达到 1000 后可在 mp 后台申请，广告位在「流量主」模块创建并拿到 unit-id；开发者工具中可使用官方测试广告位验证。official-account 是公众号关注组件，基础库 2.3.0+ 支持，但它有严格场景限制：仅当用户通过「扫普通链接二维码打开小程序」进入时才展示，且该公众号需与小程序同主体或已关联，一个页面只能放一个。

```wxml
<!-- pages/ad-demo/ad-demo.wxml -->
<view class="ad-page">
  <!-- banner 广告：unit-id 来自流量主后台创建的广告位 -->
  <!-- 开发者工具中可用官方测试 unit-id（adunit-xxxxxxxxxxxxxxxx 测试位） -->
  <ad
    wx:if="{{showAd}}"
    unit-id="{{bannerUnitId}}"
    ad-intervals="30"
    binderror="onAdError"
    bindload="onAdLoad"
  />

  <!-- 激励视频广告：看广告得奖励，配合按钮触发 -->
  <button class="reward-btn" type="primary" bindtap="onWatchRewardVideo">
    观看视频领优惠券
  </button>

  <!-- 公众号关注组件：仅「扫码普通链接打开小程序」场景展示 -->
  <official-account bindload="onOfficialLoad" binderror="onOfficialError" />
</view>
```

```js
// pages/ad-demo/ad-demo.js
Page({
  data: {
    bannerUnitId: 'adunit-xxxxxxxxxxxxxxxx', // 正式环境替换为流量主后台广告位
    showAd: false
  },

  onLoad() {
    // 广告位加载失败/无广告时不展示，不影响主流程
    this.setData({ showAd: true })
  },

  onAdLoad() {
    console.log('广告加载成功')
  },

  onAdError(e) {
    // 常见原因：unit-id 未配置、流量主未开通、类目不支持广告
    console.warn('广告加载失败', e.detail)
    this.setData({ showAd: false })
  },

  onWatchRewardVideo() {
    // 激励视频广告：用 API 方式创建
    const videoAd = wx.createRewardedVideoAd({ adUnitId: 'adunit-xxxxxxxxxxxxxx' })
    videoAd.onLoad(() => console.log('激励视频加载成功'))
    videoAd.onError((err) => {
      wx.showToast({ title: '广告加载失败，请稍后再试', icon: 'none' })
    })
    videoAd.onClose((res) => {
      if (res && res.isEnded) {
        // 完整观看：发放奖励（真实项目需后台校验广告回调）
        wx.showToast({ title: '奖励已发放', icon: 'success' })
      } else {
        wx.showToast({ title: '看完视频才能领奖哦', icon: 'none' })
      }
    })
    videoAd.show().catch(() => {
      videoAd.load().then(() => videoAd.show())
    })
  },

  onOfficialLoad() {
    // 组件加载成功（满足展示条件）
    console.log('official-account 展示')
  },

  onOfficialError() {
    // 场景不满足（非扫码普通链接进入）时组件自动隐藏，无需处理
    console.log('official-account 不可展示')
  }
})
```

```text
ad / official-account 要点：
1. ad 形态 —— banner 广告（ad unit-id）、激励视频（ad-type="video"）、插屏（wx.createInterstitialAd）
2. 流量主 —— 累计独立访客 ≥ 1000 可开通，广告位在 mp 后台创建获取 unit-id
3. 测试 —— 开发者工具与体验版可用官方测试广告位，正式环境必须替换真实 unit-id
4. 容错 —— 广告加载失败直接隐藏，bindload/binderror 双监听，不影响主流程
5. official-account —— 仅「扫普通链接二维码打开小程序」场景展示，需公众号同主体或已关联
6. 限制 —— 一个页面只能放一个 official-account；广告类目受小程序类目限制
```

## 应用场景实战

### 场景一：门店查询与导航页（map + markers + 导航）

结合 map 与 wx.openLocation 的门店查询页：地图标注多家门店，点击标记点弹出门店信息，一键导航。

```wxml
<!-- pages/stores/stores.wxml -->
<view class="stores-page">
  <map
    class="stores-map"
    longitude="{{centerLng}}"
    latitude="{{centerLat}}"
    scale="12"
    markers="{{markers}}"
    show-location="true"
    bindmarkertap="onMarkerTap"
  >
    <cover-view class="map-title">{{storeCount}} 家门店</cover-view>
  </map>

  <view class="store-list">
    <view
      class="store-item"
      hover-class="item-hover"
      wx:for="{{stores}}"
      wx:key="id"
      data-id="{{item.id}}"
      bindtap="onSelectStore"
    >
      <view class="store-name">{{item.name}}</view>
      <view class="store-address">{{item.address}}</view>
      <button class="nav-btn" size="mini" type="primary" data-id="{{item.id}}" catchtap="onGoNavi">导航</button>
    </view>
  </view>
</view>
```

```js
// pages/stores/stores.js
Page({
  data: {
    centerLng: 120.153576,
    centerLat: 30.287459,
    storeCount: 0,
    stores: [],
    markers: []
  },

  onLoad() {
    // 真实项目：wx.request 拉取门店列表
    const stores = [
      { id: 1, name: '旗舰店', address: '西湖区文三路 100 号', longitude: 120.153576, latitude: 30.287459 },
```

### 场景二：营销活动页（web-view 活动 H5 + 分享海报生成）

组合 web-view 与 canvas：活动主体用 web-view 承载 H5 页面，H5 通过 postMessage 请求小程序生成分享海报，海报由 canvas 绘制并保存相册。

```wxml
<!-- pages/activity/activity.wxml -->
<view class="activity-page">
  <web-view
    wx:if="{{showWeb}}"
    src="{{webUrl}}"
    bindmessage="onWebMessage"
  />

  <!-- 海报生成层：H5 触发后展示 -->
  <view class="poster-layer" wx:if="{{showPoster}}">
    <canvas type="2d" id="shareCanvas" class="share-canvas" />
    <view class="poster-actions">
      <button type="primary" bindtap="onSavePoster">保存到相册</button>
      <button plain="true" bindtap="onClosePoster">关闭</button>
    </view>
  </view>
</view>
```

```js
// pages/activity/activity.js
Page({
  data: {
    webUrl: 'https://h5.example.com/activity/2026',
    showWeb: true,
    showPoster: false,
    posterPath: ''
  },

  // H5 通过 wx.miniProgram.postMessage 发来的消息
  onWebMessage(e) {
    const data = e.detail.data || []
    if (data[0] && data[0].type === 'openPoster') {
      this.openPoster()
    }
  },

  openPoster() {
    this.setData({ showPoster: true })
    // 等 canvas 渲染完成后绘制
    setTimeout(() => this.drawPoster(), 100)
  },

  drawPoster() {
    const query = wx.createSelectorQuery()
    query.select('#shareCanvas').fields({ node: true, size: true }).exec((res) => {
      if (!res[0]) return
      const canvas = res[0].node
      const ctx = canvas.getContext('2d')
      const w = (canvas.width = res[0].width)
      const h = (canvas.height = res[0].height)

      // 背景
      ctx.fillStyle = '#ff5000'
      ctx.fillRect(0, 0, w, h)
      // 主文案
      ctx.fillStyle = '#ffffff'
      ctx.font = 'bold 30px sans-serif'
      ctx.textAlign = 'center'
      ctx.fillText('邀请好友一起瓜分红包', w / 2, h / 2 - 30)
      ctx.font = '18px sans-serif'
      ctx.fillText('长按识别二维码参与', w / 2, h / 2 + 40)

      wx.canvasToTempFilePath({
        canvas,
        success: (r) => this.setData({ posterPath: r.tempFilePath })
      })
    })
  },

  onSavePoster() {
    if (!this.data.posterPath) return wx.showToast({ title: '海报生成中', icon: 'none' })
    wx.saveImageToPhotosAlbum({
      filePath: this.data.posterPath,
      success: () => wx.showToast({ title: '已保存', icon: 'success' }),
      fail: () => {
        wx.showModal({
          title: '需要相册权限',
          content: '请在设置中允许保存到相册',
          confirmText: '去设置',
          success: (res) => { if (res.confirm) wx.openSetting() }
        })
      }
    })
  },

  onClosePoster() {
    this.setData({ showPoster: false, posterPath: '' })
  }
})
```

## 最佳实践与踩坑记录

### 最佳实践

1. web-view 业务域名提前配置并放置校验文件，上线前用真机验证；活动页参数（token）拼进 URL 时注意签名与过期
2. map 的 markers 图标优先用本地资源（iconPath 本地路径），网络图标依赖 downloadFile 域名，排查成本高
3. canvas 一律使用 type="2d" 新接口，海报/图表绘制封装成公共方法，统一处理尺寸换算（rpx 转 px）
4. canvas 绘制网络图片先下载到本地再 drawImage，绘制完成后再导出，避免空白海报
5. ad 组件做容错：bindload/binderror 监听，失败即隐藏；激励视频发放奖励前后台校验广告回调凭证
6. official-account 组件不满足场景时自动隐藏，页面照常开发，无需为其做特殊布局
7. 开放数据（open-data）仅用于展示；需要把昵称头像用于业务存储时，改用头像昵称填写能力
8. 原生组件（map/canvas/web-view）的覆盖元素统一 cover-view，避免层级问题在不同机型上表现不一致

### 踩坑记录

```text
坑 1：open-data 拿不到用户昵称头像用于业务
结论：想用 open-data 的昵称头像提交后台，发现 JS 层拿不到数据。
原因：open-data 是微信侧渲染的展示组件，数据不进入小程序逻辑层。
解法：展示场景用 open-data；业务存储用 chooseAvatar + type="nickname" 让用户主动提供。

坑 2：web-view 白屏或提示「域名不合法」
结论：web-view 加载页面一直白屏，控制台提示域名未配置。
原因：web-view 只允许加载业务域名白名单内的 HTTPS 页面，且域名需 ICP 备案并放置校验文件。
解法：mp 后台「开发管理-业务域名」添加域名并下载校验文件放到站点根目录；确认页面为 HTTPS；个人主体受限时升级企业主体。

坑 3：web-view 里调用 wx API 报错
结论：H5 页面里写 wx.navigateTo 等调用，控制台报「wx is not defined」。
原因：网页没有引入微信 JS-SDK（jweixin），或引入方式不对。
解法：页面引入 https://res.wx.qq.com/open/js/jweixin-1.3.2.js，且只能在 web-view 容器内使用 wx.miniProgram 系列接口。

坑 4：map 不显示或定位到默认坐标
结论：地图空白，或一直显示默认经纬度，没有定位到用户位置。
原因：未授权定位权限（scope.userLocation）、隐私协议未声明定位用途、show-location 需配合授权。
解法：wx.getLocation 前检查授权；在隐私协议中声明定位用途；用 wx.getLocation 成功后 setData 中心点坐标。

坑 5：markers 的图标不显示
结论：标记点位置有占位但图标空白，或整组 markers 不渲染。
原因：iconPath 使用了网络路径但域名未加入 downloadFile 白名单，或图标路径拼写错误。
解法：图标放本地 static 目录；必须用网络图时先配置 downloadFile 合法域名。

坑 6：canvas 用旧接口画不出内容
结论：canvas-id + createCanvasContext 绘制，真机上内容空白或报错。
原因：旧版 canvas 接口在基础库 2.9.0 后不再推荐，部分新机型渲染异常。
解法：改用 <canvas type="2d"> + createSelectorQuery 获取 node + getContext('2d') 标准 API。

坑 7：canvas 绘制网络图片失败（空白/报错）
结论：drawImage 传网络图片地址，海报上图片位置空白。
原因：canvas 绘制不允许直接使用网络图片，图片未加载完成无法绘制。
解法：先用 wx.downloadFile 或 wx.getImageInfo 获取本地临时路径，再用 canvas.createImage 加载后绘制。

坑 8：广告位一直不展示
结论：ad 组件区域空白，没有任何广告。
原因：流量主未开通、unit-id 为测试位在正式版无效、类目不支持广告、广告填充率低。
解法：确认流量主已开通且广告位审核通过；正式版使用真实 unit-id；错误时监听 binderror 打印 errCode 对照文档排查。

坑 9：official-account 组件不显示
结论：页面上放了 official-account，但始终看不到关注组件。
原因：组件仅在「扫普通链接二维码打开小程序」场景进入时才展示，其他入口一律隐藏。
解法：确认进入场景；公众号需与小程同主体或已关联；无需特殊处理，不满足条件时组件自动隐藏。

坑 10：wx.canvasToTempFilePath 导出空白图
结论：保存到相册的图片是空白或只有背景色。
原因：导出时机早于绘制完成（异步绘制未结束就导出），或 canvas 节点尺寸为 0。
解法：在图片 onload 回调内、绘制全部完成后调用导出；canvas 显式设置宽高且 node.width/height 与显示尺寸一致。
```
