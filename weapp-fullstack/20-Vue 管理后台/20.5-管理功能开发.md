## 概述

本章把前四章的知识串成真实业务功能：登录页（表单校验 + 登录请求 + token 存储 + 跳转）、用户管理（列表 + 分页 + 搜索 + 弹窗表单 + 删除确认）、数据表格进阶（操作列、状态列、格式化、多选）、表单开发（校验规则、动态表单、文件上传）以及 ECharts 图表集成（折线图、柱状图、饼图）。这些是管理后台最高频的功能形态，掌握后即可举一反三覆盖商品、订单、角色等所有管理模块。

```text
管理功能开发要点：
1. 登录页 —— el-form 校验 + 登录请求 + token 持久化 + redirect 回跳
2. 用户管理 —— 查询/新增/编辑/删除四件套，是 CRUD 页面的标准范式
3. 数据表格 —— el-table 列配置、操作列、状态列、格式化与多选
4. 表单 —— el-form 校验规则、动态表单、文件上传 el-upload
5. 图表 —— ECharts 按需引入，折线/柱状/饼图对接接口数据
6. 复用模式 —— 列表页「搜索区 + 表格 + 分页 + 弹窗表单」一套模板打天下
```

## 登录页开发

登录页是后台的第一道门面，功能链路：表单校验 -> 调用登录接口 -> token 存入 store 并持久化 -> 拉取用户信息 -> 跳转（优先回 redirect 来源页）。el-form 的 rules 负责非空与格式校验，校验通过才发请求；按钮 loading 防止重复提交；密码框用 show-password 支持明文切换。登录成功后跳转逻辑要与路由守卫的 redirect 参数配合（20.3）。

```vue
<!-- src/views/login/index.vue —— 完整登录页 -->
<template>
  <div class="login-page">
    <div class="login-card">
      <h2 class="login-title">商城管理后台</h2>
      <el-form
        ref="formRef"
        :model="form"
        :rules="rules"
        label-position="top"
        size="large"
        @keyup.enter="handleLogin"
      >
        <el-form-item label="用户名" prop="username">
          <el-input v-model="form.username" placeholder="请输入用户名" :prefix-icon="User" />
        </el-form-item>

        <el-form-item label="密码" prop="password">
          <el-input
            v-model="form.password"
            type="password"
            placeholder="请输入密码"
            show-password
            :prefix-icon="Lock"
          />
        </el-form-item>

        <el-button
          type="primary"
          class="login-btn"
          :loading="loading"
          @click="handleLogin"
        >
          {{ loading ? '登录中...' : '登 录' }}
        </el-button>
      </el-form>
    </div>
  </div>
</template>

<script setup lang="ts">
import { reactive, ref } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { User, Lock } from '@element-plus/icons-vue'
import { useUserStore } from '@/stores/user'
import type { FormInstance, FormRules } from 'element-plus'

const formRef = ref<FormInstance>()
const loading = ref(false)

const form = reactive({
  username: '',
  password: ''
})

// 校验规则：required + message + trigger
const rules: FormRules = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 3, max: 20, message: '用户名长度 3-20 个字符', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { min: 6, max: 32, message: '密码长度 6-32 个字符', trigger: 'blur' }
  ]
}

const userStore = useUserStore()
const route = useRoute()
const router = useRouter()

async function handleLogin() {
  // 1. 校验失败不继续
  const valid = await formRef.value?.validate().catch(() => false)
  if (!valid) return

  loading.value = true
  try {
    // 2. 登录：token 存入 store 并持久化
    await userStore.loginAction({ username: form.username, password: form.password })
    // 3. 拉取用户信息与权限（守卫中会补拉，这里保证登录页直接可用）
    await userStore.fetchUserInfo()
    // 4. 跳转：优先回到被拦截前的页面
    const redirect = (route.query.redirect as string) || '/'
    router.replace(redirect)
  } catch {
    // 错误已由 axios 拦截器统一提示，这里只需保持页面状态
  } finally {
    loading.value = false
  }
}
</script>

<style scoped>
.login-page {
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
  background: linear-gradient(135deg, #1f3b73 0%, #2f54eb 100%);
}

.login-card {
  width: 380px;
  padding: 40px 32px;
  background: var(--el-bg-color);
  border-radius: 8px;
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}

.login-title {
  margin-bottom: 24px;
  text-align: center;
  color: var(--el-text-color-primary);
}

.login-btn {
  width: 100%;
  margin-top: 8px;
}
</style>
```

```text
登录页要点：
1. 校验先行 —— validate 通过才发请求，空值与格式错误不请求后端
2. loading 防重 —— 请求期间按钮禁用，防止连点重复提交
3. token 持久化 —— store + localStorage 双写，刷新后登录态保持
4. redirect 回跳 —— 登录后回到被拦截页面，提升体验
5. 密码交互 —— show-password 切换明文，回车键提交
6. 错误提示 —— 登录失败由拦截器统一弹出，页面不重复处理
```

## 用户管理 CRUD 实战

用户管理是后台 CRUD 的标准范式，页面结构固定为四层：搜索区（关键字、状态下拉）-> 工具栏（新增按钮）-> 表格（列表数据）-> 分页。新增/编辑共用一个 el-dialog + el-form（弹窗内表单），通过 dialog 的 title 与表单赋值区分模式；删除用 ElMessageBox.confirm 二次确认。这个范式可以原样复制到角色、商品、订单等任何管理模块。

```vue
<!-- src/views/system/user/index.vue —— 用户管理完整实现 -->
<template>
  <div class="page-container">
    <!-- 1. 搜索区 -->
    <el-form :inline="true" :model="query" class="search-form">
      <el-form-item label="关键字">
        <el-input
          v-model="query.keyword"
          placeholder="用户名/昵称/手机号"
          clearable
          @keyup.enter="handleSearch"
        />
      </el-form-item>
      <el-form-item label="状态">
        <el-select v-model="query.status" placeholder="全部" clearable style="width: 120px">
          <el-option label="启用" :value="1" />
          <el-option label="禁用" :value="0" />
        </el-select>
      </el-form-item>
      <el-form-item>
        <el-button type="primary" :icon="Search" @click="handleSearch">查询</el-button>
        <el-button :icon="Refresh" @click="handleReset">重置</el-button>
      </el-form-item>
    </el-form>

    <!-- 2. 工具栏 -->
    <div class="table-toolbar">
      <el-button v-permission="'system:user:add'" type="primary" :icon="Plus" @click="openDialog()">
        新增用户
      </el-button>
    </div>

    <!-- 3. 数据表格 -->
    <el-table :data="rows" v-loading="loading" stripe border>
      <el-table-column prop="id" label="ID" width="70" />
      <el-table-column prop="username" label="用户名" min-width="120" />
      <el-table-column prop="nickname" label="昵称" min-width="120" />
      <el-table-column prop="phone" label="手机号" width="130" />
      <el-table-column label="状态" width="90">
        <template #default="{ row }">
          <StatusTag :status="row.status" :map="statusMap" />
        </template>
      </el-table-column>
      <el-table-column prop="createTime" label="创建时间" width="170" />
      <el-table-column label="操作" width="180" fixed="right">
        <template #default="{ row }">
          <el-button v-permission="'system:user:edit'" link type="primary" @click="openDialog(row)">
            编辑
          </el-button>
          <el-button v-permission="'system:user:delete'" link type="danger" @click="handleDelete(row)">
            删除
          </el-button>
        </template>
      </el-table-column>
    </el-table>

    <!-- 4. 分页 -->
    <AppPagination :total="total" @change="loadData" />

    <!-- 5. 新增/编辑弹窗 -->
    <el-dialog
      v-model="dialogVisible"
      :title="dialogTitle"
      width="520px"
      :close-on-click-modal="false"
      @closed="handleDialogClosed"
    >
      <el-form ref="dialogFormRef" :model="dialogForm" :rules="dialogRules" label-width="90px">
        <el-form-item label="用户名" prop="username">
          <el-input v-model="dialogForm.username" placeholder="请输入用户名" :disabled="isEdit" />
        </el-form-item>
        <el-form-item label="昵称" prop="nickname">
          <el-input v-model="dialogForm.nickname" placeholder="请输入昵称" />
        </el-form-item>
        <el-form-item label="手机号" prop="phone">
          <el-input v-model="dialogForm.phone" placeholder="请输入手机号" />
        </el-form-item>
        <el-form-item v-if="!isEdit" label="密码" prop="password">
          <el-input v-model="dialogForm.password" type="password" show-password placeholder="请输入初始密码" />
        </el-form-item>
        <el-form-item label="状态" prop="status">
          <el-radio-group v-model="dialogForm.status">
            <el-radio :value="1">启用</el-radio>
            <el-radio :value="0">禁用</el-radio>
          </el-radio-group>
        </el-form-item>
      </el-form>

      <template #footer>
        <el-button @click="dialogVisible = false">取消</el-button>
        <el-button type="primary" :loading="saving" @click="handleSave">保存</el-button>
      </template>
    </el-dialog>
  </div>
</template>

<script setup lang="ts">
import { computed, reactive, ref } from 'vue'
import { Search, Refresh, Plus } from '@element-plus/icons-vue'
import { ElMessage, ElMessageBox } from 'element-plus'
import type { FormInstance, FormRules } from 'element-plus'
import { listUser, createUser, updateUser, deleteUser } from '@/api/user'
import type { UserItem } from '@/api/user'
import AppPagination from '@/components/AppPagination.vue'
import StatusTag from '@/components/StatusTag.vue'

// ---------- 查询 ----------
const rows = ref<UserItem[]>([])
const total = ref(0)
const loading = ref(false)

const query = reactive({
  keyword: '',
  status: undefined as number | undefined,
  page: 1,
  pageSize: 10
})

const statusMap = {
  1: { label: '启用', type: 'success' },
  0: { label: '禁用', type: 'danger' }
} as const

async function loadData(page = 1, pageSize = 10) {
  query.page = page
  query.pageSize = pageSize
  loading.value = true
  try {
    const res = await listUser({ ...query })
    rows.value = res.rows
    total.value = res.total
  } finally {
    loading.value = false
  }
}

function handleSearch() {
  loadData(1, query.pageSize)
}

function handleReset() {
  query.keyword = ''
  query.status = undefined
  loadData(1, query.pageSize)
}

// ---------- 新增/编辑 ----------
const dialogVisible = ref(false)
const saving = ref(false)
const isEdit = ref(false)
const currentId = ref<number | null>(null)
const dialogFormRef = ref<FormInstance>()

const dialogForm = reactive({
  username: '',
  nickname: '',
  phone: '',
  password: '',
  status: 1
})

const dialogTitle = computed(() => (isEdit.value ? '编辑用户' : '新增用户'))

const dialogRules: FormRules = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 3, max: 20, message: '长度 3-20 个字符', trigger: 'blur' }
  ],
  phone: [
    { pattern: /^1[3-9]\d{9}$/, message: '手机号格式不正确', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入初始密码', trigger: 'blur' },
    { min: 6, message: '密码至少 6 位', trigger: 'blur' }
  ]
}

// row 为空 -> 新增；有值 -> 编辑（回填表单）
function openDialog(row?: UserItem) {
  isEdit.value = Boolean(row)
  currentId.value = row?.id ?? null
  Object.assign(dialogForm, {
    username: row?.username ?? '',
    nickname: row?.nickname ?? '',
    phone: row?.phone ?? '',
    password: '',
    status: row?.status ?? 1
  })
  dialogVisible.value = true
}

async function handleSave() {
  const valid = await dialogFormRef.value?.validate().catch(() => false)
  if (!valid) return

  saving.value = true
  try {
    if (isEdit.value && currentId.value !== null) {
      await updateUser(currentId.value, { ...dialogForm })
      ElMessage.success('修改成功')
    } else {
      await createUser({ ...dialogForm })
      ElMessage.success('新增成功')
    }
    dialogVisible.value = false
    loadData()
  } finally {
    saving.value = false
  }
}

// 弹窗关闭后清空校验状态，避免下次打开残留红字
function handleDialogClosed() {
  dialogFormRef.value?.clearValidate()
}

// ---------- 删除 ----------
async function handleDelete(row: UserItem) {
  try {
    await ElMessageBox.confirm(`确定删除用户「${row.username}」吗？删除后不可恢复。`, '删除确认', {
      type: 'warning',
      confirmButtonText: '删除',
      cancelButtonText: '取消'
    })
  } catch {
    return // 用户取消
  }

  await deleteUser(row.id)
  ElMessage.success('删除成功')
  loadData()
}

loadData()
</script>
```

```text
用户管理要点：
1. 页面范式 —— 搜索区 + 工具栏 + 表格 + 分页 + 弹窗表单，五段式固定结构
2. 弹窗复用 —— 新增/编辑共用一个 dialog，靠 row 参数区分模式
3. 表单回填 —— 编辑时 Object.assign 回填，关闭后清空校验状态
4. 校验规则 —— 必填、长度、正则（手机号）按字段配置
5. 二次确认 —— 删除必须 ElMessageBox.confirm，取消不发请求
6. 权限指令 —— 新增/编辑/删除按钮挂 v-permission（20.3）
```

## 数据表格进阶

el-table 是后台最核心的组件，进阶用法包括：操作列（固定右侧、按钮组）、状态列（el-tag 映射）、格式化（金额、时间、枚举转换）、多选（selection 列 + 批量操作）、排序（sortable + 服务端排序）、展开行、空数据与加载状态。列配置用 prop 映射字段，需要加工的字段用 #default 插槽取 row 渲染。

```vue
  if (!value) return '-'

}

// 多选

  // 示例：重新按字段排序请求，order 为 ascending / descending / null
```

## 表单与文件上传

el-form 的表单能力：rules 校验（required、pattern、validator 自定义）、动态表单项（v-for 增删行）、文件上传（el-upload 对接后台接口）。校验规则支持 async-validator 全量能力，自定义校验用 validator 函数；动态表单典型场景是规格、SKU、配置项列表。el-upload 配置 action 或 http-request 自定义上传，配合文件列表、限制类型与大小、回显。

动态表单（可增删的表单项）：

```vue
<!-- src/views/product/form.vue —— 动态规格表单（片段） -->
<template>
  <el-form ref="formRef" :model="form" :rules="rules" label-width="100px">
    <el-form-item label="商品名称" prop="name">
      <el-input v-model="form.name" placeholder="请输入商品名称" />
    </el-form-item>

    <!-- 动态规格列表 -->
```

管理后台的数据看板离不开图表，ECharts 是事实标准。集成方式：npm 安装 echarts，按需引入（只引入用到的图表与组件）控制体积；封装一个通用 Chart 组件（接收 option、监听 resize）；数据对接：接口返回原始数据，页面组装成 ECharts 的 option 结构。常用图表：折线图（趋势）、柱状图（对比）、饼图（占比）。

通用图表组件（封装初始化、更新、销毁）：

```vue
<!-- src/components/BaseChart.vue —— ECharts 通用封装 -->
<template>
  <div ref="chartRef" class="base-chart" :style="{ height }"></div>
</template>

<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref, watch } from 'vue'
import * as echarts from 'echarts'

const props = defineProps<{
  option: echarts.EChartsOption
  height?: string
}>()

const chartRef = ref<HTMLElement>()
let chart: echarts.ECharts | null = null

onMounted(() => {
  chart = echarts.init(chartRef.value!)
  chart.setOption(props.option)
  // 窗口变化自适应
  window.addEventListener('resize', handleResize)
})

watch(
  () => props.option,
  (newOption) => {
    chart?.setOption(newOption)
  },
  { deep: true }
)

function handleResize() {
  chart?.resize()
}

onBeforeUnmount(() => {
  window.removeEventListener('resize', handleResize)
  chart?.dispose()
  chart = null
})
</script>

<style scoped>
.base-chart {
  width: 100%;
}
</style>
```

## 最佳实践与踩坑记录

### 最佳实践

1. 列表页统一「搜索区 + 工具栏 + 表格 + 分页 + 弹窗」五段式模板，新模块直接套用，团队代码风格一致
2. 弹窗表单与列表页拆成独立组件（Dialog 组件内部自管理表单），页面只留数据流，长页面可维护性翻倍
3. 所有枚举值（状态、类型）抽成映射表常量并配合 StatusTag，禁止在模板里散落 if/else 判断
4. 新增/编辑共用弹窗时，用 isEdit 标志 + Object.assign 回填，关闭后 clearValidate 防残留
5. 危险操作（删除、批量操作、禁用）一律二次确认；批量操作按钮在未选中时禁用
6. 表格列的格式化（金额、时间、枚举）收敛到统一工具函数或组件，金额展示格式全局一致
7. 图表数据由接口返回原始数据、页面组装 option，BaseChart 组件不感知业务
8. 上传文件先做类型与大小前置校验，所有上传走统一封装（自动带 token），回显路径存后台返回的 URL

### 踩坑记录

```text
坑 1：表单校验不触发或 validate 一直通过
结论：点保存直接发请求，空值也提交成功。
原因：rules 里 trigger 与表单交互时机不匹配（如 blur/change 写错）；或 el-form-item 的 prop 与 model 字段名不一致。
解法：prop 必须与 :model 的字段名完全一致；输入类用 trigger: 'blur'，选择类用 trigger: 'change'；必要时 validate 前先 clearValidate。

坑 2：el-dialog 关闭后再次打开，表单残留上次数据与校验红字
结论：第二次打开弹窗看到上次的输入和红字。
原因：dialog 默认销毁内容时机不对（destroy-on-close 未开），表单状态被缓存。
解法：el-dialog 加 destroy-on-close；或 @closed 中 Object.assign 重置表单并 formRef.clearValidate()。

坑 3：编辑弹窗回填后点保存，校验报「密码不能为空」
结论：编辑模式没有密码字段，但校验规则仍在执行。
原因：编辑时密码字段 v-if 隐藏，但 rules 中 password 的 required 仍在生效。
解法：编辑模式动态移除 password 规则（computed rules）；或密码框改为「留空则不修改」并去掉 required。

坑 4：el-table 多选跨页丢失 / selection-change 拿不到数据
结论：翻页后已选中的行消失。
原因：表格没有唯一 row-key，多选状态按行引用缓存，翻页数据替换后失效。
解法：el-table 加 :row-key="row => row.id"；如需跨页保留，自行维护 selectedIds 集合并在 selection-change 中合并。

坑 5：ECharts 图表不显示或高度为 0
结论：容器渲染了但图表空白。
原因：初始化时容器高度为 0（父级未定高）或 display: none 状态初始化。
解法：容器显式设置 height（组件 props.height 默认 320px）；弹窗/tab 中的图表在可见后再 init，或用 v-if 控制渲染时机后 nextTick init。

坑 6：图表在弹窗/折叠面板中宽度错乱
结论：弹窗打开后图表被拉伸或显示不全。
原因：容器由隐藏变为可见时宽度变化，图表未 resize。
解法：容器可见后调用 chart.resize()；或监听容器尺寸变化（ResizeObserver）统一触发 resize。

坑 7：el-upload 上传报 401 或 token 未携带
结论：图片上传失败，接口报未授权。
原因：el-upload 默认用 XMLHttpRequest 直发，不走 axios 实例，拦截器未注入 token。
解法：用 :http-request 自定义上传，内部走统一封装的 axios（FormData）；不要用默认 action 直传。

坑 8：上传后表单校验仍提示「请上传图片」
结论：图片已上传成功，保存时校验不过。
原因：cover 字段的 trigger 是 blur/change 之外的时机，或校验时字段还未赋值。
解法：上传成功回调里赋值 form.cover 后手动 formRef.validateField('cover')；trigger 用 'change'。

坑 9：图表内存泄漏，切页面后页面卡顿
结论：频繁进出看板页面，浏览器内存持续增长。
原因：图表实例未 dispose，resize 监听未移除。
解法：组件 onBeforeUnmount 中 chart.dispose() 并移除 resize 监听；BaseChart 组件统一管理生命周期。

坑 10：时间格式化显示 Invalid Date
结论：列表时间列显示 Invalid Date 或 NaN。
原因：后台返回的时间字符串格式（如 2026-08-20 11:30:00）在某些浏览器 new Date() 解析失败，或字段值为 null。
解法：统一用 dayjs 解析（dayjs('2026-08-20 11:30:00')）；格式化函数对空值返回 '-'；与后台约定统一时间格式（17.2）。
```
