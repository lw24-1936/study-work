## 概述

高级数据结构解决普通数组/链表/哈希表「动态查询」能力不足的问题：并查集处理连通性，树状数组/线段树处理区间查询与单点/区间修改，稀疏表做静态 RMQ，Trie 做字符串前缀检索，Treap/跳表提供有序集合与排名操作，可持久化结构支持历史版本查询。它们各有适用边界，选择正确的结构能把复杂度从 O(n) 降到 O(log n) 甚至 O(1)。

```text
高级数据结构的选型速查：
1. 连通性、集合合并 → Union Find（近似 O(1)）
2. 单点修改 + 区间求和 → Fenwick Tree（O(log n)，常数小）
3. 区间修改/最值/复杂聚合 → Segment Tree（O(log n)，功能全）
4. 静态区间最值（无修改）→ Sparse Table（O(1) 查询）
5. 字符串前缀检索 → Trie（O(L)，L 为串长）
6. 有序 + 排名/前驱后继 → Treap / Skip List（O(log n) 期望）
7. 历史版本查询 → Persistent Data Structure
```

```python
# 线段树（区间求和 + 单点修改）的数组实现骨架
class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.tree = [0] * (4 * self.n)
        self._build(data, 1, 0, self.n - 1)

    def _build(self, data, node, l, r):
        if l == r:
            self.tree[node] = data[l]
        else:
            mid = (l + r) // 2
            self._build(data, node * 2, l, mid)
            self._build(data, node * 2 + 1, mid + 1, r)
            self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]
```

## Union Find

并查集维护若干不相交集合，支持「查询元素所属集合」和「合并两个集合」两个操作。核心优化是路径压缩 + 按秩合并，使得均摊复杂度接近常数，是处理动态连通性、最小生成树、朋友关系等问题的利器。

```text
复杂度：
单次操作均摊 O(α(n))，α 为反阿克曼函数，实际视为常数
空间 O(n)

两个核心优化：
1. 路径压缩 —— find 时把沿途节点直接挂到根，摊平树高
2. 按秩合并 —— 合并时把小树挂到大树下，控制树高
```

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:                 # 按秩合并
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1

uf = UnionFind(5)
uf.union(0, 1); uf.union(1, 2)
print(uf.find(0) == uf.find(2))   # True，0 和 2 连通
```

## Fenwick Tree

树状数组（Binary Indexed Tree）用「二进制低位 1」组织区间，用 O(log n) 支持单点修改 + 前缀和查询。它比线段树常数更小、代码更短，是「单点改、前缀问」类问题的首选。

```text
复杂度：
单点修改 O(log n)，前缀和查询 O(log n)
空间 O(n)

核心操作（lowbit）：
lowbit(i) = i & (-i)，取出 i 最低位的 1
update：i += lowbit(i) 一路向上更新
query：i -= lowbit(i) 一路向前累加
```

```python
class FenwickTree:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1)

    def update(self, i, delta):          # 单点加 delta
        i += 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)

    def query(self, i):                  # 前 i 个元素前缀和
        s = 0
        while i > 0:
            s += self.tree[i]
            i -= i & (-i)
        return s

ft = FenwickTree(5)
for i, x in enumerate([1, 3, 5, 2, 4]):
    ft.update(i, x)
print(ft.query(3))                       # 1 + 3 + 5 = 9
```

## Segment Tree

线段树是平衡二叉树，每个节点代表一个区间，支持区间查询和区间修改（配合懒标记）。功能比树状数组全面——区间和、最值、异或、区间加、区间赋值都能做，是竞赛里最通用的区间结构。

```text
复杂度：
建树 O(n)，单点/区间操作 O(log n)
空间 O(4n)

懒标记（lazy propagation）：
区间修改不递归到底，只标记父节点；
下次访问子节点时再「下推」标记，摊薄修改成本
```

```python
class SegmentTreeFull:
    def __init__(self, data):
        self.n = len(data)
        self.tree = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self._build(data, 1, 0, self.n - 1)

    def _build(self, data, node, l, r):
        if l == r:
            self.tree[node] = data[l]
            return
        mid = (l + r) // 2
        self._build(data, node * 2, l, mid)
        self._build(data, node * 2 + 1, mid + 1, r)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]

    def range_add(self, ql, qr, val, node=1, l=0, r=None):
        if r is None:
            r = self.n - 1
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:
            self.tree[node] += val * (r - l + 1)
            self.lazy[node] += val
            return
        mid = (l + r) // 2
        self.range_add(ql, qr, val, node * 2, l, mid)
        self.range_add(ql, qr, val, node * 2 + 1, mid + 1, r)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]
```

## Sparse Table

稀疏表是「静态 RMQ（区间最值）」的专用结构：预处理所有长度为 2^k 的区间最值，查询时用两个重叠的 2 的幂区间覆盖目标区间，做到 O(1) 查询。只支持可重复贡献的运算（min/max/gcd），不支持修改。

```text
复杂度：
预处理 O(n log n)，单次查询 O(1)
空间 O(n log n)

适用限制：
1. 静态 —— 不支持修改
2. 可重复贡献 —— min/max/gcd 等，区间重叠不影响结果
```

```python
import math

class SparseTable:
    def __init__(self, nums):
        self.n = len(nums)
        self.log = [0] * (self.n + 1)
        for i in range(2, self.n + 1):
            self.log[i] = self.log[i // 2] + 1
        k = self.log[self.n] + 1
        self.st = [[0] * k for _ in range(self.n)]
        for i in range(self.n):
            self.st[i][0] = nums[i]
        for j in range(1, k):
            for i in range(self.n - (1 << j) + 1):
                self.st[i][j] = min(self.st[i][j - 1], self.st[i + (1 << (j - 1))][j - 1])

    def query_min(self, l, r):           # 闭区间 [l, r]
        j = self.log[r - l + 1]
        return min(self.st[l][j], self.st[r - (1 << j) + 1][j])
```

## Trie

Trie（字典树）用「边代表字符」的多叉树存储字符串集合，共享公共前缀，支持 O(L) 的插入、查询、前缀统计。常用于字符串检索、自动补全、异或最大值等场景。

```text
复杂度：
插入/查询 O(L)，L 为字符串长度
空间 O(总字符数 × 字母表大小)

节点设计：
1. children —— 指向子节点的映射（dict 或定长数组）
2. is_end —— 标记是否为某个单词的结尾
3. count —— 可选，统计经过该节点的串数
```

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

trie = Trie()
for w in ['apple', 'app', 'apply']:
    trie.insert(w)
print(trie.search('app'))     # True
print(trie.search('apx'))     # False
```

## Persistent Data Structure

可持久化数据结构保留每次修改前的历史版本，支持「查询任意历史版本」而不用整体复制。常见实现是「路径复制」：修改时只复制被改动的节点，其余共享旧版本，使每个版本占 O(log n) 额外空间。最典型的是可持久化线段树（主席树）。

```text
复杂度：
单次修改 O(log n)（只新建被修改路径上的节点）
单次历史查询 O(log n)
空间 O(n + m log n)，m 为修改次数

核心思想：
1. 路径复制 —— 修改沿根到叶的路径，每条路径新建一份节点
2. 版本指针 —— 每次修改返回新的根节点，历史根节点仍可访问
```

```python
# 可持久化线段树（区间第 k 小，主席树思想示意）
class PersistentSegNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def update(prev, l, r, pos):
    """在 prev 版本基础上 pos 位置 +1，返回新版本根节点"""
    node = PersistentSegNode(prev.val + 1, prev.left, prev.right)
    if l != r:
        mid = (l + r) // 2
        if pos <= mid:
            node.left = update(prev.left, l, mid, pos)
        else:
            node.right = update(prev.right, mid + 1, r, pos)
    return node
```

## Treap

Treap 是「Tree + Heap」：每个节点带随机优先级，同时满足 BST 的键序和堆的优先级序。随机优先级使树高期望 O(log n)，实现上通过旋转维护。相比平衡树，代码更简单，能同时支持插入、删除、排名、前驱后继。

```text
复杂度：
所有操作期望 O(log n)
空间 O(n)

维护两个约束：
1. BST 序 —— 左子树键 < 根键 < 右子树键
2. 堆序 —— 父节点优先级高于子节点（随机 priority）
```

```python
import random

class TreapNode:
    def __init__(self, key):
        self.key = key
        self.priority = random.random()
        self.left = self.right = None

def split(root, key):
    """按 key 分裂成 (<= key, > key) 两棵 Treap"""
    if not root:
        return None, None
    if root.key <= key:
        l, r = split(root.right, key)
        root.right = l
        return root, r
    else:
        l, r = split(root.left, key)
        root.left = r
        return l, root

def merge(l, r):
    """合并两棵 Treap，要求 l 中所有 key < r 中所有 key"""
    if not l or not r:
        return l or r
    if l.priority > r.priority:
        l.right = merge(l.right, r)
        return l
    else:
        r.left = merge(l, r.left)
        return r
```

## Skip List

跳表是有序链表的「多层索引」版：底层是完整有序链表，上层是稀疏索引，查询时从高层快速跨越、再逐层下降。它以概率平衡替代严格平衡，期望 O(log n) 查找，是实现有序集合/有序映射（如 Redis ZSet）的常用结构。

```text
复杂度：
查找/插入/删除期望 O(log n)
空间 O(n)（索引节点数期望为 n 的常数倍）

核心思想：
1. 多层链表 —— 第 i 层是第 i-1 层的抽样索引
2. 随机层数 —— 插入时以 1/2 概率逐层上升，保证期望平衡
3. 自顶向下 —— 查找从最高层开始，无法前进则下降一层
```

```python
import random

class SkipNode:
    def __init__(self, val, level):
        self.val = val
        self.next = [None] * (level + 1)

class SkipList:
    def __init__(self, max_level=16):
        self.max_level = max_level
        self.head = SkipNode(float('-inf'), max_level)

    def _random_level(self):
        level = 0
        while random.random() < 0.5 and level < self.max_level:
            level += 1
        return level

    def search(self, target):
        node = self.head
        for i in range(self.max_level, -1, -1):
            while node.next[i] and node.next[i].val < target:
                node = node.next[i]
        nxt = node.next[0]
        return nxt is not None and nxt.val == target
```

## 应用场景实战

### 场景一：并查集求「省份数量」（连通分量计数）

```python
def find_circle_num(is_connected):
    n = len(is_connected)
    uf = UnionFind(n)
    for i in range(n):
        for j in range(i + 1, n):
            if is_connected[i][j]:
                uf.union(i, j)
    return len({uf.find(i) for i in range(n)})

m = [[1, 1, 0], [1, 1, 0], [0, 0, 1]]
print(find_circle_num(m))    # 2 个省份
```

### 场景二：线段树 + 懒标记求「区间和」（带区间更新）

```python
data = [1, 3, 5, 7, 9, 11]
st = SegmentTreeFull(data)
st.range_add(1, 3, 2)        # [1, 5, 7, 9, 9, 11]
st.range_add(0, 5, 1)        # 全部 +1
print(st.tree[1])            # 根节点 = 全区间和 = 6 + 2*3 + 6 = 18
```

## 最佳实践与踩坑记录

### 最佳实践

1. 单点修改 + 前缀和 → 树状数组；需要区间最值/区间修改 → 线段树
2. 并查集务必同时写路径压缩和按秩合并，单写一个可能退化
3. 线段树数组开 4 倍大小，避免满二叉树下标越界
4. 稀疏表只能做静态 RMQ，带修改的 RMQ 换线段树
5. Treap/跳表用随机化保证平衡，适合需要排名/前驱后继的有序集合场景
6. 可持久化结构只在「必须保留历史版本」时用，普通问题别过度设计

### 踩坑记录

```text
坑 1：并查集只路径压缩不按秩合并
结论：极端数据下树高仍可能退化，多次 find 变慢。
原因：路径压缩不能完全消除合并方向带来的树高累积。
解法：union 时按 rank（或 size）把小树挂到大树。

坑 2：树状数组下标混淆
结论：update 和 query 一个从 0 开始、一个从 1 开始，结果错位。
原因：树状数组内部下标习惯从 1 开始，外部 API 从 0 开始。
解法：update 内部先 i += 1 统一到 1-based，query 保持外部语义一致。

坑 3：线段树数组开 2n 而非 4n
结论：非满二叉树下标可能超过 2n，导致越界或覆盖。
原因：递归建树的最坏下标可达 4n-1。
解法：树数组统一开 4 倍大小。

坑 4：稀疏表做重叠查询时忘了可重复贡献前提
结论：对「区间和」用稀疏表查 RMQ 会得到错误结果。
原因：区间和不可重复贡献，重叠部分会被算两次。
解法：稀疏表只用于 min/max/gcd 等幂等运算，区间和用前缀和/线段树。

坑 5：Treap 忘记随机优先级
结论：用固定优先级（如键值本身）会退化成普通 BST。
原因：优先级不再随机，无法保证期望平衡树高。
解法：每个节点插入时用 random 生成优先级。
```
