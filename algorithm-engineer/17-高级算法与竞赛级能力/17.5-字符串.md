## 概述

字符串算法解决「模式匹配、回文、公共子串、多模式检索」等问题。KMP 和 Z 函数做单模式匹配，AC 自动机做多模式匹配，Manacher 求回文子串，滚动哈希用哈希值快速比较子串，后缀数组/后缀自动机刻画所有后缀的字典序与子串结构。它们把朴素 O(n·m) 的字符串比较降到 O(n+m) 甚至 O(n)。

```text
字符串算法选型：
1. 单模式匹配 → KMP / Z 函数（O(n+m)）
2. 多模式匹配（字典、敏感词）→ AC 自动机（O(n + 总匹配数)）
3. 最长回文子串 → Manacher（O(n)）
4. 子串相等比较 / 去重 → Rolling Hash（O(n) 预处理，O(1) 比较）
5. 后缀排序 / 最长公共前缀 → Suffix Array（O(n log n)）
6. 本质不同子串 / 子串出现次数 → Suffix Automaton（O(n)）
```

```python
# 字符串处理的常用前提：Python 下标从 0 开始，竞赛常转 1-based 便于边界
s = "ababc"
n = len(s)
```

## KMP

KMP 用「前缀函数」避免模式匹配中的回溯：next[i] 表示模式串前 i 个字符的最长相等前后缀长度，失配时主串指针不动、模式串跳到 next 位置。核心是 O(m) 预处理 next 数组 + O(n) 扫描匹配。

```text
复杂度：
预处理 O(m)，匹配 O(n)，总 O(n+m)
空间 O(m)

核心思想：
失配时利用「已匹配部分的最长公共前后缀」跳过无用的比较，
主串指针 i 不回退
```

```python
def build_next(pattern):
    m = len(pattern)
    nxt = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = nxt[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        nxt[i] = j
    return nxt

def kmp(text, pattern):
    nxt = build_next(pattern)
    j = 0
    res = []
    for i, ch in enumerate(text):
        while j > 0 and ch != pattern[j]:
            j = nxt[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == len(pattern):
            res.append(i - j + 1)      # 匹配成功的位置
            j = nxt[j - 1]
    return res
```

## Z

Z 函数（Z 数组）求「每个位置 i 与字符串前缀的最长公共前缀长度 z[i]」。它是 KMP 的另一种视角，代码更简洁，常用于「模式串 + 分隔符 + 主串」拼接后一次扫描找所有匹配。

```text
复杂度：
O(n)，利用已算出的 Z-box 区间加速
空间 O(n)

定义：
z[i] = s[0:] 与 s[i:] 的最长公共前缀长度
```

```python
def z_function(s):
    n = len(s)
    z = [0] * n
    l = r = 0                        # 当前最右的 Z-box 区间 [l, r)
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z

# 用 Z 函数做模式匹配：pattern + '#' + text
def z_match(text, pattern):
    z = z_function(pattern + '#' + text)
    m = len(pattern)
    return [i - m - 1 for i in range(m + 1, len(z)) if z[i] == m]
```

## AC Automaton

AC 自动机（Aho-Corasick）在 Trie 上建立失败指针（fail），一次扫描主串即可匹配所有模式串。fail 指针指向「当前节点代表串的最长真后缀」对应的节点，匹配失败时沿 fail 跳转，是「多模式匹配」的标准解法。

```text
复杂度：
建树 O(总模式串长)，匹配 O(主串长 + 匹配总数)
空间 O(总模式串长 × 字母表)

核心：
1. Trie 存所有模式串
2. BFS 建立 fail 指针（指向最长后缀节点）
3. 匹配时沿 fail 链收集所有命中模式串
```

```python
from collections import deque

class ACNode:
    def __init__(self):
        self.children = {}
        self.fail = None
        self.output = []             # 以该节点结尾的模式串

class AhoCorasick:
    def __init__(self):
        self.root = ACNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = ACNode()
            node = node.children[ch]
        node.output.append(word)

    def build(self):
        q = deque([self.root])
        while q:
            node = q.popleft()
            for ch, child in node.children.items():
                f = node.fail
                while f and ch not in f.children:
                    f = f.fail
                child.fail = f.children[ch] if f and ch in f.children else self.root
                child.output += child.fail.output
                q.append(child)

    def search(self, text):
        node = self.root
        for ch in text:
            while node and ch not in node.children:
                node = node.fail
            node = node.children[ch] if node else self.root
            for w in node.output:
                yield w
```

## Manacher

Manacher 算法在线性时间内求「最长回文子串」：对原串插入分隔符（统一成奇数长度），维护「当前最右回文边界」和中心，利用回文的对称性跳过重复扩展。比「中心扩展 O(n²)」快一个量级。

```text
复杂度：
时间 O(n)，空间 O(n)

核心技巧：
1. 插入分隔符 '#'，把偶回文统一成奇回文
2. 维护 max_right 与 center，用对称性复用已算出的回文半径
```

```python
def manacher(s):
    t = '#' + '#'.join(s) + '#'
    n = len(t)
    p = [0] * n
    center = right = 0
    for i in range(n):
        if i < right:
            p[i] = min(right - i, p[2 * center - i])
        while i - p[i] - 1 >= 0 and i + p[i] + 1 < n and t[i - p[i] - 1] == t[i + p[i] + 1]:
            p[i] += 1
        if i + p[i] > right:
            center, right = i, i + p[i]
    max_len, max_idx = max((p[i], i) for i in range(n))
    start = (max_idx - max_len) // 2
    return s[start:start + max_len]
```

## Rolling Hash

滚动哈希给每个子串一个哈希值：用多项式哈希（模大质数或双模），预处理前缀哈希，使任意子串的哈希值能 O(1) 算出，从而 O(1) 比较两子串是否相等。常用于最长公共子串、重复子串检测、字符串匹配。

```text
复杂度：
预处理 O(n)，单次子串哈希 O(1)
空间 O(n)

哈希定义（base、mod 为质数）：
hash[l..r] = (H[r+1] - H[l] · base^(r-l+1)) mod mod
碰撞用双哈希或自然溢出（unsigned long long）降低
```

```python
class RollingHash:
    def __init__(self, s, base=911382323, mod=10**9 + 7):
        self.n = len(s)
        self.base = base
        self.mod = mod
        self.h = [0] * (self.n + 1)
        self.pw = [1] * (self.n + 1)
        for i in range(self.n):
            self.h[i + 1] = (self.h[i] * base + ord(s[i])) % mod
            self.pw[i + 1] = self.pw[i] * base % mod

    def get(self, l, r):              # 闭区间 [l, r] 的哈希值
        return (self.h[r + 1] - self.h[l] * self.pw[r - l + 1]) % self.mod
```

## Suffix Array

后缀数组把字符串的所有后缀按字典序排序，得到 sa[i]（排名第 i 的后缀起始位置）和 rank[i]（后缀 i 的排名）。配合 height 数组（相邻后缀的最长公共前缀）可求任意两后缀 LCP、最长重复子串等问题。

```text
复杂度：
倍增法 O(n log n)；SA-IS 线性 O(n)
空间 O(n)

配套数组：
sa[i] —— 排名第 i 的后缀起点
rank[i] —— 后缀 i 的排名
height[i] —— 排名第 i 与第 i-1 后缀的 LCP
```

```python
# 倍增法求后缀数组
def build_sa(s):
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp = [0] * n
        for i in range(1, n):
            tmp[sa[i]] = tmp[sa[i - 1]] + (
                (rank[sa[i]], rank[sa[i] + k] if sa[i] + k < n else -1) !=
                (rank[sa[i - 1]], rank[sa[i - 1] + k] if sa[i - 1] + k < n else -1))
        rank = tmp
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa

def build_height(s, sa):
    n = len(s)
    rank = [0] * n
    for i in range(n):
        rank[sa[i]] = i
    height = [0] * n
    h = 0
    for i in range(n):
        if rank[i] == 0:
            continue
        j = sa[rank[i] - 1]
        while i + h < n and j + h < n and s[i + h] == s[j + h]:
            h += 1
        height[rank[i]] = h
        if h:
            h -= 1
    return height
```

## Suffix Automaton

后缀自动机（SAM）是「能识别一个字符串所有子串的最小 DFA」，节点数 O(n)、边数 O(n)。它能在线性时间回答：本质不同子串个数、某子串出现次数、最长公共子串等问题，是后缀树的高效替代。

```text
复杂度：
构建 O(n)，节点数 ≤ 2n-1，转移数 ≤ 3n-4
空间 O(n)

每个状态代表一组 endpos 相同的子串：
len —— 该状态最长子串长度
link —— 后缀链接，指向最短子串再删首字符后所在状态
```

```python
class SAMState:
    def __init__(self, length, link=-1):
        self.len = length
        self.link = link
        self.next = {}

class SuffixAutomaton:
    def __init__(self):
        self.states = [SAMState(0)]
        self.last = 0

    def extend(self, c):
        cur = len(self.states)
        self.states.append(SAMState(self.states[self.last].len + 1))
        p = self.last
        while p != -1 and c not in self.states[p].next:
            self.states[p].next[c] = cur
            p = self.states[p].link
        if p == -1:
            self.states[cur].link = 0
        else:
            q = self.states[p].next[c]
            if self.states[p].len + 1 == self.states[q].len:
                self.states[cur].link = q
            else:
                clone = len(self.states)
                self.states.append(SAMState(self.states[p].len + 1, self.states[q].link))
                self.states[clone].next = dict(self.states[q].next)
                while p != -1 and self.states[p].next[c] == q:
                    self.states[p].next[c] = clone
                    p = self.states[p].link
                self.states[q].link = self.states[cur].link = clone
        self.last = cur

    def distinct_substrings(self):
        return sum(st.len - self.states[st.link].len for st in self.states[1:])
```

## 应用场景实战

### 场景一：最长公共前缀查询（后缀数组 + height 的 RMQ）

```python
def longest_common_prefix(s, i, j):
    """求后缀 i 与后缀 j 的最长公共前缀长度"""
    sa = build_sa(s)
    height = build_height(s, sa)
    rank = {pos: idx for idx, pos in enumerate(sa)}
    ri, rj = rank[i], rank[j]
    if ri > rj:
        ri, rj = rj, ri
    return min(height[ri + 1:rj + 1]) if ri != rj else len(s) - i
```

### 场景二：多模式敏感词过滤（AC 自动机）

```python
ac = AhoCorasick()
for word in ['he', 'she', 'his', 'hers']:
    ac.insert(word)
ac.build()
print(list(ac.search('ushers')))     # ['she', 'he', 'hers']
```

## 最佳实践与踩坑记录

### 最佳实践

1. 单模式匹配优先 KMP，代码写熟 next 数组的求法
2. 多模式匹配用 AC 自动机，BFS 建 fail 别用 DFS
3. 回文问题用 Manacher，插入分隔符统一奇偶
4. 子串比较/去重用双哈希或自然溢出，别单哈希裸奔
5. 后缀数组配 height + RMQ 求 LCP，本质不同子串用 SAM 更简洁
6. Python 里字符串下标从 0 开始，竞赛板子转 1-based 时注意边界

### 踩坑记录

```text
坑 1：KMP next 数组下标错位
结论：next 有的版本是「前缀长度」、有的是「跳转位置」，混用导致死循环或漏匹配。
原因：不同板子对 next 的语义定义不一致（-1-based 与 0-based）。
解法：统一用「最长公共前后缀长度」语义，失配跳 next[j-1]。

坑 2：AC 自动机 fail 用 DFS 建立
结论：fail 指针依赖更浅节点的 fail，DFS 顺序错误导致指向错误节点。
原因：fail 必须按 BFS 层次顺序建立（浅层先算）。
解法：用队列 BFS 逐层建立 fail。

坑 3：Manacher 忘了插入分隔符
结论：偶回文（如 'abba'）被漏掉，最长回文算错。
原因：中心扩展法天然只能处理奇回文，偶回文没有单一中心。
解法：先插 '#' 分隔符，再统一按奇回文处理。

坑 4：滚动哈希单模被卡（哈希碰撞）
结论：不同子串哈希相同，比较结果错误。
原因：单模哈希在恶意数据/大数据量下碰撞概率高。
解法：双哈希（两个不同模数）或 64 位自然溢出。

坑 5：后缀数组排序 key 越界
结论：倍增时 rank[i+k] 下标越界报错。
原因：i+k 超过字符串长度时没有用哨兵 -1 处理。
解法：rank[i+k] if i+k<n else -1，用 -1 表示越界最小。
```
