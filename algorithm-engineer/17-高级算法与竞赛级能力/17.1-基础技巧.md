## 概述

基础技巧是竞赛级算法里出现频率最高的一批「通用套路」：它们不是具体的数据结构或算法，而是解决一大类问题的思维框架。双指针、滑动窗口、前缀和、差分解决线性序列问题，二分答案把优化问题转成判定问题，单调栈/单调队列维护「局部单调性」，贪心/分治/回溯则是三大算法范式。掌握它们，大部分中等难度的竞赛题都能找到切入点。

```text
基础技巧的核心定位：
1. 双指针/滑动窗口 —— 线性序列上的高效扫描，避免 O(n²) 暴力
2. 前缀和/差分 —— 区间查询与区间修改的 O(1) 技巧
3. 二分答案 —— 把「求最优」转成「判定可行」，配合单调性
4. 单调栈/单调队列 —— 维护序列局部单调性，解决「最近更大/更小」类问题
5. 贪心/分治/回溯 —— 三大算法设计范式，是更复杂算法的基础
```

```python
# 双指针：有序数组两数之和
def two_sum(nums, target):
    nums = sorted(nums)
    i, j = 0, len(nums) - 1
    while i < j:
        s = nums[i] + nums[j]
        if s == target:
            return [nums[i], nums[j]]
        elif s < target:
            i += 1
        else:
            j -= 1
    return []
```

## 双指针

双指针用两个游标在序列上相向或同向移动，把 O(n²) 的两两枚举压缩到 O(n)。关键是证明「指针移动后不会漏掉答案」——通常依赖数组有序，或者某一边界可以安全收缩。

```text
复杂度：
时间 O(n)，空间 O(1)

常见形态：
1. 相向双指针 —— 有序数组两数之和、三数之和、盛水容器
2. 同向快慢指针 —— 链表判环、去重、partition
3. 原地修改 —— 移动零、删除重复元素
```

```python
# 三数之和：固定一个数，剩下转两数之和
def three_sum(nums, target=0):
    nums.sort()
    n, res = len(nums), []
    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:   # 去重
            continue
        j, k = i + 1, n - 1
        while j < k:
            s = nums[i] + nums[j] + nums[k]
            if s == target:
                res.append([nums[i], nums[j], nums[k]])
                j += 1; k -= 1
                while j < k and nums[j] == nums[j - 1]:
                    j += 1
                while j < k and nums[k] == nums[k + 1]:
                    k -= 1
            elif s < target:
                j += 1
            else:
                k -= 1
    return res
```

## 滑动窗口

滑动窗口是双指针的子集：维护一个满足条件的连续区间 [left, right]，右指针扩张、左指针收缩。核心套路是「右指针逐步加入元素，一旦不满足条件就移动左指针直到重新满足」。

```text
复杂度：
时间 O(n)，每个元素最多进窗口一次、出窗口一次
空间 O(k)，k 为窗口内容纳的不同元素数

适用：
1. 最长/最短满足某条件的子数组、子串
2. 固定长度窗口的统计（配合 Counter / 哈希表）
3. 答案随窗口单调变化的场景
```

```python
# 最长无重复字符子串
def length_of_longest_substring(s):
    seen = {}
    left = ans = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1          # 收缩左边界
        seen[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

## 前缀和

前缀和预处理出 sum[0..i]，让任意区间 [l, r] 的和变成 sum[r+1] - sum[l] 的 O(1) 查询。它是「区间求和」类问题的基础，也推广到二维前缀和、前缀异或、前缀乘积等。

```text
复杂度：
预处理 O(n)，单次区间查询 O(1)
空间 O(n)

定义：
prefix[i] = nums[0] + nums[1] + ... + nums[i-1]
区间和 sum(l, r) = prefix[r+1] - prefix[l]
```

```python
# 一维前缀和：多次区间求和
def build_prefix(nums):
    prefix = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        prefix[i + 1] = prefix[i] + x
    return prefix

def range_sum(prefix, l, r):        # 闭区间 [l, r]
    return prefix[r + 1] - prefix[l]

nums = [1, 3, 5, 2, 4]
p = build_prefix(nums)
print(range_sum(p, 1, 3))            # 3 + 5 + 2 = 10
```

## 差分

差分是前缀和的逆运算：对差分数组 d 做区间 [l, r] 加 x，只需 d[l] += x、d[r+1] -= x 两个点更新，最后对 d 求前缀和还原原数组。适合「多次区间加减、最后统一查询」的场景。

```text
复杂度：
单次区间修改 O(1)，整体还原 O(n)
空间 O(n)

定义：
d[i] = a[i] - a[i-1]
区间 [l, r] 加 x → d[l] += x, d[r+1] -= x
还原：a[i] = d[0] + d[1] + ... + d[i]（对 d 求前缀和）
```

```python
# 差分：航班预订（多个区间加，最后输出每个位置的值）
def corp_flight_bookings(bookings, n):
    diff = [0] * (n + 2)
    for l, r, seats in bookings:      # 1-based 区间
        diff[l] += seats
        diff[r + 1] -= seats
    res = []
    cur = 0
    for i in range(1, n + 1):
        cur += diff[i]
        res.append(cur)
    return res
```

## 二分答案

二分答案不直接找答案，而是对答案的值域二分：若某个候选值 x 满足条件（check(x) 为真），则更大的值也可能满足，从而缩小范围。前提是 check 具有单调性——一旦条件成立，答案要么全在左边、要么全在右边。

```text
复杂度：
O(log(值域) × check 的时间复杂度)

模板要点：
1. 确定答案的单调性（满足条件的值构成前缀或后缀）
2. 写 check(mid) 判定「mid 是否可行」
3. 依据 check 结果收缩 [lo, hi]，注意开闭区间与死循环
```

```python
# 二分答案：在 D 天内把 weights 分段运输，最小化单段最大重量
def ship_within_days(weights, days):
    def check(cap):
        cnt, cur = 1, 0
        for w in weights:
            if cur + w > cap:
                cnt += 1
                cur = w
            else:
                cur += w
        return cnt <= days

    lo, hi = max(weights), sum(weights)
    while lo < hi:
        mid = (lo + hi) // 2
        if check(mid):
            hi = mid          # 可行，尝试更小
        else:
            lo = mid + 1
    return lo
```

## 单调栈

单调栈维护一个栈内元素单调递增（或递减）的栈，用于 O(n) 求「每个元素左边/右边第一个比它大/小的元素」。核心是：新元素入栈前，把栈顶所有「不满足单调性」的元素弹出，被弹出元素的「下一个更大/更小」就是当前元素。

```text
复杂度：
时间 O(n)，每个元素最多入栈出栈各一次
空间 O(n)

两类经典问题：
1. 下一个更大元素（单调递减栈）
2. 下一个更小元素 / 柱状图最大矩形（单调递增栈）
```

```python
# 下一个更大元素（单调递减栈）
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []                       # 存下标，栈内对应值递减
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res
```

## 单调队列

单调队列是「滑动窗口」+「单调性」的组合：队首维护窗口内最大/最小值，队尾保持单调。新元素入队时从队尾弹出所有比它小（求最大值时）的元素，窗口滑出时从队首弹出过期元素。用于 O(n) 求滑动窗口最值。

```text
复杂度：
时间 O(n)，每个元素最多入队出队各一次
空间 O(k)，k 为窗口大小

与单调栈的区别：
单调栈处理「全局下一个更大」，单调队列处理「窗口内最值」
```

```python
from collections import deque

# 滑动窗口最大值
def max_sliding_window(nums, k):
    dq = deque()                     # 存下标，队首是窗口内最大值
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()                 # 维护队尾单调递减
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()             # 移除滑出窗口的下标
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

## 贪心

贪心在每一步都做「当前看起来最优」的选择，不回溯。它不保证全局最优，但对具备「贪心选择性质」和「最优子结构」的问题正确且高效。关键是证明：局部最优能推出全局最优（常见手段是交换论证或反证）。

```text
复杂度：
随具体问题而定，通常 O(n log n)（排序后贪心）

典型场景：
1. 活动选择 —— 按结束时间排序，能选就选
2. 区间覆盖 —— 每次选右端点最远的区间
3. 跳跃游戏 —— 维护当前可达最远位置
```

```python
# 活动选择：选择最多不重叠的活动
def max_activities(activities):
    activities.sort(key=lambda x: x[1])   # 按结束时间排序
    count, last_end = 0, float('-inf')
    for start, end in activities:
        if start >= last_end:
            count += 1
            last_end = end
    return count

acts = [(1, 4), (3, 5), (0, 6), (5, 7), (3, 8), (5, 9)]
print(max_activities(acts))               # 3
```

## 分治

分治把大问题拆成若干结构相同的小问题，递归求解后合并结果。经典三要素：分解（divide）、解决（conquer）、合并（combine）。归并排序、快速排序、快速幂都是分治典范，复杂度常用主定理分析。

```text
复杂度（归并排序）：
时间 O(n log n)，空间 O(n)

主定理（T(n) = a·T(n/b) + f(n)）：
1. f(n) 较小 → O(n^log_b(a))
2. f(n) 相当 → O(n^log_b(a) · log n)
3. f(n) 较大 → O(f(n))
```

```python
# 归并排序 + 求逆序对数量
def merge_sort_count(nums):
    if len(nums) <= 1:
        return nums, 0
    mid = len(nums) // 2
    left, inv_l = merge_sort_count(nums[:mid])
    right, inv_r = merge_sort_count(nums[mid:])
    merged, inv = [], inv_l + inv_r
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
            inv += len(left) - i          # 左半剩余都构成逆序对
    merged += left[i:] + right[j:]
    return merged, inv
```

## 回溯

回溯在解空间树中深度优先搜索，每步做选择、递归、再撤销选择（回到上一状态）。它是「穷举 + 剪枝」，适合求所有解/组合/排列/子集这类问题。关键是用「路径、选择列表、结束条件」三要素建模，并用剪枝提前砍掉不可能的分支。

```text
复杂度：
指数级，O(b^d) 量级，b 为分支因子、d 为深度（视剪枝效果而定）

三要素：
1. 路径 —— 已做的选择
2. 选择列表 —— 当前还能做的选择
3. 结束条件 —— 到达叶子节点，收集结果
```

```python
# N 皇后：回溯 + 斜线冲突剪枝
def solve_n_queens(n):
    res = []
    def backtrack(row, cols, diag1, diag2, board):
        if row == n:
            res.append([''.join(r) for r in board])
            return
        for col in range(n):
            d1, d2 = row - col, row + col
            if col in cols or d1 in diag1 or d2 in diag2:
                continue                        # 剪枝：同列/同对角线
            cols.add(col); diag1.add(d1); diag2.add(d2)
            board[row][col] = 'Q'
            backtrack(row + 1, cols, diag1, diag2, board)
            board[row][col] = '.'               # 撤销选择
            cols.remove(col); diag1.remove(d1); diag2.remove(d2)
    board = [['.'] * n for _ in range(n)]
    backtrack(0, set(), set(), set(), board)
    return res
```

## 应用场景实战

### 场景一：滑动窗口 + 前缀和求解「和 ≥ target 的最短子数组」

```python
def min_subarray_len(target, nums):
    left = cur = 0
    ans = float('inf')
    for right, x in enumerate(nums):
        cur += x
        while cur >= target:
            ans = min(ans, right - left + 1)
            cur -= nums[left]
            left += 1
    return ans if ans != float('inf') else 0

nums = [2, 3, 1, 2, 4, 3]
print(min_subarray_len(7, nums))     # 2 → [4, 3]
```

### 场景二：差分 + 前缀和解决「拼车」问题

```python
def car_pooling(trips, capacity):
    diff = [0] * 1002
    for num, start, end in trips:
        diff[start] += num
        diff[end] -= num              # 乘客在 end 下车
    cur = 0
    for i in range(1002):
        cur += diff[i]
        if cur > capacity:
            return False
    return True

trips = [[2, 1, 5], [3, 3, 7]]
print(car_pooling(trips, 4))          # False，第 3 站超载
```

## 最佳实践与踩坑记录

### 最佳实践

1. 双指针先排序、明确「指针何时收缩」，并证明收缩方向不会漏解
2. 滑动窗口用「右扩左缩」框架，条件判断写在 while 里保证窗口始终合法
3. 前缀和数组多开一位（长度 n+1），区间和公式统一为 sum[r+1] - sum[l]
4. 二分答案先证 check 单调性，再选开闭区间模板，避免死循环
5. 单调栈/单调队列里存下标而非值，方便同时维护「最值」和「位置/窗口」
6. 回溯把「选择、递归、撤销」三步写对称，剪枝条件尽量前置

### 踩坑记录

```text
坑 1：滑动窗口 while 收缩条件写错
结论：窗口不满足条件时忘了收缩，得到错误的最长子串/最短子数组长度。
原因：只在右指针处判断一次，没有在 while 里持续收缩到合法。
解法：内层用 while（而非 if）收缩，保证每次循环结束窗口都满足条件。

坑 2：前缀和区间下标算错
结论：闭区间 [l, r] 求和写成 prefix[r] - prefix[l]，少算一个元素。
原因：混淆了「prefix[i] 是前 i 个元素和」的定义。
解法：统一用 prefix[i] = 前 i 个元素和，区间 [l, r] = prefix[r+1] - prefix[l]。

坑 3：差分区间更新 r+1 越界
结论：d[r+1] -= x 时 r 是最后一个下标，数组越界。
原因：差分数组没预留末尾哨兵位。
解法：差分数组长度开 n+2，末尾多一位兜底。

坑 4：二分答案死循环
结论：lo=hi 时循环不退出，或收缩方向写反导致答案被跳过。
原因：开闭区间混用，mid 计算和 lo/hi 赋值不配套。
解法：固定「左闭右闭」模板，可行时 hi=mid、不可行时 lo=mid+1，循环条件 lo<hi。

坑 5：贪心没证明就套用
结论：局部最优不等于全局最优，得到错误答案（如经典零钱问题贪心失败）。
原因：问题不具备贪心选择性质，硬套贪心。
解法：先用反例检验贪心正确性，必要时改用动态规划。
```
