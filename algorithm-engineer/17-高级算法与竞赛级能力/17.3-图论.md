## 概述

图论算法覆盖「最短路、最小生成树、连通性、二分图、网络流」五大块。最短路解决点对距离问题（Dijkstra/Bellman-Ford/Floyd/0-1 BFS 各有适用边权），MST 求连通图的最小代价连接，SCC/Bridge/Articulation Point 刻画图的连通结构，Max Flow/Min Cut 解决带容量网络的最大传输量，Min Cost Max Flow 进一步优化流量成本。它们是竞赛图论题的骨架。

```text
图论算法选型：
1. 非负边权单源最短路 → Dijkstra（O((V+E) log V)）
2. 含负边/负环检测 → Bellman-Ford（O(VE)）
3. 全源最短路 → Floyd（O(V³)）
4. 边权只有 0 和 1 → 0-1 BFS（O(V+E)）
5. 最小生成树 → Kruskal / Prim（O(E log E)）
6. 强连通分量/桥/割点 → Tarjan（O(V+E)）
7. 最大流/最小割 → Dinic（O(V²E)）
```

```python
# 邻接表建图（竞赛通用）
from collections import defaultdict

def build_graph(n, edges):
    g = defaultdict(list)
    for u, v, w in edges:
        g[u].append((v, w))     # 有向边 u -> v，权重 w
    return g
```

## Dijkstra

Dijkstra 求「非负权图」的单源最短路：用优先队列每次取出当前距离最小的未确定节点，松弛它的邻居。依赖边权非负保证「已确定的最短距离不会被后续更新推翻」。

```text
复杂度：
二叉堆 O((V+E) log V)；斐波那契堆 O(E + V log V)
空间 O(V+E)

限制：
不能处理负权边（负权会破坏贪心正确性），负权图用 Bellman-Ford
```

```python
import heapq

def dijkstra(n, edges, src):
    g = build_graph(n, edges)
    dist = [float('inf')] * n
    dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue               # 过期节点跳过
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## Bellman-Ford

Bellman-Ford 也能求单源最短路，且支持负权边：对全部边松弛 V-1 轮，第 V 轮仍能松弛则说明存在负环。它比 Dijkstra 慢，但能处理负权并检测负环。

```text
复杂度：
时间 O(VE)，空间 O(V)

核心结论：
1. 最多 V-1 条边构成最短路，故松弛 V-1 轮即可
2. 第 V 轮还能松弛 → 存在负权环
```

```python
def bellman_ford(n, edges, src):
    dist = [float('inf')] * n
    dist[src] = 0
    for _ in range(n - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != float('inf') and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break                # 提前收敛
    for u, v, w in edges:        # 第 V 轮检测负环
        if dist[u] != float('inf') and dist[u] + w < dist[v]:
            return dist, True    # 存在负环
    return dist, False
```

## Floyd

Floyd 用动态规划求「全源最短路」：dist[i][j] 表示 i 到 j 的最短距离，枚举中间节点 k 做松弛。代码极短，适合 V 较小（≤ 500）的稠密图。

```text
复杂度：
时间 O(V³)，空间 O(V²)

递推：
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
k 为「允许经过的中间节点集合」逐轮扩大的最外层循环
```

```python
def floyd(n, edges):
    INF = float('inf')
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = min(dist[u][v], w)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] != INF and dist[k][j] != INF:
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    return dist
```

## 0-1 BFS

当边权只有 0 和 1 时，可以用双端队列替代优先队列：松弛到权重 0 的边放到队首，权重 1 的边放到队尾，保持队列「按距离有序」。复杂度从 Dijkstra 的 O((V+E) log V) 降到 O(V+E)。

```text
复杂度：
时间 O(V+E)，空间 O(V+E)

适用：
边权 ∈ {0, 1} 的最短路，如「障碍移动代价 0/1」类网格题
```

```python
from collections import deque

def zero_one_bfs(n, edges, src):
    g = build_graph(n, edges)
    dist = [float('inf')] * n
    dist[src] = 0
    dq = deque([src])
    while dq:
        u = dq.popleft()
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if w == 0:
                    dq.appendleft(v)     # 0 权边放队首
                else:
                    dq.append(v)         # 1 权边放队尾
    return dist
```

## MST

最小生成树求连通图的「边权和最小的生成树」。Kruskal 把边按权重升序排序，用并查集避免成环、能连就连；Prim 从任意点出发，每次贪心加入最近的未访问节点。两者都是贪心，正确性由割性质保证。

```text
复杂度：
Kruskal O(E log E)；Prim（二叉堆）O(E log V)
空间 O(V+E)

关键性质：
1. 割性质 —— 任意割的最小横跨边必属于某个 MST
2. Kruskal 适合稀疏图，Prim 适合稠密图
```

```python
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])
    uf = UnionFind(n)
    mst_weight, count = 0, 0
    for u, v, w in edges:
        if uf.find(u) != uf.find(v):
            uf.union(u, v)
            mst_weight += w
            count += 1
            if count == n - 1:
                break
    return mst_weight if count == n - 1 else -1   # -1 表示不连通
```

## SCC

强连通分量（SCC）是「任意两点互相可达」的极大子图。把 SCC 缩成一个点后得到 DAG，常用于「有向图可达性、依赖关系」的化简。Kosaraju 两次 DFS、Tarjan 一次 DFS 都能求。

```text
复杂度：
O(V+E)

缩点意义：
SCC 内部强连通 → 缩成单点后图变 DAG，
配合拓扑排序解决依赖、传递闭包、必经点等问题
```

```python
# Kosaraju：两遍 DFS
def kosaraju(n, edges):
    g = defaultdict(list)
    rg = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        rg[v].append(u)

    def dfs(u, graph, visited, order):
        visited[u] = True
        for v in graph[u]:
            if not visited[v]:
                dfs(v, graph, visited, order)
        order.append(u)

    visited = [False] * n
    order = []
    for i in range(n):
        if not visited[i]:
            dfs(i, g, visited, order)      # 第一遍，得到出栈序

    visited = [False] * n
    comps = []
    for u in reversed(order):              # 按出栈逆序，在反图上 DFS
        if not visited[u]:
            comp = []
            dfs(u, rg, visited, comp)
            comps.append(comp)
    return comps
```

## Tarjan

Tarjan 算法通过一次 DFS 求 SCC，核心是 low-link 值：low[u] 表示从 u 出发（经子孙的返祖边）能回到的最早祖先。当 dfn[u] == low[u] 时，u 是其所在 SCC 的根，弹栈收集该分量。

```text
复杂度：
时间 O(V+E)，空间 O(V+E)

关键变量：
dfn[u] —— DFS 访问次序（时间戳）
low[u] —— 能回溯到的最早 dfn
dfn[u] == low[u] → u 是 SCC 的根
```

```python
def tarjan_scc(n, edges):
    g = build_graph(n, [(u, v, 1) for u, v in edges])
    dfn = [0] * n
    low = [0] * n
    in_stack = [False] * n
    stack = []
    timer = 0
    comps = []

    def dfs(u):
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        stack.append(u)
        in_stack[u] = True
        for v, _ in g[u]:
            if dfn[v] == 0:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif in_stack[v]:
                low[u] = min(low[u], dfn[v])
        if dfn[u] == low[u]:
            comp = []
            while True:
                w = stack.pop()
                in_stack[w] = False
                comp.append(w)
                if w == u:
                    break
            comps.append(comp)

    for i in range(n):
        if dfn[i] == 0:
            dfs(i)
    return comps
```

## Bridge

桥（割边）是「删除后图连通分量数增加」的边。无向图中，边 (u, v) 是桥当且仅当 low[v] > dfn[u]（子节点 v 无法不经这条边回到 u 或更早的祖先）。用一次 DFS 的 low-link 即可求全部桥。

```text
复杂度：
O(V+E)

判定条件（无向图）：
对树边 (u, v)，若 low[v] > dfn[u] → (u, v) 是桥
注意无向图需要跳过「来时的父边」，避免把返祖边误判为桥
```

```python
def find_bridges(n, edges):
    g = defaultdict(list)
    for i, (u, v) in enumerate(edges):
        g[u].append((v, i))
        g[v].append((u, i))
    dfn = [0] * n
    low = [0] * n
    timer = 0
    bridges = []

    def dfs(u, parent_edge):
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        for v, eid in g[u]:
            if eid == parent_edge:
                continue                 # 跳过父边
            if dfn[v] == 0:
                dfs(v, eid)
                low[u] = min(low[u], low[v])
                if low[v] > dfn[u]:
                    bridges.append((u, v))
            else:
                low[u] = min(low[u], dfn[v])

    for i in range(n):
        if dfn[i] == 0:
            dfs(i, -1)
    return bridges
```

## Articulation Point

割点（关节点）是「删除后图连通分量数增加」的顶点。判定：根节点若有 ≥2 个子树是割点；非根节点 u 若有某子节点 v 满足 low[v] >= dfn[u]，则 u 是割点。

```text
复杂度：
O(V+E)

判定条件（无向图）：
1. 根节点：DFS 子树数 ≥ 2 → 割点
2. 非根节点：存在子节点 v 使 low[v] >= dfn[u] → u 是割点
```

```python
def find_articulation_points(n, edges):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)
    dfn = [0] * n
    low = [0] * n
    timer = 0
    ap = set()

    def dfs(u, parent):
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        children = 0
        for v in g[u]:
            if v == parent:
                continue
            if dfn[v] == 0:
                children += 1
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if parent != -1 and low[v] >= dfn[u]:
                    ap.add(u)            # 非根节点判定
            else:
                low[u] = min(low[u], dfn[v])
        if parent == -1 and children >= 2:
            ap.add(u)                    # 根节点判定

    for i in range(n):
        if dfn[i] == 0:
            dfs(i, -1)
    return ap
```

## Bipartite Graph

二分图是「顶点可分成两个集合、所有边都横跨两个集合」的图。判定：用 BFS/DFS 交替染色，若相邻顶点同色则不是二分图。二分图还对应「无奇环」这一等价条件，是最大匹配的基础。

```text
复杂度：
O(V+E)

等价条件：
1. 可二染色（相邻顶点异色）
2. 不含奇环
```

```python
from collections import deque

def is_bipartite(n, edges):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)
    color = [-1] * n
    for s in range(n):
        if color[s] != -1:
            continue
        color[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    return False          # 同色冲突 → 非二分图
    return True
```

## Max Flow

最大流求「带容量有向图从源点到汇点的最大传输量」。核心是残余网络 + 增广路：沿一条增广路推流，直到不存在增广路。Dinic 用 BFS 分层 + DFS 多路增广优化，是竞赛最常用的实现。

```text
复杂度：
Edmonds-Karp O(VE²)；Dinic O(V²E)（一般图），二分图上更优
空间 O(V+E)

关键概念：
1. 残余网络 —— 每条边记录剩余容量 + 反向边（用于撤销）
2. 增广路 —— 从 s 到 t 的剩余容量为正的路径
3. 最大流 = 增广到无增广路为止
```

```python
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        self.g[u].append([v, cap, len(self.g[v])])
        self.g[v].append([u, 0, len(self.g[u]) - 1])   # 反向边

    def max_flow(self, s, t):
        flow = 0
        while True:
            level = [-1] * self.n
            level[s] = 0
            q = deque([s])
            while q:                                     # BFS 分层
                u = q.popleft()
                for v, cap, _ in self.g[u]:
                    if cap > 0 and level[v] == -1:
                        level[v] = level[u] + 1
                        q.append(v)
            if level[t] == -1:
                return flow
            it = [0] * self.n
            def dfs(u, f):                               # DFS 多路增广
                if u == t:
                    return f
                while it[u] < len(self.g[u]):
                    v, cap, rev = self.g[u][it[u]]
                    if cap > 0 and level[v] == level[u] + 1:
                        d = dfs(v, min(f, cap))
                        if d:
                            self.g[u][it[u]][1] -= d
                            self.g[v][rev][1] += d
                            return d
                    it[u] += 1
                return 0
            while True:
                f = dfs(s, float('inf'))
                if not f:
                    break
                flow += f
```

## Min Cut

最小割是「删除后使 s 与 t 不连通」的边集最小容量和。最大流最小割定理指出：最大流 = 最小割。求最小割值即求最大流；求割集则从 s 出发在残余网络 BFS，可达点集与不可达点集之间的原边就是最小割。

```text
复杂度：
同最大流（Dinic O(V²E)）

最大流最小割定理：
max-flow(s, t) = min-cut(s, t)

割集提取：
残余网络上从 s 可达的顶点集合 S，
原图中 S 与 V\S 之间的边构成最小割
```

```python
def min_cut_value(dinic, s, t):
    return dinic.max_flow(s, t)          # 最小割 = 最大流
```

## Min Cost Max Flow

最小费用最大流在「流量最大」的前提下进一步最小化总费用：每条边带单位费用，用 SPFA（或势函数 Dijkstra）找「费用最短路」作为增广路，沿它推流直到无法增广。

```text
复杂度：
O(flow × V × E)（SPFA 版），flow 为最大流量
空间 O(V+E)

核心：
把「找增广路」升级为「找费用最短增广路」，
用最短路算法替代 BFS，边权取费用
```

```python
from collections import deque

def min_cost_max_flow(n, edges, s, t):
    g = [[] for _ in range(n)]
    for u, v, cap, cost in edges:
        g[u].append([v, cap, cost, len(g[v])])
        g[v].append([u, 0, -cost, len(g[u]) - 1])

    total_cost, total_flow = 0, 0
    while True:
        dist = [float('inf')] * n
        inq = [False] * n
        prevv = [-1] * n
        preve = [-1] * n
        dist[s] = 0
        q = deque([s])
        while q:                                      # SPFA 找费用最短路
            u = q.popleft()
            inq[u] = False
            for i, (v, cap, cost, rev) in enumerate(g[u]):
                if cap > 0 and dist[u] + cost < dist[v]:
                    dist[v] = dist[u] + cost
                    prevv[v] = u
                    preve[v] = i
                    if not inq[v]:
                        inq[v] = True
                        q.append(v)
        if dist[t] == float('inf'):
            break
        d = float('inf')
        v = t
        while v != s:                                 # 找瓶颈流量
            d = min(d, g[prevv[v]][preve[v]][1])
            v = prevv[v]
        v = t
        while v != s:
            e = g[prevv[v]][preve[v]]
            e[1] -= d
            g[v][e[3]][1] += d
            v = prevv[v]
        total_flow += d
        total_cost += d * dist[t]
    return total_flow, total_cost
```

## 应用场景实战

### 场景一：网络延迟时间（Dijkstra 求最远可达时间）

```python
def network_delay_time(times, n, k):
    edges = [(u - 1, v - 1, w) for u, v, w in times]
    dist = dijkstra(n, edges, k - 1)
    mx = max(dist)
    return mx if mx != float('inf') else -1

times = [[2, 1, 1], [2, 3, 1], [3, 4, 1]]
print(network_delay_time(times, 4, 2))   # 2
```

### 场景二：课程表（拓扑排序 + 判环，用 BFS 入度法）

```python
def can_finish(n, prerequisites):
    g = defaultdict(list)
    indeg = [0] * n
    for a, b in prerequisites:
        g[b].append(a)
        indeg[a] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen == n

print(can_finish(2, [[1, 0]]))           # True
print(can_finish(2, [[1, 0], [0, 1]]))   # False，有环
```

## 最佳实践与踩坑记录

### 最佳实践

1. 非负权用 Dijkstra，含负权/负环用 Bellman-Ford，全源且 V 小用 Floyd
2. 边权只有 0/1 时用 0-1 BFS，别硬套 Dijkstra（多一个 log 因子）
3. 稀疏图用 Kruskal，稠密图用 Prim
4. Tarjan 求 SCC/桥/割点统一记 low-link 框架，注意无向图要跳过父边
5. 网络流存「反向边」用于撤销增广，别漏加
6. 缩点（SCC）后得到 DAG，配合拓扑排序做依赖与可达性分析

### 踩坑记录

```text
坑 1：Dijkstra 用于负权图
结论：最短距离算错，甚至死循环或错误收敛。
原因：负权边破坏「已确定节点不再更新」的贪心前提。
解法：负权图改用 Bellman-Ford 或 SPFA。

坑 2：无向图 Tarjan 忘跳过父边
结论：把正常的返祖边误判成桥或割点，结果偏多。
原因：无向图 DFS 时父边会被当成子节点返祖边处理。
解法：DFS 时传 parent 边/节点，遇到父边直接 continue。

坑 3：Floyd 中间节点 k 放错层
结论：k 放在最内层会导致结果错误。
原因：Floyd 的 k 表示「允许经过的节点集合」逐步扩大，必须在最外层。
解法：严格按 k → i → j 三层循环顺序写。

坑 4：最大流只存正向边
结论：无法撤销错误的增广，得到的不是最大流。
原因：增广路径可能不是全局最优，需要反向边回退。
解法：每条边同时建容量为 0 的反向边，增广时同时更新正反容量。

坑 5：二分图判定漏掉非连通图
结论：只从 0 号节点 BFS，非连通部分没染色，误判为二分图。
原因：图可能不连通，单个起点覆盖不到全部顶点。
解法：外层循环遍历所有未染色节点，每个连通块都独立染色。
```
