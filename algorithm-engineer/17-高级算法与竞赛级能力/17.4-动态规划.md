## 概述

动态规划（DP）把大问题拆成有重叠的子问题，通过「状态定义 + 状态转移 + 记忆化」避免重复计算。它的核心是找到合适的状态表示和递推关系，配合最优子结构（子问题最优能推出整体最优）与无后效性。按问题形态分成背包、区间、树形、状压、数位、概率、DAG 等多类，进阶技巧（单调队列、凸包、分治、四边形不等式）则用于优化转移复杂度。

```text
DP 解题四步：
1. 定义状态 —— dp[i] 或 dp[i][j] 表示什么子问题的解
2. 找转移方程 —— 当前状态由哪些更小的状态推导
3. 确定边界/初始值 —— 最小子问题的答案
4. 确定计算顺序 —— 保证转移时依赖的状态已算好（拓扑序）
```

```text
# 通用记忆化框架（伪代码模板）
dp(state):
    若满足终止条件 → 返回基础值
    否则 → 返回 min/max(某选择 + dp(下一状态) for 每个选择)
```

```python
# 记忆化的具体实现：斐波那契
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:                 # 终止条件
        return n              # 基础值
    return fib(n - 1) + fib(n - 2)   # 选择 + 子状态

print(fib(40))   # 102334155，无记忆化会指数级爆炸
```

## Knapsack

背包问题是最经典的 DP 模型：在容量限制下选物品使价值最大。01 背包（每件取或不取）、完全背包（每件可取无限次）、多重背包（有限次数）是三个基本变体，核心都是「容量作为状态维度」的递推。

```text
复杂度：
01 背包 O(nW)，空间可滚动优化到 O(W)
完全背包 O(nW)
多重背包 O(nW log k)（二进制拆分后转 01 背包）

01 背包转移（一维滚动）：
dp[j] = max(dp[j], dp[j - w[i]] + v[i])，j 从 W 递减遍历
```

```python
def knapsack_01(weights, values, W):
    dp = [0] * (W + 1)
    for w, v in zip(weights, values):
        for j in range(W, w - 1, -1):     # 逆序防止同一物品被多次选
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[W]

weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
print(knapsack_01(weights, values, 8))    # 10
```

## Interval DP

区间 DP 在「区间 [l, r]」上定义状态，枚举分割点 k 把区间拆成两个更小的子区间合并。适合「合并石子、回文子序列、括号匹配」等「操作作用在区间上」的问题。

```text
复杂度：
O(n³)，枚举区间长度 × 起点 × 分割点

通用转移：
dp[l][r] = 合并(dp[l][k], dp[k+1][r]) 对所有 l ≤ k < r 取最优
遍历顺序：先枚举区间长度 len，再枚举左端点 l
```

```python
# 合并石子最小代价（经典区间 DP）
def merge_stones(stones):
    n = len(stones)
    prefix = [0] * (n + 1)
    for i, s in enumerate(stones):
        prefix[i + 1] = prefix[i] + s
    dp = [[float('inf')] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 0
    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            for k in range(l, r):
                cost = prefix[r + 1] - prefix[l]
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r] + cost)
    return dp[0][n - 1]
```

## Tree DP

树形 DP 在树的节点上定义状态，自底向上（后序遍历）从叶子向根汇总。常见状态是「选/不选当前节点」两类，转移时合并所有子树的结果。适合「最大独立集、树的直径、树的重心、选课」等问题。

```text
复杂度：
O(n)，每个节点与边各处理一次

典型状态：
dp[u][0] —— 不选 u 时子树的最优值
dp[u][1] —— 选 u 时子树的最优值
转移：先 DFS 子节点，再汇总到父节点
```

```python
def house_robber_tree(n, edges, vals):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)
    def dfs(u, parent):
        take, skip = vals[u], 0
        for v in g[u]:
            if v == parent:
                continue
            t, s = dfs(v, u)
            take += s            # 选 u 则子节点都不能选
            skip += max(t, s)    # 不选 u 则子节点可选可不选
        return take, skip
    return max(dfs(0, -1))
```

## State Compression DP

状压 DP 用二进制位的 0/1 表示「集合中元素是否被选中」，把集合状态压缩成一个整数，dp[mask] 表示「当前集合状态为 mask 时的最优解」。适合元素个数小（n ≤ 20）、状态是子集的场景，如旅行商、集合覆盖、分配任务。

```text
复杂度：
O(n · 2^n) 量级

状态表示：
mask 的二进制第 i 位为 1 表示第 i 个元素已被处理
转移：dp[mask | (1<<i)] 由 dp[mask] 扩展而来
```

```python
# 旅行商问题（TSP）：访问所有点后回到起点的最短路径
def tsp(n, dist):
    INF = float('inf')
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0                        # 从 0 出发，只访问了 0
    for mask in range(1 << n):
        for u in range(n):
            if not (mask >> u) & 1:
                continue
            for v in range(n):
                if (mask >> v) & 1:
                    continue
                dp[mask | (1 << v)][v] = min(
                    dp[mask | (1 << v)][v], dp[mask][u] + dist[u][v])
    return min(dp[(1 << n) - 1][u] + dist[u][0] for u in range(n))
```

## Digit DP

数位 DP 在「数字的十进制（或二进制）各位」上定义状态，从高位到低位逐位决策，统计满足条件的数字个数或最优值。核心是记忆化搜索 + 高位限制标记，解决「1 到 N 之间不含 4 的数字个数」这类问题。

```text
复杂度：
O(位数 × 进制 × 状态数)，通常 O(digits × 10 × state)

关键参数：
pos —— 当前处理到第几位
tight —— 是否受到 N 的上界约束
其他限制状态（如前一位是什么、是否已出现某数字）
```

```python
from functools import lru_cache

# 统计 [0, n] 中不含数字 4 的数有多少个
def count_without_four(n):
    s = str(n)
    @lru_cache(maxsize=None)
    def dfs(pos, tight):
        if pos == len(s):
            return 1
        limit = int(s[pos]) if tight else 9
        total = 0
        for d in range(limit + 1):
            if d == 4:
                continue
            total += dfs(pos + 1, tight and d == limit)
        return total
    return dfs(0, True)
```

## Probability DP

概率 DP 求「期望值 / 概率」：状态表示到达某局面时的期望步数或概率，转移方程带概率加权。常用「期望的线性性」拆解，或用「dp[i] = 1 + Σ p·dp[next]」的自指方程通过移项求解。

```text
复杂度：
视状态数和转移而定，通常 O(n) 或 O(n·m)

两类问题：
1. 求概率 —— 到达某状态的概率
2. 求期望 —— 到达终点的期望步数/收益，利用期望线性性
```

```python
# 期望线性性示例：掷骰子直到出现 6 的期望次数
def expected_rolls():
    p = 1 / 6                          # 每局独立
    return 1 / p                       # 几何分布期望 = 6

# 概率 DP：dp[i] 表示从 i 到终点的期望步数
def expected_steps(p_success):
    # dp = 1 + (1-p)*dp → dp = 1/p
    return 1 / p_success

print(expected_rolls())                # 6.0
```

## DAG DP

DAG 上的 DP 在「有向无环图」上做动态规划：先拓扑排序，再按拓扑序逐点转移。因为无环，拓扑序天然保证「转移依赖的状态已算好」，是 DP「无后效性」的最直接体现，常用于最长路径、路径计数。

```text
复杂度：
O(V+E)

步骤：
1. 拓扑排序得到线性顺序
2. 按拓扑序更新 dp[v] = max/min(dp[u] + w(u,v))
```

```python
def dag_longest_path(n, edges):
    g = defaultdict(list)
    indeg = [0] * n
    for u, v, w in edges:
        g[u].append((v, w))
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    dp = [0] * n
    topo = []
    while q:
        u = q.popleft()
        topo.append(u)
        for v, w in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    for u in topo:
        for v, w in g[u]:
            dp[v] = max(dp[v], dp[u] + w)
    return max(dp)
```

## Monotonic Queue Optimization

当 DP 转移形如 `dp[i] = max(dp[j] + g(i))` 且 j 属于一个随 i 单调滑动的窗口时，用单调队列把「窗口内求最值」从 O(n) 降到 O(1)，整体从 O(n²) 优化到 O(n)。

```text
复杂度：
O(n)（从朴素 O(n²) 优化）

适用形态：
dp[i] = max(dp[j] + 与 j 无关的项)，j ∈ [i-k, i-1]
窗口 [i-k, i-1] 随 i 单调右移 → 单调队列维护窗口内 dp[j] 最值
```

```python
from collections import deque

# 跳跃游戏 VI：dp[i] = nums[i] + max(dp[j])，j ∈ [i-k, i-1]
def max_result(nums, k):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    dq = deque([0])
    for i in range(1, n):
        while dq and dq[0] < i - k:
            dq.popleft()                     # 滑出窗口
        dp[i] = nums[i] + dp[dq[0]]
        while dq and dp[dq[-1]] <= dp[i]:
            dq.pop()                         # 维护队尾递减
        dq.append(i)
    return dp[-1]
```

## Convex Hull Trick

凸包优化（CHT）用于转移形如 `dp[i] = min(dp[j] + a[i]·b[j])` 的问题：把每个 j 看成一条直线 y = b[j]·x + dp[j]，查询在 x = a[i] 处的最小 y。维护直线集合的下凸包，用单调性（斜率/查询点单调时）做到均摊 O(1) 查询。

```text
复杂度：
O(n) 或 O(n log n)（取决于斜率/查询点是否单调）

适用形态：
dp[i] = min(dp[j] + a[i]·b[j] + c[i])，j < i
每条候选是一条直线，查询是给定 x 求所有直线的最小值
```

```python
from collections import deque

class ConvexHullTrick:
    def __init__(self):
        self.lines = deque()       # 存 (斜率, 截距)，斜率需按递减顺序插入

    def _bad(self, l1, l2, l3):
        # 判断 l2 是否被 l1、l3 完全支配（维护下凸包，min 查询）
        m1, b1 = l1; m2, b2 = l2; m3, b3 = l3
        return (b3 - b1) * (m1 - m2) <= (b2 - b1) * (m1 - m3)

    def add(self, m, b):
        # 弹出所有被新直线支配的末尾直线（deque 只支持从两端弹出，故从尾端弹）
        while len(self.lines) >= 2 and self._bad(self.lines[-2], self.lines[-1], (m, b)):
            self.lines.pop()
        self.lines.append((m, b))

    def query(self, x):
        # 查询点 x 单调递增时，弹出前面过时的直线
        while len(self.lines) >= 2:
            (m1, b1), (m2, b2) = self.lines[0], self.lines[1]
            if m1 * x + b1 >= m2 * x + b2:
                self.lines.popleft()
            else:
                break
        m, b = self.lines[0]
        return m * x + b

# 示例：斜率递减插入（3→2→1），查询点递增
cht = ConvexHullTrick()
for m, b in [(3, -15), (2, -5), (1, 0)]:
    cht.add(m, b)
print(cht.query(-10))   # 3*(-10)-15 = -45（斜率最大者在 x 小时最优）
print(cht.query(20))    # 1*20+0 = 20（斜率最小者在 x 大时最优）
```

## Divide and Conquer Optimization

分治优化用于「决策单调性」的区间 DP：若 dp[i][j] 的最优决策点 opt[i][j] 关于 i 单调，则可以把「枚举决策点」用分治缩小范围，复杂度从 O(n²k) 降到 O(nk log n)。

```text
复杂度：
O(nk log n)（从朴素 O(n²k) 优化）

前提：
决策单调性 —— opt[i][j] ≤ opt[i+1][j]
即第 i 个分割点的最优位置随 i 单调不减
```

```python
# 分治优化：dp[i][j] = min(dp[k][j-1] + cost(k, i))，k < i
def divide_conquer_dp(n, K, cost):
    INF = float('inf')
    dp = [[INF] * (K + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    def solve(j, l, r, optl, optr):
        if l > r:
            return
        mid = (l + r) // 2
        best, bestk = INF, -1
        for k in range(optl, min(mid, optr) + 1):
            val = dp[k][j - 1] + cost(k, mid)
            if val < best:
                best, bestk = val, k
        dp[mid][j] = best
        solve(j, l, mid - 1, optl, bestk)     # 左半决策点 ≤ bestk
        solve(j, mid + 1, r, bestk, optr)     # 右半决策点 ≥ bestk
    for j in range(1, K + 1):
        solve(j, 1, n, 0, n)
    return dp[n][K]
```

## Quadrangle Inequality Optimization

四边形不等式优化利用「代价函数满足四边形不等式」这一性质，把区间 DP 的决策点范围从 [l, r] 缩到 [opt[l][r-1], opt[l+1][r]]，使区间 DP 从 O(n³) 优化到 O(n²)。

```text
复杂度：
O(n²)（从朴素 O(n³) 优化）

前提：
代价函数 w 满足四边形不等式：
w(a,c) + w(b,d) ≤ w(a,d) + w(b,c)，其中 a ≤ b ≤ c ≤ d
且满足区间包含单调性
```

```python
# 四边形不等式优化：合并石子（决策点区间压缩）
def merge_stones_opt(stones):
    n = len(stones)
    prefix = [0] * (n + 1)
    for i, s in enumerate(stones):
        prefix[i + 1] = prefix[i] + s
    dp = [[0] * n for _ in range(n)]
    opt = [[0] * n for _ in range(n)]
    for i in range(n):
        opt[i][i] = i
    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            dp[l][r] = float('inf')
            # 决策点只在 [opt[l][r-1], opt[l+1][r]] 内枚举
            for k in range(opt[l][r - 1], min(opt[l + 1][r], r - 1) + 1):
                cost = prefix[r + 1] - prefix[l]
                val = dp[l][k] + dp[k + 1][r] + cost
                if val < dp[l][r]:
                    dp[l][r] = val
                    opt[l][r] = k
    return dp[0][n - 1]
```

## 应用场景实战

### 场景一：最长递增子序列（LIS，DP + 二分优化）

```python
import bisect

def length_of_lis(nums):
    tails = []                         # tails[i] = 长度为 i+1 的递增子序列最小结尾
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)

print(length_of_lis([10, 9, 2, 5, 3, 7, 101, 18]))   # 4 → [2,3,7,101]
```

### 场景二：编辑距离（二维 DP）

```python
def edit_distance(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
    return dp[m][n]

print(edit_distance('horse', 'ros'))   # 3
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先写状态定义和转移方程，再写代码，别一上来就堆循环
2. 背包一维滚动时 01 背包逆序、完全背包正序，别记反
3. 区间 DP 先枚举区间长度，保证子区间已算好
4. 状压 DP 控制 n ≤ 20，超出就换其他方法
5. 数位 DP 用记忆化 + tight 标记，别手写硬递推
6. 转移 O(n²) 超时再考虑单调队列/凸包/分治/四边形不等式优化

### 踩坑记录

```text
坑 1：01 背包一维数组正序遍历
结论：同一物品被选多次，退化成了完全背包。
原因：正序时 dp[j-w] 已经被本次物品更新过，重复利用。
解法：01 背包容量维度逆序（W → w），完全背包才正序。

坑 2：区间 DP 按左端点顺序而非区间长度
结论：转移到未计算的子区间，结果错误。
原因：子区间长度小于当前区间，必须先算完所有更短区间。
解法：外层枚举长度 len，内层枚举左端点 l。

坑 3：状压 DP 状态数爆掉
结论：n=25 时 2^25 约 3.3 千万，内存/时间爆炸。
原因：未评估 n 的规模就上状压。
解法：n ≤ 20 才用状压，更大用折半枚举或其他方法。

坑 4：数位 DP 忘记 tight 传递
结论：高位没贴满上界时，低位被错误地限制在 N 的对应位。
原因：tight 标记没作为状态传递下去。
解法：记忆化时把 tight 也作为状态维度，tight=True 时不缓存。

坑 5：决策单调性优化误用
结论：不满足决策单调性硬上分治/四边形优化，结果错误。
原因：opt[i][j] 单调是有前提的，需代价函数满足相应性质。
解法：先证明或打表验证决策单调性，再套优化。
```
