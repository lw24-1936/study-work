## 概述

数学算法是竞赛的数论与多项式工具箱：GCD/扩展 GCD 处理最大公约数与模逆元，筛法快速求素数，快速幂与矩阵快速幂加速幂运算与递推，模运算提供「取模下的四则运算」，组合数与容斥原理做计数，CRT 合并同余方程，FFT/NTT 做多项式乘法与卷积。它们常与 DP、组合计数结合出题。

```text
数学算法速查：
1. 最大公约数/最小公倍数 → GCD（欧几里得 O(log n)）
2. 模逆元 / 裴蜀方程 → Extended GCD
3. 素数判定/筛选 → 埃氏筛 / 欧拉筛（O(n)）
4. 大指数幂取模 → Fast Power（O(log n)）
5. 线性递推（斐波那契等）→ Matrix Exponentiation（O(k³ log n)）
6. 组合计数 / 同余方程 → 组合数 + CRT
7. 多项式乘法 / 卷积 → FFT（浮点）/ NTT（模数）
```

```python
MOD = 10**9 + 7   # 常用模数
```

## GCD

最大公约数用欧几里得算法（辗转相除）：gcd(a, b) = gcd(b, a mod b)，直到 b 为 0。它还能推出最小公倍数 lcm(a, b) = a·b / gcd(a, b)。

```text
复杂度：
O(log(min(a, b)))，每次取模至少减半
空间 O(1)

核心递推：
gcd(a, b) = gcd(b, a % b)，边界 gcd(a, 0) = a
```

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    return a // gcd(a, b) * b      # 先除后乘，防止溢出

print(gcd(48, 18))    # 6
print(lcm(4, 6))      # 12
```

## Extended GCD

扩展欧几里得求一组整数解 (x, y) 使 ax + by = gcd(a, b)（裴蜀定理保证解存在）。它用于求模逆元：当 gcd(a, m) = 1 时，a·x ≡ 1 (mod m) 的解就是 a 的逆元。

```text
复杂度：
O(log(min(a, b)))

核心结论：
1. 裴蜀定理 —— ax + by = c 有整数解当且仅当 gcd(a,b) | c
2. 模逆元 —— 由扩展 GCD 求 x 使 ax ≡ 1 (mod m)
```

```python
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = extended_gcd(b, a % b)
    x, y = y1, x1 - (a // b) * y1
    return g, x, y

def mod_inverse(a, m):
    g, x, _ = extended_gcd(a, m)
    return x % m if g == 1 else None      # 无逆元

print(extended_gcd(30, 18))               # (6, -1, 2)
print(mod_inverse(3, 11))                 # 4，因为 3*4=12≡1 mod 11
```

## Sieve

筛法批量求素数：埃氏筛从 2 开始筛掉每个素数的倍数；欧拉筛（线性筛）保证每个合数只被它的最小质因子筛掉一次，复杂度 O(n)，同时能顺便求每个数的最小质因子。

```text
复杂度：
埃氏筛 O(n log log n)；欧拉筛 O(n)
空间 O(n)

用途：
1. 判断 1..n 每个数是否为素数
2. 欧拉筛同时求最小质因子，用于质因数分解
```

```python
def euler_sieve(n):
    is_prime = [True] * (n + 1)
    primes = []
    min_factor = [0] * (n + 1)
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            min_factor[i] = i
        for p in primes:
            if i * p > n:
                break
            is_prime[i * p] = False
            min_factor[i * p] = p
            if i % p == 0:               # 保证每个合数只被最小质因子筛
                break
    return primes

print(euler_sieve(20))   # [2, 3, 5, 7, 11, 13, 17, 19]
```

## Fast Power

快速幂（二分幂）用「指数折半」把 a^n 从 O(n) 次乘法降到 O(log n)：n 为偶数时 a^n = (a^(n/2))²，奇数时多乘一个 a。取模版本在每一步 mod，避免大数溢出。

```text
复杂度：
O(log n)
空间 O(1)

原理：
a^n = (a²)^(n/2)     n 为偶数
a^n = a · (a²)^((n-1)/2)   n 为奇数
```

```python
def fast_pow(a, n, mod):
    res = 1
    a %= mod
    while n:
        if n & 1:
            res = res * a % mod
        a = a * a % mod
        n >>= 1
    return res

print(fast_pow(2, 10, MOD))    # 1024
print(fast_pow(2, 100, 7))     # 2^100 mod 7 = 2
```

## Modular Arithmetic

模运算定义「同余下的四则运算」：加、减、乘直接对结果取模即可；除法要乘「模逆元」。核心是让大数运算始终控制在 [0, mod) 范围内，防止溢出并保证结果正确。

```text
核心规则（mod 为质数时）：
1. (a + b) mod m = ((a mod m) + (b mod m)) mod m
2. (a × b) mod m = ((a mod m) × (b mod m)) mod m
3. a / b ≡ a × inv(b) (mod m)，inv 用费马小定理或扩展 GCD
4. 费马小定理：a^(p-1) ≡ 1 (mod p)，故 inv(a) = a^(p-2) mod p
```

```python
def mod_inv_fermat(a, p):
    return fast_pow(a, p - 2, p)         # p 为质数

def mod_div(a, b, p):
    return a * mod_inv_fermat(b, p) % p

print(mod_div(10, 3, MOD))               # 10/3 mod 1e9+7
```

## Matrix Exponentiation

矩阵快速幂把「矩阵乘法」和「快速幂」结合，用于 O(k³ log n) 求线性递推的第 n 项（如斐波那契）。核心是把递推写成矩阵形式 X[n] = A · X[n-1]，则 X[n] = A^n · X[0]。

```text
复杂度：
O(k³ log n)，k 为矩阵维度
空间 O(k²)

斐波那契矩阵：
[F(n)  ]   [1 1]^n   [F(1)]
[F(n-1)] = [1 0]   · [F(0)]
```

```python
def mat_mul(A, B, mod):
    n = len(A)
    C = [[0] * n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if A[i][k]:
                for j in range(n):
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % mod
    return C

def mat_pow(A, n, mod):
    k = len(A)
    res = [[1 if i == j else 0 for j in range(k)] for i in range(k)]
    while n:
        if n & 1:
            res = mat_mul(res, A, mod)
        A = mat_mul(A, A, mod)
        n >>= 1
    return res

def fib(n):
    A = [[1, 1], [1, 0]]
    An = mat_pow(A, n, MOD)
    return An[1][0]                      # F(n)

print(fib(10))                           # 55
```

## Combinatorics

组合数学处理「选与排列」的计数：组合数 C(n,k) = n!/(k!(n-k)!)、排列数 A(n,k) = n!/(n-k)!。取模下用「预处理阶乘 + 阶乘逆元」O(1) 求组合数，是计数 DP 的基础。

```text
复杂度：
预处理 O(n)，单次组合数 O(1)
空间 O(n)

取模组合数：
预处理 fact[i] = i! mod p 和 inv_fact[i]
C(n,k) = fact[n] × inv_fact[k] × inv_fact[n-k] mod p
```

```python
def precompute_factorials(n, mod):
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % mod
    inv_fact[n] = mod_inv_fermat(fact[n], mod)
    for i in range(n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % mod
    return fact, inv_fact

fact, inv_fact = precompute_factorials(100, MOD)
def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

print(comb(10, 3))                       # 120
```

## Inclusion-Exclusion

容斥原理用于「并集计数」：|A ∪ B ∪ C| = 各集合之和 - 两两交集 + 三三交集 - ...。它把「至少满足一个条件」的计数拆成「交集」的带符号求和，常用于「与 n 互质/不含某性质」的计数。

```text
核心公式：
|A₁ ∪ A₂ ∪ ... ∪ Aₙ| =
  Σ|Aᵢ| - Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| - ... + (-1)^(n+1)|A₁∩...∩Aₙ|

互补应用：
满足某性质的数量 = 总数 - 不满足的数量（用容斥算不满足的并集）
```

```python
# 求 [1, n] 中与 m 互质的数的个数（容斥 + 质因子分解）
def count_coprime(n, m):
    factors = []
    x = m
    for p in range(2, int(x ** 0.5) + 1):
        if x % p == 0:
            factors.append(p)
            while x % p == 0:
                x //= p
    if x > 1:
        factors.append(x)
    res = 0
    for mask in range(1 << len(factors)):
        prod, bits = 1, 0
        for i, p in enumerate(factors):
            if mask >> i & 1:
                prod *= p
                bits += 1
        res += (-1) ** bits * (n // prod)
    return n - res

print(count_coprime(10, 6))              # 与 6 互质：1,5,7 → 3
```

## CRT

中国剩余定理（CRT）解「互质模数的同余方程组」：x ≡ aᵢ (mod mᵢ)，mᵢ 两两互质时解唯一（模 M = ∏mᵢ）。先求每个 Mᵢ = M/mᵢ 及其逆元，再线性组合得到 x。

```text
复杂度：
O(k log M)，k 为方程个数

核心公式（mᵢ 两两互质）：
M = ∏mᵢ，Mᵢ = M/mᵢ，tᵢ = Mᵢ⁻¹ mod mᵢ
x = Σ aᵢ · Mᵢ · tᵢ (mod M)
```

```python
def crt(remainders, moduli):
    M = 1
    for m in moduli:
        M *= m
    x = 0
    for a, m in zip(remainders, moduli):
        Mi = M // m
        ti = mod_inverse(Mi, m)
        x = (x + a * Mi * ti) % M
    return x

# x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7) → x = 23
print(crt([2, 3, 2], [3, 5, 7]))         # 23
```

## FFT

快速傅里叶变换（FFT）在 O(n log n) 做多项式乘法/卷积：把系数表示转成点值表示（DFT），点值相乘，再转回（IDFT）。它用复数单位根分治，是大整数乘法、卷积、信号处理的基础。

```text
复杂度：
O(n log n)，n 为卷积长度（补到 2 的幂）
空间 O(n)

流程：
1. 系数 → 点值（FFT，用单位根）
2. 点值逐点相乘
3. 点值 → 系数（IFFT）
浮点误差需四舍五入处理
```

```python
import cmath

def fft(a, invert):
    n = len(a)
    if n == 1:
        return a
    a0 = fft(a[0::2], invert)
    a1 = fft(a[1::2], invert)
    ang = 2 * cmath.pi / n * (-1 if invert else 1)
    w = complex(1, 0)
    wn = complex(cmath.cos(ang), cmath.sin(ang))
    res = [0] * n
    for k in range(n // 2):
        res[k] = a0[k] + w * a1[k]
        res[k + n // 2] = a0[k] - w * a1[k]
        if invert:
            res[k] /= 2
            res[k + n // 2] /= 2
        w *= wn
    return res

def multiply(poly1, poly2):
    n = 1
    while n < len(poly1) + len(poly2):
        n <<= 1
    a = poly1 + [0] * (n - len(poly1))
    b = poly2 + [0] * (n - len(poly2))
    fa = fft(a, False)
    fb = fft(b, False)
    for i in range(n):
        fa[i] *= fb[i]
    res = fft(fa, True)
    return [round(x.real) for x in res]
```

## NTT

数论变换（NTT）是「模意义下的 FFT」：用「原根的单位根」替代复数单位根，在整数模素数域做变换，避免浮点误差。要求模数是形如 p = c·2^k + 1 的质数（如 998244353），结果精确。

```text
复杂度：
O(n log n)

与 FFT 的区别：
1. FFT 用复数、有浮点误差；NTT 用模素数、结果精确
2. NTT 要求模数有足够的 2 的幂次因子（p-1 含 2^k）
3. 大数乘法可用「多个 NTT 模数 + CRT」合并结果
```

```python
MOD_NTT = 998244353
G = 3                                  # 原根

def ntt(a, invert):
    n = len(a)
    j = 0
    for i in range(1, n):               # 位反转置换
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]
    length = 2
    while length <= n:
        wlen = fast_pow(G, (MOD_NTT - 1) // length, MOD_NTT)
        if invert:
            wlen = fast_pow(wlen, MOD_NTT - 2, MOD_NTT)
        for i in range(0, n, length):
            w = 1
            for k in range(length // 2):
                u = a[i + k]
                v = a[i + k + length // 2] * w % MOD_NTT
                a[i + k] = (u + v) % MOD_NTT
                a[i + k + length // 2] = (u - v) % MOD_NTT
                w = w * wlen % MOD_NTT
        length <<= 1
    if invert:
        inv_n = fast_pow(n, MOD_NTT - 2, MOD_NTT)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD_NTT
    return a
```

def sum_1_to_n(n):
    # 1 + 2 + ... + n = n(n+1)/2，除法用模逆元
    return n * (n + 1) % MOD * mod_inv_fermat(2, MOD) % MOD

## 最佳实践与踩坑记录

### 最佳实践

1. lcm 先除后乘（a // gcd × b），防止中间溢出
2. 取模乘法用 Python 直接 (a * b) % mod 即可，大数不会溢出；C++ 需用 long long 或快速乘
3. 除法取模必须乘模逆元，别直接 (a / b) % mod
4. 组合数预处理阶乘 + 阶乘逆元，O(1) 查询，别每次现算
5. 递推第 n 项（斐波那契等）用矩阵快速幂，别 O(n) 线性推
6. 多项式乘法首选 NTT（精确），浮点精度要求低时可用 FFT

### 踩坑记录

```text
坑 1：lcm 直接 a * b 再除
结论：a、b 较大时乘积溢出（C++）或 Python 产生超大整数拖慢运算。
原因：先乘后除中间值超出整数范围。
解法：先除后乘 lcm = a // gcd(a, b) * b。

坑 2：除法取模直接取模
结论：(a / b) % mod 结果错误（浮点或截断）。
原因：模运算下除法不等价于普通除法，需要逆元。
解法：a * mod_inv(b, mod) % mod，用费马小定理或扩展 GCD 求逆元。

坑 3：费马小定理求逆元时 mod 非质数
结论：a^(p-2) 求出的「逆元」不正确。
原因：费马小定理要求 p 为质数且 gcd(a, p) = 1。
解法：非质数模数改用扩展 GCD 求逆元。

坑 4：CRT 在非互质模数下直接套用
结论：模数不两两互质时解不存在或结果错误。
原因：标准 CRT 要求模数两两互质。
解法：非互质情况用扩展 CRT（逐对合并 exCRT）。

坑 5：FFT 结果直接当整数
结论：浮点误差导致卷积系数差 1 或出现小数。
原因：FFT 用复数运算，存在舍入误差。
解法：结果 round() 取整；要求精确用 NTT（模数下无误差）。
```
