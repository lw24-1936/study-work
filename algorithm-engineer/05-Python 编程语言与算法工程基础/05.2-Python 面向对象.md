## 概述

面向对象编程（OOP）把数据和操作数据的方法封装成对象。Python 的 OOP 灵活而务实：类本身也是对象、支持多重继承、属性访问可被 property 和 descriptor 拦截。算法工程里，它常用于封装数据集、模型、特征工程流水线等有状态组件。

```text
面向对象的核心思想：
1. 封装 —— 数据 + 方法打包成对象，隐藏内部实现
2. 继承 —— 子类复用父类代码，表达 is-a 关系
3. 多态 —— 同一接口不同实现，调用方无需关心具体类型
4. 组合 —— 用 has-a 关系组装对象，比继承更灵活
```

```python
class Point:
    """二维坐标点，展示最基本的类定义。"""
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def distance_to_origin(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

p = Point(3, 4)
print(p.distance_to_origin())   # 5.0
```

## Class

类用 `class` 关键字定义，是创建对象的模板。`__init__` 是构造方法，`self` 指向实例本身。类体里的变量是类属性（所有实例共享），实例属性通过 `self.xxx` 定义。

```python
class Dog:
    species = "Canis"          # 类属性：所有实例共享

    def __init__(self, name):
        self.name = name       # 实例属性：每个实例独立

d1 = Dog("旺财")
d2 = Dog("来福")
print(d1.species, d2.species)  # Canis Canis（共享类属性）
print(d1.name, d2.name)        # 旺财 来福（独立实例属性）
```

```text
类属性 vs 实例属性：
1. 类属性定义在类体中，通过 类名.attr 或 实例.attr 访问，全局共享
2. 实例属性定义在 __init__ 里，绑定到具体实例
3. 修改实例.类属性 会创建同名实例属性，遮蔽类属性
```

## Object

在 Python 中一切皆对象，包括类本身；所有类都隐式继承自 `object`（Python 3 新式类）。`object` 提供了默认的 `__str__`、`__repr__`、`__eq__` 等行为，可被重写。实例化就是调用类产生新对象的过程。

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def __repr__(self):        # 重写 object 提供的方法
        return f"Car({self.brand!r})"

    def __eq__(self, other):   # 默认 == 比较 id，这里改为比较 brand
        return isinstance(other, Car) and self.brand == other.brand

c1 = Car("Tesla")
c2 = Car("Tesla")
print(repr(c1))                # Car('Tesla')
print(c1 == c2)                # True（默认会是 False）
print(isinstance(c1, object))  # True —— 一切皆继承自 object
```

```text
object 提供的默认方法（可重写）：
1. __repr__ —— 开发者可读的表示，调试用
2. __str__ —— 用户可读的表示，print 用
3. __eq__ —— 相等比较，默认比 id
4. __hash__ —— 哈希，定义 __eq__ 后需同步处理
```

## Inheritance

继承让子类复用父类的属性和方法，表达「is-a」关系。Python 支持多重继承，方法解析顺序（MRO）用 C3 线性化算法决定。`super()` 用于调用父类方法。

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError

class Cat(Animal):            # 继承 Animal
    def speak(self):
        return f"{self.name} 说：喵"

class Dog(Animal):
    def speak(self):
        return f"{self.name} 说：汪"

print(Cat("咪咪").speak())    # 咪咪 说：喵
print(Cat.__mro__)            # (Cat, Animal, object) 方法解析顺序
```

```python
# super() 调用父类 __init__
class Puppy(Dog):
    def __init__(self, name, age):
        super().__init__(name)   # 调用 Animal.__init__（Dog 未定义 __init__，向上继承）
        self.age = age

print(Puppy("小黄", 1).speak(), Puppy("小黄", 1).age)
```

```text
继承要点：
1. super() 按 MRO 找下一个实现，多重继承时保证父类只初始化一次
2. 优先「组合优于继承」，继承只用于真正的 is-a 关系
3. MRO 用 C3 算法，复杂多重继承可能报无法线性化
```

## Composition

组合是「一个对象包含另一个对象」，表达 has-a 关系。相比继承，组合耦合更低、更灵活，是 GoF 设计原则「组合优于继承」的体现，也是算法工程里最常用的组装方式。

```python
class Engine:
    def start(self):
        return "引擎启动"

class Wheels:
    def roll(self):
        return "车轮滚动"

class Car:
    def __init__(self):
        self.engine = Engine()   # has-a：Car 包含 Engine
        self.wheels = Wheels()

    def run(self):
        return self.engine.start() + "，" + self.wheels.roll()

print(Car().run())               # 引擎启动，车轮滚动
```

```text
继承 vs 组合：
1. 继承 —— is-a，子类继承父类接口，但强耦合、难改
2. 组合 —— has-a，通过持有对象复用，接口独立、灵活
3. 优先组合，只有明确的层次关系才用继承
```

## Polymorphism

多态指「同一接口、多种实现」：不同的对象对同一个方法调用做出各自的行为。Python 是鸭子类型——不检查类型，只要对象有对应方法就能调用，让代码对扩展开放、对修改关闭。

```python
class Circle:
    def area(self):
        return 3.14 * 2 * 2

class Square:
    def area(self):
        return 4 * 4

def print_area(shape):          # 不关心具体类型，只要求有 area()
    print(f"面积 = {shape.area()}")

print_area(Circle())            # 面积 = 12.56
print_area(Square())            # 面积 = 16
```

```text
鸭子类型（Duck Typing）：
1. 不检查 isinstance，只检查「有没有所需的方法」
2. 好处：无需继承同一基类也能复用同一接口
3. 风险：错误在运行时才暴露，可用类型注解 + 静态检查缓解
```

## Abstract Base Class

抽象基类（ABC）用 `abc` 模块定义接口：声明抽象方法，强制子类实现，否则无法实例化。它在鸭子类型的基础上，为接口提供显式约束和运行时检查。

```python
from abc import ABC, abstractmethod

class Model(ABC):
    @abstractmethod
    def fit(self, X, y):
        """训练模型，子类必须实现"""

    @abstractmethod
    def predict(self, X):
        """预测，子类必须实现"""

class LinearModel(Model):
    def fit(self, X, y):
        self.w = sum(x * yy for x, yy in zip(X, y)) / sum(x * x for x in X)
        return self

    def predict(self, X):
        return [self.w * x for x in X]

m = LinearModel().fit([1, 2, 3], [2, 4, 6])
print(m.predict([4, 5]))        # [8.0, 10.0]
```

```text
ABC 要点：
1. @abstractmethod 声明的方法，子类不实现就不能实例化
2. 抽象类本身不能直接实例化
3. 也可用 register() 把已存在的类虚拟注册为抽象类的子类
```

## Dataclass

`@dataclass` 自动生成 `__init__`、`__repr__`、`__eq__` 等样板方法，让「数据容器类」的定义极简。它是配置对象、特征记录、请求/响应模型的理想选择，替代手写一堆样板代码。

```python
from dataclasses import dataclass, field

@dataclass
class Feature:
    name: str
    dtype: str = "float"              # 默认值
    tags: list = field(default_factory=list)  # 可变默认值用 factory

f1 = Feature("age")
f2 = Feature("age")
print(f1)                            # Feature(name='age', dtype='float', tags=[])
print(f1 == f2)                      # True —— 自动按字段比较
```

```text
dataclass 常用参数：
1. frozen=True —— 生成不可变对象（可哈希）
2. order=True —— 自动生成比较方法
3. field(default_factory=...) —— 可变默认值，避免共享坑
4. 可用 __post_init__ 做初始化后的校验
```

## Property

`@property` 把方法伪装成属性，让外部用 `obj.attr` 的语法触发 getter/setter，从而在「看起来是属性」的背后做校验、计算、懒加载。它实现了封装而不牺牲简洁语法。

```python
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self):
        return self._radius

    @radius.setter
    def radius(self, value):
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):                 # 只读计算属性
        return 3.14159 * self._radius ** 2

c = Circle(2)
print(c.radius, c.area)             # 2 12.56636
c.radius = 5                        # 触发 setter 校验
print(c.area)                       # 78.53975
```

```text
property 三种用法：
1. @property —— 只读 getter
2. @x.setter —— 写保护 + 校验
3. @x.deleter —— 删除时的行为
```

## Descriptor

描述符是实现了 `__get__`/`__set__`/`__delete__` 中任意方法的对象，作为类属性时能拦截该属性的访问。property 本质就是描述符。描述符是 Python 元编程的利器，用于实现验证、ORM 字段、缓存等。

```python
class Positive:
    """描述符：强制属性为正数"""
    def __set_name__(self, owner, name):
        self.storage = f"_{name}"     # 记录实际存储用的属性名

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return getattr(obj, self.storage)

    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError("必须为正数")
        setattr(obj, self.storage, value)

class Account:
    balance = Positive()              # 类属性挂载描述符

a = Account()
a.balance = 100                       # 触发 __set__ 校验
print(a.balance)                      # 100，触发 __get__
# a.balance = -5                      # ValueError: 必须为正数
```

```text
描述符 vs property：
1. property 针对单个属性，代码内联
2. 描述符是可复用的类，一处定义多处使用
3. 数据描述符（有 __set__）优先级高于实例字典，是校验/ORM 的基础
```

## Magic Methods

魔术方法（dunder，双下划线方法）定义对象如何与语言特性交互：算术运算、比较、迭代、上下文管理、字符串表示等。重写它们能让自定义对象表现得像内置类型一样自然。

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):              # v1 + v2
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):             # v * n
        return Vector(self.x * scalar, self.y * scalar)

    def __len__(self):                     # len(v)
        return 2

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

    def __call__(self):                    # v()
        return (self.x, self.y)

v1, v2 = Vector(1, 2), Vector(3, 4)
print(v1 + v2)              # Vector(4, 6)
print(v1 * 3)               # Vector(3, 6)
print(len(v1), v1())        # 2 (1, 2)
```

```text
常用魔术方法分类：
1. 初始化/表示 —— __init__, __repr__, __str__
2. 运算 —— __add__, __sub__, __mul__, __truediv__
3. 比较 —— __eq__, __lt__, __le__, __hash__
4. 容器 —— __len__, __getitem__, __setitem__, __iter__, __contains__
5. 上下文 —— __enter__, __exit__
```

## 应用场景实战

### 场景一：用 dataclass + ABC 定义机器学习模型接口

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass

@dataclass
class ModelConfig:
    learning_rate: float = 0.01
    epochs: int = 100
    name: str = "model"

class BaseModel(ABC):
    @abstractmethod
    def fit(self, X, y): ...

    @abstractmethod
    def predict(self, X): ...

class MeanModel(BaseModel):
    def __init__(self, config: ModelConfig):
        self.config = config

    def fit(self, X, y):
        self.mean = sum(y) / len(y)
        return self

    def predict(self, X):
        return [self.mean] * len(X)

m = MeanModel(ModelConfig(name="mean-baseline"))
m.fit([1, 2, 3], [10, 20, 30])
print(m.predict([0, 0]))    # [20.0, 20.0]
```

### 场景二：用 descriptor + property 实现带校验的配置对象

```python
class Bounded:
    def __set_name__(self, owner, name):
        self.name = f"_{name}"

    def __get__(self, obj, objtype=None):
        return getattr(obj, self.name)

    def __set__(self, obj, value):
        if not (0 <= value <= 1):
            raise ValueError("概率必须在 [0, 1] 区间")
        setattr(obj, self.name, value)

class ThresholdConfig:
    threshold = Bounded()

c = ThresholdConfig()
c.threshold = 0.85
print(c.threshold)          # 0.85
# c.threshold = 1.5          # ValueError
```

## 最佳实践与踩坑记录

### 最佳实践

1. 优先组合优于继承，继承只用于真正的 is-a 关系
2. 数据容器类用 @dataclass，别手写 __init__/__repr__ 样板
3. 需要约束子类实现接口时用 ABC，需要轻量接口用鸭子类型
4. 可变默认参数用 field(default_factory=...)，避免共享坑
5. 外部访问属性需要校验/计算时用 property，不要直接暴露裸属性
6. 重写 __eq__ 时同步重写 __hash__（或设 __hash__ = None）

### 踩坑记录

```text
坑 1：可变默认参数被共享
结论：多个实例共享同一个 list 默认值，互相污染数据。
原因：默认值在函数定义时只求值一次，之后复用同一对象。
解法：用 field(default_factory=list) 或函数体内初始化。

坑 2：重写 __eq__ 没重写 __hash__
结论：对象放进 set/dict 时报 TypeError: unhashable。
原因：定义 __eq__ 会隐式把 __hash__ 置为 None。
解法：同时重写 __hash__，或用 frozen dataclass 自动处理。

坑 3：混淆类属性与实例属性
结论：通过实例修改类属性，其他实例看到的值不一致。
原因：实例赋值会创建同名实例属性，遮蔽类属性。
解法：类属性只读时直接访问，需要修改时用 类名.attr。

坑 4：多重继承 MRO 冲突
结论：菱形继承或复杂继承关系报 MRO 无法线性化。
原因：C3 线性化算法找不到满足所有父类顺序的解析顺序。
解法：简化继承层次，优先用组合，或显式设计 MRO。

坑 5：property 里 getter/setter 命名冲突
结论：getter 和 setter 同名导致递归调用或覆盖。
原因：setter 装饰器必须紧跟同名 property 定义。
解法：@property 定义 getter，@name.setter 定义 setter，内部存 _name。
```
