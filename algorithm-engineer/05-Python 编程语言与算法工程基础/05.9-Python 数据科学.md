## 概述

数据科学的 Python 技术栈由两块基石构成：NumPy 负责底层的数值数组运算，Pandas 负责高层的表格数据操作。算法工程师的建模流程——数据加载、清洗、特征工程、统计分析——几乎每一步都离不开这两把工具，理解它们的核心机制能显著提升工作效率。

```text
数据科学核心能力分层：
1. NumPy 层 —— ndarray、广播、向量化、ufunc、线性代数、随机数
2. Pandas 层 —— Series/DataFrame、groupby、merge、pivot、窗口、时间序列
3. 方法论 —— 向量化思维、链式操作、按索引对齐运算

关键思想：
能用数组运算就别写循环，能用 DataFrame 就别用嵌套 dict
```

```python
import numpy as np
import pandas as pd

# 数据科学的最小闭环：生成数据 → 分析 → 聚合
rng = np.random.default_rng(42)
df = pd.DataFrame({
    'x': rng.normal(0, 1, 1000),
    'group': rng.choice(['A', 'B'], 1000),
})
print(df.groupby('group')['x'].agg(['mean', 'std']))
```

## NumPy ndarray

ndarray 是 NumPy 的核心对象：同构、连续内存、固定形状的多维数组。它比 Python list 快几十倍、省内存，是所有数值计算的载体。形状（shape）、类型（dtype）、步长（strides）是理解它的三个关键属性。

```text
ndarray 核心属性：
1. shape —— 每个维度的长度，reshape 改变形状
2. dtype —— 元素类型，float64 / int32 / bool 等
3. ndim —— 维度数
4. strides —— 每维的字节步长，决定内存布局
5. 内存连续 —— 行优先（C order）访问最快
```

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]], dtype=np.float64)
print(a.shape, a.dtype, a.ndim)   # (2, 3) float64 2
print(a.strides)                  # (24, 8) 每行 24 字节，每元素 8 字节

# reshape 与展平
print(a.reshape(3, 2))
print(a.ravel())                  # 展平为一维

# 创建常用数组
print(np.zeros((2, 3)))
print(np.ones(3))
print(np.linspace(0, 1, 5))       # 等间隔 5 个点
print(np.arange(5))               # [0 1 2 3 4]
```

## broadcasting

广播（broadcasting）是 NumPy 处理不同形状数组运算的规则：当形状不匹配时，从右往左对齐维度，长度为 1 的维度自动扩展。它让你无需显式复制数据就能做「标量加矩阵」「矩阵加行向量」等运算，既省内存又快。

```text
广播规则（从右往左逐维比较）：
1. 维度长度相等 → 直接匹配
2. 其中一个长度为 1 → 扩展到另一个的长度
3. 长度不等且都不是 1 → 报错

典型例子：
(3, 1) + (1, 4) → (3, 4)
(3, 4) + (4,)   → (3, 4)，行向量广播到每一行
```

```python
import numpy as np

a = np.array([[1, 2, 3],
              [4, 5, 6]])       # (2, 3)

# 标量广播
print(a + 10)                   # 每个元素加 10

# 行向量广播到每一行
row = np.array([1, 2, 3])       # (3,)
print(a + row)                  # 每行分别加 [1,2,3]

# 列向量广播到每一列
col = np.array([[10], [20]])    # (2, 1)
print(a + col)

# 广播生成网格（无需 meshgrid 的显式复制）
x = np.arange(3)[:, None]       # (3, 1)
y = np.arange(4)[None, :]       # (1, 4)
print((x + y).shape)            # (3, 4)
```

## vectorization

向量化是用整块数组运算替代逐元素 Python 循环的编程范式。它把循环下沉到 C 层执行，消除解释器的逐条字节码开销，通常有 10-100 倍性能提升，也是让代码更简洁的写法。

```text
向量化要点：
1. 用数组运算（+ * / 比较）替代 for 循环
2. 用 NumPy 内置函数（sum、mean、where、clip）替代条件分支
3. 用布尔掩码替代 if 判断
4. 避免在循环里对数组做小操作（固定开销累积）
```

```python
import numpy as np

data = np.random.randn(100_000)

# 非向量化
def loop():
    out = np.empty_like(data)
    for i in range(len(data)):
        out[i] = data[i] * 2 if data[i] > 0 else data[i]
    return out

# 向量化：一行替代整个循环
def vec():
    return np.where(data > 0, data * 2, data)

print(np.allclose(loop(), vec()))   # True

# 布尔掩码做条件选择
mask = data > 0
result = data.copy()
result[mask] = result[mask] * 2     # 只改正数
```

## ufunc

ufunc（universal function，通用函数）是 NumPy 对数组逐元素运算的 C 级实现，包括算术运算（add、multiply）、数学函数（sin、exp、log）、比较运算（greater、equal）。它支持 out 参数复用内存、reduce 归约、accumulate 累积等高级用法。

```text
ufunc 关键能力：
1. 元素级 —— 对数组每个元素独立运算，速度快
2. 广播 —— 自动支持不同形状输入
3. out= —— 把结果写到已存在的数组，避免分配新内存
4. reduce —— 沿轴归约（如 np.add.reduce 就是求和）
5. accumulate —— 沿轴累积（如 cumsum）
```

```python
import numpy as np

a = np.array([1, 2, 3, 4])

# 算术 ufunc
print(np.add(a, 10))        # [11 12 13 14]
print(np.multiply(a, a))    # [1 4 9 16]

# 数学 ufunc
print(np.sqrt(a))           # 平方根
print(np.exp(a))            # e 的幂

# out 参数复用内存
buf = np.empty_like(a, dtype=float)
np.sqrt(a, out=buf)
print(buf)

# reduce 与 accumulate
print(np.add.reduce(a))      # 10，即 sum
print(np.add.accumulate(a))  # [1 3 6 10]，即 cumsum
```

## linear algebra

NumPy 的 linalg 模块（以及更全的 scipy.linalg）提供矩阵分解、求解、特征值等线性代数运算。机器学习里的正规方程、PCA、SVD 都依赖这些底层实现。

```text
常用线性代数运算：
1. dot / @ —— 矩阵乘法
2. inv —— 逆矩阵
3. solve —— 解线性方程组 Ax = b
4. det —— 行列式
5. eig —— 特征值与特征向量
6. svd —— 奇异值分解（PCA 的基础）
```

```python
import numpy as np

A = np.array([[3, 1], [1, 2]])
b = np.array([9, 8])

# 矩阵乘法
print(A @ A)                       # [[10  5] [ 5  5]]

# 解方程 Ax = b
print(np.linalg.solve(A, b))       # [2. 3.]

# 特征值分解
vals, vecs = np.linalg.eig(A)
print(vals)                        # 特征值

# SVD：A = U S V^T
U, S, Vt = np.linalg.svd(A)
print(S)                           # 奇异值，PCA 用前 k 个做降维

# 正规方程求线性回归系数
X = np.c_[np.ones(4), np.arange(4)]
y = np.array([1, 3, 5, 7])
w = np.linalg.inv(X.T @ X) @ X.T @ y
print(w)                           # 截距和斜率
```

## random

NumPy 的 random 模块提供高性能随机数生成。现代推荐用 Generator（default_rng），而不是旧的 np.random.* 全局函数，因为前者算法更好、可复现性更清晰、支持并行安全。

```text
随机数要点：
1. default_rng(seed) —— 现代推荐，返回 Generator 对象
2. 分布 —— normal、uniform、integers、choice、poisson
3. 可复现 —— 固定 seed 得到相同序列
4. 并行 —— 每个进程用不同 seed，避免生成相同序列
5. 旧 API —— np.random.seed 是全局状态，不推荐再用
```

```python
import numpy as np

rng = np.random.default_rng(42)   # 固定种子，结果可复现

print(rng.normal(0, 1, 5))        # 标准正态 5 个
print(rng.uniform(0, 1, 5))       # 均匀分布
print(rng.integers(0, 10, 5))     # 0-9 的整数
print(rng.choice(['a', 'b', 'c'], 5, p=[0.5, 0.3, 0.2]))  # 带概率抽样

# 相同种子 → 相同序列
r1 = np.random.default_rng(7)
r2 = np.random.default_rng(7)
print(np.array_equal(r1.normal(size=10), r2.normal(size=10)))  # True
```

## statistics

统计描述和统计推断是数据分析的基础：用 describe 看分布，用均值/中位数/标准差刻画中心与离散，用分位数和假设检验判断差异是否显著。SciPy 的 stats 模块补齐了 NumPy 缺的推断统计。

```text
统计三板斧：
1. 描述统计 —— mean、median、std、var、min/max、quantile
2. 分布刻画 —— 偏度、峰度、直方图、分位数
3. 推断统计 —— t 检验、卡方检验、置信区间（scipy.stats）
```

```python
import numpy as np
from scipy import stats

data = np.random.default_rng(0).normal(100, 15, 1000)

# 描述统计
print(f'mean={data.mean():.2f}, median={np.median(data):.2f}')
print(f'std={data.std():.2f}, var={data.var():.2f}')
print(f'分位数: {np.percentile(data, [25, 50, 75])}')

# 推断统计：均值是否等于 100 的 t 检验
t, p = stats.ttest_1samp(data, popmean=100)
print(f't={t:.3f}, p={p:.3f}')

# 两组样本差异检验
a = np.random.default_rng(1).normal(100, 15, 500)
b = np.random.default_rng(2).normal(105, 15, 500)
t2, p2 = stats.ttest_ind(a, b)
print(f'两组比较 t={t2:.3f}, p={p2:.4f}')
```

## Pandas Series/DataFrame

Series 是一维带标签数组，DataFrame 是二维表格。它们建立在 NumPy 之上，但多了索引对齐、缺失值处理、异构列类型等能力，是数据分析的主要载体。

```text
Series/DataFrame 核心：
1. 索引 —— 行 index 和列 columns，操作自动按标签对齐
2. 缺失值 —— NaN 表示，isna/fillna/dropna 处理
3. 选择 —— loc（标签）/ iloc（位置）/ 布尔索引
4. 异构 —— 不同列可以不同类型（数值、字符串、时间）
5. 链式 —— 方法返回新对象，可连续调用
```

```python
import pandas as pd

s = pd.Series([1, 2, 3, None], index=['a', 'b', 'c', 'd'])
print(s)
print(s.isna())           # 缺失值标记
print(s.fillna(0))        # 填充

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara'],
    'age': [25, 30, 28],
    'score': [88.5, 92.0, 95.5],
})
print(df.loc[0, 'name'])        # 标签定位
print(df.iloc[1, 2])            # 位置定位
print(df[df['score'] > 90])     # 布尔索引
print(df.dtypes)                # 各列类型
```

## groupby

groupby 是「分拆-应用-合并」模式：按一个或多个键把数据分组，对每组应用聚合或变换，再合并结果。它是数据分析中最常用的操作，配合 agg 能一次算多个统计量。

```text
groupby 三阶段：
1. split —— 按 key 拆成若干组
2. apply —— 对每组做聚合（sum/mean）、变换（transform）、过滤（filter）
3. combine —— 合并结果

常用：
agg 一次算多个指标；transform 保持原形状回填组内统计
```

```python
import pandas as pd

df = pd.DataFrame({
    'dept': ['ML', 'ML', 'CV', 'CV', 'CV'],
    'team': ['a', 'b', 'a', 'b', 'a'],
    'salary': [120, 90, 110, 95, 88],
    'years': [3, 2, 4, 3, 2],
})

# 单键分组 + 多指标聚合
print(df.groupby('dept')['salary'].agg(['mean', 'max', 'count']))

# 多键分组
print(df.groupby(['dept', 'team'])['salary'].mean())

# transform：组内标准化（保持原形状）
df['salary_z'] = df.groupby('dept')['salary'].transform(
    lambda x: (x - x.mean()) / x.std())
print(df)
```

## merge/join

merge 和 join 用于按键合并两张表，是关系型数据操作的核心。merge 按列匹配（类似 SQL JOIN），支持 inner/left/right/outer 四种连接方式；join 是按索引合并的便捷封装。

```text
merge 关键参数：
1. on —— 连接的键列
2. how —— inner（交集）/ left / right / outer（并集）
3. left_on / right_on —— 两边键名不同时用
4. 多对多连接会产生笛卡尔积，注意行数膨胀
```

```python
import pandas as pd

users = pd.DataFrame({
    'user_id': [1, 2, 3],
    'name': ['Alice', 'Bob', 'Cara'],
})
orders = pd.DataFrame({
    'user_id': [1, 2, 1, 4],
    'amount': [50, 80, 30, 120],
})

# inner join：只保留两边都有的 user_id
print(users.merge(orders, on='user_id', how='inner'))

# left join：保留 users 全部，orders 没有的填 NaN
print(users.merge(orders, on='user_id', how='left'))

# 键名不同 + outer join
orders2 = orders.rename(columns={'user_id': 'uid'})
print(users.merge(orders2, left_on='user_id', right_on='uid', how='outer'))
```

## pivot

pivot 和 pivot_table 把「长表」转成「宽表」：选一列作行索引、一列作列索引、一列作值。pivot_table 支持聚合（应对重复键），是交叉表分析、特征宽化的常用工具。

```text
pivot vs pivot_table：
1. pivot —— 要求行+列组合唯一，不聚合，纯重塑
2. pivot_table —— 重复组合自动聚合（默认 mean），可指定 aggfunc
3. melt —— 反向操作，宽表转长表
4. 常见用途 —— 生成特征矩阵、透视汇总
```

```python
import pandas as pd

df = pd.DataFrame({
    'date': ['2024-01-01', '2024-01-01', '2024-01-02', '2024-01-02'],
    'city': ['北京', '上海', '北京', '上海'],
    'sales': [100, 150, 120, 180],
})

# pivot：城市做列，日期做行
wide = df.pivot(index='date', columns='city', values='sales')
print(wide)

# pivot_table：有重复时聚合
df2 = pd.DataFrame({
    'date': ['2024-01-01', '2024-01-01', '2024-01-01'],
    'city': ['北京', '北京', '上海'],
    'sales': [100, 200, 150],
})
print(df2.pivot_table(index='date', columns='city',
                      values='sales', aggfunc='sum'))

# melt：宽表转回长表
print(wide.reset_index().melt(id_vars='date',
                              var_name='city', value_name='sales'))
```

## window

window（窗口函数）对滑动窗口内的数据做聚合，rolling 用于时间/顺序窗口（如移动平均），expanding 用于从起点累积（如累计和），是时序特征和指标计算的核心。

```text
窗口函数：
1. rolling(n) —— 固定长度滑动窗口，window=n
2. expanding() —— 从开头到当前的累积窗口
3. ewm() —— 指数加权移动平均，近值权重更高
4. 配合 mean/sum/std/apply 使用
5. 常需先 sort_index 或按时间排序
```

```python
import pandas as pd
import numpy as np

idx = pd.date_range('2024-01-01', periods=6, freq='D')
df = pd.DataFrame({'value': [10, 20, 15, 30, 25, 40]}, index=idx)

print(df['value'].rolling(3).mean())     # 3 日移动平均
print(df['value'].expanding().sum())     # 累积和
print(df['value'].ewm(alpha=0.5).mean()) # 指数加权

# 自定义窗口函数
print(df['value'].rolling(3).apply(np.ptp))  # 窗口内极差
```

## time series

Pandas 对时间序列有专门支持：DatetimeIndex 索引、日期范围生成、重采样（resample）、时区处理、日期偏移。时间序列是推荐、金融、监控等场景的标配数据形态。

```text
时间序列核心：
1. pd.date_range —— 生成连续时间索引
2. DatetimeIndex —— 时间戳索引，支持切片和部分匹配
3. resample —— 按频率重采样（分钟→天，sum/mean）
4. shift —— 滞后/前移，做同比环比和滞后特征
5. 时区 —— tz_localize / tz_convert
```

```python
import pandas as pd

# 生成分钟级数据，重采样到天
idx = pd.date_range('2024-01-01', periods=1440, freq='min')
df = pd.DataFrame({'value': range(1440)}, index=idx)

daily = df.resample('D').sum()       # 分钟 → 天
print(daily)

# 滞后特征（昨天的值）
df['prev'] = df['value'].shift(1)
print(df.head(3))

# 同比环比（shift 配合周期）
monthly = pd.Series([100, 110, 120, 130],
                    index=pd.date_range('2024-01-01', periods=4, freq='ME'))
print(monthly.pct_change())          # 环比
print(monthly.diff())                # 差分
```

## 应用场景实战

### 场景一：特征工程的完整流程

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 5000
df = pd.DataFrame({
    'user_id': rng.integers(0, 500, n),
    'amount': rng.lognormal(3, 1, n),
    'ts': pd.date_range('2024-01-01', periods=n, freq='min'),
})

# 1. 用户级聚合特征
feat = df.groupby('user_id')['amount'].agg(
    ['mean', 'std', 'max', 'count']).reset_index()
feat.columns = ['user_id', 'amt_mean', 'amt_std', 'amt_max', 'cnt']

# 2. 时间窗口特征（滚动均值）
df = df.set_index('ts')
df['amount_ma7'] = df['amount'].rolling(7).mean()

# 3. 宽表化（透视）
pivot_feat = df.groupby(['ts', 'user_id'])['amount'].sum().reset_index()
wide = pivot_feat.pivot(index='ts', columns='user_id', values='amount').fillna(0)
print(f'聚合特征: {feat.shape}, 宽表: {wide.shape}')
```

### 场景二：时间序列分析与异常检测

```python
import numpy as np
import pandas as pd

# 生成带异常的日销量序列
rng = np.random.default_rng(1)
idx = pd.date_range('2023-01-01', periods=365, freq='D')
sales = 100 + 10 * np.sin(np.arange(365) / 10) + rng.normal(0, 5, 365)
sales[[50, 200]] = 200   # 注入两个异常点

df = pd.DataFrame({'sales': sales}, index=idx)

# 移动平均 + 标准差做异常检测
ma = df['sales'].rolling(7).mean()
std = df['sales'].rolling(7).std()
df['z'] = (df['sales'] - ma) / std
anomalies = df[df['z'].abs() > 3]
print(f'检测到 {len(anomalies)} 个异常点: {list(anomalies.index)}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 default_rng(seed) 替代旧 np.random.seed，随机数可复现且并行安全
2. 能向量化就用 NumPy 数组运算，避免 Python 循环遍历 DataFrame
3. groupby + agg 一次算多个指标，别写多个 groupby 再拼接
4. merge 前先确认键的唯一性，警惕多对多连接导致行数爆炸
5. 时间序列先 sort_index 再做 rolling/resample，避免窗口错位
6. 特征工程结果用 copy() 隔离，避免链式索引的 SettingWithCopy 警告

### 踩坑记录

```text
坑 1：broadcasting 形状不匹配
结论：报错 operands could not be broadcast together。
原因：两个数组从右往左对齐维度，长度既不等也不为 1。
解法：用 reshape 或 [:, None] / [None, :] 补出长度为 1 的维度。

坑 2：pivot 遇到重复键报错
结论：Index contains duplicate entries, cannot reshape。
原因：行+列组合不唯一，pivot 无法决定取哪个值。
解法：改用 pivot_table 并指定 aggfunc 聚合。

坑 3：merge 后行数暴涨
结论：两张各 1 万行的表 join 出几百万行。
原因：连接键在任一侧不唯一，发生多对多笛卡尔积。
解法：join 前 drop_duplicates 或先 groupby 聚合，校验行数。

坑 4：rolling 结果开头是 NaN 被误当缺失
结论：前 n-1 个窗口结果是 NaN，直接参与计算导致全 NaN。
原因：窗口长度不足时没有足够数据填充。
解法：用 min_periods 参数控制，或对结果 fillna。

坑 5：时间序列没排序就 rolling
结论：窗口聚合结果错乱，特征对不上时间。
原因：rolling 按物理顺序滑动，索引乱序时窗口语义错误。
解法：先 sort_index() 再 rolling，或用 sort_values 按时间排好。
```
