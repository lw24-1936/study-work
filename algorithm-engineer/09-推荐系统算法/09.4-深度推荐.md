## 概述

深度推荐用神经网络自动学习高阶特征交叉和序列依赖，解决传统 LR、FM 只能人工构造交叉特征的瓶颈。它贯穿精排（CTR/CVR 预估）和召回（双塔、DSSM）两大环节，是当代推荐系统效果的核心引擎。

```text
深度推荐的演进主线：
1. 记忆 + 泛化 —— Wide & Deep 提出「宽记忆、深泛化」的经典范式
2. 自动特征交叉 —— DeepFM / xDeepFM / DCN 让模型自己学交叉，替代人工
3. 序列建模 —— DIN / DIEN 捕捉用户行为序列中的兴趣与兴趣演化
4. 多目标 —— MMOE / PLE 用专家网络共享 + 任务特异化平衡多目标
5. 向量召回 —— Two-Tower / DSSM 把用户和物品编码成向量做点积召回
```

```python
import torch
import torch.nn as nn

# 深度推荐模型统一骨架：稀疏特征 → embedding → 网络 → 输出
class BaseRecModel(nn.Module):
    def __init__(self, field_dims, embed_dim=16):
        super().__init__()
        self.embeddings = nn.ModuleList(
            [nn.Embedding(d, embed_dim) for d in field_dims])

    def embed(self, x):
        # x: [batch, num_fields]，每个 field 取对应 embedding
        return torch.cat(
            [emb(x[:, i]) for i, emb in enumerate(self.embeddings)], dim=-1)

print("深度推荐模型骨架已就绪，下面各节填充具体结构")
```

## Wide & Deep

Wide & Deep 由 Google 提出，用「Wide 部分（线性模型）记忆特征共现 + Deep 部分（MLP）泛化未见组合」两条路径并行，最后把两部分输出相加做预测。它开创了「记忆 + 泛化」的组合范式，是后续 DeepFM、DCN 的起点。

```text
Wide & Deep 的数学定义：
预测：ŷ = σ( w_wideᵀ [x, φ(x)] + w_deepᵀ a^(L) + b )

- Wide：广义线性模型，输入原始特征 + 交叉特征 φ(x)（如 AND(user=男, item=游戏)）
- Deep：多层 MLP，输入 embedding，自动学高阶非线性组合
- 合并：两部分 logit 相加后过 sigmoid
```

```python
import torch
import torch.nn as nn

class WideAndDeep(nn.Module):
    def __init__(self, field_dims, embed_dim=16, mlp_dims=(64, 32)):
        super().__init__()
        self.embeddings = nn.ModuleList(
            [nn.Embedding(d, embed_dim) for d in field_dims])
        num_fields = len(field_dims)
        # Deep 部分
        layers = []
        in_dim = num_fields * embed_dim
        for out_dim in mlp_dims:
            layers += [nn.Linear(in_dim, out_dim), nn.ReLU()]
            in_dim = out_dim
        self.deep = nn.Sequential(*layers)
        # Wide 部分（线性，按 field 做一阶加权，等价于对稀疏特征的线性模型）
        self.wide = nn.ModuleList([nn.Embedding(d, 1) for d in field_dims])
        self.out = nn.Linear(in_dim, 1)

    def forward(self, x):
        emb = torch.cat(
            [e(x[:, i]) for i, e in enumerate(self.embeddings)], dim=-1)
        deep_out = self.deep(emb)
        wide_out = sum(e(x[:, i]) for i, e in enumerate(self.wide))   # [B, 1]
        return torch.sigmoid(self.out(deep_out) + wide_out)

model = WideAndDeep(field_dims=[100, 50, 30])
print("Wide & Deep 参数总量:", sum(p.numel() for p in model.parameters()))
```

## DeepFM

DeepFM 用 FM 层替换 Wide & Deep 的 Wide 部分，让「低阶特征交叉」也由模型自动学习（而不是人工构造交叉特征），同时保留 Deep 的 MLP 学高阶交叉。FM 与 Deep 共享同一套 embedding，端到端联合训练。

```text
DeepFM 的数学定义：
预测：ŷ = σ( y_FM + y_DNN )

FM 部分（二阶交叉，无需人工构造）：
y_FM = w₀ + Σ w_i x_i + Σ_{i<j} <v_i, v_j> x_i x_j

- 共享 embedding：FM 和 DNN 用同一组隐向量 v，避免重复参数
- 二阶交叉通过「和平方减平方和」在 O(nk) 内高效计算
```

```python
import torch
import torch.nn as nn

class DeepFM(nn.Module):
    def __init__(self, field_dims, embed_dim=16, mlp_dims=(64, 32)):
        super().__init__()
        self.embeddings = nn.ModuleList(
            [nn.Embedding(d, embed_dim) for d in field_dims])
        self.linear = nn.ModuleList([nn.Embedding(d, 1) for d in field_dims])   # 一阶
        num_fields = len(field_dims)
        layers = []
        in_dim = num_fields * embed_dim
        for out_dim in mlp_dims:
            layers += [nn.Linear(in_dim, out_dim), nn.ReLU()]
            in_dim = out_dim
        self.deep = nn.Sequential(*layers)
        self.out = nn.Linear(in_dim, 1)

    def forward(self, x):
        emb = torch.stack(
            [e(x[:, i]) for i, e in enumerate(self.embeddings)], dim=1)  # [B,F,E]
        # FM 二阶交叉：0.5 * (sum² - sum of squares)
        sum_sq = emb.sum(dim=1).pow(2)
        sq_sum = emb.pow(2).sum(dim=1)
        fm_2nd = 0.5 * (sum_sq - sq_sum).sum(dim=-1, keepdim=True)
        # 一阶
        fm_1st = sum(e(x[:, i]) for i, e in enumerate(self.linear))   # [B, 1]
        # Deep
        deep_out = self.deep(emb.reshape(emb.size(0), -1))
        return torch.sigmoid(fm_1st + fm_2nd + self.out(deep_out))

model = DeepFM(field_dims=[100, 50, 30])
print("DeepFM 参数总量:", sum(p.numel() for p in model.parameters()))
```

## xDeepFM

xDeepFM 在 DeepFM 基础上加入 CIN（Compressed Interaction Network，压缩交互网络），能显式学习「向量级」的高阶特征交互（而不只是 FM 的 bit-wise 二阶），并在每层做交互与压缩，捕获任意阶的显式交叉。

```text
xDeepFM 的数学定义：
预测：ŷ = σ( y_linear + y_CIN + y_DNN )

CIN 的逐层递推（第 k 层）：
X^k_{h,*} = Σ_{i=1}^{H_{k-1}} Σ_{j=1}^{m} W^{k,h}_{i,j} ( X^{k-1}_{i,*} ∘ X^0_{j,*} )

- ∘ 是逐元素乘（Hadamard），每层与原始 embedding X⁰ 交互
- 显式高阶：第 k 层捕获 k+1 阶特征交互
- vector-wise：在向量维度上交叉，比 FM 的 bit-wise 更强
```

```python
import torch
import torch.nn as nn

class CIN(nn.Module):
    def __init__(self, num_fields, cin_layers=(64, 32)):
        super().__init__()
        self.convs = nn.ModuleList()
        prev = num_fields
        for out in cin_layers:
            self.convs.append(nn.Conv1d(prev * num_fields, out, kernel_size=1))
            prev = out

    def forward(self, x0):
        # x0: [B, F, E] 原始 embedding，F=num_fields
        B, F, E = x0.shape
        xk = x0
        result = []
        for conv in self.convs:
            # 外层：xk 的每个向量 与 x0 每个向量做 Hadamard，堆成 [B, H*F, E]
            h, f = xk.shape[1], x0.shape[1]
            outer = xk.unsqueeze(2) * x0.unsqueeze(1)     # [B, h, f, E]
            outer = outer.reshape(B, h * f, E)
            xk = conv(outer)                              # [B, H', E]
            result.append(xk.sum(dim=-1))                 # [B, H']
        return torch.cat(result, dim=1)

cin = CIN(num_fields=4)
x = torch.randn(2, 4, 16)
print("CIN 输出形状:", cin(x).shape)   # [2, 96] (64+32)
```

## DCN

DCN（Deep & Cross Network）用 Cross Network 替代 Wide 部分：每层通过「x₀ 与上一层输出的外积」做交叉，以参数量极少的显式高阶交叉捕获特征交互，深度部分仍是 MLP。它的交叉阶数随层数线性增长，参数却只有 O(n)。

```text
DCN 的数学定义：
Cross 层递推：
x_{l+1} = x₀ x_lᵀ w_l + b_l + x_l

- x₀ 是原始输入，每层都与 x₀ 做外积，保留原始特征的交叉
- 第 l 层捕获 l+1 阶交叉
- 参数量 O(n) 而非 O(n²)，高效显式高阶
```

```python
import torch
import torch.nn as nn

class CrossNet(nn.Module):
    def __init__(self, in_dim, num_layers=3):
        super().__init__()
        self.num_layers = num_layers
        self.w = nn.ParameterList(
            [nn.Parameter(torch.randn(in_dim, 1)) for _ in range(num_layers)])
        self.b = nn.ParameterList(
            [nn.Parameter(torch.zeros(in_dim)) for _ in range(num_layers)])

    def forward(self, x0):
        xl = x0
        for i in range(self.num_layers):
            xl = x0 * (xl @ self.w[i]) + self.b[i] + xl   # x0 外积交叉
        return xl

cn = CrossNet(in_dim=16)
x = torch.randn(2, 16)
print("CrossNet 输出形状:", cn(x).shape)   # [2, 16]
```

## DIN

DIN（Deep Interest Network，深度兴趣网络）解决「用户历史行为序列如何聚合」的问题：用目标物品对用户历史行为做 Attention，只激活与当前候选相关的历史兴趣，动态加权求和得到用户兴趣向量，再与目标物品向量拼接进 MLP。

```text
DIN 的数学定义：
兴趣向量：
v_u = Σ_i a_i h_i，其中 a_i = softmax( h_i · f(h_i, v_a) )

- h_i 是历史行为物品向量，v_a 是目标物品向量
- Attention 权重 a_i 由「历史物品与目标物品的相关性」决定
- 局部激活：只在与目标相关的那部分历史上给高权重
```

```python
import torch
import torch.nn as nn

class DINAttention(nn.Module):
    def __init__(self, embed_dim=16):
        super().__init__()
        self.fc = nn.Sequential(
            nn.Linear(embed_dim * 4, 32), nn.ReLU(), nn.Linear(32, 1))

    def forward(self, hist, target, mask):
        # hist: [B, T, E]，target: [B, E]
        T = hist.size(1)
        target_exp = target.unsqueeze(1).expand(-1, T, -1)        # [B,T,E]
        feat = torch.cat([hist, target_exp, hist * target_exp, hist - target_exp], dim=-1)
        att = self.fc(feat).squeeze(-1)                           # [B,T]
        att = att.masked_fill(mask == 0, -1e9)
        att = torch.softmax(att, dim=1).unsqueeze(-1)             # [B,T,1]
        interest = (att * hist).sum(dim=1)                        # [B,E]
        return interest

att = DINAttention()
hist = torch.randn(2, 10, 16)
target = torch.randn(2, 16)
mask = torch.ones(2, 10)
print("DIN 兴趣向量形状:", att(hist, target, mask).shape)   # [2, 16]
```

## DIEN

DIEN（Deep Interest Evolution Network）在 DIN 基础上给兴趣加了「演化」：用 GRU 对用户行为序列建模，让兴趣随行为顺序逐步演化，再用 Attention（AUGRU）结合目标物品，捕捉兴趣的时序变化，进一步逼近真实兴趣的动态过程。

```text
DIEN 与 DIN 的区别：
1. DIN —— 静态加权求和历史，忽略行为顺序
2. DIEN —— 用 GRU 按时间顺序编码行为，兴趣是逐时刻演化的
3. AUGRU —— 用目标物品的注意力分数调制 GRU 更新门，让相关兴趣「走得更远」
```

```python
import torch
import torch.nn as nn

class DIEN(nn.Module):
    def __init__(self, embed_dim=16, hidden_dim=32):
        super().__init__()
        self.gru = nn.GRU(embed_dim, hidden_dim, batch_first=True)
        self.att = nn.Sequential(
            nn.Linear(hidden_dim + embed_dim, 32), nn.ReLU(), nn.Linear(32, 1))

    def forward(self, hist, target):
        # hist: [B, T, E]，target: [B, E]
        gru_out, _ = self.gru(hist)                 # [B, T, H] 兴趣演化
        T = gru_out.size(1)
        target_exp = target.unsqueeze(1).expand(-1, T, -1)
        att_score = self.att(torch.cat([gru_out, target_exp], dim=-1))
        att_w = torch.softmax(att_score, dim=1)     # [B, T, 1]
        interest = (att_w * gru_out).sum(dim=1)     # [B, H]
        return interest

dien = DIEN()
hist = torch.randn(2, 10, 16)
target = torch.randn(2, 16)
print("DIEN 兴趣演化向量形状:", dien(hist, target).shape)   # [2, 32]
```

## MMOE

MMOE（Multi-gate Mixture-of-Experts）是推荐系统多目标学习（同时优化点击率、转化率、时长等）的经典结构：多个 Expert 网络共享底层，每个任务用独立的 Gate 对 Expert 输出加权组合，实现「知识共享 + 任务差异」的平衡。

```text
MMOE 的数学定义：
任务 k 的表示：
f_k(x) = Σ_i g_k(x)_i · f_i(x)

- f_i(x) 是第 i 个 Expert 的输出（多个共享的专家网络）
- g_k(x) 是任务 k 的 Gate，输出各 Expert 的权重（softmax）
- 各任务共享同一批 Expert，但通过不同的 Gate 各取所需
```

```python
import torch
import torch.nn as nn

class MMOE(nn.Module):
    def __init__(self, in_dim=32, expert_dim=16, num_experts=4, num_tasks=3):
        super().__init__()
        self.experts = nn.ModuleList(
            [nn.Linear(in_dim, expert_dim) for _ in range(num_experts)])
        self.gates = nn.ModuleList(
            [nn.Linear(in_dim, num_experts) for _ in range(num_tasks)])
        self.towers = nn.ModuleList(
            [nn.Linear(expert_dim, 1) for _ in range(num_tasks)])

    def forward(self, x):
        expert_out = torch.stack([e(x) for e in self.experts], dim=1)  # [B,NE,E]
        outputs = []
        for gate, tower in zip(self.gates, self.towers):
            w = torch.softmax(gate(x), dim=-1).unsqueeze(-1)           # [B,NE,1]
            fused = (w * expert_out).sum(dim=1)                        # [B,E]
            outputs.append(torch.sigmoid(tower(fused)))
        return torch.cat(outputs, dim=1)                               # [B,NT]

mmoe = MMOE()
x = torch.randn(4, 32)
print("MMOE 多任务输出形状:", mmoe(x).shape)   # [4, 3]
```

## PLE

PLE（Progressive Layered Extraction）是 MMOE 的改进：除了共享 Expert 之外，为每个任务保留专属 Expert，通过多层「共享 + 专属」的渐进式抽取，缓解多任务学习里的「跷跷板效应」（负迁移），让冲突目标也能稳定共训。

```text
PLE 与 MMOE 的区别：
1. MMOE —— 只有共享 Expert，任务差异全靠 Gate，冲突目标易负迁移
2. PLE —— 共享 Expert + 每任务专属 Expert 并存
3. 渐进分层 —— 多层 CGC 结构堆叠，逐层抽取共享与专属信息
4. 解决跷跷板 —— 任务可以退回自己的专属网络，不被其他任务拖累
```

```python
import torch
import torch.nn as nn

class PLE(nn.Module):
    def __init__(self, in_dim=32, expert_dim=16, num_tasks=3, shared=2, spec=1):
        super().__init__()
        self.num_tasks = num_tasks
        self.shared_experts = nn.ModuleList(
            [nn.Linear(in_dim, expert_dim) for _ in range(shared)])
        self.spec_experts = nn.ModuleList([
            nn.ModuleList([nn.Linear(in_dim, expert_dim) for _ in range(spec)])
            for _ in range(num_tasks)])
        self.gates = nn.ModuleList(
            [nn.Linear(in_dim, shared + spec) for _ in range(num_tasks)])
        self.towers = nn.ModuleList(
            [nn.Linear(expert_dim, 1) for _ in range(num_tasks)])

    def forward(self, x):
        shared_out = [e(x) for e in self.shared_experts]
        outputs = []
        for t in range(self.num_tasks):
            spec_out = [e(x) for e in self.spec_experts[t]]
            all_out = shared_out + spec_out                    # 共享 + 专属
            stacked = torch.stack(all_out, dim=1)              # [B, shared+spec, E]
            w = torch.softmax(self.gates[t](x), dim=-1).unsqueeze(-1)
            fused = (w * stacked).sum(dim=1)
            outputs.append(torch.sigmoid(self.towers[t](fused)))
        return torch.cat(outputs, dim=1)

ple = PLE()
x = torch.randn(4, 32)
print("PLE 多任务输出形状:", ple(x).shape)   # [4, 3]
```

## Two-Tower

Two-Tower（双塔 / 双塔召回）把用户塔和物品塔分别编码成向量，用两个向量的内积/余弦作为匹配分数。它是向量召回的标准结构：物品向量可离线预计算、存入 ANN 索引，在线只需算用户向量再近邻检索，极致高效。

```text
Two-Tower 的数学定义：
匹配分数：score(u, i) = f_user(u)ᵀ · f_item(i)

- 用户塔：用户画像 + 行为序列 → 用户向量
- 物品塔：物品属性 + 内容 → 物品向量
- 训练用负采样（batch 内随机负样本 + 难负样本）
- 推理：物品向量离线入库 ANN，在线只算用户向量 + 检索
```

```python
import torch
import torch.nn as nn

class TwoTower(nn.Module):
    def __init__(self, user_dim=32, item_dim=32, embed_dim=64):
        super().__init__()
        self.user_tower = nn.Sequential(
            nn.Linear(user_dim, 128), nn.ReLU(), nn.Linear(128, embed_dim))
        self.item_tower = nn.Sequential(
            nn.Linear(item_dim, 128), nn.ReLU(), nn.Linear(128, embed_dim))

    def forward(self, user_feat, item_feat):
        u = self.user_tower(user_feat)          # [B, E]
        i = self.item_tower(item_feat)          # [B, E]
        u = u / u.norm(dim=-1, keepdim=True)    # L2 归一化 → 余弦
        i = i / i.norm(dim=-1, keepdim=True)
        return (u * i).sum(dim=-1)              # 内积 = 余弦相似度

tt = TwoTower()
u = torch.randn(4, 32)
i = torch.randn(4, 32)
print("双塔匹配分数:", tt(u, i).detach().numpy())
```

## DSSM

DSSM（Deep Structured Semantic Model）最初用于搜索（Query 与 Document 的语义匹配），在推荐里演化为经典双塔召回：用户特征和物品特征分别经过多层网络映射到同一语义空间，用余弦相似度衡量匹配度，是 Two-Tower 的「语义匹配」版本。

```text
DSSM 的数学定义：
相似度：cos(q, d) = (qᵀ d) / (‖q‖·‖d‖)

- 用户侧（query 塔）：把用户特征编码成语义向量 q
- 物品侧（doc 塔）：把物品特征编码成语义向量 d
- 训练：正样本（真实交互）拉近，负样本（随机/难负）推远，用 softmax 交叉熵
```

```python
import torch
import torch.nn as nn

class DSSM(nn.Module):
    def __init__(self, user_dim=32, item_dim=32, embed_dim=64):
        super().__init__()
        self.user_tower = nn.Sequential(
            nn.Linear(user_dim, 128), nn.Tanh(), nn.Linear(128, embed_dim))
        self.item_tower = nn.Sequential(
            nn.Linear(item_dim, 128), nn.Tanh(), nn.Linear(128, embed_dim))

    def forward(self, user_feat, item_feat):
        q = self.user_tower(user_feat)
        d = self.item_tower(item_feat)
        cos = torch.nn.functional.cosine_similarity(q, d, dim=-1)
        return cos

dssm = DSSM()
u = torch.randn(4, 32)
i = torch.randn(4, 32)
print("DSSM 余弦相似度:", dssm(u, i).detach().numpy())
```

## 应用场景实战

### 场景一：电商精排的 CTR 预估（DeepFM）

```python
import torch
import torch.nn as nn

# 模拟一个 CTR 预估的小 batch：3 个 field（用户、商品、上下文）
field_dims = [1000, 5000, 200]
batch_x = torch.randint(0, 50, (8, 3))      # 8 条样本，各 field 取 id

deepfm = DeepFM(field_dims, embed_dim=8)
with torch.no_grad():
    preds = deepfm(batch_x)
print("8 条样本的 CTR 预估:", preds.squeeze().detach().numpy().round(3))
```

### 场景二：多目标排序（点击 + 转化 + 时长）

```text
电商/内容平台的多目标落地：
1. 目标选择：CTR（点不点）、CVR（买不买）、时长（停留多久）
2. 模型：MMOE 或 PLE，共享底层 + 分任务 Gate/专属专家
3. 融合：线上把多目标分数按业务权重融合（如 score = ctr * cvr * price）
4. 监控：每个目标单独监控 AUC，出现跷跷板时切换到 PLE
5. 迭代：新目标上线时增量加 Gate 和 Tower，底层专家复用
```

## 最佳实践与踩坑记录

### 最佳实践

1. 排序任务先上 DeepFM/DCN 这种「显式交叉」结构，比纯 MLP 有明显提升
2. 有行为序列数据时用 DIN/DIEN 建模兴趣，比简单平均 pooling 强很多
3. 多目标学习优先 MMOE，出现明显负迁移再升级到 PLE
4. 召回用双塔/DSSM，物品向量离线入库 ANN，在线只算用户塔，性能最优
5. 双塔训练要重视负采样：batch 内负样本 + 难负样本，避免「假负」
6. 所有深度模型都要做 embedding 层与 MLP 的正则化（dropout、BN、L2）

### 踩坑记录

```text
坑 1：双塔负采样太随机导致「假负样本」
结论：模型把用户确实会喜欢的物品当负样本推开，召回质量下降。
原因：batch 内随机负采样可能抽到「用户其实喜欢但没曝光」的物品。
解法：结合曝光未点击的真实负样本 + 难负样本（hard negative），并做去假负。

坑 2：多目标直接共享底层导致跷跷板
结论：优化 CTR 后 CVR 反而下降，两个目标互相拖累。
原因：目标任务间冲突（点击多的不一定转化多），强行共享底层发生负迁移。
解法：用 PLE 给每个任务保留专属专家，或调整损失权重与梯度策略。

坑 3：序列特征直接做平均/求和池化
结论：用户历史里大量无关行为稀释了真实兴趣，推荐不够精准。
原因：平均池化对所有历史一视同仁，无法针对当前候选聚焦相关兴趣。
解法：用 DIN 的 Attention 做局部激活，或 DIEN 的 GRU 建模兴趣演化。

坑 4：embedding 维度开太大且无正则
结论：稀疏特征多的深度模型严重过拟合，线上效果远差于离线。
原因：embedding 参数量巨大（field 基数 × 维度），缺少正则会死记训练样本。
解法：控制 embedding 维度、加 dropout/L2、限制低频特征的 embedding 更新。

坑 5：只用 bit-wise 交叉而忽略 vector-wise 交互
结论：FM 这类 bit-wise 交叉难以捕捉特征向量间的深层语义交互。
原因：bit-wise 在标量层面交叉，丢失了 embedding 向量内部的结构信息。
解法：需要更强高阶交互时用 xDeepFM 的 CIN 或 DCN 的 Cross Network。
```
