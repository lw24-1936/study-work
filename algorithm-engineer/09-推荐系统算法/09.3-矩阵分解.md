## 概述

矩阵分解（Matrix Factorization）是协同过滤的模型化升级：把「用户-物品」交互矩阵分解成低维的用户隐向量和物品隐向量，用两个向量的内积重建评分/偏好。它把离散的「找相似用户/物品」升级为连续的「embedding 点积」，既降维又填补了缺失交互，是推荐系统从统计走向模型的里程碑。

```text
矩阵分解的核心认知：
1. 隐向量 —— 用户 u 和物品 i 各有一个 k 维向量，内积 uᵀv_i 即预测分
2. 降维去噪 —— 把稀疏的高维交互压缩到低维稠密空间，捕捉潜在模式
3. 补全缺失 —— 训练好的向量可以预测从未发生过的交互
4. 是 embedding 鼻祖 —— 双塔、DSSM 等深度召回都继承了这个思想
```

```python
import numpy as np

# 矩阵分解的极简示例：R ≈ U @ Vᵀ
R = np.array([[5, 3, 0, 1],
              [4, 0, 0, 1],
              [1, 1, 0, 5],
              [0, 0, 5, 4],
              [0, 1, 5, 4]], dtype=float)

k = 2
n_users, n_items = R.shape
U = np.random.randn(n_users, k)   # 用户隐向量
V = np.random.randn(n_items, k)   # 物品隐向量
R_hat = U @ V.T
print("重构矩阵形状:", R_hat.shape)   # (5, 4)
```

## MF

MF（Matrix Factorization，矩阵分解）把评分矩阵 R 近似为用户隐向量矩阵 P 与物品隐向量矩阵 Q 的乘积 R ≈ P·Qᵀ。它只用观察到的评分拟合，通过梯度下降优化平方损失，学到的隐向量能表达用户偏好和物品属性（如喜剧/动作、文艺/商业）。

```text
MF 的数学定义：
预测：r̂_ui = p_uᵀ · q_i
目标：min Σ_{(u,i)∈K} (r_ui - p_uᵀ q_i)² + λ(‖p_u‖² + ‖q_i‖²)

K 是已知评分集合，λ 是正则化系数，防止过拟合。
隐向量维度 k 通常在 10~200，k 越大表达能力越强但越容易过拟合。
```

```python
import numpy as np

# 手写 MF 的梯度下降
def mf_sgd(R, k=10, epochs=200, lr=0.01, lam=0.02, seed=0):
    np.random.seed(seed)
    n_users, n_items = R.shape
    P = np.random.randn(n_users, k)
    Q = np.random.randn(n_items, k)
    known = [(u, i) for u in range(n_users) for i in range(n_items) if R[u, i] > 0]
    for _ in range(epochs):
        for u, i in known:
            err = R[u, i] - P[u] @ Q[i]
            P[u] += lr * (err * Q[i] - lam * P[u])
            Q[i] += lr * (err * P[u] - lam * Q[i])
    return P, Q

P, Q = mf_sgd(R, k=2)
R_hat = P @ Q.T
print("重构误差:", np.mean((R[R > 0] - R_hat[R > 0]) ** 2))
```

## SVD

推荐语境下的 SVD（FunkSVD / 隐语义模型）是对经典线性代数 SVD 的「降级」用法：因为真实评分矩阵大量缺失，无法直接做严格 SVD，于是只对观察到的评分做低秩分解，用梯度下降/交替最小二乘求解。严格意义的 SVD（R = UΣVᵀ，取前 k 个奇异值）更多用于稠密矩阵降维。

```text
两种 SVD 的辨析：
1. 严格 SVD —— R = UΣVᵀ，U/V 正交，Σ 对角，用于稠密矩阵的全局低秩近似
2. FunkSVD —— 只拟合已知评分，用 (P, Q) 两个自由矩阵，业界常用的「SVD 推荐」
3. 核心差异 —— 严格 SVD 无法处理缺失值，FunkSVD 天然绕过缺失
```

```python
import numpy as np
from sklearn.decomposition import TruncatedSVD

# 稠密矩阵上的严格 SVD 低秩近似（降维视角）
dense = np.array([[5, 3, 4, 1],
                  [4, 2, 4, 1],
                  [1, 1, 1, 5],
                  [1, 0, 5, 4],
                  [0, 1, 5, 4]], dtype=float)

svd = TruncatedSVD(n_components=2, random_state=0)
svd.fit(dense)
approx = svd.inverse_transform(svd.transform(dense))
print("前 2 奇异值占比:", round(sum(svd.explained_variance_ratio_), 3))
print("低秩近似形状:", approx.shape)
```

## SVD++

SVD++ 在 MF 的基础上，把用户的「隐式反馈」（浏览过、点过、评过但没打分）也纳入建模：物品隐向量额外加上「该用户交互过的所有物品的隐向量之和」。这让模型能利用比显式评分丰富得多的隐式信号，显著提升预测精度，是 Netflix Prize 时代的经典改进。

```text
SVD++ 的数学定义：
预测：r̂_ui = μ + b_u + b_i + q_iᵀ ( p_u + |N(u)|^(-1/2) Σ_{j∈N(u)} y_j )

其中：
- μ 全局均值，b_u/b_i 用户/物品偏置
- N(u) 用户 u 交互过的物品集合，y_j 是隐式反馈隐向量
- 括号内 = 用户显式偏好 + 隐式行为聚合，再与物品向量点积
```

```python
import numpy as np

def svdpp(R, k=5, epochs=50, lr=0.005, lam=0.02, seed=0):
    np.random.seed(seed)
    n_users, n_items = R.shape
    mu = R[R > 0].mean()
    bu, bi = np.zeros(n_users), np.zeros(n_items)
    P = np.random.randn(n_users, k)
    Q = np.random.randn(n_items, k)
    Y = np.random.randn(n_items, k)          # 隐式反馈隐向量
    for _ in range(epochs):
        for u in range(n_users):
            interacted = [j for j in range(n_items) if R[u, j] > 0]
            if not interacted:
                continue
            n_u = len(interacted)
            implicit = sum(Y[j] for j in interacted) / np.sqrt(n_u)
            for i in interacted:
                pred = mu + bu[u] + bi[i] + Q[i] @ (P[u] + implicit)
                err = R[u, i] - pred
                bu[u] += lr * (err - lam * bu[u])
                bi[i] += lr * (err - lam * bi[i])
                P[u] += lr * (err * Q[i] - lam * P[u])
                Q[i] += lr * (err * (P[u] + implicit) - lam * Q[i])
                for j in interacted:
                    Y[j] += lr * (err * Q[i] / np.sqrt(n_u) - lam * Y[j])
    return mu, bu, bi, P, Q

mu, bu, bi, P, Q = svdpp(R, k=3, epochs=20)
print("全局均值:", round(mu, 2))
```

## ALS

ALS（Alternating Least Squares，交替最小二乘）把 MF 的非凸优化问题拆成两个交替求解的最小二乘子问题：固定物品向量解用户向量，固定用户向量解物品向量，每一步都有闭式解。它天然并行、适合 Spark 等分布式计算，也容易处理隐式反馈，是工业界最常用的矩阵分解实现。

```text
ALS 的求解思路：
固定 Q 时，对每个用户 u：
p_u = (QᵀQ + λI)⁻¹ Qᵀ r_u   （最小二乘闭式解）
再固定 P，对称地解 q_i。反复交替直到收敛。

优势：
1. 每步闭式解，收敛稳定，无需调学习率
2. 用户之间、物品之间相互独立，天然可并行
3. 适合加权正则（隐式反馈场景每个样本权重不同）
```

```python
import numpy as np

def als(R, k=5, lam=0.1, iters=20, seed=0):
    np.random.seed(seed)
    n_users, n_items = R.shape
    P = np.random.randn(n_users, k)
    Q = np.random.randn(n_items, k)
    I = np.eye(k)
    for _ in range(iters):
        # 固定 Q，解每个用户的 P
        for u in range(n_users):
            idx = np.where(R[u] > 0)[0]
            if len(idx) == 0:
                continue
            Q_sub = Q[idx]
            A = Q_sub.T @ Q_sub + lam * I
            b = Q_sub.T @ R[u, idx]
            P[u] = np.linalg.solve(A, b)
        # 固定 P，解每个物品的 Q
        for i in range(n_items):
            idx = np.where(R[:, i] > 0)[0]
            if len(idx) == 0:
                continue
            P_sub = P[idx]
            A = P_sub.T @ P_sub + lam * I
            b = P_sub.T @ R[idx, i]
            Q[i] = np.linalg.solve(A, b)
    return P, Q

P, Q = als(R, k=2)
print("ALS 重构误差:", np.mean((R[R > 0] - (P @ Q.T)[R > 0]) ** 2))
```

## BPR

BPR（Bayesian Personalized Ranking，贝叶斯个性化排序）放弃预测具体评分，转而优化「用户对交互过的物品的偏好应高于未交互物品」的相对排序。它用三元组 (u, i, j) 建模，最大化「i 排在 j 前面」的后验概率，更适合只关心 Top-N 排序的推荐场景。

```text
BPR 的数学定义：
目标：max Σ_{(u,i,j)∈D} ln σ( x̂_ui - x̂_uj ) - λ‖Θ‖²

其中：
- i ∈ 用户交互过的物品（正样本），j ∈ 未交互（负样本）
- x̂_ui = p_uᵀ q_i，σ 是 sigmoid
- D 是三元组集合，负样本通常随机采样
```

```python
import numpy as np

def bpr(R, k=5, epochs=100, lr=0.05, lam=0.01, seed=0):
    np.random.seed(seed)
    n_users, n_items = R.shape
    P = np.random.randn(n_users, k)
    Q = np.random.randn(n_items, k)
    pos = {u: np.where(R[u] > 0)[0] for u in range(n_users)}
    all_items = np.arange(n_items)
    for _ in range(epochs):
        for u in range(n_users):
            if len(pos[u]) == 0:
                continue
            i = np.random.choice(pos[u])
            j = np.random.choice(all_items)
            if j in pos[u]:
                continue
            x_ui = P[u] @ Q[i]
            x_uj = P[u] @ Q[j]
            sig = 1 / (1 + np.exp(x_ui - x_uj))       # σ(x̂_uj - x̂_ui)
            P[u] += lr * (sig * (Q[i] - Q[j]) - lam * P[u])
            Q[i] += lr * (sig * P[u] - lam * Q[i])
            Q[j] += lr * (-sig * P[u] - lam * Q[j])
    return P, Q

P, Q = bpr(R, k=3, epochs=50)
print("BPR 训练完成，可对用户做 Top-N 排序推荐")
```

## Implicit Feedback

Implicit Feedback（隐式反馈）指用户没有明确打分，但通过点击、浏览、购买、播放时长等行为间接表达偏好。它没有「负样本」的概念——没交互不代表不喜欢，只是没看到。因此需要专门的置信度加权（次数越多越确信喜欢）和负采样策略，ALS 加权版是它的经典解法。

```text
隐式反馈的建模要点：
1. 置信度 —— c_ui = 1 + α·r_ui，交互次数越多，置信度越高
2. 偏好 —— p_ui = 1（有交互）或 0（无交互），但 0 不代表讨厌
3. 加权 ALS —— 目标 min Σ c_ui (p_ui - x̂_ui)² + 正则
4. 负采样 —— 随机抽未交互物品当负样本，控制正负比例
```

```python
import numpy as np

# 隐式反馈加权 ALS：置信度 c = 1 + alpha * r
def implicit_als(R, k=5, alpha=40, lam=0.1, iters=15, seed=0):
    np.random.seed(seed)
    n_users, n_items = R.shape
    P = np.random.randn(n_users, k)
    Q = np.random.randn(n_items, k)
    I = np.eye(k)
    C = 1 + alpha * R            # 置信度矩阵
    for _ in range(iters):
        for u in range(n_users):
            Cu = np.diag(C[u])
            A = Q.T @ Cu @ Q + lam * I
            b = Q.T @ Cu @ (R[u] > 0).astype(float)
            P[u] = np.linalg.solve(A, b)
        for i in range(n_items):
            Ci = np.diag(C[:, i])
            A = P.T @ Ci @ P + lam * I
            b = P.T @ Ci @ (R[:, i] > 0).astype(float)
            Q[i] = np.linalg.solve(A, b)
    return P, Q

# 隐式反馈通常是 0/1 或次数矩阵
R_imp = (R > 0).astype(float)
P, Q = implicit_als(R_imp, k=3, iters=10)
print("隐式 ALS 完成，可直接用于 Top-N 推荐")
```

## 应用场景实战

### 场景一：音乐平台的评分预测与 Top-N 推荐对比

```python
import numpy as np

def top_n_for_user(P, Q, u, n=3):
    scores = P[u] @ Q.T
    return np.argsort(scores)[::-1][:n]

P_sgd, Q_sgd = mf_sgd(R, k=2, epochs=300)
P_als, Q_als = als(R, k=2, iters=30)

# 对比两种方法的 Top-3 推荐（物品编号）
print("MF(SGD)  Top-3:", top_n_for_user(P_sgd, Q_sgd, u=0))
print("MF(ALS)  Top-3:", top_n_for_user(P_als, Q_als, u=0))
# 两者应大致重合，说明隐向量学到了稳定的用户-物品结构
```

### 场景二：电商点击数据上的隐式反馈推荐

```text
电商点击/购买场景的落地流程：
1. 数据：把点击、加购、购买合成隐式反馈强度（如购买=3、加购=2、点击=1）
2. 模型：用加权 ALS，置信度 c = 1 + alpha * strength
3. 训练：Spark MLlib 的 ALS 分布式训练，k 取 50~100
4. 召回：离线算好每个用户的 Top-K，或存 embedding 走 ANN 在线召回
5. 评估：离线用召回率/HitRate，在线用 CTR、GMV 验证
```

## 最佳实践与踩坑记录

### 最佳实践

1. 隐式反馈比显式评分数据量大得多，工业界优先用隐式反馈建模
2. ALS 比 SGD 更适合大规模分布式训练，Spark MLlib 直接可用
3. 隐向量维度 k 用交叉验证选，从 20 开始往上加，观察验证指标
4. 只关心排序而非具体分数时，用 BPR 而非平方损失
5. 训练时对热门用户/物品做采样降权，避免被少数超级活跃节点主导
6. embedding 训练好后既可以直接 Top-N 推荐，也可以接 ANN 做在线召回

### 踩坑记录

```text
坑 1：把未交互当成负样本
结论：模型学到「用户讨厌一切没见过的东西」，推荐面越来越窄。
原因：隐式反馈里「没交互」只是没曝光，不代表不喜欢，直接当负样本会严重误导。
解法：用置信度加权（没交互置信度低）或负采样，且负样本只随机抽一小部分。

坑 2：k（隐向量维度）选太大
结论：训练误差极低，但验证/线上效果反而变差，且 embedding 存不下。
原因：k 过大导致过拟合，隐向量学到了噪声而非潜在结构。
解法：k 用验证集调参，通常几十到一两百，超过收益递减。

坑 3：直接对稠密评分矩阵做 sklearn 的 SVD
结论：用 fillna(0) 或均值填充后做严格 SVD，预测结果离谱。
原因：真实评分矩阵大量缺失，填充 0 会让模型误以为「未评分=评分 0 分」。
解法：用只拟合已知评分的 FunkSVD / ALS / BPR，不要做严格 SVD。

坑 4：忽略偏置项
结论：对「整体打分偏高/偏低」的用户和物品预测偏差大。
原因：有些用户天生打高分、有些物品普遍高分，全局均值和个人偏置没被建模。
解法：加 μ + b_u + b_i 偏置项（SVD++ 的标准做法），能显著降低误差。

坑 5：隐式反馈强度直接当评分
结论：把「点了 3 次」当成「3 分」训练，预测出的分数无意义。
原因：隐式反馈的数值是「强度」不是「评分」，量纲和语义都不同。
解法：转成偏好（是否交互）+ 置信度（1 + alpha * 次数）的加权损失。
```
