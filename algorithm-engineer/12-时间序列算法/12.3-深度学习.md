## 概述

时间序列深度学习用神经网络自动学习序列中的时序依赖，跳过手工特征工程。RNN 家族（LSTM/GRU）是经典序列模型，TCN 用因果卷积并行建模，Transformer 靠自注意力捕捉长程依赖，TFT 则把可解释性引入时序预测。数据量大、非线性强、多序列联合建模时，深度学习模型通常超过统计模型和树模型。

```text
时序深度学习模型谱系：
1. RNN/LSTM/GRU —— 循环结构，顺序处理，捕捉短期到中期依赖
2. TCN —— 因果膨胀卷积，可并行，感受野可调
3. Transformer —— 自注意力，长程依赖强，可并行
4. TFT —— Transformer + 可解释性，工业级时序预测
```

```python
import torch
import torch.nn as nn

# 时序数据约定：(batch, seq_len, features)
x = torch.randn(32, 24, 5)   # 32 条序列，24 步历史，5 个特征
print("输入形状:", x.shape)
```

## RNN

循环神经网络（Recurrent Neural Network）按时间步循环更新隐藏状态：h_t = tanh(W·x_t + U·h_{t-1})，每个时间步的输出依赖当前输入和上一时刻状态。它是时序模型的开山结构，但存在梯度消失/爆炸问题，难学长期依赖。

```text
RNN 要点：
1. 循环结构 —— 隐藏状态在时间步之间传递「记忆」
2. 梯度消失 —— 长序列里早期信息的梯度指数衰减，难学长期依赖
3. 参数量 —— 权重在时间步间共享，参数量与序列长度无关
```

```python
import torch
import torch.nn as nn

class SimpleRNN(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()
        self.rnn = nn.RNN(in_dim, hidden, batch_first=True)
        self.fc = nn.Linear(hidden, out_dim)

    def forward(self, x):
        out, _ = self.rnn(x)        # out: (batch, seq, hidden)
        return self.fc(out[:, -1])  # 取最后一步预测

model = SimpleRNN(in_dim=5, hidden=16, out_dim=1)
x = torch.randn(32, 24, 5)
y = model(x)
print("RNN 预测输出:", y.shape)   # (32, 1)
```

## LSTM

长短期记忆网络（Long Short-Term Memory）用门控机制（输入门、遗忘门、输出门）和细胞状态 c_t 解决 RNN 的梯度消失问题。遗忘门决定丢弃哪些旧信息，输入门决定写入哪些新信息，使它能选择性记住长期依赖。

```text
LSTM 三个门 + 细胞状态：
1. 遗忘门 f —— 决定忘记多少旧记忆（sigmoid）
2. 输入门 i + 候选 g —— 决定写入多少新信息
3. 输出门 o —— 决定输出多少当前状态
4. 细胞状态 c —— 长期记忆，跨时间步缓慢变化
```

```python
import torch
import torch.nn as nn

class LSTMModel(nn.Module):
    def __init__(self, in_dim, hidden, out_dim, num_layers=2):
        super().__init__()
        self.lstm = nn.LSTM(in_dim, hidden, num_layers=num_layers,
                            batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden, out_dim)

    def forward(self, x):
        out, (h, c) = self.lstm(x)
        return self.fc(out[:, -1])   # 取最后时间步的隐状态

model = LSTMModel(in_dim=5, hidden=32, out_dim=1)
x = torch.randn(32, 24, 5)
print("LSTM 预测输出:", model(x).shape)   # (32, 1)
```

## GRU

门控循环单元（Gated Recurrent Unit）是 LSTM 的简化版：把遗忘门和输入门合并成一个「更新门」，用「重置门」控制历史信息的利用。参数量比 LSTM 少约 1/3，训练更快，在很多时序任务上效果与 LSTM 相当。

```text
GRU vs LSTM：
1. 两个门 —— 更新门 z（保留多少）、重置门 r（遗忘多少）
2. 无细胞状态 —— 只靠隐藏状态 h_t 传记忆
3. 参数更少 —— 训练更快，小数据集上常优于 LSTM
```

```python
import torch
import torch.nn as nn

class GRUModel(nn.Module):
    def __init__(self, in_dim, hidden, out_dim, num_layers=2):
        super().__init__()
        self.gru = nn.GRU(in_dim, hidden, num_layers=num_layers,
                          batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden, out_dim)

    def forward(self, x):
        out, h = self.gru(x)
        return self.fc(out[:, -1])

model = GRUModel(in_dim=5, hidden=32, out_dim=1)
x = torch.randn(32, 24, 5)
print("GRU 预测输出:", model(x).shape)
# 对比参数量：GRU 约是 LSTM 的 3/4
lstm = LSTMModel(5, 32, 1)
print("LSTM 参数:", sum(p.numel() for p in lstm.parameters()))
print("GRU  参数:", sum(p.numel() for p in model.parameters()))
```

## TCN

时序卷积网络（Temporal Convolutional Network）用一维因果卷积（只看向过去）+ 膨胀（dilated）卷积扩大感受野，替代 RNN 做序列建模。它可并行计算、无梯度消失问题、感受野通过膨胀系数指数扩展，训练比 RNN 快。

```text
TCN 三要素：
1. 因果卷积 —— 时刻 t 的输出只依赖 ≤ t 的输入，无未来泄漏
2. 膨胀卷积 —— dilation 指数增大，感受野 = Σ dilation，指数级扩展
3. 残差连接 —— 稳定深层训练，允许堆很多层
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TCNBlock(nn.Module):
    def __init__(self, in_ch, out_ch, kernel_size, dilation):
        super().__init__()
        self.pad = (kernel_size - 1) * dilation   # 因果卷积的左 padding
        self.conv = nn.Conv1d(in_ch, out_ch, kernel_size,
                              padding=self.pad, dilation=dilation)
        self.conv1x1 = nn.Conv1d(in_ch, out_ch, 1) if in_ch != out_ch else None

    def forward(self, x):
        out = self.conv(x)[:, :, :-self.pad] if self.pad else self.conv(x)
        out = F.relu(out)
        res = x if self.conv1x1 is None else self.conv1x1(x)
        return out + res

# x: (batch, channels, seq_len)
x = torch.randn(32, 5, 24)
block = TCNBlock(5, 16, kernel_size=3, dilation=2)
print("TCN 块输出:", block(x).shape)   # (32, 16, 24)
```

## Transformer

Transformer 用自注意力机制取代循环：每个时间步都能直接「看到」序列里任意位置，通过注意力权重加权聚合信息。相比 RNN 能更好地捕捉长程依赖，且完全可并行。时序预测里常用编码器结构，配合位置编码保留顺序信息。

```text
Transformer 做时序的关键：
1. 自注意力 —— Q/K/V 计算注意力，全局建模长程依赖
2. 位置编码 —— 注意力本身无序，需注入位置信息
3. 掩码 —— 因果掩码保证预测 t 时不看未来
4. 多步输出 —— 解码器一次生成多步预测
```

```python
import torch
import torch.nn as nn

class TimeSeriesTransformer(nn.Module):
    def __init__(self, in_dim, d_model=32, nhead=4, num_layers=2):
        super().__init__()
        self.input_proj = nn.Linear(in_dim, d_model)
        # 可学习位置编码
        self.pos = nn.Parameter(torch.randn(1, 200, d_model))
        encoder_layer = nn.TransformerEncoderLayer(d_model, nhead, batch_first=True)
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers)
        self.fc = nn.Linear(d_model, 1)

    def forward(self, x):
        h = self.input_proj(x) + self.pos[:, :x.size(1)]
        out = self.encoder(h)
        return self.fc(out[:, -1])

model = TimeSeriesTransformer(in_dim=5)
x = torch.randn(32, 24, 5)
print("Transformer 预测输出:", model(x).shape)   # (32, 1)
```

## TFT

时间融合 Transformer（Temporal Fusion Transformer）是 Google 提出的工业级时序预测模型，在 Transformer 基础上加了可解释性：变量选择网络（挑重要特征）、静态协变量编码、分位数预测（给出不确定性区间）。它适合「多变量 + 已知未来输入 + 可解释需求」的预测场景。

```text
TFT 的工业级设计：
1. 变量选择 —— 自动挑出对预测有用的输入特征
2. 分位数输出 —— 预测 10%/50%/90% 分位，给出置信区间
3. 静态协变量 —— 编码不随时间变的属性（店铺位置、商品类别）
4. 可解释性 —— 注意力权重揭示哪些历史时刻最重要
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# TFT 的分位数预测思想：输出多个分位数，用分位数损失训练
def quantile_loss(preds, target, quantiles=[0.1, 0.5, 0.9]):
    # preds: (batch, n_quantiles)，target: (batch,)
    losses = []
    for i, q in enumerate(quantiles):
        diff = target - preds[:, i]
        losses.append(torch.max(q * diff, (q - 1) * diff))
    return torch.stack(losses, dim=1).mean()

preds = torch.tensor([[9.0, 10.0, 11.0], [19.0, 20.0, 21.0]])
target = torch.tensor([10.5, 19.2])
print("分位数损失:", round(quantile_loss(preds, target).item(), 4))
```

## 应用场景实战

### 场景一：LSTM 做单序列多步预测

```python
import numpy as np
import torch
import torch.nn as nn

# 合成带趋势和季节的序列
np.random.seed(0)
t = np.arange(600)
series = 0.2 * t + 10 * np.sin(2 * np.pi * t / 30) + np.random.randn(600) * 2

def make_windows(series, window, horizon):
    X, y = [], []
    for i in range(len(series) - window - horizon + 1):
        X.append(series[i:i + window])
        y.append(series[i + window:i + window + horizon])
    return np.array(X), np.array(y)

window, horizon = 60, 10
X, y = make_windows(series, window, horizon)
X = torch.tensor(X, dtype=torch.float32).unsqueeze(-1)
y = torch.tensor(y, dtype=torch.float32)

class LSTMForecast(nn.Module):
    def __init__(self):
        super().__init__()
        self.lstm = nn.LSTM(1, 32, batch_first=True)
        self.fc = nn.Linear(32, horizon)
    def forward(self, x):
        out, _ = self.lstm(x)
        return self.fc(out[:, -1])

model = LSTMForecast()
opt = torch.optim.Adam(model.parameters(), lr=0.01)
loss_fn = nn.MSELoss()

for epoch in range(200):
    opt.zero_grad()
    pred = model(X)
    loss = loss_fn(pred, y)
    loss.backward()
    opt.step()

print("LSTM 训练损失:", round(loss.item(), 3))
print("预测未来 10 步:", model(X[-1:]).detach().numpy().round(1))
```

### 场景二：Transformer 多变量预测（含已知未来输入）

```python
import torch
import torch.nn as nn

# 多变量：历史温度 + 未来日历特征，预测电力负荷
class MultiVarTransformer(nn.Module):
    def __init__(self, in_dim, d_model=32, nhead=4):
        super().__init__()
        self.proj = nn.Linear(in_dim, d_model)
        self.pos = nn.Parameter(torch.randn(1, 100, d_model))
        layer = nn.TransformerEncoderLayer(d_model, nhead, batch_first=True)
        self.encoder = nn.TransformerEncoder(layer, 2)
        self.fc = nn.Linear(d_model, 1)

    def forward(self, x):
        h = self.proj(x) + self.pos[:, :x.size(1)]
        return self.fc(self.encoder(h)[:, -1])

# 3 个输入特征：负荷、温度、是否工作日
x = torch.randn(64, 48, 3)
model = MultiVarTransformer(in_dim=3)
print("多变量 Transformer 输出:", model(x).shape)   # (64, 1)
```

## 最佳实践与踩坑记录

### 最佳实践

1. 数据量小（几千条以内）优先统计模型或树模型，深度学习容易过拟合，数据量大再上 LSTM/Transformer
2. 输入先标准化（z-score），序列值域差异大会导致训练不稳定
3. LSTM/GRU 序列别太长（超几百步难学），用窗口切分 + 合理窗口长度
4. 需要预测区间用分位数输出（TFT 或 quantile loss），点预测对业务决策不够用
5. 训练时按时间顺序切验证集，用 early stopping，别随机 shuffle 序列

### 踩坑记录

```text
坑 1：数据没标准化就训练
结论：序列量级几十万时 loss 巨大，梯度爆炸，训练直接发散。
原因：神经网络的激活和梯度对输入尺度敏感。
解法：训练前对每列做 z-score 标准化，预测时反变换回原量纲。

坑 2：序列打乱喂给 RNN
结论：把时间顺序 shuffle 后训练，模型学的是噪声，预测无意义。
原因：RNN/LSTM 依赖时间顺序，shuffle 破坏了时序结构。
解法：保持时间顺序，用按时间的 train/val split，DataLoader 不 shuffle。

坑 3：LSTM 序列过长梯度爆炸/消失
结论：直接喂几千步的原始序列，长期依赖学不到，训练慢甚至 NaN。
原因：LSTM 虽缓解梯度消失，但超长序列仍难训练。
解法：用滑动窗口切分（如 60~100 步），或改用 TCN/Transformer。

坑 4：用未来的数据做特征（自泄漏）
结论：Transformer 的注意力没加因果掩码，预测 t 时看到了 t+1 之后的值。
原因：编码器不加 mask 会双向看，测试时未来不可得导致线上崩溃。
解法：预测任务用因果掩码，或只把「已知未来输入」（日历、计划）放进来。

坑 5：点预测误当确定值做决策
结论：只输出一个均值，库存决策没考虑不确定性，缺货/积压。
原因：模型只训练了 MSE，丢掉了分布信息。
解法：用分位数损失输出 10/50/90 分位，给出预测区间。
```
