## 概述

时间序列异常检测的核心思路是「建立一个对正常行为的描述，偏离它即为异常」。基于残差的方法用预测模型学习正常规律、拿真实值减预测值找异常；动态阈值根据数据的时变特性自适应设定告警线；变点检测则定位序列统计性质发生突变的位置。这些方法广泛用于运维监控、风控、工业传感器。

```text
异常检测四类方法：
1. 残差检测 —— 预测正常值，残差超阈值即异常
2. 动态阈值 —— 阈值随时间和周期自适应变化
3. 变点检测 —— 找序列统计性质突变的时间点
4. 基于预测 —— 用预测区间（分位数）判断是否越界
```

```python
import numpy as np
import pandas as pd

# 合成带异常点的序列：正常段 + 几个尖峰
np.random.seed(0)
t = np.arange(200)
y = 50 + np.sin(t / 10) + np.random.randn(200) * 3
y[50] += 30     # 异常尖峰 1
y[120] -= 25    # 异常低谷 2

s = pd.Series(y, index=pd.date_range("2026-01-01", periods=200, freq="D"))
print("序列均值:", round(s.mean(), 1), "标准差:", round(s.std(), 1))
```

## Residual Detection

残差检测先学一个「正常模式」的模型（移动平均、ARIMA、神经网络等），预测每个时间点的期望值，再算真实值与预测值的残差。残差显著偏离（如超过 k 倍残差标准差）即判为异常。关键在于残差要近似白噪声，异常才容易从残差里凸显。

```text
残差检测三步：
1. 建模 —— 用正常数据训练预测模型，得到期望值 ŷ_t
2. 算残差 —— r_t = y_t - ŷ_t
3. 判异常 —— |r_t| > k·σ_r 时判为异常（k 通常 2~3）
```

```python
import numpy as np
import pandas as pd

np.random.seed(0)
t = np.arange(300)
y = 50 + np.sin(t / 20) + np.random.randn(300) * 2
y[100] += 20    # 注入异常

s = pd.Series(y)
# 用移动平均当「正常模型」
pred = s.rolling(window=10, center=True).mean()
residual = s - pred
sigma = residual.std()   # 残差标准差
k = 3

anomalies = np.where(np.abs(residual) > k * sigma)[0]
print("检测到的异常位置:", anomalies)   # 应包含 100
print("异常值:", y[anomalies])
```

## Dynamic Threshold

动态阈值不设一个固定的告警线，而是让阈值随时间、周期、业务量自适应变化。常见做法：按一天 24 小时或一周 7 天分段统计各自的均值和标准差，每段的阈值不同（如夜间流量低，阈值也应低）；或用 EWMA 平滑历史得到时变基线。这能避免「固定阈值在低峰期漏报、高峰期误报」。

```text
动态阈值 vs 固定阈值：
1. 固定阈值 —— 一条线卡所有时刻，忽略周期性和量级变化
2. 分段阈值 —— 按小时/星期分段，各段有自己的 μ±kσ
3. 时变基线 —— EWMA 跟踪近期水平，阈值随基线漂移
```

```python
import numpy as np
import pandas as pd

# 带昼夜周期的流量：白天高、夜间低
np.random.seed(0)
n = 48 * 14   # 14 天，每小时一个点
idx = pd.date_range("2026-01-01", periods=n, freq="h")
hour = idx.hour
base = 30 + 20 * np.sin((hour - 6) / 24 * 2 * np.pi)   # 白天高峰夜间低谷
y = base + np.random.randn(n) * 5

# 在凌晨（流量本该低）注入一个异常，固定阈值会漏掉
y[0] += 40

s = pd.Series(y, index=idx)
# 动态阈值：按小时分段算 μ±3σ
df = pd.DataFrame({"y": y, "hour": hour})
stats = df.groupby("hour")["y"].agg(["mean", "std"])
df = df.merge(stats, on="hour")
df["upper"] = df["mean"] + 3 * df["std"]
df["lower"] = df["mean"] - 3 * df["std"]

anomalies = df[(df["y"] > df["upper"]) | (df["y"] < df["lower"])].index
print("动态阈值检测到的异常:", anomalies)   # 应包含 0
```

## Change Point

变点检测（Change Point Detection）找出序列统计性质（均值、方差、趋势、分布）发生突变的时间点，而不是逐点判异常。代表方法：CUSUM（累积和，对均值漂移敏感）、PELT/Binseg（最小化成本函数找最优分段）、贝叶斯在线变点检测（BOCPD，在线实时）。用于版本发布后指标突变、传感器漂移等。

```text
变点检测方法：
1. CUSUM —— 累积偏离和，超过阈值即报变点，对小幅持续漂移敏感
2. PELT / Binseg —— 最小化「分段成本 + 惩罚项」，离线精确分段
3. BOCPD —— 贝叶斯在线，实时更新「当前仍处于第几段」的概率
```

```python
import numpy as np
import ruptures as rpt

# 均值在两处突变
np.random.seed(0)
n = 300
signal = np.concatenate([
    np.random.randn(100) + 0,
    np.random.randn(100) + 5,    # 均值跳到 5
    np.random.randn(100) - 2,    # 均值跳到 -2
])

# PELT 算法找变点
algo = rpt.Pelt(model="rbf").fit(signal)
change_points = algo.predict(pen=10)
print("检测到的变点:", change_points)   # 应接近 [100, 200, 300]
```

## Forecasting-Based Detection

基于预测的检测用预测模型给出「未来值的置信区间」（如分位数预测），实际值落在区间外即判异常。与残差检测的区别在于：它显式输出不确定性区间，且能处理「已知未来输入」（节假日、促销）导致的预期波动，减少把正常业务变化误报为异常。

```text
基于预测检测的要点：
1. 预测区间 —— 模型输出上/下分位（如 5% 和 95%）
2. 越界判异常 —— 真实值跌破下界或冲破上界
3. 结合已知未来 —— 节假日/促销等预期变化纳入，降低误报
```

```python
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing

np.random.seed(0)
t = np.arange(200)
y = 50 + 0.1 * t + np.random.randn(200) * 3
y[180] += 25    # 尾部注入异常

# 用前 160 期训练 Holt-Winters，预测后面并给出区间
train = y[:160]
model = ExponentialSmoothing(train, trend="add").fit()
forecast = model.forecast(steps=40)

# 用残差标准差估计预测区间
resid_std = np.std(train - model.fittedvalues)
upper = forecast + 3 * resid_std
lower = forecast - 3 * resid_std

test = y[160:]
anomalies = np.where((test > upper) | (test < lower))[0]
print("越界的异常位置(相对测试段):", anomalies)   # 应包含 20（=180-160）
```

## 应用场景实战

### 场景一：监控指标实时异常检测（EWMA 动态基线）

```python
import numpy as np
import pandas as pd

# 模拟线上 QPS 监控流：正常波动 + 突增异常
np.random.seed(1)
n = 500
y = 100 + np.random.randn(n) * 8
y[300:310] += 60    # 一段流量突增

# EWMA 时变基线
alpha = 0.1
ewma = pd.Series(y).ewm(alpha=alpha).mean()
# 时变标准差（EWM 方差）
ewm_var = pd.Series(y).ewm(alpha=alpha).var()
upper = ewma + 3 * np.sqrt(ewm_var)

alerts = np.where(pd.Series(y).values > upper.values)[0]
print("EWMA 动态阈值告警点:", alerts[:10])
```

### 场景二：版本发布后变点检测定位回归

```python
import numpy as np
import ruptures as rpt

# 某接口延迟：发布前 50ms，发布后 90ms（回归）
np.random.seed(0)
n = 400
latency = np.concatenate([
    np.random.randn(200) * 5 + 50,
    np.random.randn(200) * 5 + 90,   # 版本发布导致延迟飙升
])

algo = rpt.Pelt(model="l2").fit(latency)
cps = algo.predict(pen=20)
print("检测到的延迟变点:", cps)   # 应接近 [200, 400]

# 定位变点后，前后均值对比确认回归
if len(cps) > 1:
    before = latency[:cps[0]].mean()
    after = latency[cps[0]:].mean()
    print(f"发布前均值 {before:.1f}ms → 发布后均值 {after:.1f}ms")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 有周期性指标用动态阈值（按小时/星期分段），别用一刀切固定阈值
2. 残差检测前先确认预测模型的残差是白噪声，否则异常会被残差里的结构淹没
3. 阈值系数 k 和窗口大小用历史正常数据标定，并留少量已知异常验证召回
4. 变点检测用于「找突变时刻」（发布回归、策略切换），逐点异常用残差/阈值法
5. 业务预期波动（节假日、促销、活动）要作为已知输入喂给模型，否则全是误报

### 踩坑记录

```text
坑 1：固定阈值忽略周期性
结论：白天高峰设的阈值，凌晨正常流量全被误报为异常（或反之漏报）。
原因：指标有强日周期，均值标准差在不同时段差异巨大。
解法：按小时/星期分段设动态阈值，或用 EWMA 跟踪时变基线。

坑 2：移动平均窗口把异常也平滑进去
结论：用大窗口移动平均当基线，尖峰异常被平均掉，残差反而小、检不出。
原因：中心移动平均把异常点两侧的正常值也卷进来，污染基线。
解法：用单边窗口（只用过去）、或改用预测模型（拟合时不包含未来异常）。

坑 3：预测模型的残差没白噪声化
结论：残差里还残留趋势/季节，阈值一卡就误报一串。
原因：模型没捕捉完整规律，残差含结构性信息而非纯噪声。
解法：换更强的模型，或对残差再做差分/去季节，确认残差白噪声后再定阈值。

坑 4：把已知业务波动当异常告警
结论：双十一流量暴涨被判异常，天天误报，运维麻木后漏掉真故障。
原因：异常检测模型没纳入「促销/节假日」等已知未来信息。
解法：把日历/促销作为特征喂给模型，或对已知事件时段单独放宽阈值。

坑 5：变点检测惩罚参数拍脑袋
结论：PELT 的 penalty 设太小，检测出一堆噪声变点；设太大，真变点漏掉。
原因：penalty 控制「分段复杂度」和「拟合误差」的权衡，没标定。
解法：在带标注的验证集上网格搜索 penalty，用 F1 选最优值。
```
