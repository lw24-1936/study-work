## 概述

时间序列统计方法用「趋势 + 季节 + 周期 + 残差」的分解视角，以及自回归/移动平均/指数平滑等参数模型来刻画随时间变化的数据。它们是时序预测的经典 baseline：可解释性强、数据量小也能用，是机器学习/深度学习时序模型的对照基准。

```text
时间序列的组成（经典分解）：
1. Trend 趋势 —— 长期的上升/下降走向
2. Seasonality 季节 —— 固定周期内的规律波动（周/月/年）
3. Cycle 周期 —— 非固定长度的起伏（经济周期）
4. Residual 残差 —— 去掉以上三者的随机噪声
```

```python
import numpy as np
import pandas as pd

# 合成一条「趋势 + 季节 + 噪声」的时间序列
t = np.arange(120)
trend = 0.3 * t
seasonal = 10 * np.sin(2 * np.pi * t / 12)
noise = np.random.randn(120) * 2
y = trend + seasonal + noise
s = pd.Series(y, index=pd.date_range("2026-01-01", periods=120, freq="D"))
print(s.head())
```

## Trend

趋势是序列在长时间尺度上的方向性变化（上升、下降或平稳）。识别趋势常用移动平均平滑、线性/多项式拟合，或差分。趋势是很多预测模型的前提假设——ARIMA 要求序列无趋势（或差分后无趋势）。

```text
趋势识别方法：
1. 移动平均 —— 用窗口均值平滑掉短期波动，暴露长期走向
2. 线性回归 —— 对时间 index 拟合直线，斜率即趋势方向
3. 差分 —— 一阶差分 y_t - y_{t-1} 可消除线性趋势
```

```python
import pandas as pd
import numpy as np

np.random.seed(0)
t = np.arange(200)
y = 2 * t + 50 + np.random.randn(200) * 10   # 明显上升趋势
s = pd.Series(y)

# 移动平均平滑趋势
smooth = s.rolling(window=20, center=True).mean()
# 线性拟合趋势
slope, intercept = np.polyfit(t, y, 1)
print("趋势斜率:", round(slope, 2))   # 约 2

# 差分去趋势
diff = s.diff().dropna()
print("差分后均值:", round(diff.mean(), 2))   # 接近 2（趋势的斜率）
```

## Seasonality

季节性是指序列在固定周期内重复出现的规律（电商周末销量高、空调夏季销量高、节假日流量峰值）。周期长度是识别季节性的关键：日数据看周/年周期，小时数据看天/周周期。季节性可通过季节差分或季节分解移除。

```text
季节性的三个层次：
1. 日内 —— 小时级数据按 24 小时周期波动（早晚高峰）
2. 周内 —— 日级数据按 7 天周期波动（工作日 vs 周末）
3. 年内 —— 月/季度数据按 12 个月周期波动（季节性商品）
```

```python
import pandas as pd
import numpy as np

# 带周季节性的日数据
idx = pd.date_range("2026-01-01", periods=84, freq="D")
dow = idx.dayofweek                 # 周一=0 ... 周日=6
y = 20 + 5 * (dow < 5) + np.random.randn(84) * 1.5   # 工作日高、周末低

s = pd.Series(y, index=idx)
# 按星期几分组看季节性
seasonal_mean = s.groupby(idx.dayofweek).mean()
print("各星期均值:", seasonal_mean.round(1))
```

## Stationarity

平稳性指序列的统计性质（均值、方差、自相关）不随时间变化。弱平稳要求均值恒定、方差恒定、协方差只依赖时间间隔。绝大多数时序模型（ARMA、ARIMA 差分后）都假设平稳，因为平稳序列的规律可被参数化描述。

```text
平稳性判断：
1. 严平稳 —— 任意时间窗的联合分布不变（理论概念）
2. 弱平稳 —— 均值/方差恒定，自协方差只与滞后阶数有关
3. 检验 —— ADF 检验（Augmented Dickey-Fuller），p < 0.05 拒绝非平稳
```

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller

np.random.seed(1)
stationary = np.random.randn(200)                 # 白噪声，平稳
non_stationary = np.cumsum(np.random.randn(200))  # 随机游走，非平稳

for name, x in [("白噪声", stationary), ("随机游走", non_stationary)]:
    stat, p = adfuller(x)[:2]
    print(f"{name}: ADF 统计量={stat:.2f}, p={p:.3f} → {'平稳' if p < 0.05 else '非平稳'}")
```

## ACF

自相关函数（Autocorrelation Function）度量序列与其自身滞后 k 期的相关性，即 corr(y_t, y_{t-k})。ACF 图用于判断序列是否平稳（平稳序列 ACF 快速衰减到 0）以及识别 MA 模型的阶数（ACF 截尾在 q 阶）。

```text
ACF 要点：
1. 定义 —— ρ_k = corr(y_t, y_{t-k})
2. 平稳序列 —— ACF 随 k 增大指数/快速衰减
3. 非平稳序列 —— ACF 缓慢衰减，长期不为 0（需差分）
```

```python
import numpy as np
from statsmodels.tsa.stattools import acf

np.random.seed(0)
y = np.random.randn(200)      # 白噪声
rho = acf(y, nlags=20)
print("白噪声 ACF（应接近 0）:", np.round(rho[:5], 3))

# MA(1) 过程：y_t = ε_t + 0.7ε_{t-1}，ACF 在滞后 1 截尾
eps = np.random.randn(200)
ma1 = eps[1:] + 0.7 * eps[:-1]
print("MA(1) ACF:", np.round(acf(ma1, nlags=5)[:3], 3))
```

## PACF

偏自相关函数（Partial Autocorrelation Function）度量 y_t 与 y_{t-k} 在剔除中间各期影响后的「净相关」。PACF 图用于识别 AR 模型的阶数：AR(p) 的 PACF 在滞后 p 之后截尾为 0，而 ACF 是拖尾的（缓慢衰减）。

```text
ACF vs PACF 定阶口诀：
1. AR(p) —— ACF 拖尾，PACF 在 p 阶截尾
2. MA(q) —— ACF 在 q 阶截尾，PACF 拖尾
3. ARMA(p,q) —— ACF 和 PACF 都拖尾，需结合信息准则
```

```python
import numpy as np
from statsmodels.tsa.stattools import pacf

# AR(2) 过程：y_t = 0.5 y_{t-1} + 0.3 y_{t-2} + ε_t，PACF 在滞后 2 截尾
np.random.seed(0)
n = 300
y = np.zeros(n)
eps = np.random.randn(n)
for t in range(2, n):
    y[t] = 0.5 * y[t-1] + 0.3 * y[t-2] + eps[t]
print("AR(2) PACF:", np.round(pacf(y, nlags=5)[:5], 3))
```

## AR

自回归模型（AutoRegressive）用序列自身的过去值线性预测当前值：y_t = c + Σ φ_i y_{t-i} + ε_t。AR(p) 的阶数 p 表示用前 p 期预测当期。它捕捉序列的「惯性」——过去的走势会延续。

```text
AR(p) 模型：
y_t = c + φ₁y_{t-1} + φ₂y_{t-2} + ... + φ_p y_{t-p} + ε_t

- 平稳条件：特征根都在单位圆外（|φ| < 1 时稳定）
- 定阶：看 PACF 截尾位置，或用 AIC/BIC 搜索
```

```python
import numpy as np
from statsmodels.tsa.ar_model import AutoReg

np.random.seed(0)
n = 200
y = np.zeros(n)
eps = np.random.randn(n) * 0.5
for t in range(2, n):
    y[t] = 0.7 * y[t-1] - 0.1 * y[t-2] + eps[t]

model = AutoReg(y, lags=2).fit()
print("AR(2) 拟合系数:", np.round(model.params, 3))   # 接近 [0, 0.7, -0.1]
```

## MA

移动平均模型（Moving Average）用过去的预测误差线性组合预测当前值：y_t = μ + ε_t + Σ θ_i ε_{t-i}。MA(q) 表示用前 q 期的「冲击」（误差项）影响当期。它捕捉序列对随机冲击的「记忆」，冲击的影响在 q 期后消失。

```text
MA(q) 模型：
y_t = μ + ε_t + θ₁ε_{t-1} + ... + θ_q ε_{t-q}

- ε_t 是白噪声，θ 是冲击的记忆系数
- 定阶：看 ACF 截尾位置（ACF 在 q 阶后为 0）
- 与 AR 的区别：AR 用观测值，MA 用误差项
```

```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

np.random.seed(0)
n = 200
eps = np.random.randn(n) * 0.5
y = 1 + eps[1:] + 0.6 * eps[:-1]   # MA(1)：θ=0.6

model = ARIMA(y, order=(0, 0, 1)).fit()
print("MA(1) 拟合参数:", np.round(model.params, 3))
```

## ARMA

ARMA(p, q) 同时包含自回归项和移动平均项，能刻画既有惯性又有冲击记忆的平稳序列。它要求序列本身平稳，是 ARIMA 的核心（ARIMA 就是差分 + ARMA）。

```text
ARMA(p, q)：
y_t = c + Σ φ_i y_{t-i} + ε_t + Σ θ_j ε_{t-j}

- p = AR 阶数，q = MA 阶数
- 定阶：ACF/PACF 都拖尾时，用 AIC/BIC 网格搜索
```

```python
import numpy as np
import itertools
from statsmodels.tsa.arima.model import ARIMA

np.random.seed(0)
n = 300
y = np.zeros(n)
eps = np.random.randn(n) * 0.5
for t in range(2, n):
    y[t] = 0.5 * y[t-1] + eps[t] + 0.4 * eps[t-1]   # ARMA(1,1)

# 用 AIC 网格搜索定阶
best_aic, best_order = np.inf, None
for p, q in itertools.product(range(4), range(4)):
    try:
        aic = ARIMA(y, order=(p, 0, q)).fit().aic
        if aic < best_aic:
            best_aic, best_order = aic, (p, 0, q)
    except Exception:
        continue
print("AIC 最优阶数:", best_order, "AIC:", round(best_aic, 2))
```

## ARIMA

ARIMA(p, d, q) 在 ARMA 前加差分：d 阶差分使非平稳序列变平稳，再套 ARMA。它是单变量时序预测最经典、最常用的模型，三参数 (p, d, q) 分别是自回归阶数、差分阶数、移动平均阶数。

```text
ARIMA(p, d, q) 三步：
1. d 阶差分 —— 去趋势去季节，使序列平稳
2. p 阶自回归 —— 捕捉惯性
3. q 阶移动平均 —— 捕捉冲击记忆
```

```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

np.random.seed(0)
# 非平稳序列：带趋势 + 噪声
t = np.arange(200)
y = 0.5 * t + np.cumsum(np.random.randn(200) * 0.3) + np.random.randn(200)

model = ARIMA(y, order=(1, 1, 1)).fit()
forecast = model.forecast(steps=10)
print("ARIMA 预测未来 10 期:", np.round(forecast, 2))
print("残差方差:", round(model.sigma2, 2))
```

## SARIMA

SARIMA（季节性 ARIMA）在 ARIMA 基础上加了季节性成分，用 (P, D, Q, m) 四个参数描述季节周期内的自回归/差分/移动平均，m 是季节周期长度（如月度数据 m=12，日数据按周 m=7）。适合有明确季节波动的数据。

```text
SARIMA(p,d,q)(P,D,Q,m)：
1. (p,d,q) —— 非季节部分，处理趋势和短期相关
2. (P,D,Q) —— 季节部分，处理周期为 m 的季节相关
3. m —— 季节周期长度（月=12，周=7，小时按天=24）
```

```python
import numpy as np
from statsmodels.tsa.statespace.sarimax import SARIMAX

np.random.seed(0)
# 月度数据：趋势 + 年度季节（m=12）
t = np.arange(120)
y = 0.2 * t + 8 * np.sin(2 * np.pi * t / 12) + np.random.randn(120)

model = SARIMAX(y, order=(1, 1, 1), seasonal_order=(1, 0, 1, 12)).fit(disp=False)
forecast = model.forecast(steps=12)
print("SARIMA 预测未来 12 个月:", np.round(forecast, 1))
```

## VAR

向量自回归（Vector AutoRegression）把 AR 推广到多变量：每个变量不仅依赖自己的过去，还依赖其他变量的过去值，用来刻画多个时间序列之间的相互影响。适合预测相互关联的多条序列（如气温与用电量）。

```text
VAR(p) 要点：
1. 多变量 —— 每个方程里都有所有变量的滞后项
2. 相互影响 —— 通过系数矩阵刻画变量间的动态关系
3. 前提 —— 各序列平稳，可用 Granger 因果检验筛选变量
```

```python
import numpy as np
from statsmodels.tsa.api import VAR

np.random.seed(0)
n = 200
# 两个相互影响的时间序列
e = np.random.randn(n, 2)
data = np.zeros((n, 2))
for t in range(2, n):
    data[t, 0] = 0.5 * data[t-1, 0] + 0.2 * data[t-1, 1] + e[t, 0]
    data[t, 1] = 0.3 * data[t-1, 0] + 0.4 * data[t-1, 1] + e[t, 1]

model = VAR(data).fit(maxlags=2)
forecast = model.forecast(data[-2:], steps=5)
print("VAR 预测未来 5 期:", np.round(forecast, 2))
```

## ETS

指数平滑（Exponential Smoothing / ETS）是一族用「指数衰减权重」平滑历史观测做预测的方法，三元组 (Error, Trend, Seasonal) 描述误差、趋势、季节三个成分。Holt-Winters 是带趋势和季节的 ETS。它计算简单、适合短期预测，是很多业务系统的默认基线。

```text
ETS 三元组（E,T,S）：
1. E 误差 —— additive(A) 或 multiplicative(M)
2. T 趋势 —— none / additive / damped
3. S 季节 —— none / additive / multiplicative

- SES（简单指数平滑）—— 只有水平，无趋势无季节
- Holt —— 水平 + 趋势
- Holt-Winters —— 水平 + 趋势 + 季节
```

```python
import numpy as np
from statsmodels.tsa.holtwinters import ExponentialSmoothing

np.random.seed(0)
t = np.arange(72)
y = 10 + 0.3 * t + 4 * np.sin(2 * np.pi * t / 12) + np.random.randn(72)

model = ExponentialSmoothing(
    y, trend="add", seasonal="add", seasonal_periods=12
).fit()
forecast = model.forecast(steps=12)
print("Holt-Winters 预测未来 12 期:", np.round(forecast, 1))
```

## 应用场景实战

### 场景一：月度销售预测（SARIMA vs ETS 对比）

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.statespace.sarimax import SARIMAX
from statsmodels.tsa.holtwinters import ExponentialSmoothing
from sklearn.metrics import mean_squared_error

# 生成 6 年月度销售数据，带趋势 + 年度季节
np.random.seed(42)
t = np.arange(72)
y = 100 + 1.5 * t + 20 * np.sin(2 * np.pi * t / 12) + np.random.randn(72) * 8

train, test = y[:60], y[60:]

sarima = SARIMAX(train, order=(1, 1, 1), seasonal_order=(1, 0, 1, 12)).fit(disp=False)
ets = ExponentialSmoothing(train, trend="add", seasonal="add", seasonal_periods=12).fit()

pred_sarima = sarima.forecast(len(test))
pred_ets = ets.forecast(len(test))
print("SARIMA MSE:", round(mean_squared_error(test, pred_sarima), 1))
print("ETS    MSE:", round(mean_squared_error(test, pred_ets), 1))
```

### 场景二：差分 + 平稳性检验的完整流程

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller, acf, pacf

# 非平稳序列 → 差分 → 检验平稳 → 看 ACF/PACF 定阶
np.random.seed(0)
t = np.arange(200)
y = 0.8 * t + np.cumsum(np.random.randn(200) * 0.5) + np.random.randn(200) * 3

print("原序列 ADF p 值:", round(adfuller(y)[1], 4))
d1 = np.diff(y)
print("一阶差分后 ADF p 值:", round(adfuller(d1)[1], 4))

# 差分后序列的 ACF/PACF 帮助选 ARIMA 的 p、q
print("差分后 ACF 前 4 阶:", np.round(acf(d1, nlags=4)[1:], 3))
print("差分后 PACF 前 4 阶:", np.round(pacf(d1, nlags=4)[1:], 3))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 建模前先画时序图看趋势和季节，再决定要不要差分、要不要季节成分
2. 用 ADF 检验判断平稳性，非平稳先差分，差分次数通常 0~2 次
3. ARIMA 定阶用 ACF/PACF 初判 + AIC/BIC 网格搜索确认，别只凭图猜
4. 有明显季节周期的数据优先 SARIMA 或 Holt-Winters，纯 ARIMA 会漏掉季节结构
5. 多变量相互影响的序列用 VAR，但先做 Granger 因果检验筛掉无关变量

### 踩坑记录

```text
坑 1：非平稳序列直接上 ARMA
结论：拟合出假回归，系数和预测都不可信。
原因：ARMA 要求平稳，非平稳序列的统计性质随时间漂移。
解法：先 ADF 检验，非平稳做差分（或去趋势去季节）再建模。

坑 2：季节周期设错
结论：SARIMA 的 m 设成 7 但数据实际是年度周期（m=12），季节成分完全错位。
原因：没看数据采样频率就拍脑袋设周期。
解法：按采样频率定 m——月度=12、季度=4、日按周=7、小时按天=24。

坑 3：差分过度
结论：本已平稳的序列又做一次差分，引入额外的 MA 结构，预测变差。
原因：盲目「差分到平稳」，没检查是否已平稳。
解法：每差分一次跑一次 ADF，p < 0.05 就停，不要过度差分。

坑 4：只用训练集最后一段当测试集，未按时间切分
结论：随机切分训练测试，未来信息泄漏进训练，评估虚高。
原因：时间序列有先后依赖，随机切分破坏了时间顺序。
解法：按时间顺序切分，用 TimeSeriesSplit，绝不 shuffle。

坑 5：忽略残差白噪声检验
结论：模型拟合后残差仍有自相关，说明还有信息没被提取。
原因：只看了预测误差，没检查残差是否已无结构。
解法：对残差做 Ljung-Box 检验和 ACF 图，确认是白噪声才算建模完成。
```
