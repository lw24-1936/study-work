## 概述

时间序列机器学习把预测问题改造成监督学习问题：用「历史窗口」构造特征（lag、rolling 等），再用树模型（XGBoost、LightGBM）学习「特征 → 未来值」的映射。相比 ARIMA 等统计模型，它能自动捕捉非线性关系、处理大量外部特征和多序列联合建模，是现代业务预测的主力。

```text
时间序列 → 监督学习的转换：
1. 特征 —— 过去值（lag）、滚动统计量（rolling）、日历特征
2. 标签 —— 未来某一期或多期的值
3. 模型 —— 树模型（XGBoost/LightGBM）天然处理非线性 + 特征交互
```

```python
import numpy as np
import pandas as pd

np.random.seed(0)
idx = pd.date_range("2026-01-01", periods=200, freq="D")
y = pd.Series(np.cumsum(np.random.randn(200)) + 50, index=idx)

df = pd.DataFrame({"y": y})
# 构造滞后特征：用过去 3 期的值预测当期
for lag in [1, 2, 3]:
    df[f"lag_{lag}"] = df["y"].shift(lag)
df["target"] = df["y"].shift(-1)   # 预测下一期
print(df.dropna().head())
```

## Lag Features

滞后特征（Lag Features）把 t-k 时刻的值作为预测 t 时刻的特征，是时序监督学习的核心特征。它让模型「看到过去」。窗口大小（用多少期历史）是关键超参，通常结合 ACF 或领域知识（如「用过去 7 天预测明天」）确定。

```text
Lag Features 设计要点：
1. 滞后阶数 —— 用哪些 k 的值（lag_1, lag_7, lag_30...）
2. 多步预测 —— 预测多期时，标签也相应偏移（shift(-h)）
3. 周期性滞后 —— 日数据预测明天，常用 lag_1/lag_7/lag_14 捕捉周周期
```

```python
import pandas as pd
import numpy as np

np.random.seed(0)
idx = pd.date_range("2026-01-01", periods=100, freq="D")
df = pd.DataFrame({"sales": 30 + np.random.randn(100) * 5}, index=idx)

# 构造多个滞后特征 + 多步标签
for lag in [1, 7, 14]:
    df[f"lag_{lag}"] = df["sales"].shift(lag)

for h in [1, 7]:
    df[f"target_h{h}"] = df["sales"].shift(-h)

# 删除因 shift 产生的 NaN 行
df = df.dropna()
print(df.shape)   # 100 - 14 行滞后(lag_14) - 7 行标签(target_h7) = 79 行
print(df[["lag_1", "lag_7", "target_h1"]].head(3))
```

## Rolling Features

滚动特征（Rolling Features）在滑动窗口上计算统计量（均值、标准差、最大、最小、分位数），捕捉序列的局部形态和趋势。滚动均值平滑噪声、滚动标准差反映波动率，是树模型里表达「近期趋势」最有效的手段之一。

```text
Rolling Features 常用统计量：
1. rolling mean —— 近期平均水平（趋势）
2. rolling std —— 近期波动程度（风险/活跃度）
3. rolling max/min —— 近期极值（峰值/低谷）
4. 组合 —— mean + std 一起，树模型可学到「均值上升 + 波动小」的复合模式
```

```python
import pandas as pd
import numpy as np

np.random.seed(0)
idx = pd.date_range("2026-01-01", periods=120, freq="D")
df = pd.DataFrame({"value": 50 + np.cumsum(np.random.randn(120))}, index=idx)

# 多个窗口的滚动统计量
for win in [3, 7, 14]:
    df[f"roll_mean_{win}"] = df["value"].rolling(win).mean()
    df[f"roll_std_{win}"] = df["value"].rolling(win).std()
    df[f"roll_max_{win}"] = df["value"].rolling(win).max()

# 用滚动均值/标准差构造「标准化残差」特征（z-score）
df["zscore"] = (df["value"] - df["roll_mean_7"]) / df["roll_std_7"]
print(df.dropna()[["value", "roll_mean_7", "roll_std_7", "zscore"]].head(3))
```

## XGBoost

XGBoost（Extreme Gradient Boosting）是梯度提升树的高效实现，以正则化（L1/L2）、二阶导数近似、直方图/预排序分裂、缺失值自动处理著称。在时序监督学习里，它是强 baseline：对特征做 lag/rolling 转换后直接喂入，通常能超过经典统计模型。

```text
XGBoost 核心优势：
1. 正则化 —— 目标函数加 L1/L2 惩罚，控制过拟合
2. 二阶泰勒展开 —— 用二阶导数更精确地逼近损失
3. 缺失值处理 —— 自动学习缺失值走左还是走右
4. 早停 —— early stopping 防止过拟合，提速
```

```python
import numpy as np
import pandas as pd
import xgboost as xgb
from sklearn.metrics import mean_squared_error

np.random.seed(0)
idx = pd.date_range("2026-01-01", periods=300, freq="D")
vals = 100 + np.cumsum(np.random.randn(300)) + 10 * np.sin(np.arange(300) / 7)
df = pd.DataFrame({"y": vals}, index=idx)

for lag in [1, 2, 7]:
    df[f"lag_{lag}"] = df["y"].shift(lag)
df["roll_mean_7"] = df["y"].rolling(7).mean()
df["target"] = df["y"].shift(-1)
df = df.dropna()

X = df.drop(columns=["y", "target"]).values
y = df["target"].values

# 按时间切分，不 shuffle
split = int(len(df) * 0.8)
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

model = xgb.XGBRegressor(n_estimators=200, max_depth=4, learning_rate=0.05,
                         subsample=0.8, colsample_bytree=0.8)
model.fit(X_train, y_train,
          eval_set=[(X_test, y_test)], verbose=False)
pred = model.predict(X_test)
print("XGBoost MSE:", round(mean_squared_error(y_test, pred), 2))
print("特征重要性:", dict(zip(df.drop(columns=["y", "target"]).columns,
                              model.feature_importances_.round(3))))
```

## LightGBM

LightGBM 是微软开源的梯度提升框架，用基于直方图的算法和 Leaf-wise（叶子优先）生长策略，训练速度比 XGBoost 快数倍、内存占用更低，特别适合大规模时序数据。缺点是对小样本容易过拟合，需更严格的参数控制。

```text
LightGBM vs XGBoost：
1. 分裂策略 —— Leaf-wise（LightGBM）vs Level-wise（XGBoost）
2. 直方图 —— 把连续特征离散化到 bins，提速降内存
3. 速度 —— LightGBM 通常更快，适合大样本
4. 过拟合 —— LightGBM 对 max_depth/num_leaves 更敏感
```

```python
import numpy as np
import pandas as pd
import lightgbm as lgb
from sklearn.metrics import mean_squared_error

np.random.seed(0)
idx = pd.date_range("2026-01-01", periods=400, freq="H")
vals = 50 + np.cumsum(np.random.randn(400) * 0.3) + 5 * np.sin(np.arange(400) / 24)
df = pd.DataFrame({"y": vals}, index=idx)

for lag in [1, 24, 48]:
    df[f"lag_{lag}"] = df["y"].shift(lag)
df["roll_mean_24"] = df["y"].rolling(24).mean()
df["target"] = df["y"].shift(-1)
df = df.dropna()

X = df.drop(columns=["y", "target"]).values
y = df["target"].values
split = int(len(df) * 0.8)

model = lgb.LGBMRegressor(n_estimators=300, num_leaves=31, learning_rate=0.05,
                          subsample=0.8, colsample_bytree=0.8)
model.fit(X[:split], y[:split],
          eval_set=[(X[split:], y[split:])],
          callbacks=[lgb.early_stopping(50, verbose=False)])
pred = model.predict(X[split:])
print("LightGBM MSE:", round(mean_squared_error(y[split:], pred), 2))
```

## 应用场景实战

### 场景一：多特征 + 多滞后组合的销量预测

```python
import numpy as np
import pandas as pd
import lightgbm as lgb
from sklearn.metrics import mean_absolute_error

# 合成：销量受「自身历史 + 星期 + 促销」影响
np.random.seed(1)
n = 500
idx = pd.date_range("2026-01-01", periods=n, freq="D")
dow = idx.dayofweek
promo = (np.random.rand(n) < 0.2).astype(int)
base = 40 + 5 * (dow < 5) + 20 * promo
sales = base + np.random.randn(n) * 4

df = pd.DataFrame({"sales": sales, "dow": dow, "promo": promo}, index=idx)
for lag in [1, 7, 14]:
    df[f"lag_{lag}"] = df["sales"].shift(lag)
df["roll_mean_7"] = df["sales"].rolling(7).mean()
df["target"] = df["sales"].shift(-1)
df = df.dropna()

feats = [c for c in df.columns if c not in ("sales", "target")]
X, y = df[feats].values, df["target"].values
split = int(len(df) * 0.8)

model = lgb.LGBMRegressor(n_estimators=300, num_leaves=31, learning_rate=0.05)
model.fit(X[:split], y[:split],
          callbacks=[lgb.early_stopping(50, verbose=False)])
pred = model.predict(X[split:])
print("MAE:", round(mean_absolute_error(y[split:], pred), 2))
print("Top 特征:", sorted(zip(feats, model.feature_importances_),
                          key=lambda x: -x[1])[:3])
```

### 场景二：递归多步预测（recursive forecasting）

```python
import numpy as np
import pandas as pd
import xgboost as xgb

# 训练一步预测模型，然后用「预测值滚动当输入」递归预测未来 10 步
np.random.seed(0)
n = 300
idx = pd.date_range("2026-01-01", periods=n, freq="D")
vals = 80 + np.cumsum(np.random.randn(n) * 0.5) + 6 * np.sin(np.arange(n) / 7)
df = pd.DataFrame({"y": vals}, index=idx)
for lag in [1, 2, 7]:
    df[f"lag_{lag}"] = df["y"].shift(lag)
df["target"] = df["y"].shift(-1)
df = df.dropna()

X, y = df.drop(columns=["y", "target"]).values, df["target"].values
model = xgb.XGBRegressor(n_estimators=200, max_depth=4, learning_rate=0.05)
model.fit(X, y)

# 递归预测未来 10 步
last = df["y"].iloc[-7:].tolist()   # 最近的 7 期历史
preds = []
for _ in range(10):
    feat = [last[-1], last[-2], last[-7]]
    nxt = model.predict([feat])[0]
    preds.append(nxt)
    last.append(nxt)
print("递归预测未来 10 步:", np.round(preds, 1))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 构造特征时 lag 和 rolling 一起上，再叠加日历特征（星期、是否节假日、是否促销）
2. 数据按时间顺序切分，用 TimeSeriesSplit 或固定「前 80% 训练后 20% 测试」，绝不随机切
3. 树模型必配 early stopping（用验证集监控），防止过拟合历史
4. 先跑 LightGBM 拿强 baseline（快、效果好），再用 XGBoost 或统计模型对比
5. 多步预测优先递归法（单模型滚动预测），步数多时可考虑多输出模型或直接策略

### 踩坑记录

```text
坑 1：随机切分导致未来信息泄漏
结论：测试集样本混进训练集的历史窗口，评估分数虚高，上线后预测崩。
原因：时序有先后依赖，随机 shuffle 让模型「偷看」了未来。
解法：按时间顺序切分，用 TimeSeriesSplit，特征构造也不能用到未来值。

坑 2：lag 特征引入 NaN 后没处理
结论：shift 产生的 NaN 直接喂模型报错，或 dropna 时把标签也误删。
原因：lag/rolling 在序列开头产生缺失值，没统一清理。
解法：构造完特征统一 dropna，或在开头补零/前向填充，注意别删到有效标签。

坑 3：用当前期当特征预测当前期（自泄漏）
结论：不小心把 y_t 本身当作特征预测 y_t，模型「完美」但毫无用处。
原因：特征列里混入了当期真实值（lag 设成了 0 或没 shift）。
解法：特征只用 y 的滞后项（lag≥1），标签是未来值，写代码时逐列检查。

坑 4：LightGBM num_leaves 开太大过拟合
结论：小样本上 num_leaves 设成 255，训练集拟合完美、测试集一塌糊涂。
原因：Leaf-wise 生长 + 叶子过多，模型记住噪声。
解法：小样本 num_leaves 控制在 15~31，配合 min_data_in_leaf 和早停。

坑 5：忽略概念漂移，模型不更新
结论：训练完上线后不重训，几个月后预测误差越来越大。
原因：时间序列分布随时间漂移（促销策略变、用户行为变）。
解法：定期重训（如每周/每月），或加时间衰减权重，监测线上误差。
```
