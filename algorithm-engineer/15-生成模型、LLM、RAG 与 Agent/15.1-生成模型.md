## 概述

生成模型的目标是学习真实数据分布 p_data(x)，从而能采样出「看起来像真的」新样本。判别模型学的是条件分布 p(y|x)，而生成模型学的是联合分布 p(x) 或 p(x|z)。它是文生图、文生视频、代码补全、语音合成等一切内容生成任务的底层引擎。

```text
生成模型的演进主线：
1. 自编码器 → 学隐空间，但无法自由采样（普通 AE）
2. VAE → 给隐空间加概率约束，可采样但图像偏模糊
3. GAN → 对抗训练，图像锐利但训练不稳、易模式崩塌
4. Normalizing Flow → 精确可逆，可算似然，但计算量大
5. Diffusion → 逐步加噪/去噪，质量最高，当前主流
```

```python
import torch
import torch.nn as nn

# 一个最小生成模型：从噪声 z 生成图像的骨干
class TinyGenerator(nn.Module):
    def __init__(self, latent_dim=100, out_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.ReLU(),
            nn.Linear(256, 512), nn.ReLU(),
            nn.Linear(512, out_dim), nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z)

z = torch.randn(8, 100)
print(TinyGenerator()(z).shape)   # torch.Size([8, 784])
```

## Autoencoder

自编码器（AE）是一个「编码器 + 解码器」结构：编码器把输入压到低维隐空间，解码器再从隐空间重建输入。训练目标是让重建尽量接近原图，隐空间因此学会了数据的高效表示。

```text
结构：
x → Encoder → z → Decoder → x̂

损失：L = ‖x - x̂‖²（重建误差）

关键点：
1. 无监督 —— 只需要数据本身，不需要标签
2. 降维 —— 隐维度远小于输入维度，本质是非线性 PCA
3. 局限 —— 隐空间分布未知，随机采样一个 z 不能保证生成合理图像
```

```python
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, in_dim=784, latent_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(in_dim, 256), nn.ReLU(),
            nn.Linear(256, latent_dim),
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.ReLU(),
            nn.Linear(256, in_dim), nn.Sigmoid(),
        )

    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z), z

x = torch.rand(16, 784)
recon, z = Autoencoder()(x)
print(recon.shape, z.shape)   # torch.Size([16, 784]) torch.Size([16, 32])
```

## VAE

变分自编码器（VAE）把 AE 的「确定隐向量」升级为「隐分布」。编码器输出隐变量的均值 μ 和方差 σ，再从 N(μ, σ²) 采样 z。这样隐空间被约束成连续、平滑的分布，任意采样都能生成合理样本。

```text
数学定义：
1. 编码器输出 q_φ(z|x) = N(z; μ_φ(x), σ_φ(x)²)
2. 先验 p(z) = N(0, I)
3. 损失 = 重建项 + KL 散度：
   L = E[log p_θ(x|z)] - β·KL(q_φ(z|x) ‖ p(z))

重参数化技巧（reparameterization trick）：
z = μ + σ ⊙ ε，ε ~ N(0, I)
把采样操作移到网络外部，让梯度可以反传。
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, in_dim=784, latent_dim=32):
        super().__init__()
        self.enc = nn.Linear(in_dim, 256)
        self.fc_mu = nn.Linear(256, latent_dim)
        self.fc_logvar = nn.Linear(256, latent_dim)
        self.dec = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.ReLU(),
            nn.Linear(256, in_dim), nn.Sigmoid(),
        )

    def encode(self, x):
        h = F.relu(self.enc(x))
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)          # ε ~ N(0, I)
        return mu + eps * std                # 重参数化

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.dec(z), mu, logvar

def vae_loss(x, recon, mu, logvar, beta=1.0):
    recon_loss = F.binary_cross_entropy(recon, x, reduction='sum')
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + beta * kl

vae = VAE()
x = torch.rand(16, 784)
recon, mu, logvar = vae(x)
print(f'loss = {vae_loss(x, recon, mu, logvar).item():.1f}')
```

## GAN

生成对抗网络（GAN）由生成器 G 和判别器 D 组成：G 把噪声变成假样本，D 判断样本是真还是假。两者对抗博弈，G 试图骗过 D，D 试图识破 G，最终 G 学会生成逼真样本。

```text
数学定义（minimax 博弈）：
min_G max_D  E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]

训练流程：
1. 固定 G，训练 D：真样本标 1，假样本标 0，最大化判别准确率
2. 固定 D，训练 G：让 D(G(z)) 尽量接近 1，骗过判别器
3. 交替迭代直到 D(G(z)) ≈ 0.5（判别器无法区分真假）
```

```python
import torch.nn as nn

class Generator(nn.Module):
    def __init__(self, z_dim=100, img_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(z_dim, 256), nn.ReLU(),
            nn.Linear(256, 512), nn.ReLU(),
            nn.Linear(512, img_dim), nn.Tanh(),
        )

    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, img_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(img_dim, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 1), nn.Sigmoid(),
        )

    def forward(self, x):
        return self.net(x)

G, D = Generator(), Discriminator()
z = torch.randn(8, 100)
fake = G(z)
print(f'D(fake) 平均 = {D(fake).mean().item():.3f}（训练初期接近 0.5）')
```

## WGAN

WGAN 用 Wasserstein 距离替代 GAN 的 JS 散度，解决原始 GAN 的梯度消失和训练不稳定问题。核心改动：去掉判别器输出层的 sigmoid，改用「权重裁剪」或梯度惩罚来约束判别器满足 1-Lipschitz 条件。

```text
Wasserstein 距离（推土机距离）：
W(p_r, p_g) = inf E[‖x - y‖]（把分布 p_r 搬到 p_g 的最小代价）

关键改动：
1. 判别器改叫 critic，输出实数分数（不做 sigmoid）
2. critic 损失 = E[D(x)] - E[D(G(z))]，最大化这个差
3. 生成器损失 = -E[D(G(z))]
4. 约束 critic 是 1-Lipschitz：权重裁剪到 [-c, c] 或用梯度惩罚

为什么更好：
JS 散度在两个分布不重叠时恒为 log 2，梯度为 0；Wasserstein 距离处处平滑，始终提供有意义的梯度。
```

```python
# WGAN 的 critic 与损失（梯度惩罚版本 WGAN-GP）
import torch
import torch.nn as nn

def gradient_penalty(critic, real, fake):
    alpha = torch.rand(real.size(0), 1)
    interpolates = (alpha * real + (1 - alpha) * fake).requires_grad_(True)
    d_inter = critic(interpolates)
    grads = torch.autograd.grad(
        outputs=d_inter, inputs=interpolates,
        grad_outputs=torch.ones_like(d_inter),
        create_graph=True, retain_graph=True,
    )[0]
    gp = ((grads.norm(2, dim=1) - 1) ** 2).mean()
    return gp

# critic 去掉 sigmoid，输出无界实数分数
class Critic(nn.Module):
    def __init__(self, img_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(img_dim, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 1),          # 注意：没有 sigmoid
        )

    def forward(self, x):
        return self.net(x)

C = Critic()
real, fake = torch.randn(16, 784), G(torch.randn(16, 100))
print(f'Wasserstein 估计 = {(C(real).mean() - C(fake).mean()).item():.3f}')
```

## Normalizing Flow

标准化流（Normalizing Flow）通过一串可逆变换把简单分布（如标准正态）逐步「流」成复杂的目标分布。因为变换可逆且雅可比行列式可求，它能精确计算似然 p(x)，这是 VAE 和 GAN 都做不到的。

```text
数学定义：
x = f_K ∘ ... ∘ f_1(z)，z ~ N(0, I)

变元公式（change of variables）：
log p(x) = log p(z) - Σ log |det(∂f_k / ∂f_{k-1})|

设计要点：
1. 每个 f_k 必须可逆
2. 雅可比行列式必须好算（三角矩阵、低秩更新等技巧）
3. 逆变换也要好算（用于从 z 采样 x）
```

```python
import torch
import torch.nn as nn

# RealNVP 风格的仿射耦合层（可逆、雅可比易算）
class AffineCoupling(nn.Module):
    def __init__(self, dim, hidden=64):
        super().__init__()
        self.s = nn.Sequential(
            nn.Linear(dim // 2, hidden), nn.ReLU(),
            nn.Linear(hidden, dim // 2),
        )
        self.t = nn.Sequential(
            nn.Linear(dim // 2, hidden), nn.ReLU(),
            nn.Linear(hidden, dim // 2),
        )

    def forward(self, x):          # z → x 方向
        x1, x2 = x.chunk(2, dim=-1)
        s, t = self.s(x1), self.t(x1)
        y2 = x2 * torch.exp(s) + t
        log_det = s.sum(dim=-1)
        return torch.cat([x1, y2], dim=-1), log_det

    def inverse(self, y):          # x → z 方向
        y1, y2 = y.chunk(2, dim=-1)
        s, t = self.s(y1), self.t(y1)
        x2 = (y2 - t) * torch.exp(-s)
        return torch.cat([y1, x2], dim=-1)

z = torch.randn(8, 4)
x, log_det = AffineCoupling(4)(z)
print(f'log|det| = {log_det.mean().item():.3f}，可精确算似然')
```

## Diffusion

扩散模型分两步：前向过程逐步给数据加高斯噪声，直到变成纯噪声；反向过程训练一个网络逐步去噪，把噪声还原成数据。生成时从纯噪声出发，一步步「去噪」得到样本，所以质量高、训练稳定。

```text
核心思想：
前向（加噪）：x_t = √(ᾱ_t)·x_0 + √(1-ᾱ_t)·ε，ε ~ N(0, I)
  t 从 0 到 T，ᾱ_t 单调递减，x_T 近似纯高斯噪声

反向（去噪）：学习 p_θ(x_{t-1} | x_t)，一步步从噪声回到数据

训练目标（简化后）：
L = E[‖ε - ε_θ(x_t, t)‖²]
即让网络预测「上一步加进去的噪声」，等价于去噪。
```

```python
import torch

# 前向加噪：给定干净数据 x0，一步到位得到第 t 步的加噪样本
def q_sample(x0, t, alphas_bar):
    sqrt_alpha_bar = alphas_bar[t].sqrt().view(-1, 1)
    sqrt_one_minus = (1 - alphas_bar[t]).sqrt().view(-1, 1)
    noise = torch.randn_like(x0)
    return sqrt_alpha_bar * x0 + sqrt_one_minus * noise, noise

T = 1000
alphas_bar = torch.linspace(0.9999, 1e-4, T)   # 简化的 ᾱ_t 调度（末值不为 0，避免反向去噪时除零）
x0 = torch.randn(4, 64)
x_t, eps = q_sample(x0, torch.tensor([T - 1]), alphas_bar)
print(f'x_T 方差 ≈ {x_t.var().item():.2f}（应接近 1，即纯噪声）')
```

## DDPM

DDPM（Denoising Diffusion Probabilistic Models）是扩散模型的奠基工作，把「去噪」形式化为马尔可夫链，用 UNet 在每一步预测噪声。它证明了只要 T 足够大、调度合理，反向过程就能从噪声精确重建数据。

```text
DDPM 的关键设计：
1. 方差调度 —— β_t 从 1e-4 线性增加到 0.02，ᾱ_t = Π(1-β_s)
2. 网络预测噪声 ε_θ(x_t, t)，损失为简单的 MSE
3. 采样是逐步的：x_{t-1} = (1/√α_t)(x_t - (1-α_t)/√(1-ᾱ_t)·ε_θ) + σ_t·z
4. 用时间步 t 作为条件注入网络（位置编码 + 分组归一化）

特点：生成质量高、训练稳定、不需要对抗，但采样慢（要跑 T=1000 步）。
```

```python
import torch
import torch.nn as nn

# 一个极简的噪声预测网络（真实 DDPM 用 UNet，这里用 MLP 示意）
class NoisePredictor(nn.Module):
    def __init__(self, dim=64, hidden=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim + 1, hidden), nn.ReLU(),   # +1 是时间步 t
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, dim),
        )

    def forward(self, x_t, t):
        t_norm = t.float().unsqueeze(1) / 1000.0
        return self.net(torch.cat([x_t, t_norm], dim=-1))

# 单步 DDPM 训练损失
def ddpm_loss(model, x0, t, alphas_bar):
    x_t, eps = q_sample(x0, t, alphas_bar)
    eps_pred = model(x_t, t)
    return ((eps - eps_pred) ** 2).mean()

model = NoisePredictor()
x0 = torch.randn(16, 64)
t = torch.randint(0, 1000, (16,))
print(f'DDPM loss = {ddpm_loss(model, x0, t, alphas_bar).item():.3f}')
```

## DDIM

DDIM（Denoising Diffusion Implicit Models）把 DDPM 的马尔可夫采样改成非马尔可夫的确定性采样，允许「跳步」采样，把 1000 步压缩到几十步甚至十步，速度提升一个数量级，同时保持生成质量。

```text
核心思想：
1. DDPM 采样依赖马尔可夫链，必须一步步走 T 步
2. DDIM 提出更一般的非马尔可夫前向过程，训练目标不变
3. 采样变成确定性公式（σ=0 时），可跳步、可加速

关键公式（确定性采样）：
x_{t-1} = √(ᾱ_{t-1})·x̂_0 + √(1-ᾱ_{t-1})·ε_θ(x_t, t)

其中 x̂_0 = (x_t - √(1-ᾱ_t)·ε_θ) / √(ᾱ_t) 是「预测的干净样本」。
跳步采样：从 {T, T-k, T-2k, ...} 中选时间步，只跑几十步。
```

```python
import torch

# DDIM 采样：从噪声出发，按时间子序列跳步去噪
def ddim_sample(model, shape, alphas_bar, steps=50):
    x_t = torch.randn(*shape)
    ts = torch.linspace(999, 0, steps).long()   # 跳步选择时间步
    for i in range(len(ts) - 1):
        t = torch.full((shape[0],), ts[i])
        eps_pred = model(x_t, t)
        sqrt_alpha_bar = alphas_bar[ts[i]].sqrt().view(-1, 1)
        x0_pred = (x_t - (1 - alphas_bar[ts[i]]).sqrt().view(-1, 1) * eps_pred) / sqrt_alpha_bar
        # 跳转到下一个时间步
        sqrt_ab_next = alphas_bar[ts[i + 1]].sqrt().view(-1, 1)
        x_t = sqrt_ab_next * x0_pred + (1 - alphas_bar[ts[i + 1]]).sqrt().view(-1, 1) * eps_pred
    return x_t

sample = ddim_sample(model, (4, 64), alphas_bar, steps=50)
print(f'DDIM 用 50 步完成采样，样本形状 = {sample.shape}')
```

## Latent Diffusion

潜在扩散模型（Latent Diffusion，Stable Diffusion 的底座）把扩散过程从「像素空间」搬到「隐空间」：先用 VAE 把图像压到低维 latent，再在 latent 上做扩散。计算量大幅下降，还方便引入文本等条件，是文生图的事实标准。

```text
Latent Diffusion 三件套：
1. VAE —— 把图像 x 编码到 latent z，再解码回图像（感知压缩）
2. UNet —— 在 latent 空间做去噪，并接收条件（文本 embedding）
3. 条件机制 —— 用交叉注意力把文本/图像条件注入去噪过程

优势：
1. 高效 —— latent 比像素小 8 倍左右，计算和显存大幅下降
2. 可控 —— 通过交叉注意力轻松加入文本、布局等条件
3. 质量 —— 继承了扩散模型的生成质量，是 Stable Diffusion 的核心
```

```python
import torch
import torch.nn as nn

# 条件注入的核心：交叉注意力（用文本 embedding 引导去噪）
class CrossAttention(nn.Module):
    def __init__(self, dim=64, ctx_dim=128):
        super().__init__()
        self.q = nn.Linear(dim, dim)
        self.k = nn.Linear(ctx_dim, dim)
        self.v = nn.Linear(ctx_dim, dim)
        self.scale = dim ** -0.5

    def forward(self, x, context):
        Q, K, V = self.q(x), self.k(context), self.v(context)
        attn = torch.softmax(Q @ K.transpose(-2, -1) * self.scale, dim=-1)
        return attn @ V

latent = torch.randn(4, 32, 64)     # 潜在特征
text_emb = torch.randn(4, 16, 128)  # 文本条件 embedding
out = CrossAttention()(latent, text_emb)
print(f'交叉注意力输出形状 = {out.shape}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 追求生成质量选 Diffusion/Latent Diffusion，追求速度选 GAN 或 VAE，追求可算似然选 Normalizing Flow
2. 文生图优先用现成的 Latent Diffusion 底座（Stable Diffusion），别从零训扩散模型
3. GAN 训练不稳时先换 WGAN-GP，梯度惩罚比权重裁剪更稳定
4. VAE 训练时监控 KL 项，出现 posterior collapse（KL 趋近 0）要加 β 退火或换更强的解码器
5. 扩散模型采样用 DDIM 跳步加速，50 步通常就能拿到不错的质量
6. 条件生成用交叉注意力注入条件，比直接拼接条件向量更灵活

### 踩坑记录

```text
坑 1：原始 GAN 训练时 D 太强导致 G 梯度消失
结论：判别器很快学会区分真假，D(G(z)) 趋近 0，生成器得不到有效梯度。
原因：JS 散度在真假分布不重叠时恒为常数，梯度消失。
解法：换 WGAN/WGAN-GP，或给 D 加梯度惩罚、降低 D 的学习率。

坑 2：GAN 模式崩塌（mode collapse）
结论：生成器只学会产生一两种样本，多样性极差。
原因：G 找到一个能骗过 D 的「捷径」，把所有 z 都映射到少数几个样本。
解法：WGAN、mini-batch 判别、unrolled GAN，或换扩散模型。

坑 3：VAE 后验崩塌（posterior collapse）
结论：KL 项被压到接近 0，隐变量不再编码任何信息，退化成普通 AE。
原因：解码器太强时，模型倾向忽略隐变量直接重建。
解法：KL 退火（β 从 0 渐增）、free bits、弱化解码器。

坑 4：扩散模型采样太慢
结论：DDPM 要跑 1000 步，单张图耗时几十秒。
原因：马尔可夫链采样必须逐步进行。
解法：DDIM 跳步采样、DPM-Solver 等快速 ODE 求解器，可压缩到 10-50 步。

坑 5：Normalizing Flow 维度不匹配
结论：可逆变换要求输入输出维度严格相等，维度一变就报错。
原因：可逆性和雅可比行列式都要求同维度的双射。
解法：保持各层维度一致，用 coupling/spline 等保维可逆层。
```
