## 概述

线性结构是最基础的数据结构家族：元素之间是「一对一」的顺序关系，每个元素最多有一个前驱和一个后继。数组、链表、栈、队列及其变体几乎出现在所有程序的底层，理解它们的底层内存布局和操作复杂度，是写出高性能代码的前提。

```text
线性结构的核心要点：
1. 连续 vs 链式 —— 数组内存连续、随机访问 O(1)；链表指针串联、插入删除 O(1)
2. 操作受限 —— 栈（LIFO）、队列（FIFO）通过限制操作获得清晰的语义
3. 变体扩展 —— Deque 双端可进出，Priority Queue 按优先级出队而非先进先出
4. 内存布局 —— 缓存友好性差异巨大，数组遍历远比链表遍历快
```

```python
# 线性结构一览：各结构的典型操作对比
from collections import deque
import heapq

arr = [1, 2, 3]              # 数组：下标随机访问
lst = [1, 2, 3]              # Python list 底层就是动态数组
stack = []; stack.append(1)  # 栈：用 list 模拟 LIFO
q = deque([1, 2, 3])         # 队列：collections.deque 双端
pq = []; heapq.heappush(pq, 3)  # 优先队列：heapq 最小堆

print(arr[1], stack, q, pq)  # 2 [1] deque([1, 2, 3]) [3]
```

## 数组

数组（Array）是内存中连续存放的一段同类型元素，靠下标在 O(1) 时间内随机访问任意元素。它是最简单也最重要的结构，Python 的 list 底层就是「动态数组」（自动扩容），C 语言的数组则是定长裸数组。

```text
复杂度：
- 按下标访问/修改：O(1)
- 末尾追加：均摊 O(1)
- 中间插入/删除：O(n)，需要移动后续元素
- 查找（无序）：O(n)；查找（有序）：O(log n) 二分

特点：
1. 内存连续 → 缓存友好，顺序遍历极快
2. 随机访问 O(1) → 是哈希表、堆、矩阵的底层
3. 插入删除 O(n) → 频繁增删中间元素时是瓶颈
```

```python
# 数组操作演示
arr = [10, 20, 30, 40]

# O(1) 随机访问
print(arr[2])                    # 30

# O(1) 末尾追加（均摊）
arr.append(50)

# O(n) 中间插入：下标 1 插入 99，后续元素整体右移
arr.insert(1, 99)
print(arr)                       # [10, 99, 20, 30, 40, 50]

# O(n) 中间删除
del arr[1]
print(arr)                       # [10, 20, 30, 40, 50]

# 数组切片：创建新数组，O(k)（k 为切片长度）
print(arr[1:3])                  # [20, 30]
```

## 链表

链表（Linked List）用指针把一个个节点串联起来，每个节点保存数据和指向下一个节点的引用。它牺牲了随机访问，换来了 O(1) 的插入删除（只要拿到节点指针），适合频繁增删、长度动态变化的场景。

```text
复杂度：
- 访问第 i 个节点：O(n)，必须从头遍历
- 头部插入/删除：O(1)
- 已知节点后插入/删除：O(1)
- 查找：O(n)

类型：
1. 单链表 —— 每个节点一个 next 指针
2. 双向链表 —— 每个节点 prev + next，可双向遍历
3. 循环链表 —— 尾节点指向头节点
```

```python
class ListNode:
    def __init__(self, val=0, nxt=None):
        self.val = val
        self.next = nxt


class LinkedList:
    def __init__(self):
        self.head = None

    def prepend(self, val):
        """O(1) 头插"""
        self.head = ListNode(val, self.head)

    def to_list(self):
        """O(n) 遍历"""
        res, cur = [], self.head
        while cur:
            res.append(cur.val)
            cur = cur.next
        return res

    def reverse(self):
        """O(n) 反转链表（经典面试题）"""
        prev, cur = None, self.head
        while cur:
            nxt = cur.next
            cur.next = prev
            prev, cur = cur, nxt
        self.head = prev


ll = LinkedList()
for v in [1, 2, 3, 4]:
    ll.prepend(v)
print(ll.to_list())     # [4, 3, 2, 1]
ll.reverse()
print(ll.to_list())     # [1, 2, 3, 4]
```

## 栈

栈（Stack）是「后进先出」（LIFO）的受限线性结构：只能在栈顶进行 push（入栈）和 pop（出栈）。它天然匹配「函数调用、括号匹配、撤销操作、DFS 回溯」这类需要「先处理最近的问题」的场景。

```text
复杂度：
- push / pop / peek（看栈顶）：O(1)
- 查找中间元素：O(n)，栈语义上通常不允许

特点：
1. LIFO —— 后进先出，只有栈顶可见
2. 函数调用栈 —— 递归的本质就是系统栈
3. 单调栈 —— 维护栈内元素单调性，O(n) 解「下一个更大元素」类问题
```

```python
# 栈的基本操作（用 list 模拟）
stack = []
stack.append(1)      # push
stack.append(2)
stack.append(3)
print(stack.pop())   # 3，pop 栈顶
print(stack[-1])     # 2，peek 栈顶
print(stack)         # [1, 2]


# 经典应用：括号匹配（用栈判断括号是否合法）
def is_valid(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack

print(is_valid('{[()]}'))   # True
print(is_valid('{[(])}'))   # False


# 单调栈：求每个元素右边第一个比它大的元素（O(n)）
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []   # 存下标，栈内对应值保持递减
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        stack.append(i)
    return res

print(next_greater([2, 1, 2, 4, 3]))   # [4, 2, 4, -1, -1]
```

## 队列

队列（Queue）是「先进先出」（FIFO）的受限线性结构：元素从队尾入队（enqueue），从队头出队（dequeue）。它模拟「排队」的语义，广泛用于任务调度、消息队列、BFS 层序遍历等「先来先服务」的场景。

```text
复杂度：
- enqueue / dequeue / peek（队头）：O(1)
- 查找中间元素：O(n)

实现要点：
1. 用 list 的 pop(0) 是 O(n)（要移动元素），应改用 collections.deque
2. 循环队列 —— 用数组 + 头尾指针，避免出队移动元素
3. 单调队列 —— 维护队列内元素单调，O(n) 解滑动窗口最值
```

```python
from collections import deque

# 正确做法：用 deque 实现 O(1) 入队出队
q = deque()
q.append(1)          # 入队（队尾）
q.append(2)
q.append(3)
print(q.popleft())   # 1，出队（队头）
print(q[0])          # 2，peek 队头


# 经典应用：BFS 层序遍历（队列承载「待访问」节点）
def bfs_level_order(root):
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):     # 固定当前层大小
            node = q.popleft()
            level.append(node)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res


# 单调队列：滑动窗口最大值（O(n)）
def max_sliding_window(nums, k):
    dq, res = deque(), []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:    # 保持队头是窗口内最大值
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:                 # 队头滑出窗口
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

print(max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))   # [3, 3, 5, 5, 6, 7]
```

## Deque

Deque（双端队列，Double-Ended Queue）允许在两端都进行 O(1) 的插入和删除。它比普通队列更灵活，既当栈又当队列，是很多算法（滑动窗口、单调队列、回文判断）的底层工具。

```text
复杂度：
- 两端 append / appendleft / pop / popleft：O(1)
- 按下标访问中间元素：O(n)（deque 是链式块结构，非连续数组）

特点：
1. 双向进出 —— 同时支持 FIFO 和 LIFO 语义
2. 底层是双向链表块 —— 中间访问 O(n)，别当随机访问结构用
3. maxlen 参数 —— 自动丢弃最旧元素，天然适合「最近 N 条」缓存
```

```python
from collections import deque

# 双端操作
dq = deque([1, 2, 3])
dq.append(4)            # 右端入 [1,2,3,4]
dq.appendleft(0)        # 左端入 [0,1,2,3,4]
dq.pop()                # 右端出 [0,1,2,3]
dq.popleft()            # 左端出 [1,2,3]
print(dq)               # deque([1, 2, 3])


# maxlen 用法：只保留最近 3 个元素
history = deque(maxlen=3)
for i in range(1, 6):
    history.append(i)
    print(list(history), end=' ')
# [1] [1, 2] [1, 2, 3] [2, 3, 4] [3, 4, 5] → 自动挤掉最旧


# 回文判断：双端同时比较（O(n)）
def is_palindrome(s):
    dq = deque(s)
    while len(dq) > 1:
        if dq.popleft() != dq.pop():
            return False
    return True

print(is_palindrome('radar'))    # True
print(is_palindrome('hello'))    # False
```

## Priority Queue

优先队列（Priority Queue）不再按「先进先出」出队，而是每次取出「优先级最高」的元素。它常用「二叉堆」（Heap）实现：堆顶总是最值，插入和删除最值都是 O(log n)。是 Dijkstra、任务调度、Top-K、霍夫曼编码的核心结构。

```text
复杂度（基于二叉堆）：
- 插入 push：O(log n)
- 取最值 peek：O(1)
- 弹出最值 pop：O(log n)
- 建堆 heapify：O(n)

Python 细节：
1. heapq 是最小堆 —— 取最小值；要最大堆就存负数或自定义 key
2. 堆并不保证整体有序，只保证「父 ≤ 子」的偏序
3. 用 (priority, item) 元组可做多级优先级排序
```

```python
import heapq

# 最小堆基本操作
pq = []
for x in [3, 1, 4, 1, 5, 9, 2, 6]:
    heapq.heappush(pq, x)
print(heapq.heappop(pq))   # 1（最小值）
print(heapq.heappop(pq))   # 1
print(pq[0])               # 2，堆顶是最小值（peek，O(1)）


# 最大堆：存负数
max_heap = []
for x in [3, 1, 4, 1, 5]:
    heapq.heappush(max_heap, -x)
print(-heapq.heappop(max_heap))   # 5（最大值）


# Top-K：维护大小为 K 的最小堆，堆顶是第 K 大
def top_k(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)    # 挤掉当前最小
    return sorted(heap, reverse=True)

print(top_k([3, 1, 4, 1, 5, 9, 2, 6], 3))   # [9, 6, 5]


# 多级优先级：(优先级, 序号, 任务)
tasks = [(2, 0, 'low'), (1, 1, 'high'), (2, 2, 'low2')]
heapq.heapify(tasks)
print(heapq.heappop(tasks))   # (1, 1, 'high') 先按优先级，再按序号
```

## 应用场景实战

### 场景一：用栈实现一个「撤销/重做」编辑器

```python
class Editor:
    def __init__(self):
        self.text = ''
        self.undo_stack = []    # 栈：保存历史状态
        self.redo_stack = []    # 栈：保存被撤销的状态

    def type(self, s):
        self.undo_stack.append(self.text)   # 保存旧状态
        self.redo_stack.clear()
        self.text += s

    def undo(self):
        if self.undo_stack:
            self.redo_stack.append(self.text)
            self.text = self.undo_stack.pop()

    def redo(self):
        if self.redo_stack:
            self.undo_stack.append(self.text)
            self.text = self.redo_stack.pop()


ed = Editor()
ed.type('hello'); ed.type(' world')
print(ed.text)      # hello world
ed.undo(); print(ed.text)   # hello
ed.undo(); print(ed.text)   # (空)
ed.redo(); print(ed.text)   # hello
```

### 场景二：用优先队列实现任务调度器

```python
import heapq
import itertools

class TaskScheduler:
    """按 (优先级, 到达顺序) 调度任务，优先级数字小的先执行"""
    def __init__(self):
        self.heap = []
        self.counter = itertools.count()   # 保证同优先级按先来后到

    def submit(self, name, priority):
        heapq.heappush(self.heap, (priority, next(self.counter), name))

    def run_next(self):
        if self.heap:
            priority, _, name = heapq.heappop(self.heap)
            return f'执行任务: {name} (优先级 {priority})'
        return '无任务'


sched = TaskScheduler()
sched.submit('备份数据库', 3)
sched.submit('处理用户请求', 1)
sched.submit('生成日报', 2)
for _ in range(3):
    print(sched.run_next())
# 处理用户请求 (优先级 1) → 生成日报 (优先级 2) → 备份数据库 (优先级 3)
```

## 最佳实践与踩坑记录

### 最佳实践

1. 需要频繁中间插入删除用链表，需要随机访问用数组，先明确访问模式再选结构
2. Python 队列/双端队列用 collections.deque，绝不用 list.pop(0)（那是 O(n)）
3. 优先队列用 heapq，最大堆就存负数或包装成自定义类重写比较
4. 栈的「最近优先」语义适合括号匹配、表达式求值、函数调用、DFS
5. 滑动窗口最值用单调队列，下一个更大元素用单调栈，都是 O(n)
6. 数组遍历快于链表遍历（缓存局部性），性能敏感处尽量用连续内存

### 踩坑记录

```text
坑 1：用 list.pop(0) 实现队列
结论：每次出队 O(n)，10 万元素就慢到无法忍受。
原因：list 是数组，删除队头要移动后面所有元素。
解法：用 collections.deque，两端操作都是 O(1)。

坑 2：把 deque 当随机访问结构用
结论：dq[i] 是 O(n)，频繁按下标访问反而比 list 慢。
原因：deque 底层是双向链表块，元素不连续。
解法：随机访问用 list；deque 只用于两端操作场景。

坑 3：误以为 heapq 弹出的是「全局排序」结果
结论：直接遍历堆不是有序的，只有反复 heappop 才得到升序。
原因：堆只满足父 ≤ 子的偏序，不保证兄弟节点间有序。
解法：要完整排序用 sorted() 或反复 heappop。

坑 4：优先队列存元组时比较到不可比元素
结论：push((priority, obj)) 当 priority 相同时去比较 obj 而报错。
原因：元组按从左到右依次比较，priority 相等就比 obj。
解法：元组里加一个自增序号 (priority, seq, obj)，或让 obj 可比较。

坑 5：链表反转/删除时丢指针导致断链
结论：先改 next 再移动指针，顺序错了链表就断了。
原因：链表操作要先保存「下一个节点」再改指针，否则丢失引用。
解法：统一用 prev/cur/nxt 三指针模板，先存 nxt 再改 cur.next。
```
