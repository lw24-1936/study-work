## 概述

图是「多对多」的关系结构：由顶点（Vertex）和边（Edge）组成，边可以带方向、带权重。它是最通用的数据模型，社交网络、地图导航、依赖关系、网页链接都能建模成图。图算法围绕「遍历、连通性、路径、排序、重要性」展开，是算法工程师处理关系型数据的基本功。

```text
图的核心要点：
1. 两种遍历 —— BFS 按层扩展求最短路径，DFS 深度优先求连通/环/拓扑
2. 两种表示 —— 邻接矩阵（稠密图）与邻接表（稀疏图），复杂度差异巨大
3. 经典算法 —— 最短路（Dijkstra/Floyd）、最小生成树、强连通分量、PageRank
4. 特殊结构 —— 有向无环图（DAG）可拓扑排序，是任务调度的核心
```

```python
from collections import defaultdict, deque

# 邻接表：最常用的图表示（稀疏图 O(V+E) 空间）
def build_graph(edges, directed=True):
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        if not directed:
            g[v].append(u)
    return g

edges = [(0, 1), (0, 2), (1, 3), (2, 3)]
g = build_graph(edges, directed=False)
print(dict(g))   # {0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2]}
```

## BFS

广度优先搜索（Breadth-First Search）用队列按「层」逐层扩展：先访问距离起点 1 的所有节点，再距离 2 的，依此类推。它天然保证「首次到达某个节点时的路径就是最短路径」（无权图），是层序遍历、最短路径、扩散传播、双向搜索的基础。

```text
复杂度：
- 时间：O(V + E)（每个顶点和边各访问一次）
- 空间：O(V)（队列 + visited 集合）

特点：
1. 队列 FIFO 保证按层扩展
2. 无权图最短路径 = BFS 首次访问时的层数
3. 适合：最短路径（无权）、连通块、多源扩散、迷宫
```

```python
from collections import deque

def bfs(g, start):
    visited = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nb in g[node]:
            if nb not in visited:
                visited.add(nb)
                q.append(nb)
    return order


def shortest_path_unweighted(g, start, target):
    """无权图最短路径：BFS 首次到达即最短"""
    q = deque([(start, 0)])
    visited = {start}
    while q:
        node, dist = q.popleft()
        if node == target:
            return dist
        for nb in g[node]:
            if nb not in visited:
                visited.add(nb)
                q.append((nb, dist + 1))
    return -1


g = build_graph([(0, 1), (0, 2), (1, 3), (2, 3), (3, 4)], directed=False)
print(bfs(g, 0))                           # [0, 1, 2, 3, 4]
print(shortest_path_unweighted(g, 0, 4))   # 2（0→1→3→4 或 0→2→3→4）
```

## DFS

深度优先搜索（Depth-First Search）沿着一条路径一路走到黑，走不动了再回溯，换一条路继续。它用递归（系统栈）或显式栈实现，是检测环、求连通分量、拓扑排序、找桥/割点、回溯算法的核心工具。

```text
复杂度：
- 时间：O(V + E)
- 空间：O(V)（递归深度，最坏是链状图）

特点：
1. 栈/递归 —— 深度优先，适合「路径探索」
2. 三种递归序 —— 前序、后序（回溯后）、完成时间
3. 适合：环检测、连通分量、拓扑排序、强连通分量
```

```python
def dfs_iterative(g, start):
    visited = set()
    stack = [start]
    order = []
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        for nb in g[node]:
            if nb not in visited:
                stack.append(nb)
    return order


def has_cycle_directed(g):
    """有向图环检测：用「访问中 / 已访问」三色标记"""
    WHITE, GRAY, BLACK = 0, 1, 2
    color = defaultdict(int)
    def dfs(node):
        color[node] = GRAY
        for nb in g[node]:
            if color[nb] == GRAY:      # 遇到正在访问的节点 → 有环
                return True
            if color[nb] == WHITE and dfs(nb):
                return True
        color[node] = BLACK
        return False
    for node in list(g.keys()):
        if color[node] == WHITE and dfs(node):
            return True
    return False


dag = build_graph([(0, 1), (1, 2), (0, 2)], directed=True)
cyclic = build_graph([(0, 1), (1, 2), (2, 0)], directed=True)
print(has_cycle_directed(dag))       # False
print(has_cycle_directed(cyclic))    # True
```

## 拓扑排序

拓扑排序（Topological Sort）给有向无环图（DAG）的顶点排一个线性序，使每条边 (u→v) 都满足 u 在 v 前面。它回答了「依赖关系下，任务应该按什么顺序执行」，是构建系统、课程安排、任务调度、编译依赖解析的核心。

```text
复杂度：
- 时间：O(V + E)
- 空间：O(V)

两种实现：
1. Kahn 算法 —— 反复取出入度为 0 的节点（BFS 思想）
2. DFS 后序 —— 完成时间逆序（DFS 思想）

适用前提：图必须是 DAG，有环则拓扑排序不存在（可用来判环）
```

```python
from collections import deque

def topological_sort_kahn(g, n):
    indegree = [0] * n
    for u in g:
        for v in g[u]:
            indegree[v] += 1
    q = deque([i for i in range(n) if indegree[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                q.append(v)
    return order if len(order) == n else None   # None 表示有环


# 课程依赖：1 依赖 0，2 依赖 0 和 1，3 依赖 1 和 2
g = {0: [1, 2], 1: [2, 3], 2: [3], 3: []}
print(topological_sort_kahn(g, 4))   # [0, 1, 2, 3]（一种合法顺序）
```

## 并查集

并查集（Union-Find / Disjoint Set）维护若干「不相交集合」，支持近乎 O(1) 的「合并两个集合」（union）和「判断是否同属一个集合」（find）。它是处理动态连通性、Kruskal 最小生成树、社交网络好友圈、等价类合并的核心结构。

```text
复杂度（带路径压缩 + 按秩合并）：
- find：均摊 O(α(n))，α 是反阿克曼函数，实际可视为常数
- union：均摊 O(α(n))
- 空间：O(n)

两大优化：
1. 路径压缩 —— find 时把路径上节点直接挂到根，加速后续查询
2. 按秩合并 —— 小树挂到大树，避免退化成链
```

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:    # 按秩合并
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1


uf = UnionFind(5)
uf.union(0, 1); uf.union(1, 2); uf.union(3, 4)
print(uf.find(0) == uf.find(2))   # True，0 和 2 连通
print(uf.find(0) == uf.find(3))   # False，不同集合
print(f'连通分量数: {len({uf.find(i) for i in range(5)})}')   # 2
```

## 最短路

最短路径算法求两点（或单源到所有点）之间的最短路径，是地图导航、网络路由、物流规划的核心。Dijkstra 处理非负权图，Bellman-Ford 能处理负权边，Floyd-Warshall 求所有点对的最短距离。

```text
复杂度（V 顶点、E 边）：
- Dijkstra（二叉堆）：O((V + E) log V)，要求边权非负
- Bellman-Ford：O(V·E)，能处理负权边、检测负环
- Floyd-Warshall：O(V³)，求所有点对最短路径
- BFS（无权图）：O(V + E)

Dijkstra 核心：每次从优先队列取出「当前距离最小」的未确定节点，松弛其邻居
```

```python
import heapq

def dijkstra(g, start, n):
    """g 是邻接表 {u: [(v, weight), ...]}，非负权"""
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in g[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist


# 加权图：0→1(4), 0→2(1), 2→1(2), 1→3(1), 2→3(5)
wg = {0: [(1, 4), (2, 1)], 1: [(3, 1)], 2: [(1, 2), (3, 5)], 3: []}
print(dijkstra(wg, 0, 4))   # [0, 3, 1, 4]（0→2→1→3 = 1+2+1=4）
```

## MST

最小生成树（Minimum Spanning Tree）在「带权连通无向图」里找一棵覆盖所有顶点、总权重最小的树。它是网络布线、聚类、近似算法的基础。Kruskal（基于并查集 + 排序边）和 Prim（基于优先队列 + 贪心扩展）是两大经典算法。

```text
复杂度：
- Kruskal：O(E log E)，瓶颈在排序边
- Prim（二叉堆）：O((V + E) log V)

核心思想（贪心）：
- Kruskal —— 按边权从小到大，能连（不成环）就选，直到选满 V-1 条
- Prim —— 从任意点出发，每次选「连接树内外」的最小边

性质：MST 有 V-1 条边，连通图才有 MST
```

```python
def kruskal(edges, n):
    """edges: [(weight, u, v), ...]"""
    uf = UnionFind(n)
    edges = sorted(edges)      # 按边权排序
    mst_weight = 0
    mst_edges = []
    for w, u, v in edges:
        if uf.find(u) != uf.find(v):
            uf.union(u, v)
            mst_weight += w
            mst_edges.append((u, v, w))
            if len(mst_edges) == n - 1:
                break
    return mst_weight, mst_edges


edges = [(4, 0, 1), (1, 0, 2), (2, 2, 1), (1, 1, 3), (5, 2, 3)]
print(kruskal(edges, 4))   # (6, [(0,2,1), (1,3,1), (2,1,2)]) 总权重 6
```

## SCC

强连通分量（Strongly Connected Components）把有向图划分成若干「最大强连通块」——块内任意两点互相可达。它揭示有向图的「循环依赖」结构，是编译器分析、社交网络社区发现、网页链接结构分析的基础，最常用 Kosaraju 或 Tarjan 算法。

```text
复杂度：
- Kosaraju：O(V + E)，两次 DFS（一次原图，一次反向图）
- Tarjan：O(V + E)，一次 DFS + 栈维护

核心思想（Kosaraju）：
1. 第一次 DFS 记录完成时间，得到「逆后序」
2. 反转所有边，按逆后序做第二次 DFS
3. 第二次 DFS 每次能到达的节点集就是一个 SCC

意义：SCC 缩点后得到 DAG，复杂有向图可化简为无环结构
```

```python
def kosaraju(g, n):
    # 第一次 DFS 求完成时间
    def dfs1(node, visited, order):
        visited.add(node)
        for nb in g[node]:
            if nb not in visited:
                dfs1(nb, visited, order)
        order.append(node)

    visited = set()
    order = []
    for i in range(n):
        if i not in visited:
            dfs1(i, visited, order)

    # 建反向图
    rg = defaultdict(list)
    for u in g:
        for v in g[u]:
            rg[v].append(u)

    # 第二次 DFS 按逆后序
    def dfs2(node, visited, comp):
        visited.add(node)
        comp.append(node)
        for nb in rg[node]:
            if nb not in visited:
                dfs2(nb, visited, comp)

    visited = set()
    sccs = []
    for node in reversed(order):
        if node not in visited:
            comp = []
            dfs2(node, visited, comp)
            sccs.append(comp)
    return sccs


# 0→1→2→0 是一个 SCC，3 独立
g = {0: [1], 1: [2], 2: [0, 3], 3: []}
print(kosaraju(g, 4))   # [[0, 2, 1], [3]]
```

## PageRank

PageRank 是 Google 早期的网页排序算法：一个网页的重要性 = 所有链向它的网页重要性加权之和。它把网页看成图，用「随机游走」的稳态分布来衡量节点重要度，是链接分析、学术引用影响力、推荐系统里「谁更重要」的经典算法。

```text
复杂度（幂迭代法）：
- 每轮迭代：O(E)（传播所有边的权重）
- 总：O(k·E)，k 是迭代次数（通常几十轮收敛）

核心公式（阻尼因子 d ≈ 0.85）：
PR(v) = (1-d)/N + d · Σ_{u→v} PR(u)/outdegree(u)

关键点：
1. 阻尼因子 —— 模拟「用户有 15% 概率随机跳转」，避免死胡同
2. 稳态分布 —— 反复迭代直到收敛，是马尔可夫链的平稳分布
```

```python
def pagerank(g, n, d=0.85, iters=100):
    pr = {i: 1.0 / n for i in range(n)}
    outdeg = {i: len(g[i]) for i in range(n)}
    for _ in range(iters):
        new_pr = {i: (1 - d) / n for i in range(n)}
        for u in g:
            if outdeg[u] == 0:
                continue
            share = pr[u] / outdeg[u]
            for v in g[u]:
                new_pr[v] += d * share
        pr = new_pr
    return pr


# 简单网页图：0→1, 0→2, 1→2, 2→0
g = {0: [1, 2], 1: [2], 2: [0]}
scores = pagerank(g, 3)
for node, score in sorted(scores.items(), key=lambda x: -x[1]):
    print(f'节点 {node}: {score:.4f}')
```

## 应用场景实战

### 场景一：社交网络的「六度分隔」——BFS 求最短好友链

```python
from collections import deque

def degrees_of_separation(friends, start, target):
    """无权好友图，BFS 求最短好友链长度"""
    q = deque([(start, 0)])
    visited = {start}
    while q:
        person, dist = q.popleft()
        if person == target:
            return dist
        for f in friends[person]:
            if f not in visited:
                visited.add(f)
                q.append((f, dist + 1))
    return -1


friends = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C', 'E'],
    'E': ['D'],
}
print(degrees_of_separation(friends, 'A', 'E'))   # 3（A→B→D→E）
```

### 场景二：Dijkstra 求地图两点最短距离

```python
import heapq

def shortest_driving_distance(city, start, target, n):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if u == target:
            return d
        if d > dist[u]:
            continue
        for v, w in city[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return float('inf')


# 城市路网：0=家, 1=公司, 2=商场, 3=机场（权 = 距离 km）
city = {0: [(1, 12), (2, 8)], 1: [(3, 20)], 2: [(1, 4), (3, 30)], 3: []}
print(f'家到机场最短: {shortest_driving_distance(city, 0, 3, 4)} km')   # 32
```

## 最佳实践与踩坑记录

### 最佳实践

1. 稀疏图（E ≈ V）用邻接表，稠密图（E ≈ V²）才考虑邻接矩阵
2. 无权图求最短路径直接用 BFS，别上 Dijkstra（BFS 更简单更快）
3. Dijkstra 要求边权非负，有负权边换 Bellman-Ford，全点对用 Floyd
4. 动态连通性、成环判断、Kruskal 用并查集，记得路径压缩 + 按秩合并
5. 任务依赖、课程安排先判 DAG（有环则无法拓扑排序）
6. BFS/DFS 都要 visited 标记，否则会死循环或重复访问指数爆炸

### 踩坑记录

```text
坑 1：DFS 递归在链状图上栈溢出
结论：10 万节点的链状图，递归 DFS 直接 RecursionError。
原因：递归深度 = 图深度，Python 默认递归上限约 1000。
解法：改迭代栈，或 sys.setrecursionlimit 并小心内存。

坑 2：Dijkstra 用了负权边
结论：结果错误或死循环，负权边会破坏「已确定」的贪心前提。
原因：Dijkstra 假设一旦确定最短就永不变，负权边会推翻它。
解法：负权边用 Bellman-Ford 或 SPFA，并注意负环检测。

坑 3：BFS 忘加 visited 导致重复入队
结论：层数多的节点被反复入队，复杂度爆炸甚至死循环。
原因：无向图或含环图里，邻居会互相重新访问。
解法：入队时就标记 visited，不要等出队才标记。

坑 4：并查集只用路径压缩不用按秩合并
结论：极端数据下 find 退化到接近 O(n)，性能骤降。
原因：没有按秩合并，树可能被拉成很深的链。
解法：路径压缩 + 按秩合并一起用，才是均摊 α(n)。

坑 5：拓扑排序用在有环图上
结论：得到不完整顺序，或误判为「排序成功」。
原因：有环时入度永远无法全部降到 0。
解法：最后检查 len(order) == n，不等则说明有环。
```
