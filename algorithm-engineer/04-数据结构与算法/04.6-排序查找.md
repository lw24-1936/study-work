## 概述

排序与查找是算法世界里最经典、最高频的两类操作：排序把无序数据变成有序，查找在有序/无序数据中定位目标。排序是查找的前提（二分查找要求有序），也是归并、分治、堆等思想的练兵场，更是面试的必考内容。

```text
排序与查找的核心要点：
1. 比较排序下界 —— 基于比较的排序最优 O(n log n)，归并/快排/堆排都卡在这个界
2. 非比较排序 —— 计数、基数、桶排序能突破到 O(n)，但依赖数据取值范围
3. 稳定性 —— 相等元素相对顺序是否保持，归并稳定、快排不稳定
4. 二分查找 —— O(log n) 的前提是有序，是无数算法优化的利器
```

```python
# 排序算法复杂度与稳定性速查
summary = [
    ('归并排序', 'O(n log n)', 'O(n)', '稳定'),
    ('快速排序', 'O(n log n) 平均', 'O(log n)', '不稳定'),
    ('堆排序',   'O(n log n)', 'O(1)', '不稳定'),
    ('计数排序', 'O(n + k)', 'O(k)', '稳定'),
    ('基数排序', 'O(d(n + k))', 'O(n + k)', '稳定'),
]
for name, time, space, stable in summary:
    print(f'{name}: 时间 {time}, 空间 {space}, {stable}')
```

## 二分

二分查找（Binary Search）在有序数组中每次与中间元素比较，砍掉一半搜索空间，O(log n) 找到目标。它是「有序 → 对数」最直接的体现，也是二分答案、二分边界、旋转数组搜索等变体的基础。

```text
复杂度：
- 时间：O(log n)
- 空间：O(1)（迭代）或 O(log n)（递归）

关键细节：
1. 边界开闭 —— 左闭右闭 [lo, hi] 用 lo <= hi；左闭右开 [lo, hi) 用 lo < hi
2. 防溢出 —— mid = lo + (hi - lo) // 2，别写 (lo + hi) // 2（可能溢出）
3. 变体 —— 找第一个/最后一个等于 target、找第一个大于 target
```

```python
import bisect

def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1


arr = [1, 3, 5, 7, 9, 11]
print(binary_search(arr, 7))       # 3
print(binary_search(arr, 6))       # -1

# Python 内置：bisect 模块（左/右插入点）
print(bisect.bisect_left(arr, 7))   # 3（第一个 >=7 的位置）
print(bisect.bisect_right(arr, 7))  # 4（第一个 >7 的位置）


# 二分答案：求 x 的整数平方根（在答案域上二分）
def int_sqrt(x):
    lo, hi = 0, x
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if mid * mid <= x:
            lo = mid + 1
        else:
            hi = mid - 1
    return hi

print(int_sqrt(10))   # 3
```

## 归并

归并排序（Merge Sort）用分治思想：把数组不断对半拆成子数组，各自排序后再合并两个有序子数组。它稳定、时间恒为 O(n log n)，但需要 O(n) 额外空间，适合链表排序、外部排序、求逆序对等场景。

```text
复杂度：
- 时间：O(n log n)（最好/最坏/平均都如此）
- 空间：O(n)（合并需要临时数组）

核心：
1. 分 —— 对半拆分直到单个元素（天然有序）
2. 治 —— 合并两个有序子数组（双指针归并）
3. 稳定 —— 合并时相等元素先取左边，保持相对顺序
```

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)


def merge(a, b):
    res = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:          # 等号保证稳定性
            res.append(a[i]); i += 1
        else:
            res.append(b[j]); j += 1
    res.extend(a[i:])
    res.extend(b[j:])
    return res


print(merge_sort([38, 27, 43, 3, 9, 82, 10]))   # [3, 9, 10, 27, 38, 43, 82]


# 归并的副产品：求逆序对数量（经典应用）
def count_inversions(arr):
    def merge_count(a):
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        left, cl = merge_count(a[:mid])
        right, cr = merge_count(a[mid:])
        merged, cm = [], 0
        i = j = 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i]); i += 1
            else:
                merged.append(right[j]); j += 1
                cm += len(left) - i      # 右边元素小，构成逆序对
        merged.extend(left[i:]); merged.extend(right[j:])
        return merged, cl + cr + cm
    return merge_count(arr)[1]

print(count_inversions([2, 4, 1, 3, 5]))   # 3（(2,1)(4,1)(4,3)）
```

## 快排

快速排序（Quick Sort）选一个「基准」（pivot），把比它小的放左边、大的放右边，再递归处理两边。它平均 O(n log n)、常数小、原地排序，是实际最快的通用排序算法（Python/C++ 内置 sort 都基于它或其变体）。

```text
复杂度：
- 时间：平均 O(n log n)，最坏 O(n²)（每次 pivot 都是极值，如已有序数组）
- 空间：O(log n)（递归栈）

核心：
1. 分区（partition）—— 把 pivot 归位，左边小右边大
2. 不稳定 —— 分区交换会打乱相等元素的相对顺序
3. 随机化 —— 随机选 pivot 避免最坏情况
```

```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)


print(quick_sort([3, 6, 8, 10, 1, 2, 1]))   # [1, 1, 2, 3, 6, 8, 10]


# 原地分区（Lomuto 方案），O(1) 额外空间
def partition(arr, lo, hi):
    pivot = arr[hi]
    i = lo
    for j in range(lo, hi):
        if arr[j] < pivot:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1
    arr[i], arr[hi] = arr[hi], arr[i]
    return i


def quick_sort_inplace(arr, lo=0, hi=None):
    if hi is None:
        hi = len(arr) - 1
    if lo < hi:
        p = partition(arr, lo, hi)
        quick_sort_inplace(arr, lo, p - 1)
        quick_sort_inplace(arr, p + 1, hi)
    return arr

print(quick_sort_inplace([3, 6, 8, 10, 1, 2, 1]))
```

## 堆排

堆排序（Heap Sort）先把数组建成最大堆，再反复「交换堆顶（最大）到末尾 + 下沉调整」，原地完成 O(n log n) 排序。它不需要额外空间（O(1) 额外空间），是「空间受限排序」的首选。

```text
复杂度：
- 时间：O(n log n)（建堆 O(n) + n 次 pop O(n log n)）
- 空间：O(1)（原地排序）
- 不稳定 —— 交换会破坏相等元素相对顺序

流程：
1. 建最大堆（自底向上下沉，O(n)）
2. 堆顶（最大）与末尾交换，末尾就是已排序区
3. 对剩余部分下沉调整，重复直到只剩一个元素
```

```python
def heap_sort(arr):
    a = arr[:]
    n = len(a)

    def sift_down(i, size):
        while 2 * i + 1 < size:
            child = 2 * i + 1
            if child + 1 < size and a[child + 1] > a[child]:   # 最大堆
                child += 1
            if a[i] >= a[child]:
                break
            a[i], a[child] = a[child], a[i]
            i = child

    for i in range(n // 2 - 1, -1, -1):   # 建最大堆 O(n)
        sift_down(i, n)
    for end in range(n - 1, 0, -1):       # 逐个取出最大
        a[0], a[end] = a[end], a[0]
        sift_down(0, end)
    return a


print(heap_sort([3, 6, 8, 10, 1, 2, 1]))   # [1, 1, 2, 3, 6, 8, 10]
```

## 计数

计数排序（Counting Sort）不比较元素，而是统计每个值出现的次数，再按值从小到大展开。它在「取值范围 k 不大」时做到 O(n + k)，突破比较排序的 O(n log n) 下界，是桶排序和基数排序的基础。

```text
复杂度：
- 时间：O(n + k)，k 是取值范围
- 空间：O(k)
- 稳定（用前缀和 + 反向填充时）

适用条件：
1. 元素是整数或可映射到小范围整数
2. 取值范围 k 远小于 n（如成绩 0~100 分）
3. 取值范围太大（如长 ID）则不适用，浪费 O(k) 空间
```

```python
def counting_sort(arr):
    if not arr:
        return arr
    k = max(arr) + 1
    count = [0] * k
    for x in arr:
        count[x] += 1
    # 前缀和：count[i] = 值 i 在结果中的「结束位置」
    for i in range(1, k):
        count[i] += count[i - 1]
    output = [0] * len(arr)
    for x in reversed(arr):      # 反向遍历保证稳定
        count[x] -= 1
        output[count[x]] = x
    return output


print(counting_sort([4, 2, 2, 8, 3, 3, 1]))   # [1, 2, 2, 3, 3, 4, 8]
# 成绩排序场景：0~100 分，n 很大，k=101 很小 → 计数排序非常合适
```

## 基数

基数排序（Radix Sort）按「位」从低位到高位（LSD）逐位用稳定排序（如计数排序）排序。它适合排序「定长或接近定长的数字/字符串」，时间复杂度 O(d(n + k))，d 是位数。

```text
复杂度：
- 时间：O(d(n + k))，d 是位数，k 是每位的基数（如 10 进制 k=10）
- 空间：O(n + k)
- 稳定（每轮都用稳定排序）

适用场景：
1. 整数（按十进制位或二进制位）
2. 定长字符串（如车牌号、日期、ISBN）
3. 数字范围极大但位数固定时，比计数排序更省空间
```

```python
def radix_sort(arr):
    if not arr:
        return arr
    max_val = max(arr)
    exp = 1
    while max_val // exp > 0:
        arr = counting_sort_by_digit(arr, exp)
        exp *= 10
    return arr


def counting_sort_by_digit(arr, exp):
    count = [0] * 10
    for x in arr:
        count[(x // exp) % 10] += 1
    for i in range(1, 10):
        count[i] += count[i - 1]
    output = [0] * len(arr)
    for x in reversed(arr):
        digit = (x // exp) % 10
        count[digit] -= 1
        output[count[digit]] = x
    return output


print(radix_sort([170, 45, 75, 90, 802, 24, 2, 66]))
# [2, 24, 45, 66, 75, 90, 170, 802]
```

## 外排

外部排序（External Sort）处理「内存装不下」的超大数据：数据存在磁盘，只能分块读入内存。核心思想是「归并排序的磁盘版」——先分块读入排序写回磁盘（形成有序段），再对有序段做多路归并。

```text
复杂度：
- 假设内存能装 M 个元素，总数据 N 个
- 第一阶段：读 N/M 块，每块 O(M log M) 排序
- 第二阶段：多路归并 O(N log(N/M))

核心：
1. 分块排序 —— 每次读一块到内存，排序后写回有序段（run）
2. 多路归并 —— 用优先队列（或败者树）合并所有有序段
3. 尽量减少磁盘 IO —— 增加归并路数、增大块大小
```

```python
import heapq

def external_sort_chunks(chunks):
    """chunks: 已排好序的多个有序块（模拟磁盘上的 run）"""
    # 多路归并：用小顶堆每次取所有块的最小值
    heap = []
    for i, chunk in enumerate(chunks):
        if chunk:
            heapq.heappush(heap, (chunk[0], i, 0))
    result = []
    while heap:
        val, ci, pos = heapq.heappop(heap)
        result.append(val)
        if pos + 1 < len(chunks[ci]):
            heapq.heappush(heap, (chunks[ci][pos + 1], ci, pos + 1))
    return result


# 模拟：数据太大，分成 3 块分别排序后写回磁盘
data = [9, 3, 7, 1, 8, 2, 6, 4, 5, 0, 11, 10]
chunks = [sorted(data[0:4]), sorted(data[4:8]), sorted(data[8:12])]
print(external_sort_chunks(chunks))   # [0, 1, 2, 3, ..., 11]
```

## Top-K

Top-K 问题是「在 n 个元素里找最大（或最小）的 K 个」，是高频实战问题。用小顶堆维护 K 个元素是标准解 O(n log K)；若需要全量有序则先排再取。海量数据、实时榜单、推荐召回都离不开它。

```text
复杂度（找最大的 K 个）：
- 小顶堆：O(n log K)，空间 O(K)
- 全排序：O(n log n)，空间 O(n)（K 很大时才考虑）
- 快速选择（Quickselect）：平均 O(n)，最坏 O(n²)

技巧：
1. 找最大 K 个 → 维护「大小为 K 的小顶堆」，堆顶是第 K 大
2. 找最小 K 个 → 维护「大小为 K 的大顶堆」
3. 海量数据 → 分治/分桶/外部排序后再取 Top-K
```

```python
import heapq

def top_k_largest(nums, k):
    """维护大小为 k 的小顶堆，堆顶是第 K 大"""
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)     # 挤掉当前最小的
    return sorted(heap, reverse=True)


nums = [3, 2, 1, 5, 6, 4]
print(top_k_largest(nums, 2))       # [6, 5]
print(heapq.nlargest(2, nums))      # [6, 5] 内置等价写法


def quickselect(nums, k):
    """快速选择：找第 k 大（k 从 1 开始），平均 O(n)"""
    def helper(lo, hi, k):
        pivot = nums[hi]
        i = lo
        for j in range(lo, hi):
            if nums[j] > pivot:      # 降序分区
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[hi] = nums[hi], nums[i]
        if i + 1 == k:
            return nums[i]
        elif i + 1 < k:
            return helper(i + 1, hi, k)
        else:
            return helper(lo, i - 1, k)
    return helper(0, len(nums) - 1, k)

print(quickselect([3, 2, 1, 5, 6, 4], 2))   # 5（第 2 大）
```

### 场景一：排行榜 Top-100（实时更新）

```python
import heapq

class Leaderboard:
    def __init__(self, capacity=100):
        self.cap = capacity
        self.heap = []   # 小顶堆存「分数最低」的前 K，堆顶是第 K 名

    def add_score(self, player, score):
        heapq.heappush(self.heap, (score, player))
        if len(self.heap) > self.cap:
            heapq.heappop(heap)

    def top(self, n=10):
        return sorted(self.heap, reverse=True)[:n]


lb = Leaderboard(capacity=3)
lb.add_score('alice', 90)
lb.add_score('bob', 85)
lb.add_score('carol', 95)
lb.add_score('dave', 88)    # 挤掉 85 的 bob
print(lb.top())   # [(95, 'carol'), (90, 'alice'), (88, 'dave')]
```

### 场景二：二分查找在「旋转有序数组」中的应用

```python
def search_rotated(nums, target):
    """在旋转有序数组（如 [4,5,6,7,0,1,2]）中二分查找"""
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:        # 左半有序
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                             # 右半有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1


print(search_rotated([4, 5, 6, 7, 0, 1, 2], 0))   # 4
print(search_rotated([4, 5, 6, 7, 0, 1, 2], 3))   # -1
```

## 最佳实践与踩坑记录

### 最佳实践

1. 通用排序直接用 Python 内置 sorted()/list.sort()（Timsort，稳定且针对现实数据优化）
2. 需要稳定排序用归并或 Timsort；只关心时间且空间紧张用堆排
3. 数据是有限范围整数（如成绩、年龄）用计数/基数排序，能到 O(n)
4. 内存装不下的数据用外部排序：分块排序 + 多路归并
5. Top-K 用小顶堆 O(n log K)，别全排序；要第 K 大元素用快速选择平均 O(n)
6. 二分查找牢记边界约定，统一用左闭右闭 [lo, hi] 避免 off-by-one

### 踩坑记录

```text
坑 1：快排对已有序数组退化
结论：每次 pivot 都取到极值，退化成 O(n²)，甚至递归过深。
原因：固定选首/尾元素当 pivot，有序数组下分区极不平衡。
解法：随机选 pivot 或三数取中；Python 内置 sort 已做优化。

坑 2：二分查找死循环
结论：lo 或 hi 不移动导致 while 条件恒成立，程序卡死。
原因：边界更新写成 lo = mid 或 hi = mid 而非 mid±1。
解法：统一 lo = mid + 1 / hi = mid - 1，配合 lo <= hi 条件。

坑 3：计数排序用于取值范围极大的数据
结论：要排序长 ID（如 64 位整数），count 数组开不出来直接 OOM。
原因：计数排序空间 O(k)，k = 最大值，长 ID 的 k 是天文数字。
解法：取值范围大改用基数排序或比较排序，别硬上计数排序。

坑 4：Top-K 堆的方向用反
结论：找最大 K 个却用了大顶堆，每次都要弹出最大值，复杂度变 O(n log n)。
原因：没理解「维护大小 K 的小顶堆，堆顶才是第 K 大」。
解法：找最大 K 用小顶堆，找最小 K 用大顶堆，堆顶即边界。

坑 5：归并排序递归切片造成大量内存拷贝
结论：arr[:mid] 每次递归都拷贝数组，空间和时间常数都膨胀。
原因：切片是 O(n) 拷贝，递归每一层都拷贝一遍。
解法：用下标区间 [lo, hi] 递归，只在一个临时数组上操作。
```
