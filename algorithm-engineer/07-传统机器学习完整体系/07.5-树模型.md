## 概述

树模型从「单个决策树」一路演进到「梯度提升树」，是结构化表格数据（tabular data）上最强的算法家族，常年霸榜 Kaggle 和工业界业务建模。单棵树可解释但容易过拟合；集成学习（Bagging 与 Boosting）通过组合多棵树大幅提升泛化能力，其中 XGBoost/LightGBM/CatBoost 是当前工程落地的主力。

```text
树模型的发展脉络：
1. 单棵决策树 —— ID3 → C4.5 → CART（划分准则不断改进）
2. Bagging（并行，降方差）—— Random Forest、Extra Trees
3. Boosting（串行，降偏差）—— AdaBoost → GBDT → XGBoost/LightGBM/CatBoost

核心区别：
- 决策树：信息增益/增益率/基尼系数选择划分特征
- 随机森林：多棵树 + 样本/特征随机采样，投票/平均
- 梯度提升：逐棵树拟合前一棵的残差/负梯度
```

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

X, y = make_classification(n_samples=1000, n_features=20, random_state=0)
for name, m in [('单棵决策树', DecisionTreeClassifier()),
                ('随机森林', RandomForestClassifier()),
                ('GBDT', GradientBoostingClassifier())]:
    m.fit(X, y)
    print(f'{name}: 训练准确率={m.score(X, y):.3f}')
```

## ID3

ID3（Iterative Dichotomiser 3）是最早的决策树算法，用「信息增益」选择划分特征：选能让子节点「纯度提升最大」的特征。它奠定了决策树「递归划分」的框架，但偏向取值多的特征、只处理离散特征、容易过拟合。

```text
数学定义：
信息熵：H(D) = -Σ p_k · log₂(p_k)
信息增益：Gain(D, A) = H(D) - Σ_v (|D_v|/|D|) · H(D_v)

决策：每次选信息增益最大的特征 A 划分

缺陷：
1. 偏向取值多的特征（取值多 → 划分更细 → 增益虚高）
2. 只支持离散特征
3. 无剪枝，易过拟合
```

```python
import numpy as np

def entropy(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / counts.sum()
    return -np.sum(p * np.log2(p + 1e-12))

def information_gain(X_col, y):
    """按某特征划分的信息增益"""
    total_ent = entropy(y)
    weighted = 0.0
    for v in np.unique(X_col):
        subset = y[X_col == v]
        weighted += (len(subset) / len(y)) * entropy(subset)
    return total_ent - weighted

# 离散特征示例：特征 0 取值少但信息增益大
X = np.array([[0, 1], [0, 1], [1, 0], [1, 1], [1, 0]])
y = np.array([0, 0, 1, 1, 1])
print(f'特征 0 信息增益: {information_gain(X[:, 0], y):.3f}')
print(f'特征 1 信息增益: {information_gain(X[:, 1], y):.3f}')
```

## C4.5

C4.5 是 ID3 的改进版，用「信息增益率」替代信息增益，缓解了偏向多取值特征的缺陷；同时支持连续特征（二分法）和缺失值处理，并在建树后做剪枝。

```text
数学定义：
分裂信息：SplitInfo(D, A) = -Σ_v (|D_v|/|D|) · log₂(|D_v|/|D|)
信息增益率：GainRatio(D, A) = Gain(D, A) / SplitInfo(D, A)

改进点：
1. 增益率 —— 除以「分裂信息」惩罚取值多的特征
2. 连续特征 —— 排序后二分，选增益率最大的切点
3. 缺失值 —— 按比例分配到各分支
4. 后剪枝 —— 用悲观剪枝降低过拟合
```

```python
import numpy as np

def split_info(X_col):
    _, counts = np.unique(X_col, return_counts=True)
    p = counts / counts.sum()
    return -np.sum(p * np.log2(p + 1e-12))

def gain_ratio(X_col, y):
    si = split_info(X_col)
    if si == 0:
        return 0
    return information_gain(X_col, y) / si

X = np.array([[0, 0, 0, 0, 0, 1, 1, 1]])  # 特征 0 取值少
y = np.array([0, 0, 0, 0, 1, 1, 1, 1])
print(f'信息增益: {information_gain(X[0], y):.3f}')
print(f'信息增益率: {gain_ratio(X[0], y):.3f}（除以分裂信息，惩罚多取值）')
```

## CART

CART（Classification And Regression Tree）用「基尼系数」（分类）或「MSE」（回归）选择划分，且强制生成二叉树。它是 sklearn 决策树、以及随机森林/GBDT 的底层实现，既能分类又能回归，是工程上最通用的树结构。

```text
数学定义：
基尼系数（分类）：Gini(D) = 1 - Σ p_k²
划分准则：选使 Gini(D) - Σ (|D_v|/|D|)·Gini(D_v) 最小的特征与切点

回归：选使子节点 MSE 加权和最小的特征与切点

特点：
1. 二叉树 —— 每个节点只分两支
2. 分类回归都支持 —— 分类用基尼，回归用 MSE
3. 支持代价复杂度剪枝（ccp_alpha）
```

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor
from sklearn.datasets import make_classification
import matplotlib
matplotlib.use('Agg')

def gini(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / counts.sum()
    return 1 - np.sum(p ** 2)

# 分类树：基尼系数选择划分
X, y = make_classification(n_samples=300, n_features=5, random_state=0)
clf = DecisionTreeClassifier(max_depth=3, criterion='gini', random_state=0).fit(X, y)
print('CART 分类树深度:', clf.get_depth(), '叶子节点数:', clf.get_n_leaves())

# 回归树：MSE 选择划分
Xr = np.linspace(0, 10, 100).reshape(-1, 1)
yr = np.sin(Xr).ravel() + np.random.randn(100) * 0.3
reg = DecisionTreeRegressor(max_depth=3).fit(Xr, yr)
print('CART 回归树深度:', reg.get_depth())
```

## Random Forest

随机森林（Random Forest）用 Bagging 思想并行训练多棵决策树，每棵树在「样本自助采样 + 特征随机子集」上训练，最后投票（分类）或平均（回归）。双重随机性降低树间相关性，大幅降方差、抗过拟合。

```text
两大随机性：
1. 样本随机 —— Bootstrap 自助采样，每棵树用不同的样本子集
2. 特征随机 —— 每个节点只从随机子集 m 个特征里选最优划分

关键参数：
- n_estimators —— 树的数量（越多越稳，但边际收益递减）
- max_features —— 每节点候选特征数（分类默认 sqrt(d)）
- max_depth —— 树深度限制

优点：抗过拟合、可并行、能输出特征重要性、对超参不敏感
```

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score

X, y = make_classification(n_samples=1000, n_features=30, n_informative=10, random_state=0)
rf = RandomForestClassifier(n_estimators=100, max_features='sqrt', random_state=0)
scores = cross_val_score(rf, X, y, cv=5)
print(f'随机森林 5 折交叉验证准确率: {scores.mean():.3f} ± {scores.std():.3f}')

rf.fit(X, y)
importances = rf.feature_importances_
print('Top 3 重要特征索引:', np.argsort(importances)[-3:][::-1])
```

## Extra Trees

极端随机树（Extra Trees，Extremely Randomized Trees）是随机森林的「更随机」版本：划分点也完全随机选择，而不是找最优切点。更强的随机性进一步降低方差、加快训练，代价是单棵树的偏差略增。

```text
与随机森林的区别：
1. 样本采样 —— Extra Trees 默认用全量样本（不 bootstrap）
2. 切点选择 —— 每个候选特征随机选一个切点，而非搜索最优切点
3. 随机性更强 —— 树间相关性更低，方差更小

适用：高维数据、需极快训练、对噪声鲁棒性要求高的场景
```

```python
from sklearn.ensemble import ExtraTreesClassifier, RandomForestClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score
import time

X, y = make_classification(n_samples=2000, n_features=40, n_informative=15, random_state=0)

for name, m in [('随机森林', RandomForestClassifier(n_estimators=100, random_state=0)),
                ('Extra Trees', ExtraTreesClassifier(n_estimators=100, random_state=0))]:
    t0 = time.time()
    score = cross_val_score(m, X, y, cv=5).mean()
    print(f'{name}: 准确率={score:.3f}  耗时={time.time()-t0:.2f}s')
```

## AdaBoost

AdaBoost（Adaptive Boosting）是最早的 Boosting 算法：串行训练一系列弱分类器，每次提高「前一轮分错样本」的权重，让后续分类器更关注难样本，最后加权组合。它通过「调整样本权重」而非「拟合残差」来提升。

```text
算法流程：
1. 初始化样本权重 w_i = 1/n
2. 对每轮 t：
   - 用加权样本训练弱分类器 h_t
   - 计算加权错误率 ε_t，得分类器权重 α_t = 0.5·ln((1-ε_t)/ε_t)
   - 增大错分样本权重，减小对分样本权重
3. 最终：H(x) = sign(Σ α_t·h_t(x))

核心思想：聚焦难样本，弱分类器组合成强分类器
```

```python
import numpy as np
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score

X, y = make_classification(n_samples=1000, n_features=20, random_state=0)

# 弱分类器用浅树（stump）
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=50, learning_rate=1.0, random_state=0)
scores = cross_val_score(ada, X, y, cv=5)
print(f'AdaBoost（决策树桩）准确率: {scores.mean():.3f}')

# 手写指数损失下的样本权重更新
def update_weights(weights, alpha, y, pred):
    return weights * np.exp(-alpha * y * pred)

w = np.ones(5) / 5
alpha = 0.5
y = np.array([1, 1, -1, -1, 1])
pred = np.array([1, -1, -1, -1, 1])
w_new = update_weights(w, alpha, y, pred)
w_new /= w_new.sum()
print('AdaBoost 权重更新（错分样本权重增大）:', np.round(w_new, 3))
```

## GBDT

梯度提升树（Gradient Boosting Decision Tree，GBDT）是 Boosting 的泛化：每棵新树拟合当前模型的「负梯度」（回归里即残差），逐步减小损失。它不像 AdaBoost 只用于分类，而是能优化任意可微损失函数，回归分类通吃。

```text
数学定义（加法模型 + 梯度下降）：
F_m(x) = F_{m-1}(x) + η · h_m(x)

其中 h_m 拟合负梯度：
r_im = -∂L(y_i, F(x_i)) / ∂F(x_i)

- 平方损失下负梯度就是残差 y_i - F(x_i)
- η 是学习率（shrinkage），控制每步的步长
- 每棵树是「回归树」，拟合残差而非直接拟合标签
```

```python
import numpy as np
from sklearn.ensemble import GradientBoostingRegressor, GradientBoostingClassifier
from sklearn.datasets import make_regression
from sklearn.metrics import mean_squared_error

X, y = make_regression(n_samples=800, n_features=10, noise=0.1, random_state=0)
gbr = GradientBoostingRegressor(n_estimators=100, learning_rate=0.1, max_depth=3, random_state=0)
gbr.fit(X, y)
print(f'GBDT 回归 MSE: {mean_squared_error(y, gbr.predict(X)):.4f}')

# 手写「拟合残差」的核心循环
def gbdt_residual_fit(X, y, n_trees=5, lr=0.1):
    from sklearn.tree import DecisionTreeRegressor
    F = np.full(len(y), y.mean())
    for t in range(n_trees):
        residual = y - F                              # 负梯度（平方损失=残差）
        tree = DecisionTreeRegressor(max_depth=2).fit(X, residual)
        F += lr * tree.predict(X)                     # 累加弱树
    return F

F_pred = gbdt_residual_fit(X, y)
print(f'手写 GBDT（5 棵浅树）MSE: {mean_squared_error(y, F_pred):.4f}')
```

## XGBoost

XGBoost（eXtreme Gradient Boosting）是 GBDT 的工程级优化实现：在损失上显式加正则项、用二阶泰勒展开做更精确的近似、支持列采样与缺失值自动处理，并做了大量系统优化（并行、缓存、稀疏感知）。它是 Kaggle 时代的王者。

```text
核心改进：
1. 正则化目标 —— obj = Σ L(y_i, ŷ_i) + Σ [γ·T + 0.5·λ·‖w‖²]
2. 二阶泰勒展开 —— 用 g_i、h_i（一阶二阶梯度）近似损失
3. 列采样 —— 类似随机森林，降低过拟合
4. 缺失值 —— 自动学习最优分裂方向
5. 系统优化 —— 特征预排序、缓存、并行、稀疏感知

关键参数：learning_rate(eta)、max_depth、subsample、colsample_bytree、lambda、gamma
```

```python
import numpy as np
from xgboost import XGBClassifier, XGBRegressor
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = make_classification(n_samples=2000, n_features=30, n_informative=15, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

xgb = XGBClassifier(n_estimators=100, learning_rate=0.1, max_depth=5,
                    subsample=0.8, colsample_bytree=0.8, random_state=0,
                    eval_metric='logloss')
xgb.fit(X_train, y_train)
print(f'XGBoost 准确率: {accuracy_score(y_test, xgb.predict(X_test)):.3f}')
print('Top 特征重要性:', np.argsort(xgb.feature_importances_)[-3:][::-1])
```

## LightGBM

LightGBM（Light Gradient Boosting Machine）由微软开源，针对「大数据 + 高维」做了极致优化：用直方图算法、按叶子生长（leaf-wise）、以及 GOSS（单边梯度采样）和 EFB（互斥特征捆绑）两大创新，训练速度比 XGBoost 快数倍、内存占用更低。

```text
核心优化：
1. 直方图算法 —— 把连续特征离散成桶，分裂时遍历桶而非样本
2. leaf-wise 生长 —— 优先分裂增益最大的叶子，收敛更快（需控制深度防过拟合）
3. GOSS —— 保留大梯度样本 + 随机采样小梯度样本，聚焦难样本
4. EFB —— 把互斥的稀疏特征捆绑，降低特征维度

注意：leaf-wise 树容易过拟合，务必设 num_leaves 和 max_depth
```

```python
import lightgbm as lgb
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = make_classification(n_samples=5000, n_features=50, n_informative=20, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

lgbm = lgb.LGBMClassifier(n_estimators=100, learning_rate=0.1, num_leaves=31,
                          max_depth=-1, subsample=0.8, colsample_bytree=0.8,
                          random_state=0, verbose=-1)
lgbm.fit(X_train, y_train)
print(f'LightGBM 准确率: {accuracy_score(y_test, lgbm.predict(X_test)):.3f}')
```

## CatBoost

CatBoost（Categorical Boosting）由 Yandex 开源，最大的特色是「原生处理类别特征」和「有序提升（ordered boosting）」防预测偏移。它用有序目标统计（ordered target statistics）编码类别特征，避免传统目标编码的信息泄漏，开箱即用、对类别特征友好。

```text
核心特性：
1. 原生类别特征 —— 直接传入类别列，内部用 ordered target statistics 编码
2. 有序提升 —— 用「样本之前的历史」计算残差，避免预测偏移（prediction shift）
3. 对称树 —— 每层用同一划分，结构规整，可加速推理
4. 无需大量调参 —— 默认参数通常就很好，对类别特征鲁棒

适用：类别特征多的表格数据（广告、推荐、风控）
```

```python
import numpy as np
import pandas as pd
from catboost import CatBoostClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 构造含类别特征的数据
rng = np.random.RandomState(0)
n = 2000
df = pd.DataFrame({
    'num1': rng.randn(n),
    'num2': rng.randn(n),
    'cat1': rng.choice(['A', 'B', 'C'], n),
    'cat2': rng.choice(['X', 'Y', 'Z', 'W'], n),
})
df['y'] = ((df['num1'] + df['num2'] > 0) | (df['cat1'] == 'A')).astype(int)

X_train, X_test, y_train, y_test = train_test_split(
    df[['num1', 'num2', 'cat1', 'cat2']], df['y'], test_size=0.3, random_state=0)

cat = CatBoostClassifier(iterations=100, learning_rate=0.1, depth=6,
                         cat_features=['cat1', 'cat2'], verbose=0, random_seed=0)
cat.fit(X_train, y_train)
print(f'CatBoost 准确率: {accuracy_score(y_test, cat.predict(X_test)):.3f}')
```

## 应用场景实战

### 场景一：三大 GBDT 框架横向对比

```python
import time
import numpy as np
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier
from catboost import CatBoostClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import roc_auc_score

X, y = make_classification(n_samples=10000, n_features=50, n_informative=25,
                           random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

models = {
    'XGBoost': XGBClassifier(n_estimators=200, learning_rate=0.1, max_depth=6,
                             random_state=0, eval_metric='logloss'),
    'LightGBM': LGBMClassifier(n_estimators=200, learning_rate=0.1, num_leaves=31,
                               random_state=0, verbose=-1),
    'CatBoost': CatBoostClassifier(iterations=200, learning_rate=0.1, depth=6,
                                   verbose=0, random_seed=0),
}
for name, m in models.items():
    t0 = time.time()
    m.fit(X_train, y_train)
    auc = roc_auc_score(y_test, m.predict_proba(X_test)[:, 1])
    print(f'{name}: AUC={auc:.4f}  训练耗时={time.time()-t0:.2f}s')
```

### 场景二：随机森林 + 特征重要性做特征选择

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import SelectFromModel
from sklearn.metrics import accuracy_score

X, y = make_classification(n_samples=3000, n_features=100, n_informative=15, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

# 用随机森林特征重要性做特征选择
rf = RandomForestClassifier(n_estimators=200, random_state=0).fit(X_train, y_train)
selector = SelectFromModel(rf, threshold='median', prefit=True)
X_train_sel = selector.transform(X_train)
X_test_sel = selector.transform(X_test)

print(f'特征选择前: {X_train.shape[1]} 维')
print(f'特征选择后: {X_train_sel.shape[1]} 维')

rf2 = RandomForestClassifier(n_estimators=200, random_state=0)
rf2.fit(X_train_sel, y_train)
print(f'特征选择后准确率: {accuracy_score(y_test, rf2.predict(X_test_sel)):.3f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 表格数据先跑 GBDT 系（LightGBM/XGBoost/CatBoost）当强 baseline，通常吊打线性模型
2. LightGBM 用 leaf-wise 生长，务必限制 num_leaves 或 max_depth，否则易过拟合
3. 类别特征多时优先 CatBoost（原生处理），否则 LightGBM 更快，XGBoost 最稳
4. 学习率（learning_rate）和树数量（n_estimators）联合调：小学习率 + 多树，配合早停
5. 用早停（early stopping）监控验证集，别让树无脑加满
6. 随机森林对超参不敏感，但 n_estimators 太少会欠拟合，通常 100 起步
7. 树模型对特征缩放不敏感，无需标准化；但对类别编码敏感，注意编码方式
8. 特征重要性可用于快速筛选特征，但要注意它偏向高基数特征，别全信
9. 处理缺失值时 GBDT 系自带缺失处理，但要确认框架行为一致

### 踩坑记录

```text
坑 1：LightGBM 不用早停导致严重过拟合
结论：训练集准确率 99%，测试集暴跌到 70%，泛化极差。
原因：leaf-wise 生长 + 默认参数下树持续加深，拟合了噪声。
解法：设 early_stopping_rounds 监控验证集，同时限制 num_leaves 和 min_data_in_leaf。

坑 2：用 XGBoost/LightGBM 默认处理高基数类别特征
结论：类别特征有上万个取值时，模型训练慢且效果差。
原因：GBDT 需对类别特征做编码，高基数 one-hot 会爆炸，label 编码会误导分裂。
解法：高基数类别优先用 CatBoost，或做目标编码/频率编码/嵌入，注意防泄漏。

坑 3：随机森林里树太浅导致欠拟合
结论：max_depth=3 时训练和测试准确率都低，误以为随机森林不行。
原因：单棵树太浅，集成再多也拟合不了复杂关系，偏差降不下来。
解法：随机森林的树通常让它们充分生长（不限制深度或设较大值），靠 Bagging 控制方差。

坑 4：GBDT 学习率与树数量搭配失衡
结论：learning_rate=1.0 只练 50 棵树，训练集都没拟合好，欠拟合。
原因：学习率太大步长太猛，树数量又不够，加法模型没收敛。
解法：用较小的学习率（0.01~0.1）+ 足够树数量 + 早停，二者必须联动调。

坑 5：用特征重要性做因果推断
结论：把「重要性高」当成「因果影响大」，得出错误业务结论。
原因：特征重要性反映的是预测贡献，会偏向高基数/相关特征，不是因果。
解法：重要性只用于筛选和降维，因果结论要用因果推断方法（如 SHAP 值 + 领域验证）。
```
