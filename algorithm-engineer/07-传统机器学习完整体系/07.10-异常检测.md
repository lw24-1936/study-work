## 概述

异常检测的目标是找出「与大多数数据显著不同」的样本，应用于欺诈交易、设备故障预警、网络入侵、工业质检等场景。方法分三大类：统计方法（Z-Score/IQR/马氏距离）基于分布假设，机器学习方法（Isolation Forest/LOF/One-Class SVM）基于密度或边界，深度学习方法（Autoencoder）用重构误差衡量异常程度。异常检测的核心难点是「什么是正常」往往没有明确边界，且异常样本稀少、无标签。

```text
异常检测方法的分类：
1. 统计方法 —— Z-Score、IQR、Mahalanobis（单变量/多变量分布假设）
2. 经典 ML —— Isolation Forest、LOF、One-Class SVM（密度/隔离/边界）
3. 深度学习 —— Autoencoder（重构误差）、VAE、GAN
4. 时序专用 —— Change Point（变点检测）、STL 残差、EWMA

应用领域：
1. 金融反欺诈 —— 异常交易识别
2. 工业/物联网 —— 设备故障预警
3. 网络安全 —— 入侵、异常流量检测
4. 业务监控 —— 指标突增突降告警
```

```python
import numpy as np
from sklearn.ensemble import IsolationForest

# 异常检测最小示例：混入少量异常点的数据
rng = np.random.default_rng(0)
X = rng.normal(0, 1, (200, 2))
X = np.r_[X, rng.normal(6, 0.3, (10, 2))]     # 10 个异常点

iso = IsolationForest(contamination=0.05, random_state=0).fit(X)
labels = iso.predict(X)        # 1 正常，-1 异常
print('识别出的异常点数:', np.sum(labels == -1))
```

## Z-Score

Z-Score 是最基础的单变量异常检测：把每个值标准化为「偏离均值多少个标准差」，偏离超过阈值（常为 3）就判为异常。它假设数据服从正态分布，简单快速，但对非正态数据和被异常值污染的均值/标准差敏感。

```text
Z-Score 的定义：
z = (x - μ) / σ

其中 μ 是均值，σ 是标准差。

判定规则：
1. |z| > 3 —— 通常判为异常（三西格玛原则）
2. |z| > 2 —— 较宽松的阈值

适用与局限：
1. 适用 —— 近似正态分布的单变量数据
2. 局限 —— 均值/标准差本身会被异常值拉偏，导致漏检（masking 效应）
```

```python
import numpy as np

def zscore_outliers(x, threshold=3.0):
    mu, sigma = x.mean(), x.std()
    z = (x - mu) / sigma
    return np.abs(z) > threshold, z

# 含明显异常值的数据
data = np.r_[np.random.randn(1000), np.array([10.0, -8.0, 12.0])]
mask, z = zscore_outliers(data)
print('Z-Score 识别出的异常值:', data[mask])

# 用更鲁棒的 MAD（中位数绝对偏差）替代，抗异常值污染
median = np.median(data)
mad = np.median(np.abs(data - median))
z_mad = 0.6745 * (data - median) / mad
print('基于 MAD 的异常值:', data[np.abs(z_mad) > 3.5])
```

## IQR

IQR（四分位距）用四分位数识别异常：计算 Q1（25% 分位）和 Q3（75% 分位），落在 [Q1 - 1.5·IQR, Q3 + 1.5·IQR] 之外的值判为异常。它不假设正态分布，基于分位数所以对极端值鲁棒，是箱线图的理论基础。

```text
IQR 的定义：
1. Q1 —— 25% 分位数（下四分位）
2. Q3 —— 75% 分位数（上四分位）
3. IQR = Q3 - Q1（四分位距）

判定规则：
1. 下界 = Q1 - 1.5 × IQR
2. 上界 = Q3 + 1.5 × IQR
3. 超出上下界即为异常（1.5 可调，3 为「极端异常」）

优点：
1. 基于分位数，对偏态分布和极端值鲁棒
2. 无需正态假设，比 Z-Score 更通用
```

```python
import numpy as np

def iqr_outliers(x, k=1.5):
    q1, q3 = np.percentile(x, [25, 75])
    iqr = q3 - q1
    lower, upper = q1 - k * iqr, q3 + k * iqr
    return (x < lower) | (x > upper), lower, upper

# 偏态分布（对数正态），Z-Score 会漏检/误检，IQR 更稳
data_skewed = np.random.lognormal(0, 1, 1000)
mask, lower, upper = iqr_outliers(data_skewed)
print(f'IQR 边界: [{lower:.2f}, {upper:.2f}]，识别异常 {np.sum(mask)} 个')
```

## Mahalanobis

马氏距离在多变量场景里检测异常：考虑各维度之间的相关性，用协方差矩阵的逆做尺度化，度量一个点离数据中心「多远」。它能发现「单看每个维度都正常、但组合起来异常」的点，比如身高体重都在正常范围但比例失调的人。

```text
马氏距离做异常检测：
d_M(x) = sqrt((x - μ)ᵀ Σ⁻¹ (x - μ))

其中 μ 是数据中心（均值），Σ 是协方差矩阵。

与单变量方法的区别：
1. Z-Score/IQR —— 逐维度独立判断，忽略维度间相关性
2. Mahalanobis —— 联合判断，捕捉多变量组合异常
3. 分布假设 —— 数据近似服从多元高斯分布

判定：
1. d_M² 近似服从卡方分布（自由度 = 维度数）
2. 用卡方分布的分位数做阈值
```

```python
import numpy as np
from scipy.spatial.distance import mahalanobis
from scipy.stats import chi2

# 有相关性的二维数据 + 一个「比例失调」的异常点
mean = [170, 65]
cov = [[100, 60], [60, 60]]        # 身高体重正相关
X = np.random.multivariate_normal(mean, cov, 500)

mu = X.mean(axis=0)
cov_est = np.cov(X, rowvar=False)
cov_inv = np.linalg.inv(cov_est)

# 身高 170、体重 110：每个维度都「可接受」，但组合起来比例异常
p = np.array([170, 110])
d2 = mahalanobis(p, mu, cov_inv) ** 2
threshold = chi2.ppf(0.975, df=2)   # 卡方 97.5% 分位（2 自由度）
print(f'马氏距离平方={d2:.2f}，阈值={threshold:.2f}，异常={d2 > threshold}')
```

## Isolation Forest

孤立森林（Isolation Forest）基于一个直觉：异常点「少且不同」，更容易被随机划分孤立出来。它随机选特征、随机选切分点递归分割数据，统计每个点被孤立所需的平均路径长度——异常点路径短（很快被单独分出），正常点路径长。它无需距离计算，适合高维和大数据。

```text
Isolation Forest 的核心思想：
1. 构建隔离树 —— 随机选特征和切分值，递归切分直到点被隔离
2. 路径长度 —— 异常点平均只需很少几次切分就被孤立
3. 异常分数 —— 路径越短 → 分数越高 → 越可能是异常

关键参数：
1. n_estimators —— 树的数量（越多越稳）
2. contamination —— 数据中异常的预期比例（决定阈值）
3. max_samples —— 每棵树用的样本数（256 通常够用）
```

```python
from sklearn.ensemble import IsolationForest
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(0, 1, (500, 5))
X = np.r_[X, rng.normal(5, 0.5, (20, 5))]

iso = IsolationForest(n_estimators=100, contamination=0.04, random_state=0)
labels = iso.fit_predict(X)
scores = iso.decision_function(X)     # 越小越异常
print('识别异常点数:', np.sum(labels == -1))
print('异常分数最低的 3 个样本:', np.argsort(scores)[:3])
```

```text
Isolation Forest 的优缺点：
1. 优点 —— 无距离计算，速度快，适合高维和大数据，无需分布假设
2. 缺点 —— 对局部密度异常不敏感，对「稀疏簇中的点」可能误判
3. 适用 —— 全局异常点、大数据量、特征维度较高的场景
```

## LOF

LOF（局部异常因子）基于局部密度：对每个点，比较它自身密度与它邻居的密度，密度明显低于邻居的点判为异常。它能发现「局部异常」——藏在密集区域里、但相对周围邻居明显稀疏的点，这是 Isolation Forest 和全局方法容易漏掉的。

```text
LOF 的核心思想：
1. k-distance —— 点到第 k 近邻的距离
2. 可达距离 —— max(k-distance(邻居), 实际距离)
3. 局部可达密度 —— k / Σ 可达距离（密度越高值越大）
4. LOF —— 邻居平均密度 / 自身密度

判定：
1. LOF ≈ 1 —— 密度与邻居相当，正常
2. LOF ≫ 1 —— 密度远低于邻居，异常
3. LOF < 1 —— 密度高于邻居（簇内部点）
```

```python
from sklearn.neighbors import LocalOutlierFactor
import numpy as np

# 一个密集簇 + 一个稀疏簇，全局方法会漏掉稀疏簇里的局部异常
rng = np.random.default_rng(0)
X_dense = rng.normal(0, 0.3, (300, 2))
X_sparse = rng.normal(4, 1.5, (100, 2))      # 稀疏簇整体是「局部异常」
X = np.r_[X_dense, X_sparse]

lof = LocalOutlierFactor(n_neighbors=20, contamination=0.2)
labels = lof.fit_predict(X)
lof_scores = -lof.negative_outlier_factor_
print('LOF 识别异常点数:', np.sum(labels == -1))
print('LOF 分数最高的点（最异常）:', np.argsort(lof_scores)[-3:])
```

## One-Class SVM

One-Class SVM 是单类分类器：只用「正常」样本训练，找一个把正常数据包住的边界（超球或超平面），边界之外的点判为异常。它适合「只有正常样本、异常样本稀少且未知」的冷启动场景。

```text
One-Class SVM 的思想：
1. 目标 —— 把正常样本尽量包进一个边界内
2. 核技巧 —— 用 RBF 核把数据映射到高维，找一个超球包住正常点
3. 软间隔 —— nu 参数控制允许多少样本落在边界外（即异常比例）

关键参数：
1. nu —— 训练误差上限和支撑向量比例下界（≈ 预期异常比例）
2. gamma —— RBF 核的宽度，越大边界越复杂越易过拟合
```

```python
from sklearn.svm import OneClassSVM
import numpy as np

rng = np.random.default_rng(0)
X_train = rng.normal(0, 1, (300, 2))          # 只用正常样本训练
X_test = np.r_[rng.normal(0, 1, (50, 2)),
               rng.normal(5, 0.5, (10, 2))]   # 测试含 10 个异常

ocsvm = OneClassSVM(kernel='rbf', nu=0.05, gamma=0.5).fit(X_train)
pred = ocsvm.predict(X_test)                   # 1 正常，-1 异常
print('测试集识别异常数:', np.sum(pred == -1))
```

```text
One-Class SVM 的注意点：
1. 适合 —— 正常样本充足、异常样本几乎没有的场景
2. 敏感 —— 对 nu 和 gamma 参数敏感，需调参
3. 对比 —— Isolation Forest 通常更快、更省心，可优先尝试
```

## Autoencoder

自编码器（Autoencoder）用重构误差做异常检测：训练一个「编码 → 解码」的网络，让它学会重构正常样本。正常样本重构误差小，异常样本（没见过、偏离分布）重构误差大，用误差阈值判定。它能自动学特征表示，适合图像、时序等高维数据。

```text
Autoencoder 做异常检测的思路：
1. 训练 —— 只用正常样本训练自编码器，最小化重构误差
2. 推理 —— 新样本过一遍网络，算重构误差
3. 判定 —— 重构误差超过阈值的判为异常

直觉：
1. 网络只「记住」了正常数据的模式
2. 异常数据不符合这些模式，重构出来会「失真」
3. 重构误差的大小就反映异常的严重程度
```

```python
import torch
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, in_dim=10, hidden=4):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(in_dim, hidden), nn.ReLU())
        self.decoder = nn.Sequential(nn.Linear(hidden, in_dim))

    def forward(self, x):
        return self.decoder(self.encoder(x))

def reconstruction_error(model, x):
    x_hat = model(x)
    return ((x - x_hat) ** 2).mean(dim=1)

model = Autoencoder(in_dim=10, hidden=4)
# 正常样本重构误差小，异常样本重构误差大
x_normal = torch.randn(16, 10)
x_abnormal = torch.randn(4, 10) * 5
print('正常样本重构误差:', reconstruction_error(model, x_normal).mean().item())
print('异常样本重构误差:', reconstruction_error(model, x_abnormal).mean().item())
```

```text
Autoencoder 异常检测的要点：
1. 瓶颈维度 —— hidden 太小会欠拟合（正常也重构不好），太大退化为恒等映射
2. 阈值 —— 用验证集正常样本重构误差的分位数（如 95%）做阈值
3. 变体 —— 变分自编码器（VAE）、卷积自编码器（图像）
```

## Change Point

变点检测（Change Point Detection）针对时序数据：找出序列统计特性发生突变的时间点（均值突变、方差突变、趋势转折）。它广泛用于业务指标告警、系统故障定位、金融风控。方法有基于滑动窗口的统计检验、CUSUM、贝叶斯在线变点检测，以及 rupture 库提供的各类算法。

```text
变点检测的常见方法：
1. CUSUM —— 累积和，检测均值漂移，在线实时
2. 滑动窗口 Z 检验 —— 比较前后窗口的均值差异
3. PELT/Binseg —— 离线最优分割（rupture 库）
4. 贝叶斯在线变点 —— 用概率在线估计变点位置

应用：
1. 指标监控 —— 流量/错误率突增突降
2. 故障定位 —— 系统行为突变的时间点
3. 金融 —— 价格趋势转折
```

```python
import numpy as np
import ruptures as rpt

# 构造均值突变的时间序列：前 200 点均值 0，后 200 点均值 3
signal = np.r_[np.random.randn(200) * 1.0, np.random.randn(200) * 1.0 + 3]

# PELT 算法自动找变点
algo = rpt.Pelt(model='rbf').fit(signal)
result = algo.predict(pen=10)
print('检测到的变点位置:', result)

# 用二分分割法找主要变点
algo_bin = rpt.Binseg(model='l2').fit(signal)
bkps = algo_bin.predict(n_bkps=1)
print('二分法检测的主变点:', bkps)
```

```python
# 手写 CUSUM：在线检测均值上移
def cusum_detect(signal, threshold=5, drift=0.5):
    pos_sum, neg_sum = 0.0, 0.0
    alarms = []
    for i, x in enumerate(signal):
        pos_sum = max(0, pos_sum + (x - drift))
        neg_sum = max(0, neg_sum - (x + drift))
        if pos_sum > threshold or neg_sum > threshold:
            alarms.append(i)
            pos_sum = neg_sum = 0.0      # 报警后重置
    return alarms

alarms = cusum_detect(signal)
print('CUSUM 报警点（前几个）:', alarms[:5], '总报警数:', len(alarms))
```

## 应用场景实战

### 场景一：信用卡欺诈检测

```python
from sklearn.ensemble import IsolationForest
from sklearn.metrics import classification_report
import numpy as np

rng = np.random.default_rng(42)
# 正常交易 + 少量欺诈交易（异常）
X_normal = rng.normal(0, 1, (2000, 10))
X_fraud = rng.normal(3, 0.5, (40, 10))
X = np.r_[X_normal, X_fraud]
y_true = np.r_[np.zeros(2000), np.ones(40)]

iso = IsolationForest(contamination=0.02, random_state=0)
y_pred = (iso.fit_predict(X) == -1).astype(int)
print(classification_report(y_true, y_pred, target_names=['正常', '欺诈'], zero_division=0))
```

### 场景二：传感器时序故障预警

```python
from sklearn.neighbors import LocalOutlierFactor
import numpy as np

# 设备传感器读数：正常运行 + 退化阶段出现异常读数
rng = np.random.default_rng(1)
t = np.linspace(0, 100, 500)
vibration = np.sin(t / 5) * 0.5 + rng.normal(0, 0.1, 500)
vibration[400:] += rng.normal(0, 0.8, 100)     # 400 之后设备开始异常振动

X = np.c_[t, vibration]
lof = LocalOutlierFactor(n_neighbors=20, contamination=0.05)
labels = lof.fit_predict(X)
anomaly_idx = np.where(labels == -1)[0]
print(f'检测到 {len(anomaly_idx)} 个异常读数，主要集中在 t>400: {np.sum(anomaly_idx > 400)}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 单变量数据先画直方图/箱线图，用 IQR 或 MAD 版 Z-Score，别盲目用 3σ
2. 多变量数据优先 Isolation Forest 或 LOF，能捕捉维度间关系
3. contamination 参数要贴合业务：预期异常比例决定阈值，别瞎设
4. 只有正常样本时用 One-Class SVM 或 Autoencoder 做冷启动
5. 图像/时序高维数据用 Autoencoder 重构误差，天然学特征
6. 异常检测结果一定要人工抽检，结合业务验证精度
7. 时序数据用专门的变点检测（CUSUM/PELT），别用静态异常检测硬套
8. 阈值的选择用验证集上正常样本的分数分位数，而非拍脑袋

### 踩坑记录

```text
坑 1：Z-Score 的均值和标准差被异常值污染
结论：数据里混入极端值后，μ/σ 被拉偏，真正的异常值 z 分数反而变小而漏检。
原因：Z-Score 的 μ、σ 对离群值不鲁棒（masking 效应）。
解法：改用基于中位数的 MAD 版 Z-Score，或用 IQR 分位数法。

坑 2：忽略维度相关性，逐维度单独检测
结论：身高 170、体重 110 单看都「正常」，但组合起来明显异常，逐维检测漏掉。
原因：单变量方法看不到维度之间的联合分布。
解法：多变量数据用马氏距离、Isolation Forest 或 LOF 联合判断。

坑 3：Isolation Forest 的 contamination 设错
结论：设太低漏检，设太高把正常点也标成异常，业务告警泛滥。
原因：contamination 决定决策阈值，和真实异常比例不匹配就失真。
解法：结合历史异常比例或业务可接受误报率设定，用验证集校准。

坑 4：Autoencoder 瓶颈维度选错
结论：hidden 太小时正常样本也重构不好，误差普遍大，阈值失准；太大时退化为恒等映射。
原因：瓶颈过窄欠拟合、过宽过拟合，两者都破坏重构误差的区分度。
解法：用验证集正常样本重构误差调 hidden，并监控正常/异常的误差分布分离度。

坑 5：用静态异常检测方法处理时序数据
结论：趋势、周期性的正常波动被误报为异常，告警淹没真实突变。
原因：静态方法不建模时间依赖，把趋势/周期当成异常。
解法：时序用 STL 分解后对残差检测，或用 CUSUM/PELT 等变点检测方法。
```
