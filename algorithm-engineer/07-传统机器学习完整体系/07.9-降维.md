## 概述

降维把高维数据映射到低维空间，同时尽量保留原始数据的结构信息。目的一是缓解「维度灾难」，让下游模型更稳更快；二是可视化（把数据压到 2~3 维）；三是去噪、提取主成分。降维方法分两大类：线性方法（PCA/SVD/LDA/ICA/NMF）假设数据在低维线性子空间里，流形方法（t-SNE/UMAP/Isomap/LLE）则假设数据分布在弯曲的低维流形上。

```text
降维方法的分类：
1. 线性投影 —— PCA、SVD、LDA、ICA、NMF、Kernel PCA（核技巧非线性）
2. 流形学习 —— Isomap、LLE、MDS、t-SNE、UMAP
3. 有监督 vs 无监督 —— LDA 用标签，PCA/t-SNE 等不用标签
4. 可重构 vs 仅可视化 —— PCA/NMF 能重构原数据，t-SNE/UMAP 只做低维表示
```

```python
from sklearn.decomposition import PCA
import numpy as np

# 降维最小示例：把 4 维数据压到 2 维
X = np.random.randn(100, 4)
pca = PCA(n_components=2).fit(X)
X_reduced = pca.transform(X)
print('原始形状:', X.shape, '→ 降维后:', X_reduced.shape)
print('各主成分解释方差比:', pca.explained_variance_ratio_.round(3))
```

## PCA

PCA（主成分分析）是最常用的线性降维：找到数据方差最大的正交方向（主成分），把数据投影到这些方向上。第一个主成分是方差最大的方向，第二个是与之正交且方差次大的方向，依此类推。

```text
PCA 的推导思路：
1. 数据中心化（减均值）
2. 计算协方差矩阵 C = (1/n) XᵀX
3. 对 C 做特征分解，取最大的 k 个特征值对应的特征向量
4. 把数据投影到这 k 个特征向量张成的子空间

等价视角：
1. 最大方差 —— 投影后方差最大的方向
2. 最小重构误差 —— 投影后损失信息最少
3. SVD —— X = UΣVᵀ，主成分就是 V 的前 k 列
```

```python
import numpy as np

def pca_manual(X, k):
    X_centered = X - X.mean(axis=0)
    C = X_centered.T @ X_centered / (len(X) - 1)      # 协方差矩阵
    eigvals, eigvecs = np.linalg.eigh(C)               # 特征分解
    top_idx = np.argsort(eigvals)[::-1][:k]            # 最大 k 个
    return X_centered @ eigvecs[:, top_idx], eigvals[top_idx]

X = np.random.randn(200, 5)
X_reduced, eigvals = pca_manual(X, k=2)
print('手写 PCA 降维后形状:', X_reduced.shape)
print('前 2 个特征值:', eigvals.round(2))
```

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=0.95)          # 保留 95% 方差，自动确定维数
X_reduced = pca.fit_transform(X)
print('保留 95% 方差需要的主成分数:', pca.n_components_)
print('累计解释方差比:', np.cumsum(pca.explained_variance_ratio_).round(3))
```

## SVD

SVD（奇异值分解）把任意矩阵分解为 X = UΣVᵀ。它与 PCA 数学上等价（PCA 是 SVD 在中心化数据上的特例），但 SVD 数值更稳定、可直接对稀疏矩阵计算，是推荐系统、LSI（隐语义索引）的基础。

```text
SVD 的定义：
X = U Σ Vᵀ
1. U —— 左奇异向量（行空间的正交基，m×m）
2. Σ —— 奇异值对角矩阵（按降序排列）
3. V —— 右奇异向量（列空间的正交基，n×n）

截断 SVD：
1. 只取前 k 个奇异值，得到最优 k 秩近似
2. X ≈ U_k Σ_k V_kᵀ，是低秩逼近的最优解（Eckart-Young 定理）
```

```python
import numpy as np
from sklearn.decomposition import TruncatedSVD

X = np.random.randn(100, 20)

# 完整 SVD
U, S, Vt = np.linalg.svd(X, full_matrices=False)
print('奇异值数量:', S.shape)

# 截断 SVD（sklearn 专门处理稀疏/大数据，不要求中心化）
svd = TruncatedSVD(n_components=5).fit(X)
X_reduced = svd.transform(X)
print('截断 SVD 降维后形状:', X_reduced.shape)
print('各奇异值解释方差比:', svd.explained_variance_ratio_.round(3))
```

```text
PCA 与 SVD 的关系：
1. PCA —— 先中心化，再对协方差矩阵做特征分解
2. SVD —— 直接对数据矩阵分解，无需显式算协方差，数值更稳定
3. TruncatedSVD —— 适合稀疏矩阵（如 TF-IDF），此时不能中心化（会破坏稀疏性）
4. 结果 —— 中心化后 SVD 的 V 列就是 PCA 的主成分方向
```

## LDA

LDA（线性判别分析）是有监督降维：它不用方差最大做准则，而是找「让类间散度最大、类内散度最小」的投影方向，把不同类分得越开越好。因此 LDA 既可用于降维，也可直接作为分类器（Fisher 判别）。

```text
LDA 的目标：
最大化 J(w) = (wᵀ S_B w) / (wᵀ S_W w)

其中：
1. S_B —— 类间散度矩阵（类中心之间的散布）
2. S_W —— 类内散度矩阵（各类内部的散布）
3. 最优方向 —— S_W⁻¹ S_B 的最大特征值对应的特征向量

关键限制：
1. 最多降维到 C-1 维（C 为类别数）
2. 需要标签，是有监督方法
```

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
import numpy as np

# 三类数据，LDA 降到 2 维让类尽量分开
rng = np.random.default_rng(0)
X1 = rng.multivariate_normal([0, 0, 0], np.eye(3), 100)
X2 = rng.multivariate_normal([4, 4, 4], np.eye(3), 100)
X3 = rng.multivariate_normal([-4, 4, -4], np.eye(3), 100)
X = np.r_[X1, X2, X3]
y = np.array([0] * 100 + [1] * 100 + [2] * 100)

lda = LinearDiscriminantAnalysis(n_components=2).fit(X, y)
X_lda = lda.transform(X)
print('LDA 降维后形状:', X_lda.shape)
print('各类降维后中心（应明显分开）:\n', np.round(
    [X_lda[y == c].mean(axis=0) for c in range(3)], 2))
```

```text
PCA 与 LDA 的区别：
1. PCA —— 无监督，找方差最大方向，可能把类混在一起
2. LDA —— 有监督，找类间可分性最大的方向
3. 选择 —— 有标签且想最大化可分性用 LDA；纯探索/无标签用 PCA
```

## ICA

ICA（独立成分分析）假设观测信号是若干「相互独立」的源信号的线性混合，目标是反解出这些独立源。它追求的是「统计独立」而非「不相关」（PCA 只保证不相关）。经典应用是「鸡尾酒会问题」：从多个麦克风的混合录音中分离出每个人的声音。

```text
ICA 的核心假设：
1. 源信号相互独立（非高斯）
2. 观测 = 混合矩阵 × 源信号（线性混合）
3. 目标是估计解混矩阵 W，恢复独立源

与 PCA 的区别：
1. PCA —— 找不相关（二阶统计量）方向，方差最大
2. ICA —— 找独立（高阶统计量）方向，最大化非高斯性
3. ICA 要求源信号非高斯（最多一个源可以是高斯）
```

```python
from sklearn.decomposition import FastICA
import numpy as np

# 生成两个独立信号，然后线性混合
rng = np.random.default_rng(42)
S = np.c_[np.sin(np.linspace(0, 8, 1000)),          # 源 1：正弦
          rng.laplace(size=1000)]                    # 源 2：拉普拉斯噪声
A = np.array([[1, 1], [0.5, 2]])                     # 混合矩阵
X = S @ A.T                                          # 观测到的混合信号

ica = FastICA(n_components=2, random_state=0).fit(X)
S_recovered = ica.transform(X)
# 恢复的信号与真实源高度相关（可能有符号/顺序歧义）
corr = np.corrcoef(S.T, S_recovered.T)[:2, 2:]
print('恢复信号与源信号的相关系数:\n', np.round(corr, 2))
```

## NMF

NMF（非负矩阵分解）把非负矩阵 X 分解成两个非负矩阵 W 和 H 的乘积：X ≈ W·H。非负约束让分解结果有「可加性、可解释性」——每个样本是若干「主题/部件」的非负组合，常用于主题建模、推荐、图像部件提取。

```text
NMF 的定义：
X ≈ W H，其中 X、W、H 都非负
1. W —— 基矩阵（部件/主题，n_samples × n_components）
2. H —— 系数矩阵（每个样本用多少每个部件，n_components × n_features）

优化：
1. 目标 —— min ‖X - WH‖²（Frobenius 范数），交替更新 W 和 H
2. 特点 —— 非负约束带来「部件式」稀疏可解释表示

典型应用：
1. 文本主题建模（TF-IDF 矩阵 → 主题分布）
2. 推荐系统（评分矩阵 → 用户兴趣 + 物品属性）
3. 图像部件分解（人脸 → 眼睛、鼻子等部件）
```

```python
from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

docs = [
    '机器学习 深度学习 神经网络 训练 模型',
    '深度学习 卷积 神经网络 图像 识别',
    '足球 比赛 进球 球员 联赛',
    '篮球 比赛 扣篮 球员 冠军',
    '股票 投资 基金 市场 收益',
]
tfidf = TfidfVectorizer().fit_transform(docs)
nmf = NMF(n_components=3, random_state=0, max_iter=500).fit(tfidf)

feature_names = TfidfVectorizer().fit(docs).get_feature_names_out()
for topic_idx, topic in enumerate(nmf.components_):
    top_words = [feature_names[i] for i in topic.argsort()[:-5:-1]]
    print(f'主题 {topic_idx}: {top_words}')
```

```text
NMF 与 PCA 的区别：
1. PCA —— 主成分可正可负，是「减去均值后」的最优正交基，解释性弱
2. NMF —— 所有分量非负，是「可加」的部件组合，解释性强
3. 适用 —— 数据本身非负（词频、评分、像素、频谱）时 NMF 更自然
```

## Kernel PCA

Kernel PCA 用核技巧把 PCA 推广到非线性：先把数据隐式映射到高维特征空间，再做线性 PCA。它等价于在原始空间里找非线性主成分，能捕捉 PCA 抓不住的弯曲结构。

```text
Kernel PCA 的思路：
1. 核函数 —— k(x, y) = ⟨φ(x), φ(y)⟩，隐式映射到高维
2. 核矩阵 —— K_ij = k(x_i, x_j)，在高维特征空间做中心化
3. 特征分解 —— 对中心化核矩阵做特征分解得到主成分

常用核：
1. RBF（高斯）核 —— 最常用，能捕捉任意非线性结构
2. 多项式核 —— 捕捉多项式关系
3. sigmoid 核 —— 类似神经网络激活
```

```python
from sklearn.decomposition import KernelPCA
from sklearn.datasets import make_circles

# 同心圆数据：线性 PCA 无法分开，Kernel PCA 可以
X_circle, _ = make_circles(n_samples=300, factor=0.3, noise=0.05, random_state=0)

kpca = KernelPCA(n_components=2, kernel='rbf', gamma=10).fit(X_circle)
X_kpca = kpca.transform(X_circle)
print('Kernel PCA 后第一主成分的分布范围:', X_kpca[:, 0].min().round(2), X_kpca[:, 0].max().round(2))

pca = PCA(n_components=2).fit(X_circle)
print('线性 PCA 解释方差比:', pca.explained_variance_ratio_.round(3))
```

## t-SNE

t-SNE（t 分布随机近邻嵌入）是专门为「可视化」设计的非线性降维：它在高维用高斯分布建模相似度，在低维用重尾的 t 分布建模相似度，最小化两者的 KL 散度。它擅长把高维数据的局部簇结构漂亮地展示在 2~3 维，但不保全局距离。

```text
t-SNE 的核心思想：
1. 高维相似度 —— 用高斯核把距离转成条件概率 p_ij
2. 低维相似度 —— 用 t 分布（重尾）建模低维点间的概率 q_ij
3. 优化 —— 最小化 p 与 q 的 KL 散度（梯度下降）
4. t 分布 —— 重尾让中远距离的点在低维能「散开」，避免拥挤

重要特性：
1. 只保局部结构，全局距离和簇大小无意义
2. 结果随机（需固定 random_state），每次运行可能不同
3. perplexity 是最关键参数，影响「看多少个邻居」
```

```python
from sklearn.manifold import TSNE
from sklearn.datasets import load_digits

X_digits, y_digits = load_digits(return_X_y=True)
X_tsne = TSNE(n_components=2, perplexity=30, random_state=42).fit_transform(X_digits)
print('t-SNE 降维后形状:', X_tsne.shape)

# 可视化（10 个数字类在 2D 上应形成明显簇）
import matplotlib.pyplot as plt
plt.figure(figsize=(7, 6))
plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y_digits, cmap='tab10', s=10, alpha=0.7)
plt.colorbar(label='digit class')
plt.title('t-SNE 可视化手写数字')
plt.savefig('/tmp/tsne_digits.png', dpi=100)
print('t-SNE 图已保存到 /tmp/tsne_digits.png')
```

## UMAP

UMAP（均匀流形近似与投影）是 t-SNE 的现代替代：它基于流形假设和拓扑理论，用更快的算法把数据嵌入低维。相比 t-SNE，它更好地保留了全局结构，速度更快，且能扩展到大规模数据。

```text
UMAP 的核心思想：
1. 构建高维图 —— 用 k 近邻构建模糊单纯形集（fuzzy simplicial set）
2. 低维嵌入 —— 用交叉熵最小化高维图和低维图的差异
3. 参数 —— n_neighbors 控制局部/全局平衡，min_dist 控制簇的紧凑度

与 t-SNE 的对比：
1. UMAP 更快 —— 适合百万级数据
2. UMAP 保全局 —— 簇间距离更有意义
3. UMAP 可复用 —— 学到的变换能用于新数据（transform）
```

```python
import umap
from sklearn.datasets import load_digits

X_digits, y_digits = load_digits(return_X_y=True)

# fit 后可用 transform 处理新数据（t-SNE 不具备）
reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)
X_umap = reducer.fit_transform(X_digits)
print('UMAP 降维后形状:', X_umap.shape)

# 对新样本做同一变换
new_point = X_digits[:5]
print('新样本嵌入形状:', reducer.transform(new_point).shape)
```

```text
n_neighbors 与 min_dist 的作用：
1. n_neighbors 小 → 更关注局部细节，可能过度分簇
2. n_neighbors 大 → 更关注全局结构，簇更连贯
3. min_dist 小 → 点挤得更紧，簇更紧凑
4. min_dist 大 → 点更松散，更强调全局
```

## Isomap

Isomap（等距特征映射）是流形学习的经典方法：它用「测地距离」（沿着流形表面的最短路径）替代欧氏距离，再对这个距离矩阵做 MDS。它能展开「瑞士卷」这类欧氏距离近但流形距离远的非线性结构。

```text
Isomap 的步骤：
1. 构建近邻图 —— 每个点连 k 个最近邻（或 eps 半径内）
2. 计算测地距离 —— 用图上的最短路径（Dijkstra/Floyd）近似流形距离
3. 经典 MDS —— 对测地距离矩阵做特征分解，得到低维嵌入

关键参数：
1. n_neighbors —— 太小图断裂（产生多个连通分量），太大丢失流形结构
2. 适用 —— 数据分布在低维流形上、且流形相对平坦时效果好
```

```python
from sklearn.manifold import Isomap
from sklearn.datasets import make_swiss_roll

# 瑞士卷数据：3D 空间里卷曲的 2D 流形
X_roll, color = make_swiss_roll(n_samples=1000, random_state=42)

isomap = Isomap(n_neighbors=10, n_components=2).fit(X_roll)
X_iso = isomap.transform(X_roll)
print('Isomap 把 3D 瑞士卷展开到 2D:', X_iso.shape)
print('测地距离矩阵（前 3 个非零值）:', isomap.dist_matrix_[0, :3].round(2))
```

## LLE

LLE（局部线性嵌入）假设每个点可以由其近邻的线性组合重构，并保持这个「局部线性关系」在低维不变。它用重构权重刻画局部几何，然后求一个低维嵌入让这些权重继续成立。

```text
LLE 的步骤：
1. 找近邻 —— 每个点找 k 个最近邻
2. 求重构权重 —— 用近邻线性组合重构该点，最小化重构误差
3. 求低维嵌入 —— 固定权重，求低维坐标使重构关系保持

关键特性：
1. 只依赖局部线性关系，能展开非线性流形
2. 对近邻数 k 敏感，k 太小/太大都会破坏结构
3. 计算相对快，但全局结构保持不如 Isomap
```

```python
from sklearn.manifold import LocallyLinearEmbedding

X_roll, color = make_swiss_roll(n_samples=1000, random_state=42)

lle = LocallyLinearEmbedding(n_neighbors=12, n_components=2, method='standard')
X_lle = lle.fit_transform(X_roll)
print('LLE 展开瑞士卷到 2D:', X_lle.shape)

# reconstruction_error 反映局部重构质量
print('局部重构误差:', lle.reconstruction_error_.round(4))
```

## MDS

MDS（多维缩放）从「样本间的距离（或不相似度）矩阵」出发，找一个低维坐标，让低维下的点间距离尽量接近原始距离。它是 Isomap 的最后一步，也是很多「只有距离没有坐标」场景（如心理学相似度、城市间距离）的核心工具。

```text
MDS 的类型：
1. 经典 MDS（metric）—— 保欧氏距离，等价于对双重中心化距离矩阵做 PCA
2. 非度量 MDS —— 只保距离的「排序」而非具体数值

经典 MDS 的步骤：
1. 计算距离矩阵 D（或由坐标算出）
2. 双重中心化 B = -1/2 J D² J
3. 对 B 做特征分解，取前 k 个特征向量得到坐标
```

```python
from sklearn.manifold import MDS
import numpy as np

# 只有城市间距离矩阵，没有坐标，还原相对位置
cities = ['北京', '上海', '广州', '成都', '武汉']
D = np.array([[0, 1213, 2125, 1787, 1166],
              [1213, 0, 1450, 1902, 828],
              [2125, 1450, 0, 1436, 984],
              [1787, 1902, 1436, 0, 1137],
              [1166, 828, 984, 1137, 0]], dtype=float)

mds = MDS(n_components=2, dissimilarity='precomputed', random_state=0, normalized_stress='auto')
X_mds = mds.fit_transform(D)
for city, coord in zip(cities, X_mds):
    print(f'{city}: ({coord[0]:.0f}, {coord[1]:.0f})')

print('压力值（越小拟合越好）:', mds.stress_.round(3))
```

### 场景一：PCA 去噪 + 可视化高维数据

```python
from sklearn.decomposition import PCA
from sklearn.datasets import load_digits
import numpy as np

X, y = load_digits(return_X_y=True)

# 用少量主成分重构，起到去噪效果
pca = PCA(n_components=30).fit(X)
X_reconstructed = pca.inverse_transform(pca.transform(X))
mse = np.mean((X - X_reconstructed) ** 2)
print(f'用 30/64 维重构的 MSE: {mse:.3f}')

# 前两个主成分的二维投影，观察类别可分性
pca2 = PCA(n_components=2).fit(X)
X_2d = pca2.transform(X)
print('前两主成分解释方差占比:', pca2.explained_variance_ratio_.sum().round(3))
```

### 场景二：UMAP 做客户嵌入聚类

```python
import umap
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# 模拟 500 用户 × 20 维行为特征
rng = np.random.default_rng(7)
X_users = rng.normal(size=(500, 20))
X_users[:250] += 3           # 前 250 个用户形成一个群体

X_scaled = StandardScaler().fit_transform(X_users)
embedding = umap.UMAP(n_neighbors=20, min_dist=0.1, n_components=2, random_state=0).fit_transform(X_scaled)

kmeans = KMeans(n_clusters=2, n_init=10, random_state=0).fit(embedding)
print('UMAP 嵌入后聚类的簇分布:', np.bincount(kmeans.labels_))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 降维前先标准化，PCA/NMF/t-SNE/UMAP 都对尺度敏感
2. 不知道降到几维时，用 PCA 的累计解释方差比（如保留 95%）自动选
3. 有标签且想最大化可分性用 LDA，无标签探索用 PCA
4. 非负数据（词频、评分）优先 NMF，解释性远好于 PCA
5. 可视化优先 UMAP（快、保全局），t-SNE 作补充对比
6. t-SNE/UMAP 的降维结果只用于探索/可视化，别直接喂给下游模型当特征（关系不可靠）
7. 流形方法（Isomap/LLE）调好 n_neighbors，太小图会断裂
8. 大规模数据先 PCA 降到中等维度，再 t-SNE/UMAP 精细可视化

### 踩坑记录

```text
坑 1：不标准化就做 PCA
结论：量纲大的特征主导主成分，方差小的特征被彻底淹没。
原因：PCA 最大化总方差，量纲大的特征天然方差大，主导主成分方向。
解法：StandardScaler 后再 PCA；解释主成分时也基于标准化后的载荷。

坑 2：把 t-SNE 结果当特征喂给下游模型
结论：t-SNE 不保全局距离，簇间距离、簇大小都无意义，模型学到噪声。
原因：t-SNE 只优化局部相似度的 KL 散度，输出坐标对尺度和初始化敏感。
解法：t-SNE/UMAP 仅用于可视化探索；建模特征用 PCA 或原始特征。

坑 3：t-SNE 结果每次运行不一样就怀疑代码有 bug
结论：换 random_state 或重跑，点的相对位置变了，但簇结构通常稳定。
原因：t-SNE 是非凸优化，结果依赖随机初始化。
解法：固定 random_state 保证可复现；关注「簇是否稳定」而非「点在哪」。

坑 4：Isomap/LLE 的 n_neighbors 取太小
结论：近邻图断裂成多个不连通分量，降维结果错乱甚至报错。
原因：n_neighbors 太小，流形上某些区域连不起来，测地距离无穷大。
解法：逐步增大 n_neighbors，检查图的连通性，直到所有点连通。

坑 5：用 PCA 做非线性数据降维
结论：同心圆、瑞士卷等非线性结构，线性 PCA 投影后类仍混在一起。
原因：PCA 只能找线性子空间，捕捉不到弯曲的流形结构。
解法：非线性结构用 Kernel PCA、Isomap、LLE 或 t-SNE/UMAP。
```
