## 概述

支持向量机（SVM）寻找「间隔最大」的分类超平面，只由少数「支持向量」决定决策边界，理论优美、泛化能力强。核方法（Kernel Method）是它的杀手锏：通过核函数在高维空间中隐式计算内积，把线性不可分问题变成线性可分，而无需显式做高维映射。SVM 在小样本、高维数据上表现突出，是深度学习时代前分类任务的王者。

```text
SVM 与核方法的核心脉络：
1. 最大间隔 —— 硬间隔/软间隔 SVM 寻找间隔最大的超平面
2. 对偶问题 —— 引入拉格朗日乘子，转化为只依赖内积的对偶形式
3. 核技巧 —— 用核函数 K(x,z)=⟨φ(x),φ(z)⟩ 隐式映射到高维
4. 扩展到回归/异常 —— SVR、One-Class SVM
5. 核方法通用化 —— Kernel PCA 等非 SVM 的核化算法
```

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import make_classification

X, y = make_classification(n_samples=500, n_features=10, random_state=0)
clf = svm.SVC(kernel='rbf', C=1.0, gamma='scale').fit(X, y)
print(f'SVM 支持向量数量: {clf.n_support_}（正负类各有多少支持向量）')
print(f'SVM 决策函数取值（符号决定类别）: {clf.decision_function(X[:3])}')
```

## Hard Margin

硬间隔 SVM 假设数据「线性可分」，寻找能完美分开两类、且间隔（margin）最大的超平面。间隔最大化带来最好的泛化保证——分类器对数据扰动最不敏感。

```text
数学定义（原始问题）：
min  (1/2)‖w‖²
s.t. y_i(w·x_i + b) ≥ 1,  ∀i

其中：
- w·x + b = 0 是分类超平面
- 间隔 margin = 2/‖w‖，最大化间隔 ⇔ 最小化 ‖w‖
- 约束 y_i(w·x_i + b) ≥ 1 要求所有样本正确分类且距边界至少 1

对偶问题：
max Σα_i - (1/2)ΣΣ α_i α_j y_i y_j (x_i·x_j)
s.t. α_i ≥ 0, Σ α_i y_i = 0

支持向量：α_i > 0 的样本，即恰好落在间隔边界上的点
```

```python
import numpy as np

# 硬间隔 SVM 用二次规划求解（这里用 sklearn 的线性核，C 取很大近似硬间隔）
from sklearn import svm

# 构造线性可分的两类数据
X = np.array([[1, 2], [2, 3], [3, 3], [2, 1], [3, 2],
              [8, 8], [9, 9], [9, 8], [8, 9]])
y = np.array([-1, -1, -1, -1, -1, 1, 1, 1, 1])

clf = svm.SVC(kernel='linear', C=1e9)   # C 很大 → 近似硬间隔
clf.fit(X, y)
w = clf.coef_[0]
b = clf.intercept_[0]
print(f'超平面: w={w}, b={b}')
print(f'间隔 margin = {2 / np.linalg.norm(w):.3f}')
print('支持向量索引:', clf.support_)
```

## Soft Margin

软间隔 SVM 允许部分样本「越过」间隔边界甚至被分错，通过引入松弛变量 ξ 和惩罚参数 C 在「间隔大小」与「分类错误」之间折中。它处理现实中普遍存在的「数据近似线性可分、含噪声」情况。

```text
数学定义（软间隔原始问题）：
min  (1/2)‖w‖² + C·Σ ξ_i
s.t. y_i(w·x_i + b) ≥ 1 - ξ_i,  ξ_i ≥ 0

其中：
- ξ_i 是第 i 个样本的松弛变量（允许的违规程度）
- C 是惩罚参数，权衡间隔与错误：
  C 大 → 更重视正确分类，间隔小，易过拟合
  C 小 → 更重视间隔大，容忍错误，模型更简单

对偶形式约束变为 0 ≤ α_i ≤ C
```

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 有重叠的数据（近似线性可分），软间隔更合适
X, y = make_classification(n_samples=400, n_features=2, n_redundant=0,
                           n_clusters_per_class=1, class_sep=0.8, random_state=0)
y = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

for C in [0.01, 0.1, 1.0, 10, 100]:
    clf = svm.SVC(kernel='linear', C=C).fit(X_train, y_train)
    acc = accuracy_score(y_test, clf.predict(X_test))
    print(f'C={C:>6}: 测试准确率={acc:.3f}  支持向量数={sum(clf.n_support_)}')
```

## Hinge Loss

合页损失（Hinge Loss）是 SVM 的「损失函数视角」：软间隔 SVM 的原始问题等价于「L2 正则 + 合页损失」的最小化。它只看「分得够不够远」，对正确且间隔充足的样本损失为 0，比对率损失更稀疏、对异常点更鲁棒。

```text
数学定义：
L_hinge(y, f(x)) = max(0, 1 - y·f(x))

其中 f(x) = w·x + b，y ∈ {-1, +1}

SVM 目标（无约束形式）：
min λ·‖w‖² + Σ max(0, 1 - y_i·f(x_i))

性质：
1. y·f(x) ≥ 1（分对且间隔足够）→ 损失 0
2. 0 < y·f(x) < 1（分对但太近）→ 线性惩罚
3. y·f(x) < 0（分错）→ 惩罚 > 1
```

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

def hinge_loss(y_true, scores):
    return np.maximum(0, 1 - y_true * scores)

scores = np.linspace(-2, 3, 100)
y_true = 1.0   # 正类
loss = hinge_loss(y_true, scores)
print(f'分数 score=2（分对且间隔足）→ 损失 {hinge_loss(1.0, np.array([2.0]))[0]:.1f}')
print(f'分数 score=0.5（分对但贴近边界）→ 损失 {hinge_loss(1.0, np.array([0.5]))[0]:.1f}')
print(f'分数 score=-1（分错）→ 损失 {hinge_loss(1.0, np.array([-1.0]))[0]:.1f}')

# 用合页损失训练线性分类器（梯度下降）
def hinge_gradient_descent(X, y, lr=0.01, epochs=500, lam=0.01):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        margin = y * (X @ w + b)
        # 合页损失的次梯度
        mask = margin < 1
        grad_w = -X[mask].T @ y[mask] / n + lam * w
        grad_b = -y[mask].sum() / n
        w -= lr * grad_w
        b -= lr * grad_b
    return w, b

X, y = make_classification(n_samples=200, n_features=2, n_redundant=0,
                           n_clusters_per_class=1, random_state=0)
y = np.where(y == 0, -1, 1)
w, b = hinge_gradient_descent(X, y)
pred = np.sign(X @ w + b)
print(f'合页损失 + 梯度下降训练，准确率={np.mean(pred == y):.3f}')
```

## Kernel Trick

核技巧（Kernel Trick）是 SVM 处理非线性问题的关键：通过核函数 K(x, z) 直接计算「高维映射后的内积」⟨φ(x), φ(z)⟩，无需显式构造高维特征 φ。这让 SVM 能在高维甚至无限维空间中找线性超平面，而计算量仍只依赖样本数。

```text
核心思想：
1. 数据在原空间线性不可分，但映射到高维 φ(x) 后线性可分
2. 对偶问题只出现内积 x_i·x_j，用 K(x_i, x_j) = ⟨φ(x_i), φ(x_j)⟩ 替换
3. 无需显式计算 φ(x)，直接算核函数即可

Mercer 条件：核函数对应的 Gram 矩阵须半正定，才对应某个特征空间的内积

常用核：
- 线性核：K(x,z) = x·z
- 多项式核：K(x,z) = (γ·x·z + r)^d
- RBF 核：K(x,z) = exp(-γ‖x-z‖²)
```

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 月亮数据集在原空间线性不可分
X, y = make_moons(n_samples=300, noise=0.15, random_state=0)
y = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

for kernel in ['linear', 'rbf']:
    clf = svm.SVC(kernel=kernel, C=1.0, gamma='scale').fit(X_train, y_train)
    acc = accuracy_score(y_test, clf.predict(X_test))
    print(f'kernel={kernel:>6}: 测试准确率={acc:.3f}（线性不可分 → 核技巧解决）')
```

## RBF

RBF 核（Radial Basis Function，高斯核）是最常用的核函数，把样本映射到「无限维」特征空间，能拟合任意复杂的决策边界。它只有一个关键参数 γ（gamma），控制单个样本的影响范围。

```text
数学定义：
K(x, z) = exp(-γ · ‖x - z‖²)

其中 γ > 0 控制「影响半径」：
- γ 大 → 每个样本影响范围小 → 决策边界复杂、易过拟合
- γ 小 → 每个样本影响范围大 → 决策边界平滑、易欠拟合

等价理解：RBF 核是「无限维多项式」的极限，因此表达能力极强
```

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = make_moons(n_samples=400, noise=0.2, random_state=0)
y = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

# gamma 对 RBF 决策边界复杂度的巨大影响
for gamma in [0.01, 0.1, 1.0, 10.0]:
    clf = svm.SVC(kernel='rbf', C=1.0, gamma=gamma).fit(X_train, y_train)
    acc = accuracy_score(y_test, clf.predict(X_test))
    print(f'gamma={gamma:>5}: 测试准确率={acc:.3f}  支持向量数={sum(clf.n_support_)}')
print('观察：gamma 过大 → 过拟合（支持向量数暴增），需交叉验证调优')
```

## Polynomial Kernel

多项式核（Polynomial Kernel）显式地把样本映射到「d 阶多项式」特征空间，能表达 d 阶以内的特征交互。相比 RBF，它的表达是「有限维」的，适合已知数据存在多项式关系、且希望得到可解释性的场景。

```text
数学定义：
K(x, z) = (γ · x·z + r)^d

参数：
- d（degree）—— 多项式的阶数，控制特征交互的复杂度
- γ —— 缩放系数（sklearn 默认 1/n_features）
- r（coef0）—— 常数项，控制低阶项的影响

直觉：d=1 退化为线性核；d=2 包含 x²、xz、z² 等二阶交互项
```

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import make_circles
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 同心圆数据：需要多项式（尤其二次）或 RBF 核才能分开
X, y = make_circles(n_samples=400, noise=0.1, factor=0.4, random_state=0)
y = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

for degree in [1, 2, 3, 5]:
    clf = svm.SVC(kernel='poly', degree=degree, coef0=1.0, C=1.0).fit(X_train, y_train)
    acc = accuracy_score(y_test, clf.predict(X_test))
    print(f'多项式核 degree={degree}: 测试准确率={acc:.3f}')
print('同心圆 x²+y²=r² 是二次关系 → degree=2 即可很好分开')
```

## SVR

支持向量回归（Support Vector Regression，SVR）把 SVM 的「最大间隔」思想搬到回归：拟合一条「带宽带」的函数，落在带宽 ε 内的样本不计损失，只对偏离超过 ε 的样本施加惩罚。它对异常值鲁棒，能产生稀疏解。

```text
数学定义（ε 不敏感损失）：
L_ε(y, f(x)) = max(0, |y - f(x)| - ε)

目标：
min (1/2)‖w‖² + C·Σ (ξ_i + ξ_i*)

参数：
- ε（epsilon）—— 允许的误差带宽，越大越宽容
- C —— 对超出带宽样本的惩罚力度
- 核 —— 线性核/多项式/RBF 均可

特点：只有偏离超过 ε 的样本才是「支持向量」，故稀疏
```

```python
import numpy as np
from sklearn.svm import SVR
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

np.random.seed(0)
X = np.sort(np.random.rand(200, 1) * 10, axis=0)
y = np.sin(X).ravel() + np.random.randn(200) * 0.2
# 加入几个异常点
y[::50] += 3

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

for kernel in ['linear', 'rbf']:
    svr = SVR(kernel=kernel, C=10, epsilon=0.2, gamma='scale').fit(X_train, y_train)
    mse = mean_squared_error(y_test, svr.predict(X_test))
    print(f'SVR kernel={kernel:>6}: 测试MSE={mse:.4f}  支持向量数={len(svr.support_)}')
```

## One-Class SVM

单类 SVM（One-Class SVM）是无监督异常检测算法：把「正常数据」尽量包进一个高维空间里的球/超平面边界，把边界外的点判为异常。它只需正常样本即可训练，不需要标注异常，适合「异常稀少且多样」的场景。

```text
数学定义（ν-SVM 形式）：
把数据映射到高维，寻找一个超平面把原点与数据尽可能分开，
即 f(x) = w·φ(x) - ρ，f(x) < 0 判为异常。

关键参数：
- ν（nu）—— 异常比例的上界，也是支持向量比例的下界
- γ —— RBF 核的影响半径

适用：正负样本极度不平衡、异常样本难获取的异常检测
```

```python
import numpy as np
from sklearn.svm import OneClassSVM

np.random.seed(42)
# 正常数据聚集在两个中心附近
X_normal = np.vstack([np.random.randn(300, 2) + [0, 0],
                      np.random.randn(300, 2) + [5, 5]])
# 异常数据散落在远处
X_outliers = np.random.uniform(-3, 8, (30, 2))

ocsvm = OneClassSVM(kernel='rbf', gamma='scale', nu=0.05).fit(X_normal)
# 训练数据应预测为 1（正常），异常为 -1
pred_normal = ocsvm.predict(X_normal)
pred_outliers = ocsvm.predict(X_outliers)
print(f'正常数据被误判为异常的比例: {(pred_normal == -1).mean():.3f}')
print(f'异常数据被正确检出的比例: {(pred_outliers == -1).mean():.3f}')
```

## Kernel PCA

核 PCA（Kernel PCA）把核技巧用于主成分分析，在「高维核空间」中做线性 PCA，等价于在原空间做非线性降维。它能发现线性 PCA 无法捕捉的非线性结构（如环形、螺旋形数据）。

```text
核心思想：
1. 用核函数构造核矩阵 K_ij = K(x_i, x_j)
2. 中心化核矩阵
3. 对中心化核矩阵做特征分解，取前 k 个主成分

与 PCA 对比：
- PCA 在原空间找线性主方向
- Kernel PCA 在核特征空间找主方向 → 原空间非线性

应用：非线性降维、去噪、为后续分类提取非线性特征
```

```python
import numpy as np
from sklearn.decomposition import KernelPCA, PCA
from sklearn.datasets import make_circles
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# 同心圆数据：线性 PCA 无法分开，Kernel PCA 可以
X, y = make_circles(n_samples=400, noise=0.05, factor=0.4, random_state=0)

kpca = KernelPCA(n_components=2, kernel='rbf', gamma=1.0)
X_kpca = kpca.fit_transform(X)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# 用降维后第一主成分能否区分两类来验证
from sklearn.metrics import accuracy_score
from sklearn.linear_model import LogisticRegression

for name, Xr in [('PCA', X_pca), ('Kernel PCA', X_kpca)]:
    clf = LogisticRegression(max_iter=1000).fit(Xr, y)
    acc = accuracy_score(y, clf.predict(Xr))
    print(f'{name} 降维后线性分类准确率: {acc:.3f}')
print('结论：同心圆是非线性结构，Kernel PCA 降维后线性可分，PCA 不行')
```

## 应用场景实战

### 场景一：SVM 完整调参流水线（核 + C + gamma 网格搜索）

```python
import numpy as np
from sklearn import svm
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.metrics import classification_report

X, y = load_breast_cancer(return_X_y=True)
y = np.where(y == 0, -1, 1)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

# SVM 对特征尺度敏感，必须标准化
pipe = make_pipeline(StandardScaler(), svm.SVC())
param_grid = {
    'svc__kernel': ['linear', 'rbf'],
    'svc__C': [0.1, 1, 10, 100],
    'svc__gamma': [0.001, 0.01, 0.1, 1],
}
grid = GridSearchCV(pipe, param_grid, cv=5, scoring='accuracy')
grid.fit(X_train, y_train)
print(f'最优参数: {grid.best_params_}')
print(f'最优交叉验证准确率: {grid.best_score_:.3f}')
print(f'测试集准确率: {grid.score(X_test, y_test):.3f}')
```

### 场景二：One-Class SVM 工业异常检测

```python
import numpy as np
from sklearn.svm import OneClassSVM
from sklearn.metrics import confusion_matrix

np.random.seed(0)
# 正常工况：温度与振动围绕标称值小幅波动
normal = np.random.randn(500, 2) * [1.5, 0.8] + [60, 10]
# 异常工况：明显偏离
anomaly = np.random.randn(50, 2) * [2, 1] + [75, 25]

X_all = np.vstack([normal, anomaly])
y_true = np.hstack([np.ones(500), -np.ones(50)])   # 1=正常 -1=异常

ocsvm = OneClassSVM(kernel='rbf', gamma='scale', nu=0.08).fit(normal)
y_pred = ocsvm.predict(X_all)

tn, fp, fn, tp = confusion_matrix(y_true, y_pred, labels=[1, -1]).ravel()
print(f'真正常={tn}  假异常={fp}  假正常={fn}  真异常={tp}')
print(f'异常检出率(召回): {tp / (tp + fn):.2%}')
print(f'正常误报率: {fp / (fp + tn):.2%}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. SVM 对特征尺度极其敏感，建模前务必 StandardScaler 标准化，否则间隔被大尺度特征主导
2. 先跑线性核（快、可解释），效果不够再上 RBF 核，别一上来就用 RBF
3. RBF 核必须联合调 C 和 gamma，用对数网格 + 交叉验证搜索
4. 数据量大（样本几十万级）时 SVM 训练慢，优先用 LinearSVC（线性）或换 GBDT/神经网络
5. 样本数远小于特征数（如文本、基因）时线性核 SVM 通常最好，天然抗高维
6. gamma 过大会过拟合，特征少时用 gamma='scale'（sklearn 默认）通常更稳
7. One-Class SVM 的 nu 是「异常比例上界」，用领域知识或历史异常率设定
8. Kernel PCA 降维前同样要标准化，且核与参数要用下游任务效果来选

### 踩坑记录

```text
坑 1：不标准化就上 RBF SVM
结论：某特征量纲是其它特征的 100 倍，SVM 决策边界完全被它主导。
原因：RBF 核的 ‖x-z‖² 对量纲敏感，大尺度特征淹没小尺度特征。
解法：建模前 StandardScaler，且测试时用训练集拟合的 scaler 变换。

坑 2：C 和 gamma 只调一个
结论：固定 gamma 调 C，或固定 C 调 gamma，永远找不到最优组合。
原因：C（间隔 vs 错误）和 gamma（边界复杂度）强耦合，存在联合最优。
解法：用 GridSearchCV 对 (C, gamma) 做二维对数网格搜索。

坑 3：大数据集硬上非线性 SVC
结论：几十万样本跑 RBF 核，训练数小时甚至内存爆掉。
原因：核 SVM 复杂度 O(n²)~O(n³)，样本多时不可行。
解法：大数据用 LinearSVC/SGDClassifier（线性），或用近似核方法、换 GBDT。

坑 4：One-Class SVM 的 nu 拍脑袋设太高
结论：nu=0.5 时把一半正常数据都判成异常，误报爆炸。
原因：nu 是异常比例上界，设太大意味着「预期一半都是异常」。
解法：nu 用历史异常率或业务可容忍误报率设定，配合验证集调优。

坑 5：Kernel PCA 选核不当导致降维失效
结论：用线性核做 Kernel PCA 去处理环形数据，降维后仍线性不可分。
原因：线性核 Kernel PCA 退化为普通 PCA，无法捕捉非线性流形。
解法：先可视化判断数据结构，非线性的用 RBF 核，用下游任务效果验证核选择。
```
