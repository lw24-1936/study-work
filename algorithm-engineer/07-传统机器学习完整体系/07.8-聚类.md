## 概述

聚类是无监督学习的核心任务：在没有标签的情况下，把样本分成若干组，让组内相似、组间差异大。不同聚类算法对「簇」的形状假设不同——K-Means 假设簇是球形、大小相近，DBSCAN 假设簇是任意形状的高密度区域，GMM 假设数据由多个高斯分布混合生成。选对算法，取决于你对数据分布的先验理解。

```text
聚类算法的分类与特点：
1. 划分式（K-Means/K-Medoids）—— 预先指定簇数，迭代分配与更新
2. 密度式（DBSCAN/HDBSCAN/OPTICS）—— 按密度连通性找簇，能发现任意形状
3. 层次式（Hierarchical）—— 自底向上/自顶向下合并或分裂，得到树状结构
4. 模型式（GMM）—— 用概率模型拟合，给出软分配（每个点属于每簇的概率）
```

```python
from sklearn.cluster import KMeans
import numpy as np

# 聚类最小示例：把 2 维点聚成 3 类
X = np.r_[np.random.randn(50, 2) + [2, 2],
          np.random.randn(50, 2) + [-2, -2],
          np.random.randn(50, 2) + [2, -2]]
kmeans = KMeans(n_clusters=3, random_state=0, n_init=10).fit(X)
print(kmeans.labels_[:5])       # 每个样本的簇标签
print(kmeans.cluster_centers_)  # 三个簇中心
```

## K-Means

K-Means 是最经典的划分式聚类：先随机选 K 个中心，然后反复「分配样本到最近中心 → 用均值更新中心」，直到收敛。它优化的是簇内平方和（inertia），即每个点到其所属中心的距离平方之和。

```text
K-Means 算法步骤：
1. 初始化 —— 随机选 K 个样本作为初始中心
2. 分配 —— 每个样本归到最近的中心
3. 更新 —— 每簇的中心 = 该簇所有样本的均值
4. 迭代 —— 重复 2~3 步直到中心不再变化或达到最大迭代次数

目标函数（inertia）：
J = Σ Σ ‖x - μ_k‖²（每个样本到其簇中心的平方距离之和）
```

```python
import numpy as np

def kmeans_manual(X, k, max_iter=100, tol=1e-4):
    rng = np.random.default_rng(0)
    centers = X[rng.choice(len(X), k, replace=False)]   # 随机初始化
    for _ in range(max_iter):
        # 分配：每个点到最近中心
        dists = ((X[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2)
        labels = dists.argmin(axis=1)
        # 更新：每簇均值
        new_centers = np.array([X[labels == j].mean(axis=0) for j in range(k)])
        if np.abs(new_centers - centers).max() < tol:
            break
        centers = new_centers
    return labels, centers

labels, centers = kmeans_manual(X, k=3)
print('手写 K-Means 中心:\n', centers)
```

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

kmeans = KMeans(n_clusters=3, init='k-means++', n_init=10, random_state=0).fit(X)
print('inertia:', kmeans.inertia_)
print('轮廓系数:', silhouette_score(X, kmeans.labels_))
```

```text
K-Means 的优缺点：
1. 优点 —— 简单快速，可扩展性好（MiniBatch），对球形簇效果好
2. 缺点 —— 需预设 K，对初始中心敏感，只能发现凸/球形簇，对异常值敏感
3. 局限 —— 无法处理任意形状、密度不均、大小差异大的簇
```

## K-Means++

K-Means++ 是一种更聪明的初始化策略：不是随机选 K 个中心，而是「选得越分散越好」——下一个中心倾向于选离已有中心较远的样本。这避免了随机初始化可能落在同一簇里的问题，显著提升收敛速度和最终质量。

```text
K-Means++ 初始化步骤：
1. 随机选第一个中心
2. 对每个样本，计算它到「最近已选中心」的距离 D(x)²
3. 按 D(x)² 作为概率分布，随机选下一个中心（越远越可能被选）
4. 重复 2~3 步直到选出 K 个中心

为什么更好：
1. 中心初始分布更分散，覆盖不同簇
2. 减少陷入局部最优的概率
3. 理论上有 O(log K) 的近似保证
```

```python
import numpy as np

def kmeans_plusplus_init(X, k):
    rng = np.random.default_rng(42)
    centers = [X[rng.integers(len(X))]]              # 第一个随机
    for _ in range(1, k):
        d2 = np.array([min(((x - c) ** 2).sum() for c in centers) for x in X])
        probs = d2 / d2.sum()
        centers.append(X[rng.choice(len(X), p=probs)])
    return np.array(centers)

centers = kmeans_plusplus_init(X, k=3)
print('K-Means++ 初始中心:\n', centers)
```

```python
from sklearn.cluster import KMeans

# sklearn 默认 init='k-means++'，直接对比随机初始化
kmeans_pp = KMeans(n_clusters=3, init='k-means++', n_init=10, random_state=0).fit(X)
kmeans_rand = KMeans(n_clusters=3, init='random', n_init=10, random_state=0).fit(X)
print('K-Means++ inertia:', kmeans_pp.inertia_)
print('随机初始化 inertia:', kmeans_rand.inertia_)
```

## K-Medoids

K-Medoids（PAM）和 K-Means 类似，但簇中心必须是「真实存在的样本点」（medoid），而不是所有样本的均值。这让它对异常值和噪声更鲁棒，且能用在只有「样本间距离」而没有坐标（如字符串、图）的场景。

```text
K-Medoids 与 K-Means 的区别：
1. 中心 —— K-Means 用均值（可能不是真实样本），K-Medoids 用真实样本
2. 鲁棒性 —— medoid 受异常值影响小，K-Means 均值会被异常值拉偏
3. 距离 —— K-Medoids 只需样本间距离矩阵，可处理非数值数据
4. 代价 —— 每次更新要遍历找最优 medoid，计算量更大
```

```python
from sklearn_extra.cluster import KMedoids
import numpy as np

# 加入一个远距离异常点，观察两种方法对它的敏感度
X_out = np.r_[X, [[100, 100]]]

kmedoids = KMedoids(n_clusters=3, random_state=0, method='pam').fit(X_out)
kmeans = KMeans(n_clusters=3, random_state=0, n_init=10).fit(X_out)

# medoid 是真实样本，异常点只会单独成簇或附着，不会拖偏其他簇
print('K-Medoids 各簇中心（真实样本）:\n', kmedoids.cluster_centers_)
print('K-Means 各簇中心（可能被拉偏）:\n', kmeans.cluster_centers_)
```

```text
K-Medoids 常用场景：
1. 数据含明显异常值或噪声
2. 只有距离/相似度矩阵，没有向量坐标
3. 需要簇中心本身是「有代表性的真实样本」（如代表性文档、代表性用户）
```

## DBSCAN

DBSCAN 是基于密度的聚类：把「密度足够高」的区域连成一个簇，把密度稀疏区域的点标记为噪声。它有两个参数 eps（邻域半径）和 min_samples（核心点至少需要的邻居数），能发现任意形状的簇，且自动识别异常点。

```text
DBSCAN 的核心概念：
1. 核心点（core）—— 邻域 eps 内样本数 ≥ min_samples
2. 边界点（border）—— 不是核心点，但在某个核心点的邻域内
3. 噪声点（noise）—— 既不是核心点也不是边界点，标签为 -1

算法过程：
1. 找所有核心点
2. 从每个核心点出发，把密度可达的点连成簇
3. 剩余未被覆盖的点标记为噪声
```

```python
from sklearn.cluster import DBSCAN
import numpy as np
from sklearn.datasets import make_moons

# 月牙形数据：K-Means 无法分开，DBSCAN 可以
X_moon, _ = make_moons(n_samples=300, noise=0.06, random_state=0)

dbscan = DBSCAN(eps=0.2, min_samples=5).fit(X_moon)
n_clusters = len(set(dbscan.labels_)) - (1 if -1 in dbscan.labels_ else 0)
n_noise = np.sum(dbscan.labels_ == -1)
print(f'DBSCAN 找到 {n_clusters} 个簇，噪声点 {n_noise} 个')

kmeans = KMeans(n_clusters=2, n_init=10, random_state=0).fit(X_moon)
print('K-Means 在月牙数据上的轮廓系数:', silhouette_score(X_moon, kmeans.labels_).round(3))
print('DBSCAN 在月牙数据上的轮廓系数:', silhouette_score(X_moon, dbscan.labels_).round(3))
```

```text
DBSCAN 的优缺点：
1. 优点 —— 无需预设簇数，能发现任意形状，天然抗噪
2. 缺点 —— eps/min_samples 难调，对密度不均的数据效果差
3. 高维陷阱 —— 高维下距离趋同，密度概念失效，需先降维
```

## HDBSCAN

HDBSCAN 是 DBSCAN 的升级版：不用固定 eps，而是对「密度层级」进行聚类，自动选择最稳定的簇，天然处理密度不均的数据，并且给出每个点的簇归属概率。它只需一个参数 min_cluster_size。

```text
HDBSCAN 的核心思想：
1. 密度估计 —— 用互达距离（mutual reachability）衡量密度
2. 构建最小生成树 —— 在密度空间里连点
3. 层次聚类 —— 把树按密度从高到低拆解，形成簇的层级
4. 稳定性选择 —— 选「寿命」最长的簇，天然确定簇数

相比 DBSCAN：
1. 不需要调 eps，只需 min_cluster_size
2. 能处理密度不均匀的簇
3. 输出软分配概率，可识别「边界模糊」的点
```

```python
import hdbscan

# 构造密度不均的数据：一个密簇 + 一个疏簇
X_dense = np.random.randn(100, 2) * 0.5 + [0, 0]
X_sparse = np.random.randn(100, 2) * 2.0 + [8, 8]
X_mixed = np.r_[X_dense, X_sparse]

clusterer = hdbscan.HDBSCAN(min_cluster_size=15).fit(X_mixed)
print('簇标签:', np.unique(clusterer.labels_))
print('每个点的簇归属概率（前 5）:', clusterer.probabilities_[:5])
```

## OPTICS

OPTICS 和 DBSCAN 同属密度聚类，但通过「可达距离」的排序，一次性刻画出所有密度层级下的聚类结构（可达性图 reachability plot）。它不直接输出簇标签，而是输出一个「可达距离」序列，配合不同 eps 阈值可以提取出不同粒度的簇。

```text
OPTICS 的核心概念：
1. 核心距离 —— 某点成为核心点所需的最小半径（到第 min_samples 近邻的距离）
2. 可达距离 —— 从核心点到邻点的距离，取 max(核心距离, 实际距离)
3. 可达性图 —— 按访问顺序画可达距离，山谷代表簇，峰代表簇间间隔

与 DBSCAN 的关系：
1. DBSCAN —— 固定一个 eps，只看一个密度层级
2. OPTICS —— 计算所有密度层级，用 eps 提取时不再重新扫描
```

```python
from sklearn.cluster import OPTICS

# 对密度不均数据，OPTICS 的可达性图能同时揭示密簇和疏簇
optics = OPTICS(min_samples=5, xi=0.05, min_cluster_size=0.1).fit(X_mixed)
print('OPTICS 簇标签:', np.unique(optics.labels_))
print('可达距离序列长度:', len(optics.reachability_))
print('样本访问顺序:', optics.ordering_[:10])
```

```text
OPTICS 的优缺点：
1. 优点 —— 不依赖 eps，能揭示多密度层级，对参数相对鲁棒
2. 缺点 —— 计算比 DBSCAN 更重，可达性图解释需要经验
3. 适用 —— 密度差异大、簇形状复杂、想探索层级结构的场景
```

## Hierarchical Clustering

层次聚类通过反复合并（凝聚）或分裂（分裂）构建一棵聚类树（dendrogram）。凝聚法从每个点自成一簇开始，每次合并最相似的两簇，直到只剩一个簇；用不同阈值横切树，得到不同数量的簇。

```text
层次聚类的关键点：
1. 凝聚（agglomerative）—— 自底向上合并，最常用
2. 分裂（divisive）—— 自顶向下分裂，计算更贵
3. 链接方式（linkage）—— 决定如何度量「簇与簇」的距离：
   - single —— 最近点对距离（对噪声敏感，链式效应）
   - complete —— 最远点对距离（产生紧凑簇）
   - average —— 平均点对距离（折中）
   - ward —— 最小化簇内方差增量（最常用）
```

```python
from sklearn.cluster import AgglomerativeClustering
from scipy.cluster.hierarchy import dendrogram, linkage
import matplotlib.pyplot as plt

# 凝聚聚类
agg = AgglomerativeClustering(n_clusters=3, linkage='ward').fit(X)
print('凝聚聚类标签:', agg.labels_[:5])

# 画树状图 dendrogram
Z = linkage(X, method='ward')
plt.figure(figsize=(8, 4))
dendrogram(Z, truncate_mode='level', p=5)
plt.title('Hierarchical Clustering Dendrogram')
plt.xlabel('样本索引')
plt.ylabel('距离')
plt.tight_layout()
plt.savefig('/tmp/dendrogram.png', dpi=100)
print('树状图已保存到 /tmp/dendrogram.png')
```

```text
层次聚类的优缺点：
1. 优点 —— 不需要预设簇数（看树状图切），能揭示层级结构，可解释性强
2. 缺点 —— O(N²) 或更高复杂度，大数据不可行；一旦合并无法撤销
3. 适用 —— 中小规模数据、想理解簇的层次关系、生物信息学谱系分析
```

## GMM

GMM（高斯混合模型）假设数据由 K 个高斯分布混合生成，用 EM 算法估计每个高斯分布的均值、协方差和权重。它给出「软分配」——每个点属于每个簇的概率，且能刻画椭圆形的、带相关性的簇，比 K-Means 的硬分配更灵活。

```text
GMM 的核心思想：
1. 模型 —— p(x) = Σ π_k · N(x | μ_k, Σ_k)
2. 参数 —— 每簇的权重 π_k、均值 μ_k、协方差 Σ_k
3. EM 算法 —— E 步算每个点属于每簇的后验概率，M 步更新参数
4. 软分配 —— 输出概率而非硬标签

与 K-Means 的关系：
1. K-Means —— GMM 在「各簇等协方差、球对称」下的特例（硬分配极限）
2. GMM —— 用协方差刻画簇的形状与方向，更通用
```

```python
from sklearn.mixture import GaussianMixture

# 用带相关性的椭圆簇，GMM 能学出协方差方向
mean1 = [0, 0]
cov1 = [[1.0, 0.8], [0.8, 1.0]]
mean2 = [5, 5]
cov2 = [[1.0, -0.6], [-0.6, 1.0]]
X_gmm = np.r_[np.random.multivariate_normal(mean1, cov1, 200),
              np.random.multivariate_normal(mean2, cov2, 200)]

gmm = GaussianMixture(n_components=2, covariance_type='full', random_state=0).fit(X_gmm)
probs = gmm.predict_proba(X_gmm)
print('软分配概率（前 3 行）:\n', probs[:3])
print('簇权重:', gmm.weights_)
print('对数似然:', gmm.score(X_gmm).round(2))
```

```python
# 用 BIC/AIC 自动选簇数
bics = [GaussianMixture(n_components=k, random_state=0).fit(X_gmm).bic(X_gmm)
        for k in range(1, 6)]
print('各 K 的 BIC:', [round(b, 1) for b in bics])
print('最优 K:', np.argmin(bics) + 1)   # BIC 最小对应最优
```

## 应用场景实战

### 场景一：客户分群

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import numpy as np

# 模拟用户特征：消费金额、消费频次、最近一次消费（RFM）
rng = np.random.default_rng(42)
n = 1000
recency = rng.gamma(2, 10, n)          # 最近一次购买距今天数
frequency = rng.poisson(5, n)          # 购买频次
monetary = rng.gamma(3, 100, n)        # 消费金额
X_rfm = np.c_[recency, frequency, monetary]

X_scaled = StandardScaler().fit_transform(X_rfm)
# 用肘部法辅助选 K
inertias = [KMeans(n_clusters=k, n_init=10, random_state=0).fit(X_scaled).inertia_
            for k in range(1, 9)]
print('inertia 序列:', [round(i) for i in inertias])

kmeans = KMeans(n_clusters=4, n_init=10, random_state=0).fit(X_scaled)
print('各簇人数:', np.bincount(kmeans.labels_))
print('各簇中心（标准化后）:\n', kmeans.cluster_centers_.round(2))
```

### 场景二：地理坐标聚类 + 噪声识别

```python
from sklearn.cluster import DBSCAN
import numpy as np

# 模拟 POI 坐标：三个密集区域 + 散布噪声
rng = np.random.default_rng(1)
clusters = [rng.normal(loc, 0.01, (80, 2))
            for loc in [[39.90, 116.40], [39.95, 116.45], [39.85, 116.50]]]
noise = rng.uniform([39.8, 116.3], [40.0, 116.6], (30, 2))
X_geo = np.r_[clusters[0], clusters[1], clusters[2], noise]

db = DBSCAN(eps=0.02, min_samples=5).fit(X_geo)
n_noise = np.sum(db.labels_ == -1)
n_clusters = len(set(db.labels_)) - (1 if -1 in db.labels_ else 0)
print(f'识别出 {n_clusters} 个热点区域，{n_noise} 个噪声点')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 聚类前一定标准化，K-Means/GMM/层次聚类都对量纲敏感
2. 不确定簇数时，用肘部法 + 轮廓系数 + BIC/AIC 综合判断，别只信一个
3. 数据形状未知时先 DBSCAN/HDBSCAN 探索，别默认 K-Means
4. K-Means 用 k-means++ 初始化 + 多次 n_init，避免局部最优
5. 数据含噪声/异常值时优先 K-Medoids 或 DBSCAN，别硬用 K-Means
6. 高维数据先降维再聚类，距离在高维下会失效
7. GMM 用 BIC 选簇数，且注意 covariance_type（full/tied/diag）的选择
8. 聚类结果一定要做业务可解释性验证，无监督没有「正确」答案

### 踩坑记录

```text
坑 1：不标准化就聚类
结论：量纲大的特征主导距离，簇的划分被单一特征绑架。
原因：K-Means 的欧氏距离对每个维度平方求和，量纲差异被放大。
解法：StandardScaler 或 MinMaxScaler，聚类后再把中心映射回原量纲解释。

坑 2：K-Means 预设 K 不验证
结论：K 取错时簇要么被强行合并、要么被无意义拆碎，业务解释不通。
原因：K-Means 强制输出恰好 K 个簇，没有「该不该成簇」的判断。
解法：肘部法 + 轮廓系数 + 业务理解综合定 K，或改用 DBSCAN/HDBSCAN。

坑 3：DBSCAN 在高维特征上直接跑
结论：所有点距离趋同，eps 稍微变化簇数量剧烈波动，结果无意义。
原因：高维下距离度量失去区分度（维度灾难）。
解法：先 PCA/t-SNE/UMAP 降维，再 DBSCAN 聚类。

坑 4：忽略异常点/噪声
结论：K-Means 均值中心被极端值拉偏，簇边界失真。
原因：均值对离群值不鲁棒，一个极端点能拖动整簇中心。
解法：先用 DBSCAN 或 IQR/Z-Score 识别并处理噪声，或换 K-Medoids。

坑 5：混淆软分配与硬标签
结论：把 GMM 的概率最大值当成高置信度，忽略边界模糊的样本。
原因：GMM 是软分配，某点对两簇各 0.5 时硬分类不稳定。
解法：对低置信度样本（最大概率 < 阈值）单独标记，或用于后续人工审核。
```
