## 概述

概率模型用「概率」的语言描述数据与标签的关系，不仅给出预测结果，还给出不确定性（概率值）。它分为两类：判别式模型直接建模 P(y|x)，生成式模型建模联合分布 P(x,y) 再用贝叶斯反推 P(y|x)。概率模型天然擅长处理不确定性、缺失数据和小样本，是文本分类、聚类、序列标注等任务的经典工具。

```text
概率模型的核心脉络：
1. 生成式 vs 判别式 —— 建模 P(x,y) 还是直接建模 P(y|x)
2. 朴素贝叶斯 —— 条件独立假设下的快速生成式分类
3. GMM + EM —— 含隐变量的高斯混合聚类
4. HMM / CRF —— 序列数据的概率建模（生成式/判别式）
5. 贝叶斯网络 —— 用图结构刻画变量间的条件依赖
```

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.datasets import make_classification

# 概率模型：不仅输出类别，还输出概率
X, y = make_classification(n_samples=500, n_features=8, random_state=0)
gnb = GaussianNB().fit(X, y)
proba = gnb.predict_proba(X[:3])
print('概率模型输出各类别概率:\n', np.round(proba, 3))
```

## Naive Bayes

朴素贝叶斯（Naive Bayes）是基于贝叶斯定理 + 「特征条件独立」假设的分类器。虽然「朴素」的独立假设现实中常不成立，但它计算快、样本需求少、天然输出概率，在高维稀疏数据（如文本）上表现极好。

```text
数学定义：
P(y|x) = P(y) · P(x|y) / P(x)  ∝  P(y) · Π_j P(x_j | y)

其中「朴素」指：给定类别 y，各特征 x_j 相互独立，
所以联合似然可分解为各特征似然的乘积。

分类决策：
ŷ = argmax_y P(y) · Π_j P(x_j | y)

三种常见变体：
1. Gaussian NB —— 特征为连续值，假设服从高斯分布
2. Multinomial NB —— 特征为计数（词频），服从多项式分布
3. Bernoulli NB —— 特征为 0/1（词是否出现），服从伯努利分布
```

```python
import numpy as np

# 朴素贝叶斯手写（离散特征版本）
class NaiveBayes:
    def fit(self, X, y):
        self.classes = np.unique(y)
        self.priors = np.array([np.mean(y == c) for c in self.classes])
        self.cond_probs = {}
        for c in self.classes:
            Xc = X[y == c]
            # 拉普拉斯平滑，避免概率为 0
            self.cond_probs[c] = (Xc.sum(axis=0) + 1) / (Xc.sum() + X.shape[1])
        return self

    def predict(self, X):
        log_prior = np.log(self.priors)
        scores = []
        for c in self.classes:
            p = self.cond_probs[c]
            # 用对数防止下溢
            score = log_prior[c] + (X * np.log(p) + (1 - X) * np.log(1 - p)).sum(axis=1)
            scores.append(score)
        return self.classes[np.argmax(np.array(scores), axis=0)]

X = np.array([[1, 1, 0], [1, 0, 0], [0, 1, 1], [0, 0, 1], [1, 1, 1], [0, 1, 0]])
y = np.array([1, 1, 0, 0, 1, 0])
nb = NaiveBayes().fit(X, y)
print('手写朴素贝叶斯预测:', nb.predict(X))
```

## Gaussian NB

高斯朴素贝叶斯（Gaussian NB）假设每个类别的每个特征都服从高斯分布，用该类样本的均值和方差估计分布参数。适合特征为连续值、且大致服从正态分布的场景。

```text
数学定义：
P(x_j | y=c) = N(x_j; μ_cj, σ²_cj)

参数估计（极大似然）：
μ_cj = 该类第 j 个特征的均值
σ²_cj = 该类第 j 个特征的方差（sklearn 默认加 var_smoothing 平滑）

特点：
1. 快 —— 只需算均值和方差，训练 O(n·d)
2. 简单 —— 参数极少，小样本也能用
3. 局限 —— 特征不服从高斯分布时效果下降
```

```python
import numpy as np
from sklearn.naive_bayes import GaussianNB
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

gnb = GaussianNB().fit(X_train, y_train)
print(f'Gaussian NB 准确率: {accuracy_score(y_test, gnb.predict(X_test)):.3f}')
print('各类别各特征的均值 theta_ shape:', gnb.theta_.shape)
print('各类别各特征的方差 var_ shape:', gnb.var_.shape)
```

## Multinomial NB

多项式朴素贝叶斯（Multinomial NB）假设特征服从多项式分布，适合「计数型」特征，是文本分类的事实标准 baseline（配合 TF 或词频）。它天然适应高维稀疏的词袋表示。

```text
数学定义：
P(x | y=c) = (Σ x_j)! / Π x_j! · Π θ_cj^(x_j)

其中 θ_cj = 类别 c 下特征 j 出现的概率，
用 (计数 + α) / (总计数 + α·d) 估计（α 为拉普拉斯平滑）。

适用场景：
1. 文本分类 —— 词频、TF-IDF 表示
2. 计数特征 —— 事件发生次数、商品销量档位
3. 高维稀疏 —— 每篇文档只有少数词非零
```

```python
from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 文本分类最小示例
docs = [
    'this movie is great and wonderful', 'what a fantastic film',
    'this movie is boring and bad', 'a terrible waste of time',
    'great acting in a wonderful story', 'bad plot terrible acting',
    'I loved this movie so much', 'I hated every minute of it',
]
labels = ['pos', 'pos', 'neg', 'neg', 'pos', 'neg', 'pos', 'neg']

vec = CountVectorizer()
X = vec.fit_transform(docs)
X_train, X_test, y_train, y_test = train_test_split(X, labels, test_size=0.25, random_state=0)

mnb = MultinomialNB(alpha=1.0).fit(X_train, y_train)
print(f'Multinomial NB 文本分类准确率: {accuracy_score(y_test, mnb.predict(X_test)):.3f}')
```

## Bayesian Model

贝叶斯模型（Bayesian Model）与「频率派」相对，把模型参数 θ 本身也看作随机变量，赋予先验分布 P(θ)，用贝叶斯定理结合数据更新为后验 P(θ|D)。预测时对所有可能的 θ 求期望，而非只用单个点估计，从而天然刻画不确定性。

```text
核心公式（贝叶斯定理）：
P(θ|D) = P(D|θ) · P(θ) / P(D)  ∝  似然 × 先验

频率派 vs 贝叶斯派：
- 频率派：θ 是固定未知量，用点估计（MLE）
- 贝叶斯派：θ 是随机变量，用后验分布

关键要素：
1. 先验 P(θ) —— 看到数据前对参数的信念
2. 似然 P(D|θ) —— 数据在参数下的概率
3. 后验 P(θ|D) —— 结合数据后的更新信念
4. 后验预测 —— P(y|x,D) = ∫ P(y|x,θ) P(θ|D) dθ
```

```python
import numpy as np

# 贝叶斯更新：估计硬币正面概率（Beta 分布共轭先验）
def beta_update(alpha, beta, heads, tails):
    """Beta(α,β) 先验，观测 heads 个正面、tails 个反面后的后验"""
    return alpha + heads, beta + tails

# 先验 Beta(1,1) = 均匀分布，逐次观测更新
alpha, beta = 1.0, 1.0
observations = [1, 1, 0, 1, 0, 1, 1, 1]   # 1=正面 0=反面
for obs in observations:
    alpha, beta = beta_update(alpha, beta, heads=obs, tails=1 - obs)
posterior_mean = alpha / (alpha + beta)
print(f'后验 Beta({alpha}, {beta})，正面概率后验均值 = {posterior_mean:.3f}')
print('说明：先验 Beta(1,1) 结合 8 次观测，得到对正面概率的完整后验分布')
```

## GMM

高斯混合模型（Gaussian Mixture Model，GMM）用 K 个高斯分布的加权和来拟合数据的分布，可以看作「软聚类」：每个样本以一定概率属于各个高斯成分。它比 KMeans 更灵活，能表达非球形、带重叠的簇。

```text
数学定义：
P(x) = Σ_k π_k · N(x; μ_k, Σ_k)

其中：
- π_k —— 第 k 个成分的混合权重（Σπ_k = 1）
- μ_k, Σ_k —— 第 k 个高斯成分的均值与协方差

软分配（后验隶属概率）：
γ_k(x) = π_k·N(x; μ_k,Σ_k) / Σ_j π_j·N(x; μ_j,Σ_j)

参数学习：用 EM 算法迭代估计 {π_k, μ_k, Σ_k}
```

```python
import numpy as np
from sklearn.mixture import GaussianMixture
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

np.random.seed(0)
# 生成三个高斯簇混合的数据
X1 = np.random.randn(200, 2) + [0, 0]
X2 = np.random.randn(200, 2) + [5, 5]
X3 = np.random.randn(200, 2) + [0, 5]
X = np.vstack([X1, X2, X3])

gmm = GaussianMixture(n_components=3, random_state=0).fit(X)
labels = gmm.predict(X)
proba = gmm.predict_proba(X)
print('GMM 混合权重:', np.round(gmm.weights_, 3))
print('GMM 均值:\n', np.round(gmm.means_, 2))
print('软分配：某样本属于 3 个成分的概率:', np.round(proba[0], 3))
```

## EM

EM 算法（Expectation-Maximization，期望最大化）用于求解「含隐变量」模型的最大似然估计。当数据不完整（有隐变量）时，直接最大化似然很困难，EM 通过「E 步求期望、M 步最大化」交替迭代逼近最优解。GMM、HMM、缺失数据填补都靠它。

```text
EM 两步迭代：
E 步（Expectation）—— 用当前参数估计隐变量的后验分布 Q(z) = P(z|x, θ^t)
M 步（Maximization）—— 固定 Q，最大化「期望似然」更新参数 θ

数学本质：
最大化对数似然的下界（ELBO）：
log P(x|θ) ≥ E_{Q(z)}[log P(x,z|θ)] - E_{Q(z)}[log Q(z)]

单调性：每轮迭代对数似然不降，收敛到局部最优
```

```python
import numpy as np

# EM 算法手写：估计两枚硬币的正面概率（经典抛硬币示例）
np.random.seed(0)
# 真实参数：硬币 A 正面概率 0.6，硬币 B 正面概率 0.3
true_p = [0.6, 0.3]
# 每次随机选一枚硬币抛 10 次，记录正面数（隐变量是「选了哪枚」）
n_rounds, n_toss = 100, 10
heads = []
for _ in range(n_rounds):
    coin = np.random.choice(2)
    heads.append(np.random.binomial(n_toss, true_p[coin]))
heads = np.array(heads)

# EM 估计两枚硬币的概率
pa, pb = 0.5, 0.5
for _ in range(50):
    # E 步：计算每轮数据来自硬币 A 的后验概率
    like_a = pa ** heads * (1 - pa) ** (n_toss - heads)
    like_b = pb ** heads * (1 - pb) ** (n_toss - heads)
    w_a = like_a / (like_a + like_b)
    # M 步：用加权计数更新概率
    pa = np.sum(w_a * heads) / (n_toss * np.sum(w_a))
    pb = np.sum((1 - w_a) * heads) / (n_toss * np.sum(1 - w_a))

print(f'EM 估计硬币 A 概率: {pa:.3f}（真实 0.6）')
print(f'EM 估计硬币 B 概率: {pb:.3f}（真实 0.3）')
```

## HMM

隐马尔可夫模型（Hidden Markov Model，HMM）是处理序列数据的生成式概率模型：观测序列背后有一个「隐藏状态序列」按马尔可夫链演化，每个状态以一定概率发射出观测。它回答三个基本问题：评估、解码、学习。

```text
三要素：
1. 初始状态分布 π —— 起始处于各状态的概率
2. 状态转移矩阵 A —— A_ij = P(状态 j | 状态 i)
3. 发射矩阵 B —— B_jk = P(观测 k | 状态 j)

三个基本问题：
1. 评估（前向/后向算法）—— 求 P(观测序列|模型)
2. 解码（Viterbi）—— 求最可能的隐藏状态序列
3. 学习（Baum-Welch/EM）—— 估计参数 A、B、π

典型应用：词性标注、语音识别、基因序列分析
```

```python
import numpy as np
from hmmlearn import hmm

# 用 HMM 做简单的「天气→心情」建模：隐藏状态=天气，观测=心情
model = hmm.MultinomialHMM(n_components=2, n_iter=100, random_state=0)
# 状态 0=晴, 1=雨；观测 0=开心, 1=难过
model.startprob_ = np.array([0.6, 0.4])
model.transmat_ = np.array([[0.7, 0.3], [0.4, 0.6]])
model.emissionprob_ = np.array([[0.8, 0.2], [0.3, 0.7]])

# 采样一条观测序列，再用 Viterbi 解码出最可能的天气序列
obs, states = model.sample(n_samples=10, random_state=0)
decoded = model.decode(obs.reshape(-1, 1), algorithm='viterbi')[1]
print('真实状态序列:', states)
print('Viterbi 解码:', decoded)
print('解码正确率:', np.mean(states == decoded))
```

## CRF

条件随机场（Conditional Random Field，CRF）是判别式序列标注模型，直接建模 P(标签序列 | 观测序列)，克服了 HMM 的「观测独立」假设，能利用任意丰富的特征（含上下文、前后标签依赖）。它是 NER、分词等序列标注任务的经典模型。

```text
数学定义（线性链 CRF）：
P(y|x) = (1/Z(x)) · exp( Σ λ_k·f_k(y_i, y_{i-1}, x, i) )

其中：
- f_k —— 特征函数（状态特征 + 转移特征）
- λ_k —— 特征权重（学习得到）
- Z(x) —— 归一化因子（配分函数）

与 HMM 对比：
- HMM 生成式，建模 P(x,y)；CRF 判别式，直接建模 P(y|x)
- CRF 可用全局特征、无观测独立假设，效果通常更好
- CRF 训练/解码用前向-后向 + Viterbi（与 HMM 同框架但更通用）
```

```python
from sklearn_crfsuite import CRF

# 用 CRF 做词性标注的简化演示
def word2features(sent, i):
    word = sent[i][0]
    return {
        'word': word,
        'is_first': i == 0,
        'is_last': i == len(sent) - 1,
        'prefix1': word[:1],
        'suffix2': word[-2:],
        'is_capitalized': word[0].isupper(),
        'len': len(word),
    }

train_sents = [
    [('The', 'DET'), ('dog', 'NOUN'), ('runs', 'VERB')],
    [('A', 'DET'), ('cat', 'NOUN'), ('sleeps', 'VERB')],
    [('The', 'DET'), ('boy', 'NOUN'), ('jumps', 'VERB')],
]

X_train = [[word2features(s, i) for i in range(len(s))] for s in train_sents]
y_train = [[tag for _, tag in s] for s in train_sents]

crf = CRF(algorithm='lbfgs', max_iterations=100, all_possible_transitions=True)
crf.fit(X_train, y_train)

test = [('The', ''), ('cat', ''), ('runs', '')]
X_test = [word2features(test, i) for i in range(len(test))]
print('CRF 预测词性:', crf.predict_single(X_test))
```

## Bayesian Network

贝叶斯网络（Bayesian Network）用有向无环图（DAG）表达变量间的条件依赖关系：节点是变量，有向边表示因果/依赖关系，每个节点附带一个「给定父节点的条件概率表」。它把联合分布分解为局部条件分布的乘积，既能推理也能刻画因果关系。

```text
数学定义（链式法则 + 条件独立）：
P(X_1, ..., X_n) = Π_i P(X_i | Parents(X_i))

核心用途：
1. 概率推理 —— 给定证据，推断其他变量的后验概率
2. 因果分析 —— 结构编码因果关系，可做干预与反事实
3. 结构学习 —— 从数据学习图结构 + 条件概率表

经典示例：
- 诊断网络：疾病 → 症状
- 天气 → 洒水器 / 天气 → 下雨 → 草地湿
```

```python
from pgmpy.models import BayesianNetwork
from pgmpy.factors.discrete import TabularCPD
from pgmpy.inference import VariableElimination

# 经典「草地湿」贝叶斯网络：Cloudy → Sprinkler/Rain → Wet
model = BayesianNetwork([('Cloudy', 'Sprinkler'), ('Cloudy', 'Rain'),
                         ('Sprinkler', 'Wet'), ('Rain', 'Wet')])

cpd_c = TabularCPD('Cloudy', 2, [[0.5], [0.5]])
cpd_s = TabularCPD('Sprinkler', 2, [[0.5, 0.9], [0.5, 0.1]],
                   evidence=['Cloudy'], evidence_card=[2])
cpd_r = TabularCPD('Rain', 2, [[0.8, 0.2], [0.2, 0.8]],
                   evidence=['Cloudy'], evidence_card=[2])
cpd_w = TabularCPD('Wet', 2, [[1.0, 0.1, 0.1, 0.01], [0.0, 0.9, 0.9, 0.99]],
                   evidence=['Sprinkler', 'Rain'], evidence_card=[2, 2])

model.add_cpds(cpd_c, cpd_s, cpd_r, cpd_w)
assert model.check_model()

infer = VariableElimination(model)
# 已知草地湿了，推断下雨的后验概率
result = infer.query(variables=['Rain'], evidence={'Wet': 1})
print('P(Rain=1 | Wet=1) =', round(result.values[1], 3))
```

## 应用场景实战

### 场景一：文本情感分类（朴素贝叶斯全家桶对比）

```python
from sklearn.naive_bayes import GaussianNB, MultinomialNB, BernoulliNB
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
from sklearn.datasets import fetch_20newsgroups
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report

# 用新闻组数据做二分类：电脑硬件 vs 宗教
cats = ['comp.graphics', 'soc.religion.christian']
data = fetch_20newsgroups(subset='all', categories=cats, shuffle=True, random_state=42)
X, y = data.data, data.target

vec = TfidfVectorizer(stop_words='english', max_features=5000)
X_vec = vec.fit_transform(X)
X_train, X_test, y_train, y_test = train_test_split(X_vec, y, test_size=0.3, random_state=0)

for name, m in [('Multinomial NB', MultinomialNB()),
                ('Bernoulli NB', BernoulliNB())]:
    m.fit(X_train, y_train)
    acc = accuracy_score(y_test, m.predict(X_test))
    print(f'{name}: 准确率={acc:.3f}')
```

### 场景二：GMM 软聚类 + 异常检测

```python
import numpy as np
from sklearn.mixture import GaussianMixture

np.random.seed(42)
# 正常数据来自两个高斯簇
X_normal = np.vstack([np.random.randn(300, 2) + [0, 0],
                      np.random.randn(300, 2) + [6, 6]])
# 异常点散落在低密度区域
X_outliers = np.random.uniform(-2, 8, (20, 2))
X_all = np.vstack([X_normal, X_outliers])

gmm = GaussianMixture(n_components=2, random_state=0).fit(X_normal)
# 对数似然越低越可能是异常
log_likelihood = gmm.score_samples(X_all)
threshold = np.percentile(gmm.score_samples(X_normal), 2)   # 正常数据 2% 分位
predicted_outliers = log_likelihood < threshold
print(f'检出异常点数量: {predicted_outliers.sum()}（真实 20 个）')
print(f'异常检出率: {predicted_outliers[-20:].mean():.2%}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 文本分类先跑 MultinomialNB 当 baseline，又快又稳，再上更复杂模型
2. 朴素贝叶斯对特征量纲不敏感，但对「特征是否满足分布假设」敏感，连续特征先确认是否近似高斯
3. 计数/词频特征用 MultinomialNB，0/1 特征用 BernoulliNB，别混用
4. 朴素贝叶斯遇到「训练集没见过的特征取值」概率为 0，务必开拉普拉斯平滑（alpha 用交叉验证选）
5. GMM 的成分数 K 用 BIC/AIC 选，别只凭肉眼或经验
6. EM 只能收敛到局部最优，多跑几个随机初始值取对数似然最大的
7. HMM 状态数未知时，用 BIC 或领域知识定，状态太多会过拟合
8. 序列标注任务优先 CRF（或 BiLSTM-CRF），除非数据极少或需生成式建模才用 HMM
9. 贝叶斯网络的结构学习对数据量敏感，结构不确定时优先用领域专家知识定图

### 踩坑记录

```text
坑 1：朴素贝叶斯零概率问题
结论：测试样本某特征取值在训练集中没出现过，整个类别概率直接归零。
原因：条件概率乘积中只要一项为 0，乘积就是 0，其它证据全被抹掉。
解法：拉普拉斯平滑（sklearn 的 alpha 参数），把计数 +alpha 避免 0 概率。

坑 2：连续特征直接上 MultinomialNB
结论：连续特征被当计数处理，分类效果很差甚至报错。
原因：MultinomialNB 假设特征是计数，连续值不满足多项式分布假设。
解法：连续特征用 GaussianNB，或先离散化/分箱后再用 MultinomialNB。

坑 3：GMM 用 KMeans 初始化却仍陷入局部最优
结论：同一 K 跑多次结果不同，聚类不稳定，对数似然差异大。
原因：EM 对初值敏感，容易收敛到局部最优而非全局最优。
解法：多次随机初始化（sklearn 的 n_init）取对数似然最高者，或用 kmeans 初始化。

坑 4：HMM 状态数拍脑袋定太大
结论：状态数过多时模型过拟合，解码出的状态序列无意义地频繁切换。
原因：状态越多模型越复杂，小样本下拟合噪声。
解法：用 BIC/AIC 选择状态数，或依据领域知识（如词性类别数）确定。

坑 5：忽略先验对贝叶斯模型的影响
结论：小样本下先验选择不同，后验结论差异巨大，结果不稳健。
原因：样本少时后验由先验主导，先验的主观选择被放大。
解法：小样本用弱信息先验，并做敏感性分析，报告不同先验下的结论。
```
