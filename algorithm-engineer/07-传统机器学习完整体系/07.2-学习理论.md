## 概述

学习理论回答一个根本问题：「模型在训练集上表现好，凭什么在没见过的新数据上也表现好？」它用数学刻画假设空间、经验风险与期望风险之间的差距，给出「需要多少样本才能保证泛化」的可证明结论。理解偏差-方差、过拟合与正则化，是调参、选模型、设计训练策略的理论根基。

```text
学习理论的核心命题：
1. 经验风险最小化 ≠ 期望风险最小化，两者存在泛化误差
2. 泛化误差由「偏差 + 方差 + 噪声」三部分构成
3. 假设空间越复杂（VC 维越大），过拟合风险越高
4. 样本越多，经验风险越逼近期望风险（大数定律/一致收敛）
5. 正则化是「用偏差换方差」的显式手段
```

```python
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# 学习理论的直观演示：训练误差与测试误差的背离
def true_fn(x):
    return np.sin(x)

np.random.seed(0)
X = np.linspace(-3, 3, 100)
y = true_fn(X) + np.random.randn(100) * 0.3

# 用不同复杂度多项式拟合，观察训练/测试误差
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

X_train, X_test, y_train, y_test = train_test_split(X.reshape(-1,1), y, test_size=0.3, random_state=0)
for degree in [1, 3, 15]:
    m = make_pipeline(PolynomialFeatures(degree), LinearRegression()).fit(X_train, y_train)
    tr = mean_squared_error(y_train, m.predict(X_train))
    te = mean_squared_error(y_test, m.predict(X_test))
    print(f'degree={degree:>2}: 训练MSE={tr:.3f}  测试MSE={te:.3f}')
```

## Hypothesis

假设（Hypothesis）是学习算法输出的「候选函数」，即从输入到输出的一种具体映射。所有候选函数的集合叫假设空间（Hypothesis Space）H，学习的过程就是在 H 里搜索一个最符合数据的 h。

```text
定义：
- 假设空间 H —— 所有可能模型的集合，由模型族 + 超参数决定
- 假设 h ∈ H —— 一个具体训练好的模型，如 h(x) = w·x + b
- 学习算法 —— 从 H 中选出 h 的搜索过程

举例：
- 线性模型族：H = {h(x) = w·x + b | w ∈ R^d, b ∈ R}
- 决策树族：H = 所有可能的树结构
- 神经网络族：H = 某种架构下所有可训练参数取值
```

```python
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor

# 不同「假设空间」学习同一个数据集，得到不同的假设 h
X = np.linspace(-3, 3, 50).reshape(-1, 1)
y = np.sin(X).ravel() + np.random.randn(50) * 0.2

for name, model in [('线性假设空间', LinearRegression()),
                    ('树假设空间', DecisionTreeRegressor(max_depth=3))]:
    model.fit(X, y)
    print(f'{name} → 得到的具体假设 h 已训练完成')
```

## Empirical Risk

经验风险（Empirical Risk）是模型在训练集上的平均损失，是「期望风险」的样本近似。我们实际训练时最小化的就是经验风险，因为真实分布未知，只能拿训练样本做估计。

```text
数学定义：
R_emp(h) = (1/n) Σ L(y_i, h(x_i))   —— 训练集上的平均损失

其中：
- n 是训练样本数
- L 是损失函数（MSE、交叉熵、0-1 损失等）
- (x_i, y_i) 是训练样本

经验风险最小化（ERM）：
h* = argmin_{h∈H} R_emp(h)
```

```python
import numpy as np

# 经验风险：训练集平均损失的手写计算
def empirical_risk(y_true, y_pred, loss='mse'):
    if loss == 'mse':
        return np.mean((y_true - y_pred) ** 2)
    elif loss == 'cross_entropy':
        p = np.clip(y_pred, 1e-12, 1 - 1e-12)
        return -np.mean(y_true * np.log(p) + (1 - y_true) * np.log(1 - p))

y_true = np.array([1.0, 2.0, 3.0])
y_pred = np.array([1.2, 1.8, 3.1])
print(f'经验风险（MSE）: {empirical_risk(y_true, y_pred):.4f}')
```

## Expected Risk

期望风险（Expected Risk）是模型在整个真实数据分布上的平均损失，是「真正想最小化」却无法直接计算的目标。它度量的是模型的真实泛化能力，训练数据只是从该分布采样的一个样本。

```text
数学定义：
R(h) = E_{(x,y)~P} [L(y, h(x))] = ∫ L(y, h(x)) dP(x, y)

关键点：
1. R(h) 依赖未知的真实分布 P，实践中无法直接计算
2. 经验风险 R_emp 是 R 的无偏估计，但只是「一个样本」的估计
3. 泛化误差 = R(h) - R_emp(h)，即期望与经验的差距

学习理论的核心问题：什么时候 R_emp 小 ⇒ R 也小？
```

```python
import numpy as np

# 模拟真实分布，估计期望风险（现实中我们永远不知道这个值）
def expected_risk_estimate(h, true_fn, n=100000, noise=0.3):
    x = np.random.uniform(-3, 3, n)
    y = true_fn(x) + np.random.randn(n) * noise
    return np.mean((y - h(x)) ** 2)

def h_linear(x):
    return 0.0 * x   # 一个很差的假设：常数 0

true_fn = np.sin
print(f'期望风险（对真实分布的近似）: {expected_risk_estimate(h_linear, true_fn):.4f}')
print('说明：期望风险用大样本近似，现实中只能靠测试集估计')
```

## Bias-Variance

偏差-方差分解把模型的期望泛化误差拆成三部分：偏差（模型族本身够不够准）、方差（对训练数据的扰动敏不敏感）、不可约噪声。它是理解过拟合/欠拟合、指导模型选择的基石。

```text
数学定义（平方损失下）：
E[(y - ĥ(x))²] = Bias² + Variance + σ²

其中：
- Bias² = (E[ĥ(x)] - f(x))²  —— 模型族平均预测与真实值的差距
- Variance = E[(ĥ(x) - E[ĥ(x)])²]  —— 预测随训练集波动的程度
- σ² —— 数据本身的不可约噪声

直觉：
- 简单模型：高偏差、低方差（欠拟合）
- 复杂模型：低偏差、高方差（过拟合）
- 最优模型：在两者之间取平衡
```

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

# 用 Bootstrap 估计一个模型的偏差与方差
def bias_variance(model_fn, X, y, n_boot=100):
    preds = []
    for _ in range(n_boot):
        idx = np.random.choice(len(X), len(X), replace=True)
        m = model_fn().fit(X[idx], y[idx])
        preds.append(m.predict(X))
    preds = np.array(preds)
    mean_pred = preds.mean(axis=0)
    bias = np.mean((mean_pred - y) ** 2)
    var = np.mean((preds - mean_pred) ** 2)
    return bias, var

np.random.seed(0)
X = np.linspace(-3, 3, 60).reshape(-1, 1)
y = np.sin(X).ravel() + np.random.randn(60) * 0.5

lin = lambda: LinearRegression()
poly = lambda: make_pipeline(PolynomialFeatures(15), LinearRegression())

for name, fn in [('线性（简单）', lin), ('15次多项式（复杂）', poly)]:
    b, v = bias_variance(fn, X, y)
    print(f'{name}: 偏差²={b:.3f}  方差={v:.3f}')
```

## Overfitting

过拟合（Overfitting）是模型把训练数据里的噪声和偶然模式也「背」了下来，导致训练误差很低、测试误差很高。它的本质是「记忆」而非「学习」，是实践中最高频的问题。

```text
典型表现：
1. 训练损失持续下降，验证损失先降后升
2. 训练集指标远好于测试集指标
3. 模型参数绝对值很大、决策边界过于曲折

成因：
1. 模型复杂度过高（参数太多、树太深）
2. 训练样本太少或噪声大
3. 训练轮数过多（早停可缓解）

诊断：对比训练/验证曲线，两者缺口大即过拟合
```

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

X, y = make_classification(n_samples=200, n_features=10, n_informative=3, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

# 树越深越复杂，越容易过拟合
for depth in [1, 3, 10, None]:
    clf = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(X_train, y_train)
    tr = accuracy_score(y_train, clf.predict(X_train))
    te = accuracy_score(y_test, clf.predict(X_test))
    print(f'max_depth={str(depth):>4}: 训练={tr:.3f}  测试={te:.3f}  缺口={tr-te:.3f}')
```

## Underfitting

欠拟合（Underfitting）是模型复杂度过低，连训练数据里的真实规律都没学到，训练误差和测试误差都很高。它的本质是「模型太笨」，解决方向是提升模型容量或改进特征。

```text
典型表现：
1. 训练误差和测试误差都高，且二者接近
2. 模型无法捕捉数据的非线性结构
3. 决策边界过于简单（如用直线分非线性数据）

成因：
1. 模型容量不足（线性模型拟合非线性关系）
2. 特征太少或特征工程不足
3. 正则化过强（惩罚过度，把模型压扁了）

解决：加特征、用更复杂模型、减弱正则化
```

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 数据是二次关系，却用线性模型 → 欠拟合
X = np.linspace(-5, 5, 100).reshape(-1, 1)
y = X.ravel() ** 2 + np.random.randn(100) * 3

lin = LinearRegression().fit(X, y)
from sklearn.metrics import mean_squared_error
print(f'线性模型拟合二次数据：MSE={mean_squared_error(y, lin.predict(X)):.1f}（欠拟合，误差大）')

# 换成二次多项式立刻改善
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
poly = make_pipeline(PolynomialFeatures(2), LinearRegression()).fit(X, y)
print(f'二次多项式：MSE={mean_squared_error(y, poly.predict(X)):.1f}（显著改善）')
```

## Regularization

正则化（Regularization）在经验风险上额外加一个「复杂度惩罚项」，显式地约束模型复杂度，防止过拟合。它是「奥卡姆剃刀」的数学实现：在能解释数据的前提下，偏好更简单的模型。

```text
数学定义（结构风险最小化）：
min R_emp(h) + λ·Ω(w)

常见正则项：
1. L1（Lasso）—— Ω(w)=‖w‖₁，产生稀疏解，做特征选择
2. L2（Ridge）—— Ω(w)=‖w‖²₂，收缩权重，处理共线性
3. Elastic Net —— L1 + L2 的组合
4. Dropout —— 神经网络里随机丢弃神经元，等价于集成正则

λ（或 C、alpha）是正则强度超参：越大 → 越简单 → 越抗过拟合
```

```python
from sklearn.linear_model import Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

np.random.seed(0)
X = np.linspace(-3, 3, 100).reshape(-1, 1)
y = np.sin(X).ravel() + np.random.randn(100) * 0.4
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

# 高次多项式 + 不同强度的 L2 正则
for alpha in [0, 0.01, 1.0, 100]:
    m = make_pipeline(PolynomialFeatures(15), Ridge(alpha=alpha)).fit(X_train, y_train)
    te = mean_squared_error(y_test, m.predict(X_test))
    print(f'15次多项式 + L2(alpha={alpha:>6}): 测试MSE={te:.3f}')
```

## Generalization

泛化（Generalization）是模型在「未见过」的新数据上表现良好的能力，是机器学习的终极目标。泛化误差 = 期望风险 - 经验风险，学习理论的核心就是刻画并控制这个差距。

```text
泛化误差的上界（简化形式）：
R(h) ≤ R_emp(h) + √( (复杂度 / n) · log 项 )

含义：
1. 样本 n 越大 → 泛化误差上界越小
2. 假设空间越复杂（VC 维/参数多）→ 上界越大
3. 这就是「数据多 + 模型简单」能泛化好的理论依据

提升泛化的实践手段：
1. 更多数据（数据增强）
2. 正则化 / 早停 / Dropout
3. 交叉验证选超参
4. 集成学习降低方差
```

```python
import numpy as np
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification

# 泛化能力用交叉验证估计：在多个「未见过的」验证折上评估
X, y = make_classification(n_samples=500, n_features=10, random_state=0)
scores = cross_val_score(LogisticRegression(max_iter=1000), X, y, cv=5)
print(f'5 折交叉验证各折准确率: {np.round(scores, 3)}')
print(f'泛化能力估计（均值±标准差）: {scores.mean():.3f} ± {scores.std():.3f}')
```

## VC Dimension

VC 维（Vapnik-Chervonenkis Dimension）度量一个假设空间的「表达能力」或复杂度：它等于该假设空间能被「打散」（shatter）的最大样本点数量。VC 维越大，模型越复杂，过拟合风险越高。

```text
定义：
- 打散（shatter）：假设空间 H 能对某 m 个点实现所有 2^m 种标签组合
- VC 维 = 能被 H 打散的最大点数 m

经典结论：
- d 维线性分类器的 VC 维 = d + 1
- 决策树/神经网络可无限大（不剪枝时）

用途：代入泛化误差界，给出「理论上的样本需求」
VC 维高 → 需要更多样本才能保证泛化
```

```python
import numpy as np
from itertools import product

# 演示：2 维线性分类器的打散能力（VC 维 = d+1 = 3）
def can_shatter_linear(points):
    """检查线性分类器能否对给定点实现所有标签组合（2 维）"""
    n = len(points)
    for labels in product([-1, 1], repeat=n):
        labels = np.array(labels)
        X = np.c_[points, np.ones(n)]
        # 检查是否存在 w 使 sign(w·x) = labels（用最小二乘近似判断线性可分性）
        feasible = False
        for _ in range(200):  # 随机搜索一个可行权重
            w = np.random.randn(3)
            if np.all(np.sign(points @ w[:2] + w[2]) == labels):
                feasible = True
                break
        if not feasible:
            return False
    return True

# 2 维平面上 3 个不共线点可被打散（2^3=8 种标签都能实现）
pts = np.array([[0, 0], [1, 0], [0, 1]])
print(f'3 个不共线点可被 2D 线性分类器打散: {can_shatter_linear(pts)}')
print('2 维线性分类器 VC 维 = 3（d+1），4 个点无法全部打散')
```

## PAC Learning

PAC 学习（Probably Approximately Correct，可能近似正确）是计算学习理论的核心框架：它研究「需要多少样本，才能以大概率学到一个近似正确的假设」。它给出了可学习性的形式化定义与样本复杂度下界。

```text
PAC 可学习的定义：
对任意 ε（误差容忍）、δ（置信度），存在算法，当样本数 n ≥ N(ε,δ) 时，
以概率 ≥ 1-δ 输出一个误差 ≤ ε 的假设 h。

即：P( R(h) ≤ R(h*) + ε ) ≥ 1 - δ

三个关键量：
1. ε —— 近似正确里的「近似」，允许多大误差
2. δ —— 近似正确里的「可能」，允许多大概率失败
3. N(ε,δ) —— 样本复杂度，随 1/ε、1/δ 增长，随 VC 维增长
```

```python
import numpy as np

# PAC 样本复杂度界的示意（有限假设空间）
def pac_sample_complexity(H_size, epsilon, delta):
    """有限假设空间 |H| 下的样本复杂度上界"""
    return (1.0 / epsilon) * (np.log(H_size) + np.log(1.0 / delta))

for eps in [0.05, 0.1, 0.2]:
    n = pac_sample_complexity(H_size=1000, epsilon=eps, delta=0.05)
    print(f'ε={eps:.2f}, δ=0.05 需要的样本数 ≈ {n:.0f}')
print('结论：误差容忍 ε 越小、假设空间越大，需要的样本越多')
```

## Sample Complexity

样本复杂度（Sample Complexity）是「学到一个满足精度要求的模型，至少需要多少训练样本」。它把前面的理论统一成一个实用的数量级估计，指导我们判断「数据量够不够」。

```text
样本复杂度的数量级规律：
1. 随 1/ε 线性增长 —— 想精度翻倍，样本要翻倍
2. 随 VC 维线性增长 —— 模型越复杂，需要的样本越多
3. 随 log(1/δ) 增长 —— 置信度要求对样本量的影响是对数级的（相对温和）

实践含义：
1. 模型参数量/复杂度翻倍，通常需要更多数据支撑
2. 「数据不够就别上大模型」的理论依据
3. 数据增强、迁移学习都是在「变相增加有效样本」
```

```python
import numpy as np
from sklearn.model_selection import learning_curve
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification

# 学习曲线：观察样本量如何影响训练/验证表现
X, y = make_classification(n_samples=1000, n_features=20, n_informative=5, random_state=0)

train_sizes, train_scores, val_scores = learning_curve(
    LogisticRegression(max_iter=1000), X, y, cv=5,
    train_sizes=np.linspace(0.1, 1.0, 8), random_state=0)

for n, tr, va in zip(train_sizes, train_scores.mean(axis=1), val_scores.mean(axis=1)):
    print(f'样本数={n:>4}: 训练={tr:.3f}  验证={va:.3f}  缺口={tr-va:.3f}')
print('样本越多，训练/验证缺口越小 → 泛化越好')
```

## 应用场景实战

### 场景一：用偏差-方差分解定位模型问题

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

np.random.seed(42)
X = np.linspace(-4, 4, 120).reshape(-1, 1)
y = np.sin(X).ravel() + np.random.randn(120) * 0.6
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=0)

def boot_bias_var(model_fn, X, y, n_boot=80):
    preds = []
    for _ in range(n_boot):
        idx = np.random.choice(len(X), len(X), replace=True)
        preds.append(model_fn().fit(X[idx], y[idx]).predict(X))
    preds = np.array(preds)
    mean_pred = preds.mean(axis=0)
    bias = np.mean((mean_pred - y) ** 2)
    var = np.mean((preds - mean_pred) ** 2)
    return bias, var

configs = {
    '线性(欠拟合)': lambda: LinearRegression(),
    '3次多项式(适中)': lambda: make_pipeline(PolynomialFeatures(3), LinearRegression()),
    '15次多项式(过拟合)': lambda: make_pipeline(PolynomialFeatures(15), LinearRegression()),
}
for name, fn in configs.items():
    b, v = boot_bias_var(fn, X_train, y_train)
    te = mean_squared_error(y_test, fn().fit(X_train, y_train).predict(X_test))
    print(f'{name}: 偏差²={b:.3f}  方差={v:.3f}  测试MSE={te:.3f}')
```

### 场景二：正则化强度调优 + 早停防过拟合

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification
from sklearn.model_selection import GridSearchCV

X, y = make_classification(n_samples=800, n_features=30, n_informative=8, random_state=0)

# 用交叉验证搜索最优正则强度 C（越小正则越强）
param_grid = {'C': np.logspace(-3, 2, 20)}
grid = GridSearchCV(LogisticRegression(max_iter=2000, solver='liblinear'),
                    param_grid, cv=5, scoring='accuracy')
grid.fit(X, y)
print(f'最优 C（正则强度的倒数）: {grid.best_params_["C"]:.4f}')
print(f'最优交叉验证准确率: {grid.best_score_:.3f}')
print('结论：C 过小（正则过强）欠拟合，C 过大过拟合，中间存在最优区')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 永远用独立的验证集/测试集估计泛化，绝不能拿训练误差当泛化指标
2. 用学习曲线判断「欠拟合还是过拟合」，再决定加数据还是加正则，别瞎调
3. 模型越复杂、特征越多，正则化越要跟上，否则过拟合几乎是必然
4. 交叉验证是估计泛化能力、选正则强度的标准手段，K 通常取 5 或 10
5. 正则强度用对数网格（logspace）搜索，因为最优值往往跨越多个数量级
6. 记住「偏差-方差权衡」：训练误差高→先提升模型容量；训练低测试高→先加正则/加数据
7. 早停（early stopping）是廉价高效的正则手段，监控验证集损失在上升前停下
8. 数据增强和迁移学习本质是「变相增加有效样本」，小数据场景优先考虑

### 踩坑记录

```text
坑 1：拿训练准确率当泛化能力报告
结论：训练集 99% 准确率，上线后测试集只有 70%，被严重高估。
原因：训练误差会低估真实误差，模型复杂时偏差尤其大。
解法：严格划分验证/测试集，或交叉验证，报告验证集指标。

坑 2：正则强度用线性网格搜索
结论：搜了 10 个点都没找到好结果，最优 C 在 1e-3 附近却只搜了 1~10。
原因：正则强度的影响跨多个数量级，线性取值覆盖不到。
解法：用 np.logspace 做对数网格，或先粗后细两阶段搜索。

坑 3：过拟合与欠拟合方向搞反
结论：训练误差高以为是过拟合，又加正则，结果误差更高。
原因：训练误差高通常是欠拟合（模型太弱），此时加正则雪上加霜。
解法：先看训练/验证缺口——都高是欠拟合（加容量），训练低验证高是过拟合（加正则）。

坑 4：忽略噪声导致的「不可约误差」
结论：拼命调参想再降 1% 测试误差，但数据噪声本身就有 5%，永远够不到。
原因：Bias²+Variance+σ² 中 σ² 无法通过模型消除，调参只能优化前两项。
解法：先估计数据噪声水平，设合理的目标误差上限，避免无效调参。

坑 5：小样本上评估 VC 维高的模型
结论：几百样本就训练深网络，测试集方差极大，每次跑结果都不同。
原因：VC 维高的模型需要大量样本，小样本下经验风险与期望风险差距巨大。
解法：小样本优先线性/浅树模型，或用迁移学习+强正则，多次重复实验报告方差。
```
