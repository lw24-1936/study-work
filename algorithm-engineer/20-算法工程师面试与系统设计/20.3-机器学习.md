## 概述

传统机器学习是算法工程师面试的「基本功区」，几乎必考 LR、树模型（GBDT/XGBoost/LightGBM）和几类无监督算法（K-Means、PCA、GMM）。考察重点是模型原理（损失函数、推导过程）、模型之间的对比，以及调参和过拟合控制。

```text
机器学习面试高频考点：
1. LR —— 损失函数推导、为什么用 sigmoid、与线性回归的区别
2. SVM —— 间隔最大化、核技巧、对偶问题、软间隔
3. Tree —— 信息增益/基尼系数、剪枝、特征重要性
4. GBDT —— 残差拟合、负梯度、与随机森林的区别
5. XGBoost —— 二阶泰勒展开、正则化、分裂增益
6. LightGBM —— 直方图、单边梯度采样、leaf-wise
7. K-Means —— 收敛性、K 值选择、与 GMM/EM 的关系
8. PCA —— 特征值分解/SVD、方差解释率
9. GMM —— EM 算法、软聚类、与 K-Means 的关系
```

```python
# 面试自检：机器学习整体框架
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.decomposition import PCA

# 一句话区分各类模型
# LR：线性 + sigmoid，可解释，baseline
# SVM：间隔最大化，适合高维/小样本
# Tree 系：非线性、特征组合、表格数据 SOTA
# K-Means：硬聚类，EM 特例
# PCA：线性降维，最大方差方向投影
```

## LR

逻辑回归（Logistic Regression）是分类模型的基石：用 sigmoid 把线性输出映射为概率，损失函数是交叉熵，可解释性强。

```text
核心概念：
- 模型：p(y=1|x) = σ(w·x + b)，σ(z) = 1/(1+e⁻ᶻ)
- 损失函数：交叉熵 L = -Σ[y log p + (1-y) log(1-p)]
- 推导：从「对数几率」log(p/(1-p)) = w·x 出发，或从极大似然估计推导
- 优化：梯度下降/牛顿法，损失是凸函数，可收敛到全局最优
- 与线性回归区别：回归预测连续值用 MSE，分类预测概率用交叉熵
```

```text
高频面试题：
Q1：为什么分类用交叉熵而不用 MSE？
答：MSE 配合 sigmoid 会产生「梯度消失」——预测接近 0/1 时 sigmoid 导数趋近 0，
   导致更新缓慢；交叉熵对 sigmoid 求导后梯度为 (p - y)，与误差线性相关，
   学习更快，且交叉熵是凸函数（MSE + sigmoid 非凸），优化更稳定。

Q2：为什么用 sigmoid 不用阶跃函数？
答：sigmoid 连续可导，能输出 (0,1) 的平滑概率，配合梯度下降优化；阶跃函数
   不可导且输出只有 0/1，无法用梯度方法训练。sigmoid 可看作阶跃的平滑近似。

Q3：LR 为什么用极大似然而不用最小二乘？
答：分类问题中 y 服从伯努利分布，极大似然（等价于最小化交叉熵）是自然选择；
   最小二乘假设高斯噪声，适合回归而非二分类。极大似然估计参数具有一致性和
   渐近有效性。
```

```python
import numpy as np

# 手写 LR（梯度下降 + 交叉熵）
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

class LogisticRegression:
    def __init__(self, lr=0.1, epochs=1000):
        self.lr = lr
        self.epochs = epochs

    def fit(self, X, y):
        X = np.c_[np.ones(len(X)), X]
        self.w = np.zeros(X.shape[1])
        for _ in range(self.epochs):
            p = sigmoid(X @ self.w)
            grad = X.T @ (p - y) / len(y)      # 交叉熵梯度
            self.w -= self.lr * grad
        return self

    def predict_proba(self, X):
        X = np.c_[np.ones(len(X)), X]
        return sigmoid(X @ self.w)

X = np.random.randn(500, 2)
y = (X[:, 0] + X[:, 1] > 0).astype(int)
clf = LogisticRegression().fit(X, y)
print(clf.predict_proba([[1.5, 1.5]]))   # 接近 1
```

## SVM

支持向量机通过「最大化间隔」寻找最优分类超平面，配合核技巧处理非线性问题，是小样本高维场景的利器。

```text
核心概念：
- 目标：找使两类样本间隔（margin）最大的超平面 w·x + b = 0
- 支持向量：离超平面最近、决定超平面位置的样本点
- 软间隔：引入松弛变量 ξ 和惩罚参数 C，允许少量误分类
- 对偶问题：通过拉格朗日对偶转化为只依赖内积的优化问题
- 核技巧：K(x, z) 隐式映射到高维，避免显式计算特征映射
- 常用核：线性核、RBF 核、多项式核
```

```text
高频面试题：
Q1：为什么 SVM 适合小样本高维场景？
答：SVM 决策只由少数支持向量决定，复杂度与支持向量数而非特征维度直接相关；
   核技巧避免显式高维计算。高维下样本更可能线性可分，间隔最大化提升泛化。

Q2：什么是核技巧？为什么能处理非线性？
答：把数据映射到高维特征空间使其线性可分，但映射 φ(x) 可能维数爆炸。核技巧
   直接计算 K(x,z)=<φ(x),φ(z)>，无需显式映射，通过 Mercer 核实现「隐式高维」。
   RBF 核对应无限维空间。

Q3：软间隔的参数 C 和 RBF 的 γ 怎么理解？
答：C 是误分类惩罚，C 越大越不允许犯错，容易过拟合；C 越小间隔越大、泛化越好。
   γ 控制 RBF 核的「影响半径」，γ 越大支持向量影响范围越小、决策边界越复杂，
   越容易过拟合。两者需联合调参。
```

```python
from sklearn.svm import SVC
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

X, y = make_classification(n_samples=500, n_features=10, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 线性核 vs RBF 核
for kernel in ['linear', 'rbf']:
    svm = SVC(kernel=kernel, C=1.0, gamma='scale').fit(X_train, y_train)
    print(f'{kernel} 准确率: {svm.score(X_test, y_test):.3f}')

# 支持向量数量
svm = SVC(kernel='rbf').fit(X_train, y_train)
print(f'支持向量数量: {len(svm.support_)}')
```

## Tree

决策树通过递归划分特征空间生成树结构，是树模型家族（随机森林、GBDT、XGBoost）的基础。

```text
核心概念：
- 分裂准则：ID3 信息增益、C4.5 信息增益率、CART 基尼系数
- 信息熵：H = -Σ p log p，度量不确定性；信息增益 = 划分前后熵的减少
- 基尼系数：Gini = 1 - Σ p²，衡量不纯度，CART 用它做分类
- 剪枝：预剪枝（深度/叶节点数限制）和后剪枝（代价复杂度）
- 优点：可解释、无需特征缩放、能处理非线性；缺点：易过拟合、不稳定
```

```text
高频面试题：
Q1：信息增益、增益率、基尼系数有什么区别？
答：信息增益偏向取值多的特征（如 ID 类），C4.5 用增益率除以特征的固有值来
   惩罚；基尼系数计算更简单（无对数），CART 用它，且 CART 是二叉树。分类
   常用基尼或熵，两者效果接近。

Q2：决策树为什么容易过拟合？怎么解决？
答：树可以无限细分直到每个叶节点只有一个样本，完美拟合训练集但泛化差。
   解决：限制最大深度、最小叶节点样本数、最小分裂样本数（预剪枝），或
   后剪枝，以及集成方法（随机森林/GBDT）降低方差。

Q3：决策树需要特征标准化吗？
答：不需要。决策树的分裂基于特征值的排序和阈值比较，单调变换（缩放、平移）
   不改变分裂点和树结构。这也是它与 LR/SVM/KNN 的重要区别。
```

```python
from sklearn.tree import DecisionTreeClassifier, export_text

X = [[0, 0], [0, 1], [1, 0], [1, 1]]
y = [0, 1, 1, 0]           # XOR

tree = DecisionTreeClassifier(max_depth=3).fit(X, y)
print(export_text(tree, feature_names=['x1', 'x2']))

# 查看特征重要性
from sklearn.datasets import load_iris
X_i, y_i = load_iris(return_X_y=True)
dt = DecisionTreeClassifier().fit(X_i, y_i)
print('特征重要性:', dt.feature_importances_)
```

## GBDT

梯度提升决策树（Gradient Boosting Decision Tree）通过串行地拟合「负梯度」（残差）来逐步逼近目标，是 XGBoost/LightGBM 的前身。

```text
核心概念：
- 集成方式：Boosting，串行训练多棵弱学习器（CART 回归树）
- 核心思想：每棵树拟合前面模型的「负梯度」（残差），累加逼近真实值
- 损失函数：平方损失下负梯度即残差；一般损失用梯度下降的思想
- 与随机森林区别：RF 并行 Bagging + 样本/特征抽样，降低方差；GBDT 串行
   Boosting，降低偏差
- 学习率（shrinkage）：每棵树乘小步长，配合更多树，防过拟合
```

```text
高频面试题：
Q1：GBDT 拟合的是残差还是负梯度？
答：本质是负梯度（损失函数对当前模型输出的负方向）。当损失是平方损失时，
   负梯度恰好等于残差 (y - F)，所以「拟合残差」只是平方损失下的特例；
   对其他损失函数（如 logloss），拟合的是负梯度。

Q2：GBDT 和随机森林的区别？
答：RF 是 Bagging，树并行训练、结果投票/平均，通过降低方差提升泛化；
   GBDT 是 Boosting，树串行、每棵拟合前序的负梯度，通过降低偏差提升精度。
   GBDT 通常精度更高但训练慢、易过拟合，需调学习率和树数量。

Q3：GBDT 为什么用回归树而不是分类树？
答：GBDT 拟合的是「残差/负梯度」，这是一个连续值，需要回归树输出连续数值，
   再累加到当前模型。即使做分类任务（如二分类），内部也是拟合连续梯度。
```

```python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score

X, y = make_classification(n_samples=1000, n_features=20, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

gbdt = GradientBoostingClassifier(
    n_estimators=100, learning_rate=0.1, max_depth=3, random_state=42
).fit(X_train, y_train)

proba = gbdt.predict_proba(X_test)[:, 1]
print(f'AUC: {roc_auc_score(y_test, proba):.3f}')

# 学习率与树数量的权衡
for lr in [0.05, 0.1, 0.2]:
    m = GradientBoostingClassifier(n_estimators=100, learning_rate=lr, max_depth=3).fit(X_train, y_train)
    print(f'lr={lr}: {roc_auc_score(y_test, m.predict_proba(X_test)[:, 1]):.3f}')
```

## XGBoost

XGBoost 是 GBDT 的工程化强化版，引入二阶泰勒展开、显式正则化、并行分位点分裂，是表格数据竞赛与生产的常青树。

```text
核心概念：
- 目标函数：损失 + 正则 Ω(f) = γT + 1/2 λ‖w‖²，抑制过拟合
- 二阶泰勒展开：用一阶梯度 g 和二阶梯度 h 近似损失，分裂增益公式更精确
- 分裂增益：Gain = 1/2 [G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] - γ
- 特征预排序 + 分位点近似，block 结构支持并行计算分裂
- 内置缺失值处理：自动学习缺失值的默认分裂方向
- 支持多种基学习器（gbtree/gblinear/dart）与多种损失函数
```

```text
高频面试题：
Q1：XGBoost 相比 GBDT 的改进？
答：(1) 用二阶泰勒展开，损失近似更精确、收敛更快；(2) 显式正则项 γ 和 λ
   控制复杂度防过拟合；(3) 分裂增益按 block 预排序，特征间并行计算；
   (4) 自动处理缺失值；(5) 支持列采样（colsample）进一步降低方差。

Q2：XGBoost 的分裂增益公式怎么理解？
答：分子是左右子树梯度和的平方项，衡量「分裂后左右节点各自能减少多少损失」；
   分母是二阶梯度 + λ 的归一化（二阶信息越大，分裂越「确定」）；减去 γ 是
   每次分裂的固定惩罚，只有增益超过 γ 才值得分裂，天然起到预剪枝作用。

Q3：为什么要二阶泰勒展开？
答：一阶只用到梯度方向，二阶额外利用曲率信息，对损失函数做更精确的二次
   近似，分裂点选择和叶节点权重计算都更准，通常能更快收敛到更优解。
```

```python
import xgboost as xgb

X, y = make_classification(n_samples=1000, n_features=20, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

dtrain = xgb.DMatrix(X_train, label=y_train)
dtest = xgb.DMatrix(X_test, label=y_test)

params = {
    'objective': 'binary:logistic',
    'max_depth': 3,
    'eta': 0.1,
    'subsample': 0.8,
    'colsample_bytree': 0.8,
    'eval_metric': 'auc',
    'lambda': 1.0,       # L2 正则
    'gamma': 0.1,        # 分裂最小增益
}

model = xgb.train(params, dtrain, num_boost_round=100)
preds = model.predict(dtest)
print(f'XGBoost AUC: {roc_auc_score(y_test, preds):.3f}')

# 特征重要性
importance = model.get_score(importance_type='gain')
print('Top 特征:', sorted(importance.items(), key=lambda x: -x[1])[:5])
```

## LightGBM

LightGBM 通过直方图算法、单边梯度采样（GOSS）、互斥特征捆绑（EFB）和 leaf-wise 生长策略，大幅提升训练速度与内存效率，适合大规模数据。

```text
核心概念：
- 直方图算法：连续特征离散化成 bin（如 255 个），分裂只需遍历 bin，省内存
- leaf-wise 生长：每次选增益最大的叶节点分裂，更快但需限制深度防过拟合
- GOSS：保留大梯度样本 + 随机采样小梯度样本，减少训练样本
- EFB：互斥特征捆绑，降低特征维度
- 直方图做差：父节点直方图减兄弟节点，加速兄弟节点分裂计算
```

```text
高频面试题：
Q1：LightGBM 相比 XGBoost 快在哪？
答：(1) 直方图算法把连续特征离散化，分裂遍历 bin 而非样本，速度快、内存小；
   (2) leaf-wise 只分裂增益最大的节点，同样迭代下精度更高（需限制 max_depth）；
   (3) GOSS/EFB 减少样本和特征量；(4) 直方图做差加速。代价是对小数据可能
   过拟合，需调 min_data_in_leaf 等参数。

Q2：leaf-wise 和 level-wise 的区别？
答：level-wise（XGBoost 默认）逐层分裂，每层所有节点都分裂，平衡但低效，
   会浪费在低增益节点上；leaf-wise（LightGBM）每次只分裂全局增益最大的
   叶节点，收敛更快、精度更高，但可能长出极深分支导致过拟合，需限制深度
   和叶节点最小样本数。

Q3：直方图算法的优缺点？
答：优点：内存占用小（bin 而非原始值）、分裂计算快、支持直方图做差。
   缺点：离散化带来一定精度损失（但通常可忽略，甚至有正则化收益）；分箱
   参数（max_bin）需要适当设置。
```

```python
import lightgbm as lgb

X, y = make_classification(n_samples=1000, n_features=20, random_state=0)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=1)

lgb_train = lgb.Dataset(X_train, y_train)
lgb_test = lgb.Dataset(X_test, y_test, reference=lgb_train)

params = {
    'objective': 'binary',
    'metric': 'auc',
    'num_leaves': 31,
    'max_depth': 6,
    'learning_rate': 0.1,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 1,
}

model = lgb.train(params, lgb_train, num_boost_round=100, valid_sets=[lgb_test])
preds = model.predict(X_test)
print(f'LightGBM AUC: {roc_auc_score(y_test, preds):.3f}')

print(f'特征重要性: {model.feature_importance()[:5]}')
```

## K-Means

K-Means 是最经典的硬聚类算法：把样本划分到 K 个簇，使簇内距离平方和最小。

```text
核心概念：
- 目标：最小化 SSE = Σ Σ ‖x - μ_k‖²（簇内平方和）
- 算法：初始化 K 个中心 → 分配每个点到最近中心 → 更新中心为簇均值 → 迭代
- 收敛性：SSE 单调下降，必收敛到局部最优（对初始化敏感）
- K 值选择：肘部法（SSE 拐点）、轮廓系数（silhouette）
- 与 GMM 关系：K-Means 是 GMM 在「各簇等方差、硬分配」下的特例
```

```text
高频面试题：
Q1：K-Means 一定收敛吗？会到全局最优吗？
答：一定收敛（SSE 每步不增，且划分有限），但只到局部最优，对初始中心敏感。
   用 k-means++ 智能初始化、多次随机初始化取最优，可改善。

Q2：如何选择 K？
答：肘部法画 SSE-K 曲线找拐点；轮廓系数取最大；或结合业务先验（如用户分层
   期望的层数）。也可用 Gap Statistic 与随机参照对比。

Q3：K-Means 的优缺点？
答：优点：简单、快、可扩展、易解释；缺点：需预设 K、对初始化和离群点敏感、
   只适合凸/球形簇、只能硬分配。非球形簇可用 DBSCAN 或谱聚类。
```

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import numpy as np

X, _ = make_classification(n_samples=500, n_features=2, n_informative=2,
                           n_redundant=0, n_clusters_per_class=1, random_state=42)

# 肘部法 + 轮廓系数选 K
for k in [2, 3, 4, 5, 6]:
    km = KMeans(n_clusters=k, init='k-means++', n_init=10, random_state=0).fit(X)
    sil = silhouette_score(X, km.labels_)
    print(f'K={k}: SSE={km.inertia_:.1f}, 轮廓系数={sil:.3f}')

# 手写 K-Means 核心迭代
def kmeans(X, k, iters=100):
    rng = np.random.default_rng(0)
    centers = X[rng.choice(len(X), k, replace=False)]
    for _ in range(iters):
        labels = np.argmin(((X[:, None] - centers) ** 2).sum(-1), axis=1)
        new_centers = np.array([X[labels == i].mean(0) for i in range(k)])
        if np.allclose(centers, new_centers):
            break
        centers = new_centers
    return centers, labels

centers, labels = kmeans(X, 3)
print(f'手写 K-Means 收敛, 簇中心数: {len(centers)}')
```

## PCA

主成分分析（PCA）是最常用的线性降维方法：找到方差最大的正交方向，把高维数据投影到低维空间。

```text
核心概念：
- 目标：找到使投影后方差最大的 k 个正交方向（主成分）
- 计算：中心化 → 协方差矩阵 → 特征值分解（或对数据矩阵 SVD）
- 主成分 = 协方差矩阵的前 k 大特征值对应的特征向量
- 方差解释率：λ_i / Σλ，衡量每个主成分保留的信息量
- 与 SVD 关系：对中心化数据矩阵 X 做 SVD，右奇异向量即主成分
```

```text
高频面试题：
Q1：PCA 的数学步骤？
答：1) 数据中心化（减去均值）；2) 求协方差矩阵 C = XᵀX/(n-1)；3) 对 C 做
   特征值分解，取前 k 大特征值对应特征向量；4) 数据投影到这些向量张成的
   空间。等价于对 X 做 SVD。

Q2：为什么主成分是最大方差方向？
答：方差越大，数据在该方向的「信息」越多，降维后信息损失越小。数学上可证明
   最大化投影方差等价于最大化特征值，故取前 k 大特征值的特征向量。

Q3：如何选择 k？
答：看累计方差解释率，通常保留 90%~95% 以上方差所需的成分数；或用肘部法；
   也可结合下游任务效果。PCA 前必须标准化，否则量纲大的特征主导方差。
```

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np

X = np.random.randn(200, 10)
X_scaled = StandardScaler().fit_transform(X)   # PCA 前必须标准化

pca = PCA(n_components=3)
X_reduced = pca.fit_transform(X_scaled)
print('方差解释率:', pca.explained_variance_ratio_)
print('累计解释率:', np.cumsum(pca.explained_variance_ratio_))

# 手写 PCA（特征值分解）
def pca_manual(X, k):
    X_c = X - X.mean(axis=0)
    cov = X_c.T @ X_c / (len(X) - 1)
    eig_vals, eig_vecs = np.linalg.eigh(cov)          # 升序
    top = eig_vecs[:, ::-1][:, :k]                    # 取前 k 大
    return X_c @ top

X_manual = pca_manual(X_scaled, 3)
print('手写与 sklearn 一致:', np.allclose(np.abs(X_reduced), np.abs(X_manual), atol=1e-5))
```

## GMM

高斯混合模型（Gaussian Mixture Model）用多个高斯分布的加权和建模数据，用 EM 算法求解，实现软聚类。

```text
核心概念：
- 模型：p(x) = Σ π_k · N(x | μ_k, Σ_k)，π_k 为混合系数（Σπ=1）
- 软聚类：每个样本属于每个簇的概率（后验），而非硬分配
- EM 算法：E 步求后验概率（责任值 γ），M 步更新 π、μ、Σ
- 与 K-Means 关系：各簇协方差相同且趋于 0、硬分配时退化为 K-Means
- 应用：聚类、密度估计、异常检测（低概率区域）
```

```text
高频面试题：
Q1：EM 算法流程？
答：E 步（Expectation）用当前参数计算每个样本属于每个高斯分量的后验概率
   γ_ik；M 步（Maximization）用这些后验加权更新 π、μ、Σ。两步骤迭代直到
   对数似然收敛。EM 保证似然单调不减，但收敛到局部最优。

Q2：GMM 和 K-Means 的区别？
答：GMM 是概率模型，输出软分配（样本归属概率）和各簇的协方差结构（能表达
   椭圆簇），更灵活；K-Means 硬分配、各簇等方差球形。GMM 用 EM 迭代，K-Means
   是 GMM 的特例。

Q3：GMM 怎么选分量数 K？
答：用 BIC（贝叶斯信息准则）或 AIC 在似然与复杂度间权衡，取最小的 K；或
   结合业务先验、轮廓系数等。
```

```python
from sklearn.mixture import GaussianMixture
import numpy as np

X = np.vstack([
    np.random.randn(200, 2) + [0, 0],
    np.random.randn(200, 2) + [5, 5],
    np.random.randn(200, 2) + [0, 5],
])

# BIC 选择分量数
for k in [2, 3, 4, 5]:
    gmm = GaussianMixture(n_components=k, random_state=0).fit(X)
    print(f'K={k}: BIC={gmm.bic(X):.1f}')

gmm = GaussianMixture(n_components=3, random_state=0).fit(X)
labels = gmm.predict(X)
probs = gmm.predict_proba(X)   # 软分配
print(f'聚类标签分布: {np.bincount(labels)}')
print(f'某样本归属概率: {probs[0]}')
```

### 场景二：手写 EM 算法估计 GMM 参数

面试手撕：实现一维 GMM 的 EM 迭代，展示对算法原理的掌握。

```python
import numpy as np

def gmm_em_1d(data, k=2, iters=50):
    n = len(data)
    # 初始化：随机混合系数、均值、方差
    pi = np.full(k, 1 / k)
    mu = np.random.choice(data, k)
    sigma = np.ones(k) * np.var(data)

    for _ in range(iters):
        # E 步：计算责任值 γ
        gamma = np.zeros((n, k))
        for j in range(k):
            gamma[:, j] = pi[j] * np.exp(-(data - mu[j]) ** 2 / (2 * sigma[j])) / np.sqrt(2 * np.pi * sigma[j])
        gamma /= gamma.sum(axis=1, keepdims=True)

        # M 步：更新参数
        nk = gamma.sum(axis=0)
        pi = nk / n
        mu = (gamma * data[:, None]).sum(axis=0) / nk
        sigma = (gamma * (data[:, None] - mu) ** 2).sum(axis=0) / nk
    return pi, mu, sigma

data = np.concatenate([np.random.randn(500) * 1.5 + 2, np.random.randn(500) * 0.8 - 1])
pi, mu, sigma = gmm_em_1d(data, k=2)
print(f'混合系数: {pi}')
print(f'均值: {mu}')
print(f'方差: {sigma}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 面试被问模型原理，先讲「损失函数 → 优化方法 → 关键推导」，层层递进
2. 对比类问题（LR vs SVM、GBDT vs RF、XGBoost vs LightGBM）要答出「本质区别」
3. 树模型要能说出正则化参数（γ、λ、max_depth、min_child_weight）的作用
4. PCA、K-Means、GMM 前务必标准化/归一化，否则结果被量纲主导
5. 答 K-Means 时主动提「对初始化敏感、k-means++、肘部法选 K」体现深度
6. 记住 XGBoost 分裂增益公式并会口述每项含义，是加分项
7. GMM/EM 答「保证似然单调不减、收敛到局部最优」是关键得分点

### 踩坑记录

```text
坑 1：PCA 前不标准化
结论：主成分被量纲大的特征主导，降维结果失真。
原因：PCA 最大化方差，量纲大的特征方差天然大，掩盖真实结构。
解法：StandardScaler 标准化后再 PCA。

坑 2：K-Means 用随机初始化只跑一次
结论：陷入差的局部最优，聚类结果不稳定。
原因：K-Means 对初始中心敏感，目标非凸。
解法：用 k-means++ 初始化，并 n_init 多次取 SSE 最小的结果。

坑 3：XGBoost 树数过多且无 early stopping
结论：训练集过拟合，测试集性能下降。
原因：Boosting 模型复杂度随树数增加，学习率大时尤其明显。
解法：设小学习率 + early_stopping_rounds，监控验证集指标。

坑 4：LightGBM 用默认 num_leaves 在小数据上过拟合
结论：leaf-wise 长太深，泛化差。
原因：num_leaves 过大时 leaf-wise 易长出极深单枝。
解法：限制 num_leaves（约 2^max_depth 以下）和 min_data_in_leaf。

坑 5：把 GMM 的 predict 当成硬标签后算精度
结论：误以为 GMM 输出确定类别，忽略软分配和不确定性。
原因：GMM 是概率模型，predict 只是取后验最大，丢失了概率信息。
解法：用 predict_proba 看归属置信度，低置信样本要谨慎处理。
```
