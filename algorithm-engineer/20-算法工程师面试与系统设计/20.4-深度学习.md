import torch

## BP

反向传播（Backpropagation）是神经网络训练的核心：用链式法则从输出层向输入层逐层计算梯度，更新参数。

```text
核心概念：
- 前向传播：输入逐层计算得到输出和损失
- 反向传播：用链式法则计算损失对每个参数的梯度 ∂L/∂W
- 链式法则：∂L/∂x = ∂L/∂y · ∂y/∂x，逐层传递
- 梯度消失/爆炸：深层网络中梯度连乘，激活函数导数 <1 导致消失，>1 导致爆炸
- 自动微分：PyTorch 的 autograd 自动计算梯度，无需手写求导
```

```text
高频面试题：
Q1：BP 的数学过程？
答：先前向算出各层激活值和损失 L；再反向，从输出层开始用链式法则逐层计算
   ∂L/∂W 和 ∂L/∂激活；最后用梯度下降更新参数。本质是「损失对每层参数偏导」
   的高效计算（避免重复计算中间梯度）。

Q2：梯度消失和爆炸的原因与解决？
答：深层网络中梯度逐层连乘，若每层梯度小于 1 则指数衰减（消失），大于 1 则
   指数增大（爆炸）。解决：用 ReLU 类激活（导数恒 1 不衰减）、BatchNorm、
   残差连接（ResNet 短路梯度）、梯度裁剪（爆炸）、更好的初始化（Xavier/He）。

Q3：PyTorch 的 autograd 原理？
答：前向时记录所有操作的张量计算图（requires_grad=True），反向时按拓扑逆序
   用链式法则自动求导，梯度累积到 .grad。loss.backward() 触发，zero_grad()
   清空以避免梯度累积。
```

```python
import torch
import torch.nn as nn

# 手写 BP：单隐藏层网络
class MLP:
    def __init__(self, d_in, d_hidden, d_out, lr=0.1):
        self.W1 = torch.randn(d_in, d_hidden, requires_grad=False) * 0.1
        self.b1 = torch.zeros(d_hidden)
        self.W2 = torch.randn(d_hidden, d_out) * 0.1
        self.b2 = torch.zeros(d_out)
        self.lr = lr

    def forward(self, x):
        self.h = torch.tanh(x @ self.W1 + self.b1)   # 保存中间值供反向
        self.out = self.h @ self.W2 + self.b2
        return self.out

    def backward(self, x, y):
        # 链式法则手推梯度
        d_out = self.out - y                          # MSE 梯度
        d_W2 = self.h.T @ d_out / len(y)
        d_b2 = d_out.mean(0)
        d_h = d_out @ self.W2.T * (1 - self.h ** 2)   # tanh 导数
        d_W1 = x.T @ d_h / len(y)
        d_b1 = d_h.mean(0)
        # 更新
        for param, grad in [(self.W1, d_W1), (self.b1, d_b1),
                            (self.W2, d_W2), (self.b2, d_b2)]:
            param.data -= self.lr * grad
        return ((self.out - y) ** 2).mean().item()

X = torch.randn(32, 4)
y = torch.randn(32, 1)
mlp = MLP(4, 8, 1)
mlp.forward(X)
loss = mlp.backward(X, y)
print(f'手写 BP 完成, loss={loss:.4f}')
```

## CNN

卷积神经网络（CNN）通过卷积核提取局部特征、权值共享降低参数量，是图像处理的核心结构。

```text
核心概念：
- 卷积层：卷积核在输入上滑动，局部连接 + 权值共享
- 池化层：最大/平均池化，下采样、增加平移不变性
- 感受野：输出特征图一个单元对应输入区域的大小
- 参数量：卷积层 = (k·k·C_in + 1)·C_out；全连接 = in·out
- 关键结构：ResNet 残差连接、Inception 多尺度、Depthwise 分离卷积
```

```text
高频面试题：
Q1：卷积相比全连接的优势？
答：(1) 权值共享，参数量从 in·out 降到 k²·C_in·C_out，大幅减少参数；
   (2) 局部连接，每个输出只依赖局部感受野，捕捉空间局部特征；(3) 平移
   等变性，图像特征位置移动时卷积仍能识别。

Q2：感受野怎么计算？
答：逐层叠加：RF = RF_prev + (k - 1) × stride 累积。堆叠多个小卷积核（如两个
   3×3 等价一个 5×5 感受野）参数更少、非线性更强，这是 VGG 的核心思想。

Q3：池化的作用？最大池化和平均池化区别？
答：下采样缩小特征图、减少计算量、增大感受野、增强平移不变性。最大池化保留
   最显著特征、对纹理敏感；平均池化保留整体信息、对背景更平滑。
```

```python
import torch.nn as nn

# 参数量计算
def conv_params(k, c_in, c_out):
    return (k * k * c_in + 1) * c_out

print(f'3x3 卷积 (64->128): {conv_params(3, 64, 128)}')   # 73856
print(f'1x1 卷积 (256->64): {conv_params(1, 256, 64)}')   # 16448

# 一个简单 CNN
class SimpleCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        )
        self.fc = nn.Linear(64 * 8 * 8, 10)

    def forward(self, x):
        x = self.features(x)
        return self.fc(x.flatten(1))

x = torch.randn(2, 3, 32, 32)
print(SimpleCNN()(x).shape)   # [2, 10]
```

## RNN

循环神经网络（RNN）通过隐藏状态的循环连接建模序列信息，是处理时序/文本的经典结构。

```text
核心概念：
- 循环结构：h_t = tanh(W·x_t + U·h_{t-1} + b)，隐藏状态携带历史信息
- 参数共享：所有时间步共享同一组参数 W/U/b
- 适用：序列建模、语言模型、时序预测
- 问题：长序列下梯度消失/爆炸，难以捕捉长期依赖
- BPTT：按时间展开的反向传播
```

```text
高频面试题：
Q1：RNN 为什么有梯度消失问题？
答：BPTT 中梯度要沿时间步连乘，隐藏状态转移矩阵 W 的幂若特征值 <1 则指数
   衰减，导致早期时间步的梯度消失，长距离依赖学不到。LSTM/GRU 通过门控和
   加法路径缓解。

Q2：RNN 的参数共享体现在哪？
答：所有时间步用同一组权重 W/U/b，与序列长度无关，因此能处理变长序列且
   参数量不随长度增长。这也使 RNN 具有「位置无关的归纳偏置」。

Q3：RNN 和 CNN、Transformer 处理序列的区别？
答：RNN 串行、O(n) 时间步，长依赖难学；CNN 并行但感受野固定，需堆叠扩大；
   Transformer 并行、自注意力直接建模任意两位置关系，长依赖更好，但复杂度
   O(n²)。这是 Transformer 取代 RNN 的原因。
```

```python
import torch.nn as nn

# PyTorch RNN 使用
rnn = nn.RNN(input_size=10, hidden_size=20, num_layers=2, batch_first=True)
x = torch.randn(5, 3, 10)   # (batch=5, seq_len=3, features=10)
out, h_n = rnn(x)
print(f'RNN 输出: {out.shape}, 最终隐藏: {h_n.shape}')

# 手写单步 RNN
def rnn_cell(x_t, h_prev, W, U, b):
    return torch.tanh(x_t @ W + h_prev @ U + b)

W = torch.randn(10, 20); U = torch.randn(20, 20); b = torch.zeros(20)
h = torch.zeros(20)
for t in range(3):
    h = rnn_cell(x[0, t], h, W, U, b)
print(f'手写 RNN 最终隐藏状态维度: {h.shape}')
```

## LSTM

长短期记忆网络（LSTM）通过门控机制和细胞状态（cell state）解决 RNN 的长期依赖问题。

```text
核心概念：
- 细胞状态 C_t：贯穿时间步的「主干」，用加法更新，梯度可稳定传递
- 三个门：遗忘门 f（丢弃旧信息）、输入门 i（写入新信息）、输出门 o（控制输出）
- 候选值：Ĉ_t = tanh(...)，当前输入产生的新候选记忆
- 更新：C_t = f·C_{t-1} + i·Ĉ_t，h_t = o·tanh(C_t)
- 梯度改善：加法路径 + 门控，缓解梯度消失
```

```text
高频面试题：
Q1：LSTM 如何缓解梯度消失？
答：细胞状态 C_t 的更新是「加法」而非「连乘」，梯度可沿 C 的路径几乎无损
   传递；遗忘门 f 接近 1 时保留历史梯度，接近 0 时主动丢弃。相比 RNN 的
   连乘 tanh，LSTM 的梯度能跨长时间步流动。

Q2：三个门的作用？
答：遗忘门决定丢弃多少旧细胞状态；输入门决定写入多少新候选值；输出门决定
   输出多少当前细胞状态到隐藏状态 h。三者都是 sigmoid 输出 (0,1) 的「闸门」。

Q3：LSTM 和 GRU 的区别？
答：GRU 简化 LSTM：合并遗忘门和输入门为「更新门」、去掉细胞状态、用「重置门」
   控制历史信息。参数更少、训练更快，效果接近。LSTM 表达力更强、适合更复杂
   的长期依赖。
```

```python
import torch.nn as nn

# LSTM 使用
lstm = nn.LSTM(input_size=10, hidden_size=20, num_layers=2, batch_first=True)
x = torch.randn(5, 3, 10)
out, (h_n, c_n) = lstm(x)
print(f'LSTM 输出: {out.shape}, 隐藏: {h_n.shape}, 细胞: {c_n.shape}')

# 手写 LSTM 单步
def lstm_cell(x_t, h_prev, c_prev):
    gate = nn.Linear(30, 80)(torch.cat([x_t, h_prev], -1))   # 4 个门拼一起
    i, f, g, o = gate.chunk(4, dim=-1)
    i, f, o = torch.sigmoid(i), torch.sigmoid(f), torch.sigmoid(o)
    g = torch.tanh(g)
    c = f * c_prev + i * g
    h = o * torch.tanh(c)
    return h, c

print('LSTM 门控结构展示完成')
```

## Attention

注意力机制（Attention）让模型动态关注输入的「重要部分」，是 Transformer 的基石。

```text
核心概念：
- 核心思想：根据 Query 和 Key 的相似度，对 Value 加权求和
- 公式：Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V
- 缩放因子 √d_k：防止点积过大导致 softmax 梯度消失
- 自注意力：Q、K、V 来自同一序列，捕捉序列内部依赖
- 多头注意力：多组 QKV 并行，捕捉不同子空间的关系
```

```text
高频面试题：
Q1：为什么要除以 √d_k？
答：点积 QKᵀ 的方差随维度 d_k 增大而增大，值过大时 softmax 进入饱和区，梯度
   接近 0。除以 √d_k 把方差归一化到 1，保持 softmax 梯度稳定。

Q2：自注意力和交叉注意力的区别？
答：自注意力 Q、K、V 来自同一序列（捕捉内部依赖）；交叉注意力 Q 来自一个
   序列、K/V 来自另一个（如 Transformer 解码器中 query 来自目标、key/value
   来自编码器输出），建模跨序列对齐。

Q3：Attention 相比 RNN 的优势？
答：(1) 并行计算，所有位置同时算，训练快；(2) 任意两位置的依赖路径长度 O(1)，
   无长距离衰减；(3) 可解释性强，注意力权重可视化。代价是 O(n²) 复杂度。
```

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn = F.softmax(scores, dim=-1)
    return attn @ V, attn

Q = torch.randn(2, 4, 64)
K = torch.randn(2, 4, 64)
V = torch.randn(2, 4, 64)
out, attn = scaled_dot_product_attention(Q, K, V)
print(f'注意力输出: {out.shape}, 权重: {attn.shape}')

# 多头注意力
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model=64, n_heads=4):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, N, _ = x.shape
        Q = self.W_q(x).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(B, N, self.n_heads, self.d_k).transpose(1, 2)
        out, _ = scaled_dot_product_attention(Q, K, V)
        out = out.transpose(1, 2).contiguous().view(B, N, -1)
        return self.W_o(out)

print(MultiHeadAttention()(torch.randn(2, 4, 64)).shape)   # [2, 4, 64]
```

## Transformer

Transformer 是完全基于注意力机制的序列模型，由编码器-解码器堆叠而成，是当今 LLM 的底座。

```text
核心概念：
- 结构：多头自注意力 + 前馈网络（FFN）+ 残差连接 + LayerNorm 堆叠
- 位置编码：正弦位置编码（原始）或可学习位置编码，弥补无顺序信息
- FFN：两层线性 + 激活（通常 4 倍中间维度）
- 编码器：双向自注意力；解码器：掩码自注意力 + 交叉注意力
- 优点：并行、长依赖；缺点：O(n²) 复杂度，长序列受限
```

```text
高频面试题：
Q1：为什么需要位置编码？
答：自注意力是「集合」操作，本身不区分位置顺序，交换输入顺序输出不变。位置
   编码把位置信息注入输入（加法或可学习嵌入），让模型感知顺序。

Q2：LayerNorm 放在哪？为什么是 Post-Norm/Pre-Norm？
答：原始论文是 Post-Norm（残差之后 LN），后来 Pre-Norm（残差之前）训练更稳定、
   成为主流。Pre-Norm 让梯度能更直接地流到深层，缓解深层训练不稳定。

Q3：Transformer 的复杂度是多少？
答：自注意力 O(n²·d)，FFN O(n·d²)。序列长度 n 是瓶颈，长文本需优化：稀疏
   注意力、FlashAttention、线性注意力、KV Cache 等。
```

```python
import torch.nn as nn

# Transformer Encoder Layer
encoder_layer = nn.TransformerEncoderLayer(d_model=64, nhead=4, dim_feedforward=128, batch_first=True)
encoder = nn.TransformerEncoder(encoder_layer, num_layers=2)

x = torch.randn(2, 8, 64)
print(encoder(x).shape)   # [2, 8, 64]

# 手写 Transformer Block
class TransformerBlock(nn.Module):
    def __init__(self, d_model=64, n_heads=4, d_ff=128):
        super().__init__()
        self.attn = MultiHeadAttention(d_model, n_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.GELU(), nn.Linear(d_ff, d_model))

    def forward(self, x):
        x = self.norm1(x + self.attn(x))    # Post-Norm + 残差
        x = self.norm2(x + self.ffn(x))
        return x

block = TransformerBlock()
print(block(torch.randn(2, 8, 64)).shape)   # [2, 8, 64]
```

## Normalization

归一化层稳定训练、加速收敛，是深度网络不可或缺的组件。核心是 BN 与 LN 的区别。

```text
核心概念：
- BatchNorm：对 batch 维度归一化，每个特征通道独立，需要足够大 batch
- LayerNorm：对单个样本的特征维度归一化，与 batch 无关
- 其他：InstanceNorm（图像风格迁移）、GroupNorm（小 batch 的 CV 替代）
- 作用：缓解内部协变量偏移、平滑损失曲面、允许更大学习率
- 训练/推理差异：BN 训练用 batch 统计量，推理用滑动平均统计量
```

```text
高频面试题：
Q1：BN 和 LN 的区别？
答：BN 在 batch 维度上对每个特征做归一化，依赖 batch 统计量，适合 CNN（batch
   较大、特征有空间共享）；LN 在单个样本的特征维度上做归一化，与 batch 无关，
   适合序列模型（RNN/Transformer，batch 内样本长度不一）。Transformer 用 LN。

Q2：为什么 Transformer 用 LN 不用 BN？
答：Transformer 处理变长序列，batch 内序列长度不同、pad 位置不齐，BN 的 batch
   统计量不稳定且语义混乱；LN 逐样本归一化，天然适合序列，且训练/推理一致。

Q3：BN 训练和推理时有什么区别？
答：训练时用当前 mini-batch 的均值/方差归一化；推理时用训练过程中维护的滑动
   平均均值/方差（running_mean/running_var），保证单样本推理的稳定性。
```

```python
import torch.nn as nn

# BN vs LN 对比
x = torch.randn(4, 16, 32, 32)   # (batch, channel, h, w) 图像
bn = nn.BatchNorm2d(16)
print(f'BN 输出: {bn(x).shape}')

seq = torch.randn(4, 20, 64)     # (batch, seq, dim) 序列
ln = nn.LayerNorm(64)
print(f'LN 输出: {ln(seq).shape}')

# 手写 LayerNorm
def layer_norm(x, eps=1e-5):
    mean = x.mean(-1, keepdim=True)
    var = x.var(-1, unbiased=False, keepdim=True)
    return (x - mean) / (var + eps).sqrt()

print(f'手写 LN 与官方一致: {torch.allclose(layer_norm(seq), ln(seq), atol=1e-4)}')
```

## Optimizer

优化器决定参数更新策略，从 SGD 到 Adam 的演进体现了对训练稳定性和收敛速度的权衡。

```text
核心概念：
- SGD：w -= lr·g，简单但震荡、收敛慢
- Momentum：累积历史梯度 v = βv + g，加速收敛、抑制震荡
- NAG：在「前瞻」位置计算梯度
- AdaGrad：自适应学习率，累积梯度平方，适合稀疏
- RMSProp：指数移动平均梯度平方，解决 AdaGrad 学习率衰减过快
- Adam：Momentum + RMSProp 结合，最常用
```

```text
高频面试题：
Q1：Adam 为什么好用？公式？
答：Adam 结合动量（一阶矩 m）和自适应学习率（二阶矩 v），并做偏差校正：
   m = β1·m + (1-β1)·g，v = β2·v + (1-β2)·g²，校正后 w -= lr·m̂/(√v̂+ε)。
   收敛快、对超参数不敏感、适合大多数场景。

Q2：SGD + Momentum 和 Adam 怎么选？
答：Adam 收敛快、鲁棒，适合快速迭代和大多数任务；SGD+Momentum 泛化性有时
   更好，适合调参充分、追求极致精度的场景（如某些 CV 任务）。实践中常先
   Adam 快速验证，再用 SGD 精调。

Q3：学习率调度（scheduler）的作用？
答：训练初期大学习率快速收敛，后期小学习率精调避免震荡。常用：阶梯衰减、
   余弦退火、Warmup（前几步从小学习率线性上升，稳定初期训练，Transformer
   训练必备）。
```

```python
import torch.optim as optim
import torch.nn as nn

model = nn.Linear(10, 1)
x, y = torch.randn(100, 10), torch.randn(100, 1)

# 三种优化器对比
for name, opt in [
    ('SGD', optim.SGD(model.parameters(), lr=0.01)),
    ('Momentum', optim.SGD(model.parameters(), lr=0.01, momentum=0.9)),
    ('Adam', optim.Adam(model.parameters(), lr=0.01)),
]:
    model.zero_grad()
    loss = nn.functional.mse_loss(model(x), y)
    loss.backward()
    opt.step()
    print(f'{name}: loss={loss.item():.4f}')

# 学习率调度 + warmup
scheduler = optim.lr_scheduler.CosineAnnealingLR(optim.Adam(model.parameters(), lr=1e-3), T_max=100)
print('优化器与调度器就绪')
```

## 应用场景实战

### 场景一：手写 Attention 完成序列建模

面试手撕：从零实现 scaled dot-product attention + 前向计算，展示对公式的掌握。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def attention_forward(Q, K, V):
    d_k = Q.shape[-1]
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
    weights = F.softmax(scores, dim=-1)
    return weights @ V, weights

# 模拟一句话的自注意力
seq_len, d_model = 6, 8
emb = torch.randn(seq_len, d_model)
W_q, W_k, W_v = (torch.randn(d_model, d_model) for _ in range(3))

Q, K, V = emb @ W_q, emb @ W_k, emb @ W_v
out, weights = attention_forward(Q, K, V)
print(f'注意力输出: {out.shape}')
print(f'注意力权重矩阵每行和为 1: {torch.allclose(weights.sum(-1), torch.ones(seq_len))}')
```

### 场景二：残差连接缓解梯度消失实验

面试手撕：对比有无残差连接时深层网络的梯度范数。

```python
import torch
import torch.nn as nn

def check_grad(depth, use_residual):
    layers = []
    for _ in range(depth):
        layers.append(nn.Linear(32, 32))
        layers.append(nn.Tanh())
    x = torch.randn(8, 32, requires_grad=True)
    h = x
    for i in range(0, len(layers), 2):
        linear, act = layers[i], layers[i + 1]
        out = act(linear(h))
        h = h + out if use_residual else out   # 残差连接
    h.sum().backward()
    return x.grad.norm().item()

for depth in [20, 50]:
    print(f'深度 {depth}: 无残差梯度范数={check_grad(depth, False):.6f}, '
          f'有残差={check_grad(depth, True):.6f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 面试被问网络结构，先画结构再讲「为什么这样设计」，突出演进动机
2. 回答梯度消失问题，主动给出「激活函数 + BN + 残差 + 初始化」四件套
3. 计算参数量、感受野、FLOPs 是高频动手题，要熟练
4. LSTM 答门控时强调「加法路径 + 门控」如何让梯度跨时间步流动
5. 回答 Transformer 时能说出 Pre-Norm/Post-Norm 区别是加分项
6. Optimizer 题记住 Adam 的偏差校正和「一阶/二阶矩」两个关键词
7. 训练相关题（loss 不降、梯度爆炸）要能落到「调 lr、加 BN、梯度裁剪」

### 踩坑记录

```text
坑 1：忘记 model.eval() 导致 BN/Dropout 行为错误
结论：推理结果不稳定、BN 用了 batch 统计量。
原因：训练和推理时 BN、Dropout 行为不同，不切换导致结果偏差。
解法：推理前 model.eval()，训练前 model.train()。

坑 2：Adam 学习率开太大导致 loss 震荡不收敛
结论：训练曲线剧烈震荡，loss 不降或发散。
原因：Adam 自适应学习率对初始 lr 仍敏感，lr 过大跳过最优。
解法：Adam 常用 1e-3 起步，震荡则降 lr 或加 warmup。

坑 3：手写 Attention 忘记除以 sqrt(d_k)
结论：softmax 进入饱和区，梯度消失，训练不动。
原因：点积值随维度增大，未缩放导致 softmax 分布尖锐。
解法：scores 除以 d_k 的平方根，保持梯度稳定。

坑 4：Transformer 训练不加 warmup 导致初期不稳定
结论：训练初期 loss 剧烈波动甚至 NaN。
原因：初期梯度大且方向未稳，大学习率破坏训练。
解法：warmup 从极小 lr 线性上升到目标 lr，再按余弦衰减。

坑 5：把 BN 直接套在 RNN/Transformer 上
结论：batch 内变长序列统计量不稳定，效果差。
原因：BN 依赖 batch 维度统计，序列模型 batch 内样本长度/结构不一。
解法：序列模型用 LayerNorm，逐样本归一化。
```
