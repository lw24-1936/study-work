## 概述

计算机视觉面试分「传统 CV」和「深度视觉」两条线：传统 CV 考察 OpenCV 图像处理、特征点匹配、相机标定等基本功；深度视觉考察目标检测、OCR、目标跟踪等模型的原理与选型。算法工程师面试以原理题为主，OpenCV 实操为辅。

```text
视觉面试高频考点：
1. OpenCV —— 图像表示、色彩空间、核心 API
2. 图像处理 —— 滤波、边缘检测、形态学、直方图
3. 特征点 —— SIFT/ORB、特征匹配、单应性
4. 目标检测 —— 两阶段/单阶段、YOLO、NMS、评价指标
5. OCR —— 检测 + 识别两段式、CTPN/CRNN
6. Tracking —— 多目标跟踪、卡尔曼滤波、匈牙利匹配
7. Camera Calibration —— 内参/外参、畸变矫正、张正友标定
```

## OpenCV

OpenCV 是计算机视觉最主流的开源库，面试考察图像表示、色彩空间和核心数据结构的理解。

```text
核心概念：
- 图像表示：numpy 数组，H×W×C，BGR 顺序（不是 RGB）
- 数据类型：uint8（0-255），浮点图（0-1）用于计算
- 色彩空间：BGR、灰度、HSV、Lab，不同任务选不同空间
- 通道顺序：OpenCV 默认 BGR，matplotlib/PIL 是 RGB，需注意转换
- 基础操作：读取/写入、缩放、裁剪、旋转、阈值、像素访问
```

```text
高频面试题：
Q1：为什么 OpenCV 用 BGR 而不是 RGB？
答：历史原因，OpenCV 早期沿用 BGR 格式（受某些硬件/格式影响）。实用上要注意
   OpenCV 与其他库（matplotlib/PIL）的通道顺序差异，混用前做 cvtColor 转换。

Q2：HSV 色彩空间有什么优势？
答：HSV 把「色调 H、饱和度 S、明度 V」分离，颜色信息集中在 H，对光照变化
   更鲁棒，颜色分割/检测（如识别红色）在 HSV 里比 BGR 更简单直接。

Q3：图像 resize 的插值方法有哪些？
答：INTER_NEAREST 最近邻（快、有锯齿）、INTER_LINEAR 双线性（默认、平滑）、
   INTER_CUBIC 双三次（更平滑、慢）、INTER_AREA 区域插值（缩小图像推荐，
   避免混叠）。
```

```python
import cv2
import numpy as np

rotated = cv2.warpAffine(img, M, (300, 200))
print(f'缩放: {resized.shape}, 旋转: {rotated.shape}')
```

## 图像处理

图像处理是视觉的基础功：滤波去噪、边缘检测、形态学操作、直方图分析。

```text
核心概念：
- 滤波：均值（平滑）、高斯（加权平滑去噪）、中值（去椒盐噪声）、双边（保边去噪）
- 边缘检测：Sobel（一阶梯度）、Canny（多级：高斯+梯度+非极大抑制+双阈值）
- 形态学：腐蚀（缩小亮区）、膨胀（扩大亮区）、开运算（去噪点）、闭运算（补洞）
- 直方图：统计像素分布，直方图均衡化增强对比度
- 阈值：全局阈值、Otsu 自适应阈值
```

```text
高频面试题：
Q1：高斯滤波和中值滤波的区别？
答：高斯滤波是线性加权平均，对高斯噪声效果好，但会模糊边缘；中值滤波取邻域
   中位数，是非线性滤波，对椒盐噪声（孤立亮点）效果好且能较好保留边缘。

Q2：Canny 边缘检测的步骤？
答：1) 高斯滤波去噪；2) 计算梯度幅值和方向（Sobel）；3) 非极大值抑制，只保留
   梯度方向上的局部最大值；4) 双阈值 + 边缘连接，强边缘保留，弱边缘与强边缘
   相连才保留。

Q3：开运算和闭运算的作用？
答：开运算（先腐蚀后膨胀）去掉小的亮噪点和毛刺、分离粘连物体；闭运算（先
   膨胀后腐蚀）填充小孔洞、连接断裂边缘。都是「腐蚀+膨胀」的组合，保持主体
   尺寸基本不变。
```

```python
import cv2
import numpy as np

# 构造带噪声的图像
img = np.zeros((100, 100), dtype=np.uint8)
img[30:70, 30:70] = 255                    # 白色方块
noise = np.random.rand(100, 100) < 0.05    # 5% 椒盐噪声
img[noise] = np.random.choice([0, 255], noise.sum())

# 中值滤波去椒盐噪声
denoised = cv2.medianBlur(img, 3)

# Canny 边缘检测
edges = cv2.Canny(img, 50, 150)

# 形态学开运算去噪点
kernel = np.ones((3, 3), np.uint8)
opened = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)

# 直方图均衡化
equ = cv2.equalizeHist(img.astype(np.uint8))
print(f'去噪后边缘像素数: {edges.sum()}, 开运算后白色像素: {(opened == 255).sum()}')
```

## 特征点

特征点检测与匹配是传统视觉的核心：在图像中找稳定、可重复的关键点并描述，用于匹配、拼接、SLAM。

```text
核心概念：
- 特征点特性：可重复性（同场景不同图能检出）、区分性（不同点描述不同）、鲁棒性
- SIFT：尺度不变（DoG 金字塔）+ 旋转不变（主方向）+ 128 维描述子，专利算法
- ORB：FAST 角点 + BRIEF 描述子 + 方向，免费、快，实时应用首选
- 匹配：暴力匹配（BFMatcher）、FLANN（快速近似最近邻）
- 几何验证：RANSAC 求单应性矩阵，剔除错误匹配
```

```text
高频面试题：
Q1：SIFT 和 ORB 的区别？
答：SIFT 精度高、尺度/旋转/光照不变性强，但计算量大、有专利（OpenCV 需编译
   contrib）；ORB 基于 FAST+BRIEF，速度快、免费、适合实时，但尺度不变性较弱。
   工程上移动端/实时用 ORB，精度要求高用 SIFT 或深度特征。

Q2：如何实现尺度不变性？
答：构建图像金字塔（不同尺度的高斯模糊 + 下采样），在每个尺度检测特征点，
   匹配时允许不同尺度的点对应，从而实现尺度不变。SIFT 用 DoG（高斯差分）
   金字塔检测极值点。

Q3：如何剔除错误匹配？
答：用 RANSAC（随机采样一致性）估计单应性矩阵，只保留符合几何变换的内点，
   剔除离群点。也可用 Lowe's ratio test（最近邻/次近邻距离比）预先过滤。
```

```python
import cv2
import numpy as np

# 构造两张有平移+旋转关系的图
img1 = np.zeros((200, 200), dtype=np.uint8)
cv2.rectangle(img1, (50, 50), (150, 150), 255, -1)
cv2.circle(img1, (100, 100), 20, 0, -1)

M = np.float32([[1, 0, 10], [0, 1, 5]])
img2 = cv2.warpAffine(img1, M, (200, 200))

# ORB 特征点检测与匹配
orb = cv2.ORB_create()
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)

bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
matches = sorted(matches, key=lambda x: x.distance)
print(f'ORB 匹配点数: {len(matches)}')
print(f'最近匹配距离: {matches[0].distance:.1f}')
```

## 目标检测

目标检测是视觉面试的重头戏，考察两阶段/单阶段方法的演进、YOLO 系列和评价指标。

```text
核心概念：
- 任务：定位（bbox）+ 分类（类别）
- 两阶段：R-CNN 系列（Fast/Faster R-CNN），RPN 提候选 + 精修，精度高、慢
- 单阶段：YOLO/SSD，直接回归 bbox + 分类，快、适合实时
- NMS：非极大值抑制，去掉重叠的重复框
- 评价指标：mAP、IoU、Precision/Recall、FPS
```

```text
高频面试题：
Q1：两阶段和单阶段检测的区别？
答：两阶段（Faster R-CNN）先 RPN 生成候选框再做分类回归，精度高但慢，适合
   对精度要求高的场景；单阶段（YOLO）直接端到端回归，速度快、适合实时，
   精度略低（尤其小目标）。YOLO 通过 anchor、特征金字塔等不断缩小差距。

Q2：NMS 的原理？
答：按置信度降序排列检测框，取最高分框保留，计算它与其他框的 IoU，IoU 超过
   阈值的框视为重复被抑制；对剩余框重复。Soft-NMS 不直接删除而是降低分数，
   缓解密集场景漏检。

Q3：mAP 怎么计算？
答：对每个类别，按置信度排序，逐点计算 Precision/Recall 画 PR 曲线，曲线下
   面积即 AP；所有类别 AP 的平均即 mAP。IoU 阈值（如 0.5）决定框是否算命中。
```

```python
import numpy as np

# 手写 IoU 和 NMS
def iou(box1, box2):
    x1 = max(box1[0], box2[0]); y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2]); y2 = min(box1[3], box2[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    return inter / (area1 + area2 - inter + 1e-6)

def nms(boxes, scores, threshold=0.5):
    # boxes: [x1,y1,x2,y2]，按分数降序
    order = np.argsort(scores)[::-1]
    keep = []
    while order.size > 0:
        i = order[0]
        keep.append(i)
        if order.size == 1:
            break
        ious = np.array([iou(boxes[i], boxes[j]) for j in order[1:]])
        order = order[1:][ious < threshold]
    return keep

boxes = np.array([[0, 0, 10, 10], [1, 1, 11, 11], [50, 50, 60, 60]])
scores = np.array([0.9, 0.8, 0.7])
print(f'NMS 保留的框: {nms(boxes, scores)}')   # [0, 2]
```

## OCR

OCR（光学字符识别）通常采用「检测 + 识别」两段式：先定位文本区域，再识别文字内容。

```text
核心概念：
- 两段式：文本检测（定位文本框）+ 文本识别（识别文字序列）
- 文本检测：CTPN（水平文本）、EAST、DBNet（任意形状）、PSENet
- 文本识别：CRNN（CNN 提特征 + RNN 序列建模 + CTC 解码），无需字符级标注
- CTC Loss：处理不定长序列对齐，允许重复字符和 blank
- 应用：证件识别、票据识别、车牌识别、文档数字化
```

```text
高频面试题：
Q1：OCR 为什么用两段式？
答：检测和识别任务性质不同——检测是定位回归问题，识别是序列分类问题。分离后
   各自可独立优化、复用，且工业上常先检测裁剪再识别，便于端到端调优。

Q2：CRNN 的结构？为什么用 CTC？
答：CRNN = CNN（提取视觉特征）+ RNN（建模字符序列依赖）+ CTC（序列对齐）。
   CTC 引入 blank 符号解决「图像特征帧数 ≠ 文本长度」的对齐问题，无需逐字符
   标注，直接端到端训练。

Q3：如何处理弯曲文本 / 任意形状文本？
答：水平文本用 CTPN/CRNN；弯曲/任意形状用 DBNet（可微二值化，输出概率图+阈值
   图）或 PSENet（渐进尺度扩张），能检测任意形状的文本区域。
```

```python
import numpy as np

# 手写 CTC 解码（贪心解码）
def ctc_decode(logits, blank=0):
    # logits: [T, C] 每帧的分类概率，取 argmax
    pred = np.argmax(logits, axis=1)
    result = []
    prev = blank
    for p in pred:
        if p != prev:            # 与前一帧不同才输出
            if p != blank:       # blank 跳过
                result.append(p)
        prev = p
    return result

# 模拟一段识别结果：重复字符 + blank
logits = np.array([
    [0.9, 0.05, 0.05],   # 帧0: blank
    [0.1, 0.8, 0.1],     # 帧1: 'A'
    [0.1, 0.8, 0.1],     # 帧2: 'A'（重复）
    [0.9, 0.05, 0.05],   # 帧3: blank
    [0.1, 0.1, 0.8],     # 帧4: 'B'
])
print(f'CTC 解码结果: {ctc_decode(logits)}')   # [1, 2] → "AB"
```

## Tracking

目标跟踪在视频序列中持续定位目标，分单目标跟踪（SOT）和多目标跟踪（MOT）。

```text
核心概念：
- SOT：给定首帧目标框，后续帧持续跟踪（KCF、Siamese 系列）
- MOT：检测 + 关联，多个目标同时跟踪（SORT、DeepSORT、ByteTrack）
- 关联：匈牙利算法做二分图匹配（检测框 vs 已有轨迹）
- 卡尔曼滤波：预测目标位置 + 状态估计，平滑轨迹
- 评价：MOTA（多目标跟踪准确度）、IDF1（身份保持）、ID Switch 数
```

```text
高频面试题：
Q1：SORT 和 DeepSORT 的区别？
答：SORT 用卡尔曼滤波预测 + IoU 做匈牙利匹配，简单快但遮挡/ID 切换多；
   DeepSORT 在 IoU 基础上引入外观特征（ReID 网络提取），用外观+运动联合
   匹配，减少遮挡导致的 ID 切换。

Q2：卡尔曼滤波在跟踪里的作用？
答：根据目标的运动模型预测下一帧位置（先验），再结合检测结果（观测）更新
   估计（后验），在检测缺失/遮挡时仍能维持轨迹预测，并平滑目标运动。

Q3：多目标跟踪的 ID Switch 问题怎么解决？
答：ID Switch 是同一目标被换了 ID。解决：更强的外观特征（DeepSORT）、级联
   匹配（ByteTrack 用高低置信度检测）、轨迹重识别、以及好的匈牙利匹配成本
   设计。
```

```python
import numpy as np

# 手写卡尔曼滤波（一维位置跟踪）
class KalmanFilter1D:
    def __init__(self, q=0.01, r=1.0):
        self.x = 0.0       # 状态（位置）
        self.p = 1.0       # 状态协方差
        self.q = q         # 过程噪声
        self.r = r         # 观测噪声

    def predict(self):
        # 状态不变，协方差加过程噪声
        self.p += self.q
        return self.x

    def update(self, measurement):
        k = self.p / (self.p + self.r)      # 卡尔曼增益
        self.x = self.x + k * (measurement - self.x)
        self.p = (1 - k) * self.p
        return self.x

kf = KalmanFilter1D()
true_positions = [0, 1, 2, 3, 4, 5]
measurements = [0, 0.8, 2.3, 2.7, 4.1, 4.8]   # 带噪声观测

for m in measurements:
    pred = kf.predict()
    est = kf.update(m)
    print(f'预测={pred:.2f}, 观测={m}, 滤波后={est:.2f}')
```

## Camera Calibration

相机标定求解相机的内参、外参和畸变系数，是三维视觉、AR、测量的基础。

```text
核心概念：
- 内参 K：焦距 fx/fy、主点 cx/cy，描述相机自身光学特性
- 外参 [R|t]：旋转 + 平移，描述相机在世界坐标系的位姿
- 畸变：径向畸变（桶形/枕形）、切向畸变
- 针孔模型：像素坐标 = K · [R|t] · 世界坐标
- 张正友标定：用棋盘格多视角拍摄，求解内外参
```

```text
高频面试题：
Q1：内参和外参的区别？
答：内参（fx, fy, cx, cy）描述相机内部光学几何，与相机位置无关，一次标定
   长期有效；外参（R, t）描述相机在世界坐标系的位姿，随相机移动变化。

Q2：为什么要标定畸变？
答：镜头存在径向和切向畸变，导致直线变弯、图像失真。标定出畸变系数后用
   undistort 校正，使图像符合理想针孔模型，测量/重建才准确。

Q3：张正友标定的流程？
答：打印棋盘格，从多个角度拍摄若干张图；检测角点；利用棋盘格已知的物理尺寸
   和角点对应关系，先求单应性，再通过约束求解内参，进而求每张图的外参和
   畸变系数，最后非线性优化精化。
```

```python
import numpy as np

# 模拟标定数据：生成棋盘格角点（世界坐标 + 图像坐标）
def generate_checkerboard_points(cols=9, rows=6, square_size=0.03):
    objp = np.zeros((cols * rows, 3), np.float32)
    objp[:, :2] = np.mgrid[0:cols, 0:rows].T.reshape(-1, 2) * square_size
    return objp

objp = generate_checkerboard_points()
print(f'世界坐标角点数: {objp.shape}')

# 模拟一个简单投影（针孔模型）
K = np.array([[800, 0, 320], [0, 800, 240], [0, 0, 1]], dtype=np.float32)
point_3d = np.array([0.1, 0.05, 0.5, 1.0])   # 齐次世界坐标
R_t = np.eye(3, 4, dtype=np.float32)         # 假设无旋转平移
proj = K @ R_t @ point_3d
pixel = proj[:2] / proj[2]
print(f'3D 点 {point_3d[:3]} 投影到像素: {pixel}')
```

### 场景一：车牌检测与识别流程

面试手撕：用 OpenCV 走通「灰度 → 滤波 → 边缘 → 轮廓 → 定位」的车牌定位链。

```python
import cv2
import numpy as np

def locate_plate(img):
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    edges = cv2.Canny(blur, 100, 200)
    # 形态学闭运算连接车牌字符区域
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (17, 5))
    closed = cv2.morphologyEx(edges, cv2.MORPH_CLOSE, kernel)
    contours, _ = cv2.findContours(closed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    plates = []
    for c in contours:
        x, y, w, h = cv2.boundingRect(c)
        aspect = w / float(h)
        if 2.0 < aspect < 5.0 and 100 < w < 500:   # 车牌长宽比筛选
            plates.append((x, y, w, h))
    return plates

img = cv2.imread('plate.jpg') if False else np.zeros((300, 500, 3), np.uint8)
cv2.rectangle(img, (100, 120), (400, 180), (255, 255, 255), -1)   # 模拟车牌
print(f'定位到的候选车牌区域数: {len(locate_plate(img))}')
```

### 场景二：手写 mAP 计算

面试手撕：给定检测结果和真值，计算 AP 和 mAP。

```python
import numpy as np

def compute_ap(recall, precision):
    # 11 点插值法
    ap = 0.0
    for t in np.arange(0, 1.1, 0.1):
        p = np.max(precision[recall >= t]) if np.any(recall >= t) else 0
        ap += p / 11
    return ap

def evaluate_detections(pred_boxes, pred_scores, gt_boxes, iou_thresh=0.5):
    # 简化：单类别 AP
    tp = np.zeros(len(pred_boxes))
    fp = np.zeros(len(pred_boxes))
    gt_matched = np.zeros(len(gt_boxes))
    order = np.argsort(-np.array(pred_scores))
    for idx in order:
        best_iou, best_gt = 0, -1
        for j, gt in enumerate(gt_boxes):
            i = iou(pred_boxes[idx], gt)
            if i > best_iou:
                best_iou, best_gt = i, j
        if best_iou >= iou_thresh and not gt_matched[best_gt]:
            tp[idx] = 1
            gt_matched[best_gt] = 1
        else:
            fp[idx] = 1
    tp_cum, fp_cum = np.cumsum(tp), np.cumsum(fp)
    recall = tp_cum / len(gt_boxes)
    precision = tp_cum / (tp_cum + fp_cum + 1e-9)
    return compute_ap(recall, precision)

gt = [[0, 0, 10, 10], [20, 20, 30, 30]]
pred = [[0.5, 0.5, 10.5, 10.5], [19, 19, 31, 31], [50, 50, 60, 60]]
scores = [0.95, 0.85, 0.6]
print(f'mAP: {evaluate_detections(pred, scores, gt):.3f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 面试答检测模型先分清「两阶段/单阶段」，再说速度和精度的取舍
2. 能现场手写 NMS 和 IoU 是加分项，公式要熟练
3. 传统 CV 题强调「灰度 → 滤波 → 边缘/阈值 → 形态学 → 轮廓」的标准处理链
4. OCR 题答出「检测 + 识别」两段式和 CTC 的作用，体现系统性
5. Tracking 题主动提「检测 + 关联」范式和 ID Switch 问题的应对
6. 标定题分清内参/外参/畸变三个概念，别混为一谈
7. 特征点题能说出 SIFT vs ORB 的精度/速度/专利权衡

### 踩坑记录

```text
坑 1：OpenCV 和 matplotlib 混用导致颜色错乱
结论：显示的图像颜色发蓝/发红。
原因：OpenCV 是 BGR 顺序，matplotlib/PIL 是 RGB 顺序。
解法：显示前 cv2.cvtColor(img, cv2.COLOR_BGR2RGB) 转换。

坑 2：NMS 阈值设太高导致重复框未抑制
结论：同一目标出现多个重叠框。
原因：IoU 阈值过高，重叠框未被判定为重复。
解法：IoU 阈值常用 0.5 左右，根据密集程度微调。

坑 3：OCR 直接对整图做识别
结论：复杂背景、多行文本识别效果差。
原因：缺少检测环节，识别网络难以处理未定位的文本。
解法：先文本检测定位裁剪，再逐区域识别。

坑 4：用 SIFT 时忘了 OpenCV 需编译 contrib
结论：cv2.SIFT_create() 报错 AttributeError。
原因：SIFT/SURF 有专利，移入 opencv-contrib 模块。
解法：编译 contrib 或用 ORB 替代。

坑 5：图像处理前不做 uint8/float 转换
结论：运算溢出、图像显示全黑或异常。
原因：像素运算超出 [0,255] 范围被截断，或类型不匹配。
解法：用 cv2.normalize、np.clip 控制范围，注意 dtype 一致性。
```
