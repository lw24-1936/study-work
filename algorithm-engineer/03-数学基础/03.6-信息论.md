## 概述

信息论由香农（Shannon）创立，用「熵」量化不确定性，用「交叉熵」和「KL 散度」度量两个分布之间的差异。它是机器学习的核心损失来源——分类问题的交叉熵损失、生成模型的 KL 正则、决策树的信息增益，全部源自信息论。

```text
信息论的核心概念与用途：
1. 熵 —— 随机变量的不确定性，是「信息量」的期望
2. 交叉熵 —— 用预测分布编码真实分布的平均代价，即分类损失
3. KL 散度 —— 两个分布的「距离」，度量模型分布与真实分布的差异
4. 互信息 / 信息增益 —— 特征与标签的相关性，指导特征选择与树分裂
```

```python
import numpy as np

# 熵的最小示例：均匀分布熵最大，确定事件熵为 0
def entropy(p):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                       # 0·log0 = 0
    return -(p * np.log2(p)).sum()

print(f'均匀分布 [0.5,0.5] 熵 = {entropy([0.5, 0.5]):.3f} bit')
print(f'确定分布 [1,0] 熵 = {entropy([1, 0]):.3f} bit')
```

## 熵

熵（Entropy）度量随机变量的「不确定性」，单位是 bit（log 底 2）或 nat（log 底 e）。分布越均匀熵越大，越确定熵越小。它也是「编码该随机变量所需的最少平均比特数」。

```text
数学定义：
H(X) = -Σ p(x) · log₂ p(x) = E[-log₂ p(X)]

关键性质：
1. 非负：H(X) ≥ 0
2. 均匀分布熵最大：k 个等概率事件 H = log₂ k
3. 确定事件熵为 0：p=1 时 H = 0
4. 定义约定 0·log0 = 0
```

```python
import numpy as np

def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]
    return -(p * np.log(p) / np.log(base)).sum()

# 熵随分布变化
for p in [0.0, 0.1, 0.25, 0.5, 0.9, 1.0]:
    H = entropy([p, 1 - p])
    print(f'p={p:.2f} → H = {H:.3f} bit')

# 均匀分布熵最大：k=8 个等概率事件
H_uniform = entropy(np.ones(8) / 8)
print(f'8 个等概率事件熵 = {H_uniform:.3f} bit（理论 log₂8 = 3）')
```

## 交叉熵

交叉熵（Cross Entropy）度量「用分布 q 编码真实分布 p」的平均编码代价。它把两个分布连起来，是分类问题（真实标签 one-hot 分布 vs 模型预测分布）的标准损失函数。

```text
数学定义：
H(p, q) = -Σ p(x) · log q(x)

性质：
1. 非对称：H(p, q) ≠ H(q, p)
2. 下界：H(p, q) ≥ H(p)，当且仅当 p = q 时取等
3. 关系：H(p, q) = H(p) + KL(p ‖ q)

分类中的应用：
真实标签 y（one-hot），预测概率 p̂，交叉熵损失
L = -Σ yᵢ log p̂ᵢ = -log p̂_class
```

```python
import numpy as np

def cross_entropy(p, q):
    p = np.asarray(p, dtype=float)
    q = np.asarray(q, dtype=float)
    q = np.clip(q, 1e-12, 1.0)          # 防 log(0)
    return -(p * np.log(q)).sum()

# 预测分布越接近真实分布，交叉熵越小
p_true = np.array([1.0, 0.0, 0.0])      # 真实：第 0 类
for q_pred in [[0.9, 0.05, 0.05],       # 好预测
               [0.4, 0.3, 0.3],         # 一般
               [0.1, 0.8, 0.1]]:        # 差（错判）
    print(f'q={q_pred} → 交叉熵 = {cross_entropy(p_true, q_pred):.3f}')
```

## KL散度

KL 散度（Kullback-Leibler Divergence）度量「用分布 q 近似真实分布 p 时损失了多少信息」，是两个分布差异的标准度量。它是 VAE 的损失项、知识蒸馏的软标签匹配、变分推断的核心。

```text
数学定义：
KL(p ‖ q) = Σ p(x) · log[p(x) / q(x)] = Σ p(x)log p(x) - Σ p(x)log q(x)

性质：
1. 非负：KL(p ‖ q) ≥ 0（Gibbs 不等式）
2. KL(p ‖ q) = 0 当且仅当 p = q
3. 非对称：KL(p ‖ q) ≠ KL(q ‖ p)，不是真正的「距离」
4. 关系：KL(p ‖ q) = H(p, q) - H(p)
```

```python
import numpy as np

def kl_divergence(p, q):
    p = np.asarray(p, dtype=float)
    q = np.asarray(q, dtype=float)
    p = np.clip(p, 1e-12, 1.0)
    q = np.clip(q, 1e-12, 1.0)
    return (p * np.log(p / q)).sum()

p = np.array([0.7, 0.2, 0.1])            # 真实分布
q1 = np.array([0.7, 0.2, 0.1])           # 完美近似
q2 = np.array([0.2, 0.7, 0.1])           # 差近似

print(f'KL(p‖q1) = {kl_divergence(p, q1):.4f}（相同分布 → 0）')
print(f'KL(p‖q2) = {kl_divergence(p, q2):.4f}（差异大）')

# 非对称性验证
a = np.array([0.9, 0.1])
b = np.array([0.1, 0.9])
print(f'KL(a‖b) = {kl_divergence(a, b):.3f} vs KL(b‖a) = {kl_divergence(b, a):.3f}')
```

## 互信息

互信息（Mutual Information）度量两个随机变量「共享的信息量」，即知道一个变量后另一个变量不确定性减少的程度。它刻画非线性相关性，比相关系数更全面。

```text
数学定义：
I(X; Y) = H(X) - H(X | Y) = H(Y) - H(Y | X)
        = Σ p(x, y) · log[p(x, y) / (p(x) p(y))]

性质：
1. 非负：I(X; Y) ≥ 0
2. 对称：I(X; Y) = I(Y; X)
3. I(X; Y) = 0 当且仅当 X、Y 独立
4. 关系：I(X; Y) = KL(p(x, y) ‖ p(x)p(y))
```

```python
import numpy as np
from sklearn.feature_selection import mutual_info_classif

# 互信息 vs 相关系数：互信息能捕捉非线性关系
np.random.seed(0)
X = np.random.randn(1000)
Y_linear = 3 * X + np.random.randn(1000) * 0.5    # 线性相关
Y_nonlinear = X ** 2 + np.random.randn(1000) * 0.5 # 非线性相关

def mutual_information(x, y, bins=20):
    c_xy = np.histogram2d(x, y, bins)[0]
    pxy = c_xy / c_xy.sum()
    px = pxy.sum(axis=1, keepdims=True)
    py = pxy.sum(axis=0, keepdims=True)
    mask = pxy > 0
    return (pxy[mask] * np.log(pxy[mask] / (px @ py)[mask])).sum()

print(f'线性相关：互信息 = {mutual_information(X, Y_linear):.3f}，相关系数 = {np.corrcoef(X, Y_linear)[0,1]:.3f}')
print(f'非线性相关：互信息 = {mutual_information(X, Y_nonlinear):.3f}，相关系数 = {np.corrcoef(X, Y_nonlinear)[0,1]:.3f}')
# 注意：非线性时相关系数接近 0，但互信息仍显著
```

## 信息增益

信息增益（Information Gain）是决策树选择分裂特征的标准：用某特征分裂后，标签熵减少的量，即「该特征带来了多少关于标签的信息」。等价于特征与标签的互信息。

```text
数学定义：
IG(T, a) = H(T) - Σ (|Tᵥ| / |T|) · H(Tᵥ)

其中：
1. T 是当前节点样本集，H(T) 是标签的熵
2. a 是候选分裂特征，Tᵥ 是特征 a 取值为 v 的子集
3. 按子集大小加权平均子集的熵

分裂选择：选 IG 最大的特征分裂（ID3 算法）
```

```python
import numpy as np

def entropy(labels):
    _, counts = np.unique(labels, return_counts=True)
    p = counts / counts.sum()
    return -(p * np.log2(p)).sum()

def information_gain(labels, feature):
    H_before = entropy(labels)
    H_after = 0.0
    for v in np.unique(feature):
        sub_labels = labels[feature == v]
        H_after += (len(sub_labels) / len(labels)) * entropy(sub_labels)
    return H_before - H_after

# 玩具数据集：是否出去玩（标签）与天气、湿度（特征）
labels = np.array(['去', '不去', '去', '去', '不去', '去', '不去'])
weather = np.array(['晴', '雨', '晴', '晴', '雨', '阴', '阴'])
humidity = np.array(['高', '高', '高', '低', '高', '低', '低'])

ig_weather = information_gain(labels, weather)
ig_humidity = information_gain(labels, humidity)
print(f'天气的信息增益 = {ig_weather:.3f}')
print(f'湿度的信息增益 = {ig_humidity:.3f}')
print('优先分裂特征:', '天气' if ig_weather > ig_humidity else '湿度')
```

## 应用场景实战

### 场景一：多分类交叉熵损失（手写 vs 框架）

```python
import numpy as np
import torch
import torch.nn.functional as F

def cross_entropy_loss(logits, labels):
    # logits: (n, C) 未归一化分数，labels: (n,) 真实类别
    n = len(labels)
    # softmax + 负对数似然
    exp = np.exp(logits - logits.max(axis=1, keepdims=True))  # 减 max 防溢出
    probs = exp / exp.sum(axis=1, keepdims=True)
    log_likelihood = -np.log(probs[np.arange(n), labels])
    return log_likelihood.mean()

np.random.seed(0)
logits = np.random.randn(8, 5)
labels = np.random.randint(0, 5, 8)

loss_numpy = cross_entropy_loss(logits, labels)
loss_torch = F.cross_entropy(torch.tensor(logits), torch.tensor(labels)).item()
print(f'手写交叉熵 = {loss_numpy:.4f}')
print(f'PyTorch 交叉熵 = {loss_torch:.4f}')
print('两者一致:', np.allclose(loss_numpy, loss_torch, atol=1e-6))
```

### 场景二：用互信息做特征选择

```python
from sklearn.feature_selection import mutual_info_classif
from sklearn.datasets import load_breast_cancer
import numpy as np

X, y = load_breast_cancer(return_X_y=True)   # 30 维特征，二分类

# 计算每个特征与标签的互信息
mi = mutual_info_classif(X, y, random_state=0)
top_k = np.argsort(mi)[::-1][:5]
print('互信息最高的 5 个特征索引:', top_k)
print('对应互信息值:', mi[top_k].round(3))

# 只用 top-k 特征训练，验证信息增益的效果
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
score_full = cross_val_score(LogisticRegression(max_iter=5000), X, y, cv=3).mean()
score_topk = cross_val_score(LogisticRegression(max_iter=5000), X[:, top_k], y, cv=3).mean()
print(f'全特征准确率 = {score_full:.3f}，top-5 特征准确率 = {score_topk:.3f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 分类损失用交叉熵（含 logits 版本），比 MSE 收敛快、梯度更合理
2. 计算 softmax 前先减 logits 最大值，防止 exp 上溢
3. 计算熵/KL 时对概率做 clip（如 1e-12），避免 log(0) 产生 NaN/-inf
4. 比较两个分布差异优先用 KL 散度，但记住它非对称，方向选择要符合语义
5. 特征选择想捕捉非线性关系用互信息，别只看 Pearson 相关系数
6. 决策树分裂用信息增益/信息增益比，注意「取值多的特征」会被偏爱（需增益比校正）

### 踩坑记录

```text
坑 1：softmax 前没减最大值导致 exp 上溢
结论：logits 较大时 exp 溢出为 inf，softmax 输出 NaN，损失变 NaN。
原因：exp(1000) 超出 float 精度上限。
解法：先减 logits.max()，再做 softmax，数学上等价且数值稳定。

坑 2：log(0) 产生 -inf
结论：预测概率为 0 时，-log(0) = inf，损失直接爆炸。
原因：softmax 输出可能被四舍五入为 0，或手写时没做平滑。
解法：对概率 clip 到 [1e-12, 1-1e-12]，或用框架自带的数值稳定实现。

坑 3：把 KL 散度当对称距离用
结论：KL(p‖q) 和 KL(q‖p) 结果不同，方向用错导致优化目标错误。
原因：KL 散度非对称，度量「用 q 近似 p 的代价」，角色不可互换。
解法：明确哪个是真实分布（放前面），或用对称的 JS 散度。

坑 4：用 MSE 做分类损失
结论：分类用 MSE 收敛慢，梯度在饱和区接近 0，模型学不动。
原因：sigmoid 输出饱和时 MSE 梯度趋零，交叉熵则能抵消饱和。
解法：分类（尤其 sigmoid/softmax 输出）用交叉熵损失。

坑 5：决策树用信息增益偏爱取值多的特征
结论：ID 类特征（取值极多）信息增益天然偏高，被错误优先选择。
原因：取值越多，子集越纯，熵下降越「容易」，造成过拟合。
解法：用信息增益比（除以特征自身熵）或 CART 的基尼系数。
```
