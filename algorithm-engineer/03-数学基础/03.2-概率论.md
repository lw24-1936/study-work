## 概述

概率论描述「不确定性」：给定随机试验，量化各种结果发生的可能性。它是机器学习的语言——数据本身被建模为随机变量，损失函数本质是概率（似然）的对数，而贝叶斯、期望、方差贯穿从朴素贝叶斯到深度学习的每一个环节。

```text
概率论在算法中的角色：
1. 建模语言 —— 样本服从某个分布，参数待估计
2. 损失来源 —— 极大似然、交叉熵都源自概率的负对数
3. 不确定性度量 —— 期望是预测，方差是风险
4. 大数基础 —— 大数定律与中心极限定理保证统计估计可靠
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 抛硬币 1000 次的频率逼近概率 0.5
flips = np.random.rand(1000) < 0.5
print(f'正面频率 = {flips.mean():.3f}（趋近 0.5）')
```

## 随机变量

随机变量（Random Variable）把随机试验的结果映射到实数。离散型用「概率质量函数 PMF」描述，连续型用「概率密度函数 PDF」描述，累计分布函数 CDF 统一两者。

```text
数学定义：
1. 离散型：PMF p(x) = P(X = x)，Σ p(x) = 1
2. 连续型：PDF f(x)，P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx，∫ f(x) dx = 1
3. CDF：F(x) = P(X ≤ x)，非降函数，F(-∞)=0，F(∞)=1
4. 关系：连续型 f(x) = F'(x)
```

```python
import numpy as np

# 离散随机变量：掷骰子
def dice_pmf():
    values = np.arange(1, 7)
    pmf = np.ones(6) / 6          # 每个面概率相等
    return values, pmf

values, pmf = dice_pmf()
print('PMF:', dict(zip(values, pmf)))
print('概率和 =', pmf.sum())      # 1.0

# 连续随机变量：标准正态的 PDF 与 CDF
from scipy import stats

x = np.linspace(-4, 4, 1000)
pdf = stats.norm.pdf(x)
cdf = stats.norm.cdf(x)
print(f'P(-1 ≤ X ≤ 1) = {cdf[(x <= 1) & (x >= -1)][-1] - cdf[x <= -1][-1]:.4f}')
```

## 常见分布

机器学习里反复出现的几类分布，各有适用场景：伯努利/二项描述「成功次数」，泊松描述「计数」，均匀/正态描述「噪声与先验」，指数描述「等待时间」。

```text
常见分布一览：
1. 伯努利 Bernoulli(p)：一次试验，P(X=1)=p，P(X=0)=1-p
2. 二项 Binomial(n, p)：n 次独立试验成功次数，E=np，Var=np(1-p)
3. 泊松 Poisson(λ)：单位时间事件次数，E=λ，Var=λ
4. 均匀 Uniform(a, b)：区间内等概率，E=(a+b)/2
5. 正态 Normal(μ, σ²)：钟形曲线，E=μ，Var=σ²
6. 指数 Exponential(λ)：等待时间，E=1/λ，Var=1/λ²
```

```python
import numpy as np
from scipy import stats

# 二项分布：抛 10 次硬币，正面次数的分布
binom = stats.binom(n=10, p=0.5)
print('P(X=5) =', binom.pmf(5))    # 约 0.246

# 泊松分布：平均每小时 3 次点击，恰好 2 次的概率
poisson = stats.poisson(mu=3)
print('P(X=2) =', poisson.pmf(2))  # 约 0.224

# 正态分布抽样：高斯噪声
samples = np.random.normal(loc=0, scale=1, size=10000)
print('样本均值 =', samples.mean(), '样本方差 =', samples.var())
```

## 条件概率

条件概率（Conditional Probability）在已知某事件发生的条件下重新度量另一事件的概率，是贝叶斯定理和整个概率推理的基石。

```text
数学定义：
P(A | B) = P(A ∩ B) / P(B)，其中 P(B) > 0

乘法法则：
P(A ∩ B) = P(A | B) · P(B) = P(B | A) · P(A)

全概率公式（划分 B₁,...,Bₙ）：
P(A) = Σ P(A | Bᵢ) · P(Bᵢ)
```

```python
# 条件概率示例：已知抽到红牌，求是红心的概率
# 一副牌 52 张，红牌 26 张（红心 13 + 方块 13）
P_red = 26 / 52
P_heart_and_red = 13 / 52
P_heart_given_red = P_heart_and_red / P_red
print(f'P(红心 | 红牌) = {P_heart_given_red:.3f}')   # 0.5

# 全概率公式：两个工厂供货，求总体次品率
# 厂 A 供 60%，次品率 1%；厂 B 供 40%，次品率 2%
P_A, P_B = 0.6, 0.4
P_defect_A, P_defect_B = 0.01, 0.02
P_defect = P_A * P_defect_A + P_B * P_defect_B
print(f'总体次品率 = {P_defect:.4f}')   # 0.014
```

## 贝叶斯

贝叶斯定理（Bayes' Theorem）用先验概率和似然反推后验概率，是「用证据更新信念」的数学表达，是朴素贝叶斯、贝叶斯推断、贝叶斯优化的核心。

```text
数学定义：
P(A | B) = P(B | A) · P(A) / P(B)

命名：
1. P(A) —— 先验概率（prior），看到证据前对 A 的信念
2. P(B | A) —— 似然（likelihood），A 成立时观察到 B 的可能
3. P(A | B) —— 后验概率（posterior），看到 B 后更新对 A 的信念
4. P(B) —— 证据（evidence）/ 归一化因子，由全概率公式得到
```

```python
# 贝叶斯：疾病检测的经典例子
# 患病率 1%，检测灵敏度 99%（真阳），特异度 95%（真阴）
P_disease = 0.01
P_pos_given_disease = 0.99           # 灵敏度
P_pos_given_healthy = 0.05           # 1 - 特异度

# 全概率算 P(阳性)
P_pos = (P_pos_given_disease * P_disease
         + P_pos_given_healthy * (1 - P_disease))
# 贝叶斯反推：阳性 → 患病的后验概率
P_disease_given_pos = P_pos_given_disease * P_disease / P_pos
print(f'检测阳性时真正患病概率 = {P_disease_given_pos:.3f}')   # 约 0.167
```

## 期望

期望（Expectation）是随机变量的「加权平均」，代表长期平均结果，是预测值、损失函数和收益评估的核心量。

```text
数学定义：
1. 离散型：E[X] = Σ x · p(x)
2. 连续型：E[X] = ∫ x · f(x) dx

性质（线性性）：
1. E[aX + b] = a·E[X] + b
2. E[X + Y] = E[X] + E[Y]（无论 X、Y 是否独立）
3. 独立时 E[XY] = E[X]·E[Y]
```

```python
import numpy as np

# 离散期望：掷骰子的期望值
values = np.arange(1, 7)
pmf = np.ones(6) / 6
expectation = (values * pmf).sum()
print(f'掷骰子期望 = {expectation:.1f}')   # 3.5

# 连续期望：正态分布的期望（理论值 μ=0）
samples = np.random.normal(0, 1, 100000)
print(f'样本均值逼近 E[X] = {samples.mean():.4f}')

# 期望线性性验证：E[aX+b] = aE[X]+b
a, b = 3, 5
print(f'E[3X+5] = {(a * samples + b).mean():.3f} ≈ {a * samples.mean() + b:.3f}')
```

## 方差

方差（Variance）度量随机变量偏离期望的程度，是「风险/不确定性」的度量；标准差是其平方根，量纲与 X 一致。

```text
数学定义：
Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²

性质：
1. Var(aX + b) = a² · Var(X)（常数 b 不影响方差）
2. 独立时 Var(X + Y) = Var(X) + Var(Y)
3. 标准差 σ = √Var(X)
```

```python
import numpy as np

# 方差手写实现
def variance(x):
    x = np.asarray(x)
    return np.mean(x ** 2) - np.mean(x) ** 2   # E[X²] - E[X]²

data = np.random.randn(10000)
print(f'手写方差 = {variance(data):.4f}, numpy 方差 = {data.var():.4f}')

# 线性变换 Var(aX+b) = a²Var(X)
a = 4
print(f'Var(4X) = {(a * data).var():.2f} ≈ {a**2 * data.var():.2f}')
```

## 协方差

协方差（Covariance）度量两个随机变量「同向还是反向」变化的线性关系；除以各自标准差归一化后得到相关系数，范围 [-1, 1]。

```text
数学定义：
Cov(X, Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]

相关系数：
ρ(X, Y) = Cov(X, Y) / (σ_X · σ_Y) ∈ [-1, 1]

解读：
1. Cov > 0 → 正相关（X 大 Y 也大）
2. Cov < 0 → 负相关
3. Cov = 0 → 不相关（但可能非线性相关）
```

```python
import numpy as np

# 协方差与相关系数
X = np.random.randn(1000)
Y = 2 * X + np.random.randn(1000) * 0.5   # 正相关
Z = -3 * X + np.random.randn(1000) * 0.5  # 负相关

cov_xy = np.cov(X, Y)[0, 1]
corr_xy = np.corrcoef(X, Y)[0, 1]
cov_xz = np.cov(X, Z)[0, 1]
print(f'Cov(X,Y) = {cov_xy:.2f}, ρ = {corr_xy:.3f}')   # 正相关
print(f'Cov(X,Z) = {cov_xz:.2f}')                     # 负相关

# 协方差矩阵（多变量的统一表示）
data = np.stack([X, Y, Z], axis=1)
print('协方差矩阵：')
print(np.cov(data.T).round(2))
```

## 大数定律

大数定律（Law of Large Numbers, LLN）说明样本均值在样本量增大时收敛到真实期望。它是「频率趋近概率」「样本统计量估计总体参数」的理论保证。

```text
数学定义：
设 X₁,...,Xₙ 独立同分布且 E[X] = μ，则样本均值
X̄ₙ = (1/n) Σ Xᵢ → μ（依概率收敛）

弱大数定律与强大数定律：
1. 弱 LLN：X̄ₙ 依概率收敛到 μ
2. 强 LLN：X̄ₙ 几乎必然收敛到 μ

意义：只要样本足够多，经验平均就是真实期望的良好估计
```

```python
import numpy as np

# 模拟：样本均值随样本量增大收敛到真实期望 0.5
true_mean = 0.5
for n in [10, 100, 1000, 10000, 100000]:
    samples = np.random.rand(n) < 0.5          # 伯努利(0.5)
    print(f'n={n:6d} → 频率 = {samples.mean():.4f}（真值 0.5）')

# 收敛可视化：样本均值轨迹
means = np.cumsum(np.random.rand(10000) < 0.5) / np.arange(1, 10001)
print(f'最终收敛到 {means[-1]:.4f}')
```

## 中心极限定理

中心极限定理（Central Limit Theorem, CLT）说明大量独立随机变量之和（或均值）近似服从正态分布，无论原始分布是什么。它是置信区间、假设检验和许多统计方法的根基。

```text
数学定义：
X₁,...,Xₙ 独立同分布，均值 μ、方差 σ²，则当 n 充分大时
(X̄ₙ - μ) / (σ/√n) → N(0, 1)（依分布收敛）

等价表述：
X̄ₙ ≈ N(μ, σ²/n)

关键点：
1. 不要求原始分布是正态 —— 这才是它的威力
2. 标准差 σ/√n 随 n 增大而缩小，估计越来越精确
3. n ≥ 30 通常近似已足够好
```

```python
import numpy as np

# 从「均匀分布」抽样，其均值的分布趋于正态
n = 50
means = [np.random.uniform(0, 1, n).mean() for _ in range(10000)]
means = np.array(means)

print(f'均值分布均值 = {means.mean():.4f}（真值 0.5）')
print(f'均值分布方差 = {means.var():.5f}（理论 1/(12*{n}) = {1/(12*n):.5f}）')

# 检验近似正态：偏度、峰度
from scipy import stats
print(f'偏度 = {stats.skew(means):.3f}（接近 0 = 对称）')
print(f'峰度 = {stats.kurtosis(means):.3f}（接近 0 = 正态）')
```

## 应用场景实战

### 场景一：朴素贝叶斯垃圾邮件分类

```python
import numpy as np
from collections import defaultdict

# 训练集：邮件词袋 + 标签（1=垃圾，0=正常）
def train_naive_bayes(docs, labels):
    vocab = set(w for d in docs for w in d)
    prior = np.mean(labels)                      # P(垃圾)
    counts = {c: defaultdict(int) for c in [0, 1]}
    totals = {c: 0 for c in [0, 1]}
    for d, y in zip(docs, labels):
        for w in d:
            counts[y][w] += 1
            totals[y] += 1
    # 拉普拉斯平滑的似然 P(w|c)
    like = {c: {w: (counts[c][w] + 1) / (totals[c] + len(vocab))
                for w in vocab} for c in [0, 1]}
    return prior, like, vocab

def predict_naive_bayes(doc, prior, like, vocab):
    log_p_spam = np.log(prior)
    log_p_ham = np.log(1 - prior)
    for w in vocab:
        if w in doc:
            log_p_spam += np.log(like[1][w])
            log_p_ham += np.log(like[0][w])
    return int(log_p_spam > log_p_ham)

docs = [
    ['免费', '中奖', '点击', '优惠'],
    ['免费', '领取', '大奖', '中奖'],
    ['会议', '时间', '安排', '附件'],
    ['项目', '进度', '会议', '汇报'],
    ['中奖', '免费', '优惠', '立即'],
]
labels = [1, 1, 0, 0, 1]
prior, like, vocab = train_naive_bayes(docs, labels)
test = ['免费', '中奖', '立即']
print('预测:', '垃圾' if predict_naive_bayes(test, prior, like, vocab) else '正常')
```

### 场景二：蒙特卡洛估计 π（大数定律应用）

```python
import numpy as np

def estimate_pi(n):
    x = np.random.rand(n)
    y = np.random.rand(n)
    inside = (x ** 2 + y ** 2) <= 1          # 单位圆内
    return 4 * inside.mean()                  # 面积比 × 4

for n in [1000, 10000, 100000, 1000000]:
    pi_hat = estimate_pi(n)
    print(f'n={n:8d} → π ≈ {pi_hat:.5f}（误差 {abs(pi_hat - np.pi):.5f}）')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用对数概率（log-sum）代替直接乘概率，避免下溢，这是朴素贝叶斯和 HMM 的标准做法
2. 先判断问题该用「频率派还是贝叶斯派」，再选极大似然还是后验推断
3. 处理稀疏/小样本概率时用拉普拉斯平滑，别让 0 概率把整个联合概率抹成 0
4. 相关性分析优先看相关系数（归一化），而不是只看协方差（量纲依赖）
5. 蒙特卡洛模拟先固定随机种子保证可复现，再报告多次平均结果
6. 用 CLT 做近似时，先检查样本量是否够大、分布是否重尾（重尾收敛慢）

### 踩坑记录

```text
坑 1：把「相关」当「因果」
结论：两个变量协方差为正，误以为一个导致另一个。
原因：协方差只度量线性共同变化，无法区分因果与混杂变量。
解法：想谈因果需做干预实验或因果推断（如 do-calculus），相关只是线索。

坑 2：朴素贝叶斯遇到训练集没见过的词，概率变 0
结论：整篇文档概率被乘成 0，分类失效。
原因：P(w|c)=0 直接导致联合似然为 0。
解法：拉普拉斯平滑（计数 +1），或对连续特征用高斯/对数似然。

坑 3：直接乘大量小概率导致数值下溢
结论：计算结果变成 0.0，无法比较。
原因：几十个 0.1 相乘就是 1e-30，超出浮点精度。
解法：取对数转成求和，比较 log 概率即可。

坑 4：CLT 用于重尾分布或小样本
结论：正态近似误差大，置信区间失真。
原因：重尾分布（如柯西）方差无限，收敛极慢甚至不收敛。
解法：检查分布是否有有限方差，样本量不足时用 Bootstrap 或非参数方法。

坑 5：混淆「不相关」和「独立」
结论：相关系数为 0 就断定两变量独立，导致错误建模。
原因：独立 ⇒ 不相关，但反向不成立，Y=X² 与 X 相关系数为 0 却完全依赖。
解法：独立需要 P(X,Y)=P(X)P(Y) 或检查高阶矩/互信息，不能只看相关系数。
```
