## 概述

微积分研究「变化率」，优化研究「找极值」。机器学习训练模型的本质就是优化：定义损失函数，用梯度（导数的向量版）指引参数更新方向，让损失不断下降。链式法则是反向传播的理论根基，凸优化保证全局最优，梯度下降家族则是实践中最常用的求解器。

```text
微积分与优化的关系：
1. 导数/梯度 —— 刻画「往哪走损失下降最快」
2. 链式法则 —— 反向传播逐层传递梯度的数学依据
3. 凸优化 —— 保证找到的是全局最优而非局部最优
4. GD/SGD/牛顿法 —— 一阶/二阶优化算法的工程实现
```

```python
import numpy as np

# 优化最小示例：梯度下降求 f(x) = (x-3)² 的最小值
def f(x): return (x - 3) ** 2
def df(x): return 2 * (x - 3)

x = 0.0
for _ in range(100):
    x -= 0.1 * df(x)         # x ← x - lr·f'(x)
print(f'极小值点 x = {x:.4f}（真值 3）')
```

## 导数

导数（Derivative）度量函数在某点的瞬时变化率，几何意义是切线的斜率。导数为 0 的点是极值点的候选（驻点）。

```text
数学定义：
f'(x) = lim_{h→0} [f(x+h) - f(x)] / h

几何意义：曲线在 x 处的切线斜率

关键规则：
1. 幂函数：(xⁿ)' = n·xⁿ⁻¹
2. 指数：(eˣ)' = eˣ
3. 对数：(ln x)' = 1/x
4. 乘积：(uv)' = u'v + uv'
5. 商：(u/v)' = (u'v - uv') / v²
```

```python
import numpy as np

# 数值导数（有限差分）验证解析导数
def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)   # 中心差分，误差 O(h²)

f = lambda x: x ** 3 - 2 * x + 1
fp_analytic = lambda x: 3 * x ** 2 - 2       # 解析导数

for x in [-2, 0, 1, 3]:
    num = numerical_derivative(f, x)
    ana = fp_analytic(x)
    print(f'x={x}: 数值 {num:.6f} vs 解析 {ana:.6f} → 误差 {abs(num-ana):.2e}')
```

## 偏导

偏导数（Partial Derivative）是多元函数对「某一个」变量求导、其余变量固定的结果，度量函数沿单个坐标轴的变化率。

```text
数学定义：
∂f/∂xᵢ = lim_{h→0} [f(x₁,...,xᵢ+h,...,xₙ) - f(x₁,...,xᵢ,...,xₙ)] / h

含义：其他变量视为常数，只对 xᵢ 求导

例子：
f(x, y) = x²y + sin(y)
∂f/∂x = 2xy（把 y 当常数）
∂f/∂y = x² + cos(y)（把 x 当常数）
```

```python
import numpy as np

# 数值偏导验证
def f(x, y):
    return x ** 2 * y + np.sin(y)

def partial_x(f, x, y, h=1e-5):
    return (f(x + h, y) - f(x - h, y)) / (2 * h)

def partial_y(f, x, y, h=1e-5):
    return (f(x, y + h) - f(x, y - h)) / (2 * h)

x, y = 2.0, 0.5
print(f'∂f/∂x 数值 {partial_x(f, x, y):.6f} vs 解析 {2*x*y:.6f}')
print(f'∂f/∂y 数值 {partial_y(f, x, y):.6f} vs 解析 {x**2 + np.cos(y):.6f}')
```

## 梯度

梯度（Gradient）是「所有偏导数组成的向量」，指向函数值上升最快的方向；负梯度方向是下降最快的方向，是梯度下降法的核心。

```text
数学定义：
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]ᵀ

关键性质：
1. 方向：梯度指向函数增长最快的方向
2. 大小：梯度的模 ‖∇f‖ 是最大方向导数
3. 极值点处梯度为 0：∇f = 0 是极值的必要条件
4. 负梯度 -∇f 指向下降最快方向 → 梯度下降
```

```python
import numpy as np

# 二元函数的梯度：f(x,y) = x² + y²，∇f = [2x, 2y]
def gradient_f(x, y):
    return np.array([2 * x, 2 * y])

point = np.array([3.0, 4.0])
grad = gradient_f(*point)
print(f'在 (3,4) 处梯度 = {grad}，模 = {np.linalg.norm(grad):.3f}')

# 数值梯度验证（多点）
def f(x, y): return x ** 2 + y ** 2
def numerical_grad(f, pt, h=1e-5):
    g = np.zeros_like(pt, dtype=float)
    for i in range(len(pt)):
        e = np.zeros_like(pt)
        e[i] = h
        g[i] = (f(*(pt + e)) - f(*(pt - e))) / (2 * h)
    return g

print('数值梯度 =', numerical_grad(f, point))
```

## Hessian

Hessian 矩阵是二阶偏导数组成的矩阵，描述梯度的变化率（函数的曲率）。它用于判断极值类型、设计牛顿法、评估损失曲面的几何性质。

```text
数学定义：
H = [∂²f / ∂xᵢ∂xⱼ]ᵢⱼ（n×n 对称矩阵）

极值判定（对驻点 ∇f = 0）：
1. H 正定（特征值全 > 0）→ 局部极小
2. H 负定（特征值全 < 0）→ 局部极大
3. H 不定（有正有负）→ 鞍点
4. H 半正定 → 无法直接判定

用途：
1. 牛顿法：x ← x - H⁻¹∇f
2. 评估损失曲面凹凸性、收敛性
```

```python
import numpy as np

# Hessian 的数值计算 + 极值判定
def hessian(f, pt, h=1e-4):
    n = len(pt)
    H = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            e_i, e_j = np.zeros(n), np.zeros(n)
            e_i[i] = h; e_j[j] = h
            fp = f(*(pt + e_i + e_j))
            fm = f(*(pt - e_i - e_j))
            fi = f(*(pt + e_i - e_j))
            fj = f(*(pt - e_i + e_j))
            H[i, j] = (fp - fi - fj + fm) / (4 * h * h)
    return (H + H.T) / 2

f = lambda x, y: x ** 2 + 3 * y ** 2   # 正定 Hessian → 极小
H = hessian(f, np.array([0.0, 0.0]))
print('Hessian:')
print(H.round(1))
print('特征值:', np.linalg.eigvalsh(H), '→ 全正 = 局部极小')
```

## 链式法则

链式法则（Chain Rule）计算复合函数的导数：外层导数乘以内层导数。它是反向传播（Backpropagation）的数学核心，让深度学习能高效计算每层参数的梯度。

```text
数学定义：
一元：若 y = f(u)，u = g(x)，则 dy/dx = dy/du · du/dx

多元（全导数）：
若 z = f(x, y)，x = x(t)，y = y(t)，则
dz/dt = (∂f/∂x)·(dx/dt) + (∂f/∂y)·(dy/dt)

意义：
1. 复合函数导数 = 各层导数连乘
2. 反向传播：从输出层逐层乘回输入层，一次前向 + 一次反向算完所有梯度
```

```python
import numpy as np

# 链式法则验证：y = (3x+2)²，看成 f(u)=u²，u=3x+2
def f(u): return u ** 2
def g(x): return 3 * x + 2

# dy/dx = f'(u) · g'(x) = 2u · 3 = 6(3x+2)
x = 2.0
u = g(x)
chain_result = 2 * u * 3                       # 链式法则
direct = 6 * (3 * x + 2)                       # 直接求导
print(f'链式法则 = {chain_result}，直接求导 = {direct}')

# 简单神经网络的链式法则（手动反向传播）
# 网络：x → (w·x) → sigmoid → 输出
def sigmoid(z): return 1 / (1 + np.exp(-z))
x, w, target = 1.0, 0.5, 0.7
z = w * x
y = sigmoid(z)
loss = (y - target) ** 2
# 反向：dL/dw = dL/dy · dy/dz · dz/dw
dL_dy = 2 * (y - target)
dy_dz = y * (1 - y)                 # sigmoid 导数
dz_dw = x
dL_dw = dL_dy * dy_dz * dz_dw
print(f'手动反向传播梯度 dL/dw = {dL_dw:.4f}')
```

## 凸优化

凸优化（Convex Optimization）研究凸函数的极小化问题。凸函数任意两点连线在函数图像上方，意味着「局部最优 = 全局最优」，是机器学习收敛性的理论保证。

```text
数学定义：
函数 f 是凸函数，若对任意 x, y 和 λ ∈ [0, 1]：
f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)

判定（二阶条件）：
1. 一元：f''(x) ≥ 0 对所有 x
2. 多元：Hessian 半正定（H ⪰ 0）

关键结论：
1. 凸函数局部极小 = 全局极小
2. 严格凸函数全局极小唯一
3. 线性回归、逻辑回归、SVM 的损失都是凸的
```

```python
import numpy as np

# 凸函数 vs 非凸函数
def convex_f(x): return x ** 2                     # 凸，f''=2>0
def nonconvex_f(x): return np.sin(x) + 0.3 * x     # 非凸，有多个局部极值

# 验证凸性定义：f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y)
def is_convex(f, x, y, lambdas):
    return all(f(l * x + (1 - l) * y) <= l * f(x) + (1 - l) * f(y)
               for l in lambdas)

lambdas = np.linspace(0, 1, 100)
print('x² 凸性成立:', is_convex(convex_f, -2, 2, lambdas))
print('sin(x)+0.3x 凸性成立:', is_convex(nonconvex_f, -2, 2, lambdas))
```

## 拉格朗日

拉格朗日乘子法（Lagrange Multipliers）求解「带等式约束」的优化问题，把约束问题转为无约束问题。它是对偶理论、SVM 优化和资源分配的基础。

```text
数学定义：
问题：min f(x)  s.t. g(x) = 0

构造拉格朗日函数：
L(x, λ) = f(x) + λ·g(x)

最优解满足（KKT 条件的特例）：
1. ∂L/∂x = 0（对 x 求导为 0）
2. ∂L/∂λ = g(x) = 0（约束满足）

λ 是拉格朗日乘子，解释为「约束的边际价值/影子价格」
```

```python
import numpy as np
from scipy.optimize import minimize

# 问题：max f(x,y)=xy，约束 x²+y²=1（几何上：单位圆内最大矩形面积）
# 拉格朗日：L = xy + λ(x²+y²-1)
# ∂L/∂x = y + 2λx = 0；∂L/∂y = x + 2λy = 0；∂L/∂λ = x²+y²-1 = 0
# 解得 x=y=±1/√2，λ=∓1/2

def lagrangian(vars_):
    x, y, lam = vars_
    return [y + 2 * lam * x,          # ∂L/∂x
            x + 2 * lam * y,          # ∂L/∂y
            x ** 2 + y ** 2 - 1]      # ∂L/∂λ

from scipy.optimize import root
sol = root(lagrangian, [0.7, 0.7, -0.5])
print('最优解 x, y =', sol.x[:2].round(3), '（理论 ±0.707）')
print('最大 xy =', (sol.x[0] * sol.x[1]).round(3))
```

## GD

梯度下降（Gradient Descent, GD）沿负梯度方向迭代更新参数，是最基础的一阶优化算法。学习率控制步长，是收敛速度与稳定性的关键超参数。

```text
数学定义：
x_{t+1} = x_t - η·∇f(x_t)

其中 η 是学习率（learning rate）

学习率的影响：
1. η 太小 → 收敛慢，需要很多次迭代
2. η 太大 → 震荡甚至发散
3. 合适 → 快速稳定收敛

适用场景：目标函数凸、数据量适中
```

```python
import numpy as np

# 梯度下降拟合线性回归 y = wx + b
def gd_linear_regression(X, y, lr=0.01, epochs=500):
    n = len(X)
    w, b = 0.0, 0.0
    history = []
    for _ in range(epochs):
        y_pred = w * X + b
        dw = (2 / n) * np.sum((y_pred - y) * X)   # ∂L/∂w
        db = (2 / n) * np.sum(y_pred - y)         # ∂L/∂b
        w -= lr * dw
        b -= lr * db
        history.append(((y_pred - y) ** 2).mean())
    return w, b, history

np.random.seed(0)
X = np.random.rand(100)
y = 3 * X + 1 + np.random.randn(100) * 0.1
w, b, history = gd_linear_regression(X, y)
print(f'拟合结果 y = {w:.3f}x + {b:.3f}（真 3x+1）')
print(f'损失从 {history[0]:.3f} 降到 {history[-1]:.4f}')
```

## SGD

随机梯度下降（Stochastic Gradient Descent, SGD）每次只用「一个样本」（或一小批 mini-batch）计算梯度，牺牲单步精度换取速度和跳出局部极值的能力，是深度学习的主力优化器。

```text
数学定义：
x_{t+1} = x_t - η·∇f(x_t; i)（i 是随机选取的样本）

与 GD 的区别：
1. GD —— 全量梯度，每步准确但慢，O(n) 计算
2. SGD —— 单样本梯度，有噪声但快，O(1) 计算
3. Mini-batch —— 折中，用 b 个样本，O(b)

噪声的作用：
1. 更快（每步计算量小）
2. 随机性帮助跳出鞍点/浅的局部极小
3. 但收敛路径抖动，常需学习率衰减
```

```python
import numpy as np

# SGD vs GD 收敛对比
def sgd_linear_regression(X, y, lr=0.05, epochs=5):
    n = len(X)
    w, b = 0.0, 0.0
    for epoch in range(epochs):
        for i in np.random.permutation(n):          # 随机打乱，逐样本更新
            xi, yi = X[i], y[i]
            y_pred = w * xi + b
            w -= lr * 2 * (y_pred - yi) * xi
            b -= lr * 2 * (y_pred - yi)
    return w, b

np.random.seed(0)
X = np.random.rand(1000)
y = 3 * X + 1 + np.random.randn(1000) * 0.1

w_gd, b_gd, _ = gd_linear_regression(X, y, lr=0.01, epochs=500)
w_sgd, b_sgd = sgd_linear_regression(X, y, lr=0.05, epochs=5)
print(f'GD:  y = {w_gd:.3f}x + {b_gd:.3f}')
print(f'SGD: y = {w_sgd:.3f}x + {b_sgd:.3f}（仅 5 轮即逼近）')
```

## 牛顿法

牛顿法（Newton's Method）用二阶信息（Hessian）调整步长和方向，收敛速度是二次的（远快于梯度下降的线性收敛），但每步要算并求逆 Hessian，代价高。

```text
数学定义：
x_{t+1} = x_t - H⁻¹∇f(x_t)

思想：在当前点用二阶泰勒展开近似 f，直接跳到近似函数的极小点

对比：
1. GD —— 只用一阶梯度，步长固定，线性收敛
2. 牛顿法 —— 用 Hessian 自动调整方向和步长，二次收敛
3. 代价 —— 牛顿法每步 O(n³)（求逆），高维不可行
4. 折中 —— 拟牛顿法（BFGS/L-BFGS）用低秩近似 Hessian
```

```python
import numpy as np

# 牛顿法求 f(x) = x⁴ - 3x³ + 2 的极小值
def f(x): return x ** 4 - 3 * x ** 3 + 2
def df(x): return 4 * x ** 3 - 9 * x ** 2
def d2f(x): return 12 * x ** 2 - 18 * x

def newtons_method(f_prime, f_double_prime, x0, iters=10):
    x = x0
    for _ in range(iters):
        x = x - f_prime(x) / f_double_prime(x)   # x - H⁻¹∇f
    return x

x_newton = newtons_method(df, d2f, x0=1.0)
print(f'牛顿法极小值点 x = {x_newton:.4f}（理论 9/4 = 2.25）')

# 对比：梯度下降需要更多迭代
x = 1.0
for _ in range(50):
    x = x - 0.01 * df(x)
print(f'梯度下降 50 步 x = {x:.4f}')
```

## 应用场景实战

### 场景一：梯度下降训练逻辑回归（完整流程）

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def logistic_regression_gd(X, y, lr=0.1, epochs=1000):
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    for _ in range(epochs):
        z = X @ w + b
        p = sigmoid(z)
        dw = (1 / n) * X.T @ (p - y)          # 交叉熵损失梯度
        db = (1 / n) * np.sum(p - y)
        w -= lr * dw
        b -= lr * db
    return w, b

np.random.seed(0)
X = np.random.randn(500, 2)
y = (X[:, 0] + X[:, 1] > 0).astype(float)

w, b = logistic_regression_gd(X, y)
acc = ((sigmoid(X @ w + b) > 0.5) == (y == 1)).mean()
print(f'逻辑回归准确率 = {acc:.3f}，w = {w.round(3)}，b = {b:.3f}')
```

### 场景二：L-BFGS 优化复杂损失（对比 GD）

```python
from scipy.optimize import minimize
import numpy as np

# Rosenbrock 函数（经典难优化测试函数）
def rosenbrock(x):
    return (1 - x[0]) ** 2 + 100 * (x[1] - x[0] ** 2) ** 2

# 牛顿系方法（L-BFGS，无需显式 Hessian）
res_lbfgs = minimize(rosenbrock, [0.0, 0.0], method='L-BFGS-B')
# 梯度下降对比
def gd_rosenbrock(lr=0.001, iters=20000):
    x = np.array([0.0, 0.0])
    for _ in range(iters):
        g = np.array([-2*(1-x[0]) - 400*x[0]*(x[1]-x[0]**2),
                       200*(x[1]-x[0]**2)])
        x -= lr * g
    return x

x_gd = gd_rosenbrock()
print(f'L-BFGS 解 = {res_lbfgs.x.round(4)}，函数值 = {res_lbfgs.fun:.2e}')
print(f'GD(20000步) 解 = {x_gd.round(4)}，函数值 = {rosenbrock(x_gd):.4f}')
print(f'L-BFGS 迭代次数 = {res_lbfgs.nit}，远少于 GD 的 20000')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 损失函数凸时优先用解析解或 BFGS/L-BFGS，收敛快；非凸大规模才用 SGD 系
2. 学习率先用小网格试（0.1, 0.01, 0.001），配合学习率衰减或自适应方法（Adam）
3. 梯度下降前先标准化特征，否则各方向曲率差异大，收敛慢（病态问题）
4. 数值梯度只用于「单元测试」验证解析梯度，别用于真实训练（慢且有误差）
5. 判断极值类型看 Hessian 正定性，别只看「梯度为 0」
6. 带约束优化先尝试转拉格朗日/对偶，或直接用带约束求解器（SLSQP）

### 踩坑记录

```text
坑 1：学习率太大导致发散
结论：损失不降反升，甚至变成 NaN。
原因：步长超过曲率允许范围，在极值点附近来回震荡并越走越远。
解法：调小学习率，或加入学习率衰减，或改用自适应优化器（Adam）。

坑 2：梯度为 0 就当成最小值
结论：停在鞍点或极大值点，模型不收敛。
原因：梯度为 0 只是极值必要条件，鞍点梯度也为 0（高维里鞍点极多）。
解法：看 Hessian 特征值判断；优化上用动量/SGD 噪声帮助逃出鞍点。

坑 3：特征没标准化导致收敛极慢
结论：损失曲面变成「狭长山谷」，梯度下降走锯齿路线。
原因：不同特征量纲差异大，各方向曲率（Hessian 对角元）悬殊。
解法：先 StandardScaler 标准化，再训练。

坑 4：数值梯度与解析梯度对不上却不查
结论：反向传播实现有 bug，模型学不到东西却难以定位。
原因：手写梯度公式错一个符号/转置，数值梯度能立刻暴露。
解法：用有限差分做梯度检查（gradient check），误差应 < 1e-5 量级。

坑 5：在非凸问题上用牛顿法还不加阻尼
结论：Hessian 非正定，牛顿方向可能是「上升」方向，直接发散。
原因：非凸区域 Hessian 不定，H⁻¹∇f 不再是下降方向。
解法：加阻尼（Levenberg-Marquardt）、线搜索，或改用拟牛顿/一阶方法。
```
