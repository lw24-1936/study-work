## 概述

统计学从「数据」出发推断「总体」的规律，与概率论方向相反：概率论是「给定分布推数据」，统计学是「给定数据推分布」。它是算法工程师做 A/B 测试、模型评估、参数估计和实验分析的必备工具。

```text
统计学的核心任务：
1. 抽样 —— 用样本代表总体，控制偏差与方差
2. 估计 —— 用样本统计量推断总体参数（点估计 + 区间估计）
3. 推断 —— 假设检验回答「差异是否显著」
4. 稳健 —— Bootstrap 等重采样方法在小样本/非正态下兜底
```

```python
import numpy as np
from scipy import stats

# 抽样的最小示例：从总体估计均值
population = np.random.randn(1_000_000)      # 真实总体
sample = np.random.choice(population, 1000)  # 抽样
print(f'样本均值 {sample.mean():.3f} ≈ 总体均值 {population.mean():.3f}')
```

## 抽样

抽样（Sampling）从总体中抽取子集用于推断。抽样方式决定样本是否「有代表性」，是后续一切统计推断的前提。

```text
数学定义：
总体（population）大小为 N，从中抽取 n 个构成样本

常见抽样方法：
1. 简单随机抽样 —— 每个个体等概率被抽中
2. 分层抽样 —— 按类别分层，每层按比例抽，保证类别均衡
3. 系统抽样 —— 每隔固定间隔抽一个
4. 自助抽样（Bootstrap）—— 有放回抽样，用于重采样

无偏性：样本均值 X̄ 是总体均值 μ 的无偏估计，E[X̄] = μ
```

```python
import numpy as np

population = np.arange(1, 1001)   # 总体 1..1000

# 简单随机抽样（不放回）
srs = np.random.choice(population, size=50, replace=False)

# 分层抽样：按奇偶分层，各抽一半
even = population[population % 2 == 0]
odd = population[population % 2 == 1]
stratified = np.concatenate([
    np.random.choice(even, 25, replace=False),
    np.random.choice(odd, 25, replace=False),
])

# 有放回抽样（Bootstrap 的基础）
bootstrap_sample = np.random.choice(population, size=100, replace=True)
print(f'SRS 均值 {srs.mean():.1f} | 分层均值 {stratified.mean():.1f} | 总体均值 {population.mean():.1f}')
```

## 估计

估计（Estimation）用样本统计量推断总体参数。点估计给出单一值，区间估计给出一个「有置信度」的范围。评价估计量的标准：无偏性、有效性、一致性。

```text
数学定义：
设 θ 是总体参数，θ̂ 是基于样本 X₁,...,Xₙ 的估计量

评价标准：
1. 无偏性：E[θ̂] = θ，估计量的期望等于真值
2. 有效性：Var(θ̂) 越小越有效
3. 一致性：n → ∞ 时 θ̂ 依概率收敛到 θ

常见点估计：
- 总体均值 μ → 样本均值 X̄ = (1/n)ΣXᵢ
- 总体方差 σ² → 样本方差 S² = (1/(n-1))Σ(Xᵢ - X̄)²（n-1 保证无偏）
```

```python
import numpy as np

# 样本方差的 n-1 修正：为什么除以 n-1 而不是 n
population = np.random.randn(100000)   # 真实 σ² = 1

def var_biased(x):
    return ((x - x.mean()) ** 2).mean()        # 除以 n，有偏

def var_unbiased(x):
    return ((x - x.mean()) ** 2).sum() / (len(x) - 1)   # 除以 n-1，无偏

# 反复抽样验证无偏性
biased_est = [var_biased(np.random.choice(population, 10)) for _ in range(2000)]
unbiased_est = [var_unbiased(np.random.choice(population, 10)) for _ in range(2000)]
print(f'除以 n 的均值 = {np.mean(biased_est):.3f}（偏低，有偏）')
print(f'除以 n-1 的均值 = {np.mean(unbiased_est):.3f}（约等于 1，无偏）')
```

## MLE

极大似然估计（Maximum Likelihood Estimation, MLE）选择「最可能产生当前观测数据」的参数值，是频率派参数估计的核心方法，逻辑回归、线性回归、神经网络的损失大多源于 MLE。

```text
数学定义：
给定样本 X₁,...,Xₙ 和参数 θ，似然函数
L(θ) = Π f(Xᵢ; θ)（各样本独立）

MLE 估计量：
θ̂_MLE = argmax_θ L(θ) = argmax_θ log L(θ) = argmax_θ Σ log f(Xᵢ; θ)

取对数的原因：
1. 乘积变求和，计算稳定
2. 对数单调，不改变极值点位置
```

```python
import numpy as np

# MLE 示例：正态分布均值/方差的最大似然估计
def mle_normal(x):
    mu = x.mean()                          # 均值的 MLE = 样本均值
    sigma2 = ((x - mu) ** 2).mean()        # 方差的 MLE = 除以 n（有偏）
    return mu, sigma2

true_mu, true_sigma = 5.0, 2.0
data = np.random.normal(true_mu, true_sigma, 500)
mu_hat, sigma2_hat = mle_normal(data)
print(f'μ̂ = {mu_hat:.3f}（真 {true_mu}），σ̂² = {sigma2_hat:.3f}（真 {true_sigma**2}）')

# MLE 用于伯努利：p̂ = 正面次数 / 总次数
flips = np.random.rand(1000) < 0.7
print(f'p̂_MLE = {flips.mean():.3f}（真 0.7）')
```

## MAP

最大后验估计（Maximum A Posteriori, MAP）在 MLE 基础上乘入先验，选择「后验概率最大」的参数。先验相当于正则化：高斯先验对应 L2，拉普拉斯先验对应 L1。

```text
数学定义：
由贝叶斯定理 P(θ|X) ∝ P(X|θ) · P(θ)

MAP 估计量：
θ̂_MAP = argmax_θ [ log P(X|θ) + log P(θ) ]

与 MLE 的关系：
1. 先验均匀（无信息）时，MAP = MLE
2. 高斯先验 P(θ) ∝ exp(-θ²/2σ²) → 等价于 L2 正则
3. 拉普拉斯先验 P(θ) ∝ exp(-|θ|) → 等价于 L1 正则
```

```python
import numpy as np

# MAP 示例：带 L2 先验的均值估计（等价于 Ridge 型收缩）
def map_normal_l2(x, prior_mu, prior_var):
    n = len(x)
    # 后验 = 似然(高斯) × 先验(高斯)，均值为加权平均
    sigma2 = 1.0                          # 已知似然方差
    w_data = n / sigma2
    w_prior = 1 / prior_var
    mu_map = (w_data * x.mean() + w_prior * prior_mu) / (w_data + w_prior)
    return mu_map

data = np.random.normal(10, 1, 5)          # 只有 5 个样本，真值 10
print(f'MLE  μ̂ = {data.mean():.3f}')
print(f'MAP μ̂ = {map_normal_l2(data, prior_mu=0, prior_var=4):.3f}（先验拉向 0）')
```

## 假设检验

假设检验（Hypothesis Testing）判断样本证据是否足以拒绝原假设。核心概念：原假设/备择假设、显著性水平 α、p 值、第一/二类错误。

```text
数学定义：
1. 原假设 H₀：无差异/无效果（默认成立）
2. 备择假设 H₁：存在差异/效果
3. 显著性水平 α：拒绝 H₀ 但 H₀ 实际为真的概率上限（常用 0.05）

两类错误：
1. 第一类错误（假阳性）：H₀ 为真却拒绝，概率 = α
2. 第二类错误（假阴性）：H₁ 为真却接受，概率 = β

p 值：在 H₀ 成立下，观察到当前或更极端结果的概率
决策规则：p < α → 拒绝 H₀
```

```python
import numpy as np
from scipy import stats

# 单样本 z 检验：检验均值是否等于 μ₀
def z_test(sample, mu0, sigma):
    z = (sample.mean() - mu0) / (sigma / np.sqrt(len(sample)))
    p_value = 2 * (1 - stats.norm.cdf(abs(z)))   # 双尾
    return z, p_value

# H₀: μ = 50，真实 μ = 50（应接受 H₀）
sample = np.random.normal(50, 10, 100)
z, p = z_test(sample, 50, 10)
print(f'z = {z:.3f}, p = {p:.4f} → {"拒绝 H₀" if p < 0.05 else "接受 H₀"}')
```

## 置信区间

置信区间（Confidence Interval）给出参数的一个区间，使得该区间以一定置信水平（如 95%）覆盖真实参数。它比点估计更能表达估计的不确定性。

```text
数学定义：
总体均值 μ 的 95% 置信区间（σ 已知）：
X̄ ± z_{α/2} · σ/√n，其中 z_{0.025} ≈ 1.96

σ 未知时用 t 分布：
X̄ ± t_{α/2, n-1} · s/√n

解读：
95% 置信区间不是「μ 有 95% 概率落在区间内」，
而是「重复抽样 100 次，约 95 个区间会覆盖真实 μ」
```

```python
import numpy as np
from scipy import stats

# σ 已知的置信区间
def ci_known_sigma(sample, sigma, conf=0.95):
    z = stats.norm.ppf(1 - (1 - conf) / 2)
    margin = z * sigma / np.sqrt(len(sample))
    return sample.mean() - margin, sample.mean() + margin

# σ 未知的置信区间（t 分布）
def ci_unknown_sigma(sample, conf=0.95):
    n = len(sample)
    t = stats.t.ppf(1 - (1 - conf) / 2, df=n - 1)
    margin = t * sample.std(ddof=1) / np.sqrt(n)
    return sample.mean() - margin, sample.mean() + margin

data = np.random.normal(100, 15, 50)
print('σ 已知 CI:', [round(v, 2) for v in ci_known_sigma(data, 15)])
print('σ 未知 CI:', [round(v, 2) for v in ci_unknown_sigma(data)])
```

## t检验

t 检验（t-test）在小样本或总体方差未知时比较均值，是 A/B 测试和实验分析最常用的检验。分单样本、独立双样本（Welch）、配对样本三类。

```text
数学定义：
独立双样本 t 检验统计量（Welch，不假设等方差）：
t = (X̄₁ - X̄₂) / √(s₁²/n₁ + s₂²/n₂)

自由度由 Welch–Satterthwaite 公式近似。

适用场景：
1. 单样本 —— 检验一组均值是否等于已知值
2. 独立双样本 —— 比较两组（如实验组 vs 对照组）
3. 配对样本 —— 同一对象前后测（如减肥前后）
```

```python
import numpy as np
from scipy import stats

# 独立双样本 t 检验：A/B 测试，新算法是否显著提升点击率
np.random.seed(0)
control = np.random.binomial(1, 0.10, 1000)      # 对照组 CTR 10%
treatment = np.random.binomial(1, 0.12, 1000)    # 实验组 CTR 12%

t_stat, p_value = stats.ttest_ind(treatment, control, equal_var=False)
print(f't = {t_stat:.3f}, p = {p_value:.4f}')
print('结论:', '显著提升' if p_value < 0.05 else '无显著差异')

# 配对样本 t 检验：减肥前后体重
before = np.array([80, 85, 90, 78, 82, 88])
after = np.array([78, 83, 87, 76, 80, 86])
t_paired, p_paired = stats.ttest_rel(before, after)
print(f'配对 t 检验 p = {p_paired:.4f}')
```

## 卡方

卡方检验（Chi-square Test）检验「分类变量」的独立性与拟合优度：观察频数与期望频数差异是否显著。常用于特征与标签的关联分析、列联表检验。

```text
数学定义：
χ² = Σ (Oᵢ - Eᵢ)² / Eᵢ

其中 Oᵢ 是观察频数，Eᵢ 是期望频数（独立假设下）。

两类用途：
1. 拟合优度 —— 观察分布是否符合某个理论分布
2. 独立性 —— 两个分类变量是否独立（列联表）
```

```python
import numpy as np
from scipy import stats

# 独立性检验：性别与「是否点击广告」是否相关
observed = np.array([[30, 70],    # 男：点击 30，未点击 70
                     [20, 80]])   # 女：点击 20，未点击 80

chi2, p, dof, expected = stats.chi2_contingency(observed)
print(f'χ² = {chi2:.3f}, p = {p:.4f}, 自由度 = {dof}')
print('期望频数（独立假设下）:')
print(expected)
print('结论:', '性别与点击相关' if p < 0.05 else '性别与点击独立')
```

## ANOVA

方差分析（Analysis of Variance, ANOVA）比较「三个及以上」组的均值是否有显著差异，是 t 检验的多组推广。核心思想是分解方差：组间差异 vs 组内差异。

```text
数学定义：
F 统计量 = 组间均方 / 组内均方 = (SSB/(k-1)) / (SSW/(N-k))

其中：
1. SSB（组间平方和）—— 各组均值与总均值的差异
2. SSW（组内平方和）—— 组内个体与组均值的差异
3. k 是组数，N 是总样本数

若 F 大（组间差异远大于组内随机波动），则拒绝「各组均值相等」。
```

```python
import numpy as np
from scipy import stats

# 单因素 ANOVA：三种推荐策略的转化率比较
np.random.seed(1)
group_a = np.random.normal(0.30, 0.05, 50)   # 策略 A
group_b = np.random.normal(0.32, 0.05, 50)   # 策略 B
group_c = np.random.normal(0.31, 0.05, 50)   # 策略 C

f_stat, p_value = stats.f_oneway(group_a, group_b, group_c)
print(f'F = {f_stat:.3f}, p = {p_value:.4f}')
print('结论:', '三组均值有显著差异' if p_value < 0.05 else '三组均值无显著差异')
```

## Bootstrap

Bootstrap 是有放回重采样方法，不依赖分布假设，用小样本估计统计量的分布，从而得到置信区间和标准误。它是「小样本、非正态、统计量无闭式解」时的万能兜底。

```text
数学定义：
从样本 X₁,...,Xₙ 中有放回抽样 B 次，得到 B 个 Bootstrap 样本，
对每个样本计算统计量 θ̂*，用其经验分布近似 θ̂ 的抽样分布。

用途：
1. 估计标准误：std(θ̂*)
2. 置信区间：用 θ̂* 的分位数（百分位法）
3. 非参数，无需正态假设
```

```python
import numpy as np

# Bootstrap 估计中位数的置信区间（中位数无简单闭式标准误）
def bootstrap_ci(data, stat=np.median, B=5000, conf=0.95):
    n = len(data)
    stats_ = [stat(np.random.choice(data, n, replace=True)) for _ in range(B)]
    stats_ = np.array(stats_)
    alpha = (1 - conf) / 2
    return np.percentile(stats_, [alpha * 100, (1 - alpha) * 100])

# 小样本、偏态分布，中位数的 95% CI
data = np.random.exponential(scale=2, size=30)   # 指数分布（偏态）
lo, hi = bootstrap_ci(data)
print(f'中位数 95% CI = [{lo:.3f}, {hi:.3f}]，样本中位数 = {np.median(data):.3f}')
```

## 应用场景实战

### 场景一：A/B 测试完整流程（t 检验 + 置信区间）

```python
import numpy as np
from scipy import stats

np.random.seed(42)
# 实验：新首页布局是否提升转化率
n = 5000
control = np.random.binomial(1, 0.150, n)     # 旧版转化率 15%
treatment = np.random.binomial(1, 0.162, n)   # 新版转化率 16.2%

p1, p2 = control.mean(), treatment.mean()
# 双比例 z 检验
pooled = (control.sum() + treatment.sum()) / (2 * n)
se = np.sqrt(pooled * (1 - pooled) * (2 / n))
z = (p2 - p1) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))

# 提升幅度的置信区间
se_diff = np.sqrt(p1 * (1 - p1) / n + p2 * (1 - p2) / n)
diff = p2 - p1
ci_lo, ci_hi = diff - 1.96 * se_diff, diff + 1.96 * se_diff

print(f'旧版 CTR = {p1:.4f}，新版 CTR = {p2:.4f}')
print(f'提升 = {diff * 100:.2f}%，p = {p_value:.4f}')
print(f'提升 95% CI = [{ci_lo * 100:.2f}%, {ci_hi * 100:.2f}%]')
print('结论:', '显著，值得上线' if p_value < 0.05 else '不显著，继续观察')
```

### 场景二：Bootstrap 评估模型指标稳定性

```python
import numpy as np
from sklearn.metrics import accuracy_score
from sklearn.linear_model import LogisticRegression

np.random.seed(0)
X = np.random.randn(1000, 5)
y = (X[:, 0] + X[:, 1] > 0).astype(int)

clf = LogisticRegression().fit(X, y)
acc = accuracy_score(y, clf.predict(X))

# Bootstrap 估计准确率的标准误与置信区间
def bootstrap_accuracy(clf, X, y, B=1000):
    n = len(y)
    accs = []
    for _ in range(B):
        idx = np.random.choice(n, n, replace=True)
        accs.append(accuracy_score(y[idx], clf.predict(X[idx])))
    return np.array(accs)

accs = bootstrap_accuracy(clf, X, y)
print(f'准确率 = {acc:.4f}，标准误 = {accs.std():.4f}')
print(f'95% CI = [{np.percentile(accs, 2.5):.4f}, {np.percentile(accs, 97.5):.4f}]')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 检验前先定「显著性水平 α」和「最小可检测效应」，别事后随意挑 α
2. A/B 测试用双尾检验 + 报告置信区间，不要只看 p 值
3. 两组方差差异大时用 Welch t 检验（equal_var=False），别默认等方差
4. 多组比较（≥3 组）用 ANOVA 而非多次两两 t 检验，避免多重比较膨胀假阳性
5. 小样本或非正态数据优先 Bootstrap，别硬套正态假设
6. 报告结果时同时给 p 值、效应量（effect size）和置信区间，p 值不代表效应大小

### 踩坑记录

```text
坑 1：p 值小于 0.05 就当「业务上重要」
结论：样本量一大，极小的差异也会 p < 0.05，但实际无业务价值。
原因：p 值衡量「是否有差异」，不衡量「差异多大」，对样本量敏感。
解法：同时报告效应量和置信区间，判断差异是否达到业务意义阈值。

坑 2：多重比较不校正
结论：做 20 次检验，即使全无差异，也几乎必然出现至少一个 p < 0.05。
原因：每次检验有 5% 假阳性概率，多次叠加后第一类错误率暴涨。
解法：用 Bonferroni、FDR 等校正，或多组比较直接用 ANOVA。

坑 3：对非正态小样本硬用 t 检验
结论：t 检验的前提（正态性、样本量）不满足，p 值失真。
原因：t 分布近似依赖 CLT，重尾分布小样本收敛慢。
解法：先检验正态性（Shapiro），不满足用 Mann-Whitney U 或 Bootstrap。

坑 4：混淆「统计显著」和「因果成立」
结论：观察性数据里两组显著差异，误判为处理导致。
原因：混杂变量、选择偏差、辛普森悖论都会产生虚假显著。
解法：随机化实验 + 协变量控制，观察数据用倾向得分/因果推断。

坑 5：置信区间解读错误
结论：误以为「95% CI 有 95% 概率包含真实参数」。
原因：参数是固定值，不是随机变量；随机的是区间本身。
解法：正确解读为「重复抽样 100 次，约 95 个区间覆盖真值」。
```
