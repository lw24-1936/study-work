## 概述

深度学习论文按里程碑演进：AlexNet 点燃了深度卷积网络，VGG 确立「小卷积核堆叠」范式，ResNet 用残差连接解决深层退化，BatchNorm 和 Adam 分别稳定训练和加速优化，Attention 把「聚焦关键信息」形式化，Transformer 用纯注意力取代循环结构，ViT 把 Transformer 带进视觉。理解这条脉络，就掌握了现代深度学习的骨架。

```text
深度学习论文脉络：
1. CNN 崛起 → AlexNet（2012）→ VGG（2014）→ ResNet（2015）
2. 训练稳定 → BatchNorm（2015）、Adam（2014）
3. 注意力机制 → Attention（2014）→ Transformer（2017）
4. Transformer 泛化 → ViT（2020，视觉）
```

import torch
import torch.nn as nn

## AlexNet

AlexNet（Krizhevsky et al., 2012）解决「深层 CNN 如何在大规模图像上训练并大幅提升精度」的问题：用 ReLU 加速收敛、Dropout 防过拟合、GPU 并行训练、重叠池化与数据增强，在 ImageNet 上把 top-5 错误率从 26% 降到 15.3%。核心贡献是证明「深度 CNN + 大数据 + GPU」可行。

```text
论文解决的问题：
浅层模型 + 手工特征在 ImageNet 上效果有限，深层网络难训练。

核心思想：
1. ReLU —— 替代 sigmoid/tanh，缓解梯度消失、加速收敛
2. Dropout —— 随机丢弃神经元，抑制过拟合
3. GPU 并行 —— 分两路卷积跨 GPU 训练
4. 数据增强 —— 裁剪/翻转扩充数据

关键贡献：
开启深度学习时代，让 CNN 成为视觉任务的标准 backbone。
```

```python
class AlexNet(nn.Module):
    def __init__(self, num_classes=1000):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 96, 11, stride=4), nn.ReLU(), nn.MaxPool2d(3, 2),
            nn.Conv2d(96, 256, 5, padding=2), nn.ReLU(), nn.MaxPool2d(3, 2),
            nn.Conv2d(256, 384, 3, padding=1), nn.ReLU(),
            nn.Conv2d(384, 384, 3, padding=1), nn.ReLU(),
            nn.Conv2d(384, 256, 3, padding=1), nn.ReLU(), nn.MaxPool2d(3, 2))
        self.classifier = nn.Sequential(
            nn.Dropout(), nn.Linear(256 * 6 * 6, 4096), nn.ReLU(),
            nn.Dropout(), nn.Linear(4096, 4096), nn.ReLU(),
            nn.Linear(4096, num_classes))
```

## VGG

VGG（Simonyan & Zisserman, 2014）解决「CNN 架构如何设计得更简洁、更可扩展」的问题：用大量 3×3 小卷积核堆叠替代大卷积核，网络更深、参数更规整。核心贡献是证明「深度比卷积核大小更重要」，确立了「小卷积核堆叠」的经典范式。

```text
论文解决的问题：
AlexNet 的大卷积核参数量大、结构不规整，如何系统化设计深层网络。

核心思想：
1. 3×3 堆叠 —— 两个 3×3 感受野等于一个 5×5，三个等于 7×7，
   但参数更少、非线性更多
2. 深度加深 —— VGG16/VGG19，验证深度带来的精度提升
3. 结构统一 —— 全部用 3×3 卷积 + 2×2 池化

关键贡献：
确立「小卷积核 + 深网络」范式，成为特征提取的通用 backbone。
```

```python
def vgg_block(in_c, out_c, n_conv):
    layers = []
    for _ in range(n_conv):
        layers += [nn.Conv2d(in_c, out_c, 3, padding=1), nn.ReLU()]
        in_c = out_c
    layers.append(nn.MaxPool2d(2, 2))
    return nn.Sequential(*layers)

class VGG(nn.Module):
    def __init__(self, num_classes=1000):
        super().__init__()
        self.features = nn.Sequential(
            vgg_block(3, 64, 2), vgg_block(64, 128, 2),
            vgg_block(128, 256, 3), vgg_block(256, 512, 3),
            vgg_block(512, 512, 3))
        self.classifier = nn.Sequential(
            nn.Linear(512 * 7 * 7, 4096), nn.ReLU(), nn.Dropout(),
            nn.Linear(4096, 4096), nn.ReLU(), nn.Dropout(),
            nn.Linear(4096, num_classes))
```

## ResNet

ResNet（He et al., 2015）解决「网络加深后反而退化（训练误差上升）」的问题：引入残差连接（skip connection），让网络学习「残差映射」而非直接拟合目标。核心是「恒等映射 + 残差」，使数百上千层的网络可训练，拿下 ImageNet 冠军。

```text
论文解决的问题：
深层网络出现退化——层数越多训练误差越高，不是过拟合而是难优化。

核心思想：
1. 残差连接 —— 输出 y = F(x) + x，让层学习残差 F(x)
2. 恒等捷径 —— x 直接跳连，梯度可无损回传
3. 瓶颈块 —— 1×1 降维 + 3×3 + 1×1 升维，控制参数

关键贡献：
解决深度网络的梯度退化问题，让「越深越好」重新成立，
成为几乎所有视觉 backbone 的基础组件。
```

```python
class ResidualBlock(nn.Module):
    def __init__(self, in_c, out_c, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_c, out_c, 3, stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_c)
        self.conv2 = nn.Conv2d(out_c, out_c, 3, 1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_c)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_c != out_c:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_c, out_c, 1, stride, bias=False),
                nn.BatchNorm2d(out_c))

    def forward(self, x):
        out = nn.ReLU()(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)          # 残差连接
        return nn.ReLU()(out)
```

## BatchNorm

Batch Normalization（Ioffe & Szegedy, 2015）解决「训练时内部协变量偏移、对学习率敏感」的问题：对每个 mini-batch 的激活值做标准化，再学回缩放和平移参数。核心是「归一化每层输入分布」，稳定训练、允许更大学习率、加速收敛。

```text
论文解决的问题：
深层网络训练中每层输入分布不断变化，导致收敛慢、对初始化敏感。

核心思想：
1. 批归一化 —— 对 batch 内每个特征标准化到 0 均值 1 方差
2. 可学习缩放 —— γ 缩放 + β 平移，恢复表达能力
3. 训练/推理差异 —— 训练用 batch 统计量，推理用滑动平均

关键贡献：
大幅加速收敛、放宽初始化要求、自带轻微正则化，
成为深层网络的标配组件。
```

```python
# BatchNorm 的核心公式
def batchnorm_forward(x, gamma, beta, eps=1e-5):
    mean = x.mean(axis=0)
    var = x.var(axis=0)
    x_hat = (x - mean) / (var + eps) ** 0.5
    return gamma * x_hat + beta
```

## Adam

Adam（Kingma & Ba, 2014）解决「SGD 收敛慢、对学习率敏感」的问题：结合动量（Momentum）和自适应学习率（RMSProp），对梯度的一阶矩和二阶矩做偏差修正。核心是「一阶动量加速 + 二阶动量自适应」，是深度学习默认优化器。

```text
论文解决的问题：
如何设计一个收敛快、对超参数鲁棒、适用于大规模数据的优化器。

核心思想：
1. 一阶矩 m —— 梯度指数移动平均（动量），加速下降
2. 二阶矩 v —— 梯度平方的指数移动平均，自适应缩放学习率
3. 偏差修正 —— 修正 m、v 初始为 0 带来的低估

关键贡献：
把动量与自适应学习率统一，成为训练深度学习模型的事实标准。
```

```python
def adam_update(params, grads, m, v, t, lr=1e-3, b1=0.9, b2=0.999, eps=1e-8):
    for i in range(len(params)):
        m[i] = b1 * m[i] + (1 - b1) * grads[i]
        v[i] = b2 * v[i] + (1 - b2) * grads[i] ** 2
        m_hat = m[i] / (1 - b1 ** t)     # 偏差修正
        v_hat = v[i] / (1 - b2 ** t)
        params[i] -= lr * m_hat / (v_hat ** 0.5 + eps)
```

## Attention

注意力机制（Bahdanau et al., 2014）解决「seq2seq 用固定长度向量编码整个输入、信息压缩损失」的问题：让解码器在每一步「动态关注」输入序列的相关位置，用加权求和代替固定向量。核心是「Query-Key-Value 加权聚合」，是 Transformer 的前身。

```text
论文解决的问题：
长序列的 encoder-decoder 模型信息瓶颈——固定向量装不下全部输入。

核心思想：
1. 注意力权重 —— 用 query 与每个 key 的相似度计算权重
2. 加权求和 —— 对 value 按权重加权，聚焦相关位置
3. 软对齐 —— 可微的软注意力，端到端训练

关键贡献：
把「注意力」从直觉变成可训练模块，解决序列信息瓶颈，
直接催生了 Transformer。
```

```python
import torch.nn.functional as F

def scaled_dot_attention(q, k, v, d_k):
    scores = q @ k.transpose(-2, -1) / (d_k ** 0.5)   # 缩放点积
    attn = F.softmax(scores, dim=-1)
    return attn @ v
```

## Transformer

Transformer（Vaswani et al., 2017）解决「RNN 序列建模无法并行、长程依赖难捕捉」的问题：完全用自注意力（Self-Attention）替代循环结构，配合位置编码、多头注意力、残差与前馈网络。核心是「纯注意力 + 并行化」，奠定现代 LLM 的架构基础。

```text
论文解决的问题：
序列到序列任务中 RNN 顺序计算慢、长距离依赖衰减。

核心思想：
1. 自注意力 —— 序列内任意两位置直接交互，O(1) 路径长度
2. 多头注意力 —— 多个子空间并行关注不同关系
3. 位置编码 —— 补充注意力缺失的顺序信息
4. 并行化 —— 完全去掉循环，可整句并行训练

关键贡献：
以纯注意力架构取代 RNN，成为 NLP 乃至多模态的通用底座，
是 BERT、GPT、ViT 的共同祖先。
```

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_k = d_model // n_heads
        self.n_heads = n_heads
        self.qkv = nn.Linear(d_model, d_model * 3)
        self.out = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, T, C = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        q = q.view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = k.view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        v = v.view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        attn = F.softmax(q @ k.transpose(-2, -1) / (self.d_k ** 0.5), dim=-1)
        out = (attn @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.out(out)
```

## ViT

Vision Transformer（Dosovitskiy et al., 2020）解决「Transformer 如何应用到视觉」的问题：把图像切成固定大小的 patch，当作 token 序列喂给标准 Transformer，去掉卷积归纳偏置。核心是「图像 = patch 序列」，证明纯 Transformer 在大数据预训练下可超越 CNN。

```text
论文解决的问题：
Transformer 依赖序列结构，图像是二维网格，如何直接套用。

核心思想：
1. Patch 切分 —— 图像切成 16×16 的 patch，展平成 token
2. 位置嵌入 —— 可学习的 patch 位置编码
3. 纯 Transformer —— 去掉 CNN，完全用自注意力
4. 大数据预训练 —— 在大规模数据预训练后迁移，超越 CNN

关键贡献：
证明 Transformer 的通用性，开创「视觉 Transformer」方向，
是后续 Swin、CLIP、多模态模型的起点。
```

```python
class ViT(nn.Module):
    def __init__(self, img_size=224, patch_size=16, d_model=768,
                 n_heads=12, num_classes=1000):
        super().__init__()
        n_patches = (img_size // patch_size) ** 2
        self.patch_embed = nn.Conv2d(3, d_model, patch_size, patch_size)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, d_model))
        self.pos_embed = nn.Parameter(torch.zeros(1, n_patches + 1, d_model))
        self.head = nn.Linear(d_model, num_classes)

    def forward(self, x):
        x = self.patch_embed(x)          # (B, d_model, H', W')
        x = x.flatten(2).transpose(1, 2) # (B, n_patches, d_model)
        cls = self.cls_token.expand(x.shape[0], -1, -1)
        x = torch.cat([cls, x], dim=1) + self.pos_embed
        return self.head(x[:, 0])        # 用 cls token 分类
```

## 最佳实践与踩坑记录

### 最佳实践

1. 视觉任务优先用 ResNet 预训练权重做迁移，别从零训练
2. BatchNorm 训练和推理模式要区分，推理时用滑动统计量
3. Adam 是默认优化器，但大模型/长训练常用 AdamW（带权重衰减）
4. 注意力维度 d_k 较大时用缩放点积，避免 softmax 饱和
5. Transformer 必须加位置编码，否则丢失顺序信息
6. ViT 需要大数据预训练，小数据上 CNN 通常更优

### 踩坑记录

```text
坑 1：BatchNorm 训练/推理模式混用
结论：推理时仍用 batch 统计量，小 batch 下结果抖动。
原因：忘了 model.eval() 或手动改统计量。
解法：推理前 model.eval()，让 BN 用滑动平均的全局统计量。

坑 2：Adam 不用偏差修正
结论：训练初期步长偏大，收敛不稳定甚至发散。
原因：m、v 初始为 0，前几步估计严重偏低。
解法：按公式 m_hat = m/(1-b1^t)、v_hat = v/(1-b2^t) 做偏差修正。

坑 3：Transformer 漏加位置编码
结论：序列打乱后结果不变，模型学不到顺序关系。
原因：自注意力对位置天然不敏感，无位置信息。
解法：加可学习位置嵌入或正弦位置编码。

坑 4：残差连接前忘归一化
结论：深层网络梯度不稳定，训练困难。
原因：残差结构里 BN/归一化位置不对，信号传播失衡。
解法：用 pre-norm（先归一化再残差）或标准 post-norm 结构。

坑 5：ViT 在小数据集上直接训练
结论：精度不如同等规模的 CNN，过拟合严重。
原因：ViT 缺少卷积的归纳偏置，小数据学不到好的 patch 表征。
解法：用大规模预训练权重迁移，小数据场景优先 CNN。
```
