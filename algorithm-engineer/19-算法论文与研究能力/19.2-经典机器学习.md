## 概述

经典机器学习论文塑造了「数据驱动建模」的底层范式：SVM 用最大间隔和核方法解决高维分类，集成学习（AdaBoost/GBDT/XGBoost/LightGBM）用「弱学习器组合」逼近强学习器，PCA 提供线性降维，EM 解决含隐变量的参数估计，HMM 建模序列数据的隐状态转移。它们至今仍是工业界表格数据建模的主力，也是理解深度学习的基础。

```text
经典 ML 论文脉络：
1. 分类/回归 → SVM（间隔最大化 + 核技巧）
2. 集成学习 → Bagging（随机森林）、Boosting（AdaBoost → GBDT → XGBoost → LightGBM）
3. 降维 → PCA（最大方差投影）
4. 隐变量估计 → EM 算法（通用框架）
5. 序列建模 → HMM（隐状态 + 观测 + 转移）
```

```python
# 经典 ML 的通用建模流程
from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

## SVM

支持向量机（Cortes & Vapnik, 1995）解决「高维空间分类」问题：在特征空间找一个使两类间隔（margin）最大的超平面，只依赖少数支持向量。核心创新是「最大间隔原则」和「核技巧」——用核函数隐式映射到高维，避免显式计算高维特征。

```text
论文解决的问题：
线性不可分数据如何稳健分类，且在高维特征空间不显式计算。

核心思想：
1. 最大化分类间隔 → 提高泛化能力，只由支持向量决定
2. 核技巧 K(x,z)=φ(x)·φ(z) → 隐式高维映射，免去显式 φ
3. 软间隔 + 松弛变量 → 容忍噪声与少量误分

关键贡献：
把「间隔最大化 + 凸优化 + 核方法」统一成可解的对偶问题，
奠定了一代分类器标准。
```

```python
from sklearn.svm import SVC
from sklearn.datasets import make_classification

X, y = make_classification(n_samples=200, n_features=5, random_state=0)
clf = SVC(kernel='rbf', C=1.0)          # RBF 核
clf.fit(X, y)
print(clf.support_vectors_.shape)        # 支持向量个数
```

## Random Forest

随机森林（Breiman, 2001）解决「单棵决策树过拟合、不稳定」的问题：用 Bagging 训练多棵决策树，并对每棵树随机抽样特征，投票/平均得到结果。核心创新是「样本随机 + 特征随机」的双重随机性，降低方差、提升鲁棒性。

```text
论文解决的问题：
单棵树方差大、易过拟合；Bagging 减少方差但树之间相关性强。

核心思想：
1. Bootstrap 抽样 —— 每棵树在不同样本子集上训练
2. 随机特征选择 —— 每次分裂只在随机特征子集中选最优
3. 多数投票/平均 —— 集成多棵树结果

关键贡献：
通过「样本 + 特征」双重随机化降低树间相关性，
使集成方差进一步下降，成为最实用的 off-the-shelf 模型。
```

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(n_estimators=100, max_depth=None,
                            max_features='sqrt')
rf.fit(X, y)
print(rf.feature_importances_)           # 特征重要性
```

## AdaBoost

AdaBoost（Freund & Schapire, 1997）解决「弱学习器如何组合成强学习器」的问题：迭代训练，每轮提高上一轮分错样本的权重，让后续弱学习器关注难分样本，最后按准确率加权投票。核心是「自适应重加权」，是 Boosting 思想的开山之作。

```text
论文解决的问题：
能否把任意比随机好的弱分类器提升为强分类器。

核心思想：
1. 样本权重 —— 分错的样本权重增大，下一轮被重点学习
2. 学习器权重 —— 准确率高的弱学习器话语权更大
3. 加权投票 —— 所有弱学习器加权组合

关键贡献：
提出第一个可证明的 Boosting 算法，证明训练误差指数下降，
开辟了集成学习 Boosting 分支。
```

```python
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier

ada = AdaBoostClassifier(
    base_estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=50)
ada.fit(X, y)
print(ada.estimator_weights_)            # 各弱学习器权重
```

## GBDT

梯度提升决策树（Friedman, 2001）把 Boosting 从「重加权」推广到「梯度下降」：每棵新树拟合「上一轮模型的负梯度（残差）」，沿着损失函数下降方向逐步逼近。核心是「用回归树拟合负梯度」，适用于任意可导损失函数。

```text
论文解决的问题：
AdaBoost 重加权只适用特定损失，如何对任意损失做 Boosting。

核心思想：
1. 负梯度 = 残差的推广 —— 每轮拟合损失函数的负梯度方向
2. 累加模型 —— 新树叠加到已有模型，逐步降低损失
3. 任意损失 —— 分类、回归、排序都可套用同一框架

关键贡献：
把 Boosting 统一为「函数空间上的梯度下降」，
是 XGBoost/LightGBM/CatBoost 的共同祖先。
```

```python
from sklearn.ensemble import GradientBoostingClassifier

gbdt = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1)
gbdt.fit(X, y)
print(gbdt.n_estimators_)                # 树的数量
```

## XGBoost

XGBoost（Chen & Guestrin, 2016）解决「GBDT 在大规模数据上训练慢、精度待提升」的问题：对损失函数做二阶泰勒展开，显式加正则项控制复杂度，支持近似分裂、稀疏感知、缓存优化与并行。核心创新是「二阶梯度 + 正则化 + 工程优化」。

```text
论文解决的问题：
GBDT 一阶梯度收敛慢、易过拟合，大规模数据训练效率低。

核心思想：
1. 二阶泰勒展开 —— 用梯度和 Hessian 更精确地近似损失
2. 显式正则 —— 叶子数与叶子权重 L2 正则，控制复杂度
3. 工程优化 —— 预排序、稀疏感知、分块并行、缓存友好

关键贡献：
把梯度提升推向工程极致，成为 Kaggle 与工业表格数据
长期霸榜的默认模型。
```

```python
import xgboost as xgb

dtrain = xgb.DMatrix(X, label=y)
params = {'max_depth': 3, 'eta': 0.1, 'objective': 'binary:logistic'}
bst = xgb.train(params, dtrain, num_boost_round=100)
```

## LightGBM

LightGBM（Ke et al., 2017）解决「XGBoost 在超高维、超大数据上训练慢」的问题：用基于直方图的特征离散化、单边梯度采样（GOSS）、互斥特征捆绑（EFB）、叶子生长（leaf-wise）等策略大幅提速降内存。核心创新是「直方图 + 抽样 + 捆绑」的近似加速。

```text
论文解决的问题：
XGBoost 的预排序算法在高维大数据上内存大、速度慢。

核心思想：
1. 直方图分桶 —— 连续特征离散化，分裂在桶上计算
2. GOSS —— 保留大梯度样本、采样小梯度样本，减少计算
3. EFB —— 互斥特征捆绑，降低特征维度
4. leaf-wise 生长 —— 优先分裂增益最大的叶子

关键贡献：
在不明显损失精度下把训练速度/内存提升一个数量级，
是超大规模表格数据的首选 GBDT。
```

```python
import lightgbm as lgb

dset = lgb.Dataset(X, label=y)
bst = lgb.train({'objective': 'binary', 'metric': 'auc'},
                dset, num_boost_round=100)
```

## PCA

主成分分析（Pearson, 1901; Hotelling, 1933）解决「高维数据的降维与去相关」问题：找一组正交方向（主成分），使数据在这些方向上的投影方差最大。核心是用特征值分解/奇异值分解得到「最大方差方向」，是最经典的线性降维方法。

```text
论文解决的问题：
高维数据如何用更少的正交维度保留最多信息。

核心思想：
1. 最大方差 —— 主成分是方差最大的投影方向
2. 正交分解 —— 对协方差矩阵做特征值分解
3. 截断重构 —— 取前 k 大特征值对应方向

关键贡献：
给出「方差最大化 = 特征值分解」的几何解释，
成为降维、去噪、可视化的标准工具。
```

```python
import numpy as np

def pca(X, k):
    X = X - X.mean(axis=0)               # 去中心化
    cov = X.T @ X / (len(X) - 1)         # 协方差矩阵
    eigvals, eigvecs = np.linalg.eigh(cov)
    idx = np.argsort(eigvals)[::-1][:k]  # 前 k 大特征值
    return X @ eigvecs[:, idx]

X_std = np.random.randn(100, 10)
print(pca(X_std, 2).shape)               # (100, 2)
```

## EM

期望最大化算法（Dempster et al., 1977）解决「含隐变量模型的参数估计」问题：当数据有缺失/隐变量时，似然函数难直接优化，EM 通过「E 步求隐变量期望 + M 步最大化期望似然」迭代逼近。核心是「用隐变量的后验分布补全信息」。

```text
论文解决的问题：
观测数据不完全（有隐变量/缺失）时如何做极大似然估计。

核心思想：
1. E 步 —— 用当前参数求隐变量的后验期望（补全）
2. M 步 —— 最大化补全后的期望对数似然（更新参数）
3. 迭代收敛 —— 每轮都保证似然不下降

关键贡献：
给出一个通用的隐变量参数估计框架，
是 GMM、HMM、LDA 等模型的统一求解方法。
```

```python
import numpy as np

def em_gmm(X, k=2, iters=20):
    n, d = X.shape
    # 初始化均值、方差、权重
    means = X[np.random.choice(n, k, replace=False)]
    covs = [np.eye(d) for _ in range(k)]
    weights = np.ones(k) / k
    for _ in range(iters):
        # E 步：计算每个样本属于每个簇的责任度
        resp = np.zeros((n, k))
        for j in range(k):
            diff = X - means[j]
            resp[:, j] = weights[j] * np.exp(
                -0.5 * np.sum(diff @ np.linalg.inv(covs[j]) * diff, axis=1))
        resp /= resp.sum(axis=1, keepdims=True)
        # M 步：更新参数
        nk = resp.sum(axis=0)
        weights = nk / n
        means = (resp.T @ X) / nk[:, None]
    return means, weights
```

## HMM

隐马尔可夫模型（Rabiner, 1989 教程）解决「带隐状态的序列建模」问题：观测序列由一条不可见的隐状态链生成，隐状态按马尔可夫链转移，每个状态以一定概率发射观测。核心是「隐状态 + 转移 + 发射」三层结构，配前向-后向、Viterbi、Baum-Welch 三大算法。

```text
论文解决的问题：
序列数据背后的隐状态如何推断（如语音、词性、基因）。

核心思想：
1. 隐状态链 —— 真实状态不可见，按转移矩阵演化
2. 发射概率 —— 每个隐状态以分布生成观测
3. 三大算法 —— 前向-后向（求似然）、Viterbi（解码最优路径）、
   Baum-Welch（EM 学习参数）

关键贡献：
把马尔可夫链推广到「部分可观测」场景，
是序列标注与语音识别的经典基础。
```

```python
def viterbi(obs, states, start_p, trans_p, emit_p):
    V = [{}]
    for st in states:
        V[0][st] = start_p.get(st, 0) * emit_p[st].get(obs[0], 0)
    for t in range(1, len(obs)):
        V.append({})
        for st in states:
            prob = max(V[t-1][prev] * trans_p[prev].get(st, 0)
                       * emit_p[st].get(obs[t], 0) for prev in states)
            V[t][st] = prob
    return max(V[-1].values())
```

## 应用场景实战

### 场景一：表格数据分类——集成模型对比

```python
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

for name, m in [('RandomForest', RandomForestClassifier(n_estimators=100)),
                ('GBDT', GradientBoostingClassifier(n_estimators=100))]:
    scores = cross_val_score(m, X, y, cv=5)
    print(f'{name}: acc={scores.mean():.3f} ± {scores.std():.3f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 表格数据先跑 RandomForest/GBDT 当 baseline，再调 XGBoost/LightGBM
2. SVM 对小样本高维数据（文本、基因）效果好，大数据量换 GBDT/神经网络
3. 集成模型树的数量和深度是首要调参对象，学习率与树数要配合
4. PCA 降维前先标准化，否则量纲大的特征主导主成分
5. EM 依赖初始值，多起点或 KMeans 初始化避免陷入局部最优
6. HMM 适合短程依赖序列，长程依赖换 RNN/LSTM

### 踩坑记录

```text
坑 1：SVM 在大样本上训练慢
结论：数据到 10 万级，RBF 核 SVM 训练时间不可接受。
原因：SVM 求解二次规划，复杂度随样本数超线性增长。
解法：换线性核或改用 GBDT/神经网络，或采样后用 SGD 近似。

坑 2：XGBoost 树数太多导致过拟合
结论：训练集拟合极好，测试集掉点，泛化差。
原因：树数（num_boost_round）过大且无早停，模型过度复杂。
解法：加 early stopping，或用验证集选最优树数。

坑 3：PCA 不标准化直接降维
结论：方差大的特征（量纲大）主导主成分，降维失真。
原因：主成分对量纲敏感，未标准化时方差被量纲扭曲。
解法：降维前 StandardScaler 标准化。

坑 4：EM 收敛到局部最优
结论：不同初始化得到不同结果，有的明显更差。
原因：EM 只能保证似然单调不降，不保证全局最优。
解法：多起点初始化取最优，或用 KMeans 提供好初值。

坑 5：LightGBM 用 leaf-wise 树深失控
结论：树过深导致过拟合，且 leaf-wise 易偏向深树。
原因：leaf-wise 生长只追增益，不限制叶子数。
解法：显式设 max_depth / num_leaves，配合 min_data_in_leaf。
```
