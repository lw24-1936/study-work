## 概述

特征选择是从原始特征里挑出一个「最有信息量」的子集，目的有三个：减少过拟合、加快训练、提升可解释性。方法大致分三类——过滤法（Filter，按统计量打分独立筛）、包裹法（Wrapper，用模型效果反复搜索子集）、嵌入法（Embedded，模型训练过程自带选择）。选择哪种取决于数据规模、特征数量和对可解释性的要求。

```text
特征选择的三条路线：
1. 过滤法（Filter）→ 方差、相关性、卡方、互信息，快但忽略特征间交互
2. 包裹法（Wrapper）→ RFE、前向/后向搜索，准但计算量大
3. 嵌入法（Embedded）→ L1、树模型重要性、SHAP，兼顾效果与效率
```

```python
import numpy as np
import pandas as pd
from sklearn.datasets import make_classification

# 构造 30 个特征、其中 5 个真正有信息的数据集
X, y = make_classification(n_samples=2000, n_features=30,
                           n_informative=5, n_redundant=5,
                           random_state=42)
X = pd.DataFrame(X, columns=[f'f{i}' for i in range(30)])
print(X.shape)   # (2000, 30)
```

## Variance Threshold

Variance Threshold（方差阈值）删除方差低于阈值的特征：方差接近 0 的特征（几乎取同一个值）不携带任何信息，直接丢弃。它是特征选择的第一步、最廉价的过滤器，尤其适合先清理常量列。

```text
核心思想：
1. 方差 ≈ 0 → 该特征几乎不变，无区分能力
2. 只适用于数值特征；类别特征需先编码
3. 阈值需人工设定，或直接删「方差为 0」的列
```

```python
from sklearn.feature_selection import VarianceThreshold

# 造一个常量列
X['const'] = 7.0
selector = VarianceThreshold(threshold=0.0)
X_sel = selector.fit_transform(X)
print(f'原始特征数: {X.shape[1]} → 过滤后: {X_sel.shape[1]}')
# 常量列被删除
```

```text
Variance Threshold 的坑：
1. 方差与量纲有关 —— 不同量纲特征方差不可直接比，先标准化
2. 方差小 ≠ 无用 —— 二元特征方差天然小（如罕见类别），别误删
3. 只做初筛，不能替代真正的特征选择
```

## Correlation

Correlation（相关性过滤）计算特征与目标（或特征之间）的皮尔逊相关系数，删除与目标相关性极低、或彼此高度相关（冗余）的特征。它假设「线性相关」能衡量重要性，对非线性关系无效。

```text
核心思想：
1. 特征 vs 目标 —— 相关低则剔除
2. 特征 vs 特征 —— 相关高（如 > 0.95）则冗余，保留一个
3. 只捕捉线性关系，非线性关系会漏掉
```

```python
# 特征与目标的相关性排序
corr_with_target = X.corrwith(pd.Series(y)).abs().sort_values(ascending=False)
print(corr_with_target.head(10))
```

```python
# 特征之间的高相关（冗余）检测
corr_matrix = X.corr().abs()
upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
high_corr = [col for col in upper.columns if any(upper[col] > 0.95)]
print(f'高度冗余特征（与其它特征相关 > 0.95）: {high_corr}')
```

```text
Correlation 的坑：
1. 只衡量线性 —— 强非线性关系相关系数可能接近 0
2. 特征间相关阈值难定 —— 太高漏删冗余，太低误删有用特征
3. 相关 ≠ 因果 —— 相关性高不代表特征真正有用
```

## Chi-Square

Chi-Square（卡方检验）衡量类别特征与类别目标之间的统计独立性：卡方值越大，特征与目标越不独立、越相关。它要求特征和目标都是「非负的计数/频率」，主要用在分类任务的类别特征筛选。

```text
核心思想：
1. 检验「特征与目标是否独立」，独立则无信息
2. 适用于类别特征 + 分类目标（或非负数值特征）
3. 返回卡方统计量与 p 值，p 越小越相关
```

```python
from sklearn.feature_selection import chi2, SelectKBest
from sklearn.preprocessing import MinMaxScaler

# 卡方要求特征非负，先做归一化
X_scaled = MinMaxScaler().fit_transform(X)
chi_scores, p_values = chi2(X_scaled, y)
chi_df = pd.DataFrame({'feature': X.columns, 'chi2': chi_scores, 'p': p_values})
print(chi_df.sort_values('chi2', ascending=False).head(5))
```

```python
# 直接选 top-k 特征
selector = SelectKBest(chi2, k=10)
X_chi = selector.fit_transform(X_scaled, y)
print(f'卡方选出 {X_chi.shape[1]} 个特征')
```

## ANOVA

ANOVA（方差分析 / F 检验）检验「数值特征在不同目标类别下的均值是否有显著差异」：F 值越大，说明特征取值随类别变化越明显，区分度越强。它是数值特征 + 分类目标场景下的标准过滤法，sklearn 里对应 f_classif。

```text
核心思想：
1. 组间方差 / 组内方差 = F 值
2. 组间差异大、组内差异小 → F 值大 → 特征区分度高
3. 与卡方的区别 —— 卡方针对类别特征，ANOVA 针对数值特征
```

```python
from sklearn.feature_selection import f_classif

f_scores, p_values = f_classif(X, y)
f_df = pd.DataFrame({'feature': X.columns, 'F': f_scores, 'p': p_values})
print(f_df.sort_values('F', ascending=False).head(5))
```

```python
from sklearn.feature_selection import SelectKBest

selector = SelectKBest(f_classif, k=8)
X_anova = selector.fit_transform(X, y)
print(f'ANOVA 选出 {X_anova.shape[1]} 个特征')
```

## Mutual Information

Mutual Information（互信息）衡量「知道一个变量能减少另一个变量多少不确定性」，它不假设任何函数形式，能捕捉线性和非线性关系，是比相关系数更通用的过滤法指标。但互信息更难估计，且对连续变量需要分箱或密度估计。

```text
核心思想：
1. I(X;Y) = H(Y) - H(Y|X)，越大说明 X 越能解释 Y
2. 非线性 —— 能捕捉相关系数抓不到的关系
3. 分类用 mutual_info_classif，回归用 mutual_info_regression
4. 缺点 —— 值没有绝对上界，难横向比较；易受样本量影响
```

```python
from sklearn.feature_selection import mutual_info_classif

mi = mutual_info_classif(X, y, random_state=42)
mi_df = pd.DataFrame({'feature': X.columns, 'MI': mi})
print(mi_df.sort_values('MI', ascending=False).head(10))
```

```text
Mutual Information 的坑：
1. 估计偏差 —— 小样本下互信息估计不稳定，需多次采样平均
2. 分箱敏感 —— 连续特征的互信息对离散化方式敏感
3. 不能直接比绝对值 —— 只能用于「排序」，不能设统一阈值
```

## RFE

RFE（递归特征消除）是包裹法代表：先用模型训练，每次删除最不重要的一个（或一批）特征，再重新训练，直到剩下指定数量的特征。它考虑了特征间的交互和模型的实际表现，但计算量随特征数线性增长，适合特征数中等（几百以内）的场景。

```text
核心思想：
1. 训练模型 → 按权重/重要性排序 → 删除最差特征 → 重复
2. 优点 —— 用真实模型效果衡量，比过滤法更准
3. 缺点 —— 计算量大，且依赖基础模型的选择
```

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=100, random_state=42)
rfe = RFE(estimator=model, n_features_to_select=10)
rfe.fit(X, y)
print('被选中的特征:', X.columns[rfe.support_].tolist())
print('特征排名:', rfe.ranking_)
```

```python
# RFECV：用交叉验证自动选最优特征数
from sklearn.feature_selection import RFECV

rfecv = RFECV(estimator=model, cv=5, scoring='roc_auc', min_features_to_select=1)
rfecv.fit(X, y)
print(f'最优特征数: {rfecv.n_features_}')
```

## L1

L1 正则化（Lasso 等）天然做特征选择：L1 惩罚会把不重要的权重精确压到 0，权重为 0 的特征被自动剔除。它是嵌入法代表，训练一次就同时完成「建模 + 选择」，非常高效，但系数受特征量纲影响，需先标准化。

```text
核心思想：
1. L1 惩罚 → 稀疏解 → 部分权重精确为 0
2. 权重为 0 的特征被自动淘汰
3. 适用 —— 线性模型（Lasso、带 L1 的逻辑回归），特征多、样本少
```

```python
from sklearn.linear_model import Lasso
from sklearn.preprocessing import StandardScaler

# 用 Lasso 选特征（回归），分类用带 L1 的逻辑回归
X_std = StandardScaler().fit_transform(X)
lasso = Lasso(alpha=0.01)
lasso.fit(X_std, y)
selected = X.columns[lasso.coef_ != 0]
print(f'Lasso 选出 {len(selected)} 个特征:', selected.tolist())
```

```python
from sklearn.linear_model import LogisticRegression
from sklearn.svm import LinearSVC

# 分类场景的 L1 选择
clf = LogisticRegression(penalty='l1', solver='liblinear', C=0.1)
clf.fit(X_std, y)
print(f'L1 逻辑回归非零权重特征数: {np.sum(clf.coef_ != 0)}')
```

## Tree Importance

Tree Importance（树模型特征重要性）用决策树/随机森林/GBDT 训练后，统计「每个特征被用于切分所带来的不纯度下降总量」作为重要性。它能捕捉非线性关系、天然处理类别和缺失值，是表格数据最常用的特征重要性来源之一。

```text
核心思想：
1. 特征重要性 = 该特征所有切分的「不纯度下降」加权和
2. 优点 —— 非线性、无需求标准化、可处理缺失
3. 缺点 —— 高基数特征会虚高；相关特征间重要性会被分摊
```

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(n_estimators=200, random_state=42)
rf.fit(X, y)
importances = pd.Series(rf.feature_importances_, index=X.columns)
print(importances.sort_values(ascending=False).head(10))
```

```python
# 累积重要性筛选：保留能解释 90% 重要性的特征
sorted_imp = importances.sort_values(ascending=False)
cumsum = sorted_imp.cumsum()
k = (cumsum < 0.90).sum() + 1
print(f'累积 90% 重要性只需前 {k} 个特征')
```

## SHAP

SHAP（SHapley Additive exPlanations）基于博弈论中的 Shapley 值，为每个样本的每个特征计算一个「加性贡献值」，解释「这个特征把预测从基准值推高/拉低了多少」。它比树模型自带的 importance 更精细——能看方向、能看单样本，是目前最权威的特征归因方法。

```text
核心思想：
1. 每个特征得到 Shapley 值，所有贡献相加 = 预测值 - 基准值
2. 全局重要性 = 各样本 |SHAP| 的均值
3. 优点 —— 一致、可加、有方向、单样本可解释
4. 缺点 —— 精确计算指数级，用 TreeSHAP/KernelSHAP 近似
```

```python
import shap

# TreeSHAP：树模型的快速精确 SHAP
explainer = shap.TreeExplainer(rf)
shap_values = explainer.shap_values(X.iloc[:200])
# 取分类的第二类（正类）SHAP 值
if isinstance(shap_values, list):
    shap_values = shap_values[1]

# 全局重要性：|SHAP| 均值
global_imp = pd.Series(np.abs(shap_values).mean(axis=0), index=X.columns)
print(global_imp.sort_values(ascending=False).head(10))
```

```python
# 单样本解释：某样本各特征对预测的推高/拉低
import shap
shap.initjs()   # 用于 notebook 可视化（可选）
sample = X.iloc[[0]]
sv = explainer.shap_values(sample)
if isinstance(sv, list):
    sv = sv[1]
print('基准值:', explainer.expected_value)
print('样本 SHAP:', sv[0])
# 正向 SHAP → 推高预测，负向 SHAP → 拉低预测
```

## 应用场景实战

### 场景一：多阶段特征选择 Pipeline（过滤 → 嵌入 → 收尾）

```python
from sklearn.feature_selection import VarianceThreshold, SelectKBest, mutual_info_classif
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

# 阶段一：删常量
vt = VarianceThreshold(threshold=0.0)
X1 = vt.fit_transform(X)

# 阶段二：互信息初筛（保留 top 15）
skb = SelectKBest(mutual_info_classif, k=15)
X2 = skb.fit_transform(X1, y)

# 阶段三：树模型重要性微调
rf = RandomForestClassifier(n_estimators=200, random_state=42)
score = cross_val_score(rf, X2, y, cv=5, scoring='roc_auc')
print(f'多阶段选择后特征数: {X2.shape[1]}，CV AUC = {score.mean():.4f}')
```

### 场景二：SHAP 深度解释 + 特征淘汰

```python
import shap

# 训练后看 SHAP 全局重要性，淘汰 SHAP 接近 0 的特征
rf.fit(X, y)
explainer = shap.TreeExplainer(rf)
sv = explainer.shap_values(X.iloc[:500])
if isinstance(sv, list):
    sv = sv[1]

imp = np.abs(sv).mean(axis=0)
drop = X.columns[imp < 0.01].tolist()
print(f'SHAP 重要性极低、建议淘汰的特征: {drop}')

# 淘汰后重训对比
X_kept = X.drop(columns=drop)
rf2 = RandomForestClassifier(n_estimators=200, random_state=42)
s1 = cross_val_score(rf, X, y, cv=5, scoring='roc_auc').mean()
s2 = cross_val_score(rf2, X_kept, y, cv=5, scoring='roc_auc').mean()
print(f'全特征 AUC={s1:.4f} → 精简后 AUC={s2:.4f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先删常量/低方差特征，再做真正的特征选择，省时省力
2. 过滤法（互信息/方差）用于海量特征初筛，快速缩小范围
3. 最终模型用嵌入法（L1/树重要性/SHAP）筛选，效果与解释兼顾
4. 特征选择一定要在「训练集」内做，严禁在测试集上统计
5. 树模型的 importance 有偏，关键决策用 SHAP 交叉验证
6. 特征选择后要重新评估模型，确认性能没有显著下降
7. 保留特征的业务解释，避免只信统计指标

### 踩坑记录

```text
坑 1：在完整数据集上做特征选择再划分训练/测试
结论：测试集信息泄漏进特征选择，验证集 AUC 虚高。
原因：用全量数据算方差/互信息/重要性，等于偷看了测试集。
解法：先划分，特征选择只在训练集上 fit，测试集只 transform。

坑 2：树模型重要性偏爱高基数特征
结论：ID 类高基数特征重要性虚高，实际是过拟合。
原因：高基数特征切分点多，容易「记住」训练样本，不纯度下降虚大。
解法：用 SHAP 或 permutation importance 复核，高基数特征慎信 importance。

坑 3：相关特征间重要性被分摊
结论：两个高度相关的重要特征，各自重要性都不高，可能被误删。
原因：树模型在相关特征间随机切分，重要性被平均摊薄。
解法：先做相关性冗余处理，或用 SHAP/permutation 看「联合」贡献。

坑 4：方差阈值在不同量纲特征间直接比较
结论：大数值特征方差大被保留，小数值特征方差小被误删。
原因：方差与量纲强相关，未标准化不可比。
解法：先标准化再算方差，或只用方差阈值删「常数」特征。

坑 5：卡方检验用于负值或非计数特征
结论：chi2 报错或结果无意义。
原因：卡方假设输入是非负频率/计数，负值违反假设。
解法：数值特征用 ANOVA（f_classif），类别特征或非负计数用卡方。
```
