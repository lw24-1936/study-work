## 概述

时间特征是从时间戳或时间序列里挖掘出的特征，既包括「时间戳拆解」（年、月、日、星期、小时）这类基础特征，也包括「历史统计」（滞后、滚动、趋势、周期）这类序列特征。时间特征的核心价值在于：让模型「看见」时间的顺序依赖和周期规律，这是普通表格特征无法提供的。处理时间特征的头号陷阱是数据泄漏——任何用未来数据算的特征都不能在线下训练里直接使用。

```text
时间特征的两大类：
1. 日历特征 —— 年/月/日/星期/小时/节假日，从时间戳直接拆解
2. 序列特征 —— Lag/Rolling/EWMA/Trend/Seasonality/Fourier，从历史序列统计
关键约束：只能使用「当前时刻及之前」的信息，严禁用未来数据
```

```python
import pandas as pd
import numpy as np

# 构造一条按小时采样的时间序列
idx = pd.date_range('2024-01-01', periods=720, freq='h')
np.random.seed(42)
# 带趋势 + 日周期 + 噪声的序列
trend = np.linspace(0, 10, 720)
daily = 3 * np.sin(2 * np.pi * np.arange(720) / 24)
noise = np.random.randn(720) * 0.5
ts = pd.Series(trend + daily + noise, index=idx, name='value')
print(ts.head())
```

## Lag

Lag（滞后特征）把目标序列「向前平移 k 步」作为特征：lag_k(t) = value(t-k)。它是最基础也最有效的序列特征，让模型用「过去的值」预测「现在的值」，直接刻画了时间序列的自回归结构。

```text
核心思想：
1. lag_k(t) = value(t - k)，即取 k 步前的值
2. 刻画自回归依赖 —— 过去值影响未来值
3. 多个 lag 组合 → 模型可学到短期 + 长期依赖
```

```python
# 生成多个滞后特征
for k in [1, 2, 3, 24]:
    ts_lag = ts.shift(k)
    print(f'lag_{k} 前 3 个值:', ts_lag.iloc[k:k+3].round(2).tolist())
```

```python
# 把 lag 拼成特征表
lag_df = pd.DataFrame({'value': ts})
for k in [1, 2, 3, 24]:
    lag_df[f'lag_{k}'] = ts.shift(k)
print(lag_df.dropna().head())
# 注意前 k 行是 NaN，需 drop 或填充
```

## Rolling

Rolling（滚动窗口特征）用「过去 w 个时间步的统计量」作为特征，如滚动均值、滚动标准差、滚动最大/最小值。它能刻画局部趋势和波动水平，是平滑噪声、捕捉近期状态的常用手段。

```text
核心思想：
1. 用固定大小 w 的滑动窗口，统计窗口内的均值/标准差/最值
2. 窗口大小 w 决定「看多近的历史」——w 小则敏感，w 大则平滑
3. 滚动均值常用于平滑噪声、检测趋势拐点
```

```python
# 滚动均值、标准差、最大最小值
roll = pd.DataFrame({
    'value': ts,
    'roll_mean_7': ts.rolling(7).mean(),
    'roll_std_7': ts.rolling(7).std(),
    'roll_max_7': ts.rolling(7).max(),
    'roll_min_7': ts.rolling(7).min(),
})
print(roll.iloc[6:9].round(2))
```

```text
Rolling 的坑：
1. 窗口初期的 NaN —— rolling(w) 前 w-1 个值是 NaN
2. 用 rolling 前需确保序列已按时间排序
3. 窗口越大越平滑，但也会把近期突变「糊掉」
```

## Expanding

Expanding（扩展窗口特征）的窗口从序列起点一直「扩展到当前时刻」，统计的是「从开始到现在的累计均值/累计最大值」。它适合刻画「历史累计水平」，例如累计均值可作为归一化基准、累计最大值可检测是否创新高。

```text
核心思想：
1. 窗口大小随时间增长：t 时刻的窗口 = [0, t]
2. 累计均值 —— 历史平均水位，可作为长期基准
3. 累计最大/最小 —— 是否突破历史极值
```

```python
# 扩展窗口：累计均值、累计最大值
expanding = pd.DataFrame({
    'value': ts,
    'exp_mean': ts.expanding().mean(),
    'exp_max': ts.expanding().max(),
    'exp_min': ts.expanding().min(),
})
print(expanding.iloc[100:104].round(2))
```

```text
Expanding vs Rolling：
1. Expanding —— 窗口从起点开始，越来越长，统计全局历史
2. Rolling —— 窗口固定长度，只统计最近 w 步
3. 用途 —— Expanding 看长期基准，Rolling 看近期状态
```

## EWMA

EWMA（指数加权移动平均）对历史值做「指数衰减」加权：越近的值权重越大，越远的值权重越小。相比等权重的 Rolling，EWMA 对近期变化更敏感，且没有「窗口边界跳变」的问题，是金融和时序预测里最常用的平滑与趋势指标。

```text
核心思想：
1. 权重按 (1-α)^k 指数衰减，α 越大越敏感
2. span = w 时 α = 2/(w+1)
3. 优点 —— 平滑且无窗口边界，近期突变响应快
4. 用途 —— 趋势跟踪、去噪、技术指标（MACD 等）
```

```python
# 指数加权移动平均
ewma = pd.DataFrame({
    'value': ts,
    'ewma_span7': ts.ewm(span=7).mean(),
    'ewma_span24': ts.ewm(span=24).mean(),
    'ewma_halflife12': ts.ewm(halflife=12).mean(),
})
print(ewma.iloc[10:14].round(2))
```

```text
EWMA 的参数理解：
1. span —— 大约对应 Rolling 的窗口长度（span=7 ≈ 7 步窗口）
2. halflife —— 权重衰减到一半所需步数
3. α 直接指定 —— 越大越敏感（α=1 退化为只取当前值）
```

## Trend

Trend（趋势）指序列长期的、单调的上升或下降方向，剥离了季节和噪声。提取趋势的常用方法：移动平均（简单、滞后）、线性回归拟合（给出斜率）、Hodrick-Prescott 滤波、以及差分（一阶差分消除趋势）。趋势特征是判断「处于上升期还是下降期」的关键。

```text
核心思想：
1. 趋势 = 序列的长期方向，通常用平滑或回归提取
2. 方法 —— 移动平均、线性拟合斜率、HP 滤波、差分
3. 用途 —— 判断拐点、作为回归/分类的重要特征
```

```python
from sklearn.linear_model import LinearRegression

# 用滚动线性回归提取「局部趋势斜率」
def rolling_slope(s, w=24):
    x = np.arange(w).reshape(-1, 1)
    slopes = []
    for i in range(w, len(s) + 1):
        y = s.iloc[i-w:i].values
        lr = LinearRegression().fit(x, y)
        slopes.append(lr.coef_[0])
    return pd.Series([np.nan] * (w - 1) + slopes, index=s.index)

ts_trend = rolling_slope(ts, w=24)
print('局部趋势斜率（前 30 步中的有效部分）:')
print(ts_trend.iloc[23:28].round(3))
```

```python
# 差分消除趋势
ts_diff = ts.diff(1)
print('一阶差分后前 5 个值:', ts_diff.iloc[1:6].round(2).tolist())
```

## Seasonality

Seasonality（季节性/周期性）指序列在固定周期上重复的模式，如每日高峰、每周规律、年度淡旺季。提取季节性常用「周期分解」（加法/乘法模型）、按周期分组的均值模板、或差分（季节差分消除周期）。季节特征让模型记住「几点、周几、几月」的固定规律。

```text
核心思想：
1. 季节性 = 固定周期重复的模式（日/周/月/年）
2. 加法模型：value = trend + seasonal + residual
3. 乘法模型：value = trend × seasonal × residual（波动幅度随趋势放大）
```

```python
from statsmodels.tsa.seasonal import seasonal_decompose

# 季节分解（加法模型，周期设为 24 小时）
decomp = seasonal_decompose(ts, model='additive', period=24)
print('趋势分量:', decomp.trend.iloc[24:28].round(2).tolist())
print('季节分量:', decomp.seasonal.iloc[24:28].round(2).tolist())
print('残差分量:', decomp.resid.iloc[24:28].round(2).tolist())
```

```python
# 按周期分组提取「日小时模板」（每小时的平均水平）
hour_pattern = ts.groupby(ts.index.hour).mean()
print('每日 24 小时的平均模式（前 8 小时）:')
print(hour_pattern.head(8).round(2))
```

## Fourier

Fourier（傅里叶特征）用一组正弦/余弦基函数表示周期性，把「时间」编码成 sin/cos 特征喂给模型。相比直接用「几点」这类整数特征，Fourier 特征能天然刻画「23 点和 0 点其实很近」的循环性，是线性模型和时间编码的利器。

```text
核心思想：
1. 周期 P 的 k 阶傅里叶特征 = sin(2πk·t/P)、cos(2πk·t/P)
2. 循环性 —— 时刻首尾相接，23 点与 0 点距离近
3. 优点 —— 线性模型也能拟合周期，可调阶数控制复杂度
4. 用途 —— 日/周/年周期的编码，比 one-hot 小时更平滑
```

```python
# 构造日周期（24 小时）与周周期（7 天）的傅里叶特征
def fourier_features(t, period, order):
    t = np.asarray(t, dtype=float)
    features = []
    for k in range(1, order + 1):
        features.append(np.sin(2 * np.pi * k * t / period))
        features.append(np.cos(2 * np.pi * k * t / period))
    return np.column_stack(features)

# t 用「小时序号」表示，日周期 period=24
t_hours = np.arange(len(ts))
fourier_day = fourier_features(t_hours, period=24, order=2)
print('日周期 2 阶傅里叶特征形状:', fourier_day.shape)   # (720, 4)
print('前 2 行:', fourier_day[:2].round(3))
```

```text
Fourier 的坑：
1. 阶数 order 越高越能刻画尖锐周期，但易过拟合
2. 周期 P 必须选对 —— 选错周期傅里叶特征无用
3. 适合线性模型；树模型用「小时/星期」整数特征通常已足够
```

## 应用场景实战

### 场景一：时间序列回归预测（历史特征 + 训练/测试划分）

```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

# 构造特征：lag + rolling + 时间
def build_features(s, lags=(1, 2, 24), windows=(7, 24)):
    df = pd.DataFrame({'y': s})
    for k in lags:
        df[f'lag_{k}'] = s.shift(k)
    for w in windows:
        df[f'roll_mean_{w}'] = s.rolling(w).mean()
        df[f'roll_std_{w}'] = s.rolling(w).std()
    df['hour'] = s.index.hour
    df['dow'] = s.index.dayofweek
    return df

feat = build_features(ts).dropna()
# 前 70% 训练，后 30% 测试（时间序列必须按时间切，不能随机）
split = int(len(feat) * 0.7)
train, test = feat.iloc[:split], feat.iloc[split:]
X_cols = [c for c in feat.columns if c != 'y']

rf = RandomForestRegressor(n_estimators=200, random_state=42)
rf.fit(train[X_cols], train['y'])
pred = rf.predict(test[X_cols])
print(f'测试集 MAE = {mean_absolute_error(test["y"], pred):.3f}')
```

### 场景二：用傅里叶特征让线性模型拟合周期

```python
from sklearn.linear_model import LinearRegression

# 只用傅里叶特征（日 + 周周期）拟合周期序列
t_hours = np.arange(len(ts)).reshape(-1, 1)
f_day = fourier_features(t_hours.ravel(), period=24, order=3)
f_week = fourier_features(t_hours.ravel(), period=168, order=2)
X_fourier = np.hstack([f_day, f_week])

split = int(len(ts) * 0.7)
lr = LinearRegression().fit(X_fourier[:split], ts.values[:split])
pred = lr.predict(X_fourier[split:])
print(f'傅里叶 + 线性回归 MAE = {mean_absolute_error(ts.values[split:], pred):.3f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 时间序列任务先拆「日历特征」（小时、星期、月、节假日），信息量大且便宜
2. lag 特征从业务周期出发：日数据用 lag 1/7/30，小时数据用 lag 1/24/168
3. 滚动窗口大小贴合业务节奏：短期 7、长期 30 或按周期定
4. 周期规律明显时用 Fourier 特征，比 one-hot 时间更平滑、更省维度
5. 提取趋势用滚动均值或差分，判断序列处于上升还是下降阶段
6. 所有统计特征（lag/rolling/ewma）只用「当前及过去」的数据，防未来泄漏
7. 时间序列务必按时间顺序切分，严禁随机 shuffle

### 踩坑记录

```text
坑 1：随机 shuffle 切分时间序列
结论：验证集 AUC 很好看，但上线后预测未来完全崩。
原因：随机切分让模型「偷看」到未来的样本，时间依赖被破坏。
解法：按时间顺序切分，或用 TimeSeriesSplit 做交叉验证。

坑 2：lag/rolling 用到了未来数据
结论：训练时完美，测试时特征算不出来或用了未来信息。
原因：rolling 默认窗口包含当前点或用了未来点，shift 方向写反。
解法：shift(k) 取过去值；rolling 窗口只含历史，shift(1) 后再 rolling 保证不含当前点。

坑 3：季节分解周期选错
结论：seasonal_decompose 报错或分解出无意义的季节分量。
原因：period 与真实周期不符，或周期大于序列长度一半。
解法：先看自相关图（ACF）确定周期，再设 period。

坑 4：直接对含 NaN 的 lag 特征训练
结论：模型报错或首段样本被大量丢弃。
原因：前 k 行 lag 是 NaN，dropna 可能丢掉大量早期样本。
解法：用填充（前值/均值）或接受早期样本缺失，明确处理 NaN 策略。

坑 5：忽略时间戳本身的日历信息
结论：模型学不到「周末流量低、夜间无访问」等固定规律。
原因：只做了 lag/rolling，没拆 hour/dow/节假日。
解法：从时间戳拆出年/月/日/星期/小时/是否节假日，作为基础特征。
```
