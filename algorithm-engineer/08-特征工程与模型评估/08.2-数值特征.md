## 概述

数值特征变换（scaling/transform）是特征工程的基础动作：把原始数值映射到合适的尺度或分布，让模型更容易学习。不同模型对数值尺度/分布的敏感度不同——基于距离的模型（KNN、SVM、K-Means）和基于梯度下降的模型（神经网络、逻辑回归）强烈依赖缩放；树模型（GBDT、随机森林）则对单调变换不敏感。核心是「根据模型和分布选对变换」。

```text
数值特征变换的分类：
1. 缩放（scaling）—— 改变量纲/范围，不改分布形状：
   Standardization、Min-Max、Robust Scaling、Quantile Transform
2. 分布变换（transform）—— 改变分布形状，压长尾、逼近正态：
   Log、Box-Cox、Yeo-Johnson

为什么需要变换：
1. 统一量纲 —— 避免量纲大的特征主导距离/梯度
2. 加速收敛 —— 梯度下降在特征同尺度时收敛更快更稳
3. 满足假设 —— 线性回归/统计模型假设特征近似正态
4. 压缩长尾 —— 让极端值不影响模型
```

```python
import numpy as np
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# 变换最小示例
X = np.array([[1], [2], [3], [4], [5]], dtype=float)

scaler = StandardScaler().fit(X)   # 标准化：均值 0 方差 1
print('标准化:', scaler.transform(X).ravel().round(2))

minmax = MinMaxScaler().fit(X)     # 归一化：缩到 [0, 1]
print('归一化:', minmax.transform(X).ravel().round(2))
```

## Standardization

标准化（Z-Score 标准化）把特征变换为「均值 0、方差 1」的分布：减去均值再除以标准差。它不改变分布形状，只改变位置和尺度，是线性模型、逻辑回归、SVM、神经网络、PCA 的默认预处理。

```text
标准化的定义：
x' = (x - μ) / σ

其中 μ 是均值，σ 是标准差。

特点：
1. 结果均值 0、标准差 1，保留分布形状和异常值信息
2. 适合 —— 数据近似正态分布、需要保持相对关系的场景
3. 不适合 —— 有明显异常值或重尾分布（σ 会被异常值拉偏）
4. 对异常值敏感 —— 均值和标准差都受离群点影响
```

```python
import numpy as np
from sklearn.preprocessing import StandardScaler

X = np.array([[1000, 1.0], [2000, 2.0], [3000, 3.0], [4000, 4.0]])

scaler = StandardScaler().fit(X)
X_scaled = scaler.transform(X)
print('标准化后:\n', X_scaled.round(3))
print('均值:', X_scaled.mean(axis=0).round(3))
print('标准差:', X_scaled.std(axis=0).round(3))
print('可还原:', scaler.inverse_transform(X_scaled))
```

```python
# 手写标准化，理解原理
def standardize(x):
    return (x - x.mean(axis=0)) / x.std(axis=0)

print('手写标准化与 sklearn 一致:', np.allclose(standardize(X), X_scaled))
```

## Min-Max

Min-Max 归一化把特征线性映射到固定区间（默认 [0, 1]）：减去最小值再除以极差。它保持原始分布形状和相对大小，常用于需要固定范围的场景（神经网络输入、图像像素、距离计算），但对异常值极其敏感——一个极端值就能压扁整个区间。

```text
Min-Max 的定义：
x' = (x - x_min) / (x_max - x_min)

特点：
1. 结果落在 [0, 1]（可调 feature_range 到 [-1, 1] 等）
2. 保持分布形状和数据点相对顺序
3. 对异常值极度敏感 —— x_max/x_min 由极值决定
4. 适合 —— 数据有明确边界、无极端异常值、需要非负输入的模型
```

```python
from sklearn.preprocessing import MinMaxScaler

X = np.array([[1], [2], [3], [4], [100]], dtype=float)   # 含一个异常值 100

scaler = MinMaxScaler().fit(X)
X_scaled = scaler.transform(X)
print('含异常值的 Min-Max 归一化:', X_scaled.ravel().round(3))
# 正常值 [1,2,3,4] 全被压到接近 0，异常值 100 独占 1.0
```

```python
# 自定义区间
scaler_neg = MinMaxScaler(feature_range=(-1, 1)).fit(X)
print('映射到 [-1, 1]:', scaler_neg.transform(X).ravel().round(3))

# 手写实现
def min_max(x):
    return (x - x.min(axis=0)) / (x.max(axis=0) - x.min(axis=0))
```

## Robust Scaling

Robust Scaling 用中位数和四分位距（IQR）代替均值和标准差做缩放：减去中位数再除以 IQR。它对异常值鲁棒——中位数和分位数不受极端值影响，适合数据含明显异常值、且不想（或不能）删除它们的场景。

```text
Robust Scaling 的定义：
x' = (x - median) / IQR

其中 IQR = Q3 - Q1（四分位距）。

特点：
1. 用中位数（而非均值）做中心，用 IQR（而非标准差）做尺度
2. 对异常值鲁棒 —— 极端值几乎不影响 median 和 IQR
3. 结果不是严格 [-1, 1]，但正常数据集中在有限范围内
4. 适合 —— 数据有离群点、重尾分布，仍需做缩放的场景
```

```python
from sklearn.preprocessing import RobustScaler
import numpy as np

# 含严重异常值的数据
X = np.r_[np.random.randn(100), np.array([50.0, -40.0])].reshape(-1, 1)

robust = RobustScaler().fit(X)
X_robust = robust.transform(X)

standard = StandardScaler().fit(X)
X_standard = standard.transform(X)

print('Robust 缩放后正常数据范围:',
      X_robust[:-2].min().round(2), '~', X_robust[:-2].max().round(2))
print('Standard 缩放后正常数据范围:',
      X_standard[:-2].min().round(2), '~', X_standard[:-2].max().round(2))
# Robust 缩放后正常数据仍保持合理范围，Standard 被异常值压缩
```

```python
# 手写 Robust Scaling
def robust_scale(x):
    median = np.median(x, axis=0)
    q1, q3 = np.percentile(x, [25, 75], axis=0)
    return (x - median) / (q3 - q1)

print('手写与 sklearn 一致:', np.allclose(robust_scale(X), X_robust))
```

## Quantile Transform

分位数变换把特征映射到「均匀分布」或「正态分布」：用每个值的经验分位数，通过分布函数的反函数（inverse CDF）映射到目标分布。它能彻底消除长尾、让分布变成均匀/正态，且对异常值天然鲁棒（所有值都被「拉开」到有序的分位上）。

```text
Quantile Transform 的定义：
1. 计算每个值的经验分位数（rank → 0~1）
2. 用目标分布的逆 CDF 映射到目标分布

两种输出：
1. output_distribution='uniform' —— 映射到 [0, 1] 均匀分布
2. output_distribution='normal' —— 映射到标准正态分布

特点：
1. 完全消除长尾和偏态，分布变为均匀/正态
2. 对异常值鲁棒 —— 极端值只是落在 0 或 1 分位上
3. 是非线性变换，破坏原始线性关系
4. 适合 —— 长尾、偏态严重、需「强制正态」的场景
```

```python
from sklearn.preprocessing import QuantileTransformer
import numpy as np

# 严重右偏的长尾数据
X = np.random.exponential(scale=2, size=1000).reshape(-1, 1)

qt_uniform = QuantileTransformer(n_quantiles=100, output_distribution='uniform', random_state=0)
X_uniform = qt_uniform.fit_transform(X)

qt_normal = QuantileTransformer(n_quantiles=100, output_distribution='normal', random_state=0)
X_normal = qt_normal.fit_transform(X)

print('原始偏度:', round(float(np.mean(((X - X.mean()) / X.std()) ** 3)), 2))
print('变换后偏度(正态):', round(float(np.mean(((X_normal - X_normal.mean()) / X_normal.std()) ** 3)), 2))
print('均匀变换范围:', X_uniform.min().round(3), '~', X_uniform.max().round(3))
```

```text
Quantile Transform 的注意点：
1. n_quantiles —— 分位数数量，太大易过拟合，太小损失信息
2. 测试集用训练集的分位数映射，避免泄露
3. 会破坏特征与目标的单调线性关系，需谨慎
4. 小样本时分位数估计不稳定
```

## Log

对数变换是处理「右偏长尾」最常用的方法：对正数取对数（log、log1p），把乘性关系变成加性关系、把指数级差异压缩到线性尺度。它适合收入、金额、人口、点击量等「跨度几个数量级」的正数特征。

```text
对数变换的定义：
x' = log(x)  或  x' = log1p(x) = log(1 + x)

为什么用对数：
1. 压缩长尾 —— 把 [1, 1000000] 压到 [0, 13.8]
2. 稳定方差 —— 把「方差随均值增长」的异方差数据变得稳定
3. 乘性 → 加性 —— 增长率变成差值，更适合线性模型
4. 保留单调性 —— 不改变顺序，树模型也会受益

注意：
1. 只能处理正数（x > 0），含 0 用 log1p
2. 负值/零需平移或用 Box-Cox/Yeo-Johnson
```

```python
import numpy as np

# 收入类右偏数据
income = np.random.lognormal(mean=10, sigma=1.5, size=1000)

log_income = np.log(income)
log1p_income = np.log1p(income)

print('原始范围:', income.min().round(0), '~', income.max().round(0))
print('log 后范围:', log_income.min().round(2), '~', log_income.max().round(2))

# 含 0 的数据必须用 log1p，否则 log(0) 会得到 -inf
data_with_zero = np.array([0, 1, 10, 100, 1000], dtype=float)
print('log1p 处理含 0 数据:', np.log1p(data_with_zero))
```

```python
import numpy as np
# 手写 + sklearn FunctionTransformer 集成进 pipeline
from sklearn.preprocessing import FunctionTransformer

log_transformer = FunctionTransformer(np.log1p, validate=True)
X = np.array([[0.0], [1.0], [10.0], [100.0]])
X_log = log_transformer.transform(X)
print('FunctionTransformer(log1p):', X_log.ravel().round(2))
```

## Box-Cox

Box-Cox 变换是参数化的幂变换，专门把「正数」特征变换到近似正态分布：它通过一个参数 λ 在 log、平方根、倒数等变换之间连续插值，自动选让分布最接近正态的 λ。相比手动选 log，它更灵活，能适配不同偏斜程度。

```text
Box-Cox 的定义：
x' = (x^λ - 1) / λ    (λ ≠ 0)
x' = log(x)           (λ = 0)

特点：
1. 只适用于正数（x > 0），含 0 或负值不能用
2. λ 由最大似然自动估计，选让分布最正态的值
3. λ=0 → log 变换，λ=0.5 → 平方根，λ=-1 → 倒数
4. 适合 —— 右偏/左偏的正数特征，需要近似正态
```

```python
from scipy.stats import boxcox
import numpy as np

# 右偏数据
X = np.random.exponential(scale=3, size=1000)

X_boxcox, lam = boxcox(X)
print(f'估计的最优 λ = {lam:.3f}')

# 变换前后偏度对比
from scipy.stats import skew
print('原始偏度:', skew(X).round(2))
print('Box-Cox 后偏度:', skew(X_boxcox).round(2))
```

```python
from sklearn.preprocessing import PowerTransformer

# sklearn 版：method='box-cox'，要求正数
pt = PowerTransformer(method='box-cox', standardize=True)
X_pt = pt.fit_transform(X.reshape(-1, 1))
print('sklearn Box-Cox λ:', pt.lambdas_.round(3))
print('变换后均值/标准差:', X_pt.mean().round(3), X_pt.std().round(3))
```

## Yeo-Johnson

Yeo-Johnson 变换是 Box-Cox 的推广：它把适用范围从「仅正数」扩展到「任意实数（含 0 和负数）」。原理是对正数用类似 Box-Cox 的变换，对负数用对称的镜像变换，是实际工程中更常用的幂变换（数据里常有 0 和负值）。

```text
Yeo-Johnson 的定义（分段）：
x ≥ 0 时：
  x' = ((x + 1)^λ - 1) / λ    (λ ≠ 0)
  x' = log(x + 1)             (λ = 0)
x < 0 时：
  x' = -(((-x + 1)^(2-λ) - 1) / (2-λ))    (λ ≠ 2)
  x' = -log(-x + 1)                        (λ = 2)

特点：
1. 支持任意实数（正、负、零）
2. λ 自动估计，目标近似正态
3. 是 Box-Cox 的超集，工程上更通用
4. 适合 —— 含 0 或负值、需要正态化的特征
```

```python
from sklearn.preprocessing import PowerTransformer
import numpy as np

# 含负值和 0 的数据（Box-Cox 无法处理）
X = np.r_[np.random.randn(500) * 2, np.random.randn(500) * 0.5 + 3]

pt_yj = PowerTransformer(method='yeo-johnson', standardize=True)
X_yj = pt_yj.fit_transform(X.reshape(-1, 1))

from scipy.stats import skew
print('原始偏度:', skew(X).round(2))
print('Yeo-Johnson 后偏度:', skew(X_yj).round(2))
print('估计的 λ:', pt_yj.lambdas_.round(3))

# 对比：Box-Cox 遇到负值会报错
try:
    PowerTransformer(method='box-cox').fit(X.reshape(-1, 1))
except Exception as e:
    print('Box-Cox 无法处理负值:', type(e).__name__)
```

```text
Box-Cox vs Yeo-Johnson 的选择：
1. 数据全是正数 → 两者都可，Box-Cox 更经典
2. 数据含 0 或负数 → 只能用 Yeo-Johnson
3. 不确定 → 直接用 Yeo-Johnson，覆盖所有情况
4. 结果都标准化（standardize=True）后均值 0 方差 1
```

## 应用场景实战

### 场景一：不同尺度特征统一预处理

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler
import numpy as np
import pandas as pd

df = pd.DataFrame({
    'age': np.random.randint(18, 70, 500),           # 尺度 18~70
    'income': np.random.lognormal(10, 1.5, 500),     # 尺度 10^4，长尾
    'score': np.random.uniform(0, 1, 500),           # 尺度 0~1
})

# 不同尺度特征对距离模型的影响：标准化后统一量纲
X = df[['age', 'income', 'score']].values
X_std = StandardScaler().fit_transform(X)
print('标准化后各特征标准差:', X_std.std(axis=0).round(2))

# 收入是长尾，用 log 变换后再标准化更合理
df['income_log'] = np.log1p(df['income'])
X2 = df[['age', 'income_log', 'score']].values
X2_std = StandardScaler().fit_transform(X2)
print('log 后收入范围:', df['income_log'].min().round(1), '~', df['income_log'].max().round(1))
```

### 场景二：为神经网络准备输入（Min-Max + 无泄露）

```python
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(loc=[10, 100, 1000], scale=[1, 10, 100], size=(800, 3))
y = (X[:, 0] + X[:, 1] / 10 > 15).astype(int)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 只在训练集上 fit，再 transform 测试集（防泄露）
scaler = MinMaxScaler(feature_range=(0, 1)).fit(X_train)
X_train_norm = scaler.transform(X_train)
X_test_norm = scaler.transform(X_test)

print('训练集归一化范围:', X_train_norm.min(axis=0).round(2), '~', X_train_norm.max(axis=0).round(2))
print('测试集（可能略超 [0,1]）:', X_test_norm.min(axis=0).round(2), '~', X_test_norm.max(axis=0).round(2))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 变换前先看分布：直方图/偏度/Q-Q 图，再决定用 log、Box-Cox 还是 Yeo-Johnson
2. 距离模型（KNN/SVM/K-Means）和梯度模型（NN/逻辑回归）必须缩放
3. 树模型（GBDT/随机森林）对单调变换不敏感，通常无需缩放
4. 数据有异常值 → 用 RobustScaler 或 QuantileTransformer，别用 Min-Max
5. 数据含 0/负值 → 用 Yeo-Johnson，别用 Box-Cox
6. 长尾正数特征 → 先试 log1p，再考虑 Box-Cox
7. 所有缩放/变换参数只在训练集上 fit，测试集复用（防泄露）
8. 用 Pipeline 把 scaler 和模型串起来，避免手写 fit/transform 出错

### 踩坑记录

```text
坑 1：Min-Max 用在含异常值的数据上
结论：一个极端值把 [0,1] 区间撑开，正常数据全被压到 0 附近，失去区分度。
原因：Min-Max 的 min/max 由极值决定，异常值直接决定缩放范围。
解法：含异常值用 RobustScaler 或 QuantileTransformer，或先处理异常值。

坑 2：Box-Cox 用在含 0 或负值的数据上
结论：直接报错，fit 失败，因为 Box-Cox 只定义在正数域。
原因：Box-Cox 的数学定义要求 x > 0。
解法：含 0 用 log1p，含负值用 Yeo-Johnson，或先平移数据。

坑 3：标准化参数在测试集上重新 fit
结论：测试集用自己的均值/标准差缩放，与训练集不一致，评估失真且实际泄露。
原因：训练和测试应共享同一套变换参数，测试集重新 fit 破坏了这一点。
解法：scaler.fit(X_train) 后，用同一个 scaler 只 transform 测试集。

坑 4：给树模型做了幂变换还期望提升
结论：对 GBDDT 做 log/Box-Cox，效果几乎不变，浪费精力还可能引入误差。
原因：树模型基于分裂阈值，只关心排序，对单调变换完全不变。
解法：树模型跳过缩放/幂变换；线性/距离/神经网络模型才需要。

坑 5：Quantile Transform 破坏线性关系却不自知
结论：线性回归假设的线性关系被分位数变换扭曲，系数解释失效。
原因：Quantile Transform 是非线性变换，会改变特征与目标的函数形式。
解法：仅在需要「强制正态」且不依赖线性解释时用；否则优先 log/Box-Cox。
```
