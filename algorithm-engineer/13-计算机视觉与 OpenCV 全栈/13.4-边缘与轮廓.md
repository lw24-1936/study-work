## 概述

边缘是图像里灰度急剧变化的位置，轮廓是二值图上连通的边界点序列。边缘检测靠梯度算子（Sobel/Scharr/Laplacian/Canny）找像素级的边界，轮廓则把这些边界组织成有序的点集，再提取边界框、凸包等几何描述。两者是从「哪里变化」到「目标是什么形状」的递进。

```text
边缘与轮廓的递进关系：
1. 梯度算子 —— 算灰度变化，得到边缘强度图
2. Canny —— 把边缘细化成精确的单像素边界
3. findContours —— 把边界连成有序轮廓点集
4. 几何描述 —— 边界框 / 最小外接矩形 / 凸包 / 多边形逼近
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)
edges = cv2.Canny(img, 100, 200)
contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print('边缘像素:', np.sum(edges > 0), '轮廓数:', len(contours))
```

## Sobel

Sobel 算子用 3x3 卷积核计算一阶梯度，分别求 x 方向和 y 方向的灰度变化率，再合成梯度幅值和方向。Sobel(ksize=3) 是检测边缘最基础的算子，对噪声有一定抑制（核本身带平滑），边缘比纯差分粗。

```text
Sobel 算子：
1. Gx —— 检测竖直边缘（x 方向变化）
2. Gy —— 检测水平边缘（y 方向变化）
3. 幅值 = sqrt(Gx² + Gy²)，方向 = atan2(Gy, Gx)
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)

gx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)   # x 方向梯度
gy = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)   # y 方向梯度
mag = cv2.magnitude(gx, gy)
print('x 梯度非零像素:', np.sum(np.abs(gx) > 0),
      'y 梯度非零像素:', np.sum(np.abs(gy) > 0))
```

## Scharr

Scharr 算子和 Sobel 结构相同但核系数更优（3x3 时对梯度方向的估计更精确、旋转不变性更好）。在 3x3 核上它比 Sobel 更推荐，Sobel 的 ksize 大于 3 时 Scharr 不适用（只支持 3x3）。

```text
Scharr 与 Sobel 对比：
1. Scharr 只在 ksize=3 时可用
2. 3x3 下 Scharr 梯度估计更准、角度误差更小
3. 用法相同 —— cv2.Scharr(img, ddepth, dx, dy)
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.circle(img, (50, 50), 30, 255, -1)

gx = cv2.Scharr(img, cv2.CV_64F, 1, 0)
gy = cv2.Scharr(img, cv2.CV_64F, 0, 1)
mag = cv2.magnitude(gx, gy)
print('Scharr 梯度幅值范围:', mag.min(), mag.max())
```

## Laplacian

Laplacian 是二阶导数算子，检测灰度变化率的变化，对边缘响应是「过零」——边缘两侧正负号翻转。它对噪声极敏感（二阶导放大噪声），通常先高斯平滑再求拉普拉斯（等价于 LoG，高斯拉普拉斯）。常用来做锐化和边缘检测。

```text
Laplacian 特点：
1. 二阶导 —— 对边缘的响应是过零点
2. 各向同性 —— 不区分方向
3. 敏感噪声 —— 使用前先高斯平滑
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)

blur = cv2.GaussianBlur(img, (5, 5), 0)
lap = cv2.Laplacian(blur, cv2.CV_64F)
print('拉普拉斯响应范围:', lap.min(), lap.max())   # 有正有负（过零）
```

## Canny

Canny 是实际工程里最常用的边缘检测器，输出单像素宽、连接良好的边缘。四步：高斯去噪 → 求梯度幅值方向 → 非极大值抑制（只保留梯度方向上的局部最大）→ 双阈值 + 滞后连接（强边缘确定、弱边缘靠强边缘续接）。两个阈值 low/high 是关键参数。

```text
Canny 四步：
1. 高斯平滑 —— 降噪
2. 梯度计算 —— Sobel 求幅值方向
3. 非极大值抑制 —— 细化成单像素边缘
4. 双阈值滞后 —— high 定强边、low 续接弱边
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)

edges = cv2.Canny(img, 100, 200)          # 双阈值
edges_tight = cv2.Canny(img, 150, 250)    # 阈值高 → 边缘更少
print('阈值(100,200)边缘像素:', np.sum(edges > 0),
      '阈值(150,250)边缘像素:', np.sum(edges_tight > 0))
```

## Contour（轮廓查找）

findContours 从二值图提取轮廓——每个轮廓是一个点序列（轮廓点坐标数组）。参数 mode 控制取哪些轮廓（RETR_EXTERNAL 只外层、RETR_LIST 全部、RETR_TREE 带层级），method 控制点存储方式（CHAIN_APPROX_SIMPLE 只存拐点、NONE 存所有点）。OpenCV 3+ 返回 (contours, hierarchy) 两个值。

```text
findContours 要点：
1. 输入必须是二值图（背景 0，前景非 0）
2. mode —— EXTERNAL 最外层 / LIST 全部 / TREE 层级树
3. method —— SIMPLE 压缩拐点，NONE 存全点
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (20, 20), (40, 40), 255, -1)
cv2.circle(img, (70, 70), 15, 255, -1)

contours, hierarchy = cv2.findContours(img, cv2.RETR_EXTERNAL,
                                       cv2.CHAIN_APPROX_SIMPLE)
print('轮廓数:', len(contours))   # 2：一个矩形一个圆
print('每个轮廓点数:', [len(c) for c in contours])
```

## Contour Hierarchy（轮廓层级）

hierarchy 描述轮廓之间的包含关系，每个轮廓记录 [next, prev, first_child, parent] 四个索引。当目标有内外嵌套（如圆环、带孔的物体）时，需要靠层级区分外轮廓和内孔。RETR_TREE 保留完整层级，RETR_EXTERNAL 丢弃所有内层轮廓。

```text
hierarchy 数组结构：
1. 每行 [next, prev, first_child, parent]，-1 表示无
2. RETR_EXTERNAL —— 只要最外层，忽略孔洞
3. RETR_TREE —— 完整父子树，能区分外轮廓和内孔
```

```python
import cv2
import numpy as np

# 圆环：外圆套内圆，构成父子层级
img = np.zeros((100, 100), dtype=np.uint8)
cv2.circle(img, (50, 50), 30, 255, -1)
cv2.circle(img, (50, 50), 15, 0, -1)      # 内孔（挖空）

contours, hierarchy = cv2.findContours(img, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
print('层级树轮廓数:', len(contours))     # 2（外圆 + 内孔）
print('hierarchy[0]:', hierarchy[0][0])   # 外圆 first_child 指向内孔
```

## Bounding Box（边界框）

boundingRect 计算轮廓的轴对齐外接矩形，返回 (x, y, w, h)。它是最简单、最常用的目标定位框，适合快速框出目标、做 ROI 裁剪，但矩形总是水平的，目标旋转时框会偏大、包含大量背景。

```text
boundingRect 特点：
1. 轴对齐 —— 矩形的边始终平行于图像坐标轴
2. 返回 (x, y, w, h) —— 左上角坐标 + 宽高
3. 旋转目标 —— 框偏大，但计算简单、够用
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (20, 30), (70, 60), 255, -1)
contours, _ = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
x, y, w, h = cv2.boundingRect(contours[0])
print(f'边界框: x={x} y={y} w={w} h={h}')   # x=20 y=30 w=50 h=30
```

## Minimum Area Rectangle（最小外接矩形）

minAreaRect 求轮廓的最小外接旋转矩形，返回 (中心, (宽, 高), 旋转角)。它贴合旋转目标，比轴对齐框面积更小，是计算目标朝向、主轴方向的常用工具。得到后需用 boxPoints 转成四个角点坐标，再画出来。

```text
minAreaRect 要点：
1. 返回 (center, (w, h), angle) —— 中心 + 尺寸 + 角度
2. boxPoints —— 转成 4 个角点，便于绘制/后续处理
3. 用途 —— 目标朝向估计、倾斜校正、最小包围
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
# 画一个倾斜的矩形（用旋转矩形填充）
rect = ((50, 50), (60, 20), 30)     # 中心、尺寸、旋转 30°
box = cv2.boxPoints(rect).astype(np.int32)
cv2.fillPoly(img, [box], 255)

contours, _ = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
min_rect = cv2.minAreaRect(contours[0])
print('最小外接矩形:', min_rect)   # 中心、尺寸、角度恢复约 30°
```

## Convex Hull（凸包）

convexHull 求轮廓点的凸包——包围所有点的最小凸多边形，就像用橡皮筋套住点集。用来分析目标的凸性：凸包面积与原轮廓面积之差可度量凹陷程度，是缺陷检测（convexityDefects）的基础。

```text
凸包要点：
1. 定义 —— 包围点集的最小凸多边形
2. 用途 —— 凸性分析、指尖/凹点检测、形状简化
3. convexityDefects —— 凸包与轮廓间的凹陷缺陷
```

```python
import cv2
import numpy as np

# 五角星形状的点集，凸包是五边形
img = np.zeros((100, 100), dtype=np.uint8)
pts = np.array([[50, 10], [80, 40], [70, 90], [30, 90], [20, 40]], dtype=np.int32)
cv2.fillPoly(img, [pts], 255)

contours, _ = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
hull = cv2.convexHull(contours[0])
print('凸包顶点数:', len(hull), '轮廓点数:', len(contours[0]))
```

## Polygon Approximation（多边形逼近）

approxPolyDP 用 Douglas-Peucker 算法把轮廓逼近成更少顶点的多边形，参数 epsilon 控制逼近精度（顶点到逼近线的最大距离）。epsilon 越小越贴合原轮廓，越大越简化。通过数顶点数可识别形状：3 三角形、4 四边形、多则圆形。

```text
Douglas-Peucker 逼近：
1. epsilon —— 逼近误差上限，越大顶点越少
2. 用法 —— epsilon = 0.02 * 轮廓周长（常用比例）
3. 应用 —— 形状识别（几边形）、轮廓压缩
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)   # 矩形
contours, _ = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

peri = cv2.arcLength(contours[0], True)
approx = cv2.approxPolyDP(contours[0], 0.02 * peri, True)
print('逼近后顶点数:', len(approx))   # 4 → 识别为四边形
```

## 应用场景实战

### 场景一：Canny + 轮廓提取目标边界框（定位多个目标）

```python
import cv2
import numpy as np

img = np.zeros((200, 200), dtype=np.uint8)
cv2.rectangle(img, (20, 20), (80, 80), 255, -1)
cv2.circle(img, (140, 60), 30, 255, -1)

edges = cv2.Canny(img, 100, 200)
contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
boxes = [cv2.boundingRect(c) for c in contours]
print('检出目标数:', len(boxes))
for x, y, w, h in boxes:
    print(f'  目标框 x={x} y={y} w={w} h={h}')
```

### 场景二：形状识别（多边形逼近数顶点）

```python
import cv2
import numpy as np

def detect_shape(contour):
    peri = cv2.arcLength(contour, True)
    approx = cv2.approxPolyDP(contour, 0.04 * peri, True)
    names = {3: '三角形', 4: '四边形', 5: '五边形'}
    return names.get(len(approx), f'{len(approx)}边形/圆')

img = np.zeros((100, 100), dtype=np.uint8)
# 三角形
pts = np.array([[50, 10], [90, 90], [10, 90]], dtype=np.int32)
cv2.fillPoly(img, [pts], 255)
contours, _ = cv2.findContours(img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print('识别结果:', detect_shape(contours[0]))   # 三角形
```

## 最佳实践与踩坑记录

### 最佳实践

1. 边缘检测前先高斯去噪，否则 Canny/Sobel 把噪声当边缘
2. Canny 双阈值按 1:2 或 1:3 设（low:high），high 定强边、low 续接
3. 目标定位用 boundingRect 够快，朝向/倾斜校正才用 minAreaRect
4. 多目标且内外嵌套时用 RETR_TREE 拿层级，只用外层用 RETR_EXTERNAL
5. 形状识别用 approxPolyDP，epsilon 取轮廓周长的 2%~5%
6. 轮廓面积/数量统计前确认输入是干净的连通二值图

### 踩坑记录

```text
坑 1：findContours 的返回值数量搞错
结论：按 OpenCV 3 之前的 (img, contours, hierarchy) 解包，报 ValueError。
原因：OpenCV 3+ 改为返回 (contours, hierarchy) 两个值。
解法：contours, _ = cv2.findContours(...)，别按旧版三返回值写。

坑 2：Sobel 用 uint8 输出导致负梯度截断
结论：x 方向梯度负值全被截成 0，边缘只出来一半。
原因：Sobel 对 uint8 图算梯度会产生负值，uint8 存不下。
解法：ddepth 用 cv2.CV_64F（或 CV_16S），再取绝对值转回 uint8。

坑 3：Canny 直接喂彩色图没转灰度
结论：某些版本报错或结果异常。
原因：Canny 期望单通道灰度图。
解法：先 cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) 再 Canny。

坑 4：minAreaRect 的角度记错
结论：想用返回的 angle 做旋转校正，结果方向不对。
原因：minAreaRect 的 angle 范围是 [-90, 0)，且宽高可能交换，语义易混。
解法：用 boxPoints 拿角点自己算主轴方向，别直接信 angle。

坑 5：轮廓在噪声二值图上一堆碎轮廓
结论：findContours 返回几十个噪声小轮廓，目标被淹没。
原因：阈值/边缘图有噪点，每个孤立点都成一条轮廓。
解法：先开运算去噪点，再按轮廓面积 cv2.contourArea 过滤小轮廓。
```
