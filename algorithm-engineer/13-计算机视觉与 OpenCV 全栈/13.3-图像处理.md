## 概述

图像处理是像素级的变换：阈值把灰度图变成二值掩码，滤波去噪或保边，形态学操作修饰二值区域的形状。这层操作是边缘检测、目标分割、OCR 的预处理基础，参数选择（阈值大小、核大小）直接决定后续效果，工程里大部分时间都在调这些参数。

```text
图像处理三大类操作：
1. 阈值化 —— 灰度图分二值，分割前景背景
2. 滤波 —— 去噪/平滑/锐化，改的是像素邻域
3. 形态学 —— 膨胀腐蚀等，改的是二值区域形状
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100), dtype=np.uint8)
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
blurred = cv2.GaussianBlur(img, (5, 5), 0)
print(binary.shape, blurred.shape)
```

## Threshold（固定阈值）

threshold 用一个全局阈值把灰度图二值化：大于阈值的像素置为 maxval（通常 255），否则置 0。阈值类型 THRESH_BINARY / THRESH_BINARY_INV / THRESH_TRUNC / THRESH_TOZERO 决定映射规则。它假设前景和背景的灰度分布有明显分界，光照不均时效果差。

```text
threshold 的类型：
1. THRESH_BINARY —— >thresh 置 maxval，否则 0
2. THRESH_BINARY_INV —— 上面取反，适合背景亮的图
3. THRESH_TRUNC —— >thresh 截断为 thresh，其余不变
4. THRESH_TOZERO —— ≤thresh 置 0，其余不变
```

```python
import cv2
import numpy as np

img = np.array([[0, 100, 200, 255]], dtype=np.uint8)
_, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
_, inv = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY_INV)
print(binary)   # [[0 0 255 255]]
print(inv)      # [[255 255 0 0]]
```

## Adaptive Threshold（自适应阈值）

adaptiveThreshold 对每个像素用其邻域的局部阈值（邻域均值或高斯加权均值减去一个常数 C），解决固定阈值在光照不均（如文档阴影）下失效的问题。参数 blockSize 决定邻域大小（须为奇数），C 是补偿常数。

```text
自适应阈值两种方法：
1. ADAPTIVE_THRESH_MEAN_C —— 邻域均值 - C
2. ADAPTIVE_THRESH_GAUSSIAN_C —— 高斯加权均值 - C
适用：光照不均匀的图，如文档扫描、车牌
```

```python
import cv2
import numpy as np

# 造一张左暗右亮的渐变图，固定阈值会失效，自适应能分开
img = np.tile(np.arange(256, dtype=np.uint8), (50, 1))   # 每列灰度递增
adaptive = cv2.adaptiveThreshold(img, 255,
                                 cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                 cv2.THRESH_BINARY, 11, 2)
print(adaptive.shape, adaptive[0, 0], adaptive[0, -1])   # 局部阈值各自二值化
```

## Otsu（大津法）

Otsu 自动找最优全局阈值：遍历所有可能阈值，选使类间方差最大的那个——即前景和背景的灰度差异最大。配合 THRESH_OTSU 标志，threshold 返回的 retval 就是自动算出的阈值，省去手工调参，适合灰度直方图呈双峰的图。

```text
Otsu 原理：
1. 目标 —— 最大化类间方差（前景、背景分得越开越好）
2. 优点 —— 自动、无参数
3. 前提 —— 直方图近似双峰，单峰或多峰效果差
```

```python
import cv2
import numpy as np

# 双峰图：背景 40 附近，前景 200 附近
bg = np.random.normal(40, 10, 5000).astype(np.uint8)
fg = np.random.normal(200, 10, 5000).astype(np.uint8)
img = np.concatenate([bg, fg]).reshape(100, 100)

thresh_val, binary = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print('自动阈值:', thresh_val)   # 落在 40~200 之间的类间方差最大点
```

## Blur（均值模糊）

blur 是均值滤波：每个像素替换为邻域均值，用 boxFilter 实现。核越大平滑越强、越模糊，同时细节丢失越严重。均值滤波对高斯噪声和椒盐噪声都有一定抑制，但会抹平边缘，且对椒盐噪声抑制有限。

```text
均值模糊特点：
1. 核内所有像素权重相同（都是 1/核面积）
2. 线性滤波，实现简单、速度快
3. 会模糊边缘，对椒盐噪声效果差
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100), dtype=np.uint8)
blur3 = cv2.blur(img, (3, 3))
blur9 = cv2.blur(img, (9, 9))   # 核越大越模糊
print(np.std(img), np.std(blur9))   # 标准差下降 → 更平滑
```

## Gaussian Blur（高斯模糊）

GaussianBlur 用二维高斯核对邻域加权平均，中心权重高、边缘权重低，比均值模糊更自然地平滑，边缘保留稍好。是去高斯噪声和做图像金字塔（下采样前先模糊）的标准选择。参数 (ksize, sigmaX)，sigma 越大越模糊，ksize 设为 0 时由 sigma 自动推算。

```text
高斯模糊要点：
1. 核权重服从二维高斯分布，中心大四周小
2. 两个参数 —— 核大小 ksize + 标准差 sigma
3. 用途 —— 去高斯噪声、Canny 前置、图像金字塔
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100), dtype=np.uint8)
g1 = cv2.GaussianBlur(img, (5, 5), 0)
g2 = cv2.GaussianBlur(img, (0, 0), 5)   # 靠 sigma 控制模糊强度
print(g1.shape, g2.shape)
```

## Median Blur（中值模糊）

medianBlur 取邻域像素的中值，是非线性滤波。它对椒盐噪声（随机黑白点）抑制效果极好——噪声点是被孤立的极值，取中值直接滤掉，而边缘能较好保留。核大小 ksize 是奇数，越大去噪越强但细节损失越大。

```text
中值滤波特点：
1. 非线性 —— 取中值而非加权平均
2. 椒盐噪声克星 —— 孤立极值点被中值替换
3. 保边 —— 对边缘破坏比均值/高斯小
```

```python
import cv2
import numpy as np

# 加椒盐噪声再用中值滤波去
img = np.full((100, 100), 128, dtype=np.uint8)
noise = img.copy()
noise[::10, ::10] = 0      # 黑点
noise[1::10, 1::10] = 255  # 白点
clean = cv2.medianBlur(noise, 5)
print('噪声点数:', np.sum(noise != 128), '滤波后:', np.sum(clean != 128))
```

## Bilateral Filter（双边滤波）

bilateralFilter 同时考虑空间距离和像素值差异两个权重，在平滑的同时保住边缘——空间上近的、颜色上相似的像素才参与平均。它是「去噪 + 保边」的经典选择，适合磨皮、美化，但计算量远大于普通滤波，核大时很慢。

```text
双边滤波两个权重：
1. 空间权重 —— 离中心越近权重越大（高斯）
2. 值域权重 —— 像素值越接近权重越大（保边关键）
参数：d 邻域直径、sigmaColor 值域、sigmaSpace 空间
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100), dtype=np.uint8)
bf = cv2.bilateralFilter(img, d=9, sigmaColor=75, sigmaSpace=75)
print(bf.shape)   # 平滑内部、保留强边缘
```

## Sharpen（锐化）

锐化增强边缘和细节，本质是增强高频分量。最常用的是拉普拉斯锐化：原图减去（或加上）拉普拉斯算子提取的边缘，或用一个中心大、四周负的卷积核（如 [[0,-1,0],[-1,5,-1],[0,-1,0]]）做 filter2D。锐化会放大噪声，通常先去噪再锐化。

```text
锐化常用方法：
1. 卷积核 —— filter2D 用中心 5 四周 -1 的核
2. 拉普拉斯增强 —— img - k * Laplacian(img)
3. unsharp mask —— 原图 + (原图 - 模糊图) * k，更可控
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100), dtype=np.uint8)
kernel = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]], dtype=np.float32)
sharp = cv2.filter2D(img, -1, kernel)
print(sharp.shape)
```

## Morphology（形态学概述）

形态学操作作用在二值图（或灰度图）上，用结构元（kernel）在图像上滑动，做集合运算来改变前景区域的形状。基础操作是腐蚀和膨胀，两者组合出开运算、闭运算、梯度、顶帽、黑帽。核心工具是 getStructuringElement 生成结构元（矩形、椭圆、十字）。

```text
形态学结构元：
1. MORPH_RECT —— 矩形，最常用
2. MORPH_ELLIPSE —— 椭圆，适合圆润目标
3. MORPH_CROSS —— 十字，连接细线用
```

```python
import cv2
import numpy as np

kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
print(kernel)   # 5x5 全 1 的矩形结构元
```

## Erosion（腐蚀）与 Dilation（膨胀）

腐蚀（erode）让前景区域收缩：结构元完全落在前景内时中心才保留，能去掉细小白点和细线连接。膨胀（dilate）让前景扩张：结构元碰到前景时中心就置为前景，能填充小孔洞、连接断裂区域。两者是对偶操作，都改变区域大小但不改变整体形状骨架。

```text
腐蚀 vs 膨胀：
1. 腐蚀 —— 去噪点、断开细连接、缩小目标
2. 膨胀 —— 填孔洞、连接断裂、放大目标
3. 对偶 —— dilate = 对补集做 erode，本质对称
```

```python
import cv2
import numpy as np

img = np.zeros((50, 50), dtype=np.uint8)
cv2.rectangle(img, (20, 20), (30, 30), 255, -1)   # 10x10 方块
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
eroded = cv2.erode(img, kernel)
dilated = cv2.dilate(img, kernel)
print('原前景像素:', np.sum(img > 0),
      '腐蚀后:', np.sum(eroded > 0),
      '膨胀后:', np.sum(dilated > 0))
```

## Opening（开运算）与 Closing（闭运算）

开运算 = 先腐蚀后膨胀，能去掉小噪点、细突起，同时不显著改变大目标尺寸。闭运算 = 先膨胀后腐蚀，能填小孔洞、连接窄断裂。两者都不改变目标的主体尺寸，是「去噪 + 保形」的标准组合。

```text
开闭运算组合：
1. 开运算 = erode → dilate，去白噪点
2. 闭运算 = dilate → erode，填黑孔洞
3. 记忆 —— 「开」去小白点，「闭」填小黑洞
```

```python
import cv2
import numpy as np

img = np.zeros((50, 50), dtype=np.uint8)
cv2.rectangle(img, (10, 10), (40, 40), 255, -1)   # 大方块
img[25, 25] = 0                                    # 中间挖个黑点
img[0:2, 0:2] = 255                                # 角落加个白噪点
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
opening = cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)    # 去白噪点
closing = cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)   # 填黑点
print('开运算去噪点后前景:', np.sum(opening > 0),
      '闭运算填孔后前景:', np.sum(closing > 0))
```

## Gradient（形态学梯度）

形态学梯度 = 膨胀 - 腐蚀，得到目标的轮廓边界。因为膨胀扩大、腐蚀收缩，两者之差正好是边缘一圈。比 Sobel 得到的边缘更贴合二值目标的外轮廓，常用于提取区域边界。

```text
形态学梯度：
1. 公式 —— gradient = dilate(img) - erode(img)
2. 结果 —— 目标的轮廓带
3. 用途 —— 提取前景边界、轮廓增强
```

```python
import cv2
import numpy as np

img = np.zeros((50, 50), dtype=np.uint8)
cv2.circle(img, (25, 25), 15, 255, -1)
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
grad = cv2.morphologyEx(img, cv2.MORPH_GRADIENT, kernel)
print('梯度（边界）像素数:', np.sum(grad > 0))   # 圆环
```

## Top Hat（顶帽）与 Black Hat（黑帽）

顶帽 = 原图 - 开运算，提取比邻域更亮的细小结构（小突起、亮斑）。黑帽 = 闭运算 - 原图，提取比邻域更暗的细小结构（小孔、暗斑）。两者都用于提取「尺寸小于结构元」的局部特征，是形态学的「细节提取」工具。

```text
顶帽与黑帽：
1. 顶帽 = img - open(img)，提取亮的小结构
2. 黑帽 = close(img) - img，提取暗的小结构
3. 应用 —— 不均匀光照下的背景校正、微小目标检测
```

```python
import cv2
import numpy as np

img = np.full((50, 50), 100, dtype=np.uint8)
img[20:23, 20:23] = 200     # 一个小亮斑
img[40:43, 40:43] = 20      # 一个小暗斑
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (9, 9))
tophat = cv2.morphologyEx(img, cv2.MORPH_TOPHAT, kernel)
blackhat = cv2.morphologyEx(img, cv2.MORPH_BLACKHAT, kernel)
print('顶帽检出亮斑:', np.sum(tophat > 30), '黑帽检出暗斑:', np.sum(blackhat > 30))
```

## 应用场景实战

### 场景一：文档二值化（Otsu + 开运算去噪）

```python
import cv2
import numpy as np

# 模拟带噪点的文档灰度图：背景偏灰 + 文字偏黑 + 椒盐噪声
img = np.full((100, 200), 200, dtype=np.uint8)
img[40:60, 20:180] = 30              # 一行「文字」
noise = img.copy()
noise[::7, ::7] = 0
noise[1::7, 1::7] = 255

th, binary = cv2.threshold(noise, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
clean = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
print('Otsu 阈值:', th, '开运算后噪点像素:', np.sum(clean > 0))
```

### 场景二：车牌/目标预处理（灰度 + 高斯 + 自适应阈值）

```python
import cv2
import numpy as np

# 模拟光照不均的字符图，自适应阈值把字符和背景分开
base = np.tile(np.arange(200, dtype=np.uint8), (80, 1))   # 左暗右亮
img = base.copy()
img[30:50, 20:180] = 30     # 深色字符条
g = cv2.GaussianBlur(img, (5, 5), 0)
adapt = cv2.adaptiveThreshold(g, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                              cv2.THRESH_BINARY_INV, 15, 5)
print('检出前景（字符）像素:', np.sum(adapt > 0))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 阈值化前先看灰度直方图，双峰用 Otsu，单峰/光照不均用自适应
2. 去椒盐噪声用中值滤波，去高斯噪声用高斯滤波，别一律 blur
3. 需要保边去噪（磨皮、深度图）用双边滤波，接受它的慢
4. 形态学结构元大小要大于要去除的噪点尺寸，否则去不干净
5. 开运算去白噪点、闭运算填黑孔，先想清楚目标再选
6. 锐化前先平滑去噪，否则噪声被一起放大

### 踩坑记录

```text
坑 1：Otsu 和固定阈值混用写法错误
结论：写成 cv2.THRESH_BINARY | cv2.THRESH_OTSU 或用错 retval，阈值是 0。
原因：OTSU 是 flag 要和类型做加法（+），不是按位或（|）。
解法：cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)。

坑 2：自适应阈值的 blockSize 写成偶数
结论：adaptiveThreshold 直接报错。
原因：blockSize 必须是奇数（要有个中心像素）。
解法：blockSize 用 3/5/7...等奇数，越大邻域越平滑。

坑 3：高斯核参数 sigma 和 ksize 都设导致疑惑
结论：同时设了 ksize 和 sigma，模糊强度出乎预期。
原因：sigmaX=0 时从 ksize 自动推算，两者都设时以 sigma 为准。
解法：要么只给 ksize 且 sigma=0，要么 ksize=(0,0) 只给 sigma。

坑 4：双边滤波 d 设太大导致极慢
结论：d=50 时双边滤波卡成秒级，实时场景直接不可用。
原因：双边滤波是 O(核面积) 的逐像素非线性计算。
解法：d 控制在 5~15，sigma 调平滑，或用快速近似（cv2.edgePreservingFilter）。

坑 5：形态学操作忘了转二值图
结论：直接在彩色图/浮点图上跑形态学，结果乱。
原因：腐蚀膨胀对多通道图逐通道做，语义不对。
解法：先转灰度 + 阈值得到二值掩码，再形态学处理。
```
