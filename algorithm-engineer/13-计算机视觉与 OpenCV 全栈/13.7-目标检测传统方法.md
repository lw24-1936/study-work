## 概述

目标检测要回答两个问题：图像里「有没有目标」以及「目标在哪里」。在深度学习一统江湖之前，检测靠的是「手工特征 + 分类器 + 滑窗/候选区域」这套组合拳：先用滑窗或候选区域把图像切成一堆候选框，再对每个框提取手工特征（Haar、HOG 等），最后交给分类器（SVM、AdaBoost）判断框里是不是目标。它们精度不如现代深度模型，但速度快、可解释、无需 GPU，至今仍活跃在嵌入式与实时场景。

```text
传统目标检测的核心思想：
1. 定位 —— 用滑窗（穷举）或候选区域（Selective Search）生成候选框
2. 特征 —— 对每个候选框提取手工特征（Haar / HOG / DPM 部件特征）
3. 分类 —— 用 SVM / AdaBoost 等分类器判断框内是否为目标
4. 合并 —— 用非极大值抑制（NMS）去重，输出最终框
```

```python
import cv2

# 传统检测的整体流程示意（人脸检测）
img = cv2.imread('people.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
detector = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')
faces = detector.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30))
for (x, y, w, h) in faces:
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)
print(f'检测到 {len(faces)} 张人脸')
```

## Sliding Window

滑窗（Sliding Window）是最朴素的定位策略：用一个固定大小的窗口在图像上从左到右、从上到下按步长滑动，每个位置裁出一个子图交给分类器。为了检测不同大小的目标，还要对图像做「图像金字塔」——多尺度缩放后分别滑窗。它是所有传统检测器的定位基础，缺点是计算量大、窗口数量爆炸。

```text
滑窗的关键参数：
1. 窗口尺寸 —— 与待检测目标的长宽比/大小匹配
2. 步长 stride —— 越小越密、漏检越少，但候选框越多
3. 尺度 —— 通过图像金字塔覆盖不同大小的目标
4. 数量估算 —— (W/stride) × (H/stride) × 尺度数，很容易到百万级
```

```python
import numpy as np

def sliding_window(image, window_size, step):
    """生成滑窗坐标，返回 (x, y, 子图)"""
    h, w = image.shape[:2]
    win_h, win_w = window_size
    for y in range(0, h - win_h + 1, step):
        for x in range(0, w - win_w + 1, step):
            yield (x, y, image[y:y + win_h, x:x + win_w])

def image_pyramid(image, scale=1.2, min_size=(30, 30)):
    """多尺度图像金字塔，配合滑窗检测不同大小的目标"""
    yield image
    while True:
        w = int(image.shape[1] / scale)
        h = int(image.shape[0] / scale)
        image = cv2.resize(image, (w, h))
        if w < min_size[0] or h < min_size[1]:
            break
        yield image

# 统计一张 640x480 图在 64x128 窗口、步长 8 下的候选框数量
count = len(list(sliding_window(np.zeros((480, 640)), (128, 64), 8)))
print(f'单尺度候选框数: {count}')   # 约 5000+，多尺度会轻松破百万
```

## Haar Cascade

Haar Cascade 是 Viola-Jones 人脸检测器的核心，也是 OpenCV 里最易用的传统检测器。它用一组 Haar 小波特征（黑白矩形块的亮度差）描述局部纹理，再通过 AdaBoost 从海量特征里挑出最有判别力的弱分类器，级联（Cascade）起来：前面的简单分类器快速否决「明显不是人脸」的区域，只有通过所有级的窗口才算目标。它的精髓是「先粗后精」的级联结构 + 积分图加速特征计算。

```text
Haar Cascade 三大要素：
1. Haar 特征 —— 黑白矩形区域亮度差（边缘、线、对角等模板）
2. 积分图 —— O(1) 计算任意矩形区域像素和，特征提取极快
3. AdaBoost 级联 —— 每级由若干弱分类器组成，逐级否决负样本

关键参数：
- scaleFactor —— 每次缩放图像的比例（越小越慢、检出越多）
- minNeighbors —— 邻域内重叠框数阈值（越大越严格、误检越少）
```

```python
import cv2

# 人脸检测 + 眼睛检测的两级联示例
face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')
eye_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_eye.xml')

img = cv2.imread('face.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30))
for (x, y, w, h) in faces:
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)
    roi_gray = gray[y:y + h, x:x + w]
    eyes = eye_cascade.detectMultiScale(roi_gray)
    for (ex, ey, ew, eh) in eyes:
        cv2.rectangle(img, (x + ex, y + ey), (x + ex + ew, y + ey + eh), (255, 0, 0), 2)
print(f'人脸: {len(faces)} 张')
```

## HOG

HOG（Histogram of Oriented Gradients，方向梯度直方图）是行人检测的金标准特征。它把图像分成若干 cell，统计每个 cell 内像素梯度方向的直方图，再在更大的 block 上做归一化，得到一个对光照、几何形变鲁棒的特征向量。经典用法是 HOG + 线性 SVM 做行人检测（Dalal & Triggs 2005）。HOG 关注「轮廓/形状」，对纹理和颜色不敏感，因此特别适合人这种有明显轮廓的目标。

```text
HOG 的计算流程：
1. 灰度化 + gamma 归一化 —— 减少光照影响
2. 计算梯度 —— Sobel 算子求每个像素的梯度幅值与方向
3. cell 直方图 —— 把 8x8 cell 内梯度按方向（9 个 bin）投票
4. block 归一化 —— 2x2 cell 组成 block，做 L2 归一化抗光照
5. 拼接 —— 所有 block 的归一化直方图拼成最终特征向量
```

```python
import cv2

# OpenCV 内置 HOG 行人检测器
hog = cv2.HOGDescriptor()
hog.setSVMDetector(cv2.HOGDescriptor_getDefaultPeopleDetector())

img = cv2.imread('pedestrians.jpg')
boxes, weights = hog.detectMultiScale(img, winStride=(8, 8), padding=(8, 8), scale=1.05)
for (x, y, w, h) in boxes:
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 0, 255), 2)
print(f'检测到行人: {len(boxes)} 个，置信度: {weights}')
```

```python
# 手动计算 HOG 特征（用于理解原理）
import numpy as np

def compute_hog_descriptor(image, cell_size=8, block_size=2, nbins=9):
    gx = cv2.Sobel(image, cv2.CV_32F, 1, 0)
    gy = cv2.Sobel(image, cv2.CV_32F, 0, 1)
    magnitude = np.sqrt(gx ** 2 + gy ** 2)
    orientation = (np.arctan2(gy, gx) * 180 / np.pi) % 180   # 方向归到 [0, 180)
    h, w = image.shape
    features = []
    for by in range(0, h - cell_size * block_size + 1, cell_size):
        for bx in range(0, w - cell_size * block_size + 1, cell_size):
            block_hist = []
            for cy in range(block_size):
                for cx in range(block_size):
                    cell_hist = np.zeros(nbins)
                    for py in range(cell_size):
                        for px in range(cell_size):
                            bin_idx = int(orientation[by + cy * cell_size + py, bx + cx * cell_size + px] / (180 / nbins)) % nbins
                            cell_hist[bin_idx] += magnitude[by + cy * cell_size + py, bx + cx * cell_size + px]
                    cell_hist /= (np.linalg.norm(cell_hist) + 1e-6)   # L2 归一化
                    block_hist.extend(cell_hist)
            features.extend(block_hist)
    return np.array(features)

gray = cv2.cvtColor(cv2.imread('person.png'), cv2.COLOR_BGR2GRAY)
desc = compute_hog_descriptor(cv2.resize(gray, (64, 128)))
print(f'HOG 特征维度: {desc.shape[0]}')
```

## Selective Search

Selective Search 是一种候选区域（Region Proposal）生成算法，它放弃穷举滑窗，转而基于颜色、纹理、大小、吻合度等相似度，自底向上地把超像素/小区域逐步合并成大区域，最终得到约一两千个「可能包含目标」的候选框。相比滑窗的百万级候选，它把候选数砍了几个数量级，是 R-CNN、Fast R-CNN 时代的标配候选生成器。

```text
Selective Search 的核心思想：
1. 过分割 —— 用图分割把图像切成大量超像素小区域
2. 相似度 —— 计算相邻区域的颜色/纹理/大小/吻合度相似度
3. 合并 —— 迭代合并最相似的两个区域，生成层次结构
4. 候选框 —— 每个中间区域的外接矩形都是一个候选框

特点：召回率高（通常 95%+），但速度慢（CPU 约 1~2 秒/图）
```

```python
import cv2

# 使用 opencv-contrib 的 Selective Search
# pip install opencv-contrib-python
img = cv2.imread('animals.jpg')
ss = cv2.ximgproc.segmentation.createSelectiveSearchSegmentation()
ss.setBaseImage(img)
ss.switchToSelectiveSearchFast()    # 快速模式，或 switchToSelectiveSearchQuality() 高质量模式
rects = ss.process()                # 返回候选框列表
print(f'候选框总数: {len(rects)}')

# 取前 N 个置信度最高的候选框
for i, rect in enumerate(rects[:200]):
    x, y, w, h = rect
    if w > 20 and h > 20:
        cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 1)
cv2.imwrite('ss_proposals.jpg', img)
```

## DPM

DPM（Deformable Part Models，可变形部件模型）是深度学习前的检测巅峰，由 Felzenszwalb 提出，多次拿下 PASCAL VOC 冠军。它把目标建模成一个「根滤波器」加若干「部件滤波器」，每个部件相对根有可形变的偏移约束（弹簧模型），因此能处理行人等非刚体目标的姿态变化。HOG 特征 + 隐 SVM（Latent SVM）训练，配合多尺度滑窗。它是 HOG 检测的部件化升级，思想直接影响了后来的目标检测研究。

```text
DPM 的核心组成：
1. 根滤波器 root filter —— 描述目标整体外观
2. 部件滤波器 part filter —— 描述局部（头、躯干、四肢），分辨率更高
3. 形变代价 —— 部件偏离理想位置的二次惩罚，允许姿态形变
4. 隐 SVM —— 部件位置当作隐变量，训练时交替优化

流程：多尺度 HOG 特征图 → 根+部件分数 → 形变代价求和 → NMS 输出
```

```python
import numpy as np

# DPM 打分原理示意：根分数 + 部件分数 - 形变代价
def dpm_score(root_map, part_maps, anchor, deform_cost, part_offsets):
    score = root_map[anchor[0], anchor[1]]                     # 根滤波器响应
    for part_map, offset in zip(part_maps, part_offsets):
        py, px = anchor[0] + offset[0], anchor[1] + offset[1]
        part_response = part_map[py, px]                       # 部件滤波器响应
        dcost = deform_cost * (offset[0] ** 2 + offset[1] ** 2)   # 形变代价
        score += part_response - dcost
    return score

# 假设已得到 HOG 特征图上的响应（此处用随机值示意）
root_map = np.random.rand(10, 10)
part_maps = [np.random.rand(10, 10) for _ in range(3)]
part_offsets = [(1, 0), (-1, 1), (0, -1)]
print(f'DPM 得分: {dpm_score(root_map, part_maps, (5, 5), 0.05, part_offsets):.3f}')
```

## 应用场景实战

### 场景一：实时人脸检测（Haar Cascade + NMS）

```python
import cv2

face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    # 适当调参平衡速度与精度：scaleFactor 大 → 快，minNeighbors 大 → 严
    faces = face_cascade.detectMultiScale(gray, scaleFactor=1.2, minNeighbors=5, minSize=(40, 40))
    for (x, y, w, h) in faces:
        cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    cv2.imshow('Face Detection', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release()
cv2.destroyAllWindows()
```

### 场景二：行人检测（HOG + SVM）

```python
import cv2

hog = cv2.HOGDescriptor()
hog.setSVMDetector(cv2.HOGDescriptor_getDefaultPeopleDetector())

img = cv2.imread('street.jpg')
# 大图先缩小检测，再映射回原坐标，减少计算量
scale = 0.5
small = cv2.resize(img, (int(img.shape[1] * scale), int(img.shape[0] * scale)))
boxes, weights = hog.detectMultiScale(small, winStride=(8, 8), padding=(16, 16), scale=1.05)

# 过滤低置信度检测
confident = [(b, w) for b, w in zip(boxes, weights) if w[0] > 0.5]
for (x, y, w, h), score in confident:
    x, y, w, h = int(x / scale), int(y / scale), int(w / scale), int(h / scale)
    cv2.rectangle(img, (x, y), (x + w, y + h), (0, 0, 255), 2)
    cv2.putText(img, f'{score[0]:.2f}', (x, y - 5), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 255), 1)
print(f'行人数量（置信度>0.5）: {len(confident)}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 人脸检测用 Haar Cascade 先跑起来，参数 scaleFactor=1.1、minNeighbors=5 是稳定起点
2. 行人检测用 HOG + SVM，winStride 与 scale 是速度/精度主要旋钮，慢场景先降采样
3. 候选生成优先 Selective Search（质量模式）保证召回，再让分类器去精排
4. 所有传统检测器输出都要过 NMS，否则同一个目标会框出一堆重叠框
5. 特征提取前统一灰度化 + 归一化，避免光照干扰 HOG/Haar 特征
6. 多尺度检测务必用图像金字塔，单尺度只能检测固定大小的目标

### 踩坑记录

```text
坑 1：滑窗步长太小导致候选框爆炸
结论：640x480 图步长 2 时候选框轻松破百万，CPU 跑不动。
原因：滑窗数量 = (W/stride) × (H/stride) × 尺度数，与步长平方成反比。
解法：步长设 8~16，或用 Selective Search 代替穷举滑窗。

坑 2：Haar Cascade 检测不到侧脸/遮挡人脸
结论：默认正脸模型对侧脸、遮挡、大角度人脸漏检严重。
原因：Haar 特征基于正面正样本训练，泛化能力有限。
解法：换侧脸/多视角级联文件，或改用深度模型（如 MTCNN）。

坑 3：HOG 检测器对不同图像尺寸敏感
结论：直接把大图丢进 detectMultiScale 极慢甚至卡死。
原因：HOG 在原始分辨率上滑窗计算量随像素数线性爆炸。
解法：先按比例缩小图像再检测，坐标映射回原图。

坑 4：忘记 NMS，同一人脸框出十几个框
结论：检测结果出现大量重叠框，视觉效果极差。
原因：滑窗相邻位置都触发分类器，产生冗余正例。
解法：用 NMS（cv2.dnn.NMSBoxes 或手写 IoU 阈值 0.3~0.5）去重。

坑 5：Selective Search 候选框数量失控
结论：大图生成几万候选框，后续特征提取耗时过长。
原因：质量模式对细节丰富的图会产生大量合并区域。
解法：限制最大候选数（如取前 2000），并过滤过小/过大框。
```
