## 概述

视频分析处理的是「时间序列图像」：不仅要理解单帧内容，更要利用帧与帧之间的时序关系。它的核心技术围绕「运动」展开——用光流估计像素运动、用背景差分找运动目标、用跟踪器在时间轴上持续定位目标。多目标跟踪（MOT）是集大成的应用：检测器找目标、卡尔曼滤波预测运动、数据关联匹配 ID，SORT/DeepSORT/ByteTrack 是这条主线的三代代表。

```text
视频分析的核心链路：
1. 采样/读取 —— Frame Sampling 抽取关键帧，控制计算量
2. 运动估计 —— Optical Flow / Background Subtraction 找运动
3. 单目标跟踪 —— 给定初始框，持续跟踪一个目标
4. 多目标跟踪 —— 检测 + 预测 + 关联，维护多个目标 ID
5. 时序模型 —— Kalman Filter 预测状态，SORT/DeepSORT/ByteTrack 工程化
```

```python
import cv2

# 视频读取与抽帧的入口
cap = cv2.VideoCapture('video.mp4')
fps = cap.get(cv2.CAP_PROP_FPS)
frame_count = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
print(f'视频 {frame_count} 帧，{fps:.1f} FPS，时长 {frame_count / fps:.1f}s')
ret, frame = cap.read()
print(f'单帧尺寸: {frame.shape}')
cap.release()
```

## Frame Sampling

帧采样（Frame Sampling）是从视频里抽取帧的策略：视频动辄几十上百 FPS，逐帧处理计算量巨大，且相邻帧高度冗余。按固定间隔抽帧（如每秒 1 帧）、按关键帧抽、或按场景变化自适应抽，都能在保留信息的同时大幅降低计算量。它是所有视频处理流水线的第一道「降本」关口。

```text
帧采样策略：
1. 均匀采样 —— 每隔 N 帧取一帧（最常见，简单可控）
2. 时间采样 —— 每秒固定取 K 帧，与帧率解耦
3. 关键帧采样 —— 只取 I 帧，解码最快
4. 自适应采样 —— 按运动/场景变化程度动态调整间隔
```

```python
import cv2

def sample_frames(video_path, interval=30):
    """按固定间隔均匀抽帧"""
    cap = cv2.VideoCapture(video_path)
    frames = []
    idx = 0
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        if idx % interval == 0:
            frames.append(frame)
        idx += 1
    cap.release()
    return frames

def sample_by_time(video_path, per_second=1):
    """按每秒固定帧数抽帧（与帧率解耦）"""
    cap = cv2.VideoCapture(video_path)
    fps = cap.get(cv2.CAP_PROP_FPS) or 30
    interval = max(1, int(fps / per_second))
    cap.release()
    return sample_frames(video_path, interval=interval)

frames = sample_by_time('video.mp4', per_second=1)
print(f'每秒 1 帧，共抽取 {len(frames)} 帧')
```

## Optical Flow

光流（Optical Flow）估计像素在相邻帧之间的运动矢量：假设亮度恒定、小位移，求解每个像素 (u, v) 的位移场。它不依赖目标检测，直接描述「画面里哪里在动、往哪动」，广泛用于运动分割、动作识别、视频稳定、跟踪。经典算法有 Lucas-Kanade（稀疏、角点）、Farneback（稠密、Gunnar Farneback）、以及深度光流 RAFT。

```text
光流的两大假设：
1. 亮度恒定 —— 同一像素在两帧间灰度不变
2. 小位移 —— 帧间运动微小，可用泰勒展开近似

分类：
- 稀疏光流 —— Lucas-Kanade，只算角点等特征点的运动
- 稠密光流 —— Farneback / RAFT，算整幅图像每个像素的运动
```

```python
import cv2
import numpy as np

# Lucas-Kanade 稀疏光流：跟踪角点
cap = cv2.VideoCapture('video.mp4')
ret, old_frame = cap.read()
old_gray = cv2.cvtColor(old_frame, cv2.COLOR_BGR2GRAY)
# 选角点作为跟踪点
p0 = cv2.goodFeaturesToTrack(old_gray, maxCorners=100, qualityLevel=0.3, minDistance=7)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    new_gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    p1, status, err = cv2.calcOpticalFlowPyrLK(old_gray, new_gray, p0, None)
    good_new = p1[status == 1].reshape(-1, 1, 2)
    good_old = p0[status == 1].reshape(-1, 1, 2)
    # 画出运动轨迹
    for new, old in zip(good_new, good_old):
        a, b = new.ravel(); c, d = old.ravel()
        cv2.line(frame, (int(a), int(b)), (int(c), int(d)), (0, 255, 0), 2)
    cv2.imshow('Optical Flow', frame)
    old_gray = new_gray.copy()
    p0 = good_new.reshape(-1, 1, 2)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release(); cv2.destroyAllWindows()
```

```python
# Farneback 稠密光流：整幅图像的运动场
import cv2

cap = cv2.VideoCapture('video.mp4')
ret, frame1 = cap.read()
prev = cv2.cvtColor(frame1, cv2.COLOR_BGR2GRAY)

mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
print(f'光流场尺寸: {flow.shape}，平均运动幅度: {mag.mean():.3f}')
```

## Background Subtraction

背景差分（Background Subtraction）把「前景运动目标」从静态背景里抠出来：先建立背景模型，再把每帧与背景比较，差异大的像素就是前景。它不需要训练目标检测器，是监控场景（固定摄像头）里运动目标提取的经典手段。OpenCV 提供 MOG2（高斯混合模型）、KNN、GMG 等背景建模器。

```text
背景差分流程：
1. 背景建模 —— 用前若干帧学习背景（MOG2 用高斯混合）
2. 前景提取 —— 当前帧与背景差异超过阈值的像素标为前景
3. 后处理 —— 形态学去噪、填洞，得到干净的前景 mask
4. 背景更新 —— 光照变化时逐步更新背景模型

适用：固定机位监控；不适用：移动摄像头、剧烈光照变化
```

```python
import cv2

backSub = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=50, detectShadows=True)
cap = cv2.VideoCapture('surveillance.mp4')

while True:
    ret, frame = cap.read()
    if not ret:
        break
    fg_mask = backSub.apply(frame)          # 前景掩码（含阴影，阴影为灰色）
    # 形态学去噪
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_OPEN, kernel)
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_CLOSE, kernel)
    # 找运动目标的轮廓
    contours, _ = cv2.findContours(fg_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for c in contours:
        if cv2.contourArea(c) > 500:
            x, y, w, h = cv2.boundingRect(c)
            cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 0, 255), 2)
    cv2.imshow('Background Subtraction', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release(); cv2.destroyAllWindows()
```

## Object Tracking

单目标跟踪（Single Object Tracking）：给定第一帧的目标框，后续帧持续定位这个目标。与检测不同，跟踪器假设「目标已给定」，专注在时序上锁定它。方法分经典相关滤波（KCF、CSRT，速度快、精度一般）和深度孪生网络（SiamRPN、SiamFC，精度高）。挑战是遮挡、形变、尺度变化导致的漂移。

```text
单目标跟踪 vs 多目标跟踪：
- 单目标 —— 给定初始框，只跟一个目标，无 ID 关联
- 多目标 —— 检测器持续发现目标，需 ID 分配与轨迹管理

相关滤波核心思想：
- 学习一个滤波器，使目标区域响应最大，通过循环移位训练
- 在下一帧搜索最大响应位置，即目标新位置
```

```python
import cv2

# 用 CSRT 跟踪器（OpenCV 内置，精度较高）
tracker = cv2.TrackerCSRT_create()
cap = cv2.VideoCapture('video.mp4')
ret, frame = cap.read()
bbox = (100, 100, 60, 60)          # 初始框 (x, y, w, h)
tracker.init(frame, bbox)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    ok, bbox = tracker.update(frame)
    if ok:
        x, y, w, h = [int(v) for v in bbox]
        cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    else:
        cv2.putText(frame, 'Lost', (20, 40), cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)
    cv2.imshow('SOT', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release(); cv2.destroyAllWindows()
```

## Multi-Object Tracking

多目标跟踪（MOT）同时跟踪多个目标：检测器在每帧找到所有目标，跟踪器把跨帧的目标关联起来，给每个目标一个稳定的 ID，形成完整轨迹。它比单目标跟踪多了「数据关联」这个核心问题——这一帧的检测框对应上一帧的哪个目标？还要处理新目标出现（ID 生成）、目标消失（ID 终止）、遮挡后的重识别。评估用 MOTA、IDF1、ID Switches。

```text
MOT 的核心流程（Tracking-by-Detection）：
1. 检测 —— 每帧用检测器（如 YOLO）找所有目标
2. 预测 —— 用运动模型（卡尔曼滤波）预测目标下一帧位置
3. 关联 —— 检测框与预测框做匹配（IoU / 外观相似度）
4. 管理 —— 分配 ID、生成新轨迹、终止消失轨迹

评估指标：
- MOTA —— 多目标跟踪准确率（综合 FP/FN/ID Switch）
- IDF1 —— 身份保持能力
- ID Switches —— ID 切换次数，越少越好
```

```python
import numpy as np

# MOT 数据关联的核心：IoU 匹配矩阵
def iou_matrix(detections, tracks):
    n_det, n_trk = len(detections), len(tracks)
    mat = np.zeros((n_det, n_trk))
    for i, d in enumerate(detections):
        for j, t in enumerate(tracks):
            x1 = max(d[0], t[0]); y1 = max(d[1], t[1])
            x2 = min(d[2], t[2]); y2 = min(d[3], t[3])
            inter = max(0, x2 - x1) * max(0, y2 - y1)
            area_d = (d[2] - d[0]) * (d[3] - d[1])
            area_t = (t[2] - t[0]) * (t[3] - t[1])
            mat[i, j] = inter / (area_d + area_t - inter + 1e-6)
    return mat

detections = [[10, 10, 50, 50], [100, 100, 160, 160]]
tracks = [[12, 12, 52, 52], [200, 200, 240, 240]]
print(f'IoU 匹配矩阵:\n{iou_matrix(detections, tracks)}')
```

## Kalman Filter

卡尔曼滤波（Kalman Filter）是线性动态系统的最优状态估计器，也是跟踪里「预测目标位置」的标准工具。它用「预测-更新」两步循环：预测阶段用运动模型推下一时刻状态（位置、速度），更新阶段用新观测（检测框）修正预测。即使目标暂时被遮挡、检测丢失，卡尔曼滤波也能靠运动模型「外推」目标位置，是 SORT/DeepSORT 的运动模型基础。

```text
卡尔曼滤波的两步：
1. 预测 —— 用状态转移矩阵 A 预测下一时刻状态 x̂ = A·x
2. 更新 —— 用观测 z 和卡尔曼增益 K 修正：x = x̂ + K·(z - H·x̂)

状态向量（匀速模型）：[x, y, w, h, vx, vy, vw, vh]
卡尔曼增益 K —— 权衡预测与观测的可信度
```

```python
import numpy as np

class KalmanFilter:
    """一维匀速卡尔曼滤波示意（状态 = [位置, 速度]）"""
    def __init__(self, dt=1.0, process_noise=0.1, measure_noise=1.0):
        self.dt = dt
        self.A = np.array([[1, dt], [0, 1]])          # 状态转移：匀速运动
        self.H = np.array([[1, 0]])                    # 观测矩阵：只观测位置
        self.Q = np.eye(2) * process_noise             # 过程噪声
        self.R = np.eye(1) * measure_noise             # 观测噪声
        self.x = np.zeros((2, 1))                      # 初始状态
        self.P = np.eye(2)                             # 初始协方差

    def predict(self):
        self.x = self.A @ self.x
        self.P = self.A @ self.P @ self.A.T + self.Q
        return self.x[0, 0]

    def update(self, z):
        S = self.H @ self.P @ self.H.T + self.R
        K = self.P @ self.H.T @ np.linalg.inv(S)       # 卡尔曼增益
        self.x = self.x + K @ (z - self.H @ self.x)
        self.P = (np.eye(2) - K @ self.H) @ self.P
        return self.x[0, 0]

kf = KalmanFilter()
true_pos = [0, 1, 2, 3, 4, 5]                        # 真实匀速运动
for z in true_pos:
    pred = kf.predict()
    est = kf.update(np.array([[z + np.random.randn() * 0.5]]))  # 带噪声观测
    print(f'预测 {pred:.2f}，观测 {z}，估计 {est:.2f}')
```

## SORT

SORT（Simple Online and Realtime Tracking）是 MOT 的经典基线：用检测器找目标 + 卡尔曼滤波预测运动 + 匈牙利算法做 IoU 关联。它极其简单高效（数百 FPS），但只看 IoU、不看外观，导致遮挡后目标容易 ID Switch。SORT 的价值在于证明「检测 + 卡尔曼 + 匈牙利」这套组合就足以做到不错的实时跟踪，后续 DeepSORT、ByteTrack 都在它的框架上改进。

```text
SORT 的核心组成：
1. 检测 —— 每帧用检测器（如 Faster R-CNN / YOLO）
2. 预测 —— 卡尔曼滤波预测每个轨迹的下一帧位置
3. 关联 —— 检测框与预测框算 IoU，匈牙利算法求最优匹配
4. 管理 —— 匹配上的更新轨迹，没匹配的轨迹超时删除，新检测建新轨迹

局限：无外观特征，遮挡时仅靠运动预测，易 ID Switch
```

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def sort_association(dets, tracks, iou_threshold=0.3):
    """SORT 的 IoU 关联：返回匹配对与未匹配项"""
    n_det, n_trk = len(dets), len(tracks)
    if n_det == 0 or n_trk == 0:
        return [], list(range(n_det)), list(range(n_trk))
    cost = np.zeros((n_det, n_trk))
    for i, d in enumerate(dets):
        for j, t in enumerate(tracks):
            x1 = max(d[0], t[0]); y1 = max(d[1], t[1])
            x2 = min(d[2], t[2]); y2 = min(d[3], t[3])
            inter = max(0, x2 - x1) * max(0, y2 - y1)
            area = (d[2] - d[0]) * (d[3] - d[1]) + (t[2] - t[0]) * (t[3] - t[1]) - inter
            cost[i, j] = inter / (area + 1e-6)
    row, col = linear_sum_assignment(-cost)      # 最大化 IoU
    matched = [(r, c) for r, c in zip(row, col) if cost[r, c] > iou_threshold]
    unmatched_dets = [i for i in range(n_det) if i not in [m[0] for m in matched]]
    unmatched_trks = [j for j in range(n_trk) if j not in [m[1] for m in matched]]
    return matched, unmatched_dets, unmatched_trks

dets = [[10, 10, 50, 50], [100, 100, 160, 160], [300, 300, 320, 320]]
trks = [[12, 12, 52, 52], [200, 200, 240, 240]]
matched, um_dets, um_trks = sort_association(dets, trks)
print(f'匹配: {matched}, 未匹配检测: {um_dets}, 未匹配轨迹: {um_trks}')
```

## DeepSORT

DeepSORT 在 SORT 上补上了「外观特征」：用一个人物重识别（ReID）网络提取每个检测框的外观 embedding，关联时同时考虑「运动相似度（马氏距离）」和「外观相似度（余弦距离）」，加权融合成代价矩阵。这样即使目标被短暂遮挡，也能靠外观特征在重新出现时找回原 ID，显著降低 ID Switch。它是 SORT 的直接升级，工程上最常用的 MOT 方案之一。

```text
DeepSORT 相对 SORT 的改进：
1. 外观特征 —— ReID 网络提取 128 维 embedding
2. 双重距离 —— 马氏距离（运动）+ 余弦距离（外观）加权
3. 级联匹配 —— 优先匹配最近更新的轨迹，缓解遮挡
4. 特征库 —— 保留每个轨迹最近若干帧的外观特征

代价矩阵 = λ·外观距离 + (1-λ)·运动距离
```

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def deepsort_cost(motion_cost, appearance_cost, lam=0.1):
    """DeepSORT 融合运动与外观代价"""
    return lam * appearance_cost + (1 - lam) * motion_cost

def cosine_distance(a, b):
    a, b = np.asarray(a), np.asarray(b)
    a = a / (np.linalg.norm(a, axis=-1, keepdims=True) + 1e-8)
    b = b / (np.linalg.norm(b, axis=-1, keepdims=True) + 1e-8)
    return 1 - a @ b.T

# 3 个检测的外观特征 vs 2 个轨迹的外观特征（128 维 ReID embedding）
det_feats = np.random.randn(3, 128)
trk_feats = np.random.randn(2, 128)
app_cost = cosine_distance(det_feats, trk_feats)      # [3, 2]
motion_cost = np.random.rand(3, 2)                    # 马氏距离（示意）
cost = deepsort_cost(motion_cost, app_cost, lam=0.1)
row, col = linear_sum_assignment(cost)
print(f'DeepSORT 最优关联: 检测 {row} -> 轨迹 {col}')
```

## ByteTrack

ByteTrack 的洞察是「低置信度检测也有价值」：SORT/DeepSORT 通常直接丢弃低于阈值的检测框，但这些框往往是遮挡中、模糊中的真实目标。ByteTrack 把检测框按置信度分成高、低两档，先做高分框与轨迹的关联，再把剩余轨迹与低分框做第二次关联（只做 IoU 匹配），从而救回大量被遮挡目标。它不用外观特征，纯靠「利用低分框 + 运动模型」就达到当时 SOTA，且速度更快。

```text
ByteTrack 的核心策略：
1. 分档 —— 检测框按置信度分高分/低分两档
2. 第一轮关联 —— 高分框与所有轨迹做 IoU 匹配
3. 第二轮关联 —— 未匹配轨迹与低分框做 IoU 匹配（救回遮挡目标）
4. 无需外观 —— 不依赖 ReID，速度快、ID Switch 少

关键价值：把被传统方案丢弃的低分框重新利用
```

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def bytetrack_two_stage(high_dets, low_dets, tracks, high_thresh=0.5):
    """ByteTrack 两阶段关联示意"""
    def iou(a, b):
        x1 = max(a[0], b[0]); y1 = max(a[1], b[1])
        x2 = min(a[2], b[2]); y2 = min(a[3], b[3])
        inter = max(0, x2 - x1) * max(0, y2 - y1)
        return inter / ((a[2] - a[0]) * (a[3] - a[1]) + (b[2] - b[0]) * (b[3] - b[1]) - inter + 1e-6)

    def associate(dets, trk_indices):
        if not dets or not trk_indices:
            return [], list(range(len(dets))), trk_indices
        cost = -np.array([[iou(d, tracks[j]) for j in trk_indices] for d in dets])
        row, col = linear_sum_assignment(cost)
        matched = [(r, trk_indices[c]) for r, c in zip(row, col) if -cost[r, c] > 0.1]
        um_dets = [i for i in range(len(dets)) if i not in [m[0] for m in matched]]
        um_trks = [j for j in trk_indices if j not in [m[1] for m in matched]]
        return matched, um_dets, um_trks

    # 第一轮：高分框关联
    matched, um_high, um_trks = associate(high_dets, list(range(len(tracks))))
    # 第二轮：低分框与剩余轨迹关联（救回遮挡目标）
    matched2, um_low, _ = associate(low_dets, um_trks)
    return matched + matched2, um_high, um_low

tracks = [[10, 10, 50, 50], [100, 100, 160, 160]]
high = [[12, 12, 52, 52]]
low = [[105, 105, 165, 165]]       # 低分框，实际是遮挡中的轨迹 2
matched, um_high, um_low = bytetrack_two_stage(high, low, tracks)
print(f'总匹配: {matched}, 未匹配高分: {um_high}, 未匹配低分: {um_low}')
```

backSub = cv2.createBackgroundSubtractorMOG2()

        break

import numpy as np

def compute_mota(fp, fn, id_switches, gt):
    """MOTA 指标：1 - (FP + FN + ID_SW) / GT"""

## 最佳实践与踩坑记录

### 最佳实践

1. 固定机位监控先上背景差分，零训练、CPU 实时，是最快的运动检测方案
2. 跟踪任务先用 SORT 跑 baseline，ID Switch 严重再升级 DeepSORT 或 ByteTrack
3. 检测器质量决定跟踪上限：优先换更强的检测器，再优化关联算法
4. 光流只算角点（稀疏光流）即可满足多数运动分析，稠密光流很耗时
5. 抽帧间隔按目标运动速度定，慢速目标可加大间隔，快速目标要加密
6. 评估 MOT 务必同时看 MOTA 和 IDF1，MOTA 高但 IDF1 低说明 ID 混乱

### 踩坑记录

```text
坑 1：SORT 在遮挡场景 ID 频繁切换
结论：目标被遮挡再出现时被当成新目标，ID Switch 飙升。
原因：SORT 只靠 IoU，遮挡期间靠卡尔曼外推，位置漂移后对不上。
解法：换 DeepSORT（外观特征重识别）或 ByteTrack（低分框救回）。

坑 2：背景差分对光照变化敏感
结论：白天到傍晚光照渐变，整片区域被误判为前景。
原因：固定阈值背景模型无法适应缓慢光照漂移。
解法：用 MOG2 自适应更新背景，或加大 history 让模型逐步适应。

坑 3：光流假设不成立导致漂移
结论：快速运动、大位移目标光流估计严重失真。
原因：Lucas-Kanade 假设小位移，大位移违背了泰勒展开前提。
解法：用图像金字塔迭代（PyrLK），或换深度光流 RAFT。

坑 4：卡尔曼滤波参数乱设
结论：过程噪声过大预测不可信，过小则跟踪迟滞。
原因：Q/R 分别反映模型与观测的可信度，需与真实噪声匹配。
解法：按检测器定位误差设 R，按目标加速度设 Q，必要时实测标定。

坑 5：抽帧间隔固定导致关键动作丢失
结论：快速动作（如击球瞬间）被均匀抽帧跳过。
原因：均匀采样不考虑内容变化，关键帧可能落在间隔中间。
解法：按运动幅度自适应抽帧，运动剧烈时加密采样。
```
