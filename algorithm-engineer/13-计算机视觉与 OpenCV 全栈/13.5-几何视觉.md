## 概述

几何视觉研究图像的几何关系：平面间的映射（仿射、透视、单应）、相机成像模型（内参、畸变）、多视图关系（立体、对极）以及从图像恢复三维姿态（PnP）。它是标定、测距、SLAM、AR 的数学基础，核心是把「像素坐标」和「世界坐标」用矩阵联系起来。

```text
几何视觉的主线：
1. 平面变换 —— 仿射/透视/单应，2D 到 2D
2. 成像模型 —— 相机矩阵 + 畸变，3D 到 2D
3. 多视图 —— 立体视觉 + 对极几何，恢复深度
4. 姿态求解 —— PnP，从 2D 点反解 3D 位姿
```

```python
import cv2
import numpy as np

# 单应矩阵：四对点求解平面映射
src = np.float32([[0, 0], [100, 0], [100, 100], [0, 100]])
dst = np.float32([[0, 0], [120, 10], [110, 120], [10, 100]])
H, _ = cv2.findHomography(src, dst)
print(H.shape)   # (3, 3)
```

## Affine Transform（仿射变换）

仿射变换是「线性变换 + 平移」，用 2x3 矩阵表示，保持平行线平行、直线仍是直线，但不保持角度和长度。旋转、缩放、平移、剪切都是仿射变换。用三对不共线点即可唯一确定（getAffineTransform），配合 warpAffine 应用。

```text
仿射变换性质：
1. 保平行 —— 平行线变换后仍平行
2. 保直线 —— 直线仍是直线
3. 自由度 —— 6 个参数（2x3 矩阵）
4. 确定条件 —— 三对不共线点
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (20, 20), (40, 40), 255, -1)

src = np.float32([[20, 20], [40, 20], [20, 40]])
dst = np.float32([[20, 20], [60, 20], [20, 60]])   # x/y 各拉伸
M = cv2.getAffineTransform(src, dst)
warped = cv2.warpAffine(img, M, (100, 100))
print(M)
```

## Perspective Transform（透视变换）

透视变换是更一般的 2D 射影变换，用 3x3 矩阵表示，能表达「近大远小」的透视效果，不再保平行线（平行线会汇聚到灭点）。用四对点确定（getPerspectiveTransform），warpPerspective 应用。典型场景是文档/车牌倾斜校正、鸟瞰图变换。

```text
透视变换性质：
1. 保直线 —— 但平行线可汇聚
2. 自由度 —— 8 个（3x3 矩阵，齐次等价）
3. 确定条件 —— 四对点（任意三点不共线）
4. 应用 —— 透视校正、俯视图、图像配准
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (10, 10), (90, 90), 255, 3)

# 四角点映射成梯形（模拟透视）
src = np.float32([[10, 10], [90, 10], [90, 90], [10, 90]])
dst = np.float32([[30, 10], [70, 10], [90, 90], [10, 90]])
M = cv2.getPerspectiveTransform(src, dst)
warped = cv2.warpPerspective(img, M, (100, 100))
print(warped.shape)
```

## Homography（单应性矩阵）

单应 H 是两张平面图之间的 3x3 射影映射，x' = H·x（齐次坐标）。它把一个平面的点映射到另一个平面，是图像拼接、平面检测、增强现实的基石。最少四对匹配点即可求解，通常用 RANSAC 在大量含噪匹配点里鲁棒估计。

```text
单应矩阵求解：
1. 数学 —— x' = Hx，H 是 3x3、8 自由度
2. 最少点 —— 4 对（RANSAC 用更多点剔外点）
3. findHomography(method=RANSAC) —— 鲁棒估计
```

```python
import cv2
import numpy as np

# 含噪匹配点里用 RANSAC 估计单应
np.random.seed(0)
src = np.random.rand(50, 2) * 100
H_true = np.array([[1.2, 0.1, 5], [0.0, 1.1, 3], [0, 0, 1]])
dst = (H_true @ np.c_[src, np.ones(50)].T).T
dst = dst[:, :2] / dst[:, 2:]
H_est, mask = cv2.findHomography(src, dst, cv2.RANSAC, 3.0)
print('内点比例:', mask.sum() / len(mask))
```

## Camera Matrix（相机内参矩阵）

相机内参矩阵 K 把相机坐标系下的 3D 点投影到像素坐标：p = K·[R|t]·X。K 包含焦距 fx, fy 和主点 cx, cy。它是标定的核心输出，也是从像素反推 3D 射线的必经之路。

```text
内参矩阵 K：
1. 形式 —— [[fx, 0, cx], [0, fy, cy], [0, 0, 1]]
2. fx/fy —— 焦距（像素单位），cx/cy —— 主点（图像中心附近）
3. 用途 —— 3D 投影、去畸变、深度反投影
```

```python
import numpy as np

# 内参矩阵投影：相机 3D 点 → 像素坐标
K = np.array([[500, 0, 320],
              [0, 500, 240],
              [0, 0, 1]], dtype=np.float64)
X_cam = np.array([0.5, 0.3, 2.0])     # 相机坐标系下的点
p = K @ X_cam
u, v = p[0] / p[2], p[1] / p[2]
print(f'像素坐标: ({u:.1f}, {v:.1f})')   # 约 (445, 315)
```

## Distortion（畸变）

真实镜头不满足理想针孔模型，会产生畸变：径向畸变（桶形/枕形，离中心越远越明显）和切向畸变（镜头与传感器不平行）。畸变系数 [k1, k2, p1, p2, k3] 在标定时一并求出，用 undistort 校正，是精确测量前的必要步骤。

```text
畸变两类：
1. 径向 —— 桶形（广角）/ 枕形（长焦），由 k1/k2/k3 描述
2. 切向 —— 镜头装配不平，由 p1/p2 描述
3. 校正 —— cv2.undistort 用内参 + 畸变系数
```

```python
import cv2
import numpy as np

K = np.array([[500, 0, 320], [0, 500, 240], [0, 0, 1]], dtype=np.float64)
dist = np.array([-0.2, 0.05, 0, 0, 0])   # 桶形畸变系数
img = np.random.randint(0, 256, (480, 640, 3), dtype=np.uint8)
undistorted = cv2.undistort(img, K, dist)
print(undistorted.shape)
```

## Calibration（相机标定）

标定就是求相机内参和畸变系数：拍多张不同角度的棋盘格，检测角点（findChessboardCorners），用已知棋盘格物理尺寸建立「世界点 ↔ 像素点」对应，calibrateCamera 求解。标定结果的重投影误差越小越好（通常 < 0.5 像素）。

```text
标定流程：
1. 采集 —— 拍多张不同位姿的棋盘格
2. 角点检测 —— findChessboardCorners + cornerSubPix
3. 求解 —— calibrateCamera 得 K、dist、外参
4. 评估 —— 重投影误差
```

```python
import cv2
import numpy as np

# 造一个棋盘格角点坐标做标定示意（世界点是 (x,y,0) 平面）
objp = np.zeros((6 * 9, 3), np.float32)
objp[:, :2] = np.mgrid[0:9, 0:6].T.reshape(-1, 2)   # 每个格子 1 单位

# 实际中 imgpoints 来自 findChessboardCorners，这里示意
img = np.zeros((480, 640), dtype=np.uint8)
imgpoints = objp[:, :2].astype(np.float32) * 20 + np.float32([100, 100])
objpoints = [objp]
ret, K, dist, rvecs, tvecs = cv2.calibrateCamera(
    objpoints, [imgpoints], img.shape[::-1], None, None)
print('重投影误差:', ret)
print('焦距 fx,fy:', K[0, 0], K[1, 1])
```

## Stereo Vision（立体视觉）

立体视觉用两个相机（左右眼）拍摄同一场景，利用视差（同一点在两图中的位置差）恢复深度：深度 Z = f·B / disparity。B 是基线（两相机距离），视差越大物体越近。核心是立体匹配（找左右图对应点），结果存成视差图。

```text
立体视觉深度公式：
1. Z = f * B / disparity
2. f 焦距，B 基线，disparity 视差
3. 视差越大越近，基线越长测距越远越准
```

```python
import cv2
import numpy as np

# 视差 → 深度
f, B = 500.0, 0.1     # 焦距(像素) 基线(米)
disparity = 50.0      # 视差(像素)
Z = f * B / disparity
print(f'深度: {Z:.2f} 米')   # 1.0 米
```

## Epipolar Geometry（对极几何）

对极几何描述两个相机视图间的几何约束：一个 3D 点在左右图的投影点，分别落在两条「极线」上。核心是基础矩阵 F（像素坐标）和本质矩阵 E（归一化坐标），它们编码了相机的相对位姿，用于极线约束搜索、三角化恢复 3D。

```text
对极几何三要素：
1. 极线 —— 一个视图的点对应另一视图的一条线
2. 本质矩阵 E —— 编码相对旋转平移，5 自由度
3. 基础矩阵 F —— 像素坐标下的约束，8 点法求解
约束：x'^T F x = 0
```

```python
import cv2
import numpy as np

# 8 点法估计基础矩阵（示意用匹配点）
np.random.seed(0)
pts1 = np.random.rand(20, 2) * 100
pts2 = pts1 + np.random.randn(20, 2) * 2
F, mask = cv2.findFundamentalMat(pts1, pts2, cv2.FM_8POINT)
print(F.shape)   # (3, 3)
```

## PnP

PnP（Perspective-n-Point）从 n 个「3D 世界点 + 对应 2D 像素点」求解相机位姿（旋转 R 和平移 t）。已知内参时，最少 3 点（P3P），常用 solvePnP 的迭代法或 EPNP，配合 RANSAC 抗噪。它是 AR 标记定位、机器人视觉定位的核心。

```text
PnP 求解：
1. 输入 —— n 对 3D 世界点 ↔ 2D 像素点 + 内参
2. 输出 —— 旋转向量 rvec + 平移 tvec
3. 最少 3 点（P3P），多点更稳（EPnP/迭代 + RANSAC）
```

```python
import cv2
import numpy as np

# 已知内参，3D 点与 2D 点对应求解位姿
K = np.array([[500, 0, 320], [0, 500, 240], [0, 0, 1]], dtype=np.float64)
objp = np.float32([[0, 0, 0], [1, 0, 0], [0, 1, 0], [0, 0, 1]])
imgp = np.float32([[320, 240], [420, 240], [320, 340], [320, 220]])

ok, rvec, tvec = cv2.solvePnP(objp, imgp, K, None)
print('求解成功:', ok)
print('旋转向量:', rvec.ravel(), '平移:', tvec.ravel())
```

## Pose Estimation（姿态估计）

姿态估计是求解物体/相机在三维空间中的旋转与平移。PnP 是其中一种（点对应求解），还有用 ArUco 标记、棋盘格、关键点求解位姿。得到 rvec/tvec 后可用 Rodrigues 转旋转矩阵，再 projectPoints 把 3D 点反投影回图像验证。

```text
姿态估计要点：
1. 位姿 = 旋转 R + 平移 t（相对某坐标系）
2. Rodrigues —— 旋转向量 ↔ 旋转矩阵互转
3. 验证 —— projectPoints 反投影，看与真实像素点误差
```

```python
import cv2
import numpy as np

K = np.array([[500, 0, 320], [0, 500, 240], [0, 0, 1]], dtype=np.float64)
objp = np.float32([[0, 0, 0], [1, 0, 0], [0, 1, 0], [0, 0, 1]])
imgp = np.float32([[320, 240], [420, 240], [320, 340], [320, 220]])

ok, rvec, tvec = cv2.solvePnP(objp, imgp, K, None)
R, _ = cv2.Rodrigues(rvec)              # 旋转向量 → 旋转矩阵
proj, _ = cv2.projectPoints(objp, rvec, tvec, K, None)   # 反投影验证
err = np.linalg.norm(proj.reshape(-1, 2) - imgp, axis=1).mean()
print(f'反投影平均误差: {err:.3f} 像素')
```

## 应用场景实战

### 场景一：文档透视校正（四角点 + 单应）

```python
import cv2
import numpy as np

# 模拟一张拍歪的文档，四个角点不是标准矩形
img = np.zeros((300, 400, 3), dtype=np.uint8)
cv2.rectangle(img, (50, 50), (350, 250), (255, 255, 255), 3)

# 检测到的四个角点（拍歪了）
src = np.float32([[50, 60], [350, 50], [320, 250], [70, 240]])
dst = np.float32([[0, 0], [400, 0], [400, 300], [0, 300]])   # 校正到正面矩形
M = cv2.getPerspectiveTransform(src, dst)
corrected = cv2.warpPerspective(img, M, (400, 300))
print('校正后尺寸:', corrected.shape)
```

### 场景二：单目测距（已知物体尺寸 + 内参）

```python
import cv2
import numpy as np

# 已知相机焦距 f 和物体真实宽度 W，量出图像里宽度 w，估距离
f = 500.0            # 焦距（像素）
W_real = 0.2         # 物体真实宽度 20cm
w_pixels = 100.0     # 图像中物体宽度 100 像素
distance = f * W_real / w_pixels
print(f'估计距离: {distance:.2f} 米')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 标定棋盘格要多角度、覆盖图像边缘，标定才准
2. 单应/基础矩阵估计用 RANSAC，匹配点有外点时也稳
3. 任何精确测量前先 undistort 去畸变，否则边缘误差大
4. solvePnP 用多点 + SOLVEPNP_ITERATIVE 或 EPNP，比 P3P 稳
5. 立体测距基线越远测越远越准，但匹配难度上升，权衡
6. 验证位姿用 projectPoints 反投影看误差，别只看求解成功

### 踩坑记录

```text
坑 1：findHomography 点少于 4 对报错
结论：给 3 对点求解单应，直接抛异常。
原因：单应矩阵 8 自由度，最少要 4 对不共线点。
解法：保证 >= 4 对匹配点，RANSAC 场景给更多。

坑 2：warpPerspective 目标尺寸设错导致裁剪
结论：校正后的图被裁掉一部分，内容不完整。
原因：dst 尺寸小于变换后内容范围，超出部分被切掉。
解法：先算四个源角点变换后的位置，取包围范围作为输出尺寸。

坑 3：solvePnP 忘了给内参
结论：用默认单位矩阵当内参，解出的位姿完全错误。
原因：PnP 依赖内参把像素转成归一化坐标，内参错全错。
解法：先标定拿真实 K，再传给 solvePnP。

坑 4：畸变系数和标定内参不配套
结论：undistort 后图像反而更歪。
原因：用了别的相机/分辨率的畸变系数，K 和 dist 不匹配。
解法：畸变系数和 K 必须来自同一次标定，且分辨率一致。

坑 5：视差图当深度图直接算
结论：把视差（disparity）当成距离，近远全反。
原因：深度 Z = f*B/disparity，视差与深度成反比。
解法：按公式换算成深度，或读深度相机的 depth 通道。
```
