## 概述

特征点是图像里稳定、可重复定位的「关键点」——角点、斑点等局部极值。检测器负责找点，描述子负责把点周围编码成可比较的向量，匹配器负责在两张图之间建立对应。它们是图像拼接、SLAM、物体识别、3D 重建的基石，选哪个特征取决于对速度、尺度/旋转不变性、专利的取舍。

```text
特征点流水线三环节：
1. 检测器 —— Harris / FAST / SIFT / SURF / BRISK / AKAZE，找关键点
2. 描述子 —— BRIEF / ORB / SIFT / SURF，编码邻域成向量
3. 匹配器 —— BFMatcher / FLANN，建立点对应
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
orb = cv2.ORB_create()
kp = orb.detect(img, None)
kp, des = orb.compute(img, kp)
print('关键点数:', len(kp), '描述子形状:', des.shape)
```

## Harris（角点检测）

Harris 是经典的角点检测器：在窗口内计算灰度变化的二阶矩矩阵，用其特征值判断角点/边缘/平坦区——两个方向都变化大就是角点。它只检测（不生成描述子）、对旋转有一定不变性、对尺度不敏感，常用作其他特征检测器的预处理或做角点定位。

```text
Harris 判定准则：
1. 两个方向灰度都变化大 → 角点
2. 只一个方向变化 → 边缘
3. 都不变化 → 平坦区
响应 R = det(M) - k * trace(M)²，M 是梯度二阶矩矩阵
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)

gray = np.float32(img)
corners = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)
# 角点响应大于最大值的 1% 视为角点
corner_mask = corners > 0.01 * corners.max()
print('检测到角点像素数:', np.sum(corner_mask))   # 矩形四角附近
```

## FAST

FAST（Features from Accelerated Segment Test）是速度最快的角点检测器之一：以候选点为圆心比较圆周上 16 个像素，若有连续 n 个（通常 9）都比中心亮或暗，则是角点。它只检测、无方向无尺度，通常配 ORB 一起用，是实时 SLAM 的首选。

```text
FAST 判定：
1. 比较圆周 16 个像素与中心点灰度
2. 连续 9 个更亮或更暗 → 角点
3. 极快 —— 只做像素比较，实时友好
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100), dtype=np.uint8)
cv2.rectangle(img, (30, 30), (70, 70), 255, -1)

fast = cv2.FastFeatureDetector_create(threshold=10, nonmaxSuppression=True)
kp = fast.detect(img, None)
print('FAST 角点数:', len(kp))
```

## ORB

ORB 是 FAST 检测器 + BRIEF 描述子的组合，并补上了方向和尺度（用图像金字塔），是免费、快速、有旋转不变性的实用特征。它是 SIFT/SURF 的开源替代，实时性极好，是 SLAM（如 ORB-SLAM）、手机端特征匹配的主力。

```text
ORB 组成：
1. 检测 —— FAST 角点 + 方向（灰度质心法）
2. 描述 —— BRIEF 二进制描述子（256 bit）
3. 优点 —— 免费、快、旋转不变；缺点 —— 尺度不变性弱于 SIFT
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
orb = cv2.ORB_create(nfeatures=500)
kp, des = orb.detectAndCompute(img, None)
print('关键点数:', len(kp), '描述子:', des.shape)   # (n, 32) uint8，32*8=256 bit
```

## SIFT

SIFT（Scale-Invariant Feature Transform）用高斯差分（DoG）金字塔在尺度空间找极值作为关键点，再算 128 维浮点描述子，具有尺度和旋转不变性，对光照、视角也有鲁棒性，是传统特征的黄金标准。缺点是慢、且曾受专利保护（现已过期，OpenCV 主版本已开源）。

```text
SIFT 四步：
1. 尺度空间极值 —— DoG 金字塔找候选关键点
2. 关键点定位 —— 亚像素精化、剔除低对比度/边缘点
3. 方向分配 —— 梯度直方图定主方向
4. 描述子 —— 16 个 4x4 邻域的 8 方向梯度 → 128 维
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
sift = cv2.SIFT_create()
kp, des = sift.detectAndCompute(img, None)
print('关键点数:', len(kp), '描述子:', None if des is None else des.shape)
# 若输出 None：图像纹理太少，SIFT 找不到关键点
```

## SURF（原理与使用限制）

SURF 是 SIFT 的加速版：用盒式滤波近似高斯、用 Haar 小波响应加速，速度比 SIFT 快数倍，也有尺度/旋转不变性，描述子 64 或 128 维。核心限制是它受专利保护，OpenCV 主分支默认不包含，需用 opencv-contrib-python 并可能被移到 legacy 模块。

```text
SURF 要点：
1. 原理 —— 盒式滤波 + 积分图加速，近似 SIFT
2. 描述子 —— 64/128 维浮点，Haar 小波响应
3. 限制 —— 专利保护，主分支不含，需 contrib 包且 API 在变
```

```python
# SURF 在 opencv-contrib-python 中，且可能位于 xfeatures2d
try:
    surf = cv2.xfeatures2d.SURF_create(400)
    print('SURF 可用（需 opencv-contrib-python）')
except AttributeError:
    print('SURF 不可用：专利保护，主分支不包含，建议改用 ORB/SIFT')
```

## BRIEF

BRIEF 只生成二进制描述子（不做检测）：在关键点邻域随机采样若干对像素，比较灰度大小得到一串 0/1 位。二进制描述子用汉明距离（异或）匹配，速度极快、存储省，但没有旋转和尺度不变性（常配 ORB 补方向）。

```text
BRIEF 特点：
1. 二进制描述子 —— 随机像素对比较，产出 128/256/512 bit
2. 匹配快 —— 汉明距离（异或 + 计数）
3. 局限 —— 无旋转/尺度不变性，需配合方向估计
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
# 用 FAST 检测 + BRIEF 描述
fast = cv2.FastFeatureDetector_create()
brief = cv2.xfeatures2d.BriefDescriptorExtractor_create() if hasattr(cv2, 'xfeatures2d') else None
kp = fast.detect(img, None)
# brief 需 contrib；无 contrib 时用 ORB 的 BRIEF 变体
orb = cv2.ORB_create()
kp2, des = orb.compute(img, kp)
print('BRIEF 风格二进制描述子:', des.shape)
```

## BRISK

BRISK 是另一种二进制特征：检测用尺度空间 FAST，描述子用同心圆采样模式的像素对比较，天然具有尺度和旋转不变性，速度介于 ORB 和 SIFT 之间。适合需要尺度不变又要求比 SIFT 快的场景。

```text
BRISK 特点：
1. 检测 —— 多尺度 FAST（尺度不变）
2. 描述 —— 同心圆采样，二进制描述子
3. 优势 —— 免费、有尺度旋转不变、比 SIFT 快
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
brisk = cv2.BRISK_create()
kp, des = brisk.detectAndCompute(img, None)
print('BRISK 关键点:', len(kp), '描述子:', des.shape)   # (n, 64) 512 bit
```

## AKAZE

AKAZE 是 KAZE 的加速版，用非线性扩散滤波（而非高斯）构建尺度空间，能更好地保留边缘和细节，对模糊、噪声更鲁棒。它免费、有尺度旋转不变性，二进制描述子（MLDB），质量常优于 ORB，是高质量实时特征的代表。

```text
AKAZE 特点：
1. 尺度空间 —— 非线性扩散（保边更好）
2. 描述子 —— MLDB 二进制，快
3. 优势 —— 模糊/噪声下鲁棒，质量高于 ORB
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
akaze = cv2.AKAZE_create()
kp, des = akaze.detectAndCompute(img, None)
print('AKAZE 关键点:', len(kp), '描述子:', des.shape)   # (n, 61)
```

## Feature Matching（特征匹配）

特征匹配在两幅图的描述子间建立对应：对图 1 的每个描述子，在图 2 里找最相似（距离最小）的描述子。暴力匹配找最近邻，FLANN 用近似索引加速。为过滤错误匹配，常用 Lowe's ratio test（最近邻距离 < 0.75 * 次近邻距离）或 RANSAC 几何验证。

```text
匹配与过滤：
1. 距离 —— 二进制用汉明距离，浮点用欧氏/L2
2. Lowe's ratio —— d_best < 0.75 * d_second，剔除歧义匹配
3. 几何验证 —— RANSAC 估计单应/基础矩阵剔外点
```

```python
import cv2
import numpy as np

# 两张图用 ORB 匹配
img1 = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
img2 = img1.copy()    # 同一张图，匹配应全部正确

orb = cv2.ORB_create()
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
print('匹配数:', len(matches))
```

## BFMatcher

BFMatcher 是暴力匹配器：对每个查询描述子，遍历所有训练描述子算距离取最近。简单、精确，但复杂度 O(n·m)，点多了很慢。参数 normType 要匹配描述子类型——二进制描述子用 NORM_HAMMING，浮点描述子（SIFT/SURF）用 NORM_L2。

```text
BFMatcher 要点：
1. 暴力 —— 全量距离比较，最准但最慢
2. normType —— HAMMING 配二进制，L2 配浮点
3. crossCheck=True —— 双向匹配，过滤单向误匹配
```

```python
import cv2
import numpy as np

des1 = np.random.randint(0, 2, (10, 32), dtype=np.uint8)   # 10 个 256bit 描述子
des2 = des1.copy()

bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
print('暴力匹配数:', len(matches))   # 10，crossCheck 保证一一对应
```

## FLANN

FLANN（Fast Library for Approximate Nearest Neighbors）用近似最近邻索引（KD-tree、KMeans 树）加速匹配，点很多时比暴力匹配快几个量级，代价是可能不是精确最近邻。二进制描述子用 LSH 索引，浮点描述子用 KD-tree，参数需按描述子类型配置。

```text
FLANN 要点：
1. 近似 —— 用索引结构加速，牺牲少量精度换速度
2. 索引 —— 浮点用 KD-tree，二进制用 LSH
3. 适用 —— 大规模点集匹配（成千上万关键点）
```

```python
import cv2
import numpy as np

# 浮点描述子用 FLANN（KD-tree 索引）
des1 = np.random.rand(100, 128).astype(np.float32)
des2 = des1.copy()

index_params = dict(algorithm=1, trees=5)          # KD-tree
search_params = dict(checks=50)
flann = cv2.FlannBasedMatcher(index_params, search_params)
matches = flann.knnMatch(des1, des2, k=2)          # 每个点找 2 近邻
print('FLANN 匹配点数:', len(matches))
```

## 应用场景实战

### 场景一：图像拼接（特征匹配 + RANSAC 单应）

```python
import cv2
import numpy as np

# 两张有重叠的图，用 ORB 匹配 + 单应拼接（示意）
img1 = np.random.randint(0, 256, (300, 400), dtype=np.uint8)
img2 = img1[:, 100:].copy()   # 右移重叠

orb = cv2.ORB_create()
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)

bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
matches = sorted(matches, key=lambda m: m.distance)

if len(matches) >= 4:
    src = np.float32([kp1[m.queryIdx].pt for m in matches])
    dst = np.float32([kp2[m.trainIdx].pt for m in matches])
    H, mask = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
    print('匹配数:', len(matches), '单应内点:', int(mask.sum()))
```

### 场景二：模板查找（SIFT + Lowe's ratio test）

```python
import cv2
import numpy as np

# 在大图里找小图（SIFT 匹配 + ratio test）
template = np.random.randint(0, 256, (50, 50), dtype=np.uint8)
scene = np.random.randint(0, 256, (200, 200), dtype=np.uint8)
scene[50:100, 50:100] = template   # 把模板贴进场景

sift = cv2.SIFT_create()
kp1, des1 = sift.detectAndCompute(template, None)
kp2, des2 = sift.detectAndCompute(scene, None)

bf = cv2.BFMatcher()
knn = bf.knnMatch(des1, des2, k=2)
good = [m for m, n in knn if m.distance < 0.75 * n.distance]
print('Lowe ratio test 后匹配数:', len(good))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 实时场景用 ORB（快、免费），精度优先用 SIFT 或 AKAZE
2. 二进制描述子（ORB/BRIEF/BRISK）用 NORM_HAMMING，浮点（SIFT/SURF）用 NORM_L2
3. 匹配后必做 ratio test 或 RANSAC，裸最近邻误匹配很多
4. 商业产品避开 SURF（专利），用 ORB/SIFT/AKAZE 替代
5. 特征数量多、追求速度用 FLANN，点数少用 BFMatcher 精确
6. 匹配前确认两张图描述子维度一致（同一种特征）

### 踩坑记录

```text
坑 1：SIFT 检测不到关键点返回 None
结论：des 是 None，后续 des.shape 报 AttributeError。
原因：图像纹理太平（纯色/随机噪声），SIFT 找不到稳定极值。
解法：先判断 des is not None，或换纹理丰富的图，或调低 contrastThreshold。

坑 2：二进制和浮点描述子用错距离
结论：ORB 描述子用 NORM_L2 匹配，结果全乱。
原因：二进制描述子要用汉明距离，L2 距离没意义。
解法：BFMatcher 二进制用 cv2.NORM_HAMMING，浮点用 cv2.NORM_L2。

坑 3：SURF 用 cv2.SURF_create 报 AttributeError
结论：主分支 OpenCV 里根本没有 SURF_create。
原因：SURF 受专利保护，只在 opencv-contrib 的 xfeatures2d 里。
解法：改用 ORB/SIFT，或装 contrib 包并确认模块存在。

坑 4：knnMatch 后直接当单点匹配用
结论：把 (m, n) 元组当单匹配对象，取 .queryIdx 报错。
原因：knnMatch 返回列表的列表，每个元素是 k 个 DMatch。
解法：先 ratio test 拆出 (m, n)，取 m 才是最优匹配。

坑 5：FLANN 二进制描述子用默认 KD-tree 索引
结论：FLANN 配 ORB 二进制描述子报错或慢。
原因：KD-tree 索引是为浮点描述子设计的，二进制要用 LSH。
解法：二进制描述子 index_params 用 algorithm=6（LSH）。
```
