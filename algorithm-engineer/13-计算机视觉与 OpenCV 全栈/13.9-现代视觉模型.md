## 概述

现代视觉模型经历了「卷积独大 → 检测框架细化 → Transformer 崛起 → 基础模型泛化」的演进。CNN 奠定了特征提取的地基，ResNet 用残差连接解决了深度网络退化，EfficientNet 用复合缩放把效率推到极致；检测侧有 YOLO/SSD（单阶段）与 Faster R-CNN/Mask R-CNN（两阶段）两条主线；DETR 把检测变成了集合预测；Vision Transformer/Swin Transformer 让 Transformer 全面进入视觉；Segment Anything 与 CLIP 则开启了「视觉基础模型」的泛化时代。

```text
现代视觉模型的演进脉络：
1. 骨干网络 —— CNN → ResNet → EfficientNet → ViT → Swin
2. 目标检测 —— 两阶段 Faster R-CNN / 单阶段 YOLO、SSD → DETR
3. 实例分割 —— Mask R-CNN → Segment Anything
4. 视觉-语言 —— CLIP 打通图文联合表征
5. 趋势 —— 卷积 → Transformer，专用模型 → 基础模型
```


## CNN

CNN（卷积神经网络）是视觉深度学习的基石，用「局部感受野 + 权值共享 + 池化」三大机制，比全连接网络参数少得多、且天然保留空间结构。一个典型 CNN 由若干卷积层（提特征）、激活层（非线性）、池化层（降维）堆叠，最后接全连接层分类。理解卷积的滑动计算、感受野、通道是理解所有现代视觉模型的前提。

```text
CNN 三大机制：
1. 局部感受野 —— 每个神经元只看局部区域，符合图像局部性
2. 权值共享 —— 同一卷积核扫遍全图，参数与位置无关
3. 池化 —— 下采样降低分辨率、扩大感受野、增加平移不变性

核心超参：卷积核大小、步长、padding、输出通道数
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Linear(128 * 4 * 4, 128), nn.ReLU(), nn.Linear(128, num_classes),
        )
    def forward(self, x):
        return self.classifier(self.features(x))

model = CNN()
x = torch.randn(2, 3, 32, 32)
print(f'输出: {model(x).shape}')   # [2, 10]
```

## ResNet

ResNet（残差网络）用「残差连接（skip connection）」解决了深层网络退化问题：与其让网络直接学 H(x)，不如让它学残差 F(x) = H(x) - x。跳跃连接让梯度可以「抄近路」回传，从而训练 50、101、甚至 152 层的深度网络。残差块是它的基本单元，也是几乎所有后续骨干（含 ViT 之外的卷积系）的标准组件。

```text
残差块核心思想：
1. 恒等映射 —— y = F(x) + x，让网络至少能学会恒等
2. 梯度直通 —— 反向传播时梯度可沿跳跃连接无衰减回传
3. Bottleneck —— 1x1 降维 + 3x3 卷积 + 1x1 升维，降低计算量
4. 解决退化 —— 深层网络不再比浅层更差
```

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    """ResNet 基本残差块"""
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels),
            )
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)         # 残差连接：F(x) + x
        return torch.relu(out)

block = ResidualBlock(64, 64)
x = torch.randn(2, 64, 32, 32)
print(f'残差块输出: {block(x).shape}')
```

## EfficientNet

EfficientNet 用「复合缩放（compound scaling）」统一缩放网络的深度、宽度、分辨率三个维度，在同等计算量下显著超越之前的模型。它提出：深度、宽度、分辨率三者应协同按固定系数放大，而非单独调某一维。B0 是基线，B1~B7 逐步放大。核心模块是移动端友好的 MBConv（Mobile Inverted Bottleneck + SE 注意力）。

```text
复合缩放公式：
depth = α^φ, width = β^φ, resolution = γ^φ
且 α·β²·γ² ≈ 2（每级放大约 2 倍计算量）

特点：
1. 三个维度协同缩放，比单独加深/加宽更高效
2. MBConv + SE 通道注意力模块
3. B0~B7 覆盖从移动端到服务器多档算力
```

```python
import torch
import torch.nn as nn

class SEBlock(nn.Module):
    """Squeeze-and-Excitation 通道注意力，EfficientNet 的核心组件"""
    def __init__(self, channels, reduction=4):
        super().__init__()
        self.fc = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(channels, channels // reduction),
            nn.ReLU(),
            nn.Linear(channels // reduction, channels),
            nn.Sigmoid(),
        )
    def forward(self, x):
        scale = self.fc(x).unsqueeze(-1).unsqueeze(-1)   # [B, C, 1, 1]
        return x * scale

x = torch.randn(2, 32, 16, 16)
print(f'SE 注意力输出: {SEBlock(32)(x).shape}')
```

## YOLO

YOLO（You Only Look Once）是单阶段检测的开山之作：把检测当作回归问题，一次前向直接输出所有框的坐标和类别，速度极快（可达实时乃至几百 FPS）。它把图像划分成 S×S 网格，每个网格预测若干候选框，一次性回归完成，省去了「候选区域生成」这一步。历经 YOLOv1 到 YOLOv8/v9/v10 多代演进，一直是工业界实时检测的首选。

```text
YOLO 的核心思想：
1. 单阶段 —— 一次前向直接出框 + 类别，无候选区域阶段
2. 网格划分 —— 图像分成 S×S 网格，每个格子负责中心落在其中的目标
3. 端到端回归 —— 框坐标 + 置信度 + 类别概率一起回归
4. 演进 —— v2 锚框/BN、v3 多尺度、v5 工程化、v8 多任务、v9 更优结构
```

```python
import torch

# YOLO 损失的核心组成示意（分类 + 置信度 + 框回归）
def yolo_loss(pred_cls, pred_conf, pred_box, gt_cls, gt_box, mask):
    # mask 标记哪些网格有目标
    cls_loss = torch.nn.functional.cross_entropy(pred_cls.reshape(-1, pred_cls.shape[-1]), gt_cls.reshape(-1))
    conf_loss = torch.nn.functional.binary_cross_entropy(pred_conf, mask.float())
    # 框回归用 MSE 或 CIoU，此处简化为 MSE
    box_loss = torch.nn.functional.mse_loss(pred_box, gt_box)
    return cls_loss + conf_loss + box_loss

loss = yolo_loss(torch.randn(13, 13, 80), torch.rand(13, 13, 1),
                 torch.rand(13, 13, 1, 4), torch.randint(0, 80, (13, 13)),
                 torch.rand(13, 13, 1, 4), torch.rand(13, 13, 1))
print(f'YOLO 总损失: {loss.item():.3f}')
```

## SSD

SSD（Single Shot MultiBox Detector）是另一个经典单阶段检测器：在多个不同分辨率的特征图上预设不同长宽比的默认框（default box / anchor），每个特征层直接预测框偏移和类别。多尺度特征图让它比 YOLOv1 更好地检测小目标。核心贡献是「多尺度特征图 + 多长宽比 anchor」的单次前向检测。

```text
SSD 的核心要点：
1. 多尺度特征图 —— 在 6 个不同尺度的特征层上分别检测
2. 默认框 —— 每层预设不同长宽比（1:1、1:2、2:1 等）的 anchor
3. 单次前向 —— 各层同时回归偏移 + 分类
4. 小目标 —— 高分辨率浅层特征图负责小目标
```

```python
import torch
import torch.nn as nn

def ssd_anchor_boxes(feature_map_size, scales, aspect_ratios):
    """生成 SSD 某层的默认框（简化：中心点 + 宽高）"""
    anchors = []
    fm_h, fm_w = feature_map_size
    for i in range(fm_h):
        for j in range(fm_w):
            cx, cy = (j + 0.5) / fm_w, (i + 0.5) / fm_h
            for s in scales:
                anchors.append([cx, cy, s, s])                       # 1:1 正方形
                for ar in aspect_ratios:
                    anchors.append([cx, cy, s * (ar ** 0.5), s / (ar ** 0.5)])
    return torch.tensor(anchors)

anchors = ssd_anchor_boxes((38, 38), [0.1], [2.0, 0.5])
print(f'单层 anchor 数量: {anchors.shape[0]}')   # 38*38*3
```

## Faster R-CNN

Faster R-CNN 是两阶段检测的集大成者，核心贡献是 RPN（Region Proposal Network）：用可学习的网络生成候选区域，替代了之前 Selective Search 这类外部算法，实现了端到端训练。流程是：骨干提取特征 → RPN 生成候选框 → RoI Pooling 统一尺寸 → 分类 + 回归。精度高、速度比单阶段慢，适合精度优先的场景。

```text
两阶段检测流程：
1. 骨干 —— CNN 提取整图特征
2. RPN —— 在特征图上滑窗，回归 anchor 偏移，输出候选框
3. RoI Pooling —— 把不同大小的候选框特征池化成固定尺寸
4. 检测头 —— 对每个候选框做分类 + 框回归

RPN 的 anchor：多尺度多长宽比预设框，9 个/位置
```

```python
import torch
import torch.nn as nn

class RPNHead(nn.Module):
    """RPN 头示意：输出每个 anchor 的 objectness + 框偏移"""
    def __init__(self, in_channels=256, num_anchors=9):
        super().__init__()
        self.conv = nn.Conv2d(in_channels, in_channels, 3, padding=1)
        self.cls_logits = nn.Conv2d(in_channels, num_anchors * 2, 1)     # 有/无目标
        self.bbox_pred = nn.Conv2d(in_channels, num_anchors * 4, 1)      # dx,dy,dw,dh
    def forward(self, feat):
        h = torch.relu(self.conv(feat))
        return self.cls_logits(h), self.bbox_pred(h)

rpn = RPNHead()
feat = torch.randn(2, 256, 50, 50)
cls_logits, bbox = rpn(feat)
print(f'RPN 分类: {cls_logits.shape}, 回归: {bbox.shape}')
```

## Mask R-CNN

Mask R-CNN 在 Faster R-CNN 上扩展出实例分割能力：在分类、回归两个头之外，新增一个「掩码头（mask branch）」，对每个候选框输出逐像素的二值掩码。同时用 RoIAlign 替代 RoI Pooling，用双线性插值消除量化误差，这是它对小目标分割精度提升的关键。检测 + 分割一体化，是实例分割的标杆。

```text
Mask R-CNN 相对 Faster R-CNN 的两处关键改动：
1. RoIAlign —— 双线性插值替代取整量化，避免位置误差
2. 掩码分支 —— 每个 RoI 额外输出 K 类逐像素掩码（K 通道 sigmoid）

多任务损失 = 分类损失 + 框回归损失 + 掩码损失（逐像素 BCE）
```

```python
import torch
import torch.nn.functional as F

def roi_align(feature, rois, output_size=7):
    """RoIAlign 简化示意：双线性插值池化到固定尺寸"""
    # 简化实现：对每个 RoI 用双线性采样（真实用 torchvision.ops.roi_align）
    num_rois = rois.shape[0]
    pool = torch.nn.AdaptiveAvgPool2d((output_size, output_size))
    pooled = []
    for i in range(num_rois):
        x1, y1, x2, y2 = rois[i].int()
        crop = feature[0, :, y1:y2 + 1, x1:x2 + 1]
        pooled.append(pool(crop))
    return torch.stack(pooled)

feat = torch.randn(1, 256, 50, 50)
rois = torch.tensor([[10.0, 10.0, 40.0, 40.0], [5.0, 5.0, 30.0, 30.0]])
pooled = roi_align(feat, rois)
print(f'RoIAlign 输出: {pooled.shape}')   # [2, 256, 7, 7]
```

## DETR

DETR（Detection Transformer）把目标检测重新定义成「集合预测」问题：用 Transformer 编码器-解码器 + 可学习的目标查询（object query），一次性输出固定数量的预测（框 + 类别），并用匈牙利算法做预测与真值的最优匹配。它彻底去掉了 anchor、NMS 等手工组件，是检测范式从「稠密预测 + 后处理」到「端到端集合预测」的转折点。

```text
DETR 的核心设计：
1. 集合预测 —— 输出固定 N 个预测，N 远大于真实目标数
2. 目标查询 —— 可学习的 query，每个 query 对应一个目标
3. 匈牙利匹配 —— 预测与真值做二分图最优匹配（不是简单排序）
4. 无 NMS —— 端到端，去掉了 anchor 和 NMS 后处理
5. 损失 —— 匹配后的分类损失 + 框 L1 + GIoU
```

```python
import torch

def hungarian_matching(cost_matrix):
    """匈牙利算法示意：用 scipy 解最优匹配"""
    from scipy.optimize import linear_sum_assignment
    row_ind, col_ind = linear_sum_assignment(cost_matrix)
    return row_ind, col_ind

# 简化：3 个预测 vs 2 个真值，cost 为「损失越小越好」
cost = torch.tensor([[0.2, 0.9, 0.8],
                     [0.7, 0.1, 0.6]])   # [GT, 预测]
row_ind, col_ind = hungarian_matching(cost.numpy())
print(f'最优匹配: GT {row_ind} -> 预测 {col_ind}')   # 0->0, 1->1
```

## Vision Transformer

Vision Transformer（ViT）把 Transformer 直接搬进视觉：把图像切成 16×16 的 patch，每个 patch 展平成向量当作「视觉词元（token）」，加上位置编码后送入标准 Transformer 编码器。它在足够大的数据上预训练后，能在分类上超越卷积网络。ViT 证明了「Transformer + 大规模数据」可以替代卷积的归纳偏置，是视觉 Transformer 浪潮的开端。

```text
ViT 的流程：
1. 切 patch —— 224x224 图像切成 16x16 patch，共 196 个 token
2. 线性投影 —— 每个 patch 展平后线性映射到 D 维 embedding
3. 位置编码 —— 加可学习位置嵌入，保留空间信息
4. Transformer —— 标准编码器堆叠，用 class token 输出分类
5. 大预训练 —— 在 ImageNet-21k / JFT-300M 上预训练才优于 CNN
```

```python
import torch
import torch.nn as nn

def img_to_patches(img, patch_size=16):
    """把图像切成 patch 并展平为 token 序列"""
    b, c, h, w = img.shape
    n = (h // patch_size) * (w // patch_size)
    patches = img.unfold(2, patch_size, patch_size).unfold(3, patch_size, patch_size)
    patches = patches.permute(0, 2, 3, 1, 4, 5).reshape(b, n, c * patch_size * patch_size)
    return patches

img = torch.randn(1, 3, 224, 224)
tokens = img_to_patches(img)
print(f'ViT token 序列: {tokens.shape}')   # [1, 196, 768]
```

## Swin Transformer

Swin Transformer 是让 Transformer 真正高效进入视觉的里程碑：它用「分层结构 + 窗口注意力（shifted window）」解决了 ViT 的两个痛点——计算量随分辨率平方增长、以及缺少多尺度特征。窗口内做自注意力大幅降低复杂度，移动窗口（shifted window）让相邻窗口能交换信息。分层结构天然产出多尺度特征图，因此既能做分类，也能无缝用于检测、分割。

```text
Swin 的核心机制：
1. 窗口注意力 —— 只在 7x7 窗口内做自注意力，复杂度线性
2. 移动窗口 —— 相邻层窗口错位，实现跨窗口信息交互
3. 分层结构 —— 4 个 stage 逐步降采样，产出多尺度特征
4. 复杂度 —— 从 ViT 的 O(N²) 降到 O(N)，支持高分辨率
```

```python
import torch
import torch.nn as nn

class WindowAttention(nn.Module):
    """窗口多头自注意力的简化示意"""
    def __init__(self, dim, num_heads=4):
        super().__init__()
        self.num_heads = num_heads
        self.qkv = nn.Linear(dim, dim * 3)
        self.proj = nn.Linear(dim, dim)
    def forward(self, x):
        # x: [B*num_windows, window_pixels, dim]
        b, n, d = x.shape
        qkv = self.qkv(x).reshape(b, n, 3, self.num_heads, d // self.num_heads)
        q, k, v = qkv.unbind(2)                       # 每个 [b, n, heads, head_dim]
        q, k, v = q.transpose(1, 2), k.transpose(1, 2), v.transpose(1, 2)   # [b, heads, n, head_dim]
        attn = (q @ k.transpose(-2, -1)) * (d // self.num_heads) ** -0.5    # [b, heads, n, n]
        attn = attn.softmax(dim=-1)
        out = (attn @ v).transpose(1, 2).reshape(b, n, d)                   # [b, n, d]
        return self.proj(out)

wa = WindowAttention(dim=96)
x = torch.randn(8, 49, 96)   # 8 个窗口 × 7x7=49 像素
print(f'窗口注意力输出: {wa(x).shape}')
```

## Segment Anything

Segment Anything（SAM）是图像分割的基础模型：给定一个提示（点、框、文本），就能分割出对应的目标掩码，且能零样本泛化到没见过的类别。它由三部分组成：图像编码器（ViT 系）、提示编码器、掩码解码器，在海量「SA-1B」数据集（1100 万图、10 亿掩码）上训练。SAM 让「分割」从「为每个数据集训练专用模型」变成了「一个通用模型 + 提示交互」。

```text
SAM 的三组件架构：
1. 图像编码器 —— 重 ViT 骨干，提取图像 embedding（计算最贵）
2. 提示编码器 —— 编码点/框/掩码/文本提示
3. 掩码解码器 —— 融合图像与提示 embedding，输出掩码

特点：提示驱动、零样本、海量数据训练、可交互式分割
```

```python
import torch

def mask_decoder_forward(image_emb, prompt_emb):
    """掩码解码器示意：图像 embedding 与提示 embedding 融合输出掩码"""
    # 简化：点积注意力融合
    fused = image_emb * prompt_emb.unsqueeze(-1).unsqueeze(-1)
    mask_logits = fused.mean(dim=1, keepdim=True)   # 聚合到单通道
    return torch.sigmoid(mask_logits)

image_emb = torch.randn(1, 256, 64, 64)   # 图像编码器输出
prompt_emb = torch.randn(1, 256)          # 点/框提示编码
mask = mask_decoder_forward(image_emb, prompt_emb)
print(f'SAM 掩码输出: {mask.shape}')   # [1, 1, 64, 64]
```

## CLIP

CLIP（Contrastive Language-Image Pretraining）用「对比学习」把图像和文本拉进同一个语义空间：用 4 亿「图文对」训练，让匹配的图文 embedding 靠近、不匹配的远离。它带来两个革命性能力：零样本分类（用文本描述类别，无需微调）和图文联合表征（支撑文搜图、图生文等下游）。CLIP 是视觉-语言多模态的奠基之作。

```text
CLIP 的核心设计：
1. 双塔结构 —— 图像编码器 + 文本编码器，分别输出 embedding
2. 对比学习 —— 拉近匹配图文对，推远不匹配对（InfoNCE 损失）
3. 零样本分类 —— 把类别名当文本提示，算图文相似度即可分类
4. 数据规模 —— 4 亿图文对，海量弱监督是关键
```

```python
import torch
import torch.nn.functional as F

def clip_contrastive_loss(image_emb, text_emb, temperature=0.07):
    """CLIP 对比学习损失（InfoNCE）"""
    image_emb = F.normalize(image_emb, dim=-1)
    text_emb = F.normalize(text_emb, dim=-1)
    logits = image_emb @ text_emb.t() / temperature   # [B, B] 相似度矩阵
    labels = torch.arange(image_emb.shape[0])
    loss_i = F.cross_entropy(logits, labels)          # 图像→文本
    loss_t = F.cross_entropy(logits.t(), labels)      # 文本→图像
    return (loss_i + loss_t) / 2

img_emb = torch.randn(4, 512)
txt_emb = torch.randn(4, 512)
print(f'CLIP 对比损失: {clip_contrastive_loss(img_emb, txt_emb).item():.3f}')
```

```python
# CLIP 零样本分类示意：算图像与每个类别文本的相似度
import torch
import torch.nn.functional as F

def zero_shot_classify(image_emb, class_text_embs):
    image_emb = F.normalize(image_emb, dim=-1)
    class_text_embs = F.normalize(class_text_embs, dim=-1)
    logits = image_emb @ class_text_embs.t()
    return logits.softmax(dim=-1)

image_emb = torch.randn(1, 512)
class_text_embs = torch.randn(5, 512)   # 5 个类别的文本描述
print(f'零样本分类概率: {zero_shot_classify(image_emb, class_text_embs)}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 骨干选型按算力：移动端 MobileNet/EfficientNet-B0，服务器 ResNet-50/Swin-T，追求精度上 ViT 大模型
2. 实时检测用 YOLO，精度优先用 Faster R-CNN，需要分割用 Mask R-CNN
3. 迁移学习先冻结骨干微调头，数据足够再解冻全局微调，学习率设骨干的 1/10
4. 用 ViT 前务必先在大规模数据上预训练，否则不如 ResNet（ViT 依赖数据量）
5. 高分辨率检测/分割优先 Swin 而非 ViT，窗口注意力更省算力
6. 零样本/开放类别任务直接上 CLIP、SAM 这类基础模型，避免重复标注

### 踩坑记录

```text
坑 1：直接从头训练 ViT
结论：小数据集上 ViT 效果远不如 ResNet，甚至不收敛。
原因：ViT 缺乏卷积的归纳偏置，需要海量数据才能学到局部性。
解法：用 ImageNet-21k 预训练权重迁移，或小数据优先 CNN。

坑 2：Mask R-CNN 用 RoI Pooling 而非 RoIAlign
结论：小目标掩码错位、边缘锯齿，分割精度明显下降。
原因：RoI Pooling 两次取整量化，坐标误差随下采样放大。
解法：用 RoIAlign 双线性插值，保持亚像素精度。

坑 3：DETR 训练不收敛 / 收敛极慢
结论：前几十 epoch loss 很高，检测结果很差。
原因：集合预测 + 匈牙利匹配，需要大量 epoch 学 query。
解法：训练 epoch 拉到 300+，或用 Deformable DETR 加速收敛。

坑 4：CLIP 直接做细粒度分类
结论：对品种、型号等细粒度类别零样本效果差。
原因：对比学习学到的是粗粒度语义，文本描述区分度不足。
解法：用 prompt engineering 强化描述，或在下游数据上微调。

坑 5：YOLO 锚框（anchor）与数据分布不匹配
结论：自定义数据集（如小目标、长条目标）检测效果差。
原因：默认 anchor 尺寸针对 COCO，与自身数据尺度不匹配。
解法：用 K-Means 聚类生成适配数据的 anchor，或换 anchor-free 版本。
```
