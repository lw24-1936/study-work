## 概述

OpenCV（Open Source Computer Vision Library）是最主流的开源计算机视觉库，cv2 模块覆盖了图像/视频读写、颜色转换、几何变换到特征检测的完整链路。这篇讲的是最底层的那批 API——读写、显示、变换，它们是后续所有图像处理操作的地基，用得最频繁也最容易踩坑。

```text
OpenCV 基础的核心操作：
1. 读写 —— imread / imwrite / imshow 搞定单张图
2. 视频 —— VideoCapture / VideoWriter 搞定流
3. 转换 —— cvtColor 换颜色空间
4. 几何 —— resize / crop / rotate / flip / warp 改位置和尺寸
```

```python
import cv2
import numpy as np

# 最简链路：造图 → 写盘 → 读回 → 看形状
img = np.zeros((100, 100, 3), dtype=np.uint8)
cv2.imwrite('/tmp/_demo.png', img)
back = cv2.imread('/tmp/_demo.png')
print(back.shape)   # (100, 100, 3)
```

## cv2.imread

imread 从磁盘读入图像，返回 NumPy 数组。第二个参数 flags 控制读入模式：默认 IMREAD_COLOR（3 通道 BGR）、IMREAD_GRAYSCALE（灰度）、IMREAD_UNCHANGED（原样含 Alpha）。读不存在的路径不报错，返回 None——这是最常见的隐藏 bug。

```text
imread 的 flags：
1. cv2.IMREAD_COLOR = 1 —— 彩色 BGR（默认）
2. cv2.IMREAD_GRAYSCALE = 0 —— 单通道灰度
3. cv2.IMREAD_UNCHANGED = -1 —— 原样读入（含 Alpha 通道）
```

```python
import cv2

img_color = cv2.imread('/tmp/_demo.png')                # BGR
img_gray = cv2.imread('/tmp/_demo.png', cv2.IMREAD_GRAYSCALE)
img_raw = cv2.imread('/tmp/_demo.png', cv2.IMREAD_UNCHANGED)
print(img_color.shape, img_gray.shape, img_raw.shape)   # (100,100,3) (100,100) (100,100,3)

missing = cv2.imread('/tmp/_not_exist.png')
print(missing is None)   # True —— 路径错了也不报错
```

## cv2.imwrite

imwrite 把图像写到磁盘，根据文件后缀自动选编码格式（.png 无损、.jpg 有损压缩）。写 JPEG 时可用 IMWRITE_JPEG_QUALITY 参数控制质量（0~100）。返回 True/False 表示是否成功，常用来确认路径可写。

```text
imwrite 要点：
1. 后缀决定格式 —— .png 无损 / .jpg 有损 / .bmp 无压缩
2. JPEG 质量 —— [cv2.IMWRITE_JPEG_QUALITY, 90] 控制压缩率
3. 返回值 —— True 成功，False 失败（路径不存在/无权限）
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (200, 200, 3), dtype=np.uint8)
ok1 = cv2.imwrite('/tmp/_q90.jpg', img, [cv2.IMWRITE_JPEG_QUALITY, 90])
ok2 = cv2.imwrite('/tmp/_q10.jpg', img, [cv2.IMWRITE_JPEG_QUALITY, 10])
print(ok1, ok2)   # True True
import os
print(os.path.getsize('/tmp/_q90.jpg'), os.path.getsize('/tmp/_q10.jpg'))  # 质量低 → 体积小
```

## cv2.imshow

imshow 弹出窗口显示图像，配合 waitKey 控制窗口停留。waitKey(0) 无限等待按键，waitKey(30) 等 30 毫秒（视频播放用）。GUI 依赖桌面环境，服务器/无头环境（headless）下会报错，需换成写盘或 matplotlib 展示。

```text
imshow + waitKey 配合：
1. imshow(winname, img) —— 显示，窗口名可复用
2. waitKey(0) —— 阻塞等任意键；waitKey(n) —— 等 n 毫秒
3. destroyAllWindows() —— 关闭所有窗口
```

```python
import cv2
import numpy as np

img = np.zeros((100, 100, 3), dtype=np.uint8)
# 无头环境下下面两行会抛异常，注释仅作示意：
# cv2.imshow('win', img)
# cv2.waitKey(0)
# cv2.destroyAllWindows()
print('imshow 需要 GUI；无头环境用 imwrite + matplotlib 替代')
```

## VideoCapture

VideoCapture 打开摄像头（参数 0 表示默认摄像头）或视频文件，read() 逐帧读取。读到的帧是 BGR 数组，读不到新帧时返回 (False, None)，可用这个判断视频是否放完。循环读帧是视频分析的标准骨架。

```text
VideoCapture 用法：
1. 打开源 —— cv2.VideoCapture(0) 摄像头 / ('file.mp4') 视频文件
2. 逐帧读 —— ok, frame = cap.read()
3. 结束判断 —— ok 为 False 说明流结束
4. 释放 —— cap.release() 必须调用
```

```python
import cv2
import numpy as np

# 造一个假视频文件再读
fourcc = cv2.VideoWriter_fourcc(*'mp4v')
w = cv2.VideoWriter('/tmp/_demo.mp4', fourcc, 20.0, (64, 64))
for i in range(10):
    f = np.full((64, 64, 3), i * 25, dtype=np.uint8)
    w.write(f)
w.release()

cap = cv2.VideoCapture('/tmp/_demo.mp4')
n = 0
while True:
    ok, frame = cap.read()
    if not ok:
        break
    n += 1
cap.release()
print('帧数:', n)   # 10
```

## VideoWriter

VideoWriter 把帧序列编码成视频文件。核心是 FourCC 四字符编码（mp4v、XVID、MJPG 等）和帧率、尺寸三要素，尺寸必须和写入帧一致。写完后 release() 才会真正落盘，忘调用会导致文件损坏打不开。

```text
VideoWriter 三要素：
1. FourCC —— 编码器代号，如 mp4v（MP4）、XVID（AVI）
2. fps —— 帧率，决定播放速度
3. size —— (宽, 高)，必须与写入帧尺寸一致
```

```python
import cv2
import numpy as np

fourcc = cv2.VideoWriter_fourcc(*'mp4v')
out = cv2.VideoWriter('/tmp/_out.mp4', fourcc, 20.0, (100, 100))
for i in range(30):
    frame = np.full((100, 100, 3), i * 8, dtype=np.uint8)
    out.write(frame)
out.release()   # 不 release 文件可能损坏
print('写入完成')
```

## Image / Video I/O

图像和视频的读写本质上是同一套流程：I/O 层负责编解码和传输，应用层拿到的都是 BGR 帧数组。图像是「单帧的 I/O」，视频是「多帧循环的 I/O」。生产里 I/O 常是瓶颈，可用多线程/预读解耦解码和计算。

```text
I/O 层的职责：
1. 解码 —— 把 jpg/png/mp4 字节流转成帧数组
2. 编码 —— 把帧数组转回字节流（压缩）
3. 瓶颈 —— 解码慢时，用线程池预取帧，别让计算线程空等
```

```python
import cv2

# 图像 I/O 与视频 I/O 的对应关系
# 图像：imread（解码）→ 处理 → imwrite（编码）
# 视频：VideoCapture.read（解码）→ 处理 → VideoWriter.write（编码）
img = cv2.imread('/tmp/_demo.png')
print('单帧 I/O：读入', img.shape)

cap = cv2.VideoCapture('/tmp/_demo.mp4')
ok, frame = cap.read()
print('视频 I/O：首帧', frame.shape)
cap.release()
```

## Color Conversion

cvtColor 在任意两种颜色空间之间转换，用 COLOR_ 前缀的常量指定方向（如 BGR2GRAY、BGR2HSV、BGR2LAB、GRAY2BGR）。它是颜色分割、特征处理前几乎必过的一步，方向写反（GRAY2BGR 写成 BGR2GRAY）会导致通道数或颜色全错。

```text
cvtColor 常用方向：
1. BGR2GRAY —— 转灰度，降维省计算
2. BGR2HSV —— 转 HSV，颜色分割用
3. BGR2LAB —— 转 LAB，亮度颜色解耦
4. GRAY2BGR —— 灰度转三通道，便于和其他彩色图拼接
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (50, 50, 3), dtype=np.uint8)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
lab = cv2.cvtColor(img, cv2.COLOR_BGR2LAB)
print(gray.shape, hsv.shape, lab.shape)   # (50,50) (50,50,3) (50,50,3)
```

## Resize

resize 缩放图像到目标尺寸，常用插值方式：INTER_NEAREST 最近邻（快、有锯齿）、INTER_LINEAR 双线性（默认、平滑）、INTER_CUBIC 三次（放大质量高）、INTER_AREA（缩小质量好）。放大和缩小该选不同插值，缩小时用 INTER_AREA 能避免摩尔纹。

```text
resize 插值选型：
1. 缩小 —— INTER_AREA，区域平均，最稳
2. 放大 —— INTER_CUBIC 或 INTER_LINEAR
3. 保真要求低 —— INTER_NEAREST，最快
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100, 3), dtype=np.uint8)
small = cv2.resize(img, (50, 50), interpolation=cv2.INTER_AREA)     # 缩小
big = cv2.resize(img, (200, 200), interpolation=cv2.INTER_CUBIC)    # 放大
print(small.shape, big.shape)   # (50,50,3) (200,200,3)
```

## Crop

裁剪（Crop）是取图像的一个矩形子区域，本质就是 NumPy 切片：img[y1:y2, x1:x2]。注意 OpenCV 数组是 (高, 宽) 顺序，所以第一个切片是行（y），第二个是列（x）。切片是视图不是拷贝，改它会连带改原图，需要独立数据时用 .copy()。

```text
裁剪要点：
1. 切片顺序 —— img[行(y):行, 列(x):列]，先 y 后 x
2. 视图语义 —— 切片共享内存，改前 .copy()
3. ROI —— 感兴趣区域常用 crop 取出后单独处理
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100, 3), dtype=np.uint8)
roi = img[20:60, 30:80]          # 取 y∈[20,60), x∈[30,80)
print(roi.shape)                 # (40, 50, 3)
print(roi is img)                # False 但共享内存
roi_copy = img[20:60, 30:80].copy()   # 独立拷贝
```

## Rotate

rotate 按 90° 的倍数旋转图像，ROTATE_90_CLOCKWISE / ROTATE_180 / ROTATE_90_COUNTERCLOCKWISE。这是无损的像素重排（不插值），适合旋转 90/180/270 度。任意角度的旋转要用 warpAffine 配旋转矩阵，会引入插值和黑边。

```text
rotate 与任意角度旋转的区别：
1. rotate —— 只支持 90° 倍数，纯重排无插值，快
2. getRotationMatrix2D + warpAffine —— 任意角度，需插值、填边
```

```python
import cv2
import numpy as np

img = np.arange(12).reshape(3, 4).astype(np.uint8)   # 3 行 4 列
rot90 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)      # 变 4 行 3 列
print(img.shape, '->', rot90.shape)                   # (3,4) -> (4,3)
print(rot90)
```

## Flip

flip 镜像翻转图像，flipCode 决定方向：1 水平翻转、0 垂直翻转、-1 同时翻转（180°）。数据增强里水平翻转是最常用的手段（训练图片不够时翻倍样本）。注意水平翻转会改变文字的左右方向，OCR 场景要谨慎。

```text
flipCode 约定：
1. 1 —— 水平翻转（左右镜像）
2. 0 —— 垂直翻转（上下颠倒）
3. -1 —— 水平 + 垂直（等价旋转 180°）
```

```python
import cv2
import numpy as np

img = np.arange(12).reshape(3, 4).astype(np.uint8)
flip_h = cv2.flip(img, 1)   # 水平镜像
flip_v = cv2.flip(img, 0)   # 垂直镜像
print(flip_h)
print('原图', img[0], '水平后', flip_h[0])
```

## Warp

warpAffine / warpPerspective 是最通用的几何变换：给定 2x3 仿射矩阵或 3x3 透视矩阵，把原图每个像素映射到新位置。resize/rotate/平移都是它的特例。核心是构造变换矩阵——平移、缩放、旋转用 getRotationMatrix2D / getAffineTransform，透视用 getPerspectiveTransform。

```text
Warp 家族：
1. warpAffine —— 2x3 矩阵，保平行线（仿射）
2. warpPerspective —— 3x3 矩阵，可做透视（近大远小）
3. 变换矩阵 —— 三对点 getAffineTransform，四对点 getPerspectiveTransform
```

```python
import cv2
import numpy as np

img = np.random.randint(0, 256, (100, 100, 3), dtype=np.uint8)
# 平移：x 方向 +20，y 方向 +10
M = np.float32([[1, 0, 20], [0, 1, 10]])
moved = cv2.warpAffine(img, M, (100, 100))
# 旋转 45° 绕中心
(h, w) = img.shape[:2]
R = cv2.getRotationMatrix2D((w / 2, h / 2), 45, 1.0)
rotated = cv2.warpAffine(img, R, (w, h))
print(moved.shape, rotated.shape)
```

## 应用场景实战

### 场景一：批量读图统一尺寸（预处理流水线）

```python
import cv2
import numpy as np

# 把一批不同尺寸的图统一缩放到 224x224 灰度（喂模型前）
imgs = [np.random.randint(0, 256, (100, 100, 3), dtype=np.uint8),
        np.random.randint(0, 256, (200, 300, 3), dtype=np.uint8)]
out = []
for im in imgs:
    g = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)
    r = cv2.resize(g, (224, 224), interpolation=cv2.INTER_AREA)
    out.append(r)
print([o.shape for o in out])   # [(224, 224), (224, 224)]
```

### 场景二：视频抽帧保存关键帧

```python
import cv2
import numpy as np

# 从视频里每 5 帧抽一帧存盘（做标注数据集）
fourcc = cv2.VideoWriter_fourcc(*'mp4v')
w = cv2.VideoWriter('/tmp/_src.mp4', fourcc, 25.0, (64, 64))
for i in range(25):
    w.write(np.full((64, 64, 3), i * 10, dtype=np.uint8))
w.release()

cap = cv2.VideoCapture('/tmp/_src.mp4')
idx = 0
saved = 0
while True:
    ok, frame = cap.read()
    if not ok:
        break
    if idx % 5 == 0:
        cv2.imwrite(f'/tmp/_frame_{idx}.jpg', frame)
        saved += 1
    idx += 1
cap.release()
print('保存帧数:', saved)   # 0,5,10,15,20 → 5 帧
```

## 最佳实践与踩坑记录

### 最佳实践

1. imread 后先判 None，路径错/文件坏时能第一时间发现
2. 统一在 BGR 空间处理，输出/显示前再转，别来回转
3. 缩放用 INTER_AREA，放大用 INTER_CUBIC，按方向选插值
4. 批量处理时 I/O 用线程池预读帧，计算线程不空等
5. 裁剪、翻转这类纯重排操作记得 .copy()，避免误改原图
6. VideoWriter 写完必须 release()，否则视频文件损坏

### 踩坑记录

```text
坑 1：imread 返回 None 后续直接崩
结论：读不存在的路径不报错，返回 None，img.shape 抛 AttributeError。
原因：OpenCV 对读失败静默，不抛异常。
解法：读图后 `if img is None:` 提前 return 或 raise。

坑 2：imwrite 静默失败却当成功
结论：写到了不存在的目录，返回 False 但代码继续跑，文件没落盘。
原因：imwrite 失败只返回 False，不抛异常，返回值常被忽略。
解法：检查返回值 `assert ok`，或先 os.makedirs 保证目录存在。

坑 3：imshow 在服务器报错
结论：无 GUI 的 headless 环境调 imshow 抛 cv2.error。
原因：imshow 依赖 X11/桌面显示服务。
解法：无头环境改用 imwrite 存盘或 matplotlib 内联显示。

坑 4：VideoWriter 尺寸和帧不一致
结论：写视频时报错或输出黑边/拉伸。
原因：VideoWriter 初始化的 size 必须和每帧的 (宽,高) 完全一致。
解法：用 frame.shape[1], frame.shape[0] 作为 (宽,高) 传入初始化。

坑 5：Resize 尺寸写反
结论：想缩成 (宽 300, 高 200)，结果图是 (300 高, 200 宽) 方向颠倒。
原因：cv2.resize 的 dsize 参数是 (宽, 高)，而数组 shape 是 (高, 宽)。
解法：resize 的 dsize 写 (width, height)，检查时看 shape 的 (h, w)。
```
