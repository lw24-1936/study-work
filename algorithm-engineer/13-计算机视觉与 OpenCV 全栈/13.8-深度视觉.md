## 概述

深度视觉是用卷积神经网络（CNN）和 Transformer 解决视觉理解问题的一整套任务谱系。按「输出粒度」可以把它们排成一条从粗到细的线：图像分类（整图一个标签）→ 目标检测（定位框 + 类别）→ 语义分割（像素级类别）→ 实例分割（像素级个体）→ 全景分割（语义 + 实例的合并）。加上关键点、OCR、人脸、跟踪这些专用任务，共同构成了工业界视觉系统的能力拼图。

```text
深度视觉任务谱系（按输出粒度从粗到细）：
1. 图像分类 —— 整图 → 一个类别标签
2. 目标检测 —— 框 + 类别（目标在哪里、是什么）
3. 语义分割 —— 每个像素 → 类别（不区分个体）
4. 实例分割 —— 每个像素 → 类别 + 个体实例
5. 全景分割 —— 语义（stuff）+ 实例（thing）统一标注
6. 关键点检测 —— 定位目标上的关键点坐标
7. OCR / 人脸 / 跟踪 —— 面向特定目标的专用任务
```

```python
import torch
import torchvision.models as models
import torchvision.transforms as T

# 深度视觉的入口：用预训练 ResNet 做图像分类
model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1).eval()
transform = T.Compose([T.Resize(256), T.CenterCrop(224), T.ToTensor(),
                       T.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])])
img = transform(T.ToPILImage()(torch.rand(3, 224, 224)))
with torch.no_grad():
    logits = model(img.unsqueeze(0))
print(f'输出 1000 类 logits 形状: {logits.shape}')
```

## Image Classification

图像分类是深度视觉的「Hello World」：输入一张图，输出一个类别标签。CNN 从 ImageNet 的 1000 类分类任务上崛起，分类网络（ResNet、EfficientNet 等）的骨干（backbone）也是所有其他视觉任务的通用特征提取器。训练用交叉熵损失，评估用 Top-1/Top-5 准确率。

```text
图像分类的核心要点：
1. 骨干网络 —— 在 ImageNet 预训练后迁移到下游任务
2. 损失函数 —— 交叉熵 CrossEntropyLoss
3. 数据增强 —— 随机裁剪、翻转、颜色抖动，提升泛化
4. 评估指标 —— Top-1 / Top-5 准确率
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    """一个用于图像分类的轻量 CNN"""
    def __init__(self, num_classes=10):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(64 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))   # 32x32 -> 16x16
        x = self.pool(F.relu(self.conv2(x)))   # 16x16 -> 8x8
        x = x.view(x.size(0), -1)
        return self.fc(x)

model = SimpleCNN(num_classes=10)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# 一个训练 step 的示意
x = torch.randn(4, 3, 32, 32)
y = torch.randint(0, 10, (4,))
loss = criterion(model(x), y)
optimizer.zero_grad(); loss.backward(); optimizer.step()
print(f'交叉熵损失: {loss.item():.4f}')
```

## Object Detection

目标检测在分类的基础上加上了「定位」：输出目标的边界框（bounding box）和类别。它由两个子任务组成——回归框坐标、分类框内容。检测是自动驾驶、安防、工业质检里最常用的视觉任务，评估用 mAP（mean Average Precision），主流模型分两阶段（Faster R-CNN）和单阶段（YOLO/SSD）两派。

```text
目标检测的组成：
1. 定位 —— 回归边界框 (x, y, w, h)
2. 分类 —— 判断框内目标类别
3. 损失 —— 分类损失 + 回归损失（Smooth L1 / CIoU）
4. 评估 —— mAP@0.5 / mAP@0.5:0.95
```

```python
import torch

# 检测框 IoU 计算（评估的核心指标）
def box_iou(box1, box2):
    x1 = max(box1[0], box2[0]); y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2]); y2 = min(box1[3], box2[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    return inter / (area1 + area2 - inter + 1e-6)

pred = torch.tensor([10.0, 10.0, 60.0, 60.0])
gt = torch.tensor([20.0, 20.0, 70.0, 70.0])
print(f'IoU = {box_iou(pred, gt):.3f}')   # 0.6 左右
```

```python
# Smooth L1 回归损失（检测框回归常用，对异常值更鲁棒）
def smooth_l1_loss(pred, target, beta=1.0):
    diff = torch.abs(pred - target)
    loss = torch.where(diff < beta, 0.5 * diff ** 2 / beta, diff - 0.5 * beta)
    return loss.mean()

print(smooth_l1_loss(torch.tensor([1.0, 2.0]), torch.tensor([1.5, 1.8])))
```

## Semantic Segmentation

语义分割把图像里每个像素都打上一个类别标签，回答「每个像素是什么」。它不区分同类中的不同个体——画面里所有人都是同一个「person」标签。核心架构是编码器-解码器（Encoder-Decoder），代表有 FCN、U-Net、DeepLab。损失是逐像素交叉熵，评估用 mIoU（mean Intersection over Union）。

```text
语义分割的核心要点：
1. 逐像素分类 —— 输出与输入同尺寸的类别图
2. 编码器-解码器 —— 下采样提特征 + 上采样恢复分辨率
3. 跳跃连接 —— U-Net 保留空间细节
4. 评估 —— mIoU，即各类别交集/并集的均值
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class UNetBlock(nn.Module):
    """U-Net 的双卷积块"""
    def __init__(self, in_c, out_c):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_c, out_c, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(out_c, out_c, 3, padding=1), nn.ReLU(inplace=True),
        )
    def forward(self, x):
        return self.conv(x)

class TinyUNet(nn.Module):
    """简化的 U-Net 语义分割网络"""
    def __init__(self, num_classes=21):
        super().__init__()
        self.enc1 = UNetBlock(3, 64)
        self.enc2 = UNetBlock(64, 128)
        self.pool = nn.MaxPool2d(2)
        self.up = nn.ConvTranspose2d(128, 64, 2, stride=2)   # 上采样
        self.dec = UNetBlock(128, 64)                        # 拼接后 128 -> 64
        self.out = nn.Conv2d(64, num_classes, 1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        d1 = self.up(e2)
        d1 = self.dec(torch.cat([d1, e1], dim=1))            # 跳跃连接
        return self.out(d1)

model = TinyUNet(num_classes=21)
out = model(torch.randn(2, 3, 256, 256))
print(f'分割输出（逐像素 logits）: {out.shape}')   # [2, 21, 256, 256]
```

## Instance Segmentation

实例分割比语义分割更进一步：不仅要判断像素类别，还要区分「同类中的不同个体」，给每个目标一个独立掩码（mask）。代表模型是 Mask R-CNN——在 Faster R-CNN 上多加了条 mask 分支，对每个检测框内的目标做像素级分割。它是「检测 + 分割」的结合体。

```text
实例分割 vs 语义分割：
- 语义分割 —— 所有 person 像素都是同一标签，不区分个体
- 实例分割 —— 每个人一个独立掩码，N 个人输出 N 个 mask

Mask R-CNN 三头结构：
1. 分类头 —— 框内类别
2. 回归头 —— 框坐标精修
3. 掩码头 —— 框内逐像素二值掩码
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MaskHead(nn.Module):
    """Mask R-CNN 掩码分支的简化示意"""
    def __init__(self, in_channels=256, num_classes=80):
        super().__init__()
        self.convs = nn.Sequential(
            nn.Conv2d(in_channels, 256, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(256, num_classes, 1),
        )
    def forward(self, roi_features):
        # roi_features: [N, 256, 14, 14]，输出 [N, num_classes, 14, 14]
        logits = self.convs(roi_features)
        # 对每个实例的类别通道做 sigmoid 得到二值掩码
        return torch.sigmoid(logits)

head = MaskHead(num_classes=80)
rois = torch.randn(4, 256, 14, 14)
masks = head(rois)
print(f'掩码输出: {masks.shape}')   # [4, 80, 14, 14]，4 个实例 × 80 类
```

## Panoptic Segmentation

全景分割是语义分割和实例分割的统一：把像素分为「thing」（可数目标，如人、车，需要实例区分）和「stuff」（不可数背景，如天空、道路、草地，只需语义类别）。一张图每个像素恰好属于一个标签，thing 像素带 instance id，stuff 像素只带类别。评估用 PQ（Panoptic Quality），模型代表如 Panoptic FPN、MaskFormer。

```text
全景分割的规则：
1. thing 类 —— 人、车、动物等，需要区分实例
2. stuff 类 —— 天空、道路、草地等，只分语义
3. 无重叠 —— 每个像素唯一归属，thing 与 stuff 不重叠
4. 评估 —— PQ = SQ × RQ（分割质量 × 识别质量）
```

```python
import numpy as np

def panoptic_quality(pred_seg, pred_inst, gt_seg, gt_inst):
    """PQ 指标的核心思想示意：分割质量 SQ × 识别质量 RQ"""
    # 简化：把 (seg, inst) 组合成唯一 id，统计匹配
    def combine(seg, inst):
        return seg * 1000 + inst
    pred_ids = combine(pred_seg, pred_inst)
    gt_ids = combine(gt_seg, gt_inst)
    # 计算匹配的 id 并集、交集
    matched = set(pred_ids.flatten().tolist()) & set(gt_ids.flatten().tolist())
    sq = len(matched) / max(len(set(pred_ids.flatten().tolist())), 1)   # 简化示意
    rq = len(matched) / max(len(set(gt_ids.flatten().tolist())), 1)
    return sq * rq

# 随机示意
print(f'PQ 示意值: {panoptic_quality(np.zeros((4, 4)), np.zeros((4, 4)), np.zeros((4, 4)), np.zeros((4, 4))):.3f}')
```

## Keypoint Detection

关键点检测定位目标上的语义关键点坐标，如人体 17 个关节点、人脸 68 个 landmark、手部 21 个关节点。输出通常是每个关键点的热力图（heatmap），取热力峰值得到坐标。它支撑姿态估计、动作识别、人脸对齐、手势交互等应用，评估用 OKS（Object Keypoint Similarity）或 PCK。

```text
关键点检测的核心要点：
1. 热力图 —— 每个关键点输出一张高斯热力图，峰值即坐标
2. 人体 —— COCO 17 点（鼻、眼、肩、肘、腕、髋、膝、踝）
3. 评估 —— OKS（类似关键点版 IoU）、PCK（正确关键点比例）
4. 代表模型 —— Hourglass、OpenPose、HRNet
```

```python
import torch
import torch.nn.functional as F
import numpy as np

# 从热力图解码关键点坐标（取 argmax，再做高斯校正到亚像素精度）
def heatmap_to_keypoints(heatmaps):
    """heatmaps: [K, H, W]，返回 [K, 2] 坐标"""
    k, h, w = heatmaps.shape
    coords = []
    for hm in heatmaps:
        flat = hm.flatten()
        idx = int(flat.argmax())
        y, x = idx // w, idx % w
        # 简单的高斯峰值校正（亚像素）
        if 0 < x < w - 1 and 0 < y < h - 1:
            dx = (hm[y, x + 1] - hm[y, x - 1]) / 2
            dy = (hm[y + 1, x] - hm[y - 1, x]) / 2
            x, y = x + dx, y + dy
        coords.append([x, y])
    return torch.tensor(coords)

heatmaps = torch.rand(17, 64, 64)   # 17 个关键点的热力图
coords = heatmap_to_keypoints(heatmaps)
print(f'关键点坐标: {coords.shape}')   # [17, 2]
```

## OCR

OCR（Optical Character Recognition，光学字符识别）从图像中提取文字：先「检测」文字区域（Text Detection），再「识别」区域内容（Text Recognition）。它横跨检测、分割、序列建模多个技术点，广泛应用于证件识别、票据、车牌、文档数字化。详见 [[13.11-OCR]] 的专题笔记。

```text
OCR 的两阶段流水线：
1. 文字检测 —— 定位图像中的文字区域/文本框
2. 文字识别 —— 对裁剪出的文字条做字符序列识别

也可端到端一体，或引入版面分析做复杂文档理解
```


## Face Detection

人脸检测是目标检测的一个特化子任务：定位图像中所有人脸的位置。相比通用检测，它对人脸特有的尺度小、角度多变、遮挡等问题有专门优化。传统用 Haar Cascade，深度学习时代用 MTCNN（多级级联 CNN）、RetinaFace、SCRFD 等，输出人脸框（有时附带 5 点 landmark）。

```text
人脸检测的代表方案：
1. Haar Cascade —— 传统方法，CPU 即可实时
2. MTCNN —— PNet→RNet→ONet 三级级联，框 + 关键点
3. RetinaFace —— 单阶段，框 + 5 点 landmark，精度高
4. SCRFD —— 轻量高效，适合端侧部署
```

```python
import cv2
import numpy as np

# OpenCV DNN 加载人脸检测模型（如 ResNet-SSD）
net = cv2.dnn.readNetFromCaffe('deploy.prototxt', 'res10_300x300_ssd_iter_140000.caffemodel')
img = cv2.imread('group.jpg')
h, w = img.shape[:2]
blob = cv2.dnn.blobFromImage(cv2.resize(img, (300, 300)), 1.0, (300, 300), (104.0, 177.0, 123.0))
net.setInput(blob)
detections = net.forward()
for i in range(detections.shape[2]):
    confidence = detections[0, 0, i, 2]
    if confidence > 0.5:
        box = detections[0, 0, i, 3:7] * np.array([w, h, w, h])
        (x1, y1, x2, y2) = box.astype('int')
        cv2.rectangle(img, (x1, y1), (x2, y2), (0, 255, 0), 2)
print(f'人脸检测完成，阈值 0.5')
```

## Face Recognition

人脸识别解决「这是谁」的问题：把检测到的人脸对齐后，提取人脸 embedding（特征向量），再与底库里的人脸做相似度比对。核心是「度量学习」——用三元组损失（Triplet Loss）或 ArcFace 损失训练，让同一个人的人脸向量靠近、不同人的远离。识别本质上是「1:N 检索」，验证是「1:1 比对」。

```text
人脸识别的流程：
1. 检测 —— 定位人脸框
2. 对齐 —— 用 landmark 做人脸对齐（仿射变换）
3. 特征 —— 网络提取 512 维人脸 embedding
4. 比对 —— 余弦相似度，超过阈值判定同人

代表损失：Triplet Loss、ArcFace（加性角度间隔）
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ArcFaceLoss(nn.Module):
    """ArcFace 加性角度间隔损失，人脸识别主流损失"""
    def __init__(self, num_classes, emb_size=512, margin=0.5, scale=64.0):
        super().__init__()
        self.weight = nn.Parameter(torch.FloatTensor(num_classes, emb_size))
        nn.init.xavier_normal_(self.weight)
        self.margin = margin
        self.scale = scale

    def forward(self, embeddings, labels):
        # 归一化嵌入和权重，计算角余弦
        embeddings = F.normalize(embeddings)
        w = F.normalize(self.weight)
        cosine = embeddings @ w.t()
        # 对真实类别加角度间隔
        one_hot = F.one_hot(labels, num_classes=self.weight.size(0)).float()
        cosine_m = cosine - self.margin * one_hot
        return F.cross_entropy(self.scale * cosine_m, labels)

loss_fn = ArcFaceLoss(num_classes=1000)
emb = torch.randn(8, 512)
labels = torch.randint(0, 1000, (8,))
print(f'ArcFace 损失: {loss_fn(emb, labels).item():.3f}')
```

```python
# 人脸比对：余弦相似度
def cosine_similarity(a, b):
    a = F.normalize(a); b = F.normalize(b)
    return (a * b).sum(dim=-1)

emb1 = torch.randn(1, 512)   # 底库人脸
emb2 = torch.randn(1, 512)   # 待识别人脸
sim = cosine_similarity(emb1, emb2)
print(f'相似度: {sim.item():.3f}，阈值 0.6 判断是否同人')
```

## Tracking

跟踪（Tracking）是在视频帧序列中持续定位某个目标：给定第一帧的目标框，后续帧预测它的位置。它分单目标跟踪（SORT 类，给定初始框一路跟）和多目标跟踪（MOT，还要处理新目标出现、旧目标消失、ID 关联）。跟踪是视频分析的核心，详见 [[13.10-视频分析]] 专题。

```text
跟踪的分类：
1. 单目标跟踪 —— 给定初始框，持续跟踪一个目标（KCF、SiamRPN）
2. 多目标跟踪 —— 多目标 + ID 关联 + 轨迹管理（SORT、DeepSORT、ByteTrack）
3. 核心挑战 —— 遮挡、形变、光照、尺度变化、目标交错
```

```python
import cv2

# OpenCV 内置跟踪器（CSRT/KCF）快速上手
tracker = cv2.TrackerCSRT_create()
cap = cv2.VideoCapture('video.mp4')
ret, frame = cap.read()
bbox = cv2.selectROI('Select Target', frame, False)   # 手动框选目标
tracker.init(frame, bbox)
while True:
    ret, frame = cap.read()
    if not ret:
        break
    ok, bbox = tracker.update(frame)
    if ok:
        (x, y, w, h) = [int(v) for v in bbox]
        cv2.rectangle(frame, (x, y), (x + w, y + h), (0, 255, 0), 2)
    cv2.imshow('Tracking', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release(); cv2.destroyAllWindows()
```

## 应用场景实战

### 场景一：图像分类到语义分割的完整推理

```python
import torch
import torchvision.models.segmentation as seg

# 语义分割推理（DeepLabV3 + ResNet50）
model = seg.deeplabv3_resnet50(weights=seg.DeepLabV3_ResNet50_Weights.COCO_WITH_VOC_LABELS_V1).eval()
```

### 场景二：检测 + 关键点的多任务流水线

```python
import torch

# 多任务联合训练示意：共享骨干 + 两个头
class MultiTaskHead(nn.Module):
    def __init__(self, backbone_dim=512, num_classes=80, num_keypoints=17):
        super().__init__()
        self.cls_head = nn.Linear(backbone_dim, num_classes)      # 检测分类头
        self.box_head = nn.Linear(backbone_dim, 4)                # 检测回归头
        self.kpt_head = nn.Linear(backbone_dim, num_keypoints * 2)  # 关键点头

    def forward(self, feat):
        return self.cls_head(feat), self.box_head(feat), self.kpt_head(feat)

head = MultiTaskHead()
feat = torch.randn(4, 512)
cls_logits, boxes, keypoints = head(feat)
print(f'分类: {cls_logits.shape}, 框: {boxes.shape}, 关键点: {keypoints.shape}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 图像分类用 ImageNet 预训练骨干做迁移学习，小数据也能训出好效果
2. 目标检测先上 YOLO 跑通，再按精度需求换 Faster R-CNN 等两阶段模型
3. 语义分割 U-Net 适合小数据/医学影像，DeepLab 适合自然场景多类别
4. 实例分割直接用 Mask R-CNN，它是检测到分割的最平滑过渡
5. 人脸识别务必做人脸对齐，对齐质量对 embedding 影响巨大
6. 跟踪任务先明确单目标还是多目标，两者评估指标和方案完全不同

### 踩坑记录

```text
坑 1：分割输出直接 argmax 但不做尺寸对齐
结论：预测图与原始图像尺寸不一致，可视化或后处理出错。
原因：编码器-解码器输出常因池化不整除而略小于输入。
解法：最后插值到原始尺寸（F.interpolate），或用整除的输入尺寸。

坑 2：人脸识别忘做对齐
结论：同一人不同角度/姿态下 embedding 差异大，误拒率高。
原因：网络对人脸姿态敏感，未对齐导致特征不稳定。
解法：先用 landmark 做仿射对齐到标准脸，再提取 embedding。

坑 3：目标检测用 mAP 以外的指标误导判断
结论：只看 accuracy 会觉得模型很好，实际漏检严重。
原因：检测场景正负样本极度不平衡，accuracy 无意义。
解法：统一用 mAP@0.5、mAP@0.5:0.95，配合 Recall 看漏检。

坑 4：全景分割把 thing 和 stuff 用同一套 loss 训
结论：可数目标边界模糊，stuff 与 thing 互相干扰。
原因：thing 需要实例区分、stuff 只需语义，性质不同。
解法：用 PQ 评估，模型选 MaskFormer 等统一但区分处理的设计。

坑 5：关键点热力图直接取 argmax 不校正
结论：关键点坐标有整像素量化误差，精度受限。
原因：热力图分辨率低于原图，argmax 只能到整像素。
解法：对峰值邻域做高斯/二次函数拟合做亚像素校正。
```
