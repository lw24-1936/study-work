## 概述

本项目构建一套时间序列预测与异常检测平台：接入监控指标（QPS、CPU、销量、传感器读数），用 ARIMA/LightGBM/LSTM/Transformer 多模型做预测，预测值和真实值偏差触发异常检测，变点检测定位趋势突变，最终实时告警推送。业务价值在于从「事后看报表」变成「提前发现异常」，典型场景是运维监控、业务指标巡检、工业传感器故障预警。

```text
平台核心能力：
1. 指标接入 —— 监控指标时序数据统一采集
2. 预测 —— ARIMA（线性）/ LightGBM（特征）/ LSTM·Transformer（深度）
3. 异常检测 —— 预测偏差、动态阈值、孤立森林
4. 变点检测 —— 定位趋势/均值的突变点
5. 实时告警 —— 规则 + 分级 + 推送，抑制告警风暴
```

```python
# 平台主流程：预测 → 残差 → 异常判定 → 告警
def detect_anomaly(series, model, window=24):
    forecast = model.predict(series)                 # 预测
    residual = series[-len(forecast):] - forecast    # 残差
    threshold = dynamic_threshold(residual)          # 动态阈值
    anomalies = np.abs(residual) > threshold         # 异常点
    return anomalies, residual, threshold
```

## 技术选型

| 环节 | 选择 | 理由 | 备选 |
|---|---|---|---|
| 统计预测 | ARIMA/SARIMA | 线性趋势 + 季节性的经典模型，可解释 | ETS、Prophet |
| 特征预测 | LightGBM | 用滞后/滚动特征建模，非线性、快 | XGBoost、CatBoost |
| 深度预测 | LSTM / Transformer | 长序列依赖建模，多序列联合预测 | TCN、TFT |
| 异常检测 | 残差 + 动态阈值 | 预测偏差是最直观的异常信号 | Isolation Forest、LOF |
| 变点检测 | ruptures（Pelt/Binseg） | 离线变点分割，定位突变时刻 | 自研 CUSUM |
| 告警 | 规则 + 分级 | 阈值/持续时长/分级，抑制风暴 | 告警平台对接 |

选型原则：按数据规模分档——小数据、强周期性用 ARIMA；中等数据、特征丰富用 LightGBM；大数据、多序列用深度学习。异常检测统一走「预测残差 + 动态阈值」，简单可靠且可解释。

```python
import numpy as np

def dynamic_threshold(residual, k=3, window=24):
    """动态阈值：滚动窗口的均值 + k 倍标准差"""
    r = np.asarray(residual)
    mean = pd.Series(r).rolling(window, min_periods=1).mean().values
    std = pd.Series(r).rolling(window, min_periods=1).std().values
    return mean + k * std
```

## 架构设计

平台分「离线训练」和「在线检测」两条链路。离线训练各模型、计算变点、拟合阈值；在线对实时流入的指标做预测、算残差、判定异常、触发告警。

```text
离线训练                           在线检测
┌──────────────┐                  ┌──────────────┐
│ 历史指标数据  │                  │ 实时指标流入  │
└──────┬───────┘                  └──────┬───────┘
       │ 训练 ARIMA/GBDT/LSTM              │ 加载模型
       ▼                                  ▼
┌──────────────┐                  ┌──────────────┐
│ 模型 + 阈值   │ ─────────────►  │ 预测 + 残差    │
│ 变点分析      │                  │ + 动态阈值     │
└──────────────┘                  └──────┬───────┘
                                         ▼
                                  ┌──────────────┐
                                  │ 异常判定       │
                                  │ → 告警推送      │
                                  └──────────────┘
```

```python
# 离线：训练 + 拟合阈值 + 变点分析
def offline_train(series):
```

## ARIMA

ARIMA 是时序预测的经典基线：差分让序列平稳，AR 项建模自相关，MA 项建模误差。带季节性的序列用 SARIMA。本项目用 ARIMA 处理强周期性、线性趋势的指标，作为所有深度模型的对照基线。

```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller

# 造一条带趋势 + 噪声的序列
t = np.arange(100)
series = 0.5 * t + 10 * np.sin(t / 5) + np.random.randn(100) * 2

# 平稳性检验：不平稳则差分
print(f"ADF p-value = {adfuller(series)[1]:.3f}")

model = ARIMA(series, order=(1, 1, 1))    # (p, d, q)
fit = model.fit()
forecast = fit.forecast(steps=10)
print(forecast)
```

```text
ARIMA 参数含义：
1. p —— AR 阶数，看 PACF 截尾
2. d —— 差分阶数，使序列平稳
3. q —— MA 阶数，看 ACF 截尾
4. 季节性 —— 用 SARIMA 加 (P,D,Q,s)，s 是周期
5. 前提 —— 序列平稳，建模前先 ADF 检验 + 差分
```

## LightGBM

LightGBM 做时序预测靠「特征工程 + 回归」：把时间序列转成监督学习样本，用滞后特征、滚动统计、时间特征喂给 GBDT。它擅长捕捉非线性关系和特征交互，比 ARIMA 更灵活。特征构造细节见 [[08.5-时间特征]]。

```python
import numpy as np
import pandas as pd
import lightgbm as lgb

# 时序转监督样本：用过去 3 个点预测下一个点
def make_lag_features(series, lags=3):
    df = pd.DataFrame({"y": series})
    for i in range(1, lags + 1):
        df[f"lag_{i}"] = df["y"].shift(i)
    df["rolling_mean_7"] = df["y"].shift(1).rolling(7).mean()
    return df.dropna()

series = np.sin(np.arange(200) / 10) + np.random.randn(200) * 0.1
data = make_lag_features(series)
X = data.drop(columns="y").values
y = data["y"].values

train = lgb.Dataset(X[:-20], y[:-20])
model = lgb.train({"objective": "regression", "learning_rate": 0.05}, train, num_boost_round=100)
pred = model.predict(X[-20:])
print(pred[:5])
```

```text
LightGBM 时序预测要点：
1. 特征 —— 滞后值 + 滚动均值/标准差 + 时间特征（小时/星期）
2. 切分 —— 按时间顺序切分，禁止随机 shuffle（会泄露未来）
3. 多步预测 —— 递归预测（用预测值当下一轮输入）或直接多输出
4. 优势 —— 非线性、特征交叉、可解释（特征重要性）
```

## LSTM 与 Transformer

深度模型处理长序列依赖和多序列联合预测。LSTM 用循环结构记住长期状态，Transformer 用自注意力并行建模任意距离的依赖。本项目用它们处理大规模、多变量的时序场景。

```python
import torch
import torch.nn as nn

class LSTMForecaster(nn.Module):
    def __init__(self, input_dim=1, hidden=64, num_layers=2):
        super().__init__()
        self.lstm = nn.LSTM(input_dim, hidden, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden, 1)

    def forward(self, x):
        out, _ = self.lstm(x)          # x: (batch, seq, input_dim)
        return self.fc(out[:, -1, :])  # 取最后一步输出预测下一个点

class TransformerForecaster(nn.Module):
    def __init__(self, d_model=64, nhead=4, num_layers=2):
        super().__init__()
        self.embed = nn.Linear(1, d_model)
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model, nhead, batch_first=True),
            num_layers,
        )
        self.fc = nn.Linear(d_model, 1)

    def forward(self, x):
        out = self.encoder(self.embed(x))
        return self.fc(out[:, -1, :])

seq = torch.randn(32, 24, 1)     # 32 条序列，每条 24 步
print(LSTMForecaster()(seq).shape)          # (32, 1)
print(TransformerForecaster()(seq).shape)   # (32, 1)
```

```text
LSTM vs Transformer：
1. LSTM —— 顺序处理，长序列慢但内存省，适合中小规模
2. Transformer —— 并行注意力，长序列快但显存大，适合大规模
3. 多变量 —— 输入维度从 1 扩到 N，联合建模多条相关序列
4. 概率预测 —— 输出均值和方差（Gaussian NLL）可做预测区间
```

## 异常检测

异常检测的通用做法：用模型预测期望值，真实值偏离预测超过动态阈值即判异常。这种方式比孤立森林/LOF 更适合时序（考虑趋势和周期），还能给出「偏离了多少」。统计和机器学习方法见 [[07.10-异常检测]]。

```python
import numpy as np

def detect_anomalies(actual, forecast, window=24, k=3):
    residual = np.abs(np.asarray(actual) - np.asarray(forecast))
    mean = pd.Series(residual).rolling(window, min_periods=1).mean().values
    std = pd.Series(residual).rolling(window, min_periods=1).std().values
    threshold = mean + k * std
    return residual > threshold, threshold

# 模拟：正常段 + 一个突刺异常
actual = np.sin(np.arange(100) / 10)
actual[50] += 8                     # 第 50 点注入异常
forecast = np.sin(np.arange(100) / 10)
anomalies, threshold = detect_anomalies(actual, forecast)
print(np.where(anomalies)[0])       # 应包含 50
```

```text
异常检测三类方法：
1. 预测残差 —— 预测值 vs 真实值偏差，考虑趋势周期，可解释
2. 动态阈值 —— 滚动均值 + k·std，自适应业务波动
3. 无监督 —— Isolation Forest / LOF，不依赖预测模型，适合无历史
```

## 变点检测

变点检测定位序列「结构发生变化」的时刻——均值跳变、趋势转折、方差突变。和异常检测的区别：异常是「单点偏离」，变点是「分布/趋势的持续变化」。本项目用 ruptures 的 Pelt/Binseg 算法离线分割。

```python
import numpy as np
import ruptures as rpt

# 造一段带变点的序列：前 50 点均值 0，后 50 点均值 5
signal = np.concatenate([np.random.randn(50), np.random.randn(50) + 5])

algo = rpt.Pelt(model="rbf").fit(signal)
change_points = algo.predict(pen=10)     # 返回变点位置（含末尾）
print(change_points)                      # 应包含 50 附近的变点

# Binseg 二分分割：指定变点数量
algo2 = rpt.Binseg(model="l2").fit(signal)
print(algo2.predict(n_bkps=1))
```

```text
变点检测算法：
1. Pelt —— 惩罚项自动定变点数，适合离线批量
2. Binseg —— 二分分割，指定变点数量
3. CUSUM —— 累积和检验，适合在线实时检测均值漂移
4. 与异常区别 —— 异常是点，变点是段（结构变化）
```

## 实时告警

检测到异常后要实时推送告警。本项目用「规则 + 分级 + 抑制」设计：异常持续 N 个点才告警（避免毛刺误报），按偏离程度分级（warning/critical），告警风暴时合并降噪。

```python
import time

def alert_engine(anomalies, severity_scores, rules):
    """规则告警：持续时长 + 分级 + 风暴抑制"""
    alerts = []
    for i, is_anom in enumerate(anomalies):
        if is_anom:
            severity = "critical" if severity_scores[i] > rules["critical_threshold"] else "warning"
            # 持续 N 个点才告警
            if sum(anomalies[i:i + rules["min_duration"]]) >= rules["min_duration"]:
                alerts.append({"ts": time.time(), "severity": severity, "idx": i})
    return deduplicate(alerts)     # 相邻同源告警合并

def deduplicate(alerts, window_sec=300):
    """告警风暴抑制：时间窗内同源告警合并为一条"""
    merged = []
    for a in alerts:
        if not merged or a["ts"] - merged[-1]["ts"] > window_sec:
            merged.append(a)
    return merged
```

```text
实时告警设计：
1. 持续判定 —— 连续 N 个点异常才告警，过滤毛刺
2. 分级 —— warning/critical，按偏离程度和指标重要性
3. 抑制 —— 时间窗内同源告警合并，避免告警风暴
4. 渠道 —— 钉钉/邮件/Webhook 分级推送
```

## 应用场景实战

### 场景一：QPS 时序预测 + 异常检测

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

# 模拟一天 QPS：白天高夜间低的周期 + 噪声 + 一个异常点
t = np.arange(144)                     # 144 个 10 分钟点
qps = 100 + 50 * np.sin(2 * np.pi * t / 144) + np.random.randn(144) * 5
qps[80] += 60                          # 注入流量突刺

model = ARIMA(qps[:80], order=(1, 1, 1)).fit()
forecast = model.forecast(steps=64)    # 预测后 64 个点

actual = qps[80:]
residual = np.abs(actual - forecast)
threshold = residual.mean() + 3 * residual.std()
anomalies = residual > threshold
print(f"异常点: {np.where(anomalies)[0] + 80}")   # 应命中第 80 点
print(f"阈值: {threshold:.1f}, 最大偏离: {residual.max():.1f}")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 时序切分按时间顺序，禁止随机 shuffle，否则未来信息泄露进训练
2. 异常检测优先用「预测残差 + 动态阈值」，可解释且适应业务波动
3. ARIMA 建模前先 ADF 检验平稳性，不平稳先差分
4. 告警加持续时长判定和风暴抑制，避免毛刺和告警轰炸
5. 多模型同时跑，用简单模型（ARIMA）做基线，深度模型做提升
6. 阈值用滚动窗口动态计算，固定阈值扛不住业务周期波动

### 踩坑记录

```text
坑 1：时序数据随机 shuffle 切分训练集
结论：验证集 AUC 高得离谱，上线后预测崩盘。
原因：shuffle 让模型看到未来数据，时间依赖被打乱。
解法：按时间顺序切分，用 TimeSeriesSplit 做交叉验证。

坑 2：用固定阈值做异常检测
结论：白天阈值合适，夜间业务低谷时正常波动被误报成异常。
原因：业务指标有周期性，固定阈值无法适应不同时段的波动。
解法：滚动窗口动态阈值，或分时段（白天/夜间）设不同阈值。

坑 3：ARIMA 对非平稳序列直接建模
结论：模型残差有趋势，预测随步长发散。
原因：ARIMA 假设序列平稳，非平稳序列不满足前提。
解法：先 ADF 检验，不平稳则差分（d 阶）后再建模。

坑 4：单个点异常就触发告警
结论：噪声毛刺频繁触发告警，运维麻木后忽略真告警。
原因：单点偏离可能是随机噪声，不构成真实异常。
解法：连续 N 个点异常才告警，加风暴抑制合并同源告警。

坑 5：LightGBM 只用滞后特征没有滚动统计
结论：模型学不到趋势和周期，预测滞后于真实值。
原因：纯滞后特征信息有限，滚动均值/标准差能刻画局部趋势。
解法：加 rolling mean/std、时间特征（小时/星期/节假日）。
```
