## 概述

本项目是一套面向表格数据的一站式分析建模平台：从原始 CSV/数据库表出发，完成数据清洗、探索性分析、特征工程、模型训练、评估到模型落盘的完整闭环。业务价值在于把散落在各脚本里的建模流程固化成一个可复用、可复现的 pipeline，让算法工程师把时间花在特征和模型上，而不是重复写数据预处理样板代码。

```text
平台核心能力：
1. 统一数据入口 —— 读取 CSV/Parquet/数据库，统一成 DataFrame
2. 自动清洗 —— 缺失值、异常值、重复值、类型校正
3. EDA 报告 —— 分布、相关性、缺失率一屏看清
4. 特征工程 —— 数值/类别/时间特征统一转换
5. 训练与评估 —— 交叉验证 + 多指标，模型可选
6. 模型保存 —— joblib/ONNX 落盘，支持线上加载
```

```python
import pandas as pd
import numpy as np

# 平台统一数据入口：一份配置描述数据源，一个函数返回清洗后的 DataFrame
def load_data(cfg: dict) -> pd.DataFrame:
    src = cfg["source"]
    if src["type"] == "csv":
        df = pd.read_csv(src["path"], parse_dates=src.get("date_cols", []))
    elif src["type"] == "parquet":
        df = pd.read_parquet(src["path"])
    else:
        raise ValueError(f"未知数据源类型: {src['type']}")
    return df
```

## 技术选型

| 组件 | 选择 | 理由 | 备选 |
|---|---|---|---|
| 数值计算 | NumPy | 向量化运算的地基，几乎所有库都依赖它的 ndarray | 纯 Python list（慢 100 倍） |
| 表格处理 | Pandas | 生态最全、API 最熟，清洗和 EDA 首选 | Polars（更快，见下） |
| 大数据表格 | Polars | 惰性求值 + 多线程，10GB 级数据比 Pandas 快 5-10 倍 | DuckDB、Dask |
| 科学计算 | SciPy | 统计检验、优化、稀疏矩阵、插值 | statsmodels |
| 建模 | Scikit-learn | 统一 fit/predict API，覆盖 90% 传统 ML | XGBoost/LightGBM（树模型专用） |

选型核心原则：Pandas 负责「中小数据 + 复杂清洗逻辑」，Polars 负责「大数据 + 简单聚合」，两者通过 `df.to_pandas()` / `pl.from_pandas(df)` 互转。建模统一走 Scikit-learn 的 `fit/predict/transform` 接口，树模型场景才上 LightGBM/XGBoost。

```python
import polars as pl

# Polars 惰性求值：大文件只扫一遍，聚合下推

       .filter(pl.col("amount") > 0)
       .group_by("user_id")
       .agg(pl.col("amount").sum().alias("total_amount")))
df_small = q.collect()          # 触发执行，结果转回 Pandas 继续复杂清洗
pdf = df_small.to_pandas()
```

## 架构设计

平台按「数据 → 特征 → 模型 → 产物」四层组织，每层一个模块，模块间只传 DataFrame 和模型对象，不共享全局状态。

```text
┌─────────────────────────────────────────────────────┐
│  数据层   load / clean（缺失·异常·重复·类型校正）      │
│            │                                        │
│  特征层   EDA → 特征工程（数值/类别/时间）             │
│            │                                        │
│  模型层   训练（CV + 调参）→ 评估（多指标）            │
│            │                                        │
│  产物层   模型保存（joblib / ONNX）+ 评估报告           │
└─────────────────────────────────────────────────────┘
```

```python
# pipeline 骨架：每一步一个函数，串起来就是完整建模流程
def build_pipeline(cfg):

    report = eda(df)             # 特征层
```

## NumPy

本项目里 NumPy 是底层数值运算的载体：特征数组的矩阵变换、缺失值掩码、统计量的向量化计算都基于 ndarray。Pandas/Sklearn 的输入输出本质都是 NumPy 数组，理解 ndarray 才能调通这三者之间的数据流。

```python
import numpy as np

# 特征矩阵的向量化处理：不用 for 循环逐行算
X = np.random.randn(1000, 5)
X = np.where(np.isnan(X), 0.0, X)          # 缺失值掩码填充
X_norm = (X - X.mean(axis=0)) / X.std(axis=0)   # 按列标准化

# 统计量向量化：一次算出所有列的均值/方差/分位数
print(X.mean(axis=0).round(3))
print(np.percentile(X, [25, 50, 75], axis=0))
```

```text
NumPy 在本项目中的三个角色：
1. 底层存储 —— Pandas 列数据、Sklearn 特征矩阵都是 ndarray
2. 向量化计算 —— 逐列的统计/标准化/分箱，避免 Python for 循环
3. 与 C 库对接 —— 内存布局连续时，可直接传给 ONNX Runtime 等推理引擎
```

## SciPy

SciPy 承担 Pandas/Sklearn 覆盖不到的「科学计算」职责：统计检验（t 检验、卡方）、分布拟合、插值、稀疏矩阵。本项目里典型用途是 EDA 阶段的分布检验和特征工程阶段的 Box-Cox 变换（`scipy.stats.boxcox`）。

```python
from scipy import stats
import numpy as np

# EDA：正态性检验（Shapiro-Wilk）+ 相关性检验（Pearson）
x = np.random.randn(500)
print(stats.shapiro(x))                     # (统计量, p值)，p>0.05 接受正态
y = 2 * x + np.random.randn(500) * 0.5
print(stats.pearsonr(x, y))                 # 相关系数 + p 值

# 特征工程：Box-Cox 把偏态特征拉向正态
x_skew = np.exp(np.random.randn(500))       # 对数正态，明显右偏
x_box, lam = stats.boxcox(x_skew)
print(f"lambda={lam:.2f}, 变换后偏度={stats.skew(x_box):.2f}")
```

## Scikit-learn

建模层统一走 Scikit-learn。它最大的价值不是某个算法，而是 `Estimator` 的统一接口：所有模型都有 `fit` / `predict` / `transform`，可以塞进同一个 `Pipeline` 里做交叉验证和调参。本项目用 `Pipeline` 把「预处理 + 模型」打包，避免测试集泄露。

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression

# Pipeline：预处理和模型打包，交叉验证时不会泄露
pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("clf", LogisticRegression()),
])
pipe.fit(X_train, y_train)
print(pipe.predict_proba(X_test[:3]))
```

```text
Scikit-learn 统一接口：
- fit(X, y)      —— 训练
- predict(X)     —— 预测标签
- predict_proba  —— 输出概率（分类）
- transform(X)   —— 特征变换（预处理器）
所有 estimator 都能放进 Pipeline / GridSearchCV，接口一致才能自动化。
```

## 数据清洗

清洗是建模的第一道关卡。本项目把清洗拆成四步：缺失值处理、异常值处理、重复值去重、类型校正，每步一个函数，产出可复用的清洗规则。

```python
import pandas as pd
import numpy as np

def clean(df: pd.DataFrame) -> pd.DataFrame:
    df = df.copy()
    # 1. 缺失值：数值列中位数填充，类别列众数填充
    for col in df.columns:
        if df[col].dtype in ("float64", "int64"):
            df[col] = df[col].fillna(df[col].median())
        else:
            df[col] = df[col].fillna(df[col].mode()[0] if not df[col].mode().empty else "unknown")
    # 2. 异常值：按 IQR 截断
    for col in df.select_dtypes("number").columns:
        q1, q3 = df[col].quantile([0.25, 0.75])
        iqr = q3 - q1
        df[col] = df[col].clip(q1 - 1.5 * iqr, q3 + 1.5 * iqr)
    # 3. 重复值
    df = df.drop_duplicates()
    # 4. 类型校正
    df["amount"] = pd.to_numeric(df["amount"], errors="coerce")
    return df
```

## EDA

探索性分析在建模前回答三个问题：数据长什么样、特征和目标什么关系、有没有直接可用的强特征。本项目用一份函数产出「缺失率 + 分布 + 相关性」三张表，配合可视化快速定位问题。

```python
import pandas as pd
import numpy as np

def eda(df: pd.DataFrame, target: str = None):
    # 1. 概览：形状、缺失率、类型
    missing = df.isna().mean().round(3)
    # 2. 数值列分布：均值/标准差/偏度
    desc = df.describe().T[["mean", "std", "min", "max"]]
    # 3. 与目标相关性
    corr = None
    if target:
        corr = df.select_dtypes("number").corr()[target].abs().sort_values(ascending=False)
    return {"shape": df.shape, "missing": missing, "desc": desc, "corr": corr}

report = eda(df, target="amount")
print(report["shape"], report["missing"])
print(report["corr"].head())     # 和目标最相关的特征排前面
```

## 特征工程

把原始列转换成模型能吃的数值特征。本项目覆盖三类：数值特征（标准化、分箱、log 变换）、类别特征（One-Hot、Target Encoding）、时间特征（拉取年月日时分、节假日标记）。时间特征可参考 [[08.5-时间特征]]。

```python
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
import pandas as pd

# 数值 + 类别特征统一转换
df = pd.DataFrame({
    "age": [22, 45, 30, 35],
    "city": ["北京", "上海", "北京", "深圳"],
})
prep = ColumnTransformer([
    ("num", StandardScaler(), ["age"]),
    ("cat", OneHotEncoder(handle_unknown="ignore"), ["city"]),
])
X = prep.fit_transform(df)
print(X.toarray().round(2))
```

```python
# Target Encoding：类别特征用目标均值编码（需配合交叉验证防泄露）
def target_encode(df, cat_col, target_col, k=5):
    global_mean = df[target_col].mean()
    agg = df.groupby(cat_col)[target_col].agg(["mean", "count"])
    smoothing = 1 / (1 + np.exp(-(agg["count"] - k) / k))
    return agg["mean"] * smoothing + global_mean * (1 - smoothing)

print(target_encode(df, "city", "amount"))
```

## 训练

训练层用「交叉验证 + 超参数搜索」保证模型稳定。本项目用 `StratifiedKFold`（分类）或 `KFold`（回归）配合 `GridSearchCV`，一次跑出最优参数和泛化估计。

```python
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.datasets import make_classification

X, y = make_classification(n_samples=2000, n_features=10, random_state=42)
params = {"n_estimators": [50, 100], "max_depth": [3, 5], "learning_rate": [0.05, 0.1]}
gs = GridSearchCV(
    GradientBoostingClassifier(),
    params,
    cv=StratifiedKFold(5, shuffle=True, random_state=42),
    scoring="roc_auc",
    n_jobs=-1,
)
gs.fit(X, y)
print(gs.best_params_)       # 最优超参数
print(gs.best_score_)        # 交叉验证 AUC
```

## 评估

评估不只报一个准确率。分类用混淆矩阵 + Precision/Recall/AUC，回归用 MAE/MSE/R²。本项目统一输出指标字典，避免「只看准确率误判模型好坏」，详见 [[08.6-模型评估]]。

```python
from sklearn.metrics import (classification_report, roc_auc_score,
                             mean_absolute_error, r2_score)

def evaluate(model, X, y, task="classification"):
    y_pred = model.predict(X)
    if task == "classification":
        y_proba = model.predict_proba(X)[:, 1]
        return {
            "auc": roc_auc_score(y, y_proba),
            "report": classification_report(y, y_pred, output_dict=True),
        }
    return {
        "mae": mean_absolute_error(y, y_pred),
        "r2": r2_score(y, y_pred),
    }

metrics = evaluate(gs.best_estimator_, X, y)
print(metrics["auc"])
```

## 应用场景实战

### 场景一：用户流失预测完整流水线

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split, StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score, classification_report

# 造一份模拟的用户行为数据
rng = np.random.default_rng(42)
n = 5000
df = pd.DataFrame({
    "age": rng.integers(18, 60, n),
    "login_days": rng.integers(0, 30, n),
    "order_cnt": rng.integers(0, 10, n),
    "avg_amount": rng.gamma(2, 50, n),
    "churn": rng.integers(0, 2, n),
})
# 注入一个强信号：登录天数低、订单少 → 更容易流失
df["churn"] = ((df["login_days"] < 5) & (df["order_cnt"] < 2)).astype(int)

X = df.drop(columns="churn")
y = df["churn"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

pipe = Pipeline([("scaler", StandardScaler()),
                 ("clf", GradientBoostingClassifier(n_estimators=100, max_depth=3))])
cv_auc = cross_val_score(pipe, X_train, y_train, cv=StratifiedKFold(5, shuffle=True, random_state=42),
                         scoring="roc_auc").mean()
pipe.fit(X_train, y_train)
test_auc = roc_auc_score(y_test, pipe.predict_proba(X_test)[:, 1])
print(f"CV AUC={cv_auc:.3f}, Test AUC={test_auc:.3f}")
print(classification_report(y_test, pipe.predict(X_test)))
```

## 最佳实践与踩坑记录

### 最佳实践

1. 预处理和模型打包进同一个 Pipeline，交叉验证才不会把测试集信息泄露到特征工程里
2. 类别特征做 Target Encoding 时必须在 fold 内计算编码，否则直接过拟合
3. 清洗规则写成函数并记录版本，模型复现依赖同一套清洗逻辑
4. 评估分类任务别只看准确率，类别不平衡时优先看 AUC / PR-AUC
5. 保存模型时把特征名、预处理 Pipeline 一起存，避免线上特征对不上
6. 大数据量先过 Polars 惰性扫描瘦身，再转 Pandas 做细粒度清洗

### 踩坑记录

```text
坑 1：交叉验证时把标准化放进了 fold 外
结论：测试集信息泄露进训练，CV 分数虚高、线上掉点。
原因：先对全量数据 fit StandardScaler 再切分，均值方差混入了测试集。
解法：把 scaler 和模型一起放进 Pipeline，交给 cross_val_score 统一处理。

坑 2：Target Encoding 用全量数据算均值
结论：类别编码直接「看见」了标签，验证集上过拟合。
原因：编码时用了包含当前样本的目标均值。
解法：在 K-Fold 内用「其他 fold」的均值编码，或加平滑系数抑制小类别。

坑 3：Pandas 的 inplace 原地修改导致链式赋值告警
结论：df[df.a>0]['b']=1 这种写法不生效或告警，数据没改到。
原因：链式索引返回的是副本，赋值落到临时对象上。
解法：用 .loc 一次定位：df.loc[df.a>0, 'b'] = 1。

坑 4：joblib 保存的模型换了环境加载报错
结论：换机器/换 sklearn 版本后 joblib.load 失败。
原因：joblib 序列化依赖 Python 对象和库版本，跨版本不兼容。
解法：固定依赖版本，或跨语言/跨版本场景改用 ONNX 导出。

坑 5：Box-Cox 变换对含负值/零值的特征直接报错
结论：scipy.stats.boxcox 输入必须严格为正。
原因：Box-Cox 只定义在正数域，log 变换同理。
解法：负值/零值用 Yeo-Johnson（PowerTransformer），或先平移再变换。
```
