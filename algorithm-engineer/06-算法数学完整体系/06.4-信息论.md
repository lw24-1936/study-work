## 概述

信息论量化「信息」与「不确定性」，是机器学习损失函数和评估指标的理论来源：交叉熵是分类/语言模型的标准损失，KL 散度是 VAE 和分布对齐的核心，困惑度是语言模型的评估指标。它区别于 03.6 的前置概览，这里从算法/ML 视角深入每个概念并给出实现。

```text
信息论在算法中的核心地位：
1. 损失函数 —— 交叉熵 = 分类任务默认损失，等于 KL + 熵
2. 分布对齐 —— KL/JS 散度度量两个分布的距离
3. 特征选择 —— 互信息/信息增益挑选最有用的特征
4. 模型评估 —— 困惑度衡量语言模型质量
```

```python
import numpy as np

# 信息论的核心直觉：越不确定的事件，信息量越大
# 自信息 I(x) = -log P(x)
p = np.array([0.9, 0.5, 0.1])
self_info = -np.log2(p)
print('自信息（越稀有信息量越大）:', self_info)   # [0.15 1.0 3.32]
```

## Entropy

熵（Entropy）度量随机变量的不确定性：分布越均匀，熵越大；越集中，熵越小。它是信息量的期望，是理解一切信息度量的起点。

```text
数学定义：
H(X) = -Σ P(x) log P(x) = E[-log P(X)]

性质：
1. 非负：H(X) ≥ 0
2. 均匀分布熵最大：离散均匀分布 H = log n
3. 确定事件熵为 0：P(x)=1 时 H=0

底数：log2 单位 bit，ln 单位 nat，log10 单位 hart
```

```python
import numpy as np

def entropy(p, base=2):
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                       # 过滤 0（0 log 0 = 0）
    return -np.sum(p * np.log(p)) / np.log(base)

# 熵最大 = 均匀分布
uniform = np.array([0.25, 0.25, 0.25, 0.25])
peaked = np.array([0.97, 0.01, 0.01, 0.01])
print(f'均匀分布熵: {entropy(uniform):.3f} bit')   # 2.0（= log2 4）
print(f'集中分布熵: {entropy(peaked):.3f} bit')     # ≈ 0.24
```

## Cross Entropy

交叉熵（Cross Entropy）度量「用分布 q 编码真实分布 p」所需的平均编码长度。它是分类任务的标准损失函数，最小化交叉熵等价于让预测分布逼近真实分布。

```text
数学定义：
H(p, q) = -Σ p(x) log q(x)

分解：H(p, q) = H(p) + D_KL(p ‖ q)
（交叉熵 = 真实分布的熵 + KL 散度）

分类损失：真实标签 one-hot p，预测概率 q
L = -Σ y_i log ŷ_i（多分类 softmax 交叉熵）
```

```python
import numpy as np

# 多分类交叉熵
def cross_entropy(y_true, y_pred):
    y_pred = np.clip(y_pred, 1e-12, 1.0)
    return -np.sum(y_true * np.log(y_pred))

y_true = np.array([1, 0, 0])          # 真实类别 0
y_pred_good = np.array([0.8, 0.1, 0.1])
y_pred_bad = np.array([0.3, 0.3, 0.4])

print(f'好预测 CE: {cross_entropy(y_true, y_pred_good):.3f}')
print(f'坏预测 CE: {cross_entropy(y_true, y_pred_bad):.3f}')
```

```python
import torch
import torch.nn.functional as F

# PyTorch 交叉熵（自动含 softmax + log）
logits = torch.tensor([[2.0, 0.5, -1.0], [0.1, 3.0, 0.2]])
labels = torch.tensor([0, 1])
loss = F.cross_entropy(logits, labels)
print(f'PyTorch CE loss: {loss.item():.3f}')
```

## KL Divergence

KL 散度（KL Divergence）度量两个分布 p 和 q 的差异：用 q 近似 p 时「额外损失的信息」。它不对称，是 VAE 正则项、蒸馏、分布对齐的核心。

```text
数学定义：
D_KL(p ‖ q) = Σ p(x) log(p(x) / q(x)) = E_p[log(p/q)]

性质：
1. 非负：D_KL ≥ 0（Gibbs 不等式），等于 0 当且仅当 p = q
2. 不对称：D_KL(p‖q) ≠ D_KL(q‖p)
3. 不是真正的距离（不满足对称性和三角不等式）

直观：D_KL(p‖q) 是「用 q 编码 p 的额外成本」
```

```python
import numpy as np

def kl_divergence(p, q):
    p = np.asarray(p); q = np.asarray(q)
    p = np.clip(p, 1e-12, 1); q = np.clip(q, 1e-12, 1)
    return np.sum(p * np.log(p / q))

p = np.array([0.7, 0.3])
q = np.array([0.5, 0.5])

print(f'D_KL(p‖q) = {kl_divergence(p, q):.4f}')
print(f'D_KL(q‖p) = {kl_divergence(q, p):.4f}')   # 不对称！
```

## JS Divergence

JS 散度（Jensen-Shannon Divergence）是 KL 散度的对称化版本，取值在 [0, 1]（log2 时），解决了 KL 不对称和可能无穷大的问题。它是 GAN 早期损失的理论基础。

```text
数学定义：
D_JS(p ‖ q) = ½ D_KL(p ‖ m) + ½ D_KL(q ‖ m)
其中 m = (p + q) / 2 是两分布的平均

性质：
1. 对称：D_JS(p‖q) = D_JS(q‖p)
2. 有界：[0, log 2]（自然对数下），KL 可无界
3. 平方根 sqrt(D_JS) 是真正的距离度量
```

```python
import numpy as np
from scipy.spatial.distance import jensenshannon

p = np.array([0.7, 0.3])
q = np.array([0.5, 0.5])

# scipy 的 jensenshannon 返回 sqrt(D_JS)
js_dist = jensenshannon(p, q)
print(f'JS 散度: {js_dist**2:.4f}')       # D_JS
print(f'JS 距离: {js_dist:.4f}')          # sqrt(D_JS)

# 手写验证
def js_divergence(p, q):
    m = 0.5 * (p + q)
    return 0.5 * kl_divergence(p, m) + 0.5 * kl_divergence(q, m)
print(f'手写 D_JS: {js_divergence(p, q):.4f}')
```

## Mutual Information

互信息（Mutual Information）度量两个变量「共享的信息」：知道一个变量能减少另一个变量多少不确定性。它对称、非负，用于特征选择、因果发现、表示学习。

```text
数学定义：
I(X; Y) = Σ Σ P(x,y) log(P(x,y) / (P(x)P(y)))

等价形式：
1. I(X;Y) = H(X) - H(X|Y)（Y 减少 X 的不确定性）
2. I(X;Y) = H(X) + H(Y) - H(X,Y)
3. I(X;Y) = D_KL(P(X,Y) ‖ P(X)P(Y))（联合与独立的距离）

性质：对称、非负；独立时 I=0（反之不成立）
```

```python
import numpy as np
from sklearn.feature_selection import mutual_info_classif

# 特征选择：哪个特征与标签的互信息最大
np.random.seed(0)
X1 = np.random.randn(500)                       # 无关特征
X2 = np.random.randn(500)                       # 相关特征
y = (X2 > 0).astype(int)                        # 标签由 X2 决定

X = np.column_stack([X1, X2])
mi = mutual_info_classif(X, y, random_state=0)
print(f'互信息: X1={mi[0]:.3f}, X2={mi[1]:.3f}')
# X2 的互信息远大于 X1 → X2 是有效特征
```

## Information Gain

信息增益（Information Gain）是决策树分裂时选特征的准则：用某特征划分后，标签熵下降多少。下降越多，特征越有价值，即分裂前后熵的差。

```text
数学定义：
IG(D, A) = H(D) - Σ_v (|D_v| / |D|) · H(D_v)

其中：
- H(D)：划分前标签的熵
- D_v：特征 A 取值 v 的子集
- 加权后熵：划分后各子集熵的加权平均

等价于：标签与特征的互信息 I(Y; A)
```

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import make_classification

# 信息增益：决策树特征重要性
X, y = make_classification(n_samples=500, n_features=10,
                           n_informative=3, random_state=0)
tree = DecisionTreeClassifier(criterion='entropy', max_depth=5)
tree.fit(X, y)

print('特征重要性（基于信息增益）:')
print(np.round(tree.feature_importances_, 3))
# 前 3 个 informative 特征的 importance 显著更高
```

## Perplexity

困惑度（Perplexity）是语言模型的核心评估指标：模型对测试语料的「平均惊讶程度」。困惑度越低，模型越好。它直接由交叉熵取指数得到。

```text
数学定义：
PPL = exp(-(1/N) Σ log P(w_i | context))
    = 2^H(p, q)（以 bit 为单位）

含义：
1. 相当于「均匀分布的有效词汇数」
2. PPL = 10 表示模型平均在 10 个等可能词里猜
3. PPL 越低越好，最小值为 1

与交叉熵关系：PPL = exp(cross_entropy)
```

```python
import numpy as np
import torch
import torch.nn.functional as F

# 困惑度 = exp(交叉熵)
def perplexity(logits, targets):
    ce = F.cross_entropy(logits, targets, reduction='mean')
    return torch.exp(ce)

# 模拟语言模型输出：词表 10000
torch.manual_seed(0)
logits = torch.randn(100, 10000)        # 100 步预测
targets = torch.randint(0, 10000, (100,))

ppl = perplexity(logits, targets)
print(f'困惑度: {ppl.item():.1f}')       # 接近词表大小，说明模型很弱

# 完美预测时 PPL → 1
logits_perfect = torch.zeros(100, 10000)
logits_perfect[range(100), targets] = 100.0   # 正确位置极高
print(f'完美预测困惑度: {perplexity(logits_perfect, targets).item():.3f}')
```

## 应用场景实战

### 场景一：KL 散度做知识蒸馏的温度缩放

```python
import numpy as np

# 教师模型和学生模型的 softmax 概率（带温度 T 软化）
def softmax_with_temperature(logits, T):
    logits = np.asarray(logits) / T
    e = np.exp(logits - logits.max())
    return e / e.sum()

teacher_logits = np.array([4.0, 1.0, 0.5])
student_logits = np.array([2.0, 1.0, 0.8])

T = 3.0   # 温度：越高分布越软，越能传递「暗知识」
p_teacher = softmax_with_temperature(teacher_logits, T)
p_student = softmax_with_temperature(student_logits, T)

kl = np.sum(p_teacher * np.log(p_teacher / p_student))
print(f'温度 {T} 下教师分布: {np.round(p_teacher, 3)}')
print(f'蒸馏 KL 损失: {kl:.4f}')
```

### 场景二：互信息做特征筛选

```python
import numpy as np
from sklearn.feature_selection import SelectKBest, mutual_info_classif

np.random.seed(1)
X = np.random.randn(1000, 20)
# 只有第 3、7、15 个特征真正与标签相关
y = (X[:, 3] + X[:, 7] * 0.5 - X[:, 15] > 0).astype(int)

# 选互信息最高的 5 个特征
selector = SelectKBest(mutual_info_classif, k=5)
X_selected = selector.fit_transform(X, y)
selected_idx = np.where(selector.get_support())[0]
print('选中的特征索引:', selected_idx)   # 应包含 3, 7, 15
```

## 最佳实践与踩坑记录

### 最佳实践

1. 分类任务默认用交叉熵损失，它和 softmax 组合梯度简洁、数值稳定
2. 算 KL/熵时对概率做 clip 或加极小值，避免 log(0) 产生 -inf/NaN
3. 语言模型评估统一用困惑度，方便跨模型、跨语料比较
4. 分布对齐优先用 JS 散度（对称有界），比 KL 更稳定
5. 特征选择用互信息能捕捉非线性关系，比皮尔逊相关更强
6. 知识蒸馏时用温度软化教师分布，让学生学到类间关系

### 踩坑记录

```text
坑 1：log(0) 导致 NaN
结论：算熵或 KL 时出现 NaN/-inf。
原因：概率为 0 时 log(0) 无定义，未做处理。
解法：对概率 np.clip(p, 1e-12, 1) 或过滤 p>0 的项。

坑 2：混淆 KL 散度的方向
结论：用 D_KL(q‖p) 代替 D_KL(p‖q)，优化目标完全不同。
原因：KL 不对称，方向不同含义不同（forward/reverse KL）。
解法：明确 p 是真实分布、q 是模型分布，通常最小化 D_KL(p‖q)。

坑 3：把熵直接当损失却用错方向
结论：想最大化熵（如强化学习探索）却写成最小化。
原因：熵越大不确定性越高，方向上容易搞反。
解法：明确目标：正则项用 -H 最大化熵，压缩用最小化熵。

坑 4：困惑度直接用自然对数却标 bit 单位
结论：不同底数导致困惑度数值不可比。
原因：exp 和 log 底数要一致，ln 对应 e，log2 对应 2。
解法：统一用自然对数（PyTorch 默认）或统一 bit，报告时注明。

坑 5：用皮尔逊相关代替互信息做特征选择
结论：遗漏非线性关系的特征。
原因：皮尔逊只捕捉线性相关，互信息捕捉任意依赖。
解法：连续特征用 mutual_info_regression/classif，捕捉非线性。
```
