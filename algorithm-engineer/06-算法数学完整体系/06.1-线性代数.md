## 概述

线性代数是算法工程师最重要的数学工具：数据是矩阵、特征是向量、模型是矩阵运算、降维是矩阵分解、深度学习是张量运算。它区别于 03.4 的前置概览，这里从算法/ML 视角深入每一个概念，并给出 NumPy/PyTorch 实现。

```text
线性代数在算法中的核心地位：
1. 数据表示 —— 样本是向量，数据集是矩阵，batch 是张量
2. 模型表达 —— 线性模型 w·x、神经网络 Wx+b 都是矩阵运算
3. 降维与压缩 —— SVD/PCA 是推荐系统与降维的基石
4. 优化求解 —— 正规方程、梯度、Hessian 都依赖矩阵微积分
```

```python
import numpy as np
import torch

# 数据 = 矩阵：n 个样本、d 个特征的二维数组
X = np.random.randn(100, 10)      # 100 样本 x 10 特征
print(X.shape)                    # (100, 10)
```

## 向量空间

向量空间（Vector Space）是定义在数域上、满足加法和数乘封闭性的集合。算法里的特征空间、隐空间、Embedding 空间都是向量空间的实例。

```text
数学定义：
向量空间 V 满足（对任意 u, v ∈ V，标量 a, b ∈ F）：
1. 加法封闭：u + v ∈ V
2. 数乘封闭：a·u ∈ V
3. 八条公理：结合律、交换律、零元、负元、分配律等

子空间：V 的非空子集 W 若也封闭，则是子空间
基与维数：线性无关且能张成整个空间的一组向量叫基，个数叫维数
```

```python
import numpy as np

# 验证向量空间：R^3 中所有向量张成的空间
v1 = np.array([1, 0, 0])
v2 = np.array([0, 1, 0])
v3 = np.array([0, 0, 1])

# 任意向量可表示为基的线性组合
x = np.array([3, -2, 5])
coeffs = np.array([x[0], x[1], x[2]])
reconstructed = coeffs[0] * v1 + coeffs[1] * v2 + coeffs[2] * v3
print(reconstructed)   # [ 3 -2  5]，张成 R^3
```

## 范数

范数（Norm）度量向量的「长度」，是机器学习正则化、距离度量、梯度裁剪的理论基础。最常用的是 L1、L2 和 L∞ 范数。

```text
数学定义：
Lp 范数：‖x‖_p = (Σ |x_i|^p)^(1/p)

1. L1 范数：‖x‖₁ = Σ |x_i|          → 稀疏、特征选择（Lasso）
2. L2 范数：‖x‖₂ = (Σ x_i²)^(1/2)   → 欧氏距离、正则化（Ridge）
3. L∞ 范数：‖x‖_∞ = max |x_i|        → 最坏情况上界
4. Frobenius 范数：‖A‖_F = (Σ a_ij²)^(1/2) → 矩阵版 L2
```

```python
import numpy as np

x = np.array([3, -4, 0])
print(np.linalg.norm(x, 1))      # 7.0   L1
print(np.linalg.norm(x, 2))      # 5.0   L2（欧氏长度）
print(np.linalg.norm(x, np.inf)) # 4.0   L∞

A = np.array([[1, 2], [3, 4]])
print(np.linalg.norm(A, 'fro'))  # 5.477... Frobenius
```

## 内积

内积（Inner Product）把两个向量映射为一个标量，度量「方向相似度」。点积是最常见的内积，是注意力机制、相似度检索（cosine）、核方法的数学基础。

```text
数学定义：
标准内积（点积）：⟨x, y⟩ = x·y = Σ x_i y_i = ‖x‖‖y‖cos(θ)

性质：
1. 对称性：⟨x, y⟩ = ⟨y, x⟩
2. 线性性：⟨ax+bz, y⟩ = a⟨x, y⟩ + b⟨z, y⟩
3. 正定性：⟨x, x⟩ ≥ 0，等号当且仅当 x = 0

余弦相似度：cos(θ) = ⟨x, y⟩ / (‖x‖‖y‖)
```

```python
import numpy as np

x = np.array([1, 2, 3])
y = np.array([4, 5, 6])

dot = np.dot(x, y)                     # 点积
cosine = dot / (np.linalg.norm(x) * np.linalg.norm(y))
print(dot, cosine)                     # 32 0.9746...

# 矩阵内积（一次算 batch 相似度）
X = np.random.randn(10, 5)
S = X @ X.T                            # 10x10 的 Gram 矩阵（两两内积）
print(S.shape)
```

## 正交

正交（Orthogonal）指两个向量内积为 0，几何上「垂直」。正交基、正交矩阵是 QR 分解、旋转、PCA 的核心概念。

```text
数学定义：
正交向量：⟨x, y⟩ = 0
正交矩阵 Q：QᵀQ = QQᵀ = I，即 Q⁻¹ = Qᵀ，列向量两两正交且单位长

性质：
1. 正交矩阵保持长度：‖Qx‖ = ‖x‖
2. 正交矩阵保持内积：⟨Qx, Qy⟩ = ⟨x, y⟩（旋转不改变夹角）
3. det(Q) = ±1
```

```python
import numpy as np

# Gram-Schmidt 正交化：把任意基转成标准正交基
def gram_schmidt(A):
    Q = np.zeros_like(A, dtype=float)
    for i in range(A.shape[1]):
        q = A[:, i].astype(float)
        for j in range(i):
            q -= np.dot(Q[:, j], A[:, i]) * Q[:, j]
        Q[:, i] = q / np.linalg.norm(q)
    return Q

A = np.random.randn(5, 3)
Q = gram_schmidt(A)
print(np.round(Q.T @ Q, 5))   # 单位矩阵 → Q 是正交矩阵
```

## 投影

投影（Projection）把向量投到子空间上，得到「最近」的表示。最小二乘、PCA 降维、注意力里的残差都可理解为投影。

```text
数学定义：
向量 b 在向量 a 上的投影：proj_a(b) = (⟨a, b⟩ / ⟨a, a⟩) · a

在列空间上的正交投影矩阵：
P = A(AᵀA)⁻¹Aᵀ，投影结果 p = Pb

最小二乘：min ‖Ax - b‖² 的解满足 Ax 是 b 在列空间上的投影
```

```python
import numpy as np

# b 在 a 方向上的投影
a = np.array([1, 0])
b = np.array([1, 1])
proj = (np.dot(a, b) / np.dot(a, a)) * a
print(proj)   # [1. 0.]

# 正交投影矩阵 P
A = np.random.randn(5, 2)
P = A @ np.linalg.inv(A.T @ A) @ A.T
print(np.allclose(P @ P, P))   # True，投影矩阵幂等 P² = P
```

## 矩阵

矩阵（Matrix）是二维数组，算法里无处不在。核心运算有矩阵乘法、转置、逆、伪逆，其中「矩阵乘法 = 线性变换」这个观点是理解一切的基础。

```text
数学定义：
矩阵乘法：(AB)_ij = Σ_k A_ik B_kj

关键观点：
1. 矩阵 = 线性变换：y = Ax 把向量 x 变换到 y
2. 列空间：A 的列向量张成的空间，Ax 是其线性组合
3. 逆矩阵：AA⁻¹ = I，仅方阵且满秩时存在
4. 伪逆（Moore-Penrose）：A⁺ = (AᵀA)⁻¹Aᵀ，用于不可逆/非方阵
```

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A @ B)                 # 矩阵乘法
print(A.T)                   # 转置
print(np.linalg.inv(A))      # 逆矩阵
print(np.linalg.pinv(A))     # 伪逆（非方阵也能用）
```

## Rank

秩（Rank）是矩阵线性无关列（或行）的最大个数，等于列空间的维数。它刻画了矩阵「信息量」——低秩意味着数据冗余，是低秩分解、压缩、推荐系统的基础。

```text
数学定义：
rank(A) = A 的列空间中线性无关列的最大个数 = 非零奇异值个数

性质：
1. rank(A) ≤ min(m, n)
2. 满秩：方阵 rank(A) = n ⇔ 可逆 ⇔ det(A) ≠ 0
3. rank(AB) ≤ min(rank(A), rank(B))
4. 秩-零化度定理：rank(A) + dim(null(A)) = n
```

```python
import numpy as np

A = np.array([[1, 2, 3],
              [2, 4, 6],   # 第 2 行是第 1 行的 2 倍
              [1, 1, 1]])
print(np.linalg.matrix_rank(A))   # 2（第三行独立，前两行相关）

# 低秩近似：只保留最大的 k 个奇异值
U, s, Vt = np.linalg.svd(A)
k = 2
A_low = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
print(A_low)
```

## Determinant

行列式（Determinant）是方阵的一个标量，几何上表示线性变换对「有向体积」的缩放因子。det(A)=0 表示变换把空间压扁（降维），矩阵不可逆。

```text
数学定义（递归）：
det(A) = Σ_j (-1)^(i+j) a_ij · M_ij（按行展开，M 是余子式）

性质：
1. det(AB) = det(A)·det(B)
2. det(Aᵀ) = det(A)
3. det(A⁻¹) = 1/det(A)
4. det(A) ≠ 0 ⇔ A 可逆 ⇔ 满秩
5. 特征值之积：det(A) = Π λ_i
```

```python
import numpy as np

A = np.array([[2, 1], [1, 2]])
print(np.linalg.det(A))   # 3.0

# 验证 det(A) = 特征值之积
eigvals = np.linalg.eigvals(A)
print(np.prod(eigvals))   # 3.0（2x2 矩阵：特征值 3 和 1）

# det = 0 → 奇异矩阵，不可逆
S = np.array([[1, 2], [2, 4]])
print(np.linalg.det(S))   # 0.0
```

## Eigenvalue / Eigenvector

特征值与特征向量描述线性变换的「不动方向」：Ax 与 x 同向，只做伸缩。它们是 PCA、谱聚类、图算法、矩阵幂运算的根基。

```text
数学定义：
Ax = λx，其中 λ 是特征值，x ≠ 0 是特征向量

求解：解特征方程 det(A - λI) = 0 得到特征值，代回求特征向量

性质：
1. Σ λ_i = trace(A)（特征值之和 = 迹）
2. Π λ_i = det(A)（特征值之积 = 行列式）
3. 实对称矩阵特征值全为实数，特征向量可正交
```

```python
import numpy as np

A = np.array([[2, 1], [1, 2]])
eigvals, eigvecs = np.linalg.eig(A)
print(eigvals)      # [3. 1.]
print(eigvecs)      # 两列是单位特征向量

# 验证 Ax = λx
for i in range(2):
    lhs = A @ eigvecs[:, i]
    rhs = eigvals[i] * eigvecs[:, i]
    print(np.allclose(lhs, rhs))   # True True
```

## EVD

特征值分解（EVD，Eigendecomposition）把方阵分解为 A = QΛQ⁻¹。对实对称矩阵可写成 A = QΛQᵀ（Q 正交），这是 PCA 的核心。

```text
数学定义：
A = Q Λ Q⁻¹，其中 Q 的列是特征向量，Λ 是对角特征值矩阵

对称矩阵（如协方差矩阵）：A = Q Λ Qᵀ

PCA 流程：
1. 数据中心化，算协方差矩阵 C = XᵀX / n
2. 对 C 做 EVD：C = QΛQᵀ
3. 取前 k 大特征值对应的特征向量作为主成分方向
```

```python
import numpy as np

# 对称矩阵的 EVD
A = np.array([[2, 1], [1, 2]])
w, Q = np.linalg.eigh(A)          # 对称矩阵专用，特征值升序
reconstructed = Q @ np.diag(w) @ Q.T
print(np.allclose(reconstructed, A))   # True

# PCA 手写：用 EVD 对协方差矩阵降维
X = np.random.randn(100, 5)
Xc = X - X.mean(0)
C = Xc.T @ Xc / len(X)
w, Q = np.linalg.eigh(C)
k = 2
X_pca = Xc @ Q[:, -k:]            # 取最大 k 个特征值对应方向
print(X_pca.shape)                # (100, 2)
```

## SVD

奇异值分解（SVD）是最强大的矩阵分解，适用于任意 m×n 矩阵：A = UΣVᵀ。它是 PCA、推荐系统（矩阵分解）、图像压缩、伪逆、低秩近似的统一框架。

```text
数学定义：
A = U Σ Vᵀ
- U (m×m)：左奇异向量，AAᵀ 的特征向量
- Σ (m×n)：对角奇异值 σ₁ ≥ σ₂ ≥ ... ≥ 0（非负）
- V (n×n)：右奇异向量，AᵀA 的特征向量

联系：
1. AᵀA 的特征值 = σ²（奇异值的平方）
2. 截断 SVD：保留前 k 个奇异值 → 最佳 rank-k 近似
3. SVD 比 EVD 更通用：不需要方阵，数值更稳定
```

```python
import numpy as np

A = np.random.randn(6, 4)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
print(U.shape, s.shape, Vt.shape)   # (6,4) (4,) (4,4)

# 重建：A = U @ diag(s) @ Vt
A_recon = U @ np.diag(s) @ Vt
print(np.allclose(A, A_recon))      # True

# 截断 SVD 低秩近似（图像/矩阵压缩）
k = 2
A_low = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
print(f'保留 {k}/{len(s)} 个奇异值，误差: {np.linalg.norm(A - A_low):.3f}')
```

## QR

QR 分解把矩阵分解为正交矩阵 Q 和上三角矩阵 R：A = QR。它用于求解最小二乘、计算特征值（QR 迭代）、数值稳定的线性求解。

```text
数学定义：
A = Q R
- Q：正交矩阵（QᵀQ = I）
- R：上三角矩阵

最小二乘求解：
Ax = b → QRx = b → Rx = Qᵀb（R 上三角，回代即可解）
比正规方程 (AᵀA)⁻¹Aᵀb 数值更稳定，不放大条件数
```

```python
import numpy as np

A = np.random.randn(6, 3)
Q, R = np.linalg.qr(A)
print(np.allclose(Q @ R, A))              # True
print(np.allclose(Q.T @ Q, np.eye(3)))    # True，Q 正交

# QR 解最小二乘
b = np.random.randn(6)
x = np.linalg.solve(R, Q.T @ b)           # 回代
print(x)
```

## PSD / PD

正定（PD）与半正定（PSD）矩阵是机器学习中最重要的矩阵类别：协方差矩阵、Gram 矩阵、Hessian（凸函数）、核矩阵都是 PSD。PSD 保证二次型非负，是凸优化的关键。

```text
数学定义：
半正定（PSD）：对任意 x ≠ 0，xᵀAx ≥ 0 ⇔ 所有特征值 ≥ 0
正定（PD）：对任意 x ≠ 0，xᵀAx > 0 ⇔ 所有特征值 > 0

判断方法：
1. 所有特征值 ≥ 0（PSD）/ > 0（PD）
2. 所有顺序主子式 ≥ 0（Sylvester 判据，PD 时 > 0）
3. 可 Cholesky 分解：A = LLᵀ（仅 PD 可分解）

来源：任意矩阵 B，BᵀB 和 BBᵀ 都是 PSD
```

```python
import numpy as np

# 协方差矩阵一定是 PSD
X = np.random.randn(100, 5)
C = X.T @ X / len(X)
eigvals = np.linalg.eigvalsh(C)
print(eigvals.min())   # ≥ 0（数值上可能是极小正数）

# 验证 PSD：xᵀCx ≥ 0 对所有 x
x = np.random.randn(5)
print(x @ C @ x)       # ≥ 0

# Cholesky 分解（仅 PD 可做）
A = np.array([[4, 1], [1, 3]])
L = np.linalg.cholesky(A)
print(L @ L.T)         # 还原 A
```

## Trace

迹（Trace）是方阵对角线元素之和，等于特征值之和。它在矩阵求导、Frobenius 范数、循环求迹技巧（tr(AB)=tr(BA)）里频繁出现。

```text
数学定义：
trace(A) = Σ_i a_ii = Σ_i λ_i（特征值之和）

关键性质：
1. tr(A + B) = tr(A) + tr(B)
2. tr(cA) = c·tr(A)
3. tr(AB) = tr(BA)（循环性质，最重要）
4. tr(AᵀA) = ‖A‖_F²（Frobenius 范数平方）
5. tr(AᵀB) = ⟨A, B⟩（矩阵内积）
```

```python
import numpy as np

A = np.random.randn(4, 4)
print(np.trace(A))                 # 对角线之和
print(np.linalg.eigvals(A).sum())  # 等于特征值之和（复数取实部）

# 循环性质 tr(AB) = tr(BA)
B = np.random.randn(4, 4)
print(np.allclose(np.trace(A @ B), np.trace(B @ A)))   # True

# tr(AᵀA) = Frobenius 范数平方
print(np.allclose(np.trace(A.T @ A), np.linalg.norm(A, 'fro')**2))  # True
```

## Kronecker Product

克罗内克积（Kronecker Product）是两个矩阵的分块张量积，把 A 的每个元素 a_ij 替换成 a_ij·B。它用于多元统计、Kronecker 结构化协方差、某些图算法和 Kronecker 因子化。

```text
数学定义：
A ⊗ B = [[a₁₁B, a₁₂B, ...],
         [a₂₁B, a₂₂B, ...], ...]

A (m×n), B (p×q) → A ⊗ B (mp × nq)

性质：
1. (A ⊗ B)(C ⊗ D) = (AC) ⊗ (BD)
2. (A ⊗ B)ᵀ = Aᵀ ⊗ Bᵀ
3. (A ⊗ B)⁻¹ = A⁻¹ ⊗ B⁻¹
```

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 5], [6, 7]])
K = np.kron(A, B)
print(K.shape)   # (4, 4)
print(K)
# [[ 0  5  0 10]
#  [ 6  7 12 14]
#  [ 0 15  0 20]
#  [18 21 24 28]]
```

## Matrix Calculus

矩阵微积分（Matrix Calculus）研究标量对向量/矩阵、向量对向量的导数，是反向传播、正规方程推导、最大似然求解的数学语言。

```text
常用公式（分母布局）：
1. ∂(aᵀx)/∂x = a
2. ∂(xᵀAx)/∂x = (A + Aᵀ)x（对称时 = 2Ax）
3. ∂(‖Ax - b‖²)/∂x = 2Aᵀ(Ax - b)
4. ∂(log|x|)/∂x = 1/x（标量）

最小二乘闭式解推导：
L = ‖Xw - y‖² → ∂L/∂w = 2Xᵀ(Xw - y) = 0 → w = (XᵀX)⁻¹Xᵀy
```

```python
import numpy as np

# 数值验证 ∂(xᵀAx)/∂x = (A + Aᵀ)x
A = np.random.randn(3, 3)
x = np.random.randn(3)

def f(x): return x @ A @ x

eps = 1e-6
num_grad = np.zeros(3)
for i in range(3):
    dx = np.zeros(3); dx[i] = eps
    num_grad[i] = (f(x + dx) - f(x - dx)) / (2 * eps)

analytic = (A + A.T) @ x
print(np.allclose(num_grad, analytic, atol=1e-4))   # True
```

## Jacobian

雅可比矩阵（Jacobian）是「向量值函数」对「向量」的一阶导数矩阵，第 (i,j) 项是 ∂f_i/∂x_j。它描述非线性映射的局部线性化，是神经网络反向传播链式法则的载体。

```text
数学定义：
J_ij = ∂f_i / ∂x_j

f: R^n → R^m，则 J 是 m×n 矩阵：
J = [[∂f₁/∂x₁, ..., ∂f₁/∂x_n],
     ...
     [∂f_m/∂x₁, ..., ∂f_m/∂x_n]]

应用：
1. 反向传播：每层是一个 Jacobian，链式法则连乘
2. 非线性最小二乘：Gauss-Newton 用 Jacobian 近似 Hessian
3. 变换后协方差的传播
```

```python
import torch

# 用 autograd 计算 Jacobian
x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
f = torch.stack([x[0]**2 + x[1], torch.sin(x[1]) + x[2]**3])

J = torch.autograd.functional.jacobian(lambda t: f, x)
print(J)
# tensor([[2.0000, 1.0000, 0.0000],
#         [0.0000, -0.4161, 27.0000]])
```

## Hessian

海森矩阵（Hessian）是标量函数对向量的二阶导数矩阵，第 (i,j) 项是 ∂²f/∂x_i∂x_j。它刻画曲率，用于判断极值、牛顿法、损失函数凸性分析。

```text
数学定义：
H_ij = ∂²f / ∂x_i ∂x_j

对称性（Schwarz 定理）：混合偏导可交换 → H 对称

用途：
1. 二阶条件：∇f = 0 且 H 正定 → 局部极小
2. 牛顿法：x ← x - H⁻¹∇f
3. 凸性：H 处处 PSD ⇔ f 凸
```

```python
import torch

def f(x):
    return x[0]**2 + 3 * x[0] * x[1] + x[1]**2

x = torch.tensor([1.0, 2.0], requires_grad=True)
H = torch.autograd.functional.hessian(f, x)
print(H)
# tensor([[2., 3.],
#         [3., 2.]])
```

## Tensor

张量（Tensor）是标量、向量、矩阵的高维推广，是 PyTorch/TensorFlow 的核心数据结构。深度学习中 batch 数据、卷积核、注意力权重都是张量。

```text
数学定义：
0 阶张量 = 标量，1 阶 = 向量，2 阶 = 矩阵，n 阶 = n 维数组

深度学习里的常见张量形状：
1. batch 数据：(B, C, H, W) 图像 或 (B, T, D) 序列
2. 卷积核：(out_channels, in_channels, kH, kW)
3. 注意力：(B, num_heads, T, T)

关键操作：reshape、transpose、broadcast、einsum、matmul
```

```python
import torch

# 4 阶张量：batch 图像
imgs = torch.randn(32, 3, 224, 224)   # (B, C, H, W)
print(imgs.shape)

# 维度操作
print(imgs.mean(dim=(2, 3)).shape)    # (32, 3) 全局池化
print(imgs.transpose(1, 3).shape)     # (32, 224, 224, 3)

# einsum：矩阵乘法的通用表达
A = torch.randn(4, 5); B = torch.randn(5, 3)
C = torch.einsum('ik,kj->ij', A, B)
print(C.shape)   # (4, 3)
```

## 应用场景实战

### 场景一：用 SVD 做推荐系统矩阵分解

```python
import numpy as np

# 用户-物品评分矩阵（含缺失值，用 0 占位）
R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 5, 4],
    [0, 1, 5, 4],
], dtype=float)

# SVD 分解，取 rank-2 近似，填充缺失评分
U, s, Vt = np.linalg.svd(R, full_matrices=False)
k = 2
R_hat = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]

print('原始评分矩阵:')
print(R)
print('SVD 填充后的预测评分:')
print(np.round(R_hat, 2))
# 缺失位置 (0,2) 被预测出合理的值
```

from sklearn.decomposition import PCA
import numpy as np

## 最佳实践与踩坑记录

### 最佳实践

1. 数值求解优先用 SVD 和 QR，避免直接求逆（条件数大时误差爆炸）
2. 判断矩阵是否可逆/正定，先看特征值，再决定用 inv 还是 pinv
3. 协方差矩阵、Gram 矩阵要意识到它们是 PSD，可用 Cholesky 加速
4. 矩阵求导不确定时，用有限差分或 PyTorch autograd 数值验证
5. 高维数据先做 SVD/PCA 降维，既能去噪又能加速下游
6. 推荐系统的缺失评分用 SVD 截断填充，别用 0 直接算相似度

### 踩坑记录

```text
坑 1：直接求逆 (XᵀX)⁻¹ 解正规方程
结论：特征共线或条件数大时，结果数值不稳定甚至报错。
原因：XᵀX 条件数是 X 的平方，浮点误差被放大。
解法：用 np.linalg.lstsq 或 SVD/QR 求解，数值稳定。

坑 2：混淆 EVD 和 SVD 的适用场景
结论：对非方阵或病态矩阵强行做 EVD 会失败。
原因：EVD 只对方阵定义，且非对称矩阵特征值可能复数、特征向量不正交。
解法：一般矩阵用 SVD；只有对称矩阵（协方差等）才用 eigh 做 EVD。

坑 3：忘记数据是 PSD 却用一般求逆
结论：协方差矩阵求逆效率低且可能不稳定。
原因：PSD 矩阵有 Cholesky 分解 L Lᵀ，求逆更稳定。
解法：用 np.linalg.cholesky 或 scipy 的 solve(cholesky=True)。

坑 4：计算 cosine 相似度时忘记归一化
结论：直接用内积当相似度，被向量长度干扰。
原因：内积 = ‖x‖‖y‖cosθ，长度差异大会盖过方向信息。
解法：先 L2 归一化再点积，或显式除以模长。

坑 5：数值比较特征值是否为零用 ==
结论：本应奇异的矩阵，特征值算出 1e-16 而被误判非零。
原因：浮点误差让 det 不为精确 0。
解法：用阈值 np.isclose(x, 0, atol=1e-8) 判断。
```
