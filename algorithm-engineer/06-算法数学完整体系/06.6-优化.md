## 概述

优化是机器学习的发动机：训练模型 = 最小化损失函数。从凸优化的理论保证（Lagrange、KKT、对偶）到深度学习的实用算法（SGD、Adam、学习率调度），优化贯穿建模全流程。它区别于 03.5 的前置概览，这里从算法/ML 视角深入每个概念并给出实现。

```text
优化在算法中的核心地位：
1. 训练目标 —— 损失函数最小化是几乎所有模型的训练方式
2. 理论保证 —— 凸优化给出全局最优和收敛性证明
3. 实践核心 —— 优化器选择直接影响收敛速度和最终效果
4. 工程技巧 —— 学习率调度、warmup、梯度裁剪决定训练成败
```

```python
import numpy as np
import torch

# 优化的本质：找到让损失最小的参数
def loss(w, X, y):
    return np.mean((X @ w - y) ** 2)

X = np.random.randn(100, 5)
y = X @ np.array([1, 2, -1, 0.5, 0]) + 0.1
w0 = np.zeros(5)
print(f'初始损失: {loss(w0, X, y):.3f}')
```

## Convex Set

凸集（Convex Set）指集合内任意两点的连线都在集合内。凸集是凸优化的定义域基础，保证优化问题的「可行域」没有凹陷。

```text
数学定义：
集合 C 是凸集，若对任意 x, y ∈ C 和 θ ∈ [0, 1]：
θx + (1-θ)y ∈ C

常见凸集：
1. 超平面、半空间
2. 范数球：{x | ‖x‖ ≤ r}
3. 半正定锥：{X | X ⪰ 0}

判断：两点连线（凸组合）仍在集合内
```

```python
import numpy as np

def is_convex_combination_in_set(x, y, theta, in_set):
    """检查凸组合是否在集合内"""
    return in_set(theta * x + (1 - theta) * y)

# 验证范数球是凸集：‖x‖ ≤ 1
def in_unit_ball(v): return np.linalg.norm(v) <= 1

x = np.array([0.8, 0.0])
y = np.array([0.0, 0.9])
for theta in [0.2, 0.5, 0.8]:
    z = theta * x + (1 - theta) * y
    print(f'θ={theta}: 凸组合在球内? {in_unit_ball(z)}')
```

## Convex Function

凸函数（Convex Function）指函数图像在任意两点连线（弦）之下。凸函数的局部最优就是全局最优，是优化问题「好解」的关键性质。

```text
数学定义：
f 是凸函数，若对任意 x, y 和 θ ∈ [0, 1]：
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)

等价判断（可微时）：
1. 一阶条件：f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)（切线在下方）
2. 二阶条件：Hessian 处处半正定 H ⪰ 0

重要性：凸函数任意局部极小点都是全局极小点
```

```python
import numpy as np

def is_convex(f, x, y, n=100):
    """采样验证凸性：弦上值 ≥ 函数值"""
    for i in range(n):
        theta = i / n
        z = theta * x + (1 - theta) * y
        if f(z) > theta * f(x) + (1 - theta) * f(y) + 1e-10:
            return False
    return True

f_convex = lambda x: x**2        # 凸
f_nonconvex = lambda x: x**3     # 非凸（x<0 部分）

print('x² 凸?', is_convex(f_convex, np.array([-2.0]), np.array([2.0])))
print('x³ 凸?', is_convex(f_nonconvex, np.array([-2.0]), np.array([2.0])))
```

## Lagrange

拉格朗日乘子法（Lagrange Multipliers）求解带等式约束的优化问题：把约束和目标合并成拉格朗日函数，求驻点。

```text
数学定义：
min f(x)  s.t. g(x) = 0

构造拉格朗日函数：
L(x, λ) = f(x) + λ·g(x)

最优条件：∇_x L = 0，∇_λ L = 0（即 g(x)=0）

λ 含义：约束的「影子价格」，表示放松约束对目标的影响
```

```python
import numpy as np
from scipy.optimize import minimize

# min x² + y²  s.t. x + y = 1
def f(x): return x[0]**2 + x[1]**2
constraints = {'type': 'eq', 'fun': lambda x: x[0] + x[1] - 1}

res = minimize(f, [0.5, 0.5], constraints=constraints)
print(f'最优解: {res.x}')   # [0.5, 0.5]，拉格朗日乘子 λ 由 KKT 给出
print(f'最小值: {res.fun}')
```

## KKT

KKT 条件（Karush-Kuhn-Tucker）是不等式约束优化问题的最优性必要条件，是拉格朗日乘子法的推广，也是 SVM、约束优化的理论基础。

```text
数学定义（min f(x) s.t. g_i(x) ≤ 0, h_j(x) = 0）：
1. 稳定性：∇f + Σ λ_i ∇g_i + Σ μ_j ∇h_j = 0
2. 原始可行性：g_i(x) ≤ 0, h_j(x) = 0
3. 对偶可行性：λ_i ≥ 0
4. 互补松弛：λ_i · g_i(x) = 0

互补松弛含义：约束不活跃（g_i<0）时 λ_i=0；活跃时 λ_i>0
凸问题下 KKT 是充分必要条件
```

```python
import numpy as np
from scipy.optimize import minimize

# min x²  s.t. x ≥ 1（即 -x + 1 ≤ 0）
def f(x): return x[0]**2
constraints = {'type': 'ineq', 'fun': lambda x: x[0] - 1}  # x ≥ 1

res = minimize(f, [5.0], constraints=constraints)
print(f'最优解: {res.x[0]:.3f}')   # 1.0，约束活跃（g=0）
# 互补松弛：x=1 时约束活跃 λ>0；若无约束最优在 0，约束把解「推」到边界
```

## Duality

对偶性（Duality）把原始问题转成对偶问题：对偶问题给出原始最优值的下界（弱对偶），凸问题下二者相等（强对偶）。SVM 的对偶形式、拉格朗日对偶是经典应用。

```text
数学定义：
原始问题：min f(x) s.t. g_i(x) ≤ 0
拉格朗日：L(x, λ) = f(x) + Σ λ_i g_i(x)
对偶函数：g(λ) = min_x L(x, λ)
对偶问题：max_λ g(λ) s.t. λ ≥ 0

弱对偶：g(λ*) ≤ f(x*)（对偶 ≤ 原始）
强对偶：凸 + Slater 条件 → g(λ*) = f(x*)（相等）
对偶间隙 = 原始最优 - 对偶最优（应为 0 或非负）
```

```python
import numpy as np

# 简单对偶：min x²  s.t. x ≥ 1
# 原始最优 f* = 1（x=1）
# 拉格朗日 L = x² + λ(1-x)，对偶 g(λ) = min_x L = λ - λ²/4
# 对偶问题 max g(λ) = 1（λ=2 时），强对偶成立
def dual(lam): return lam - lam**2 / 4

# 数值求对偶最优
from scipy.optimize import minimize_scalar
res = minimize_scalar(lambda l: -dual(l), bounds=(0, 10), method='bounded')
print(f'对偶最优: {dual(res.x):.3f}（原始最优 1.0，强对偶相等）')
```

## GD

梯度下降（Gradient Descent, GD）沿负梯度方向迭代更新参数，是最基础的优化算法。每次用全量数据计算梯度，收敛稳定但计算昂贵。

```text
数学定义：
θ ← θ - η · ∇f(θ)

其中 η 是学习率，∇f 是全量数据梯度

特点：
1. 每次更新用全部样本，梯度准确、下降稳定
2. 计算成本高，大数据下每步都要扫全量
3. 凸函数下收敛到全局最优，收敛率 O(1/k)
```

```python
import numpy as np

# 全量梯度下降拟合线性回归
def gd(X, y, lr=0.01, epochs=500):
    w = np.zeros(X.shape[1])
    for _ in range(epochs):
        grad = (2 / len(X)) * X.T @ (X @ w - y)   # 全量梯度
        w -= lr * grad
    return w

X = np.random.randn(200, 3)
true_w = np.array([2.0, -1.0, 0.5])
y = X @ true_w + 0.1
w = gd(X, y)
print('GD 结果:', np.round(w, 3))   # ≈ [2, -1, 0.5]
```

## SGD

随机梯度下降（Stochastic Gradient Descent, SGD）每次用一个样本（或小批量）计算梯度更新。梯度有噪声但计算快，能逃离局部极小，是深度学习训练的基础。

```text
数学定义：
θ ← θ - η · ∇f_i(θ)（单个样本 i）

小批量 SGD（mini-batch）：
θ ← θ - η · (1/|B|) Σ_{i∈B} ∇f_i(θ)

特点：
1. 每步快，适合大规模数据
2. 梯度噪声帮助逃离鞍点/局部极小
3. 收敛震荡，需配合学习率衰减
```

```python
import numpy as np

# 小批量 SGD 拟合线性回归
def sgd(X, y, lr=0.01, epochs=200, batch_size=32):
    w = np.zeros(X.shape[1])
    n = len(X)
    for epoch in range(epochs):
        idx = np.random.permutation(n)
        for i in range(0, n, batch_size):
            batch = idx[i:i+batch_size]
            Xb, yb = X[batch], y[batch]
            grad = (2 / len(batch)) * Xb.T @ (Xb @ w - yb)
            w -= lr * grad
    return w

X = np.random.randn(1000, 3)
y = X @ np.array([2.0, -1.0, 0.5]) + 0.1
w = sgd(X, y)
print('SGD 结果:', np.round(w, 3))
```

## Momentum

动量法（Momentum）在梯度上累积历史速度，加速收敛并抑制震荡：像小球滚下坡，惯性帮助跨过局部极小和鞍点。

```text
数学定义：
v ← β·v - η·∇f(θ)    （β 通常 0.9）
θ ← θ + v

含义：
1. v 是累积的速度（历史梯度指数加权平均）
2. 同方向梯度持续累积 → 加速
3. 震荡方向互相抵消 → 稳定

Nesterov：先看「下一步位置」的梯度，更聪明
```

```python
import numpy as np

def sgd_momentum(X, y, lr=0.01, epochs=200, beta=0.9, batch_size=32):
    w = np.zeros(X.shape[1])
    v = np.zeros(X.shape[1])
    n = len(X)
    for epoch in range(epochs):
        idx = np.random.permutation(n)
        for i in range(0, n, batch_size):
            batch = idx[i:i+batch_size]
            Xb, yb = X[batch], y[batch]
            grad = (2 / len(batch)) * Xb.T @ (Xb @ w - yb)
            v = beta * v - lr * grad     # 动量更新
            w += v
    return w

X = np.random.randn(1000, 3)
y = X @ np.array([2.0, -1.0, 0.5]) + 0.1
w = sgd_momentum(X, y)
print('SGD+Momentum 结果:', np.round(w, 3))
```

## Adam

Adam（Adaptive Moment Estimation）结合动量和自适应学习率：一阶矩估计（动量）加二阶矩估计（梯度平方的滑动平均），是深度学习最常用的默认优化器。

```text
数学定义：
m ← β₁·m + (1-β₁)·g          （一阶矩，动量）
v ← β₂·v + (1-β₂)·g²         （二阶矩，梯度能量）
m̂ ← m / (1-β₁ᵗ)，v̂ ← v / (1-β₂ᵗ)   （偏差校正）
θ ← θ - η · m̂ / (√v̂ + ε)

默认超参：β₁=0.9, β₂=0.999, ε=1e-8, η=1e-3
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

for epoch in range(300):
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    optimizer.step()

print('Adam 学到的权重:', model.weight.data.numpy().round(3))
```

## AdamW

AdamW 把权重衰减（L2 正则）从梯度里解耦出来，直接作用在权重上。它修复了 Adam 的 L2 正则与自适应学习率耦合的问题，是当前训练 Transformer 的标准优化器。

```text
数学定义（与 Adam 的唯一区别）：
θ ← θ - η · (m̂ / (√v̂ + ε) + λ·θ)
              ↑ Adam 部分        ↑ 解耦的权重衰减

Adam 的 L2 问题：把 λθ 加进梯度后，会被自适应学习率 m̂/(√v̂+ε)
重新缩放，导致正则效果被削弱或扭曲
AdamW：权重衰减直接 θ ← θ(1-ηλ)，与梯度路径解耦
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

for epoch in range(300):
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    optimizer.step()

print('AdamW 学到的权重:', model.weight.data.numpy().round(3))
```

## RMSProp

RMSProp 用梯度平方的滑动平均来归一化每个参数的学习率：变化大的参数步长变小，变化小的参数步长变大，适合非平稳目标和 RNN 训练。

```text
数学定义：
E[g²] ← β·E[g²] + (1-β)·g²    （梯度平方的滑动平均）
θ ← θ - η · g / √(E[g²] + ε)

与 AdaGrad 区别：
- AdaGrad：累积所有历史梯度平方（单调增，学习率只会变小）
- RMSProp：滑动平均（可增可减，避免学习率过早衰减为 0）

默认 β = 0.9, ε = 1e-8
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.RMSprop(model.parameters(), lr=1e-2)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

for epoch in range(300):
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    optimizer.step()

print('RMSProp 学到的权重:', model.weight.data.numpy().round(3))
```

## AdaGrad

AdaGrad 为每个参数维护梯度平方的累积和，自适应调整学习率：频繁更新的参数学习率变小，稀疏参数保持较大学习率，适合稀疏特征场景。

```text
数学定义：
G ← G + g²                  （累积梯度平方和）
θ ← θ - η · g / √(G + ε)

特点：
1. 每个参数独立的学习率，适合稀疏梯度
2. 缺点：G 单调递增，学习率单调衰减，后期趋于 0 停止学习
3. 被 RMSProp/Adam 取代，但思想是自适应学习率的开山之作
```

```python
import numpy as np

def adagrad(X, y, lr=1.0, epochs=200, eps=1e-8):
    w = np.zeros(X.shape[1])
    G = np.zeros(X.shape[1])   # 累积梯度平方
    n = len(X)
    for epoch in range(epochs):
        for i in range(n):
            grad = 2 * X[i] * (X[i] @ w - y[i])
            G += grad ** 2
            w -= lr * grad / (np.sqrt(G) + eps)   # 自适应学习率
    return w

X = np.random.randn(500, 3)
y = X @ np.array([2.0, -1.0, 0.5]) + 0.1
w = adagrad(X, y)
print('AdaGrad 结果:', np.round(w, 3))
```

## Newton

牛顿法（Newton's Method）用二阶信息（Hessian 逆）指导更新方向，收敛速度是二次的，远快于梯度下降。但需要计算并求逆 Hessian，高维下开销巨大。

```text
数学定义：
θ ← θ - H⁻¹ · ∇f(θ)

推导：对 f 做二阶泰勒展开，求展开式的最小值点
f(θ+Δ) ≈ f(θ) + ∇fᵀΔ + ½ ΔᵀHΔ
令导数 = 0 → Δ = -H⁻¹∇f

特点：
1. 二次收敛：误差平方级下降，接近最优时极快
2. 代价：每步 O(n³) 求 Hessian 逆，高维不可行
3. 要求 H 正定，否则方向错误
```

```python
import numpy as np

# 牛顿法 vs 梯度下降：最小化 f(x) = (x-3)⁴
def f(x): return (x - 3)**4
def fp(x): return 4*(x - 3)**3
def fpp(x): return 12*(x - 3)**2

# 牛顿法
x_newton = 0.5
for _ in range(20):
    x_newton = x_newton - fp(x_newton) / fpp(x_newton)

# 梯度下降
x_gd = 0.5
for _ in range(100):
    x_gd -= 0.01 * fp(x_gd)

print(f'牛顿法: {x_newton:.6f}（二次收敛，快速）')
print(f'梯度下降: {x_gd:.6f}（线性收敛，较慢）')
```

## L-BFGS

L-BFGS（Limited-memory BFGS）是拟牛顿法的一种：不显式存储 Hessian 矩阵，而是用有限历史梯度近似 Hessian 逆，兼顾牛顿法的快速收敛和内存效率，适合中小规模凸优化。

```text
数学思想：
BFGS 迭代近似 Hessian 逆 B ≈ H⁻¹，用梯度差更新：
B ← (I - ρsyᵀ)B(I - ρysᵀ) + ρssᵀ

L-BFGS：只保存最近 m 对 (s, y)（如 m=10），
s = θ_{k+1} - θ_k（参数差），y = ∇f_{k+1} - ∇f_k（梯度差）
用两循环递归计算 B·∇f，无需存完整矩阵

适用：中小规模、光滑凸问题（如逻辑回归），不适合大批量深度学习
```

```python
import numpy as np
from scipy.optimize import minimize

# L-BFGS 求解逻辑回归（中小规模凸问题）
def loss_and_grad(w, X, y):
    z = X @ w
    p = 1 / (1 + np.exp(-z))
    p = np.clip(p, 1e-12, 1-1e-12)
    loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
    grad = X.T @ (p - y) / len(y)
    return loss, grad

X = np.random.randn(500, 5)
true_w = np.array([1.0, -2.0, 0.5, 0, 0])
y = (X @ true_w + 0.1*np.random.randn(500) > 0).astype(float)

w0 = np.zeros(5)
res = minimize(lambda w: loss_and_grad(w, X, y), w0,
               method='L-BFGS-B', jac=True)
print('L-BFGS 结果:', np.round(res.x, 3))   # ≈ 真值的缩放
```

## Learning Rate Schedule

学习率调度（Learning Rate Schedule）在训练过程中动态调整学习率：常见的有多项式衰减、余弦退火、阶梯衰减。合理调度能兼顾「前期快速收敛、后期精细收敛」。

```text
常见调度策略：
1. 阶梯衰减（Step）：每隔若干 epoch 学习率乘以 γ
2. 指数衰减：η_t = η₀ · γ^t
3. 余弦退火（Cosine）：η_t = η_min + ½(η₀-η_min)(1+cos(πt/T))
4. 多项式衰减：η_t = (η₀-η_min)(1-t/T)^p + η_min

余弦退火是训练大模型的常用默认选择
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 余弦退火调度
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

lrs = []
for epoch in range(200):
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    optimizer.step()
    scheduler.step()
    lrs.append(scheduler.get_last_lr()[0])

print(f'学习率变化: 起始 {lrs[0]:.4f} → 结束 {lrs[-1]:.4f}')
```

## Warmup

学习率预热（Warmup）在训练初期把学习率从极小值线性（或指数）爬升到目标值，避免初期梯度大导致模型震荡发散。它是训练 Transformer 的标配技巧。

```text
数学定义（线性 warmup）：
前 W 步：η_t = η_target · (t / W)
之后：按正常调度衰减

为什么需要 warmup：
1. 初期参数随机，梯度大且方向不稳
2. 直接大步长容易震荡甚至发散
3. 预热让模型「慢慢进入状态」，再加速

Warmup 步数：通常是几百到几千步，Transformer 常用 4000 步
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 自定义 warmup + 线性衰减
def warmup_then_decay(step, warmup_steps=50, total_steps=200):
    if step < warmup_steps:
        return step / warmup_steps              # 线性预热
    else:
        return 1 - (step - warmup_steps) / (total_steps - warmup_steps)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

lrs = []
for step in range(200):
    scale = warmup_then_decay(step)
    for pg in optimizer.param_groups:
        pg['lr'] = 0.1 * scale
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    optimizer.step()
    lrs.append(optimizer.param_groups[0]['lr'])

print(f'Warmup 学习率峰值在 step 50: {max(lrs):.4f}')
```

## Gradient Clipping

梯度裁剪（Gradient Clipping）限制梯度的范数，防止梯度爆炸导致训练发散。是训练 RNN/Transformer 的必备技巧，有按范数裁剪和按值裁剪两种。

```text
数学定义（按范数裁剪）：
若 ‖g‖ > max_norm，则 g ← g · max_norm / ‖g‖

两种方式：
1. clip by norm：梯度整体按范数缩放，保持方向
2. clip by value：逐元素裁剪到 [-v, v] 区间

适用场景：
1. RNN/Transformer 训练（梯度易爆炸）
2. 损失突刺（loss spike）后的恢复
常用阈值：max_norm = 1.0 或 5.0
```

```python
import torch
import torch.nn as nn

model = nn.Linear(3, 1)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

X = torch.randn(1000, 3)
y = X @ torch.tensor([[2.0], [-1.0], [0.5]]) + 0.1

for epoch in range(300):
    optimizer.zero_grad()
    loss = ((model(X) - y) ** 2).mean()
    loss.backward()
    # 梯度裁剪：限制梯度范数不超过 1.0
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()

print('含梯度裁剪的训练完成, 权重:', model.weight.data.numpy().round(3))
```

## 应用场景实战

### 场景一：不同优化器收敛速度对比

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

def train(optimizer_name, lr=0.01, epochs=200):
    torch.manual_seed(0)
    model = nn.Linear(10, 1)
    X = torch.randn(500, 10)
    y = X @ torch.randn(10, 1) + 0.1
    opt_cls = {'SGD': torch.optim.SGD, 'Adam': torch.optim.Adam,
               'RMSProp': torch.optim.RMSprop}[optimizer_name]
    optimizer = opt_cls(model.parameters(), lr=lr)
    losses = []
    for _ in range(epochs):
        optimizer.zero_grad()
        loss = ((model(X) - y) ** 2).mean()
        loss.backward()
        optimizer.step()
        losses.append(loss.item())
    return losses

plt.figure(figsize=(8, 4))
for name, lr in [('SGD', 0.01), ('Adam', 0.01), ('RMSProp', 0.01)]:
    plt.plot(train(name, lr), label=name)
plt.xlabel('epoch'); plt.ylabel('loss')
plt.legend(); plt.title('不同优化器收敛速度')
plt.show()
```

### 场景二：完整训练配置（warmup + cosine + clip）

```python
import torch
import torch.nn as nn

# 模拟一个「标准」的现代训练配置
torch.manual_seed(42)
model = nn.Sequential(nn.Linear(20, 64), nn.ReLU(), nn.Linear(64, 1))
X = torch.randn(2000, 20)
y = (X[:, :5].sum(dim=1, keepdim=True) > 0).float()

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

warmup = 50
total = 500

def lr_at(step):
    if step < warmup:
        return 1e-3 * (step / warmup)
    t = (step - warmup) / (total - warmup)
    return 1e-3 * 0.5 * (1 + torch.cos(torch.tensor(3.14159 * t)).item())

for step in range(total):
    for pg in optimizer.param_groups:
        pg['lr'] = lr_at(step)
    optimizer.zero_grad()
    loss = torch.nn.functional.binary_cross_entropy_with_logits(model(X), y)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()

print(f'最终损失: {loss.item():.4f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 训练 Transformer/大模型默认用 AdamW + 余弦退火 + warmup，这是被验证的稳定组合
2. SGD 需要细心调学习率和动量，Adam 对学习率更鲁棒，新手优先 Adam
3. 权重衰减和 L2 正则不是一回事（Adam 下），要用解耦的 AdamW
4. 训练 RNN/Transformer 一定加梯度裁剪，防止 loss 突刺发散
5. 学习率是最重要的超参数，先用学习率搜索（如 1e-5 到 1e-1 对数扫描）
6. 凸问题（逻辑回归等中小规模）优先 L-BFGS，收敛快且无需调学习率

### 踩坑记录

```text
坑 1：Adam 里把 weight_decay 当 L2 正则用
结论：期望的 L2 正则效果没达到，泛化受影响。
原因：Adam 的自适应学习率会重缩放梯度里的 λθ，正则被扭曲。
解法：用 AdamW，权重衰减直接作用在权重上。

坑 2：学习率太大导致发散还不知道
结论：loss 突然变 NaN 或震荡不收敛。
原因：步长超过稳定范围，参数被推离最优。
解法：监控 loss，出现 NaN 立即降低学习率，加梯度裁剪。

坑 3：忘加 warmup 直接大步长训练
结论：Transformer 训练初期 loss 震荡甚至发散。
原因：随机初始化梯度大且方向乱，大学习率放大了不稳定。
解法：前若干步 warmup，线性爬升学习率。

坑 4：牛顿法在 Hessian 非正定处直接崩溃
结论：H⁻¹ 方向错误，迭代发散。
原因：非凸区域 Hessian 可能负定，-H⁻¹g 不是下降方向。
解法：加对角扰动 H+λI，或用拟牛顿（BFGS/L-BFGS）。

坑 5：混淆凸问题的局部最优和全局最优
结论：以为非凸问题找到的局部最优就是全局最优。
原因：只有凸函数才能保证局部最优 = 全局最优。
解法：非凸问题多随机初始化跑多次，或用退火/全局优化。
```
