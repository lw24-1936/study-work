## 概述

概率论描述不确定性，是机器学习的「语言」：模型的输出是概率、损失是负对数似然、生成模型是对分布的建模、贝叶斯方法全程在概率框架下推理。它区别于 03.2 的前置概览，这里从算法/ML 视角深入每个概念并给出实现。

```text
概率论在算法中的核心地位：
1. 建模不确定 —— 分类输出概率、回归输出分布参数
2. 损失函数来源 —— 交叉熵、负对数似然都从概率导出
3. 生成模型 —— VAE、GAN、扩散模型本质是建模数据分布
4. 推断框架 —— 贝叶斯、MLE、MAP 都是概率推断
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 概率三要素：样本空间、事件、概率测度
# 抛硬币 10000 次，频率趋近概率 0.5
n = 10000
flips = np.random.binomial(1, 0.5, n)
print(f'正面频率: {flips.mean():.3f}')   # ≈ 0.5
```

## 随机变量

随机变量（Random Variable）把随机试验的结果映射为数值，是概率建模的基本对象。分为离散型（取值有限/可数）和连续型（取值不可数）两类。

```text
数学定义：
随机变量 X: Ω → R，把样本空间结果映射到实数

两类：
1. 离散型：用概率质量函数 PMF 描述，P(X=x) = p(x)，Σ p(x) = 1
2. 连续型：用概率密度函数 PDF 描述，P(a<X<b) = ∫_a^b f(x)dx

累积分布函数 CDF：F(x) = P(X ≤ x)，单调不减，F(+∞)=1
```

```python
import numpy as np

# 离散随机变量：骰子点数
values = np.arange(1, 7)
pmf = np.ones(6) / 6
print('PMF 之和:', pmf.sum())   # 1.0

# 连续随机变量：标准正态的 PDF 与 CDF
from scipy.stats import norm
x = np.linspace(-3, 3, 100)
pdf = norm.pdf(x)
cdf = norm.cdf(x)
print('PDF 积分≈1:', np.trapezoid(pdf, x).round(4))   # 1.0
```

## 概率分布

概率分布是随机变量取值的完整描述。算法工程师必须熟悉常见分布：伯努利、二项、泊松、高斯、指数、均匀，以及它们各自的适用场景。

```text
常见分布速查：
1. 伯努利 Bernoulli(p)：二分类，P(X=1)=p
2. 二项 Binomial(n,p)：n 次独立试验成功次数
3. 泊松 Poisson(λ)：单位时间事件发生次数，E=Var=λ
4. 高斯 Gaussian(μ,σ²)：连续数据默认假设，中心极限定理的归宿
5. 指数 Exponential(λ)：等待时间，无记忆性
6. 均匀 Uniform(a,b)：无先验时的默认选择
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 高斯分布是「默认分布」
mu, sigma = 0, 1
samples = np.random.normal(mu, sigma, 10000)

plt.hist(samples, bins=50, density=True, alpha=0.6)
x = np.linspace(-4, 4, 200)
plt.plot(x, 1/np.sqrt(2*np.pi)*np.exp(-x**2/2), 'r-')
plt.title('Gaussian(0,1) 采样 vs 理论密度')
plt.show()
```

## 联合分布

联合分布描述多个随机变量同时取值的概率，是理解变量间关系的基础。联合概率 P(X,Y)、边缘概率 P(X)、条件概率 P(Y|X) 三者构成概率论的运算骨架。

```text
数学定义：
离散：P(X=x, Y=y) 联合 PMF
连续：f(x, y) 联合 PDF

边缘化：P(X) = Σ_y P(X, Y) 或 f(x) = ∫ f(x,y) dy
（把不关心的变量「积分掉」）

独立性：P(X,Y) = P(X)P(Y) ⇔ X 与 Y 独立
```

```python
import numpy as np

# 二维联合分布 → 边缘分布
joint = np.array([
    [0.1, 0.2],   # P(X=0,Y=0) P(X=0,Y=1)
    [0.3, 0.4],   # P(X=1,Y=0) P(X=1,Y=1)
])
p_x = joint.sum(axis=1)   # 边缘 P(X)
p_y = joint.sum(axis=0)   # 边缘 P(Y)
print('P(X):', p_x)       # [0.3 0.7]
print('P(Y):', p_y)       # [0.4 0.6]

# 独立性检验：P(X,Y) == P(X)P(Y)?
print(np.allclose(joint, np.outer(p_x, p_y)))   # False → 不独立
```

## 条件分布

条件分布描述「已知 Y 后 X 的分布」，是贝叶斯推断、生成模型、序列建模的核心。条件概率 = 联合概率 / 边缘概率。

```text
数学定义：
P(X=x | Y=y) = P(X=x, Y=y) / P(Y=y)

连续情形：f(x|y) = f(x,y) / f(y)

性质：
1. 对每个固定 y，P(·|y) 仍是合法分布（非负、求和为 1）
2. 链式法则：P(x₁,...,x_n) = Π P(x_i | x₁,...,x_{i-1})
3. 条件期望 E[X|Y] 是 Y 的函数，也是「最佳预测」
```

```python
import numpy as np

joint = np.array([
    [0.1, 0.2],
    [0.3, 0.4],
])
p_y = joint.sum(axis=0)
# 已知 Y=0，求 X 的条件分布
p_x_given_y0 = joint[:, 0] / p_y[0]
print('P(X|Y=0):', p_x_given_y0)   # [0.25 0.75]

# 链式法则：P(A,B,C) = P(A)P(B|A)P(C|A,B)
p_a = 0.5
p_b_given_a = 0.8
p_c_given_ab = 0.3
p_abc = p_a * p_b_given_a * p_c_given_ab
print('P(A,B,C):', p_abc)   # 0.12
```

## 条件独立

条件独立（Conditional Independence）是概率图模型和朴素贝叶斯的关键假设：给定 Z 后，X 和 Y 独立。它大幅简化联合分布的表达。

```text
数学定义：
X ⊥ Y | Z ⇔ P(X, Y | Z) = P(X | Z) P(Y | Z)

等价表述：P(X | Y, Z) = P(X | Z)

与无条件独立的区别：
X ⊥ Y 不推出 X ⊥ Y | Z，反之亦然
（条件独立和无条件独立互不蕴含）

应用：
1. 朴素贝叶斯：给定类别，特征之间条件独立
2. HMM/贝叶斯网络：给定父节点，节点与其非后代独立
```

```python
import numpy as np

# 朴素贝叶斯的条件独立假设
# 给定类别 C，特征 X1、X2 条件独立：P(X1,X2|C) = P(X1|C)P(X2|C)
p_x1_given_c = np.array([0.9, 0.1])   # C=0 时 X1 的分布
p_x2_given_c = np.array([0.7, 0.3])

# 直接算联合 vs 条件独立近似
joint_given_c = np.outer(p_x1_given_c, p_x2_given_c)
print('P(X1,X2|C=0):')
print(joint_given_c)
```

## Bayes

贝叶斯定理（Bayes' Theorem）是概率推断的基石：用先验 P(H) 和似然 P(E|H) 反推后验 P(H|E)。它是贝叶斯分类器、贝叶斯推断、信念更新的核心公式。

```text
数学定义：
P(H|E) = P(E|H) · P(H) / P(E)

各项名称：
1. P(H|E)：后验（posterior）—— 看到证据后的信念
2. P(E|H)：似然（likelihood）—— 假设下证据的概率
3. P(H)：先验（prior）—— 看到证据前的信念
4. P(E)：证据（evidence）—— 归一化常数 P(E)=Σ_H P(E|H)P(H)

口诀：后验 ∝ 似然 × 先验
```

```python
import numpy as np

# 疾病检测问题：患病率 1%，检测准确率 99%
p_disease = 0.01            # 先验 P(D)
p_pos_given_disease = 0.99  # 灵敏度 P(+|D)
p_pos_given_healthy = 0.01  # 误报率 P(+|¬D)

# 贝叶斯：检测阳性，真正患病的概率
p_pos = p_pos_given_disease * p_disease + p_pos_given_healthy * (1 - p_disease)
p_disease_given_pos = p_pos_given_disease * p_disease / p_pos
print(f'检测阳性后患病概率: {p_disease_given_pos:.3f}')   # 0.5，而非 0.99
```

## 期望

期望（Expectation）是随机变量的「平均值」，是概率加权平均。它在损失函数、风险最小化、强化学习价值函数里无处不在。

```text
数学定义：
离散：E[X] = Σ x · P(X=x)
连续：E[X] = ∫ x · f(x) dx

性质（线性性，最重要）：
1. E[aX + b] = aE[X] + b
2. E[X + Y] = E[X] + E[Y]（不需要独立）
3. 独立时：E[XY] = E[X]E[Y]

条件期望 E[X|Y] 是「给定 Y 时 X 的最佳均方预测」
```

```python
import numpy as np

# 离散期望
values = np.array([1, 2, 3, 4, 5, 6])
pmf = np.ones(6) / 6
print('骰子期望:', np.sum(values * pmf))   # 3.5

# 连续期望（采样近似）：X ~ Exp(1)，E[X] = 1
samples = np.random.exponential(1, 100000)
print('指数分布期望(采样):', samples.mean().round(3))   # ≈ 1.0

# 线性性验证：E[2X+3] = 2E[X]+3
X = np.random.randn(100000)
print(np.allclose((2*X + 3).mean(), 2*X.mean() + 3))   # True
```

## 方差

方差（Variance）度量随机变量偏离期望的程度，是「风险/不确定性」的量化。标准差是方差的平方根，量纲与变量一致。

```text
数学定义：
Var(X) = E[(X - E[X])²] = E[X²] - E[X]²

性质：
1. Var(aX + b) = a²Var(X)
2. 独立时：Var(X + Y) = Var(X) + Var(Y)
3. Var(X) ≥ 0，等号当且仅当 X 是常数

标准差：σ = sqrt(Var(X))
```

```python
import numpy as np

X = np.random.randn(100000)
print('样本方差:', X.var(ddof=1).round(3))   # ≈ 1.0

# Var(X) = E[X²] - E[X]²
print(np.allclose(X.var(), (X**2).mean() - X.mean()**2))   # True

# Var(aX+b) = a²Var(X)
print(np.allclose((3*X + 5).var(), 9 * X.var()))   # True
```

## 协方差

协方差（Covariance）度量两个随机变量「同向还是反向」变动，是相关系数、PCA、多元高斯的基础。协方差矩阵是多元分析的核心对象。

```text
数学定义：
Cov(X, Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]

性质：
1. Cov(X, X) = Var(X)
2. 独立 ⇒ Cov(X,Y) = 0（反之不成立！）
3. 相关系数：ρ = Cov(X,Y) / (σ_X σ_Y) ∈ [-1, 1]

协方差矩阵：Σ_ij = Cov(X_i, X_j)，对称且半正定
```

```python
import numpy as np

# 构造相关的两个变量
X = np.random.randn(10000)
Y = 2 * X + np.random.randn(10000) * 0.5   # Y 与 X 强相关

cov_matrix = np.cov(X, Y)
print('协方差矩阵:')
print(cov_matrix)
# [[~1.0, ~2.0],
#  [~2.0, ~4.25]]

# 相关系数
corr = np.corrcoef(X, Y)[0, 1]
print(f'相关系数: {corr:.3f}')   # ≈ 0.97
```

## 大数定律

大数定律（Law of Large Numbers, LLN）保证样本均值收敛到期望：样本越多，估计越准。它是「频率趋于概率」、蒙特卡洛方法、在线学习的理论根基。

```text
数学定义（弱大数定律）：
X̄_n = (1/n) Σ X_i → E[X]（依概率收敛）

强版本：X̄_n → E[X]（几乎必然收敛）

含义：
1. 样本均值是期望的一致估计
2. 蒙特卡洛：用大量采样近似积分/期望
3. 采样越多，波动越小（方差 ∝ 1/n）
```

```python
import numpy as np

# 模拟：样本均值随 n 增大收敛到 0.5
true_mean = 0.5
for n in [10, 100, 1000, 10000, 100000]:
    sample = np.random.binomial(1, 0.5, n)
    print(f'n={n:>6}: 样本均值={sample.mean():.4f} (真值 {true_mean})')
# 输出显示随 n 增大，均值越来越接近 0.5
```

## 中心极限定理

中心极限定理（CLT）说明：大量独立同分布随机变量之和（标准化后）近似服从标准正态分布，无论原始分布是什么。它是置信区间、假设检验、误差分析的理论基础。

```text
数学定义：
设 X₁,...,X_n 独立同分布，均值 μ、方差 σ²，则
(ΣX_i - nμ) / (σ√n) → N(0, 1)（依分布收敛）

含义：
1. 不管原始分布多怪，样本均值都近似正态
2. 样本均值 X̄ ≈ N(μ, σ²/n)
3. 解释为何高斯分布在统计里如此核心
```

```python
import numpy as np
import matplotlib.pyplot as plt

# 从均匀分布采样，样本均值竟趋于正态
means = []
for _ in range(5000):
    means.append(np.random.uniform(0, 1, 30).mean())

plt.hist(means, bins=50, density=True, alpha=0.6)
x = np.linspace(0.2, 0.8, 200)
mu, sigma = 0.5, np.sqrt(1/12/30)
plt.plot(x, 1/np.sqrt(2*np.pi*sigma**2)*np.exp(-(x-mu)**2/(2*sigma**2)), 'r-')
plt.title('均匀分布均值的 CLT 正态收敛')
plt.show()
```

## Markov Property

马尔可夫性质（Markov Property）指「未来只依赖现在，与过去无关」。它是马尔可夫链、HMM、MCMC、强化学习（MDP）的基础假设。

```text
数学定义：
P(X_{t+1} = x | X_t, X_{t-1}, ..., X_0) = P(X_{t+1} = x | X_t)

即：给定当前状态，未来与历史条件独立

相关概念：
1. 转移矩阵 P：P_ij = P(X_{t+1}=j | X_t=i)，行和为 1
2. 平稳分布 π：π = πP（马尔可夫链长期稳定态）
3. 一阶 vs 高阶：N-gram 语言模型是 (N-1) 阶马尔可夫链
```

```python
import numpy as np

# 天气马尔可夫链：晴/雨
# 转移矩阵：P[晴→晴]=0.8, P[晴→雨]=0.2, P[雨→晴]=0.4, P[雨→雨]=0.6
P = np.array([[0.8, 0.2],
              [0.4, 0.6]])

# 从晴天开始，模拟 10 步
state = 0
states = [state]
for _ in range(10):
    state = np.random.choice(2, p=P[state])
    states.append(state)
print('状态序列:', states)   # 0=晴 1=雨

# 平稳分布 π = πP（解特征值问题）
eigvals, eigvecs = np.linalg.eig(P.T)
pi = eigvecs[:, np.argmin(np.abs(eigvals - 1))]
pi = pi / pi.sum()
print('平稳分布:', pi.real)   # ≈ [0.667 0.333]
```

## 应用场景实战

### 场景一：朴素贝叶斯文本分类

```python
import numpy as np
from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import CountVectorizer

docs = [
    'free money win now', 'free free cash offer',
    'machine learning algorithm', 'deep learning neural network',
    'data science statistics', 'probability bayes inference',
]
labels = [1, 1, 0, 0, 0, 0]   # 1=垃圾 0=正常

vec = CountVectorizer()
X = vec.fit_transform(docs)
clf = MultinomialNB().fit(X, labels)

new_doc = vec.transform(['free cash money'])
print('预测:', clf.predict(new_doc))          # [1] 垃圾
print('概率:', clf.predict_proba(new_doc))     # 基于 Bayes 的后验概率
```

### 场景二：贝叶斯参数估计（Beta-Binomial 共轭）

```python
import numpy as np

# 点击率 CTR 估计：先验 Beta(a,b)，观测点击/曝光
# Beta-Binomial 共轭：后验也是 Beta
a_prior, b_prior = 2, 8          # 先验：认为 CTR ≈ 0.2
clicks, impressions = 30, 100    # 观测：100 次曝光 30 次点击

a_post = a_prior + clicks
b_post = b_prior + (impressions - clicks)

# 后验均值（贝叶斯估计的 CTR）
ctr_bayes = a_post / (a_post + b_post)
ctr_mle = clicks / impressions
print(f'贝叶斯估计 CTR: {ctr_bayes:.3f}')   # 0.291
print(f'MLE 估计 CTR:   {ctr_mle:.3f}')     # 0.300，先验向 0.2 收缩
```

## 最佳实践与踩坑记录

### 最佳实践

1. 处理类别不平衡时，先算基准概率（base rate），再评估模型是否真的学到了东西
2. 概率相乘容易下溢，改用对数概率 log-sum-exp 技巧
3. 先验的选择要透明，尤其在小样本下先验影响很大，用共轭先验简化计算
4. 独立性假设要验证，不满足时改用图模型或去掉强假设
5. 概率校准问题用 Platt/Isotonic 校准，别直接信输出概率
6. 蒙特卡洛估计要报告方差/置信区间，单次采样结果不可信

### 踩坑记录

```text
坑 1：把「相关」当成「因果」
结论：Cov(X,Y)≠0 或相关系数高，不代表 X 导致 Y。
原因：可能存在混淆变量 Z 同时影响两者，或纯属巧合。
解法：下因果结论需实验设计或因果推断方法，相关性只作线索。

坑 2：忽略先验对后验的影响
结论：小样本下先验选错，后验结论被带偏。
原因：贝叶斯后验 ∝ 似然 × 先验，样本少时先验权重高。
解法：报告先验选择，做敏感性分析，样本充足时两者趋于一致。

坑 3：概率连乘直接算导致下溢
结论：大量概率相乘得到 0 或 NaN。
原因：浮点数最小约 1e-308，连乘很快下溢。
解法：全部转对数概率，log P = Σ log p_i，用 logsumexp。

坑 4：把条件独立假设当真
结论：朴素贝叶斯在特征强相关时概率估计严重失真。
原因：P(X1,X2|C)=P(X1|C)P(X2|C) 假设特征独立，现实中常不成立。
解法：虽然概率失真但分类往往仍可用；要精确就用贝叶斯网络。

坑 5：混淆 E[XY]=E[X]E[Y] 的成立条件
结论：X、Y 不独立时，用 E[XY]=E[X]E[Y] 算协方差出错。
原因：该式要求 X、Y 独立；不独立时 E[XY]≠E[X]E[Y]。
解法：用定义 Cov(X,Y)=E[XY]-E[X]E[Y] 或 np.cov 直接算。
```
