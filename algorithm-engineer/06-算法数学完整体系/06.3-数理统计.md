## 概述

数理统计研究如何从数据中推断总体：估计参数、构造置信区间、检验假设。它是模型评估（A/B 测试、显著性检验）、参数估计（MLE/MAP）、实验设计的理论基础，也是算法工程师做「数据驱动决策」的必备能力。

```text
数理统计在算法中的核心地位：
1. 参数估计 —— MLE/MAP 是大多数模型训练的数学本质
2. 模型评估 —— 置信区间、假设检验判断模型是否真的更好
3. 实验设计 —— A/B 测试的显著性、样本量计算
4. 鲁棒推断 —— Bootstrap/Permutation 应对小样本和复杂分布
```

```python
import numpy as np
from scipy import stats

# 统计推断的两大任务：估计 + 检验
sample = np.random.normal(5, 2, 1000)
print(f'点估计: 均值={sample.mean():.3f}, 标准差={sample.std(ddof=1):.3f}')
```

## Sampling

抽样（Sampling）是从总体中抽取样本的过程。统计结论依赖样本的代表性，抽样方法决定推断是否有效。算法里对应数据采样、负采样、分层采样。

```text
数学定义：
总体（population）→ 抽样（sampling）→ 样本（sample）→ 统计量（statistic）

常见抽样方法：
1. 简单随机抽样：每个个体等概率被抽
2. 分层抽样：按层（类别）比例抽取，保证代表性
3. 系统抽样：每隔 k 个抽一个
4. 自助抽样（Bootstrap）：有放回重采样

核心概念：
- 统计量：样本的函数（如样本均值），是随机变量
- 抽样分布：统计量的分布，是推断的桥梁
```

```python
import numpy as np

population = np.random.randn(100000)   # 总体

# 简单随机抽样
srs = np.random.choice(population, size=500, replace=False)

# 分层抽样：按正负分层，各抽 250
pos = population[population > 0]
neg = population[population <= 0]
stratified = np.concatenate([
    np.random.choice(pos, 250, replace=False),
    np.random.choice(neg, 250, replace=False),
])
print(f'简单随机均值 {srs.mean():.3f}, 分层均值 {stratified.mean():.3f}')
```

## Estimation

估计（Estimation）用样本统计量推断总体参数。分为点估计（给出单一值）和区间估计（给出范围）。估计量有三大性质：无偏性、一致性、有效性。

```text
数学定义：
点估计：用统计量 θ̂ 估计参数 θ

估计量性质：
1. 无偏性：E[θ̂] = θ（期望等于真值）
2. 一致性：θ̂ → θ（样本增大时收敛）
3. 有效性：方差更小的估计量更有效

经典例子：
- 样本均值 X̄ 是总体均值 μ 的无偏估计
- 样本方差 S² = Σ(x_i-X̄)²/(n-1) 是 σ² 的无偏估计（除以 n-1 而非 n）
```

```python
import numpy as np

# 样本方差：除以 n-1 才是无偏估计
X = np.random.normal(5, 2, 30)
var_biased = np.var(X)           # 除以 n
var_unbiased = np.var(X, ddof=1) # 除以 n-1
print(f'有偏方差 {var_biased:.3f}, 无偏方差 {var_unbiased:.3f}')

# 模拟验证无偏性：多次抽样，估计量的均值趋于真值
means = []
for _ in range(10000):
    means.append(np.random.normal(5, 2, 30).mean())
print(f'样本均值的平均: {np.mean(means):.4f}（真值 5）')   # ≈ 5.0
```

## MLE

最大似然估计（MLE）选择「让观测数据出现概率最大」的参数：θ̂ = argmax P(data|θ)。它是逻辑回归、朴素贝叶斯、绝大多数模型训练的数学本质（最小化负对数似然）。

```text
数学定义：
θ̂_MLE = argmax_θ L(θ) = argmax_θ Π P(x_i | θ)

等价于最小化负对数似然（NLL）：
θ̂ = argmin_θ -Σ log P(x_i | θ)

例子：高斯分布 MLE
μ̂ = (1/n) Σ x_i（样本均值）
σ̂² = (1/n) Σ (x_i - μ̂)²（有偏方差）
```

```python
import numpy as np
from scipy.optimize import minimize

# 高斯分布 MLE 闭式解
X = np.random.normal(3, 1.5, 1000)
mu_mle = X.mean()
sigma_mle = np.std(X)   # MLE 用除以 n（有偏）
print(f'μ̂={mu_mle:.3f}, σ̂={sigma_mle:.3f}')   # ≈ 3, 1.5

# 数值优化求 MLE：拟合伯努利参数 p
def neg_log_lik(p, data):
    p = np.clip(p, 1e-12, 1-1e-12)
    return -np.sum(data * np.log(p) + (1 - data) * np.log(1 - p))

data = np.random.binomial(1, 0.7, 500)
res = minimize(neg_log_lik, x0=0.5, args=(data,))
print(f'p̂_MLE={res.x[0]:.3f}')   # ≈ 0.7
```

## MAP

最大后验估计（MAP）在 MLE 基础上引入先验：θ̂ = argmax P(θ|data) = argmax P(data|θ)P(θ)。先验起正则化作用，是 L1/L2 正则、贝叶斯视角下的参数估计。

```text
数学定义：
θ̂_MAP = argmax_θ P(θ | data) = argmax_θ [log P(data|θ) + log P(θ)]

与 MLE 关系：
- MLE：只看数据（似然）
- MAP：似然 × 先验（数据 + 先验知识）

经典对应：
- 高斯先验 P(θ)∝e^(-λθ²) → 等价 L2 正则（Ridge）
- 拉普拉斯先验 P(θ)∝e^(-λ|θ|) → 等价 L1 正则（Lasso）
```

```python
import numpy as np

# 高斯先验下的 MAP = 带 L2 正则的估计
# 例：估计均值 μ，先验 N(0, τ²)，数据 N(μ, σ²)
data = np.random.normal(2, 1, 10)   # 少量数据
sigma2, tau2 = 1.0, 1.0             # 似然方差、先验方差
n = len(data)

mu_mle = data.mean()
mu_map = (n / sigma2) / (n / sigma2 + 1 / tau2) * mu_mle
print(f'MLE={mu_mle:.3f}, MAP={mu_map:.3f}')   # MAP 向 0 收缩（正则化效果）
```

## Confidence Interval

置信区间（Confidence Interval）给出参数的区间估计：在重复抽样下，该区间以指定置信水平（如 95%）覆盖真值。它量化估计的不确定性，是模型评估报告的标准内容。

```text
数学定义：
95% 置信区间：P(L ≤ θ ≤ U) = 0.95
（注意：θ 是固定的，随机的是区间 [L, U]）

均值的置信区间（σ 已知）：
X̄ ± z_{α/2} · σ/√n

σ 未知时用 t 分布：
X̄ ± t_{α/2, n-1} · S/√n
```

```python
import numpy as np
from scipy import stats

X = np.random.normal(10, 3, 100)
mean, std = X.mean(), X.std(ddof=1)
n = len(X)

# t 分布置信区间
t_crit = stats.t.ppf(0.975, df=n-1)
margin = t_crit * std / np.sqrt(n)
ci = (mean - margin, mean + margin)
print(f'95% 置信区间: [{ci[0]:.2f}, {ci[1]:.2f}]')   # 应覆盖真值 10
```

## Hypothesis Test

假设检验（Hypothesis Test）判断数据是否提供足够证据拒绝原假设。核心是原假设/备择假设、p 值、显著性水平 α、两类错误。它是 A/B 测试的统计框架。

```text
数学定义：
原假设 H₀：默认成立的假设（如「无差异」）
备择假设 H₁：想证明的假设（如「有差异」）

p 值：在 H₀ 为真时，观察到当前或更极端结果的概率
拒绝规则：p < α 时拒绝 H₀（α 通常 0.05）

两类错误：
1. 第一类错误（α）：H₀ 真却拒绝（误报）
2. 第二类错误（β）：H₁ 真却接受（漏报），功效 = 1-β
```

```python
import numpy as np
from scipy import stats

# 检验硬币是否公平（H₀: p=0.5）
flips = np.random.binomial(1, 0.6, 200)   # 实际偏向 0.6
n_heads = flips.sum()
p_value = stats.binomtest(n_heads, len(flips), 0.5).pvalue
print(f'正面 {n_heads}/{len(flips)}, p值={p_value:.4f}')
print('结论:', '拒绝 H₀，硬币不公平' if p_value < 0.05 else '无法拒绝 H₀')
```

## t-Test

t 检验（t-Test）用于比较均值：单样本 t 检验（样本均值 vs 已知值）、独立双样本 t 检验（两组均值对比）、配对 t 检验（同组前后对比）。是 A/B 测试最常用的检验。

```text
数学定义（双样本）：
t = (X̄₁ - X̄₂) / sqrt(S_p²(1/n₁ + 1/n₂))

前提假设：
1. 两组独立
2. 近似正态（CLT 下大样本可放宽）
3. 方差齐性（Welch 检验可放宽此假设）

自由度：n₁ + n₂ - 2（Welch 用近似自由度）
```

```python
import numpy as np
from scipy import stats

# A/B 测试：两组转化率是否有显著差异
group_a = np.random.binomial(1, 0.10, 1000)
group_b = np.random.binomial(1, 0.12, 1000)

t_stat, p_value = stats.ttest_ind(group_a, group_b)
print(f't={t_stat:.3f}, p值={p_value:.4f}')
print('结论:', '显著差异' if p_value < 0.05 else '无显著差异')

# 配对 t 检验（同一批用户前后对比）
before = np.random.normal(100, 10, 30)
after = before + np.random.normal(5, 3, 30)
t_stat, p_value = stats.ttest_rel(before, after)
print(f'配对检验 p值={p_value:.4f}')   # 应显著
```

## Chi-Square

卡方检验（Chi-Square）用于类别变量的独立性检验和拟合优度检验：判断两个分类变量是否相关，或观测频数与理论频数是否一致。

```text
数学定义：
χ² = Σ (O_i - E_i)² / E_i
其中 O 是观测频数，E 是期望频数

两类应用：
1. 独立性检验：两个类别变量是否独立（列联表）
2. 拟合优度检验：观测分布是否符合某理论分布

自由度 df = (行数-1)(列数-1)（独立性检验）
```

```python
import numpy as np
from scipy.stats import chi2_contingency

# 列联表：性别 × 是否点击广告
#            点击  未点击
table = np.array([
    [120, 380],   # 男
    [90, 410],    # 女
])
chi2, p, dof, expected = chi2_contingency(table)
print(f'χ²={chi2:.3f}, p值={p:.4f}')
print('结论:', '性别与点击相关' if p < 0.05 else '性别与点击独立')
```

## ANOVA

方差分析（ANOVA）比较三个及以上组的均值是否有差异。它通过比较「组间方差」和「组内方差」来判断，是 t 检验的多组推广。

```text
数学定义：
F = 组间方差 / 组内方差 = MSB / MSW

思想：
1. 组间差异大（组间方差大）→ 组均值不同
2. 组内差异大（组内方差大）→ 数据本身噪声大
3. F 值越大，越可能拒绝「各组均值相等」的 H₀

单因素 ANOVA：一个因子（分组变量）
前提：各组独立、正态、方差齐性
```

```python
import numpy as np
from scipy import stats

# 三种算法的性能对比（多组）
algo_a = np.random.normal(0.85, 0.05, 30)
algo_b = np.random.normal(0.87, 0.05, 30)
algo_c = np.random.normal(0.90, 0.05, 30)

F, p = stats.f_oneway(algo_a, algo_b, algo_c)
print(f'F={F:.3f}, p值={p:.4f}')
print('结论:', '三组均值有显著差异' if p < 0.05 else '无显著差异')
```

## Bootstrap

自助法（Bootstrap）通过「有放回重采样」构造统计量的抽样分布，无需假设总体分布。它用于计算置信区间、估计标准误，特别适合小样本或复杂统计量。

```text
数学思想：
1. 从原样本有放回抽 n 个（一个 bootstrap 样本）
2. 计算该样本的统计量 θ̂*
3. 重复 B 次（如 1000），得到 θ̂* 的分布
4. 用分位数构造置信区间

优点：无需分布假设，通用
适用：标准误、置信区间、偏差修正
```

```python
import numpy as np

X = np.random.normal(0, 1, 50)   # 小样本
B = 5000
boot_means = np.empty(B)
for i in range(B):
    sample = np.random.choice(X, size=len(X), replace=True)
    boot_means[i] = sample.mean()

# 95% 分位数置信区间
ci_low, ci_high = np.percentile(boot_means, [2.5, 97.5])
print(f'Bootstrap 95% CI: [{ci_low:.3f}, {ci_high:.3f}]')
print(f'标准误: {boot_means.std():.3f}')
```

## Permutation Test

置换检验（Permutation Test）是「精确的」假设检验：打乱组标签，重算检验统计量，得到零分布。它不依赖分布假设，是 A/B 测试的稳健替代。

```text
数学思想：
1. 计算原始两组差异（如均值差）D_obs
2. 合并两组，随机打乱标签，重新分组
3. 计算新差异 D_perm，重复 B 次
4. p 值 = (|D_perm| ≥ |D_obs| 的次数) / B

与 Bootstrap 区别：Bootstrap 重采样数据，Permutation 重采样标签
```

```python
import numpy as np

a = np.array([3, 5, 7, 9, 11])
b = np.array([2, 4, 6, 8, 10])
D_obs = np.mean(a) - np.mean(b)

combined = np.concatenate([a, b])
B = 10000
count = 0
for _ in range(B):
    np.random.shuffle(combined)
    perm_a = combined[:len(a)]
    perm_b = combined[len(a):]
    if abs(perm_a.mean() - perm_b.mean()) >= abs(D_obs):
        count += 1
p_value = count / B
print(f'置换检验 p值={p_value:.4f}')
```

## Bayesian Inference

贝叶斯推断（Bayesian Inference）把参数当作随机变量，用后验分布 P(θ|data) 表达对参数的完整信念，而非单一的点估计。它天然支持不确定性量化、在线更新和先验融合。

```text
数学定义：
后验 P(θ|data) ∝ 似然 P(data|θ) × 先验 P(θ)

推断方式：
1. 点估计：后验均值/众数（MAP）
2. 区间估计：可信区间（credible interval）
3. 预测：P(x_new|data) = ∫ P(x_new|θ)P(θ|data)dθ

与频率派区别：
- 频率派：θ 固定，数据随机
- 贝叶斯派：θ 随机，数据固定
```

```python
import numpy as np
from scipy import stats

# Beta-Binomial 共轭：CTR 估计的完整后验分布
a_prior, b_prior = 2, 8
clicks, impressions = 25, 100
a_post = a_prior + clicks
b_post = b_prior + (impressions - clicks)

# 后验分布 Beta(a_post, b_post)
x = np.linspace(0, 1, 1000)
posterior = stats.beta.pdf(x, a_post, b_post)

# 后验均值 + 95% 可信区间
post_mean = a_post / (a_post + b_post)
ci_low, ci_high = stats.beta.ppf([0.025, 0.975], a_post, b_post)
print(f'后验均值 CTR={post_mean:.3f}')
print(f'95% 可信区间: [{ci_low:.3f}, {ci_high:.3f}]')
```

## 应用场景实战

### 场景一：A/B 测试完整流程（含置信区间）

```python
import numpy as np
from scipy import stats

# 对照组 vs 实验组（点击率）
np.random.seed(42)
control = np.random.binomial(1, 0.10, 5000)
treatment = np.random.binomial(1, 0.115, 5000)

# 1. 双样本 z 检验（比例检验）
p1, p2 = control.mean(), treatment.mean()
p_pool = (control.sum() + treatment.sum()) / (len(control) + len(treatment))
se = np.sqrt(p_pool * (1 - p_pool) * (1/len(control) + 1/len(treatment)))
z = (p2 - p1) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))
print(f'对照组 {p1:.4f}, 实验组 {p2:.4f}, 提升 {(p2-p1)/p1:.2%}')
print(f'z={z:.3f}, p值={p_value:.4f}')

# 2. 提升的置信区间
lift = p2 - p1
se_lift = np.sqrt(p1*(1-p1)/len(control) + p2*(1-p2)/len(treatment))
ci = (lift - 1.96*se_lift, lift + 1.96*se_lift)
print(f'绝对提升 95% CI: [{ci[0]:.4f}, {ci[1]:.4f}]')
```

### 场景二：模型性能的 Bootstrap 置信区间

```python
import numpy as np
from sklearn.metrics import accuracy_score

# 模型预测结果
np.random.seed(0)
y_true = np.random.randint(0, 2, 200)
y_pred = (y_true == np.random.randint(0, 2, 200)).astype(int)  # 构造有噪声的预测

# Bootstrap 估计 accuracy 的置信区间
B = 2000
accs = []
for _ in range(B):
    idx = np.random.choice(len(y_true), len(y_true), replace=True)
    accs.append(accuracy_score(y_true[idx], y_pred[idx]))

ci = np.percentile(accs, [2.5, 97.5])
print(f'Accuracy={np.mean(accs):.3f}, 95% CI=[{ci[0]:.3f}, {ci[1]:.3f}]')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 报告估计结果时同时给置信区间，单点估计没有不确定性信息
2. A/B 测试前先算样本量（功效分析），避免功效不足或浪费流量
3. 多重比较要校正（Bonferroni/FDR），否则假阳性率飙升
4. 小样本或分布未知时优先 Bootstrap/Permutation 检验
5. 方差估计用 ddof=1（无偏），别默认用有偏方差
6. p 值不是「效应大小」，显著不等于重要，要结合业务影响

### 踩坑记录

```text
坑 1：样本方差除以 n 而不是 n-1
结论：小样本下系统低估总体方差。
原因：样本均值用了数据，损失 1 个自由度，除以 n 有偏。
解法：用 np.var(x, ddof=1) 或 np.std(x, ddof=1)。

坑 2：多重比较不做校正
结论：同时检验 20 个指标，几乎必有假阳性。
原因：每次检验 α=0.05，20 次至少 1 次假阳性的概率约 64%。
解法：Bonferroni 校正 α/k，或 FDR（Benjamini-Hochberg）。

坑 3：把 p>0.05 解释为「H₀ 为真」
结论：p 值不显著就断言「无差异」，可能只是样本不够。
原因：p>α 只能说明证据不足，不能证明无差异（可能第二类错误）。
解法：报告功效分析，或改用等价性检验（equivalence test）。

坑 4：t 检验忽略正态/方差齐性前提
结论：前提不满足时 p 值失真。
原因：t 检验假设正态和方差齐性，违背后检验不稳健。
解法：方差不等用 Welch t 检验，分布偏差用 Mann-Whitney 非参数检验。

坑 5：置信区间被误解为「真值有 95% 概率落在区间内」
结论：这是贝叶斯可信区间的解释，不是频率派置信区间的含义。
原因：频率派里 θ 固定，区间随机；95% 指「重复抽样 95% 的区间覆盖 θ」。
解法：想要「真值在区间内的概率」，用贝叶斯可信区间。
```
