## 概述

微积分是深度学习训练的动力来源：梯度下降靠导数、反向传播靠链式法则、牛顿法靠 Hessian、损失函数局部近似靠泰勒展开。它区别于 03.5 的前置概览，这里从算法/ML 视角深入每个概念并给出 NumPy/PyTorch 实现。

```text
微积分在算法中的核心地位：
1. 优化 —— 梯度下降/牛顿法都依赖导数与二阶导
2. 反向传播 —— 链式法则把误差从输出层传回输入层
3. 损失近似 —— 泰勒展开提供局部二次近似（牛顿法）
4. 敏感性分析 —— Jacobian 描述输入对输出的影响
```

```python
import torch

# 自动微分：微积分在深度学习里的落地
x = torch.tensor(3.0, requires_grad=True)
y = x**3 + 2*x + 1
y.backward()
print(f'f(x)=x³+2x+1 在 x=3 的导数: {x.grad.item()}')   # 3*9+2 = 29
```

## Derivative

导数（Derivative）描述函数在某点的瞬时变化率，几何上是切线斜率。它是梯度的基础，也是理解「损失如何随参数变化」的起点。

```text
数学定义：
f'(x) = lim_{h→0} [f(x+h) - f(x)] / h

几何意义：曲线在 x 处的切线斜率
物理意义：瞬时变化率

常见求导公式：
1. (x^n)' = n·x^(n-1)
2. (e^x)' = e^x，ln(x)' = 1/x
3. (sin x)' = cos x
```

```python
import numpy as np

def f(x): return x**3 + 2*x + 1

# 数值导数（中心差分）vs 解析导数
def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 3.0
analytic = 3 * x**2 + 2      # f'(x) = 3x² + 2
numeric = numerical_derivative(f, x)
print(f'解析导数: {analytic}, 数值导数: {numeric:.5f}')
print(f'误差: {abs(analytic - numeric):.2e}')
```

## Partial Derivative

偏导数（Partial Derivative）是多元函数对单个变量的导数：固定其他变量，只对一个变量求导。它是梯度和 Jacobian 的组成元素。

```text
数学定义：
∂f/∂x_i = lim_{h→0} [f(x_1,...,x_i+h,...,x_n) - f(x)] / h
（其他变量视为常数）

记法：∂f/∂x_i

例子：f(x, y) = x²y + 3xy³
∂f/∂x = 2xy + 3y³（y 当常数）
∂f/∂y = x² + 9xy²（x 当常数）
```

```python
import torch

# PyTorch 自动求偏导
x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)
f = x**2 * y + 3 * x * y**3

f.backward()
print(f'∂f/∂x = {x.grad.item()}')   # 2xy + 3y³ = 12 + 81 = 93
print(f'∂f/∂y = {y.grad.item()}')   # x² + 9xy² = 4 + 162 = 166
```

## Gradient

梯度（Gradient）是多元函数所有偏导数组成的向量，指向函数增长最快的方向。梯度下降沿负梯度方向走，是几乎所有神经网络训练的核心。

```text
数学定义：
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂x_n]ᵀ

性质：
1. 方向：指向函数值增长最快的方向
2. 大小：等于该方向的变化率（最大方向导数）
3. 极值点处 ∇f = 0（一阶必要条件）

梯度下降更新：θ ← θ - η·∇f(θ)
```

```python
import numpy as np

# 梯度下降求 f(x,y) = x² + y² 的最小值（真值 0,0）
def f(x, y): return x**2 + y**2
def grad(x, y): return np.array([2*x, 2*y])

theta = np.array([3.0, -4.0])   # 初始点
lr = 0.1
for step in range(50):
    theta = theta - lr * grad(*theta)
print(f'梯度下降结果: {theta}')   # 逼近 [0, 0]
```

## Jacobian

雅可比矩阵（Jacobian）是向量值函数的导数矩阵，每行是一个输出对输入的梯度。它是神经网络层间反向传播的数学载体，也用于坐标变换和敏感性分析。

```text
数学定义：
对 f: R^n → R^m，Jacobian 是 m×n 矩阵：
J_ij = ∂f_i / ∂x_j

特例：
1. m = 1 时，J 就是梯度的转置（行向量）
2. 线性函数 f = Ax 的 Jacobian 就是 A

反向传播：每层的 Jacobian 连乘（链式法则的矩阵形式）
```

```python
import torch

# 向量值函数 f(x) = [x₁² + x₂, sin(x₂)]
x = torch.tensor([1.0, 2.0], requires_grad=True)

def f(x):
    return torch.stack([x[0]**2 + x[1], torch.sin(x[1])])

J = torch.autograd.functional.jacobian(f, x)
print('Jacobian:')
print(J)
# [[2.0, 1.0],
#  [0.0, cos(2)≈-0.416]]
```

## Hessian

海森矩阵（Hessian）是标量函数的二阶导数矩阵，刻画曲率。它用于判断极值点性质、牛顿法、凸性判定，也是理解优化算法收敛速度的关键。

```text
数学定义：
H_ij = ∂²f / ∂x_i ∂x_j

对称性：混合偏导可交换（Schwarz 定理）→ H 对称

用途：
1. 二阶条件：∇f=0 且 H 正定 → 局部极小点
2. 牛顿法：x ← x - H⁻¹∇f（二阶收敛）
3. 凸性判定：H 处处半正定 ⇔ f 凸
```

```python
import torch

def f(x):
    return x[0]**2 + 3*x[0]*x[1] + x[1]**2 + x[0]**4

x = torch.tensor([1.0, 2.0], requires_grad=True)
H = torch.autograd.functional.hessian(f, x)
print('Hessian:')
print(H)
# [[2+12x₀², 3],
#  [3,       2]]
```

## Chain Rule

链式法则（Chain Rule）是复合函数求导的规则，也是反向传播的数学本质：误差从输出层逐层回传，每一层乘以本层导数。深度学习的训练全靠它高效计算梯度。

```text
数学定义（单变量）：
h(x) = f(g(x)) → h'(x) = f'(g(x)) · g'(x)

多变量链式法则：
∂L/∂x = Σ_k (∂L/∂y_k) · (∂y_k/∂x)

反向传播三步：
1. 前向：逐层计算输出
2. 反向：从输出层开始，误差乘以局部梯度回传
3. 更新：用累计梯度更新参数
```

```python
import numpy as np

# 手写反向传播：f = w·x + b → sigmoid → 损失
def sigmoid(z): return 1 / (1 + np.exp(-z))

x, w, b = 1.0, 2.0, 0.5
y_true = 1.0

# 前向
z = w * x + b
y = sigmoid(z)
loss = (y - y_true)**2

# 反向（链式法则逐层求导）
dL_dy = 2 * (y - y_true)
dy_dz = y * (1 - y)
dz_dw = x
dz_db = 1

dL_dw = dL_dy * dy_dz * dz_dw
dL_db = dL_dy * dy_dz * dz_db
print(f'∂L/∂w = {dL_dw:.4f}, ∂L/∂b = {dL_db:.4f}')
```

## Taylor Expansion

泰勒展开（Taylor Expansion）用多项式在局部逼近函数：一阶是线性近似（切线），二阶是二次近似（抛物线）。它是牛顿法、损失函数曲率分析、梯度下降收敛性分析的工具。

```text
数学定义：
f(x) ≈ f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + ... + f⁽ⁿ⁾(a)(x-a)ⁿ/n!

一阶近似（线性化）：
f(x) ≈ f(a) + f'(a)(x-a)

二阶近似（牛顿法依据）：
f(x) ≈ f(a) + f'(a)(x-a) + ½ f''(a)(x-a)²

多元二阶近似：
f(x) ≈ f(a) + ∇f(a)ᵀ(x-a) + ½ (x-a)ᵀH(a)(x-a)
```

```python
import numpy as np

def f(x): return np.sin(x)

# 在 a=0 处展开：sin x ≈ x - x³/6 + x⁵/120
a = 0.0
x = np.linspace(-2, 2, 100)

taylor1 = f(a) + np.cos(a) * x                          # 一阶
taylor3 = taylor1 - np.sin(a) * x**2/2 - np.cos(a) * x**3/6
print(f'x=1.0 处 sin= {f(1.0):.4f}')
print(f'一阶近似= {f(a) + np.cos(a)*1.0:.4f}')
print(f'三阶近似= {f(a) + np.cos(a)*1.0 - np.cos(a)*1.0**3/6:.4f}')
```

## 应用场景实战

### 场景一：完整反向传播训练单层网络

```python
import numpy as np

# 单层网络 + MSE 损失，手写反向传播训练
np.random.seed(0)
X = np.random.randn(100, 3)
y_true = (X @ np.array([2.0, -1.0, 0.5]) > 0).astype(float)

def sigmoid(z): return 1 / (1 + np.exp(-z))

w = np.random.randn(3)
b = 0.0
lr = 0.5

for epoch in range(500):
    # 前向
    z = X @ w + b
    y = sigmoid(z)
    # 损失
    loss = np.mean((y - y_true)**2)
    # 反向传播（链式法则）
    dL_dy = 2 * (y - y_true) / len(X)
    dy_dz = y * (1 - y)
    dz = dL_dy * dy_dz
    dL_dw = X.T @ dz
    dL_db = dz.sum()
    # 更新
    w -= lr * dL_dw
    b -= lr * dL_db
    if epoch % 100 == 0:
        print(f'epoch {epoch}: loss={loss:.4f}')

print('学习到的权重:', np.round(w, 2), '（真值约 [2,-1,0.5] 的缩放）')
```

### 场景二：牛顿法求解方程（二阶信息加速）

```python
import numpy as np

# 牛顿法求 f(x) = x³ - x - 2 = 0 的根
def f(x): return x**3 - x - 2
def fp(x): return 3*x**2 - 1

x = 1.5   # 初始点
for i in range(10):
    x = x - f(x) / fp(x)
print(f'牛顿法求根: x = {x:.6f}（真值约 1.521380）')

# 对比：梯度下降求 f(x) = (x-3)² 最小值，牛顿法一步到位
def g(x): return (x - 3)**2
def gp(x): return 2*(x - 3)
def gpp(x): return 2.0

x_gd = 0.0
for _ in range(20): x_gd -= 0.1 * gp(x_gd)   # 梯度下降要很多步

x_newton = 0.0
x_newton = x_newton - gp(x_newton) / gpp(x_newton)   # 牛顿法一步
print(f'GD 结果: {x_gd:.4f}, 牛顿法结果: {x_newton:.4f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 复杂梯度先手推再用 autograd 或有限差分数值验证，避免符号错误
2. 反向传播里注意矩阵维度对齐，梯度形状必须和参数形状一致
3. 用中心差分 (f(x+h)-f(x-h))/2h 而非前向差分，误差从 O(h) 降到 O(h²)
4. 判断极值要结合 Hessian：∇f=0 只是必要条件，H 正定才是极小
5. 牛顿法收敛快但对初始点和 Hessian 奇异性敏感，大规模问题用拟牛顿（L-BFGS）
6. 泰勒展开用于分析时记住它是局部近似，离展开点远了会发散

### 踩坑记录

```text
坑 1：反向传播忘记除以 batch size
结论：梯度被放大 batch 倍，训练震荡或发散。
原因：损失用了均值，梯度也必须均值（除以 n）。
解法：损失用 mean 时，梯度同样 mean，或统一用 sum 并调学习率。

坑 2：数值微分用前向差分导致精度差
结论：导数误差 O(h)，且 h 太小引入舍入误差。
原因：前向差分 (f(x+h)-f(x))/h 截断误差大。
解法：用中心差分，h 取 1e-5~1e-7 平衡截断和舍入误差。

坑 3：混淆梯度与方向导数
结论：把梯度当成任意方向的变化率。
原因：梯度只沿「最陡方向」，方向导数 = ∇f·u（单位向量 u）。
解法：任意方向的变化率要投影：D_u f = ∇f·u。

坑 4：牛顿法在非凸或奇异 Hessian 上失效
结论：H⁻¹ 不存在或方向错误，迭代发散。
原因：牛顿法要求 Hessian 正定，非凸处可能负定。
解法：加阻尼（Levenberg-Marquardt）、Hessian 对角扰动，或用拟牛顿。

坑 5：泰勒展开取太多项在远离展开点处发散
结论：高阶近似在 x 远离 a 时反而更差。
原因：泰勒级数有收敛半径，超出半径多项式剧烈发散。
解法：仅在展开点附近用高阶近似，远处用其他方法。
```
