## 概述

激活函数是网络里唯一引入非线性的地方：线性层的复合仍是线性，只有插入非线性激活，网络才有能力拟合复杂函数。选择激活函数要在「梯度流动性」和「表达力」之间权衡——饱和函数（sigmoid/tanh）有界但容易梯度消失，ReLU 家族解决了梯度消失但输出无上界。

```text
激活函数的核心诉求：
1. 非线性 —— 让网络能表达非线性映射
2. 可微 —— 反向传播需要导数（ReLU 在 0 点不可微，实践中取单侧值）
3. 梯度不消失 —— 饱和区导数接近 0 会导致学习停滞
4. 计算便宜 —— 每层每神经元都要算，exp 比 max 贵得多
5. 输出范围稳定 —— 有界便于数值稳定，无界需要配合归一化
```

```python
import torch
import torch.nn.functional as F

x = torch.tensor([-3., -1., 0., 1., 3.])
for name, fn in [('sigmoid', torch.sigmoid), ('tanh', torch.tanh),
                 ('relu', F.relu), ('gelu', F.gelu), ('silu', F.silu)]:
    print(f'{name:8s}: {fn(x).tolist()}')
```

## Sigmoid

Sigmoid 把输入压缩到 (0, 1)，天然适合做概率输出。它曾经是隐藏层的默认激活，但因为两端饱和、导数最大只有 0.25、输出不以 0 为中心，深层网络里很容易梯度消失，现在主要用在二分类输出层和门控结构。

```text
数学定义：
σ(z) = 1 / (1 + e⁻ᶻ)
σ'(z) = σ(z)·(1 - σ(z))

性质：
1. 输出范围 (0, 1)，可解释为概率
2. 导数最大值 0.25，多层连乘指数衰减 → 梯度消失
3. 输出恒为正（不以 0 为中心），梯度更新方向被偏置，收敛慢
```

```python
import torch

def sigmoid(z):
    return 1 / (1 + torch.exp(-z))

z = torch.tensor([-5., 0., 5.])
print(sigmoid(z))                       # 接近 [0, 0.5, 1]
print(sigmoid(z) * (1 - sigmoid(z)))    # 导数，在 0 处最大 0.25

# 饱和区演示：|z| 大时导数几乎为 0
print(torch.sigmoid(torch.tensor(50.)))     # 1.0（饱和）
print(torch.sigmoid(torch.tensor(-50.)))    # 0.0（饱和）
```

## Tanh

Tanh 是 Sigmoid 的平移缩放版，输出范围 (-1, 1)，以 0 为中心，缓解了 Sigmoid 输出偏置的问题，但两端依然饱和、梯度消失问题仍在。它在 RNN 隐藏状态和早期网络里常见。

```text
数学定义：
tanh(z) = (eᶻ - e⁻ᶻ) / (eᶻ + e⁻ᶻ) = 2σ(2z) - 1
tanh'(z) = 1 - tanh²(z)

与 sigmoid 的关系：tanh(z) = 2σ(2z) - 1
优点：零中心，梯度比 sigmoid 更强（导数最大 1）
缺点：两端仍饱和，深层网络梯度消失
```

```python
import torch

z = torch.tensor([-2., 0., 2.])
print(torch.tanh(z))                 # [-0.96, 0, 0.96]，零中心
print(1 - torch.tanh(z) ** 2)        # 导数，z=0 处为 1

# 与 sigmoid 的等价关系验证
z = torch.tensor(1.5)
print(torch.isclose(torch.tanh(z), 2 * torch.sigmoid(2 * z) - 1))  # True
```

## ReLU

ReLU 是当前隐藏层最常用的激活：正区间恒等、负区间置 0。它解决了 sigmoid/tanh 的正向饱和问题（正区间导数恒为 1），计算只需一次 max，收敛快；代价是负区间导数为 0，神经元可能「死掉」再也无法激活。

```text
数学定义：
ReLU(z) = max(0, z)
ReLU'(z) = 1 if z > 0 else 0

优点：
1. 正区间无饱和，梯度恒为 1，缓解梯度消失
2. 计算极便宜（一次比较），利于深层和大模型
3. 稀疏激活 —— 负输入输出 0，天然稀疏

缺点：
1. 负区间梯度 0，Dead ReLU 问题
2. 输出不以 0 为中心
```

```python
import torch
import torch.nn as nn

relu = nn.ReLU()
z = torch.tensor([-3., -1., 0., 2., 5.])
print(relu(z))                       # [0, 0, 0, 2, 5]

# Dead ReLU 演示：学习率过大导致权重偏移，神经元输出恒为负
w = torch.tensor([1.0], requires_grad=True)
x = torch.tensor([-10.0])            # 大负输入
out = relu(w * x)
out.backward()
print(w.grad)                        # 0，梯度为 0，神经元无法更新
```

## Leaky ReLU

Leaky ReLU 给负区间一个很小的斜率（如 0.01），让负输入也有非零梯度，解决 Dead ReLU。PReLU 把斜率也变成可学习参数。它在对抗 ReLU 神经元死亡时有用，但实践中收益不如预期，不总是优于 ReLU。

```text
数学定义：
LeakyReLU(z) = z if z > 0 else α·z   （α 默认 0.01）
LeakyReLU'(z) = 1 if z > 0 else α

变体：
1. PReLU —— α 作为可学习参数，每个通道一个
2. RReLU —— α 在训练时随机采样，测试时取平均

优点：负区间不再梯度为 0，缓解 Dead ReLU
```

```python
import torch
import torch.nn as nn

leaky = nn.LeakyReLU(0.01)
z = torch.tensor([-3., -1., 0., 2.])
print(leaky(z))                      # [-0.03, -0.01, 0, 2]

# PReLU：负斜率可学习
prelu = nn.PReLU(num_parameters=1)
out = prelu(z)
print(out, prelu.weight)             # 初始 α=0.25，随训练更新
```

## GELU

GELU（高斯误差线性单元）是 Transformer 架构的默认激活：它不像 ReLU 那样硬截断，而是用「输入为正的概率」平滑加权，在 0 附近连续可微，且有一定随机正则效果。BERT、GPT 系列都用它。

```text
数学定义：
GELU(z) = z · Φ(z) = z · P(Z ≤ z)，Z ~ N(0, 1)

近似形式（工程常用）：
GELU(z) ≈ 0.5z · (1 + tanh(√(2/π)·(z + 0.044715·z³)))

性质：
1. 处处可微，比 ReLU 平滑，梯度更稳定
2. 负输入不是硬置 0，而是小概率通过
3. 在 Transformer/大模型里表现优于 ReLU
```

```python
import torch
import torch.nn.functional as F

z = torch.tensor([-3., -1., 0., 1., 3.])
print(F.gelu(z))

# 精确形式（用标准正态 CDF）与近似形式对比
cdf = 0.5 * (1 + torch.erf(z / (2 ** 0.5)))
exact = z * cdf
approx = 0.5 * z * (1 + torch.tanh((2 / 3.14159) ** 0.5 * (z + 0.044715 * z ** 3)))
print(torch.allclose(exact, approx, atol=1e-3))   # True
```

## SiLU / Swish

SiLU 也叫 Swish，是 z 乘以 sigmoid：正区间接近线性（类似 ReLU 但平滑），负区间趋近 0 但不硬截断。它由搜索发现，在很多视觉和现代网络（EfficientNet、ConvNeXt）里表现优于 ReLU。

```text
数学定义：
SiLU(z) = z · σ(z) = z / (1 + e⁻ᶻ)

性质：
1. 平滑、处处可微，负区间非零
2. 有下界（约 -0.28）无上界
3. 是 GELU 的近亲，形状相似，但 SiLU 计算更简单
```

```python
import torch
import torch.nn.functional as F

z = torch.tensor([-3., -1., 0., 1., 3.])
print(F.silu(z))                      # [~-0.14, ~-0.27, 0, 0.73, 2.86]

# 手写验证 SiLU = z * sigmoid(z)
manual = z * torch.sigmoid(z)
print(torch.allclose(F.silu(z), manual))    # True
```

## Softmax

Softmax 把任意实数向量映射成和为 1 的概率分布，是多分类输出层的标准选择。它保持输入的大小顺序（单调），且指数放大差异让最大项更突出。配合交叉熵使用时，梯度退化为「预测概率 - 真实标签」，训练稳定。

```text
数学定义：
softmax(z)ᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}

性质：
1. 输出非负、和为 1，可解释为类别概率
2. 单调保序，指数放大相对差异
3. 数值稳定性：减去 max(z) 再算，避免 e^大数 溢出

与交叉熵结合：dL/dz = softmax(z) - y（one-hot）
```

```python
import torch
import torch.nn.functional as F

logits = torch.tensor([2.0, 1.0, 0.1])
probs = F.softmax(logits, dim=-1)
print(probs, probs.sum())            # 概率分布，和为 1

# 数值稳定写法：先减 max
def stable_softmax(z):
    z = z - z.max()
    return torch.exp(z) / torch.exp(z).sum()

print(stable_softmax(torch.tensor([1000., 1000., 1000.])))  # 不溢出，均匀 1/3

# 温度参数：温度越低越尖锐
for T in [0.5, 1.0, 5.0]:
    print(f'T={T}:', F.softmax(logits / T, dim=-1))
```

## 应用场景实战

### 场景一：多分类情感分类输出层

```python
import torch
import torch.nn as nn

# 输出层用 softmax + 交叉熵，PyTorch 的 CrossEntropyLoss 内置 softmax
class Classifier(nn.Module):
    def __init__(self, in_dim, num_classes):
        super().__init__()
        self.fc = nn.Linear(in_dim, num_classes)

    def forward(self, x):
        return self.fc(x)            # 返回 logits，softmax 交给 loss

model = Classifier(10, 3)
x = torch.randn(4, 10)
logits = model(x)
labels = torch.tensor([0, 2, 1, 0])

loss_fn = nn.CrossEntropyLoss()
print(f'loss={loss_fn(logits, labels):.4f}')
print('概率分布:', torch.softmax(logits[0], dim=-1))
```

### 场景二：不同激活函数对训练速度的影响

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
x = torch.randn(2000, 20)
y = (x[:, 0] * x[:, 1] > 0).float().unsqueeze(1)   # 非线性决策边界

def train_with(act_fn, name):
    net = nn.Sequential(nn.Linear(20, 64), act_fn,
                        nn.Linear(64, 64), act_fn, nn.Linear(64, 1))
    opt = torch.optim.Adam(net.parameters(), lr=1e-3)
    for step in range(200):
        loss = nn.functional.binary_cross_entropy_with_logits(net(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
    print(f'{name}: final_loss={loss.item():.4f}')

train_with(nn.ReLU(), 'ReLU')
train_with(nn.Tanh(), 'Tanh')      # tanh 饱和，收敛较慢
train_with(nn.GELU(), 'GELU')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 隐藏层默认 ReLU 起步，Transformer/大模型用 GELU，视觉现代网络可试 SiLU
2. 二分类输出用 Sigmoid，多分类用 Softmax（配合 CrossEntropyLoss，别手动拼）
3. 输出层前一层不用 ReLU 这种会「截断」的激活，保证 logits 能取负值
4. 数值稳定：Softmax 先减 max，Sigmoid 用 log-sum-exp 或 torch 自带实现
5. 初始化与激活配对：ReLU 家族配 He 初始化，tanh/sigmoid 配 Xavier
6. 遇到 Dead ReLU 可换 Leaky ReLU/PReLU，或调小学习率

### 踩坑记录

```text
坑 1：softmax 直接对很大的 logits 计算导致 NaN
结论：logits 很大时 e^z 溢出为 inf，出现 inf/inf = NaN。
原因：e^1000 超出浮点表示范围。
解法：softmax 前减去 max(z)，或直接 torch.log_softmax 内部已处理。

坑 2：sigmoid + MSE 做分类训练不动
结论：损失下降极慢，训练像卡住。
原因：sigmoid 饱和区导数接近 0，MSE 梯度含 σ' 项，梯度消失。
解法：分类改用 BCEWithLogitsLoss / CrossEntropyLoss。

坑 3：把 ReLU 放在输出层做回归
结论：模型永远预测不出负值，拟合能力受限。
原因：ReLU 负区间输出 0，输出被截断到 [0, +∞)。
解法：回归输出层用恒等（无激活）或按需用有界激活。

坑 4：训练时加了 Dropout 忘记切换 eval 模式，与激活无关但同源
结论：推理时输出被随机置零，结果不稳定。
原因：Dropout 在 train 模式随机失活，eval 模式才关闭。
解法：推理前 model.eval()，配合 torch.no_grad()。

坑 5：混淆 Leaky ReLU 的负斜率符号
结论：传了负的 negative_slope，负区间反而放大。
原因：API 参数理解错误，negative_slope 应为正小数。
解法：nn.LeakyReLU(0.01) 传正值，验证负输入输出为负的小值。
```
