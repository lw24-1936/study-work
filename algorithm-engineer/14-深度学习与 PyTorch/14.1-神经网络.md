## 概述

神经网络是用多层可微函数堆叠出来的参数化模型：前向计算逐层变换输入，反向传播把损失梯度沿链式法则传回，用梯度下降更新参数。它是深度学习的基础结构，几乎所有现代模型（CNN、RNN、Transformer）都是它的特例或变体。

```text
神经网络的核心构成：
1. 前向传播 —— 输入逐层做线性变换 + 非线性激活，得到预测
2. 损失函数 —— 量化预测与真实标签的差距，是优化的目标
3. 反向传播 —— 链式法则计算每个参数对损失的梯度
4. 参数更新 —— 优化器沿负梯度方向调整权重
5. 初始化 —— 决定训练起点，错误初始化会导致梯度消失/爆炸
```

```python
import torch
import torch.nn as nn

# 一个最小 MLP：输入 4 维 → 隐藏 8 维 → 输出 2 维
net = nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 2),
)
x = torch.randn(3, 4)          # 3 个样本，每个 4 维
print(net(x).shape)            # torch.Size([3, 2])
```

## Perceptron

感知机是最早的神经元模型：对输入做加权求和，再过一个阶跃/阈值函数输出二值结果。它是线性分类器，只能解决线性可分问题，无法处理 XOR。

```text
数学定义：
y = φ(w·x + b)

其中 φ 是阶跃函数（或符号函数）：
φ(z) = 1  if z ≥ 0
φ(z) = 0  if z < 0

更新规则（感知机学习算法）：
w ← w + η·(t - y)·x   # 预测错误时才更新
b ← b + η·(t - y)

限制：只能拟合线性决策边界，XOR 这类线性不可分问题无法收敛。
```

```python
import numpy as np

# 感知机手写实现（线性可分的二分类）
def perceptron_fit(X, y, lr=0.1, epochs=100):
    n_samples, n_feat = X.shape
    w = np.zeros(n_feat)
    b = 0.0
    for _ in range(epochs):
        for i in range(n_samples):
            pred = 1 if np.dot(w, X[i]) + b >= 0 else 0
            err = y[i] - pred
            w += lr * err * X[i]
            b += lr * err
    return w, b

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y = np.array([0, 0, 0, 1])       # AND 门，线性可分
w, b = perceptron_fit(X, y)
print([1 if np.dot(w, x) + b >= 0 else 0 for x in X])  # [0, 0, 0, 1]
```

## MLP

MLP（多层感知机）在输入输出之间加入一个或多个隐藏层，每层都是「线性变换 + 非线性激活」。至少一层隐藏层且用非线性激活的 MLP 是万能逼近器，能拟合任意连续函数，因此能解决 XOR 这类非线性问题。

```text
结构：
输入 x → W1·x + b1 → σ → W2·(σ(W1·x+b1)) + b2 → 输出

两层 MLP 的前向计算：
h = σ(W1 x + b1)
y = W2 h + b2

关键点：
1. 没有非线性激活，多层退化成单层线性变换
2. 隐藏层宽度和深度决定模型容量
3. 万能逼近定理：单隐层足够宽可逼近任意连续函数
```

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()
        self.fc1 = nn.Linear(in_dim, hidden)
        self.fc2 = nn.Linear(hidden, hidden)
        self.fc3 = nn.Linear(hidden, out_dim)
        self.act = nn.ReLU()

    def forward(self, x):
        x = self.act(self.fc1(x))
        x = self.act(self.fc2(x))
        return self.fc3(x)

net = MLP(4, 16, 1)
print(net(torch.randn(8, 4)).shape)   # torch.Size([8, 1])

# XOR 验证：MLP 能拟合线性不可分问题
xor_x = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
xor_y = torch.tensor([[0.], [1.], [1.], [0.]])
model = MLP(2, 8, 1)
opt = torch.optim.Adam(model.parameters(), lr=0.1)
for _ in range(2000):
    loss = nn.functional.mse_loss(model(xor_x), xor_y)
    opt.zero_grad(); loss.backward(); opt.step()
print((model(xor_x) > 0.5).float().view(-1).tolist())  # [0,1,1,0]
```

## Activation

激活函数给网络引入非线性。没有它，多层线性变换复合后仍是线性变换，网络表达力等价于单层。激活函数的选取会影响梯度流动（饱和区梯度消失）和收敛速度，具体函数见 [[14.2-激活函数]]。

```text
作用：
1. 引入非线性 —— 让网络能拟合非线性决策边界
2. 控制输出范围 —— sigmoid/tanh 有界，ReLU 半有界
3. 影响梯度 —— 饱和区梯度接近 0，导致学习停滞

常见选择：
- 隐藏层默认 ReLU 或 GELU
- 二分类输出 sigmoid，多分类输出 softmax
- 回归输出通常不加激活（恒等映射）
```

```python
import torch
import torch.nn.functional as F

x = torch.tensor([-2., -1., 0., 1., 2.])
print('ReLU:  ', F.relu(x))      # [0,0,0,1,2]
print('Sigmoid:', torch.sigmoid(x))
print('Tanh:  ', torch.tanh(x))
```

## Loss

损失函数把「预测与真实的差距」量化成一个标量，是反向传播的起点。回归用 MSE/MAE，二分类用 BCE，多分类用 CrossEntropy，它们决定了模型优化的方向和最终学到的输出分布。

```text
常见损失：
1. MSE = (1/n) Σ (y - ŷ)²        —— 回归，对大误差敏感
2. MAE = (1/n) Σ |y - ŷ|         —— 回归，对异常值鲁棒
3. BCE = -[y log ŷ + (1-y) log(1-ŷ)]  —— 二分类
4. CrossEntropy = -Σ y log softmax(z) —— 多分类（PyTorch 内置 softmax）

为什么分类不用 MSE：sigmoid + MSE 梯度含 σ'(z)，饱和区梯度消失，收敛慢；
交叉熵与 softmax 结合后梯度简化为 (ŷ - y)，收敛快。
```

```python
import torch
import torch.nn as nn

# 三种损失对比
y_true = torch.tensor([1.0, 0.0, 1.0])
y_pred = torch.tensor([0.9, 0.2, 0.8])

mse = nn.MSELoss()(y_pred, y_true)
bce = nn.BCELoss()(y_pred, y_true)
print(f'MSE={mse:.4f}, BCE={bce:.4f}')

# 多分类：CrossEntropy 内部先 softmax 再取负对数似然
logits = torch.randn(2, 5)          # 2 个样本，5 类
labels = torch.tensor([1, 3])
ce = nn.CrossEntropyLoss()(logits, labels)
print(f'CrossEntropy={ce:.4f}')
```

## Backpropagation

反向传播用链式法则，把输出端的损失梯度一层层往回传，算出每个参数的梯度。它依赖「前向计算时缓存中间激活值」，是训练神经网络的核心算法，也是 PyTorch Autograd 自动实现的机制。

```text
计算图与链式法则：
L = f(g(x)) → dL/dx = (dL/dg) · (dg/dx)

对一层线性变换 y = Wx + b：
dL/dW = (dL/dy) · xᵀ
dL/db = (dL/dy)
dL/dx = Wᵀ · (dL/dy)   # 继续往回传

反向传播 = 沿着计算图反向，逐节点用局部梯度相乘。
```

```python
import torch

# 手工反向传播：二层网络，验证与 Autograd 一致
x = torch.tensor([1.0, -2.0, 3.0], requires_grad=True)
W = torch.tensor([[0.5, -0.3, 0.2], [0.1, 0.4, -0.2]], requires_grad=True)

y = W @ x                          # 线性层
loss = (y ** 2).sum()              # 平方损失
loss.backward()

# 手工推导：loss = Σ(Wx)²，dL/dW = 2·y·xᵀ
manual_grad = 2 * (W @ x).detach().unsqueeze(1) * x.detach().unsqueeze(0)
print(torch.allclose(W.grad, manual_grad))   # True

# 梯度会沿 x 继续回传
print(x.grad)   # Wᵀ · 2y
```

## Initialization

参数初始化决定训练的起点。全零初始化会让同层所有神经元梯度相同、无法分化（对称性破坏失败）；过大初始化导致激活饱和/梯度爆炸，过小导致梯度消失。Xavier/He 初始化根据层宽缩放方差，是训练稳定收敛的前提。

```text
初始化目标：保持前向信号和反向梯度的方差在层间稳定。

常见方案：
1. Xavier/Glorot —— 适合 tanh/sigmoid，方差 = 2/(fan_in + fan_out)
2. He/Kaiming —— 适合 ReLU 家族，方差 = 2/fan_in（考虑 ReLU 砍掉一半）
3. 全零初始化 —— 禁止，破坏对称性，所有神经元学的一样
4. 正交初始化 —— 保持范数，用于 RNN 隐藏状态

PyTorch nn.Linear 默认用 Kaiming Uniform。
```

```python
import torch.nn as nn

layer = nn.Linear(10, 20)

# 手动用不同方案初始化
nn.init.xavier_uniform_(layer.weight)     # Xavier
nn.init.kaiming_normal_(layer.weight, a=0, mode='fan_in')   # He
nn.init.orthogonal_(layer.weight)         # 正交
nn.init.zeros_(layer.bias)                # 偏置一般置零

# 检查初始化后的权重统计
print(f'weight mean={layer.weight.mean():.4f}, std={layer.weight.std():.4f}')
```

## 应用场景实战

### 场景一：MNIST 手写数字分类

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

transform = transforms.Compose([transforms.ToTensor(),
                                transforms.Normalize((0.1307,), (0.3081,))])
train = datasets.MNIST('./data', train=True, download=True, transform=transform)
loader = DataLoader(train, batch_size=64, shuffle=True)

net = nn.Sequential(nn.Flatten(), nn.Linear(784, 256), nn.ReLU(),
                    nn.Linear(256, 128), nn.ReLU(), nn.Linear(128, 10))
opt = torch.optim.Adam(net.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

for epoch in range(2):
    total = 0
    for x, y in loader:
        opt.zero_grad()
        loss = criterion(net(x), y)
        loss.backward()
        opt.step()
        total += loss.item()
    print(f'epoch {epoch}: loss={total / len(loader):.4f}')
```

### 场景二：回归拟合非线性函数

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

torch.manual_seed(0)
x = torch.linspace(-3, 3, 100).unsqueeze(1)
y = x**3 - 2*x + torch.randn(100, 1) * 0.5    # 带噪声的三次函数

net = nn.Sequential(nn.Linear(1, 32), nn.Tanh(),
                    nn.Linear(32, 32), nn.Tanh(), nn.Linear(32, 1))
opt = torch.optim.Adam(net.parameters(), lr=1e-2)
for _ in range(2000):
    loss = nn.functional.mse_loss(net(x), y)
    opt.zero_grad(); loss.backward(); opt.step()

plt.scatter(x.numpy(), y.numpy(), s=5)
plt.plot(x.numpy(), net(x).detach().numpy(), color='red')
plt.title(f'MSE={loss.item():.3f}')
plt.show()
```

## 最佳实践与踩坑记录

### 最佳实践

1. 隐藏层默认用 ReLU 或 GELU，输出层按任务选激活（分类 softmax/sigmoid，回归恒等）
2. 线性层之后紧跟 BatchNorm 时，LayerNorm/BatchNorm 已经带了偏置，可以关掉 Linear 的 bias 避免冗余参数
3. 先用小网络（少量隐藏层）跑通数据流，再逐步加深加宽，别一上来就堆大模型
4. 用 He/Kaiming 初始化配合 ReLU，Xavier 配合 tanh/sigmoid，别用全零初始化
5. 分类任务损失用 CrossEntropyLoss，别自己拼 softmax + log，数值更稳定
6. 反向传播前记得 opt.zero_grad()，否则梯度会跨 batch 累加

### 踩坑记录

```text
坑 1：全零初始化导致所有神经元学得一模一样
结论：网络表达力退化成单个神经元，训练无法进行。
原因：同层神经元梯度完全一致，参数更新后仍对称，破坏不了对称性。
解法：用随机初始化（Xavier/He），偏置可置零。

坑 2：忘记加非线性激活，深层网络等价单层线性
结论：加深网络没有带来任何收益，拟合不了非线性关系。
原因：线性变换的复合仍是线性变换，表达力无提升。
解法：每个线性层后接非线性激活，除非该层是残差连接等特殊情况。

坑 3：损失用 MSE 配 sigmoid 输出做分类
结论：训练初期收敛极慢，梯度接近 0。
原因：sigmoid 饱和区导数 σ'(z)≈0，MSE 梯度含 σ'(z) 项，梯度消失。
解法：分类用 CrossEntropy（配 softmax），梯度简化为 ŷ - y。

坑 4：初始化方差过大导致梯度爆炸，loss 变成 NaN
结论：训练几步后 loss 发散为 inf/NaN。
原因：权重过大，前向激活饱和、反向梯度指数放大。
解法：用标准初始化 + 学习率 warmup，必要时加梯度裁剪。

坑 5：反向传播时没清梯度，loss 不下降甚至震荡
结论：梯度跨 batch 累加，更新方向错误。
原因：PyTorch 的 backward 默认累加梯度，不覆盖。
解法：每个 step 前 opt.zero_grad()，或用 set_to_none=True 省显存。
```
