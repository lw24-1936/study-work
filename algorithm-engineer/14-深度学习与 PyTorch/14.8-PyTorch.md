## 概述

PyTorch 是当前深度学习研究和工业落地的首选框架：动态计算图（define-by-run）让调试像写普通 Python 一样直观，Tensor/Autograd/nn.Module 三层抽象覆盖从张量运算到分布式训练的全部需求。

```text
PyTorch 的核心抽象：
1. Tensor —— 张量，GPU 加速的多维数组，可自动求导
2. Autograd —— 自动微分，反向传播的基础
3. nn.Module —— 神经网络层的封装，管理参数与 forward
4. DataLoader —— 数据加载与批处理
5. Optimizer / Scheduler —— 参数更新与学习率调度
```

```python
import torch
import torch.nn as nn

# 最小可运行：张量 + 自动求导 + 一次梯度下降
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2            # y = x²
y.backward()          # 自动求导
print(x.grad)         # tensor([4.]) → dy/dx = 2x = 4
```

## Tensor

Tensor 是 PyTorch 的基本数据结构，类似 NumPy 的 ndarray，但支持 GPU 和自动求导。

```python
import torch

# 创建
a = torch.tensor([1, 2, 3])
b = torch.zeros(2, 3)
c = torch.randn(4, 4)
d = torch.arange(10)

# 与 NumPy 互转（共享内存，改一边另一边也变）
import numpy as np
arr = np.array([1, 2, 3])
t = torch.from_numpy(arr)
back = t.numpy()

# GPU 迁移
if torch.cuda.is_available():
    x = torch.randn(1000, 1000).cuda()
    y = x @ x.T          # GPU 矩阵乘法
```

```text
Tensor 的关键点：
1. dtype —— float32 默认，训练常用 float16/bf16（AMP）
2. device —— CPU 或 CUDA，用 .to(device) 迁移
3. requires_grad —— 需要求导的张量设为 True
4. 视图 vs 拷贝 —— view/reshape 共享内存，clone 拷贝
```

## Dataset

Dataset 封装「取第 i 个样本」的逻辑，是数据管线的起点。

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, data, labels):
        self.data = data
        self.labels = labels

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        return self.data[idx], self.labels[idx]

# 内置数据集
from torchvision.datasets import MNIST
from torchvision import transforms

dataset = MNIST(root='./data', train=True, download=True,
                transform=transforms.ToTensor())
```

## DataLoader

DataLoader 把 Dataset 变成迭代的批量数据，负责批处理、打乱、并行加载。

```python
from torch.utils.data import DataLoader

loader = DataLoader(dataset, batch_size=64, shuffle=True, num_workers=4)

for batch_idx, (x, y) in enumerate(loader):
    # x: [64, 1, 28, 28], y: [64]
    print(f'batch {batch_idx}: x={x.shape}, y={y.shape}')
    break   # 只看第一个 batch
```

```text
DataLoader 的关键参数：
1. batch_size —— 批大小
2. shuffle —— 训练集打乱，验证集不打乱
3. num_workers —— 并行加载进程数，太少成为瓶颈
4. pin_memory —— 锁页内存，加速 CPU→GPU 传输
5. drop_last —— 丢弃最后不足一批的数据
```

## Transform

Transform 做数据预处理和数据增强，通常是 `transforms.Compose` 组合多个操作。

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])

# 数据增强（训练集常用）
train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(0.2, 0.2, 0.2),
    transforms.ToTensor(),
])
```

## nn.Module

nn.Module 是所有网络层的基类，管理子模块和参数，定义 forward 前向传播。

```python
import torch.nn as nn
import torch.nn.functional as F

class MLP(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()
        self.fc1 = nn.Linear(in_dim, hidden)
        self.fc2 = nn.Linear(hidden, out_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        return self.fc2(x)

model = MLP(784, 256, 10)
print(model)          # 打印结构
print(list(model.parameters()))  # 自动收集所有参数
```

```text
nn.Module 的要点：
1. 子模块放 __init__，forward 只描述数据流
2. 参数自动注册 —— 赋给 self 的模块/参数会被追踪
3. state_dict —— 保存/加载权重的标准格式
4. 三种模式 —— train()（Dropout/BN 生效）vs eval()（推理）
```

## Parameter

Parameter 是特殊的 Tensor，注册到 Module 后会被 optimizer 自动收集。

```python
import torch.nn as nn

class Layer(nn.Module):
    def __init__(self):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(10, 10))
        self.bias = nn.Parameter(torch.zeros(10))

layer = Layer()
# optimizer 会自动收集 layer.parameters()
# 普通 Tensor 赋值不会被注册，需用 register_buffer 或 Parameter
```

## Autograd

Autograd 是自动微分引擎，构建动态计算图，backward 时自动计算梯度。

```python
import torch

x = torch.randn(3, requires_grad=True)
w = torch.randn(3, requires_grad=True)
y = (x * w).sum()      # 前向构建计算图
y.backward()           # 反向自动求梯度
print(x.grad, w.grad)

# 梯度清零（默认累加）
x.grad.zero_()

# 推理时不构建计算图
with torch.no_grad():
    z = x * 2
```

```text
Autograd 的要点：
1. 动态图 —— 每次前向都重建计算图，控制流天然支持
2. 梯度累加 —— backward 默认累加，每步前要 zero_grad
3. no_grad —— 推理/验证时禁用，省显存加速
4. detach —— 从计算图断开，阻止梯度回传
```

## Optimizer

Optimizer 用梯度更新参数，封装 SGD/Adam 等优化算法。

```python
import torch.optim as optim

optimizer = optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)

# 训练循环的标准三步
optimizer.zero_grad()   # 1. 清空上一步梯度
loss.backward()         # 2. 反向传播
optimizer.step()        # 3. 更新参数

# 不同参数组用不同学习率
optimizer = optim.AdamW([
    {'params': model.features.parameters(), 'lr': 1e-4},
    {'params': model.classifier.parameters(), 'lr': 1e-3},
], weight_decay=1e-4)
```

## Scheduler

Scheduler 按策略调整学习率，常用 Cosine Decay、Step、Warmup 等。

```python
from torch.optim.lr_scheduler import CosineAnnealingLR, OneCycleLR

scheduler = CosineAnnealingLR(optimizer, T_max=100)

for epoch in range(100):
    train_one_epoch()
    scheduler.step()    # 每个 epoch 后更新学习率
```

```text
Scheduler 的要点：
1. 时机 —— 通常每 epoch step，也可每 batch（OneCycleLR）
2. Warmup —— 训练初期线性升学习率，避免不稳定
3. Cosine Decay —— 现代训练标配，从初始值余弦退到最小
```

## AMP

AMP（自动混合精度）用 float16/bf16 计算、float32 累积，几乎无损地加速训练、省显存。

```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for x, y in loader:
    optimizer.zero_grad()
    with autocast():          # 自动混合精度
        loss = model(x)
    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
```

```text
AMP 的要点：
1. 加速 —— 利用 Tensor Core，训练快 1.5~3 倍
2. 省显存 —— 激活存半精度，能上更大 batch
3. GradScaler —— 防止梯度下溢，需配合使用
4. 新版 torch.amp 统一了 autocast 接口
```

## DistributedDataParallel

DDP 用多卡数据并行训练，每卡一个模型副本，梯度同步后更新。

```python
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

# 初始化进程组
dist.init_process_group(backend='nccl')
model = model.cuda()
model = DDP(model, device_ids=[local_rank])

# 启动：torchrun --nproc_per_node=8 train.py
```

```text
DDP 的要点：
1. 数据并行 —— 每卡处理不同 batch，梯度 all-reduce 同步
2. 启动 —— 用 torchrun，别再手写 mp.spawn
3. 数据分区 —— 配合 DistributedSampler 保证每卡数据不重复
4. 同步 BN —— 跨卡同步 BatchNorm 统计量（SyncBatchNorm）
```

## FSDP

FSDP（全分片数据并行）把模型参数、梯度、优化器状态分片到各卡，能训更大的模型。

```python
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP

model = FSDP(model)
# 配合 torch.distributed.checkpoint 保存/加载
```

```text
FSDP vs DDP：
1. DDP —— 每卡存完整模型副本，显存开销大
2. FSDP —— 参数分片，各卡只存 1/N 参数，训大模型必备
3. 激活检查点 —— 配合 activation checkpoint 进一步省显存
```

## Checkpoint

Checkpoint 保存/加载模型权重和训练状态，支持断点续训。

```python
# 保存
torch.save({
    'epoch': epoch,
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': optimizer.state_dict(),
    'loss': loss,
}, 'checkpoint.pt')

# 加载（续训）
ckpt = torch.load('checkpoint.pt')
model.load_state_dict(ckpt['model_state_dict'])
optimizer.load_state_dict(ckpt['optimizer_state_dict'])
```

```text
Checkpoint 的要点：
1. 保存 state_dict —— 别保存整个 model（绑定类定义，迁移性差）
2. 同时存 optimizer/scheduler —— 才能断点续训
3. 多卡用 torch.distributed.checkpoint 或 sharded 保存
4. 定期保存 + 保留最佳模型（best.pt）
```

## 应用场景实战

### 场景一：完整训练流程（MNIST 分类）

```python
import torch, torch.nn as nn, torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# 数据
transform = transforms.ToTensor()
train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
train_loader = DataLoader(train_set, batch_size=64, shuffle=True)

# 模型
model = nn.Sequential(nn.Flatten(), nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 10))

# 训练
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-3)
for epoch in range(3):
    for x, y in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(x), y)
        loss.backward()
        optimizer.step()
    print(f'Epoch {epoch}, loss={loss.item():.4f}')
```

### 场景二：迁移学习 + 微调

```python
import torchvision.models as models

# 加载预训练模型，替换分类头
model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V1)
model.fc = nn.Linear(model.fc.in_features, 10)

# 冻结主干，只训分类头
for p in model.parameters():
    p.requires_grad = False
for p in model.fc.parameters():
    p.requires_grad = True

optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)
```

## 最佳实践与踩坑记录

### 最佳实践

1. 用 `model.state_dict()` 保存，别 `torch.save(model)` 整个对象
2. 训练前 `optimizer.zero_grad()`，别忘梯度累加陷阱
3. 推理/验证用 `torch.no_grad()` + `model.eval()`
4. 数据加载 num_workers 设 4-8，太少成瓶颈
5. 显存不足优先 AMP + 减小 batch，再上梯度累积/FSDP
6. 固定随机种子保证可复现

### 踩坑记录

```text
坑 1：训练时忘了 zero_grad
结论：loss 不下降或震荡，梯度越累越大。
原因：backward 默认累加梯度，不清零就叠加了历史梯度。
解法：每个 step 前 optimizer.zero_grad()（或 set_to_none=True 省显存）。

坑 2：torch.save(model) 整个模型
结论：换环境/换版本后加载报错，或序列化出超大的 pickle。
原因：保存整个对象绑定了类定义和 Python 环境。
解法：保存 model.state_dict()，加载时先建同结构模型再 load_state_dict。

坑 3：推理没关 no_grad 和 eval
结论：显存暴涨、预测结果和训练不一致。
原因：计算图累积占用显存；Dropout/BN 在 train 模式行为不同。
解法：推理前 model.eval() + with torch.no_grad()。

坑 4：data 在 CPU、model 在 GPU
结论：报错 expected device cuda but got cpu。
原因：只把 model 移到 GPU，数据忘了 .to(device)。
解法：统一 device 变量，数据和模型都 .to(device)。

坑 5：num_workers=0 训练极慢
结论：GPU 空转等数据，训练速度被数据加载拖垮。
原因：主进程串行读数据，CPU 成了瓶颈。
解法：num_workers 设 4-8，配 pin_memory=True 加速传输。
```
