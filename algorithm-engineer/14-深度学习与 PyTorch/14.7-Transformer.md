## 概述

Transformer 用纯注意力机制替代 RNN 的循环结构，通过「自注意力」让序列中任意两个位置直接交互，彻底解决了长距离依赖问题，且天然可并行。它由 Encoder-Decoder 架构组成，衍生出 BERT（只用 Encoder）、GPT（只用 Decoder）等现代大模型的基石结构。

```text
Transformer 的核心构件：
1. Self-Attention —— 每个位置动态聚合全序列信息
2. Multi-Head —— 多个注意力子空间并行，捕捉不同关系
3. Positional Encoding —— 注入位置信息（注意力本身无序）
4. Encoder —— 双向上下文编码（BERT）
5. Decoder —— 自回归生成 + Causal Mask（GPT）
6. KV Cache —— 缓存历史键值，加速自回归推理
```

```python
import torch
import torch.nn as nn

# PyTorch 内置 Transformer Encoder 层
encoder_layer = nn.TransformerEncoderLayer(d_model=64, nhead=8, batch_first=True)
encoder = nn.TransformerEncoder(encoder_layer, num_layers=3)

x = torch.randn(2, 10, 64)          # [batch, seq, d_model]
print(encoder(x).shape)             # [2, 10, 64]
```

## Self-Attention

自注意力让序列中每个位置都作为「查询」，去和所有位置（包括自己）的「键」打分，再对「值」加权求和。它让每个 token 的输出都融入了全局上下文，且任意两位置的交互路径长度恒为 1，从根本上解决了 RNN 的长距离依赖问题。

```text
数学定义：
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V

Q = XW_Q, K = XW_K, V = XW_V（都来自同一个输入 X，故称「自」注意力）

除以 √d_k 的原因：点积方差随 d_k 增大，除以 √d_k 防止 softmax 梯度饱和。
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def self_attention(x, W_q, W_k, W_v):
    Q = x @ W_q; K = x @ W_k; V = x @ W_v
    d_k = Q.shape[-1]
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
    attn = F.softmax(scores, dim=-1)
    return attn @ V, attn

torch.manual_seed(0)
x = torch.randn(1, 5, 8)             # [batch, seq, d_model]
W_q = torch.randn(8, 8); W_k = torch.randn(8, 8); W_v = torch.randn(8, 8)
out, attn = self_attention(x, W_q, W_k, W_v)
print('输出:', out.shape, '注意力权重和:', attn.sum(-1))   # 权重和=1
```

## Multi-Head Attention

多头注意力把 Q/K/V 投影到 h 个低维子空间，分别做自注意力再拼接。它让模型在多个表示子空间里同时关注不同位置和不同关系（句法、语义、指代），是「单头注意力表达力不足」的解法。

```text
数学定义：
MultiHead(Q,K,V) = Concat(head_1, ..., head_h) · W_O
head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)

每头维度 d_k = d_model / h，总参数量与单头同量级但表达力更强。
```

```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_head):
        super().__init__()
        assert d_model % n_head == 0
        self.d_k = d_model // n_head
        self.n_head = n_head
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x, mask=None):
        N, S, _ = x.shape
        Q = self.W_q(x).view(N, S, self.n_head, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(N, S, self.n_head, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(N, S, self.n_head, self.d_k).transpose(1, 2)
        scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = torch.softmax(scores, dim=-1)
        out = (attn @ V).transpose(1, 2).contiguous().view(N, S, -1)
        return self.W_o(out)

mha = MultiHeadAttention(64, 8)
print(mha(torch.randn(2, 10, 64)).shape)    # [2, 10, 64]
```

## Q/K/V

Q（Query）、K（Key）、V（Value）是注意力的三个核心矩阵。它们来自「检索」的类比：查询 Q 去和所有键 K 算相似度（打分），用得到的权重对值 V 加权求和。自注意力里三者都来自同一输入；交叉注意力里 Q 来自解码器、K/V 来自编码器。

```text
三者含义：
1. Query —— 「我想找什么」，当前要聚合信息的位置
2. Key —— 「我能提供什么」，被查询的位置的索引特征
3. Value —— 「我实际有什么」，被加权求和的内容

流程：score = QKᵀ → softmax → 加权 V。
打分函数除点积外，还有加性（additive）、缩放点积（scaled dot-product）等。
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 交叉注意力：Q 来自一个序列，K/V 来自另一个序列
def cross_attention(q, kv, W_q, W_k, W_v):
    Q = q @ W_q
    K = kv @ W_k
    V = kv @ W_v
    d_k = Q.shape[-1]
    return F.softmax(Q @ K.transpose(-2, -1) / (d_k ** 0.5), dim=-1) @ V

q = torch.randn(1, 3, 8)      # 3 个查询（如解码步）
kv = torch.randn(1, 6, 8)     # 6 个键值（如编码输出）
W_q = torch.randn(8, 8); W_k = torch.randn(8, 8); W_v = torch.randn(8, 8)
print(cross_attention(q, kv, W_q, W_k, W_v).shape)   # [1, 3, 8]
```

## Positional Encoding

注意力本身对位置不敏感（打乱顺序结果不变），需要显式注入位置信息。原始 Transformer 用「正弦位置编码」——每个位置每个维度用不同频率的正弦/余弦函数编码，加到输入 embedding 上。它无需学习、能外推到更长序列。

```text
数学定义（正弦位置编码）：
PE(pos, 2i)   = sin(pos / 10000^{2i/d})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d})

性质：
1. 无需学习，长度可外推
2. 相对位置可由线性变换表示
3. 不同频率覆盖不同尺度的位置关系
```

```python
import torch
import math

def sinusoidal_pe(seq_len, d_model):
    pe = torch.zeros(seq_len, d_model)
    pos = torch.arange(seq_len).unsqueeze(1)          # [seq, 1]
    i = torch.arange(d_model).unsqueeze(0)            # [1, d]
    angle = pos / (10000 ** (2 * (i // 2) / d_model))
    pe[:, 0::2] = torch.sin(angle[:, 0::2])
    pe[:, 1::2] = torch.cos(angle[:, 1::2])
    return pe

pe = sinusoidal_pe(10, 16)
print(pe.shape)              # [10, 16]

# 不同维度的频率不同：低维度变化快、高维度变化慢
print('第0维变化快:', pe[:4, 0])
print('第8维变化慢:', pe[:4, 8])
```

## RoPE

RoPE（旋转位置编码）通过旋转矩阵把位置信息编码进 Q/K 的内积里：位置 m 和 n 的注意力分数只依赖它们的相对位置 (m-n)，而不是绝对位置。它天然编码相对位置、无需学习、可外推，是 LLaMA、Qwen 等主流大模型的标准位置编码。

```text
机制：
对 Q/K 的每个二维分量对，按位置 m 旋转角度 m·θ_i：
f(q, m) = q · e^{imθ}   （复数表示下的旋转）

内积性质：⟨f(q,m), f(k,n)⟩ = ⟨q, k⟩·e^{i(m-n)θ}，只依赖 m-n。

相比正弦 PE：RoPE 作用在 Q/K 上（而非加到输入），编码的是相对位置。
```

```python
import torch

def rotate_half(x):
    x1, x2 = x[..., : x.shape[-1] // 2], x[..., x.shape[-1] // 2:]
    return torch.cat((-x2, x1), dim=-1)

def apply_rope(q, k, pos):
    # 简化示意：按位置旋转 Q/K 的相邻维度对
    sin, cos = pos.sin(), pos.cos()
    q_rot = q * cos + rotate_half(q) * sin
    k_rot = k * cos + rotate_half(k) * sin
    return q_rot, k_rot

q = torch.randn(1, 4, 16)          # [batch, seq, d]
k = torch.randn(1, 4, 16)
pos = torch.arange(4).float()      # 位置 0..3
q_rot, k_rot = apply_rope(q, k, pos.unsqueeze(1))
print('RoPE 后形状:', q_rot.shape, k_rot.shape)

# 关键性质：内积只依赖相对位置
q0 = q[:, 0:1]; k2 = k[:, 2:3]
q0_rot, _ = apply_rope(q0, q0, torch.tensor([0.]))
_, k2_rot = apply_rope(k2, k2, torch.tensor([2.]))
print('相对位置编码不变性验证完成')
```

## ALiBi

ALiBi（Attention with Linear Biases）不做位置编码，而是直接在注意力分数上减去一个「与距离成正比」的惩罚项。位置越远、惩罚越大。它零额外参数、训练快，且训练短序列后能外推到长序列，是 RoPE 之外另一种外推方案。

```text
机制：
score = QKᵀ/√d_k - m·|i - j|    （m 是每头不同的斜率）

性质：
1. 无需学习位置嵌入，参数为零
2. 训练短、推理长（外推）表现好
3. 每头用不同 m，多头覆盖不同距离尺度
```

```python
import torch
import torch.nn.functional as F

def alibi_attention(q, k, v, num_heads):
    N, S, d = q.shape
    d_k = d // num_heads
    q = q.view(N, S, num_heads, d_k).transpose(1, 2)
    k = k.view(N, S, num_heads, d_k).transpose(1, 2)
    v = v.view(N, S, num_heads, d_k).transpose(1, 2)

    scores = q @ k.transpose(-2, -1) / (d_k ** 0.5)
    # 线性偏置：每头斜率不同
    slopes = torch.tensor([2 ** (-8 * (h + 1) / num_heads) for h in range(num_heads)])
    dist = torch.arange(S).unsqueeze(0) - torch.arange(S).unsqueeze(1)
    bias = slopes.view(1, num_heads, 1, 1) * dist.abs().float()
    scores = scores - bias
    attn = F.softmax(scores, dim=-1)
    return attn @ v

q = torch.randn(1, 6, 16)
print(alibi_attention(q, q, q, num_heads=4).shape)   # [1, 4, 6, 4]
```

## Encoder

Encoder（编码器）由多层「多头自注意力 + 前馈网络 + 残差 + LayerNorm」堆叠而成，负责把输入序列编码成上下文相关的表示。它是双向的——每个位置都能看到整个序列（无 causal mask），适合理解类任务，是 BERT 的主体。

```text
单层 Encoder 结构：
x → Multi-Head Self-Attention → Add&Norm → FFN → Add&Norm

Add&Norm：残差连接 + LayerNorm（Post-LN 传统，Pre-LN 现代更稳）
FFN：两个线性层 + 激活（中间维度通常 4×d_model），提供非线性变换
```

```python
import torch
import torch.nn as nn

class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_head, d_ff):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, n_head, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.GELU(), nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x):
        attn_out, _ = self.attn(x, x, x)        # 双向，无 mask
        x = self.norm1(x + attn_out)            # 残差 + LN
        x = self.norm2(x + self.ffn(x))
        return x

layer = EncoderLayer(64, 8, 256)
print(layer(torch.randn(2, 10, 64)).shape)      # [2, 10, 64]
```

## Decoder

Decoder（解码器）是自回归生成的主体：每个位置的输出只能依赖它之前的 token（causal mask 屏蔽未来），逐步生成序列。它由「掩码自注意力 + 交叉注意力 + 前馈网络」组成，是 GPT 等生成式模型的核心。

```text
单层 Decoder 结构：
x → Masked Self-Attention → Add&Norm → Cross Attention → Add&Norm → FFN → Add&Norm

与 Encoder 的区别：
1. 自注意力加了 causal mask（看不到未来）
2. 多一个 cross attention（Q 来自自己，K/V 来自 Encoder）
3. 自回归生成：每步只产出一个 token
```

```python
import torch
import torch.nn as nn

class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_head, d_ff):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, n_head, batch_first=True)
        self.cross_attn = nn.MultiheadAttention(d_model, n_head, batch_first=True)
        self.ffn = nn.Sequential(nn.Linear(d_model, d_ff), nn.GELU(), nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)

    def forward(self, x, enc_out, causal_mask):
        self_out, _ = self.self_attn(x, x, x, attn_mask=causal_mask)
        x = self.norm1(x + self_out)
        cross_out, _ = self.cross_attn(x, enc_out, enc_out)
        x = self.norm2(x + cross_out)
        x = self.norm3(x + self.ffn(x))
        return x

layer = DecoderLayer(64, 8, 256)
causal = torch.triu(torch.full((10, 10), float('-inf')), diagonal=1)  # 上三角屏蔽
print(layer(torch.randn(2, 10, 64), torch.randn(2, 8, 64), causal).shape)
```

## Causal Mask

Causal Mask（因果掩码）是一个上三角掩码矩阵，保证位置 i 只能看到位置 ≤ i 的信息，看不到未来。它是自回归生成和因果语言模型的必要条件——训练时并行计算所有位置，用 mask 屏蔽未来位置，避免信息泄露。

```text
构造：
mask[i, j] = 0  if j > i（屏蔽）
mask[i, j] = 1  if j <= i（允许）

实现：注意力分数矩阵的上三角位置设为 -inf，softmax 后权重为 0。
```

```python
import torch
import torch.nn.functional as F

def causal_mask(seq_len):
    # 返回上三角为 -inf 的掩码
    return torch.triu(torch.full((seq_len, seq_len), float('-inf')), diagonal=1)

mask = causal_mask(5)
print(mask)                          # 上三角是 -inf

# 应用到注意力分数
scores = torch.randn(1, 5, 5)
masked = scores + mask               # 未来位置变 -inf
attn = F.softmax(masked, dim=-1)
print('每行未来位置权重=0:', attn[0, 0, 1:].sum().item())
```

## Cross Attention

交叉注意力是「两个不同序列之间的注意力」：Query 来自解码器当前表示，Key/Value 来自编码器输出。它让解码器在生成每个 token 时去「查阅」源序列的相关位置，是 Encoder-Decoder 架构（翻译、摘要）里解码器对齐源语言的关键。

```text
与自注意力的区别：
1. 自注意力：Q = K = V = 同一序列（同源）
2. 交叉注意力：Q 来自 decoder，K/V 来自 encoder（异源）

作用：解码器每步动态检索源序列信息，替代 Seq2Seq 的固定上下文向量。
```

```python
import torch
import torch.nn as nn

cross_attn = nn.MultiheadAttention(embed_dim=64, num_heads=8, batch_first=True)

enc_out = torch.randn(2, 8, 64)      # 编码器输出（K/V）
dec_hidden = torch.randn(2, 6, 64)   # 解码器状态（Q）

out, attn_weights = cross_attn(dec_hidden, enc_out, enc_out)
print('输出:', out.shape)             # [2, 6, 64]
print('注意力权重:', attn_weights.shape)   # [2, 6, 8]，解码每步对编码位置的权重
```

## KV Cache

KV Cache 是自回归推理的加速技术：生成第 t 个 token 时，前 t-1 步的 K/V 已经算过且不会变，把它们缓存下来，每步只算新 token 的 Q/K/V，避免重复计算。它把每步推理的复杂度从 O(n²) 降到 O(n)，是大模型推理提速的基石。

```text
机制：
1. 生成第 1 个 token：算全部 K/V 并缓存
2. 生成第 t 个 token：只算新 token 的 Q/K/V，与缓存的 K/V 拼接
3. 内存随序列长度线性增长（缓存的 K/V 越来越大）

效果：避免每步重算历史 K/V，推理时间从平方降到线性。
```

```python
import torch

class KVCache:
    def __init__(self):
        self.k = self.v = None

    def update(self, new_k, new_v):
        self.k = new_k if self.k is None else torch.cat([self.k, new_k], dim=1)
        self.v = new_v if self.v is None else torch.cat([self.v, new_v], dim=1)

def step_attention(q, k, v, cache):
    cache.update(k, v)                       # 缓存新 token 的 K/V
    scores = q @ cache.k.transpose(-2, -1)   # 与所有历史 K 打分
    return scores @ cache.v

cache = KVCache()
q = torch.randn(1, 1, 8)
for _ in range(3):
    k = torch.randn(1, 1, 8)
    v = torch.randn(1, 1, 8)
    out = step_attention(q, k, v, cache)
    print('缓存长度:', cache.k.shape[1])      # 1 → 2 → 3 线性增长
```

## 应用场景实战

### 场景一：手写 mini GPT（因果语言模型）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MiniGPT(nn.Module):
    def __init__(self, vocab, d_model, n_head, n_layer, block_size):
        super().__init__()
        self.tok_emb = nn.Embedding(vocab, d_model)
        self.pos_emb = nn.Embedding(block_size, d_model)
        self.blocks = nn.ModuleList([
            nn.TransformerEncoderLayer(d_model, n_head, dim_feedforward=4*d_model,
                                       batch_first=True) for _ in range(n_layer)])
        self.ln = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab)
        self.block_size = block_size

    def forward(self, idx):
        N, T = idx.shape
        pos = torch.arange(T, device=idx.device)
        x = self.tok_emb(idx) + self.pos_emb(pos)
        causal = torch.triu(torch.full((T, T), float('-inf'), device=idx.device), diagonal=1)
        for blk in self.blocks:
            x = blk(x, src_mask=causal)         # causal mask 屏蔽未来
        return self.head(self.ln(x))

model = MiniGPT(vocab=1000, d_model=64, n_head=4, n_layer=2, block_size=16)
x = torch.randint(0, 1000, (4, 16))
logits = model(x)
loss = F.cross_entropy(logits.view(-1, 1000), x.view(-1))
print(f'语言模型 loss={loss.item():.4f}')
```

### 场景二：Transformer 做序列分类（Encoder only）

```python
import torch
import torch.nn as nn

class TransformerClassifier(nn.Module):
    def __init__(self, vocab, d_model, n_head, n_layer, num_class):
        super().__init__()
        self.emb = nn.Embedding(vocab, d_model)
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model, n_head, batch_first=True), n_layer)
        self.fc = nn.Linear(d_model, num_class)

    def forward(self, x):
        out = self.encoder(self.emb(x))
        return self.fc(out[:, 0])              # 取 [CLS] 位置

model = TransformerClassifier(vocab=5000, d_model=64, n_head=4, n_layer=2, num_class=3)
x = torch.randint(0, 5000, (4, 20))
print(model(x).shape)                          # [4, 3]
```

## 最佳实践与踩坑记录

### 最佳实践

1. 训练用 Pre-LN（残差前归一化）比 Post-LN 稳定，深网络和大模型默认 Pre-LN
2. 位置编码选 RoPE（主流 LLM）或 ALiBi（外推场景），固定正弦 PE 主要在教学/兼容
3. 因果模型训练时并行算全序列 + causal mask，推理时开 KV Cache 提速
4. 注意力 softmax 前加 mask（-inf），别用 0 或负数小值（softmax 后仍会有权重）
5. 大模型注意力用 flash attention 等实现，省显存且快
6. 自回归生成推理时用 KV Cache，长文本时注意缓存内存线性增长

### 踩坑记录

```text
坑 1：causal mask 方向搞反，训练时泄露未来信息
结论：验证 loss 低但生成完全不可用，纯靠「作弊」。
原因：mask 屏蔽了历史、放开了未来，模型看到答案。
解法：上三角设为 -inf（j>i 屏蔽），并可视化 mask 核对。

坑 2：忘记除以 √d_k，大维度下 softmax 梯度饱和
结论：训练不稳，注意力权重退化成 one-hot。
原因：点积方差随 d_k 线性增长，softmax 输入过大进入饱和区。
解法：scores = QKᵀ / sqrt(d_k)，这是缩放点积注意力的关键。

坑 3：RoPE 位置编码没对 Q 和 K 都做旋转
结论：相对位置信息丢失，长序列效果差。
原因：RoPE 的核心是让 Q/K 内积只依赖相对位置，只旋一边破坏了这个性质。
解法：Q 和 K 都按各自位置旋转，再算内积。

坑 4：推理时不用 KV Cache，长序列生成极慢
结论：生成几百 token 就要几十秒，不可用。
原因：每步都重算全部历史 K/V，复杂度 O(n²)。
解法：缓存历史 K/V，每步只算新 token，复杂度降为 O(n)。

坑 5：训练时把 batch_first 与 PyTorch 默认的 seq-first 混用
结论：多头注意力的 reshape 维度错乱，报错或结果不对。
原因：PyTorch 老 API 默认 [seq, batch]，设 batch_first=True 才是 [batch, seq]。
解法：统一 batch_first=True，reshape 时按 [N, S, H, d_k] 顺序操作。
```
