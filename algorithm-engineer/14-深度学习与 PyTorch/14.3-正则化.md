## 概述

正则化是一类「防止模型死记硬背训练集」的技术：通过在训练中注入噪声、约束参数规模或限制训练轮数，降低模型的过拟合倾向、提升泛化能力。注意区分两个词——Dropout/Weight Decay/Early Stopping 是「抑制过拟合」的正则化，BatchNorm/LayerNorm/GroupNorm 是「稳定训练」的归一化，两者常常被一起讨论。

```text
正则化/归一化的核心手段：
1. Dropout —— 随机失活神经元，等价于训练大量子网络的集成
2. Weight Decay —— L2 惩罚收缩权重，限制模型容量
3. Early Stopping —— 验证集不再变好就停，防止过度拟合训练集
4. BatchNorm/LayerNorm/GroupNorm —— 归一化中间激活，稳定分布、加速收敛
```

```python
import torch
import torch.nn as nn

# 一个同时用上多种正则化手段的模块
class RegularizedBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc = nn.Linear(dim, dim)
        self.norm = nn.LayerNorm(dim)
        self.dropout = nn.Dropout(0.1)

    def forward(self, x):
        return self.dropout(nn.functional.relu(self.norm(self.fc(x))))

blk = RegularizedBlock(64)
print(blk(torch.randn(4, 64)).shape)   # torch.Size([4, 64])
```

## Dropout

Dropout 在训练时以概率 p 随机把神经元输出置 0，推理时关闭。它强迫网络不依赖任何单个神经元，等价于隐式训练指数级的子网络集成，是防止过拟合最常用的手段之一。

```text
机制：
训练：每个神经元以概率 p 失活（输出置 0），其余按 1/(1-p) 缩放
推理：Dropout 关闭，直接用全网络

为什么有效：
1. 打破神经元间的共适应，特征不能依赖特定搭档
2. 等价于 2^n 个子网络共享权重的集成
3. 相当于对激活注入乘性噪声
```

```python
import torch
import torch.nn as nn

dropout = nn.Dropout(p=0.5)
x = torch.ones(1, 10)

dropout.train()
print('train:', dropout(x))           # 一半元素为 0，其余为 2（1/(1-0.5)）

dropout.eval()
print('eval: ', dropout(x))           # 全 1，推理时关闭

# 手写实现等价性
mask = (torch.rand(1, 10) > 0.5).float() / (1 - 0.5)
print('manual:', x * mask)
```

## BatchNorm

BatchNorm 对每个特征通道，在 batch 维度上归一化（减均值除标准差）再做仿射变换。它让每层输入分布稳定，允许更大学习率、加速收敛，并有一定正则效果。缺点是依赖 batch 大小，小 batch 时统计量不稳定。

```text
数学定义：
x̂ = (x - μ_B) / √(σ_B² + ε)     # μ_B、σ_B 是 batch 内的通道均值/方差
y = γ·x̂ + β                       # γ、β 是可学习仿射参数

训练用 batch 统计量，推理用训练期累积的全局滑动平均（running_mean/var）。

问题：batch 太小（如 1~2）时统计量噪声大；RNN/Transformer 里变长序列难用。
```

```python
import torch
import torch.nn as nn

bn = nn.BatchNorm1d(4)
x = torch.randn(8, 4)                # batch=8, 通道=4

bn.train()
y = bn(x)
# 归一化后每通道 batch 维度均值≈0、方差≈1
print(y.mean(dim=0).round(decimals=5))   # tensor([0.,0.,0.,0.])
print(y.var(dim=0, unbiased=False).round(decimals=5))  # tensor([1.,1.,1.,1.])

print('running_mean:', bn.running_mean)   # 推理用的滑动统计量
```

## LayerNorm

LayerNorm 对单个样本的所有特征维度归一化，不依赖 batch，因此每个样本独立计算统计量。它是 Transformer 的标准归一化，特别适合变长序列和小 batch 场景。

```text
数学定义：
对单个样本 x ∈ R^d：
x̂ = (x - μ) / √(σ² + ε)，其中 μ、σ 是 x 各维度的均值/标准差
y = γ·x̂ + β

与 BatchNorm 的区别：
- BN：在 batch 维度归一化每个特征（依赖 batch，适合 CNN）
- LN：在特征维度归一化每个样本（不依赖 batch，适合序列/Transformer）
```

```python
import torch
import torch.nn as nn

ln = nn.LayerNorm(4)
x = torch.randn(8, 4)                # 8 个样本，每样本 4 维

y = ln(x)
# 每个样本（每行）归一化后均值 0、方差 1
print(y.mean(dim=1).round(decimals=5))       # tensor([0.,0.,...,0.])
print(y.var(dim=1, unbiased=False).round(decimals=5))  # tensor([1.,1.,...,1.])

# LayerNorm 对 batch 大小不敏感：batch=1 也稳定
print(ln(torch.randn(1, 4)))
```

## GroupNorm

GroupNorm 是 BatchNorm 和 LayerNorm 的折中：把通道分成若干组，每组内部做归一化。它不依赖 batch 大小，在检测/分割等「batch 很小」的视觉任务里表现稳定，是 Group Normalization 论文提出时的直接动机。

```text
机制：
把 C 个通道分成 G 组，每组 C/G 个通道，在 (N, group) 维度上归一化。

参数：
- num_groups —— 分组数，G=1 等价 LayerNorm，G=C 等价 InstanceNorm

适用：batch 小（检测/分割训练常 batch=1~2）时比 BatchNorm 更稳。
```

```python
import torch
import torch.nn as nn

x = torch.randn(2, 8, 4, 4)          # N=2, C=8, H=4, W=4

gn = nn.GroupNorm(num_groups=4, num_channels=8)   # 4 组，每组 2 通道
y = gn(x)

# 每组内归一化：组内均值 0
group = y[:, :2].reshape(2, -1)      # 第一组（通道 0-1）
print(group.mean().round(decimals=5))       # ≈ 0

# batch=1 也稳定（对比 BatchNorm）
gn_small = nn.GroupNorm(4, 8)
print(gn_small(torch.randn(1, 8, 4, 4)).shape)
```

## Weight Decay

Weight Decay 在损失函数里加 L2 惩罚项，让权重在每次更新时额外收缩一个比例，等价于「参数越小越好」的先验。它抑制权重过大、限制模型复杂度，是比 Dropout 更底层的正则化。注意在 Adam 里应解耦实现（AdamW），否则与自适应学习率耦合会失效。

```text
数学定义：
L_total = L + (λ/2)·‖w‖²

对 SGD，梯度项多出 λ·w，更新变为：
w ← w - η·(∇L + λ·w) = (1 - ηλ)·w - η·∇L

对 Adam：直接加 L2 项会让惩罚被自适应学习率缩放，需用 AdamW 解耦。
```

```python
import torch
import torch.nn as nn

model = nn.Linear(10, 1)

# SGD + weight decay（L2 正则）
opt_sgd = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-2)

# AdamW 解耦 weight decay
opt_adamw = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

# 手动验证 weight decay 效果：比较有无 wd 时权重范数
m1 = nn.Linear(10, 1); m2 = nn.Linear(10, 1)
m2.load_state_dict({k: v.clone() for k, v in m1.state_dict().items()})
o1 = torch.optim.SGD(m1.parameters(), lr=0.1, weight_decay=0.0)
o2 = torch.optim.SGD(m2.parameters(), lr=0.1, weight_decay=0.5)
x = torch.randn(4, 10); y = torch.randn(4, 1)
for _ in range(100):
    l1 = nn.functional.mse_loss(m1(x), y); o1.zero_grad(); l1.backward(); o1.step()
    l2 = nn.functional.mse_loss(m2(x), y); o2.zero_grad(); l2.backward(); o2.step()
print(f'无 wd 权重范数: {m1.weight.norm():.3f}')
print(f'有 wd 权重范数: {m2.weight.norm():.3f}')   # 更小，被收缩
```

## Early Stopping

Early Stopping 在训练中监控验证集指标，一旦验证指标连续若干轮不再改善就停止训练，并回滚到最佳权重。它用「限制训练时间」来防止过拟合，是最简单也最有效的正则化手段之一。

```text
机制：
1. 每 epoch 评估验证集 loss/指标
2. 若连续 patience 轮无改善，停止训练
3. 恢复历史最优 checkpoint

为什么有效：训练后期模型开始记忆噪声，验证 loss 上升（过拟合），
此时停下并回滚到拐点附近能保留泛化最好的参数。
```

```python
import torch
import torch.nn as nn

class EarlyStopping:
    def __init__(self, patience=3, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.best_score = float('inf')
        self.counter = 0

    def __call__(self, val_loss):
        if val_loss < self.best_score - self.min_delta:
            self.best_score = val_loss
            self.counter = 0
            return False                  # 继续训练
        self.counter += 1
        return self.counter >= self.patience   # True = 停止

stopper = EarlyStopping(patience=2)
for epoch, val_loss in enumerate([0.5, 0.4, 0.35, 0.36, 0.37, 0.38]):
    if stopper(val_loss):
        print(f'epoch {epoch} 早停，best={stopper.best_score:.3f}')
        break
```

## 应用场景实战

### 场景一：Dropout 与 Weight Decay 联合对抗过拟合

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
# 小样本高维：天然容易过拟合
x = torch.randn(200, 50)
y = (x[:, 0] * x[:, 1] > 0).float().unsqueeze(1)

def build(with_reg):
    layers = [nn.Linear(50, 128), nn.ReLU(), nn.Linear(128, 128), nn.ReLU()]
    if with_reg:
        layers.insert(2, nn.Dropout(0.3))
    layers.append(nn.Linear(128, 1))
    return nn.Sequential(*layers)

for name, reg in [('无正则', False), ('有正则', True)]:
    net = build(reg)
    opt = torch.optim.AdamW(net.parameters(), lr=1e-3, weight_decay=1e-2 if reg else 0)
    for _ in range(500):
        loss = nn.functional.binary_cross_entropy_with_logits(net(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
    # 训练集上的 loss：有正则应略高（不过度拟合）
    print(f'{name}: train_loss={loss.item():.4f}')
```

### 场景二：BatchNorm vs LayerNorm 在小 batch 下的稳定性

```python
import torch
import torch.nn as nn

# 极端小 batch：batch=1 时 BatchNorm 统计量退化为该样本本身
x = torch.randn(1, 4)
bn = nn.BatchNorm1d(4)
ln = nn.LayerNorm(4)

bn.eval(); ln.eval()
with torch.no_grad():
    # eval 模式下 BN 用 running_mean/var（初始 0/1），LN 用样本自身统计量
    print('BN(eval, batch=1):', bn(x))
    print('LN(eval, batch=1):', ln(x))

# 小 batch 训练时 BN 统计量噪声大，建议用 GroupNorm/LayerNorm 替代
```

## 最佳实践与踩坑记录

### 最佳实践

1. CNN 用 BatchNorm，Transformer/序列用 LayerNorm，小 batch 视觉任务（检测/分割）用 GroupNorm
2. Dropout 概率一般 0.1~0.5，大的网络/过拟合严重时调高，小网络可不加
3. 全连接层 Dropout 放在激活之后、下一层之前；现代 Transformer 常把 Dropout 加在 attention 和残差连接上
4. Weight Decay 配 Adam 用 AdamW（解耦），配 SGD 直接 weight_decay 即可
5. 归一化层自带偏置，其前的 Linear 层可以关 bias，减少冗余参数
6. Early Stopping 的 patience 要留够（数据噪声大时调大），别设太小导致欠拟合

### 踩坑记录

```text
坑 1：推理时忘记关 Dropout
结论：每次推理结果都不同，输出随机波动。
原因：Dropout 在 train 模式随机失活，eval 模式才关闭。
解法：推理前 model.eval()，并用 torch.no_grad() 包裹。

坑 2：小 batch 训练用 BatchNorm 导致训练不稳定
结论：batch=1~2 时统计量噪声极大，收敛差甚至发散。
原因：BN 的均值和方差来自 batch，batch 太小估计不准。
解法：小 batch 场景换 GroupNorm 或 LayerNorm，或增大 batch。

坑 3：Adam 里直接用 weight_decay 参数没起到正则效果
结论：加了 weight_decay 但权重几乎没被收缩。
原因：Adam 的 L2 惩罚被自适应学习率缩放，正则会失效。
解法：改用 AdamW（解耦 weight decay），或自己手动 w = w*(1-lr*λ) 收缩。

坑 4：BN 的 train/eval 切换不一致导致精度掉点
结论：训练 acc 很高，推理 acc 明显下降。
原因：训练用 batch 统计量，推理用 running_mean/var，两者若没对齐（如没训够轮数）会漂移。
解法：确保足够多 epoch 让 running 统计量收敛，推理前 model.eval()。

坑 5：Early Stopping 的 patience 设太小时过早停止
结论：模型还欠拟合就被停了，效果差。
原因：验证 loss 天然有波动，耐心太短会被噪声误判为「不再改善」。
解法：patience 设到 5~20，看验证曲线波动幅度定，必要时配合模型保存最优权重。
```
