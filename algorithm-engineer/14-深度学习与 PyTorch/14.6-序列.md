## 概述

序列模型处理「顺序有关」的数据：文本、语音、时间序列等。核心挑战是让模型记住历史信息并建模长距离依赖。RNN 用循环结构共享参数处理变长序列，LSTM/GRU 用门控解决长距离依赖，Seq2Seq 加 Attention 把序列映射到序列，成为机器翻译和后来 Transformer 的前身。

```text
序列模型的演进脉络：
1. RNN —— 循环共享权重，天然处理变长序列，但长依赖会梯度消失
2. LSTM/GRU —— 门控机制选择性记忆，缓解长距离依赖
3. Seq2Seq —— 编码器-解码器架构，序列到序列
4. Attention —— 动态加权历史信息，突破 RNN 的瓶颈
5. Transformer —— 纯注意力，见 [[14.7-Transformer]]
```

```python
import torch
import torch.nn as nn

# PyTorch 内置 RNN/LSTM/GRU
for name, cls in [('RNN', nn.RNN), ('LSTM', nn.LSTM), ('GRU', nn.GRU)]:
    layer = cls(input_size=8, hidden_size=16, batch_first=True)
    out, h = layer(torch.randn(4, 10, 8))     # [batch, seq, input]
    print(f'{name}: out {out.shape}, h {h.shape if not isinstance(h, tuple) else h[0].shape}')
```

## RNN

RNN（循环神经网络）把同一个参数块在每个时间步重复使用，当前隐藏状态由「上一时刻隐藏状态 + 当前输入」共同决定。它能处理任意长度序列，但标准 RNN 在长序列上反向传播时梯度会指数衰减（梯度消失），难以捕捉长距离依赖。

```text
数学定义：
h_t = tanh(W_h·h_{t-1} + W_x·x_t + b)

参数在时间步间共享：W_h、W_x、b 对所有 t 相同。
输出：y_t = W_o·h_t（或取最后一步 h_T）

梯度问题：反向传播跨时间步，tanh 导数 <1 连乘 → 梯度指数衰减。
```

```python
import torch
import torch.nn as nn

rnn = nn.RNN(input_size=4, hidden_size=8, batch_first=True)
x = torch.randn(2, 5, 4)              # batch=2, seq=5, input=4

out, h = rnn(x)
print('out:', out.shape)              # [2,5,8]  每个时间步的输出
print('h:  ', h.shape)                # [1,2,8]  最后一步的隐藏状态

# 手写单步 RNN 验证
x0 = x[:, 0, :].unsqueeze(0)          # 第一步输入
h0 = torch.zeros(1, 2, 8)
manual_h = torch.tanh(h0 @ rnn.weight_hh_l0.T + x0 @ rnn.weight_ih_l0.T + rnn.bias_hh_l0 + rnn.bias_ih_l0)
print('手写与内置一致:', torch.allclose(h[0], manual_h, atol=1e-5))
```

## LSTM

LSTM（长短期记忆网络）引入「细胞状态」和三个门（遗忘门、输入门、输出门），用门控决定信息的保留、写入和输出。细胞状态上的加性更新让梯度能跨很多时间步直线流动，有效缓解 RNN 的梯度消失，是处理长序列的主力 RNN 变体。

```text
数学定义：
f_t = σ(W_f·[h_{t-1}, x_t] + b_f)       # 遗忘门
i_t = σ(W_i·[h_{t-1}, x_t] + b_i)       # 输入门
o_t = σ(W_o·[h_{t-1}, x_t] + b_o)       # 输出门
c̃_t = tanh(W_c·[h_{t-1}, x_t] + b_c)    # 候选细胞状态
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t         # 细胞状态（加性更新）
h_t = o_t ⊙ tanh(c_t)                   # 隐藏状态

关键：c_t 的更新是「加」而非「乘」，梯度不衰减，解决长依赖。
```

```python
import torch
import torch.nn as nn

lstm = nn.LSTM(input_size=4, hidden_size=8, num_layers=2, batch_first=True)
x = torch.randn(3, 6, 4)

out, (h, c) = lstm(x)
print('out:', out.shape)              # [3,6,8]
print('h/c:', h.shape, c.shape)       # [2,3,8]  两层，最后一步状态

# 手写单步 LSTM 门控计算
W_ih = lstm.weight_ih_l0              # [4*8, 4]
W_hh = lstm.weight_hh_l0              # [4*8, 8]
b = lstm.bias_ih_l0 + lstm.bias_hh_l0
x0 = x[:, 0, :]                       # [3,4]
h0 = torch.zeros(1, 3, 8); c0 = torch.zeros(1, 3, 8)

gates = (x0 @ W_ih.T + h0[0] @ W_hh.T + b)   # [3, 32]
i, f, g, o = gates.chunk(4, dim=1)           # 拆成 4 个门
i, f, o = torch.sigmoid(i), torch.sigmoid(f), torch.sigmoid(o)
g = torch.tanh(g)
c1 = f * c0[0] + i * g                        # 细胞状态更新
h1 = o * torch.tanh(c1)
print('门控手写通过:', i.shape, f.shape, o.shape, g.shape)
```

## GRU

GRU（门控循环单元）是 LSTM 的简化版：把遗忘门和输入门合并成一个「更新门」，去掉独立的细胞状态，只保留隐藏状态。参数更少、训练更快，在很多任务上效果接近 LSTM，是小模型的首选。

```text
数学定义：
z_t = σ(W_z·[h_{t-1}, x_t])          # 更新门（决定保留多少旧状态）
r_t = σ(W_r·[h_{t-1}, x_t])          # 重置门（决定忽略多少旧状态）
h̃_t = tanh(W_h·[r_t ⊙ h_{t-1}, x_t]) # 候选状态
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

只有两个门 + 一个状态，参数约为 LSTM 的 3/4。
```

```python
import torch
import torch.nn as nn

gru = nn.GRU(input_size=4, hidden_size=8, batch_first=True)
x = torch.randn(3, 6, 4)

out, h = gru(x)
print('out:', out.shape)              # [3,6,8]
print('h:  ', h.shape)                # [1,3,8]  GRU 无细胞状态

# 参数对比：LSTM vs GRU
lstm = nn.LSTM(4, 8)
gru = nn.GRU(4, 8)
print('LSTM 参数:', sum(p.numel() for p in lstm.parameters()))
print('GRU  参数:', sum(p.numel() for p in gru.parameters()))
```

## Seq2Seq

Seq2Seq 用「编码器-解码器」架构做序列到序列的映射：编码器把输入序列压成一个上下文向量（通常取最后隐藏状态），解码器从这个向量逐词生成输出序列。它奠定了机器翻译、摘要、对话生成的基础，但上下文向量是固定长度的信息瓶颈。

```text
架构：
编码器：RNN 读入输入序列 → 最后隐藏状态 h_T 作为上下文向量 c
解码器：以 c 为初始状态，逐词生成输出 y_1, y_2, ..., y_m

瓶颈：所有输入信息压进一个固定维度向量，长序列信息丢失。
```

```python
import torch
import torch.nn as nn

class Seq2Seq(nn.Module):
    def __init__(self, enc_vocab, dec_vocab, emb_dim, hidden):
        super().__init__()
        self.enc_emb = nn.Embedding(enc_vocab, emb_dim)
        self.dec_emb = nn.Embedding(dec_vocab, emb_dim)
        self.encoder = nn.GRU(emb_dim, hidden, batch_first=True)
        self.decoder = nn.GRU(emb_dim, hidden, batch_first=True)
        self.out = nn.Linear(hidden, dec_vocab)

    def forward(self, src, tgt):
        # 编码：取最后隐藏状态
        _, h = self.encoder(self.enc_emb(src))      # h=[1,N,hidden]
        # 解码：用 h 作初始状态，逐步生成
        dec_out, _ = self.decoder(self.dec_emb(tgt), h)
        return self.out(dec_out)                    # [N, tgt_len, vocab]

model = Seq2Seq(enc_vocab=100, dec_vocab=100, emb_dim=16, hidden=32)
src = torch.randint(0, 100, (2, 5))     # 输入序列
tgt = torch.randint(0, 100, (2, 4))     # 目标序列
print(model(src, tgt).shape)            # [2, 4, 100]
```

## Teacher Forcing

Teacher Forcing 在训练解码器时，用「真实的上一词」而不是「模型预测的上一词」作为下一步的输入。它让训练稳定、收敛快，但会造成「训练-推理不一致」（exposure bias）——推理时模型必须靠自己的预测续写，一步错可能步步错。

```text
两种模式：
1. Teacher Forcing —— 输入 y_{t-1}（真实标签），训练快但暴露偏差
2. Free Running —— 输入 ŷ_{t-1}（模型预测），与推理一致但训练难

折中：scheduled sampling，训练中随机混合真实和预测输入，概率随训练降低。
```

```python
import torch
import torch.nn as nn

# 演示 Teacher Forcing：解码器输入是真实标签
class Decoder(nn.Module):
    def __init__(self, vocab, emb, hidden):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb)
        self.gru = nn.GRU(emb, hidden, batch_first=True)
        self.out = nn.Linear(hidden, vocab)

    def forward(self, tgt_input, h):
        # tgt_input 是真实目标序列（右移一位），即 teacher forcing
        out, h = self.gru(self.emb(tgt_input), h)
        return self.out(out)

dec = Decoder(vocab=50, emb=16, hidden=32)
tgt = torch.randint(0, 50, (2, 4))            # 目标词
tgt_input = torch.cat([torch.zeros(2, 1, dtype=torch.long), tgt[:, :-1]], dim=1)  # <sos> + 前词
print(dec(tgt_input, torch.zeros(1, 2, 32)).shape)   # [2, 4, 50]
```

## Attention

Attention 让解码器在生成每个词时，动态地对编码器的所有隐藏状态加权求和，而不是只用固定的上下文向量。它解决了 Seq2Seq 的信息瓶颈，是 Transformer 的核心前身。注意力机制本质是「查询（query）在键值（key/value）上的加权检索」。

```text
Bahdanau 注意力（加性注意力）：
e_t = vᵀ · tanh(W_a·h_dec + U_a·h_enc)    # 打分
α = softmax(e_t)                          # 权重归一化
c_t = Σ α_i · h_enc_i                     # 上下文向量（加权和）

效果：解码每步都能「看」到输入的不同位置，长序列不再丢信息。
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class BahdanauAttention(nn.Module):
    def __init__(self, hidden):
        super().__init__()
        self.W = nn.Linear(hidden, hidden, bias=False)
        self.U = nn.Linear(hidden, hidden, bias=False)
        self.v = nn.Linear(hidden, 1, bias=False)

    def forward(self, dec_hidden, enc_outputs):
        # dec_hidden: [N, hidden]，enc_outputs: [N, seq, hidden]
        score = self.v(torch.tanh(self.W(dec_hidden).unsqueeze(1) + self.U(enc_outputs)))
        alpha = F.softmax(score, dim=1)              # [N, seq, 1]
        context = (enc_outputs * alpha).sum(dim=1)   # [N, hidden]
        return context, alpha.squeeze(-1)

enc_outputs = torch.randn(2, 7, 32)
dec_hidden = torch.randn(2, 32)
attn = BahdanauAttention(32)
context, alpha = attn(dec_hidden, enc_outputs)
print('context:', context.shape, '权重和:', alpha.sum(dim=1))   # 权重和=1
```

## 应用场景实战

### 场景一：文本情感分类（LSTM）

```python
import torch
import torch.nn as nn

class SentimentLSTM(nn.Module):
    def __init__(self, vocab, emb, hidden, num_class):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb)
        self.lstm = nn.LSTM(emb, hidden, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(hidden * 2, num_class)

    def forward(self, x):
        emb = self.emb(x)
        out, (h, _) = self.lstm(emb)
        # 取双向的最后一步拼接
        feat = torch.cat([h[-2], h[-1]], dim=1)
        return self.fc(feat)

model = SentimentLSTM(vocab=5000, emb=128, hidden=64, num_class=2)
x = torch.randint(0, 5000, (4, 20))       # 4 句话，各 20 词
print(model(x).shape)                     # [4, 2]
```

### 场景二：字符级语言模型（GRU 生成）

```python
import torch
import torch.nn as nn

# 用 GRU 预测下一个字符
vocab_size, emb, hidden = 64, 32, 64
model = nn.Sequential(
    nn.Embedding(vocab_size, emb),
    nn.GRU(emb, hidden, batch_first=True),
)
head = nn.Linear(hidden, vocab_size)

x = torch.randint(0, vocab_size, (2, 10))
out, _ = model(x)
logits = head(out)                        # 每步预测下一个 token
loss = nn.CrossEntropyLoss()(logits.reshape(-1, vocab_size),
                             torch.randint(0, vocab_size, (2, 10)).reshape(-1))
print(f'字符级语言模型 loss={loss.item():.4f}')
```

## 最佳实践与踩坑记录

### 最佳实践

1. 序列分类用 LSTM/GRU 取最后（或双向拼接）隐藏状态接分类头
2. 处理长序列优先双向 LSTM + Attention，而不是单靠加深 RNN
3. 训练时用 Teacher Forcing，推理时用贪心/束搜索（beam search）解码
4. RNN 训练必开梯度裁剪（gradient clipping），防止长序列反传梯度爆炸
5. 变长序列用 pack_padded_sequence 掩掉 padding，避免无效计算
6. 能用 GRU 就用 GRU（参数少、快），需要更强长依赖再上 LSTM

### 踩坑记录

```text
坑 1：忘记梯度裁剪，长序列训练 loss 变 NaN
结论：训练几步后 loss 爆炸为 inf/NaN。
原因：RNN 跨时间步反传，tanh/sigmoid 导数连乘导致梯度爆炸。
解法：torch.nn.utils.clip_grad_norm_(params, 1.0)，阈值一般 0.5~5。

坑 2：batch_first 参数设错导致维度对不上
结论：报 shape mismatch 错误。
原因：PyTorch 默认 [seq, batch, feat]，设 batch_first=True 才是 [batch, seq, feat]。
解法：统一用 batch_first=True，或始终核对输入输出 shape。

坑 3：Teacher Forcing 训练很好但推理效果差
结论：训练 loss 低，生成文本却跑飞。
原因：暴露偏差——推理时用预测词续写，与训练分布不一致。
解法：用 scheduled sampling 逐步降低 teacher forcing 比例，或推理用束搜索。

坑 4：padding 序列没 mask，模型学到 padding 位置的噪声
结论：效果差，尤其长文本和变长序列场景。
原因：RNN 把 padding 的 0 也当真输入处理。
解法：用 pack_padded_sequence / pad_packed_sequence，或注意力里加 mask。

坑 5：把最后一步输出当上下文却忘了取隐藏状态
结论：用 out[:, -1, :] 和 h 混淆，结果不稳定。
原因：out 是每步输出，h 是隐藏状态，二者含义不同。
解法：分类任务取 h（或双向拼接），需要每步输出才用 out。
```
