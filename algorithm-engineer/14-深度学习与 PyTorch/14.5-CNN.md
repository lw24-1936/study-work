## 概述

CNN（卷积神经网络）用卷积核在图像上滑动提取局部特征，是计算机视觉的基石。它的两大核心思想是「局部连接」（每个输出只看一个小窗口）和「权重共享」（同一个卷积核扫遍全图），这两点让 CNN 参数量远小于全连接、且天然具备平移不变性。ResNet 之后的发展主线是「如何让网络更深、更宽、更高效」。

```text
CNN 的核心构件：
1. 卷积 —— 滑动窗口 + 权重共享提取局部特征
2. 池化 —— 下采样降低分辨率、增大感受野
3. 残差连接 —— 让梯度直通、训练极深网络
4. 骨干网络 —— ResNet / DenseNet / EfficientNet / ConvNeXt
```

```python
import torch
import torch.nn as nn

# 一个最小 CNN：卷积 → 池化 → 全连接
net = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Flatten(),
    nn.Linear(16 * 16 * 16, 10),
)
x = torch.randn(1, 3, 32, 32)
print(net(x).shape)   # torch.Size([1, 10])
```

## Convolution

卷积是 CNN 的基本运算：一个可学习的小卷积核在输入上滑动，每个位置做逐元素乘加，得到特征图的一个像素。卷积核学到的是局部模式（边缘、纹理、形状），越深层的卷积核响应的模式越抽象。

```text
数学定义（2D 卷积）：
out[i,j] = Σ_{k,l} x[i+k, j+l] · W[k,l] + b

感受野：一个输出像素依赖的输入区域大小（核越大感受野越大）
权重共享：同一卷积核扫全图，参数量与输入尺寸无关
输出通道数 = 卷积核个数，每个核产生一个特征图
```

```python
import torch
import torch.nn as nn

conv = nn.Conv2d(in_channels=1, out_channels=2, kernel_size=3, bias=True)
x = torch.randn(1, 1, 5, 5)
y = conv(x)
print(f'输入 {x.shape} → 输出 {y.shape}')   # [1,1,5,5] → [1,2,3,3]

# 参数量 = 输出通道 × 输入通道 × 核高 × 核宽 + 偏置
print('参数量:', sum(p.numel() for p in conv.parameters()))

# 手写 2D 卷积验证
def conv2d(x, w, b):
    n, ci, h, w_ = x.shape
    co, _, kh, kw = w.shape
    oh, ow = h - kh + 1, w_ - kw + 1
    out = torch.zeros(n, co, oh, ow)
    for i in range(oh):
        for j in range(ow):
            out[:, :, i, j] = (x[:, :, i:i+kh, j:j+kw].unsqueeze(1) * w).sum(dim=(2,3,4)) + b
    return out

print(torch.allclose(conv(x), conv2d(x, conv.weight, conv.bias), atol=1e-5))  # True
```

## Padding

Padding 在输入四周补零（或镜像/复制），让输出保持期望的尺寸。没有 padding 时卷积每层缩小核宽一半，深层后特征图会缩到 0；same padding 让输出尺寸 = 输入尺寸 / stride。

```text
数学定义（valid vs same）：
valid（无 padding）：out = (in - k) / stride + 1
same（padding=(k-1)/2）：out = in / stride，保持尺寸

作用：
1. 保持特征图尺寸，让网络可以堆很多层
2. 让边缘像素也参与同样多的卷积计算（减少边缘信息丢失）
```

```python
import torch
import torch.nn as nn

x = torch.randn(1, 1, 32, 32)

# valid：不 padding，输出缩小
conv_valid = nn.Conv2d(1, 1, kernel_size=3)        # padding=0
print('valid:', conv_valid(x).shape)                # [1,1,30,30]

# same：padding=1，输出尺寸不变
conv_same = nn.Conv2d(1, 1, kernel_size=3, padding=1)
print('same: ', conv_same(x).shape)                 # [1,1,32,32]

# 手算验证：out = (in + 2p - k)/stride + 1
print('公式验证:', (32 + 2*1 - 3)//1 + 1)           # 32
```

## Stride

Stride 是卷积核每次滑动的步长。stride=1 逐步滑动，stride=2 跳格滑动，输出尺寸减半。大 stride 相当于带学习的下采样，常用来替代池化层压缩空间分辨率。

```text
数学定义：
out = (in + 2p - k) / stride + 1

stride=2 时输出尺寸约减半，同时增大感受野。
现代网络（如 ConvNeXt）倾向用 stride=2 的卷积替代池化做下采样。
```

```python
import torch
import torch.nn as nn

x = torch.randn(1, 3, 64, 64)

conv_s1 = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=1)
conv_s2 = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=2)

print('stride=1:', conv_s1(x).shape)   # [1,8,64,64]
print('stride=2:', conv_s2(x).shape)   # [1,8,32,32]  尺寸减半
```

## Dilation

Dilation（空洞卷积）在卷积核的元素之间插入空隙，不增加参数却成倍扩大感受野。它在语义分割里被广泛用来在不降低分辨率的前提下捕捉更大范围的上下文。

```text
数学定义：
有效核大小 = k + (k-1)·(d-1)
输出 = (in + 2p - 有效核大小) / stride + 1

dilation=1 是普通卷积；dilation=2 时 3×3 核覆盖 5×5 区域但只有 9 个参数。
```

```python
import torch
import torch.nn as nn

x = torch.randn(1, 1, 32, 32)

conv_d1 = nn.Conv2d(1, 1, kernel_size=3, dilation=1)
conv_d2 = nn.Conv2d(1, 1, kernel_size=3, dilation=2)

print('dilation=1:', conv_d1(x).shape)    # 感受野 3×3
print('dilation=2:', conv_d2(x).shape)    # 感受野 5×5，参数不变

print('参数量相同:', conv_d1.weight.numel() == conv_d2.weight.numel())  # True
```

## Pooling

Pooling 对局部区域做下采样（取最大或平均），降低分辨率、增大感受野、带来少量平移不变性。MaxPooling 取窗口最大值，保留最显著特征；AveragePooling 取均值，常用于网络末端做全局池化。

```text
常见类型：
1. MaxPool2d —— 取窗口最大，保留强特征，抗噪声
2. AvgPool2d —— 取窗口平均，平滑特征
3. Global Avg Pooling —— 整张特征图取平均，得到 1×1，接分类头

输出尺寸：out = (in - k)/stride + 1
```

```python
import torch
import torch.nn as nn

x = torch.randn(1, 1, 4, 4)
print('输入:\n', x.squeeze())

max_pool = nn.MaxPool2d(kernel_size=2, stride=2)
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

print('max pool:', max_pool(x).shape)    # [1,1,2,2]
print('avg pool:', avg_pool(x).shape)

# 全局平均池化：每通道一个标量
gap = nn.AdaptiveAvgPool2d(1)
print('GAP:', gap(x).shape)              # [1,1,1,1]
```

## Residual

Residual（残差连接）把输入直接加到卷积输出上，让网络学习「残差」而非完整映射。它让梯度通过捷径（skip connection）直通浅层，解决了深层网络的梯度消失和退化问题，是训练超过几十层网络的关键。

```text
数学定义：
y = F(x) + x

若 F 是恒等映射最优，网络只需把 F 学成 0，比学恒等映射容易得多。
梯度：dL/dx = dL/dy · (dF/dx + 1)，+1 项让梯度直通，不消失。
```

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.conv1 = nn.Conv2d(dim, dim, 3, padding=1)
        self.conv2 = nn.Conv2d(dim, dim, 3, padding=1)
        self.act = nn.ReLU()

    def forward(self, x):
        return self.act(self.conv2(self.act(self.conv1(x))) + x)   # 残差连接

blk = ResidualBlock(16)
print(blk(torch.randn(1, 16, 32, 32)).shape)   # [1,16,32,32]
```

## ResNet

ResNet 把残差连接系统化，用「瓶颈块 + 残差捷径」堆叠出 18/34/50/101/152 层的深度网络，在 ImageNet 上首次把错误率降到人类水平以下。它的瓶颈块用 1×1 卷积降维再升维，控制了深度网络的参数量，成为后续几乎所有视觉网络的骨架范式。

```text
结构要点：
1. 瓶颈块：1×1(降维) → 3×3(卷积) → 1×1(升维)，加残差捷径
2. 网络分 4 个 stage，每 stage 分辨率减半、通道翻倍
3. 首层 7×7 卷积 + stride=2，最后全局平均池化接全连接分类

深度：18/34（basic block），50/101/152（bottleneck block）
```

```python
import torchvision.models as models
import torch

resnet50 = models.resnet50(pretrained=False)
print('ResNet50 参数量(M):', sum(p.numel() for p in resnet50.parameters()) / 1e6)

x = torch.randn(1, 3, 224, 224)
print('输出:', resnet50(x).shape)        # [1, 1000]  ImageNet 1000 类
```

## DenseNet

DenseNet 把每一层都连接到前面所有层（密集连接），让特征反复复用、梯度更通畅，用更少的参数达到 ResNet 相当的精度。它的稠密连接带来了极强的特征传播和隐式深度监督，代价是显存占用高（特征要缓存给后面所有层）。

```text
核心思想：
第 l 层输入 = 前面所有层的输出在通道维拼接 [x0, x1, ..., x_{l-1}]

增长率 k：每层新产生的通道数（很小，如 32）
优点：特征复用、梯度直达、参数高效
缺点：显存高（中间特征都要留着拼接）
```

```python
import torch
import torch.nn as nn

class DenseLayer(nn.Module):
    def __init__(self, in_ch, growth_rate):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, growth_rate, 3, padding=1)

    def forward(self, x):
        out = self.conv(x)
        return torch.cat([x, out], dim=1)    # 通道拼接，密集连接

# 连续三层，每层输入通道递增
x = torch.randn(1, 16, 8, 8)
d1 = DenseLayer(16, 8);  x = d1(x)          # 16 → 24
d2 = DenseLayer(24, 8);  x = d2(x)          # 24 → 32
d3 = DenseLayer(32, 8);  x = d3(x)          # 32 → 40
print('三层 Dense 后通道数:', x.shape[1])    # 40
```

## EfficientNet

EfficientNet 用「复合缩放」同时、按固定比例放大网络的深度、宽度和输入分辨率，在同等精度下比 ResNet 小得多、快得多。它的核心是 MBConv 块（含深度可分离卷积 + SE 注意力），是移动端和高效视觉任务的主力骨干。

```text
核心思想：
1. 复合缩放：depth、width、resolution 按系数 d=α^φ, w=β^φ, r=γ^φ 同步放大
2. MBConv：深度可分离卷积（先逐通道 3×3，再逐点 1×1）+ Squeeze-and-Excitation
3. 从 EfficientNet-B0 到 B7，逐级放大

优点：精度/速度/参数的三者平衡好，适合资源受限场景。
```

```python
import torchvision.models as models
import torch

for name in ['efficientnet_b0', 'efficientnet_b4']:
    net = getattr(models, name)(pretrained=False)
    params = sum(p.numel() for p in net.parameters()) / 1e6
    print(f'{name}: 参数量={params:.1f}M')

x = torch.randn(1, 3, 224, 224)
print(models.efficientnet_b0(pretrained=False)(x).shape)   # [1, 1000]
```

## ConvNeXt

ConvNeXt 是「CNN 的现代化改造」：把 Swin Transformer 的训练技巧和结构设计（LayerNorm、GELU、大卷积核、Patchify stem）搬回纯卷积网络，证明精心设计的 CNN 能达到甚至超越 Transformer 的精度，同时保留 CNN 的推理友好性。

```text
相对传统 ResNet 的改造：
1. 深度可分离卷积 + 7×7 大卷积核（仿 Swin 的窗口注意力）
2. LayerNorm 替代 BatchNorm，GELU 替代 ReLU
3. 用 stride=2 的卷积替代池化下采样
4. 更少的激活函数、更多归一化，训练用更激进的增强

结论：架构的「现代化技巧」比「Transformer vs CNN」本身更重要。
```

```python
import torchvision.models as models
import torch

convnext_tiny = models.convnext_tiny(pretrained=False)
print('ConvNeXt-T 参数量(M):', sum(p.numel() for p in convnext_tiny.parameters()) / 1e6)

x = torch.randn(1, 3, 224, 224)
print('输出:', convnext_tiny(x).shape)     # [1, 1000]
```

## 应用场景实战

### 场景一：用 ResNet 做迁移学习分类

```python
import torch
import torch.nn as nn
import torchvision.models as models

# 冻结 backbone，只训练新的分类头
model = models.resnet18(pretrained=True)
for param in model.parameters():
    param.requires_grad = False
model.fc = nn.Linear(model.fc.in_features, 5)   # 换成 5 类

x = torch.randn(2, 3, 224, 224)
y = torch.tensor([1, 3])
criterion = nn.CrossEntropyLoss()
opt = torch.optim.Adam(model.fc.parameters(), lr=1e-3)

model.train()
loss = criterion(model(x), y)
opt.zero_grad(); loss.backward(); opt.step()
print(f'loss={loss.item():.4f}')
```

### 场景二：手写残差块堆叠成小 CNN

```python
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.stem = nn.Conv2d(3, 32, 3, padding=1)
        self.block1 = nn.Sequential(
            nn.Conv2d(32, 32, 3, padding=1), nn.ReLU(),
            nn.Conv2d(32, 32, 3, padding=1), nn.ReLU())
        self.block2 = nn.Sequential(
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(),
            nn.Conv2d(64, 64, 3, padding=1), nn.ReLU())
        self.shortcut2 = nn.Conv2d(32, 64, 1)   # 1×1 卷积匹配通道，残差才能相加
        self.pool = nn.MaxPool2d(2)
        self.fc = nn.Linear(64 * 4 * 4, num_classes)

    def forward(self, x):
        x = self.pool(nn.functional.relu(self.stem(x)))
        x = self.pool(nn.functional.relu(self.block1(x) + x))
        x = self.pool(nn.functional.relu(self.block2(x) + self.shortcut2(x)))
        return self.fc(torch.flatten(x, 1))

net = SmallCNN()
print(net(torch.randn(1, 3, 32, 32)).shape)   # [1, 10]
```

## 最佳实践与踩坑记录

### 最佳实践

1. 默认骨干选 ResNet（通用）/ EfficientNet（轻量）/ ConvNeXt（追求精度），按任务和算力选
2. 小卷积核（3×3）堆叠比大卷积核（7×7/11×11）参数少、感受野等效，优先用小核
3. same padding（padding=k//2）保持尺寸，方便堆层和残差连接
4. 下采样优先用 stride=2 的卷积替代池化（保留更多信息，现代网络趋势）
5. 迁移学习时冻结 backbone、只训练分类头，数据少时别从头训
6. 图像预处理要归一化到与预训练一致的均值/方差（ImageNet 的 [0.485,0.456,0.406]）

### 踩坑记录

```text
坑 1：卷积后接全连接时忘记算展平后的维度
结论：报 size mismatch 错误。
原因：卷积输出是 [N, C, H, W]，Linear 要的是 [N, C*H*W]。
解法：接 nn.Flatten() 或用 torch.flatten(x, 1)，维度算不准就打印 shape 核对。

坑 2：预训练模型输入尺寸不对导致精度骤降
结论：迁移学习效果比从头训练还差。
原因：预训练模型在 224×224 上训练，直接喂 32×32 特征分布不对。
解法：把输入 resize 到预训练尺寸，或只复用浅层特征重新适配。

坑 3：DenseNet 训练时显存爆掉
结论：OOM，batch 稍大就超显存。
原因：密集连接要缓存前面所有层特征用于拼接，中间激活占显存极大。
解法：减小 batch，或用 gradient checkpointing 牺牲速度换显存。

坑 4：下采样时 stride 和 padding 不匹配导致尺寸算错
结论：特征图尺寸不是预期的整数，后续层报错。
原因：out=(in+2p-k)/stride+1 没整除，产生小数（其实 PyTorch 会向下取整）。
解法：设计网络时逐层核验输出尺寸公式，不确定就打印 shape。

坑 5：MaxPooling 放太多导致信息丢失、精度上不去
结论：网络越深反而越差。
原因：池化是硬下采样，过多池化丢失细节信息。
解法：控制下采样次数（一般 4-5 次到 1/32 分辨率），用 stride 卷积替代部分池化。
```
