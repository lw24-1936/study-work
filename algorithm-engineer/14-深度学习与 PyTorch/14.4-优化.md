## 概述

优化器决定了「梯度如何变成参数更新」。深度学习的损失面高度非凸、充满鞍点和噪声，好的优化器要能在这些地形里稳定下降。从朴素 SGD 到动量、自适应学习率（Adam），再到配套的学习率调度（Warmup、Cosine Decay）和训练稳定性技术（梯度裁剪、混合精度），它们共同决定训练能不能收敛、收敛多快。

```text
优化器的演进脉络：
1. SGD —— 每次用（mini-batch）梯度直接更新，方向噪声大
2. Momentum —— 累加历史梯度，惯性冲过鞍点、减小震荡
3. Adam —— 一阶矩 + 二阶矩自适应缩放每维学习率，收敛快
4. AdamW —— 把 weight decay 与自适应学习率解耦，泛化更好
5. 配套技术 —— Warmup 起步、Cosine 退火、梯度裁剪、混合精度
```

```python
import torch
import torch.nn as nn

model = nn.Linear(10, 1)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

# 一次完整的参数更新
x = torch.randn(4, 10); y = torch.randn(4, 1)
loss = nn.functional.mse_loss(model(x), y)
opt.zero_grad(); loss.backward(); opt.step()
```

## SGD

SGD（随机梯度下降）每次用一个小批量（mini-batch）的梯度更新参数。相比全量梯度下降，它更快、能逃出某些局部极小，但更新方向噪声大、在高曲率方向震荡明显，收敛慢。

```text
数学定义：
θ ← θ - η·∇L_B(θ)

其中 ∇L_B 是 mini-batch B 上的平均梯度。

特点：
1. 每次只算一个小批量，内存和时间都可控
2. 梯度有噪声，天然带有正则化/逃逸能力
3. 所有维度共用同一学习率，曲率差异大的方向会震荡
```

```python
import torch
import torch.nn as nn

model = nn.Linear(2, 1)
opt = torch.optim.SGD(model.parameters(), lr=0.01)

# 手写 SGD 等价实现
def sgd_step(params, lr):
    with torch.no_grad():
        for p in params:
            p -= lr * p.grad

x = torch.randn(8, 2); y = torch.randn(8, 1)
loss = nn.functional.mse_loss(model(x), y)
model.zero_grad(); loss.backward()
sgd_step(model.parameters(), lr=0.01)   # 与 opt.step() 等价
print(f'loss={loss.item():.4f}')
```

## Momentum

Momentum 在 SGD 基础上累加历史梯度的指数滑动平均，更新时用「动量」而不是当前梯度。它让方向一致的维度加速、方向反复的维度抵消，冲过小鞍点、减小震荡，是 SGD 最重要的增强。

```text
数学定义：
v ← β·v + ∇L     （β 常见 0.9，Nesterov 用未来位置的梯度）
θ ← θ - η·v

直观：把更新看成有惯性的球，历史梯度是速度，当前梯度是加速度。
Nesterov 变体先沿动量走一步再算梯度，收敛理论更好。
```

```python
import torch
import torch.nn as nn

model = nn.Linear(2, 1)
opt = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# 手写 Momentum 等价实现
def momentum_step(params, lr, beta, buffers):
    with torch.no_grad():
        for i, p in enumerate(params):
            buffers[i] = beta * buffers[i] + p.grad
            p -= lr * buffers[i]

x = torch.randn(8, 2); y = torch.randn(8, 1)
loss = nn.functional.mse_loss(model(x), y)
model.zero_grad(); loss.backward()
bufs = [torch.zeros_like(p) for p in model.parameters()]
momentum_step(model.parameters(), 0.01, 0.9, bufs)
print(f'loss={loss.item():.4f}')
```

## Adam

Adam 结合 Momentum（一阶矩估计）和 RMSProp（二阶矩估计），对每个参数自适应地缩放学习率。它收敛快、对超参数不太敏感，是深度学习的默认优化器；缺点是二阶矩的噪声在前期会让步长不稳定，泛化有时略逊于 SGD。

```text
数学定义：
m ← β1·m + (1-β1)·g        # 一阶矩（动量）
v ← β2·v + (1-β2)·g²       # 二阶矩（梯度平方的滑动平均）
m̂ = m/(1-β1ᵗ)；v̂ = v/(1-β2ᵗ)   # 偏差修正
θ ← θ - η·m̂ / (√v̂ + ε)

默认 β1=0.9, β2=0.999, ε=1e-8。
每个参数有自己的有效学习率 η/(√v̂+ε)，适合稀疏梯度。
```

```python
import torch
import torch.nn as nn

model = nn.Linear(2, 1)
opt = torch.optim.Adam(model.parameters(), lr=1e-3, betas=(0.9, 0.999))

# 手写 Adam 等价实现（含偏差修正）
def adam_step(params, lr, beta1, beta2, eps, state, t):
    with torch.no_grad():
        for p in params:
            m, v = state[id(p)]
            m = beta1 * m + (1 - beta1) * p.grad
            v = beta2 * v + (1 - beta2) * p.grad ** 2
            m_hat = m / (1 - beta1 ** t)
            v_hat = v / (1 - beta2 ** t)
            p -= lr * m_hat / (torch.sqrt(v_hat) + eps)
            state[id(p)] = (m, v)

x = torch.randn(8, 2); y = torch.randn(8, 1)
loss = nn.functional.mse_loss(model(x), y)
model.zero_grad(); loss.backward()
st = {id(p): (torch.zeros_like(p), torch.zeros_like(p)) for p in model.parameters()}
adam_step(model.parameters(), 1e-3, 0.9, 0.999, 1e-8, st, t=1)
print(f'loss={loss.item():.4f}')
```

## AdamW

AdamW 把 L2 正则（weight decay）从 Adam 的自适应缩放里解耦出来，直接在更新后对权重做乘法收缩。它保留了 Adam 的快速收敛，又恢复了 weight decay 应有的泛化正则效果，是 Transformer 和大模型训练的标准优化器。

```text
数学定义（解耦 weight decay）：
θ ← θ - η·m̂/(√v̂ + ε) - η·λ·θ

即先做 Adam 更新，再额外减去 η·λ·θ。

为什么解耦：Adam 里把 λ‖θ‖² 加进 loss，惩罚会被 √v̂ 缩放，
高频/大梯度参数几乎不被惩罚；解耦后每个参数统一按比例收缩。
```

```python
import torch
import torch.nn as nn

model = nn.Linear(2, 1)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

# 对比：Adam + L2 正则（耦合） vs AdamW（解耦）
def adam_with_l2(params, lr, lam, state, t):
    with torch.no_grad():
        for p in params:
            m, v = state[id(p)]
            g = p.grad + lam * p          # L2 梯度直接加进 loss 的梯度
            m = 0.9 * m + 0.1 * g
            v = 0.999 * v + 0.001 * g ** 2
            p -= lr * (m / (1 - 0.9 ** t)) / (torch.sqrt(v / (1 - 0.999 ** t)) + 1e-8)
            state[id(p)] = (m, v)

x = torch.randn(8, 2); y = torch.randn(8, 1)
loss = nn.functional.mse_loss(model(x), y)
model.zero_grad(); loss.backward()
print('AdamW 更新前权重范数:', model.weight.norm().item())
opt.step()
print('AdamW 更新后权重范数:', model.weight.norm().item())
```

## Warmup

Warmup 在训练开始阶段把学习率从很小的值线性（或按比例）升到目标值。它避免训练初期梯度统计量（尤其 Adam 的二阶矩）还不准确时用大学习率导致发散，对大模型和大 batch 训练尤其重要。

```text
机制：
前 N 步学习率线性增长：lr = base_lr * step/N
N 步之后进入正常调度（余弦退火等）。

为什么需要：
1. 训练初期参数随机、梯度方向不可靠，大学习率易震荡/发散
2. Adam 的二阶矩 v 初期很小，有效学习率 η/√v̂ 会异常大
3. 大 batch 训练梯度噪声大，需要先小步稳定
```

```python
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(4, 1)
opt = optim.AdamW(model.parameters(), lr=1e-3)

# 线性 warmup：前 1000 步从 0 升到 base_lr
def lr_warmup(step, warmup_steps, base_lr):
    if step < warmup_steps:
        return base_lr * step / warmup_steps
    return base_lr

for step in range(2000):
    lr = lr_warmup(step, 1000, 1e-3)
    for g in opt.param_groups:
        g['lr'] = lr
    if step in [0, 500, 1000, 1500]:
        print(f'step {step}: lr={opt.param_groups[0]["lr"]:.6f}')
```

## Cosine Decay

Cosine Decay 让学习率按余弦曲线从初始值平滑衰减到接近 0，训练末期以小步长精细收敛到损失面的底部。相比阶梯式衰减，它更平滑，是现代大模型训练的标准调度，常与 Warmup 组合成「Warmup + Cosine」模式。

```text
数学定义（半周期余弦）：
lr(t) = lr_min + 0.5·(lr_max - lr_min)·(1 + cos(π·t/T))

其中 t 是当前步，T 是总步数。

特点：
1. 训练前期保持较高学习率探索，末期平滑降到最小
2. 比 step decay 平滑，避免学习率突降带来的震荡
```

```python
import torch
import torch.nn as nn
import math

model = nn.Linear(4, 1)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
total_steps = 1000

scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=total_steps)

for step in range(total_steps):
    scheduler.step()
    if step in [0, 250, 500, 750, 999]:
        print(f'step {step}: lr={opt.param_groups[0]["lr"]:.6f}')
```

## Gradient Clipping

Gradient Clipping 把梯度的范数（或逐元素）限制在阈值内，防止梯度爆炸导致训练发散。它在 RNN/LSTM 和大模型训练里是标配——长序列反传或坏样本可能产生巨大梯度，一次更新就把参数冲飞。

```text
两种方式：
1. 按范数裁剪（推荐）：若 ‖g‖ > c，则 g ← g·c/‖g‖
2. 按值裁剪：clamp(g, -c, c)，逐元素截断

阈值常见 0.5~5.0。裁剪只改变梯度的「大小」，不改变方向。
```

```python
import torch
import torch.nn as nn

model = nn.LSTM(8, 16, batch_first=True)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

x = torch.randn(4, 10, 8)
loss = model(x)[0].sum()
loss.backward()

# 裁剪前梯度范数
before = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
print(f'裁剪前梯度范数: {before:.3f}')

# 手写按范数裁剪等价实现
def clip_by_norm(params, max_norm):
    total = sum((p.grad.norm() ** 2) for p in params if p.grad is not None) ** 0.5
    coef = max_norm / (total + 1e-6)
    if coef < 1:
        for p in params:
            p.grad.mul_(coef)
    return total

# 或按值裁剪
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)
```

## Mixed Precision

Mixed Precision 训练时用 FP16（或 BF16）存激活和做矩阵乘法，用 FP32 保存权重主副本和梯度累加，大幅提升吞吐、省显存。配合 GradScaler 解决 FP16 下小梯度下溢的问题，是 GPU 训练的标准加速手段。

```text
机制：
1. 权重保留 FP32 主副本
2. 前向/反向用 FP16 计算（快、省显存）
3. 梯度累加回 FP32，避免精度丢失
4. GradScaler 放大 loss，防止小梯度在 FP16 下下溢为 0

BF16 变体：指数位与 FP32 相同、范围大，无需 scaler 也能用，但精度略低。
```

```python
import torch
import torch.nn as nn

model = nn.Linear(10, 1).cuda()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
scaler = torch.cuda.amp.GradScaler()          # 梯度缩放器

x = torch.randn(16, 10, device='cuda')
y = torch.randn(16, 1, device='cuda')

with torch.cuda.amp.autocast():               # 自动混合精度上下文
    loss = nn.functional.mse_loss(model(x), y)

opt.zero_grad()
scaler.scale(loss).backward()                 # 缩放后反传
scaler.step(opt)                              # 反缩放后更新
scaler.update()                               # 动态调整缩放因子
print('mixed precision step done')
```

## 应用场景实战

### 场景一：Warmup + Cosine 完整训练循环

```python
import torch
import torch.nn as nn
import math

torch.manual_seed(0)
model = nn.Sequential(nn.Linear(8, 32), nn.ReLU(), nn.Linear(32, 1))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

x = torch.randn(500, 8)
y = (x[:, 0] * x[:, 1] + x[:, 2]).unsqueeze(1)

total_steps, warmup = 3000, 300
base_lr = 1e-3
for step in range(total_steps):
    # warmup + cosine 组合
    if step < warmup:
        lr = base_lr * step / warmup
    else:
        progress = (step - warmup) / (total_steps - warmup)
        lr = base_lr * 0.5 * (1 + math.cos(math.pi * progress))
    for g in opt.param_groups:
        g['lr'] = lr

    loss = nn.functional.mse_loss(model(x), y)
    opt.zero_grad(); loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    opt.step()
print(f'final loss={loss.item():.4f}')
```

### 场景二：不同优化器收敛对比

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
x = torch.randn(1000, 4)
y = (x[:, 0] * 2 - x[:, 1] + 1).unsqueeze(1)

def train(optimizer_name):
    net = nn.Linear(4, 1)
    opt = getattr(torch.optim, optimizer_name)(net.parameters(), lr=0.05)
    for _ in range(200):
        loss = nn.functional.mse_loss(net(x), y)
        opt.zero_grad(); loss.backward(); opt.step()
    return loss.item()

for name in ['SGD', 'Adam', 'AdamW']:
    print(f'{name}: final_loss={train(name):.6f}')
# Adam/AdamW 通常显著快于裸 SGD
```

## 最佳实践与踩坑记录

### 最佳实践

1. 默认 AdamW（lr 1e-3~3e-4，weight_decay 0.01~0.1），大模型再加 Warmup + Cosine
2. 追求极限泛化（如某些视觉分类比赛）可试 SGD + Momentum + 长时间训练，但调参成本高
3. 大 batch 训练要相应放大学习率，并配合 warmup，避免起步不稳
4. RNN/LSTM/大模型必开 Gradient Clipping（max_norm 0.5~5）
5. 混合精度用 AMP 的 GradScaler，注意权重主副本保持 FP32
6. 学习率调度与 batch size 联动：batch 翻倍时学习率按比例调，经验法则 lr ∝ batch

### 踩坑记录

```text
坑 1：Adam 起步时没 warmup 直接大学习率导致发散
结论：前几步 loss 就爆炸成 NaN。
原因：训练初期二阶矩 v 很小，有效学习率 η/√v̂ 异常大。
解法：前 N 步线性 warmup，或用更小学习率。

坑 2：把 weight_decay 加进 Adam 当成 AdamW 用
结论：以为做了正则，实际泛化没提升。
原因：Adam 里 L2 惩罚被自适应学习率缩放，正则失效。
解法：直接用 torch.optim.AdamW，或 SGD + weight_decay。

坑 3：混合精度训练下小梯度下溢为 0
结论：训练到后期 loss 不再下降，梯度全是 0。
原因：FP16 最小正规数约 6e-5，小于它的梯度被截成 0。
解法：用 GradScaler 放大 loss，或改用 BF16（范围大无需 scaler）。

坑 4：余弦退火设了 T_max 但训练步数不一致
结论：学习率没降到预期就训练结束了，或提前归零。
原因：T_max 与真实训练步数不匹配。
解法：T_max 设为实际总步数（epoch 数 × 每 epoch 步数）。

坑 5：梯度裁剪阈值设太小，训练变成随机游走
结论：loss 下降极慢甚至不下降。
原因：梯度被过度裁剪，更新方向和大小都失真。
解法：max_norm 先设宽松值（如 5.0），观察梯度范数分布再收紧。
```
