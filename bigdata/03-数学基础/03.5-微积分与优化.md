## 概述

微积分与优化是机器学习、深度学习和大数据算法的数学底座。微积分研究函数的变化率（导数、梯度、Hessian 矩阵），优化研究如何找到使目标函数最小（或最大）的参数。绝大多数模型训练——从线性回归到神经网络——最终都归结为一个优化问题：用梯度信息迭代更新参数，让损失函数不断下降。理解导数怎么算、梯度指向哪、凸与非凸的区别，是读懂优化器和调参的前提。

```text
微积分与优化的核心关系：
1. 导数/梯度 —— 描述函数局部变化方向和速率，是优化的「指南针」
2. 链式法则 —— 复合函数求导规则，是神经网络反向传播的数学基础
3. 凸性 —— 凸函数的局部最优就是全局最优，非凸函数则可能陷入局部极小
4. 一阶方法（GD/SGD）—— 只用梯度，步长靠学习率，简单但收敛慢
5. 二阶方法（牛顿法）—— 用 Hessian 修正步长方向，收敛快但计算贵
```

```python
import numpy as np

# 一个简单的目标函数 f(x) = (x - 3)^2 + 2，极小值在 x=3
def f(x):
    return (x - 3) ** 2 + 2

def df(x):
    return 2 * (x - 3)  # 解析导数

x = np.array(0.0)
for i in range(100):
    x = x - 0.1 * df(x)   # 梯度下降，学习率 0.1
print(f"梯度下降收敛到 x={x:.4f}, f={f(x):.4f}")   # x≈3.0000
```

## 导数与偏导

导数描述一元函数在某点的瞬时变化率，几何意义是切线的斜率；偏导是多元函数对其中一个变量的导数（其余变量视为常数）。梯度是偏导向量，指向函数上升最快的方向——所以梯度下降要沿「负梯度」方向走。数值上导数可用差分近似，但解析求导更精确、更快。

```text
导数与偏导要点：
1. 导数 —— f'(x) = lim(h→0) [f(x+h)-f(x)]/h，切线的斜率
2. 偏导 —— 多元函数逐变量求导，梯度 = 各偏导组成的向量
3. 梯度方向 —— 函数值上升最快的方向，负梯度是下降最快方向
4. 解析导 vs 数值导 —— 解析导精确，数值导（差分）易受浮点误差影响
```

```python
import numpy as np

# 二元函数 f(x,y) = x^2 + y^2，梯度 = (2x, 2y)
def f2(x, y):
    return x**2 + y**2

def grad_f2(x, y):
    return np.array([2*x, 2*y])   # 解析偏导

# 数值偏导（中心差分）作对比
def numerical_grad(f, xy, h=1e-5):
    g = np.zeros_like(xy, dtype=float)
    for i in range(len(xy)):
        xp = xy.copy(); xp[i] += h
        xm = xy.copy(); xm[i] -= h
        g[i] = (f(*xp) - f(*xm)) / (2*h)
    return g

xy = np.array([2.0, -1.0])
print("解析梯度:", grad_f2(*xy))            # [4. -2.]
print("数值梯度:", numerical_grad(f2, xy))   # [4.00000001 -2.00000001]
```

## 梯度与 Hessian

梯度是函数的一阶导数向量（对多元函数），Hessian 是二阶导数矩阵——它刻画函数曲面的弯曲程度，特征值全正说明函数在该点局部是「碗状」（凸），可用于判断极值类型和指导二阶优化。梯度和 Hessian 是牛顿法、L-BFGS 等二阶方法的核心输入。

```text
梯度与 Hessian 要点：
1. 梯度 —— 一阶信息，方向 = 上升最快方向，范数 = 变化速率
2. Hessian —— 二阶信息，对称矩阵 H[i][j] = ∂²f/∂xi∂xj
3. 极值判定 —— 梯度为 0 且 Hessian 正定 → 局部极小；负定 → 极大；不定 → 鞍点
4. 曲率 —— Hessian 特征值反映各方向曲率，条件数大 → 病态、收敛慢
```

```python
import numpy as np

# f(x,y) = x^2 + 3y^2，Hessian = [[2,0],[0,6]]
def f(x, y):
    return x**2 + 3*y**2

def grad(x, y):
    return np.array([2*x, 6*y])

def hessian(x, y):
    return np.array([[2.0, 0.0], [0.0, 6.0]])

# 在 (0,0) 处 Hessian 正定 → 局部极小
H = hessian(0, 0)
eig = np.linalg.eigvals(H)
print("Hessian 特征值:", eig)              # [2. 6.] 全正 → 极小点
print("条件数:", np.linalg.cond(H))        # 6/2 = 3，越大越病态
```

## 链式法则与反向传播

链式法则是对复合函数求导的规则：外层对内层求导，再乘内层对自变量求导。它是一维的「链」；推广到神经网络的多层结构，就是反向传播（Backprop）——从输出层逐层往前传梯度，每层用本地雅可比矩阵乘上游梯度。链式法则是所有深度学习框架自动微分（autograd）的理论基础。

```text
链式法则要点：
1. 一元链式 —— d(f(g(x)))/dx = f'(g(x)) · g'(x)
2. 多元链式 —— 雅可比矩阵相乘，逐层传播梯度
3. 反向传播 —— 先前向算输出，再反向逐层传梯度，避免重复计算
4. 自动微分 —— PyTorch/TensorFlow 靠计算图 + 链式法则自动算梯度
```

```python
import numpy as np

# 复合函数 f = (wx + b)^2，链式法则求 df/dw
def forward(w, x, b):
    z = w * x + b          # 内层线性
    return z ** 2, z       # 外层平方

def backward(dz, w, x, b, z):
    # dz/dw = x, dz/db = 1, dz/dx = w
    # df/dz = 2z（外层对 z 求导）
    df_dz = 2 * z
    return df_dz * x, df_dz * 1.0, df_dz * w   # 分别对 w、b、x 的梯度

w, x, b = np.array(2.0), np.array(3.0), np.array(1.0)
y, z = forward(w, x, b)
dw, db, dx = backward(1.0, w, x, b, z)
print(f"df/dw={dw}, df/db={db}, df/dx={dx}")
# 验证：f=(2*3+1)^2=49, df/dw=2*7*3=42 ✓
```

## 凸优化与凸函数

凸函数是「任意两点连线在函数图像上方」的函数，其局部最优一定是全局最优——这是它比非凸函数好优化的根本原因。凸优化研究凸函数（或凸集合）上的最小化问题，线性规划、二次规划、逻辑回归的负对数似然等都是凸问题。深度学习的目标函数（神经网络损失）是非凸的，所以只求局部极小，靠随机性和初始化找好解。

```text
凸函数与凸优化要点：
1. 凸函数定义 —— f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)，任意 λ∈[0,1]
2. 关键性质 —— 局部最优 = 全局最优，无鞍点陷阱
3. 二阶判据 —— Hessian 半正定 ⇔ 凸函数
4. 凸问题举例 —— 线性回归（MSE）、逻辑回归、SVM 的凸形式
5. 非凸问题 —— 神经网络，靠 SGD 随机性跳出局部极小
```

```python
import numpy as np

# 判断凸性：f(x)=x^2 是凸的，f(x)=sin(x) 非凸
def is_convex_1d(f, lo, hi, n=100):
    xs = np.linspace(lo, hi, n)
    for _ in range(50):
        x1, x2 = np.random.uniform(lo, hi, 2)
        lam = 0.5
        mid = lam * x1 + (1 - lam) * x2
        if f(mid) > lam * f(x1) + (1 - lam) * f(x2) + 1e-9:
            return False
    return True

print("x^2 凸?", is_convex_1d(lambda x: x**2, -5, 5))        # True
print("sin(x) 凸?", is_convex_1d(lambda x: np.sin(x), -5, 5)) # False
```

## 拉格朗日乘子与约束优化

拉格朗日乘子法把「带约束的优化问题」转化为「无约束问题」：构造拉格朗日函数 L(x, λ) = f(x) + λ·g(x)，对 x 和 λ 同时求导置零。它在机器学习里的典型应用是 SVM（最大化间隔受分类约束）、PCA（方差最大受正交约束）。KKT 条件是不等式约束下最优解的一阶必要条件。

```text
拉格朗日乘子要点：
1. 等式约束 —— min f(x) s.t. g(x)=0 → L = f(x) + λg(x)，∂L/∂x=0, ∂L/∂λ=0
2. 乘子含义 —— λ 是约束的「价格」，衡量放松约束能带来多少收益
3. KKT 条件 —— 不等式约束 + 互补松弛 + 对偶可行，是最优解的必要条件
4. 对偶问题 —— 把原问题转成对偶问题求解，SVM 的核心技巧
```

```python
import numpy as np

# min f(x,y)=x^2+y^2  s.t. x+y=1
# L = x^2+y^2 + λ(x+y-1)，解得 x=y=0.5, λ=-1
def lagrange_system():
    # ∂L/∂x = 2x+λ = 0; ∂L/∂y = 2y+λ = 0; ∂L/∂λ = x+y-1 = 0
    # 矩阵形式 [[2,0,1],[0,2,1],[1,1,0]] [x,y,λ]^T = [0,0,1]
    A = np.array([[2.0, 0.0, 1.0],
                  [0.0, 2.0, 1.0],
                  [1.0, 1.0, 0.0]])
    b = np.array([0.0, 0.0, 1.0])
    return np.linalg.solve(A, b)

x, y, lam = lagrange_system()
print(f"最优解 x={x:.4f}, y={y:.4f}, λ={lam:.4f}")  # x=y=0.5, λ=-1
print(f"目标值 f={x**2 + y**2:.4f}")               # 0.5
```

## 梯度下降与 SGD

梯度下降（GD）是最基础的优化算法：每步沿负梯度方向走一步，步长由学习率控制。批量 GD 用全部数据算梯度（精确但慢），随机梯度下降（SGD）每次只用一个（或一小批）样本算梯度（噪声大但快、能逃出局部极小），小批量（Mini-batch）GD 是折中，也是深度学习默认选择。学习率是超参数里最敏感的一个。

```text
GD 与 SGD 要点：
1. 批量 GD —— 全量数据算梯度，稳定但每步都慢，内存吃紧
2. SGD —— 单样本梯度，噪声大、收敛震荡但快，随机性助逃局部极小
3. Mini-batch —— 一小批（32/64/128）算梯度，噪声与速度折中，DL 默认
4. 学习率 —— 太大震荡发散，太小收敛慢；常配衰减调度
5. 动量 —— 累积历史梯度加速、抑制震荡（Momentum/Adam 的基础）
```

```python
import numpy as np

# 线性回归：y = 3x + 2，用 SGD 拟合
np.random.seed(0)
X = np.random.rand(100, 1) * 10
y = 3 * X.ravel() + 2 + np.random.randn(100) * 0.5

w, b = 0.0, 0.0
lr = 0.01
for epoch in range(200):
    for i in range(len(X)):          # 逐个样本 SGD
        pred = w * X[i, 0] + b
        err = pred - y[i]
        w -= lr * err * X[i, 0]      # dL/dw = err * x
        b -= lr * err                # dL/db = err
print(f"SGD 拟合: w={w:.3f}, b={b:.3f}（真实 w=3, b=2）")
```

## 牛顿法

牛顿法是二阶优化方法：用函数的二阶泰勒展开逼近，每步沿「-Hessian⁻¹ · 梯度」方向走，相当于自动调整各方向步长。它对凸函数收敛极快（二次收敛），但每步要算并求逆 Hessian（O(n³)），高维时不可行，于是有拟牛顿法（L-BFGS 用低秩近似 Hessian）。牛顿法也用于求根（方程 f(x)=0 的迭代）。

```text
牛顿法要点：
1. 更新公式 —— x ← x - H⁻¹∇f(x)，二阶信息修正步长
2. 收敛速度 —— 二次收敛，比 GD 的一阶收敛快得多
3. 代价 —— 每步 O(n³) 求逆，高维参数（神经网络）用不起
4. 拟牛顿 —— BFGS/L-BFGS 用梯度差近似 Hessian 逆，避免显式求逆
5. 求根场景 —— x ← x - f(x)/f'(x)，解方程和最大似然常用
```

```python
import numpy as np

# 用牛顿法求函数极小值：f(x) = x^4 - 3x^2 + x，f'=4x^3-6x+1, f''=12x^2-6
def f(x):  return x**4 - 3*x**2 + x
def fp(x): return 4*x**3 - 6*x + 1
def fpp(x): return 12*x**2 - 6

x = 2.0
for i in range(10):
    x = x - fp(x) / fpp(x)      # 牛顿法迭代
print(f"牛顿法收敛到 x={x:.6f}, f={f(x):.6f}")

# 对比：牛顿法求根 x^2 - 2 = 0（求 sqrt(2)）
x = 1.5
for i in range(5):
    x = x - (x**2 - 2) / (2*x)
print(f"牛顿法求 sqrt(2) = {x:.8f}")   # ≈1.41421356
```

## 应用场景实战

### 场景一：逻辑回归的梯度下降训练

```python
import numpy as np

# 生成二分类数据
np.random.seed(0)
n = 200
X = np.random.randn(n, 2)
y = (X[:, 0] + X[:, 1] > 0).astype(int)   # 线性可分

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 逻辑回归负对数似然 + 梯度
def loss_and_grad(w, X, y):
    z = X @ w
    p = sigmoid(z)
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))
    grad = X.T @ (p - y) / n
    return loss, grad

w = np.zeros(2)
for epoch in range(1000):
    loss, grad = loss_and_grad(w, X, y)
    w -= 0.5 * grad
    if epoch % 200 == 0:
        print(f"epoch {epoch}: loss={loss:.4f}")

pred = (sigmoid(X @ w) > 0.5).astype(int)
print(f"准确率 = {np.mean(pred == y):.4f}")
```

### 场景二：带 L2 正则的岭回归（凸优化）

```python
import numpy as np

# 岭回归：min ||Xw - y||^2 + λ||w||^2，闭式解 w = (X^T X + λI)^-1 X^T y
np.random.seed(0)
X = np.random.randn(100, 5)
true_w = np.array([1.5, -2.0, 0.5, 0.0, 0.0])
y = X @ true_w + np.random.randn(100) * 0.3

def ridge_closed_form(X, y, lam):
    n_features = X.shape[1]
    return np.linalg.solve(X.T @ X + lam * np.eye(n_features), X.T @ y)

for lam in [0.0, 0.1, 1.0]:
    w = ridge_closed_form(X, y, lam)
    print(f"λ={lam}: w={np.round(w, 3)}")
# λ 越大，系数越被压缩向 0，抑制过拟合
```

## 最佳实践与踩坑记录

### 最佳实践

1. 深度学习默认用 Mini-batch SGD + 自适应优化器（Adam/AdamW），别用批量 GD
2. 学习率先从小试起（1e-3 是常见起点），配学习率衰减或 warmup
3. 特征尺度差异大时先标准化，否则梯度下降在「狭长山谷」里震荡难收敛
4. 能解析求导就别用数值差分，数值导慢且有截断误差
5. 判断凸性用 Hessian 半正定，别只凭直觉（很多损失表面看凸其实非凸）
6. 高维优化用 L-BFGS（拟牛顿）代替牛顿法，避免 Hessian 求逆

### 踩坑记录

```text
坑 1：学习率设太大导致发散
结论：损失不降反升，参数震荡甚至溢出为 NaN。
原因：步长超过曲率允许范围，越过极小点来回跳。
解法：调小学习率或用学习率衰减；配合梯度裁剪防止梯度爆炸。

坑 2：特征不标准化直接上梯度下降
结论：收敛极慢，不同特征更新幅度差异巨大。
原因：尺度大的特征主导梯度，等高线呈狭长椭圆，梯度方向反复横跳。
解法：训练前做 StandardScaler 标准化（均值 0、方差 1）。

坑 3：把非凸函数当凸函数追求「全局最优」
结论：神经网络训练卡在某个局部极小，反复调参无果。
原因：非凸目标没有全局最优保证，追求全局最优是伪需求。
解法：目标改为「足够好的局部极小」，靠好的初始化 + SGD 随机性 + 正则。

坑 4：牛顿法在 Hessian 不可逆处除零
结论：迭代出现 NaN 或除零错误。
原因：Hessian 奇异或不定时 H⁻¹ 不存在，方向无定义。
解法：加阻尼（Levenberg-Marquardt 的 λI），或改用拟牛顿/L-BFGS。

坑 5：数值梯度步长 h 选太大或太小
结论：导数算不准，优化或校验结果错误。
原因：h 太大截断误差大，h 太小受浮点舍入误差主导。
解法：h 取 1e-5~1e-7，中心差分比前向差分精度高一阶。
```
