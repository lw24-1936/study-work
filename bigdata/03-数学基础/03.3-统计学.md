## 概述

统计学从数据中推断总体规律：用样本估计总体参数（估计、MLE/MAP）、用假设检验判断差异是否显著、用置信区间表达不确定性。这是数据分析师和算法工程师的基本功——A/B 实验结论、指标波动是否异常、模型参数估计都靠它。大数据让「全量计算」成为可能，但抽样、检验、区间估计仍是决策的标准语言。

```text
统计推断的主线：
抽样 -> 估计（点估计/区间估计）
     -> 假设检验（t 检验/卡方/ANOVA）
MLE/MAP -> 参数估计的理论方法
Bootstrap -> 不依赖分布的区间估计与推断
```

## 抽样

抽样是从总体中抽取部分样本用于推断。核心问题：怎么抽（随机、分层、系统、整群）、抽多少（样本量）。随机抽样保证样本有代表性，是大数定律和 CLT 应用的前提；分层抽样按子群比例抽取，提升估计精度；有偏抽样会毁掉整个推断。大数据里抽样用于快速探索、日志采样、以及无法全量计算的场景。

```text
抽样要点：
1. 简单随机抽样 —— 每个个体等概率被抽，最基础
2. 分层抽样 —— 按层（如城市、性别）比例抽，减少方差
3. 系统抽样 —— 等间隔抽取，注意周期性偏差
4. 有偏抽样 —— 抽样方式有偏，结论不可信，最要警惕
```

```python
# Python：抽样方法演示
import numpy as np

np.random.seed(42)
population = np.arange(1, 10001)   # 总体 1..10000

# 简单随机抽样（无放回）
sample = np.random.choice(population, size=100, replace=False)
print("随机抽样均值:", sample.mean(), "总体均值:", population.mean())

# 分层抽样：按奇偶分层各抽 50
even = population[population % 2 == 0]
odd = population[population % 2 == 1]
stratified = np.concatenate([
    np.random.choice(even, 50, replace=False),
    np.random.choice(odd, 50, replace=False),
])
print("分层抽样均值:", stratified.mean())
```

## 估计

估计分点估计和区间估计。点估计用统计量给出参数的单一值（如样本均值估总体均值），关注无偏性、一致性、有效性；区间估计给出一个区间（置信区间），表达不确定性。好的估计量应无偏（期望等于真值）且方差小（有效）。大数据里，指标均值、转化率都是估计量。

```text
估计要点：
1. 点估计 —— 用样本统计量估参数（样本均值、样本方差）
2. 无偏性 —— E[估计量] = 真值；样本均值无偏，样本方差除以 n-1 才无偏
3. 一致性 —— 样本增大，估计量收敛到真值
4. 区间估计 —— 置信区间表达估计的不确定性
```

```python
# Python：估计量的无偏性验证
import numpy as np

np.random.seed(42)
true_mu, true_sigma = 5.0, 2.0

# 重复抽样，看样本均值与样本方差的无偏性
mean_estimates, var_biased, var_unbiased = [], [], []
for _ in range(5000):
    s = np.random.normal(true_mu, true_sigma, 30)
    mean_estimates.append(s.mean())
    var_biased.append(s.var())                    # 除以 n
    var_unbiased.append(s.var(ddof=1))            # 除以 n-1

print("样本均值均值:", np.mean(mean_estimates), "(真值 5.0)")
print("有偏方差均值:", np.mean(var_biased), "(偏小)")
print("无偏方差均值:", np.mean(var_unbiased), "(接近 4.0)")
```

## MLE

极大似然估计（MLE）选择「使观测数据出现概率最大」的参数：θ̂ = argmax P(data|θ)。它是一致、渐近有效的估计方法，是逻辑回归、朴素贝叶斯、很多模型参数估计的理论基础。实现上常对似然取对数（log-likelihood）转成求和，再用优化方法（梯度下降）求解。

```text
MLE 要点：
1. 思想 —— 找让「观测数据最可能发生」的参数
2. 似然函数 —— L(θ) = P(data|θ)，连乘，取 log 转求和
3. 求解 —— 求导令其为 0，或数值优化（梯度下降）
4. 性质 —— 一致性、渐近正态、渐近有效
```

```python
# Python：MLE 估计正态分布参数（闭式解）+ 数值验证
import numpy as np
from scipy.optimize import minimize

np.random.seed(42)
data = np.random.normal(5.0, 2.0, 1000)

# 正态分布 MLE 闭式解：μ = 均值，σ² = 有偏方差
mu_mle = data.mean()
sigma_mle = np.sqrt(((data - mu_mle) ** 2).mean())
print("MLE μ =", mu_mle, "MLE σ =", sigma_mle)

# 数值法：负对数似然最小化
def neg_log_likelihood(params):
    mu, sigma = params
    return -np.sum(-0.5 * np.log(2 * np.pi * sigma**2) - (data - mu)**2 / (2 * sigma**2))

res = minimize(neg_log_likelihood, [0, 1], method="Nelder-Mead")
print("数值 MLE:", res.x)
```

## MAP

最大后验估计（MAP）在 MLE 基础上引入先验：θ̂ = argmax P(θ|data) = argmax P(data|θ)P(θ)。当数据少时先验起正则化作用，防止过拟合；数据多时先验影响减弱，MAP 趋近 MLE。MAP 是贝叶斯方法的点估计版本，也是 L1/L2 正则化的理论来源（高斯先验对应 L2，拉普拉斯先验对应 L1）。

```text
MAP 要点：
1. 公式 —— θ̂ = argmax P(data|θ)·P(θ)（贝叶斯定理去掉分母）
2. 与 MLE —— 多乘先验项；数据多时先验可忽略，MAP≈MLE
3. 正则化 —— 高斯先验 -> L2 正则，拉普拉斯先验 -> L1 正则
4. 应用 —— 样本少时用先验纠偏，防止过拟合
```

```python
# Python：MAP 估计——高斯先验对应 L2 正则
import numpy as np

np.random.seed(42)
# 真实均值 0.5，样本很少（5 个），先验认为均值接近 0（方差 1）
data = np.random.normal(0.5, 1.0, 5)
n = len(data)

# MAP：正态似然 + 正态先验 N(0, τ²)，闭式解
# θ_map = (Σx / σ²) / (n/σ² + 1/τ²)
sigma2, tau2 = 1.0, 1.0
theta_map = (data.sum() / sigma2) / (n / sigma2 + 1 / tau2)
print("MLE(样本均值):", data.mean())
print("MAP(带先验):", theta_map, "-> 向先验 0 收缩")
```

## 假设检验

假设检验判断「观测到的差异是真实存在还是随机波动」。流程：设原假设 H0（无差异）与备择假设 H1，选检验统计量，算 p 值，与显著性水平 α（常 0.05）比较。p < α 拒绝 H0（差异显著），否则不拒绝。两类错误：第一类（弃真，H0 真却拒绝）、第二类（存伪，H1 真却不拒绝）。A/B 实验的显著性判断就是假设检验。

```text
假设检验要点：
1. H0/H1 —— 原假设默认「无差异」，备择是「有差异」
2. p 值 —— H0 成立时，观察到当前或更极端结果的概率
3. 显著性水平 —— α=0.05，p<α 拒绝 H0
4. 两类错误 —— 第一类（误拒）、第二类（漏检），power = 1 - 第二类错误
5. 陷阱 —— p 值小不代表差异大，只代表「不太可能由随机产生」
```

```python
# Python：单样本 z 检验
import numpy as np
from scipy import stats

np.random.seed(42)
# H0: 均值 = 100；样本实际来自均值 102 的总体
sample = np.random.normal(102, 5, 200)
mu0 = 100

z = (sample.mean() - mu0) / (sample.std(ddof=1) / np.sqrt(len(sample)))
p_value = 2 * (1 - stats.norm.cdf(abs(z)))   # 双侧
alpha = 0.05
print(f"z = {z:.3f}, p = {p_value:.6f}")
print("拒绝 H0（差异显著）" if p_value < alpha else "不拒绝 H0")
```

## 置信区间

置信区间给出参数的一个区间，有 1-α 的把握包含真值（如 95% 置信区间）。它是区间估计的形式，比点估计多表达了不确定性。均值 95% 置信区间 ≈ 样本均值 ± 1.96·(σ/√n)（大样本）。宽度取决于置信水平、标准差和样本量。A/B 实验报告指标通常附置信区间。

```text
置信区间要点：
1. 定义 —— 反复抽样下，区间以 1-α 概率包含真参数
2. 均值 CI —— x̄ ± z·(σ/√n)，z=1.96（95%）
3. 影响因素 —— 置信水平越高越宽、样本越大越窄、方差越大越宽
4. 解读 —— 「95% 置信」指方法长期覆盖真值的频率，不是单次概率
```

```python
# Python：计算均值的 95% 置信区间
import numpy as np
from scipy import stats

np.random.seed(42)
sample = np.random.normal(50, 10, 400)

mean, std = sample.mean(), sample.std(ddof=1)
n = len(sample)
z = stats.norm.ppf(0.975)   # 1.96
margin = z * std / np.sqrt(n)
ci_low, ci_high = mean - margin, mean + margin
print(f"95% 置信区间: [{ci_low:.2f}, {ci_high:.2f}]")

# 或用 scipy 直接算（t 分布更严谨）
ci = stats.t.interval(0.95, df=n-1, loc=mean, scale=std/np.sqrt(n))
print("t 分布置信区间:", ci)
```

## t 检验

t 检验用于小样本（n < 30）或总体方差未知时比较均值，分单样本 t 检验（均值是否等于某值）、独立双样本 t 检验（两组均值是否不同）、配对 t 检验（同一批对象前后对比）。核心是用 t 分布（比正态更肥尾）替代正态，自由度 df = n-1。A/B 实验常用双样本 t 检验。

```text
t 检验要点：
1. 适用 —— 小样本或方差未知的均值比较
2. 类型 —— 单样本、独立双样本、配对（前后测）
3. t 分布 —— 自由度越小越肥尾，样本大时趋近正态
4. 前提 —— 近似正态、方差齐性（双样本可用 Welch 校正）
```

```python
# Python：独立双样本 t 检验
import numpy as np
from scipy import stats

np.random.seed(42)
# A 组均值 100，B 组均值 103，各 50 样本
a = np.random.normal(100, 10, 50)
b = np.random.normal(103, 10, 50)

t_stat, p_value = stats.ttest_ind(a, b)   # Welch t 检验
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")
print("两组均值差异显著" if p_value < 0.05 else "差异不显著")

# 配对 t 检验：同一批用户实验前后
before = np.random.normal(100, 10, 30)
after = before + np.random.normal(3, 2, 30)
t_stat, p_value = stats.ttest_rel(before, after)
print(f"配对 t 检验: t = {t_stat:.3f}, p = {p_value:.4f}")
```

## 卡方检验

卡方检验判断分类变量之间是否独立（或观测频数与期望频数是否一致）。构造统计量 χ² = Σ (观测-期望)²/期望，服从卡方分布。用于：独立性检验（如性别与购买是否独立）、拟合优度检验（如骰子是否均匀）。是大数据里「两个分类维度是否相关」的标准工具。

```text
卡方检验要点：
1. 用途 —— 分类变量独立性、拟合优度
2. 统计量 —— χ² = Σ(O-E)²/E，O 观测、E 期望
3. 前提 —— 期望频数不能太小（一般 ≥5）
4. 应用 —— 特征与标签相关性、漏斗各环节差异
```

```python
# Python：卡方独立性检验
import numpy as np
from scipy.stats import chi2_contingency

# 列联表：行=性别(男/女)，列=是否购买(买/没买)
observed = np.array([[80, 120],   # 男：买 80，没买 120
                     [60, 140]])  # 女：买 60，没买 140

chi2, p, dof, expected = chi2_contingency(observed)
print(f"χ² = {chi2:.3f}, p = {p:.4f}")
print("性别与购买相关（不独立）" if p < 0.05 else "性别与购买独立")
print("期望频数:\n", expected)
```

## ANOVA

方差分析（ANOVA）比较三个及以上组的均值是否有显著差异。它把总变异分解为组间变异和组内变异，构造 F 统计量 = 组间均方/组内均方。F 值大说明组间差异相对组内波动更大。单因素 ANOVA 比较一个因子的多水平；多因素 ANOVA 处理多因子。它解决「多组比较」时 t 检验逐对比较导致的误差累积问题。

```text
ANOVA 要点：
1. 用途 —— 三组及以上均值比较
2. 思想 —— 分解变异：总变异 = 组间 + 组内，F = 组间/组内
3. 前提 —— 各组正态、方差齐性、样本独立
4. 与 t 检验 —— 两组时 ANOVA 的 F 等于 t²；多组用 ANOVA 避免误差累积
```

```python
# Python：单因素 ANOVA
import numpy as np
from scipy import stats

np.random.seed(42)
# 三组数据，B 组均值明显不同
group_a = np.random.normal(100, 5, 30)
group_b = np.random.normal(108, 5, 30)
group_c = np.random.normal(101, 5, 30)

f_stat, p_value = stats.f_oneway(group_a, group_b, group_c)
print(f"F = {f_stat:.3f}, p = {p_value:.6f}")
print("至少一组均值不同" if p_value < 0.05 else "各组均值无显著差异")
```

## Bootstrap

Bootstrap 通过「有放回重采样」估计统计量的分布，不依赖正态假设。方法：从样本有放回抽 n 个（重复 B 次），每次算统计量，得到其经验分布，进而算置信区间、标准误、偏差。它适用于无闭式解、分布未知、小样本的场景，是大数据里通用且稳健的推断工具。

```text
Bootstrap 要点：
1. 思想 —— 用重采样模拟「重新抽样」的分布
2. 步骤 —— 有放回抽 n 个 -> 算统计量 -> 重复 B 次 -> 得到分布
3. 置信区间 —— 用分位数法（percentile）取 2.5%/97.5%
4. 优点 —— 不依赖分布假设，通用稳健
```

```python
# Python：Bootstrap 估计中位数的置信区间
import numpy as np

np.random.seed(42)
data = np.random.exponential(2.0, 100)   # 偏态分布，中位数无简单闭式

B = 5000
boot_medians = []
for _ in range(B):
    resample = np.random.choice(data, size=len(data), replace=True)
    boot_medians.append(np.median(resample))

boot_medians = np.array(boot_medians)
ci_low, ci_high = np.percentile(boot_medians, [2.5, 97.5])
print(f"中位数 = {np.median(data):.3f}")
print(f"Bootstrap 95% 置信区间: [{ci_low:.3f}, {ci_high:.3f}]")
print(f"Bootstrap 标准误: {boot_medians.std():.3f}")
```

## 应用场景实战

### 场景一：A/B 实验的完整显著性检验

```python
# 实验：新推荐算法 vs 旧算法，比较转化率
import numpy as np
from scipy import stats

np.random.seed(42)
# 对照组 5000 人转化 500，实验组 5000 人转化 560
n_c, x_c = 5000, 500
n_t, x_t = 5000, 560

p_c = x_c / n_c
p_t = x_t / n_t
# 合并比例与标准误
p_pool = (x_c + x_t) / (n_c + n_t)
se = np.sqrt(p_pool * (1 - p_pool) * (1/n_c + 1/n_t))
z = (p_t - p_c) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))
print(f"对照转化率 {p_c:.4f}, 实验转化率 {p_t:.4f}")
print(f"z = {z:.3f}, p = {p_value:.4f}")
print("实验显著优于对照" if p_value < 0.05 else "差异不显著")
```

### 场景二：用 Bootstrap 评估指标稳定性

```python
# 电商 GMV 指标的稳定性评估：不假设分布，用 Bootstrap 算置信区间
import numpy as np

np.random.seed(42)
# 30 天的每日 GMV（万元），分布偏态
gmv = np.random.exponential(100, 30)

B = 5000
boot_means = [np.random.choice(gmv, len(gmv), replace=True).mean() for _ in range(B)]
ci = np.percentile(boot_means, [2.5, 97.5])
print(f"日均 GMV = {gmv.mean():.1f} 万")
print(f"Bootstrap 95% CI: [{ci[0]:.1f}, {ci[1]:.1f}] 万")
# 用于判断本月 GMV 是否真的「涨了」，而非随机波动
```

## 最佳实践与踩坑记录

### 最佳实践

1. 抽样要随机，警惕任何形式的有偏抽样，样本代表性是推断的前提
2. 报告估计结果附置信区间，别只给点估计
3. A/B 实验用双样本检验，样本量提前用 power 分析确定
4. 多组比较用 ANOVA，别用多次 t 检验（误差累积）
5. 卡方检验注意期望频数 ≥5，否则用 Fisher 精确检验
6. 分布未知或样本小时用 Bootstrap，通用且稳健
7. 理解 p 值的真实含义：p 小不等于效应大，还要看效应量和实际意义

### 踩坑记录

```text
坑 1：把「不拒绝 H0」理解成「H0 成立」
结论：p>0.05 就断言「无差异」，结论可能错误。
原因：不拒绝只说明证据不足，不等于原假设为真（可能是样本不够）。
解法：表述为「未发现显著差异」，并结合 power 分析判断样本量。

坑 2：多组两两 t 检验导致假阳性
结论：三组以上两两比较，误报显著差异的概率大增。
原因：每次检验都有 α 的误报率，多次比较误差累积。
解法：用 ANOVA 整体检验，或事后多重比较校正（Bonferroni）。

坑 3：样本方差除以 n 导致低估
结论：用样本估计总体方差系统性偏小。
原因：样本均值「吃掉」一个自由度，除以 n 是有偏估计。
解法：样本方差除以 n-1（ddof=1），得到无偏估计。

坑 4：置信区间解读成「真值有 95% 概率落在这个区间」
结论：对置信区间的概率解释错误。
原因：真值是固定常数，不是随机的；随机的是区间。
解法：正确表述为「重复抽样下，95% 的区间会包含真值」。
```
