## 概述

信息论（Information Theory）由香农在 1948 年奠基，用「比特」量化信息的不确定性与传递。它回答几个核心问题：一个随机变量携带多少信息（熵）、两个分布有多接近（KL 散度/交叉熵）、两个变量共享多少信息（互信息）。在大数据与机器学习里，信息论是决策树分裂、模型损失函数（交叉熵）、特征选择（信息增益/互信息）的数学根基。

```text
信息论核心量之间的关系：
1. 熵 H(X)        —— 单个变量「平均要多少比特才能描述」，不确定性度量
2. 交叉熵 H(P,Q)  —— 用分布 Q 去编码真实分布 P 的代价，模型损失函数
3. KL 散度 D(P||Q) = H(P,Q) - H(P) —— 两个分布的「距离」（非对称）
4. 互信息 I(X;Y)  —— 一个变量能减少另一个变量多少不确定性
5. 信息增益 Gain = H(Y) - H(Y|X) —— 知道 X 后 Y 熵的下降量，即 I(X;Y)
```

```python
import math

def entropy(probs):
    """输入概率分布（和为 1），返回香农熵（单位：比特）。"""
    return -sum(p * math.log2(p) for p in probs if p > 0)

# 均匀分布熵最大，确定性分布熵为 0
print(entropy([0.5, 0.5]))      # 1.0   —— 一枚公平硬币
print(entropy([0.9, 0.1]))      # 0.469 —— 偏斜硬币，更确定
print(entropy([1.0, 0.0]))      # 0.0   —— 完全确定
```

## 熵

熵（Entropy）度量一个随机变量的平均不确定度，单位是比特。直觉上：越不确定的事件（如掷骰子）熵越大，越确定的事件熵越小。熵是编码理论的基础——它给出无损编码该随机变量的理论下限（平均码长 ≥ 熵）。在数据压缩、随机数质量评估、特征分裂中都用熵作为「混乱程度」的标尺。

```text
熵的要点：
1. 公式 H(X) = -Σ p(x) log2 p(x)，p(x) 是各取值概率
2. 均匀分布熵最大（log2 n，n 为取值个数）
3. 退化分布（某值概率为 1）熵为 0，完全确定
4. 熵只依赖概率分布，与取值本身无关
5. 联合熵 H(X,Y) = -Σ p(x,y) log2 p(x,y)，条件熵 H(Y|X) = H(X,Y) - H(X)
```

```python
import math

def joint_entropy(pairs):
    """pairs: [(x, y, p_xy), ...]，返回联合熵。"""
    return -sum(p * math.log2(p) for _, _, p in pairs if p > 0)

def conditional_entropy(pairs, x_entropy):
    """H(Y|X) = H(X,Y) - H(X)。"""
    return joint_entropy(pairs) - x_entropy

# 天气(X) 与 是否带伞(Y) 的联合分布
# X: 晴(0)/雨(1)，Y: 不带伞(0)/带伞(1)
pairs = [
    (0, 0, 0.7),   # 晴且不带伞
    (0, 1, 0.05),  # 晴且带伞
    (1, 0, 0.05),  # 雨且不带伞
    (1, 1, 0.2),   # 雨且带伞
]
HX = entropy([0.75, 0.25])       # 天气熵
print("H(X) =", HX)
print("H(X,Y) =", joint_entropy(pairs))
print("H(Y|X) =", conditional_entropy(pairs, HX))
```

## 交叉熵

交叉熵（Cross Entropy）H(P,Q) = -Σ p(x) log2 q(x)，衡量「用分布 Q 去编码真实分布 P」所需的平均比特数。P 是真实标签分布，Q 是模型预测分布。交叉熵越小，说明 Q 越接近 P。在机器学习中，交叉熵损失（Cross-Entropy Loss）是分类任务的标准损失函数，训练就是最小化交叉熵。

```text
交叉熵要点：
1. H(P,Q) = -Σ p(x) log2 q(x)，注意 log 里是 q，权重是 p
2. 交叉熵 ≥ 熵：H(P,Q) ≥ H(P)，等号当且仅当 Q = P
3. 分类损失 —— 多分类用 softmax + 交叉熵，二分类用 binary cross-entropy
4. 与 KL 散度的关系 —— H(P,Q) = H(P) + D(P||Q)
```

```python
import math

def cross_entropy(p, q):
    """p 真实分布，q 预测分布，返回交叉熵（自然对数）。"""
    return -sum(pi * math.log(qi) for pi, qi in zip(p, q) if pi > 0)

# 三分类：真实标签是类别 0（one-hot），模型输出概率
p = [1.0, 0.0, 0.0]
q_good = [0.9, 0.05, 0.05]   # 预测接近真实
q_bad  = [0.3, 0.4, 0.3]     # 预测偏离真实

print("交叉熵(好预测) =", round(cross_entropy(p, q_good), 4))  # 0.1054
print("交叉熵(差预测) =", round(cross_entropy(p, q_bad), 4))   # 1.2040

# 二分类交叉熵（标签 y 为 0/1）
def binary_cross_entropy(y, p):
    return -(y * math.log(p) + (1 - y) * math.log(1 - p))

print("BCE(标签1, 预测0.9) =", round(binary_cross_entropy(1, 0.9), 4))  # 0.1054
```

## KL 散度

KL 散度（Kullback-Leibler Divergence）D(P||Q) = Σ p(x) log2(p(x)/q(x))，度量分布 Q 相对真实分布 P 的「额外信息代价」。它是非对称的（D(P||Q) ≠ D(Q||P)），也不满足三角不等式，因此不是严格的距离，但常被当作「分布差异」使用。变分推断、生成模型（VAE/GAN）的损失、以及「用 Q 逼近 P」的优化目标都建立在 KL 散度上。

```text
KL 散度要点：
1. D(P||Q) = Σ p(x) log2(p(x)/q(x))，非负，D=0 当且仅当 P=Q
2. 非对称 —— 前向 KL 与反向 KL 优化行为不同（VAE 常用反向 KL）
3. D(P||Q) = H(P,Q) - H(P)，即「交叉熵减熵」
4. 计算时 q(x)=0 而 p(x)>0 会导致 log(0) → 无穷，需加平滑（epsilon）
```

```python
import math

def kl_divergence(p, q):
    """D(P||Q)，注意参数顺序：第一个是真实分布 P。"""
    return sum(pi * math.log2(pi / qi)
               for pi, qi in zip(p, q) if pi > 0)

p = [0.5, 0.5]      # 真实分布
q = [0.9, 0.1]      # 近似分布

print("D(P||Q) =", round(kl_divergence(p, q), 4))   # 0.5310
print("D(Q||P) =", round(kl_divergence(q, p), 4))   # 0.7369 —— 非对称！

# 加平滑避免 qi=0 导致除零
def kl_smoothed(p, q, eps=1e-9):
    q = [max(qi, eps) for qi in q]
    return sum(pi * math.log2(pi / qi) for pi, qi in zip(p, q) if pi > 0)
```

## 互信息

互信息（Mutual Information）I(X;Y) 度量两个随机变量共享的信息量，即「知道 X 能减少多少关于 Y 的不确定性」。I(X;Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)。互信息对称（I(X;Y) = I(Y;X)）且非负，等于 0 当且仅当 X 与 Y 独立。在特征选择、聚类评估（NMI）、因果初筛中，互信息是比相关系数更通用的依赖度量——它能捕捉非线性关系。

```text
互信息要点：
1. I(X;Y) = H(Y) - H(Y|X)，对称且非负
2. 与独立性 —— I=0 当且仅当 X、Y 独立
3. 比相关系数强 —— 能度量非线性依赖，但计算需要估计联合分布
4. 归一化互信息 NMI = 2I(X;Y)/(H(X)+H(Y))，常用于聚类质量评估
```

```python
import math

def mutual_information(joint):
    """joint: {(x, y): p_xy}，返回 I(X;Y)。"""
    px = {}
    py = {}
    for (x, y), pxy in joint.items():
        px[x] = px.get(x, 0) + pxy
        py[y] = py.get(y, 0) + pxy
    mi = 0.0
    for (x, y), pxy in joint.items():
        if pxy > 0:
            mi += pxy * math.log2(pxy / (px[x] * py[y]))
    return mi

# 两个独立骰子的联合分布 → 互信息应为 0
joint_indep = {(i, j): 1/36 for i in range(1, 7) for j in range(1, 7)}
print("独立变量互信息 =", mutual_information(joint_indep))  # ~0.0

# 完全相关：Y = X（两骰子同值）
joint_dep = {(i, i): 1/6 for i in range(1, 7)}
print("完全相关互信息 =", round(mutual_information(joint_dep), 4))  # log2(6) ≈ 2.585
```

## 信息增益

信息增益（Information Gain）是决策树选择分裂特征的准则：Gain(Y, X) = H(Y) - H(Y|X)，即按特征 X 分裂后，目标变量 Y 的熵减少了多少。信息增益越大，说明该特征对预测 Y 越有用。ID3 算法用它挑分裂点；C4.5 用信息增益率（除以特征自身熵）修正「偏向取值多的特征」的缺陷。

```text
信息增益要点：
1. Gain(Y,X) = H(Y) - H(Y|X)，本质上就是互信息 I(X;Y)
2. 决策树 —— 每次选信息增益最大的特征做分裂
3. 偏向问题 —— 取值多的特征天然增益大，C4.5 用增益率修正
4. 连续特征 —— 先排序再找使增益最大的切分点
```

```python
import math

def info_gain(y_entropy, branches):
    """branches: [(weight, branch_entropy)]，weight 为分支样本占比。"""
    cond_entropy = sum(w * h for w, h in branches)
    return y_entropy - cond_entropy

# 例子：预测「是否购买」，候选特征「是否点击广告」
# 总体：买(6) / 不买(4) → 熵
p_total = [0.6, 0.4]
H_total = entropy(p_total)
print("H(是否购买) =", round(H_total, 4))  # 0.9710

# 按「是否点击」分裂：点击的样本里买(5)不买(1)；未点击里买(1)不买(3)
H_click   = entropy([5/6, 1/6])     # 点击分支熵
H_noclick = entropy([1/4, 3/4])     # 未点击分支熵
gain = info_gain(H_total, [(0.6, H_click), (0.4, H_noclick)])
print("按「是否点击」分裂的信息增益 =", round(gain, 4))
```

## 应用场景实战

### 场景一：用信息增益做特征选择

```python
import math
from collections import Counter

def entropy_of(labels):
    n = len(labels)
    return -sum((c / n) * math.log2(c / n) for c in Counter(labels).values())

def feature_info_gain(feature_values, labels):
    """计算某个离散特征的增益：Gain = H(Y) - Σ (|Dv|/|D|) H(Dv)。"""
    n = len(labels)
    total_entropy = entropy_of(labels)
    # 按特征取值分组
    groups = {}
    for v, y in zip(feature_values, labels):
        groups.setdefault(v, []).append(y)
    cond = 0.0
    for v, ys in groups.items():
        cond += (len(ys) / n) * entropy_of(ys)
    return total_entropy - cond

# 垃圾邮件分类：候选特征「含免费」「含链接」「含感叹号」
labels  = ['spam', 'ham', 'spam', 'ham', 'spam', 'ham', 'spam', 'spam']
f_free  = [1, 0, 1, 0, 1, 0, 1, 1]      # 是否含「免费」
f_link  = [1, 1, 1, 1, 1, 0, 1, 1]      # 是否含链接
f_excl  = [1, 0, 0, 1, 0, 1, 0, 0]      # 是否含感叹号

for name, f in [("含免费", f_free), ("含链接", f_link), ("含感叹号", f_excl)]:
    print(f"{name} 的信息增益 = {feature_info_gain(f, labels):.4f}")
# 增益最大的特征最适合做根节点分裂
```

### 场景二：交叉熵损失监督训练一个逻辑回归

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

def bce_loss(w, xs, ys):
    """逻辑回归的交叉熵损失，w 为权重，xs/ys 为样本与标签。"""
    total = 0.0
    for x, y in zip(xs, ys):
        p = sigmoid(w * x)
        p = max(min(p, 1 - 1e-9), 1e-9)   # 防 log(0)
        total += -(y * math.log(p) + (1 - y) * math.log(1 - p))
    return total / len(xs)

# 用梯度下降最小化交叉熵（一轮演示）
w = 0.0
xs = [1, 2, 3, 4, 5]
ys = [0, 0, 1, 1, 1]
lr = 0.1
for _ in range(3):
    grad = sum((sigmoid(w * x) - y) * x for x, y in zip(xs, ys)) / len(xs)
    w -= lr * grad
    print(f"w={w:.3f}, loss={bce_loss(w, xs, ys):.4f}")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 分类模型损失优先用交叉熵而非均方误差，收敛更快且与 softmax 输出天然匹配
2. 计算熵/散度时对概率做平滑（加 epsilon 或用 max(p, eps)），避免 log(0) 得 NaN
3. KL 散度注意参数顺序，D(P||Q) 中 P 是真实分布，写反会得到错误优化目标
4. 特征选择时，离散特征用信息增益，连续特征先分桶或直接估互信息
5. 评估聚类质量用归一化互信息（NMI），它惩罚「聚类数过多」的作弊
6. 熵的单位（bit 用 log2、nat 用 ln）全链路保持一致，别混用

### 踩坑记录

```text
坑 1：KL 散度把参数顺序写反
结论：优化方向完全错误，模型学出来的分布偏离真实分布。
原因：D(P||Q) 非对称，把预测分布当成 P、真实分布当成 Q 就优化反了。
解法：记住第一个参数是真实/目标分布 P，第二个是要优化的近似分布 Q。

坑 2：log(0) 导致 NaN
结论：损失函数输出 NaN，训练直接崩溃。
原因：预测概率为 0 或 1 时 log 无定义，数值下溢也会产生 0。
解法：对概率做裁剪 max(min(p, 1-eps), eps)，或用 log_softmax 稳定计算。

坑 3：用熵评估「随机性」但忽略分布形状
结论：两个熵相同的分布可能完全不同，误判数据特征。
原因：熵只依赖概率集合，不依赖取值顺序，多个分布可同熵。
解法：熵只能衡量「不确定度」，比较分布差异请用 KL 散度或 JS 散度。

坑 4：把互信息当相关性用却忽略样本量
结论：小样本上互信息估计严重偏大，误报「强依赖」。
原因：有限样本估计联合分布有偏差，稀疏格子导致互信息高估。
解法：样本量不足时用互信息的校正估计，或改用相关系数做初筛。
```
