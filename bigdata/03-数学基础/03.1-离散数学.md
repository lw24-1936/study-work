## 概述

离散数学研究「离散的、不连续」的数学结构，是计算机科学（也是大数据算法）的理论地基。集合、逻辑、关系、函数、组合、递推、图论这些概念，直接对应数据结构的抽象、SQL 的关系模型、算法的复杂度分析、图计算和递归算法。理解离散数学，才能看懂论文里的形式化定义，才能严谨地设计算法。

```text
离散数学与大数据算法的对应：
1. 集合 -> 去重、集合运算（UNION/INTERSECT）、Bloom Filter
2. 关系 -> SQL 的关系模型、JOIN、外键
3. 图论 -> 图计算、社交网络分析、依赖调度 DAG
4. 递推 -> 递归算法、动态规划、Master 定理
```

## 集合

集合是无序、不重复的元素整体，是离散数学最基础的结构。核心概念：元素与集合的属于关系（∈）、子集（⊆）、并集（∪）、交集（∩）、差集、补集、幂集（所有子集的集合）。集合运算是 SQL 的 UNION/INTERSECT/EXCEPT 的理论来源，也是去重、基数估计（见 17 章）的基础。

```text
集合的定义与运算：
1. 属于 —— a ∈ A 表示 a 是集合 A 的元素
2. 子集 —— A ⊆ B 当且仅当 A 的每个元素都在 B 中
3. 并/交/差 —— A ∪ B、A ∩ B、A - B（在 A 不在 B）
4. 幂集 —— P(A) = A 的所有子集，|P(A)| = 2^|A|
```

```python
# Python：集合运算
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print("并集:", A | B)          # {1,2,3,4,5,6}
print("交集:", A & B)          # {3,4}
print("差集:", A - B)          # {1,2}
print("对称差:", A ^ B)        # {1,2,5,6}
print("A 是否子集:", A <= {1, 2, 3, 4, 5})  # True

# 幂集（所有子集）
from itertools import chain, combinations
def powerset(s):
    return chain.from_iterable(combinations(s, r) for r in range(len(s) + 1))
print("幂集大小:", len(list(powerset(A))))  # 2^4 = 16
```

## 逻辑

命题逻辑研究「命题的真假与推理」。命题是能判断真假的陈述句，用逻辑联结词组合：与（∧）、或（∨）、非（¬）、蕴含（→）、等价（↔）。真值表穷举所有取值组合判断复合命题真假。逻辑是程序条件判断、SQL 的 WHERE 条件、以及算法正确性证明的基础。

```text
命题逻辑要点：
1. 联结词 —— ¬非、∧与、∨或、→蕴含（P→Q 等价于 ¬P∨Q）、↔等价
2. 真值表 —— 枚举所有真假组合，判断复合命题
3. 德摩根律 —— ¬(P∧Q) = ¬P∨¬Q，¬(P∨Q) = ¬P∧¬Q
4. 应用 —— WHERE 条件化简、布尔表达式优化、程序断言
```

```python
# Python：真值表验证德摩根律
def implies(p, q):
    return (not p) or q

# 枚举 P、Q 的所有真假组合
for p in (True, False):
    for q in (True, False):
        lhs = not (p and q)          # ¬(P∧Q)
        rhs = (not p) or (not q)     # ¬P∨¬Q
        assert lhs == rhs, "德摩根律不成立！"
print("德摩根律对 P、Q 所有取值均成立")

# 蕴含等价：P→Q == ¬P∨Q
for p in (True, False):
    for q in (True, False):
        assert implies(p, q) == ((not p) or q)
print("蕴含等价 ¬P∨Q 成立")
```

## 关系

关系是集合之间的关联——二元关系 R 是 A×B 的子集，即「满足某种联系的有序对集合」。关系有自反、对称、传递等性质；等价关系（自反+对称+传递）把集合划分成等价类。SQL 的表连接、外键引用、用户关注关系，本质都是关系。理解关系是理解关系模型（见 05 章）的理论前提。

```text
关系要点：
1. 二元关系 —— R ⊆ A×B，即有序对 (a, b) 的集合
2. 性质 —— 自反（aRa）、对称（aRb→bRa）、传递（aRb∧bRc→aRc）
3. 等价关系 —— 同时满足自反/对称/传递，把集合分成等价类（划分）
4. 应用 —— JOIN 是关系的组合，外键是关系约束，图是关系的可视化
```

```python
# Python：判断关系性质
def is_reflexive(A, R):
    return all((a, a) in R for a in A)

def is_symmetric(R):
    return all((b, a) in R for (a, b) in R)

def is_transitive(R):
    pairs = set(R)
    return all((a, c) in pairs for (a, b) in R for (c, d) in R if b == c)

A = {1, 2, 3}
# 等价关系：模 3 同余
R = {(a, b) for a in A for b in A if a % 3 == b % 3}
print("自反:", is_reflexive(A, R), "对称:", is_symmetric(R), "传递:", is_transitive(R))
```

## 函数

函数是特殊的关系——每个输入恰好对应一个输出（f: A → B，A 中每个元素在 B 中有唯一像）。核心概念：定义域、值域、单射（一对一）、满射（值域覆盖 B）、双射（既单射又满射）。函数是「确定性映射」的抽象，对应程序的纯函数、哈希函数、映射表（Map）。

```text
函数要点：
1. 定义 —— 每个 x∈A 唯一对应 f(x)∈B，是「单值」关系
2. 单射 —— 不同输入输出不同（可逆）；满射 —— 每个 y 都有原像；双射 —— 两者兼备
3. 复合 —— (g∘f)(x) = g(f(x))，对应函数嵌套调用
4. 应用 —— 哈希函数、映射/字典、UDF、纯函数
```

```python
# Python：函数与性质
def f(x):
    return x * 2   # 偶数映射，单射

def g(x):
    return x % 3   # 取模，满射到 {0,1,2} 但不是单射

# 判断单射（在有限定义域上）
def is_injective(func, domain):
    return len({func(x) for x in domain}) == len(domain)

print("f 是否单射:", is_injective(f, range(10)))  # True
print("g 是否单射:", is_injective(g, range(10)))  # False

# 复合函数
h = lambda x: g(f(x))
print("复合 h(5) =", h(5))   # (5*2) % 3 = 1
```

## 组合

组合数学研究「数数」——有多少种排列、组合、选择方式。核心：排列 P(n,k)、组合 C(n,k)、乘法原理、加法原理、容斥原理。大数据里，组合用于估算搜索空间、采样方案、A/B 实验的分组数、以及「有多少种可能的 Top-K 组合」这类问题。

```text
组合要点：
1. 排列 —— P(n,k) = n!/(n-k)!，顺序有关
2. 组合 —— C(n,k) = n!/(k!(n-k)!)，顺序无关
3. 乘法原理 —— 分步选择相乘；加法原理 —— 分类选择相加
4. 容斥原理 —— |A∪B| = |A| + |B| - |A∩B|，去重计数的基础
```

```python
# Python：排列组合与容斥
import math
from itertools import permutations, combinations

n, k = 5, 3
print("P(5,3) =", math.perm(n, k))               # 60
print("C(5,3) =", math.comb(n, k))               # 10
print("排列数验证:", len(list(permutations(range(n), k))))
print("组合数验证:", len(list(combinations(range(n), k))))

# 容斥原理：|A∪B| = |A| + |B| - |A∩B|
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
print("|A∪B| =", len(A | B), "容斥结果 =", len(A) + len(B) - len(A & B))
```

## 递推

递推关系用前面的项定义后面的项（如斐波那契 F(n) = F(n-1) + F(n-2)）。它是递归算法和动态规划的理论基础。求解递推的复杂度用 Master 定理（T(n) = aT(n/b) + f(n) 的渐进界）。大数据里，递归 CTE、递归下降解析、分治算法都依赖递推。递推与分治是 04 章算法的基础。

```text
递推要点：
1. 递推式 —— 用前项定义后项，需初始条件（base case）
2. 斐波那契 —— F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)
3. Master 定理 —— T(n)=aT(n/b)+f(n) 的渐进复杂度判定
4. 应用 —— 动态规划、递归算法、递归 CTE（SQL）
```

```python
# Python：递推的三种实现与复杂度
import sys
sys.setrecursionlimit(10000)

# 1. 朴素递归（指数级 O(2^n)）
def fib_rec(n):
    if n <= 1:
        return n
    return fib_rec(n - 1) + fib_rec(n - 2)

# 2. 记忆化（O(n)）
from functools import lru_cache
@lru_cache(maxsize=None)
def fib_memo(n):
    if n <= 1:
        return n
    return fib_memo(n - 1) + fib_memo(n - 2)

# 3. 迭代（O(n)，O(1) 空间）
def fib_iter(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print("fib(20) =", fib_memo(20), fib_iter(20))
```

## 图论

图 G = (V, E) 由顶点集 V 和边集 E 组成，是关系最直观的表示。概念：有向/无向图、路径、环、连通性、度、树（无环连通图）、二分图。图算法（遍历、最短路径、最小生成树、拓扑排序、PageRank）是大数据图计算（Spark GraphX、图数据库）的理论基础。DAG（有向无环图）直接对应调度依赖。

```text
图论要点：
1. 表示 —— 邻接矩阵（O(V²) 空间）、邻接表（O(V+E) 空间）
2. 度 —— 顶点的边数，有向图分入度/出度
3. 树 —— 无环连通图，n 个顶点 n-1 条边
4. DAG —— 有向无环图，拓扑排序，对应任务调度依赖
5. 应用 —— 社交网络、最短路径、PageRank、依赖调度
```

```python
# Python：邻接表表示 + BFS/DFS 遍历
from collections import deque

graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D', 'E'],
    'D': ['E'],
    'E': [],
}

def bfs(start):
    visited, q = {start}, deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                q.append(nxt)
    return order

def dfs(node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for nxt in graph[node]:
        if nxt not in visited:
            dfs(nxt, visited)
    return visited

print("BFS:", bfs('A'))       # A B C D E
print("DFS:", dfs('A'))       # 深度优先顺序
```

## 证明

数学证明是「从公理/已知结论严谨推导新结论」的过程。常用方法：直接证明、反证法（假设结论为假推出矛盾）、数学归纳法（证明 base case 和归纳步）、构造性证明（构造出对象）。算法正确性、复杂度下界、系统性质（一致性、活性）的论证都依赖证明思维。大数据工程师读论文、写算法论证时离不开它。

```text
证明方法：
1. 直接证明 —— 从条件出发，逻辑推导到结论
2. 反证法 —— 假设结论不成立，推出矛盾，故结论成立
3. 数学归纳法 —— 证 P(1) 成立 + P(k)→P(k+1)，则对一切 n 成立
4. 构造法 —— 构造一个满足条件的对象，直接证明存在性
```

```text
归纳法证明示例：1 + 2 + ... + n = n(n+1)/2
Base case：n=1 时，左边=1，右边=1*2/2=1，成立
归纳步：假设 n=k 成立，即 1+...+k = k(k+1)/2
        则 n=k+1 时：1+...+k+(k+1) = k(k+1)/2 + (k+1)
        = (k+1)(k/2 + 1) = (k+1)(k+2)/2，结论对 k+1 成立
故对一切正整数 n 成立。
```

```python
# Python：验证求和公式对前 n 项都成立（数值验证归纳结论）
def verify_sum_formula(n):
    for k in range(1, n + 1):
        lhs = sum(range(1, k + 1))
        rhs = k * (k + 1) // 2
        assert lhs == rhs, f"n={k} 时不成立"
    return True

print("求和公式对 1..100 全部成立:", verify_sum_formula(100))
```

## 应用场景实战

### 场景一：用图论做任务依赖的拓扑排序（调度器核心）

```python
# 拓扑排序：调度 DAG，判断依赖是否成环
from collections import deque, defaultdict

def topo_sort(tasks, dependencies):
    """tasks: 任务列表; dependencies: [(前置, 后置)] 列表"""
    indegree = {t: 0 for t in tasks}
    adj = defaultdict(list)
    for u, v in dependencies:
        adj[u].append(v)
        indegree[v] += 1

    q = deque([t for t in tasks if indegree[t] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                q.append(v)

    if len(order) != len(tasks):
        raise ValueError("依赖成环，无法拓扑排序")
    return order

tasks = ["ods", "dwd", "dws", "ads"]
deps = [("ods", "dwd"), ("dwd", "dws"), ("dws", "ads")]
print("调度顺序:", topo_sort(tasks, deps))  # ods dwd dws ads
```

### 场景二：用集合与容斥做多条件的去重计数

```python
# 统计「点击或下单」的去重用户数（容斥去重）
clicked = {1, 2, 3, 4, 5}
ordered = {4, 5, 6, 7}

# 并集（点击或下单）去重用户
union = clicked | ordered
print("点击或下单去重用户:", len(union))

# 交集（既点击又下单）用户
both = clicked & ordered
print("既点击又下单用户:", len(both))

# 容斥验证：|A∪B| = |A| + |B| - |A∩B|
assert len(union) == len(clicked) + len(ordered) - len(both)
print("容斥原理验证通过")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 设计算法前先想清楚数据结构对应的离散结构（集合/关系/图）
2. 递推问题优先记忆化或迭代，避免朴素递归的指数爆炸
3. 去重计数先想到容斥与集合运算，别重复计算
4. 用图表示依赖关系，拓扑排序能提前发现依赖成环
5. 判断关系性质（自反/对称/传递）写测试，等价类划分常用于分治
6. 读论文遇到形式化定义，回归离散数学的集合/逻辑/关系语言
7. 递归算法先写清 base case 和递推关系，再动手编码

### 踩坑记录

```text
坑 1：朴素递归算斐波那契导致指数级耗时
结论：fib(40) 要算几十亿次，程序卡死。
原因：无记忆化，大量子问题重复计算，复杂度 O(2^n)。
解法：记忆化递归或迭代，降到 O(n)。

坑 2：图遍历忘记标记访问导致死循环
结论：有环的图用 DFS 无限递归，栈溢出。
原因：只沿边遍历不记录 visited，在环上打转。
解法：维护 visited 集合，入队/入栈前检查是否访问过。

坑 3：依赖调度未做环检测导致任务卡住
结论：工作流永远跑不完，卡在某个节点。
原因：DAG 存在环，拓扑排序无法完成，调度器死等。
解法：拓扑排序前检测环，发现环直接报错并定位依赖。

坑 4：把「关系」理解成「集合里的元素」混淆概念
结论：建模时把关系当集合元素，导致数据结构设计错误。
原因：未区分「元素属于集合」与「元素对构成关系」两个层次。
解法：明确 R ⊆ A×B 是「有序对集合」，用集合/表结构分别表达。
```
