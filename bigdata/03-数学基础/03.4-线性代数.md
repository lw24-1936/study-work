## 概述

线性代数是机器学习和数据分析的数学语言：数据是矩阵、特征是向量、模型是线性变换。向量与矩阵运算、秩、特征值、正交、QR 分解、SVD、PCA，这些概念贯穿推荐系统（矩阵分解）、降维、图计算、深度学习（权重矩阵）。大数据里的协同过滤、PCA 降维、SVD 压缩都直接建立在线性代数之上。

```text
线性代数的应用映射：
1. 向量 -> 特征向量、词向量、Embedding
2. 矩阵 -> 数据表、权重矩阵、协方差矩阵
3. 特征值/SVD -> 主成分、低秩近似、推荐系统
4. 正交 -> 基变换、QR、Gram-Schmidt
```

## 向量

向量是有方向和大小的量，可看作有序数组（特征向量）。核心运算：加法（对应分量相加）、数乘、点积（内积，衡量方向相似度）、范数（长度）。点积是相似度计算（余弦相似度）的基础，向量空间是线性代数的基本舞台。大数据里，用户/物品特征、词嵌入都是向量。

```text
向量要点：
1. 表示 —— v = (v1, v2, ..., vn)，n 维特征向量
2. 点积 —— u·v = Σ ui·vi，几何上是 |u||v|cosθ
3. 范数 —— ||v||2 = √(Σvi²)，向量的长度
4. 余弦相似度 —— cosθ = u·v/(|u||v|)，度量方向一致性
```

```python
# Python/NumPy：向量运算
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

print("加法:", u + v)
print("数乘:", 2 * u)
print("点积:", np.dot(u, v))          # 32
print("L2 范数:", np.linalg.norm(u))  # sqrt(14)
# 余弦相似度
cos = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
print("余弦相似度:", cos)
```

## 矩阵

矩阵是二维数组，是线性变换的表示，也是数据的自然容器（行=样本，列=特征）。核心运算：矩阵乘法（对应线性变换复合）、转置、逆、行列式。矩阵乘法不满足交换律（AB ≠ BA）。大数据里，特征矩阵、权重矩阵、协方差矩阵、邻接矩阵都是矩阵；矩阵乘法是神经网络前向传播的核心。

```text
矩阵要点：
1. 乘法 —— (AB)[i,j] = Σ A[i,k]·B[k,j]，要求 A 列数 = B 行数
2. 转置 —— Aᵀ 行列互换；逆 —— A⁻¹ 满足 AA⁻¹ = I
3. 非交换 —— AB ≠ BA，矩阵乘法顺序重要
4. 应用 —— 特征矩阵、权重矩阵、线性变换、图邻接矩阵
```

```python
# Python/NumPy：矩阵运算
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("矩阵乘法:\n", A @ B)
print("转置:\n", A.T)
print("逆矩阵:\n", np.linalg.inv(A))
print("行列式:", np.linalg.det(A))

# 验证 AB ≠ BA
print("AB == BA ?", np.array_equal(A @ B, B @ A))
```

## 秩

矩阵的秩是「线性无关的行（或列）的最大数目」，衡量矩阵包含的独立信息量。满秩矩阵可逆，秩小于行列数说明存在线性相关（冗余）。秩决定线性方程组解的结构，也是低秩近似的理论基础——用秩 r 的矩阵逼近原矩阵可以压缩数据。SVD/PCA 的核心就是做低秩近似。

```text
秩的要点：
1. 定义 —— 最大线性无关行/列数，rank(A) ≤ min(m, n)
2. 满秩 —— rank = min(m,n)，可逆（方阵）
3. 低秩 —— 存在冗余，可压缩；rank(A+B) ≤ rank(A)+rank(B)
4. 应用 —— 低秩近似、矩阵补全（推荐系统）、数据压缩
```

```python
# Python/NumPy：秩的计算
import numpy as np

A = np.array([[1, 2, 3],
              [2, 4, 6],   # 第 2 行 = 第 1 行 × 2
              [0, 1, 1]])

print("矩阵 A:\n", A)
print("秩:", np.linalg.matrix_rank(A))   # 2（第 2 行冗余）

# 满秩矩阵
B = np.random.rand(3, 3)
print("随机矩阵秩:", np.linalg.matrix_rank(B))   # 3（几乎必然满秩）
```

## 特征值

特征值与特征向量满足 Av = λv——矩阵 A 作用在特征向量 v 上只缩放不改变方向，缩放因子就是特征值 λ。特征值描述线性变换在特征方向上的伸缩，是分析矩阵性质（稳定性、正定性、主成分）的关键。特征分解 A = QΛQ⁻¹（对角化），是 PCA、谱聚类、PageRank 的基础。

```text
特征值要点：
1. 定义 —— Av = λv，v 是特征向量，λ 是特征值
2. 特征分解 —— A = QΛQ⁻¹，Λ 是对角特征值矩阵
3. 意义 —— 特征值表示变换在特征方向的缩放
4. 应用 —— PCA、谱聚类、PageRank、稳定性分析
```

```python
# Python/NumPy：特征值分解
import numpy as np

A = np.array([[2, 1],
              [1, 2]])

eigenvalues, eigenvectors = np.linalg.eig(A)
print("特征值:", eigenvalues)          # [3, 1]
print("特征向量:\n", eigenvectors)

# 验证 Av = λv
for i in range(len(eigenvalues)):
    lhs = A @ eigenvectors[:, i]
    rhs = eigenvalues[i] * eigenvectors[:, i]
    print(f"验证特征值 {eigenvalues[i]}:", np.allclose(lhs, rhs))
```

## 正交

正交向量是点积为零的向量（夹角 90°），正交矩阵是各列（行）互相正交且单位长度的矩阵，满足 QᵀQ = I（Q⁻¹ = Qᵀ）。正交基让坐标表示简洁，正交变换保长度和角度（旋转、反射）。Gram-Schmidt 过程把任意基转成正交基，QR 分解就基于它。大数据里正交用于基变换、白化、以及稳定的数值算法。

```text
正交要点：
1. 正交向量 —— u·v = 0，互相垂直
2. 正交矩阵 —— QᵀQ = I，列向量构成标准正交基
3. 性质 —— 正交变换保范数（||Qx|| = ||x||），数值稳定
4. Gram-Schmidt —— 把线性无关向量组正交化
```

```python
# Python/NumPy：正交性验证与 Gram-Schmidt
import numpy as np

# 验证旋转矩阵是正交矩阵
theta = np.pi / 4
Q = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print("QᵀQ == I ?", np.allclose(Q.T @ Q, np.eye(2)))
print("保范数:", np.linalg.norm(Q @ np.array([3, 4])), "(原长度 5)")

# Gram-Schmidt 正交化
def gram_schmidt(vectors):
    basis = []
    for v in vectors:
        for b in basis:
            v = v - np.dot(b, v) / np.dot(b, b) * b
        basis.append(v / np.linalg.norm(v))
    return np.array(basis)

vecs = np.array([[1.0, 1.0], [1.0, 0.0]])
ortho = gram_schmidt(vecs)
print("正交化结果:\n", ortho)
print("两列正交?", np.isclose(np.dot(ortho[0], ortho[1]), 0))
```

## QR 分解

QR 分解把矩阵 A 分解成 A = QR，其中 Q 是正交矩阵，R 是上三角矩阵。用途：求解线性方程组（最小二乘）、求特征值（QR 迭代算法）、数值稳定的正交化。最小二乘 A x = b 通过 QR 变成 R x = Qᵀb（上三角，回代求解），比直接求逆数值更稳定。

```text
QR 分解要点：
1. 形式 —— A = QR，Q 正交，R 上三角
2. 方法 —— Gram-Schmidt、Householder 变换、Givens 旋转
3. 用途 —— 最小二乘求解、特征值 QR 迭代、正交化
4. 优点 —— 数值稳定，避免直接求逆的误差
```

```python
# Python/NumPy：QR 分解与最小二乘
import numpy as np

np.random.seed(42)
A = np.random.rand(5, 3)
b = np.random.rand(5)

# QR 分解
Q, R = np.linalg.qr(A)
print("Q 正交验证:", np.allclose(Q.T @ Q, np.eye(3)))
print("A == QR ?", np.allclose(A, Q @ R))

# 用 QR 解最小二乘：R x = Qᵀb
x = np.linalg.solve(R, Q.T @ b)
print("QR 最小二乘解:", x)
print("对比 lstsq:", np.linalg.lstsq(A, b, rcond=None)[0])
```

## SVD

奇异值分解（SVD）把任意 m×n 矩阵 A 分解成 A = UΣVᵀ，其中 U、V 是正交矩阵，Σ 是对角奇异值矩阵（非负、降序）。SVD 是线性代数「最通用」的分解——适用于任意矩阵，是低秩近似、PCA、矩阵压缩、推荐系统（隐语义模型）的理论核心。取前 k 个奇异值得到最佳秩 k 近似。

```text
SVD 要点：
1. 形式 —— A = UΣVᵀ，U 左奇异、V 右奇异、Σ 奇异值对角
2. 性质 —— 奇异值 σ₁≥σ₂≥...≥0，个数 = rank(A)
3. 低秩近似 —— 取前 k 个奇异值，得到 Frobenius 范数意义下的最佳秩 k 近似
4. 应用 —— PCA、推荐系统、图像压缩、矩阵补全
```

```python
# Python/NumPy：SVD 分解与低秩近似
import numpy as np

np.random.seed(42)
A = np.random.rand(6, 4)

U, S, Vt = np.linalg.svd(A, full_matrices=False)
print("奇异值:", S)

# 验证 A = U Σ Vᵀ
Sigma = np.diag(S)
print("A == UΣVᵀ ?", np.allclose(A, U @ Sigma @ Vt))

# 低秩近似：只保留前 2 个奇异值
k = 2
A_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
error = np.linalg.norm(A - A_k) / np.linalg.norm(A)
print(f"秩 {k} 近似的相对误差: {error:.3f}")
```

## PCA

主成分分析（PCA）是经典的线性降维方法：找到方差最大的正交方向（主成分），把数据投影到这些方向上。实现就是数据中心化后做 SVD（或特征分解协方差矩阵），取前 k 个主成分。它用于降维、去噪、可视化、特征提取，是 SVD 最典型的应用。

```text
PCA 要点：
1. 思想 —— 找方差最大的正交方向，投影保留最多信息
2. 步骤 —— 中心化 -> 协方差矩阵 -> 特征分解/SVD -> 取前 k 主成分
3. 方差解释率 —— Σ前 k 奇异值² / Σ全部奇异值²，衡量保留信息量
4. 应用 —— 降维、可视化、去噪、特征提取
```

```python
# Python：用 SVD 实现 PCA 并可视化
import numpy as np

np.random.seed(42)
# 生成有相关性的二维数据
mean = [0, 0]
cov = [[3, 2], [2, 1]]   # 两维强相关
X = np.random.multivariate_normal(mean, cov, 500)

# 1. 中心化
X_centered = X - X.mean(axis=0)

# 2. SVD
U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)

# 3. 投影到第一主成分
X_pca = X_centered @ Vt.T[:, :1]

# 方差解释率
explained = S[0]**2 / (S**2).sum()
print(f"第一主成分方差解释率: {explained:.3f}")
print("降维后形状:", X_pca.shape)
```

## 应用场景实战

### 场景一：用 SVD 做推荐系统的矩阵分解（隐语义模型）

```python
# 用户-物品评分矩阵（含缺失值），用 SVD 做低秩近似预测缺失评分
import numpy as np

# 5 用户 x 4 物品的评分矩阵，0 表示未评分
R = np.array([
    [5, 3, 0, 1],
    [4, 0, 0, 1],
    [1, 1, 0, 5],
    [0, 0, 5, 4],
    [0, 1, 5, 4],
])

# 用 SVD 低秩近似补全（简化版，忽略归一化）
U, S, Vt = np.linalg.svd(R, full_matrices=False)
k = 2
R_hat = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
print("原始评分矩阵:\n", R)
print("SVD 重构（预测缺失评分）:\n", np.round(R_hat, 2))
# R[0,2] 原本是 0，现在被预测出一个值
print("预测用户1对物品3的评分:", round(R_hat[0, 2], 2))
```

### 场景二：用 PCA 对高维特征降维后聚类

```python
# 高维特征降维，提升后续聚类的效果与速度
import numpy as np
from sklearn.decomposition import PCA

np.random.seed(42)
# 生成 1000 样本 x 50 维的高维数据（含大量冗余）
X = np.random.rand(1000, 50)

# PCA 降到 5 维，保留主要方差
pca = PCA(n_components=5)
X_reduced = pca.fit_transform(X)

print("降维前形状:", X.shape)
print("降维后形状:", X_reduced.shape)
print("累计方差解释率:", pca.explained_variance_ratio_.sum())
```

## 最佳实践与踩坑记录

### 最佳实践

1. 相似度计算用点积/余弦，先做向量归一化再点积
2. 解线性方程组优先用 lstsq 或 QR，别直接算逆矩阵（数值不稳定）
3. 矩阵乘法注意维度匹配，A 的列数必须等于 B 的行数
4. 降维用 PCA 时先标准化特征，避免量纲差异主导方差
5. 低秩近似选 k 看奇异值衰减曲线（肘部法则），别拍脑袋
6. 大矩阵分解用随机化 SVD（randomized SVD）加速
7. 判断矩阵是否可逆先看秩是否满秩，而不是直接求逆试错

### 踩坑记录

```text
坑 1：直接求逆解方程导致数值不稳定
结论：矩阵接近奇异时，inv(A) 结果误差巨大甚至报错。
原因：逆矩阵对微小扰动敏感，条件数大时误差放大。
解法：用 lstsq、QR 分解或伪逆（pinv）求解。

坑 2：PCA 前没标准化导致主成分被量纲大的特征主导
结论：降维结果主要反映量纲大的特征，小量纲特征被忽略。
原因：PCA 对方差敏感，量纲大的特征方差大，主导主成分。
解法：PCA 前先标准化（z-score），让各特征方差可比。

坑 3：矩阵乘法维度不匹配
结论：np.dot/矩阵乘法报 shape 错误。
原因：A(3,4) 与 B(3,4) 不能相乘，需要 B(4,k)。
解法：检查 A 列数 == B 行数，或用 A @ B 前打印 shape 确认。

坑 4：用低秩近似时 k 选太大没意义
结论：k 接近满秩，压缩/降维效果不明显，还白费计算。
原因：奇异值衰减慢，前 k 个没覆盖足够信息。
解法：画奇异值曲线选肘部，或按方差解释率阈值（如 95%）定 k。
```
