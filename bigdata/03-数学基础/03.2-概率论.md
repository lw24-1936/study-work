## 概述

概率论研究随机现象的规律，是数据分析、统计推断、机器学习和 A/B 实验的理论基础。随机变量、分布、条件概率、贝叶斯、期望方差这些概念，直接用于流量预估、异常检测、推荐系统、A/B 实验显著性判断。大数据里的采样估计、基数估计（17 章）、实时风控的异常概率都建立在概率论之上。

```text
概率论的核心链条：
随机变量 -> 分布（刻画取值规律）-> 期望/方差（数字特征）
条件概率 -> 贝叶斯定理 -> 后验推断
大数定律 + 中心极限定理 -> 采样与区间估计的理论保证
```

## 随机变量

随机变量是把随机试验的结果映射成数值的函数，分离散型（取值有限/可数，如掷骰子）和连续型（取值连续，如身高）。离散型用概率质量函数 PMF 描述（P(X=x)），连续型用概率密度函数 PDF 描述（落在区间的概率是积分）。分布函数 CDF（P(X≤x)）统一描述两者的累积概率。

```text
随机变量要点：
1. 离散型 —— PMF：P(X=x)，如骰子点数、泊松计数
2. 连续型 —— PDF：f(x)，P(a<X<b)=∫f(x)dx，如正态分布
3. CDF —— F(x)=P(X≤x)，单调不减，从 0 到 1
4. 独立 —— 两个变量取值互不影响，P(X,Y)=P(X)P(Y)
```

```python
# Python：离散与连续随机变量的 PMF/PDF/CDF
import numpy as np
from scipy import stats

# 离散：二项分布 Binomial(n=10, p=0.5)
binom = stats.binom(n=10, p=0.5)
print("P(X=5) =", binom.pmf(5))          # 质量函数
print("P(X<=5) =", binom.cdf(5))         # 分布函数

# 连续：标准正态分布 N(0,1)
norm = stats.norm(0, 1)
print("f(0) =", norm.pdf(0))             # 密度函数
print("P(X<=1.96) =", norm.cdf(1.96))    # 约 0.975
```

## 常见分布

几个分布覆盖了大数据绝大多数场景：伯努利（单次成败）、二项（n 次独立成败的次数）、泊松（单位时间随机事件数）、几何（首次成功次数）、均匀（等概率）、正态（大量独立因素叠加）、指数（事件间隔时间）。理解「什么场景用什么分布」是建模的第一步。

```text
常见分布与场景：
1. 伯努利/二项 —— 点击与否、n 次转化中成功次数
2. 泊松 —— 单位时间到达数（请求量、订单数）
3. 几何 —— 首次成功前的尝试次数（留存、转化次数）
4. 正态 —— 大量独立因素叠加（误差、均值分布）
5. 指数 —— 无记忆的等待时间（请求间隔）
```

```python
# Python：各分布的可视化与采样
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 二项分布
axes[0].hist(np.random.binomial(n=10, p=0.5, size=10000), bins=11, density=True)
axes[0].set_title("Binomial(n=10, p=0.5)")

# 泊松分布
axes[1].hist(np.random.poisson(lam=5, size=10000), bins=15, density=True)
axes[1].set_title("Poisson(lambda=5)")

# 正态分布
axes[2].hist(np.random.normal(0, 1, size=10000), bins=40, density=True)
axes[2].set_title("Normal(0, 1)")
plt.show()
```

## 条件概率

条件概率 P(A|B) 是「已知 B 发生，A 发生的概率」，定义为 P(A|B) = P(A∩B)/P(B)。它是贝叶斯定理、马尔可夫链、留存分析、推荐系统（已知用户历史行为，预测下一步）的基础。乘法公式 P(A∩B) = P(A|B)P(B) 把联合概率拆成条件概率的乘积。

```text
条件概率要点：
1. 定义 —— P(A|B) = P(A∩B) / P(B)，要求 P(B) > 0
2. 乘法公式 —— P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)
3. 独立 —— A、B 独立当且仅当 P(A|B) = P(A)
4. 应用 —— 留存率（已知活跃，次日留存）、马尔可夫链、推荐
```

```python
# Python：条件概率计算与独立性判断
# 场景：1000 个用户，800 点击广告，其中 200 下单；不点击的 200 人中 20 下单
total = 1000
click = 800
order_and_click = 200
order_no_click = 20
order = order_and_click + order_no_click

# P(下单 | 点击) vs P(下单 | 不点击)
p_order_given_click = order_and_click / click
p_order_given_noclick = order_no_click / (total - click)
print("P(下单|点击) =", p_order_given_click)
print("P(下单|不点击) =", p_order_given_noclick)
# 下单与点击不独立（概率不同）
print("下单与点击独立?", abs(p_order_given_click - order / total) < 1e-9)
```

## 贝叶斯

贝叶斯定理 P(A|B) = P(B|A)·P(A)/P(B)，把「先验概率 P(A)」和「似然 P(B|A)」结合成「后验概率 P(A|B)」。它是贝叶斯推断、朴素贝叶斯分类器、垃圾邮件过滤、A/B 实验贝叶斯分析的理论核心。直觉：用新证据 B 更新对 A 的信念。

```text
贝叶斯要点：
1. 公式 —— P(A|B) = P(B|A)·P(A) / P(B)
2. 先验/后验 —— P(A) 先验信念，P(A|B) 看到证据后的更新信念
3. 朴素贝叶斯 —— 假设特征独立，用于文本分类、垃圾邮件
4. 应用 —— 垃圾邮件过滤、医疗诊断、推荐、实验分析
```

```python
# Python：贝叶斯做垃圾邮件过滤
# 已知：垃圾邮件占 20%；含"免费"的邮件中 90% 是垃圾；正常邮件含"免费"占 5%
p_spam = 0.20
p_free_given_spam = 0.90
p_free_given_ham = 0.05
p_ham = 1 - p_spam

# 全概率：P(含免费) = P(免费|垃圾)P(垃圾) + P(免费|正常)P(正常)
p_free = p_free_given_spam * p_spam + p_free_given_ham * p_ham

# 后验：P(垃圾 | 含免费)
p_spam_given_free = p_free_given_spam * p_spam / p_free
print("P(垃圾 | 含'免费') =", round(p_spam_given_free, 4))  # 约 0.818
```

## 期望

期望 E[X] 是随机变量的「加权平均」，离散型是 Σ x·P(X=x)，连续型是 ∫ x·f(x)dx。它是随机变量的「中心位置」，是预测、收益估计、A/B 实验指标均值的基础。期望有线性性质：E[aX+bY] = aE[X]+bE[Y]（无论 X、Y 是否独立）。

```text
期望要点：
1. 定义 —— 离散 Σ x·p(x)，连续 ∫ x·f(x)dx
2. 线性性 —— E[aX+bY] = aE[X]+bE[Y]，无条件成立
3. 意义 —— 长期平均、预测值、指标均值
4. 应用 —— 收益预估、留存 LTV、实验指标
```

```python
# Python：期望计算与验证
import numpy as np

# 骰子点数的期望
faces = np.arange(1, 7)
p = np.full(6, 1/6)
expected = np.sum(faces * p)
print("骰子期望:", expected)   # 3.5

# 大数定律验证：采样均值收敛到期望
samples = np.random.choice(faces, size=100000, p=p)
print("10 万次采样均值:", samples.mean())  # 接近 3.5

# 线性性验证
x = np.random.poisson(3, 10000)
y = np.random.poisson(5, 10000)
print("E[2X+3Y] =", (2*x + 3*y).mean(), "理论:", 2*3 + 3*5)
```

## 方差

方差 Var(X) = E[(X-μ)²] 衡量随机变量偏离期望的程度，标准差 σ = √Var。方差反映数据的波动/风险，是 A/B 实验里估计样本量、风险控制、特征缩放的基础。性质：Var(aX+b) = a²Var(X)；独立时 Var(X+Y) = Var(X)+Var(Y)。

```text
方差要点：
1. 定义 —— Var(X) = E[(X-μ)²] = E[X²] - (E[X])²
2. 标准差 —— σ = √Var(X)，与 X 同单位
3. 性质 —— Var(aX+b)=a²Var(X)；独立时方差可加
4. 应用 —— 波动度量、样本量估计、特征标准化
```

```python
# Python：方差计算与性质验证
import numpy as np

data = np.array([2, 4, 6, 8, 10])
mu = data.mean()
var = np.mean((data - mu) ** 2)         # 总体方差
print("均值:", mu, "方差:", var, "标准差:", np.sqrt(var))

# Var(aX+b) = a²Var(X)
a, b = 3, 10
transformed = a * data + b
print("Var(3X+10) =", np.var(transformed), "理论:", a**2 * np.var(data))
```

## 协方差

协方差 Cov(X,Y) = E[(X-μx)(Y-μy)] 衡量两个变量的线性相关方向与强度：正值同向、负值反向、零不相关。归一化后得到相关系数 ρ = Cov/(σx·σy)，取值 [-1, 1]。协方差矩阵是多元统计、PCA、金融组合风险的基石。注意：不相关不等于独立（除非正态）。

```text
协方差要点：
1. 定义 —— Cov(X,Y) = E[(X-μx)(Y-μy)] = E[XY] - E[X]E[Y]
2. 相关系数 —— ρ = Cov/(σxσy)，∈[-1,1]，度量线性关系
3. 协方差矩阵 —— 多元随机变量的协方差集合，PCA 的核心
4. 陷阱 —— 相关系数为 0 仅表示无线性关系，不表示独立
```

```python
# Python：协方差与相关系数
import numpy as np

np.random.seed(42)
x = np.random.normal(0, 1, 10000)
y = 2 * x + np.random.normal(0, 0.5, 10000)   # y 与 x 强正相关

# 协方差与相关系数
cov_matrix = np.cov(x, y)
print("协方差矩阵:\n", cov_matrix)
corr = np.corrcoef(x, y)[0, 1]
print("相关系数:", corr)   # 接近 0.97

# 独立变量相关系数接近 0
z = np.random.normal(0, 1, 10000)
print("独立变量相关系数:", np.corrcoef(x, z)[0, 1])
```

## 大数定律

大数定律（LLN）说：样本均值随样本量增大收敛到总体期望。它是「用样本估计总体」的理论保证——采样越多，估计越准。大数据里，抽样调查、日志采样分析、A/B 实验的指标估计都依赖它：只要样本足够大，样本均值就可靠。

```text
大数定律要点：
1. 弱大数定律 —— 样本均值依概率收敛到期望 μ
2. 强大数定律 —— 样本均值几乎必然收敛到 μ
3. 条件 —— 独立同分布（i.i.d.）且期望存在
4. 应用 —— 采样估计、指标均值、蒙特卡洛积分
```

```python
# Python：大数定律的数值演示
import numpy as np

np.random.seed(0)
mu_true = 0.7   # 真实期望（伯努利 p=0.7）
for n in [10, 100, 1000, 10000, 100000]:
    samples = np.random.binomial(1, mu_true, n)
    print(f"n={n:>6}, 样本均值={samples.mean():.4f}, 误差={abs(samples.mean()-mu_true):.4f}")
# 误差随 n 增大而减小
```

## 中心极限定理

中心极限定理（CLT）说：大量独立同分布随机变量之和（或均值）近似服从正态分布，无论原始分布是什么。它解释了正态分布的普遍性，也是置信区间、假设检验、A/B 实验显著性判断的理论基础。实际含义：即使数据本身偏态，样本均值的分布也近似正态。

```text
中心极限定理要点：
1. 结论 —— n 足够大时，样本均值 ~ N(μ, σ²/n)
2. 条件 —— 独立同分布，方差有限（Lyapunov 条件可放宽到不同分布）
3. 意义 —— 不依赖原始分布，均值分布趋于正态
4. 应用 —— 置信区间、假设检验、A/B 实验
```

```python
# Python：CLT 数值演示——均匀分布的样本均值趋于正态
import numpy as np

np.random.seed(42)
means = []
for _ in range(5000):
    sample = np.random.uniform(0, 1, 30)   # 原始是均匀分布
    means.append(sample.mean())

means = np.array(means)
print("样本均值的均值:", means.mean(), "(理论 0.5)")
print("样本均值的标准差:", means.std(), "(理论 1/sqrt(12*30) ≈", 1/np.sqrt(12*30), ")")

# 检验是否近似正态：偏度接近 0、峰度接近 3
from scipy import stats
print("偏度:", stats.skew(means), "峰度:", stats.kurtosis(means))
```

## 应用场景实战

### 场景一：用泊松分布预估系统容量

```python
# 服务每分钟请求数服从泊松分布，均值 100
# 问：每分钟请求超过 130 的概率（用于容量规划）
from scipy import stats
import numpy as np

lam = 100
prob_over = 1 - stats.poisson.cdf(130, lam)
print(f"每分钟请求超过 130 的概率: {prob_over:.4f}")

# 求 99.9% 分位数（容量至少要接住这个量）
capacity = stats.poisson.ppf(0.999, lam)
print(f"99.9% 分位数（容量下限）: {capacity}")
```

### 场景二：用贝叶斯做 A/B 实验的转化率估计

```python
# 贝叶斯 A/B：用 Beta 分布估计转化率后验
# A 组：1000 用户 120 转化；B 组：1000 用户 150 转化
from scipy import stats

# 先验 Beta(1,1)（均匀），后验 Beta(1+转化, 1+未转化)
posterior_a = stats.beta(1 + 120, 1 + 880)
posterior_b = stats.beta(1 + 150, 1 + 850)

print("A 组后验均值:", posterior_a.mean())
print("B 组后验均值:", posterior_b.mean())

# B 优于 A 的概率（采样估计）
import numpy as np
np.random.seed(0)
samples_a = posterior_a.rvs(100000)
samples_b = posterior_b.rvs(100000)
p_b_better = (samples_b > samples_a).mean()
print(f"B 组转化率高于 A 组的概率: {p_b_better:.4f}")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 建模前先判断「什么分布」，选对分布比调参更重要
2. 用大数定律和 CLT 理解「样本够大才可靠」，别用小样本下结论
3. 协方差/相关系数只反映线性关系，判断独立要看更完整的依赖结构
4. 贝叶斯更新时明确先验来源，先验不同后验可能差异很大
5. A/B 实验的显著性判断要用 CLT 的均值近似正态，注意样本量
6. 蒙特卡洛模拟用随机种子保证可复现
7. 概率估算结果要附置信区间，别只给点估计

### 踩坑记录

```text
坑 1：把相关系数 0 当成独立
结论：认为两变量无关，但实际存在非线性依赖。
原因：相关系数只度量线性关系，非线性的 Y=X² 相关系数可能为 0。
解法：独立性判断用更严格的方法（互信息、卡方检验）。

坑 2：小样本直接算转化率并下结论
结论：10 个用户 3 个转化，就断言转化率 30%。
原因：样本太小，样本均值方差大，估计极不稳定。
解法：用置信区间或贝叶斯后验表达不确定性，样本够了再下结论。

坑 3：忽略先验对后验的影响
结论：不同人用不同先验，得出完全相反的后验结论。
原因：贝叶斯后验依赖先验，样本少时先验主导结果。
解法：样本少时用弱先验（无信息先验），并报告先验敏感性。

坑 4：泊松/正态分布用错场景
结论：用正态分布建模「单位时间事件数」，概率估计偏差大。
原因：计数数据是离散非负，泊松更合适；正态可能给负值概率。
解法：计数用泊松/二项，连续误差用正态，先看数据取值范围。
```
