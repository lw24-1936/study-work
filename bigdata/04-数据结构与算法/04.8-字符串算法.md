## 概述

字符串算法围绕「模式匹配」和「字符串相似度」两大主题。模式匹配解决「在一个大文本里找模式串」，从朴素的 O(n·m) 优化到 O(n+m)：KMP 用前缀函数、Z 算法用 Z 数组、Rabin-Karp 用哈希，AC 自动机则同时匹配多个模式串。后缀数组解决「子串相关的批量查询」，编辑距离解决「两个串有多像」。这些是搜索引擎、日志过滤、DNA 比对、拼写纠错的底层。

```text
字符串算法速览：
1. KMP        —— 前缀函数避免回溯，O(n+m) 单模式匹配
2. Z          —— Z 数组，实现更简洁的线性匹配
3. Rabin-Karp —— 滚动哈希，O(n+m) 期望，支持多模式
4. AC 自动机  —— Trie + KMP，一次匹配多个模式串
5. 后缀数组   —— 所有后缀排序，子串批量查询
6. 编辑距离   —— 两串相似度，DP 求解
```

## KMP

KMP（Knuth-Morris-Pratt）算法通过预处理模式串的「前缀函数」（next 数组，记录每个位置的最长相等前后缀长度），在匹配失败时让模式串跳到「已知已匹配」的位置，而不是回退文本指针。这样文本指针只前进不后退，整体 O(n+m)。它是字符串匹配的教科书算法，广泛用于 grep、文本编辑器、协议解析。

```text
KMP 要点：
1. 前缀函数 next[i] —— 模式串前 i 个字符的最长相等真前后缀长度
2. 失配不回溯 —— 文本指针单调前进，模式串按 next 跳
3. 复杂度 —— O(n + m)，n 文本长，m 模式长
4. 应用 —— 子串查找、周期检测、字符串压缩
```

```python
def kmp_prefix(pattern):
    """计算前缀函数（next 数组）。"""
    m = len(pattern)
    nxt = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = nxt[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        nxt[i] = j
    return nxt

def kmp_search(text, pattern):
    """返回所有匹配位置。"""
    nxt = kmp_prefix(pattern)
    j = 0
    matches = []
    for i, ch in enumerate(text):
        while j > 0 and ch != pattern[j]:
            j = nxt[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == len(pattern):
            matches.append(i - j + 1)
            j = nxt[j - 1]
    return matches

text = "ababababcabab"
pattern = "abab"
print("前缀函数 =", kmp_prefix(pattern))      # [0,0,1,2]
print("匹配位置 =", kmp_search(text, pattern))
```

## Z

Z 算法通过 Z 数组求匹配：Z[i] 表示「从位置 i 开始与原串的最长公共前缀长度」。把「模式串 + 分隔符 + 文本」拼成一个串求 Z 数组，Z 值等于模式串长度的位置就是匹配点。它和 KMP 同为 O(n+m)，但实现更简洁、思路更直观（维护一个 [l, r] 匹配区间），也用于求字符串的周期和重复结构。

```text
Z 算法要点：
1. Z[i] —— s[i:] 与 s[0:] 的最长公共前缀
2. 拼接 —— pattern + '#' + text 求 Z，匹配点 Z 值 = len(pattern)
3. 复杂度 O(n+m)，维护 [l, r] 区间复用已算信息
4. 应用 —— 模式匹配、周期检测、border 分析
```

```python
def z_function(s):
    n = len(s)
    z = [0] * n
    l = r = 0
    for i in range(1, n):
        if i <= r:
            z[i] = min(r - i + 1, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] - 1 > r:
            l, r = i, i + z[i] - 1
    return z

def z_search(text, pattern):
    combined = pattern + "#" + text
    z = z_function(combined)
    m = len(pattern)
    return [i - m - 1 for i in range(m + 1, len(combined)) if z[i] == m]

print("Z 数组 =", z_function("ababab"))
print("匹配位置 =", z_search("ababababcabab", "abab"))
```

## Rabin-Karp

Rabin-Karp 用「滚动哈希」匹配：把模式串和文本的每个长度 m 的子串都算哈希值，哈希相等再逐字符确认。滚动哈希的核心是 O(1) 从当前窗口哈希推出下一窗口哈希（减去最高位、乘进制、加新字符）。它期望 O(n+m)，且天然支持「一次匹配多个模式串」（只需比较哈希集合），是查重、多模式过滤的常用手段。

```text
Rabin-Karp 要点：
1. 滚动哈希 —— O(1) 滑窗更新哈希值
2. 哈希冲突 —— 哈希相等要逐字符二次确认
3. 多模式 —— 匹配多个等长模式串时效率高
4. 期望 O(n+m)，最坏 O(n·m)（全是冲突时）
```

```python
def rabin_karp(text, pattern, base=256, mod=10**9 + 7):
    m, n = len(pattern), len(text)
    if m > n:
        return []
    # 最高位权重 base^(m-1)
    h = pow(base, m - 1, mod)
    p_hash = t_hash = 0
    for i in range(m):
        p_hash = (p_hash * base + ord(pattern[i])) % mod
        t_hash = (t_hash * base + ord(text[i])) % mod
    matches = []
    for i in range(n - m + 1):
        if p_hash == t_hash and text[i:i + m] == pattern:
            matches.append(i)
        if i < n - m:
            # 滚动：去头、加尾
            t_hash = (t_hash - ord(text[i]) * h) % mod
            t_hash = (t_hash * base + ord(text[i + m])) % mod
    return matches

print("匹配位置 =", rabin_karp("ababababcabab", "abab"))
```

## AC 自动机

AC 自动机（Aho-Corasick）在 Trie 树上加「失配指针（fail）」，同时匹配多个模式串：fail 指针指向「当前状态的最长后缀对应的状态」，匹配失败时沿 fail 跳转而不回溯文本。它一次扫描文本即可找出所有模式串的所有出现位置，复杂度 O(n + 总匹配数)。用于敏感词过滤、多关键词检索、病毒特征匹配。

```text
AC 自动机要点：
1. Trie + fail 指针 —— 多模式同时匹配
2. fail —— 指向最长可匹配后缀，失配沿其跳转
3. BFS 建 fail —— 按层构建，子节点继承父的 fail
4. 复杂度 O(n + 匹配总数)，一次扫完
```

```python
from collections import deque

class AhoCorasick:
    def __init__(self):
        self.next = [{}]        # 转移表
        self.fail = [0]
        self.out = [set()]      # 每个节点结束的模式

    def add(self, word, idx):
        node = 0
        for ch in word:
            if ch not in self.next[node]:
                self.next[node][ch] = len(self.next)
                self.next.append({})
                self.fail.append(0)
                self.out.append(set())
            node = self.next[node][ch]
        self.out[node].add(idx)

    def build(self):
        q = deque()
        for ch, nxt in self.next[0].items():
            self.fail[nxt] = 0
            q.append(nxt)
        while q:
            u = q.popleft()
            for ch, v in self.next[u].items():
                f = self.fail[u]
                while f and ch not in self.next[f]:
                    f = self.fail[f]
                self.fail[v] = self.next[f].get(ch, 0)
                self.out[v] |= self.out[self.fail[v]]
                q.append(v)

    def search(self, text):
        node = 0
        found = []
        for i, ch in enumerate(text):
            while node and ch not in self.next[node]:
                node = self.fail[node]
            node = self.next[node].get(ch, 0)
            for idx in self.out[node]:
                found.append((idx, i))
        return found

ac = AhoCorasick()
for i, w in enumerate(["he", "she", "his", "hers"]):
    ac.add(w, i)
ac.build()
print("匹配结果 (模式id, 文本位置) =", ac.search("ushers"))
```

## 后缀数组

后缀数组（Suffix Array）是「字符串所有后缀按字典序排序后的数组」，配合高度数组（LCP，相邻后缀的最长公共前缀）可解决大量子串问题：最长重复子串、两个串的最长公共子串、子串出现次数、不同子串个数。构建可用倍增法 O(n log n)。它是后缀树的空间优化替代，是文本索引、基因序列分析的利器。

```text
后缀数组要点：
1. sa[i] —— 排名第 i 的后缀的起始位置
2. 倍增构造 —— 按长度 1,2,4,... 的排名排序，O(n log n)
3. LCP 数组 —— 相邻后缀的最长公共前缀，子串问题的关键
4. 应用 —— 最长重复子串、最长公共子串、子串计数
```

```python
def build_suffix_array(s):
    """倍增法构建后缀数组。"""
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    k = 1
    tmp = [0] * n
    while k < n:
        sa.sort(key=lambda x: (rank[x], rank[x + k] if x + k < n else -1))
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            tmp[cur] = tmp[prev] + (
                (rank[prev], rank[prev + k] if prev + k < n else -1) !=
                (rank[cur], rank[cur + k] if cur + k < n else -1))
        rank, tmp = tmp, rank
        if rank[sa[-1]] == n - 1:
            break
        k *= 2
    return sa

def lcp_array(s, sa):
    """Kasai 算法求 LCP 数组。"""
    n = len(s)
    rank = [0] * n
    for i, p in enumerate(sa):
        rank[p] = i
    h = 0
    lcp = [0] * (n - 1)
    for i in range(n):
        if rank[i] > 0:
            j = sa[rank[i] - 1]
            while i + h < n and j + h < n and s[i + h] == s[j + h]:
                h += 1
            lcp[rank[i] - 1] = h
            if h > 0:
                h -= 1
    return lcp

s = "banana"
sa = build_suffix_array(s)
print("后缀数组 =", sa)
print("LCP =", lcp_array(s, sa))
```

## 编辑距离

编辑距离（Edit Distance / Levenshtein Distance）是「把一个串变成另一个串所需的最少操作次数」（插入、删除、替换各算一次）。它用动态规划 O(m·n) 求解，是字符串相似度的标准度量，用于拼写纠错、模糊搜索、DNA 序列比对、抄袭检测。变体有带权编辑距离、最长公共子序列（只允许插入删除）。

```text
编辑距离要点：
1. 定义 —— 最少插入/删除/替换次数
2. DP —— dp[i][j] 表示 s1[:i] 与 s2[:j] 的距离
3. 复杂度 O(m·n)，空间可优化到 O(min(m,n))
4. 应用 —— 拼写纠错、模糊匹配、序列比对
```

```python
def edit_distance(s1, s2):
    m, n = len(s1), len(s2)
    # 一维滚动优化空间
    prev = list(range(n + 1))
    for i in range(1, m + 1):
        cur = [i] + [0] * n
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                cur[j] = prev[j - 1]
            else:
                cur[j] = 1 + min(prev[j], cur[j - 1], prev[j - 1])
        prev = cur
    return prev[n]

print("编辑距离('kitten','sitting') =", edit_distance("kitten", "sitting"))  # 3
print("编辑距离('flaw','lawn') =", edit_distance("flaw", "lawn"))            # 2
```

## 应用场景实战

### 场景一：用 AC 自动机做敏感词过滤

```python
class SensitiveWordFilter:
    def __init__(self, words):
        self.ac = AhoCorasick()
        self.words = words
        for i, w in enumerate(words):
            self.ac.add(w, i)
        self.ac.build()

    def censor(self, text):
        hits = self.ac.search(text)
        # 命中位置替换为 *
        masked = list(text)
        for idx, end_pos in hits:
            wlen = len(self.words[idx])
            start = end_pos - wlen + 1
            for p in range(start, end_pos + 1):
                masked[p] = '*'
        return ''.join(masked)

bad_words = ["暴力", "赌博", "诈骗"]
f = SensitiveWordFilter(bad_words)
print(f.censor("这个平台涉嫌赌博和诈骗"))   # 这个平台涉嫌**和**
```

### 场景二：用 KMP 在日志中检索关键字

```python
def grep_keyword(log_lines, keyword):
    """在每行日志里用 KMP 找关键字，返回命中行号。"""
    nxt = kmp_prefix(keyword)
    hits = []
    for lineno, line in enumerate(log_lines, start=1):
        if kmp_search(line, keyword):
            hits.append(lineno)
    return hits

logs = [
    "INFO: user login success",
    "ERROR: connection timeout",
    "INFO: user logout",
    "ERROR: disk full, timeout",
]
print("含 'timeout' 的行 =", grep_keyword(logs, "timeout"))   # [2, 4]
```

## 最佳实践与踩坑记录

### 最佳实践

1. 单模式匹配用 KMP 或内置 find（find 底层已优化），别用朴素双循环
2. 多模式匹配用 AC 自动机，一次扫描搞定所有关键词
3. 多次在同一文本上做子串查询，先建后缀数组/后缀树
4. 字符串相似度用编辑距离，但注意 O(m·n) 对大串要设长度上限
5. 哈希匹配（Rabin-Karp）一定要二次逐字符确认，防冲突误报
6. 敏感词/关键词过滤优先用成熟的库（如 Aho-Corasick 的 C 实现），性能更好

### 踩坑记录

```text
坑 1：朴素匹配在大文本上 O(n·m) 超时
结论：长文本长模式时跑不动。
原因：双循环每次失配都回退文本指针，最坏 n*m 次比较。
解法：用 KMP/Z/滚动哈希把复杂度降到 O(n+m)。

坑 2：Rabin-Karp 只比较哈希不二次确认
结论：哈希冲突导致误报匹配位置。
原因：不同子串哈希可能相同（生日悖论），不确认会报假阳性。
解法：哈希相等后逐字符比较，或选大质数模降低冲突概率。

坑 3：编辑距离用于超长字符串内存/时间爆炸
结论：O(m·n) 时间和空间不可接受。
原因：10 万 × 10 万的 DP 表不可能建立。
解法：设长度上限，超长用分块近似或改用其他相似度（如 SimHash）。

坑 4：后缀数组忘记处理分隔符导致跨串匹配
结论：求两串公共子串时把两个串当成了一个。
原因：直接拼接两串，后缀可能跨越边界产生假公共子串。
解法：拼接时中间插入不出现的分隔符（如 '#'）。
```
