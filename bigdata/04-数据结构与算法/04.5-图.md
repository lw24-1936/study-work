## 概述

图（Graph）由顶点（Vertex）和边（Edge）组成，描述「多对多」的关系，比树更一般。社交网络、网页链接、道路网络、数据血缘、依赖调度都是图。图算法的两大主题是「遍历」（BFS/DFS）和「结构分析」（连通性、最短路、最小生成树、强连通分量、重要性排序）。大数据里，PageRank 是图计算的开山算法，Spark GraphX、图数据库（Neo4j）都是图思想在分布式上的落地。

```text
图的表示与核心算法：
1. 表示 —— 邻接矩阵（稠密）与邻接表（稀疏，最常用）
2. 遍历 —— BFS 层序（最短路无权）、DFS 深搜（连通性/环检测）
3. 拓扑排序 —— DAG 的依赖顺序（任务调度）
4. 最短路 —— Dijkstra / Bellman-Ford / Floyd
5. MST —— Kruskal / Prim（最小代价连通所有点）
6. SCC —— 强连通分量（Kosaraju / Tarjan）
7. PageRank —— 顶点重要性排序（网页排名）
```

```python
def build_adj_list(n, edges, directed=False):
    """edges: [(u, v, w)]，返回邻接表（默认无向）。"""
    adj = [[] for _ in range(n)]
    for u, v, *rest in edges:
        w = rest[0] if rest else 1
        adj[u].append((v, w))
        if not directed:
            adj[v].append((u, w))
    return adj
```

## BFS

广度优先搜索（Breadth-First Search，BFS）用队列从起点逐层向外扩展，先访问距离近的节点。它在无权图上天然给出「最短路径」（按边数），是求最短路、层序遍历、连通分量、扩散传播（如社交网络的 K 度人脉）的基础。时间 O(V+E)，空间 O(V)。

```text
BFS 要点：
1. 队列驱动 —— 先进先出，逐层扩展
2. 无权最短路 —— 首次访问到某节点的层数就是最短边数
3. 应用 —— 最短路径、连通分量、传播扩散、迷宫
4. 复杂度 —— O(V+E)，需 visited 防重复入队
```

```python
from collections import deque

def bfs_shortest_path(adj, start):
    """无权图 BFS 求 start 到所有点的最短边数。"""
    n = len(adj)
    dist = [-1] * n
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v, _ in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

adj = build_adj_list(6, [(0,1),(0,2),(1,3),(2,3),(3,4),(4,5)])
print("0 到各点最短边数 =", bfs_shortest_path(adj, 0))
```

## DFS

深度优先搜索（Depth-First Search，DFS）从起点沿一条路走到黑，再回溯换路。它记录「进入时间/退出时间」和「父边」，用于检测环、求连通分量、拓扑排序（后序遍历反转）、强连通分量、生成树。DFS 可用递归或显式栈实现，时间 O(V+E)。

```text
DFS 要点：
1. 一路走到底再回溯 —— 栈（递归）驱动
2. 环检测 —— 访问到「灰色」（正在访问）节点说明有环
3. 拓扑排序 —— DFS 后序遍历的逆序
4. 应用 —— 连通分量、环检测、拓扑、SCC、桥/割点
```

```python
def dfs_recursive(adj):
    n = len(adj)
    visited = [False] * n
    order = []
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v, _ in adj[u]:
            if not visited[v]:
                dfs(v)
    for i in range(n):
        if not visited[i]:
            dfs(i)
    return order

def has_cycle(adj):
    """有向图环检测：三色标记法。"""
    n = len(adj)
    color = [0] * n   # 0 白 1 灰 2 黑
    def dfs(u):
        color[u] = 1
        for v, _ in adj[u]:
            if color[v] == 1:
                return True
            if color[v] == 0 and dfs(v):
                return True
        color[u] = 2
        return False
    return any(color[i] == 0 and dfs(i) for i in range(n))

adj = build_adj_list(6, [(0,1),(0,2),(1,3),(2,3),(3,4),(4,5)], directed=True)
print("DFS 顺序 =", dfs_recursive(adj))
print("有环？", has_cycle(adj))
```

## 拓扑排序

拓扑排序（Topological Sort）给出 DAG（有向无环图）的线性序列，使每条边的起点都排在终点之前。它是「依赖关系」的标准解法：编译依赖、任务调度、课程先修。实现有 Kahn 算法（不断删入度为 0 的节点）和 DFS 逆后序两种。若图有环则无法拓扑排序，这本身也是环检测的手段。

```text
拓扑排序要点：
1. 只适用于 DAG —— 有环则不存在拓扑序
2. Kahn —— 入度为 0 的点入队，删边减入度，O(V+E)
3. DFS 逆后序 —— 后序遍历反转即为拓扑序
4. 应用 —— 任务调度、依赖解析、编译顺序、数据血缘
```

```python
from collections import deque

def kahn_toposort(adj):
    n = len(adj)
    indeg = [0] * n
    for u in range(n):
        for v, _ in adj[u]:
            indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v, _ in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []   # 有环返回空

# 课程依赖：0→1→3, 0→2→3, 3→4, 4→5
adj = build_adj_list(6, [(0,1),(0,2),(1,3),(2,3),(3,4),(4,5)], directed=True)
print("拓扑序 =", kahn_toposort(adj))
```

## 并查集

并查集（Union-Find / Disjoint Set）维护「不相交集合」的合并与查询，用「父指针森林」表示：find 找根、union 合并两集合。配「路径压缩 + 按秩合并」后，单次操作接近 O(α(n))（反阿克曼函数，近似常数）。它是连通性判断、最小生成树（Kruskal）、动态连通性的利器。

```text
并查集要点：
1. find —— 找根并路径压缩，把沿途节点直接挂到根
2. union —— 按秩合并，小树挂大树
3. 复杂度 —— 近似 O(α(n))，几乎常数
4. 应用 —— 连通分量、Kruskal、朋友圈、等价类
```

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return
        if self.rank[rx] < self.rank[ry]:      # 按秩合并
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1

    def connected(self, x, y):
        return self.find(x) == self.find(y)

uf = UnionFind(6)
for a, b in [(0,1),(1,2),(3,4)]:
    uf.union(a, b)
print("0 和 2 连通？", uf.connected(0, 2))   # True
print("0 和 3 连通？", uf.connected(0, 3))   # False
```

## 最短路

最短路（Shortest Path）求两点间权重和最小的路径。Dijkstra 用于非负权图（贪心 + 优先队列，O((V+E) log V)）；Bellman-Ford 能处理负权边（O(VE)，还能判负环）；Floyd-Warshall 求所有点对最短路（O(V³)，动态规划）。最短路是导航、网络路由、物流调度的核心算法。

```text
最短路要点：
1. Dijkstra —— 非负权，贪心 + 最小堆，每次确定一个点的最短距
2. Bellman-Ford —— 支持负权，V-1 轮松弛，能检测负环
3. Floyd —— 所有点对，O(V³)，适合稠密小图
4. 应用 —— 导航、路由协议、路径规划
```

```python
import heapq

def dijkstra(adj, start):
    n = len(adj)
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist

# 带权有向图
adj = build_adj_list(5, [(0,1,4),(0,2,1),(2,1,2),(1,3,1),(2,3,5),(3,4,3)], directed=True)
print("0 到各点最短路 =", dijkstra(adj, 0))   # [0,3,1,4,7]
```

## MST

最小生成树（Minimum Spanning Tree，MST）是「用最小总代价连通所有顶点」的边集，结果是一棵含 V-1 条边的树。Kruskal 按边权排序 + 并查集判环（适合稀疏图，O(E log E)）；Prim 从一点贪心扩展最近点（适合稠密图，O(E log V)）。MST 用于网络布线、集群连通、图像分割。

```text
MST 要点：
1. Kruskal —— 边排序 + 并查集，稀疏图首选
2. Prim —— 顶点扩展 + 最小堆，稠密图首选
3. 性质 —— V-1 条边，无环，总权最小
4. 应用 —— 布线、管网设计、聚类
```

```python
def kruskal(n, edges):
    """edges: [(u, v, w)]，返回 MST 边集与总权。"""
    edges = sorted(edges, key=lambda e: e[2])
    uf = UnionFind(n)
    mst, total = [], 0
    for u, v, w in edges:
        if not uf.connected(u, v):
            uf.union(u, v)
            mst.append((u, v, w))
            total += w
        if len(mst) == n - 1:
            break
    return mst, total

edges = [(0,1,4),(0,2,1),(1,2,2),(1,3,5),(2,3,8),(3,4,3)]
mst, total = kruskal(5, edges)
print("MST 边 =", mst, "总权 =", total)
```

## SCC

强连通分量（Strongly Connected Components，SCC）是有向图的极大子集，其中任意两点互相可达。SCC 把有向图「缩点」成一个 DAG（每个 SCC 一个点），揭示图的骨架结构。经典算法有 Kosaraju（两次 DFS）和 Tarjan（一次 DFS + 维护 low 值）。SCC 用于分析网页互链集群、社交圈、程序依赖环。

```text
SCC 要点：
1. 强连通 —— 子集内任意两点互相可达
2. Kosaraju —— 原图 DFS 逆后序 + 反向图 DFS，两次 DFS
3. Tarjan —— 一次 DFS，用 dfn/low 找分量
4. 缩点 —— SCC 合并后形成 DAG，便于分析骨架
```

```python
def kosaraju(adj):
    n = len(adj)
    # 反向图
    radj = [[] for _ in range(n)]
    for u in range(n):
        for v, _ in adj[u]:
            radj[v].append((u, 1))
    # 第一次 DFS 求后序
    visited = [False] * n
    order = []
    def dfs1(u):
        visited[u] = True
        for v, _ in adj[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)
    for i in range(n):
        if not visited[i]:
            dfs1(i)
    # 第二次 DFS 按逆后序在反向图上找分量
    visited = [False] * n
    comp = [-1] * n
    def dfs2(u, cid):
        visited[u] = True
        comp[u] = cid
        for v, _ in radj[u]:
            if not visited[v]:
                dfs2(v, cid)
    cid = 0
    for u in reversed(order):
        if not visited[u]:
            dfs2(u, cid)
            cid += 1
    return comp

# 0→1→2→0 构成 SCC，3→4 单独
adj = build_adj_list(5, [(0,1),(1,2),(2,0),(2,3),(3,4)], directed=True)
print("SCC 编号 =", kosaraju(adj))
```

## PageRank

PageRank 是 Google 的网页排名算法，用「随机游走」思想评估节点重要性：一个节点被越多重要节点链接，它越重要。迭代公式 PR(v) = (1-d)/N + d·Σ PR(u)/L(u)，d 是阻尼系数（默认 0.85）。它把图结构转成稳定分布（马尔可夫链收敛），是图计算、推荐系统、社交影响力分析的开山算法，Spark GraphX 有内置实现。

```text
PageRank 要点：
1. 核心思想 —— 被重要节点链接的节点也重要
2. 公式 —— PR = (1-d)/N + d·Σ(PR/出度)，d 阻尼系数 0.85
3. 迭代收敛 —— 反复传播直到稳定，是马尔可夫链稳态
4. 应用 —— 网页排名、社交影响力、推荐排序、金融网络
```

```python
def pagerank(adj, d=0.85, iters=50):
    n = len(adj)
    pr = [1.0 / n] * n
    out_deg = [len(adj[u]) for u in range(n)]
    for _ in range(iters):
        new_pr = [(1 - d) / n] * n
        for u in range(n):
            for v, _ in adj[u]:
                new_pr[v] += d * pr[u] / out_deg[u]
        pr = new_pr
    return pr

# 一个简单的网页链接网络
adj = build_adj_list(4, [(0,1),(0,2),(1,2),(2,0),(3,2)], directed=True)
rank = pagerank(adj)
print("PageRank =", [round(r, 4) for r in rank])
```

## 应用场景实战

### 场景一：用拓扑排序做任务依赖调度

```python
from collections import deque

def schedule_tasks(adj, task_names):
    """按依赖顺序输出任务执行序列。"""
    n = len(adj)
    indeg = [0] * n
    for u in range(n):
        for v, _ in adj[u]:
            indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v, _ in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    if len(order) < n:
        return "存在循环依赖，无法调度"
    return [task_names[i] for i in order]

tasks = ["建表", "抽取", "清洗", "聚合", "报表"]
# 依赖：建表→抽取→清洗→聚合→报表，清洗也依赖抽取
adj = build_adj_list(5, [(0,1),(1,2),(2,3),(3,4)], directed=True)
print("执行顺序 =", schedule_tasks(adj, tasks))
```

### 场景二：用并查集分析社交网络的朋友圈数量

```python
def count_friend_circles(n, friendships):
    """friendships: [(a,b)] 朋友关系，返回朋友圈个数。"""
    uf = UnionFind(n)
    for a, b in friendships:
        uf.union(a, b)
    roots = {uf.find(i) for i in range(n)}
    return len(roots)

# 8 个人，3 个朋友圈
friendships = [(0,1),(1,2),(3,4),(5,6),(6,7)]
print("朋友圈数量 =", count_friend_circles(8, friendships))   # 3
```

## 最佳实践与踩坑记录

### 最佳实践

1. 稀疏图用邻接表，稠密图才用邻接矩阵，避免内存浪费
2. 无权图求最短路用 BFS，别用 Dijkstra（BFS 更简单且同为最优）
3. 有负权边用 Bellman-Ford，非负权用 Dijkstra，别混用
4. 动态连通性/判环用并查集，比每次 DFS 高效
5. 依赖调度先判环（拓扑排序结果长度 < V 即有环）
6. 大规模图用图计算框架（GraphX、Giraph），单机算法撑不住亿级图

### 踩坑记录

```text
坑 1：Dijkstra 用在负权图上结果错误
结论：算出的「最短路」不是真正最短路。
原因：Dijkstra 假设已确定节点的最短距不再变小，负权边会打破这个前提。
解法：负权边用 Bellman-Ford 或 SPFA，判负环用 Bellman-Ford 第 V 轮。

坑 2：BFS 忘记 visited 标记导致死循环
结论：程序无限循环或队列爆炸。
原因：无向图/有环图中节点被反复入队。
解法：入队即标记 visited，而不是出队时标记。

坑 3：并查集只 union 不路径压缩导致退化
结论：find 退化成 O(n)，大规模下性能差。
原因：父指针链越来越长，没有压缩成扁平的树。
解法：find 里做路径压缩 + union 按秩合并，保证近似 O(1)。

坑 4：把 PageRank 用于无出度节点导致不收敛
结论：结果震荡或死节点分数丢失。
原因：出度为 0 的节点（悬挂节点）无法传递权重，概率不守恒。
解法：对悬挂节点按均匀分布分摊权重，或引入随机跳转（teleport）。
```
