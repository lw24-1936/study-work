## 概述

线性结构是元素按「顺序」组织的数据结构，是最基础的抽象。它们按访问方式和插入删除位置的不同分化成数组、链表、栈、队列、双端队列、优先队列。大数据系统里处处是它们的影子：消息队列（Kafka）是队列的持久化实现，任务调度（YARN/线程池）靠优先队列，函数调用和表达式求值靠栈。理解线性结构的复杂度取舍，是理解一切高级数据结构的前提。

```text
六大线性结构速览：
1. 数组       —— 连续内存，O(1) 随机访问，插入删除 O(n)
2. 链表       —— 分散节点，O(1) 头插/删除，访问 O(n)
3. 栈         —— LIFO 后进先出，只操作一端
4. 队列       —— FIFO 先进先出，入队尾出队头
5. Deque      —— 双端队列，两端都可插入删除
6. Priority Queue —— 按优先级出队，底层是堆
```

## 数组

数组（Array）是连续内存上存储同类型元素的线性结构，支持 O(1) 的随机访问（通过下标直接计算地址），是缓存友好度最高的结构。代价是插入/删除需移动元素（O(n)），且定长数组扩容要整体拷贝。数组是其他结构的基础——哈希表的桶、堆的底层、字符串的存储都是数组。

```text
数组要点：
1. 随机访问 O(1) —— 基地址 + 下标 × 元素大小，一步算地址
2. 缓存友好 —— 连续内存，顺序遍历预取命中率高
3. 插入删除 O(n) —— 中间插入要移动后续元素
4. 动态扩容 —— 满时翻倍拷贝，摊销 O(1)（见摊销分析）
```

```python
class ArrayList:
    """用 Python 列表演示动态数组的扩容与插入删除。"""
    def __init__(self):
        self.data = []

    def get(self, i):          # O(1) 随机访问
        return self.data[i]

    def insert(self, i, x):    # O(n)：中间插入需移动
        self.data.insert(i, x)

    def remove(self, i):       # O(n)：删除后移动
        return self.data.pop(i)

    def __repr__(self):
        return str(self.data)

arr = ArrayList()
for x in [1, 2, 3, 4, 5]:
    arr.data.append(x)
print("随机访问 arr[2] =", arr.get(2))   # 3
arr.insert(1, 99)
print("中间插入后 =", arr)               # [1, 99, 2, 3, 4, 5]
arr.remove(1)
print("删除后 =", arr)
```

## 链表

链表（Linked List）由一个个节点组成，每个节点存数据 + 指向下一个节点的指针，节点在内存中分散，靠指针串起来。它的优势是 O(1) 的头插/头删（只需改指针），劣势是访问第 i 个元素要 O(n) 遍历、且缓存不友好。分单向、双向、循环三种。链表是 LRU 缓存、哈希表冲突链、跳跃表等结构的基础。

```text
链表要点：
1. 头插/头删 O(1) —— 只改指针，无需移动元素
2. 随机访问 O(n) —— 必须从头一步步走
3. 缓存不友好 —— 节点分散，遍历缓存命中率低
4. 双向链表 —— 多存一个 prev 指针，删除任意节点 O(1)
```

```python
class Node:
    __slots__ = ('val', 'next')
    def __init__(self, val, nxt=None):
        self.val = val
        self.next = nxt

class LinkedList:
    def __init__(self):
        self.head = None

    def prepend(self, val):          # O(1) 头插
        self.head = Node(val, self.head)

    def find(self, val):             # O(n) 查找
        cur = self.head
        idx = 0
        while cur:
            if cur.val == val:
                return idx
            cur = cur.next
            idx += 1
        return -1

    def to_list(self):
        out, cur = [], self.head
        while cur:
            out.append(cur.val)
            cur = cur.next
        return out

ll = LinkedList()
for v in [1, 2, 3]:
    ll.prepend(v)          # 头插，最终顺序 [3, 2, 1]
print("链表 =", ll.to_list())
print("查找 2 的位置 =", ll.find(2))
```

## 栈

栈（Stack）是 LIFO（Last In First Out）结构，只能在栈顶插入（push）和删除（pop），看栈顶叫 peek。它的特性天然匹配「后进先出」的场景：函数调用栈、表达式求值、括号匹配、DFS 的显式实现、浏览器的前进后退。栈的所有操作都是 O(1)。

```text
栈要点：
1. LIFO —— 最后进来的最先出去
2. 操作 —— push/pop/peek 均为 O(1)
3. 应用 —— 括号匹配、表达式求值、函数调用、DFS、撤销操作
4. 单调栈 —— 维护栈内单调性，解「下一个更大元素」类问题
```

```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, x):        # O(1)
        self.items.append(x)

    def pop(self):            # O(1)
        return self.items.pop()

    def peek(self):           # O(1)
        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

# 括号匹配：判断括号串是否合法
def is_valid(s):
    st = Stack()
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            st.push(ch)
        else:
            if st.is_empty() or st.pop() != pairs[ch]:
                return False
    return st.is_empty()

print(is_valid("()[]{}"))     # True
print(is_valid("([)]"))       # False

# 单调栈：求每个元素右边第一个比它大的元素下标
def next_greater(nums):
    st, res = [], [-1] * len(nums)
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:
            res[st.pop()] = x
        st.append(i)
    return res

print(next_greater([2, 1, 2, 4, 3]))   # [4, 2, 4, -1, -1]
```

## 队列

队列（Queue）是 FIFO（First In First Out）结构，队尾入队（enqueue）、队头出队（dequeue）。它模拟「排队」语义，是消息系统、任务调度、BFS 的核心。大数据里 Kafka 是持久化分布式队列，YARN 的任务队列、线程池的阻塞队列都是队列思想。入队出队均 O(1)。

```text
队列要点：
1. FIFO —— 先进先出，公平排队
2. 操作 —— enqueue/dequeue/peek 均 O(1)
3. 应用 —— BFS、消息队列、任务调度、生产者消费者
4. 循环队列 —— 用数组 + 双指针实现，避免出队后空间浪费
```

```python
from collections import deque

class Queue:
    def __init__(self):
        self.q = deque()

    def enqueue(self, x):     # O(1)
        self.q.append(x)

    def dequeue(self):        # O(1)
        return self.q.popleft()

    def peek(self):
        return self.q[0]

    def is_empty(self):
        return len(self.q) == 0

# BFS 层序遍历一棵简单二叉树（队列的经典应用）
def level_order(root):
    if not root:
        return []
    q = Queue()
    q.enqueue(root)
    result = []
    while not q.is_empty():
        node = q.dequeue()
        result.append(node.val)
        if node.left:
            q.enqueue(node.left)
        if node.right:
            q.enqueue(node.right)
    return result

# 用简单类模拟树节点
class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

tree = TreeNode(1, TreeNode(2, TreeNode(4)), TreeNode(3))
print("BFS 层序 =", level_order(tree))   # [1, 2, 3, 4]
```

## Deque

双端队列（Deque，Double-Ended Queue）允许在两端都进行 O(1) 的插入和删除，是栈和队列的超集。Python 的 collections.deque 用双向链表 + 分块实现，两端操作都是 O(1)。Deque 是滑动窗口（求窗口最大值）、单调队列、LRU 缓存的理想结构——既能从尾部加新元素，又能从头部淘汰旧元素。

```text
Deque 要点：
1. 两端 O(1) —— 头尾都可 push/pop
2. 超集 —— 既能当栈（限制一端）又能当队列（一端进一端出）
3. 应用 —— 滑动窗口最大值、单调队列、LRU 缓存
4. Python —— collections.deque 支持 appendleft/popleft
```

```python
from collections import deque

# 单调队列求滑动窗口最大值：O(n)
def max_sliding_window(nums, k):
    dq = deque()   # 存下标，队头始终是窗口内最大值的下标
    res = []
    for i, x in enumerate(nums):
        # 从队尾弹出比当前小的（保持单调递减）
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        # 队头滑出窗口则弹出
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

print(max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))
# [3, 3, 5, 5, 6, 7]
```

## Priority Queue

优先队列（Priority Queue）不按插入顺序、而按「优先级」出队，出队总是取优先级最高（或最低）的元素。底层通常是二叉堆，插入和删除堆顶都是 O(log n)，取堆顶 O(1)。它用于任务调度（优先级高的先执行）、Top-K 问题、Dijkstra 最短路、Huffman 编码、数据流中位数。大数据里 YARN 的多队列调度、Spark 的任务排序都基于优先级思想。

```text
优先队列要点：
1. 按优先级出队，不是 FIFO
2. 底层二叉堆 —— push/pop O(log n)，peek O(1)
3. Python —— heapq 实现的是「最小堆」，取最大需取负或自定义
4. 应用 —— Top-K、Dijkstra、任务调度、合并 K 个有序链表
```

```python
import heapq

class MinPriorityQueue:
    def __init__(self):
        self.heap = []

    def push(self, priority, item):   # O(log n)
        heapq.heappush(self.heap, (priority, item))

    def pop(self):                    # O(log n)，弹出优先级最小的
        return heapq.heappop(self.heap)

    def peek(self):                   # O(1)
        return self.heap[0]

    def __len__(self):
        return len(self.heap)

# Top-K：用大小为 K 的最小堆求最大的 K 个元素
def top_k(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)   # 弹出堆里最小的，保留最大的 K 个
    return sorted(heap, reverse=True)

print(top_k([3, 1, 5, 7, 2, 8, 4, 6], 3))   # [8, 7, 6]

# 最大堆：存负值
def max_heap_demo(nums):
    heap = [-x for x in nums]
    heapq.heapify(heap)
    return -heapq.heappop(heap)

print("最大值 =", max_heap_demo([3, 9, 1, 7]))
```

## 应用场景实战

### 场景一：用栈实现一个简单的表达式计算器

```python
def calc(s):
    """支持 + - * / 和括号的简易计算器（只处理非负整数）。"""
    num, sign, stack = 0, '+', []
    s += '+'
    for ch in s:
        if ch.isdigit():
            num = num * 10 + int(ch)
        elif ch in '+-*/':
            if sign == '+':
                stack.append(num)
            elif sign == '-':
                stack.append(-num)
            elif sign == '*':
                stack.append(stack.pop() * num)
            elif sign == '/':
                stack.append(int(stack.pop() / num))
            num, sign = 0, ch
        elif ch == '(':
            # 简化处理：这里演示核心逻辑，完整括号处理可递归
            pass
    return sum(stack)

print(calc("3+2*2"))        # 7
print(calc("10-4/2"))       # 8
```

### 场景二：用队列模拟生产者消费者（消息队列思想）

```python
from collections import deque
import random

class MessageQueue:
    """简化版消息队列：生产者入队，消费者出队。"""
    def __init__(self, capacity):
        self.q = deque()
        self.capacity = capacity

    def produce(self, msg):        # 队列满则丢弃（背压的最简模拟）
        if len(self.q) < self.capacity:
            self.q.append(msg)
            return True
        return False

    def consume(self):
        return self.q.popleft() if self.q else None

mq = MessageQueue(3)
produced = consumed = 0
for i in range(10):
    if mq.produce(f"msg-{i}"):
        produced += 1
    if random.random() < 0.5:
        msg = mq.consume()
        if msg:
            consumed += 1
print(f"生产 {produced} 条，消费 {consumed} 条，队列剩余 {len(mq.q)} 条")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 频繁随机访问选数组，频繁头插头删选链表，别用错结构
2. 成员判断、去重用 set/dict，不要用 list 的 in 做 O(n) 扫描
3. 字符串拼接用列表收集再 join，避免 O(n²)
4. 需要「窗口内最值」用单调队列/单调栈，别每次暴力重扫
5. Top-K 用大小为 K 的最小堆，复杂度 O(n log k) 而非 O(n log n)
6. Python 里优先队列用 heapq，需要最大堆时存负值

### 踩坑记录

```text
坑 1：在遍历列表时增删元素
结论：索引错乱，漏处理或越界。
原因：删除元素后后续元素前移，循环索引与内容错位。
解法：倒序遍历删除，或用列表推导式/过滤生成新列表。

坑 2：用 list 当队列用 pop(0)
结论：每次 pop(0) 都是 O(n)，大数据量下极慢。
原因：pop(0) 要移动所有后续元素，退化成 O(n) 的伪队列。
解法：用 collections.deque 的 popleft()，两端操作 O(1)。

坑 3：把栈/队列的复杂度记混
结论：误以为链表随机访问 O(1)，写出低效代码。
原因：链表访问第 i 个元素要 O(n) 遍历，只有头尾操作是 O(1)。
解法：牢记「数组访问快、链表增删快」，查表对照使用。

坑 4：优先队列默认是最小堆却按最大堆用
结论：Top-K 结果取反，拿到的是最小的 K 个。
原因：Python heapq 是最小堆，heappop 弹出的是最小值。
解法：求最大 K 个时用最小堆+淘汰策略，或对值取负。
```
