## 概述

算法思想是「解题的通用套路」，比具体算法更本质。贪心是「每一步选当下最优」，分治是「把问题拆成子问题再合并」，动态规划是「记住子问题避免重复计算」，回溯是「试错 + 撤销」，随机化是「用随机性规避最坏情况」，近似算法是「放弃精确换可行」。面对一个陌生问题，先识别它属于哪种思想，再套用框架，是高效解题的关键。

```text
六大算法思想的本质：
1. 贪心 —— 每步局部最优，希望得到全局最优（需证明）
2. 分治 —— 拆子问题 + 递归求解 + 合并结果
3. 动态规划 —— 最优子结构 + 重叠子问题 + 记忆化
4. 回溯 —— 深度优先试错，失败撤销（剪枝优化）
5. 随机化 —— 随机选点/打乱，规避最坏输入
6. 近似算法 —— 求「接近最优」的可行解，换取效率
```

## 贪心

贪心（Greedy）算法在每一步都做「当下看起来最好」的选择，不回溯、不考虑未来。它的问题在于局部最优不一定全局最优——只有满足「贪心选择性质」和「最优子结构」时贪心才正确（如哈夫曼编码、活动选择、部分背包、Dijkstra、Prim）。判断能否用贪心，关键是能否证明「每次贪心选择都不会错过最优解」。

```text
贪心要点：
1. 每步局部最优，不做回溯
2. 适用前提 —— 贪心选择性质 + 最优子结构
3. 经典 —— 找零、活动选择、哈夫曼、Dijkstra、Prim、区间调度
4. 陷阱 —— 0-1 背包贪心会错，需动态规划
```

```python
def activity_selection(starts, ends):
    """选择最多不重叠的活动（经典贪心：按结束时间排序）。"""
    acts = sorted(zip(ends, starts))   # 按结束时间排序
    count, last_end = 0, -1
    chosen = []
    for end, start in acts:
        if start >= last_end:
            chosen.append((start, end))
            last_end = end
            count += 1
    return chosen

starts = [1, 3, 0, 5, 8, 5]
ends   = [2, 4, 6, 7, 9, 9]
print("选择的活动 =", activity_selection(starts, ends))

def coin_change(coins, amount):
    """找零（硬币面值可贪心的场景：如人民币 1/5/10/20）。"""
    coins = sorted(coins, reverse=True)
    result = []
    for c in coins:
        while amount >= c:
            amount -= c
            result.append(c)
    return result if amount == 0 else None

print("找零 63 =", coin_change([25, 10, 5, 1], 63))
```

## 分治

分治（Divide and Conquer）把问题分成若干相同形式的子问题，递归求解后合并子问题的解。典型三步：分解（Divide）、求解（Conquer）、合并（Combine）。归并排序、快速排序、二分查找、大整数乘法（Karatsuba）、最近点对、矩阵乘（Strassen）都是分治。分治的关键是子问题独立（无重叠），合并代价可控。

```text
分治要点：
1. 三步 —— 分解、递归求解、合并
2. 子问题独立 —— 不重叠，与动态规划的区别
3. 复杂度 —— 主定理 T(n) = aT(n/b) + f(n)
4. 经典 —— 归并/快排、二分、最近点对、Karatsuba
```

```python
def max_subarray_divide(arr):
    """分治求最大子数组和（跨越中点的部分单独算）。"""
    def _solve(lo, hi):
        if lo == hi:
            return arr[lo]
        mid = (lo + hi) // 2
        left_max = _solve(lo, mid)
        right_max = _solve(mid + 1, hi)
        # 跨越中点的最大和
        l_sum, best_l = 0, float('-inf')
        for i in range(mid, lo - 1, -1):
            l_sum += arr[i]
            best_l = max(best_l, l_sum)
        r_sum, best_r = 0, float('-inf')
        for i in range(mid + 1, hi + 1):
            r_sum += arr[i]
            best_r = max(best_r, r_sum)
        return max(left_max, right_max, best_l + best_r)
    return _solve(0, len(arr) - 1)

print("最大子数组和 =", max_subarray_divide([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 6
```

## 动态规划

动态规划（Dynamic Programming，DP）解决「最优子结构 + 重叠子问题」的问题：把大问题分解成子问题，用数组/表记住子问题的解，避免重复计算。核心是定义状态、写出状态转移方程、确定边界与遍历顺序。从斐波那契到背包、最长公共子序列、编辑距离、Floyd 最短路、Viterbi，DP 是算法思想的集大成者。

```text
动态规划要点：
1. 适用 —— 最优子结构 + 重叠子问题
2. 三步 —— 定义状态、状态转移方程、初始化边界
3. 自底向上（填表）vs 自顶向下（记忆化递归）
4. 优化 —— 滚动数组省空间，状态压缩
```

```python
def knapsack_01(weights, values, capacity):
    """0-1 背包：每件物品选或不选。"""
    dp = [0] * (capacity + 1)   # 滚动数组（一维优化）
    for w, v in zip(weights, values):
        for c in range(capacity, w - 1, -1):   # 倒序避免重复选
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[capacity]

def lcs(s1, s2):
    """最长公共子序列长度。"""
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

print("0-1 背包最大价值 =", knapsack_01([2, 3, 4, 5], [3, 4, 5, 6], 8))  # 10
print("LCS('abcde','ace') =", lcs("abcde", "ace"))   # 3
```

## 回溯

回溯（Backtracking）系统地枚举所有候选解，采用「试错 + 撤销」：每步做一个选择并前进，若发现走不通就撤销上一步（回溯），换一个选择继续。它是 DFS 的泛化，用于组合、排列、子集、N 皇后、数独、迷宫等「枚举所有解」的问题。关键优化是剪枝（提前排除不可能的分支）和去重。

```text
回溯要点：
1. 试错 + 撤销 —— 选、递归、撤销三步
2. 本质 DFS —— 枚举解空间树
3. 剪枝 —— 提前排除无效分支，大幅提速
4. 应用 —— 排列组合、N 皇后、数独、路径枚举
```

```python
def permute(nums):
    """全排列：经典回溯。"""
    res = []
    used = [False] * len(nums)
    def backtrack(path):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack(path)
            path.pop()          # 撤销
            used[i] = False     # 撤销
    backtrack([])
    return res

def solve_n_queens(n):
    """N 皇后：回溯 + 列/对角线剪枝。"""
    cols = set(); diag1 = set(); diag2 = set()
    res = []
    def backtrack(row, board):
        if row == n:
            res.append(board[:])
            return
        for c in range(n):
            if c in cols or (row - c) in diag1 or (row + c) in diag2:
                continue
            cols.add(c); diag1.add(row - c); diag2.add(row + c)
            board.append(c)
            backtrack(row + 1, board)
            board.pop()
            cols.remove(c); diag1.remove(row - c); diag2.remove(row + c)
    backtrack(0, [])
    return len(res)

print("全排列 [1,2,3] =", permute([1, 2, 3]))
print("4 皇后解数 =", solve_n_queens(4))   # 2
```

## 随机化

随机化（Randomized Algorithm）引入随机性来改善性能或简化实现：随机快速排序（随机 pivot 规避最坏 O(n²)）、随机化快速选择、蒙特卡洛（可能给错答案但概率极小，如 Miller-Rabin 素性测试）、拉斯维加斯（答案一定对但运行时间随机，如随机化快排）。大数据里，随机采样、随机哈希（避免最坏冲突）、Reservoir Sampling 都是随机化思想。

```text
随机化要点：
1. 随机 pivot/打乱 —— 规避最坏输入
2. 蒙特卡洛 —— 可能错但概率极小（素性测试）
3. 拉斯维加斯 —— 一定对但耗时随机（随机快排）
4. 应用 —— 采样、哈希、负载均衡、近似统计
```

```python
import random

def reservoir_sample(stream, k):
    """蓄水池抽样：从长度未知的流中均匀抽取 k 个。"""
    sample = []
    for i, item in enumerate(stream):
        if i < k:
            sample.append(item)
        else:
            j = random.randint(0, i)
            if j < k:
                sample[j] = item
    return sample

def miller_rabin(n, k=5):
    """Miller-Rabin 素性测试（蒙特卡洛，误判概率 < 4^-k）。"""
    if n < 2:
        return False
    for p in [2, 3, 5, 7, 11]:
        if n % p == 0:
            return n == p
    d, s = n - 1, 0
    while d % 2 == 0:
        d //= 2; s += 1
    for _ in range(k):
        a = random.randint(2, n - 2)
        x = pow(a, d, n)
        if x in (1, n - 1):
            continue
        for _ in range(s - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False
    return True

print("蓄水池抽样 =", reservoir_sample(range(1000), 5))
print("is_prime(97) =", miller_rabin(97))   # True
```

## 近似算法

近似算法（Approximation Algorithm）面向 NP-hard 问题，不求最优解，只求「有质量保证的近似解」——用近似比（approximation ratio）衡量「最坏情况下解与最优解的差距」。典型有顶点覆盖的 2-近似、旅行商的 1.5-近似（Christofides）、集合覆盖的贪心 ln n-近似。大数据场景下，HyperLogLog、Count-Min Sketch 等概率数据结构也是「近似」思想的工程化。

```text
近似算法要点：
1. 面向 NP-hard —— 精确解指数级不可行
2. 近似比 —— 解质量有理论上界保证
3. 经典 —— 顶点覆盖 2-近似、集合覆盖 ln n-近似
4. 工程化 —— 概率数据结构用近似换空间/时间
```

```python
def vertex_cover_approx(edges):
    """顶点覆盖 2-近似：任取一条边，把两端点都加入覆盖。"""
    cover = set()
    remaining = set(edges)
    while remaining:
        u, v = remaining.pop()
        cover.add(u)
        cover.add(v)
        # 删除所有与 u 或 v 相关的边
        remaining = {e for e in remaining if u not in e and v not in e}
    return cover

edges = [(0,1),(0,2),(1,3),(2,3),(3,4)]
print("顶点覆盖 =", vertex_cover_approx(edges))
```

## 应用场景实战

### 场景一：用动态规划做字符串相似度（编辑距离）

```python
def edit_distance(s1, s2):
    """编辑距离：插入/删除/替换的最小次数。"""
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i - 1] == s2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],      # 删除
                                   dp[i][j - 1],      # 插入
                                   dp[i - 1][j - 1])  # 替换
    return dp[m][n]

print("编辑距离('kitten','sitting') =", edit_distance("kitten", "sitting"))  # 3
# 应用：拼写纠错、模糊匹配、DNA 序列比对
```

### 场景二：用贪心做区间调度（资源分配）

```python
def max_concurrent_jobs(intervals):
    """贪心：选最多不重叠的区间（类比调度最多任务）。"""
    intervals = sorted(intervals, key=lambda x: x[1])   # 按结束时间
    chosen, last_end = [], float('-inf')
    for start, end in intervals:
        if start >= last_end:
            chosen.append((start, end))
            last_end = end
    return chosen

jobs = [(1, 4), (3, 5), (0, 6), (5, 7), (3, 8), (5, 9), (6, 10), (8, 11)]
print("最多可调度 =", max_concurrent_jobs(jobs))
# 应用：会议室分配、任务排期、资源调度
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先判断问题属于哪种思想：求「最值 + 可拆子问题」想 DP，「每步选最优」想贪心
2. 贪心必须能证明正确性，不能凭直觉——0-1 背包贪心就是错的
3. DP 先写状态定义和转移方程，再写代码，别上来就写循环
4. 回溯记得剪枝和去重，否则指数爆炸
5. 快排/快速选择用随机化 pivot，规避最坏输入
6. 精确解不可行时考虑近似算法，并明确近似比

### 踩坑记录

```text
坑 1：贪心不加证明直接用
结论：0-1 背包等场景贪心结果错误，且难察觉。
原因：贪心只在满足贪心选择性质时正确，很多问题局部最优不等于全局最优。
解法：用反例验证；拿不准就用动态规划（一定能出正确解）。

坑 2：DP 忘记初始化边界导致结果全错
结论：递推从错误起点开始，答案错误。
原因：dp[0] 或首行首列未正确初始化，转移时读到了错误初值。
解法：先把边界（i=0、j=0）显式填好，再写转移循环。

坑 3：回溯不剪枝导致指数级超时
结论：数据稍大就跑到天荒地老。
原因：无剪枝时解空间是满树，2^n 或 n! 爆炸。
解法：加可行性剪枝、最优性剪枝，或用记忆化消除重复分支。

坑 4：把分治和 DP 混用导致重复计算
结论：分治处理重叠子问题时指数级重复计算。
原因：分治假设子问题独立，若子问题重叠（如斐波那契），会重复算多次。
解法：子问题重叠时改用 DP 或记忆化，别用朴素分治。
```
