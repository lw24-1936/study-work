## 概述

排序和查找是算法最基础也最高频的操作。查找的核心是二分查找——把有序数组的查找从 O(n) 降到 O(log n)；排序则分「比较排序」（归并/快排/堆排，理论下界 O(n log n)）和「非比较排序」（计数/基数，借助值域特性可达 O(n)）。大数据里还有「外排序」（数据放不下内存）和「Top-K」（只取最大 K 个）两个实用主题，它们直接对应 Shuffle 排序、分布式归并、Top-N 统计等真实场景。

```text
排序查找全景：
1. 二分查找 —— 有序数组 O(log n) 查找
2. 归并排序 —— 稳定 O(n log n)，外排的基础
3. 快排 —— 平均 O(n log n)，原地，实际最快
4. 堆排 —— O(n log n) 原地，适合取 Top-K
5. 计数/基数排序 —— 非比较 O(n)，依赖值域
6. 外排 —— 内存放不下时多路归并
7. Top-K —— 只取最大/最小 K 个，O(n log k)
```

## 二分查找

二分查找（Binary Search）在有序数组上每次取中点，把查找区间砍半，O(log n) 定位目标或插入位置。关键是边界处理（闭区间/开区间、mid 取法、循环条件），「lower_bound」（第一个 ≥ target 的位置）是最通用的变体。它是所有「有序 + 查找/定位」场景的基础，也是分治思想的最小示例。

```text
二分查找要点：
1. 前提 —— 数组有序（或满足单调性）
2. 复杂度 —— O(log n)，每次规模减半
3. 边界 —— 注意 mid 溢出（用 lo + (hi-lo)//2）
4. lower_bound —— 找第一个 ≥ target 的下标，最常用变体
```

```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

def lower_bound(arr, target):
    """第一个 >= target 的下标，找不到返回 len(arr)。"""
    lo, hi = 0, len(arr)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo

arr = [1, 3, 5, 7, 9, 11]
print("查找 7 =", binary_search(arr, 7))       # 3
print("lower_bound(6) =", lower_bound(arr, 6))  # 3（第一个 >=6 的是 7）
```

## 归并排序

归并排序（Merge Sort）是典型分治：递归地把数组对半切，切到单元素（天然有序），再两两合并成有序序列。合并过程是稳定的（相等元素保持原相对顺序），时间始终 O(n log n)，但需要 O(n) 辅助空间。它的「有序合并」操作是外排序、多路归并、分布式归约（Shuffle 后的 sort-merge）的核心步骤。

```text
归并排序要点：
1. 分治 —— 分到单元素再两两合并
2. 稳定 —— 相等元素顺序不变
3. 复杂度 —— 时间 O(n log n)，空间 O(n)
4. 应用 —— 外排序、链表排序、求逆序对
```

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    merged, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:     # <= 保证稳定性
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
    merged += left[i:] + right[j:]
    return merged

def count_inversions(arr):
    """归并排序顺便统计逆序对数量。"""
    def merge_count(a):
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        l, inv_l = merge_count(a[:mid])
        r, inv_r = merge_count(a[mid:])
        inv = inv_l + inv_r
        merged, i, j = [], 0, 0
        while i < len(l) and j < len(r):
            if l[i] <= r[j]:
                merged.append(l[i]); i += 1
            else:
                merged.append(r[j]); j += 1
                inv += len(l) - i      # 左边剩余的都是逆序对
        return merged + l[i:] + r[j:], inv
    return merge_count(arr)[1]

print(merge_sort([5, 2, 8, 1, 9, 3]))
print("逆序对数 =", count_inversions([2, 4, 1, 3, 5]))   # 3
```

## 快排

快速排序（Quick Sort）选一个基准（pivot），把数组分成「小于基准」和「大于基准」两半，再递归排序两边。平均 O(n log n)、原地排序、常数小，是实际最快的通用排序，Java/Python 的内置排序核心。但它不稳定，且最坏（每次 pivot 都取到极值，如已有序数组）退化到 O(n²)。随机化选 pivot 或三数取中能规避最坏。

```text
快排要点：
1. 分治 —— 选 pivot，分区，递归两边
2. 平均 O(n log n)，最坏 O(n²)（pivot 总取极值）
3. 不稳定 —— 分区交换会打乱相等元素顺序
4. 优化 —— 随机 pivot、三数取中、小数组切插入排序
```

```python
import random

def quick_sort(arr):
    def _qs(a, lo, hi):
        if lo >= hi:
            return
        # 随机选 pivot 规避最坏情况
        p = random.randint(lo, hi)
        a[lo], a[p] = a[p], a[lo]
        pivot = a[lo]
        i, j = lo, hi
        while i < j:
            while i < j and a[j] >= pivot:
                j -= 1
            while i < j and a[i] <= pivot:
                i += 1
            if i < j:
                a[i], a[j] = a[j], a[i]
        a[lo], a[i] = a[i], a[lo]
        _qs(a, lo, i - 1)
        _qs(a, i + 1, hi)
    a = arr[:]
    _qs(a, 0, len(a) - 1)
    return a

print(quick_sort([5, 2, 8, 1, 9, 3, 1]))
```

## 堆排

堆排序（Heap Sort）把数组建成大顶堆（heapify），反复把堆顶（最大值）与末尾交换并缩小堆，再下沉调整。时间 O(n log n)、原地 O(1) 空间、不稳定。它的优势是不需要额外空间且能「流式」取前 K 个——Top-K 问题用大小为 K 的堆，复杂度 O(n log k)。建堆本身是 O(n)（自底向上 heapify）。

```text
堆排要点：
1. 建堆 O(n) —— 自底向上从最后一个非叶节点下沉
2. 排序 O(n log n) —— 反复取堆顶交换再下沉
3. 原地 —— 只用 O(1) 额外空间
4. 应用 —— Top-K、优先队列、合并有序流
```

```python
def heapify(arr, n, i):
    largest = i
    l, r = 2 * i + 1, 2 * i + 2
    if l < n and arr[l] > arr[largest]:
        largest = l
    if r < n and arr[r] > arr[largest]:
        largest = r
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)

def heap_sort(arr):
    a = arr[:]
    n = len(a)
    for i in range(n // 2 - 1, -1, -1):   # 建大顶堆 O(n)
        heapify(a, n, i)
    for i in range(n - 1, 0, -1):         # 排序
        a[0], a[i] = a[i], a[0]
        heapify(a, i, 0)
    return a

print(heap_sort([5, 2, 8, 1, 9, 3]))
```

## 计数排序

计数排序（Counting Sort）是非比较排序：统计每个值出现的次数，再按值顺序重建数组。时间 O(n + k)（k 是值域范围），稳定，但要求元素是整数且值域不大——值域太大则计数数组也巨大，浪费内存。它适合「值域小、数据量大」的场景，如年龄、成绩、灰度值排序，也是基数排序的子步骤。

```text
计数排序要点：
1. 非比较 —— 依赖值域，不依赖元素间比较
2. 复杂度 —— O(n + k)，k 为值域大小
3. 稳定 —— 可用前缀和定位保持顺序
4. 限制 —— 只适合整数且值域小
```

```python
def counting_sort(arr):
    if not arr:
        return []
    max_v = max(arr)
    cnt = [0] * (max_v + 1)
    for x in arr:
        cnt[x] += 1
    # 前缀和定位，保证稳定
    for i in range(1, len(cnt)):
        cnt[i] += cnt[i - 1]
    out = [0] * len(arr)
    for x in reversed(arr):      # 倒序保证稳定
        cnt[x] -= 1
        out[cnt[x]] = x
    return out

print(counting_sort([3, 1, 4, 1, 5, 9, 2, 6]))
```

## 基数排序

基数排序（Radix Sort）按「位」逐位排序：从最低位到最高位，每位用计数排序（稳定）作为子步骤。时间 O(d·(n+k))，d 是位数，k 是每位进制。它突破了「比较排序 O(n log n) 下界」——因为它不比较元素大小，而是按位处理。适合整数、定长字符串（如手机号、日期）排序，是字符串排序（LSD）的标准方法。

```text
基数排序要点：
1. 按位稳定排序 —— 低位到高位，每位用计数排序
2. 复杂度 —— O(d·(n+k))，突破比较排序下界
3. 应用 —— 整数、定长字符串、电话号码
4. 变体 —— LSD（低位优先）与 MSD（高位优先）
```

```python
def radix_sort(arr):
    if not arr:
        return []
    max_v = max(arr)
    exp = 1
    a = arr[:]
    while max_v // exp > 0:
        buckets = [[] for _ in range(10)]
        for x in a:
            buckets[(x // exp) % 10].append(x)
        a = [x for b in buckets for x in b]   # 稳定收集
        exp *= 10
    return a

print(radix_sort([170, 45, 75, 90, 802, 24, 2, 66]))
```

## 外排

外排序（External Sort）处理「数据远大于内存」的排序：把大文件切成能装入内存的块，每块内排序后写回磁盘成「有序段」（run），再用多路归并把所有 run 合并成一个有序大文件。核心是减少磁盘 IO——用置换选择（Replacement Selection）生成更长的初始 run，用败者树优化多路归并。这是 Hadoop Shuffle 排序、数据库大表排序的底层原理。

```text
外排要点：
1. 分块内排序 —— 每块装入内存排序，生成有序 run
2. 多路归并 —— 同时归并 K 个 run，IO 次数与 K 相关
3. 目标 —— 最小化磁盘 IO 次数
4. 应用 —— Hadoop Shuffle、数据库 ORDER BY 大表
```

```python
import heapq

def external_sort_sketch(chunks):
    """多路归并的演示：合并 K 个已排序 chunk。"""
    heap = []
    iters = [iter(c) for c in chunks]
    for i, it in enumerate(iters):
        first = next(it, None)
        if first is not None:
            heapq.heappush(heap, (first, i))
    out = []
    while heap:
        val, i = heapq.heappop(heap)
        out.append(val)
        nxt = next(iters[i], None)
        if nxt is not None:
            heapq.heappush(heap, (nxt, i))
    return out

# 三个已排序的 run（模拟磁盘上的有序段）
runs = [[1, 4, 7], [2, 5, 8], [3, 6, 9]]
print("多路归并结果 =", external_sort_sketch(runs))
```

## Top-K

Top-K 问题是从 n 个元素中找出最大（或最小）的 K 个，不需要全排序。标准解法是维护一个大小为 K 的最小堆：遍历所有元素，堆满后每来一个就与堆顶比，更大则替换堆顶并下沉。复杂度 O(n log k)，k 远小于 n 时远优于 O(n log n) 的全排序。它对应「热门商品 Top-N」「访问量最高的 URL」等大数据统计。

```text
Top-K 要点：
1. 最小堆求最大 K 个 —— 堆顶是「当前第 K 大」，淘汰小的
2. 复杂度 O(n log k) —— 只维护 K 个，不排序全部
3. 变体 —— 快速选择（Quick Select）平均 O(n) 求第 K 大
4. 应用 —— 热门统计、排行榜、异常值检测
```

```python
import heapq

def top_k(nums, k):
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)      # 淘汰最小的
    return sorted(heap, reverse=True)

# 快速选择：求第 K 大，平均 O(n)
def quick_select(arr, k):
    import random
    a = arr[:]
    def _select(lo, hi, k):
        p = random.randint(lo, hi)
        a[p], a[hi] = a[hi], a[p]
        pivot, i = a[hi], lo
        for j in range(lo, hi):
            if a[j] > pivot:         # 找第 k 大，降序分区
                a[i], a[j] = a[j], a[i]
                i += 1
        a[i], a[hi] = a[hi], a[i]
        if i == k:
            return a[i]
        return _select(lo, i - 1, k) if i > k else _select(i + 1, hi, k)
    return _select(0, len(a) - 1, k - 1)

nums = [3, 1, 5, 7, 2, 8, 4, 6, 9]
print("Top-3 =", top_k(nums, 3))           # [9, 8, 7]
print("第 3 大 =", quick_select(nums, 3))   # 7
```

## 应用场景实战

### 场景一：求海量日志中访问量最高的 Top-N URL

```python
import heapq

def top_n_urls(log_stream, n):
    """流式统计 URL 频次，维护大小为 N 的最小堆。"""
    freq = {}
    heap = []
    for url in log_stream:
        freq[url] = freq.get(url, 0) + 1
    # 建大小为 n 的最小堆（按频次）
    for url, cnt in freq.items():
        heapq.heappush(heap, (cnt, url))
        if len(heap) > n:
            heapq.heappop(heap)
    return sorted(heap, reverse=True)

logs = ["a.com","b.com","a.com","c.com","a.com","b.com","d.com","c.com","c.com"]
print("Top-2 URL =", top_n_urls(logs, 2))
```

### 场景二：用二分查找定位海量有序数据的分区边界

```text
场景：一张按 user_id 有序的十亿行大表，要按 user_id 范围分片查询。

思路：
1. 表按 user_id 有序（或可二分），先采样/记录每个分区的边界值
2. 查询 user_id = X 时，对边界数组做二分查找，定位到唯一分区
3. 只读那一个分区，而不是全表扫描

本质：二分查找把「从十亿行里找一行」降为 O(log n) 次分区定位，
      再配合 B+ 树索引把磁盘 IO 降到最低。
```

```python
def locate_partition(boundaries, user_id):
    """boundaries: 各分区起始 user_id（有序），返回所在分区下标。"""
    import bisect
    idx = bisect.bisect_right(boundaries, user_id) - 1
    return idx

# 三个分区，起始 id 分别为 1, 100001, 200001
boundaries = [1, 100001, 200001]
print("user_id=150000 在分区", locate_partition(boundaries, 150000))  # 1
print("user_id=999999 在分区", locate_partition(boundaries, 999999))  # 2
```

## 最佳实践与踩坑记录

### 最佳实践

1. 数据量小用内置 sort（快排/归并混合），别手写排序，除非是学习
2. 要求稳定排序用归并/TimSort，不要求稳定用快排（更快）
3. 值域小的整数用计数/基数排序，可到 O(n)
4. 只取前 K 个用大小为 K 的堆，别全排序再截断
5. 内存放不下用外排序（分块排序 + 多路归并）
6. 二分查找注意边界，用 lower_bound 定位插入点最稳妥

### 踩坑记录

```text
坑 1：快排遇到已有序数组退化到 O(n²)
结论：排序耗时暴涨，大数据下无法接受。
原因：每次都取第一个元素当 pivot，分区极不平衡。
解法：随机选 pivot 或三数取中，或直接用内置排序（已做优化）。

坑 2：二分查找 mid = (lo+hi)//2 整数溢出
结论：lo+hi 超出整数范围时结果错误。
原因：某些语言（如旧 Java）int 相加溢出。
解法：写成 lo + (hi - lo) // 2。

坑 3：Top-K 用最大堆导致内存和复杂度都错
结论：堆越维护越大，复杂度变成 O(n log n)。
原因：求最大 K 个应维护最小堆（淘汰小的），用最大堆会堆住全部元素。
解法：求最大 K 个用最小堆；求最小 K 个用最大堆。

坑 4：计数排序值域太大导致内存爆炸
结论：值域一亿就分配一亿的计数数组，内存溢出。
原因：计数排序内存依赖值域 k，k 大时 O(k) 空间不可行。
解法：值域大时改回比较排序，或用基数排序按位降值域。
```
