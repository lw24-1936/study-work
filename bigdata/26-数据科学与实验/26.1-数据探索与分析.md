## 概述

数据探索与分析（EDA）是在建模或深入分析前，用统计量与可视化手段理解数据的结构、分布、异常与关联关系的过程。它通过描述统计、相关性、分布、异常检测等手段发现数据质量问题、洞察业务规律，为后续建模和实验设计打基础。EDA 强调「先看数据再下结论」，用 pandas/numpy/scipy 快速迭代。

```text
数据探索分析流程：
1. 数据概览 —— 行数、列数、类型、缺失值、样本预览
2. 描述统计 —— 均值/中位数/方差/分位数，把握中心与离散
3. 分布分析 —— 直方图/箱线图/偏度峰度，识别分布形态
4. 相关性 —— 皮尔逊/斯皮尔曼，找变量间线性/单调关系
5. 异常检测 —— 3σ/IQR/孤立森林，定位脏数据与异常点
6. 分组对比 —— Cohort/漏斗/留存，业务维度洞察
```

```text
EDA 核心工具（Python）：
1. pandas —— 数据读取、清洗、聚合、透视
2. numpy —— 数值计算与向量化操作
3. scipy.stats —— 假设检验、分布拟合、相关性
4. matplotlib / seaborn —— 可视化
```

## EDA

EDA 是一套系统化「认识数据」的方法论，核心动作是概览结构、查缺失、看分布、找异常、验相关。它不追求精确结论，而是快速建立数据直觉，发现质量问题和潜在规律，指导后续特征工程与建模。EDA 输出通常是一份数据画像报告（如 pandas-profiling 自动生成）。

```text
E D A 要点：
1. 目标 —— 快速建立数据直觉，发现问题与规律
2. 步骤 —— 概览 → 缺失 → 分布 → 异常 → 相关 → 分组
3. 产物 —— 数据画像报告 + 关键洞察 + 待处理问题清单
4. 原则 —— 先看数据再建模，不盲从统计数字
```

```python
import pandas as pd
import numpy as np

np.random.seed(42)
df = pd.DataFrame({
    'user_id': np.arange(1, 10001),
    'age': np.random.randint(18, 60, 10000),
    'order_cnt': np.random.poisson(3, 10000),
    'gmv': np.random.lognormal(5, 1, 10000),
    'is_vip': np.random.choice([0, 1], 10000, p=[0.8, 0.2]),
})
df.loc[100:105, 'age'] = np.nan    # 注入缺失
df.loc[9999, 'gmv'] = 1e8          # 注入异常

print(df.shape)              # (10000, 5) 概览
print(df.isnull().sum())     # 缺失统计：age 有 6 个缺失
print(df.describe())         # 数值列基本统计
```

## 描述统计

描述统计用集中趋势（均值、中位数、众数）和离散程度（方差、标准差、极差、四分位距）刻画数据整体面貌。均值对异常值敏感，中位数稳健；标准差衡量离散，分位数刻画分布位置。描述统计是 EDA 的第一手信息，用来快速判断数据是否合理、有无明显异常。

```text
描述统计要点：
1. 集中趋势 —— 均值、中位数、众数，反映数据中心
2. 离散程度 —— 方差、标准差、极差、四分位距 IQR
3. 分位数 —— 25%/50%/75% 分位数，刻画分布位置
4. 偏度峰度 —— 偏度衡量对称性，峰度衡量尾部厚重
5. 稳健性 —— 中位数/IQR 比均值/标准差更抗异常值
```

```python
import numpy as np
from scipy import stats

x = df['gmv']
mean, median = np.mean(x), np.median(x)
std, var = np.std(x, ddof=1), np.var(x, ddof=1)   # ddof=1 无偏
q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1
skew, kurt = stats.skew(x), stats.kurtosis(x)

print(f"均值={mean:.2f} 中位数={median:.2f} 标准差={std:.2f}")
print(f"Q1={q1:.2f} Q3={q3:.2f} IQR={iqr:.2f}")
print(f"偏度={skew:.2f} 峰度={kurt:.2f}")
```

## 相关性分析

相关性分析衡量两变量之间的线性（皮尔逊）或单调（斯皮尔曼）关联强度，取值 -1 到 1。皮尔逊对异常值和线性假设敏感，斯皮尔曼基于秩更稳健。相关性矩阵是发现「哪些变量与目标相关、哪些共线」的重要工具，但「相关不等于因果」，强相关可能由混淆变量导致。

```text
相关性分析要点：
1. 皮尔逊 —— 衡量线性相关，对异常值敏感
2. 斯皮尔曼 —— 基于秩，衡量单调关系，更稳健
3. 取值 —— -1（负相关）到 +1（正相关），0 无关
4. 相关矩阵 —— 热力图展示多变量两两相关
5. 注意 —— 相关不等于因果，警惕共线性与伪相关
```

```python
from scipy import stats

r, p = stats.pearsonr(df['order_cnt'], df['gmv'])
print(f"皮尔逊 r={r:.3f}, p={p:.3e}")
rho, p2 = stats.spearmanr(df['order_cnt'], df['gmv'])
print(f"斯皮尔曼 rho={rho:.3f}, p={p2:.3e}")

corr = df[['age', 'order_cnt', 'gmv', 'is_vip']].corr()
print(corr.round(3))
target_corr = corr['gmv'].drop('gmv').sort_values(ascending=False)
print(target_corr)
```

## 分布分析

分布分析研究单个变量的取值分布形态：是正态、偏态还是长尾。通过直方图、密度曲线、箱线图、QQ 图判断分布类型，用偏度峰度量化形态。分布分析指导后续处理——长尾分布常做对数变换，偏态数据可能影响线性模型假设，异常值往往表现为分布尾部的孤立点。

```text
分布分析要点：
1. 直方图 —— 看分布形态（正态/偏态/双峰/长尾）
2. 箱线图 —— 看中位数、四分位、离群点
3. QQ 图 —— 判断是否接近正态分布
4. 变换 —— 长尾数据对数变换，使其接近正态
```

```python
import numpy as np
from scipy import stats

print(f"gmv 偏度={stats.skew(df['gmv']):.2f}")        # 右偏（长尾）
df['log_gmv'] = np.log1p(df['gmv'])                   # 对数变换
print(f"变换后偏度={stats.skew(df['log_gmv']):.2f}")

w, p = stats.shapiro(df['age'].dropna().sample(500))   # 正态性检验
print(f"Shapiro W={w:.3f}, p={p:.3f}")                 # p<0.05 拒绝正态

print(df['gmv'].quantile([0.5, 0.9, 0.99, 0.999]))     # 尾部观察
```

## 异常检测

异常检测识别数据中偏离正常模式的点，用于数据清洗（脏数据、录入错误）和业务洞察（欺诈、故障）。常用方法：基于统计的 3σ / IQR 准则（适合近似正态分布）、基于密度的孤立森林、基于距离的聚类离群。EDA 阶段以快速发现为主，需结合业务判断是「真异常」还是「脏数据」。

```text
异常检测要点：
1. 3σ 准则 —— 超出均值 ± 3 倍标准差视为异常（正态假设）
2. IQR 准则 —— 超出 [Q1-1.5*IQR, Q3+1.5*IQR] 视为离群
3. 孤立森林 —— 基于树划分，异常点更易被孤立，适合高维
4. 业务判断 —— 异常≠错误，可能是真实极端值（大客户）
```

```python
import numpy as np
from sklearn.ensemble import IsolationForest

# IQR 准则
q1, q3 = df['gmv'].quantile([0.25, 0.75])
lower, upper = q1 - 1.5 * (q3 - q1), q3 + 1.5 * (q3 - q1)
out_iqr = df[(df['gmv'] < lower) | (df['gmv'] > upper)]
print(f"IQR 检出异常数：{len(out_iqr)}")

# 3σ 准则
mean, std = df['gmv'].mean(), df['gmv'].std()
out_3s = df[np.abs(df['gmv'] - mean) > 3 * std]
print(f"3σ 检出异常数：{len(out_3s)}")

# 孤立森林（多变量联合检测）
iso = IsolationForest(contamination=0.01, random_state=42)
df['anomaly'] = iso.fit_predict(df[['age', 'order_cnt', 'gmv']].fillna(0))
print(f"孤立森林异常数：{(df['anomaly'] == -1).sum()}")
```

## Cohort

Cohort（同期群）分析把用户按某个共同特征（如注册月份、首单月份）分组，追踪各组在后续时间的行为差异，用于剥离「时间混杂」看真实趋势。常见「注册同期群」对比不同月份注册用户的首月留存或累计消费，判断获客质量变化。Cohort 通常以行为矩阵呈现：行是同期群，列是时间偏移。

```text
Cohort 要点：
1. 定义 —— 按共同特征分组的用户群，追踪纵向表现
2. 分组维度 —— 注册月、首单月、首次激活渠道
3. 观察指标 —— 留存率、累计 GMV、人均消费
4. 价值 —— 剥离整体趋势，比较不同批次的真实质量
```

```python
import pandas as pd
import numpy as np

np.random.seed(1)
regs = pd.DataFrame({
    'user_id': np.arange(1, 1001),
    'reg_month': np.random.choice(pd.date_range('2026-01', periods=4, freq='MS'), 1000),
})
orders = pd.DataFrame({
    'user_id': np.random.randint(1, 1001, 5000),
    'order_month': np.random.choice(pd.date_range('2026-01', periods=6, freq='MS'), 5000),
    'amount': np.random.uniform(10, 200, 5000),
})

merged = orders.merge(regs, on='user_id')
merged['month_offset'] = (
    merged['order_month'].dt.to_period('M') - merged['reg_month'].dt.to_period('M')
).apply(lambda x: x.n)

cohort = merged.pivot_table(
    index='reg_month', columns='month_offset',
    values='amount', aggfunc='sum').fillna(0)
print(cohort.round(1))
```

## Funnel

漏斗分析追踪用户沿多步骤流程的转化（访问→注册→下单→支付），统计各步骤人数并计算相邻步骤转化率，定位流失最严重环节。漏斗的关键是定义好「步骤顺序」和「同一会话/时间窗」，避免跨会话误匹配。它是转化优化、产品改进的核心分析工具。

```text
Funnel 要点：
1. 定义 —— 有序步骤，统计每步到达人数与转化率
2. 转化率 —— 相邻步骤人数比，定位流失环节
3. 口径 —— 严格有序（必须按序）vs 宽松（可跳跃）
4. 时间窗 —— 限定在会话/窗口内完成全流程
```

```python
import pandas as pd

events = pd.DataFrame({
    'user_id': [1, 1, 1, 2, 2, 3, 1, 4, 4, 4],
    'step': ['view', 'cart', 'order', 'view', 'cart', 'view',
             'pay', 'view', 'cart', 'pay'],
})
step_order = ['view', 'cart', 'order', 'pay']

def max_step(steps):
    idx = [step_order.index(s) for s in steps if s in step_order]
    return max(idx) if idx else -1

user_deepest = events.groupby('user_id')['step'].apply(lambda s: max_step(list(s)))
funnel = pd.DataFrame([
    {'step': s, 'users': (user_deepest >= i).sum()}
    for i, s in enumerate(step_order)
])
funnel['conv_rate'] = funnel['users'] / funnel['users'].iloc[0]
print(funnel)
```

## Retention

留存衡量用户在首次使用后于第 N 天仍活跃的比例（次日、7 日、30 日留存），是产品健康度的核心指标。留存分析通常结合 Cohort：按注册日期分组看各批用户留存曲线，判断产品改进是否真提升长期价值。留存计算本质是「首日用户集合 ∩ 第 N 日活跃集合」的占比。

```text
Retention 要点：
1. 定义 —— 第 N 日仍活跃用户 / 首日用户数
2. 指标 —— 次日/7 日/30 日留存，曲线反映衰减
3. 本质 —— 首日用户集合与第 N 日活跃集合的交集占比
4. 结合 Cohort —— 分注册批次看留存，剥离整体趋势
```

```python
import pandas as pd
import numpy as np

np.random.seed(7)
n = 5000
reg = pd.DataFrame({
    'user_id': np.arange(1, n + 1),
    'reg_date': np.random.choice(pd.date_range('2026-08-01', periods=3, freq='D'), n),
})
active = pd.DataFrame({
    'user_id': np.random.randint(1, n + 1, 20000),
    'active_date': np.random.choice(pd.date_range('2026-08-01', periods=10, freq='D'), 20000),
}).drop_duplicates()

merged = active.merge(reg, on='user_id')
merged['day_n'] = (merged['active_date'] - merged['reg_date']).dt.days
retained = merged[merged['day_n'] >= 0].drop_duplicates(['user_id', 'day_n'])

for n_day in [1, 7]:
    base = reg['user_id'].nunique()
    kept = retained[retained['day_n'] == n_day]['user_id'].nunique()
    print(f"{n_day} 日留存率 = {kept / base:.2%}")
```

## 应用场景实战

### 场景一：电商订单数据完整 EDA

```python
import pandas as pd
import numpy as np
from scipy import stats

np.random.seed(2026)
df = pd.DataFrame({
    'order_id': np.arange(1, 20001),
    'user_id': np.random.randint(1, 5001, 20000),
    'channel': np.random.choice(['app', 'h5', 'pc', 'mini'], 20000),
    'amount': np.random.lognormal(4, 0.8, 20000),
    'items': np.random.poisson(2, 20000),
})
df.loc[3:7, 'amount'] = np.nan
df.loc[19999, 'amount'] = 5e5

print(df.info())                       # 概览
print(df.isnull().sum())               # 缺失：amount 5 条
print(f"偏度={stats.skew(df['amount'].dropna()):.2f}")

q1, q3 = df['amount'].quantile([0.25, 0.75])
upper = q3 + 1.5 * (q3 - q1)
big_orders = df[df['amount'] > upper]  # 异常大额
print(f"大额异常订单数={len(big_orders)}")

channel_stats = df.groupby('channel')['amount'].agg(['mean', 'median', 'count'])
print(channel_stats.round(2))          # 分渠道对比

r, p = stats.spearmanr(df['items'].dropna(), df['amount'].dropna())
print(f"件数与金额 Spearman rho={r:.3f}")
```

```text
EDA 结论示例：
1. 数据规模 20000 行，amount 有 5 条缺失、1 条极端值
2. amount 右偏（长尾），对数变换后接近正态
3. IQR 检出 1 个极端大额订单，需业务确认是否真实
4. 各渠道客单价差异明显，app 渠道客单最高
5. 件数与金额单调正相关，符合业务直觉
```

### 场景二：用户留存与转化漏斗组合分析

```python
import pandas as pd
import numpy as np

np.random.seed(99)
reg = pd.DataFrame({
    'user_id': np.arange(1, 3001),
    'reg_date': np.random.choice(pd.date_range('2026-08-01', periods=5, freq='D'), 3000),
})
behav = pd.DataFrame({
    'user_id': np.random.randint(1, 3001, 15000),
    'step': np.random.choice(['visit', 'signup', 'order', 'pay'],
                             p=[0.5, 0.2, 0.2, 0.1], size=15000),
    'ts': np.random.choice(pd.date_range('2026-08-01', periods=10, freq='D'), 15000),
})

order = ['visit', 'signup', 'order', 'pay']
funnel = behav.groupby('step')['user_id'].nunique().reindex(order)
print("各步骤人数：", funnel.values)
conv = funnel / funnel.shift(1)
print("步骤间转化率：", conv.fillna(1).round(3).values)

merged = behav.merge(reg, on='user_id')
merged['day_n'] = (merged['ts'] - merged['reg_date']).dt.days
retained = merged[(merged['day_n'] > 0) & (merged['day_n'] <= 7)]
retention = (
    retained.drop_duplicates(['reg_date', 'user_id'])
    .groupby('reg_date')['user_id'].nunique()
    / reg.groupby('reg_date')['user_id'].nunique()
)
print("各注册批次 7 日留存率：", retention.round(3).values)
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先看数据再建模 —— 用 describe / info / 缺失统计建立第一印象，再决定建模方向
2. 分类型处理缺失 —— 数值用中位数/均值，类别用众数，关键字段缺失需追因
3. 异常值先判「真假」—— 用 IQR/3σ 快速定位后，结合业务判断是脏数据还是真实极端值
4. 长尾分布先变换 —— 对数/Box-Cox 变换后再做相关性与建模
5. 相关矩阵可视化 —— 用热力图快速发现共线性与目标相关变量
6. 结论要可复现 —— 固定随机种子、记录数据版本与清洗规则
7. EDA 结论落文档 —— 形成数据画像报告，供团队复用

### 踩坑记录

```text
坑 1：不处理缺失值直接建模
结论：模型报错或结果偏差，统计量失真。
原因：pandas 多数统计函数对 NaN 静默跳过，样本量悄悄减少。
解法：先 df.isnull().sum() 统计缺失，再按类型填充或删除。

坑 2：用皮尔逊相关分析非线性关系
结论：两个强单调非线性变量相关系数接近 0，误判为无关。
原因：皮尔逊只捕捉线性关系，对非线性/单调关系不敏感。
解法：同时计算斯皮尔曼秩相关，或用散点图目测关系形态。

坑 3：异常值一刀切删除
结论：误删真实高价值客户（大额订单），结论失真。
原因：把业务极端值当成脏数据，未区分「异常」与「错误」。
解法：异常点单独分析，确认来源后再决定删除/修正/保留。

坑 4：漏斗不限定时间窗导致跨会话误匹配
结论：把相隔数天的行为串成一个漏斗，转化率虚高。
原因：未限定同一会话或时间窗，任意时间行为都算完成流程。
解法：定义会话窗口或最大完成时长，窗口内行为才计入漏斗。

坑 5：留存分子分母口径不一致
结论：留存率计算错误，偏高或偏低。
原因：分子用「任意活跃」，分母用「注册」，口径不统一。
解法：明确定义活跃行为，分子分母用同一去重维度与口径。
```
