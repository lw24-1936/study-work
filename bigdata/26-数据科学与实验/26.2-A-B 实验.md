## 概述

A/B 实验（随机对照实验）是把用户随机分成实验组和对照组，只改变一个变量，通过对比两组指标的差异来判断该变量是否带来真实效果，是因果推断的「黄金标准」。它依赖随机化消除混杂、用假设检验和置信区间量化不确定性、用样本量计算保证统计功效。A/B 实验是互联网产品迭代、算法上线、运营策略验证的核心方法论。

```text
A B 实验核心流程：
1. 假设 —— 明确要验证的改动与核心指标
2. 随机化 —— 用户随机分流到实验组 / 对照组
3. 样本量 —— 基于最小可检测效应与功效计算所需样本
4. 观测 —— 收集两组的指标数据
5. 检验 —— 显著性检验 + 置信区间，判断是否有效
6. 决策 —— 显著则上线，不显著则保留原方案
```

```text
A B 实验三要素：
1. 随机化 —— 消除混杂，保证组间可比
2. 控制变量 —— 只改一个因素，隔离效应
3. 统计推断 —— 用概率语言量化效果与不确定性
```

## 随机化

随机化是把实验单元（用户、设备、请求）随机分配到不同实验组的过程，目的是让所有已知和未知的混杂因素在组间均匀分布，从而把组间指标差异归因于实验变量。随机化是 A/B 实验因果性的基石，常用的有简单随机、分层随机（按用户特征分层再随机）、哈希分流（用用户 ID 哈希值稳定分流）。

```text
随机化要点：
1. 目的 —— 消除混杂，使组间只有实验变量不同
2. 方法 —— 简单随机、分层随机、哈希稳定分流
3. 稳定性 —— 同一用户多次访问应分到同一组（哈希）
4. 分层 —— 按地域/平台/活跃度分层，减少组间方差
5. 失效 —— 随机化被破坏（如交叉污染）则实验不可信
```

```python
import numpy as np

np.random.seed(42)
n = 10000
user_id = np.arange(n)

# 1. 简单随机：均匀分两组
groups = np.random.choice(['control', 'treatment'], size=n, p=[0.5, 0.5])
print("简单随机分组：", np.unique(groups, return_counts=True))

# 2. 哈希稳定分流：同一用户永远落到同一组
def hash_bucket(uid, n_buckets=100):
    return uid % n_buckets   # 简化；生产用 MD5/xxhash

bucket = hash_bucket(user_id)
treatment = bucket < 50      # 前 50 个桶进实验组
print("哈希分流实验组人数：", treatment.sum())

# 3. 分层随机：按平台分层，层内随机
platform = np.random.choice(['ios', 'android'], size=n)
df = {'uid': user_id, 'platform': platform}
# 每层内按 50/50 随机
import pandas as pd
d = pd.DataFrame(df)
d['group'] = d.groupby('platform')['uid'].transform(
    lambda x: np.random.choice(['c', 't'], len(x), p=[0.5, 0.5])
)
print(d.groupby(['platform', 'group']).size())
```

## 样本量

样本量计算在实验开始前确定需要多少用户才能检测出预期的最小效应。它由四个参数决定：显著性水平 α、统计功效 1-β、最小可检测效应 MDE、指标的方差。样本量太小会导致功效不足（有真实效果却检不出），太大则浪费流量与时间。二值指标和连续指标有不同的样本量公式。

```text
样本量四参数：
1. α —— 显著性水平（通常 0.05），犯 I 类错误概率
2. β —— II 类错误概率，功效 = 1 - β（通常 0.8）
3. MDE —— 最小可检测效应（相对提升），越小需样本越多
4. 方差 —— 指标波动越大，需样本越多
```

```text
连续指标（均值类）样本量公式：
n = ( (z_{α/2} + z_β)^2 * 2 * σ^2 ) / δ^2
其中 σ 为指标标准差，δ 为最小可检测绝对效应

二值指标（比率类）样本量公式：
n = ( (z_{α/2} + z_β)^2 * (p1(1-p1) + p2(1-p2)) ) / (p1 - p2)^2
其中 p1、p2 为对照/实验组的比率
```

```python
import numpy as np
from scipy import stats

def sample_size_continuous(alpha, power, sigma, delta):
    """连续指标样本量（每组）"""
    z_alpha = stats.norm.ppf(1 - alpha / 2)   # 双侧
    z_beta = stats.norm.ppf(power)
    n = (z_alpha + z_beta) ** 2 * 2 * sigma ** 2 / delta ** 2
    return int(np.ceil(n))

def sample_size_binary(alpha, power, p1, p2):
    """二值指标样本量（每组）"""
    z_alpha = stats.norm.ppf(1 - alpha / 2)
    z_beta = stats.norm.ppf(power)
    n = (z_alpha + z_beta) ** 2 * (p1 * (1 - p1) + p2 * (1 - p2)) / (p1 - p2) ** 2
    return int(np.ceil(n))

# 例：GMV 均值 100，标准差 200，想检出 5 的提升（绝对 delta=5）
n1 = sample_size_continuous(0.05, 0.8, sigma=200, delta=5)
print(f"连续指标每组样本量：{n1}")

# 例：转化率基线 10%，想检出相对 10% 提升（即 10% -> 11%）
n2 = sample_size_binary(0.05, 0.8, p1=0.10, p2=0.11)
print(f"二值指标每组样本量：{n2}")
```

## 显著性

显著性检验回答「观测到的组间差异是否可能只是随机波动」。它先假设无效果（原假设 H0：两组均值相等），计算在该假设下观测到当前差异（或更极端）的概率 p 值；若 p 值小于显著性水平 α（通常 0.05），则拒绝原假设，认为差异显著。常用双样本 t 检验（连续指标）和 z 检验/卡方检验（二值指标）。

```text
显著性检验要点：
1. 原假设 H0 —— 两组无差异，观测差异来自随机
2. p 值 —— 在 H0 下观测到当前差异及更极端的概率
3. 判定 —— p < α（0.05）拒绝 H0，认为显著
4. I 类错误 —— 无效果却判显著，概率 = α
5. 常用检验 —— t 检验（连续）、z/卡方（二值）
```

```python
import numpy as np
from scipy import stats

np.random.seed(1)
# 对照组与实验组（连续指标，如客单价）
control = np.random.normal(100, 20, 1000)
treatment = np.random.normal(103, 20, 1000)   # 真提升 3

# 双样本 t 检验
t_stat, p_value = stats.ttest_ind(treatment, control, equal_var=False)
print(f"t 统计量={t_stat:.3f}, p 值={p_value:.4f}")
print("显著" if p_value < 0.05 else "不显著")

# 二值指标（转化率）用比例 z 检验
from statsmodels.stats.proportion import proportions_ztest
c_conv = 100; c_n = 1000
t_conv = 120; t_n = 1000
z_stat, p_val = proportions_ztest([t_conv, c_conv], [t_n, c_n])
print(f"z 统计量={z_stat:.3f}, p 值={p_val:.4f}")
```

## 置信区间

置信区间给出效应量的一个区间估计，如「实验组比对照组提升 3%，95% 置信区间为 [1%, 5%]」，比单一的 p 值提供更多信息——既判断显著性，又给出效应大小与精度。95% 置信区间的含义是：重复实验 100 次，约 95 次的区间会包含真实效应。区间不包含 0 等价于显著。

```text
置信区间要点：
1. 定义 —— 效应量估计的区间，反映不确定性
2. 95% CI —— 重复抽样 95% 的区间包含真实值
3. 判显著 —— CI 不含 0 等价于显著（双侧）
4. 信息量 —— 比 p 值多给出效应大小与精度
5. 计算 —— 点估计 ± z_{α/2} * 标准误
```

```text
均值差置信区间公式：
CI = (x̄_t - x̄_c) ± z_{α/2} * sqrt( s_t²/n_t + s_c²/n_c )
其中 x̄ 为样本均值，s 为样本标准差，n 为样本量
```

```python
import numpy as np
from scipy import stats

np.random.seed(2)
control = np.random.normal(100, 20, 1000)
treatment = np.random.normal(103, 20, 1000)

diff = treatment.mean() - control.mean()
se = np.sqrt(treatment.var(ddof=1) / len(treatment)
             + control.var(ddof=1) / len(control))
z = stats.norm.ppf(0.975)          # 双侧 95% -> 1.96
ci_low, ci_high = diff - z * se, diff + z * se

print(f"效应量={diff:.3f}")
print(f"95% 置信区间=[{ci_low:.3f}, {ci_high:.3f}]")
print("显著" if (ci_low > 0 or ci_high < 0) else "不显著")  # 区间不含 0
```

## 多重检验

多重检验问题：当同时检验多个指标或多个实验组时，即使都没有真实效果，也会因为「显著性水平 α 的累积」而出现假阳性（I 类错误膨胀）。例如检验 20 个独立指标，每个 α=0.05，至少一个假显著的概率高达 1-(1-0.05)^20 ≈ 64%。解决方案：Bonferroni 校正（α 除以检验次数）、FDR 控制（Benjamini-Hochberg）、预注册核心指标减少检验次数。

```text
多重检验要点：
1. 问题 —— 检验次数越多，假阳性概率累积越高
2. 假阳性膨胀 —— m 次检验，至少一个假显著 ≈ 1-(1-α)^m
3. Bonferroni —— α 除以 m，最保守，控制 FWER
4. FDR —— Benjamini-Hochberg，控制假发现率，更宽松
5. 实践 —— 预注册主指标，次要指标用校正或作为探索
```

```text
假阳性膨胀公式：
P(至少一个假阳性) = 1 - (1 - α)^m
例：m=20, α=0.05 -> 1 - 0.95^20 ≈ 0.64
Bonferroni 校正：α' = α / m
```

```python
import numpy as np
from statsmodels.stats.multitest import multipletests

# 模拟 20 个指标的 p 值（其中 2 个真有效，18 个纯随机）
np.random.seed(3)
pvals = np.random.uniform(0, 1, 20)
pvals[0], pvals[1] = 0.001, 0.01   # 2 个真有效

# 不校正：p < 0.05 判显著（含假阳性）
naive = (pvals < 0.05).sum()
print(f"不校正显著数：{naive}")

# Bonferroni 校正
bonf_reject, bonf_p, _, _ = multipletests(pvals, alpha=0.05, method='bonferroni')
print(f"Bonferroni 显著数：{bonf_reject.sum()}")

# FDR（Benjamini-Hochberg）
fdr_reject, fdr_p, _, _ = multipletests(pvals, alpha=0.05, method='fdr_bh')
print(f"FDR 显著数：{fdr_reject.sum()}")

# 演示：18 个纯随机 p 值中，不校正时的假阳性期望
random_pvals = np.random.uniform(0, 1, 18)
print(f"纯随机 18 个指标中 p<0.05 的个数：{(random_pvals < 0.05).sum()}")
```

## CUPED

CUPED（Controlled Pre-Experiment Data）利用实验前的协变量（如用户历史指标、实验前同一指标的取值）来降低指标的方差，从而在相同样本量下提升检验灵敏度、缩短实验周期。核心思想是用协变量对指标做回归残差校正，方差削减量正比于协变量与指标的相关系数平方。实验前的同一指标是最强的协变量。

```text
C U P E D 要点：
1. 目标 —— 用实验前数据降低指标方差，提升功效
2. 原理 —— 协变量回归校正，方差减少 ρ² 比例
3. 最佳协变量 —— 实验前同一指标（相关性最高）
4. 收益 —— 相同功效下可减少样本量或缩短实验周期
5. 注意 —— 协变量必须发生在实验开始前，不能污染
```

```text
CUPED 方差削减公式：
Y_cuped = Y - θ * (X - X̄)
其中 X 为实验前协变量，θ 为协方差/方差比
方差削减率 = ρ²（Y 与 X 的相关系数平方）
```

```python
import numpy as np

np.random.seed(4)
n = 5000
# 实验前指标（协变量）
pre = np.random.normal(100, 20, n)
# 实验后指标：与 pre 强相关 + 噪声
post = 0.8 * pre + np.random.normal(0, 10, n)

# 分组
group = np.random.choice([0, 1], n)   # 0 对照，1 实验

# 原始指标方差 vs CUPED 校正后方差
raw_var = np.var(post)
theta = np.cov(post, pre)[0, 1] / np.var(pre)   # 协方差/方差
pre_mean = pre.mean()
post_cuped = post - theta * (pre - pre_mean)
cuped_var = np.var(post_cuped)

print(f"原始方差：{raw_var:.1f}")
print(f"CUPED 后方差：{cuped_var:.1f}")
print(f"方差削减率：{1 - cuped_var / raw_var:.2%}")

# 相关系数平方应约等于削减率
rho = np.corrcoef(post, pre)[0, 1]
print(f"ρ² = {rho**2:.2%}")
```

## 应用场景实战

### 场景一：推荐算法上线 A/B 实验完整评估

```python
import numpy as np
from scipy import stats
from statsmodels.stats.proportion import proportions_ztest

np.random.seed(5)
# 模拟：对照组（旧算法）与实验组（新算法）的点击数据
n_c, n_t = 20000, 20000
# 曝光 -> 点击（二值）转化率：旧 10%，新 11%
clk_c = np.random.binomial(1, 0.10, n_c)
clk_t = np.random.binomial(1, 0.11, n_t)

# 1. 描述统计
print(f"对照组 CTR={clk_c.mean():.4f}, 实验组 CTR={clk_t.mean():.4f}")

# 2. 显著性检验（比例 z 检验）
z_stat, p_val = proportions_ztest([clk_t.sum(), clk_c.sum()], [n_t, n_c])
print(f"z={z_stat:.3f}, p={p_val:.4f}")

# 3. 效应量与置信区间
p1, p2 = clk_t.mean(), clk_c.mean()
diff = p1 - p2
se = np.sqrt(p1 * (1 - p1) / n_t + p2 * (1 - p2) / n_c)
ci_low, ci_high = diff - 1.96 * se, diff + 1.96 * se
print(f"CTR 提升={diff:.4f}, 95% CI=[{ci_low:.4f}, {ci_high:.4f}]")

# 4. 决策
if p_val < 0.05 and ci_low > 0:
    print("结论：显著正向，建议全量上线")
elif p_val >= 0.05:
    print("结论：不显著，保留原方案")
```

```text
实验评估检查清单：
1. 实验前 —— 样本量是否达标？分流是否随机稳定？
2. 实验中 —— 是否有 SRM（样本比例失调）？有无交叉污染？
3. 实验后 —— 主指标是否显著？CI 是否含 0？有无辛普森悖论？
4. 稳健性 —— 是否做了多重检验校正？效应量是否够业务意义？
```

### 场景二：用 CUPED 缩短实验周期

```python
import numpy as np
from scipy import stats

np.random.seed(6)
n = 8000
# 实验前 7 天 GMV 作为协变量
pre_gmv = np.random.lognormal(4, 0.7, n)
# 实验期 GMV 与 pre 强相关 + 处理效应
post_gmv = 0.9 * pre_gmv + np.random.normal(20, 5, n)
group = np.random.choice([0, 1], n)
# 给实验组加一个 2% 的处理效应
post_gmv[group == 1] *= 1.02

# 原始 t 检验
t_raw, p_raw = stats.ttest_ind(post_gmv[group == 1], post_gmv[group == 0])
print(f"原始检验：t={t_raw:.3f}, p={p_raw:.4f}")

# CUPED 校正
theta = np.cov(post_gmv, pre_gmv)[0, 1] / np.var(pre_gmv)
post_cuped = post_gmv - theta * (pre_gmv - pre_gmv.mean())
t_cuped, p_cuped = stats.ttest_ind(post_cuped[group == 1], post_cuped[group == 0])
print(f"CUPED 检验：t={t_cuped:.3f}, p={p_cuped:.4f}")

# 方差削减率
reduction = 1 - np.var(post_cuped) / np.var(post_gmv)
print(f"方差削减率={reduction:.2%}")
print("说明：CUPED 使 t 值更大、p 值更小，相同效果更容易检出")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 预注册主指标与假设 —— 实验前定好核心指标与方向，避免事后挑显著指标
2. 样本量先行 —— 用 MDE 和功效算好所需样本，再决定实验时长
3. 哈希稳定分流 —— 保证同一用户多次访问落在同一组，避免稀释效应
4. 报告置信区间 —— 不只报 p 值，效应量 + CI 才是完整结论
5. 优先用 CUPED —— 有实验前数据就做方差削减，缩短实验周期
6. 多指标用校正 —— 主指标之外的多指标检验用 FDR/Bonferroni 控制假阳性
7. 监控 SRM —— 检查各组样本比例是否与预期一致，发现分流故障

### 踩坑记录

```text
坑 1：数据没攒够就下结论（偷看 p 值）
结论：p 值在实验早期剧烈波动，提前停止导致假阳性或假阴性。
原因：未达样本量就反复观察显著性，犯「偷看」错误，α 被抬高。
解法：预先算好样本量，攒够数据后再做一次检验，或采用序贯检验。

坑 2：多指标同时检验不校正
结论：把随机波动的次要指标误判为显著，上线无效甚至有害改动。
原因：几十个指标每个 0.05，假阳性概率累积到很高。
解法：预注册主指标，次要指标用 Bonferroni/FDR 校正，或降级为探索。

坑 3：实验组间用户交叉污染
结论：对照组用户「泄露」到实验组（如共享账号、社交传播），效应被稀释。
原因：分流粒度不当（用户级改设备级），或社交网络产生溢出效应。
解法：选对分流粒度，评估溢出场景改用聚类随机或网络实验。

坑 4：忽略辛普森悖论
结论：整体指标显著提升，但各细分人群反而下降，误判上线。
原因：分组比例差异与细分效应方向相反，整体被加权扭曲。
解法：按关键维度（平台/新老用户）分层检查效应方向一致性。

坑 5：把相关性当因果下决策
结论：把历史相关关系当作实验效果，上线无效策略。
原因：未做随机化对照实验，观测差异可能来自混杂变量。
解法：关键决策必须以随机化 A/B 实验为准，观测分析只做假设来源。
```
