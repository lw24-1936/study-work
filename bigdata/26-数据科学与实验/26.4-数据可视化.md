## 概述

数据可视化是把抽象的数据转换为图形表达的过程，其核心目标是利用人类视觉系统对位置、长度、颜色、面积等图形属性的高敏感度，快速揭示数据中的模式、异常与趋势。在大数据链路中，可视化既是探索性数据分析（EDA）的工具，也是面向业务与决策者的最终交付形态。选型时通常遵循「探索用代码库（Matplotlib/Seaborn/Plotly）、前端报表用 ECharts、自助分析用 Superset/Tableau/Power BI、运维监控用 Grafana」的分层思路。

```text
数据可视化选型分层：
- 探索分析层：Matplotlib（底层控制）、Seaborn（统计默认美）、Plotly（交互）
- 前端展示层：ECharts（开源、中文友好、图表全）
- 自助 BI 层：Superset（开源）、Tableau（商业标杆）、Power BI（微软生态）
- 监控运维层：Grafana（时序指标、告警、Dashboard 即代码）
核心原则：图形属性映射数据 → 位置最精确 → 长度次之 → 颜色面积谨慎
```

## Matplotlib 基础绘图

Matplotlib 是 Python 生态最底层的绘图库，仿照 MATLAB 提供面向对象（Figure/Axes）与 pyplot 函数式两套接口，几乎其他所有 Python 可视化库都构建于其之上。它适合对图形元素做像素级精细控制，代价是需要手写大量样式代码。掌握 Figure、Axes、Artist 三层对象模型以及坐标系、刻度、图例、颜色映射等概念，是后续学习 Seaborn 与 Plotly 的基础。

```text
Matplotlib 核心概念：
- Figure：整张画布，可包含多个 Axes（子图）
- Axes：实际绘图区域，一个 Axes 承载一条或多条曲线
- Artist：所有可见元素（线、文本、图例）的基类
- 两种接口：pyplot（隐式状态机）与 Axes 方法（显式、推荐）
- 常用：subplots 布局、legend 图例、set_xlabel/ylabel 标签、cmap 配色
```

```python
import matplotlib
matplotlib.use("Agg")  # 无显示环境下保存图片而非弹窗
import matplotlib.pyplot as plt
import numpy as np

# 准备数据
x = np.linspace(0, 2 * np.pi, 100)
y1, y2 = np.sin(x), np.cos(x)

# 面向对象方式创建 1 行 2 列子图
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

ax1.plot(x, y1, label="sin(x)", color="#1f77b4", linewidth=2)
ax1.plot(x, y2, label="cos(x)", color="#ff7f0e", linestyle="--")
ax1.set_title("折线图", fontsize=12)
ax1.set_xlabel("x"); ax1.set_ylabel("y")
ax1.legend(); ax1.grid(alpha=0.3)

# 散点图 + 颜色映射
rng = np.random.default_rng(42)
px = rng.normal(0, 1, 200); py = rng.normal(0, 1, 200)
sc = ax2.scatter(px, py, c=np.sqrt(px**2 + py**2), cmap="viridis", s=15)
ax2.set_title("散点图"); fig.colorbar(sc, ax=ax2, label="半径")

fig.tight_layout()
fig.savefig("matplotlib_demo.png", dpi=120)
print("图片已保存: matplotlib_demo.png")
```

## Seaborn 统计可视化

Seaborn 构建于 Matplotlib 之上，面向统计可视化，内置对 DataFrame 的原生支持与更美观的默认主题。它的核心价值在于用极少的代码生成带置信区间、分面（facet）、分组聚合等统计语义的图表，例如回归拟合线、箱线图、小提琴图、热力图等。对于探索性数据分析，Seaborn 通常能以 Matplotlib 几分之一的代码量产出可直接用于报告的高质量图形。

```text
Seaborn 核心能力：
- 数据接口：直接传 DataFrame，用 x/y/hue/col 指定维度
- 关系图：relplot / scatterplot / lineplot
- 分布图：histplot / kdeplot / boxplot / violinplot
- 分类图：catplot / barplot / countplot
- 统计图：regplot（回归）、heatmap（矩阵热力，常配相关矩阵）
- 分面：FacetGrid / figure-level 函数（relplot、catplot、displot）
```

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# 加载内置数据集
tips = sns.load_dataset("tips")

# 1) 分面回归：按日期(smoker)分行、时间(time)分列
g = sns.lmplot(data=tips, x="total_bill", y="tip",
               col="time", row="smoker", height=3)
g.savefig("seaborn_lmplot.png")

# 2) 相关矩阵热力图
corr = tips[["total_bill", "tip", "size"]].corr()
fig, ax = plt.subplots(figsize=(5, 4))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm",
            square=True, ax=ax)
ax.set_title("相关性热力图")
fig.tight_layout(); fig.savefig("seaborn_heatmap.png")
print("图片已保存: seaborn_lmplot.png / seaborn_heatmap.png")
```

## Plotly 交互式图表

Plotly 提供面向浏览器的交互式图表，支持缩放、悬停提示、图例点击筛选、动画等能力，可导出为独立 HTML 或在 Jupyter 中内嵌。其 Python 库 plotly.express 面向快速绘图，plotly.graph_objects 面向精细控制，二者共享同一套底层 figure 数据结构（JSON 序列化）。它特别适合需要让读者自行探索数据的场景，例如数据报告、大屏与数据产品原型。

```text
Plotly 核心能力：
- plotly.express：一行代码出图，自动推断聚合与配色
- graph_objects：细粒度控制 trace、layout 与 update
- 交互特性：hover 提示、缩放平移、图例筛选、滑杆动画
- 输出：fig.show()、fig.write_html()、fig.to_json()
- 与 Dash 组合可构建完整数据应用
```

```python
import plotly.express as px
import plotly.graph_objects as go

df = px.data.gapminder().query("year == 2007")

# 1) express 气泡图（GDP x 寿命 x 人口，颜色区分大洲）
fig1 = px.scatter(df, x="gdpPercap", y="lifeExp", size="pop",
                  color="continent", hover_name="country",
                  log_x=True, size_max=60, title="2007 年各国 GDP 与预期寿命")
fig1.write_html("plotly_bubble.html")

# 2) graph_objects 组合柱状图 + 折线（双 y 轴）
months = ["1月", "2月", "3月", "4月"]
sales = [120, 150, 130, 180]; rate = [0.10, 0.15, 0.12, 0.20]
fig2 = go.Figure()
fig2.add_trace(go.Bar(x=months, y=sales, name="销售额"))
fig2.add_trace(go.Scatter(x=months, y=rate, name="增长率",
                          yaxis="y2", mode="lines+markers"))
fig2.update_layout(title="销售额与增长率", yaxis2=dict(overlaying="y",
                  side="right", tickformat=".0%"))
fig2.write_html("plotly_dual_axis.html")
print("已生成: plotly_bubble.html / plotly_dual_axis.html")
```

## ECharts 前端图表库

ECharts 是百度开源的 JavaScript 图表库，提供折线、柱状、饼图、地图、桑基图、关系图等丰富图表，中文文档完善、社区活跃，是国产前端数据可视化的首选。它通过声明式 option 对象配置图表，支持大数据量的增量渲染与流式加载。在离线数仓与数据平台中，ECharts 常作为前端大屏与报表页面的渲染引擎，后端只需输出 JSON 数据即可驱动。

```text
ECharts 要点：
- 声明式配置：一个 option 对象描述坐标系、series、legend、tooltip
- 图表类型：bar / line / pie / scatter / map / sankey / graph / heatmap
- 数据驱动：后端产出 JSON，前端 setOption 渲染，前后端解耦
- 大数据量：dataZoom 缩放、progressive 渐进渲染、WebGL 加速
- 主题与导出：自定义主题、内置导出图片能力
```

```json
{
  "title": {"text": "各省销售额"},
  "tooltip": {"trigger": "axis"},
  "xAxis": {"type": "category", "data": ["北京", "上海", "广东", "浙江"]},
  "yAxis": {"type": "value"},
  "series": [
    {"name": "销售额", "type": "bar",
     "data": [820, 932, 901, 934]},
    {"name": "利润", "type": "line",
     "data": [220, 182, 191, 234]}
  ]
}
```

```text
上述 JSON 即为 ECharts 的 option 对象，前端通过
echarts.init(dom).setOption(option) 完成渲染，后端仅需
负责把数仓查询结果序列化成该结构即可，实现前后端彻底解耦。
```

## Superset 自助式 BI

Apache Superset 是开源的现代数据探索与可视化平台，由 Airbnb 开源，支持连接绝大多数 SQL 数据库与 OLAP 引擎（Hive、Trino、ClickHouse、Druid 等）。它面向业务分析师提供无需写代码的拖拽式图表构建、SQL Lab 手写查询、以及由多张图表拼装而成的 Dashboard。其「语义层」允许为字段定义指标与维度，屏蔽底层表结构复杂度，是数据团队低成本搭建自助分析入口的常见选择。

```text
Superset 要点：
- 数据源：支持 SQLAlchemy 连接众多数据库 / 引擎
- 图表：Explore 界面拖拽维度与指标，自动生成 SQL
- SQL Lab：直接编写 SQL、查看结果、保存为虚拟数据集
- 语义层：定义 metric（聚合指标）与 column（维度）供复用
- Dashboard：多图表布局、过滤器联动、定时刷新与邮件订阅
```

## Grafana 监控可视化

Grafana 是面向时序指标与运维监控的开源可视化平台，以「数据源 + 面板 + 告警 + Dashboard」为核心模型，支持 Prometheus、InfluxDB、MySQL、Elasticsearch、Loki 等上百种数据源。它强调 Dashboard 即代码（可导出 JSON 复用）与告警规则管理，是观测性（可观测性）三支柱中「可视化」环节的事实标准。数据工程团队也常用它监控任务运行时长、数据延迟、数据量与管道吞吐等指标。

```text
Grafana 要点：
- 数据源：Prometheus / InfluxDB / MySQL / ClickHouse / Loki 等
- 面板：Graph、Stat、Gauge、Table、Heatmap、Bar gauge
- 变量：模板变量实现同一 Dashboard 多环境/多实例复用
- 告警：阈值规则 → 通知渠道（邮件、钉钉、Slack）
- Dashboard as Code：JSON 导出/导入，便于版本化管理
```

```json
{
  "datasource": {"type": "prometheus", "uid": "prom"},
  "targets": [
    {"expr": "rate(etl_task_duration_seconds_sum[5m])",
     "legendFormat": "任务耗时速率"}
  ],
  "title": "ETL 任务耗时监控",
  "fieldConfig": {
    "defaults": {"unit": "s"}
  }
}
```

```text
上述 JSON 为 Grafana 面板配置片段。数据平台常见做法是让
调度系统把任务状态推送到 Prometheus，再用 Grafana 面板
聚合展示任务成功率、耗时 P99 等关键健康指标。
```

## Tableau 商业智能

Tableau 是商业智能可视化领域的标杆产品，以「拖拽即分析」的交互范式著称，其核心技术 VizQL 能将拖拽操作自动翻译为可视化查询。它支持连接数据库、数据仓库、文件与云端数据源，提供强大的 LOD（Level of Detail）表达式做跨粒度计算，并拥有成熟的 Server/Cloud 协作与权限体系。Tableau 的强项在于探索式分析与故事化呈现，但作为商业软件需要授权成本。

```text
Tableau 要点：
- 拖拽维度/度量自动生成图表，颜色/大小/形状映射字段
- 数据连接：数据库、数仓、Excel、云平台（Snowflake/BigQuery）
- LOD 表达式：FIXED / INCLUDE / EXCLUDE 控制计算粒度
- Tableau Prep 做数据清洗，Tableau Server 做共享与权限
- 故事（Story）串联多视图用于叙事式汇报
```

```text
Tableau 为闭源商业软件，无代码可运行。典型使用流程：
1) 连接数据源（如数仓的订单宽表）
2) 拖「地区」到列、「销售额」到行 → 自动生成柱状图
3) 拖「品类」到颜色 → 堆叠细分
4) 用 LOD 表达式 FIXED [客户] 计算客户终身价值
5) 发布到 Server 并配置行级权限后嵌入报表门户
```

## Power BI 微软 BI

Power BI 是微软的商业智能套件，与 Excel、Azure、Teams 深度集成，采用 DAX（Data Analysis Expressions）作为建模与计算语言。其核心是「Power Query 取数清洗 → 数据模型（星型/雪花）→ DAX 度量 → 可视化报表」的完整链路。凭借较低的边际成本与微软生态绑定，Power BI 在企业尤其是传统行业拥有极高渗透率，是商业 BI 阵营与 Tableau 并列的双雄。

```text
Power BI 要点：
- Power Query（M 语言）：数据抽取、清洗、转换
- 数据模型：多表关系（星型模式），关系而非扁平表
- DAX：度量值、上下文转换（行上下文/筛选上下文）
- 可视化：报表页 + 钻取 + 书签 + RLS 行级安全
- 生态：Power BI Service 云端共享、与 Excel/Azure 集成
```

```text
Power BI 为闭源商业软件，无代码可运行。典型建模流程：
1) Power Query 导入事实表与维度表并清洗
2) 建立维度表到事实表的一对多关系（星型模式）
3) DAX 定义度量，如：
   销售额 = SUM('销售事实'[金额])
   同比 = DIVIDE([销售额], CALCULATE([销售额], SAMEPERIODLASTYEAR('日期'[日期])))
4) 拖拽度量与维度生成报表，配置 RLS 后发布到 Service
```

## 应用场景实战

### 场景一：销售数据的探索性分析

数据团队拿到一份电商销售明细后，需要快速摸清销售额分布、品类占比与时间趋势，再产出一份可交互报告供业务查看。用 Seaborn 完成快速探索，用 Plotly 产出交互式交付件。

```python
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt
import plotly.express as px

# 构造模拟销售数据
rng = np.random.default_rng(7)
n = 1000
df = pd.DataFrame({
    "date": pd.date_range("2026-01-01", periods=n, freq="H"),
    "category": rng.choice(["数码", "服饰", "食品", "家居"], n),
    "amount": np.round(rng.lognormal(mean=4, sigma=1.2, size=n), 2),
})

# 1) Seaborn 探索：品类销售额分布（箱线图）
plt.figure(figsize=(8, 5))
sns.boxplot(data=df, x="category", y="amount", hue="category")
plt.title("各品类销售额分布")
plt.savefig("eda_boxplot.png"); plt.close()

# 2) 按天聚合，Plotly 输出交互式时间趋势
df["day"] = df["date"].dt.date
daily = df.groupby(["day", "category"], as_index=False)["amount"].sum()
fig = px.line(daily, x="day", y="amount", color="category",
              title="各品类销售额日趋势")
fig.write_html("sales_trend.html")
print("生成: eda_boxplot.png / sales_trend.html")
```

### 场景二：大数据平台监控大屏

数据平台需要一面监控大屏，实时展示任务成功率、数据延迟、吞吐量等关键指标。后端调度系统把指标写入 Prometheus，Grafana 负责可视化与告警；对外展示大屏则用 ECharts 渲染后端聚合的 JSON 结果。这里给出 ECharts 大屏对应的后端数据产出示例。

```python
import json

# 后端从数仓查询后，拼装 ECharts 所需的 option 结构
def build_dashboard_option(task_success_rate: float,
                           delays: dict, throughput: list) -> dict:
    return {
        "title": {"text": "数据平台监控大屏"},
        "tooltip": {},
        "series": [
            {"name": "任务成功率", "type": "gauge",
             "detail": {"formatter": "{value}%"},
             "data": [{"value": round(task_success_rate * 100, 1)}]},
            {"name": "数据延迟", "type": "pie", "radius": "55%",
             "data": [{"name": k, "value": v}
                      for k, v in delays.items()]},
            {"name": "吞吐", "type": "line",
             "data": throughput}
        ],
    }

opt = build_dashboard_option(
    0.98,
    {"实时(<1min)": 80, "准实时(1-5min)": 15, "离线(>1h)": 5},
    [1200, 1350, 1280, 1500, 1600],
)
with open("dashboard_option.json", "w", encoding="utf-8") as f:
    json.dump(opt, f, ensure_ascii=False, indent=2)
print("已生成 dashboard_option.json，供 ECharts 前端消费")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 依据数据类型选图形：比较用柱状、趋势用折线、占比用饼图（少用）、分布用直方/箱线、关系用散点、构成用堆叠/桑基。
2. 优先用位置与长度编码核心数据，颜色只做分类或强调，避免用面积、3D 效果制造视觉欺骗。
3. 探索用 Seaborn 快速出图，交付用 Plotly/ECharts 交互化，最终固化进 Superset/Tableau 做成自助报表。
4. 统一配色与主题：连续变量用感知均匀的 colormap（viridis），分类色板固定顺序，保持品牌一致性。
5. 大屏与报表坚持「后端产出 JSON、前端渲染」的解耦架构，避免在 SQL/前端里散落重复口径。
6. 为图表补全标题、坐标轴单位、图例与数据时间范围，缺省信息是可视化最常见的信息丢失点。
7. 监控类图表用 Grafana 并配合告警阈值，让「看图」升级为「被通知」，而非依赖人工盯屏。

### 踩坑记录

```text
坑 1
结论：Matplotlib 在服务器/容器中 fig.show() 无反应或报错
原因：缺少图形后端（无 X server / 无显示设备）
解法：import matplotlib 后执行 matplotlib.use("Agg")，改用 fig.savefig 输出文件

坑 2
结论：中文标题/标签渲染为方框乱码
原因：默认字体不含中文字形
解法：plt.rcParams["font.sans-serif"] = ["SimHei", "Arial Unicode MS"]，并设置 axes.unicode_minus = False

坑 3
结论：Plotly 图表在 Jupyter 中正常但导出的 HTML 空白或交互失效
原因：误用 fig.show() 而非 write_html，或渲染依赖外部 CDN 且环境无外网
解法：统一用 fig.write_html()，离线环境设置 include_plotlyjs="inline" 内嵌 JS

坑 4
结论：Seaborn 热力图 annot=True 时数字重叠看不清
原因：单元格太小、字体过大或数值小数位过多
解法：用 fmt=".2f" 控制精度、缩小 annot 字号、增大画布 figsize

坑 5
结论：ECharts 大数据量（百万点）渲染卡顿
原因：默认一次性绘制全部图形元素
解法：开启 progressive 渐进渲染、dataZoom 采样、或改用 large 模式 / WebGL 渲染

坑 6
结论：Grafana 面板数据源切换后 SQL 查询报语法错误
原因：不同数据源查询方言差异（PromQL、InfluxQL、SQL 不通用）
解法：切换数据源时同步改写查询，或用变量绑定数据源并在面板中按类型适配
```
