## 概述

因果推断回答「X 是否导致了 Y」的问题，而不仅仅是「X 与 Y 是否相关」。它用潜在结果框架（Potential Outcomes）定义因果效应、用 DAG 刻画变量间的因果结构、用 ATE/ATT 量化效应大小，并在无法做随机实验时用 PSM、DID 等方法从观测数据中近似识别因果效应。因果推断是 A/B 实验之外的补充，用于评估无法随机化的政策、活动或历史决策。

```text
因果推断两大框架：
1. 潜在结果框架（Rubin）—— 比较同一单元接受/不接受处理的潜在结果
2. 结构因果模型（Pearl）—— 用 DAG 与 do 算子刻画因果结构

因果推断核心问题：
3. 识别 —— 从观测数据能否唯一确定因果效应（可识别性）
4. 估计 —— 用何种方法估计效应大小（ATE/ATT）
5. 混杂 —— 如何消除混杂变量的偏差
```

## DAG

DAG（有向无环图）用节点表示变量、有向边表示因果方向，是可视化与推理因果结构的工具。它帮助识别混杂变量、中介变量、对撞变量，判断哪些路径是因果路径、哪些是非因果的「后门路径」，从而确定「控制哪些变量」能消除混杂。DAG 是 Pearl 结构因果模型的核心语言。

```text
D A G 要点：
1. 节点 —— 变量，边 —— 因果方向（X -> Y 表示 X 影响 Y）
2. 后门路径 —— X 与 Y 间经过混杂的非因果路径
3. 中介 —— X -> M -> Y，M 在因果路径上，不应控制
4. 对撞 —— X -> C <- Y，控制 C 反而引入对撞偏差

后门准则：用一组变量 Z 阻断所有后门路径且不打开对撞路径，
控制 Z 后 X 对 Y 的效应即为因果效应
```

```python
import networkx as nx

# X=处理(发券)，Y=结果(下单)，C=混杂(活跃度)
G = nx.DiGraph()
G.add_edges_from([('C', 'X'), ('C', 'Y'), ('X', 'Y')])

paths = list(nx.all_simple_paths(G.to_undirected(), 'X', 'Y'))
print("X 与 Y 之间的路径：", paths)          # X-C-Y 与 X-Y

parents = list(nx.ancestors(G, 'X'))
print("X 的父节点（混杂）：", parents)         # ['C']
print("结论：控制 C 即可阻断后门路径 X<-C->Y，识别因果效应")
```

## Confounder

Confounder（混杂变量）是同时影响处理 X 和结果 Y 的变量，它制造了 X 与 Y 之间的虚假相关。如果不控制混杂变量，观测到的关联会混入混杂造成的偏差，导致「相关但不因果」的错误结论。识别并控制混杂是观测性因果推断的核心任务，常用方式有分层、回归调整、倾向得分、匹配。

```text
Confounder 要点：
1. 定义 —— 同时影响处理 X 和结果 Y 的第三变量
2. 危害 —— 制造虚假相关，扭曲因果效应估计
3. 识别 —— 用 DAG 找 X 与 Y 的共同原因
4. 控制 —— 分层、回归调整、倾向得分匹配

混杂偏差示意：C->X，C->Y，X->Y
不控制 C：关联 = 因果效应 + 混杂偏差
控制 C：剥离 C 的影响，剩下的才是 X 的因果效应
```

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

np.random.seed(1)
n = 5000
C = np.random.normal(0, 1, n)                      # 混杂：活跃度
X = np.random.binomial(1, 1 / (1 + np.exp(-0.5 * C)))
Y = np.random.binomial(1, 1 / (1 + np.exp(-(0.8 * C + 0.5 * X))))  # X 真效应 0.5
df = pd.DataFrame({'C': C, 'X': X, 'Y': Y})

naive = sm.Logit(df['Y'], sm.add_constant(df[['X']])).fit(disp=0)
print(f"不控制混杂的效应估计：{naive.params['X']:.3f}")   # 高估

adj = sm.Logit(df['Y'], sm.add_constant(df[['X', 'C']])).fit(disp=0)
print(f"控制混杂后的效应估计：{adj.params['X']:.3f}")      # 接近 0.5
```

## Potential Outcomes

潜在结果框架（Rubin Causal Model）定义每个单元在「接受处理」和「不接受处理」两种情形下的潜在结果 Y(1) 和 Y(0)，因果效应是同一单元两个潜在结果之差。根本问题在于同一单元只能观测到其中一个（反事实缺失），因此因果推断的核心是把「个体因果效应」转化为可估计的「平均因果效应」，借助随机化或可忽略性假设。

```text
Potential Outcomes 要点：
1. 潜在结果 —— Y(1) 接受处理，Y(0) 不接受处理
2. 个体因果效应 —— Y(1) - Y(0)，通常不可观测
3. 反事实问题 —— 同一单元只能观测一个潜在结果
4. 可忽略性 —— (Y(1), Y(0)) ⟂ X | C，条件随机化假设

观测结果：Y_i = X_i * Y_i(1) + (1 - X_i) * Y_i(0)
随机化下：E[Y|X=1] - E[Y|X=0] 无偏估计 ATE
```

```python
import numpy as np

np.random.seed(2)
n = 10000
Y0 = np.random.normal(50, 10, n)   # 不接受处理的潜在结果
Y1 = Y0 + 5                        # 接受处理的结果（个体效应恒 5）
X = np.random.binomial(1, 0.5, n)
Y_obs = np.where(X == 1, Y1, Y0)   # 只观测到其中一个

ate = Y_obs[X == 1].mean() - Y_obs[X == 0].mean()
print(f"估计 ATE={ate:.3f}（真实 ATE=5）")
print(f"对照组样本 { (X == 0).sum() } 个，其 Y1 永远不可观测（反事实缺失）")
```

## ATE

ATE（Average Treatment Effect，平均因果效应）是「全体人群」接受处理与不接受处理的潜在结果之差的期望，即 E[Y(1) - Y(0)]。它衡量某个处理（政策、药物、活动）对整个群体的平均影响，是最常用的因果效应度量。在随机化实验或满足可忽略性假设下，ATE 可由组间均值差无偏估计。

```text
A T E 要点：
1. 定义 —— ATE = E[Y(1) - Y(0)]，全人群平均效应
2. 意义 —— 处理对所有人的平均影响
3. 估计 —— 随机化下 = 处理组均值 - 对照组均值
4. 假设 —— 可忽略性 + 正值性（每个单元都有概率接受处理）

公式：ATE = E[Y(1)] - E[Y(0)]
估计：ATÊ = (1/n1)ΣY_i(1) - (1/n0)ΣY_j(0)
```

```python
import numpy as np

np.random.seed(3)
n = 2000
Y0 = np.random.normal(100, 15, n)
Y1 = Y0 + np.random.normal(8, 3, n)   # 平均效应 8，有异质性
X = np.random.binomial(1, 0.5, n)
Y = np.where(X == 1, Y1, Y0)

ate = Y[X == 1].mean() - Y[X == 0].mean()
n1, n0 = (X == 1).sum(), (X == 0).sum()
se = np.sqrt(Y[X == 1].var(ddof=1) / n1 + Y[X == 0].var(ddof=1) / n0)
print(f"ATE={ate:.3f}，95% CI=[{ate-1.96*se:.3f}, {ate+1.96*se:.3f}]")
```

## ATT

ATT（Average Treatment Effect on the Treated，处理组的平均处理效应）是「实际接受处理的那部分人」的因果效应，即 E[Y(1) - Y(0) | X=1]。它回答「处理对已接受处理的人平均有多大影响」，比 ATE 更聚焦，常用于政策评估——关注的是「被政策覆盖的人」受益多少。当处理效应存在异质性时，ATT 与 ATE 不同。

```text
A T T 要点：
1. 定义 —— ATT = E[Y(1) - Y(0) | X=1]，处理组平均效应
2. 聚焦 —— 只关心实际接受处理的人群
3. 与 ATE 差异 —— 异质性下两者不同（选择偏差）
4. 估计 —— 需为处理组构建反事实（匹配/加权）

公式：ATT = E[Y(1)|X=1] - E[Y(0)|X=1]
反事实项 E[Y(0)|X=1] 不可直接观测，需用对照组近似
```

```python
import numpy as np

np.random.seed(4)
n = 3000
C = np.random.normal(0, 1, n)              # 活跃度
X = (C > 0.3).astype(int)                  # 活跃用户更可能被处理
Y0 = 50 + 5 * C + np.random.normal(0, 5, n)
Y1 = Y0 + 3 + 2 * C                        # 效应随 C 增大
Y = np.where(X == 1, Y1, Y0)

att_true = (Y1 - Y0)[X == 1].mean()
att_naive = Y[X == 1].mean() - Y[X == 0].mean()
print(f"真实 ATT={att_true:.3f}")
print(f"朴素估计={att_naive:.3f}（有选择偏差）")
print(f"处理组平均 C={C[X==1].mean():.3f} vs 对照组 {C[X==0].mean():.3f}")
```

## PSM

PSM（Propensity Score Matching，倾向得分匹配）用倾向得分（给定协变量下接受处理的概率）作为匹配依据，为每个处理组单元在对照组找倾向得分相近的单元配对，从而构造可比的对照组，消除观测混杂。它适合「处理非随机」的观测数据，步骤：估计倾向得分 → 匹配 → 检验平衡性 → 估计效应。PSM 只能消除已观测混杂，无法处理未观测混杂。

```text
P S M 要点：
1. 倾向得分 —— e(X) = P(X=1 | C)，给定协变量接受处理的概率
2. 原理 —— 相同倾向得分的单元，协变量分布平衡
3. 步骤 —— 估计得分 → 匹配 → 平衡性检验 → 效应估计
4. 局限 —— 只消除观测混杂，未观测混杂仍会偏倚

性质：X ⟂ C | e(C)，即给定倾向得分后处理与协变量独立
因此匹配倾向得分可近似实现随机化
```

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors

np.random.seed(5)
n = 4000
C1 = np.random.normal(0, 1, n); C2 = np.random.binomial(1, 0.4, n)
X = np.random.binomial(1, 1 / (1 + np.exp(-(0.8 * C1 + 0.5 * C2))))
Y = 10 + 2 * C1 + 3 * C2 + 4 * X + np.random.normal(0, 3, n)   # 真效应 4
df = pd.DataFrame({'C1': C1, 'C2': C2, 'X': X, 'Y': Y})

lr = LogisticRegression(max_iter=1000).fit(df[['C1', 'C2']], df['X'])
df['ps'] = lr.predict_proba(df[['C1', 'C2']])[:, 1]

treated, control = df[df['X'] == 1], df[df['X'] == 0]
nn = NearestNeighbors(n_neighbors=1).fit(control[['ps']])
idx = nn.kneighbors(treated[['ps']])[1].flatten()
matched = control.iloc[idx]

print(f"PSM 后 ATT={treated['Y'].mean() - matched['Y'].mean():.3f}（真值 4）")
print(f"朴素估计={treated['Y'].mean() - control['Y'].mean():.3f}（有偏）")
```

## DID

DID（Difference-in-Differences，双重差分）通过比较「处理组处理前后的变化」与「对照组同期变化」的差异来估计因果效应，能消除不随时间变化的选择偏差和共同时间趋势。它需要平行趋势假设（若无处理，两组结果变化趋势相同）。DID 常用于政策评估——比较政策实施地区与非实施地区在政策前后的差异。

```text
D I D 要点：
1. 思想 —— 处理组前后差 - 对照组前后差 = 净效应
2. 平行趋势 —— 假设无处理时两组变化趋势一致
3. 消除 —— 不随时间变化的选择偏差 + 共同时间冲击
4. 数据 —— 需处理前后两期 + 处理/对照两组

估计量：DID = (Ȳ_{T,后}-Ȳ_{T,前}) - (Ȳ_{C,后}-Ȳ_{C,前})
回归：Y = β0 + β1*Treat + β2*Post + β3*(Treat*Post) + ε，β3 即 DID
```

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

np.random.seed(6)
n = 2000
treat = np.random.binomial(1, 0.5, n)         # 是否政策城市
post = np.random.binomial(1, 0.5, n)          # 政策前后
base = 30 + 5 * treat                          # 不随时间变的选择偏差
Y = base + 3 * post + 5 * treat * post + np.random.normal(0, 2, n)  # DID 真效应 5
df = pd.DataFrame({'treat': treat, 'post': post, 'y': Y})
df['tp'] = df['treat'] * df['post']

X = sm.add_constant(df[['treat', 'post', 'tp']])
model = sm.OLS(df['y'], X).fit()
print(f"DID 效应（tp 系数）={model.params['tp']:.3f}（真值 5）")
```

## 应用场景实战

### 场景一：优惠券发放效果评估（PSM 匹配）

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors

np.random.seed(7)
n = 8000
age = np.random.normal(35, 10, n)
spend = np.random.lognormal(5, 0.6, n)          # 历史消费（混杂）
p_coupon = 1 / (1 + np.exp(-(0.6 * (spend - 200) / 100)))
coupon = np.random.binomial(1, p_coupon)        # 高消费更可能被发券
order = 50 + 0.8 * spend + 30 * coupon + np.random.normal(0, 20, n)  # 真效应 30
df = pd.DataFrame({'age': age, 'spend': spend, 'coupon': coupon, 'order': order})

naive = df[df['coupon'] == 1]['order'].mean() - df[df['coupon'] == 0]['order'].mean()
print(f"朴素效应估计={naive:.2f}")

lr = LogisticRegression(max_iter=1000).fit(df[['age', 'spend']], df['coupon'])
df['ps'] = lr.predict_proba(df[['age', 'spend']])[:, 1]
treated, control = df[df['coupon'] == 1], df[df['coupon'] == 0]
nn = NearestNeighbors(n_neighbors=1).fit(control[['ps']])
idx = nn.kneighbors(treated[['ps']])[1].flatten()
matched = control.iloc[idx]

att = treated['order'].mean() - matched['order'].mean()
print(f"PSM 后 ATT={att:.2f}（真值 30）")
print(f"匹配前 spend 差={treated['spend'].mean()-control['spend'].mean():.2f}")
print(f"匹配后 spend 差={treated['spend'].mean()-matched['spend'].mean():.2f}")
```

```text
评估结论要点：
1. 朴素估计因处理组高消费而高估发券效果
2. PSM 匹配后协变量平衡，估计更接近真实效应
3. 注意：PSM 只消除观测混杂，未观测混杂风险仍在
4. 结合业务：发券增量订单 vs 发券成本做 ROI 判断
```

### 场景二：政策效果 DID 评估

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm

np.random.seed(8)
regions = 30
treated_regions = set(range(10))                # 前 10 个地区实施政策
rows = []
for r in range(regions):
    is_treat = 1 if r in treated_regions else 0
    base = 100 + np.random.normal(0, 5)         # 地区固定效应
    for post in [0, 1]:
        y = base + 2 * post + 8 * is_treat * post + np.random.normal(0, 2)  # 政策效应 8
        rows.append({'region': r, 'treat': is_treat, 'post': post, 'y': y})

df = pd.DataFrame(rows)
df['tp'] = df['treat'] * df['post']
X = sm.add_constant(df[['treat', 'post', 'tp']])
X = pd.concat([X, pd.get_dummies(df['region'], prefix='r', drop_first=True)], axis=1)
model = sm.OLS(df['y'], X.astype(float)).fit()
print(f"DID 政策效应={model.params['tp']:.3f}（真值 8）")

pre_t = df[(df['treat'] == 1) & (df['post'] == 0)]['y'].mean()
pre_c = df[(df['treat'] == 0) & (df['post'] == 0)]['y'].mean()
print(f"政策前处理组={pre_t:.2f} vs 对照组={pre_c:.2f}（平行趋势检验思路）")
```

## 最佳实践与踩坑记录

### 最佳实践

1. 先画 DAG 再定控制变量 —— 用 DAG 识别混杂、中介、对撞，避免控制错变量
2. 明确估计目标 —— 想回答 ATE（全体）还是 ATT（被处理者），选对估计量
3. 检验平衡性 —— PSM 匹配后必须检查协变量是否平衡，不匹配则重配
4. 验证平行趋势 —— DID 前用政策前多期数据检验处理/对照组趋势一致性
5. 因果结论要谨慎 —— 观测性方法只能消除观测混杂，未观测混杂需敏感性分析
6. 优先随机实验 —— 能随机化就随机化，观测方法作为补充而非替代
7. 报告假设与局限 —— 明确可忽略性/平行趋势等假设是否成立及证据

### 踩坑记录

```text
坑 1：控制中介变量导致效应被低估
结论：因果效应被「过度控制」，真实效应被中介吸收而缩水。
原因：把 X -> M -> Y 路径上的中介 M 当作混杂控制，切断了因果路径。
解法：用 DAG 区分混杂与中介，中介变量不纳入控制。

坑 2：控制对撞变量引入选择偏差
结论：控制了 X -> C <- Y 的对撞点 C，反而制造虚假相关。
原因：对撞点条件化会打开原本关闭的路径（对撞偏差）。
解法：识别对撞结构，避免条件化对撞变量及其后代。

坑 3：PSM 匹配后不做平衡性检验
结论：匹配质量差，效应估计仍有混杂偏差。
原因：倾向得分估计不准或匹配算法不当，协变量未真正平衡。
解法：匹配后对比标准化均差（SMD），不平衡则调整模型或匹配法。

坑 4：DID 忽略平行趋势检验
结论：政策前两组趋势已不同，DID 估计有偏。
原因：平行趋势假设不成立，对照组不能代表处理组的反事实趋势。
解法：用政策前多期数据做平行趋势检验，不成立则改用合成控制法。

坑 5：把观测关联当成因果结论
结论：上线「看起来有效」的策略，实际无效甚至有害。
原因：未识别混杂或未做反事实推断，混淆相关与因果。
解法：明确因果假设、控制混杂、优先随机实验验证。
```
