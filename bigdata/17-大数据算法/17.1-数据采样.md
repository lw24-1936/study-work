## 概述

采样是从大规模数据集中抽取一个能代表总体的子集，用子集的统计特征近似总体的技术。在大数据场景下，采样让「在 PB 级数据上做精确计算」变成「在小样本上做近似计算」，把成本降几个数量级。它广泛用于数据探索、A/B 测试、查询近似（COUNT DISTINCT、分位数）、图算法（PageRank 采样）等。采样算法的核心是「无偏性」——每个样本被抽中的概率要可控、可算。

```text
采样解决的核心问题：
1. 成本 —— 全量计算太贵，小样本近似
2. 速度 —— 交互式探索/实时查询，秒级出近似结果
3. 无偏 —— 样本要能代表总体，误差可控
4. 流式 —— 数据是流（未知总量），要在线采样
```

## Random Sampling 随机采样

随机采样（简单随机采样）是「每个元素以相同概率独立被抽中」的采样，是所有采样方法的基础。离线场景直接「洗牌取前 k」或「按概率过滤」即可，每个元素被选中的概率相等（k/N）。它保证样本是无偏的，是 A/B 测试随机分桶、统计估计的标准做法。

```text
随机采样要点：
1. 定义 —— 每个元素独立、等概率被抽中
2. 概率 —— 抽样率 p = k/N，每个元素选中概率 p
3. 实现 —— 洗牌取前 k（Fisher-Yates）或按概率过滤
4. 无偏性 —— 样本期望等于总体，方差随样本量增大而减小
```

```python
import random
import numpy as np

# 简单随机采样：从 N=10000 里抽 k=100
data = list(range(10000))
sample = random.sample(data, 100)          # 无放回，等概率

# 按概率过滤（有放回近似，适合大数据流式）
p = 100 / 10000
filtered = [x for x in data if random.random() < p]
print(f"random.sample 抽到 {len(sample)} 个，概率过滤抽到 {len(filtered)} 个")

# 估计总体均值（无偏）
population = np.random.randn(10000)
sample_mean = np.mean(random.sample(list(population), 500))
print(f"样本均值 {sample_mean:.4f} ≈ 总体均值 {population.mean():.4f}")
```

## Reservoir Sampling 蓄水池采样

蓄水池采样解决「数据总量未知的流式等概率采样」：从流中抽取 k 个元素，保证「流中每个元素被选中的概率都是 k/N（N 未知）」。算法：前 k 个直接进蓄水池；第 i（i>k）个元素以 k/i 的概率替换池中随机一个元素。它只用 O(k) 空间、一趟扫描，是流式采样、日志采样、MapReduce 采样的基石。

```text
蓄水池采样要点：
1. 场景 —— 流式数据、总量未知、只扫一遍
2. 算法 —— 前 k 个进池；第 i 个以 k/i 概率替换池中随机元素
3. 空间 —— O(k)，不随 N 增长
4. 无偏 —— 每个元素最终在池中的概率都是 k/N
```

```python
import random

def reservoir_sampling(stream, k):
    """从流 stream 中等概率抽 k 个元素"""
    reservoir = []
    for i, item in enumerate(stream, start=1):
        if i <= k:
            reservoir.append(item)
        else:
            j = random.randint(1, i)
            if j <= k:
                reservoir[j - 1] = item
    return reservoir

# 验证：每个元素被选中概率接近 k/N
N, k, trials = 1000, 20, 2000
counts = [0] * N
for _ in range(trials):
    for idx in reservoir_sampling(range(N), k):
        counts[idx] += 1
expected = k / N * trials
print(f"元素 0 被选中 {counts[0]} 次，期望 {expected:.0f} 次")
```

## Stratified Sampling 分层采样

分层采样先把总体按某个特征分成若干层（strata，如按地区、按年龄段），再在每层内独立随机采样。它保证每层都有足够样本，避免简单随机采样「小层抽不到」的风险，且能降低估计方差（层内同质）。常用于「既要总体估计、又要保证每个子群体都有代表性」的场景（如用户分群调查、按地域配额采样）。

```text
分层采样要点：
1. 先分层 —— 按关键特征（地区/年龄/等级）划分
2. 层内采样 —— 每层独立随机抽（可按比例或等额）
3. 优势 —— 保证小层有样本，降低方差
4. 适用 —— 总体异质、关心子群体估计
```

```python
import random

# 按城市分层采样：每层抽 10%
users = [("北京", i) for i in range(1000)] + \
        [("上海", i) for i in range(500)] + \
        [("广州", i) for i in range(100)]

def stratified_sample(data, key, rate=0.1):
    strata = {}
    for item in data:
        strata.setdefault(key(item), []).append(item)
    result = []
    for layer in strata.values():
        k = max(1, int(len(layer) * rate))
        result.extend(random.sample(layer, k))
    return result

sample = stratified_sample(users, key=lambda x: x[0])
cities = {}
for c, _ in sample:
    cities[c] = cities.get(c, 0) + 1
print("各城市样本数:", cities)  # 每层都有样本，小城市不会被漏掉
```

## Weighted Sampling 加权采样

加权采样是「每个元素被抽中的概率与其权重成正比」的采样。用于「某些元素更重要，希望它们更可能被抽中」的场景（如按交易金额加权的风险抽样、按流量加权的节点采样）。实现有 A-ES 算法（指数分布技巧：给每个元素生成 u_i^(1/w_i)，取最小/最大的 k 个）、别名表法（O(1) 单次采样）。

```text
加权采样要点：
1. 定义 —— P(选中 i) ∝ w_i，权重越大越可能被抽中
2. 实现 —— A-ES（指数技巧 O(N log N)）、别名表（O(1) 单次）
3. 场景 —— 按重要性/金额/流量加权抽样
4. 注意 —— 权重为 0 的元素不会被抽中，负权重需特殊处理
```

```python
import random
import heapq

def weighted_sample(items, weights, k):
    """A-ES 算法：无放回加权采样 k 个"""
    # 每个元素生成 key = random()^(1/w)，取 key 最大的 k 个
    keys = []
    for item, w in zip(items, weights):
        if w > 0:
            key = random.random() ** (1.0 / w)
            heapq.heappush(keys, (key, item))
            if len(keys) > k:
                heapq.heappop(keys)   # 保留 key 最大的 k 个
    return [item for _, item in keys]

items = ["普通", "VIP", "普通", "普通"]
weights = [1, 100, 1, 1]
# VIP 权重 100，被抽中概率远超普通
result = weighted_sample(items, weights, 2)
print("加权采样结果:", result)
```

## Systematic Sampling 系统采样

系统采样（等距采样）是「按固定间隔抽取」：随机选一个起点，然后每隔固定步长抽一个。它实现简单、样本分布均匀，适合「数据有自然顺序（时间、编号）」且「无明显周期性」的场景。风险是：如果数据存在与步长同频的周期，会抽到有偏的样本（如每 7 天抽一次恰好都抽到周一）。

```text
系统采样要点：
1. 方法 —— 随机起点 + 固定步长 k（k = N/n）
2. 优点 —— 简单、分布均匀、易实现
3. 风险 —— 数据有周期性时产生偏差
4. 适用 —— 有自然顺序、无周期的数据
```

```python
import random

def systematic_sample(data, k):
    n = len(data)
    step = n // k
    start = random.randint(0, step - 1)
    return [data[i] for i in range(start, n, step)][:k]

data = list(range(1000))
sample = systematic_sample(data, 10)
print("系统采样（步长 100）:", sample)
```

## Sampling Bias 采样偏差

采样偏差指样本不能代表总体、导致估计系统性偏离真实值。常见来源：自选择偏差（主动参与的人更极端）、幸存者偏差（只看成功案例）、便利采样（只采容易采到的）、时间窗口偏差（只看活跃期）。偏差一旦引入，增大样本量也无法消除——样本量大只是让「错的估计」更精确，不是更正确。

```text
采样偏差要点：
1. 本质 —— 样本与总体的系统性差异，导致估计偏离
2. 来源 —— 自选择、幸存者、便利采样、时间窗口
3. 危害 —— 样本量增大也无法消除偏差
4. 对策 —— 随机化采样、分层、加权校正（IPW）
```

```text
经典偏差案例：
- 幸存者偏差：只统计「没流失的用户」评估功能，忽略了流失用户的不满
- 时间窗口偏差：只在「活动期间」采样，忽略了平时行为
- 便利采样：只采「在线活跃用户」，低估沉默用户占比
```

## Importance Sampling 重要性采样

重要性采样用「从一个方便采样的分布 q 采样，再用权重 w = p/q 校正」来估计目标分布 p 的期望。它解决「目标分布 p 难采样，但可以从 q 采样」的问题，核心是权重校正保证无偏。在强化学习（离线策略评估）、蒙特卡洛积分、稀有事件模拟（小概率事件用偏置分布放大再校正）中广泛使用。

```text
重要性采样要点：
1. 思想 —— 从 q 采样，用权重 w=p/q 校正，估计 p 的期望
2. 公式 —— E_p[f] = E_q[f · p/q]，权重比校正
3. 无偏 —— 权重校正保证估计无偏
4. 风险 —— q 与 p 差异大时权重方差大，估计不稳定
```

```python
import numpy as np

# 用重要性采样估计 E_p[x^2]，p 是标准正态
# 从 q = 均匀分布 U(-5,5) 采样，权重 = p(x)/q(x)
np.random.seed(0)
n = 100000
x = np.random.uniform(-5, 5, n)              # 从 q 采样
q_density = 1 / 10                            # q = 均匀分布密度
p_density = np.exp(-x**2 / 2) / np.sqrt(2 * np.pi)  # p = 标准正态
weights = p_density / q_density

est = np.mean(x**2 * weights)
print(f"重要性采样估计 E[x^2] = {est:.4f}（真实值 1.0）")
```

## Streaming Sampling 流式采样

流式采样在「数据持续流入、只能扫一遍、总量未知」的约束下抽样，是蓄水池采样、时间衰减采样、滑动窗口采样的统称。核心挑战：无法预知总量、无法回看、内存有限。流式采样的目标是在这些约束下给出尽可能无偏、有代表性的样本，供实时统计、实时监控、在线学习使用。

```text
流式采样要点：
1. 约束 —— 单遍扫描、总量未知、内存有限
2. 工具 —— 蓄水池（等概率）、滑动窗口（最近 N）、时间衰减（近期权重高）
3. 用途 —— 实时统计、在线监控、在线学习
4. 权衡 —— 样本代表性 vs 内存 vs 计算开销
```

```python
import random
from collections import deque

# 滑动窗口采样：只保留最近 N 个元素（有界内存）
class SlidingWindowSampler:
    def __init__(self, n):
        self.n = n
        self.window = deque(maxlen=n)

    def update(self, item):
        self.window.append(item)

    def sample(self, k):
        return random.sample(list(self.window), min(k, len(self.window)))

s = SlidingWindowSampler(100)
for i in range(1000):
    s.update(i)          # 流式更新
print("滑动窗口采样:", s.sample(5))   # 只从最近 100 个里抽
```

## 应用场景实战

### 场景一：大表去重计数的近似采样

```python
# 用蓄水池采样近似估计「不同用户数」的分布
import random

def reservoir(stream, k):
    pool = []
    for i, x in enumerate(stream, 1):
        if i <= k:
            pool.append(x)
        elif random.randint(1, i) <= k:
            pool[random.randint(0, k - 1)] = x
    return pool

# 模拟日志流，估计活跃用户中 VIP 占比
users = ["vip" if random.random() < 0.1 else "normal" for _ in range(1000000)]
sample = reservoir(users, 10000)
vip_ratio = sum(1 for u in sample if u == "vip") / len(sample)
print(f"VIP 占比估计 {vip_ratio:.4f}（真实 0.1 附近）")
```

### 场景二：分层采样做 A/B 测试分桶

```python
import random

# 按地区分层随机分桶，保证实验组对照组各地区均衡
def stratified_bucket(users, buckets=2):
    strata = {}
    for u in users:
        strata.setdefault(u["city"], []).append(u)
    assign = {}
    for city, us in strata.items():
        random.shuffle(us)
        for i, u in enumerate(us):
            assign[u["id"]] = i % buckets
    return assign

users = [{"id": i, "city": c} for i, c in enumerate(
    ["北京"]*1000 + ["上海"]*500 + ["广州"]*100)]
assign = stratified_bucket(users)
print("北京用户分桶:", [assign[i] for i in range(3)])
```

## 最佳实践与踩坑记录

### 最佳实践

1. 总量未知的流式场景用蓄水池采样，O(k) 空间、等概率无偏
2. 关心子群体代表性用分层采样，别用简单随机（会漏小层）
3. 数据有自然顺序且无周期用系统采样，简单高效
4. 权重差异大用 A-ES 或别名表做加权采样
5. 采样前先检查偏差来源（幸存者、自选择、时间窗口）
6. 用分层/加权校正抵消已知偏差

### 踩坑记录

```text
坑 1：把「样本量大」当「样本无偏」
结论：结论错得越精确。
原因：偏差是系统性的，样本量增大只降方差、不降偏差。
解法：先治偏差（随机化/分层/加权），再谈样本量。

坑 2：系统采样撞上数据周期
结论：抽到的样本有规律性偏差（如都抽到周一）。
原因：步长与数据周期同频，采样点固定落在周期的同一位置。
解法：检测数据周期性，换随机采样或打乱顺序再系统采样。

坑 3：加权采样权重有 0 或负值
结论：权重为 0 的元素永不抽中、负权重报错。
原因：算法假设权重为正，0 导致 key 无定义、负值破坏概率语义。
解法：过滤 0 权重，负权重先转为正（如加常数偏移）。

坑 4：重要性采样 q 与 p 差异过大
结论：估计方差爆炸，结果极不稳定。
原因：权重 p/q 在 q 尾部巨大，少数样本主导估计。
解法：选与 p 形状相近的 q，或用重尾 q（如 t 分布）。

坑 5：蓄水池采样没理解「流式」前提，用在随机访问数据上
结论：实现了 O(N) 的蓄水池，却不如直接 random.sample 高效。
原因：蓄水池是为单遍流设计的，随机访问数据可直接索引采样。
解法：能随机访问就用 random.sample，流式才用蓄水池。
```
