## 概述

算法工程师面试的「机器学习与推荐」部分，考的是「模型原理 + 业务落地」两条线：一条线是经典机器学习（过拟合、正则化、评估指标、损失函数），另一条线是工业推荐/搜索系统（召回—排序—重排、向量检索 ANN、特征工程）。大数据背景的算法岗尤其看重「模型怎么在工程上落地」，因此每个知识点都要能答出「原理 + 为什么 + 工程实现」。本主题按「核心概念 + 高频面试题（含参考答案）+ 关键代码」组织。

```text
机器学习与推荐面试的考察重点：
1. 机器学习 —— 过拟合、正则化、损失函数、评估指标、逻辑回归
2. 推荐系统 —— 召回/排序/重排、协同过滤、矩阵分解、冷启动
3. 搜索系统 —— 倒排索引、相关性打分、Query 理解
4. ANN —— 向量召回、HNSW、LSH、PQ/IVF
5. 特征工程 —— 归一化、离散化、Embedding、特征交叉
```

## 机器学习面试

机器学习面试的「基础题」集中在：偏差与方差、过拟合与欠拟合、正则化、损失函数、梯度下降、评估指标。这类题看似简单，却是区分「背答案」和「真理解」的关键——面试官会追问「为什么 L1 产生稀疏解」「AUC 为什么对类别不平衡不敏感」这类机制层面的问题。高频题：过拟合怎么解决、L1/L2 区别、AUC 原理、逻辑回归为什么用 Sigmoid、梯度下降的变种。

```text
机器学习高频面试题：
1. 偏差 vs 方差 —— 欠拟合 vs 过拟合
2. 过拟合怎么解决 —— 数据/正则/降复杂度/早停/Dropout
3. L1 vs L2 正则 —— 稀疏解 vs 平滑解
4. AUC 是什么、为什么用 —— 排序能力、对类别不平衡不敏感
5. 逻辑回归原理 —— Sigmoid + 最大似然 + 交叉熵
6. 梯度下降变种 —— SGD/Momentum/Adam
```

```python
# 手撕：逻辑回归梯度下降（含 L2 正则）
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def logistic_regression(X, y, lr=0.1, epochs=1000, l2=0.01):
    n, d = X.shape
    w = np.zeros(d)
    for _ in range(epochs):
        z = X @ w
        grad = X.T @ (sigmoid(z) - y) / n + l2 * w  # L2 正则梯度
        w -= lr * grad
    return w

X = np.array([[1, 2], [2, 3], [3, 4], [5, 6], [6, 7]])
y = np.array([0, 0, 0, 1, 1])
w = logistic_regression(X, y)
print(w)  # 正负样本分界线附近的权重
```

## 推荐系统面试

推荐系统面试考「漏斗结构」和「核心算法」两层：漏斗是「召回 → 粗排 → 精排 → 重排」四段式；核心算法是协同过滤（UserCF/ItemCF）、矩阵分解（SVD++）、FM/DeepFM、以及冷启动。高频题：召回和排序的区别、UserCF 和 ItemCF 怎么选、冷启动怎么解决、DeepFM 为什么比 LR 强。答这类题的关键是「把工程链路讲清楚」——先讲漏斗再讲每层的算法。

```text
推荐系统高频面试题：
1. 召回 vs 排序 —— 召回求快求全、排序求准
2. UserCF vs ItemCF —— 用户多选 ItemCF、物品更新快选 UserCF
3. 冷启动 —— 内容画像/热门兜底/探索利用
4. 矩阵分解 —— 用户-物品隐向量内积
5. DeepFM —— FM 显式交叉 + DNN 隐式交叉
```

```python
# 手撕：ItemCF 物品相似度 + Top-N 推荐
from collections import defaultdict

def item_similarity(user_items):
    # 统计物品共现次数
    co_occur = defaultdict(lambda: defaultdict(int))
    item_users = defaultdict(set)
    for user, items in user_items.items():
        for i in items:
            item_users[i].add(user)
    for user, items in user_items.items():
        for i in items:
            for j in items:
                if i != j:
                    co_occur[i][j] += 1
    # 余弦相似度
    sim = defaultdict(dict)
    for i in co_occur:
        for j in co_occur[i]:
            sim[i][j] = co_occur[i][j] / (len(item_users[i]) * len(item_users[j])) ** 0.5
    return sim

user_items = {'u1': ['a', 'b', 'c'], 'u2': ['b', 'c'], 'u3': ['a', 'b']}
print(item_similarity(user_items))  # b 和 c 相似度最高
```

## 搜索系统面试

搜索系统面试考「倒排索引」和「相关性排序」：倒排索引是「词 → 文档列表」的映射（区别于正排的「文档 → 词」）；相关性打分从 TF-IDF 演进到 BM25，再到 Learning to Rank。高频题：倒排索引怎么构建、BM25 比 TF-IDF 好在哪、Query 理解包含哪些步骤、搜索和推荐的区别。答题要点是把「离线建索引 + 在线检索打分」两段讲清楚。

```text
搜索系统高频面试题：
1. 倒排索引原理 —— 词 → 文档列表，配合跳表/压缩
2. TF-IDF vs BM25 —— BM25 引入长度归一化和饱和项
3. Query 理解 —— 分词/纠错/改写/意图识别
4. 搜索 vs 推荐 —— 主动 vs 被动、精准 vs 探索
5. Learning to Rank —— Pointwise/Pairwise/Listwise
```

```text
倒排索引结构（面试必背）：
词项（term） → 倒排列表（posting list）
  ├─ 文档 ID 列表（docID，升序存储，可用差值压缩）
  ├─ 词频（term frequency）
  └─ 位置信息（position，短语查询用）
查询时：对多个 term 的 posting list 做交集（AND）/并集（OR）
```

## ANN 面试

ANN（近似最近邻）是推荐/搜索「向量召回」的底层引擎，面试考「为什么要近似」和「三大流派」：图索引（HNSW）、哈希（LSH）、量化（PQ/IVF）。高频题：为什么不用暴力 KNN、HNSW 原理、LSH 原理、PQ 怎么压缩向量、召回率和速度怎么权衡。答这类题的关键是「讲清索引结构」——面试官会追问 HNSW 的层结构、LSH 的哈希函数设计。

```text
ANN 高频面试题：
1. 为什么用 ANN —— 精确检索 O(n·d) 在大规模下不可行
2. HNSW 原理 —— 多层跳表 + 贪心搜索，复杂度 O(log n)
3. LSH 原理 —— 哈希把相似向量映射到同一桶
4. PQ 原理 —— 向量分段 + 聚类量化压缩存储
5. 召回率 vs 速度 —— 通过参数（M/efSearch）权衡
```

```text
HNSW 层级结构（面试必背）：
第 0 层：包含所有节点（稠密图，高精度）
上层：按概率指数递减抽样（稀疏图，快速导航）
查询：从最顶层贪心向下 → 每层找最近邻 → 第 0 层精搜
参数：M（每节点连接数）、efSearch（候选集大小）
```

## 特征工程面试

特征工程面试考「特征处理」和「特征交叉」两类：特征处理是归一化/标准化、离散化/分箱、缺失值填充、类别编码（One-Hot/Label/Target）；特征交叉是人工组合特征、FM 自动二阶交叉、以及 Embedding 表示。高频题：归一化和标准化的区别、为什么树模型不需要归一化而线性模型需要、什么时候离散化、Embedding 和 One-Hot 的区别。答题要点是「结合模型特性」——不同模型对特征的敏感度不同。

```text
特征工程高频面试题：
1. 归一化 vs 标准化 —— Min-Max vs Z-Score
2. 树模型 vs 线性模型 —— 树不依赖特征尺度、线性模型需要
3. 离散化的好处 —— 抗异常值、引入非线性、稀疏加速
4. One-Hot vs Embedding —— 高维稀疏 vs 低维稠密
5. 特征交叉 —— 人工组合 vs FM/DeepFM 自动交叉
```

```python
# 手撕：标准化（Z-Score）与归一化（Min-Max）
import numpy as np

def z_score(x):
    return (x - np.mean(x)) / np.std(x)

def min_max(x):
    return (x - np.min(x)) / (np.max(x) - np.min(x))

x = np.array([1.0, 2.0, 3.0, 4.0, 100.0])  # 含异常值
print(z_score(x))   # 异常值仍远离均值
print(min_max(x))   # 异常值把其他值压缩到极小区间
```

## 应用场景实战

### 场景一：手撕「AUC 计算」

```python
# 手撕：根据预测分数和真实标签计算 AUC
def auc_score(y_true, y_score):
    # 按分数降序排序
    pairs = sorted(zip(y_score, y_true), key=lambda p: -p[0])
    pos = sum(y_true)
    neg = len(y_true) - pos
    pos_rank_sum = 0
    pos_seen = 0
    for _, label in pairs:
        if label == 1:
            pos_seen += 1
            pos_rank_sum += pos_seen
    # 处理并列分数：用平均秩
    if pos == 0 or neg == 0:
        return 0.5
    return (sum(i + 1 for i, (_, l) in enumerate(pairs) if l == 1)
            - pos * (pos + 1) / 2) / (pos * neg)

y_true = [0, 1, 0, 1, 1]
y_score = [0.2, 0.8, 0.3, 0.9, 0.7]
print(auc_score(y_true, y_score))  # 接近 1.0 表示排序能力好
```

### 场景二：手撕「协同过滤 Top-N 推荐」

```python
# 手撕：基于 ItemCF 相似度给用户推荐 Top-N 物品
def recommend(user, user_items, sim, top_n=2):
    seen = set(user_items[user])
    scores = {}
    for item in seen:
        for other, s in sim.get(item, {}).items():
            if other not in seen:
                scores[other] = scores.get(other, 0) + s
    return sorted(scores.items(), key=lambda p: -p[1])[:top_n]

user_items = {
    'u1': ['a', 'b'],
    'u2': ['b', 'c'],
    'u3': ['a', 'b', 'c'],
}
sim = {
    'a': {'b': 0.8, 'c': 0.5},
    'b': {'a': 0.8, 'c': 0.9},
    'c': {'b': 0.9, 'a': 0.5},
}
print(recommend('u1', user_items, sim, top_n=2))  # 推荐 c（相似度 0.9）
```

## 最佳实践与踩坑记录

### 最佳实践

1. 答模型题用「原理 → 为什么有效 → 工程落地」三段式
2. 推荐系统题先画「召回 → 排序 → 重排」漏斗，再展开每层算法
3. ANN 题背熟 HNSW 的「多层图 + 贪心搜索」，这是区分度所在
4. 评估指标题区分「业务指标（点击率/转化率）vs 模型指标（AUC/召回）」
5. 特征题结合模型答，如「树模型无需归一化，线性模型必须」

### 踩坑记录

```text
坑 1：把 AUC 答成「曲线下面积」就不再展开
结论：答不出 AUC 的本质，得分低。
原因：AUC 的本质是「正样本排在负样本前面的概率」，反映排序能力。
解法：讲清 AUC = P(正样本分数 > 负样本分数)，并说明对类别不平衡不敏感。

坑 2：分不清召回和排序的职责
结论：把两者算法混为一谈，链路答乱。
原因：召回解决「候选从百万到百」的召回率和速度，排序解决「百到十」的精度。
解法：记牢「召回求快求全（双塔/协同过滤/向量），排序求准（精排模型）」。

坑 3：答 ANN 只说「近似查找」说不出索引结构
结论：被追问 HNSW/LSH 原理时卡壳。
原因：只记了结论没记结构，而索引结构是 ANN 的考察重点。
解法：背熟 HNSW 多层图、LSH 哈希桶、PQ 分段量化三种索引。

坑 4：特征工程答成「万能公式」，不区分模型
结论：回答「所有模型都要归一化」这类错误结论。
原因：树模型基于分裂阈值，对特征单调变换不敏感，无需归一化。
解法：区分「线性/距离模型需要归一化，树模型不需要」。

坑 5：冷启动只答「热门兜底」
结论：方案单一，体现不出分层策略。
原因：冷启动分「用户冷启动 / 物品冷启动 / 系统冷启动」三类，策略不同。
解法：用户冷启动用画像+热门，物品冷启动用内容特征+探索，系统冷启动用规则。
```
