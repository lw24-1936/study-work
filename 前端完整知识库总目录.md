# 前端工程师完整知识库总目录

> **定位**：面向前端开发工程师、Web 全栈工程师、前端架构师、移动端跨平台工程师以及前端技术负责人，建立从计算机基础、Web 原理、HTML/CSS/JavaScript，到 TypeScript、浏览器、工程化、React/Vue、Node.js、性能、安全、测试、可观测性、跨端、微前端、Serverless、SSR/SSG、WebAssembly、AI 前端与企业级前端架构的完整知识体系。
>
> **目标**：不仅掌握“怎么写页面”，还要掌握浏览器为什么这样运行、网络请求如何完成、渲染如何发生、框架为什么这样设计、工程系统如何构建、性能如何优化、安全问题如何治理，以及如何设计大型前端应用。
>
> **知识库结构**：公共计算机基础 → Web 基础 → HTML/CSS → JavaScript → TypeScript → 浏览器与网络 → 前端工程化 → UI 框架 → 状态管理 → 数据请求 → Node.js/BFF → 性能 → 安全 → 测试 → 可观测性 → 跨端 → 微前端 → SSR/SSG → WebAssembly → AI 前端 → 架构设计 → 综合项目。
